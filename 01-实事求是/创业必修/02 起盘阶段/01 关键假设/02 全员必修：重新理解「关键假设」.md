# 全员必修：重新理解「关键假设」

**讲师**：Truman（一堂CEO / 课程总设计师）
**课程性质**：一堂新人入门第一课《重新理解"业务里程碑"》的第一个核心知识点——是整个一堂科学课程体系的**底层地基**
**课程地位**：一堂最早、最值钱、也最缺练的课题
- **最早**：一堂第一节课的第一个知识点（XY创业者）
- **最值钱**：一堂30%-50%的高分课题都和它有关（五步法/需求/产品内核/壁垒/ROI/转化率/业务公式等）
- **最缺练**：99%的人理解还很浅，「看似听懂/并不会用」最多的课题
**Truman原话**：「这是我在面试时，判断一个人科学素养高低的最简单的一个方法」
**交付模型**：关键假设Ω模型 + ABCD象限模型 + 鼓励团队提假设工具箱
**教研支撑**：10+年亲身操盘实践 + 150+失败细节研究 + 访谈大量百亿美金高管/赛道头部大佬 + 22万+字共建作业
**一句话定位**：用确定性的前提假设，去解决高难度的业务问题——关键假设思维，就是从"愿望"到"科学"

## 一、为什么关键假设如此重要：普遍痛点

**六种最常见的业务驱动姿势（都有硬伤）**：
- **愿景驱动**：我有一个美好的愿望，我很看好，所以努力一定能做成
- **直觉驱动**：我有一个直觉or灵感，用直觉来指导做事
- **经验驱动**：根据过去经验做事，用已有经验指导新任务
- **对标驱动**：同行做什么，我就照抄什么，完全抄同行总不会错
- **运气驱动**：我相信我八字很硬，总是运气不差，我喜欢赌一把
- **老板驱动**：老板说什么我就做什么

**核心问题**：大量业务一号位/核心团队，各有各的姿势和问题——
- 逮着一个商业机会，头脑一热，all in，砸了全部资源去赌
- 跟团队探讨创业可行性，总是鸡同鸭讲，没办法专业地平等对话
- 面对具体业务卡点/难题，想一出是一出，靠直觉，没体系
- 项目做了一堆，决策做了很多，有对有错，但没积累什么认知

**灵魂拷问**：既然在科学领域（物理/化学/社会学/心理学），"提假设"是基本工具，缺失了寸步难行——那为什么在科学管理领域，假设思维应用很少呢？

## 二、核心概念：X型 vs Y型创业者

### X型创业者（愿景驱动）
- 典型姿势：我在做一个抖音女装带货公司 / 年轻人都喜欢的白酒品牌 / 下沉市场连锁火锅店
- 核心动作：组建完整团队 → 凑几十万 → 3-6个月开发 → 推到市场看反馈 → 看看能不能成功
- 致命特征：迷恋自己的灵感和idea，整个想法一大坨，没有拆解细节和风险，愿望很美好但默认努力就能成
- **追问一句「最需要验证什么？哪个点最决定成败？」——有一半一号位没想清楚**

### Y型创业者（假设驱动）
- 典型姿势：「你这个业务/渠道/产品的关键假设是什么？」
- 核心信念：不要看业务表面的现象（数据/产品形态/用户评价），而是围绕前提假设来推进业务
- 对成功的态度：默认业务有很大风险、极容易失败，提前把"能成"的前提条件拆出来，一步步测试
- 对结果的信念：在模型和假设确定的情况下，结果往往是客观确定的——而且往往是小概率成功的

**金句**：「想出一个idea一点不值钱。这种庞大的愿景，至少有几十上百个人跟你有过相同的想法。而真正值钱的，是这个idea背后一整套的关键假设。」

## 三、什么是"关键假设"：核心定义

**假设** = 你的模式如果想成立，它所依赖的所有关键前提条件
- 这些假设如果全部验证成立 → 业务基本就跑通了
- 如果有一条不成立 → 业务很难走下去，需要转型甚至放弃

**关键假设** = 所有假设里面，风险最高、对你创业最重要的假设

**一句话解读本质**：用确定性的前提假设，去解决高难度的业务问题。不要只盯着结果+碰运气，而是把结果拆解成一系列的前提假设，每一个假设又有前提假设。不要只奢望于运气好，而是在每一个"前提假设"上思考和做功。

## 四、Truman十年关键假设段位进化史

**第一阶段：用直觉做业务（工作前4年）**
- 在美团做产品经理，级别低，工作简单：产品方案、项目管理、数据分析
- 有一个笔记本叫《我的创业想法》，每个idea写了一堆优势123456，都非常兴奋
- 状态：典型的X型选手——迷恋设计、迷恋自己的灵感和idea、整个想法一大坨没有拆解、觉得机会都很大、默认努力就能成
- 自评：「那个时候觉得自己可棒了，天赋异禀，有很多很棒的想法」

**第二阶段：被挑战（开始接触假设思维）**
- 开始意识到：原来做业务还有另一种思维方式
- 被高手追问「你这个项目会死在哪里？」——开始懵，后来慢慢理解
- 从盲目自信 → 开始懂得拆解风险

**第三阶段：碎片积累**
- 大量接触各种项目搞砸案例，收集150+失败细节
- 需求太弱/天花板低/商业亏损/补贴失误/产品力弱/过早细化……
- 开始尝试找规律：「能不能真正找到一套科学的、简洁的、普适有效的拆解工具？」

**第四阶段：体系成型**
- 研究国内外经典教材：《精益创业》（价值假设+增长假设）、《商业模式新生代》（9宫格）、精益画布
- 不满意现有工具 → 带团队自力更生 → 从150+失败分类合并同类项 → 诞生「一堂五步法」
- 起名"一堂五步法"，正式成为一套成体系的科学创业工具

**第五阶段：大量刻意练习**
- 为了练五步法，主动设计各种练习机会：路演嘉宾提问/晚餐聊业务/抽烟扎堆捞人/主动打电话/CEO问诊
- 一年内从＜10次拆解 → 50-100次拆解
- 努力拉满专业度，追求用道理说服对方 → 约50%项目当场给出N万级别建议 → 至少20+假设现场被案主自己证伪
- 「那一年我收到了很多'发着光'的好评——但我一直没好意思承认，我并不是单纯对大家好，其实是我训练的样本太少了」

**第六阶段：全面专家（2021年起）**
- 继续升级五步法模型，展开每个模块具体实操方法论
- 培养内部专家教练（张磊/孔源/兰毅等）→ 培养种子选手（徐剑/秦鹏/马易等几十人）→ 启动MBA/训战营
- 寻求高手对话，持续磨课升级

## 五、核心操作框架：Ω模型（关键假设三板斧）

**口诀**：先加法，再减法，最后快速验证——每个环节3个套路

```
Ω模型五环节
明确目标 → 做加法 → 做减法 → 做验证 → 不断调整（贝叶斯迭代）
```

> ⚠️ **核心认知**：「先明确出口，再规划路径」——讨论必须基于明确的目标。有目标，才能谈路径、效率、成败。

### 第一板斧：加法——把业务拆成假设

**核心理念**：有能力把业务拆成一组假设，用几句话或一页纸，把整个业务所有要素提炼出来。

**Truman的探索之路（如何找到259）**：

| 阶段 | 工具 | 来源 | 评价 |
|:---|:---|:---|:---|
| 第一阶段 | **2分法**（价值假设+增长假设） | 《精益创业》 | 简洁但太粗糙，无法覆盖很多问题 |
| 第二阶段 | **9分法**（商业模式画布） | 《商业模式新生代》 | 经典完整但不趁手，不方便记忆和填写 |
| 第三阶段 | **精益画布** | 《精益创业实战》 | 改良版，但仍不够科学/简洁/普适 |
| 第四阶段 | **5分法**（一堂五步法） | 自力更生 | 从150+失败细节合并同类项，需求→方案→商业→增长→壁垒 |
| 终局 | **259体系** | 一堂 | 2简洁/5普适落地/9完整汇报——三把工具组合 |

**259口诀记忆**：
- **2**（价值假设+增长假设）：最简洁，适合快速判断
- **5**（需求→方案→商业→增长→壁垒）：最普适，适合讨论和落地
- **9**（商业模式画布或一堂商业画布）：最完整，适合复杂汇报（面对投资人/老板）

**案例——自动送水服务系统（V1.0加法版）**：
- 定价合理，能通过使用费赚到钱
- 能通过自建BD地推团队获得增长
- 能通过推荐裂变获得快速增长
- 硬件系统识别水的准确率达到99%+
- 水站老板普遍愿意采购这个系统
- ……

**关键原则**：「只要你开始拆解假设，即便拆解得没那么清晰、那么完整，也远远好于你没有'关键假设'的意识。」

### 第二板斧：减法——提炼关键假设

**核心理念**：从一大堆假设中挑出重点——不能眉毛胡子一把抓，把注意力放在关键假设上。

**减法三条原则**：

**原则① · 前置假设优先**
- 假设有前后依赖关系，259最大价值（之一）就是给了推理的前后依赖关系
- 没验证需求存在→不要过早关心商业模式和增长问题
- **灵魂自测**：「如果你当下的验证失败，是回退一步呢？还是全盘推翻？」——如果全盘推翻，要认真反思
- 反面教训：有同学每次创业都先思考增长渠道，忽略前置假设→用户画像不准→解决方案调整→渠道计划全部推翻重来

**原则② · 验证单一假设**
- 每次尽量只验证一件事情，执行快，回退也是小范围试错
- 典型错误：一个用户都没验证过就天天搞品牌/技术专利/官网打磨细节；一批货没试卖过就囤50万货；一家店没测过就一次性开3家
- 金句：「很多创始人都喜欢挑简单的验证，甚至会刻意回避高风险的部分。你要知道，关键假设必须一组全部成立，模式才成立——风险越高失败率越高，一定逃不掉的，拖得越晚损失越大」

**原则③ · 风险高优先**
- 大家都担心的，就是你眼下最重要的关键假设
- 不要回避问题——风险越高的假设往往最致命，越应该尽早挑出来，用最低成本验证
- **7个快速提炼关键假设的渠道（CheatSheet）**：行业常识、专家访谈、竞争对手调研、自我提问头脑风暴、投资FA建议、失败案例研究、最佳实践分析

**案例——自动送水服务系统（V3.0减法版）**：
三天研究后，3条关键假设浮出水面：
- 行政职责所在，公司已习惯多订一些，"忘订尴尬"普遍来说并不疼
- 水站本身利润很低+IT化弱，水站老板普遍不愿意额外承担每年大几百/上千费用
- 即便付款率高，不到1k定价也很难支撑新客户BD和拓展

**戏剧性真实结局**：案主当年扛了10多天水、烧了150万、拉团队大半年研发，结果发布后迅速证伪——他反思说「一顿饭一瓶酒的成本，就能拿到同样的关键认知」。Truman点评：「用身体上的勤奋，掩盖思想上的懒惰，只是感动了自己。」

### 第三板斧：快验证——低成本拿认知

**核心理念**：面对挑出来的关键假设，知道如何快速验证——如何用10%的投入，完成100%的工作。

**验证三方法（从低成本到高成本）**：

| 方法 | 一句话 | 成本量级 | 案例 |
|:---|:---|:---|:---|
| **常识**（行业经验） | 找圈内认知最好的人聊，直接拿行业Benchmark | 极低 | 线下零售毛利低于40%建不起分销渠道 |
| **调研**（通过对手回答） | 研究竞品死亡原因，比辛苦开发再验证高效太多 | 低 | 假装合作拿到竞品成本结构；入职门店拿财务报表 |
| **实验**（设计MVP测试） | 小步快跑，低成本试错，避免一上来就做大而全产品 | 中 | 樊登用PPT验证付费意愿后再做APP |

**金句**：「能烧别人的钱，就别烧自己的钱。」「没有调查，就没有发言权。没有调研，就没有决策权。」

**量级差距铁律**：常识 ＜ 调研 ＜ 实验 ＜＜＜ 全量开发——差距是数量级的

**经典案例——东南亚电商平台（验证成本砍掉90%）**：
- 原计划：开发简单版淘宝，需要小100万，但手里钱不够
- 关键假设减法后锚定两条：选品（SKU要符合当地人支付能力）+ 获客（要有规模化渠道）
- 关键追问：「如果只验证这两个问题，真的需要开发一个新的淘宝吗？」
- 最终方案：用客服人工模拟微信拼团，几万块钱就能验证——手里的钱够做N次实验

**经典案例——WEB版打车软件（2005年）**：
- 拆出5条关键假设后，发现第3条（网上打车体验远远好于路边招手）在当时不成立——没有智能手机、没有GPS定位、没有移动网络
- 在2005年做这个项目几乎注定失败——无论验证花300万/30万/3万/0元，结论都一样

## 六、ABCD象限模型：关键假设的四大应用场景

**两个维度**：宏观（全局）←→ 微观（关键环节） × 决定成败 ←→ 决定效率

| | 宏观（全局视角） | 微观（关键环节） |
|:---|:---|:---|
| **成败问题** | **A. 商业场景** → 一堂五步法 | **B. 决策场景** → 投产比ROI |
| **效率问题** | **C. 增长场景** → 业务公式 | **D. 转化场景** → 动力阻力触点 |

**使用要诀**：
- 上面一行（A/B）得认真选择，因为容易错——决定成败
- 下面一行（C/D）得仔细分析，因为容易差——决定效率
- 左边一列（A/C）是全局视角，中高层得有的战略思维
- 右边一列（B/D）是重点攻坚，中基层得有的专业能力

**精益优先级**：A ＞＞ B ＞ C、D

**个人修炼顺序**：D → B/C → A，形成科学决策的核心能力训练

## 七、长期迭代：建立持续机制

**核心心法——贝叶斯定理式迭代**：
- 坚持：验证所有假设成立 → 持续推进
- 调整：根据有效学习调整假设和方案
- 放弃：证伪关键假设 → 果断止损

**团队提假设工具箱（激发团队优质想法）**：
- **最基本**：老板重视——多用话术「这个想法最早是谁提出来的啊！」
- **进阶版**：明确规矩——提出想法者独占功劳50%，其余所有人分50%
- **高配版**：关联奖金——和OKR/KPI一起使用，成为绩效评估重要维度
- **设定数字**：立Flag逼自己——「每人至少带3个优化想法来」「凑齐15个假设再散会」
- **灵感闪现五字诀**：压（高压挤压创意）+ 看（看足够多的东西）+ 聚（专注头脑风暴）+ 拆（结构化思考）+ 再（从已有答案激发新答案）

**务实提醒**：「如果你的团队很难落地'关键假设'这四个字的话语体系，没关系，你可以叫它任何词——主要矛盾、关键成功要素、前提条件、提升想法……都可以。」

## 八、终极升华：Y模型——一堂科学型组织的底层信仰

```
Y型创业：一堂科学型组织

理论（抽象过的规律）
  ↕
验证（一手真实世界的反馈）
  ↕
提炼模型 → 科学类比 → 假设驱动 → 我的认知
  ↕
定性定量
  ↕
实事求是 + 解放思想
  ↕
知行合一
  ↕
解决真正问题
```

**Y模型四要素**：
- **真正解决问题**：能把新认知持续落到工作里，围绕具体问题展开（#真实问题）
- **有关键认知**：基于目标和问题，构建因果认知模型，知行合一，务实可用（#因果关系）
- **有理论迭代**：有经典的方法论/原则，也有自己提炼的模型（#抽象二手信息）
- **有验证迭代**：持续拿到反馈，迭代认知，做调研和实验（#现场一手信息）

**两个根本信念**：
- **实事求是**：一切从客观现实出发，尊重客观规律，保持敬畏心——去调研事实、了解案例、学习业务现场真实的细节和过程
- **解放思想**：不必迷信经验，学习更底层原理，遵循普适正确的公理——提各种假设，总结上层新经验和建模

## 九、收尾：重新理解「关键假设」

**核心信念**：
- 关键假设思维，就是从"愿望"到"科学"——从"我认为它是XX的"到"我假设它是XX的"
- 相对于只会墨守成规"固定执行"，没有什么想法是比较糟糕的
- 关键假设 ≠ 任务清单ToDoList，它的本质是你业务未来"可能的提升机会"
- 能做好「事前验尸」，可以给自己多几条命
- 抛开个人执念和观点偏好，用客观假设来分析问题——这是一套更高维、更科学、可以用来修炼业务能力的方法论

**金句**：「关键假设思维，就是从'愿望'到'科学'。」
