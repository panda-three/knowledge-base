## 二、为什么一定要学：三类商业分析困扰

**Truman 做课背景**：拜访案例发现，超过 50% 的赔钱，都是因为**单元模型不完整**导致的。

**三类普遍困扰**：

| 困扰类型 | 典型表现 | 核心病因 |
|---|---|---|
| **过于宏大** | 聊"商业模式"总是宏大模糊——行业趋势、平台、免费模式、PEST，对商业模式单元缺少具体分析能力 | 缺少把宏大商业模型「拆到最小单元」的工具 |
| **过于玄学** | 被碎片式商业博主带着走——"商业赚钱的本质是利他""本质是红利""本质是效率"，缺少统一底层逻辑 | 缺少一个简洁、可操作的核心框架 |
| **很难训练** | 三张表不好用（有滞后性、早期做不出来），缺少一个简单有效的工具来评估/算账/决策/迭代 | 找不到趁手的商业分析武器 |

**一堂的解法**：单元模型——**找到商业的最小经济循环，用它来评估整体业务的可行性**。纯业务侧的商业工具，几乎不需要有太多财务基础就能掌握。

## 三、核心认知：什么是单元模型

### 3.1 定义

**单元模型** = 你的商业模式里，能够体现**成本收入关系**的某一个**最小运作单元**。

**一句话**：你业务可运营、可复制的一个最小单元；你业务未来的规模化，核心就是复制这个模型。

### 3.2 多轮本质（三层递进理解）

| 层次 | 理解 | 核心含义 |
|---|---|---|
| **第一层** | 单元模型和公司总账的关系 | 公司总账 = 一个个单元模型的汇总；总账亏损时，只有拆到单元才能定位哪里出了问题 |
| **第二层** | 单元模型是创业几乎最好的**经营和预判工具** | 每经营一个单元，都能实时看到盈利性；推广前用单元模型预判整体可行性——定性 < 定量 < 定钱 |
| **第三层** | 单元模型是**复制工具** | 搞清楚单元模型之后再开始复制——「用你最强大的执行力，把一个亏损的模型复制 100 遍，才是真正的创业悲剧」 |

### 3.3 适用与不适用

| 场景 | 结论 |
|---|---|
| **想做规模复制**的业务 | ⭐⭐⭐ 必须认真算——不认真算模型是致命的 |
| **小而美精品店**（不需要复制） | 单元模型也可以算，但意义不大——不如比别人早起两小时 |
| **只卖一次 / 只摆一次地摊** | 价值不显著——赚不赚钱相对简单，一目了然 |
| **长期经营**（持续获客/投放/开店/销售/招聘） | ⭐⭐⭐ 必须认真算——很有可能你复制的是错的 |

## 四、核心交付：创始人算账能力 6 个段位 + 15 个典型错误

### 4.1 段位全景图

```
L1 · 不算账      缺算账意识    → 只谈初心、不谈变现、不谈数字
L2 · 算错账      缺单元模型    → 只算大账、存在盲区、选错模型
L3 · 有粗糙账    缺关键项      → 忽略经营成本、忽略组织成本、忽略财务成本
L4 · 有完整账    缺基准值      → 缺少统计意义、错误类比、乐观预期
L5 · 完整账+基准值  缺动态预测  → 忽略规模变化、忽略外部变化、忽略业务变化
L6 · 动态预测    顶级认知      → 完整账+基准值，持续动态更新
```

### 4.2 各段位详拆

**L1 · 不算账——缺算账意识**

| 维度 | 说明 |
|---|---|
| **典型表现** | 王同学开餐饮店辛辛苦苦干一年没赚钱；袁同学开 KTV 赔掉家里几十万；王同学做石墨烯护眼罩只定性不定量就开始研发 |
| **经典错误** | 只谈初心（满口情怀不谈变现）、不谈变现（聊半天商业模式全程没数字）、不谈数字（没有算账习惯） |
| **一句话诊断** | 根本没意识到要算账，长期依赖直觉和热情做决策 |

**L2 · 算错账——缺单元模型**

| 维度 | 说明 |
|---|---|
| **典型表现** | 朱同学开线下全屋定制实体店，不知道当地具体怎么算；云教室产品拿到全国第一大标就开始复制，烧掉 2000 多万——事后总结「那个时候不会算账，不知道啥叫单元模型」 |
| **经典错误** | 只算大账（看公司总数不看单订单/单用户）、存在盲区（不知道有单销售/单履约等模型）、选错模型（直觉选 A 模型但其实关键成本在 B 模型里） |
| **一句话诊断** | 有算的意识但算的账根本不对，完全没法跟专业投资机构平等对话 |

**L3 · 有粗糙账——缺关键项**

| 维度 | 说明 |
|---|---|
| **典型表现** | 很多 BP 里商业模式页「还算有些数字」但关键成本项漏了——没算房租/售后/培训/售前成本；电主轴案例定价低于真实成本 5 年没发现 |
| **经典错误** | 忽略经营成本（只算制造成本不算房租/售后）、忽略组织成本（扩张后管理成本没算）、忽略财务成本（账期/税费/资金成本） |
| **一句话诊断** | 开始建立了模型框架，但关键成本项大量缺失 |

**L4 · 有完整账——缺基准值**

| 维度 | 说明 |
|---|---|
| **典型表现** | 有能力把完整的单元模型具象出来，找到所有关键成本收入项——但判断力不行 |
| **经典错误** | 缺少统计意义（凭一个样本就下结论）、错误类比（拿别人家的基准值直接套自己）、乐观预期（收入高估、成本低估） |
| **一句话诊断** | 模型完整但没对标行业基准，缺乏说服力 |

**L5 · 完整账+基准值——缺动态预测**

| 维度 | 说明 |
|---|---|
| **典型表现** | 模型完整 + 通过调研/测试拿到各指标基准值——很有说服力，但离完美还差一步 |
| **经典错误** | 忽略规模变化（小规模跑通 ≠ 大规模成立，饮用水配送案例：从 100 家到 500 家，SKU 从几百到 4000+，配送时效从 48h 崩到 96h）、忽略外部变化（竞争导致降价、原材料涨价）、忽略业务变化（订单结构变化导致利润率骤降） |
| **一句话诊断** | 静态数据漂亮，但没做规模化推演——「规模不经济」是致命陷阱 |

**L6 · 动态预测——顶级认知**

| 维度 | 说明 |
|---|---|
| **核心能力** | ① 完整账+基准值 ② 持续动态更新 ③ 推演不同规模下的模型变化 ④ 提前布局对抗规模不经济 |
| **一句话评价** | 有些创业者靠这个段位的商业评估直接说服 VC 拿到融资 |

### 4.3 四象限分析法

```
定性 ←   → 定量 ←   → 定钱
(粗糙)    (精确)     (严格财务)
```

- L3 以下基本在定性区间
- L4 完成定量（完整模型+关键数字）
- L4-L5 进入定钱（严格财务 ROI）
- L6 动态定钱（持续追踪财务模型变化）

## 五、十大典型单元模型清单

```
维度             单元模型           简介
───────────────  ────────────────   ──────────────────────
按销售           1. 单订单模型       按每个订单销售来计算，测算订单循环
                 2. 单SKU模型        按每个SKU来计算，测算毛利结构

按人头           3. 单用户模型       按每个C端用户计算，如首单/30天/180天
                 4. 单客户模型       按每个B端客户计算，能否持续复制客户
                 5. 单销售模型       按每个销售人员来算，能否持续复制销售
                 6. 单履约模型       按每个履约人员来算（美甲师/咨询师/顾问）

按空间           7. 单柜子模型       按每个柜子为物理空间计算
                 8. 单门店模型       按每个门店为物理空间计算
                 9. 单商圈模型       按每个商圈为物理空间计算
                10. 单城市模型       按每个城市为物理空间计算
```

**使用原则**：

| 原则 | 说明 |
|---|---|
| **复制哪个算哪个** | 你靠复制什么扩张，就重点算什么单元模型 |
| **哪个最虚盯紧哪个** | 数据最模糊、成本最不可控的模型最需要优先算清 |
| **拆多细做多细决策** | 单元模型拆到多细的颗粒度，商业分析就能触达多细的层级 |

**特定业务必算模型**：
- To C 产品 → 单用户首单模型 + 单用户生命周期模型（CAC/LTV）
- To B 业务 → 单销售模型（To B 一定要算的模型）
- 线下连锁 → 单门店模型 + 单城市模型
- 有履约人员 → 单履约模型

## 六、单元模型与 ROI：科学决策三角形

### 6.1 统一理解框架

```
ROI = 产出 / 投入 = (A+B+C+D) / (X+Y+Z)
```

**公司成立的条件**：所有单元模型加权汇总后，产出持续大于投入。

### 6.2 科学决策三角形

```
                  高度
          长期视角 · 公司视角 · 机会成本

宽度  ←────── ROI 决策 ──────→  深度
关键收益项                       优先级定性
关键成本项                       部分定量
时间窗口                         定量公式
```

| 维度 | 含义 | 关键拷问 |
|---|---|---|
| **宽度** | 要素完整——列全所有关键成本和收益项 | 「还有吗？还有吗？」 |
| **深度** | 从定性走到定钱——把关键要素换成数字 | 「这个要素到底是多少？」 |
| **高度·长期视角** | 随着时间 ROI 会显著变好还是变差？ | 「站在 N 年维度看，这个决策该怎么做？」 |
| **高度·公司视角** | 老板/CEO 会怎么评估这个决策？ | 「如果+1 视角思考，还有哪些关键要素？」 |
| **高度·机会成本** | 这个决策是不是 ROI 最高的选项？ | 「稀缺资源还能做哪些其他事情？」 |
| **高度·时间窗口** | 外部竞争/关键资源/流量红利有窗口期吗？ | 「有些机会错过就不再有了」 |

## 七、商业模式与五步法的整体关系

### 7.1 五步法逐层拆解 + 商业模式的位置

```
需求 → 解决方案 → 商业模式 → 增长 → 壁垒
 0       1         1→10     10→100   长期
```

| 阶段 | 核心关注 | 商业模式相关金句 |
|---|---|---|
| 0→1 | 需求验证 + 产品内核 | — |
| **1→10** | **跑通商业模式** | 「不要过早复制，未经验证的商业模式」 |
| 10→100 | 增长复制 | 单元模型健康后，才大规模复制 |
| 长期 | 壁垒构建 | 单元模型持续优化，结构成本优势 |

### 7.2 商业模式跑通的标志

**两个必要条件**：
- 跑通**规模化**商业模式（不只是小样本盈利）
- 找到一个**可持续**的大渠道（不只靠关系/红利）

### 7.3 商业模式与其他四步的衔接

| 衔接方向 | 关系 |
|---|---|
| **需求和商业模式** | 需求确定了定价和用户群→直接影响单元模型中的收益项 |
| **解决方案和商业模式** | 产品内核 = 单元模型中最关键的转化率；内核不够强→关键转化率低→收益项上不去 |
| **商业模式和增长** | 单元模型跑通才有资格谈增长；没跑通就增长→系统性地放大错误 |
| **商业模式和壁垒** | 持续优化单元模型中的成本结构→构成壁垒中的成本优势 |

## 八、经典赔钱案例（三类典型教训）

### 案例一：校园 O2O 项目——L2 算错账型

**背景**：以太应届生做校园 O2O，靠快速融资一路跑到 B 轮

**错误**：铺了一些学校，但没搞清为什么有的赚钱有的亏钱，就以**城市为单位**快速全国铺开

**结果**：该算的单元模型关键成本项没测算清楚，融了钱后快速扩张，全亏掉、现金流烧光

**教训**：单元模型没到 L5/L6 段位，复制越多亏得越多——**单元模型是复制工具，搞清楚再复制**

### 案例二：电主轴项目——L3 缺关键项型

**背景**：徐同学公司推出电主轴产品，投入 5 年陪跑一个大客户，销量从 2 台到 150 台+

**错误**：
- 成本计算中**没有考虑房租和售后服务成本**，定价从一开始就低于真实成本
- 没考虑机加工件价格上涨的可能性
- 没考虑机床厂家竞争导致客户降价要求

**结果**：5 年后营收只剩 20 多万，业务清盘

**教训**：**忽略经营成本/忽略外部变化**——单元模型关键项缺失，长期亏损不自知

### 案例三：夫妻店供应链项目——L5 缺动态预测型

**背景**：杜明睿团队为夫妻老婆店提供聚合支付+线上商城+进货服务，拿到 1000 万融资

**错误**：跑通了小规模单店模型就快速推广到 100+ 家，没动态预测规模化后的变化：
- 饮用水利润率极低（一件 24 瓶赚不到 5 块），配送成本却很高
- SKU 突破 4000，长尾货品利润微薄
- 没自建仓储 → 断货缺货 → 配送时效从 48h 崩到 96h

**结果**：仅剩几十万，关停业务

**教训**：**忽略规模变化**——小规模健康 ≠ 大规模成立，**规模不经济**是隐性杀手

## 九、总结收口

### 核心金句

| # | 金句 |
|---|---|
| 1 | **不要过早复制，未经验证的商业模式**——这是五步法如果你只学一招，就学单元模型的原因 |
| 2 | **单元模型是你犯大错误前的最后一道防线**——守住盈亏平衡的底线 |
| 3 | 单元模型是**复制工具**——搞清楚再复制，不然复制越多亏得越多 |
| 4 | 单元模型是**预判工具**——用最小经济单元判断整个商业模式的可行性 |
| 5 | 单元模型是**经营工具**——拆多细的颗粒度，就能做多细的经营决策 |
| 6 | 「**你用最强大的执行力，把一个亏损的模型复制 100 遍，这才是真正的创业悲剧**」 |
| 7 | **被需要，永远是商业模式的第一原则** |

### 修炼路径

| 段位 | 核心修炼动作 |
|---|---|
| L1→L2 | 从不算账到有算账意识——业务里要有数字 |
| L2→L3 | 找到核心单元模型——选对模型、拆对维度 |
| L3→L4 | 补齐所有关键成本收入项——经营/组织/财务成本都不漏 |
| L4→L5 | 拿到基准值——调研同行、自己测试、统计数据 |
| L5→L6 | 动态预测——推演不同规模下模型变化，提前对抗规模不经济 |

### 课后作业
- 用十大单元模型清单，找到你业务最核心的 1-2 个单元模型
- 按段位图自评你目前的算账段位，画出你的单元模型收支结构
- 问自己：如果规模翻 5 倍，我现在的单元模型还成立吗？
