## 一、为什么需要这堂课：普遍痛点

**核心发现**：85%的业务一号位，基本做事姿势都是歪的

**典型症状**：
- 做了好几年，一直抓不住重点，把主要精力和钱放在根本不重要的环节上
- 九成情况：没有理解清楚业务成败背后的底层逻辑
- 面对同一个创业项目，不同CEO看到的业务深度完全不同
- 没方向/缺团队/没资源/不赚钱/不增长——分析到最后全是缺少对业务底层逻辑的理解

**两个预热思考题**：
- **题1**：给你一张白纸，20分钟让张一鸣/王兴快速理解你的项目全貌并帮你做百万级决策——你会怎么写？
- **题2**：不同业务（抖音品牌/连锁门店/社区产品/咨询陪跑）差异极大，能否用一套底层通用框架大幅提升每个项目成功率？经验70%可迁移？

**课程四大话题**：
- **击穿本质**：我们创业，究竟在创什么？
- **拆解业务**：如何拆解项目背后的逻辑？
- **主要矛盾**：如何抓住商业模式的关键？
- **十倍提速**：如何低成本地验证你业务？

## 二、击穿本质：创业究竟在创什么？

### X型创业者（愿景驱动）
- 典型姿势：我在做抖音女装带货 / 年轻人都喜欢的白酒品牌 / 下沉市场连锁火锅店
- 核心动作：组建团队→凑几十万→3-6个月开发→推到市场看反馈→看能不能成功
- 致命特征：迷恋idea，整个想法一大坨没拆解，默认努力就能成
- **追问一句「最需要验证什么？哪个点最决定成败？」——一半一号位没想清楚**

### Y型创业者（假设驱动）
- 典型姿势：「你这个业务/渠道/产品的关键假设是什么？」
- 核心信念：不要看表面现象，围绕前提假设来推进业务
- 对成功的态度：默认业务风险极大、极容易失败，提前把"能成"的前提条件拆出来一步步测试
- **金句**：「想出一个idea一点不值钱。真正值钱的，是这个idea背后一整套的关键假设」

### 核心定义
- **假设** = 你的模式想成立，所依赖的所有关键前提条件
- 全部验证成立 → 业务跑通
- 有一条不成立 → 很难走下去，需转型或放弃
- **关键假设** = 所有假设中风险最高、对你创业最重要的假设

### 案例：京东无人餐厅（2018年）
- 表面光鲜：京东签约、500万启动、媒体争相报道、客户坐高铁来
- 关键假设：机器人不是营销噱头，而是能实实在在提升经营效率
- 事实：机器对食材形状要求极严→后厨人数只多不少→做菜不好吃→差评→复购惨不忍睹→严重亏损关停

### 案例：WEB版打车软件（假设2005年）
- 关键假设之一：网上打车体验远好于路边招手
- 2005年现实：无智能手机、无GPS定位、无移动网络→注定失败
- 核心教训：无论验证花300万/30万/3万/0元，结论都一样

## 三、拆解业务：一堂五步法（259体系）

### 一堂五步法：五个最关键的商业里程碑

| 步骤 | 核心问题 | 一句话 |
|:---|:---|:---|
| **需求** | 原点问题：目标用户、场景、是否存在真实问题 | 问题存在，的确需要解决？ |
| **解决方案** | 价值问题：产品差异化、价值、能否解决问题 | 价值成立，可以解决问题？ |
| **商业模式** | 效率问题：能否赚钱，能否持续赚钱 | 商业成立，可以模式跑通？ |
| **增长** | 复制问题：如何持续获客、持续增长 | 持续获客，完成增长？ |
| **壁垒** | 终局问题：面对竞争，靠什么能赢 | 预判壁垒，形成竞争优势？ |

**核心特性**：环环相扣，依次推导——需求→方案→商业→增长→壁垒

### 259口诀记忆
- **2**（价值假设 + 增长假设）：最简洁，适合快速判断——来自《精益创业》
- **5**（需求→方案→商业→增长→壁垒）：最普适，适合讨论和落地——一堂自力更生提炼
- **9**（商业模式画布 / 一堂商业画布）：最完整，适合复杂汇报/面对投资人——来自《商业模式新生代》

### 259三个价值
- **2分法**：出现最早，价值假设+增长假设，简洁但太粗糙
- **5分法**：从150+失败细节合并同类项，需求/方案/商业/增长/壁垒
- **9分法**：经典的商业模式画布，完整但不趁手

**金句**：「没有关键假设的一堂五步法，就是个空壳。」

## 四、主要矛盾：如何抓住商业模式的关键

### 从假设到关键假设——减法三原则

**原则① · 前置假设优先**
- 假设有前后依赖关系——259最大价值之一就是给了推理的先后顺序
- 没验证需求存在→不要过早关心商业模式和增长
- 灵魂自测：「如果当下验证失败，是回退一步？还是全盘推翻？」——全盘推翻就反思

**原则② · 验证单一假设**
- 每次只验证一件事，执行快、回退小
- 典型错误：一个用户没验证就搞品牌/技术专利；一批货没试过就囤50万；一家店没测过就开3家

**原则③ · 风险高优先**
- 大家都担心的 = 眼下最重要的关键假设
- 风险越高越致命，越应尽早挑出来用最低成本验证

### 7个快速提炼关键假设的渠道（CheatSheet）
行业常识 → 专家访谈 → 竞争对手调研 → 自我提问头脑风暴 → 投资FA建议 → 失败案例研究 → 最佳实践分析

### 关键案例：自动送水服务系统
- 案主扛了10多天水、烧150万、拉团队研发大半年
- 减法后3条关键假设：忘订尴尬并不疼 / 水站利润低不愿额外付费 / 定价支撑不了BD拓展
- **结果**：发布后迅速证伪——「一顿饭一瓶酒的成本就能拿到同样的认知」
- **金句**：「用身体上的勤奋，掩盖思想上的懒惰，只是感动了自己」

## 五、十倍提速：如何低成本地验证业务

### 验证三方法（量级差距铁律）

| 方法 | 一句话 | 成本量级 |
|:---|:---|:---|
| **常识**（行业经验） | 找圈内认知最好的人聊，直接拿行业Benchmark | 极低 |
| **调研**（通过对手回答） | 研究竞品死亡原因，比辛苦开发再验证高效太多 | 低 |
| **实验**（设计MVP测试） | 小步快跑，低成本试错 | 中 |

**常识 ＜ 调研 ＜ 实验 ＜＜＜ 全量开发——差距是数量级的**

### 经典案例：东南亚电商平台（砍掉90%验证成本）
- 原计划：开发简单版淘宝，需小100万，但钱不够
- 关键假设减法后锚定两条：选品+获客
- 追问：「如果只验证这两个问题，真的需要开发新淘宝吗？」
- 最终：用客服人工模拟微信拼团，几万块就能验证——钱够做N次实验

### 低成本验证本质四要素
- 有系统性风险（积蓄/公司资源/老板信任/团队信心/现金流）
- 花额外时间测试
- 少量试错成本（用低成本聪明方法）
- 大幅降低（提前验证更划算）

**金句**：「没有关键假设的精益创业，就很难低成本。」「能烧别人的钱，就别烧自己的钱。」

## 六、常犯的六种错误驱动姿势（都需升级）

| 驱动方式 | 问题 |
|:---|:---|
| 愿景驱动 | 美好的愿望+努力=一定能成 |
| 直觉驱动 | 凭直觉灵感指导做事 |
| 经验驱动 | 用旧经验指导新任务 |
| 对标驱动 | 完全照抄同行 |
| 运气驱动 | 相信自己八字硬、运气好 |
| 老板驱动 | 老板说什么就做什么 |

**核心升级**：从以上六种→**假设驱动**——用确定性的前提假设，去解决高难度的业务问题

## 七、关键假设三板斧（Ω模型五环节）

**口诀**：先明确出口，再规划路径

**五环节**：明确目标 → 做加法（拆成假设） → 做减法（提炼关键假设） → 做验证（低成本拿认知） → 不断调整（贝叶斯迭代）

- **加法**：用259把业务拆成一组假设
- **减法**：前置优先 / 单一验证 / 风险高优先
- **验证**：常识 → 调研 → 实验
- **迭代**：坚持/调整/放弃

**金句**：「只要你开始拆解假设，即便拆解得没那么清晰完整，也远远好于没有关键假设的意识」
