# 课程：好想法变真事下·青少年营

**一句话结论：** 喊队友靠真爱粉口碑（第一个用户叫得出名字+给一句能直接说出口的推荐语）；守城堡不靠技术，靠别人抄不走的数据、信任与习惯；整图一辈子能用。

---

## 一、核心交付

- 第四关 喊队友三问+一句推荐语公式。
- 第五关 护城河三问+三类隐形资产。
- 一张AI错题小助手完整五关画布。
- 一条迭代心法：V1.0假设→V2.0实战→V3.0迭代。

## 二、关键框架

### 2.1 第四关 喊队友三问

| 问 | 要点 |
|---|---|
| 第一个用户叫得出名字吗 | 拒绝"所有学生"，锁定具体的人 |
| 用完会主动推荐吗 | 要"忍不住安利"的情绪，不是"还行" |
| 他怎么跟朋友描述 | 给他一句能直接说的话 |

- 错题助手推荐语：**"拍个照就出同类题，数学多对三道题。"**
  - 低门槛动作钩子=拍照；高感知成果=多对三道题。
- 传播公式：具体场景 + 可感知结果，≤15字。
- 广告是单向自嗨，口碑是双向奔赴。

### 2.2 第五关 守城堡三问

| 问 | 真护城河标准 |
|---|---|
| 多久能被复刻 | 一天能抄=没壁垒，要数年才追上 |
| 独有资产多硬 | 数据沉淀/用户信任/行业洞察 |
| 用户迁移多难 | 数据+习惯+社交链=数字契约 |

### 2.3 三类隐形护城河

| 资产 | 例子 |
|---|---|
| 别人没有的真实数据 | 独家错题数据越用越准 |
| 老师同学的信任关系 | 长期相处的口碑背书 |
| 用惯不想换的习惯 | 路径依赖，重传嫌麻烦 |

> 「AI时代技术壁垒在消融，唯一抄不走的是长期深耕的坚持。」

### 2.4 错题小助手五关画布

| 关 | 关键内容 |
|---|---|
| 找宝藏 | 总错同类题的中小学生；考前复习 |
| 造武器 | 拍照归类+出3道同类题；先手写找10人试 |
| 算金币 | 月卡5元/年卡48元；单题成本5分 |
| 喊队友 | 同桌起步；推荐语"多对三道题" |
| 守城堡 | 数据越用越准+错题记录迁移难+口碑 |

### 2.5 迭代三版

- V1.0 初探地图：行动起点，不是终点。
- V2.0 实战反馈：去真实场景找隐藏陷阱。
- V3.0 迭代通关：假设变验证后的真路径。

## 三、金句与判断

> 「用户愿意说，才是真的好。」
> 「点子不值钱，你做出来的积累才是壁垒。」
> 「AI是队友不是对手——提问比答题更值钱。」

## 四、行动建议

| 层级 | 行动 |
|---|---|
| 基础 | 给点子写一句≤15字推荐语 |
| 进阶 | 写下第一个真实用户的名字 |
| 高阶 | 问：对手抄走我要花多久？抄不走的是什么 |

### 课后寻宝任务

未来一周找3个"要是能……就好了"的瞬间记下来，下次课挑一个用五步法拆。
