## 三、调研需求全景：四种场景四类问题

### 3.1 你在什么场景下需要调研？

```text
四类最典型的调研需求场景：

第一类：某一个关键信息的深度挖掘
  → 同行的投放ROI关键benchmark
  → 同行销售的关键策略（阻力消除话术）
  → 某个模块的技术路线选择和坑

第二类：某一个复杂目标的调研论证
  → 某公司财务报表是否有造假和注水
  → 在我的城市做自助台球厅有没有机会
  → 某个新品的可行性和成功率

第三类：基于大量案例寻找规律
  → 爆款标题的方法
  → 同类IP朋友圈策略，搭建选题子弹库
  → AI做图方法，快速学习成为专家

第四类：持续跟进同行变化和动态
  → 同行每周销量和市占率
  → 竞品新课题和爆款新课
  → 对标账号新爆款脚本的自动抓取分析
```

### 4.2 第一次飞跃：挖掘式调研 — 深度·挖

> **「扎扎实实做一次深度调研，比得上你瞎忙活大半年！」**

**一句话定义**：

```text
挖掘式调研 = 锁定高价值的调研情报目标，用多轮深度挖掘，穷尽手段，拿到水下信息。
```

| 维度 | 内容 |
|------|------|
| **本质** | 从本质出发：锁定高价值调研情报目标，穷尽手段拿到信息 |
| **军事角色** | 侦察兵——深入敌后，拿到关键情报 |
| **三大常见问题** | ①随机调研（想一出是一出）②手段单一（只会百度）③浅尝辄止（搜一下就停） |
| **核心心法** | 场景 + 情报：锁定场景，穷尽手段 |

**典型问题清单**：

```text
- 不开店的情况下，怎么拿到店铺的单元模型？
- 不动手的情况下，怎么学到业务内部的关键knowhow？
- 竞品打价格战时，怎么弄清对方的ROI？
- 竞品在这些场景下怎么做？优势是什么？劣势是什么？
```

**经典案例速查**：

| 案例 | 调研对象 | 核心手段 | 结果 |
|------|----------|----------|------|
| 大表哥·抖音团长 | 抖音团长商业模式 | 以应聘者身份深度访谈团长 | 2个月营收900万的生意被完整拆解 |
| 李瑞·火锅店选址 | 肯德基门店真实客流 | 深夜蹲守21天数人头，三班倒 | 选址模型升级，火锅店冲进全国第八 |
| 邵麟惠·金融牌照 | 海外政府金融牌照 | 调研信息节点→找到教堂神父→撮合 | 克服重重困难拿下牌照 |
| 张飞飞·竞品组织架构 | 竞品三级组织架构 | 公开碎片+伪装面试+猎头+在行 | 画出竞品完整组织架构图 |

**挖掘式调研三张核心卡片**：

```text
卡片1：一堂调研黑客·超级武器库（14大类调研策略）
卡片2：8张《调研手段卡》（按场景匹配调研重点和手段）
卡片3：深度调研信念——对于高价值情报，「绝大多数都是能调研出来的」
```

### 4.3 第二次飞跃：系统式调研 — 高度·准

> **「用好OSCAR模型，锁定调研目标，用专业分析框架缩小范围，一轮轮针对性获取重要情报。」**

**一句话定义**：

```text
系统式调研 = 围绕一个复杂的高难度目标，用一套科学流程（OSCAR），逐步拆解、高质量执行，最终完成复杂决策。
```

| 维度 | 内容 |
|------|------|
| **本质** | 用体系发挥情报的最大价值 |
| **军事角色** | 决策者——制定作战计划，系统推演 |
| **三大常见问题** | ①目标模糊（不知道调研什么）②缺少框架（什么都觉得有关系）③盲目寻找（没想清楚答案在哪） |
| **核心工具** | OSCAR模型 |
| **核心特点** | 系统式调研的特点是：用体系发挥情报的最大价值 |

**OSCAR模型 · 调研黑客五部曲**：

```text
┌─────────────────────────────────────────────────────┐
│              OSCAR 调研黑客五部曲                      │
├─────┬────────────────┬──────────────────────────────┤
│  O  │ Objective      │ 明确你的调研目标              │
│     │ 目标           │ 咬死目标，调研先行             │
├─────┼────────────────┼──────────────────────────────┤
│  S  │ Scope          │ 缩小你的调研范围              │
│     │ 范围           │ 三个原则：专注/专业/剥离       │
│     │                │ 从宏观到微观，越小越好          │
├─────┼────────────────┼──────────────────────────────┤
│  C  │ Checklist      │ 罗列调研产品清单              │
│     │ 清单           │ 高水平计划，明确要搜集什么      │
├─────┼────────────────┼──────────────────────────────┤
│  A  │ Acquisition    │ 不择手段获取情报              │
│     │ 获取           │ 全面搜集，依靠人工+工具         │
├─────┼────────────────┼──────────────────────────────┤
│  R  │ Reasoning      │ 拿到信息正确判断              │
│     │ 归因           │ 形成报告，完成决策支撑          │
└─────┴────────────────┴──────────────────────────────┘
```

> 💡 每一步的执行质量，都直接决定了整体调研质量。如果某个环节没做，或者执行质量很差，整体调研也一定拿不上台面。

**OSCAR 每一步的S 法则详解**：

| S 法则 | 全称 | 一句话 |
|---------|------|--------|
| **专注原则** | Focus | 从宏观到微观，越小越好 |
| **专业原则** | Professional | 找到一个专业的分析框架 |
| **剥离原则** | Strip | 主动剥离非关键信息 |

**经典案例：咖啡加盟调研**

```text
场景：亲戚想加盟某头部咖啡品牌，品牌方数据看起来很好——
      投资22.5万，日销400杯，月利润近1万，22个月回本。

标准化系统式调研（古董同学做法）：
  ① 明确目标：验证这个加盟生意是否真的赚钱
  ② 缩小范围：聚焦单店单元模型（不是品牌整体数据）
  ③ 罗列清单：实际日销/实际客单价/实际人工/实际水电/实际损耗
  ④ 获取情报：蹲点数人头、访谈已加盟店主、看外卖平台真实销量
  ⑤ 正确判断：品牌方宣称日销400杯，实际很多店日均不足100杯
                → 果断放弃，避免20-50万亏损
```

### 4.4 第三次飞跃：爆炸式调研 — 宽度·全

> **「一次饱和式的建模：找到足够宽、足够多的案例，一遍遍分类建模，直到模型稳定才终止。」**

**一句话定义**：

```text
爆炸式调研 = 展开足够宽、足够多的调研，围绕大量案例信息，提炼共性寻找规律，用共性规律来指导做事。
```

| 维度 | 内容 |
|------|------|
| **本质** | 一次饱和式的建模——不是找1-2个案例照抄，是大量案例→分类→建模 |
| **军事角色** | 参谋——基于情报提炼规律、制定战法 |
| **三大常见问题** | ①案例太少（只看1-2个就下结论）②缺少规律（只看表象，不会找共性）③结论很差（照抄个例，效果差） |
| **一堂内部地位** | **A级基本功**——每年至少100个爆炸式调研 |

**一堂的爆炸式调研应用全景**：

```text
一堂几乎就是一家构建在爆炸式研究上的公司。

教研维度：   做课、提炼底层规律和方法论
泛产品维度： 选产品内核、做产品设计
业务策略维度：选渠道、做投放、用户激励、朋友圈策略……

每年至少 100 个爆炸式调研项目。
```

**爆炸式调研三步法**：

| 步骤 | 动作 | 说明 |
|------|------|------|
| **1. 加法** | 尽可能多地搜集案例 | 不是3个5个，而是30个50个甚至100个 |
| **2. 分类** | 对案例进行多轮分类 | 按不同维度标签化、分组 |
| **3. 建模** | 提炼共性规律，形成稳定模型 | 反复迭代直到模型稳定，再用模型指导做事 |

**AI 如何加速爆炸式调研**：

```text
这不是一个简单的提示词，而是一个系统逐步加法→加法→加法→饱和式建模的过程。
非常考验AI的本身知识、调用工具、即时建模的过程。

Truman 曾搓过一个「爆炸式研究」专家，用来辅助建模：
  - 短期系统了解「早期创业公司」全套激励策略
  - AI 提炼「阻力消除策略」超级小抄
  - 最终质量已超过很多公开文章和书的水平
```

### 4.5 第四次飞跃：自动式调研 — 动态·稳

> **「让情报持续涌向自己。通过流程化、数据化、自动化、智能化的方式，长期稳定地做调研。」**

**一句话定义**：

```text
自动式调研 = 围绕市场，用一套机制流程或数据工具/IT系统，让竞争情报源源不断涌向你，辅助做极致的市场洞察。
```

| 维度 | 内容 |
|------|------|
| **本质** | 让情报持续涌向自己 |
| **军事角色** | 哨兵——长期值守，持续预警 |
| **三大常见问题** | ①忽略同行（认为关注竞对不重要）②不够持续（偶尔调研）③不够深入（泛泛信息，对业务没帮助） |
| **三类糟糕结果** | 忽略同行、忽略变化、迭代太慢 |

**经典案例速查**：

| 案例 | 调研机制 | 核心价值 |
|------|----------|----------|
| **以太·FA线索库** | 监控全网200+信息源，48h内收录→CC→打分→流入销售公海 | 月收录上万项目，打造国内最大融资型项目数据库 |
| **M同学·ToG业务** | 从人工监控→技术抓取→AI筛选归纳，全渠道自动化 | 覆盖率从20-30%→接近100%，人只需阅读最重要信息 |
| **李志宏·AI机会扫描** | 高管团队持续扫描Github/HuggingFace增速最快项目 | 新内容24h内讨论完一轮，持续发现新业务机会 |
| **吴同学·竞品基金监控** | AI智能体监控竞品基金收益率/持仓/费率 | 发现异常→分析持仓调整→及时调整自身策略 |

**AI 在自动式调研中的角色**：

```text
自动式调研是AI最容易加速的部分。
典型场景：
  - 「AI每天日报」
  - 「AI自动监控」
  - 「AI每天抓取」

尤其是 Openclaw 火了以后，日常监控发日报几乎是第一个主流场景。
有大量的方法和教程，需要自己持续探索和学习。
```

## 五、调研雷达：四维坐标系

### 5.1 核心隐喻

```text
┌─────────────────────────────────────────────────────┐
│              调研雷达 · 四维坐标系                      │
│                                                     │
│              深度 (挖掘式)                            │
│                ↑                                    │
│                |                                    │
│   宽度 ←───────┼────────→ 高度                       │
│  (爆炸式)      |         (系统式)                     │
│                |                                    │
│                ↓                                    │
│              动态 (自动式)                            │
│                                                     │
│  每一个人、每一个团队，都拥有一个"调研雷达"，           │
│  雷达范围越大，扫描情报越多，决策水平越高。              │
└─────────────────────────────────────────────────────┘
```

### 5.2 关键认知

> **「雷达有一个特殊性：彼此之间是相互调研和借鉴的。」**

```text
苗同学的真实教训：
  "之前很自信，总是习惯性忽略竞争对手。
   最后交了很多学费，各种踩坑后才发现：
   人家对我们一清二楚，我对人家什么都一无所知。"

你的调研雷达和竞品的调研雷达，在同一个战场上互相扫描。
谁的雷达更强大，谁就掌握信息不对称的优势。
```

### 5.3 四次飞跃与雷达对应关系

| 飞跃 | 雷达维度 | 修炼目标 | 一句话 |
|------|----------|----------|--------|
| 第一次 | **深度** | 掘地三尺，拿到水下情报 | 某些高价值情报必须深度挖掘才能拿到 |
| 第二次 | **高度** | 系统框架，全局推演 | 面对复杂目标，用OSCAR体系化推进 |
| 第三次 | **宽度** | 饱和建模，寻找规律 | 大量案例→分类→建模→用模型指导做事 |
| 第四次 | **动态** | 持续监控，情报自涌 | 不是一次性调研，而是建立长期情报系统 |

## 六、「重新理解」情报调研：四层价值击穿

### 6.1 调研帮你做四类决策

```text
┌─────────────────────────────────────────────┐
│        调研服务于四种关键决策                   │
├──────────┬──────────────────────────────────┤
│ 选择题   │ 做关键取舍要先调研                  │
```

## 十二、L6 级别进阶认知

### 认知一：调研不是「加分项」，而是「生存项」

> 95%的操盘手调研能力普遍欠缺。这意味着——如果你能系统性地做好调研，你已经比95%的同行拥有信息优势。**信息差是商业世界最古老、最持久的竞争优势。** 不是「做调研的人更优秀」，而是「不做调研的人迟早会被淘汰」。

### 认知二：调研雷达的大小，决定你决策质量的上限

> 每一个人、每一个团队都拥有一个「调研雷达」。雷达范围越大，扫描情报越多，决策水平越高。**你的商业判断永远不会超过你所掌握的信息质量。** 调研雷达需要四个维度均衡发展——深度不够会浮于表面，高度不够会碎片混乱，宽度不够会只见树木，动态不够会被市场抛弃。

### 认知三：AI不是调研的替代品，而是调研的放大器

> AI可以让系统式调研从2-3天压缩到几小时，让自动式调研从「偶尔看看」变成「7×24持续监控」。但AI只能加速你的方法论，不能替代你的判断力。**高阶使用AI的前提，是你自己首先理解OSCAR、理解四次飞跃、理解什么时候该用什么手段。** 人的差距不在工具，在于「提出正确问题」的能力。

### 认知四：调研最重要的不是技巧，而是信念

> Truman在课上反复强调：「你夜不能寐的答案，往往只差认真挖一下了。」很多创业者之所以不调研，不是因为没有技巧，而是**根本不相信答案可以通过调研找到**。他们更相信自己的直觉、经验或者运气。建立「万事皆可调研」的信念，比学会100种调研技巧更重要。

### 认知五：一堂本身就是「调研驱动型公司」的最佳证据

> 一堂每年至少做100个爆炸式调研——选产品内核靠调研，做产品设计靠调研，选渠道靠调研，做投放靠调研。**一堂几乎就是一家构建在爆炸式研究上的公司。** 这不是理论课，这是Truman和他的团队每天都在做的事。调研能力是一堂团队的A级基本功，也应该是你的。
