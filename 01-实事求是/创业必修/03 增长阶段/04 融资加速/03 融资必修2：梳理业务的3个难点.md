# 融资必修2：梳理业务的3个难点

> L6 级别清单体笔记 ｜ 主讲：周子敬（以太创服CEO）
> 训练营2 · 一堂融资系列课

---

## 一、课程定位：融资的根基是「把业务梳透」

```text
融资的第一步，是把业务一块一块地梳理清楚。
```

融资必修1 解决了「认知地基」——融资是什么、什么时候融、用什么姿势。融资必修2 解决的是认知地基之上最硬的一层：

**当投资人问你三个问题时，你能不能给出逻辑自洽、数据扎实的回答：**

| 序号 | 投资人的核心问题 | 对应难点 |
|---|---|---|
| 难点1 | 你的项目到底在做什么？ | 讲清商业模式 |
| 难点2 | 这个项目能做多大？ | 估算天花板 |
| 难点3 | 为什么是你们能做成？ | 讲清项目团队 |

**一句话定调：**

```text
业务梳理不是写作文，而是把你脑子里的模糊感觉，变成投资人能理解、能相信、能算账的清晰结构。
```

---

## 二、课前预热：三个测试问题

在进入三个难点之前，先用三个问题测试自己的准备状态：

| 问题 | 合格线 |
|---|---|
| 投资人问天花板怎么算，你能用至少两种方法交叉验证回答吗？ | 能说出具体数字和计算逻辑 |
| 投资人问你商业模式，你能从至少两个角度回答，且逻辑一致吗？ | 能切换不同场景的回答方式 |
| 投资人问团队优势，你能说出「为什么是你们，不是别人」吗？ | 有不可替代性的证据 |

如果你对其中任何一个问题犹豫，说明这一课就是为你准备的。

## 三、难点1：项目在做什么？——讲清商业模式

### 3.1 核心认知：商业模式在不同场景有不同的讲法

周子敬的核心判断：

```text
商业模式不是只有一种讲法。
面对不同场景，你要能从不同角度把同一件事讲清楚。
```

三种场景，三种讲法：

| 场景 | 适用方法 | 核心问题 |
|---|---|---|
| **公司内部** | 商业模式画布（九步法） | 完整的业务逻辑是否自洽？ |
| **BP 阶段** | 商业模式三段式 | 能否在几分钟内让投资人理解？ |
| **面聊投资人** | 盈利模式 | 投资人最关心的钱从哪里来？ |

### 3.2 场景一：公司内部——商业模式画布（九步法）

用 MECE 原则（相互独立、完全穷尽），把业务拆成九个模块：

| 模块 | 核心问题 | 填写示例 |
|---|---|---|
| **客户细分** | 你服务谁？ | B端中小企业 / C端年轻女性 |
| **价值主张** | 你给客户什么独特价值？ | 帮客户省50%时间 |
| **渠道通路** | 你怎么触达客户？ | 线上广告+地推+渠道代理 |
| **客户关系** | 你怎么维护客户？ | 专属客服+社群+自助平台 |
| **收入来源** | 钱怎么进来？ | SaaS订阅+交易佣金 |
| **核心资源** | 你有什么关键资产？ | 技术专利+行业数据+品牌 |
| **关键业务** | 你每天在做什么事？ | 产品迭代+客户成功+供应链管理 |
| **重要伙伴** | 谁帮你做？ | 物流商、支付平台、行业协会 |
| **成本结构** | 钱花在哪？ | 人力成本、服务器、营销费用 |

**检验标准**：

```text
画完之后，找一个完全不了解你业务的人（比如你妈），
看 TA 能不能在 3 分钟内理解你在做什么。
```

### 3.3 场景二：BP 阶段——商业模式三段式

BP 里不需要展示完整的九步画布，而是压缩为三个核心段落：

| 段落 | 核心内容 | 一句话检验 |
|---|---|---|
| **产品模式** | 你做什么产品/服务，解决什么痛点 | 用户不用你的产品会怎样？ |
| **运营模式** | 你怎么做起来——获客、交付、留存 | 你的增长引擎是什么？ |
| **盈利模式** | 你怎么赚钱，什么时候盈亏平衡 | 一笔交易你能赚多少？ |

### 3.4 场景三：面聊投资人——聚焦盈利模式

**投资人最关心的一句话版本**：

```text
「你怎么赚钱？」
```

不要绕弯。直接回答：

- 谁给你钱（B端客户 / C端用户 / 广告主）？
- 付多少钱（客单价 / ARPU / 抽佣比例）？
- 多久付一次（一次性 / 按月 / 按年）？
- 毛利多少（收入减去直接成本剩多少）？

### 3.5 商业模式梳理自检清单

- [ ] 我能不能在 30 秒内说清我的商业模式？
- [ ] 我能不能在 3 分钟内用三段式讲清楚？
- [ ] 我能不能在不看笔记的情况下画出完整的商业模式画布？
- [ ] 每个模块里有没有明显的逻辑漏洞？
- [ ] 我的收入来源和成本结构是否匹配？

## 四、难点2：项目能做多大？——估算天花板

### 4.1 核心认知：天花板不是拍脑袋

```text
「这是一个千亿市场」——这是废话。
```

不是数字越大越好，也不是越保守越好。投资人在乎的是：

```text
你是不是真的理解自己的市场边界在哪里，
以及你用什么方法算出来的。
```

### 4.2 市场规模估算的四种方法

这是课程最核心的框架之一。**建议四种方法至少用两种以上交叉验证。**

| 方法 | 怎么做 | 优点 | 缺点 |
|---|---|---|---|
| **第三方数据** | 引用行业报告：国家统计局、麦肯锡、BCG、艾瑞咨询等 | 权威、省时 | 滞后、颗粒度粗 |
| **自顶向下** | 从宏观数据出发，一层层乘以比例拆到细分市场 | 逻辑清晰，容易讲 | 每层比例可能不准 |
| **自底向上** | 从基础用户单元出发，乘以付费意愿和渗透率 | 贴近业务真实情况 | 需要对用户有深度理解 |
| **寻找对标** | 找到人群/模式相近的成熟业务，进行类比 | 直观，有参照系 | 对标不精准容易有偏差 |

### 4.3 方法详解：自顶向下

**核心逻辑**：从一个大池子出发，一层层往下过滤。

**示例——高端童装电商**：

```
中国服饰市场 2万亿
    × 童装占比 15% → 3000亿
    × 高端童装占比 20% → 600亿
    × 电商渗透率 15% → 90亿
```

**关键原则**：每一层的比例都要有出处，不能全是拍脑袋。

### 4.4 方法详解：自底向上

**核心逻辑**：从一个最小的用户单元出发，向上叠加。

**示例——高端童装电商**：

```
每年新生儿 2000万 → 5-15岁总人数 2亿
    × 年均消费 1000元 → 2000亿
    × 高端占比 20% → 400亿
    × 电商渗透率 15% → 60亿
```

**关键原则**：用户基数要有来源，付费数据最好有调研或类比支撑。

### 4.5 方法详解：寻找对标

**核心逻辑**：找到和你最像的「邻居」，看 TA 们的天花板。

**示例——高端童装电商**：

```
中高端玩具市场 80-100亿
    → 服装市场规模结构类似
    → 推测 80-100亿
```

### 4.6 交叉验证：把四种方法的结果放在一起

```
自顶向下：90亿
自底向上：60亿
第三方数据：70-85亿
寻找对标：80-100亿

→ 结论：这是一个 60-100 亿的市场
```

**投资人的判断**：四种方法都在同一个量级，说明你对市场的理解是扎实的，不是在吹牛。

### 4.7 TAM / SAM / SOM：业务内部视角

融资时可以给 VC 适当包装，但做业务不要忽悠自己。业务内部需要用更严谨的三层概念：

| 概念 | 全称 | 含义 | 怎么算 |
|---|---|---|---|
| **TAM** | 总可寻址市场 | 理论上你的产品能卖的所有市场 | 最宏观的天花板 |
| **SAM** | 可服务市场 | 以你当前的资源和能力能覆盖的部分 | TAM × 你能触达的比例 |
| **SOM** | 可获取市场 | 以你的竞争地位实际能拿到的份额 | SAM × 你的竞争优势能赢的比例 |

### 4.8 当天花板不够大时：三种讲故事思路

如果算出天花板确实不够大，不要硬吹。课程给了三种应对策略：

| 策略 | 适用场景 | 故事线 |
|---|---|---|
| **用高速增长弥补** | 增速 > 行业平均 2-3 倍 | 「天花板虽然有限，但我们正在快速吃掉」 |
| **拓展多元化可能** | 有第二曲线的雏形 | 「第一曲线站稳后，第二曲线打开新空间」 |
| **国际化扩张** | 模式可跨境复制 | 「中国市场是起点，东南亚/欧美是增量」 |

### 4.9 一个核心洞察：周子敬的市场终局判断

```text
进入一个现在分散但是将来有可能高度集中的行业。
```

这是投资人最喜欢的叙事——不是因为现在大，而是因为将来格局会变，而你是那个推动集中化的人。

### 4.10 天花板估算自检清单

- [ ] 我是否用了至少两种方法交叉验证？
- [ ] 每一层比例的出处我能不能说清楚？
- [ ] TAM / SAM / SOM 是否分别算过？
- [ ] 如果天花板不够大，我有没有准备应对策略？
- [ ] 同行/竞品的天花板是怎么算的，和我的差异在哪？

## 五、难点3：为什么你能做成？——讲清项目团队

### 5.1 核心认知：投资人投的不是「优秀简历」

```text
投资人常说「投资就是投团队」。
但这不是让你列简历，而是回答一个问题：
为什么是你？不是别人？
```

### 5.2 投资人心目中「好团队」的三个维度

| 维度 | 投资人想看什么 | 反面案例 |
|---|---|---|
| **行业经验** | 你是否在这个领域有过深度积累 | 跨界空降、对行业一知半解 |
| **完整战斗力** | 核心团队是否覆盖了关键职能（产品+技术+运营+销售） | 全是同质化背景，有明显短板 |
| **创始人特质** | 大公司背景还是连续创业者？你从哪来？ | 说不清自己的创业动机和优势 |

### 5.3 讲团队的两个关键原则

**原则一：讲「不可替代性」，不讲「优秀」**

| 错误的讲法 | 正确的讲法 |
|---|---|
| 「我们团队都是名校毕业」 | 「我在这个行业做了 8 年，经历过完整的起落周期」 |
| 「我们的 CTO 技术很强」 | 「CTO 之前做过同类产品，日活做到过 500 万」 |
| 「我们团队很拼」 | 「我们过去 6 个月从 0 做到 10 万用户，没有花钱投过广告」 |

**原则二：讲「化学反应」，不讲「各自背景」**

```text
投资人不只是看每个人单独有多强，
而是看这群人在一起，是不是 1+1 > 2。
```

- 你们是怎么认识的？不是为了创业临时组的局。
- 你们一起经历过什么？最好有过并肩作战的经历。
- 分工是否互补？不是三个做技术的人凑在一起。

### 5.4 团队故事的叙事结构

用一条清晰的故事线串联：

```
过去经历 → 发现机会 → 决定创业 → 凭什么比别人做得好
```

**示例结构**：

1. **起点**：「我在 XX 公司做了 5 年的 XX 业务……」
2. **发现**：「在这个过程中，我发现了一个被忽视的痛点……」
3. **决策**：「我决定出来做这件事，因为……」
4. **优势**：「我比其他人更有可能做成，因为我有……（资源/经验/认知）」

### 5.5 早期项目团队特别提醒

对于种子轮 / 天使轮项目：

- **团队 > 模式 > 数据**。这个阶段投资人几乎就是在投「人」。
- 如果团队有短板（比如缺 CTO），坦率说比假装有更好，但要说明你已经知道这是一个需要补的环节。
- 创始人必须亲自讲团队的故事，不要推给联合创始人或 HR。

### 5.6 团队描述自检清单

- [ ] 我能不能在 1 分钟内说清「为什么是我们」？
- [ ] 我的团队故事是一条完整的因果链，还是零散事实的堆砌？
- [ ] 我的描述中，「不可替代性」是否压过了「优秀」？
- [ ] 核心职能是否都有能打的人覆盖？
- [ ] 如果投资人追问「你最弱的一环是什么」，我有没有坦率且自信的回答？

## 六、业务梳理的三个常见坑

### 6.1 坑一：用太多专业术语

```text
「我们是一个基于AI驱动的去中心化SaaS协同平台……」
```

**纠偏**：你妈听不懂 = 投资人没耐心听。用白话重新讲一遍。

### 6.2 坑二：只说「没有竞争对手」

```text
「我们没有竞争对手。」
```

**纠偏**：两种情况——要么你没做调研（这是致命伤），要么这个市场根本不存在（更致命）。至少说出你的替代品是谁，哪怕不是直接竞品。

### 6.3 坑三：数据只讲大的，不讲小的

```text
「这是一个万亿市场。」
```

**纠偏**：投资人想知道的是你的 SOM，不是你从网上抄来的行业报告总数字。从大往小拆，才有说服力。

## 七、业务梳理完成后：七个投资人必问的核心问题

梳理完三个难点后，用这七个问题做最终检验。这是以太内部提炼的「投资人视角七个核心问题」：

| 序号 | 问题 | 检验什么 |
|---|---|---|
| 1 | 你的用户是谁？他们的痛点是什么？ | 需求是否真实存在 |
| 2 | 你的解决方案是什么？为什么比现有方案好？ | 产品是否有差异化价值 |
| 3 | 你怎么赚钱？盈利模式是什么？ | 商业模式是否成立 |
| 4 | 这个市场有多大？你怎么算出来的？ | 天花板是否足够 |
| 5 | 你的竞争对手是谁？你有什么壁垒？ | 竞争优势是否持续 |
| 6 | 为什么是你们这个团队？ | 团队是否不可替代 |
| 7 | 你下一步的里程碑是什么？需要多少钱？ | 融资节奏是否合理 |

> **把所有问题放在一张纸上，让不熟悉你业务的人挨个提问。答不上来的，就是盲区。**

## 九、三节课之间的关系

```text
融资必修1 → 知道「为什么要梳理」和「用什么姿势梳理」
融资必修2 → 把业务拆成三块（模式/天花板/团队），一块一块讲清楚
融资必修3 → 把梳理好的内容写成一份合格的 BP
```

梳理是地基，BP 是楼上。地基歪了，楼盖得再漂亮也没用。

## 十、核心记忆点（30 秒回顾）

```text
1. 梳理业务是融资的根基：说不清业务，BP 写得再漂亮也没用。
2. 难点1：讲清商业模式 —— 公司内部用画布，BP 用三段式，见投资人聚焦盈利模式。
3. 难点2：估算天花板 —— 四种方法，至少两种交叉验证。自顶向下 × 自底向上。
4. TAM/SAM/SOM：做业务不要忽悠自己，用保守的 SOM 指导决策。
5. 天花板不够大：高速增长 / 多元化 / 国际化，三种故事线备好。
6. 难点3：讲清团队 —— 不是列简历，是回答「为什么非得是你们」。
7. 团队故事线：过去经历 → 发现机会 → 决定创业 → 凭什么比别人做得好。
8. 终极检验：七个投资人核心问题，挨个过，答不上来就是盲区。
9. 进入一个现在分散但未来会高度集中的行业 = 投资人最喜欢的叙事。
10. 梳理完业务 → 下一步：准备一份好的 BP（融资必修3）。
```
