## 一、开篇三条铁律原则

**原则①：不碰红线**
- 只做合法合规的事，返点/腐败/暗箱操作/违规均不讨论
- 一堂学员基本操守：务实+正直

**原则②：只谈商务**
- 范畴限定：给大客户个性化送礼 + 给小B/用户规模化送礼
- 不包含：公司内部员工福利、朋友间、情侣、父母长辈送礼
- 商务送礼有目的性，亲属送礼是单纯感情和爱

**原则③：不要迷信**
- 送礼 ≠ 立刻成交、立刻搞定客户（就如「销售≠会喝酒」）
- 定位：维护客户关系的重要手段之一，和「卖点提炼」「客户分层」「销售激励」一样，只是手段
- 不轻视，也不迷信

**徐剑金句**：「送礼和"卖点提炼""客户分层""销售激励"一样，只是个手段而已。」

## 二、为什么需要科学送礼：普遍痛点

**三大糟糕回忆**：
- **老三样困境**：月饼、茶叶、粽子年年送，花了几万十几万成本，只送出几百几千效果——钱花了没差异，记不住
- **选品无能**：见识不够，不知道优秀礼物怎么一步步思考设计出来的，每年选品都很难
- **犯忌讳翻车**：批量送猪肉给清真领导、号码牌数字不吉利、大闸蟹不会做——心意好，得罪人

**核心问题**：送了10多年礼、上千件礼物，还是送不出去、送得尴尬、送不到位——甚至搞砸关系、失去信任、搞没订单

## 三、送礼的本质与六大价值

**本质**：商务送礼 = 促进社交，构建信任，推动商务关系到达下一个节点

**六大价值**：
- **加活跃**：增加粘性和活跃
- **表心意**：表达支持与喜爱
- **建关系**：提升信任和关系
- **做传播**：提升品牌和传播
- **做试探**：可以试探和破冰
- **做提醒**：替你和你的产品说话

**替代方案（不送礼也能提升信任）**：吃饭、喝酒、唱歌、一起旅游；好好打磨产品和服务、打磨品牌营销故事

**核心信念**：「送礼不是玄学，不是关系学，不是厚黑学，就是一个非常有效的业务工具，也可以提假设、建模型，也可以当做团队的核心能力来做。」

## 四、60分：提见识——大量搞砸与出色案例

### 糟糕送礼五大典型翻车

**翻车① · 老三样随大流**
- 新年送日历、十五送元宵、端午送粽子、中秋送月饼
- 问题：太普通，对方根本记不住——过节收到几十盒月饼粽子，分不清哪盒是谁的
- 扩展：每次中秋送月饼大闸蟹、探望送果篮、新年送台历、春节带土特产、预算不够送本子笔水杯

**翻车② · 活体动物灾难**
- 送活大鹅：箱子里鹅叫、高速上怕飞出来、放浴室关两天、开车满世界找能宰鹅的菜市场、车做全面内饰清洁（洗车师傅问「大哥做禽类生意的吧」）
- 扩展：送半只羊自己分割（大型分shi现场）、大鱼占浴缸自己刮鳞、海产品腥味多天不散、腊肉不会做全扔了、没切鹿茸至今在冰箱

**翻车③ · 不考虑使用场景**
- 送带巨大Logo的人体工学椅，董事长来问「你和这个供应商什么关系」——赶紧换掉
- 当着摄像头硬塞礼物、当着几十人面给领导送礼被保安带出办公楼、趁人不在放下就走连名字都没留
- 中铁合作方当众送两条烟、女客户送男客户一盒袜子（回家没法交代）、送超大盆栽不会养

**翻车④ · Top5失败场景**
- 不知道谁送的
- 送完没有跟进
- 无包装、包装差（报纸卷脚踏板→被当成送钱）
- 公开送礼
- 抱佛脚，意图太明显

**翻车⑤ · 送礼不考虑收礼负担**
- 送84寸触控一体机（400斤，需叉车卸，全办公室男士上阵累到买盒饭补充体力）

### 出色送礼标杆案例

**案例① · 新疆羊肉烧烤全链条服务（顶级案例）**
- 第一步：新买小羊羔，当地切割剔骨穿串，航空加急
- 第二步：第二天中午北京机场落地，远程找货拉拉取货送到公司
- 第三步：加钱让司机去市场把烧烤炉子、碳、烧烤料全买好送过来
- 第四步：当天团建，还找了一个烧烤师傅跟着整个公司去
- 评价：「这是我们吃过的最最最最最完整服务的一次烧烤，没有之一」

**案例② · 给客户家人的天文望远镜**
- 客户孩子8-9岁过生日，送「带手机自动找星星」功能天文望远镜 + 上门安装调试服务
- 客户拒绝安装自己上手，妈妈在旁边笑，孩子催爸爸快点装「我要看月亮」
- 客户反馈：「以前围在一起就是监督写作业，好久没有在一起开心相处了」

**案例③ · 给合作伙伴兄弟的366双袜子**
- 年前吃饭听说对方忙得没时间打理、只有三双袜子、媳妇也不管
- 立刻买366双各类袜子→被感谢发朋友圈昭告天下

**案例④ · 品牌厂商的优秀伴手礼**
- 英伟达PCB格尺、龙芯钥匙扣、联想65w充电器、什么值得买积木
- 设计公司把自己设计的美术馆做成纸片装饰品，一直放在桌面上

## 五、70分：建框架——商务送礼人货场三角形

**核心模型**：送礼 = 人（送给谁）+ 货（送什么）+ 场（怎么送）
- 两类送礼差异：左边偏个性化ToB/高客单/关系型/点对点 vs 右边偏运营ToC/To小B/中低客单/1v多营销
- 颜色分区逻辑：越往上越精准，越往下越标准
- 策略权衡：综合取舍【精准】和【标准】

### 基本功① · 分析送礼的「人」

**送礼对象筛选五段位**：

| 段位 | 送谁 | 典型场景 |
|:---|:---|:---|
| L1 目标人 | 只需要送决策者本人 | 做SAAS只送采购负责人；做交付只送技术领导 |
| L2 目标人+影响者 | 家人（子女/父母/配偶/宠物）+同事（红人/上下级/司机/秘书）+朋友 | 给代理商领导的父母送羽绒服，一送几百件全部超级喜欢 |
| L3 +项目周边人 | 加上看似无关但其实是项目周边的人 | 其他科室领导（过会时全公司领导会议）；具体测试用户、财务、甚至加班时看门大爷 |
| L4 +定期维护 | 形成固定送礼节奏和心智 | 每月1号送水果——客户打电话来问「水果呢？你们公司出问题了？」→已形成心智 |
| L5 顶尖高手 | 随时创造专属送礼时间，不经意间想送就送 | 小销售到哪都让客户介绍对象，介绍成了送礼感谢→主动创造强交互 |

**关键案例**：
- 医院信息中心7个技术人员坐一起，只送对接的1个人→后来找其他人调试都爱答不理
- 某省教育局：主管处长+司机+门卫都照顾到→从门卫那知道友商来访时间，推测项目推进进度
- 黑客技术转销售：带客户参加黑客技术比赛，荣誉都写客户名字和客户所在部门→超高价值

### 基本功② · 分析送礼的「货」

**9大选品策略矩阵**：

| 分类 | 思考维度 | 策略关注点 |
|:---|:---|:---|
| 收礼人 | 刚需上 | 刚需常用不舍得买 > 低性价比 > 日常需求 |
| 收礼人 | 专属上 | 专属荣誉 > 惊喜 > 专属 > 稀缺 > 昂贵 > 通用 |
| 收礼人 | 价值上 | 情绪价值 > 功能价值 > 价格 |
| 礼品 | 频率上 | 高频 > 低频（用到/看到/想到 = 都是高频） |
| 礼品 | 复用上 | 能反复送 > 单次送 |
| 礼品 | 时间上 | 长期用 > 短期用 > 单次用 |
| 场景 | 互动上 | 共同体验 > 个人体验 > 静止无互动 |
| 场景 | 情绪上 | 公开晒/炫耀 > 公开用 > 私下用 |
| 场景 | 传播上 | 有公司文化属性 > 无公司文化属性 |

**两大核心选品逻辑**：
- **低「性价比」策略**：500预算买耳机→中低端；买显示器→最差的；买钢笔→中高水平；买保温杯→中高。建议买「低性价比」品类中的高配
- **高频用策略**：送完就吃完扔了 vs 能持续用反复用。豪车毒老纪送嘉云糖罐子：吃完罐子可以收藏一排/养鱼/养多肉/养乌龟→深深刻在客户记忆里

**选品不为清单**：

| 问题分类 | 一句话解释 | 典型礼品 |
|:---|:---|:---|
| 价格感知不强 | 收礼人对价格不可感知 | 大部分茶叶、土特产 |
| 严重同质化 | 大家都在送的，至少选同品类最好 | 苹果手机不能选128G要选512G |
| 限制使用条件 | 时间/文化/偏好等特殊限制 | 大闸蟹、限时礼品卡、演唱会门票 |
| 体验难度太高 | 增加用户负担降低送礼效果 | 3000块积木拼装、稀有植物 |
| 品质差 | 影响对公司产品评价 | 易坏数据线、三无充电宝、几十块电脑包 |
| 占用空间 | 可能影响家装风格 | 挂画、大花盆、大型玩具车 |
| 过于贵重 | 远超收入和关系亲疏度 | 1w工资送5w的表 |
| 太个性化 | 很难匹配对方偏好 | 护肤品、香水、服饰 |
| 太专业 | 自己理解难达到对方标准 | 跑鞋、发烧音响、字画 |
| 太过隐私 | 越界和造成误会 | 女销售送男客户袜子 |
| 预期结果不好 | 体验/使用结果可能不佳 | 体检、戈壁徒步、爬山 |
| 不分层 | 不同职位应有所差异 | 领导送万宝龙，职员送凌美 |

### 基本功③ · 分析送礼的「场」

**场景触点模拟六步闭环**（站在用户角度，核心原则：不能让客户有负担）：
- 模拟送的过程
- 模拟收的过程
- 模拟用的过程
- 模拟存的过程
- 模拟再次见面
- 模拟回的过程

每个环节都要舒服、别有硬伤，才是一个最完整的送礼流程。

**送礼时间节点五段位**：

| 段位 | 策略 | 案例 |
|:---|:---|:---|
| 入门 | 过节送礼（狭义触点） | 中秋/春节扎堆送 |
| 进阶 | MOT峰终定律（广义触点） | 考试结果出来时送短信推送；对方急需时送口罩/布洛芬 |
| 高阶 | 创新触点 | 造节送礼、日常送礼、峰值送礼、开头结尾送礼 |
| L4 | 定期赠送 | 每月1号送水果→送出来一个心智 |
| L5 | 随时创造专属时间 | 小销售让客户介绍对象→创造强交互；封箱酒节 |

**一堂触点实践**：从春节送教材→马拉松/出圈日/200期校庆造节→每周五「我请客」日常→优秀毕业生/升年级峰值→线下课HappyEnding + 任务见面礼→中秋/端午反而静默不送，和同行错开效果更好

**场景设计不为清单**：
- 派送原则：小礼公开送，大礼品隐蔽送；小礼送公司，大礼送车里/家里/快递
- 必跟故事：跟上一个故事，体现用心+加深印象，故事是礼品的内核之一
- 必做跟进：确认是否收到，送上祝福语
- 准备话术：防拒绝话术、防推辞话术、保持关系话术
- 注意礼仪：给对方留下好印象

## 六、85分：提价值——礼物价值提升七感武器库

**核心模型**：七感模型 = 4种追求「名利权情」+ 3种包装出来的感觉

**口决记忆**：「4+3」——荣誉感 + 昂贵感 + 权益感 + 专属感 | 趣味感 + 高级感 + 实用感

> 一盒月饼/月历/笔记本/书包/书，从中刻意增加1-3种感觉，价值感就会显著大幅增加。

---

**提升① · 荣誉感（名）**
- 原理：人普遍希望拥有名誉、喜欢被赞扬、喜欢声誉
- 方法：授予奖励、授予身份、奖牌、奖状、电子证书
- 案例：BiliBili粉丝奖牌、Keep奖牌变商业模式、一堂马拉松奖牌、钉钉大会给徐剑颁「青藤王者」→徐剑在自己公司周年庆给合作伙伴颁「数族之光」

**提升② · 昂贵感（利）**
- 原理：「值钱」是相对感受——2000送手机很便宜，2000送打火机就是奢侈品
- 方法：买低性价比品类的高配、精美包装、关联金银
- 案例：送笔（红环自动铅笔/施华洛世奇笔/派克钢笔）；徐剑年会做金手链（克数不高仅200元，包装精美有证书，没到场的人懊悔可惜，后续活动到场率极高）

**提升③ · 权益感（权）**
- 原理：人想要特权、特殊权利、别人没有的身份资源——ROI极高
- 方法：身份特权、特殊资源、特殊名额
- 案例：一堂年级解锁《我用一堂12345》、MBA高阶社群、马拉松内场VIP；VMware送粉丝T恤、英特尔送VIP包、柯达送VIP客户限量金属模型套装

**提升④ · 专属感（情）**
- 原理：「名利权情」之情——专属感、私交、人情，人与人和公司间的特别关系
- 方法：文化定制、特别签名、写祝福语、手工制作、特意定制、带客户姓名/Logo
- 案例：甘孜文旅「千年之吻」汽车香氛；马占凯签名+寄语几十块书→数千上万价值感；某同学善剪纸艺术创作肖像/产品/场景送中外客户；拍卖会上看到紫砂壶带「徐」字专门拍下；中通客车宣传处剪纸送国外客户；上门给客户种植物、上门烹饪大闸蟹；茅台开瓶器；冬奥冠军签名明信片；送清真月饼给回民专家；送糖尿病随身健康提示给糖尿病合作方；老干部母亲去世租30辆奔驰宝马；非洲部落葬礼特意参加（有外国人参加是最高礼遇）；送带姓氏冲锋衣

**提升⑤ · 趣味感**
- 原理：人喜欢新鲜、有趣、有意思的东西
- 方法：趣味包装、礼物变盲盒、超级大、超级小、大小整套
- 案例：蔡澜花花世界兔年月饼盒→DIY创作+自带马克笔干掉阻力；小王子联名食物盲盒；一堂大缸子（大到泡面都大，网红属性）+ 大中小一套；一堂专题随机图书盲盒；粽子礼盒拼成龙舟能吃能玩

**提升⑥ · 高级感**
- 原理：人对高级/艺术/有才华的东西普遍更认可价值
- 方法：特别艺术设计、文化定制、增加金句
- 案例：德国净水器龙头获红点设计大奖→伴手礼→第二天拿去集团送CEO→夸奖产品有调性→拿下战略合作起画龙点睛作用；东莞莞香礼盒包装素雅，既记住城市又增加儒雅好感；一堂欢喜笔记「进一寸有一寸的欢喜」；黄宝书扉页「有些书只用读一遍，而这本手册，值得你翻烂」；香薰包装燃烧到底浮现另一句话；送白茶加话「一年是茶、三年是药、七年是宝」；南极寄明信片「我在世界尽头想起你」；西西弗惜福日历每天一本书一句话→翻到共情瞬间

**提升⑦ · 实用感**
- 原理：东西本身实用，或通过技巧让「本来不实用的」变实用
- 方法：变成清单、变成工具、变成实用工具
- 案例：黄宝书加二维码&电子版画布→大大增加实用性；欢喜笔记开篇加「选课清单」+页面下加「关联思考」→增加功能性；水水500本图书合集加「阅读时间」→海报变阅读目标清单；线下毕业证书背面印整个训练所有关键小抄

## 七、一堂规模化送礼的工业化复盘

**送礼段位演进史**：
- **V1 初创期**：大节日人工发几百份→手忙脚乱
- **V2 22年**：成立「泛产品设计」虚拟小组 + 3大调整（统一供应商库 / 外部仓库+统一物流SOP / 全场景覆盖）→瞬间拥有批量发上千件能力
- **V3 23年起**：创新「**攻坚会**」解题方法——集体共建+群体智慧涌现投票→工业化生产礼品

**攻坚会流程**：明确目标（场景/目标/预算）→ 建立审美（过去Top礼物雷达图模型）→ 各自提案（每人2-5个）→ 现场激发（头脑风暴30-50个选项）→ 深度打磨（合并优点重新设计）→ 礼物讲香（包装文案/起名字/讲香优化）

**V4 持续升级**：
- 发现「大海报」「卡牌」ROI极高——几块钱成本，三位数甚至四位数心理价值感，且增加传播和壁垒（迁移成本），每年大量新课题可做，一口气做十几套
- 5年IT和学籍系统发挥作用——分层定制、随机金句、学届定制，最近马拉松名字和排名1v1定制

**成果**：50人小创业公司，少量业余时间（无全职），硬生生做出十亿美金级别公司的送礼水平

**一堂的礼品矩阵**：产品化→SOP化→工业化→个性化→金句化→定制化（还在持续迭代：一堂小卖部 / 微信送礼 / 惊喜计划 / 训战带走落地计划……）

**并非终点**：「不到最佳，终不还！」——无限进步追求

## 八、收尾：重新理解科学送礼的三句话

**第一句：送礼是一个科学基本功。**
送礼不是玄学、不是关系学、不是厚黑学。就是一个非常有效的业务工具，可以提假设、建模型，可以当作团队核心能力来做。一旦重视起来，不再是千年不变的随大流送节日礼物，而是不断提升客户信任、同时修炼内部能力的利器。

**第二句：送礼也可以无限进步。**
有的送礼很精准但不够标准化，有的礼物很标准但不够精准和有价值。送礼是一个可以长期不断修炼、不断进步、不断精进的核心能力。

**第三句：喜欢和用户交朋友的公司，运气总不会太差。**
当你把用户当朋友，说人话，对他好，真心帮助他，然后期待他变得更好。把时间拉长，这些付出都会以「运气」的方式不断还给你。少发80%礼物短期不会怎样，但你会失去：出现在书架上的机会、出现在会议桌上的机会、出现在聊天语境里的机会、出现在朋友圈里的机会——这些短期不重要，但长期是商业终局最核心的**品牌壁垒**和**迁移成本**。

## 九、马易ToB送礼成长复盘（精华浓缩）

**送礼段位成长路径**：
- 阶段一（小白）：什么贵送什么，什么好送什么，自己喜欢就送什么；当着几十人面给邮储领导送粽子→被骂+保安带出楼→2年内没参与任何项目
- 阶段二（模仿）：学着前辈送→逢年过节盯关键人送→发现「钱没少花，大家送的一样，效果不好」；客户一个节日收200多箱月饼→楼下食堂给员工分了
- 阶段三（总结规律）：不能公开送 → 不能扎堆送 → 不能不署名 → 不能价格太高（违法违规给收礼人惹麻烦）
- 阶段四（突破）：帮某央企客户写创新业务申报材料，拿全公司二等奖→整个部门态度转变→订单不用说了。明白「送烟送酒是最低级行为」+「不只送关键人，要围绕关键人送周围人」
- 阶段五（系统化）：Excel记录客户喜好和历史送礼信息 → 礼品标准化（1500元/年每人，单次不超500）→ 每月1号送水果（形成心智）→ 礼品库建设（不同场景/不同人/不同标准选取）→ 团队送礼水平下限整体提升，费用可控，运营效率提升
