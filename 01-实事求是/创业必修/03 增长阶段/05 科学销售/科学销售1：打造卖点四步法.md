# 科学销售1：打造卖点四步法 · L6 清单体笔记

> 课程：科学销售1：打造卖点四步法｜讲师：李蕊｜平台：一堂
> L6 标准：不只罗列知识点——拆底层结构、建要素关联、标常见误区、给可迁移判断框架。

---

## 一、先看清楚：这节课在科学销售五步法中的位置

### 1.1 一句话定位
**打造卖点是科学销售的第一步——做错了，后面过程拆解、业绩推进、激励、工具，每一步的质量都会被打折；做对了，它像火车头一样拉着后面四步的价值往上升。**

### 1.2 它在五步全景中的坐标

```
科学销售五步法：
A.提炼卖点 ← 本节
B.拆解过程
C.推进业绩
D.激励团队
E.打造工具
```

### 1.3 这节课的核心交付
**两个四步法 + 一套落地工具**：

| 交付 | 内容 |
|---|---|
| **用户分层四步法** | 搞清楚「卖给谁」——哪类客户才是重点 |
| **卖点提炼四步法** | 搞清楚「怎么打动他」——对每类重点客户说什么 |
| **全套落地工具** | Checklist + 模板表 + 最佳实践合集，拿来就能用 |

> **关键关系**：先分层、再提炼。不对的人，对的卖点也是错的。

## 二、第一个四步法：用户分层

### 2.0 这一步到底在解决什么

**大多数团队的真相**：销售出去跑了一圈又一圈，才发现自己根本就没想清楚——哪些线索是重点？哪类客户值得花最多时间？

**用户分层的本质**：不是给客户贴标签，而是**让团队知道往哪使劲**。

| 不做用户分层 | 做用户分层 |
|---|---|
| 所有客户一把抓，销售各自为战 | 明确主攻方向，资源集中投放 |
| 销冠一走，客户判断经验全带走 | 分层标准沉淀在组织里，可复制 |
| 不同客户用同一套打法 | 不同层级配不同策略和跟进强度 |
| 销售之间无法交流经验 | 同类客户经验可共享、可复盘 |

### 2.1 用户分层四步法全景

| 步骤 | 做什么 | 落地工具 |
|---|---|---|
| **第一步：确定销售目标** | 先想清要攻什么市场、做到什么规模 | 常见销售目标清单 Checklist |
| **第二步：提出分层假设** | 做加法（穷举可能用户群）→ 做减法（聚焦最有价值的） | 常见用户分层清单 Checklist |
| **第三步：验证用户分层** | 用数据分析 + 实验，验证假设是否成立 | 数据分析 & 做实验方法 |
| **第四步：分层全面执行** | 配套资源、指标、话术，按分层差异化打 | 用户分层落地模板表 |

### 2.2 每一步的深层拆解

**第一步：确定销售目标**

这是用户分层的前置条件——不知道要去哪，就没法判断谁是你的用户。

方法路径：

| 分析维度 | 要搞清楚什么 |
|---|---|
| 分析产品 | 你的产品天然更适合哪类人？ |
| 分析常识 | 行业的基本判断：谁更需要你？ |
| 分析历史成交 | 已经成交的客户里，谁最优质？ |
| 分析同行 | 竞品在打哪群人？他们漏掉了谁？ |
| 分析专家 | 行业老炮怎么划分这个市场？ |

> **常见错误**：跳过目标直接分层。结果是分出来了，但不知道哪个分层值得重点打。

**第二步：提出分层假设**

这是最关键的一步——两层动作，缺一不可：

```text
【做加法】穷举所有可能的用户群体
  方法：拆解最佳实践、调研、头脑风暴
  目标：不遗漏可能的金矿

【做减法】聚焦最有价值的用户群体
  方法：按体量、利润、频次、竞争强度筛
  目标：找出能让你活下来且能长大的那群人
```

> **核心认知**：这一步叫「假设」，不是「结论」。没有验证之前，你只是提出了一个需要被检验的判断。这和一堂「关键假设」的方法论一脉相承——先写下来，再去验证，不断迭代。

**第三步：验证用户分层**

假设不验证 = 赌博。

| 验证方式 | 做什么 |
|---|---|
| 数据分析 | 拉历史数据看不同分层的转化率、客单价、复购率、生命周期价值 |
| 做实验 | 小范围定向打某个分层，看实际转化效果 |

> **常见错误**：拍脑袋分了层，就直接全面执行。李蕊老师反复强调——哪怕经验丰富，到了实践中检验时，仍然会有不少需要校准调整的地方。

**第四步：分层全面执行**

验证通过 ≠ 万事大吉。这一步要把分层「落地」：

| 落地动作 | 说明 |
|---|---|
| 配套资源 | 不同层级配多少人、多少钱、多少时间 |
| 配套指标 | 不同层级的转化目标和考核标准 |
| 配套话术 | 不同层级的销售卖点和跟进策略 |
| 配套节奏 | 不同层级的跟进频率和触达方式 |
| 动态迭代 | 市场在变，分层也要定期校准 |

> **关键认知**：用户分层不是一次性工程。它是一个「写假设 → 验证 → 执行 → 迭代」的持续循环。

### 2.3 用户分层最容易被忽略的三个隐形价值

1. **明确工作方向**：销售往哪类客户上使劲，不再瞎跑。
2. **明确策略差异**：不同类型和重点级别的客户，安排不同强度的跟进动作和运营动作。
3. **为卖点精准度打底**：用户切得越清晰，后续匹配卖点就会越精准。

## 三、第二个四步法：卖点提炼

### 3.0 这一步到底在解决什么

**大多数团队的真相**：让销售出去讲产品，结果每个人讲的都不一样。有的讲功能，有的讲价格，有的讲情怀——你根本不知道哪个版本最有效，也无法复盘优化。

**卖点提炼的本质**：不是写一句广告语，而是**让团队知道「对这个人，现在说什么最能打动他」**。

### 3.1 卖点提炼四步法全景

| 步骤 | 做什么 | 落地工具 |
|---|---|---|
| **第一步：写出初始版本** | 三种写法快速起手：1+N法 / 逻辑型 / Top3 | — |
| **第二步：建立卖点审美** | 知道「好卖点」长什么样 | 优秀卖点检查清单 Checklist；常见卖点提炼维度清单 Checklist |
| **第三步：进行多轮打磨** | 内部讨论 → 外部定性 → 外部定量，反复修正 | 外部定性判断方法清单；外部定量方法清单 |
| **第四步：落地场景应用** | 不同角色、不同决策阶段用不同卖点 | 常见卖点落地清单 Checklist |

### 3.2 每一步的深层拆解

**第一步：写出初始版本**

三种起手写法，告别空白文档恐惧：

| 写法 | 怎么做 | 适用场景 |
|---|---|---|
| **1+N 法** | 1 个核心卖点 + N 个支撑卖点 | 有明确主打方向，需要体系化 |
| **逻辑型** | 按「为什么选 → 为什么好 → 为什么现在」的逻辑链写 | 需要层层说服的复杂决策 |
| **Top3 法** | 只提炼最强的 3 个卖点，其他删掉 | 资源有限，需要聚焦一击必中 |

> **核心认知**：初稿不需要完美。先写出来，才有东西可以打磨。这和一堂「先完成再完美」的底层价值观完全一致。

**第二步：建立卖点审美**

这一步是整套方法论里**最容易被跳过、但最决定质量**的一步。

很多人以为卖点就是「把产品功能列出来」，但好的卖点有清晰的审美标准：

| 审美维度 | 好卖点的标准 |
|---|---|
| **具体** | 不空泛。不是说「质量好」，而是说「故障率低于0.3%」 |
| **差异化** | 不和竞品讲一样的东西。找到「只有我能这么说」的点 |
| **对客户有价值** | 不是「我们有多牛」，而是「对你有用在哪」 |
| **可感知** | 客户能秒懂，不需要你解释三分钟 |
| **可量化** | 能用数字就不用形容词。「提升效率」不如「从3天缩到2小时」 |

> **小冰块案例（课内经典）**：一家充电产品公司，从「体积小、充电不过热、充电快」进化到：
> - 小，体积减小 **50%**
> - 冰，充电降温 **40%**
> - 快，充电提速 **400%**
>
> 然后把三个卖点组合，取名「**小冰块**」。三个特征融成一个可感知的名字，用户听完就记住。
>
> **这个案例的 L6 解读**：它示范了审美标准的三个层次——①卖点数字化（从模糊形容词变成具体数字）→ ②卖点结构化（三个维度各一句话）→ ③卖点命名化（一个好名字让整套卖点自己会传播）。

**第三步：进行多轮打磨**

卖点不是写出来的，是**磨**出来的。三个阶段：

| 打磨阶段 | 做什么 | 核心问题 |
|---|---|---|
| **内部讨论** | 团队内部交叉挑战卖点 | 「这个卖点真的独特吗？」「客户真的在乎吗？」 |
| **外部定性** | 拿给客户/渠道/伙伴听，看反应 | 「听完你最记住哪个点？」「听完你会买吗？」 |
| **外部定量** | 用数据测试不同卖点的转化率 | A/B 测试：版本A vs 版本B，哪个转化更好？ |

> **李蕊老师的核心态度**：精益求精。哪怕你觉得卖点已经很明确了，还要多轮打磨，不断回到用户场景，在每个节点上去校验。这种追求是一般销售团队和顶级销售团队的分水岭。

**第四步：落地场景应用**

卖点提炼完锁在文档里 = 白做。这一步解决「怎么让卖点真正用起来」：

| 落地维度 | 做什么 | 举例 |
|---|---|---|
| **不同客户角色** | 同一产品，对不同人说不同卖点 | 决策者关心 ROI，使用者关心好不好用，采购关心风险 |
| **不同决策阶段** | 初次接触 vs 深度沟通 vs 临门一脚，卖点不同 | 初接触讲差异化，深度沟通讲案例，临门一脚讲紧迫性 |
| **不同渠道** | 电话、面谈、微信、官网、展会，卖点适配 | 面谈可以展开，微信要一句话说清 |
| **全员培训** | 不只是发文档，要演练、要考核 | 让每个销售都能用自己的话把核心卖点讲清楚 |

> **常见错误**：提炼了一个「万能卖点」，对所有场合所有人用。事实上，卖点应该是一套「武器库」，在不同场景调用不同武器。

### 3.3 用户分层 × 卖点提炼的咬合关系（L6 理解）

这两个四步法不是孤立的——它们之间存在一个**强咬合**关系：

```text
用户分层 ←→ 卖点提炼

用户不同 → 痛点不同 → 卖点必须因「层」而异
卖点反馈 → 暴露分层不准 → 回过来修正分层假设
```

**一句话**：你卖给谁，决定你说什么；客户对你说什么的反应，反过来检验你「卖给谁」的判断对不对。

> 这也解释了为什么这节必修课叫「打造卖点四步法」而不是两个独立的课——因为它们本质上是同一个工作的前后两半。有同学总结得很精准：**用户分层的四步法 = 销售目标定位 → 提出分层假设 → 验证 → 配套落地 → 动态迭代；卖点提炼的四步法 = 对应不同用户的卖点假设 → 提出卖点假设 → 验证卖点假设 → 配套落地 → 动态迭代。** 两套方法的底层逻辑完全同构，都是一堂关键假设方法论在销售场景的「用」。

## 五、常见误区雷达

| 编号 | 误区 | 为什么是错的 | 正确做法 |
|---|---|---|---|
| ① | 不做用户分解，所有客户一把抓 | 资源分散，销售各自为战 | 先分层再分配，集中打最有价值的 |
| ② | 不做卖点提炼，让销售自由发挥 | 每个人说的都不一样，无法复盘优化 | 统一提炼核心卖点，培训后上场 |
| ③ | 卖点只写不用，锁在文档里 | 提炼了等于白提炼 | 培训 + 演练 + 考核，确保每个销售真会用 |
| ④ | 一个卖点打所有客户 | 不同客户痛点不同，一套话术不可能通杀 | 按用户分层匹配差异化卖点 |
| ⑤ | 卖点停在「讲功能」，不「讲价值」 | 客户不关心你有什么，只关心对他有什么用 | 把每个功能翻译成「对客户的具体价值」 |
| ⑥ | 分层和卖点一次性做完就不再迭代 | 市场在变，客户在变，竞品在变 | 定期复盘，把分层和卖点当活资产持续迭代 |

| 模块 | 内容 |

## 七、如果你只能带走三样东西

1. **「先分层，再提炼」是铁律**。不知道卖给谁，就不可能有对的话术。这个顺序不能反。
2. **卖点的审美是可训练的**。不是凭感觉说「这个卖点不错」，而是用具体、差异化、对客户有价值、可感知、可量化五个标准来判断。建立审美比写出第一版更重要。
3. **卖点不是写出来的，是磨出来的**。写出初版只是 10%，剩下的 90% 是内部挑战 → 外部定性 → 外部定量 → 场景落地 → 持续迭代。锁在文档里的卖点 = 没有卖点。
