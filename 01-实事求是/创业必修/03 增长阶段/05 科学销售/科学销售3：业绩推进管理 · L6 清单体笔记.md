## 一、先看清位置：这节课在五步法中的坐标

### 1.1 一句话定位
**业绩推进管理是科学销售第三步——前面卖点提炼和过程拆解都是「设计」，这一步是把设计落到真实的销售动作上、拿到结果。没有这一步，再好的设计也是纸上谈兵。**

### 1.2 它在五步全景中的位置

```
科学销售五步法：
A. 提炼卖点 ──→ 对谁说什么
B. 拆解过程 ──→ 在哪个节点用力
C. 推进业绩 ← 本节 ──→ 怎么盯过程、拿结果
D. 激励团队 ──→ 怎么持续驱动
E. 打造工具 ──→ 所有设计的落地载体
```

### 1.3 这节课的核心交付

```text
一句话定义：业绩推进 = 通过拆目标、盯过程，拿到最终想要的业绩结果。
```

| 交付 | 内容 |
|---|---|
| **业绩必达三步法** | 拆解目标冲业绩 → 制定策略可执行 → 日常推进追目标 |
| **三个管理原则** | 跳一跳够得着 / 盯紧20%项目 / 结果都是追出来的 |
| **一个完整进化案例** | 李蕊涂料公司从「拍脑袋」到「科学管理」的三阶段演进 |
| **两套业务案例** | 2B 头部支付公司案例 + 2C 电商最佳实践案例 |
| **全套落地工具** | 常见拆解维度清单 + 常见策略清单 + 常见跟进手段清单 + 业绩跟踪管理模板 |

## 二、先诊断：不推进业绩，团队长什么样

### 2.0 80% 的团队卡在哪

李蕊老师开篇判断：

```text
起码有 8 成以上的同学，连最基础的「把定好的销售目标完成」都做不好。
```

三个典型症状：

| 症状 | 本质问题 |
|---|---|
| 公司大目标挂在墙上，销售不知道今天该干什么 | **没拆目标**：目标停在数字，没落到人头和动作 |
| 周会只问「签了吗」，不问「卡在哪一步」 | **没盯过程**：只看结果，过程是黑箱 |
| 销售有业绩 gap 时，管理者给不出具体帮助 | **没策略辅导**：只会催，不会帮 |

> **核心判断**：顶级销售总监不是「运气好碰上牛销售」，而是「目标拆得细、过程盯得住、gap 出现时有办法」。

### 2.1 业绩推进说到底是在干什么

一句话版本：

```text
业绩推进 = 一次性为一类业务、一个团队，设计一套「目标→策略→跟进」的落地闭环。
```

展开三层理解：

| 层级 | 含义 |
|---|---|
| **对销售** | 知道本月重点打什么项目、关键节点在哪、卡住了找谁要策略 |
| **对管理者** | 有抓手：日周月该盯什么数据、什么会议该追什么问题、什么项目该亲自下场 |
| **对组织** | 目标有依据、过程有监控、策略有迭代，不靠天吃饭 |

### 2.2 核心底层认知：这一步是前面两步的「检验器」

```text
业绩推进 与 提炼卖点 / 过程拆解 之间的三个咬合关系：

第一，业绩推进可以检验分层和卖点的准确性。
    → 为了完成目标，你知道怎么一步步追。追的过程中发现人群不对、卖点不准，就反过头去优化前面。

第二，业绩推进可以检验过程拆解是否清晰、动作是否匹配。
    → 如果卖点对了，但业绩还是追不动，就去检查过程拆解是否拆到位、每个节点的动作是否够用。

第三，前两者都没问题，管理的重点就落在让销售刻意练习，把每个执行动作做到位。
    → 如果销售做不到位，就想各种办法帮助销售刻意练习。
```

> **L6 解读**：这层关系是整节课最被低估的认知。很多管理者把业绩推进当成孤立环节，实际上它是前两步的「实战压力测试」——目标追不动，要么卖点打错了，要么节点拆错了，要么销售不会做。三个病因对应三个药方，不能用一个药方治所有病。

## 三、一个完整案例击穿认知：涂料公司三阶段进化

这是李蕊老师用自己的创业经历讲的完整故事。三个阶段，每一段都是一次管理认知升级。

### 3.1 三阶段全景对比

| 维度 | A. 拍脑袋管（2017前） | B. 粗放式管理（2018-2019） | C. 科学式管理（2020起） |
|---|---|---|---|
| **目标制定** | 按市场规模 × 1%，均分到人头 | 目标依然离谱，但开始做销售预测 | 基于去年完成 + 基准值 + 三倍池子 + 分级定标 |
| **过程跟进** | 周会复盘，陷入客户细节扯皮 | 上 CRM，要求录入拜访记录 | S级月会 + A级周会 + 攻坚小组每日群更新 |
| **中间指标** | 拍脑袋定「送多少面墙」，跟业务无关 | CRM 打卡：见了谁、什么角色 | 项目节点式进展 + 大项目地图 |
| **数据监控** | 无 | 拜访数据沉淀 | CRM 不定期看进展 + 人员淘汰数据体系 |
| **结果** | 送墙送到自己家，一条涂鸦街上千平方，零效果 | 多了一点抓手，起码销售不那么摸鱼了 | 目标有依据、项目有重点、卡点有策略 |

### 3.2 第一阶段的血泪教训：「送墙」的故事

```text
当时的逻辑：产品这么好，只要拼命露出，客户看到都可能成交。

于是定了一个中间指标：每个月要送多少面墙。

结果：销售上有政策，下有对策——
→ 有的送到亲戚家
→ 有的送到朋友家
→ 有的送到家居店
→ 有的送公益组织
→ 有的干脆送到自己家里
→ 奉贤一条涂鸦街，送了上千平方

最后有用吗？一点用都没有。
```

> **L6 解读**：这个案例示范了「跟业务无关的过程指标」有多危险。指标只要不指向真实成交，销售就会用各种方式「完成指标」而不「完成业绩」。中间指标必须和最终的成交链路咬合在一起，否则就是自欺欺人。

### 3.3 第三阶段的关键做法

**管理手段 1：完成目标拆解，给销售定一个符合基准值的目标**

| 层级 | 怎么做 |
|---|---|
| **公司目标** | 在去年完成的基础上定增长目标，不凭空拍 |
| **三倍池子** | 目标 500 万 → 找到能支持 1500 万的项目池。不是「有一个项目就指望它成」，而是「用三倍的潜在机会支撑一倍的确定性」 |
| **个人目标** | 用前几年数据积累出每个销售的「基准值」，分级定目标，让每个人都是跳一跳够得着的状态 |

> **为什么「三倍池子」是关键**：如果目标 500 万、手里只有 600 万的项目，任何一个项目掉链子就会崩。而 3 倍池子意味着你有足够的腾挪空间——这个项目掉了，立刻能从池子里补一个上来追。

**管理手段 2：启用全面的业绩跟进手段**

| 会议类型 | 跟进频率 | 跟进重点 |
|---|---|---|
| 早会 | 每一天 | 帮销售理清当天工作思路 |
| 晚会 | 每一天 | 更多是为了销售成长 |
| 周会 | 每一周 | 销售和销售总监过 A 类项目 |
| 培训会 | 每一周 | 讲制度、政策、新品 |
| 月会 | 每个月 | CEO 亲自参加，针对 S 级项目的大项目地图 |
| 销售总监跟进 | 随时 | 盯住 A 级项目，日常沟通 |

**管理手段 3：开始各方面监控数据**

| 监控维度 | 做什么 |
|---|---|
| **CRM 节点监控** | 不定期查看项目节点式进展。不是看「这个月签了多少」，而是看「这个项目推进到哪个节点了、有没有卡住」 |
| **攻坚小组群** | 每个 S 级项目建一个群，群里每天随时更新项目最新进展。信息透明、响应快、CEO 能实时感知 |
| **人员成长数据** | 用数据做淘汰决策——不是凭感觉开人 |

> **人员淘汰的 1-3-6 机制（李蕊老师的实战框架）**：

| 时间节点 | 判断维度 | 淘汰率 |
|---|---|---|
| **1 个月** | 通过打电话数量判断意愿。愿不愿意干、有没有行动力 | ~50% |
| **3 个月** | 通过考试和模拟训练判断能力。能不能学会、能不能做对 | ~10-20% |
| **6 个月** | 通过 A 级以上项目个数判断综合能力。能不能独立拿结果 | ~30-40% |

## 四、业绩必达三步法：完整方法论

### 4.0 三步法全景

| 步骤 | 核心任务 | 关键词 |
|---|---|---|
| **第一步** | 拆解目标冲业绩 | 从公司目标拆到个人目标，让每个人知道自己该打多少 |
| **第二步** | 制定策略可执行 | 针对目标找差距、找突破口、定策略 |
| **第三步** | 日常推进追目标 | 用会议节奏 + 数据监控 + 项目分级，把目标追到手 |

### 4.1 第一步：拆解目标冲业绩

**核心原则**：好的目标是让销售跳一跳够得着的。

李蕊老师自己的反思：

```text
我从大公司出来后，其实并不缺少目标拆解意识。
但问题是，当时的目标完全脱离了销售的实际能力，
再加上给销售的支持也不够，所以销售完全够不着。
```

**目标拆解的三个关键动作**：

| 动作 | 怎么做 | 常见错误 |
|---|---|---|
| **定公司目标** | 基于去年完成 + 增长预期，不凭空拍 | 按市场容量 × 1% 均分——脱离实际能力 |
| **建三倍池子** | 目标 500 万 → 储备 1500 万的项目机会 | 池子太浅，掉一个项目目标就崩 |
| **分级定个人目标** | 用历史数据算每个销售的基准值，分级定标 | 均分到人头——销冠和新销售背一样的数 |

**课程重点讲解——销售目标拆解的三种方法（对应不同业务类型）**：

| 方法 | 适用场景 | 拆解逻辑 |
|---|---|---|
| **按人头均分+系数** | 销售能力差异较大的团队 | 以历史基准值为锚，新销售和老销售背不同目标 |
| **按漏斗反推** | 有清晰转化漏斗的业务 | 从成交目标反推：需要多少线索→多少拜访→多少提案→多少成交 |
| **按阶段/区域拆** | 有明确区域或行业划分的业务 | 按区域潜力 + 历史完成 + 增长空间分配 |

### 4.2 第二步：制定策略可执行

**核心原则**：目标定完了不能散养——要配套「怎么打」的策略。

> 这部分在课内通过 2B 支付公司案例和 2C 电商案例做了完整演示。面销业务的策略重点是「卡在哪个节点、出什么招推过去」；电商业务的策略重点是「砸钱看数据、达不到就修正投放和转化动作」。

**策略制定的三个来源**：

| 来源 | 做什么 |
|---|---|
| **从 gap 反推** | 目标和现状之间的差距是什么？是线索不够、转化不够、还是客单价不够？ |
| **从节点找突破口** | 回到过程拆解图，找到当前卡在最严重的节点，集中突破 |
| **从最佳实践借力** | 同行打了什么策略？内部销冠做了什么不一样的动作？ |

### 4.3 第三步：日常推进追目标

**核心原则**：结果都是追出来的。

这步的核心是把「等结果」变成「追过程」。李蕊老师用涂料公司的真实案例论证了这一点（详见第五节）。

**日常推进的三层体系**：

| 层级 | 对象 | 频率 | 重点 |
|---|---|---|---|
| **CEO 层** | S 级项目 | 月会 + 攻坚群每日更新 | 最重要的项目不能丢，CEO 亲自盯 |
| **销售总监层** | A 级项目 | 周会 + 随时沟通 | 主力项目保持节奏，卡住了立刻出策略 |
| **销售个人层** | 日常动作 | 早会理思路 + 晚会复盘 | 保证每天的力气砸在正确的地方 |

## 五、三个管理原则：业绩推进的底层信条

### 5.1 原则一：好的目标是让销售跳一跳够得着的

```text
不要脱离基准值，不要脱离销售的能力。
把握住这两点，在赋能销售、帮他们提升能力后，他们其实也很愿意去追高目标的。
```

| 错误做法 | 正确做法 |
|---|---|
| 按市场规模 × 1% 均分 | 基于去年实际完成 + 每人历史基准值 |
| 所有销售背一样的数 | 分级定标，新人老人不同目标 |
| 定完就完了，没有支持 | 定目标同时配套策略辅导和资源支持 |

### 5.2 原则二：牢记二八法则，盯紧 20% 的项目

```text
公司把 80% 的精力花在 20% 的项目上，让它们达成 80% 的业绩。
对于小项目勇于放弃，对于大项目永不放弃。
```

**核心工具：大项目地图**

大项目地图 = 把重要项目按「哪个月要成交」标注在一张图上，配合销售节点图使用。

| 作用 | 说明 |
|---|---|
| **做销售预测校准** | 每月过进展时重新对一遍预测。哪个项目不顺利、没有如期成交，立刻判断有没有项目能补上 |
| **讲重点项目的节点情况** | 开会不再东拉西扯。用节点图精确判断：见关键人了吗？谈方案了吗？报价了吗？ |
| **给销售更直接的策略辅导** | 通过销售描述，确认节点是不是真做扎实了。不够就补动作；策略不对就换打法。销售会觉得你是帮他的 |

### 5.3 原则三：结果都是追出来的

```text
项目卡住了，你越是要想办法动起来。
如果光等，那就是等死。我们宁愿找死，也不能等死。
```

**击穿认知的案例——被甲方关键人抵触的学校项目**：

| 环节 | 发生了什么 |
|---|---|
| **绝境** | 设计师在标书里用了竞品的图；甲方关键人 A 对销售爱答不理 |
| **常规判断** | 两个关键角色都抵触，成交概率极低，销售很沮丧 |
| **突破** | 李蕊坚持「别放弃，再想想办法」。后来找到了甲方关键角色 B，销售跟他喝酒喝得很好，B 愿意帮忙 |
| **转机** | B 帮争取到提前一天打样的机会（行业惯例是同一天打样）。公司用了全「速干」涂料 |
| **结果** | 第二天甲方评审时，其他家的黑板擦不干净，只有这家能正常擦掉。一个本来觉得没希望的项目就这样追回来了 |

> **L6 解读**：这个案例示范了「永不放弃」不是鸡汤——它需要三样东西同时成立：①有节点图知道卡在哪（关键角色接触）；②有策略能力找到突破口（找到 B + 争取提前打样）；③有产品硬实力接住机会（速干涂料）。三者缺一，「追」就是瞎追。

### 5.4 三个原则的有无对比

| 没有这三个原则 | 有这三个原则 |
|---|---|
| 目标脱离实际，销售躺平或造假 | 目标跳一跳够得着，销售愿意追 |
| 精力平均撒在所有项目上 | 80% 精力砸在 20% 关键项目 |
| 卡住了等，等着等着项目就死了 | 主动找突破口，宁愿试错也不干等 |

## 六、2B vs 2C：两种业务形态的业绩推进差异

李蕊老师在课程中通过两个完整案例做了对比讲解。

| 维度 | 2B 面销业务（头部支付公司案例） | 2C 电商业务（一堂同学最佳实践） |
|---|---|---|
| **反馈来源** | 人的行为动作——销售推进到哪个节点、客户反应如何 | 海量数据——花了多少钱、达到什么效果、转化率多少 |
| **推进逻辑** | 客户没顺利到下一个节点 → 找实际和背后差距的原因 → 出策略让销售再推 | 砸钱看数据 → 达到预期继续、达不到就修正投放和转化动作 |
| **盯的重点** | 关键节点进展 + 关键人接触深度 | 投放 ROI + 转化漏斗各环节数据 |
| **策略调整** | 卡在某个节点 → 分析是人的问题还是策略的问题 → 换打法 | 数据不好 → 修正投放策略或页面转化 → 再测 |

> **关键认知**：两种业务的底层逻辑是一致的——都是「盯过程、找 gap、出策略、追结果」。只是 2B 的过程是「人的行为和节点」，2C 的过程是「数据和转化率」。

## 七、配套工具矩阵

| 工具 | 用途 |
|---|---|
| **常见拆解维度清单 Checklist** | 第一步：从哪些维度拆解目标（按人头/按漏斗/按区域/按产品线……） |
| **常见策略清单 Checklist** | 第二步：发现 gap 后，从哪些方向找突破策略 |
| **常见跟进手段清单 Checklist** | 第三步：日周月该用什么会议、什么报表、什么节奏盯 |
| **业绩跟踪管理模板** | 把目标拆解、策略制定、日常跟进整合在一张表里，拿来就能用 |
| **大项目地图模板** | 标注 S 级 / A 级项目的预计成交月份和当前节点，做销售预测校准 |
| **人员淘汰数据框架（1-3-6）** | 1 月看意愿、3 月看能力、6 月看综合结果，数据驱动淘汰决策 |

## 八、常见误区雷达

| 编号 | 误区 | 为什么是错的 | 正确做法 |
|---|---|---|---|
| ① | 目标按市场规模一拍，均分到人头 | 脱离销售实际能力，销售够不着，直接躺平 | 基于去年完成 + 每人历史基准值，分级定标 |
| ② | 定跟业务无关的中间指标 | 销售上有政策下有对策，指标完成了业绩没完成 | 中间指标必须和成交链路咬合，指向真实成交 |
| ③ | 只盯结果，不盯过程 | 月底才发现 gap，来不及补救 | 用节点图 + 周会 + 大项目地图盯关键节点进展 |
| ④ | 所有项目平均用力 | 关键项目资源不够，小项目占用太多精力 | 二八法则：80% 精力砸在 20% 关键项目上 |
| ⑤ | 项目卡住了就等 | 等就是等死，越等销售越无力 | 回到上一个节点排查，找到突破口主动出击 |
| ⑥ | 目标拆完就散养，不配套策略 | 销售知道目标但不知道怎么打 | 同步给出策略方向 + 持续在周会上做策略辅导 |
| ⑦ | 凭感觉判断人，不开数据驱动的淘汰 | 烂销售长期占坑，好销售被拖累 | 用 1-3-6 数据框架做淘汰决策 |

## 九、这节课在五步法中的咬合关系（L6 理解）

```text
提炼卖点（科学销售1）
    ↓
过程拆解（科学销售2）
    ↓
    卖点决定「对谁说」，过程决定「在哪个节点打」
    ↓
业绩推进（科学销售3）← 本节
    ↓
    这一步骤同时做三件事：
    ① 把卖点和过程拆解落到真实目标上
    ② 用业绩结果检验前两步是否做对了
    ③ 为下一步激励提供数据依据（谁完成了、谁卡在哪）
    ↓
激励团队（科学销售4）
    ↓
    业绩推进的数据告诉你「该激励谁、该淘汰谁、该补什么能力」
```

**一句话咬合**：卖点和过程拆解是「设计」，业绩推进是「执行」。设计再好，没有执行闭环，等于零。执行中暴露的问题，反过来倒逼设计升级。这是一个「设计 → 执行 → 反馈 → 修正 → 再设计」的持续迭代飞轮。

## 十、如果你只能带走三样东西

1. **「三倍池子 + 基准值定标」是目标管理的命门**。不要凭空拍目标——用历史数据算基准值，用三倍项目池支撑一倍确定性。目标脱离实际能力，再好的过程管理也推不动。

2. **「大项目地图 + 二八法则」是过程管理的核心**。不要所有项目平均用力——把 80% 的精力砸在 20% 的关键项目上，用大项目地图做预测校准和策略辅导，小项目勇于放弃。

3. **「结果都是追出来的」不是鸡汤，是管理纪律**。项目卡住了不要等——回到节点图排查卡点，找到突破口主动出击。每一次追回来的项目，都在向团队植入「宁愿找死、不能等死」的信念。
