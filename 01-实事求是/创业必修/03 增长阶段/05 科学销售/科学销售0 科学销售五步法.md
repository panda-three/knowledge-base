# 科学销售五步法 · L6 清单体笔记

> 课程：销售入门：科学销售五步法｜讲师：李蕊｜平台：一堂
> L6 标准：不只罗列知识点，而是拆出底层结构、建立要素关联、标注常见误区、给出可迁移判断框架。

---

## 一、先重新理解：这门课到底在讲什么

### 1.1 一句话定位
**这门课不是教「一个销售怎么成交」——而是教「怎么让一批人稳定地干好销售」。**
它的对象是 CEO / 销售总监 / 业务负责人，核心命题是 **销售体系化复制**。

### 1.2 核心判断：销售管理的三个段位

| 段位           | 状态       | 典型特征                |
| ------------ | -------- | ------------------- |
| **A. 直觉式管理** | 靠感觉、靠老板盯 | 只看最终结果，CEO 一放松业绩就掉  |
| **B. 粗放式管理** | 有初步体系    | 开始看过程指标，但体系不全、不稳定   |
| **C. 科学式管理** | 有体系、可复制  | 有复盘、有迭代、有工具、有数据、有过程 |

> 多数公司卡在 B 段位：有意识但不成系统，销冠一走就崩。

### 1.3 课程底盘：科学销售五步法全景

```
科学销售 = 提炼卖点 × 拆解过程 × 推进业绩 × 激励团队 × 打造工具
```

这五步不是并列 checklist，而是一个**层层咬合的系统**：
- 卖点没提炼清楚 → 过程拆解找不到关键节点
- 过程没拆清楚 → 业绩推进只能盯结果、无法指导动作
- 业绩推进没抓手 → 激励变成瞎发钱
- 激励不成体系 → 工具没人用 / 用了也白用

## 二、第一步：提炼卖点（用户分层 + 卖点提炼）

### 2.1 这一步解决什么问题

**最大困扰**：缺用户卖点——不知道哪类客户才是重点，卖点停留在「讲功能」而不是「讲价值」。

| 常见错误   | 后果                |
| ------ | ----------------- |
| 不做用户分解 | 所有客户一把抓，销售各自为战    |
| 不做卖点提炼 | 每个销售说的都不一样，无法复盘优化 |
| 卖点只写不用 | 提炼完锁在文档里，不培训、不落地  |

### 2.2 两个四步法

**用户分层四步法**：

| 步骤         | 做什么                        |
| ---------- | -------------------------- |
| 第一步：确定销售目标 | 先想清楚要攻什么市场、做到什么规模          |
| 第二步：提出分层假设 | 做加法（穷举可能用户群）+ 做减法（聚焦最有价值的） |
| 第三步：验证用户分层 | 用数据、拜访、转化验证分层是否成立          |
| 第四步：分层全面执行 | 配套资源、指标、话术，按分层差异化打         |

**卖点提炼四步法**：

| 步骤         | 做什么                        |
| ---------- | -------------------------- |
| 第一步：写出初始版本 | 先把能说的卖点全列出来                |
| 第二步：建立卖点审美 | 知道「好卖点」长什么样（具体、差异化、对客户有价值） |
| 第三步：进行多轮打磨 | 用客户反馈反复修正，不是一次定稿           |
| 第四步：落地场景应用 | 不同客户角色、不同决策阶段用不同卖点         |

### 2.3 可迁移的关键认知

- **用户分层是卖点提炼的前提**。不对的人，对的卖点也是错的。
- **卖点不是「你的产品有多好」，而是「对这个人来说，为什么现在就要选你」**。
- 卖点要细分到角色：决策者关心 ROI，使用者关心好不好用，采购关心风险。

## 三、第二步：拆解过程（决策路径 + 销售动作）

### 3.1 这一步解决什么问题

**最大困扰**：不拆销售过程——整个成单路径是黑箱，销售靠感觉推进，管理靠结果倒推。

| 常见错误 | 后果 |
|---|---|
| 不拆决策节点 | 不知道客户卡在哪一步，没法精准干预 |
| 没有销售重点 | 每个环节平均用力，关键节点反而被忽略 |
| 缺少销售动作 | 拆了过程但不配套具体动作，拆了等于白拆 |

### 3.2 过程拆解三步法

| 步骤  | 做什么                                 |
| --- | ----------------------------------- |
| 第一步 | **还原客户决策路径**：从第一次接触 → 最终签约，画出完整链路   |
| 第二步 | **识别关键决策节点**：找出对成交影响最大的 3-5 个卡点     |
| 第三步 | **配套标准化销售动作**：每个节点上，销售该做什么、说什么、交付什么 |

### 3.3 关键工具：常见用户决策清单 + 销售动作做加法小抄

- **决策清单**：把不同行业/客户类型的典型决策路径模板化，拿来就能套。
- **动作做加法**：在每个节点上穷举可做的销售动作，然后根据阶段做减法聚焦。

> **核心判断**：拆过程不是越细越好——拆到「能定位问题、能指导动作」的颗粒度就够了。

---

## 四、第三步：推进业绩（拆目标 + 抓过程 + 拿结果）

### 4.1 这一步解决什么问题

**最大困扰**：不抓销售过程——目标定完就散养，月底才发现 gap，来不及补救。

| 常见错误 | 后果 |
|---|---|
| 没有拆解目标 | 公司大目标挂在墙上，销售不知道今天该干什么 |
| 没有跟进日常 | 周会只问「签了吗」，不追「卡在哪一步」 |
| 不做销售指导 | 销售有业绩缺口时，管理者给不出具体帮助 |

### 4.2 业绩必达三步法

| 步骤 | 做什么 |
|---|---|
| 第一步 | **科学拆解目标**：从年度→季度→月度→周，按销售人头和转化率反推 |
| 第二步 | **建立过程监控**：日/周数据看板 + 关键节点预警 |
| 第三步 | **动态指导干预**：发现 gap 立刻追，不是追「你为什么没签」，而是「卡在哪一步，我帮你看看」 |

### 4.3 关键工具：业绩管理拆解画布 + 三个目标拆解模板

- **拆解画布**：一张图画清楚目标链、转化漏斗、过程指标、责任人。
- **三个拆解模板**：不同业务类型（高客单/低客单、2B/2C）的目标拆解范例。

> **核心判断**：顶级销售总监不是「运气好碰上牛销售」，而是「目标拆得细、过程盯得住、gap 出现时有办法」。

---

## 五、第四步：激励团队（不只是发钱）

### 5.1 这一步解决什么问题

**最大困扰**：不懂激励团队——要么只会发钱，要么连发钱的标准都不透明。

| 常见错误 | 后果 |
|---|---|
| 忽略团队激励 | 销售觉得「干多干少一个样」 |
| 只会金钱激励 | 短期有用，长期边际递减，团队没有归属感 |
| 缺少激励标准 | 提成方案模糊、更改随意，销售不信任公司 |

### 5.2 销售激励三步法

| 步骤 | 做什么 |
|---|---|
| 第一步：做加法 | 建立完整激励认知——金钱、成长、荣誉、竞赛、晋升、文化，六个维度 |
| 第二步：做减法 | 根据公司阶段聚焦 2-3 个最重要的激励杠杆 |
| 第三步：配套落地 | 提成方案透明 + 晋级梯子清晰 + PK 机制有节奏 |

### 5.3 关键工具：销售激励能力雷达图 + 销售激励武器库

- **激励不只是提成**。六个维度：
  - 金钱（提成/奖金）
  - 成长（培训/晋级）
  - 荣誉（Top Sales / 标杆）
  - 竞赛（小组 PK / 季度冲刺）
  - 晋升（销售→组长→总监的清晰路径）
  - 文化（使命认同 / 团队归属）

> **核心判断**：激励的终极目标不是「让销售多拿钱」，而是「让销售愿意做那些对的事，哪怕短期不直接产生业绩」。

## 六、第五步：打造工具（工具箱 × 落地培训）

### 6.1 这一步解决什么问题

**最大困扰**：没有工具箱——让销售赤手空拳上战场。

| 常见错误 | 后果 |
|---|---|
| 销售工具单一 | 只有一两个话术 + FAQ，完全不够用 |
| 工具只写不用 | 做了工具不培训、不演练、不迭代 |
| 工具不做升级 | 市场变了、客户变了，工具还是旧版本 |

### 6.2 打造销售工具三步法

| 步骤 | 做什么 |
|---|---|
| 第一步 | **装备工具武器库**：6 大类 39 个工具，按场景补齐 |
| 第二步 | **分层分级落地**：60 分工具（小白上手）→ 75 分工具（独立作战）→ 85 分工具（顶级销售） |
| 第三步 | **培训 + 迭代闭环**：不只是发文档，要模拟训练 + 实战复盘 + 持续升级 |

### 6.3 关键工具：销售武器库六维雷达图 + 销售工具武器库

**六类销售工具**：

| 类别 | 举例 |
|---|---|
| 获客工具 | 线索库、话术模板、邀约脚本 |
| 展示工具 | 产品演示、案例集、客户证言 |
| 跟进工具 | CRM 记录模板、跟进节奏表 |
| 促单工具 | 合同模板、报价策略、促销话术 |
| 服务工具 | 售后 FAQ、客户成功案例 |
| 管理工具 | 日报模板、周会复盘模板、数据看板 |

> **核心判断**：一套好的工具箱能让小白销售快速拉到 60 分，让 85 分销售更稳定地批量产出。

## 七、课程的顶层认知：先导课 × 五节系列课

### 7.1 课程结构

| 层级 | 内容 | 交付物 |
|---|---|---|
| **先导课**（认知必修） | 建立科学销售审美，理解五步全景 + 六大错误识别 | 销售管理能力雷达图、五步法全景地图 |
| **系列课 1** | 提炼卖点 | 用户分层四步法 + 卖点提炼四步法 |
| **系列课 2** | 过程拆解 | 过程拆解三步法 + 决策清单 + 动作小抄 |
| **系列课 3** | 业绩推进 | 业绩必达三步法 + 拆解画布 + 目标模板 |
| **系列课 4** | 激励团队 | 激励三步法 + 激励雷达图 + 激励武器库 |
| **系列课 5** | 打造工具 | 工具三步法 + 六维雷达图 + 39 件武器库 |

### 7.2 六大常见错误（先导课核心诊断框架）

| 编号 | 错误 | 对应五步位置 |
|---|---|---|
| ① | 销售管理缺位，只盯结果不看过程 | 全局 |
| ② | 缺用户卖点，不做分层不做提炼 | A. 提炼卖点 |
| ③ | 不拆销售过程，黑箱推进 | B. 拆解过程 |
| ④ | 不抓销售过程，目标散养 | C. 推进业绩 |
| ⑤ | 不懂激励团队，只会发钱或干脆不发 | D. 激励团队 |
| ⑥ | 没有工具箱，销售赤手空拳 | E. 打造工具 |

### 7.3 五步之间的咬合关系（L6 级别理解）

```
提炼卖点 → 拆解过程 → 推进业绩
    ↓                      ↓
  卖点决定「对谁说什么」   过程决定「盯什么指标」
                             ↓
                    激励团队 ← 推进业绩
                        ↓
                    打造工具（贯穿全程，是所有设计的落地载体）
```

**一句话**：卖点决定方向，过程提供抓手，业绩给出节奏，激励维持动力，工具完成规模化复制。

## 八、如果你只能带走三样东西

1. **从「盯结果」切到「盯体系」**。科学销售不是比谁更会催单，而是比谁的销售体系更能让普通人稳定产出。
2. **用五步法给自己体检**。对照六大错误，先找出你最痛的那个短板——别五个一起补，先补当前阶段最卡的那一步。
3. **工具不是写出来就完了**。销售工具的生命周期是：设计 → 培训 → 演练 → 实战 → 复盘 → 迭代。只写不练 = 白做。
