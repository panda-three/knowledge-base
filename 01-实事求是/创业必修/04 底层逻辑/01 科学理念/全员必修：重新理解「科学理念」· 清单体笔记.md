# 课程：科学理念·全员必修

**一句话结论：** 科学＝相信并追求客观因果规律；Y模型是把"道"讲清楚的唯一底座。

---

## 一、核心交付

- 一个定义：科学＝相信并追求客观的因果规律。
- 一张地图：Y模型（核心→两源→三姿势→四工具）。
- 三案例体感：时间管理 / 抖音投放 / 品牌起名。
- 一套工具：22张红蓝卡牌，与Y模型节点一一对应。
- 一句心法：圣人畏因，凡人畏果，把注意力放在"因"上。

## 二、关键框架

### 2.1 课程定位

- 一堂150节课中最底层的一节必修课，没有之一。
- 老课升级，横跨100年科学定义、覆盖100节课内容。
- 招生口径：1节顶100节；悟性够强可自行推演全部课程。
- 追求"道法器用"贯穿自洽，不只讲工具和术。

### 2.2 为什么要学：三类不科学现象

| 类型 | 典型表现 |
|---|---|
| 专家不自信 | 都在讲"科学"，却说不清什么是科学，长期自我重复 |
| 创业者缺训练 | 凭偏好/迷信背景/依赖经验，错误归因、情绪决策 |
| 管理者语境缺失 | 追求科学却无定义，2025年仍是理论/金句迷信重灾区 |

### 2.4 60分体感：X型 vs Y型

**核心对比：**

| 维度 | X型选手 | Y型选手 |
|---|---|---|
| 状态 | 抓不住规律、焦虑、被推着走 | 有模型、持续优化、持续迭代 |
| 认知 | 模糊认知→随机结果 | 因果模型→可复现结果 |
| 差距 | 低水平重复，难有进步 | 长此以往逐年拉开差距 |

> 借假修真：三个Y型案例的共性＝解决真问题＋建因果模型＋学理论＋拿事实验证。

### 2.5 Y模型四步推理（70分统一框架）

**第一步·核心：** 相信并追求客观因果规律。

- 有了"果"（目标），认知层级决定结果层级。
- 商业80%是运气，人和人差距在那20分确定性。
- 圣人畏因，凡人畏果——盯着认知和规律，不盯结果。

**第二步·进步（两个来源）：**

| 来源 | 含义 | 方向 |
|---|---|---|
| 理论 | 抽象过的规律模型（学别人/自己提炼） | 认识世界 |
| 事实 | 业务现场现实（调研别人/自己测试） | 改造世界 |

- 参考《实践论》：不断学理论、理解事实，逐步进化。

**第三步·姿势（三大最小集）：**

| 姿势 | 心法 |
|---|---|
| 知行合一 | 认知与实践统一，同步升级 |
| 实事求是 | 敬畏客观事实与规律，承认自己是普通人 |
| 解放思想 | 善用新工具解新问题，不拘泥固有路径 |

**第四步·能力（四大迭代工具）：**

| 工具 | 偏 | 作用 |
|---|---|---|
| 定性定量 | 事实 | 调研实验，全面准确理解事实 |
| 科学类比 | 理论 | 辩证交叉类比，理解规律内核与边界 |
| 假设驱动 | 事实 | 勇敢提前置假设，驱动工作推进 |
| 提炼建模 | 理论 | 练习自建模型，抽象客观规律 |

### 2.6 高端局：科学型组织与红蓝卡

- 教员案例：非科班出身，靠调研/打仗/决策练成战略家。
- 王慧文：能做高质量复盘的组织，差不多能做好所有事。
- 《毛选》14个"主义"名词：主观/冒险/盲动/关门/机会/山头/宗派/自由/个人/教条/本本/经验/尾巴主义等。
- 受"对抗演习"启发做**红蓝卡片**：
  - 一手警惕、一手鼓励；一手修正、一手追求。

  - 蓝卡：看到苗头多引导、多反馈，甚至严厉制止（含易错指数、踩坑深度）。
  - 每卡与Y模型节点一一对应，红蓝严格对应。

## 四、案例拆解

### 4.1 场景1：Truman本人的时间管理

**X型（2021年前）三特点：**

| # | 特点 |
|---|---|
| 1 | 事情太多，总被事情推着走，深度思考时间被抢占 |
| 2 | 随性安排时间，跟着感觉/谁催得急走 |
| 3 | 学了一堆工具（番茄/GTD/四象限/OKR/吃青蛙）都坚持不下去 |

**Y型四件事（2022年起）：**

| 步骤 | 动作 |
|---|---|
| ① 找评价维度 | 定目标：提升时间利用效率→经营成果→平衡家庭健康 |
| ② 建因果模型 | 三模型：时间/精力模型 × 事情模型 × 匹配模型 |
| ③ 学工具优化 | 双峰哲学划AB工作；番茄重点在定时专注；公开排期防撞车 |
| ④ 提假设验证 | 通勤6个假设，仅"上班做方案""下班磨课"成功，其余失败 |

- AB工作演进：白天公司协作/夜里创作 → 周一周三公司/周四周五车库闭关。
- 近一年提30-50个小假设，逐月围绕三模型复盘迭代。
- [配图：Truman时间管理模型应用截图、通勤假设验证清单]

### 4.2 场景2：抖音AD付费投放

**迭代三段：**

| 阶段 | 做法 | 结果 |
|---|---|---|
| 外包 | 找供应商做内容投放 | 3个月跑偏到"拼多多风"，同学认不出 |
| 自建临摹 | 拉网感最强2人虚拟小组，拆同行脚本 | ROI 0.3-0.6抖动，每周净亏（峰值一周亏台小米汽车） |
| 攻坚建模 | 复盘会判定"犯懒、寄望外部"，自己建模 | 一季度每周迭代，5个选题全部起量，ROI跑通 |

**科学攻坚两步：**

| 步骤 | 内容 |
|---|---|
| 明确目标 | 获客规模 × ROI（ROI合格下追新客量，非单纯利润） |
| 分析条件（4模型） | 短视频审美 / 工业化生产 / 测试流程 / 投放策略 |

- 牵头建文档《Truman的极致攻坚：写短视频》。
- 刷1000+视频、列10+选题、整理100+话术子弹库。
- 沉淀模型：对标拆解 / 3s模型 / ABACC模型 / 投放复盘。
- 外溢：跑通视频号、小红书，月6000-8000体验课付费用户，翻4倍+。
- 新假设持续提：混剪/数字人/自然流口播、切人群账号、渠道联动。
- [配图：4大模型团队协作框架图、脚本迭代起量曲线]

### 4.3 场景3：Leo潮玩品牌起名字

**X型三种姿势：** 全凭感觉 / 调研最佳实践 / 请教专家朋友。

**Y型四步法：**

| 步骤 | 关键动作 |
|---|---|
| ① 建立框架 | 目标3维：目标用户/使用场景/名字边界；评价4维：传播性/匹配性/意义性/安全性 |
| ② 做好加法 | 六轮凑200+名字：头脑风暴40+/同行30+/产品40+/语文30+/朋友20+/AI40+ |
| ③ 专业减法 | 四轮筛选（见下表） |
| ④ 实践落地 | 配套Logo/Slogan/VI；运营中持续加深认知 |

**四轮减法：**

| 轮次 | 维度 | 结果 |
|---|---|---|
| 内部筛选 | 传播/匹配/意义，办"筛选比赛" | 200+ → 50+ |
| 商标查询 | 安全性，注册成功率<70%直接筛除 | 50+ → 12 |
| 投票PK | 加权投票：普通用户1票/资深用户3票/业内5票 | 12 → 前三 |
| 仿真测试 | 自做Demo图，线上假产品测试真实场景 | 综合定一名 |

- 结果：半年起盘，拿到几百万元投资。
- 提醒：改名是ROI问题，早期成本可控，成熟期得不偿失。

## 五、80分：三大追求详解

### 5.1 追求一·知行合一

- 2016年知识付费狂学习：500万字知识库，解决问题时无一字能用。
- 认识世界极度自信、改造世界极度不自信，焦虑一年。
- 觉醒：废掉"知识大脑"，躬身入局，为每个具体问题找因果。
- 入门标志：对复杂事形成朴素、框架性认知（因果树干，承载枝叶）。
- 一堂内部反复追问"这背后因果关系是什么"，两年问了七八十次。
- 面试必问："决定这个结果最重要的3个要素是什么？"
- 评价：说"不知道"算0分；高谈阔论却举不出例子＝负分。

### 5.2 追求二·相信理论

- 避免重复造轮子：你的问题历史上早有人抽象成方法/模型/工具。
- 科学定价先学常见策略：成本/竞争/撇脂/渗透/阶梯定价。
- **模型易得，使用慎重**——Copy同行常只抄到壳子。
- 警惕迷惑性金句：舍九取一/利他/私域/流量第一均有严格边界。
- 自己萃取模型案例：选品4步法/销售数百节点模型/抖音直播公式/99%项目死亡里程碑。
- **建模5件套（由浅到深）：**

| 顺序 | 工具 | 作用 |
|---|---|---|
| 1 | 深度复盘 | 主观→事实→原因→方法→能力 |
| 2 | 深度思考 | 透过表象看3-7层规律 |
| 3 | 模型武器库 | 建几十种范式库，随调随用 |
| 4 | 辩证讨论 | 苏格拉底式反例追问 |
| 5 | 爆炸式研究 | 大量案例收集分类定性定量 |

### 5.3 追求三·相信事实

**科学定价自测5问（百分制自评）：**

1. 对标定价最佳实践是谁？列3-5家。
2. 他们定价多少？有何规律与共性？
3. 你定量跟踪过其定价变化和成本结构吗？
4. 你对自己定价提过几个假设（1/3/5/10+）？
5. 你做过定价实验吗？如何设计？

**定性→定量梯度（越往后越难越准）：**

| 场景 | 梯度 |
|---|---|
| 时间管理 | 模糊大块时间 < 具体小时 < 小时×产能 |
| 科学招聘 | 模糊好感 < 定性分级(No/Hire/Strong Hire) < 分维度打分 |
| 科学决策 | 直觉 < 优先级定性 < 局部定量 < 定量公式 < 严格财务定量 |
| 科学文案 | 模糊手感 < 用户投票 < 数据分析 |

- 定量有成本，按决策重要性匹配定量等级，算ROI。
- **假设驱动的5个转变：**

| 从 | 到 |
|---|---|
| 主观判断 | 客观假设 |
| 拍脑袋直觉 | 对客观现实的假设 |
| 有心理包袱 | 回归客观规律 |
| 老板命令 | 老板对客观世界的假设 |
| 推翻老板权威 | 用事实验证假设 |

- 关键假设第三板斧＝验证，时刻提醒自己这是量级上的成本差，低成本验证。
- 左右矛盾时：信事实，"实践是检验真理的唯一标准"。

## 六、90分主动修炼 / 100分唯一道路

### 6.1 Y模型适用边界

- 八字：成事儿。严谨：希望未来、真实世界、持续、成事儿的人。
- 四词缺一不可：希望未来 / 真实世界 / 持续 / 成事儿。
- 越想持续成大事，越要持续建模、迭代出市场最佳实践。

### 6.2 三步修炼

| 阶段 | 内容 |
|---|---|
| 正视问题 | 三种偏科：纯经验派(天花板低)/纯理论派(无法落地)/纯测试派(重复造轮子) |
| 个人修炼 | 三要素：迭代(无限逼近真理)/工具(两叉持续做工)/匹配(配套组织流程) |
| 团队修炼 | 红蓝卡+1/-1修正，从Y模型四象限持续填策略工具 |

- Truman成长路径：理论派(<2016) → 知行合一(16-17) → 假设实验(17-19)。
- 练习Tips：抖音搜"商业认知/创富思维/生意老板"，找逻辑硬伤。

### 6.3 100分唯一道路

- 2013年人生意义之问，找到"小红区域"意象：因我的出现把认知边界外推一丢丢。
- **三个坚持：**

| 坚持 | 含义 |
|---|---|
| 体系建模 | 从经验→常识→方法论→本质→科学素养层，挖到最根 |
| 无限追求 | 无限逼近正确的路，远重于眼下这个版本的答案 |
| 科学道路 | 若一堂消失，最遗憾是"科学创业+大规模交付"这面旗倒了 |

- 一堂使命两条：①把创业打造成一个学科；②提升中国创业者整体上下限。
