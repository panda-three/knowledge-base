# 01-实事求是 · Home（原文层）

## 本层定义（准入标准）

> 原文层：**成熟可信的外部知识体系**与可验证事实。回答「外部世界已知什么」。
> 判定口诀：**成熟的、外部的、可信的 → 01**。
> 所有外部输入保留 `source` 出处，可追溯。

**准入闸（默认拒入）**：01 是「升级目的地」不是「接收口」——外部新素材一律先落 02，仅以下四类经用户拍板才升 01：

1. 一堂官方课程体系；
2. 经典/公认体系（教科书、行业标准、权威机构）；
3. 高验证度外部作品（来源权威＋时间/规模检验＋事实可核验＋成体系）；
4. 本人反复验证、真·成体系可对外调用的成熟产物。

拿不准一律降 02。

**排除（分流）**：个人观点/新理念/时效观察 → 02；自己的实践/教案/复盘 → 03；消化后的再加工 → 02。

**判定速查（存东西时按顺序问）**：

1. 这是我**做过**的吗？（教案/练习/项目/复盘）→ **03**
2. 这是**一堂官方课 / 经典教科书**吗？→ **01**
3. 都不是（看到的 / 想的 / 不确定）→ **02**，拿不准一律先放 02
4. 实在判不了 → **05 收件箱**
