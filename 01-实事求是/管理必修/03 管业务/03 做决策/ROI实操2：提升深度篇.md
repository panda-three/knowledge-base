## 一、为什么要学——破题篇

### 1.1 从宽度到深度——缺了什么

> 在《宽度篇》，你学会了"列推建查"四字诀，能把该看的成本项和收益项都列全。但列全之后，更棘手的问题出现了。

| 典型困境 | 具体表现 | 根因 |
|---|---|---|
| **数字不靠谱** | 我知道要算钱，但数字从哪来？感觉全靠瞎猜 | 缺少从模糊到清晰的定量方法和经验值积累 |
| **取值很纠结** | 乐观值是10%，悲观值是20%，差了一倍——取哪个？ | 缺少三点预测和科学类比的策略 |
| **不知道收到哪一层** | 有些决策只需要定性排排序就够了，有些必须算到财务ROI——但界限在哪里？ | 缺少"深度与决策复杂度匹配"的判断框架 |
| **同行数据能抄吗** | 同行有数据可以直接借鉴吗？抄了发现水土不服怎么办？ | 缺少交叉类比的科学方法 |
| **X型决策习惯** | 除了极少数严谨的财务计算，其他决策都喜欢简单拍脑袋 | 没有Y型决策者的"层层深入"习惯 |

### 1.2 认知审美篇的经典案例回顾——深度的价值

> 当年Truman做PM时的一个例子：

```text
场景：后端效率优化方案，可以把某个运营环节效率提升300%。
产品团队强推："300%效率提升！太值了！"
技术团队不接："需要50人日开发，成本太高了！"
双方差点拍桌子。

新来的产品总监拿出一张纸：
"全部折合成人日，换算成工资，看看研发投入运营多少年能赚回来。"

数据公式一拉：6-8年。
结论：公司有很多高优先级的事，6-8年才回本的项目排到最后。

启发：很多时候，我们的犹豫不决，是因为分析的深度还不够。
```

## 二、核心框架①：X型 vs Y型决策者——你的决策习惯是哪一种

> 这是本课的第一个核心模型——两张决策习惯图谱的对比，揭示了"深度"的底层差异。

### 2.1 五层ROI评估深度

| 层级 | 名称 | 核心动作 | 典型场景 |
|---|---|---|---|
| **L0** | 拍脑袋 | 基本上不评估，根据直觉定 | "感觉这个应该挺划算的" |
| **L1** | 优先级定性 | 简单做做定性，排排优先级 | "A方案比B方案重要，先做A" |
| **L2** | 部分定量 | 重要的要素，尝试定量描述 | "大概需要3个人做2周，预计能带来20万收入" |
| **L3** | 定量公式 | 严格的公式，努力定量 | 建立转化漏斗公式，每个参数有具体数值 |
| **L4** | 严格财务ROI | 最狭义准确的财务ROI准确计算 | (A+B+C+D) / (X+Y+Z)，全量成本/全量收益货币化 |

### 2.2 X型与Y型的本质差异

```text
X型决策者：
  除了极少数的严谨财务计算（L4），
  其他决策都很模糊，都喜欢简单拍脑袋（L0-L1）。

Y型决策者：
  从L0到L4层层递进——
  先定性排优先级，再部分定量，
  关键要素建定量公式，重大决策做严格财务ROI。
  深度不是"要么拍脑袋要么算到死"，
  而是"根据决策复杂度，匹配适当的深度"。
```

### 2.3 深度选择的铁律

```text
当你的①决策复杂度越高、②试错成本越高、③货币化程度越高，
越应该深入下去决策。

反过来，杀鸡不用牛刀——
快收快放，做完收刀，搞定即可。

核心原则：
  - 有些决策很简单，列一列成本收益要素，排排优先级，就够了（L1）
  - 还有些不够，你得努力定量、找出数字、货币价值，就能判断了（L2-L3）
  - 有些还不够，关系到公司商业模式生死，你得完整、精细化地做模型分析（L4）
```

## 三、核心框架②：10个案例停车场——四层深度的逐层推演

> 这是本课最独特的教学方式。Truman用了"案例停车场"的形式，通过10个真实案例的多轮迭代，带着学员一层层探索"不同类型的决策，到底要思考到多深的层级"。

### 3.1 10个案例清单

```text
1. 公司要不要每个月开一个复盘会？
2. 公司要不要做一个新人Landing一页纸？
3. 管公司员工中午饭，划不划算？
4. 上班开车，还是打车，哪个划算？
5. 自建班班沟通IM系统，划不划算？
6. 公司全员涨薪20%，划不划算？
7. 换租隔壁更大办公室，划不划算？
8. 网站备案渠道获客，能不能划算？
9. 房产中介，通过上门送桶装水，挖掘优质房产线索
10. 百度投放SEM，买线索驱动增长
```

### 3.2 四层深度与案例匹配逻辑

```text
案例1-4：相对简单 → L1优先级定性或L2部分定量就够了
  比如"上班开车还是打车"——不用建复杂财务模型，
  部分定量（时间成本+油费+停车费 vs 打车费）就能判断。

案例5-8：中等复杂度 → L2部分定量到L3定量公式
  比如"自建IM系统"——需要拆研发成本、维护成本、
  效率提升的货币化价值，建立转化公式。

案例9-10：高复杂度/高试错成本 → L3定量公式到L4严格财务ROI
  比如"百度SEM投放"——关系到公司增长引擎，
  需要完整的单元模型分析，每个参数都精确定量。
```

### 3.3 来自认知审美篇的经典案例——6-8年回本的决策

```text
后端效率优化方案：
  收益：某个运营环节效率提升300%
  成本：50人日开发

产品总监的深度升级：
  L1定性："效率提升300%很大"vs"50人日成本很高"→结论：僵持不下
  L4严格财务：全部折合成人日→换算成工资→
              研发投入运营多少年能赚回来？
              结论：6-8年→项目排到最后

深度不够 = 僵持不下
深度够了 = 秒出结论
```

## 四、核心工具①：三大数字预测策略——从模糊到清晰

> "我知道模型啊，但是数字感觉不靠谱啊？我是按乐观值算还是悲观值算？同行有数据我可以直接借鉴直接抄吗？"——Truman看完了数百份学员作业，提炼了三个最高频的策略。

### 4.1 三大策略全景

```text
策略1：攒经验值 —— 总结你的经验值和基准值
策略2：交叉类比 —— 找决定因素，交叉类比
策略3：三点预测 —— 乐观、合理、悲观三点预测
```

---

### 4.2 策略1：攒经验值——业务专家最宝贵的资产

> "作为一个业务专家，我们常年在一个业务深耕，积累的最宝贵的资产，就是关键的用户洞察和核心的业务经验值。模型可以速成，但『经验值』是一个持续积累的过程。"

#### (A) 经验值的三个来源

| 来源 | 含义 | 一堂示例 |
|---|---|---|
| **行业benchmark** | 参考行业常识和公开数据 | 课程类年费会员续费率行业均值：30-70% |
| **竞争数据** | 参考对标同行的数字 | 头部编程选手获客成本200-300，初创选手300-400 |
| **过去历史数值** | 参考自己过去积累的真实数据 | 一堂每节课包含的干货点50-80个；直播Flag实现率70-90% |

#### (B) Truman在一堂积累的经验值示例

```text
公司发展预测上的：
  课程创新型教育，起盘阶段测课6-18个月很正常
  品牌+规模经济导致的集中度CR1：20-40%
  教育/SaaS早期业务增速（AB轮）：50-200%/年

教研做课方向上的：
  一节课包含的干货点：50-80个
  课程价值比（核心方法论：专项方法论：案例课）= 25:5:1
  磨课难度占比（input-process-output）= 3:6:1
  课程质量线：方法论NPS70合格，80优秀，90天花板
  平均作业率（作业/进直播间）：40-70%

运营和商业模式上的：
  用户点击转化漏斗CTR：5-20%
  直播Flag实现率：70-90%
  直播间上课峰值：30-45分钟
  课程类年费会员续费率行业均值：30-70%

Truman甚至总结了：每年1-3个学员全职加入一堂的经验值（正在不断缩短ing）
```

#### (C) 经验值的核心使用心法

```text
当我有意识地形成了这些经验值，
我就会一遍遍使用、打磨、评估ROI、修正，
然后随着这些值越来越靠谱，
ROI预测的准确率也就会越来越高了。

核心原则：在做业务过程中，一定有意识地持续积累关键经验值。
不是"等到需要做决策了才去找数据"，
而是"平时就在积累决策需要的数字弹药"。
```

### 4.3 策略2：交叉类比——科学类比三步走

> 当自己的经验值不够，或者面对全新业务时，用交叉类比来获得靠谱的数字区间。

#### (A) 交叉类比三步走

| 步骤 | 核心动作 | 具体做法 |
|---|---|---|
| **第一步：找关键要素** | 找到影响指标高低的3-5个关键要素 | 如"获客成本"的关键要素：品牌力、竞争强度、规模效应、付费意愿、客户一致性 |
| **第二步：排要素顺序** | 确定这几个要素的占比或优先级 | 品牌力影响最大（占40%），竞争强度次之（占30%） |
| **第三步：做区间定量** | 找到不同要素组合的参考值，综合拿到你的区间定量 | 参考同行A（品牌强、竞争弱）：200-300；同行B（品牌弱、竞争强）：400-600 → 我是初创品牌、竞争中等 → 推测300-500 |

#### (B) Truman的实战推演示例

```text
背景：初创编程教育公司，需要预估获客成本。

步骤1：找关键要素
  品牌力、竞争强度、规模效应、付费意愿、客户一致性

步骤2：对标分析
  头部编程选手：200-300（品牌强、规模大、竞争激烈，但我品牌弱、成本更高）
  初创美术赛道：300-400（付费意愿高一些、竞争强一些，都没品牌、规模小，我成本更高）
  K12英语初创：300-500（竞争弱一些、付费意愿弱一些，都是少儿群体，我成本更高）

步骤3：综合推测
  推测基准值：300-600区间
  乐观值：300（竞争缓和、品牌快速建立）
  合理值：450（中等竞争、品牌逐步建立）
  悲观值：600（竞争激烈、品牌建立缓慢）
```

#### (C) 交叉类比的举一反三

```text
用同样的方法，可以思考：

影响「货损」的一般要素有哪些？
影响「账期」的一般要素有哪些？
影响「退款率」的一般要素有哪些？
影响「推荐率」的一般要素有哪些？

如果你们公司有这些关键要素，而且持续需要做决策，
那就值得坐下来总结一下——

随着你对于「科学类比」掌握得越来越熟练，
你的ROI评估能力也就逐步提升了。
```

### 4.4 策略3：三点预测——乐观、合理、悲观

> "我的数据预测范围是10-20%，上下相差将近一倍，我该怎么选择哪个数据代入呢？"

#### (A) 常见的三种取值倾向及其问题

| 取值方式 | 做法 | 问题 |
|---|---|---|
| **选最好值估** | 按最好值测算，给团队加油打气 | 盲目乐观，一旦没达成士气崩盘 |
| **按最差值估** | 按最保守测算，降低预期 | 过于保守，好机会被pass掉 |
| **按中间值估** | 取平均数/中位数 | 没有区分度，无法揭示极端风险 |

#### (B) Truman的两轮估算法

```text
第一轮：偏乐观值，用来证伪和排除
  各个数据用偏好的版本带入：
  成本偏低的点，价值偏高的点，带进去试试看。
  
  核心价值："先在黑板上成功，再在现实里成功。"
  这是一个必要非充分的条件——
  成了没什么，但如果乐观值都不行，那就不用干了。
  
  在一堂出现过几十上百次这样的快速ROI沟通：
    - 三江源公益项目：比较高的数据带进去，整体都是亏损的
    - 孵化器送《最佳实践》获客：比较高的数据都带进去，整体不值得

第二轮：乐观/合理/悲观三点预测
  乐观值很理想——如果一切顺利可以达到的上限
  合理值能接受——按正常情况最可能实现的值
  悲观值有风险——如果多个环节不顺利可能的下限
```

#### (C) 三点预测的后续动作

```text
把乐观/合理/悲观的三个值代入公式，看到结果范围。

然后努力把这些要素提炼成关键假设，
然后做实验，亲手去测试和验证它。

这样相对来说，
是一个比较安全稳妥、科学高效的做事策略。
```

## 五、决策深度与ROI评估的最终公式

> Truman在课上给的总结公式——"通过深度的不断增加，决策要素的定量越来越准确。"

```text
决策深度 ≠ 越深越好
决策深度 = 与决策复杂度/试错成本/货币化程度的匹配度

简单决策（开车vs打车）
  → L1-L2：列列成本收益，部分定量，快速判断

中等决策（自建系统/全员涨薪）
  → L2-L3：建立定量公式，关键参数有可靠数字

重大决策（商业模式生死/增长引擎）
  → L3-L4：严格财务ROI，完整单元模型，多轮三点预测
```

## 六、ROI的十年基本功——课程收官

> "希望大家课程听到这，要深刻体会我说的一句话：ROI对你的决策训练来说，是最重要的、十年维度的基本功。有些技巧，学会了立竿见影，而ROI需要持续刻意练习，才能逐步提升段位。"

### 6.1 做成一个业务/项目/投资决策的要素

```text
有太多的要素：运气、政策、红利、团队信心、现金流等等。
这些要素，很多都是靠『天』，往往是外部的、是很难改变的。

但ROI不一样——
它是你可以持续修炼、持续积累、持续迭代的能力。
它是Y型决策者的核心操作系统。
```

### 6.2 三条课后作业（挑战极高）

| 作业 | 内容 | 难度 |
|---|---|---|
| **作业一：成败回顾** | 回顾过往ROI评估在『深度』上的成败得失。可以是决策成功因为足够深，也可以是交过学费因为明显不够深 | 中等 |

## 七、ROI深度修炼段位成长地图

| 段位 | 核心能力 | 典型表现 | 使用工具 |
|---|---|---|---|
| **L1 拍脑袋** | 无深度意识 | 基本上不评估，根据直觉定——"感觉应该划算" | 无 |
| **L2 定性优先级** | 能做简单的定性排序 | 至少能说"A比B重要"，但说不清A比B值多少 | 简单罗列+定性排序 |
| **L3 部分定量** | 重要要素能尝试定量 | 关键成本/收益能给出大致数字（"大概3个人2周"），而不是"应该挺值" | 经验值+简单类比 |
| **L4 定量公式** | 能建立转化公式，努力定量 | 有完整的公式结构，每个参数有具体数值（可能还不够准但框架对） | 定量公式+交叉类比 |
| **L5 严格财务ROI** | 最狭义准确的财务ROI计算 | 全量成本/全量收益货币化，(A+B+C+D)/(X+Y+Z)能拉出来 | 财务ROI公式+三点预测 |
| **L6 经验值驱动** | 持续积累、持续迭代，决策又快又准 | 有意识地积累了大量的业务经验值，遇到新决策能快速用类比+三点预测做出判断，Y型决策习惯内化为肌肉记忆 | 三策略全套+持续积累经验值 |

## 九、L6 刻意练习自检清单

### X/Y决策习惯——你是哪一种

- [ ] 对照X型与Y型决策者图谱，你更像哪一种？你的团队更像哪一种？
- [ ] 回顾你过去3年的关键决策（试错成本10w以上），其中多少比例是"拍脑袋"（L0）、多少是"定性排序"（L1）、多少做了"部分定量"（L2）、多少到了"定量公式"（L3）或"严格财务ROI"（L4）？
- [ ] 你是否能做到"根据决策复杂度匹配深度"——简单决策快收快放，重大决策深度挖掘？

### 深度判断——你是否在正确的层级做决策

- [ ] 面对下一个重要决策，你能否先判断它"该收到哪一层"——L1定性排排优先级就够了？还是需要L2部分定量？还是必须L3定量公式甚至L4严格财务ROI？
- [ ] 你是否能识别"杀鸡用了牛刀"（简单决策过度分析）和"杀牛用了鸡刀"（重大决策浅尝辄止）的情况？

### 三大策略——你是否掌握了从模糊到清晰的武器

- [ ] **策略1-攒经验值**：你是否有意识地积累了自己业务领域的关键经验值（至少10个常用数字）？你能说出它们的来源（行业benchmark/竞争数据/历史数值）吗？
- [ ] **策略2-交叉类比**：面对一个没有直接数据的决策，你是否能用"三步走"（找关键要素→排要素顺序→做区间定量）来科学类比？
- [ ] **策略3-三点预测**：你是否习惯做两轮估算——第一轮偏乐观值用来证伪（"乐观值都不行就不用干了"），第二轮乐观/合理/悲观三点取区间？

### 经验值——你是否在持续积累

- [ ] 你能在1小时内写出多少个可以用来决策的经验值？Truman在课上展示了几十个——你的业务有多少？
- [ ] 你的经验值是否覆盖了关键维度：获客成本、转化率、客单价、毛利率、续费率、人效、退款率、账期……？
- [ ] 你是否有一个记录和更新经验值的习惯（而不是每次决策时重新"凭感觉估"）？

### 综合自检

- [ ] 对照ROI深度修炼段位地图（L1-L6），你现在更像L几？下一段最需要突破的是什么？
- [ ] 回顾过去，你有没有一个"因为深度不够而迟迟无法下结论"的决策——如果当时用了交叉类比+三点预测，会更快得出结论吗？
- [ ] 你是否愿意把"攒经验值"作为一个终身习惯——而不只是"听了一节好课，学会了三个策略"？
- [ ] Truman说"ROI是十年基本功"，你认同吗？你准备怎么用十年的时间周期来修炼它？
