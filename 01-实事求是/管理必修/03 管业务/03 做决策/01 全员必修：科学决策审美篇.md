## 一、为什么要学——破题篇

### 1.1 什么是「广义ROI」——这节课最重要的概念重新定义

> Truman在开篇就定了基调："我们讲的是'广义ROI'，不只是投资、营销领域的投资回报率（狭义ROI），更多是我们日常做决策、做业务、带团队用到的ROI。"

| 对比维度 | 狭义ROI（投资/营销领域） | 广义ROI（本课关注的） |
|---|---|---|
| **决策数量** | 少数几次重大投资决策 | 日常几十上百个管理+业务决策 |
| **典型场景** | 投资回报率计算、广告投放ROI | 要不要给员工提供免费午餐？要不要全员打卡？要不要做IP？要不要做直播？要不要招聘技术合伙人？ |
| **使用频率** | 偶尔（季度/年度） | 每天/每周 |
| **评估难度** | 通常有数据支撑，可定量 | 很多没有现成数据，需要自己建模型 |

### 1.2 广义ROI决策中的六大常见惯性

> "在这种广义ROI决策中，大家总是容易陷入一系列惯性。"

| 惯性类型 | 具体表现 | 后果 |
|---|---|---|
| **喜欢拍脑袋** | 想到什么就觉得"应该做"，没有拆成本和收益 | 决策质量完全取决于当时的心情和直觉 |
| **模糊想想就拍板** | "感觉这个应该划算吧"——没有定量，没有数据 | 事后发现完全不划算，但已经投入了 |
| **丢三落四** | 只看到最表面的成本和收益，漏掉大量关键项 | 看似赚钱的项目实际巨亏 |
| **不能全面评估** | 只看直接成本，不看间接成本/机会成本/长期影响 | ROI虚高，决策长期来看是错的 |
| **碍于面子** | 已经投入了就不愿意停，沉没成本绑架理性 | 继续往坑里填资源 |
| **单一选项封闭思考** | 只在"做"和"不做"之间二选一，不探索"怎么做更好" | 错失更优方案 |

### 1.3 Truman观察团队ROI决策水平的两个最重要视角

```text
第一视角：敏感性——
  回顾过去3年，你有多少次关键选择（试错成本10w以上）？
  关于选人、选功能、选方向、选方案都可以。

第二视角：模型——
  这些选择决策，你都是独立做的吗？
  背后有方法论吗？有系统的一致性的方法论吗？
  你的团队有一致共识的决策方法论吗？
```

## 二、第一部分：建审美——三轮LEO的成长故事

> "我先给大家完整讲几个例子，带你体会一下，一个不合格→入门→高阶的ROI评估是怎么迭代出来的。为了呈现真实具体的讲课状态，今天所有案例均为真实。"

### 2.1 LEO的第一个案例：产品负责人的「老带新」决策

#### (A) 背景

| 要素       | 内容                                       |
| -------- | ---------------------------------------- |
| **时间**   | 2019年                                    |
| **场景**   | LEO入职一家头部成人教育公司，做小产品模块负责人                |
| **业务模型** | 在线教育标准模型：投放买量 → 体验课转化 → 3个月训练营 → 二次复购    |
| **核心问题** | 渠道红利减少，投放成本越来越高，月销虽上亿但增长趋缓               |
| **任务**   | 探索「老带新」能不能成为新的增长点——通过老学员转介绍获得免费流量，降低投放成本 |

#### (B) LEO的第一版本ROI（不合格）

> LEO已经是有经验的产品经理，有ROI意识——但只做了最粗的拆解。

| 维度 | LEO的第一版 |
|---|---|
| **收益R** | 活动收入（老带新带来的课程销售收入） |
| **成本I** | 活动激励成本（给老学员的奖励） |
| **ROI判断** | 收益 > 成本，划算！搞！ |
| **Truman的评价** | ❌ **只看到了一小半的成本。** 丢三落四——漏掉了研发成本、运营成本、设计师成本、项目管理成本…… |

#### (C) LEO的第二版本ROI（入门但还不完整）

> 复盘会上被领导劈头盖脸问："你算过研发成本么？你算过运营成本么？你算过设计师的成本么？"

| 新增成本项 | 具体数据 |
|---|---|
| 设计师 | 5人日 ≈ 5000元 |
| 后端 | 20人日 ≈ 30000元 |
| 前端 | 10人日 ≈ 15000元 |
| 测试 | 5人日 ≈ 5000元 |
| 运营 | 3人日 ≈ 3000元 |
| **总计（新增）** | **58000元** |

> 算上产研成本后，ROI从看起来"很赚"变成了2.1。但长期来看，如果做成常规活动，产研成本可以摊薄到忽略不计。

**LEO以为这次可以拿到大红花了——但领导又问了一个让他彻底懵掉的问题。**

#### (D) LEO的第三版本ROI（高阶——机会成本视角）

> "这个项目就算做了，一个月最多也就30万，占业务也就3‰都不到。如果你把这些资源，用来做别的事，能赚更多么？比如做XXXXX项目，如果做的话，一个月提升几百万GMV，应该问题不大吧？"

| 认知升级 | 内容 |
|---|---|
| **之前的盲区** | LEO只看「老带新本身的ROI是否大于1」，没有和「其他可能的项目」做对比 |
| **领导给的视角** | 公司需求池里躺着那么多需求——如果把同样的人力投入到别的项目，能赚多少？ |
| **核心概念** | **机会成本**——投入在老带新上的资源，不能同时投入到其他项目上 |

> LEO赶紧回去打开需求池，按照能提升的GMV和ROI综合排序——老带新，的确不是排在最前面的。于是抓紧进入下一轮的业务探索。

### 2.2 LEO的第二个案例：新业务负责人的「地推获客」决策

#### (A) 背景

| 要素 | 内容 |
|---|---|
| **场景** | LEO成为新业务负责人，探索新的增长渠道 |
| **初始判断** | 发现一个很棒的增长假设——用一些小册子（成本很低），就能换回数万个精准新客 |
| **LEO的冲动判断** | "今年增长有着落了！给我2个月，我给你把这个业务做起来！" |

#### (B) 第一版本ROI（不合格——只看到表面）

> Mr.T当场就说："这对于公司是个不小成本的试错，要提前估一下ROI。但是，就你这点信息量，完全没办法做判断啊。如果只看到这么浅、这么表面的一层，太粗糙了。"

| 问题 | 说明 |
|---|---|
| **只看到** | 小册子成本低（表面成本）→ 可能带来很多新客（表面收益） |
| **没看到** | 线下地推BD人员的工资和培训成本、销售团队组建和管理成本、合伙人时间、持续运营成本…… |

#### (C) 第二版本ROI——建评估模型、拆到地推人员单元

> Mr.T引导LEO："我们得试着建一个评估模型，然后分析一下可行性。因为这里面最重要的决策是线下的地推BD，我们就按一个地推人员来算吧。"

| 拆解动作 | 具体做法 |
|---|---|
| **建评估模型** | 按一个地推人员为单元，分析单人投入产出 |
| **算人力成本** | 地推人员工资、培训成本、管理成本 |
| **算边际收益** | 一个人一个月能覆盖多少人？转化率多少？客单价多少？ |
| **算时间窗口** | 一线城市孵化器2-3个月就差不多洗完了——团队就得解散 |

#### (D) 结论

> "非常不划算啊。这次Leo的小红花又没有领到——被Mr.T在黑板上一个公式，加上两通电话聊得哑口无言。Leo的能力又涨了一点点，下次一定要努力拆解公式，做预判。"

**核心教训：不要凭"这个点子太棒了"的兴奋感做决策，先建模型、算清楚再说。**

### 2.3 LEO的第三个案例：课程负责人的「全员参加MBA」决策

#### (A) 背景

| 要素 | 内容 |
|---|---|
| **场景** | LEO成为一堂的课程负责人，负责案例课线 |
| **触发事件** | Mr.T问：咱们MBA线下三天两夜有很多优秀同学和案例，教研每个月要不要全员参与啊？ |
| **LEO的第一反应** | "去啊！这是一次千载难逢的接触用户的机会，还能认识同学交朋友，全员必须上阵！" |

#### (B) 第一版本ROI（不合格——只看到模糊价值）

> Mr.T提醒："这个毕竟会影响比较深远，别有执念，还是要努力评估一下ROI。你用这一句话去跟团队讲，占用周末，大家真得服气吗？"

| 问题 | 表现 |
|---|---|
| **只看到模糊价值** | "接触用户""认识同学"——全是定性，没有定量 |
| **没考虑成本** | 5个人3天时间、周末加班心理压力、结束后1v1沟通成本 |
| **无法说服团队** | 大概率出现时间投入产出比很低、下属不理解、没有积极性甚至吐槽 |

#### (C) 第二版本ROI——拆成本收益 + 机会成本

> LEO开始认真评估：

**成本项：** 5个同学3天时间、周末加班心理压力、结束后1v1沟通成本

**收益项：**
- 挖掘案例：大概能挖1-2个S案例（2h），3-5个A级别案例（1h）
- 挖掘专家：有机会挖掘领域专家，未来做方法论课（约1/300人）
- 收获认知：大量接触学员案例，培养创业Sense，提升做课能力（暂时定性）

**机会成本：** 每个人3天 = 15人日——如果不去线下，从优秀作业、学霸、案例集里挖掘，同样的资源能挖出来多少个？

> 初步判断：如果只是这样算，**大概率不去了**——和过去的机会成本比，挖掘效率差不多，且不占用休息时间。

#### (D) 第三版本ROI——打磨和迭代ROI，探索"怎么做更好"

> Mr.T继续问："你觉得，教研必须去三天么？去一天，行不行？去一个人行不行？"
>
> **"对啊！Leo的思路彻底打开了——如果ROI拆成了要素，最有意义的是，它就可以打磨和迭代了，你可以试试有没有办法调整一下，努力提升R，努力降低I。"**

| 调整动作 | 具体做法 | 效果 |
|---|---|---|
| **调整1：降成本I** | 成本降为1天，只在最后一天路演时过去 | **↓67%** |
| **调整2：提收益R** | 更聚焦的参与——只参与最高价值的路演环节 | 案例挖掘效率不降反升 |
| **调整3：降心理成本** | 从"占用整个周末"变成"只需1天"，团队接受度大幅提升 | 下属服气、积极性高 |

> **核心启示：ROI不是一把"做不做"的铡刀，而是一个可以打磨和迭代的设计工具。第一版ROI不好看不代表要放弃——你可以"拉价值、降成本、调方案"。优秀的ROI，往往出现在第2/3版，甚至5/10版里。**

## 三、第二部分：核心框架——科学决策三角形

> "把判断转化成商业语言，变成三个维度。" —— Truman

### 3.1 科学决策三角形全景

```text
                    宽度
                关键收益项
                关键成本项
                   /\
                  /  \
                 /    \
                /  ROI \
               /  决策  \
              /  三角形  \
             /            \
            /              \
    深度                  高度
  优先级定性          长期视角
  部分定量            公司视角
  定量公式          机会成本
                    时间窗口
```

### 3.2 三维度详解

| 维度 | 核心问题 | 从低到高的进化 | 一堂口诀 |
|---|---|---|---|
| **宽度** | 有没有漏掉关键的成本项和收益项？ | 只看到最表面的成本/收益 → 全面穷举关键成本项和收益项 | "努力找一找，把关键投入项、收益项找出来，避免出现盲区和大的误判" |
| **深度** | 能不能把评估从定性升级为定量？ | 模糊定性（"有价值"） → 部分定量（"大概2000元/月"） → 完整定量公式 | "ROI估算深度要匹配决策的重要性和难度" |
| **高度** | 有没有看到长期视角、公司视角、机会成本和时间窗口？ | 只看短期、只看本部门、没考虑机会成本 → 长期公司视角 + 机会成本 + 时间窗口 | "全局思考，综合权衡" |

### 3.3 三维度的递进关系

```text
宽度：先把该看的都看到（不丢三落四）
  ↓
深度：把看到的尽量算清楚（不模糊定性）
  ↓
高度：从更高的视角做判断（不短视、不局部）

三维度不是"选一个"，而是"都做到"。
只是不同决策的复杂度不同，三维度需要的深度也不同。
```

### 3.4 补充：方案评估三角形（认知篇关联）

> 这是ROI三角形在方案设计阶段的具体应用——转化成商业语言的三个判断维度。

| 维度 | 核心问题 |
|---|---|
| **投入产出比ROI** | 划不划算？投入 VS. 产出 |
| **机会成本** | 是不是最佳？这个选项 VS. 其他所有选项 |
| **时间窗口** | 是不是现在？现在做 VS. 其他所有时间 |

## 四、第三部分：深度理解——ROI的三句核心心法

> Truman在第一节课送给学员的三句话。

### 4.1 三句心法

| 心法 | 含义 | 反例 |
|---|---|---|
| **要全局思考，综合权衡** | 不只是看最表面的ROI，而是看宽度（全面成本收益）+ 深度（定量）+ 高度（长期/公司/机会成本/时间窗口） | Leo的第一个案例——只看到活动激励成本，没看到产研成本、机会成本 |
| **要相信可以预判** | 不要因为"不确定"就放弃预判——建模型、拆公式、做定量估算，预判越早、试错成本越低 | Leo的第二个案例——"这个点子太棒了"的兴奋感不能替代预判 |
| **要把它当做团队能力，苦练基本功** | ROI不是一个人的天赋，而是一个团队可以共同修炼的基本功——有共识的方法论、有共同的判断语言 | "这些选择决策，你背后有方法论吗？你的团队有一致共识的决策方法论吗？" |

## 五、LEO的三次成长全览——从混乱到熟练

| 案例 | LEO的段位 | 踩了什么坑 | 学到了什么 | 对应三角维度 |
|---|---|---|---|---|
| **案例1：老带新** | 有ROI意识但丢三落四 | 只看到活动激励成本，漏了产研成本；没做机会成本对比 | ①全面拆成本收益 ②机会成本——"如果把资源用来做别的项目呢？" | **宽度 + 高度** |
| **案例2：地推获客** | 凭兴奋感做判断 | 被一个好点子冲昏头脑，没有建评估模型就下判断 | ①建评估模型 ②拆到最小单元（单人）做预判 ③永远先算清楚再行动 | **深度 + 宽度** |
| **案例3：全员MBA** | 只看到模糊价值 | 只看到"接触用户"的定性价值，没算成本，没迭代方案 | ①定量拆成本收益 ②机会成本 ③**ROI可以打磨和迭代**——降成本（去1天）、提收益（只参加路演） | **深度 + 高度 + 迭代思维** |

> **核心规律：优秀的ROI，往往出现在第2/3版，甚至5/10版里——第一版通常惨不忍睹，但经过N轮反复"拉价值、降成本、调方案"，最终都完成很不错的业务结果。**

## 六、ROI修炼段位成长地图

| 段位 | 核心能力 | 典型表现 | 对应三个维度 |
|---|---|---|---|
| **L1 拍脑袋** | 无ROI意识 | 凭感觉、凭兴奋感、凭"这个点子太棒了"做决策 | 宽度0 / 深度0 / 高度0 |
| **L2 有成本收益意识** | 能做简单的成本收益拆解 | 像Leo第一版——列了最明显的成本和收益，但丢三落四 | 宽度入门（但漏很多） |
| **L3 能全面拆解** | 不丢三落四，关键成本收益项全考虑到 | 像Leo第二版——补上了产研成本，还考虑了摊薄效应 | 宽度合格 |
| **L4 能定量评估** | 把定性评估升级为定量评估 | 建评估模型、拆到最小单元、算具体数字而非"大概有用" | 深度合格 |
| **L5 能全局视角** | 能考虑机会成本、时间窗口、公司视角 | 像Leo被领导追问"做别的项目能赚更多吗？"——从局部ROI升级到全局ROI | 高度合格 |
| **L6 能迭代打磨** | 把ROI当成设计工具持续打磨 | "这个ROI不好看——我们能不能拉价值、降成本、调方案？"——出现在第3/5/10版 | 三维度全通 + 迭代思维 |

## 八、L6 刻意练习自检清单

### 广义ROI意识——你是否在用ROI做日常决策

- [ ] 过去一个月，你做了多少个涉及"要不要做"的决策（哪怕是小决策）？其中有多少是随手拍脑袋，有多少认真做了ROI拆解？
- [ ] 你是否能把"广义ROI"的概念内化——不只是投资决策需要ROI，日常管理和业务决策也需要？
- [ ] 你的团队在做决策时，有没有共同的ROI评估语言和方法论？还是每个人各凭感觉？

### 宽度——你有没有丢三落四

- [ ] 回顾你最近做的一个重要决策——你是否把所有关键的成本项都列全了？（不只是直接成本，还有间接成本、团队时间、管理成本、机会成本）
- [ ] 你是否把所有关键的收益项都列全了？（不只是直接收益，还有间接收益、长期收益、能力积累）
- [ ] 你有没有像Leo一样——第一次列ROI时漏掉了产研成本这种"看不见但巨大"的成本？

### 深度——你有没有在定量

- [ ] 你的ROI评估目前更多是定性（"有价值"）还是定量（"预期带来XX收益，预计投入XX成本"）？
- [ ] 对于试错成本10w以上的决策，你是否做了定量评估？如果没有，为什么——是没数据，还是没习惯？
- [ ] 你是否建立了"建评估模型"的习惯——拆到最小单元（如按一个地推人员来算），而不是笼统估算？

### 高度——你有没有看到更高的视角

- [ ] 你做决策时，是否考虑了机会成本——"如果我投入这些资源做A，就不能做B，B的收益是多少？"
- [ ] 你是否考虑了时间窗口——"现在是做这件事的最佳时机吗？早了还是晚了？"
- [ ] 你是否从公司全局视角而非局部部门视角看ROI——"这对我的部门划算，但对公司整体划算吗？"

### 迭代思维——你是否在打磨ROI

- [ ] 你拿到第一版ROI后，有没有习惯追问"能不能拉价值、降成本、调方案"——而不是直接判死刑或直接绿灯？
- [ ] 你有过一个ROI，从第一版惨不忍睹，经过3-5版迭代后变成一个扎实决策的经历吗？
- [ ] 你团队的ROI评估文化是"一次评估定生死"，还是"第一版只是起点"？

### 综合自检

- [ ] 对照ROI修炼段位地图（L1-L6），你现在更像L几？下一段最需要突破的是宽度、深度还是高度？
- [ ] 回顾你过去三年，你做过的关键决策（试错成本10w以上）中，有没有一个像Leo一样——如果当时做了完整的ROI评估，结果会完全不同？
- [ ] 你是否愿意把"科学决策"作为你长期刻意练习的管理基本功——而不只是"听了一节好课，知道了ROI三个字母"？
