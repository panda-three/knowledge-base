> **"动态股权设计的核心，就是让股权即能有机会变多，也有可能变少。常用的动态调整的工具主要有四种：期权、限制性股权、退出回购、递增递减机制。"** —— 芦玮娜律师

## 一、为什么要学——破题篇

### 1.1 茶园案例的三个终极困境——没有动态调整的惨痛代价

> 芦律师在认知审美篇和股权必修1、2中反复用茶园案例展示了"权责不相当"和"控制权缺失"的后果。在本课，她完整揭示了茶园项目找到她时面临的三个终极困境——这三个困境完美体现了没有做好股权动态调整设计的坑。

| 困境 | 具体表现 | 对应的动态调整缺失 |
|---|---|---|
| **困境一：银行贷款到期** | 张三没能力拿钱出来，姚仁和隋便发想到自己的股权比例，不甘心不明不白地拿钱出来，公司面临资信危机 | **权责不相当**——出钱的人股权少，不出钱的人股权多，没有任何机制让"愿意追加出资的人获得更多股权" |
| **困境二：退出价格僵局** | 张三提出破产清算，姚仁和隋便发不同意，提出要不张三退出。张三同意退，但要求按上一次融资的投后估值900万元来转让——没有任何一方愿意让步 | **退出路径不清晰**——没有提前约定"不同退出情形下的回购价格"，只能现场博弈 |
| **困境三：激励股权被卡** | 姚仁找到了一个优秀的销售总监，口头承诺给股权激励，但张三和隋便发都不同意稀释自己的股权来激励新人 | **激励股权没预留**——没有预留期权池，优秀人才进不来，现有股东不愿稀释 |

> **芦律师的判断：这三个困境的根因贯穿了整个ACAC四原则——①权责不相当、②退出路径不清晰、③激励股权没预留。其中②和③都是"调整"原则的缺失。**

### 1.2 为什么"调整"是股权结构的安全阀

```text
股权必修1解决了：初始股权怎么分（静态公平）
股权必修2解决了：分了之后控制权怎么保障（静态控制）

但现实中：
  → 合伙人可能中途离职——股权还在但人不干了
  → 合伙人可能违法犯罪——公司商誉受损但他还是股东
  → 优秀人才想加入——股权全分完了没有空间
  → 新业务需要独立团队——现有股权结构无法灵活调整

股权结构如果没有"动态调整"机制 = 
  一套没有安全阀的压力容器——
  正常运转时没问题，
  一旦出现任何意外，立刻炸锅。
```

### 1.3 动态调整的本质——让股权"活"起来

```text
芦律师的核心定义：

动态股权设计的核心，就是让股权即能有机会变多，也有可能变少。

三大维度：
  ① 进得来 —— 如何合法获得一个公司的股份（吸引新人才、新合伙人）
  ② 出得去 —— 约定好退出机制，避免在退出上踩坑（老合伙人离开）
  ③ 股权可变化 —— 能增能减，灵活变化适应企业需求（随贡献变化而调整）

四种工具：
  期权 / 限制性股权 / 退出回购 / 递增递减机制
```

## 二、核心框架：三大维度——进得来、出得去、股权可变化

> "第一部分，进得来。如何合法获得一个公司的股份。第二部分，出得去。约定好退出机制，避免在退出上踩坑。第三部分，股权可变化。能增能减，灵活变化适应企业需求。"

### 2.1 三大维度全景

```text
                    动态调整的三大维度

    进得来                  出得去                 股权可变化
 （吸引新力量）          （合伙人退出）           （股权结构弹性）
       ↓                      ↓                       ↓
  期权激励             善意退出回购            递增递减机制
  限制性股权           过错退出惩罚            里程碑式分股
  预留期权池           退出价格设计            成熟机制（Vesting）
```

### 2.2 三大维度详解

| 维度 | 核心问题 | 对应的痛点场景 | 一堂茶园案例 |
|---|---|---|---|
| **进得来** | 如何合法获得公司股份？新合伙人/核心员工怎么给股权？ | 姚仁找到了优秀销售总监但无法给股权——所有股东的股权都锁死了 | 困境三：激励股权没预留 |
| **出得去** | 合伙人离开时股权怎么处理？不同原因（善意/过错）怎么区分对待？ | 张三人已不在公司但股权还在，要求按高估值退出——没有提前约定退出路径 | 困境二：退出价格僵局 |
| **股权可变化** | 股权能不能随贡献变化而增减？新业务怎么独立分股？ | 合伙人承诺All in却只兼职、出资分期到位但股权已全部工商登记 | 困境一：权责不相当（出钱和持股错位） |

## 三、第一维度深度：进得来——四种动态工具全景

> "而常用的动态调整的工具主要有四种，即：期权、限制性股权、退出回购、递增递减机制。下面我们从三个维度给大家拆解这四个工具，分别是让股东进得来，也出得去，股权可变化。"

### 3.1 四大工具全景速查

| 工具 | 适用场景 | 一句话定义 | 解决什么问题 | 一堂股权系列课配套资源 |
|---|---|---|---|---|
| **期权** | 吸引和激励核心员工/高管 | 授予在未来特定时间内以约定价格购买公司股权的权利 | "进得来"——让优秀人才分享公司增长红利，但不必一开始就给股权 | 《一堂期权池协议书》 |
| **限制性股权** | 对新合伙人能力/资源/资金不确定但急需给股权承诺 | 给股权但附加成熟条件——条件满足了股权才真正属于你 | "进得来+出得去"——防止给了股权后人不干活或能力不匹配 | — |
| **退出回购** | 所有合伙人的所有退出场景 | 提前约定不同退出情形下的回购价格和回购方式 | "出得去"——避免退出时漫天要价或无限期僵持 | 《一堂转让代持协议》 |
| **递增递减机制** | 贡献持续变化的长期合伙关系 | 股权比例随贡献变化而逐步调整——多贡献者增、少贡献者减 | "股权可变化"——让股权始终和贡献匹配 | — |

### 3.2 期权——让优秀人才"先进来，再绑定"

| 维度 | 说明 |
|---|---|
| **适用场景** | 公司想吸引核心高管/关键技术人才，但对方需要看到股权的想象空间 |
| **运作原理** | 授予期权（在未来特定时间内以约定价格购买公司股权的权利）→ 成熟期（通常4年，1年cliff）→ 行权（支付行权价获得股权） |
| **关键设计要素** | 期权池大小（通常10-20%）、行权价格、成熟节奏（vesting schedule）、行权期限、离职后期权处理方式 |
| **茶园的反面教训** | 姚仁找到优秀销售总监并口头承诺给股权，但张三和隋便发不同意稀释——因为早期没有预留期权池。**期权池必须在分配阶段就预留出来，而不是"等需要的时候再商量"。** |

> **芦律师的提醒："我们说股权的本质是，一个能增值的支付工具，这也是为什么股权会有激励的效果。但是想要股权产生激励效果，应该至少做到两点：第一，大家对项目的价值高度认可，拿到项目股权会自然而然产生股东的责任感——共识共担。第二，大家都愿意为了把项目做大拼命做事，并且对分享项目的增长红利有所期待——共创共享。"**

### 3.3 限制性股权——"先承诺，后兑现"

| 维度 | 说明 |
|---|---|
| **适用场景** | 对新合伙人的能力/资源/资金实力不太确定，但又急需给出股权承诺 |
| **运作原理** | 给予股权，但附加成熟条件——条件满足了股权才真正成熟、真正属于该合伙人 |
| **常见成熟条件** | ①全职参与后成熟（承诺All in的合伙人先成熟一部分，剩下一部分等全职参与后再兑现）②业绩对赌成熟（合伙人负责的工作实现了对应的业绩目标后再按约定成熟）③出资节奏成熟（分期出资的按出资的节奏来完成股权的成熟） |
| **核心价值** | 解决了"给了股权但人不干活"的困境——股权是对"未来的贡献"的承诺保障，不是对"过去的关系"的一次性奖赏 |

### 3.4 退出回购——"走得清清楚楚"

| 维度 | 说明 |
|---|---|
| **适用场景** | 所有合伙人、所有退出情形——可能是创始人主动要求合伙人退出，也可能是合伙人主动要求退出 |
| **运作原理** | 提前约定：在不同退出场景里，公司或大股东按不同的价格对退出股权进行回购 |
| **退出场景分类** | **善意退出**（一般没有给公司造成不利影响或损失的）vs **过错退出**（违反竞业协议、职务侵占、损害公司利益、违法犯罪等） |
| **回购价格设计** | 建议区分善意/过错。善意退出参考：固定价格、出资款固定倍数溢价、融资估值折扣（如3-5折）、公司当年利润总额比例。过错退出参考：出资款折扣甚至0元强制回购 |
| **茶园的直接教训** | 张三要求按上一次融资的投后估值退出（900万）——如果提前约定了退出价格为"出资款的X倍"或"净资产的一定比例"，就不会出现这种漫天要价的僵局 |

### 3.5 递增递减机制——"贡献变股权变"

| 维度 | 说明 |
|---|---|
| **适用场景** | 合伙人贡献持续变化——有人越来越重要、有人越来越边缘 |
| **运作原理** | 预设在特定条件下，某些合伙人的股权比例可以增加（递增）、某些合伙人的股权比例可以减少（递减） |
| **典型触发条件** | 追加出资完成 → 股权递增 / 未完成业绩承诺 → 股权递减 / 从全职转为兼职 → 股权调整 / 引入新核心合伙人 → 现有股东等比稀释 |
| **核心价值** | 让股权始终"和贡献挂在一起"——从静态的"分完就定了"变成动态的"跟着贡献走" |

## 四、第二维度深度：出得去——退出机制的系统设计

> 芦律师用茶园案例的"平行时空"推演，展示了退出机制设计完整闭环——从退出情形分类到回购价格设计。

### 4.1 退出机制设计的四个步骤

| 步骤 | 核心动作 | 具体做法 |
|---|---|---|
| **第一步：分类** | 把退出场景分为善意退出和过错退出 | 善意：经协商一致退出、因离婚导致股权有被分割的风险、被宣告失踪/死亡等。过错：违反合伙人承诺导致公司损失≥100万元、因违法行为受到刑事处罚、因过错或重大过失使公司遭受100万元以上损失 |
| **第二步：定价** | 为每种退出场景约定回购价格计算方式 | 善意退出：按"净资产×1.5""出资款+年化8%利息""融资估值的3-5折"等方式。过错退出：按"出资款×0.5""当月净资产值×0.5"等惩罚性低价 |
| **第三步：定顺位** | 约定谁有权优先认购退出股权 | 通常按"公司→大股东→其他股东"的顺序，防止退出股权流入公司不希望的人手中 |
| **第四步：写进协议** | 把退出机制写进《股东协议》或《公司章程》 | 不只要口头约定，必须落到纸面——这是股权必修4（签订协议）要做的落地动作 |

### 4.2 茶园案例的退出机制推演

> 以下是芦律师在认知审美篇中展示的完整退出机制设计表格——帮助茶园项目的股权方案从55分（分配30分+控制25分）提升到70分（+调整15分）。

| 退出类型 | 退出情形 | 退出价格 |
|---|---|---|
| **合伙人善意终止** | ①经协商一致退出<br>②因离婚导致股权有被分割的风险<br>③被宣告失踪、宣告死亡或死亡 | 按如下价格较高者为准，最高不超过拟回购股权对应出资款的10倍：<br>①标的公司最近一个会计年度的净资产×1.5×拟回购股权比例<br>②拟回购股权比例对应的已支付的出资款+（回购比例对应的已支付的出资款×8%/365×自出资之日起至回购之日止的天数） |
| **合伙人过错终止** | ①违反合伙人承诺<br>②因违法行为受到刑事处罚<br>③因过错或重大过失使公司遭受100万元以上的损失 | 按以下就低：<br>①出资款×回购股权比例×0.5<br>②当月公司净资产值×回购股权比例×0.5 |
| **分红股创始人过错终止** | ①违反合伙人承诺损害公司或其他股东利益导致受害方达到100万元以上损失的<br>②因违法行为受到刑事处罚 | 按以下就低：<br>①行权价款÷已成熟配送激励股数×回购股权数×0.5<br>②当月公司净资产值×回购股权数÷公司总股数×0.5 |
| **认购顺位** | 公司→B→C（即公司有优先认购权，大股东其次） | — |
| **表决权** | 对应比例由认购方共同享有 | — |

> **芦律师的总结："这样好处是什么？当我们的合伙人和创始人出现不能承担股东责任的情况下，我们依靠这些规则可以对公司的股权进行动态调整或救济。加入退出机制后，茶园股权方案从55分提升到70分。"**

## 五、第三维度深度：股权可变化——特殊场景的动态设计

### 5.1 里程碑式分股——"先合作再合伙"

> "当我们对某个项目一拍即合，可确实彼此从来都没有合伙共事过，无论是对创始团队还是对项目都没有太大信心或确定性的时候，我们是不是可以试着'先合作再合伙'。"

| 维度 | 说明 |
|---|---|
| **适用场景** | ①彼此从未合伙共事过，对团队和项目信心不足 ②公司想孵化新项目，需要拉一个团队出来独立经营 |
| **运作原理** | 整个项目全部或部分的股权暂不做分配（可以形象理解为"冻结住"），通过设置业务里程碑再对股权进行分配——当达到里程碑（如业务收入达到1000万、或者融到资），然后再按事先的约定来分配股权 |
| **芦律师的重要警告** | "里程碑式分股实施过程中难度比较大，因为涉及到太多主观系数需要事先达成一致——怎么设置里程碑、怎么设置大家各自的贡献、贡献怎么对应股权。这里涉及到太多主观评估，创始团队达成一致的难度比较大。我服务的案例中，真正用得好的比较少，对创业者的要求比较高——要求这个创业者极富领导力，对整个商业模式的精准评估要求比较高。" |

### 5.2 成熟机制（Vesting）——"股权是对未来的承诺"

| 维度 | 说明 |
|---|---|
| **适用场景** | 所有合伙人——尤其是承诺"All in"但还没实际行动的、或能力/资源尚未验证的新合伙人 |
| **运作原理** | 股权不是一次性归属，而是随时间/条件逐步成熟。标准成熟节奏：4年成熟期 + 1年cliff（悬崖期）——干满一年成熟25%，之后每月成熟1/48 |
| **成熟条件的灵活设计** | ①承诺All in的合伙人先成熟一部分，剩下一部分等全职参与后再兑现 ②合伙人负责的工作实现了对应的业绩目标后再按约定成熟 ③分期出资的按出资的节奏来完成股权的成熟 |
| **核心价值** | 股权是对"未来的贡献"的承诺——防止合伙人拿了股权就撤。常见的惨痛教训：合伙人干了3个月就走了，工商登记的30%股权永久挂在他名下 |

### 5.3 预留激励——让优秀人才"有得给"

| 维度 | 说明 |
|---|---|
| **适用场景** | 所有早期创业公司——在股权分配时就预留出期权池，用于未来吸引核心人才 |
| **运作原理** | 在初始股权分配时就预留10-20%的期权池（通常由创始人代持或放入持股平台），约定成熟节奏和行权条件，用于激励未来的核心高管和关键人才 |
| **茶园的直接教训** | 姚仁找到了优秀销售总监但无法给股权——因为早期分配时三个股东把100%的股权都分完了，没有任何预留 |
| **芦律师的核心提醒** | 股权的激励效果需要两个前提：①共识共担——大家对项目价值高度认可，拿到股权有股东责任感 ②共创共享——大家都愿意拼命做事，对分享增长红利有所期待。**如果这两个前提不具备，给了股权也不会有激励效果。** |

## 六、茶园案例的完整修复路径——从0分到70分的三段跳

> 这是芦律师贯穿整个股权系列课的最完整案例推演——茶园项目的股权方案从认知审美篇的0分，到股权必修1分配设计后30分，再到股权必修2控制设计后55分，最终在本课加入退出机制后达到70分。

### 6.1 三段跳全景

| 修复阶段 | 对应课程 | 修复了什么 | 分数变化 | 具体动作 |
|---|---|---|---|---|
| **第一阶段：初始状态** | 认知审美篇 | — | **0分** | 按出资比例分股权（张三45%/姚仁35%/隋便发20%），没有控制权设计，没有退出机制，没有期权池 |
| **第二阶段：权责相当** | 股权必修1 | 股权分配——量化贡献差异 | **0→30分**（+分配30分） | 识别了权责不相当的问题、按贡献量化重新评估分配方案 |
| **第三阶段：多元控制** | 股权必修2 | 控制权——持股平台实现绝对控制 | **30→55分**（+控制25分） | 张三做GP控制合伙企业→表决权从45%→72.5%；约定累计分红5000万后姚仁/隋便发转让27.5%股权给张三 |
| **第四阶段：动态调整** | 股权必修3（本课） | 调整——退出机制设计 | **55→70分**（+调整15分） | 加入完整的善意退出/过错退出回购条款、认购顺位约定 |

### 6.2 70分之后——还有15分在哪

```text
股权体检总满分：100分
  认知审美篇：0分
  股权必修1（分配）：+30分 → 30分
  股权必修2（控制）：+25分 → 55分
  股权必修3（调整·本课）：+15分 → 70分
  股权必修4（签约）：+15分 → 85分（预设目标）

剩余15分的空间：
  - 里程碑式分股的动态设计
  - 递增递减机制的长周期调整
  - 激励股权的具体成熟和行权方案
  - 茶园量产阶段的新人才引入和股权激励落地

芦律师的态度：
  → 70分已经是一个相当健康的股权方案（从0分起步）
  → 85分是追求极致，但需要更多的精力和更复杂的谈判
  → 对于大多数创业公司，70分足以支撑健康运营
```

## 七、动态调整修炼段位成长地图

| 段位 | 核心能力 | 典型表现 | 调整机制状态 |
|---|---|---|---|
| **L1 无调整意识** | 股权分完就完了 | 工商登记完股权比例，没有任何成熟机制、退出机制、期权池 | 没有任何动态调整设计 |
| **L2 有成熟机制** | 所有合伙人股权有Vesting | 至少约定了4年成熟期+1年cliff——不会出现"干3个月带着全部股权走人"的惨案 | 进得来（基础版） |
| **L3 有退出机制** | 约定了善意退出和过错退出的不同处理 | 合伙人离开时股权怎么收、按什么价格收——都有事先约定，不会现场博弈 | 出得去（基础版） |
| **L4 有期权池** | 预留了期权池并有成熟行权方案 | 至少预留了10-20%的期权池，能吸引和激励优秀核心人才 | 进得来（完整版） |
| **L5 有动态体系** | 四大工具灵活组合使用 | 期权+限制性股权+退出回购+递增递减四种工具全部到位，且根据不同场景灵活选用 | 出得去+股权可变化（完整版） |
| **L6 调整敏捷** | 股权结构能随业务变化灵活调整 | 新业务线可以独立分股、核心人才可以顺畅进入、不合格合伙人可以体面退出——而不引发僵局 | ACAC原则三完全落地 |

## 九、L6 刻意练习自检清单

### 进得来——你的公司能吸引新人才吗

- [ ] 你们公司有没有预留期权池？预留了多少（10%？15%？20%？）？谁在代持或管理这个期权池？
- [ ] 如果要吸引一个年薪100万的核心高管，你们能不能给出一个有竞争力的股权方案——而不需要现有股东"临时商量"？
- [ ] 所有合伙人的股权是否都有成熟机制（Vesting）？如果有人现在离职，股权怎么处理——是已经约定好的还是"到时候再说"？

### 出得去——你的公司能处理合伙人退出吗

- [ ] 你们是否把退出场景分成了"善意退出"和"过错退出"？有没有明确的区分标准（如：造成100万元以上损失=过错退出）？
- [ ] 善意退出的回购价格是怎么计算的——净资产×1.5？出资款+年化利息？融资估值的3-5折？这个计算方式所有合伙人都同意吗？
- [ ] 过错退出的回购价格是否有足够的惩罚性——让过错方"不敢"轻易做出损害公司的行为？
- [ ] 退出股权的认购顺位是否约定好了——公司优先、大股东其次、其他股东再次？

### 股权可变化——你的股权结构能灵活调整吗

- [ ] 如果有合伙人从全职变成兼职，股权比例有没有相应的调整机制？
- [ ] 如果有人愿意追加出资帮助公司渡过难关，有没有机制让他获得更多股权？
- [ ] 如果公司要孵化一个新业务，能不能独立设置一套股权激励机制——而不和母公司的股权结构冲突？
- [ ] 你们有没有尝试过"里程碑式分股"？如果没尝试过，是因为不需要，还是因为难度太大而回避了？

### 三大困境——你的公司有没有茶园的影子

- [ ] 对照茶园的困境一（权责不相当）——你们公司现在有没有"出钱多的人股权少、出钱少的人股权多"的情况？有没有成熟的调整机制？
- [ ] 对照茶园的困境二（退出价格僵局）——如果有人今天提出退出，你们能不能拿出一个大家都认可的退出价格——还是必然陷入僵局？
- [ ] 对照茶园的困境三（激励股权被卡）——如果你想引入一个核心人才，你能顺畅地给出股权吗——还是需要"所有股东都同意"但你知道有些人肯定不会同意？

### 综合自检

- [ ] 对照动态调整段位地图（L1-L6），你的股权方案现在更像L几？下一段最需要补充的是哪个维度——进得来、出得去、还是股权可变化？
- [ ] 完整回顾茶园案例的三段跳修复路径（0→30→55→70）——你的公司最像哪个阶段的茶园？如果要升一档，最该做的是什么？
- [ ] 你是否愿意把"动态调整"作为合伙关系的长期安全阀——而不只是"工商注册时一次性分完就不用管了"？
