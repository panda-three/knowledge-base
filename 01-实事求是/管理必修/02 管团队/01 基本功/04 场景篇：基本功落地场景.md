## 〇、课程总纲

> **"基本功不是一蹴而就的，而是一步步从模糊到具体，从混乱到一致，从空壳到完整，一步步形成的。"** —— 春萍
>
> 这是"苦练基本功"系列的场景篇。春萍（一堂基本功系列课负责人、教研专家）通过三个横跨ToB/ToC、线上/线下、AI/非AI的真实案例，交付了一套从**宏观→中观→微观**三级透视基本功落地的完整方法论。本课解决的核心问题是：**知道基本功很重要，但回到真实业务现场，到底怎么一步步落地？**

| 维度 | 说明 |
|---|---|

## 一、为什么要学——破题篇

### 1.1 课程要回答的核心问题

| 问题 | 说明 |
|---|---|
| 基本功到底发挥什么价值？ | 不只理论上有用，在真实业务现场到底改变了什么？ |
| 基本功在一个团队中是如何一步步真正落地的？ | 不是一次性工程，而是分阶段、分场景、一点一点演化的 |
| 在AI时代，基本功是变得不重要了，还是更重要？ | 直面时代命题，给出"一个不变点 + 三个新变化"的答案 |

### 1.2 学完前三节课后的真实困境

> "回到自己业务中的时候，还是一坨，不知道如何下手。"

| 困境 | 表现 |
|---|---|
| 知道要拆 | 但面对自己的业务，不知道从哪里拆起 |
| 知道要练 | 但团队口头说好，实际行为不变 |
| 知道武器库 | 但不知道什么阶段该用什么武器 |
| 知道AI来了 | 但不确定基本功在AI时代到底是贬值还是升值 |

### 1.3 热身调研：你现在的基本功阶段

```text
□ 过去没听说过
□ 听说过，但没系统学习过
□ 在一堂学过，但没有太强的体感
□ 偶尔在尝试，但还没有很好的结果
□ 一直坚持在练，而且有了一些不错的结果
□ 坚定的实践者，持续练核心基本功，笃定是必经之路
```

> **本课目标：不管目前在哪个阶段，听完后全面升级对基本功的理解，对"AI时代基本功还是不是必经之路"有更笃定的答案。**

## 三、案例一：大客户销售基本功（刘伟）

> **核心启示：把一个复杂的大客户销售能力，拆到"见客户第一句话怎么说""穿什么样的衣服"这种颗粒度，然后让新人用1个月时间天天陌拜练习——半年到1年，新人就能培养成行业前20的王牌销售。**

### 3.1 背景与挑战

| 要素 | 内容 |
|---|---|
| **行业** | ToB大客户销售，客单价100万-2000万 |
| **核心问题** | 老人推不动（有自己套路、不屑练基本功），新人成长慢 |
| **破局思路** | "老人推不动，那就从新人开始"——用尽各种方法研究标准化销售 |

### 3.2 三步构建体系

| 步骤 | 核心工作 | 具体内容 |
|---|---|---|
| **第一步：学习最佳实践** | 深入研究标杆 | 研究华为大客户销售、IBM大客户销售流程和案例 |
| **第二步：调研访谈高手** | 萃取隐性经验 | 招聘和访谈友商大客户高手，提炼可复制动作 |
| **第三步：深入复盘总结** | 从自身经验挖矿 | 拉着老销售逐一复盘失败和成功销售项目 |

### 3.3 核心交付：从"天龙八步"到"十八般武艺"

| 层级 | 工具 | 颗粒度 |
|---|---|---|
| **流程框架** | 大客户销售关键五要素 | 分析销售成功的关键维度 |
| **过程管理** | "天龙八步" | 销售过程标准化流程 |
| **极致拆解** | **"十八般武艺"** | 拆到极致颗粒度的具体动作 |

### 3.4 "十八般武艺"颗粒度示例

| 基本功 | 颗粒度 |
|---|---|
| 见客户第一句话怎么说 | 研究出"钩子话术"——在开口瞬间勾住对方注意力，设计开场小桥段 |
| 穿什么衣服见客户 | 结论：**比客户稍微正式一点点**——太随意不专业，太隆重有压力 |
| 怎么请客户吃饭 | 拆成独立动作，形成标准化模型 |
| 怎么发消息 | 形成标准话术和时机判断 |
| 怎么陌拜 | 新人1个月什么都不干，天天去餐厅/酒店/电子市场陌拜，回来写销售记录，总结复盘 |

### 3.5 天龙八步完整流程

```text
第一步：接触潜在客户（10%）——客户基本资料清晰 + 初步需求清晰 + 下一步接触意愿
第二步：明确客户需求（20%）——SPIN挖掘 + 需求时间窗口 + 商机确认 + 竞争优势
第三步：技术认可与立项（30%）——技术认可评估 + 差异优势确认 + 公司认可 + 决策链认可
第四步：客户和决策链（40%）——组织结构图 + 教练/枪手确认 + 采购流程和关键点
第五步：承诺与认可（60%）——客户关系到位 + 教练信息到位 + 合作模式认可 + 决策链倾向
```

### 3.6 成果

| 指标 | 数据 |
|---|---|
| 2009年接手→2011年 | 人数基本不变，老人砍掉一半，年销售额提升130%，最大订单2000万 |
| 2012年 | 团队20人左右，年销售额在2011年基础上再翻番 |
| 利润率 | 规模和营收持续扩大，利润率反而升高（行业罕见——规模扩张通常稀释利润） |
| 整体利润 | 大客户销售整体利润增加20%左右 |
| 组织韧性 | 团队不再因为某个销售离开而遭受重大损失——组织建立在"系统"而非"能人"之上 |
| 新人培养 | 半年到1年，把新人培养成行业前20的王牌销售 |

## 四、案例二：获客转化基本功（温童凯）

> **核心启示：把面向大学生的驾校代理招生，拆成"加微信"和"促转化"两阶段，每个动作都写"脚本"和"子弹库"，然后用"一张白纸"的新人替代"有资源的KOL"——让业务不再依赖少数精英，而是稳定、可复制地培养出一大批60分选手。**

### 4.1 背景与挑战

| 要素 | 内容 |
|---|---|
| **业务** | 山西太原大学城驾校业务，深耕十多年 |
| **旧模式** | 靠大学生做校园代理推广招生——180人团队，实际业绩主要依赖10来个"精英" |
| **核心问题** | 学生交付极不稳定（缺钱时干两天，不缺钱不见人），精英毕业/不干→业务断崖 |
| **根源** | 把业务成败建立在某个"厉害"的个人身上，而非一套体系 |

### 4.2 转机：一堂"苦练基本功"课后的觉醒

> **"不能把业务的成败，建立在某一个'厉害'的个人身上，而是应该建立一套体系。要把所有人的平均水平，都拉到一条至少60分的及格线上。"**

### 4.3 拆：掰开了揉碎了拆基本功

| 阶段 | 核心任务 | 拆解内容 |
|---|---|---|
| **第一阶段：加微信** | 把漏斗开口做大 | 设计各种线上/线下"钩子"——办活动、论坛发帖、送小礼物、跑楼——加到尽可能多的学生微信 |
| **第二阶段：促转化** | 建立信任，促成报名 | 通过微信运营、线上线下接触沟通，让人愿意信你、报名驾校 |

> **关键洞察：大学生活有明确固定的节奏和时间周期，每年都在循环——特别适合固定下来一套有效的"标准动作"。**

### 4.4 建：给每个动作都建"脚本"和"子弹库"

| 基本功颗粒度 | 普通做法（❌） | 他们的做法（✅） | 效果 |
|---|---|---|---|
| **跑班/跑宿舍加微信** | "同学你好，我们是XX驾校的，了解一下？" | "同学你好，我是你的学长，看你们刚来，怕找不到教学楼，我帮你拉到xx群里，给你们发个校园地图，后面还可以帮你抢课……"——**完全不提"驾校"和"学车"** | 加微信效率提升好几倍 |
| **探需开场白** | "学弟/学妹，你有没有学车的需求呀？"（90%说"没有"） | "我最近在xx驾校兼职，我们老板让我们做个调研来了解下各地的行情，诶，你知道在你们老家，学车多少钱？" | 一句话精准筛选：不知道=潜在客户 / 便宜很多=比价阶段 / 已报名=不跟 |

### 4.5 推和练：段位划分 + 新人一张白纸

| 策略 | 说明 |
|---|---|
| **招人换思路** | 之前找KOL（学生会主席/部长，有资源但不好管，分成极高）；现在重点招普通同学，越小白越好——沟通能力还行就OK，不需要人脉，只需要听话、照做、肯学 |
| **段位划分SABC** | 按基本功水平分级，让每人都有适合自己的练习目标 |
| **老带新** | 内部业务骨干带着小白先做，一边培养一边写文档，一边做一边迭代 |
| **文档驱动** | 拆出大量基本功文档：加微信、朋友圈宣传、探需SOP、陌拜扫楼、咨询话术、跑班话术 |

### 4.6 成果

> 2024年全年招了1800多人，比疫情前最多时还多。从"依赖10来个精英"到"批量培养60分选手"，业务不再坐过山车。

## 五、基本功落地的三级透视：宏观·中观·微观

> 春萍将基本功落地拆成三个观察层次，这是本节课最核心的框架贡献。

### 5.1 三级透视全景

```text
宏观：不同基本功是怎么从1个到10个到100个增长的？
  ↓
中观：一个基本功是怎么一步步演化形成出来的？
  ↓
微观：某一个具体的基本功内部要素是怎么成熟的？
```

### 5.2 宏观：一个典型的基本功推行计划（四阶段）

| 阶段 | 核心任务 | 状态 |
|---|---|---|
| **第一阶段** | 从少数几个最关键的基本功开始 | 单点突破 |
| **第二阶段** | 从极少数团队/成员开始试点 | 灰度验证 |
| **第三阶段** | 逐步扩展范围，看到价值后从1到N | 规模化 |
| **第四阶段** | 全面制度化，和考核晋升绑定 | 组织化 |

```text
一堂自己的状态：五步法在第四阶段，大概有7-10个商业单元
（MBA/训战营/私董会/咨询/AI/内训等）分别在2-3个阶段进化中
```

## 六、中观：一个基本功的演化——拆解落地最佳路径图

> **中心思想：不见兔子不撒鹰（ROI思维），随着认知和价值逐步增加，逐步细化和加重投入。**

### 6.1 六大阶段演化路径

```text
A. 模糊管理 → B. 拆关键 → C. 起名字 → D. 模型化 → E. 阶梯化 → F. 制度化
```

### 6.2 各阶段详解

| 阶段 | 核心工作 | 可用工具/方法 | 触发条件 |
|---|---|---|---|
| **A. 模糊管理** | 大而全、模糊一片 | —— | 初始状态，还没开始拆 |
| **B. 拆关键** | 加法（靠框架/靠专家/靠同行/靠复盘）→ 减法（业务当前目标 + 三环六维过滤） | 四大拆解路径 + 三环六维模型 | 意识到需要拆 |
| **C. 起名字** | 宽而不泛、简单朗朗上口、有差异化、善用动词 | 命名技巧 | 拆出了可独立交付的动作 |
| **D. 模型化** | 本质/方法论 + 清单/画布 + SOP/配套检查 | N步法、清单、SOP、画布、Case | 认知成熟到可以写出来教别人 |
| **E. 阶梯化** | 以身作则 + 标杆用户 + 阶段拆L6 + 岗位拆SABC | 段位图、进阶路线 | 出现分层矛盾（老人太简单、新人太难） |
| **F. 制度化** | 苦练基本功文化建设 + 配套知识库 + 培训练习 + 新人Landing + 绩效/职级/晋升绑定 | 考核体系、晋升体系、培训体系 | 组织扩大，口头传帮带不够用 |

### 6.3 推动演化的五个"质变信号"

> 基本功不是按计划升级的，而是被这些质变信号推动着进入下一阶段的。

| 质变信号 | 含义 | 触发动作 |
|---|---|---|
| **稳定重复** | 发现某个动作被反复做，而且每次做法和结果有规律 | 值得被"拆出来命名" |
| **必经之路** | 发现某个动作是绕不开的关键环节，做不好就整体失败 | 值得被"模型化" |
| **认知成熟** | 对某个动作的理解已足够清晰，可以写出来教给别人 | 值得被"文档化标准化" |
| **分层矛盾** | 老手觉得太简单、新手觉得太难 | 需要做"段位阶梯化" |
| **组织扩大** | 团队人数增加，口头传帮带不够用了 | 需要进入"制度化" |

> **核心认知：在真实场景里，是遇到一个质变点，就一点点优化、往前推进的一个落地过程。不是一次性规划好的。**

## 七、微观：一个完整基本功的五个关键要素

> 一个完整的基本功，包含五个关键要素，才可以让团队真正练起来，真正成为团队知识资产。

| 要素 | 含义 | 示例（以"十层解读"为例） |
|---|---|---|
| **1. 名字** | 有一个明确的、独一无二的名字 | "十层解读" |
| **2. 场景** | 明确哪些场景需要使用这个基本功 | 做课时需要深入解读一个核心概念/Y模型 |
| **3. 原则方法** | 基本功的模型或指导原则 | 挑战用10个不同角度解读同一个东西 |
| **4. Case** | 参考案例（正面/负面），帮助理解好与坏 | Truman用10个角度解读Y模型的案例 |
| **5. 配套练习** | 有哪些课程/材料/机会可以练习 | 教研做课时每次都可以用，新人Landing训练任务 |

### 7.1 要素的演化规律

```text
绝大多数基本功都是从初步想法（假设），
一步步补全、从残缺到完整，
最后升级为全面的。

不是一开始五个要素都齐全的，
而是在真实场景里一点一点补上去的。
```

## 八、基本功的实质理解——手段与目的

### 8.1 基本功的本质定位

| 维度 | 说明 |
|---|---|
| **基本功是手段** | 目的还是为了建模练习，进而提升组织能力，最终提升关键产出 |
| **基本功的平替手段** | 顶上去/不复制、依赖招聘、工作外包、IT、AI |
| **基本功的巨大优势** | 稳定性、可控性、复制性、规模经济 |
| **基本功的对应短板** | 长期见效慢、组织要求高、需要一号位强支持（以身作则） |

## 九、进化：AI带来了什么变化

> **"在AI逐步普及的未来，基本功到底还重不重要？基本功和人工智能，人和AI，究竟是什么关系？"**

### 9.1 一个不变点

```text
不变的：拆解都是核心。

不论是想练基本功，还是想高效应用人工智能，
都是同一个起点：作为业务的负责人，必须学会拆解业务。
```

### 9.2 三个新变化

| 新变化 | 核心含义 | 具体说明 |
|---|---|---|
| **变化一：起点变了** | AI降低了"练"的门槛，但提高了"拆"的要求 | 过去可以慢慢练、慢慢迭代；现在AI能快速执行，但你得先拆清楚"让AI练什么"——拆的颗粒度和准确度要求更高了 |
| **变化二：颗粒度变了** | AI基本功需要拆到更具体的层次 | "AI基本功"至少能拆出7-10个专题模块（提示词工程/文生图/Vibe Coding/Agent/模型微调等），真正高价值的是结合业务找到更小、更具体的AI基本功单元 |
| **变化三：角色变了** | 人机协同的新分工 | 重复的、标准化的活交给AI；人腾出手来做判断、做决策、做需要经验和审美的事情。**AI落地的终局不是机器替代人，而是懂业务的人拿着AI，重新定义自己团队的工作方式** |

### 9.3 AI基本功颗粒度示例

| 层级 | 基本功 | 颗粒度 |
|---|---|---|
| **第一层（泛）** | 提示词基本功 | 太泛，不可直接练 |
| **第二层（进了一步）** | 结构化提示词基本功 | 能写出逻辑清晰、要素完整的提示词 |
| **第三层（具体可练）** ✅ | AI赋能的全网调研提示词 | 教研团队为高效搜集资料而专门提炼的、包含特定流程和指令的基本功 |

### 9.4 AI落地的关键认知

| 关键认知 | 说明 |
|---|---|
| **先帮到谁，而不是替代谁** | 在公司AI落地时，最大阻力不在技术，而在人心。先找到让AI干员工最讨厌的活（如反复写安抚话术），让大家感觉AI是来"帮你挡子弹"的 |
| **人机协同的分工** | 人不是被AI替代，而是从"一线干活"变成"抽查AI的工作、给AI做教练"——定义规则、校准边界、兜底容错 |
| **先跑通60分，比追求90分重要一百倍** | AI落地有太多不确定性，最务实的做法是找到最小闭环——哪怕只覆盖一个场景、只解决一个问题，先让它在真实业务里转起来 |

### 9.5 你的AI落地能力公式

```text
AI落地能力 = f(基本功 , 数据 , 场景)

基本功：练习使用各种AI工具，善于使用AI工具和特性解决问题
数据：高水平的结果需要高水平的数据，主动搜集和积累高质量数据
场景：发掘高匹配的细分场景，本身就是AI能力进步的重要维度
```

## 十、四大必备要素：拆·建·推·练（场景篇再提炼）

> 春萍从三个案例中提炼出基本功实施的四关，和Truman的框架呼应但侧重落地视角。

| 关卡 | 核心任务 | 常见卡点 | 案例中的解法 |
|---|---|---|---|
| **拆 — 拆解出来** | 识别背后重复工作 | 缺意识、识别不出来、拆得太粗/太细 | 刘伟研究华为+IBM+访谈高手+复盘失败项目；温童凯把招生全流程掰开揉碎 |
| **建 — 建立模型** | 建立做事的固定套路 | 没有形成固定套路、模型太模糊 | 刘伟建"天龙八步"+"十八般武艺"；温童凯给每个动作写"脚本"和"子弹库" |
| **推 — 推动落地** | 让基本功真正发挥作用 | 大家不喜欢苦和重复、老销售抵触 | 刘伟从新人开始推（老人抵触"我都干了十几年了"）；温童凯招"一张白纸"的新人不招KOL |
| **练 — 反复重复** | 不断鼓励大量重复 | 热乎一下应付领导、很难持续 | 刘伟让新人1个月天天陌拜写销售记录；温童凯让小白代理照着文档做、边做边迭代 |

### 10.1 基本功化的本质再强调

```text
执行SOP的核心目标：把这件事稳定做完。
基本功化的核心目标：把一个工作单元，转化成团队的刻意练习。

刻意练习的基础：刻意（强目标感，专注，高追求）
刻意练习四大必要要素：套路 + 非舒适区 + 重复 + 反馈
```
