## 一、为什么要学——破题篇

### 1.1 冷启动难题

> 团队把打法给到大家，也建立了文档，在会议上反复强调——但几周后发现效果很差，大家口头说好，实际还是按旧习惯。**从"纸面上"到"意识里"再到"手里的活儿"，这中间隔着一整个武器库。**

| 常见落地卡点 | 具体表现 |
|---|---|
| **团队没意识** | 遇到问题只想靠个人英雄主义、专家、外包解决 |
| **团队不认同** | 觉得不需要，短期看不到成效，认为是浪费自己时间 |
| **团队没动力** | 应付了事，专家抵触，不想分享自己的"绝活" |
| **团队执行难** | 业绩压力大，难以坚持，或者练跑偏、练太少 |

### 1.2 团队苦练基本功的底层原理

> **经典的《刻意练习》四要素：套路 + 非舒适区 + 大量重复 + 及时反馈。**

```text
套路：固定的指导原则和执行框架
非舒适区：处在有难度、对自己不满足的进步状态
大量重复：大规模重复，增加练习频次和循环次数
及时反馈：及时收集反馈，了解差距，修正姿势

凑齐的要素越多 → 练习越科学越高效 → 进步速度越快
```

### 1.3 本节课的教学新玩法：三轮理解

```text
第一轮：认识武器 —— 直接呈现全景地图2.0，快速走一圈认识完整武器库
第二轮：熟悉武器 —— 讲三个一手案例，感受武器在真实业务现场的效果
第三轮：掌握武器 —— 从10个角度深度解读，学会自由选用和组合打包
```

## 二、核心交付：一堂苦练基本功武器库·全景地图2.0

> 这个小抄从1.0到2.0，经历了多轮研究、300+共建同学讨论打磨，是目前一堂最完整的**基本功落地策略总图**。

### 2.1 全景地图五层结构

```text
顶层一：四大目标（基本功练习的四大追求）
    ↑
顶层二：四关要闯（拆·建·推·练）
    ↑
核心层：横轴五列武器组（有氛围 / 有追求 / 有练习 / 有流程 / 有制度）
    ↑
底层一：四大拆解场景 + 三环六维分析
    ↑
底层二：基本功四大分类（A创造/B专业/C领先/D标准/E SOP）
```

### 2.2 全景地图横轴：五组武器

> 地图的核心是五列横轴，从"软"到"硬"逐步升级。

| 武器组 | 一句话目标 | 核心武器（逐级递进） |
|---|---|---|
| **第一组：有氛围** | 让团队从意识上接受 | 挂在嘴边 → 文字化 → 文化墙 → 手边武器库 |
| **第二组：有追求** | 让团队有成长动力 | 以身为则 → 选先锋角色 → 灰度发布 → Flag驱动(20%迭代) |
| **第三组：有练习** | 让团队真正动手练 | 善于培训 → 善于练习 → 善于复盘 → 善于会议 |
| **第四组：有流程** | 让练习稳定可持续 | 制定计划 → 记录过程 → 建知识库 → 考核评估 |
| **第五组：有制度** | 让基本功和组织绑定 | 监督考察 → 绩效考评 → 职级划分 → 岗位晋升 |

### 2.3 五组武器的核心逻辑

```text
从"让人愿意练"（氛围） → 到"让人想练好"（追求）
  → 到"让人真的练"（练习） → 到"让练习可管理"（流程）
    → 到"让练好有回报"（制度）

越往右越硬，越需要前置条件；
不是一步到位全用，而是循序渐进、按需取用。
```

## 三、案例一：一堂 NPC 基本功——新岗位×新人，1年内培养100+志愿者

> 兰毅的私董会NPC案例：把一个被同行说"不可能规模化"的复杂角色，拆成基本功，1年内培养150+NPC，覆盖2400+学员，月交付190+场。**一堂私董会目前已是全国最大的私董会小组。**

### 3.1 背景与挑战

| 要素 | 内容 |
|---|---|
| **目标** | 让S级私董会每月做到几百场规模交付（免费or低成本） |
| **行业判断** | 同行一致摇头："不可能！私董会对主持人要求太高了，全是非标的。" |
| **核心瓶颈** | 私董会中的组织者角色（NPC）是关键——但光靠"负责任、亲和力、积极"这些特质无法复制 |

### 3.2 NPC基本功能拆解过程

```text
第一步：测试验证
  18个小组多轮测试 → 确认NPC就是大规模复制的关键

第二步：拆专家
  兰毅拆解自己（主持41场、11496人次）+
  找到优秀内测小组，看回放、看群互动 +
  组织优秀NPC复盘，挖掘背后可练动作

第三步：拆出7个关键基本功
  ①破冰基本功 ②Pitch案主/幕僚 ③熟练使用指南文档
  ④主持控场 ⑤出口式咨询引导/平等对话
  ⑥挑选合适私董会选题 ⑦如何进行提问
```

### 3.3 以"破冰热场"为例的完整落地链

| 环节 | 具体做法 | 使用的武器 |
|---|---|---|
| **建模** | 萃取关键要素：时效性/自我披露/找到共识/目标立flag + 引入"两真一假"等游戏 + 共建《破冰工作手册》 | N步法 + 建池子 + 头脑风暴 |
| **划段位** | 60分（按时组织）/ 80分（踊跃做案主）/ 100分（称兄道弟、跨国相见） | 划分段位 SABC |
| **培训** | 线上NPC启动会 + 线下2天1夜特训营 + 专家督导会 + 最佳实践分享 | 入职集训 + 导师计划 |
| **练习** | 线上分组模拟破冰 + 线下培训现场实战 + 各组必须开破冰会 + 合影+合集视频 | 训练任务 + 桌下练习 |
| **反馈** | NPC自我复盘作业 + 小组成员提交破冰反馈 + 兰毅统一分析发送各组 | 交叉反馈 + 复盘会议 |
| **激励** | 各组接龙捷报 + 排行榜 + 破冰视频合集（仪式感） | 表扬先进 + 最佳实践分享 |

### 3.4 NPC案例成果

| 指标 | 数据 |
|---|---|
| 累计培训NPC | 150名 |
| 累计覆盖MBA学员 | 2445人 |
| 累计活动场次 | 1800场 |
| 月均场次 | 190+场 |
| 组员续报率 | 60% |
| 结营作业NPS | 8分 |
| NPC续服务率 | 90% |

> **核心启示：不可能规模化的角色，只要拆到基本功颗粒度，配上武器库全链条——培训、练习、反馈、段位、激励——就能实现规模化复制。**

## 四、案例二：古董的奶茶基本功——100家连锁的SOP标准化

> 古董是一堂青岛学习中心主理人，开了100家头部品牌连锁奶茶店。这个案例展示了从"做奶茶很简单"的用户错觉，到"几百条SOP + 三层保障机制"的专业现实。

### 4.1 反常识：一家20平米奶茶店有多少SOP？

```text
不是1-5个，不是5-10个，不是10-20个……
答案是：至少几百个。
```

### 4.2 按工作站拆解的SOP体系

| 工作站 | 工作内容 |
|---|---|
| **后区** | 准备各种奶茶原料和配料 |
| **奶区** | 配料、冰块等配餐工作 |
| **柜台** | 客人点单和取货 |
| **雪克** | 需要手摇加工的产品处理 |

每个工作站都有几十到上百条SOP，覆盖了从开铺到闭店的每一个动作。

### 4.3 古董的全公司基本功体系

```text
8大方向：基础认知、工作站管理、QSC品控、行政工作、
         员工训练发展、营运管理、通用管理、经营决策
涉及70-80项基本功：

认知层：公司认知、QSC认知、高效能人士7个习惯（前3个）、
        带训最佳实践等 〜10项
专业层：工作站/QSC/行政/训练发展/营运 〜50+项
管理层：通用管理能力、经营能力 〜15-20项
```

### 4.4 保证SOP执行到位的三层策略

| 策略 | 具体做法 |
|---|---|
| **策略1：打造认知共识** | 招聘时就渗透公司要求（"我们很牛，但要求也很高"）+ 新员工集中培训（发着工资让你听课）+ 定期考试（新人考试/晋升考试）+ 老员工榜样传播 |
| **策略2：日常经营检查** | 门店自查（每日/每周/每月不同要求）+ 稽核部门不通知抽查（2-3页A4纸上百条标准逐项检查，一次近4小时）+ QSC品质服务清洁三大维度 |
| **策略3：挂钩绩效晋升** | 个人：QSC专项奖金+其他奖金（出问题按严重程度扣除）+ 全店：QSC严重不达标→全店员工无晋升考试资格 |

> **核心启示：让奶茶店一线员工"不用动脑子"稳定执行，靠的不是自觉，而是SOP的日常检查 + 奖金晋升的铁腕绑定。这就是从"D标准类工作"走向"E SOP类工作"的完整路径。**

## 五、案例三：一堂逐字稿基本功——教研专家的长期进化

> 一堂所有讲师、嘉宾、案主的表达都稳定在合格线以上——靠的是一次次拆解、建模、练习而成的逐字稿基本功。

### 5.1 逐字稿基本功的演化时间线

| 阶段 | 时间 | 状态 | 关键动作 |
|---|---|---|---|
| **第一阶段** | 一堂第一年 | Truman一个人做课，一大坨完整交付 | 没有分解工作，没有基本功概念 |
| **第二阶段** | 2021年 | 带2-3人做课，发现复制困难 | 正式剥离"写逐字稿"基本功，开始让大家一起写 |
| **第三阶段** | 2022年 | 教研从1-2个变3-4个，协作变复杂 | 进一步分化出写稿子、磨课会、专家访谈；统一命名"逐字稿" |
| **第四阶段** | 2022年底 | 一次性招募3个同学入职教研 | 开知识库、建审美/方法模型、形成培训体系 |
| **第五阶段** | 至今 | 持续细化升级 | 逐字稿基本功不断升级段位，多人协作稳定输出 |

### 5.2 基本功演化的普遍规律

```text
模糊管理（一大坨，无法复制）
  → 拆关键（剥离出可独立交付的动作）
    → 起名字（统一话语体系，告别混乱称呼）
      → 模型化（建审美、方法论、N步法、清单）
        → 阶梯化（分段位，每人找到成长坐标）
          → 制度化（考核、晋升、知识库、新人Landing绑定）
```

### 5.3 现实中的基本功推行路径 vs 理想中的路径

| | 理想推行（❌ 不现实） | 现实推行（✅ 可行） |
|---|---|---|
| **路径** | 一次性全部拆齐 → 一次性全部推行 | 从少数几个最关键的开始 → 从极少数团队/成员开始 → 逐步扩展 |
| **时间** | 1个月提交全部，3个月拆完，6个月训练，12个月考核 | 逐步探索、逐步细化、看到价值后再从1到N |
| **风险** | 一次性工作量太大，不同Leader素质不一，齐头并进不现实 | 先拿到小胜仗、先培养氛围，越往后推行越容易 |

### 5.4 什么时候适合从上往下强推行？

```text
三个条件同时具备：
①业务成熟：商业模式和业务模型分工相对成熟
②团队成熟：尤其是一号位对业务的认知足够好
③基本功素质好：整个团队已经形成苦练基本功氛围

如果不具备 → 先从下往上练素质，再从上往下搭架构。
```

## 六、全景地图2.0 深度解读：五组武器从软到硬

> **不要过早细化未经验证的基本功。不要过早推行未经思考的基本功。**

### 6.1 第一组：有氛围——让团队从意识上接受

| 武器 | 含义 | 具体做法 |
|---|---|---|
| **挂在嘴边** | 管理者不厌其烦地重复"苦练基本功"的话语体系 | 口号化："普通人总喜欢找捷径，高手都在苦练基本功" |
| **文字化** | 落到正式文档里，成为"白纸黑字"的正式要求 | 公司内部文档、新人手册、团队OKR |
| **文化墙** | 贴出来展示，让每个人每天都能看到 | 文化墙Post、办公室标语、飞书群公告 |
| **手边武器库** | 在办公室、会议中配置基本功工具 | 基本功小抄卡片、自查清单、SOP速查表 |

> **底线思维：如果团队还没有"苦练基本功"的共同语言，后面的所有制度都推不动。先把话语体系建立起来。**

### 6.2 第二组：有追求——让团队有成长动力

| 武器 | 含义 | 具体做法 |
|---|---|---|
| **以身作则** | 一号位/业务Leader亲自带头练习 | Truman五年写了上百个方案、秦同学一年写了100+逐字稿 |
| **选先锋角色** | 找到愿意先试的标杆选手/团队 | 找积极热情、愿意尝鲜的团队成员先练 |
| **灰度发布** | 逐步放开范围，不一步全量 | 先1-2人试点 → 小团队验证 → 再全量推广 |
| **Flag驱动** | 每次追求20%迭代，用"小胜仗"积累信心 | "这一版比上一版在X维度提升20%" |

> **张阳老师的直播案例——三个阶段循序渐进：**
>
> 第一阶段（MVP测试）：只让一个新销售背话术，三个月后他拿下销冠 → 其他主播开始动摇
>
> 第二阶段（扩大范围）：老主播看到新人的业绩，开始主动背诵话术 → 业绩稳步提升
>
> 第三阶段（全量推广）：强制要求所有人背话术，不合格不能上播 → ROI方差从50%降到0.3%

> **反例警告：如果张阳一上来就全量强制推行，主播可能走一大半，严重影响稳定性。**

### 6.3 第三组：有练习——让团队真正动手练

| 武器 | 含义 | 具体做法 |
|---|---|---|
| **善于培训** | 入职集训 + 导师计划 + 训练任务 | 新员工Landing训练任务、脱产培训、导师1v1带教 |
| **善于练习** | 背诵练习 + 桌下练习 + 实战练习 | 兰毅让NPC线上分组模拟破冰；古董新员工在模拟店练一周 |
| **善于复盘** | 交叉反馈 + BA对比 + 复盘会议 | NPC小组成员给NPC写反馈；逐字稿交叉互评 |
| **善于会议** | 日常例会强调基本功 + 专项复盘会 | 每周例会固定5分钟讲"这周基本功练得怎么样" |

> **刻意练习四要素在这个环节全部出场：套路（培训给方法）+ 非舒适区（对标最佳实践找差距）+ 大量重复（训练任务反复做）+ 及时反馈（交叉反馈 + 复盘会议）。**

### 6.4 第四组：有流程——让练习稳定可持续

| 武器 | 含义 | 具体做法 |
|---|---|---|
| **制定计划** | 个人/团队的基本功练习计划 | 明确练什么、练多久、每周几次、谁来检查 |
| **记录过程** | 记录练习的时间/次数/版本 | 逐字稿版本号、NPC破冰次数统计、SOP执行记录 |
| **建知识库** | 团队共建基本功指南 | 飞书知识库：方法论文档 + 好/坏Case + 自查清单 |
| **考核评估** | 基本功认知/技能考试 | 新人转正考基本功认知、晋升考基本功实操 |

> **一堂教研的基本功知识库演化：从"全在Truman一个人脑子里" → "有共享文档" → "有完整知识库，包含方法论、Case、清单、自查表、评估标准"**

### 6.5 第五组：有制度——让基本功和组织绑定

| 武器 | 含义 | 具体做法 |
|---|---|---|
| **监督考察** | 监督/检查/辅导机制 | 古董奶茶店：稽核部门不通知抽查，2-3页A4纸上百条标准 |
| **绩效考评** | 和薪酬/奖金强绑定 | QSC专项奖金直接挂钩SOP执行结果 |
| **职级划分** | 跟职级体系挂钩，基本功段位=职级门槛 | NPC的SABC段位与续服务资格绑定 |
| **岗位晋升** | 岗位考核和晋升条件之一 | 古董：QSC不过关 → 全店无晋升报名资格 |

> **核心逻辑：当基本功从"提倡"变成"要求"，从"口头鼓励"变成"考核晋升条件"，团队的练习动力就完全不同了。** 不是靠热爱驱动，而是靠制度托底。

## 七、全景地图纵轴：从加法到减法、从抽象到具体

### 7.1 拆的维度：从加法到减法

| 层面 | 工作 | 工具 |
|---|---|---|
| **加法** | 穷举所有可能的候选基本功 | 四大拆解场景（框架拆/专家拆/外部拆/复盘拆）+ 建池子/头脑风暴/攻坚会 |
| **减法** | 用三环六维过滤出关键基本功 | 三环分析模型：足够价值（重复性/复利性）× 足够务实（场景性/具体性）× 足够可练（独立性/检验性） |

### 7.2 建的维度：从抽象到具体

| 层面 | 产出 | 工具 |
|---|---|---|
| **本质/底层规律** | 第一性原理 → 本质逻辑 → ROI决策 → 本质要素 | 追问"这件事最底层的规律是什么" |
| **方法论层** | N步法 + 公式 + 拆N步法 | 建立可执行的流程和要素管理 |
| **清单/画布层** | 评估雷达图 + Checklist + 小抄Cheatsheet | 让标准可视化、可自查 |
| **SOP层** | 极其具体的完整工作流 + 严格分工和时间管理 | 固化到100%稳定执行 |

### 7.3 推的维度：按颗粒度、按难度、按范围

| 维度 | 从 → 到 | 说明 |
|---|---|---|
| **按颗粒度** | 从1个基本功开始 → 逐步细化 | 先练好一个，再扩展更多 |
| **按难度** | 先能力 → 再模块 → 再任务 | 从大到小逐步拆解 |
| **按范围** | 各级别自行向下拆解 | 公司级拆大块 → 业务线拆专项 → 个人拆具体 |

## 八、超级小抄：10个角度深度解读（Truman教学精华）

> Truman用了10个角度来解读这个武器库，帮助学员全面理解。

### 角度1：基本功的四大追求路线图

```text
创造类工作 ──专业化→ 专业类工作 ──领先化→ 领先类工作 ──标准化→ 标准类工作 ──SOP化→ SOP类工作

每个阶段的核心任务：
专业化：建池子 / 头脑风暴 / 攻坚会 / 找最佳实践 / 建审美 / 做分解
领先化：建模型 / 持续复盘升级
标准化：魔鬼细节建模 / 持续复制
SOP化：100%执行 / 监督执行 / 两层加锁
```

### 角度2：四关要闯的刻意练习循环

```text
拆（拆出关键）→ 建（建立模型）→ 推（推动共识）→ 练（大量重复）

这不是一次性走完的，而是循环往复、每一轮都在螺旋上升。
```

### 角度3：从模糊到具体的渐进光谱

```text
抽象 ←————————————————————————→ 具体

原则引导 ──→ 方法论框架 ──→ 清单画布 ──→ SOP固化

"把基本功从黑盒子变成透明盒子，从凭手感到100%执行"
```

### 角度4：从软到硬的推动杠杆

```text
软 ←————————————————————————→ 硬

有氛围 ──→ 有追求 ──→ 有练习 ──→ 有流程 ──→ 有制度

越往右越依赖组织能力，越需要前置条件的成熟
```

### 角度5：基本功化的本质不是做SOP

```text
执行SOP的核心目标：把这件事稳定做完
基本功化的核心目标：把一个工作单元转化成团队的刻意练习

同样写逐字稿：
- 普通执行：写完交差
- 基本功化：这次比上次在结构/金句/节奏上提升20%
```

### 角度6：循序渐进 > 一步到位

```text
现实路径：从1个关键基本功开始 → 从极少团队/成员开始 → 打出小胜仗 →
         积累氛围和信心 → 从1到N逐步扩展

强行推行的风险：工作量巨大、Leader素质不一、团队抵触、专家流失
```

### 角度7：选标杆基本功的ROI思维

```text
不要一口气推行10条基本功。先选1-2条：
- 最影响业务结果的
- 高频重复的
- 有成熟最佳实践可参照的
- 团队当前最容易接受的
```

### 角度8：一号位以身作则的不可替代性

```text
一号位不动，团队就不会真正动。
一号位亲自做、亲自示范、亲自复盘，
比100封全员邮件都有效。

反例：Leader自己从不写逐字稿，却要求团队"好好练" → 没人会当真
```

### 角度9：Flag驱动——20%迭代的力量

```text
不要追求一次从60分到90分。每次只追20%：
- 这一版比上一版在金句密度上提升20%
- 这次破冰比上次在参与率上提升20%
- 这周SOP执行比上周在完整度上提升20%

小胜仗积累信心，大目标吓退行动。
```

### 角度10：基本功的长期主义——耐住寂寞守住平凡

```text
"做别人做不到的事情，做别人看不上的事情。"

基本功的竞争壁垒在于：对手知道这个道理，但不愿意花时间。
你能坚持三年每天练逐字稿，你就拥有了别人无法短期追赶的能力。
```
