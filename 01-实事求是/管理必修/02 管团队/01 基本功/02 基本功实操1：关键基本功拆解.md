## 一、为什么要学——破题篇

### 1.1 大家拆基本功时的真实困境

> "回到自己业务中的时候，还是一坨，不知道如何下手。"

| 两类极端 | 表现 | 后果 |
|---|---|---|
| **拆得太少** | 从来没有认真拆过基本功，没有尝试分解高频重复的关键执行动作 | 人才培养不了，能力复制不了 |
| **拆得太多** | 一个业务环节拆出几十条基本功，列了"美好基本功清单" | 完全无法落地，执行团队接不住 |

### 1.2 线下训战营的惊人发现

> Truman 在 MBA 进阶营带大家实战练习时，出了一个题目，一动手发现：**95% 的同学竟然过去没有练过拆解基本功。**

| 常见翻车场景 | 具体表现 |
|---|---|
| **拆得过大** | "商业分析基本功""产品Sense基本功"——无法定义、无法落地练习 |
| **拆得过细** | 按流程拆出12环节/48要素/96基本功组/259个基本功动作——团队根本接不住 |
| **太难太许愿** | "定价基本功""赚钱基本功""上市基本功"——太难无法上手，太美好不是动作 |
| **太短太临时** | "中移动标书撰写基本功""马拉松招生基本功"——项目没了基本功也就没了 |

### 1.3 关键基本功的一句话本质理解

> **针对具体的工作场景，找到独立、可检验的动作，来实现不断重复练习，最终形成长期巨大复利。**

```text
六大关键词：具体 · 场景 · 独立 · 可检验 · 重复 · 复利
```

## 二、核心工具①：三环六维分析模型

> 这正是第一节课发布的核心判断工具。本节课将它升级为实操拆解的"过滤器"——任何拆出来的候选基本功，都要过这六道关卡。

### 2.1 三环全景图

```text
               足够务实（场景性 + 具体性）
                      ↑
                      |
    足够可练 ← —— 关键基本功 —— → 足够价值
  （独立性+检验性）              （重复性+复利性）
```

### 2.2 六维度详解（高频实操版）

| 维度 | 核心问题 | 正例 ✅ | 反例 ❌ |
|---|---|---|---|
| **场景性** | 服务真实工作场景吗？ | 写预热思考题（做课场景） | 练口才（场景太泛） |
| **具体性** | 可以建模和教学吗？ | 写逐字稿、记笔记、灵感闪现 | 提高表达能力（无法建模） |
| **独立性** | 是一连串完整动作，能独立交付吗？ | 开项目启动会（完整可交付） | "说话清晰"（不是一个完整动作单元） |
| **检验性** | 一动手就知道会不会、水平高不高？ | 画线框图、做BA对比 | "有产品感"（不可检验） |
| **重复性** | 可以大量重复、高频使用吗？ | 写逐字稿（每次做课都能练） | 一次性的特殊任务 |
| **复利性** | 持续进步对团队的长期价值大吗？ | 记笔记（知识资产复利） | 换灯泡（没有复利积累） |

### 2.3 六维分析的实战用法的三条铁律

| 铁律 | 说明 |
|---|---|
| **不要求六维满分** | 占越多越好，但不要求全部满足，按实际场景取舍 |
| **找三圈交集** | 足够务实 × 足够可练 × 足够价值 三圈交汇处 = 关键基本功 |
| **用六维做减法** | 当候选基本功太多时，用六维逐条过滤，砍掉得分低的 |

### 2.4 三个现场测试——培养你的审美

> Truman 在课上出了三个测试题，训练大家"用六维做判断"的直觉。

**测试一：一堂教研重点练的基本功**

| 候选基本功 | 是否关键？ | 判断逻辑 |
|---|---|---|
| 讲课 | ❌ | 太大太宽泛，不具体，不独立 |
| 夸讲师 | ❌ | 复利性不足，不是核心动作 |
| **记笔记** | ✅ | 具体、可检验、高频重复、复利极大 |
| 用一堂五步法 | ❌ | 太笼统 |
| 算单元模型 | ❌ | 频次不够，不是每人每次都要做 |
| **方法论建模** | ✅ | 独立动作、可检验、长期复利 |
| 写招生文案 | ❌ | 场景太窄，不是核心高频动作 |
| 画课程地图 | ❌ | 太阶段性、太临时 |

**测试二：连锁奶茶店店长重点练的基本功**

| 候选基本功 | 是否关键？ | 判断逻辑 |
|---|---|---|
| **品控** | ✅ | 具体可检验、每天重复、决定客户体验 |
| 团队管理 | ❌ | 太大太宽泛 |
| 销售能力 | ❌ | 太笼统 |
| **订货能力** | ✅ | 具体独立动作、每天做、直接影响成本和新鲜度 |
| **设备保养** | ✅ | 具体可检验、高频、不出事就是最大价值 |
| 运营管理 | ❌ | 太大太宽泛 |
| 沟通协调 | ❌ | 太模糊 |
| **客诉处理** | ✅ | 独立动作、可检验、高频重复、直接决定口碑 |

**测试三：一堂 1v1 销售重点练的基本功**

| 候选基本功 | 是否关键？ | 判断逻辑 |
|---|---|---|
| 沟通能力 | ❌ | 太大太宽泛 |
| 同理心 | ❌ | 不可检验、不可独立作为一个完整动作 |
| **用户分层** | ✅ | 具体、可检验、独立动作 |
| **需求挖掘** | ✅ | 独立、可检验、决定成交率的核心动作 |
| 建立人设 | ❌ | 太模糊 |
| 专家访谈 | ❌ | 场景不对（销售不是做访谈） |
| **讲香体系** | ✅ | 具体可建模、可检验、每次沟通必用 |
| **推荐课程** | ✅ | 独立完整动作、可检验、直接决定转化 |

### 2.5 一个好词 ≠ 一个好基本功

> **任何一个好词，套上"基本功"三个字，貌似都很打动人，都很香，都很有迷惑性。**
>
> — "沟通基本功、商业分析基本功、算账基本功、讲道理基本功、团队搭建基本功、销售基本功、下属辅导基本功、向上管理基本功、时间管理基本功……"
>
> **判断铁律：不要被名字迷惑，用六维模型过滤。**

## 三、核心工具②：四大拆解路径

> **基本功靠什么发现？有四个常见的剥离路径。**

| 拆解路径 | 方法 | 适用场景 | 优势 | 风险 |
|---|---|---|---|---|
| **靠框架拆** | Top-down：从工作流/业务模块/岗位角色/用户体验流程出发，梳理高频关键动作 | 业务流程清晰、已有成熟分工的团队 | 完备性强，不遗漏 | 容易大而全、拆出一大片 |
| **靠专家拆** | 萃取高手/师傅/销冠的隐性经验，把"说不清楚的绝活"变成可教的动作 | 团队有明确的高手和普通人的差异 | 抓住真正决定质量的关键 | 专家可能说不清楚、或不愿分享 |
| **靠外部拆** | 逆向工程：拆解同行/最佳实践的关键动作 | 有明确的行业标杆可以参照 | 跳出现有认知盲区 | 照搬可能水土不服 |
| **靠复盘拆** | 从复盘会/项目复盘中找反复出现的成功动作和失败动作 | 已经有一定项目经验的团队 | 来自真实经验，体感强 | 容易陷入具体案例，缺乏抽象 |

### 3.1 靠框架拆——实操方法

| 拆解维度 | 具体做法 | 一堂/同学案例 |
|---|---|---|
| **按工作流程** | 按工作环节一步步分析关键动作 | 同学：拆解"销售拜访流程"，找到7个潜在基本功 |
| **按岗位角色** | 按不同岗位、角色、工作模块分析 | 一堂：通过拆解复盘营业务模块，找到5个忽略的基本功 |
| **按用户体验** | 按用户体验推进顺序拆解我们的关键动作 | 同学：拆解客户成交过程，找到3个忽略的基本功 |

> **提醒：自上而下虽然完备，但容易大而全拆出一大片，导致难以练习。建议围绕三环六维 + 眼下目标，确定 Top 1-5 基本功。**

### 3.2 四大路径的使用顺序建议

```text
先靠复盘拆（有体感） → 再靠专家拆（有深度） → 再靠框架补（有完备性） → 按需靠外部对标（有突破）
```

## 四、最佳实践：美团的拆解体系

> **美团应该是国内大厂里，从理念到执行，"苦练基本功"的最佳实践标杆。**
>
> Truman 在课上分享了他离开美团后，专门调研和拜访了几位美团内部业务负责人的访谈体感。

### 4.1 美团的四层拆解金字塔

```text
              王兴（一号位理念）
                    ↓
         公司级专业委员会（统一大块拆解）
                    ↓
       各业务团队Leader（承上启下拆解）
                    ↓
    关键项目负责人（落地负责一线拆解）
                    ↓
  全体员工（自我管理和个人练习计划）
```

### 4.2 美团的三类基本功

| 类别 | 内容 | 负责方 |
|---|---|---|
| **通用基本功** | 写作、沟通、高效能人士的七个习惯 | 公司统一推行 |
| **管理基本功** | 管自己（时间管理）、管团队（选用育励汰+组织分工）、管业务（定目标→追过程→做复盘） | 管理者必修 |
| **专业基本功** | 技术、客服、设计、产品等各专业方向 | 专业委员会 + 业务Leader |

### 4.3 美团的落地案例——某业务线产品运营团队

| 层级 | 基本功内容 |
|---|---|
| **公司通用层** | 写作、沟通等通用基本功继续保留 |
| **业务增加层** | NCAPE 各环节基本功（新签、信息、库存、价格、附加值服务） |
| **管理增加层** | 价值观底线（不犯错误为底线）、SOP（设立行为中位线）、团队建设（树立标杆为高线） |
| **子团队层** | 各职能梳理基本功 Top3，明确负责人 + 衡量/评价标准 |

### 4.4 美团基本功运用的评价标准（行为锚定法）

| 运用等级 | 典型行为 |
|---|---|
| **熟练运用** | 持续关注并提炼工作中反复使用的基本技能；即使处于巅峰状态仍要求自己和团队刻意练习；以身作则，领导他人共同练习；构建有效机制，长期提升团队结果 |
| **过度运用** | 影响正常工作的时间分配；忽略需要达成的目标；追求大而全的基本功清单；把时间花在与本职工作无关的基本功练习上 |
| **运用不足** | 只看重新奇知识技能，看轻基础技能；认为基本功只是对初学者的要求；当基本功出问题时不花时间练习；管理者不建机制，只在出问题时才提要求；只提苦练要求，不为团队提供支持和反馈 |

> **核心启发：美团的体系告诉我们，基本功拆解不是一次性工程，而是从公司一号位逐层向下拆、逐层细化、逐层负责的长期建设。**

## 五、基本功的演化：拆解落地最佳路径图

> **核心原则：不见兔子不撒鹰（ROI 思维）——随着认知和价值逐步增加，逐步细化和加重投入，一步步完成基本功的演化。**

### 5.1 基本功能否升级的五个"质变信号"

| 质变信号 | 含义 | 触发下一步动作 |
|---|---|---|
| **稳定重复** | 发现某个动作被反复做，而且每次做法和结果有规律 | 值得被"拆出来命名" |
| **必经之路** | 发现某个动作是绕不开的关键环节，做不好就整体失败 | 值得被"模型化" |
| **认知成熟** | 对某个动作的理解已足够清晰，可以写出来教给别人 | 值得被"文档化标准化" |
| **分层矛盾** | 老手觉得太简单、新手觉得太难 | 需要做"段位阶梯化" |
| **组织扩大** | 团队人数增加，口头传帮带不够用了 | 需要进入"制度化" |

### 5.2 六大阶段演化路径

```text
A. 模糊管理 → B. 拆关键 → C. 起名字 → D. 模型化 → E. 阶梯化 → F. 制度化
```

| 阶段 | 核心工作 | 可用工具 | 状态说明 |
|---|---|---|---|
| **A. 模糊管理** | 大而全、模糊一片 | —— | 初始状态，还没开始拆 |
| **B. 拆关键** | 加法（靠框架/靠专家/靠同行/靠复盘）→ 减法（业务当前目标 + 三环六维过滤） | 四大拆解路径 + 三环六维模型 | 从模糊到聚焦，找出关键基本功 |
| **C. 起名字** | 宽而不泛、简单朗朗上口、有差异化、善用动词 | 命名技巧 | 让团队能挂在嘴边、记住、传播 |
| **D. 模型化** | 本质/方法论 + 清单/画布 + SOP/配套检查 | N步法、清单、SOP、画布、Case | 可执行、可检查、可教学 |
| **E. 阶梯化** | 以身作则 + 标杆用户 + 阶段拆L6 + 岗位拆SABC | 段位图、进阶路线 | 让每人都有适合自己的练习目标 |
| **F. 制度化** | 苦练基本功文化建设 + 配套知识库 + 培训练习 + 新人Landing + 绩效/职级/晋升绑定 | 考核体系、晋升体系、培训体系 | 从"提倡"变成"要求" |

### 5.3 一堂教研基本功的真实演化过程（案例还原）

```text
阶段一：模糊管理
  "我们要做好教研"——只有理念，没有抓手

阶段二：拆关键
  用四大路径拆解出"记笔记"和"方法论建模"两个关键基本功

阶段三：起名字
  "记笔记" "方法论建模"——简洁、朗朗上口、动词驱动

阶段四：模型化
  记笔记 → 怎么记、记什么、格式标准、好/坏 Case
  方法论建模 → 建模N步法 + 清单 + 评审标准

阶段五：阶梯化
  记笔记段位：
    入门（清晰记录：顶层清晰，信息全面，容易阅读）
    进阶（逻辑清晰：结构MECE，舒服分点，逻辑&视觉对齐）
    高阶（实时重构：边挖边记，全面组装，持续重构）
  训练周期：入门周级 → 进阶月级 → 高阶年级

阶段六：制度化
  新人Landing练记笔记 → 日常例会检查 → 教研评审标准绑定 → 知识库沉淀
```

## 六、基本功演化的两个模式

### 6.1 两种模式对比

| 模式 | 路径 | 优势 | 风险 |
|---|---|---|---|
| **自下而上** | 先练素质 → 再搭架构。先让团队在一个具体基本功上练出体感 → 再扩展到更多 → 再形成体系 | 体感扎实，不空洞 | 可能偏科，缺乏全局 |
| **自上而下** | 先搭架构 → 再填内容。先规划好团队需要哪些基本功体系 → 再逐步拆解每个 → 再落地练习 | 全局清晰，不遗漏 | 可能脱离实际，落地困难 |

### 6.2 Truman 的关键建议

> **"先从下往上练素质，再从上往下搭架构。"**

| 两条铁律 | 说明 |
|---|---|
| **不要过早细化未经验证的基本功** | 还没练过、还没确认是否真的有效的，不要花大精力建模 |
| **不要过早推行未经思考的基本功** | 还没想清楚六维得分、还没拆到可练颗粒度的，不要硬推给团队 |

## 七、阶梯化实操：给一个基本功画段位图

> **新人总觉得太大太难，老人总觉得太简单——往往就是因为没分层。**

### 7.1 为什么要做段位划分

```text
如果没有段位：
  - 新人面对"高阶标准" → 觉得太难，放弃
  - 老人面对"基础标准" → 觉得太简单，不屑
  - 管理者面对"一刀切" → 推不动

有了段位：
  - 新人知道自己该练到什么程度（入门）
  - 进阶者知道下一个台阶在哪里（进阶）
  - 高手知道自己还有空间（高阶）
  - 管理者可以精准匹配练习任务
```

### 7.2 一堂逐字稿基本功段位（示例）

| 段位 | 标准 | 训练周期 |
|---|---|---|
| **入门** | 结构完整，逻辑通顺，没有明显跳跃 | 周级 |
| **进阶** | 长短节奏有设计，重点突出，有情绪起伏 | 月级 |
| **高阶** | 金句密度高，故事感强，能引发强烈共鸣 | 年级 |

### 7.3 一堂记笔记基本功段位（示例）

| 段位 | 标准 | 训练周期 |
|---|---|---|
| **入门** | 清晰记录：顶层清晰，信息全面，容易阅读 | 周 |
| **进阶** | 逻辑清晰：结构MECE，舒服分点，逻辑&视觉对齐 | 月 |
| **高阶** | 实时重构：边挖边记，全面组装，持续重构 | 年 |

### 7.4 段位划分的三种表达方式

| 方式 | 适用场景 |
|---|---|
| 入门/进阶/高阶 | 适合大多数基本功，简洁清晰 |
| 60分/70分/85分 | 适合有明确质量标准的场景 |
| L1-L6 | 适合需要精准管理、长期追踪的团队 |

> **核心洞察：当你给一个工作画完段位以后，整个团队的状态就很不一样了——从"我很差/我很牛"的二元评价，变成"我在哪个段位、下一段需要什么"的成长心态。**

### 7.5 一个岗位的能力进阶段位（以销售框架为例）

> 大量同学拆分过岗位的不同段位。以年为单位，给出一个可以奋斗 3-5 年、可预见的能力进阶段位。

```text
销售岗位段位示例（一堂内部框架 1.0→4.0 演化）：
  L1 能执行：按话术完成标准销售流程
  L2 能调整：根据用户反应调整话术和节奏
  L3 能分层：主动判断用户类型，选择不同策略
  L4 能建模：提炼自己的方法论，可教给新人
  L5 能迭代：持续升级销售模型，推动团队整体升级
```

## 八、基本功的颗粒度阶梯

> **同一个能力，在不同颗粒度层级上都可以叫"xx基本功"。关键是找到六维度交集最大的那个层级。**

### 8.1 颗粒度向下拆解示例

```text
做课能力                          ← 太大，无法直接练习
  → 写作能力                      ← 还是偏大
    → 写逐字稿能力                ← 接近可练
      → 写预热思考题能力          ← 具体、独立、可检验 ✅

销售能力                          ← 太大
  → 1v1电话销售能力               ← 还是偏大
    → 开场白基本功                 ← 接近可练
      → 开场一句话打招呼           ← 具体、独立、可检验 ✅

讲课能力                          ← 太大
  → 表达能力                      ← 太模糊
    → 公开讲课能力                ← 还是偏大
      → 讲香课程能力              ← 接近可练
        → 提问互动能力            ← 具体、独立、可检验 ✅
```

### 8.2 颗粒度选择铁律

```text
在哪一个层级上，六维度的交集最大、最均衡，那个层级就是当前阶段最该练的基本功。

- 太往上 → 违背具体性和独立性
- 太往下 → 违背独立性和复利性
- 找金三角交汇处 → 关键基本功
```

## 九、基本功演化的完整要素清单（一个成熟基本功长什么样）

> **绝大多数基本功都是从初步想法（假设），一步步补全、从残缺到完整，最后升级为全面的。**

| 要素 | 含义 | 示例（以"十层解读"为例） |
|---|---|---|
| **1. 名字** | 有一个明确的、独一无二的名字 | "十层解读" |
| **2. 场景** | 明确哪些场景需要使用这个基本功 | 做课时需要深入解读一个核心概念/Y模型 |
| **3. 原则方法** | 基本功的模型或指导原则 | 挑战用10个不同角度解读同一个东西 |
| **4. Case** | 参考案例（正面/负面），帮助理解好与坏 | Truman用10个角度解读Y模型的案例 |
| **5. 配套练习** | 有哪些课程/材料/机会可以练习 | 教研做课时每次都可以用；新人Landing训练任务 |

## 十、Truman 的管理进阶：一堂自己的基本功进化史

> Truman 把一堂的基本功建设分成五个阶段，这是课程里最宝贵的"一手实战还原"。

| 阶段 | 管理状态 | 标志性事件 |
|---|---|---|
| **第一阶段** | 个人刻意练习（2015-2016） | 接触《刻意练习》，自己练写作、用户场景分析、讲课、标题、产品设计、ROI讲道理。一年成长超过过去三年，"竟然有人开始觉得我是文案高手、讲课高手、产品高手了" |
| **第二阶段** | 手把手带人（2019年后） | 团队超15人，按传统方式"我做你看，我说你听，你做我看，你说我听"带人。**"远远低于预期，成长速度太慢了。一遍又一遍，进步很小。"** |
| **第三阶段** | 觉醒：拆出基本功 | 开始把"模糊能力"拆成"可练的基本功"。如做课能力拆成逐字稿、记笔记、全网调研等。**"基本功不是能力，而是能力背后可以被反复练习的具体动作。"** |
| **第四阶段** | 全面基本功化（2023秋） | 年度大课后推动全员基本功化：教研、班班、销售、增长、产品交付团队全部参与。**"公司知识库越来越厚，雷达图、N步法、SOP、模板清单数量远超过去3年总和。"** |
| **第五阶段** | 持续细化与升级 | 基本功不断拆分细化：专家访谈1拆3；全网调研1拆2；故事线设计1拆3。**"基本功不是一蹴而就的，而是一步步从模糊到具体，从混乱到一致，从空壳到完整。"** |

## 十二、L6 刻意练习自检清单

### 拆解前——你是否具备了解题意识

- [ ] 你是否有意识从日常工作中剥离那些高频重复的关键动作（而不只是"把活干完"）？
- [ ] 你是否理解"拆得太多"和"拆得太少"都是问题，关键是找到六维度交集最大的颗粒度？
- [ ] 你是否在用三环六维模型做减法，而不是看着一堆候选基本功无从下手？

### 拆解中——四大路径是否被充分使用

- [ ] 你是否尝试过至少两种拆解路径（框架拆 + 专家拆 / 复盘拆 + 外部拆）进行交叉验证？
- [ ] 如果用"靠框架拆"，是否选择了合适的拆解维度（工作流程 / 岗位角色 / 用户体验）？
- [ ] 如果用"靠专家拆"，是否找到了真正的高手、并成功萃取了TA说不清楚的隐性经验？
- [ ] 如果用"靠复盘拆"，是否从真实项目中发现了反复出现的成功动作和失败动作？
- [ ] 如果用"靠外部拆"，是否有明确的行业标杆做逆向工程，而不是凭空想象？

### 拆解后——你的候选基本功是否值得练

- [ ] 每个候选基本功是否用六维度逐条打过分（场景性/具体性/独立性/检验性/重复性/复利性）？
- [ ] 你拆出的关键基本功是否在"足够务实 × 足够可练 × 足够价值"三圈交汇处？
- [ ] 颗粒度是否恰当——既不过大导致无法建模，也不过小导致失去独立性？
- [ ] 你是否给它起了一个明确、独一无二、朗朗上口、善用动词的名字？

### 建模——是否有可执行的标准

- [ ] 每个关键基本功是否有明确的原则方法（N步法/清单/画布/公式/框架）？
- [ ] 是否有正面和负面 Case 作为参考标杆？
- [ ] 是否可以被一个不了解背景的新人看懂并开始尝试执行？
- [ ] 配套的练习材料和机会是否已经准备好？

### 阶梯化——是否让每个人都能找到位置

- [ ] 这个基本功是否划分了段位（入门/进阶/高阶 或 L1-L6）？
- [ ] 每个段位是否有清晰的升级标准（而非模糊描述）？
- [ ] 新人是否知道自己该练到什么程度，老人是否看到自己继续进步的空间？
- [ ] 进阶周期是否合理（入门周级 → 进阶月级 → 高阶年级）？

### 演化——你是否把握了节奏

- [ ] 你是否按"不见兔子不撒鹰"原则，随着认知和价值逐步增加才逐步加重投入？
- [ ] 你是否避免了"过早细化未经验证的基本功"和"过早推行未经思考的基本功"？
- [ ] 你是否出现了质变信号（稳定重复 / 必经之路 / 认知成熟 / 分层矛盾 / 组织扩大），并据此推动了下一阶段演化？
- [ ] 你的基本功建设更接近"自下而上先练素质"还是"自上而下先搭架构"？节奏是否匹配当前阶段？

- [ ] 你能说出你们团队当前最重要的 3 个关键基本功吗？每个的六维度分别打几分？
