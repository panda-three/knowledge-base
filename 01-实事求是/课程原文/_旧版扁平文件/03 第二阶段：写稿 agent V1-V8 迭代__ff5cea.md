# 截图04 第二阶段：从手工作坊，到写稿 agent1.0

当时我们用的平台是 WorkBuddy，所以我做的第一版，就是在WB上封装了一个小红书内容转译专家agent。

（界面：WorkBuddy 上「内容转译专家」agent 卡片，标签"小红书爆款改写""一堂内容转译"，描述：把小红书爆款转为创业者内容，保留70%爆款框架+30%一堂方法论，站在创始人视角改写。）

它最开始的目标特别简单：解放我！让小伙伴可以模拟我，把爆款改写成一篇在我的评审线上看得过去的内容。

我先口喷了一段提示词，大概是他是谁，擅长什么，名字叫什么，他的工作流程，我会提供的多种语料素材......然后围绕双三角的6个角又经历了8轮迭代。

（界面：8 张双三角画布缩略图 V1-V8 的迭代记录）

后来小伙伴给我的反馈特别直接：**你这个 agent 太好用了。**

（界面：会议文字记录截图，小伙伴说"其实我用起来感觉特别丝滑"；后续对话"我就觉得他，嗯，特别提高我的效率""这给我一点点信心和笃定的是，因为我之前确实"）

## 对她的帮助：第一层是审美

对她的帮助有两层：

**第一层是审美。**

- 以前她看爆款，只知道这篇好像挺火。
- 现在通过 agent 一步一步引导，她知道要拆什么：标题、结构、用户画像、评论区关注点、What/Why/How、爆款原因，以及它和一堂到底能不能接上。

这个 agent 对小伙伴的价值，不只是"帮她写快一点"，而是每一篇都在带她刻意练习。

比如它会一遍遍引导她看：

- 评论区怎么说？
- 用户高频关键词是什么？
- 用户画像是谁？
- 他在什么具体场景下遇到了什么问题？
- 这篇爆款到底为什么能打动人？

把思考方式装到小伙伴的脑子里，形成肌肉记忆。

## 第二层是提效

**第二层是提效。**

- 以前她看到一个标题，要想很久这个能不能写。
- 后来她看多了，练多了，开始有敏感性，看到标题就能快速识别：这个是 What 型，还是 Why 型，还是 How 型；这个选题只是爆，还是既爆又和一堂有关。

这就是从"靠我讲"变成"她自己开始有判断"的第一步。

写作时间也开始明显下降。从一开始一篇7到8个小时，后来大概能压到3个小时左右。

这个阶段只是接入AI的第一步。但对我们来说，已经是不小进步了。

以前是她死熬，我死讲。

现在至少变成：她知道要跟着什么流程走，知道哪里要问点点，知道怎么拆爆款，知道哪个架构要替换一堂解法。

所以这个阶段，我的双三角画布第一次真的开始动起来。

- 在人的能力这一侧，我把自己的审美、体系、创造力，从脑子里挖出来了。
- AI能力这一侧，WorkBuddy 不再只是一个试试的AI工具，开始变成我们工作的得力助手。

但是，做到这里，新的问题又出现了。
