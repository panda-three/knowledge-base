# 04 实操：双三角的六大落地场景（概述 + 入门 + 进阶 + 高阶）

## 实操概述：一个引擎，三阶六变

- 第二部分讲完，我们来讲第三部分实操。
- 如果它是一个科学的因果关系内核，一堂双三角能用在哪些重要的工作场景呢？
- 【提问🤔】大家觉得，双三角在哪些场景下特别有用？
- 通用场景，比如员工培训，而不是文生图，写小说这种具体工作类型。
- 看看几百上千个同学加一起，能不能把这些高价值场景凑齐。
- 从入门到进阶，我们做了一次大的复盘，发现有六大高价值场景。
- 这个发动机转上去，AI的迭代和进步会全面提速。
- 【划重点💡】哈哈为了方便大家理解，我分别写了一个形象的比喻：
  - 入门基础：X光（拆解用），心法（口喷用）
  - 进阶使用：画布（筹备用），拼图（分工用）
  - 高阶修炼：地图（训练用），底牌（战略用）
- 这是一个有六种变化的AI驱动引擎：
- 一堂双三角：一个引擎，三阶六变
  - 同一个科学内核，装进不同项目与难题
  - 双三角引擎 → 驱动
  - 高阶修炼：地图|训练用，底牌|战略用
  - 进阶使用：画布|筹备用，拼图|分工用
  - 入门基础：X光|拆解用，心法|口喷用
  - 逐级升级
- 时间有限，我快速带大家理解一下这六种高价值的场景。
- 你们感受一下，是不是能体会到，每一周双三角都更值钱了hhh。

## 入门场景：基础使用

我们先来看两个高频的入门场景，不难，但是这两个场景是大家完成知行合一的行动开始关键。

### 1）拆解用：X光

- 第一个是最基础的用法，就是发现一个"很优秀""很有竞争力""很想学"的AI落地结果的时候，大家平时会如何条件反射的思考？
- 学之前，我们先来做一个测试：
- 来，做一个"条件反射"测试
- 敲黑板，说重点
- 【思考1🤔】一堂有哪些小的AI工具大家觉得很不错，比如某个Partner、某个AI小工具，某个场景，你如果要是能学会就太好了。
- 【思考2🤔】如果你们想学，花1天-1周复刻，你们条件反射会想怎么学习？
- 【划重点💡】你们过去，习惯性会如何理解和学习？
  1. 入门：它用了什么AI工具？
  2. 进阶：它用了什么工作流组合？
  3. 科学：它背后的双三角是如何支撑的？
- 大家都说自己心里"认可双三角"，如果没有条件反射选【3】就是在手上还没有真正入门。
- 我曾经拆解过一堂的一些双三角：
  - 一堂：人生红点教练Partner探索（案例背后的AI核心策略和稀缺竞争力）
  - 一堂：作业洞察和特别表白（案例背后的AI核心策略和稀缺竞争力）
  - 一堂：龙虾训练"灵魂赋能"实验（案例背后的AI核心策略和稀缺竞争力）
  - 一堂：教育新官网制作（案例背后的AI核心策略和稀缺竞争力）
- 我们在马拉松拆解了大量的双三角：
- 很多时候，我们难以做到复刻，往往不是卡在AI技术和基本功，大概率是数据、审美，甚至我越来越发现，卡住我们难以做到的往往是工作流和体系。
- 除了拆别人，对于自己这个技能同样好用：
- 自己的优秀表现，也用双三角拆一下（这是一个值得培养的好习惯）
- 当我们做完了一个任务（Codex、YAI、OpenClaw）你直接让他扫描一下全文，然后给你基于双三角写一份入盘报告，比如这是我做的一个"AI高阶建模示范"，最后随口喷的提示词：
  - 提示词：非常不错，你感觉咱们的工作质量怎么样？你去学一下一堂AI双三角，这个模型是用来解读人和AI高水平协作的框架。你去研究一下这个模型，然后帮我还原一下刚才咱们所有的工作过程，你做了什么，我做了什么，以及咱们两个是如何互补的。帮我尝试做一次大的复盘和整理，以及如果没有人，AI会怎么样？如果没有AI人会怎么样？为什么人乘以AI在双三角下会有如此巨大的产出，以及这个可以作为一个案例包作为全部的复盘。然后同时如果未来我给团队教学，这是一个很棒的AI双三角教学材料，帮我做一个完整的复盘吧。注意是总分，总的结构。
- 然后YAI做了一份复盘报告。
- 提醒：用YAI你可以直接让他自学知识库，然后干活儿；如果是其它Agent，你需要自己准备双三角的数据包DataPack or 技能Skill。

### 2）口喷用：心法

- 入门阶段的第二种用法，光"学习不够"，我选了一个"解决问题"的场景。这个场景比较有趣了，这是一个我最近反复强调、反复带大家练的基本功。
- 口喷是什么意思呢？简单说，就是直接语音输入，用类似于人类讨论的方式，直接用嘴来打字，调用AI来干活。
- 哈哈，大家有在一些场合发现我展现我的"口喷基本功"么？感受到我一直在刻意练习么？第一次听我完整口喷长提示词，感受如何hh。
- 【口喷🤣】现做一个调研吧：大家和AI协作，口喷的比例如何？
  1. 基本没习惯，打字为主
  2. 偶尔试试，使用很少
  3. 多数口喷，占比很高
  4. 基本口喷，每天几十几十百次口喷
- 在线下AI训练营，我们画过一个图：
- 打字是在写指令，口喷是在带团队
- 关键不是写还是说，而是你有没有把AI需要的上下文补够。

**常规写提示词 vs 口喷提示词**

| | 常规写提示词 | 口喷提示词 |
|---|---|---|
| 优点 | 结构清楚、便于保存、容易复用、适合模板 | 速度快3-10倍、符合直觉、边说边补、上下文更足 |
| 代价 | 输入慢、容易太短、容易抽象、容易漏背景 | 容易发散、容易啰嗦、结构不稳、需要先有框架 |
| 适合 | 短任务、稳定任务、标准任务、可封装任务 | 复杂项目、多轮协作、临场任务、快速交代上下文 |

- 常规写提示词：先想清楚再写下来（结构、标准、可复用）；口喷提示词：先说出来再一起完善（边说边想边补充）
- 口喷的框架示例：目标（我要的结果是...）、边界（不需要的内容是...）、背景（项目当前情况是...）、标准（好坏的标准是...）、数据（参考这些数据...）、纠偏（如果偏了，往...方向调）、节奏（先...再...最后...）
- 写提示词强在结构和复用：适合标准化、可沉淀、可规模化的任务
- 口喷提示词强在速度、直觉和上下文密度：适合复杂、动态、需要快速对齐的任务
- 高手都两手抓，用对场景，效果翻倍!
- 这不是今天的重点，口喷的刻意练习、工作和动作要领我先不讲，我只想回答一个问题：喷的本质是什么？
- 有人说口喷的本质是结构化提示词、是数据、是上下文、是给限制，这些都不本质。
- 那本质是什么？
- 其实我在线下讲过一句话：
- 口喷的本质，就是用嘴快速凑齐双三角
- 敲黑板，说重点
- 喷出你的审美，喷出你的体系和节奏感，喷出你的数据，喷出你的技术特性，然后让AI在更高水准的双三角工作，整个工作的表现就会全面提升。
- 哈哈，我们画过一个示意图（双三角 + 口喷提示词 + 九字诀）。
- 一句话：双三角是内功，九字诀是外功，口喷提示词是动作。
- 九字诀：定目标，控节奏，做纠偏。
- 哈哈哈，为了试图证明我会，我给你们演示一个Demo吧，你们挑一个例子：
  1. 帮我写一封Top水准的信（比如新版本Y30扉页）
  2. 做一个课程的Top插图（Codex文生图）
  3. 帮我配置一个Top个人助理（龙虾/Hermes角色文档）。
- 只能喷一段，争取一次性喷干净，感受一下背后的刻意练习。
- （演示提示词：我是在线教育公司的CEO，希望做一个AI CEO助理来全面支撑我的工作。如果你不了解我和"一堂"，请去我们的代码库系统地认识一下我和一堂的背景；同时，帮我去obsidian里看一下关于角色配置的最佳实践，进行系统学习。然后，请帮我设计一个OpenClaw的角色配置文档，一共5~7个角色。我对这些角色的美好想象是，它们主要的工作内容有以下三点：
  1. 记录灵感与想法：我平时有任何灵感想法，可以随时抛给它，它帮我记录，并按照一定的规则进行分类，随时能帮我整理出一份完整的清单。
  2. 定期汇报与事项提醒：它需要定期帮我汇报这些清单的变化，并实时帮我记着关键事项。
  3. 专题研究：如果我需要学习一些专题，或者有一些感兴趣的课题，我会随手扔给它，由它帮我做一些专题研究。
  - 寻找与定义助理特质：
    (a) 学习方法与最佳实践：关于这些学习的方法，你可以去知识库里学一下对应的方法和最佳实践的原则，自己去做一次扫描。
    (b) 全网摸查与研究报告：我过去没有人类助理，你去帮我全网扫一扫。对于一两百人量级的在线教育公司，CEO助理有哪些审美和特质？把他们的沟通方法、思考原则和习惯做一次全网的摸查，然后给我写一篇研究报告。
    (c) 理想助理画像：我对于这个助理美好的想象是：她可能是一个28岁、北大经济学和心理学双修的硕士女生。
    (1) 对人：跟人协作时情商极高，很容易给别人提供情绪价值，大家很愿意跟她说话，她可以自带温度。
    (2) 对事：面对事儿的时候非常理性，不会有情绪。每次讨论事儿的时候非常理性客观，有非常强的RY思维。
    (d) 补充RY方法论：如果对RY这个方法论不熟的话，你帮我去我们的课程体系里抽离一下，什么叫做"科学决策"和"讲道理"的理念，帮我打一个数据包。
  - 生产过程设想：变过来整个的生产过程，我初步的设想是分成四个大的里程碑：
    第一个里程碑，你先不要做任何的动手，帮我把刚才所有的工作写一篇工作计划，然后帮我去做一次预演，给我写一篇执行文档。
    第二个，给我搜集信息啊，给我全面的去把我需要的一些内容一篇一篇的整理成文档。
    第三个，完成初稿，你试着把我刚才说的这些信息拼成一个最佳实践的文档。
    第四个，把所有的这些东西最终做一个MVP的测试啊，通过做大概5~10个小的测试任务来评估你的工作质量，最终来完成发布和交付）
- 最后我想讲一个有趣的"理念"，我在一堂内部教练、NPC、主理人培训的时候，我讲过一个有趣的概念：
- 每周双三角指数：口喷次数 × 双三角框架 = 学习速度
  - （图：AI新范式 / 刻意练习 / 打破边界 / 探索新可能 / 刻意投入 / 持续精进 / 复利成长）
- 未来1年，这个指数会决定一堂同学们进步的代际差。
- 而口喷提示词，就是刻意练习这个最小、最高频的工具。
  - 定义：内心装着双三角，用口喷的方式和AI协作。
  - 动作要领：定目标，控节奏，做纠偏。
  - 刻意练习：①目标 ②套路 ③非舒适区 ④大量重复 ⑤反馈
  - 预期：每个月练习1000遍口喷提示词。
- 期待：每次线下练习大家都很High，或许口喷提示词再酝酿一段时间，可以做成一节类似于《清单体笔记》《逐字稿》的必修课，大家可以期待一下。
- 好啦，双三角的两个场景（认知-拆解，心法-口喷）我就讲完了，还挺扎实的嗯嗯嗯。

## 进阶使用：专业解题

- 下面进入进阶阶段：面对一个AI难的项目和工程，如何来全面修炼和解题。
- 我们分成两部分来讲：事 和 人。

### 3）筹备用：画布

- 其实在一堂内部，双三角最大的一个价值，就是用来"梳理和筹备"：遇到一个难题，先别怕，先试着凑一遍双三角，看看能有多少认知，多少牌能出，只要有牌，就不怕。
- 我们曾经提炼过一个简单的AI落地五步曲：
  - 01 定场景：充分加法，专业减法。
  - 02 做计划：定义一页纸，拆节点，准备数据，定义出口
  - 03 快验证：验证核心关键假设，MVP，小步快跑。
  - 04 工程化：产品化&技术化，稳定交付，系统化
  - 05 做迭代：稳定部署，收集反馈Case，数据循环，拥抱变化。
- 其中第二步做计划，就是在真正动手以前，提前准备素材，节点，工作流，数据，测试集等等。
- 在之前的工作和课程上，我们讲过各种版本：一页纸啊，雷达图啊，工作流啊。各个老师各个课程都不一样，大家混乱，我们也很难沉淀。
- 后来在一次磨课时候，花总突然说了一句：准备的本质，不就是你们的双三角么？
- 有点尴尬，但很有道理啊。
- 归根结底，不就是提前凑一凑双三角，做做计划，准备一下么？
- 后来我们逐步养成习惯，自己内部工作，先梳理和讨论双三角：
  - 双三角预判画布示例（AI教练辅导）：
    - 人类三角：审美❤️（1. Truman美好想象 2. 优秀的教练辅导过程 3. 课上的ROI最佳实践案例）；体系❤️（1. 工作流：辅导工作流 #难 2. ROI模型：投入产出分析 3. 科学决策三角形：深度高度宽度 4. 决策深度：简单定性，区间定量，定量公式）；创造力（1. AI先理解，后提问）
    - AI三角：场景（1. 个人场景 2. 业务场景 3. 公司场景）；数据❤️（1. 理想案例推演（流程具体化）2. 课程方法论Datapack 3. 沟通话术Datapack 4. 停车场模型Datapack 5. todolist+Not todolist）；基本功（1. 提示词 2. Agent多轮打磨）

  12 1．完整思考过程：识别任务、拆解六要素、判断哪里模糊、决定优先补什么；
  13 2．实际填写画布：把思考结果落到一张可复用、可复盘的双三角画布上。
  15 请你先帮我确认这个练习能力的范围是否合适，并带我开始第一次关于「填双三角画布」的刻意练习。
  17 注意：「一堂双三角」是一堂的核心方法论，后续内容需要优先调用「一堂知识库」的内容。
- （C Partner校准示范：把「填写画布」校准为「AI协作双三角前置结构化与偏差诊断」——在每次AI协作启动时，能识别任务场景类型，主动完成双三角六要素的结构化思考与填写，产出高质量协作前置输入；当AI交付质量不足时，能快速识别哪个要素缺失导致了偏差，并针对性优化前置输入，并在结果复盘时反向优化要素缺口。）

### 6）战略用：底牌

- 最后一个用法，估计有些同学会困扰了。
- 在大家眼里，如果我说"一堂双三角"是一个AI战略层的问题，大家信么？
- 哈哈，如果是半年前，我自己也不太相信。
- 不过经过这半年的实践，我已经比较笃定了。
- 最近我做了一张还挺喜欢的插画示意图：
- 灵魂拷问：面对未来3-10年的重要管理、创业与决策课题，你是想继续积累零散经验，还是长出一棵属于自己的决策树？
  - 零散经验（碎片直觉、机会、红利、运气）：时灵时不灵、难以复制、长期不稳定
  - 决策树（愿景与目标、核心原则、决策框架、关键维度、底层能力 → 决策系统、主干、分层、可复盘、长期主义；学习、思考、复盘、执行）：系统成长、可复制、持续进化
- 大家一堂学了挺久了，这张图你们足够笃定了么？
- 我最近最兴奋的，大概率就是十个八年，一堂双三角或许是唯一对于一堂，能够达到"一堂五步法"级别的操作系统了。
- 第一个五年计划，我把"商业战略"构建在一堂五步法上
  - 我不知道你们的感觉啊，你们能感觉到一堂对于一堂五步法极度笃定么？我们的每个阶段的决策，渠道选择，定价，项目取舍，品牌优化，都会归到一堂五步法层面完成一次思考和自洽。
  - 每年几十次试错、迭代，就在一个模型上不断思考、修正、优化，现在的一堂五步法，已经变成一种肌肉记忆，靠着直觉都能决策得还不错了。
  - 一堂坚定的用一堂五步法，并且持续取得成果，这几乎是我们早期最重要的战略选择。
- 如果新的五年计划，我把"AI战略"构建在一堂双三角上呢
- 未来5年，我把一堂的AI核心竞争力开始构建在双三角上，今年初，我给自己定了一个目标：
  - 2026年，我要刻意练习100次双三角的构建。（课程Partner，VibeCoding，小设计，方案打磨）
  - 上个月，我又给自己定了一个小目标：争取每一天，脑子装着双三角，每个月口喷1000次。（YAI、Codex、ClaudeCode、龙虾/爱马仕社团）
- 如果我们能联合上百个AI专家一起研究双三角的各个细节规律，如果我们有了上千个大家开源的AI真实双三角落地案例，如果我们有上百个AI落地专家（FDE），会不会一堂"推动科学"的使命会大幅加速呢？
- AI这是个持久战，不是大公司一定会战胜小公司，不是资源多的公司一定会战胜小公司，但是我相信，在正确的方向，迭代速度最快、复利积累最快的团队，一定会战胜那些碎片、迭代缓慢的团队。
- 历史上已经无数次证明过这个逻辑了。
- 希望一堂下一个新的五年，就从这个笃定的框架开始。
- 最后我想感慨一句，既然这个叫战略，叫底牌，作为一节有开山属性、有江湖地位的必修课，我想稍微拔高一点点。
- 一年前我带着大家拆《毛选》，拆《论持久战》对我启发巨大，我深刻体会到一句话：
- 真正顶级的战略追求，是开放的阳谋
- 不靠阴谋诡计，不靠外部运气，不靠某一个人的才华和英雄主义，而是基于底层辩证法的正确道路，然后用一往无前的勇气和执行力，终将走向胜利。
- 竟然最近双三角给了我类似的笃定感：这不是需要藏着的Knowhow和商业秘密，这不是需要藏着的信息差，从方法论到工具，从案例到一堂实践全部开源。
- 我相信的是，一堂比同行们更笃定，迭代的更频繁，复利积累地更快。
- 我猜有人可能会问，你的同行/对手全知道了学会了怎么办？就像很多人看《论持久战》也有经验，如果敌人也拿到了学会了怎么办？
- 是啊，怎么办呢？
- 那他们哪是对手啊，那是同志，我们不就是一类人么。
