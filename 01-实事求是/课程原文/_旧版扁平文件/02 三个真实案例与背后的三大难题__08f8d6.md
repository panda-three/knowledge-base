# 截图03 案例1：城市出圈海报

大家普遍都不会"系统式调研"。

【思考】在介绍这套方法之前，我想先问大家一个问题：你有没有遇到过这种情况，派出去一个同事做调研，或者自己去调研，拿回来一大堆信息，但最后发现，对真正要做的那个决策，帮助几乎为零？

我见过太多这种情况了。来，我先给大家举几个真实的例子，有体感之后，我们再来分析背后的原因。

第一个例子：大家还记得去年秋季马拉松，我们出过一组很好看的城市出圈海报吗？

（界面：北京、上海、深圳、广州四座城市海报——红墙映雪豆汁儿烫、外滩旁蟹壳黄、档口旺代码长、凉茶苦利是旺，均为「我在认真学一堂」系列，标注各城市学区人数、复盘字数、听课时长与排名依据）

简单回顾下，在设计这个海报初期，我们需要先去找一轮参考和对标。

负责这个项目的PM雨安最初的做法是：翻了大量的小红书、设计网站，一个帖子一个帖子地翻，结果情况是，一直在划划划。看到一个，觉得不合适就划掉，又找下一个，又划掉，结果到最后找了半天什么也没锁定。

后来Truman和他复盘，为什么这轮调研效率这么低？

其实最主要就因为，当时他没有想清楚，自己到底要从对标海报里拿什么。是城市地标的呈现方式？是整体风格的高级感？还是信息密度的设计？…目标不清楚，看再多也是白看。

后来改进后的做法是，列出几个关键调研点，看看别人的海报有没有以下这些亮点——

1. 怎么突出一致性和差异性
2. 怎么突出城市地标和文化
3. 有什么版式显得洋气高级
4. 怎么增加图片的信息密度

然后，打开花瓣网，开始搜索城市海报，有的放矢地一边收集一边排序、分类，也就花了20+分钟看了几百个，大概就整理了几组最佳实践池子：

- 组合设计：用来看一个系列的一致性和差异性；
- 大图大字：感受城市文化符号和大字张力的；
- 色块文字，能容纳得更多：用来设计排版和借鉴格式的。

最后，结合信息密度和风格参考，很快就选定了三个作为设计"母版"。

# 截图03 案例2：胡椒厨房加盟

第二个例子：这是来自陈同学的一个餐饮加盟案例。

几年前，他看到来自新加坡的铁板牛排品牌"胡椒厨房"，在大陆某些门店人气很旺——出品快、摆盘精致、客单价也还行。他觉得这个模式可以赚钱，于是考虑要不要加盟。

（界面：胡椒厨房门店装饰、菜单、铁板牛排餐品、铁板意面餐品、铁板烤肉餐品等图片）

陈同学作为创业老兵，也是有调研意识的，也去门店蹲了好几次，主要考察了对方的经营状态、人流、翻台率等等，总之看着人气很旺，觉得靠谱，然后就决定干了。然后他就去找选址、谈装修、组团队，没多久第一家门店开起来了。结果开了半年，业绩一直起不来，最后关门亏损离场。

复盘的时候，他才发现：

- 关键信息都没调研到：胡椒厨房在大陆的门店，其实陆陆续续都在关闭。而且网上早就有大量"性价比不高、复购率低"的评价。
- 调研太浅太表面：更关键的是，胡椒厨房在新加坡本地，其实只是美食城里的一个小档口品牌，根本不是他想象中的正餐连锁——这个事实，只要他当时飞过去实地看一眼，立刻就清楚了，但他没去。

这就是一个非常典型的调研失误：只看到了竞对表面的火爆，没有去深挖那些真正重要的信息——人群画像、复购率、真实经营数据，进而判断这个品类适不适合他的城市。

看似做了不少调研了，但最后却导致了决策的重大误判。这样的调研，你能看到的，只是你想看到的。

# 截图04 案例3：智能早餐机

第三个例子：这是来自张同学的"智能早餐机"的案例。职场白领没时间吃早餐啊，那就让用户提前一天点餐，第二天他们把餐送柜子里，他们上班时直接带上去就能吃了。

启动前，他也想做过调研，但是市面上几乎找不到竞品，过去有一些融资报道，于是认为只要产品体验好就能成。

他组建了团队，研发了样机，搞定了供应链，在大量写字楼楼下，铺设了多台智能柜售卖早餐，准备大干一场。

（界面：智能早餐柜产品图，扫码下单、免费早餐等营销信息）

等他真正深入行业后才傻了眼：该品类几年前相关项目几乎全行业失败，且失败项目留下的痕迹有限，调研时拿不到有效信息。

复盘的时候，他才发现致命盲区：

- 调研对象的缺失：没意识到"死掉的项目"才是最有价值的课本。他没去深挖先行者为何倒下——是机器维护成本太高？还是单机坪效根本覆盖不了固定成本？
- 情报挖掘深度不够：他只看能搜到的融资信息，却从未约过行业专家。那些失败项目的完整单元模型数据，本可以通过专家访谈轻松拿到，但他一次都没约。

这就是典型的调研失误：没去调研"行业的尸体"，如果你不搞清楚前人是怎么死的，大概率会在同一个坑里以同样的方式倒下。看似做了不少调研，但最后却导致了决策的重大误判。

# 截图04 背后的三大难题

讲到这儿，你们有没有在这些例子里，看见自己？

大量浪费、拿不到结论、调研了等于没调研……这些其实是很普遍的问题。

【常见问题】我们在访谈的过程中，发现很多团队在这一类调研上，背后主要有这几个误区：

系统式调研的三大难题：太大而全，目标跑偏，效率极低。

第一，目标模糊。很多人是这样开始调研的："大概想看看这个市场怎么样……"然后就开始搜资料、找报告、拉数据，最后拿了一堆信息回来，开始拼答案。问题在哪？他从一开始，就没有一个清晰的"要解决的判断"。没有超强的目标导向，脑子里只有个模模糊糊的方向，然后就着急开始盲目调研。习惯是"哪个容易拿就拿什么"，拿一大堆信息堆在桌上，再来拼答案。这是最常见的姿势，也是最低效的姿势。

第二，缺少框架。还有一类人更努力，调研非常多，看起来很拼。但最后你会发现：有效信息很少。为什么？因为调研过程没有重点，感觉看到什么都觉得有关系。没有优先级，没有模型，没有筛选机制。结果就是，执行看上去很努力，信息拿了一大堆，但最后发现，拿了大量无用信息，对决策帮助不大。努力了半天，结果方向从一开始就错了。

第三，盲目寻找。还有一种更常见：上网找一些调研模板，套一个"竞品分析框架"，开始填空。或者"我先随便看看，边看边想"。这背后其实是一种状态：缺少计划性，没有提前想清楚答案藏在哪里，先把能找到的都找一遍，结果找着找着就迷路了。

这三种典型情况，说到底，大多数人调研做得差，不是因为不努力，是因为没有一套科学的体系来组织这个过程。

之所以在真实的商业环境中，真正有效的高质量调研极难、极少，就是因为调研的背后都是各种重要的商业决策。

当你做完调研，到底能不能支撑你去做出这个决策、做对这个决策，能不能只是通过调研就把一个想法证实、或者证伪？

这真的是非常难的啊。而系统式调研发挥的最大的价值就是，帮你找到那些决策支撑的点、并且拿到背后的充分信息。越有体系、有章法地去进行调研，就有越大的概率能够趋近于高质量地拿到结果。
