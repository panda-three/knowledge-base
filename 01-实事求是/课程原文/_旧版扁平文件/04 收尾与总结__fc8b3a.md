# 截图08 总结：Image 版 PPT 八步工作流与双三角

## 为什么先做 Image PPT

- 把 PPT 初稿从手工排版变成可拆解流程、可批量出图、集中验收、持续沉淀。
- 核心链路：资料读取 → 页面规划 → 生图 → 导出交付。

## 8 步流程

1. 项目目录整理上下文。
2. 让 Codex 盘点资料，生成 asset_inventory.md：明确每份 Word 对应 1-2 页；不编造未提供数据与内容；若缺素材列待补充清单。
3. Product Design 先做风格设计：先做 ASCII 内容线框，再探索封面关键页视觉方向，多轮刷风格样板图选定路线，生成 visual_style_guide.md。
4. 先出 1-2 页样张：用 Image Gen 先验证风格版式密度；画面统一 16:9；先小范围试错避免一次全部返工；重点确认标题、Logo、信息层级。
5. 批量生成 Image PPT：根据 3 份规范文件继续批量生图；文字过多时优先压缩层级不缩到不可读；文件按 01.png 02.png... 编排；截图内容可参考对应 Word。
6. 逐页修改与修图：Codex 可配合截图/注释迭代；ChatGPT 网页也可用"编辑+评论"改图；提示要写清页码、问题、保留项、限制条件；正式入页前截图先做脱敏处理。
7. 用 Presentations 导出：图片确认无误后再导出 PPT/PDF；图片版 PPT 视觉最稳定；关键页可转可编辑 PPT 便于后续改字；要求 16:9 整页铺满不裁切。
8. 沉淀专属 Image PPT Skill：把流程整理成项目级 image-ppt-skill；纳入目录规范 3 份 .md 文件；补上质量检查清单与常见错误处理；让下次执行更快更稳更可复用。

### 核心提醒

- 先盘点资料再生图。
- 先做 1-2 页样张再批量生成。
- 真实截图优先，敏感信息先遮蔽。
- 不要生成可读 UI / 代码 / 价格 / Logo。
- 图片版适合稳定交付，可编辑页按需转换。

小贴士：3 份关键文件——asset_inventory.md 资料盘点、ascii_content_layout.md 内容线框、visual_style_guide.md 风格规范。流程关键词：项目目录 → 盘点资料 → 定线框 → 定风格 → 出样张 → 批量生图 → 改图 → 导出。

## 回顾一堂双三角：AI 时代新范式模型

人类三角 × AI 三角——人变强了调教更强 AI，持续让自己变强 × 持续使用 AI 更强；有了强 AI 辅助人变得更强。

人类三角：审美（专业见识 / 最佳实践 / 评价标准）× 体系（科学体系思维 / 假设验证模型 / 稳定知识结构）× 基本功（基础 LLM 提示词智能体、宽度多模态 AI 工具库 ∞、深度模型微调训练 / 工程化）× 数据（非结构化数据 / 结构化数据 / 形成资产）。

版本更新于 2026.7.3 @北京一堂实验室。一堂·坚持只做必修课，双三角决定人和人之间 AI 能力的代际差。

### 人类三角应用在 Codex 做 PPT

- 审美：你知道什么叫清楚、什么叫好看、什么能代表你。
- 体系：附件映射、提示词、Skill、版本和 QA。
- 创造力：同一份内容可以选择 HTML 也可以选择 Image 还是混合使用。

### AI 三角应用在 Codex 做 PPT

- 场景：你知道什么时候该用 HTML 什么时候该用 Image。
- 基本功：guizang-ppt-skill、Image Gen、Product Design 和 Presentations 插件。
- 数据：Word、Markdown、图片、案例、模板和历史上下文对话。

## 做 PPT 的三个关键节点：把判断权拿回来

1. 内容方案确认前，你决定讲什么。
2. 风格定调时，你决定什么叫好看。
3. 最终验收时，你决定这份东西能不能代表你见人。

## 最后三句金句（敲黑板说重点）

- Codex 跑得很快，方向错了也会浪费得更快。
- AI 负责执行，人负责内容、审美与最终责任。
- 先思考后设计，先验证后批量；先复查才交付。
