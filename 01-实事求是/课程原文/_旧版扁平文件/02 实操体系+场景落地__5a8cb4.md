### 从元素周期律，到 Feature 周期律

真正的跃迁，不是知道更多，而是找到组织知识的规律

**元素周期律**

- 没有周期表：孤立记忆、难以比较、发现靠偶然
- 有了周期表：分类定位、发现规律、预测未知
- 孤立事实 → 结构关系

**Feature 周期律**

- 没有Feature：追逐工具、凭感觉调、经验难迁移
- 有了Feature：拆解变量、假设测试、组合迁移
- 记住已有 → 预测未知
- 经验收藏 → 科学实验

元素周期律是自然规律；Feature 周期律是持续演化的工作框架。真正稳定的是：拆解、假设、验证、组合。

身份决定立场，资源提供认知，环境赋予能力，协作完成任务。

### 场景1 解题地图：做事可以"假设实验"

以我们过去的体感，Feature思维最大的价值，就是可以把我们的团队快速切换到"科学假设状态"：做预判，提假设，做实验，试错复盘。

- 传统经验派："我换个说法试试""我换个工具试试""别人这么写我也这么写"。
- Feature派："我提出一个具体假设：这个任务差是因为缺少最终意图、缺少 few-shot、缺少专业案例、缺少数据来源、缺少工作流确定性，或缺少评测标准。"

Feature天然就是客观假设：这个小的特性，对于结果提升是显著的。

**切换Feature思维，自然就进入了科学实验状态**

这就是为什么Feature越小越好，越小就可以测试越快，成本越低。

这样，可以把模模糊糊，大而全的东西变成了"关键假设思维"。

Feature 派可以把提示词工程、上下文工程这些工程实践翻译成普通学习者也能使用的训练语言：每个 Feature 都是一张可测试的牌。

### 把招商审美翻译成评分规则

人负责定规则，AI负责执行，这就是招商版的 Feature

**规则评分（先于 LLM 预筛）**

- +4分 一级来源（宜昌经信、襄阳招商、武汉政府）
- +4分 命中湖北关键词
- +3分 标题含总投资X亿
- +3分 硬项目词（开工、投产、签约、扩产）
- -4分 软宣传稿（表彰、欢歌、春风行动）

分数决定谁能进 LLM 评分池  
媒体源最多 1 条，其余名额留给一级来源  
省 LLM 调用，是省钱钱

**负面约束（硬过滤直接扔掉）**

- 长者模式
- 政府信息公开
- 12345 页面
- 软宣传稿（无实质项目信息）

命中就跳过，不送 LLM  
政府站标配页面天天有  
不设负面清单，评分池全是噪音

**五维 LLM 评分**

- 通用五维（满分 20）：交叉密度、信息优势、因果深度、时效、来源权威
- 招商相关性五维（满分 10）：产业契合度、项目机会、企业领导价值、政策杠杆、可操作性
- 规则筛选，再让 LLM 深评
- 评分结果带中文摘要
- 事实·影响·建议动作

规则 + 模型 = 两层过滤  
负面清单和加分规则一样重要  
约束 = 告诉 AI 什么不是招商

用规则筛完，再让模型从市场影响、信息优势、时效、来源权威等维度打分。

## 11 场景落地：统一心法

好了，讲完了事情的"专业上手"和"无限调优"，下面我们来讲讲对于人的改变。

当一个人开始理解、接受、使用了Feature思维，会有什么变化呢？

### 场景3 统一心法：成长可以"刻意练习"

这一步才是对我来说最最重要的，就是：我可以对于AI各个项目进行大一统的刻意练习。

比如我发现，我平时会做5类完全不同的AI工作：

1. AI做内容：写文案，作图，做设计，写方案，做研究。
2. AI做产品：VibeCoding做各种系统和APP；
3. AI做封装：持续搓有竞争力的Partner和Agent。
4. AI做落地：作业挖掘AI化，个性化运营AI化，作业洞察AI化。
5. AI做兴趣：哄娃，搓小玩具，搓小游戏，写小说，写歌儿等等。

这些工作有的是对话，有的是Agent，有的是VibeCoding，千奇百怪，而且每个月都在新增加一堆的新案例、新工具和最佳实践。

有没有可能我来以不变应万变呢？十年磨一剑呢？

答案就是：使用一套统一的Feature框架。  
一旦切换，你会发现上面各种项目，其实本质上没什么区别。

新工具出现时，不再问"我要不要追"，而是拆它到底新增了哪些 Feature，这些 Feature 对我的任务有没有价值。

1. 可拆解：它把宏大的AI能力拆成可练的微技能
2. 可训练：可以统一地刻意练习了（统一了套路）
3. 能迁移：能力不再绑定单一平台，而具备跨工具迁移能力
4. 强复利：每个Feature都能不断进入新的任务、新的组合、新的交付

讲到这里，我必须要强调一个基本事实：Feature不是"学会"的，而是"用会"的。

### 掌握Feature的确很香，但还是要理性务实

就算你听了10遍课，把每一个Feature关键词都记得滚瓜烂熟，如果你没有实践用过这些Feature，体会过它们对于AI交付结果的显著改变，那么约等于什么也不会。

清单本身没有很高价值：如果只是收藏几百个策略名称，Feature 思维会退化为另一种技巧派。真正价值来自实践以后的诊断、测试、组合和沉淀。

我们曾经在《上手第一课》给过大家一张图，后半段的"理解底层原理""学习控制变量"和"掌握内核边界"，其实根本原因就是感受Feature的价值。

### 一堂AI上手曲线 · 循序渐进突破图

YITANG AI Step-by-Step Learning · Pathway to Breakthroughs

- 前期不要觉得怕；
- 中期不要觉得远；
- 后期不要觉得乱。

学习曲线：

- 想学欲望 → 快认识（AI辅助学、快速搜索、最佳实践）→ 怕 → 入门（早动手、粘贴运行、跟做一遍、改造练习）→ 远 → 进阶（建知识库、场景清单、项目驱动）→ 乱 → 无限进步 → 高阶
- 理解底层原理
- 学习控制变量
- 掌握内核边界

真正体会过成功（内核）和失败（边界），才会慢慢把这些Feature消化掉，变成你自己的"Feature Library"。

每一个高质量的Feature 加入Library，需要大概经历6个阶段：偶遇（听），理解（想），尝试（做），内核（成），边界（败），肌肉记忆（练习）。

**地图上的 Feature**：看见、听过、收藏，都还不属于你  
**背包里的 Feature**：能诊断·能测试·能组合·能迁移

穿过成功与失败，知识才变成能力  
从信息 → 体验 → 洞察 → 能力 → 本能

不要收藏 Feature，要消化 Feature。

我们先来回顾下这节课的必知必会，最后我们来探讨下，为什么Feature思维，对于长期有追求的人来说，如此重要。

开篇我先给大家讲了两种思维方式：T型 VS. F型

**同一个问题，两种完全不同的解题方式**  
工具思维关注"用什么"，Feature 思维关注"为什么有效"

- T 工具思维：问题 → 工具 → 成/败

  - 追工具、整体试用、成败二分
  - 借工具之假，修能力之真
  - 工具变了，能力重来
- F Feature 思维：问题 → Feature → 工具

  - 先拆机制、再选载体、测试沉淀
  - 拆解·假设·测试·组合
  - 工具会变，Feature可以迁移

真正需要积累的，不是工具清单，而是可迁移的 FeatureSet。

然后给了大家一个基本定义：

**初步定义Feature：提升AI解题水平的的最小实践单位**

接着我试着讲，这并不是什么大创新，只是给大家一套更底层系统、更加容易科学实操的AI做事方式：

**一堂AI基本功全地图：Feature思维**  
Yitang AI Fundamentals Map: Feature Thinking

- A.原理派（关注算法）：难上手、不够实用、很稳定、容易迁移
- B.工程派（关注系统）
- C.工具派（关注流行）
- D.教程派（关注场景）
- E.模板派（关注粘贴）：好上手、非常实用、不稳定、难以迁移
- F.Feature派：把有效、可控、可迁移的部分全部拆出来，用"最小原子"思维做事

取长补短关系：

- 原理派 ← 取长（支撑原理）→ 工程派
- 工具派 ← 取长（拆解要素）→ 教程派
- 教程派 ← 补短（高效迁移）→ 模板派
