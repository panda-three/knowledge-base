# 截图01 为何缩小范围

## 提问：有了调研目标，直接去聊人、去拜访不就行了吗？为什么要缩小范围？

大家有没有这样的困扰：面对各类堆积如山的信息，是不是所有的都需要收集，整理回来？面对鱼龙混杂的信息，有没有核心，有没有边界？哪些是核心必要项，哪些是噪音干扰项？即便你有了一个很棒的目标，也很容易在海量的信息中，迷失自己。

## 抢答练习：我想在西安加盟一个xx知名品牌奶茶，我想预判调研成功率，怎么调研？

是不是还挺不容易的？

1. 看奶茶过去10年的行业趋势和竞争格局？
2. 看西安的GDP和产业格局？
3. 看加盟品牌的官方招商材料？
4. 看抖音加盟店主的分享和案例？
5. 看小红书、美团评价和口碑？

看哪个呢？

## 两种调研习惯：全拿回来 vs. 带着精准维度调研

我们常见两种不同的状态：如果是简单调研无所谓，但是如果是复杂管理课题，没有精准维度，就太容易跑偏了。

OK，早期调研如何快速拆解调研范围呢？这个真的是一个非常非常非标的问题。在之前课程内测中，有一半同学反馈，最难的就是缩小范围这个点，每次调研，都拿到了一堆信息，不知道该怎么建模型，怎么抓住最关键的信息。

## 你的调研能力，就是你的业务能力

这个的确很难，也几乎是调研方法论里最难学习的一步。我之前分享过一句话：你的调研能力，就是你的业务能力。

大家懂我想表达的含义么？如果你懂某种产品策略，那么你可以自己设计出来，别人的产品你也可以调研出来。反过来也一样，如果你看不懂，你也大概率做不出来。

所以说，大家不要盲目相信网上提供的一两种竞品分析工具，所有不说清工具目标和适用条件是什么，就鼓励大家去套用的，都是在耍流氓。核心还是要提升自己的业务能力。你对产品价值、增长模式、商业模式理解得越透彻，你的竞品分析也就会越清晰。

这也是为什么我们在调研过程中，很反感那些从网上『套个模板』式的调研方法论，因为每个调研的目标、模型和范围都不一样。

【划重点】送给大家一个核心心法。下面给大家准备了三个招式。

# 截图02 内核边界（第5式）

## 不是 28 法则

这个模型很多同学是不是都感觉听烂了，没啥啊，不就是28法则么。为什么Truman一直反复强调，没完没了。

## 抢答：内核边界这个思维方式是分几层？

注意，这是三层：这个远比简单的28法则实操价值大得多。

- 内核：这是最关键的、必要的、决定性的
- 中间：接受模糊，可以做，也可以妥协的
- 边界外：这是果断放弃，即便再香，看到了也不会收录的。

# 截图03 宏中微观（第6式）

## 不要试图用低纬度的解法去解决高纬度的问题

我曾经拍过一个爆款短视频，叫做：不要试图用低纬度的解法去解决高纬度的问题。大致的思路是，一个人职业的发展和决策，一般是逐层上升的：SOP层、ROI决策层，商业模式层，行业层。如果遇到的是宏观的问题，用低纬度的方法是很难解决的。

说明：当然必须要辩证地看，用宏观抽象的模型，也很难解决微观具体的问题。核心还是在于匹配。

在老版本的课上我讲过很多细节，但是有些过于细了，也不完整；而且最大的问题是，微观中观宏观是一个相对概念，不同角色和立场来看完全不同。

## 划重点：业务的核心宏中微观模型

今天我试着给大家一个完整的表格吧，大会员同学努力听懂，MBA同学这是必修（高阶营阶段）：

| 层级 | 核心模型 | 内容 |
|-|-|-|
| 第一层 | 具体SOP | 1. 具体的完整工作链条 2. 严格分工和时间管理 3. 结果评估和考核机制 4. 过程监督和加锁机制 |
| 第二层 | ROI/转化率 | 某一个决策和转化率的节点（一堂·科学决策三角形：宽度/深度/高度）；核心模型：提升转化三板斧——动力（我为什么要做呢？）/阻力（我为什么犹豫呢？）/触点（我如何一步步被推动？）。提升转化率的3大策略：提升动力，减少阻力，发掘触点。随着动力、阻力、触点假设的逐步验证，转化率自然而然就一步步提升了。 |
| 第三层 | 业务公式 | 用目标、参数、逻辑关系三要素系统拆解业务 |
| 第四层 | 单元模型 | 分析业务的一个最小经济循环，建模分析。一堂十大典型单元模型：按销售（订单单模型/单SKU模型）、按人头（单用户模型/单客户模型/单销售模型/单履约模型）、按空间（单柜子模型/单门店模型/单商圈模型/单城市模型）。配套：单元模型定量分析画布（收入/成本/净利的关键项、数据、占比） |
| 第五层 | 商业模式 | 使用259对于商业全局有一个分析（一堂五步画布 Yitang Five-step Canvas） |
| 第六层 | 完整公司 | 1）基本业务公式：业务（财务）+组织（人） 2）用结构图拆（获客渠道/流量产品/中间层/商业产品；竞品：轻流） 3）用时间轴拆（同学案例：某农业职业培训/某同学拆解小米） |
| 第七层 | 行业分析 | 一堂做了一套《行业分析画布》（拆解你的产业链）。小龙虾行业预判画布：1.拆解行业链条 2.洞察行业里的变化 3.预判下一个稳态 4.判断行业周期 5.行业天花板大小 6.行业集中度 |

## 抢答：看看大家反应速度

1. 简单的：如果我想调研某某公司的办卡率为什么很高，怎么调研？
2. 中等的：我想调研某一家公司的知识管理/建模流程，怎么调研？

## 划重点：一堂推荐的高频使用的《16个因果规律模型》

| 核心模型 | 场景/心法 | 解读/价值 |
|-|-|-|
| 机会预判 | 用于创业方向选择、新业务启动前判断。"机会预判"就是：主动想终局，充分做加法，专业做减法。 | 用于做创业方向选择时，探索成功概率，其核心重点在于三个关键词：①主动想终局（长期视角/终局区间）②充分做加法（拆足创业选项池）③专业做减法（排除各种硬伤/找到最高可行选项）。机会预判，能大幅提升创业成功率，是创业ROI最高的工作。 |
| 一堂五步法 | 用于系统拆解和分析商业项目的底层逻辑。"一堂五步法"就是：需求、解决方案、商业模式、增长、壁垒五个商业里程碑。 | 用于做商业分析时，探索业务完整性，其核心重点在于五个关键词：①需求（原点问题/目标用户）②解决方案（价值问题/产品内核）③商业模式（单元模型/能否赚钱）④增长（复制问题/持续获客）⑤壁垒（终局问题/竞争优势）。一堂五步法，能帮你系统理解业务底层逻辑，有重点有节奏地起盘新业务，显著提升成功率。 |
| 需求原点 | 用于创业/项目/产品起盘、前用户需求分析。"需求原点"就是：找到用户真实存在且必须解决的核心问题。 | 用于做商业分析时，探索业务起点，其核心重点在于三个关键词：①目标用户（具体人群）②场景（使用环境）③问题（待解决痛点），使用拆推评算一步步进行需求分析。好的需求原点，是商业的原点问题，决定了后续所有环节的成败概率。 |
| JTBD | 用于分析用户需求与产品价值的剥离拆解。"JTBD"就是：用户"雇佣"产品完成待办任务以实现进步。 | 用于需求推演时，探索用户真实需求，其核心重点在于四个步骤：①圈定核心任务 ②分解任务地图 ③深挖隐藏洞察 ④提出需求假设。JTBD，能帮助企业找到用户真实需求，避免伪需求，提升产品竞争力。 |
| 产品内核 | 用于分析决定商业成效的产品要素。"产品内核"就是：用户愿意选择你的最小解决方案。 | 用于做一个新产品，新项目时候，探索产品的核心价值，其核心重点在于四个关键词：①用户 ②愿意选择 ③最小 ④解决方案。产品内核，决定了一个产品的关键转化率，进而决定了一个商业模式的信心和健康度。 |
| 单元模型 | 用于商业模式验证、业务盈利性研判。"单元模型"就是：复制哪个算哪个，哪个最虚盯紧哪个！ | 用于选择核心单元模型时，探索业务复制增长的关键驱动要素，其核心重点在于三个关键词：①复制（模型最大价值在于复制）②算哪个（找到最核心的单元模型）③盯紧（重点关注最虚、最不确定的成本收益项）。单元模型，是你不犯大错误的最后一道能力防线，是判断业务是否可持续盈利，是商业模式跑通的标志。 |
| 规模经济 | 用于分析业务规模扩大后的成本收益变化。"规模经济"就是：随着规模增加，哪些因素会变好，哪些因素会变差。 | 用于做规模分析时，探索规模效应，其核心重点在于两个维度：①规模经济要素（12个变优要素）②规模不经济要素（12个变劣要素）。规模经济分析，能帮你预判业务扩张难度，制定正确的对抗策略，避免规模陷阱。 |
| 渠道探索 | 用于分析持续获客和渠道选择。"渠道探索"就是：通过扫描、预判、测试、建模四步科学探索渠道。 | 核心重点在于四个关键词：①扫描（做加法/消除盲区）②预判（做减法/排优先级）③测试（拿认知/验证假设）④建模（持续化/工业化）。渠道探索，能帮你科学搭建可持续获客渠道，避免盲目跟风和重大亏损。 |
| 业务公式 | 用于拆解业务要素与因果，实现科学增长。"业务公式"就是：用目标、参数、逻辑关系三要素系统拆解业务。 | 用于做业务管理时，探索增长路径，其核心重点在于三个关键词：①目标 ②参数 ③逻辑关系。所有业务公式拆解，本质上都是在思考这三件事，形成完整的业务认知。业务公式，是业务螺旋上升的根本要素，从入门到高水平科学的过程，就是不断挑战高目标的过程。 |
| 最佳转化率 | 用于分析关键业务环节的转化率提升和优化。"最佳转化率"就是：善于用动力阻力触点，用假设驱动转化率提升。 | 用于做业务转化率的提升，①动力提升 ②阻力消除 ③触点挖掘，通过大量假设验证，不断迭代优化关键转化环节。 |
| 科学决策 | 用于分析日常业务决策、团队管理和资源分配。"科学决策ROI"就是：用宽度、深度、高度三个维度全面评估投入产出。 | 用于做广义ROI决策时，探索决策质量，其核心重点在于三个关键词：①宽度（关键收益项/成本项）②深度（优先级定性/部分定量/定量公式）③高度（长期视角/公司视角/机会成本/时间窗口）。科学决策ROI，决定了各个竞争团队的资源利用率，这个成长速度拉开了平庸和优秀的差距。 |
| 科学学习IPO | 用于系统化构建个人学习体系和能力提升。"科学学习IPO"就是：通过输入、处理、输出的闭环循环提升学习质量。 | 用于系统化学习时，探索高效学习路径，其核心重点在于三个关键词：①输入（高质量信息源）②处理（思维模型与体系化）③输出（实践与反馈闭环）。科学学习IPO，决定了认知迭代速度，是长期解决问题能力的底层引擎。 |
| 人生红点 | 用于分析长期人生规划、职业选择和重大决策。"人生红点"就是：你内心最渴望、愿意长期投入的人生终极追求。 | 用于做人生重大选择时，探索内心真实渴望，其核心重点在于四个关键词：①内心最渴望 ②愿意长期投入 ③人生终极 ④追求。人生红点，是人生的底牌，早点拿到形成内心笃定，你的做事成长路径会变短，效率是最高的。（附：一堂人生红点十二问——1.关键选择 2.峰值瞬间 3.低谷瞬间 4.对外标杆 5.长期愿景 6.拆解落地 7.抗挫韧性 8.抗诱惑 9.风险边界 10.点线持续 11.复盘迭代 12.强制排序） |
| 工业化生产 | 用于分析持续高质量交付的确定性模型。"工业化生产"就是：面对高度不确定工作，持续进行高质量交付的底层模型。 | 用于做持续交付时，探索确定性模型，其核心重点五个关键词：①定目标（培养敏感性，主动提高目标预期）②建节点（建立多节点的筛选模型）③做加法（建立一个选项池）④做减法（逐步专业筛选和评估）⑤快迭代（循序渐进建立工业化生产线）。工业化生产，能对抗规模不经济，用流程代替直觉，把失败留给内部，保持高水准对外输出。 |
| 融资公式 | 用于分析风险投资的核心决策逻辑。"融资公式"就是：赚钱=业务天花板×成功概率。 | 用于做融资分析时，探索投资决策逻辑，其核心重点在于两个维度：①业务天花板（细分行业天花板×集中度）②成功概率（Why Now×Why Me）。融资公式，能帮你理解VC投资本质，加速融资进程，提升拿钱成功率。（附：业务梳理要点清单Checklist——Who：你的团队有哪些优势？Where：你的业务天花板多高？Why：你解决的痛点到底是什么？How：你的打法壁垒是什么？Which：你的竞争环境怎么样？What：你传递愿景的吗？What：你的融资计划是什么？） |
| 双三角模型 | 用于分析AI时代的个人和团队竞争力构建。"双三角模型"就是：三角（审美/体系/基本功）+三角（数据/场景/创造力）相互增强。 | 用于构建AI时代竞争力时，探索人机协同模式，其核心重点在于两个三角：①人类三角（专业见识/科学体系思维/基础能力）②AI三角（非结构化数据/多模态工具库/模型微调训练）。双三角模型，决定了AI时代同样都会用AI，不同人业务结果相差这么大，是领先完成AI范式迁移的关键。 |
