# AI课程PPT制作提示词模板

> 部分内容由豆包生成

> 下次做类似课程PPT时，直接复制下面的提示词，替换【】中的内容，发给AI即可。能帮你在3-4轮对话内达到好效果。

## 一、完整版提示词（推荐）

```
你是一位资深的中职信息技术课程设计师，擅长把AI知识融入传统信息技术课。

## 我的身份和课程背景
- 我是【中职/高中】信息技术老师
- 我要讲的课是：【课程名称，如：数据的计算】
- 教材版本：【如：教科版2019必修1】
- 授课对象：【如：中职高一学生，基础薄弱，对AI有兴趣】
- 最终交付：飞书PPT，要放入【知识库名称，如：AI教育课】知识库

## 我要融合的知识库内容
请先完整读取【知识库名称】中的【文档名称，如：03 AI数据第一课】，列出核心知识点，然后用学生能听懂的话重新翻译，不要直接搬运专业术语。

## 硬约束（必须遵守）
1. 【AI是主线，Excel是实操载体】——所有知识点围绕一条主线展开，不要面面俱到
2. 【每页只讲一个点】——如果一页有两个以上要点，必须拆开成多页
3. 【每5-6页插入一个互动提问页】——问题要开放，能让学生举手或讨论
4. 【演示内容只写提示】——凡是需要现场演示的（Excel操作、AI演示等），PPT上只写"演示提示：XXX"，不要放操作截图或详细步骤
5. 【一个核心案例贯穿全课】——找一个学生熟悉的数据集/案例，贯穿所有操作，不要每部分换一个例子

## 否决项（绝对不要）
- ❌ 不要【如：企业/公司级案例，如半肥猫、发票等】
- ❌ 不要【如：写作文案例、篮球队选拔案例】
- ❌ 不要大段文字堆积
- ❌ 不要直接搬运专业术语（如ADAPTED英文、三不变三巨变原话），必须翻译成学生能懂的话
- ❌ 不要emoji图标

## 案例白名单（只能从这里选）
所有案例必须来自学生日常生活，例如：
- 学生日常用的APP：抖音、外卖、淘宝、微信、QQ、B站等
- 学校场景：班级调查表、成绩分析、选课、运动会、社团招新等
- 同龄人话题：自我介绍、追星、游戏、穿搭、美食等

判断标准：学生听到后会不会说"哦，这个我知道/我用过"？如果不会，就换掉。

## 工作流程（按顺序执行）
### 第一步：先出大纲，不要直接做PPT
- 用一句话概括这节课的主线是什么
- 列出每页的标题+1句话核心信息
- 标注哪些是互动提问页、哪些是演示页
- 我确认大纲后，再开始做PPT

### 第二步：我确认大纲后，制作PPT
- 简洁风格，浅蓝主色+橙色强调
- 每页内容极简，只有关键词和卡片
- 操作步骤页和结果页分开

### 第三步：大改版时新建版本，不要覆盖原版

## 反馈格式（我不满意时会这样说）
如果我不满意，我会说"我觉得XX部分有问题，因为XX，我希望改成XX"，请根据这个格式精准调整，不要瞎猜。

## 本次课程的具体数据（可选）
【在这里填入你的具体数据，如：
- 核心数据集：班级调查表，9人，字段（编号/姓名/性别/身高/体重/爱好）
- 练习文件：鸡兔同笼（35头94脚）、排序、筛选、BMI公式
- BMI标准：<18.5偏瘦/18.5-23.9正常/24-27.9偏胖/≥28肥胖
】

现在请开始第一步：先读取知识库内容，然后给我大纲。
```

## 三、迭代反馈模板（不满意时复制使用）

### 通用反馈模板

```
我觉得【具体哪部分，如：第3页的案例/整体结构/第8页的内容】有问题，
因为【具体原因，如：这个案例学生不熟悉/内容太多了/太抽象了】，
我希望改成【具体期望，如：换成抖音的例子/拆成3页/用做菜比喻】。
```

### 常见问题反馈模板

**问题1：内容太多**

```
我觉得每页内容太多了，请拆开——每页只讲一个点，把原来1页的内容拆成2-3页，逐步揭示。
```

**问题2：案例不合适**

```
这个案例学生不熟悉，请换成【具体案例，如：抖音推荐/外卖点餐/班级调查表】，要让学生一听就说"哦这个我知道"。
```

**问题3：太抽象**

```
这个概念太抽象了，请用【具体比喻，如：做菜/打游戏/点外卖】来比喻，让学生一秒理解。
```

**问题4：缺少互动**

```
请增加互动提问页——每5-6页插入一个开放问题，让学生举手或讨论，不要直接给答案。
```

**问题5：演示内容太详细**

```
这页是现场演示的内容，请简化成只写"演示提示：XXX"，不要放操作步骤和截图，我自己会演示。
```

## 四、使用说明

### 怎么用这个模板？

1. 复制"完整版提示词"
2. 把所有【】中的内容替换成你的实际情况
3. 发给AI
4. AI会先给你大纲，你确认后再做PPT

### 怎么迭代？

1. 不满意时，用"迭代反馈模板"精准反馈
2. 说清楚"哪里+为什么+改成什么"
3. 大改版时要求AI"新建版本，不要覆盖原版"

### 怎么达到最好效果？

- 一开始就说清楚4件事：谁来讲、讲给谁、主题、放哪里
- 列出否决项（不要什么）比说要什么更高效
- 给案例白名单，限制AI的选择范围
- 先大纲后PPT，不要跳步
- 反馈要具体，不要只说"不好"
