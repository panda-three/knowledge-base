# 03 框架：现场推导与理解（人类竞争力 + AI竞争力 + 整合在一起 + 形成飞轮 + AI原生）

## 框架：现场推导和理解

- 为了让大家100%接受和有体感，我带着大家重头推一遍吧。
- 如果大家听过课，尽量"假装"是新人，跟我重头思考一遍如何hh?
- 为了剥离人和AI的协作互补共生关系，我们来控制变量吧，一半一半来看。

## 第一步推导：人类竞争力

- 请大家思考一个很本质的问题：
- 【本质问题1】AI时代，管理/创业者的竞争力在哪里？
- 敲黑板，说重点
- 我们先控制变量，假设大家都会用AI，水平都差不多（提示词/Agent/Coze/Codex/落地部署），那不同人使用AI的真正区别在哪里呢？
- 我最近很认可一类观点：我们一直讲AI，实际上讲的还是人，是人和AI如何在一起的问题。
- 举一个具体的例子：大家都在用AI写短视频选题和脚本，用的工作流都差不多，但不同人写出的AI文案差异极大，有的兼具网感与人味儿，数据就很好，而多数人的就很一般。
  - 同样用AI做调研，不同人的调研报告质量有极大的区别，差在哪了？
  - 同样用AI做视频，不同人的视频质量相差不止一两个层次，差哪儿了？
  - 同样用AI做销售方案，不同人的销售方案质量相差很大，差哪儿了？
- 【洞察】先不考虑AI能力，人和人本身差距，使用AI最核心的竞争力在哪里？
- 很多人做过比喻，有人形容它是"一位顶级学校的实习生助理"，有人形容它是"一个24小时随叫随到的工作副手"。随着这两年AI的快速免费化，你拥有了50-100个成本极低的"名校实习生"，你如何带好他们呢？
- 反思人类的管理和操盘能力，其实核心还是得人足够强，才能领导大量AI发挥巨大的价值。
- 【划重点】人类最稀缺的三个要素：审美，体系，创造力。
- 人类竞争力三角：AI时代的人类本身稀缺能力
  - 人类三角：持续让自己变强
  - 创造力（顶点）、审美、体系
  - "同样都是AI高手，为什么业务结果相差这么大？"

### 理解每一个角的必要性（敲黑板，说重点）

1. 审美：建立高水平判断力，对于结果能做出高水准的判断。#偏结果
2. 体系：对于解决一类问题，有成熟的、稳定的思考和执行框架 #偏过程
3. 创造力：敢于跳出原来的经验和惯例，敢于提出新解法、新设想 #偏创新

- 对于真正高水平的有竞争力的AI交付工作，每一个角都是必要的么？

【提问🤔】审美重要么？why?

- 必要，人的判断力是AI迭代的主要驱动力。
- 同义词：判断力，品味。
- 这往往也是AI的边界：如果你本身有一个很明确的高价值任务（做图/写作/找答案/阅读），且你本身是专业的，有判断力、能评估结果，那么AIGC可以成为你非常好的助理，你可以命令它、调教它、教育它，一步步迭代实现你的任务。
- 反过来说，如果你本身没有最佳实践的审美，没有评估判断能力，没有框架能力，没有灵感，你想寄希望于AIGC做出来非常优秀、顶级的作品，这个目前还远远不现实。
- 即便十几年产品出身，自认为审美还算过关，但我最近一年依然建立了几十轮各种各样的审美（如A.影响 Oscar段子策划、课题实事求是、B.设计 Capa摄影师、建立基本审美等研究资产）。
- 哈哈有了AI（帮忙和需要），我感觉我这半年建立的审美比过去三年都多。

【提问🤔】体系重要么？why?

- 必要，这是人专业的核心体现。
- 同义词：体系，框架，模型。
- 相对于顶级的人类团队，AI有三大缺陷：1）概率不稳定 2）幻觉 3）上下文太短
- 这就会导致每次都随机发挥，内部随性而为，对外又无比笃定。
- 如果人没有确定性的体系、框架，就会被AI带着走，充满了随机和未知。
- 一个有趣的小例子：ROI决策，Top模型问"要不要全员配置顶级大模型"
  - 版本1：肯定配啊，巴拉巴拉。
  - 版本2：稍微换个说法，肯定谨慎啊，巴拉巴拉。
  - 版本3：ROI三角，分成拆解抓主要矛盾。

【提问🤔】创新重要么？why?

- 必要，这是人类或许最后最大的价值了。
- 同义词：创造力，创新，解放思想。
- AI来自词汇预测，会习惯性调用人类已有的知识和经验，跳出来原来的惯例，跳出经验，敢于解放思想，敢于大胆突破已有规律，这是人类大概率的最后的竞争力。
- 好啦，这三个总结一句话吧：
- 三个角汇总成一句话：人永远是主体
- 敲黑板，说重点
- 永远不要放弃判断、建模和发挥想象力的权力，如果这三个都失去了，我们就真的沦为了AI的工具了。
- 这是一个好消息，AI越强，对于人的要求越高，但是我们得把注意力从"动手执行""重复劳动"移开，把全身心的注意力投入到人类三角的提升上。
- ❤️动态说明：这三个角是会逐步变化的，随着AI越来越强，审美和体系的下限会被持续推高，对人的要求会越来越高，倒逼人类不断进步，AI会逐步吃掉所有AI水平线以下的工作。

## 第二步推导：AI竞争力

- 好，下面是第二个本质问题：
- 【本质问题2】AI时代，使用AI的水平体现在哪里？
- 敲黑板，说重点
- 我们继续控制变量进行分析：同样都是销售专家、产品专家、短视频专家，假设个人的专业水平差不多，那为什么不同人/团队落地AI的效果差异这么大呢？
- 有人问，学习提示词、Coze不就是两三个小时就行了嘛，有什么难的？
- 所以AI的实操能力真正体现在什么地方？从入门到进阶到高阶，究竟靠什么？
- 【洞察】先不考虑其他因素，不同人使用AI，最核心的能力差异在哪里？
- AI竞争力三角：AI时代的使用AI的稀缺能力
  - AI三角：持续使用AI更强
  - 场景（顶点）、基本功、数据
  - "同样都是业务专家，为什么AI结果相差这么大？"
- 场景：发掘高匹配的细分场景，本身就是AI能力进步的重要维度
- 数据：高水平的结果需要高水平的数据，主动搜集和积累高质量数据
- 基本功：练习使用各种AI工具，善于使用AI工具和特性解决问题
- 而你的AI落地能力 = f(基本功, 数据, 场景)

### 理解每一个角的必要性（敲黑板，说重点）

【提问】场景重要么？why?

- 极度必要，充分理解AI和问题的匹配，是所有工作的基础。
- 同义词：AI机会探索，AI价值判断，AI落地边界。
- 10个清华顶级毕业生领回公司了，某些人能把他们训练成各个业务场景的攻坚小组，而有些人只会让他们端茶倒水、讲讲段子。
- AI场景本身的探索，就是核心竞争力：提出场景假设，大量闪现和激发，然后评估可行性和ROI，然后测试一步步落地，这个本身就是AI的核心能力。

【提问🤔】数据重要么？why?

- 当然必要，这几乎是AI最后最大的资产和壁垒了。
- 同义词：AI数据资产，AI数据建设。
- 我们专门讲了一节《数据第一课》，未来会加速研究，变成一个必修课。很多时候我们做不成AI落地，很大程度上都卡在数据上，而不是AI技术。

【提问🤔】基本功重要么？why?

- 当然必要，但这个放在最后，这个慢慢会变成最不重要的。
- 同义词：AI工具，AI技术，AI实操能力。
- 各种AI工具，提示词，Agent，Coze，Codex，微调训练这些工具的使用，属于"上手挺难，一旦会了再也不难"，每个项目都差不多，所以我的判断是，这些工具会是双三角最容易大家全体学会的。

- 预告❤️：修炼AI技术基本功很容易陷入工具思维，我最近一直在带着团队思考"特性（Feature）思维"，找到工具背后通用的一套最小的技术特性，比如模型，加角色，加案例，加限制，加记忆，加CoT，加模型参数等等。

- 好啦，也总结一下一句话吧：
- 三个角汇总成一句话：系统思维用AI
- 敲黑板，说重点
- 随着你练更强的基本功、发现更多场景、积累更多数据，你的AI使用和落地能力就会越来越强。
- 讲完了两句话：人永远是主体，系统思维用AI。
- 充分理解并认同了么？我们继续来推导。

## 第三步推导：整合在一起

- 准备好，惊喜来了：当我们把这些要素试着组合一起，找到里面的内在联系，这样两个三角，就变成了一个"双三角"模型：
- 双三角图：创造力（人类三角顶点）× 场景（AI三角顶点）；人类三角由审美、体系支撑创造力；AI三角由基本功、数据支撑场景。
  - 灵魂拷问"同样都会用AI，为什么不同人业务结果相差这么大？"
  - 灵魂拷问"同样都是业务高手，为什么不同人AI结果相差这么大？"
- 双三角呈现出来的信息密度比两个三角大多了：谁是底座，谁是支撑，两个三角形成了一个非常"优雅"的分型的哲学美感。
- 人类三角，审美和体系支撑了创造力，这是人类最后的核心竞争力和高阶能力，如果没有底座，你的创造力也是凭空瞎想，瞎解放思想。
- AI三角，基本功和数据支撑了场景，如果你某些场景AI落地困难，问问自己技术基本功和数据攒够了么？如果没有底座，场景也就是个凭空愿望而已。
- 这是官方解读，当然我看到有不少老同学各种花式十层解读：什么审美《=》数据，体系《=》基本功，什么底下实事求是上面解放思想，什么Y模型映射，的确也有一些道理，醍醐灌顶。
- 这些不够严谨而且有些抽象过度，这是你们的观点啊，官方暂不收录。
- 理解到这一层，基本上就能开始有一个体感：协作默契。
- 协作默契 双三角使用入门的标志性现象：
  - 不迷信：不迷信任何AI强大，只是一个特性而已。
  - 不怪罪：结果不好，跟AI无关，全是自己太弱了。
- 什么时候该放手，什么时候该抓到自己手里，不轻易让渡给AI，有了这个模型，慢慢就可以打磨出这种协作默契。
- 好啊，继续推导，这两个三角的内在关系什么呢？是简单的两块积木硬拼在一起吗？内部的本质逻辑是什么呢？

## 第四步推导：形成飞轮

- 双三角的精髓，在于飞轮
- 敲黑板，说重点
- 大家充分理解这个逻辑么？如果只是一个"简单的分解工具"，双三角的价值就被远远低估了，这是一个自增强的飞轮，典型的特点是启动很难，但是在任何一个点做功都是作用到飞轮上，一旦滚起来，会自循环，越滚越快，然后以一种谁也无法抵挡的速度进步。
- 其中最大的两个卡点是：
  - 为什么我们总是无法专注修炼核心能力？没时间啊。
  - 为什么我们总是发现AI的表现不够优秀？人太弱啊。
- 那如果我们把这个飞轮构建起来，滚起来呢？
  - 人，提升审美，AI表现变好，大幅减少人的工作时间
  - 人有了时间，继续升级自己的审美和体系。
- 当我们把这个逻辑也画到图上，这张图终于完整了：
  - 创造力：✓理解底层规律 ✓善于解放思想 ✓提出创造假设
  - 场景：✓业务拆解 ✓ROI预判 ✓AI打磨 ✓组织部署
  - 人类三角：持续让自己变强；AI三角：持续使用AI更强；人变强了，调教更强AI；有了强AI，辅助人变得更强
  - 审美：✓专业见识 ✓最佳实践 ✓评价标准
  - 体系：✓科学体系思维 ✓假设验证模型 ✓稳定知识结构
  - 基本功：✓基础：LLM提示词/智能体 ✓宽度：多模态/AI工具库（∞） ✓深度：模型微调训练/工程化
  - 数据：✓非结构化数据 ✓结构化数据 ✓形成资产
- 相对于灵机一动、碎片工具和单一教程，系统早期最大的劣势就是学习和启动都很难：又复杂又无趣，又没有成就感。
- 但这是一个先难后易，先慢后快的道路，一旦掌握，后面会越来越快，产生一种复利级别的效果。
- 好啦，回到本质，我们完成最后一步推导。
- 这个模型归根结底，为什么一堂要提炼，一堂最大最大的坚持是什么？
- 同行提炼了很多很有启发、很通透的AI本质，那一堂给出的答案是追求____的？
- 答案：科学。

## 第五步推导：AI原生

- 都听出茧子了，但，什么是"AI原生"？
- "AI原生"这个词大家应该都听烂了吧？hhh
- AI原生公司，AI原生组织，AI原生产品，AI原生运营...
- 几乎每个人都渴望"AI原生"，但是好像每个人都讲不太清楚是什么。
- 在你眼里，AI原生是什么？
- 我抛出来几个典型观点，大家认可哪个？
  1. AI原生，就是全员习惯性使用LLM就是AI原生
  2. AI原生，就是没有AI，根本做不成的那些项目。
  3. AI原生，就是十倍速提效的一种工作方式。
  4. AI原生，就是把AI当做一个人/员工来培养。
  - ……
- 这些哪些对？哪些更有道理？
- 其实这些都对，但是也都不够本质，这个问题估计一两年很难有业界共识。
- 但这个时代命题，总需要有人来试着呼应。
- 我分享一个我们一堂阶段性的研究成果吧，不管是我们自己实践，还是内部教学，都可以全面提升大家的自治性和笃定感。
- AI原生一句话理解：AI不再是一个外挂的工具，而是一个完全重新架构的一套全新的工作范式。
  - 不是某一个工具用得贼溜，就是AI原生，它需要具有系统性。
  - 不是某一个项目效率提了N倍，就是AI原生，它需要具有持续性。
  - 不是某一个人学习能力很强，就是AI原生。这是一种无法摆脱AI的共生协作关系。
- 大家知道我想说什么了么？总结一句话：
- 双三角就是AI原生范式切换，这个里面的"科学的内核"
- 我们都想要"AI原生"，就像是我们都想要"年入千万"一样，只是结果。
- 什么因导致呢？你得满足足够大的需求，你得提供好的产品，你得有健康的利润。
- 喊口号价值不大，一堂五步法才是"年入千万"的科学内核。
- AI原生的组织变革，十倍速提效也是一样，都是结果。
- 而背后的因是你的体系，数据，基本功，
- 光喊口号没用，这些才是你能抓在手里的东西。
- 而双三角，就是我们这些理性务实科学派，经过层层讨论共识，给出的阶段性答案。
- 这个模型，一年半前有了"模糊感觉"，一年前提炼成"模型"，半年前凝聚了"上万人案例共识"，又经历了半年的内部反复实践和迭代，终于今天初步成熟了。
- 准备好，今天我们要做一个重大的升级：正式命名。
