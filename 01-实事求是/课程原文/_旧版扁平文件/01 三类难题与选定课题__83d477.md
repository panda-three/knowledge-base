# 截图01 提前划重点：三类难题

## 400+ 报名作业聚类出的卡点

这次讲师共创营收到了 400+ 报名作业，我们把大家在作业里写的卡点做了聚类，发现真正卡住大家的，不是 PPT 怎么做、不是逐字稿怎么写，而是三类结构性难题：

1. **第一类：选定课题**。拿到一个成人方法论，不知道该怎么"理解魂儿"，怕讲歪了。
2. **第二类：进行转译**。成人课怎么变成孩子真实遇到的问题、真实能完成的动作、真实可观察的变化。
3. **第三类：线上交付**。孩子不在面前，怎么让他愿意听、听得懂、有收获。

今天这场培训，就是把这三类难题的拆解方法一次讲清楚。

# 截图02 看见魂儿：每个课题讲五件事

## 怎么算"看懂"一个课题

选定课题的第一步，不是急着写大纲，而是先把这门课的"魂儿"看清楚。我们建议每个课题都讲清楚五件事：

1. 这门课要解决的**根本问题**是什么。
2. 这门课的**中心思想**是什么（一句话说清本质）。
3. 孩子（和老师自己）对这个课题最常见的**误解**是什么。
4. 这门课的**审美判断标准**是什么（什么叫好、什么叫歪）。
5. 这门课**最不能讲歪**的地方是什么。

这五件事没答清楚，后面所有逐字稿、案例、互动都会飘。

# 截图03 商业素质方向五课

## 总魂儿：从商业直觉走向科学验证

商业素质方向的总魂儿是一句话：**从商业直觉走向科学验证**。面对真实世界，不靠热情拍脑袋，而是用科学方法去拆解、判断、验证、迭代。这个方向一共五门课：

1. **一堂五步法**：把创业拆成需求、解决方案、商业模式、增长、壁垒五个里程碑，一课一阶段。
2. **需求洞察**：先研究客观问题，再谈方案。第一性事实是"某类用户在某场景真实遭遇的问题"，审美是实事求是。
3. **产品内核**：不是功能清单，而是"用户愿意选择你的最小解决方案"，是一门减法课。
4. **情报调研**：OSCAR 五步——Objective 定目标、Scope 划范围、Checklist 列清单、Acquisition 去采集、Reasoning 做推理；调研是为了降低关键判断的不确定性。
5. **MVP 验证**：先识别风险、再剥离关键假设，用最低成本拿到真实反馈，六个字"糙、快、猛、准、可复盘"。

# 截图04 看见未来方向五课

## 总魂儿：让孩子早一点看见未来

看见未来方向帮孩子先看见更远的世界，才能准备更好的自己。这个方向五门课：

1. **泛产品设计**：产品能力是可迁移的，以用户为中心；三大修养是理解用户、追求最佳实践、持续打磨。
2. **科学决策**：决策不靠直觉靠科学。判断一个决策质量看 ROI 三维度——宽度（要素完整）、深度（定量精准）、高度（全局视角），三角形越饱满决策越稳。
3. **人生红点**：人生底牌要早点拿到，追求时笃定、妥协时心甘。它不是职业规划、不是兴趣测试、也不是玄学使命，要落到路径、能力、资源、里程碑、复盘。
4. **领导力**：领导力 = 领导别人心甘情愿去解决难题的能力。要把管理、权力、领导力三件事区分开。
5. **AI 双三角**：人类三角 × AI 三角形成双向增强飞轮，背后是两个灵魂拷问——你想成为什么样的人、你想让 AI 帮你做什么。

# 截图05 学习提速方向五课

## 总魂儿：从努力和天赋叙事走向科学学习系统

学习提速方向的总魂儿是：**从"努力和天赋"的叙事，走向"科学学习系统"**。会学习的人，往往能更早拉开差距。这个方向五门课：

1. **时间管理**：时间管理是建模、匹配、迭代的科学过程，背后有三个可建模变量——时间可建模、事情可建模、时间与事情的匹配关系可建模。
2. **IPO 科学学习**：Goal 目标 / Input 输入 / Process 过程 / Output 产出 / Feedback 反馈五环，用系统视角诊断学习卡在哪一环。
3. **刻意练习**：不是低水平重复，而是结构完整、带反馈的非舒适区训练。三个误区要避开——勤奋不等于刻意练习、坚持不等于刻意练习、复盘也不等于刻意练习。
4. **个人知识管理**：知识不靠记忆靠系统，能力不靠天赋靠 IPO，核心是"资产化"。
5. **清单体笔记**：最朴素的格式——分点、分层、独立、专注，把 90% 到 100% 的精力压在内容质量和逻辑本身，而不是花俏排版。
