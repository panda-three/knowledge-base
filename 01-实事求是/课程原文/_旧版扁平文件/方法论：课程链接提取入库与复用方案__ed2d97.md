## 二、为什么这两次能成功（关键经验）

1. **先解决"读不到"的问题，再谈"存得好"**：课程站在登录墙后面，必须走浏览器 + 用户接管登录，而不是硬抓或放弃。
2. **识别页面渲染机制**：该站是"按视口懒加载"的长文档，直接抓取只能拿到登录页或一小段；必须滚动采集，且滚动太快会漏内容（任务 2 第一次只采到全文 1/3）。
3. **清洗是质量的核心**：页面每个视口都混着三样"噪音"——常驻左侧目录、常驻页脚、常驻评论区，不摘干净就无法拼接，还会出现大量重复。
4. **拼接用"后缀-前缀最大重叠"**：相邻快照内容重叠，逐行找最大公共重叠段再追加，能无损去重。
5. **写入走标准通道**：`lark-cli docs +create`（Markdown 导入）→ `lark-cli wiki +move`（迁入知识库），全程 user 身份。
6. **交付前回读验证**：用与生成路径不同的方式（fetch 回读）核对章节齐全、无评论残留、无重复标题。

## 三、可复用工作流（8 步）

### 第 0 步 · 环境前置

- 确认 `lark-cli` 可用；**本机代理坑**：lark-cli 调用前必须加前缀

  ```
  env -u http_proxy -u https_proxy -u HTTP_PROXY -u HTTPS_PROXY lark-cli ...
  ```
- 目标知识库：AI教育课，`space_id = 7669431379494440158`

### 第 1 步 · 打开链接并处理登录墙

- 用浏览器（mac_computer_use_tool，plane="bu"）打开链接
- 若跳到登录页 → 立即调 `interaction_request_action(type="browserControl")` 请用户扫码/快捷登录，**不要绕行**
- 登录态在浏览器会话内保持，同站后续链接通常免登录

### 第 2 步 · 判断页面渲染方式

- 快速试探：`get_page_text()` 长度。若只返回 \~2000-4000 字符（无论视口多大），判定为懒加载虚拟列表
- 页面可能弹出"定位阅读位置"进度条，期间滚动被禁用 → **等进度条消失再滚动**（必要时清 localStorage 后重载）

### 第 3 步 · 滚动采集（慢 = 稳）

- 导航到顶部（sy=0）
- 循环：`page_info()` 读 sy/ph → `get_page_text()` 存快照 → `scroll(500,400,"down",amount=3)` → sleep 0.5s 等渲染
- 结束条件：sy 到达 ph-h-5；或连续 3 次 sy 不变；**到底后再等 3 秒**，确认懒加载是否继续生长（页面 ph 会变）
- **每 10 步增量保存快照 JSON 到 /tmp**，防止 300s 工具超时丢数据

### 第 4 步 · 文本清洗（成败关键）

每个快照的结构 = 常驻左侧目录（TOC，固定行数）+ 当前视口文章片段 + 常驻评论区尾部：

1. **摘 TOC**：快照开头固定签名行（以标题行开头、以"标题 ​"结尾，任务 2 为 29 行），完全匹配则删除
2. **截断评论区**：从第一个评论者行（正则 `^.+\s\d{4}-\d{2}-\d{2} \d{2}:\d{2}:\d{2}$`）或"全文评论"起截断
3. **去页脚**：删除"真诚点赞，手留余香"（页面常驻页脚，每个视口都出现）
4. **去 UI 标签**：删除 "PlainText"、"复制"（代码块按钮文字）
5. **拼接**：后缀-前缀最大重叠匹配（`acc[-k:] == lines[:k]`）逐快照追加
6. **代码块去重**：若页面把同一代码块渲染两遍（如长 Prompt、流程图），定位起止标记相同的整块序列，删除第二份

### 第 5 步 · 完整性校验

- 用章节标题清单逐一核对出现次数与位置
- 检查无评论时间戳残留（`\d{4}-\d{2}-\d{2} \d{2}:\d{2}:\d{2}` 计数为 0）
- 统计重复行，确认无大面积重复

### 第 6 步 · 结构化 Markdown

- 大章节转 `## `，小节转 `### `；**只转首个出现的标题行**（正文里重复的句子不要转标题，避免重复标题）
- `•`/`◦` 与其后内容合并为 `- 内容`（列表项）
- `N.`/`a.` 序号与其后内容合并为有序列表
- 长 Prompt / 流程图包 \`\`\` 代码块
- 压缩连续空行

### 第 7 步 · 写入飞书知识库

```bash

cd <项目目录>
```
