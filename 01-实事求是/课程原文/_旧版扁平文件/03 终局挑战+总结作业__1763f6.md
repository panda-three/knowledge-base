# 截图05 终局挑战：如何只用500元验证一个想法？

## 敲黑板，说重点

相信大家已经学会了今天的方法，接下来，我们进入今天最后一个挑战，也是这节课的终极挑战：这一次，不是Leo的故事，也不是班级活动。而是老师遇到的真实问题，想请大家帮忙给我参谋一下。

前面说过，我开了两家文具文创店。现在是暑假，我发现个现象：孩子放暑假，但家长并不放假，很多家长要上班，孩子又不用上学，如果没有安排好暑假的去处，孩子可能就在家刷手机、发呆，常常会很无聊。

我的店里有一块空间，大概十几平米。我就在想：暑假的时候，能不能把它做成一个小小的手作空间？既可以帮助很多小朋友打发无聊的假期时光，又可以增加一些我们门店的营收。

我们有空调，有桌子，小朋友来了，可以做串珠手链、奶油胶手机壳、拼豆、不织布娃娃等各种手工DIY活动，还有吃有喝。做完的成品还可以带走。这个想法听起来还不错，对不对？

但是问题来了——如果我真的去布置空间、买材料、做宣传，可能要投入至少1到2万元。我并不想这么快就全量投入，因为这里面有几个问题，我还没有确认：

- 孩子到底愿不愿意来？
- 来了以后，能不能坐得住？
- 他们更喜欢哪一种手作？
- 他们愿不愿意为材料和体验付钱？

如果我等到钱都花出去了，空间也布置好了，才发现没人来，那就太晚了。

这里我们先用刚才的"三问"来想一想：

第一，我的想法是什么？暑假在文具店里做一个手作空间。

第二，我最需要先确认什么？孩子愿不愿意来，来了以后能不能坐得住，愿不愿意付材料费。

第三，我能用什么小办法试一下？不先装修，不大规模进货，只用500元以内做一次小型试玩。

所以现在，我只给自己500元预算。我要先验证一下，这个想法到底靠不靠谱。

## 互动：好了，老师求助你们了，如果是你，你会建议我怎么做？

1. 先简单装修一块区域。空间像样了，孩子才会觉得专业
2. 先做海报和报名链接。看有多少人扫码报名，再决定要不要做
3. 不装修，买少量材料，邀请10个孩子试玩一次，收少量材料费
4. 先问家长愿不愿意让孩子来。家长同意，项目才有可能成立

请在评论区打1.2.3.4。鼓励大家说说自己的想法。

这道题不是除了正确答案其他都错。你要想的是：

- 哪个动作最接近真实情况？
- 哪个动作最能帮我避免花大钱踩坑？

我们一个一个看：

1. 先装修一块区域。这个看起来很认真，但问题是，装修已经是在花大钱了。还没验证，就先投入，这有点像Leo第一次直接花几天时间打磨他的画结果没人买。

2. 先做海报，看有没有人扫码报名。这个有价值。它可以测试大家有没有兴趣。但是它有一个问题：它测不出小朋友来了以后能不能坐得住，也测不出他们真的喜欢做哪种DIY手作。

4. 先问家长愿不愿意让孩子来。这个也有价值。因为家长确实是重要决策者。但它还是停留在"嘴上愿不愿意"。有的家长会说愿意，但最后不一定真的带孩子来。

3. 不装修，先买少量材料，邀请10个孩子来试玩一次，收少量材料费。这个是我最倾向的方案。因为它最接近真实情况。它能同时测三件事：

- 第一，孩子愿不愿意来。
- 第二，来了以后愿不愿意坐下来做。
- 第三，愿不愿意为材料付一点钱。

比如，我先花四五百元准备少量材料，做一次小型试玩：

- 串珠手链，收费9.9元一条
- 拼豆，收费9.9元一小时，39.9元整天不限时
- 奶油胶手机壳，收费19.9元一个
- 不织布娃娃，收费29.9元一个

然后看什么？

- 看有没有人报名。
- 看小朋友来了以后能玩多久。
- 看哪个项目最先被选完。
- 看有没有孩子做完以后问："下次什么时候还能来？"

这就比单纯问一句"你喜不喜欢手作"更真实。

## 互动：下面四个动作，哪个最接近我们今天说的"验证"？

1. 我觉得这个东西肯定会火，所以我先认真准备好
2. 我问朋友："你觉得这个想法好吗？"朋友说好，我就做
3. 我让真实会参与的人做一个小选择，甚至付出一点小行动
4. 我先把所有方案做完整，再等活动当天看效果

我直接说答案，最接近的是3。为什么不是2？因为别人嘴上说"挺好""我愿意"，不一定代表他真的会买、会报名、会参加。真正更有价值的信号是：他有没有做出一点真实行动。比如：

- 投票
- 报名
- 预订
- 试用

愿意花一点点钱。愿意花一点时间。这些都比一句"我觉得挺好"更接近真实反馈。

所以，验证不是随便问一句："你喜不喜欢？"因为好的验证，不只是听别人说喜欢，而是看真实的人会不会行动。

回到这次文具店增加手作区的案例，测试一次试玩活动，不是仅仅停留在嘴上的意愿调查，而是为了验证更关键的问题：

- 有没有人来？
- 来了做不做？
- 做了愿不愿意付材料费？
- 做完还想不想再来？

所以你会发现，一个好的小测试，不一定要很贵，但它要尽量靠近真实场景。

回到刚刚文具店手工区的案例，我们再用刚才的"三问定方向，八字跑流程"套一下。

| 三问定方向 | 手作空间案例 |
|-|-|
| 我的想法是什么？ | 暑假在文具店里做一个手作空间 |
| 我最需要先确认什么？ | 孩子愿不愿意来、能不能坐得住、愿不愿意付材料费 |
| 我能用什么小办法试一下？ | 不装修，不大规模进货，先用500元以内做一次小型试玩 |

方向想清楚以后，再看八字流程：

| 八字跑流程 | 手作空间案例 |
|-|-|
| 先问 | 问孩子和家长是否感兴趣，了解他们喜欢什么手作 |
| 再测 | 邀请10个孩子来真实试玩，收少量材料费 |
| 测完就调 | 根据报名人数、停留时间、项目选择和复购意愿，决定下一步怎么调整 |

你会发现，这个方法不是让我们不行动。恰恰相反，它是让我们更聪明地行动。不是一上来就投入1万、2万，而是先用500元拿到真实反馈。

- 如果反馈很好，我再扩大投入。
- 如果反馈不好，我也只是花了500元买到一个重要答案，而不是花了2万元才发现方向不对。

好了，在大家的帮助下，我们门店的真实问题就有了一个更靠谱的验证方案，非常感谢大家。

# 截图06 总结：好想法不是想出来的，是试出来的

## 敲黑板，说重点

课程的最后，我们一起花几分钟的时间，梳理一下今天都学了点啥？

今天这节课，我们从Leo的第一次约稿讲起……第一次，Leo觉得大家夸他画得好，就代表真的会有人下单。结果接单图发出去以后才发现，点赞和夸奖有一些，但却没人下单。第二次，他去相关论坛上、QQ群里，去看别人想要什么样的画。结果就完全不一样了。他接到了人生中的第一个画稿，赚到了第一笔零花钱。第三次，他调整了自己的接稿方向，专注自己更擅长的领域。这使他不但接单成功率高，花的时间更少了，赚的钱更多了，客户满意度还高，复购也多。

后来我们又看到，班级活动也一样。如果先做完整PPT，最后才给老师看，最后才知道同学喜不喜欢，就很容易返工。最后，我们用同样的方法看了一个真实的手作空间想法。

这三个场景看起来不一样：

- 一个是画画接单。
- 一个是班级活动。
- 一个是文具店手作空间。

但它们背后的方法是一样的：三问定方向，八字跑流程。

三问，是让我们在行动之前先想清楚：

1. 我的想法是什么？
2. 我最需要先确认什么？
3. 我能用什么小办法试一下？

八字，是让我们想清楚这"三问"之后，真正开始行动：先问，再测，测完就调。

先问，不要只靠自己猜。再测，不要一上来就大量投入，力求完美。测完就调，不要停滞不前，而要不断地调整方法，让结果更好。

## 课后作业

终于到了布置课后作业的环节啦！

作业一：感受一下。听了今天的课，你有什么想法或者体会吗？有没有哪一句话、哪个故事、哪个选择题让你有一点触动？可以写出来和同学们交流。

作业二：三问定方向。试着找一个你最近想做的小事，回答这三问：

1. 我的想法是什么？
2. 我最需要先确认什么？
3. 我能用什么小办法试一下？

比如：

- 我想买一个比较贵的东西。
- 我最需要先确认：我是不是真的会经常用。
- 我能用的小办法：先借朋友的试几天，或者去店里试几次。

作业三：八字跑流程。如果你愿意挑战一下，还可以真的做一次小验证。要求不用高：

- 不超过一天。
- 不超过10元。

你可以试着完成：

1. 先问：我问了谁？问了什么？
2. 再测：我用了什么小办法试了一下？
3. 测完就调：我发现了什么？下一步准备怎么改？

比如：

- 你想买一个比较贵的东西，可以先借朋友的试一试，或者去店里试几次。
- 你想组织一次小活动，可以先问5个人，看看大家是不是真的愿意参加。
- 你想做一个小作品，可以先做一个草图或者小样，给3个人看一看。

你不用一开始就做得很完美。你只需要先小小地试一下。因为很多时候，真正让我们变厉害的，不是一次就做对，而是我们愿意听见反馈，愿意调整，愿意做下一版。
