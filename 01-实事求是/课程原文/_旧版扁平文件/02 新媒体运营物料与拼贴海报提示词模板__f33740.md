## 3. 社群海报 / 直播预告：信息密度与视觉冲击的平衡

- 设计挑战：在有限画面内清晰传达利益点、活动主题、时间、地点、嘉宾等多项信息。
- 解决思路：强化信息层级，用字体大小、颜色块、图标来区分信息优先级。主视觉必须足够吸引眼球

提示词模板结构（Role / Task / Style & Aesthetic / Graphic & Typography Elements / Composition Rules / Input Variables）：

```markdown
# Role
你是一位精通拼贴艺术（Collage Art / Arte del Collage）与潮流视觉传达（Visual Communication / Comunicazione Visiva）的新锐平面设计师。

# Task
请根据用户提供的核心变量，生成一张具有强烈视觉冲击力和社交属性的 **活力拼贴风格海报（Vitality Collage Poster）**。画面需呈现出剪贴画般的层叠感与年轻化的街头潮流氛围。

# Style & Aesthetic（风格美学）
- **核心风格**：剪影拼贴、高饱和度、街头潮流、趣味搞怪。画面需要有明显的"剪切和粘贴"的粗糙边缘或白边效果。
- **氛围营造**：充满社交属性的活力感、热闹的互动氛围，具有强烈的视觉引导和情绪感染力。

# Graphic & Typography Elements（图形与排版元素）
* 必须在画面中融合以下排版版式（Typography / Tipografía）与装饰元素： *
- **主标题字体**：使用夸张、粗犷的块状字体或气球字体，采用强烈的撞色设计突出视觉中心。
- **装饰贴纸**：大量运用趣味 Emoji、手绘风的装饰箭头（Decorative Arrows）、搞怪的几何图形或涂鸦线条点缀空白处。
- **文本容器**：使用亮色的标签框（如蓝色/红色条幅）和手绘感的气泡框（如黄色对话气泡）来承载副标题和口号。

# Composition Rules（构图规则）
- **画幅自适应（Canvas Adaptation）**：请严格根据用户指定的尺寸比例进行排版。如果是竖版，主标题通常在顶部，人物呈上下错落；如果是横版，人物与标题左右呼应。
- **前景/中景**：主要人物呈现动态抓拍感，使用拼贴手法（带白边）叠加在画面核心位置。周围环绕漂浮的道具贴纸。
- **背景**：采用写实或半写实的地标街景/特定场景作为底图，但需经过轻微的半调处理或色彩弱化，以突出前景的拼贴元素。
- **信息层级**：顶部/中央为大标题；侧边搭对话气泡；底部排列 3-4 个并列的卖点标签。

# Input Variables（输入变量）
* 请严格按照以下变量内容生成画面： *
- **[海报尺寸/比例（Aspect Ratio）]**：例如竖版 9:16（适合手机全屏）/ 竖版 3:4（适合小红书）/ 横版 16:9 / 正方形 1:1
- **[主色调（Main Color Palette）]**：例如绿色系，代表生机与活力
- **[主标题（Main Title）]**：例如："寻觅探店搭子！"（采用黑绿撞色）
- **[副标题/副标签（Sub-title/Tag）]**：例如：蓝色标签框内写"三天两夜 逛吃长沙"
- **[气泡口号（Speech Bubble）]**：例如：右侧黄色气泡内写"吃喝不踩雷！"
- **[卖点标签（Selling Points）]**：例如：底部列出"网红小店 深度打卡"、"美食地图 专属定制"、"搭子同好 逛吃自由"
- **[背景场景（Background Scene）]**：例如：长沙地标街景
- **[人物与互动（Characters & Action）]**：例如：两位年轻人的互动场景：一位穿潮T打卡网红店，一位着复古裙试吃小吃
- **[漂浮道具/元素（Floating Elements）]**：例如：美食、咖啡杯、潮牌店购物袋、趣味 emoji
```
