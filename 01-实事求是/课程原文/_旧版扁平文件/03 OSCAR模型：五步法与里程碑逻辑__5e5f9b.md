# 截图05 科学体系：认识OSCAR模型

说回来，任何一个「竞争情报调研」的工作，都可以拆分成这五步来执行，依次深入，层层递进。大家如果能够熟练掌握这五部曲，就可以应付几乎所有的竞争情报搜集工作了。所以再说一遍，这几个字母真的是强烈建议你们一定要背下来的核心方法论。

不着急，我们一步步来理解。

展开看一层，OSCAR每一步是什么：

1. 第一步，Objective 明确目标。在调研开始之前，先定清楚你要做的是什么判断。
2. 第二步，Scope 缩小范围。基于目标，想清楚要调研哪些维度和指标。
3. 第三步，Checklist 罗列清单。基于范围，列出真正值得研究的竞品和对象。
4. 第四步，Acquisition 获取情报。不择手段，把你需要的信息拿回来。
5. 第五步，Reasoning 归因判断。拿到信息，做出高质量的业务判断。

## OSCAR模型是怎么来的

说实话，总结这个模型的过程特别难，我们内部调整了好几个模型。

一方面呢，不同的创业题目，不同的阶段，不同的创业者，遇到的创业调研难题差异很大。这是一个极度非标的问题，很难找到一个简单的方法，适用于所有的情况。

另一方面呢，我们课程研发小组在调研中发现，整个互联网，关于「竞争调研」的优质信息非常少。有不少关于产品「竞品分析」的文章，但基本都是入门产品经理的练手作品，对于创业者的帮助不大。

我们教研小组采访了很多早期CEO，发现了一个有趣的现象：真正好的调研方法论，往往都在一些优秀大公司的工作流程里，在一些顶级高手的日常工作里。但由于信息比较敏感，所以很少有人愿意把它完整的整理分享出来。

因为竞争调研对于创业的价值很大，所以我们一堂想尝试挑战一下，总结一套系统的、普适的、可以被复用的、可以真正落地实操的调研打法。

我们拜访了行业内的5类专家：

1. 市场上的真实调研案例
2. 顶级投资人+VC的公司的DD（尽职调查）流程
3. 大公司做新业务的方法
4. 优秀的创业老兵
5. 市场上的研究机构

总结出了一套调研打法，简称OSCAR模型。面对任何一个调研工作，只要抓住这五个关键环节，就能大幅提升调研的质量。这套方法论，我们还给它起了个响亮的名字：调研黑客五部曲。

【划重点】「调研黑客」方法论，由五个关键执行环节组成：

1. 明确你的调研目标（Objective，目标）
2. 缩小你的调研范围（Scope，范围）
3. 罗列调研产品清单（Checklist，清单）
4. 不择手段获取情报（Acquisition，获取）
5. 拿到信息正确判断（Reasoning，归因）

为了方便大家记忆，我们教研小组给它对应了一组英文缩写，OSCAR正好就是各个步骤的英文单词首字母。

# 截图06 怎么理解："里程碑"逻辑

再展开看一层，OSCAR是一个「里程碑」模型。

细心的同学可能已经留意到，我们在模型图上已经对五个步骤做了颜色上的分组，实际上这五步就是这么一个非常直观的「前后依赖步骤」：目标→计划→执行→归因。

- 目标 = Objective：确定调研的高难目标是什么，并且牢牢锁死；
- 计划 = Scope x Checklist：缩小调研范围，想清楚关键指标，并且列出调研对象清单，这就能够制定完整、精准的调研计划；
- 执行 = Acquisition：开始动手调研，通过一轮又一轮的穷尽手段，"聪明"地拿全关键信息；
- 归因 = Reasoning：最后通过获得的情报信息，回到最初的目标，完成那个高难度的决策判断。

但是还不止如此，它之所以是一个"里程碑"模型的本质，因为它并不只是一个平铺的流程，更关键的是背后的底层逻辑关系：前后依赖，不跳步。

【划重点】OSCAR的逻辑链是：

- O决定SC：目标决定了路径，你要调研哪些维度、找哪些对象；
- S决定C：范围决定了清单，否则调研对象无边无际；
- SC指导A：调研计划越清晰，执行越果断；
- A的完成度决定R：信息拿得够不够全，决定了你能不能归因；
- R再回看O：得到结论，看能不能支撑那个需要做出的判断，完成目标。

你会发现，它们不是并列关系。是一层一层"推出来"的。你最好是把每一步都做充分、做到位，才能进入下一步。不论中间哪一步断了、缺了、没做好，后面的调研质量都一定会受影响，不是"可能"，是"一定"会受影响。

再仔细看一层，在图中除了从左往右的实线箭头，还有几处虚线和往回走的箭头，这里有几个要强调的关键动作：

- 支撑目标：从目标出发，所有动作都回到目标校验；
- 制定调研计划：从范围到清单，把计划做扎实；
- 开始动手调研：计划清晰后再执行；
- 果断执行：执行阶段不犹豫；
- 补充挖掘：信息不够时，从归因回退到获取，再挖一轮。

里程碑对应关系：目标（高难目标）、计划（维度准/竞品够）、执行（聪明/多轮）、归因（建模/交叉）。
