核心心法：慢，就是快。你在第一遍读题、读文时多花的2分钟，省掉的是后面卡住、重读、做错的20分钟。

## 关键能力——读题"三步法"

为了方便你更好的掌握"输入"这个核心能力，我们给你准备了一个学霸都在使用的"读题三步法"小抄，我们来看，同样的"读题三步法"，在数学、语文、英语中，具体怎么做。

（小抄图：读题"三步法"——数学 | 语文 | 英语）

| 遍数 | 数学 | 语文 | 英语 |
|-|-|-|-|
| 第一遍：通读 | 快速通读题目，了解大概：什么图形，点怎么动，求什么 | 快速通读文章，了解文体、大概内容、作者倾向 | 快速通读全文（跳过空格），了解故事梗概、基本时态和基调 |
| 第二遍：详读 | 圈出所有数字、角度、平行垂直关系、动点速度和范围 | 圈出首尾句、转折词、观点词、反复出现的核心词 | 圈出空格前后的逻辑词、固定搭配提示词、词性提示 |
| 第三遍：拼读 | 明确求长度、角度、面积，还是求值、证明、找关系 | 明确问主旨、细节、含义、作用，需要概括还是引用原文 | 明确考时态、语态、介词、连词，还是名词/动词搭配 |

核心口诀：先读全，再圈关键，最后问核心。

读题三遍，每一遍都有其核心动作，应用在不同的学科里，关键动作都一样。

同样的三步——"正常读、圈关键、问核心"。

- 在数学里，你圈的是数字和图形关系；
- 在语文里，你圈的是核心句和作者态度词；
- 在英语里，你圈的是逻辑词和搭配提示。

这套学习方法的骨架一样，但具体做法有所不同。说白了，你不用每科学一套全新方法，你只需要微调同一个方法。

## 第二板斧——处理与整理方法：整理出各科自己的解题套路

好，通过"读题三步法"，关键信息读进来了，很清晰。接下来第二板斧：怎么处理这些信息，想出解答思路？

第二把斧头，Process，简称P，处理。处理这个环节，就要用到我们的解题四步卡。

这套解题四步卡，是适用于"所有科目都能用的解题卡"。

## 解题四步卡——万能解题模型

（图示：四步解题法——读题审考点，按步解题再检查）

- 第一步 | 读：获取清晰的关键信息——先完整读题，圈出数字、条件、对象、目标和限制
- 第二步 | 审：判断类型、考点、核心问什么——判断题型，明确它在考什么，答案要求什么或证明什么
- 第三步 | 解：按这类题对应的步骤和知识来解——选择相关公式、定理、方法，按步骤写出推理过程
- 第四步 | 查：验算答案、检查步骤、看看有没有更好的方法——代入验算，检查逻辑漏洞，比较不同解法是否一致

读题不丢条件 | 审题不跑方向 | 解题不乱步骤 | 查题不留漏洞。

我们将解题四步卡拆解成关键可执行与操作步骤：

1. 读——3确定：读题三遍，确定题型、确定条件、确定问题
2. 审——5审提：审情景、审条件、审范围、审要求、审联系
3. 解——5依据：定义、定理、性质、公式、推论
4. 查——5检查：结果代入、试题重做、稳步检查、正反结合、引入条件

为了方便你理解和掌握，我给你一套四步卡的核心内容，每个表格内容值得你重点学习一遍。

## 读题步骤

| 步骤 | 说明 |
|-|-|
| 1、读题 | 读题是审题的基础，也许在开始读题阶段你不知道该注意什么，没有关系，此步骤对考生的要求是"一字不落"，是后面几个步骤进行的最基础内容，只有一字不落，才不会有漏网之鱼。时间允许情况下，先读一遍明确题型，读第二遍再进行题目分析，明确问题和条件。 |
| 2、明确题型 | 明确题型并不是确定是选择题还是问答题，因为这个是一目了然的，此处的明确题型是确定题目是哪个方向的题目，可能会涉及到哪些定律或者定式，这些是隐藏的已知条件，题目的考察目的也是要考察这些定律定式是否掌握。 |
| 3、明确问题 | 我们的目标是解答题目，因此最最重要的就是明确目标，找出题目的问题是什么，是几个，是否定还是肯定，需要考生答题答到何种程度，是只需要结果还是过程也需要，这些都是要明确的。 |
| 4、明确条件 | 确定目标导向之后，明确题干中给出了哪些已知条件，大部分题目中的已知条件都是一条一条给出的，在实际审题中很容易分辨。此处需要确定哪些是条件，条件有几个。 |
| 5、分析条件 | 大部分题目还是条件+问题的简单模式，但是不排除有的难题，比如某些附加题可能会掺杂一些无用条件，用来干扰考生，此点只作为注意点，不作为审题步骤。解答结束后一旦出现已知条件没有用到的情况，需要再次检查解答过程是否条理清晰完整，如果无误，此条件为伪条件，不用过分担心条件没用上的问题。 |

## 解题过程

| 步骤 | 说明 |
|-|-|
| 一是审题要准 | 看完题目要能迅速摸清条件、公式、题意等 |
| 二是思维要快 | 120分钟150分，考察的就是考生单位时间内的得分能力 |
| 三是计算要细 | 粗心大意要不得，只有细心才能得高分。 |
| 一、读懂题意 | 明确哪些是题面给出的已知和没有给出的已知，也要明确题意所要求解答的问题。 |
| 二、思考具体思路 | 根据掌握的知识，思索解答习题的解题思路。或者，根据要求解答的问题，步步逆推需要的条件，直至推导的所有条件在题意中为已知。 |
| 根据解题思路步步正向解题 | 求解题步骤之前，应尽可能地把教材上的知识和例题吃透，要求能够举一反三，如此才能有更多的解题思路；否则，基础知识没掌握好，就无法举一反三地灵活运用，这时求解题步骤，就会因为过程中出现问题而解题思路无法贯通，也就无法最终解答习题，得到正确的解题结果了。 |

## 检查步骤

| 方法 | 说明 |
|-|-|
| 1、结果代入法 | 将结果代入公式，看看能否反向求解出原题所给的已知量；或是从已知求得的结论，向已知条件推导。这是最典型的"逆向确认"方式。 |
| 2、试题重做法 | 这一方法的主要过程是：如果时间允许，可将某些试题重做一遍，如两次试题获得同一答案，解题一般就不会有错了。 |
| 3、稳步检查法 | 这一步也是从审题开始检查，以便从中发现问题进行矫正。这种方法不能发现一些根本性的错误，但却可以检查出计算和表达上的一些错误。 |
| 4、正反结合法 | 正反结合的方法通常有两种途径。一种是以检查丢、漏、误为目的的检查，这种检查多采用"正向确认"的方式进行；另一种是以判断解答方向是否正确为目的的检查，这种检查多采用"逆向确认"方式。 |
| 5、引入条件法 | 这种方法是从解答条件入手进行分析，看看答案是否符合所给条件。 |
| 6、专拣"粗心点"法 | 就是在检查时间不足的情况下，专门检查自己平时容易出错的问题。 |
| 7、多变检查法 | 根据剩余时间的多少来决定自己如何检查。若时间充足，可以挨个检查。一旦发现时间不多就要先检查分数集中的试题或自己认为把握不大的试题。 |
| 8、比照检查法 | 对于选择性试题，检查以后将题号和答案的符号写在一张纸上，然后一一对照，以避免出现填错或漏填。 |

以上这四步，是处理任何学科问题的通用框架。但具体到每一科，"审"和"解"的内容有所不同。

## 展示"四步卡"应用（示例）

我们来看，它在数学这门科目的应用：

数学（几何图形题）——刚刚那道数学题，按照四步卡是如何解决的：

题目：6. 两个直角三角板如图摆放，其中∠BAC=∠AEF=90°，∠AFE=60°，∠ABC=45°，AE⊥BC，边BC分别与AE, AF相交于点M, N. 若BC=12, 则MN=（选项：A. 2√3  B. 3√3  C. 4√3  D. 6√3）

a. 读：读题三遍，确定题型、确定条件、确定问题

- 通读：两个直角三角板共顶点A摆放，已知四个角（90°/90°/60°/45°）和BC=12，求MN。
- 详读：圈出关键信息——「∠BAC=∠AEF=90°」「∠AFE=60°」「∠ABC=45°」「AE⊥BC」「BC=12」「MN」。
- 拼读：BC这条边作"舞台"，把两条斜线AE、AF串在它上面——AE⊥BC交于M，AF交BC于N；由BC长度反推MN。
- 确定题型——几何图形选择题，三角形。
- 确定条件——圈点勾划出这道题的所有条件，两组角 + 一组垂直 + BC=12。
- 确定问题——求一条几何求线段长，求MN。

b. 审：审情景、审条件、审范围、审要求、审联系

- 情景：几何求线段（标量题）
- 条件：∠BAC=∠AEF=90°、∠AFE=60°、∠ABC=45°、AE⊥BC
- 范围：等腰直角三角形、勾股定理、三角函数，BC=12
- 要求：MN
- 联系：45°→等腰直角三角形；30°→tan30°=√3/3

c. 解：定义、定理、性质、公式、推论

- 定义：由∠BAC=90°、∠ABC=45°知 △ABC是等腰直角三角形，∴AB=AC=BC/√2=6√2。
- 定义：由∠ABM=45°且AE⊥BC（∠AMB=90°），∴△ABM也是等腰直角三角形，∴AM=BM=AB/√2=6。
- 性质：由∠AEF=90°、∠AFE=60°，∴∠EAF=30°。
- 定理&公式：在Rt△AMN中，∠MAN=∠EAF=30°，∠AMN=90°，∴MN=AM·tan30°=6×(√3/3)=2√3。

d. 查：结果代入、试题重做、稳步检查、正反结合、引入条件

- 结果代入：MN=2√3≈3.46；BM=6；则BN=BC-BM-MN=12-6-2√3≈2.54>0 ✓
- 正反结合：△ABN中∠BAN=-15°，∠ABN=45°，∠ANB=120°，与整体自洽 ✓
- 验算结果是否合理？代入原式检验？

以上就是解一道数学题的解题套路。有了这个套路，你在答题的过程中，脑子就有了一根主线，就不会跑边。仔细思考，整个解题模型可以迁移到很多学科的学习场景中。

唯一不同之处，"审"和"解"两步，是每科自己的"看家本领"。通用四步卡给你框架，而你需要为每科填充专属的内容。

## "整理方法"——整理出你的学科方法卡

整理方法，说白了就是把你在某一科成功解决问题的步骤，整理出来，变成一张你可以随时查看、拿出来用、甚至传给别人的"方法卡"。就像你整理出一张小抄，上面写着"看到这种题，第一步做什么，第二步做什么"。

整理一次，用一百次。而且，你可以为每一科都整理一张甚至多张方法卡。

（图示：中心是通用四步框架，四周延伸出数学、语文、考点、物理等各科具体用法的便签图）

就像这张图，中心是通用四步框架，四周延伸出各科的具体用法，不同之处是审和解。

【划重点】这就是你大脑里该有的样子：

- 数学方法卡里，记着"看到几何题先想辅助线，看到方程题先化简"。
- 语文方法卡里，记着"主旨题回看首尾段，含义题定位上下文"。
- 英语方法卡里，记着"看到since+时间段想完成时，看到逗号隔开可能是从句"。

工具就像盖房子搭的架子。而整理方法，就是让你自己成为那个搭架子的人。

所以，今天的课后任务之一：为你觉得最需要提升的一科，动手做一张属于你自己的"四步方法卡"。可以写在笔记本子上，建立属于自己的各学科解题模型，建模能力是一项重要的核心能力。

【划重点】第二板斧核心收获：

1. 通用四步卡：读→审→解→查（处理任何问题的框架）。
2. 各科自己的具体用法：每科的"审"和"解"步骤不同，需要你刻意总结。
3. 整理方法：把学科特有的成功步骤记下来，变成可重复使用的"方法卡"。
4. 行动：课后为你的一科，制作一张专属方法卡。
