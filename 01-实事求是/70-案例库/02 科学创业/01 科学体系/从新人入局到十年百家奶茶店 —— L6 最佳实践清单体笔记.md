# 从新人入局到十年百家奶茶店 —— L6 最佳实践清单体笔记

> **源课**：一堂 Live「从新人入局到十年百家奶茶店」  
> **案主**：古董（董晓峰）——创业十年，门店过百，营收过亿  
> **核心命题**：一个前世界500强招聘负责人，如何从奶茶行业纯新人，用科学方法在7年半开出100+直营店  
> **笔记定位**：不只还原一个连锁品牌的完整起盘过程，更提炼「入局前推演全链条」「选址×培训×订货三基本功的科学建模」「ROI驱动的科学决策四关训练」等可迁移底层模型

## 一、先看全局：古董的"十年百店"全景

### 1.1 古董是谁

| 维度 | 身份标签 |
|---|---|
| 出身 | 前世界500强公司招聘负责人 |
| 创业 | 从奶茶行业纯新人入局，7年半开出100+直营店，营收破亿 |
| 一堂身份 | 一堂MBA学员、一堂Gap计划参与者、连锁经营专家 |
| 课程地位 | 一堂唯一从头到尾讲完"如何从新人入局做到十年百店"完整历程的案主 |
| 战略目标 | 十年百店（已实现）、营收过亿（已实现）、不依赖我能自运转（已实现） |

### 1.2 四个阶段的"三张牌"对比——看清进化全貌

| 维度 | 第一阶段：新人入局 | 第二阶段：学习储备 | 第三阶段：起盘实践 | 第四阶段：未来目标 |
|---|---|---|---|---|
| **时间** | 入行前 | 2年时间 | 7年半 | 未来 |
| **核心特征** | 什么都没有，只有"想创业"的心 | 苦练基本功，积累行业认知 | 从0到100+店，营收破亿 | 持续进化 |
| 认知 | 奶茶都没有喝过几杯 | 大量阅读、大量走访、大量请教 | — | — |
| 能力 | 无行业经验，无专业技能 | 招聘能力可迁移→选址/培训/订货待建 | 选址×培训×订货三项基本功建模 | 团队已可自运转 |
| 资源 | 无资金、无人脉、无品牌 | 找到现在的合伙人，找到现在的品牌 | 品牌方区域市场，从0做到100 | — |

### 1.3 Truman开场三问

Truman在课程开篇，用三个问题为这堂课定位：

> **"作为十年创业者，今天这个时代，做小本生意，还有没有可能？"**

> **"这些年，他在一堂的历程，对我们理解创业者长期成长，有什么启发？"**

这三个问题，也是这堂课的底层主线。

## 二、新人入局：两年学习储备期——"奶茶都没有喝过几杯"

### 2.1 入局前的真实状态

| 维度 | 状态 |
|---|---|
| 行业经验 | 奶茶都没有喝过几杯 |
| 专业技能 | 无 |
| 资金 | 无 |
| 人脉 | 无 |
| 品牌 | 无 |

**唯一的牌**：招聘能力——世界500强招聘负责人的职业积累。

### 2.2 两年储备期做了什么

| 动作 | 内容 |
|---|---|
| **大量阅读** | 行业报告、连锁经营书籍、餐饮管理方法论 |
| **大量走访** | 走访大量门店，和从业者交流 |
| **大量请教** | 找行业老兵、加盟商、供应商聊天 |
| **关键思考** | "做大"还是"做久"？——最终选择了后者 |
| **关键决策** | 找到现在的合伙人，找到现在的品牌 |

### 2.3 入局前的五步法推演——"还没开店，先推演全链条"

古董在入局之前，已经在头脑中推演了五步法全链条：

| 五步法环节 | 入局前的预判 |
|---|---|
| **用户需求** | 年轻消费者，奶茶已经从"尝鲜"变成"日常消费品" |
| **产品方案** | 找到匹配的品牌，不是自己创品牌——借力 |
| **商业模式** | 直营而非加盟——"加盟可能更快，但我想要自己把模型跑通" |
| **增长方式** | 区域深耕，先在青岛扎根再考虑扩张 |
| **壁垒** | 长期的品质和品牌信任，而非短期规模 |

### 2.4 连锁经营的核心基本功预判——"还没开店，先想清楚要练什么"

入局前预判出三项核心基本功：

| 基本功 | 行业常见误区 | 古董的预判 |
|---|---|---|
| **选址** | 凭经验、看感觉、听房东说 | 需要科学模型，需要数据分析 |
| **培训** | 师傅带徒弟、口头传经验 | 需要标准化，需要可复制 |
| **订货** | 凭经验估算、堆满仓库就行 | 需要精准匹配门店规模和销售节奏 |

## 三、选址基本功：从"凭感觉"到"按模型打分"

### 3.1 选址为什么是"决定门店50%成败"的基本功

```text
选址决定了：
  → 客流量天花板（人来不来）
  → 客群匹配度（来的对不对于）
  → 租金成本率（能不能赚钱）
  → 竞争格局（竞对怎么分布）
```

### 3.2 选址的科学化路径——对标全球最佳实践

**对标对象**：肯德基——全球最成熟的连锁选址体系之一。

**肯德基选址给古董的启发**：

| 肯德基做法 | 古董的落地 |
|---|---|
| 精准测算人流量 | 从"凭眼睛看、经验感受"→**数人头工具表**，分时段统计 |
| 沉淀"建店模型" | 从"测算业绩特别依赖个人专业度"→**多维度评分模型** |
| 提前制定"网络规划" | 从"只有粗略计划"→在目标城市画候选区域 |

**L6级核心认知**：选址不是"走到一个铺面觉得不错就定下来"，而是**先有网络规划（在哪个城市、哪个区域铺），再去该区域找具体铺面**。很多新手做反了——先看到一个铺面觉得不错，再倒推这里行不行。

### 3.3 选址基本功的核心动作链

```text
第一步：网络规划——在目标城市画出候选区域
第二步：精准测流——数人头工具表分时段统计
第三步：代入建店模型——坪效、房租占比、盈亏平衡测算
第四步：竞品分析——同区域竞品经营状况
第五步：团队评审——不是老板一人拍板，按模型打分
```

### 3.4 选址能力的组织化——从依赖能人到团队可协作

| 阶段 | 选址方式 | 开店速度 |
|---|---|---|
| 转型前 | 依赖个别人经验选址 | 2年开30家店 |
| 转型后 | 团队成员皆可按流程选址 | **半年开出30家店** |

## 四、培训基本功：订货能力的四阶段进化

### 4.1 订货为什么值得练成基本功

奶茶门店的订货直接影响：
- 资金占用（货太多→现金流紧张）
- 缺货损耗（货太少→断货丢生意）
- 物流成本（订货频率不合理→运费浪费）
- 净利润（成本率每降1个百分点，利润就多一截）

### 4.2 订货基本功的四阶段演化——颗粒度随规模逐步细化

| 阶段 | 门店数 | 订货方式 | 核心原则 | 制度配套 |
|---|---|---|---|---|
| **第一阶段** | <10家 | 督导凭经验估算，每月固定时间下单 | **堆满仓库不缺货就行** | 无 |
| **第二阶段** | 10-20家 | 引入千元订货公式+安全库存原则+节省运费原则 | 有章法但质量还不稳定 | 纳入副店长培训+晋升考试 |
| **第三阶段** | 20-40家 | 优化月度库存盘点+订货量计算 | 督导+店主管共同完成 | 与绩效挂钩 |
| **第四阶段** | 40-100家 | 搭建中台+IT系统，订货频次从月度升级为**周度** | 店主管填数据→中台校准 | 统计错误+绩效挂钩+月度经营会汇报 |

**最终成果**：成本率降低1.5个百分点，净利润提升10%。

### 4.3 L6级核心认知

> "基本功化的颗粒度要和业务阶段矛盾匹配。如果第一天就用第四阶段的SOP+中台+IT系统，在不到10家店时根本不值得——员工素质、门店数量、收入利润都撑不起来。但如果在规模化发展过程中既不追求也没有能力细化基本功，大概率很难把门店开到100+家。"

**核心公式**：基本功颗粒度= f（门店规模、团队能力、ROI可承受度）。不是越细越好，而是**和阶段矛盾匹配**。

## 五、古董在一堂的成长历程——「ROI驱动的科学决策」四关训练

### 5.1 古董的一堂课表

| 时间 | 关键节点 |
|---|---|
| 加入一堂 | 早期学员 |
| 关键课程 | 五步法、科学决策、ROI、单元模型、预判、增长、壁垒 |
| 关键作业 | 一份满分作业 |
| 关键身份 | 一堂MBA学员、Gap计划参与者、案例课案主 |

### 5.2 古董在一堂的核心收获——ROI作为"十年基本功"

| 层次 | 含义 | 古董的运用 |
|---|---|---|
| **宽度视角** | 不只算财务，算全量收益和成本项 | 培训的价值不算进去，只看营运数据就一定选错 |
| **深度视角** | 不只算短期，算长期和机会成本 | "最多60万损失换十年百店时间窗口" |
| **高度视角** | 不只算自己，算公司视角、团队视角 | 招聘能力拉满是现实约束，不代入现实做不出对的选择 |

### 5.3 一堂对古董创业发挥的几个重要帮助

| 帮助 | 具体体现 |
|---|---|
| **创业底层框架** | 五步法提供了从需求到壁垒的全局思维框架 |
| **基本功体系** | 教会"拆建推练"四字诀——拆关键动作、建做事套路、推团队共识、练大量重复 |
| **决策方法论** | ROI驱动决策——所有重大决策都在画布上跑一遍再做 |
| **长期信念** | "长期十倍努力ROI可能不高，但长期一倍更好才是壁垒" |

### 5.4 为什么古董能成为一堂"最佳案例样本"

Truman的评价：

> "古董最大的特点是'平衡'。他不是那种'赌性很强'的创业者，也不是那种'过度保守'的经营者。他有一种非常难得的特质：**该快的时候敢快（16个月14家店），该慢的时候能慢（两年学习储备期、订货基本功逐阶段进化），该坚持的时候能坚持（十年目标从不偏移）。**"

## 六、跨案例提炼：L6 级底层模型

### 模型一：新人入局科学起盘的「三阶段法」

```text
第一阶段：学习储备（入局前）
  核心动作：大量阅读+大量走访+大量请教
  核心产出：行业认知+五步法预判+基本功清单
  关键决策：做大还是做久？加盟还是直营？选哪个品牌？
  古董用时：2年

第二阶段：起盘验证（0→1→10）
  核心动作：精益验证单店模型→跑通UE→建立基本功
  关键决策：开多快？用什么节奏复制？
  古董成果：16个月14家店

第三阶段：规模复制（10→100）
  核心动作：基本功标准化→人才培养→组织升级
  关键决策：培训vs营运如何平衡？组织怎么匹配规模？
  古董成果：7年半100+店
```

### 模型二：连锁经营的三项核心基本功识别框架

```text
识别方法：在所有的业务动作中，找到那些
  → 高频重复（每天都在发生）
  → 决定成败（做不好直接影响利润和成长）
  → 可标准化（可以拆成步骤和标准）
  → 随规模需要不断进化

古董的三项：
  ✅ 选址——决定50%的成败
  ✅ 培训——决定了人才供给速度和质量
  ✅ 订货——直接决定资金占用和净利润
```

### 模型三：基本功落地的ROI节奏判断矩阵

```text
纵轴：基本功化的投入（人力+时间+制度成本）
横轴：业务阶段和规模

关键原则：
  <10家店时：基本功ROI优先级低——核心矛盾在"活下来"
  10-40家店时：基本功ROI急剧上升——规模上去了，不规范就会失控
  40-100家店时：基本功ROI极高——没有系统就管不了

古董的订货基本功就是按照这个节奏逐阶段进化的。
```

### 模型四：从"凭感觉选址"到"按模型打分"的三层建模法

```text
第一层：对标最佳实践
  → 找到行业内公认选址最强的品牌（肯德基/茶百道）
  → 拿到他们的选址流程和方法论

第二层：本地化适配
  → 对照自身品牌阶段、客单价、门店大小、街边/商场比例
  → 调整到"跳一跳够得着"的版本

第三层：工具化沉淀
  → 数人头工具表（不是凭感觉，而是分时段统计）
  → 多维度评分模型（坪效/房租占比/竞品距离/客群匹配……）
  → 团队可操作（不再是"老板亲自去看"，而是"按流程打分"）
```

## 七、L6 级别审美清单：好的连锁经营者长什么样

| 维度 | 60分合格 | 85分优秀 | L6无限进步 |
|---|---|---|---|
| **入局姿势** | 有想法就入场 | 做几轮调研再入场 | 两年学习储备——大量阅读+大量走访+大量请教+五步法全链条推演 |
| **基本功识别** | 大概知道什么重要 | 能列出关键基本功 | 入局前就预判出选址×培训×订货三项核心基本功，并随着规模逐阶段进化颗粒度 |
| **选址方式** | 凭感觉、看铺面 | 有简单的流量估算 | 对标肯德基+茶百道→多维度评分模型→数人头工具表→团队可协作 |

## 八、可直接带走的最小行动清单

### 如果你也准备新人入局一个新行业：

1. **先做两件事——"大量阅读+大量走访"**：古董入局前奶茶都没喝过几杯，两年时间靠阅读和走访建立了行业认知。别急着开店，先把自己泡进行业里
2. **入局前先推演全链条**：用五步法把你还没开始的业务完整推演一遍——用户是谁、怎么满足、怎么赚钱、怎么增长、壁垒在哪
3. **预判你的核心基本功**：入局前就想清楚——这个业务里哪些动作是高频重复、决定成败、可标准化、需要随规模进化的？列出来，这就是你未来要练的基本功

### 如果你已经在经营连锁业务：

4. **评估你的基本功颗粒度**：你现在的基本功颗粒度和业务阶段匹配吗？<10家店时不需要100家店的SOP，但到了40家店还没有系统就会失控
5. **对标至少一个最佳实践再建模**：像古董对标肯德基选址一样——你不一定做到行业顶尖的水平，但至少要知道"好的长什么样"
6. **把ROI画成习惯**：下一次面临重大决策时，先画一张ROI画布——列全收益项、列全成本项、代入长期视角、代入现实约束。让决策从"拍脑袋"变成"算清楚"

---

> **一句话收束**：古董用两年学习储备、七年半实践、100+家直营店、20+张ROI画布的完整历程证明了同一件事——**新人入局不是劣势，前提是你愿意用科学方法弥补经验的不足。** 当他在入局前就推演了五步法全链条、预判了三项核心基本功、对标了全球最佳实践、建立了ROI驱动的决策习惯之后——一个"奶茶都没喝过几杯"的新人，可以在7年半开出100+店、营收破亿。而那句"十年百店不是一句口号，而是每一次决策时都拿出来重新秤一秤的那把秤"，和那句"基本功的颗粒度要和业务阶段矛盾匹配"，或许是所有草根创业者最该记住的两句话：**科学创业不是"听了就会"，而是"练了才懂"。而所谓基本功，不过是把一个又一个关键动作，练到不用想就能做对的程度。**
