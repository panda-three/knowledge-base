# 《搞砸4：医美、沃柑和袋泡茶》L6 清单体笔记

---

## 一、课程定位

> **一句话**：一个手握3000万的投资人、一个扎根泥土的新农人、一个20年品牌老兵——三种背景，三类赛道，同一个致命错误：把"我以为"当成了"已验证"。

| 维度   | 信息                                              |
| ---- | ----------------------------------------------- |
| 课程   | 搞砸之夜第四期                                         |
| 案例数  | 3个                                              |
| 案主   | 金宝珠（医美）、方宏纯（沃柑）、王浩海（袋泡茶 / 茶语网）                  |
| 总学费  | 合计约3500万+ 不可量化的人生代价                             |
| 共同底色 | 都在自己原本的领域有过辉煌；都带着"我能行"的自信下场；都轻视了"门外汉进入新行业"的认知鸿沟 |

## 二、3个案例逐一深挖

---

### 案例 ①｜金宝珠：投资人下场做医美，亏损3000万被迫清盘

**背景速览**

| 维度 | 信息 |
|---|---|
| 案主 | 金宝珠，一堂创始届同学 |
| 过往战绩 | 某互联网大厂高管，成都地区带领1500人销售团队，年销售额20亿+ |
| 转行身份 | 天使投资人，参与运营约5亿盘子的私募基金 |
| 项目 | 自主出资，从零打造高端医疗美容机构 |
| 起盘姿势 | 高举高打——最贵地段、最壕装修、最大团队 |
| 学费 | 约3000万，2年多烧光 |
| 案主原话 | "3000万对于大多数人来说，可能是努力一辈子都未必能创造的财富，在我手上2年多就烧完，我自己都觉得很败家" |

**搞砸路径**

```text
互联网大厂高管 + 投资人身份 → 
看到医美赛道风口（2018年最火爆）→
手握资金 + 数据 + 政府支持三张"王牌" →
试图投资现成机构未果 → "既然投不进去，自己干！" →
全团队零医美行业经验 → 花钱请人、豪华选址、全量开店 →
一系列关键假设从未验证 → 2年多烧光3000万 → 被迫清盘
```

**关键决策链还原**

| 阶段      | 做了什么                 | 问题在哪                                              |
| ------- | -------------------- | ------------------------------------------------- |
| 1. 入局   | 看到医美火爆，手握资金+数据+政府支持  | **三张"王牌"制造了过度自信**——有资源≠懂行业                        |
| 2. 决策   | 投资现成机构谈不拢，决定自己干      | "谈不拢就自己干"是创业者最危险的跳跃——**把投资能力等同于运营能力**             |
| 3. 找人   | 谈了三个月，没挖到合适的CEO      | 依然选择硬上，**核心岗位空缺时仍不刹车**                            |
| 4. 选址装修 | 选最贵地段、最壕装修、最大面积      | 完全从"我以为客户看重什么"出发——**奢华装修和人力对医美客户的成交影响远不如价格和成功案例** |
| 5. 运营   | 直营+渠道两条线平行推进，长期摇摆    | **关键假设（直营 vs 渠道）从未被明确提出和验证**                      |
| 6. 获客   | 放大互联网产品运营基因，没有线下医疗经验 | 从未拆解业务公式和漏斗，**不知道关键假设到底有哪些**                      |

**三个核心认知**

| # | 认知点 | 深度解读 |
|---|---|---|
| 1 | **资源越多，越容易跳过验证** | 案主原话："3000万有3000万的打法，300万有300万的打法。最难的是，我现在手里有3000万，很难当那2700万不存在。往往就是高举高打，不精益，不去访谈、不去调研、不去测试" |
| 2 | **关键假设不识别 = 蒙眼狂奔** | 如果再来一次，案主会优先验证这些假设：①几类医美服务目标画像差异大，客户必须拆分清楚，SKU必须聚焦；②决定客户成交的是价格和成功案例，不是奢华装修；③医美行业稀缺的是获客能力和销售能力，不是医生资源 |
| 3 | **验证成本的量级差距** | 常识 < 调研 < 验证 < 全量开发。案主直接跳到了最贵的那一档——**用全量开店替代了所有低成本验证**。案主原话："用30万能拿到的认知，不要花3000万去拿" |

> **🔑 L6级洞察**：金宝珠的案例最刺痛人的地方在于——她不是没有认知能力（本身是投资人，见过无数项目），但她把"投资人的判断力"当成了"创业者的验证力"。**知道别人为什么死，和能让自己不死，中间隔着一个"亲自下场，从零做起"。** 当你的认知和能力驾驭不了那么大的资金量时，钱一定会离你而去——这是她自己悟出的最痛的一条规律。

### 案例 ②｜方宏纯：新农人创业，沃柑踩坑负债200万+

**背景速览**

| 维度 | 信息 |
|---|---|
| 案主 | 方宏纯，新农人创业者 |
| 赛道 | 沃柑种植 + 供应链 + 销售（全链条） |
| 时长 | 四年 |
| 业绩表象 | 营收从200多万一路做到3000多万 |
| 最终结果 | 不仅没赚到钱，还负债200多万 |
| 身份 | 仍然坚持在农业赛道，转向水果连锁和香水柠檬 |

**搞砸路径**

```text
农业情怀 + 创业激情 →
做沃柑全链条（种植基地 + 供应链仓 + 销售渠道）→
三张"牌"全部算错单元模型 →
营收增长但利润为负 → 
规模越大、亏损越大 → 负债200多万 → 放弃沃柑项目
```

**三张牌，三个致命错误**

| 业务板块 | 做了什么 | 单元模型错在哪里 |
|---|---|---|
| 🃏 种植基地 | 从几十亩扩张到几百亩 | **成本项大量遗漏**：技术员、管理用房、农具设备等扩张成本完全没有算进模型。从几十亩到几百亩，不是简单乘法，成本结构发生了质变 |
| 🃏 供应链仓 | 建分选仓做品控和一件代发 | **没有波峰波谷意识**：所有预测都是"乐观预测"。真实运营中，产能利用率在波谷时极低，固定成本却一分不少 |
| 🃏 销售渠道 | 大宗销售（百果园、盒马等），年营收3000万+ | **没算"单销售模型"**：利润连销售工资都覆盖不了。更有账期长导致现金流紧张、疫情期间坏账几十万、新人经验不足导致赔付等连环问题 |

**三个核心认知**

| # | 认知点 | 深度解读 |
|---|---|---|
| 1 | **单元模型不只是"算账"，是赔钱的最后守门员** | 三个板块的单元模型全部出错——不是算得不准，而是根本没认真算。案主的原话是："单元模型是你赔钱的最后守门员"，但这个守门员在三次决策中全部缺位 |
| 2 | **规模不经济是隐蔽杀手** | 营收从200万到3000万，但成本上升更快——这是典型的"规模不经济"。产地规模不经济、人工规模不经济、供应链规模不经济，三重叠加 |
| 3 | **大宗销售的隐性成本链** | 账期拉长→现金流紧张→临时贷款；疫情期间渠道商坏账→几十万无法追回；新人供货质量不达标→赔付。表面看是增长，底下全是窟窿 |

> **🔑 L6级洞察**：方宏纯的案例最让人警醒的是——他不是一个"懒人"，他做了全链条，营收也在增长，看起来一切都在往好里走。**但增长是最危险的麻醉剂。** 当你看到营收曲线向上时，你不会想去查单元模型。而当你想查的时候，负债已经把你压住了。农业创业亏损率90%以上，不是因为这个行业没机会，而是因为太多人像方宏纯一样——带着情怀入场，却没有带着单元模型入场。

### 案例 ③｜王浩海：袋泡茶创业，从原地起飞到快速崩盘

**背景速览**

| 维度 | 信息 |
|---|---|
| 案主 | 王浩海（王老吉），一堂七年级同学，学分1112分 |
| 身份一 | 20年经验的市场老兵，服务过大益茶、八马茶、松下、西铁城、长安汽车、雷克萨斯、益力多、云南白药等品牌 |
| 身份二 | 茶语网业务合伙人（2014-2020年），内容电商+袋泡茶项目操盘手 |
| 赛道 | 袋泡茶消费品牌 |
| 资源 | 茶语网拿到3000万A轮融资，业内影响力"无人不知" |
| 项目时长 | 前后三年 |
| 学费 | 大几百万 |
| 案主自评 | "资深X型创业踩坑达人"；听课时的感受是"字字诛心，课上讲的每一个坑自己都精准地踩到了" |

**搞砸路径**

```text
茶语网起盘（茶叶版"汽车之家"）→ 
拿到3000万A轮融资 → 业内影响力极高 →
不满足于内容，转型内容电商 + 消费品 →
看到袋泡茶风口（市场报告预测2020年超350亿）→
自认为有专业茶资源 + 内容能力 + 设计能力 →
全量开发产品（前后三年）→ 
一系列"我以为"逐一被市场证伪 → 
大几百万烧光 → 项目崩盘
```

**四个"我以为"的层层证伪**

| 阶段 | "我以为" | 现实 | 代价 |
|---|---|---|---|
| 🃏 用户需求 | 大众消费者在意茶包袋的差异化、在意杯装袋泡茶的方便 | 去掉杯子、回归传统茶包袋，消费者决策不受影响。专利茶包袋和杯子这些"我们以为的卖点"，根本不影响消费决策 | 为"自以为的内核"付出了巨大生产成本 |
| 🃏 竞品分析 | 从营销角度对比优劣，以为专业茶资源是竞品不可企及的壁垒 | 根本没有拆过竞品的商业逻辑。立顿为什么那样定价？为什么有专业原叶茶资源的人没有下场做袋泡茶？——这些都没想过 | 把竞品的"商业选择"误解为"能力缺失" |
| 🃏 渠道能力 | 线上线下一起推，线下获客转移到线上 | 没有线下渠道能力，某些渠道根本铺不进去。如果认真找行业内的人聊一下，可能早就发现了 | 全量开发的产品，渠道根本接不住 |
| 🃏 目标设定 | "做出一款产品，填补市场空白，颠覆市场" | 教研同学问"具体销售额目标是什么"时哑口无言。全是又大又空的目标，没有任何定性定量 | 三年投入没有量化标尺，无法判断什么时候该止损 |

**四个核心认知**

| # | 认知点 | 深度解读 |
|---|---|---|
| 1 | **营销思维造不出好产品** | 案主原话："我们一直在设想如何把产品'呈现出来'，而不是扎根到真实业务场景中，把产品真的'做出来'。"从立项开始就是一个PPT产品方案——这是营销人创业最致命的路径依赖 |
| 2 | **敬畏心 = 默认自己是新手** | "如果我们默认自己是新手，就不会觉得我们的资源对竞对来说是优势。很有可能这只是对方商业逻辑背后的选择。"20年市场老兵的自信，让他跳过了"找行业内的人仔细聊一下"这个最基础的验证动作 |
| 3 | **没有关键假设意识 = 把预判当笃定** | 案主第一次听到"关键假设"这个概念时"惊为天人"。整个项目过程中，他一直把自己的预判当作笃定，沿着预判疯狂优化，碰壁之后再放大招——而不是把每个预判当成待验证的假设 |
| 4 | **五步法是预判工具，不是讲故事工具** | 如果当年能用五步法拆用户（专业茶人 vs 大众消费者）、拆渠道（线上 vs 线下，场景匹配吗？能力能达到吗？），很多方向在纸面上就能被证伪，根本不需要花三年几百万去验证 |

> **🔑 L6级洞察**：王浩海的案例是"专业能力反噬"的终极样本。他太懂营销了，所以他把一切问题都当成营销问题来解决——用户不买？优化卖点。渠道不进？优化话术。产品不够好？优化包装。**但真正的问题是：他从一开始就没有问过"用户到底在意什么"。** 20年的专业经验在这里不是资产，是盲区——因为他太相信自己知道答案了。

## 三、跨案例共性规律（L6级提炼）

### 规律 1：门外汉困境——「行业敬畏心的三种丧失」

| 案主 | 原领域 | 新赛道 | 敬畏心丧失的姿势 |
|---|---|---|---|
| 金宝珠 | 互联网大厂高管 + 投资人 | 医美 | "我有钱有资源有数据，稳了" |
| 方宏纯 | 新农人创业者 | 沃柑全链条 | "我热爱农业，我愿意吃苦，我能行" |
| 王浩海 | 20年品牌营销老兵 | 袋泡茶消费品 | "我有专业茶资源 + 内容能力 + 设计能力，优势明显" |

**三个人都不是笨蛋，三个人都在原领域很强。但他们都低估了一件事：新行业的"常识"，比你想象的多得多。而常识不能靠聪明来替代，只能靠敬畏来获得。**

### 规律 2：资源诅咒的第四种面孔——「认知替代的三种变体」

| 案主 | 被什么资源"诅咒" | 跳过了什么 |
|---|---|---|
| 金宝珠 | 3000万现金 + 互联网数据 + 政府支持 | 客户需求验证、关键假设识别、低成本测试 |
| 方宏纯 | 农业情怀 + 执行力 + 早期小规模成功 | 单元模型精算、规模不经济预判、大宗销售隐性成本 |
| 王浩海 | 3000万融资 + 专业茶资源 + 20年营销经验 | 用户需求验证、竞品商业逻辑拆解、渠道能力真实评估 |

**这是"搞砸"系列反复出现的规律——资源不是问题，资源让你觉得"不需要验证"才是问题。** 而且这一次，三个案主的资源类型完全不同（资金、情怀、专业经验），但导致的行为模式完全相同。

### 规律 3：验证成本的量级差距——「全量开发的诱惑」

```text
金宝珠：直接全量开店（几百万级），跳过了常识访谈（几百块）、调研（几千块）、MVP验证（几万块）
方宏纯：从几十亩直接扩到几百亩，跳过了单元模型精算（几小时）
王浩海：全量开发产品 + 全量生产（大几百万），跳过了卖点测试（几万块）
```

**三个案主都在验证成本阶梯上，直接选择了最贵的那一档。而事后回头看，那些被跳过的低成本验证，几乎都能提前暴露致命问题。**

### 规律 4：一堂五步法的「死因分布」

| 案主 | 需求/关键假设 | 解决方案 | 商业模式（单元模型） | 增长 | 壁垒 |
|---|---|---|---|---|---|
| 金宝珠 | **🔴 致命** | 🔴 | 🔴 | 🟡 | 🟡 |
| 方宏纯 | 🟡 | 🟡 | **🔴 致命** | 🔴 | — |
| 王浩海 | **🔴 致命** | 🔴 | 🟡 | 🔴 | 🔴 |

- **金宝珠死在第一步+第三步**：关键假设从未识别（直营vs渠道？客户到底看重什么？），单元模型也没算对
- **方宏纯死在第三步**：需求对、方向对，但三张牌的单元模型全部算错，规模越大死得越惨
- **王浩海死在第一步**：用户需求、竞品逻辑、渠道能力——三个最基本的假设一个都没验证

### 规律 5：「早点遇到一堂就好了」——搞砸之夜的高频忏悔

| 案主 | 原话 | 深层含义 |
|---|---|---|
| 金宝珠 | 2020年就花4000多买了股权课，但"一开始真没觉得一堂有多特别"。中途很长时间没学，过了几年再回来才发现"一堂变样子了" | **"认识一堂"和"在一堂真学"之间差了好几年** |
| 方宏纯 | Trinity的话"点醒了我"——创业是概率游戏，最重要的能力是从失败中总结认知 | **情怀不能替代方法论，但方法论可以让情怀走得更远** |
| 王浩海 | 听课"字字诛心，课上讲的每一个坑自己都精准地踩到了"；学分1112分的七年级同学 | **踩完坑再来学，知道每一句话的分量；但更好的顺序是先学再踩** |

## 四、L6级行动清单

### 🔴 如果你手里有"大资源"（资金/数据/人脉/经验）：

| # | 行动 | 对应案例 |
|---|---|---|
| 1 | 先问自己：这些资源最容易让我跳过什么验证？写下来 | 金宝珠、王浩海 |
| 2 | 假装你只有十分之一的资源，最应该先验证哪三个假设？ | 金宝珠 |
| 3 | "3000万有3000万的打法，300万有300万的打法"——你现在更像在按哪个量级打？ | 金宝珠 |

### 🟡 如果你是行业门外汉进入新赛道：

| # | 行动 | 对应案例 |
|---|---|---|
| 4 | 默认自己是新手，列出"我不知道什么"清单。找三个行业里的人深聊，而不是只靠自己调研 | 三个案例全体 |
| 5 | 竞品分析不要只做营销层的对比——去拆他的商业逻辑、定价逻辑和"他为什么选择不做某些事" | 王浩海 |
| 6 | 把你的"笃定"全部改成"假设"——如果你说不出这个判断是验证过的还是你以为的，那它就是假设 | 王浩海 |

### 🟢 如果你正在做涉及"全链条"或"重资产"的业务：

| # | 行动 | 对应案例 |
|---|---|---|
| 7 | 每一个业务板块单独算单元模型——不要只算整体账 | 方宏纯 |
| 8 | 单元模型不只算"乐观预测"——至少做三点预测（乐观/中性/悲观），尤其关注波峰波谷 | 方宏纯 |
| 9 | 营收增长时，警惕"规模不经济"——有没有固定成本在暗中吃掉利润？有没有隐性成本没入账？ | 方宏纯 |

### 🔵 如果你发现自己在用"营销思维"做产品：

| # | 行动 | 对应案例 |
|---|---|---|
| 10 | 把PPT放下，直接去问用户：如果去掉这个"卖点"，你还买不买？ | 王浩海 |
| 11 | 用最低成本测试卖点——海报、详情页、标题、软文里换不同卖点组合，看用户反应 | 王浩海 |
| 12 | 设定定性定量目标，不是"填补市场空白"，而是"6个月销售额达到X"——没有数字标尺，你永远不知道什么时候该止损 | 王浩海 |
