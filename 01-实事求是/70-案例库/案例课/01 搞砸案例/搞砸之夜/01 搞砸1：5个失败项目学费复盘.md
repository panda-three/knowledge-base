# 《搞砸1：5个失败项目学费复盘》L6 清单体笔记

---

## 一、课程定位

> **一句话**：吃一个人的堑，长一群人的智——用一堂五步法深度复盘5个真实搞砸案例，把失败变成可迁移的商业认知。

- **课程性质**：一堂「搞砸之夜」系列第一期，一次拿出5个失败案例
- **方法论工具**：一堂五步法（需求→解决方案→商业模式→增长→壁垒）
- **核心主张**：成功充满随机性（难复制），失败充满确定性（好复刻）
- **适用人群**：有创业想法的人、正在创业的人、想建立商业认知的人

## 二、5个案例逐一深挖

---

### 案例 ①｜徐睿遥：从销冠到创业，2年烧光600万

**背景速览**

| 维度 | 信息 |
|---|---|
| 案主 | 徐睿遥（磁姐），稀土永磁行业深耕20年 |
| 过往战绩 | 连续10+年每年给公司带来1.5亿营收 |
| 创业姿势 | 从零起盘，组建团队、租办公场地、做产品，高举高打 |
| 结果 | 商业模式未跑通就盲目扩张，现金流断裂，黯然离场 |

**搞砸路径**

```text
大公司销冠 → 高估个人能力边界 → 高配创业 → 
商业模式未验证即扩张 → 现金流断裂
```

**三个核心认知**

| # | 认知点 | 深度解读 |
|---|---|---|
| 1 | **角色转变的Gap** | 从大公司的销售专家到创业者，中间隔着巨大的鸿沟。销冠≠会创业，单一能力≠系统能力 |
| 2 | **创业浪费触目惊心** | 大企业出来创业，习惯 "高举高打"——豪华办公室、高薪团队、过度准备，却没有先去验证商业模式 |
| 3 | **初心与韧性的区别** | 失败后依然在行业里寻找机会是韧性，但这不能替代早期精益验证 |

> **🔑 L6级洞察**：大厂出来的创业者最容易犯的错误不是"不够努力"，而是"用资源替代验证"。你过去的成功方式，恰恰可能是你未来失败的原因。

### 案例 ②｜乔君洁：服装品牌折扣仓，12家店关停

**背景速览**

| 维度 | 信息 |
|---|---|
| 案主 | 乔君洁，20+年服装零售经验 |
| 过往战绩 | 巅峰期河南300+门店，年销售额过10亿 |
| 项目 | 品牌折扣仓（品牌往年库存打折甩卖） |
| 结果 | 花1.5年才验证生意难做，浪费约5000万机会成本 |

**搞砸路径**

```text
行业老手 + 表面资源匹配 → 忽略一个常识 →
按经验而非验证推进 → 1.5年后才发现模型不成立
```

**三个核心认知**

| # | 认知点 | 深度解读 |
|---|---|---|
| 1 | **经验≠免死金牌** | 20年行业经验不能替代对具体商业模型的验证。过去做对了A，不意味着这次做B也能对 |
| 2 | **常识的致命性** | "忽略一个常识导致满盘皆输"——越是经验丰富的人，越容易跳过对"显然正确"假设的验证 |
| 3 | **真实开源的复盘价值** | 案主毫无保留地分享行业Benchmark、折扣生意Knowhow、单店模型，让后来者避免重复踩坑 |

> **🔑 L6级洞察**：最危险的不是你不知道，而是你"以为自己知道"。20年经验的诅咒在于：你会用过去的成功来强化自信，而这恰恰阻碍你去验证那些"显而易见"的假设。

### 案例 ③｜Amanda：电影票在线选座，烧光近8个亿

**背景速览**

| 维度 | 信息 |
|---|---|
| 案主 | Amanda，连续创业者，12年创业经验 |
| 赛道 | 电影院在线选座 + 影院SaaS系统 + 出票机 |
| 资源量级 | 5轮融资共计7.98亿（天使300万→最后一轮3亿） |
| 战绩 | 合作影院2000+家，市占率一度达30% |
| 结果 | 融资花光，自救失败，黯然离场 |

**搞砸路径**

```text
赶上风口 → 融资顺风顺水 → 心态膨胀 →
只追风口不分析商业本质 → 盲目扩张忽视壁垒 → 
做不到实事求是 → 一地破碎
```

**三个核心认知**

| # | 认知点 | 深度解读 |
|---|---|---|
| 1 | **资源幻觉** | 融资越多，越容易用资源替代思考。大资源在手时的心态涨落，会导致决策严重变形 |
| 2 | **追风口但不分析商业** | 风口让增长看起来容易，但风口退去后才知道谁在裸泳。没有商业本质支撑的增长，本质上是在烧钱买时间 |
| 3 | **实事求是的稀缺性** | 草根团队拿到大资源后，最难的不是执行，而是保持"实事求是"的判断力 |

> **🔑 L6级洞察**：钱多有时候比钱少更危险。钱少逼你去验证本质，钱多让你跳过验证直接扩张。近8亿的教训浓缩成一句话：资源不是壁垒，认知才是。

### 案例 ④｜颜颖奇：全国第一家无人餐厅

**背景速览**

| 维度 | 信息 |
|---|---|
| 案主 | 颜颖奇，草根创业者 |
| 背景 | 没有餐饮经验，跨领域创业 |
| 机会 | 凭借商业敏感性和人脉，获得开全国第一家"无人餐厅"的机会 |
| 结果 | 烧光资金，惨淡离场 |

**搞砸路径**

```text
发现新机会 → 跨领域进入 → 快速开店（媒体焦点）→ 
但预判、单元模型、获客渠道全无深度思考 →
烧光资金 → 关店离场
```

**三个核心认知**

| # | 认知点 | 深度解读 |
|---|---|---|
| 1 | **跨领域的认知鸿沟** | 进入一个全新领域（尤其是跨行业+新技术），商业预判能力几乎为零。不懂行业常识的人，会把正常风险当成意外 |
| 2 | **网红效应≠商业模式** | 第一家无人餐厅的媒体曝光不等于商业可行。媒体的关注度会制造"成功"的错觉，让人跳过单元模型的认真测算 |
| 3 | **及时止损的能力** | 在明显无法盈利时，能够及时止损、保存现金流，是最被低估的创业能力之一 |

> **🔑 L6级洞察**：跨领域创业最大的陷阱不是"不懂"，而是"不知道自己不懂"。当媒体和外界都在夸你的时候，你很难承认自己其实连单元模型都没算明白。

### 案例 ⑤｜徐剑复盘：创业"梦之队"的机顶盒项目，价值3000万

**背景速览**

| 维度 | 信息 |
|---|---|
| 复盘者 | 徐剑，投资人 |
| 团队配置 | 前外企中国区总裁 + 硅谷海归 + 原广电高管 |
| 资源量级 | 起步融资1000万，次年再融2000万 |
| 业务 | ToB机顶盒 |
| 结果 | 渠道方业务调整，合作戛然而止，千万元库存滞销，创始人负债数百万 |

**搞砸路径**

```text
梦之队组建 → 全量开发产品 → 
靠资源和能力搞定大客户渠道 → 全量备货 →
渠道方业务调整 → 单一大客户依赖暴露 → 瞬间崩塌
```

**三个核心认知**

| # | 认知点 | 深度解读 |
|---|---|---|
| 1 | **团队豪华≠决策正确** | 顶级团队也会做出糟糕决策。经验让人自信，但经验也可能变成"不验证"的理由 |
| 2 | **单一大客户依赖** | 通过资源搞定渠道是捷径，但捷径的另一面是脆弱。一个外部变化就能让整个业务归零 |
| 3 | **精益的反面：全量开发 + 全量备货** | 产品没验证就全量开发，渠道未稳固就全量备货——这是典型的"用资源替代验证"的翻车姿势 |

> **🔑 L6级洞察**：梦之队的危险在于"经验共识"——当一群聪明人都认为"不需要验证"的时候，恰恰最需要验证。3000万的教训核心：运气帮你掩盖的问题，最终都会以更大的代价暴露。

## 三、跨案例共性规律（L6级提炼）

### 规律 1：从大公司/大平台到创业——「角色断裂律」

```
大公司给你的能力 ≠ 创业需要的能力
大公司给你的资源 ≠ 创业可用的资源
大公司给你的信心 ≠ 创业该有的信心
```

徐睿遥、颜颖奇、机顶盒团队，三个案例都踩了这个坑。**大厂出来的创业者，最该做的第一件事不是扩张，而是"卸载"过去成功经验带来的盲目自信。**

### 规律 2：资源是一把双刃剑——「资源诅咒律」

| 资源状态 | 行为模式 | 结局 |
|---|---|---|
| 钱少 | 被迫精益、被迫验证 | 要么快速死，要么找到真方向 |
| 钱多 | 跳过验证、全量扩张 | 烧光后才发现模型根本不成立 |

Amanda的8亿和机顶盒的3000万，都是"资源诅咒"的典型。**钱越多，越要逼自己做"穷的时候才会做的事"。**

### 规律 3：经验反噬——「专家盲区律」

```
20年服装经验的乔君洁 → 忽略了"一个常识"
12年创业经验的Amanda → 在风口中心迷失了商业本质
梦之队顶级配置 → 靠经验做关键决策
```

**经验最大的陷阱是：你越擅长某个领域，越容易跳过基础验证。因为在你的认知里，这些是"显然不需要验证的"。**

### 规律 4：早期验证缺失是最大公约数

5个案例的共同死因排序：

```text
1. 需求/假设未验证（5/5）
2. 单元模型未算清（4/5）
3. 商业模式未跑通就扩张（4/5）
4. 盲目追风口/机会（3/5）
5. 单一大客户/渠道依赖（2/5）
```

### 规律 5：一堂五步法的「哪一步死」分布

| 失败环节 | 案例数 | 代表案主 |
|---|---|---|
| 需求/关键假设 | 5/5 | 全员 |
| 解决方案 | 3/5 | 无人餐厅、机顶盒、折扣仓 |
| 商业模式（单元模型） | 4/5 | Amanda、折扣仓、无人餐厅、机顶盒 |
| 增长 | 3/5 | Amanda、机顶盒、徐睿遥 |
| 壁垒 | 2/5 | Amanda、机顶盒 |

**越往前端的问题，越致命；越靠后端的问题，越花钱。但最贵的学费总是交在"跳过了第一步"。**

### 规律 6：失败者的共同品质

```text
没有人是笨蛋，没有人不努力。
每个人都曾在自己的领域里成功过。
每个人都在某个时刻觉得自己"想清楚了"。

但创业不是"想清楚就够了"，
而是"验证过了才算数"。
```

## 四、L6级行动清单

### 🔴 如果你正在考虑创业/新项目：

| # | 行动 | 一句话理由 |
|---|---|---|
| 1 | 把关键假设写在纸上，至少列出3个 | 脑子里的假设不是假设，是幻觉 |
| 2 | 用最低成本先验证需求，别做产品 | 5个案例中5个都死在需求/假设没验证 |
| 3 | 把单元模型算到3层以上 | "看起来赚钱"和"真的赚钱"之间差了一个单元模型 |
| 4 | 设定"验证失败"的止损线 | 及时止损是这5个案例里最被低估的能力 |

### 🟡 如果你是从大厂/大平台出来创业：

| # | 行动 | 一句话理由 |
|---|---|---|
| 5 | 先卸载"过去成功经验"的盲目自信 | 销冠×1、行业老手×1、梦之队×1都死在这上面 |
| 6 | 用穷人的方式做第一轮验证 | 钱多会让你跳过最重要的那一步 |
| 7 | 角色转变不是心态问题，是能力结构问题 | 从专家到创业者，缺的不是努力，是一整套新能力 |

### 🟢 如果你已经在创业中：

| # | 行动 | 一句话理由 |
|---|---|---|
| 8 | 检查你有没有"单一大客户依赖" | 机顶盒案例：一个外部变化让3000万归零 |
| 9 | 问自己：现在做的事有没有经过验证？ | 如果不是，停下扩张，先做验证 |
| 10 | 把你的项目放进五步法重新审视 | 看一看你现在卡在哪一步，那一步下面有没有未验证的假设 |

---

> **最后一句话**：这5个案例的总学费超过**8.6亿人民币 + 不可量化的人生代价**。你不需要再交一遍。吃一个人的堑，长一群人的智——这是搞砸之夜的本意，也是这份笔记存在的意义。
