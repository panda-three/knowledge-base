# ToC案例：挂脖空调从0到数千万 —— L6 最佳实践清单体笔记

> **源课**：一堂「五步法案例必修课：挂脖空调」  
> **案主**：Cici李蕊——十年电商人，细分领域"黄埔军校"爆品操盘手  
> **核心命题**：一个比同行贵几十倍的挂脖空调，如何用五步法在5个月内从20多种用户中精准定位、十几版卖点迭代、全网卖到4000万  
> **笔记定位**：不只还原一个高客单消费品的完整起盘过程，更提炼「场景化减法」「四版卖点进化论」「六论据定价验证」「九渠道→抖音汽车大V」的可迁移底层模型与L6级科学创业审美

## 二、需求分析：从「年轻男性」到「露营四大场景」的四轮减法

### 2.1 场景化减法全景

Cici团队没有停留在"用户是年轻男性"这个笼统画像上，而是做了一个极其详尽的场景分析——把所有可能的户外场景全量列出，逐一排除：

| 类型 | 场景 | 判断 | 排除原因 |
|---|---|---|---|
| **室内** | 厨房做饭 | ❌ | — |
| | 上网课 | ❌ | — |
| | 办公室使用 | ❌ | — |
| **室外·路上** | 路上通勤 | ❌ | — |
| | 跑步 | ❌ | — |
| | 遛娃 | ❌ | — |
| | 长途旅行 | ❌ | — |
| | 游乐场 | ❌ | — |
| **室外·户外活动** | 户外工作 | ❌ | — |
| | 拍婚纱照 | ❌ | — |
| | 写生 | ❌ | — |
| | 摄影 | ❌ | — |
| | 登山 | ❌ | — |
| | 徒步 | ❌ | — |
| | 钓鱼（海钓/河钓） | ❌ | — |
| | 景点旅游 | ❌ | — |
| **露营细分** | 自带帐篷 | ❌ | 人群匹配度不够 |
| | 精致露营 | ✅ | — |
| | 公园亲子 | ❌ | — |
| **四大精准场景** | **烧烤/搭帐篷/搬运/游戏** | ✅✅✅ | **最终锁定** |

### 2.2 场景减法的核心原则

```text
不是「谁会在户外觉得热」，而是「谁在户外最需要一台空调，
且愿意付高价，且能成为内容传播的载体」。

露营用户的三重匹配：
  1. 场景匹配——露营时长时间待在户外，热是真实痛点
  2. 价格匹配——精致露营人群消费力强，1088元可接受
  3. 内容匹配——露营本身就是强内容场景，适合短视频传播
```

### 2.3 从V1到V3的需求迭代

| 版本 | 用户画像 | 核心问题 | 迭代驱动 |
|---|---|---|---|
| V1（模糊版） | 「主要是年轻男性」 | 太笼统——年轻男性在什么场景下需要挂脖空调？ | 用户调研发现场景极度分散 |
| V2（宽场景版） | 「户外活动的年轻男性」 | 仍然太宽——户外工作者和精致露营者是两类完全不同的人 | 逐一场景排除 |
| V3（精准版） | 「露营用户，四大精准场景：烧烤/搭帐篷/搬运/游戏」 | — | 所有场景全量列出→逐一验证排除 |

### 2.4 L6级核心认知

> 「很多人做消费品，用户画像停在'25-35岁男性，一二线城市，月收入XXXX'。Cici的做法是：把所有可能的使用场景全部列出来，一个一个排除，直到找到那几个最精准、最有内容传播力的场景。」

**场景 ≠ 人群标签。场景 = 用户在什么情况下会掏出这个产品。** 同样是年轻男性，在办公室开会时不需要挂脖空调，在露营地搭帐篷时需要——这就是场景化减法的力量。

## 三、产品内核：四版卖点进化——从「功能堆砌」到「制冷才是灵魂」

### 3.1 卖点迭代全景

| 版本 | 卖点 | 核心问题 | 迭代逻辑 |
|---|---|---|---|
| **第一版** | 全球首款集制冷、制热、吹风于一体的体感装备 | **贪多求全**——功能堆砌，用户根本记不住。制热在夏天是伪需求 | 加法过猛，什么都想说等于什么都没说 |
| **第二版** | 挂脖空调，秒降温，真沁凉 | 把"空调"和"降温"提出来了，但仍然不够sharp | 用户反馈："到底是空调还是风扇？" |
| **第三版** | **只有能制冷的才叫空调** | 一句话把"制冷"打透——不是风扇，不是降温，是**制冷** | 核心洞察：风扇只能吹风，空调能制冷。要的就是这个认知差 |
| **第四版** | 可穿戴空调，未来已来 | 在第三版基础上加入科技感和未来感 | 品牌化表达，为长期壁垒做铺垫 |

### 3.2 卖点进化的底层方法论

```text
加法阶段：把所有可能的卖点都列出来
  → 柔风模式/制热模式/续航无忧/颜值很酷/体感降温/精准控温系统/
    风速可达Xm/s/四季可用/三种模式/人体工学设计/全面送风……

减法阶段：问三个致命问题
  ① 用户听到这句话，会停下刷视频的手吗？
  ② 竞品能不能说同样的卖点？
  ③ 这个卖点是"加分项"还是"必须项"？

从功能参数 → 功能场景 → 品类定义 → 品牌愿景
```

**第一版到第三版的质变**：从说"我有什么功能"到说"我是什么品类"。**"只有能制冷的才叫空调"——这句话不只描述了产品功能，更重新定义了品类边界。**

### 3.3 L6级核心认知

> 「不要告诉用户你有什么功能。告诉用户，你是什么，你不是什么。'只有能制冷的才叫空调'——这句话的杀伤力在于：它把市面上所有不能制冷的挂脖风扇，全部从用户心智中'开除'了。无论竞品堆了多少功能，只要不能制冷，就不是空调——只是风扇。」

## 四、商业模式：定价1088元的「六个论据」

### 4.1 定价的艰难决策

**背景**：普通挂脖风扇市场价约几十到一百多元。1088元是普通产品的几十倍。

### 4.2 六个定价论据——验证1088元是否站得住

| 论据 | 验证方式 | 结论 |
|---|---|---|
| **论据1** | 不卖功能，卖生活方式 | 1088 ✓ |
| **论据2** | 20%用户跳过优惠券，直接下单 | 1088 ✓ |
| **论据3** | 用户不问折扣，问功能 | 1088 ✓ |
| **论据4** | 去掉优惠券后，整体收入反而上升 | 1088 ✓ |
| **论据5** | 直播间一进来就问1088那款且直接下单 | 1088 ✓ |
| **论据6** | 1288变色款上架后，成交量更大 | **1288** ✓——还有提价空间！ |

### 4.3 定价背后的思维方式

```text
常规做法：成本+利润=定价
Cici做法：用户愿意为"空调"而不是"风扇"付多少钱？

定价不是算术题，而是定位题——
  如果你把自己当风扇卖，1088是自杀；
  如果你把自己当可穿戴空调卖，1088是合理。

「不卖功能，卖生活方式」——这句话是整个定价策略的魂。
露营不是"在户外乘凉"，露营是"我在过一种更好的生活"。
为更好的生活付1088，合理。
```

### 4.4 L6级核心认知

> 「Cici没有'一拍脑袋定个价然后看能不能卖出去'，而是收集了六个独立的证据，从不同角度验证1088元的可行性。更重要的是，论据6证明了1088不是天花板——1288也有人买。定价不是算术题，而是定位题。」

## 五、增长：从9个渠道、N多类型大V到「抖音汽车大V」

### 5.1 增长探索全景

| 阶段 | 动作 | 发现 |
|---|---|---|
| **全渠道扫描** | 京东、天猫、抖音、线下活动、线上投放……全量覆盖 | 不能错失任何重要渠道 |
| **大V类型测试** | N多类型大V逐一测试 | 不同类型大V带来的用户画像和转化率差异巨大 |
| **锁定** | **抖音汽车大V** | 最精准匹配露营用户——开车去露营的人，关注汽车大V |

### 5.2 增长的深层逻辑

```text
用户链路还原：
  精致露营爱好者 → 开车去露营 → 关注汽车大V → 
  刷到汽车大V的露营内容 → 看到挂脖空调 → 种草下单

为什么是汽车大V而不是户外大V？
  → 户外大V的粉丝多是硬核户外玩家（登山/徒步），露营对他们只是「过夜」
  → 汽车大V的粉丝多是自驾露营爱好者（开车到营地、搭帐篷、烧烤），消费力更强、更匹配
```

### 5.3 L6级核心认知

> 「找准了用户和场景之后，增长不会自动发生。到底哪一类大V、哪一种形式能真正锁定目标用户，仍然需要一步步测试。Cici从9个渠道、N多类型大V中锁定了抖音汽车大V——不是在办公室里想出来的，是测出来的。」

## 七、跨案例提炼：L6 级底层模型

### 模型一：消费品的「场景化减法」模型

```text
Step 1：全量列举——把所有可能的使用场景列出来（室内/室外/通勤/运动/休闲……）
  不要用「我觉得这个场景可能行」来过滤，先全量列出，不遗漏。

Step 2：逐一排除——对每个场景问三个问题
  ① 用户在这个场景下真的有需求吗？
  ② 这个场景的用户愿意付这个价格吗？
  ③ 这个场景有内容传播力吗？（能不能拍出好看的短视频？）

Step 3：锁定精准场景——从N个场景中筛出2-4个最优场景
  挂脖空调：20+场景 → 逐轮排除 → 露营四大场景

Step 4：场景反哺卖点和增长——用场景倒推「该说什么」「在哪说」
  露营场景 → 制冷是核心需求 → 「只有能制冷的才叫空调」
  露营场景 → 用户开车去露营 → 汽车大V
```

### 模型二：卖点进化四阶模型——从功能参数到品牌愿景

```text
第一阶段：功能参数（加法阶段）
  「全球首款集制冷、制热、吹风于一体」——堆功能，什么都想说
  问题：用户记不住，也没有差异化

第二阶段：功能场景
  「挂脖空调，秒降温，真沁凉」——开始说场景体感
  问题：仍然不够sharp，和竞品拉不开差距

第三阶段：品类定义（sharp突破！）
  「只有能制冷的才叫空调」——重新定义品类
  威力：把竞品全部开除出「空调」品类

第四阶段：品牌愿景
  「可穿戴空调，未来已来」——品牌化表达
  作用：不只卖产品，更在建设品牌心智

核心公式：最好的卖点不是「我的功能比你好」，而是「我和你不是一个品类」。
```

### 模型三：定价的「六论据交叉验证法」

```text
不是「成本+毛利=定价」，而是「用户愿意为这个定位付多少钱？」

Cici的六论据：
  ① 定位论据：「不卖功能，卖生活方式」→ 这个定位需要高价支撑
  ② 行为论据：20%用户跳过优惠券直接下单 → 价格不敏感
  ③ 关注点论据：用户不问折扣，问功能 → 关注价值，不关注价格
  ④ 收入论据：去掉优惠券后收入反升 → 优惠券在降低品牌调性
  ⑤ 效率论据：直播间一进来就下单 → 价格在可接受范围内
  ⑥ 上探论据：1288款卖得更好 → 天花板还没到！

每个论据独立验证，六个交叉——结论很清晰：1088元不是贵了，是正好。
```

### 模型四：增长的「场景倒推渠道」模型

```text
不是「什么渠道能卖货」，而是「用户在这个场景下，会关注什么内容」。

场景 → 用户画像 → 内容消费习惯 → 渠道策略

挂脖空调为例：
  露营场景 → 开车去露营的人 → 关注汽车内容 → **汽车大V**

  如果只按「户外场景→户外大V」的逻辑去投，大概率投到的是登山徒步人群，
  他们不需要挂脖空调，转化率会很差。

核心公式：渠道选择 = 场景内容消费链的最后一步，
不是第一步。先有场景，再有内容策略，最后才有渠道选择。
```

### 模型五：五步法的「互相咬合」闭环模型

```text
用户（露营四大场景）
  ↕ 互相支撑
方案（空调定位×制冷卖点）
  ↕ 互相支撑
模式（1088元——因为是空调不是风扇）
  ↕ 互相支撑
增长（汽车大V——因为用户开车去露营）
  ↕ 累积指向
壁垒（品牌——从第一天就有意识建设）

五步法最大的价值不是每一步单独有多好，
而是五个步骤能不能互相验证、互相支撑、一起指向同一个方向。
```

## 八、L6 级别审美清单：好的消费品操盘手长什么样

| 维度 | 60分合格 | 85分优秀 | L6无限进步 |
|---|---|---|---|
| **用户理解** | 有用户画像（年轻男性、25-35岁） | 有场景分析 | 全量场景列举→逐一排除→锁定精准场景→场景反哺卖点和增长 |
| **卖点打磨** | 有一两句卖点 | 有几版迭代 | 四版卖点从功能参数到品类定义→「只有能制冷的才叫空调」→一句话开除所有竞品 |
| **定价策略** | 成本+毛利=定价 | 参考竞品定价 | 六论据交叉验证→从用户意愿出发→证明1088可行且1288仍有空间 |
| **增长方式** | 什么渠道都试试 | 有几个重点渠道 | 9渠道×N多大V类型逐一测试→从场景倒推渠道→锁定汽车大V |
| **全局预判** | 一步一步摸索着做 | 五个环节都有思考 | 五步法三版迭代→五个环节互相咬合→从模糊各自为战到闭合飞轮 |
| **品牌意识** | 卖货为主 | 有品牌名字 | 「从最早就认定只能是品牌，从一开始做就有意识在建设」——所有动作最终指向品牌资产积累 |

## 九、可直接带走的最小行动清单

### 如果你也在做消费品的产品定位和卖点打磨：

1. **做一次全量场景列举**：把所有可能的使用场景列出来——不要遗漏，哪怕看起来"不太可能"。然后逐一用三个问题排除——有真实需求吗？愿意付这个价吗？能拍出好看的内容吗？
2. **写四版卖点**：第一版堆功能、第二版说场景、第三版重新定义品类、第四版品牌化表达。写完放在一起对比——哪一版最sharp？
3. **收集你的定价论据**：不要只算成本和毛利。像Cici一样，从用户行为（有没有跳过优惠券）、用户关注点（问功能还是问折扣）、提价测试（加一个更贵的SKU试试）——收集至少5-6个独立的证据

### 如果你想优化增长渠道：

4. **从场景倒推渠道**：先想清楚用户在什么场景下用你的产品→这个场景下他们会关注什么内容→谁在产出这些内容？——这才是你的渠道。不是"什么渠道在卖货我就去哪"
5. **测试不同类型的达人**：不要找一个类型就定了。N多类型逐一测试——不同粉丝画像、不同内容风格、转化率可能差几倍

### 对消费品创业者：

6. **画一张五步法咬合自查表**：五个环节写出来之后，问自己——用户画像支撑定价吗？定价匹配渠道策略吗？卖点真的打中了用户最核心的需求吗？渠道能精准触达你定位的用户吗？——如果咬合不紧，再好的单点优势也做不持久

---

> **一句话收束**：Cici李蕊用挂脖空调从0到全网4000万的过程证明了同一件事——**消费品不是「我有好产品」就能卖好，而是「我找对了人、说对了话、定对了价、选对了渠道」五个环节全部咬合在一起的系统能力。** 当她用场景化减法把用户从「年轻男性」精准到「露营四大场景」、用四版卖点从「功能堆砌」进化到「只有能制冷的才叫空调」、用六个论据验证了1088元的合理性、用九渠道测试锁定了汽车大V之后——五个环节开始互相支撑、形成闭环。而那句"不卖功能，卖生活方式"，和那句"只有能制冷的才叫空调"，或许是所有消费品创业者最该记住的两句话：**最好的定位不是「我比你好」，而是「我和你不是一个品类」。最好的定价不是「我成本多少」，而是「用户愿意为这个生活方式付多少钱」。**
