# 小龙虾外卖：四年千店的科学之旅 —— L6 最佳实践清单体笔记

> **源课**：一堂评分最高的案例课之一「小龙虾外卖：4年千店的科学之旅」  
> **案主**：彭雪起（Peter）——堕落虾联合创始人，前IBM工程师，连续创业者  
> **核心命题**：一个实验室里的液氮冷冻技术，如何用假设驱动和科学实验在4年内从0开到1500家店  
> **笔记定位**：不只还原一个餐饮品牌的完整起盘过程，更提炼「预判→试错→转型→复制」的科学创业全流程与可迁移的假设驱动底层模型

## 一、先看全局：彭雪起与堕落虾的五阶段创业全景

### 1.1 彭雪起是谁

| 维度 | 身份标签 |
|---|---|
| 出身 | 2006年毕业，前期在央企和IBM做技术 |
| 创业起点 | 2012年出来跟朋友创业，最早做过男装电商，做到过年3亿规模 |
| 战绩一 | 2015年做小龙虾外卖（堕落虾），3年从0到1500+家店，融资3次，成为小龙虾行业头部品牌 |
| 战绩二 | 2019年退出后独立再次创业做跨境电商，2年10人小团队做到年销5000万美金（2023年已增长到年销1亿美金） |
| 一堂地位 | 第一个在一堂讲过多个业务且每个都拿到很好业务结果的创业者 |
| 课程地位 | 一堂所有案例课里面**学习人数最多、同学投票最高**的一节 |

**Truman的评价**：

> "创业成功是小概率事件，一次的成功可能是偶然的，连续成功的背后，大概率是有规律的。彭雪起是第一个在一堂讲过多个业务且每个都拿到很好业务结果的创业者。"

|---|---|---|---|---|
| **第1阶段：兴趣阶段** | 2014年上半年 | 发现液氮冷冻技术，做冷冻实验 | 这个技术能商业化吗？ | 技术预判 |

|---|---|---|
| **预判** | 下场前做充分调研和推演，预判做的越充分，后面踩的坑越少 | 2个月预判：行业分析、天花板计算、商业模式推演 |
| **红利** | 识别并抓住行业红利窗口期 | 2015年外卖崛起——美团开店连营业执照都不需要 |

| **科学** | 假设驱动+精益验证，不做无谓的牺牲 | 每一步都先拆关键假设，用最小成本验证 |

## 二、第一阶段：兴趣阶段——"发现液氮冷冻技术"

### 2.1 缘起：一个大学实验室的技术

2014年，彭雪起的一个合伙人特别喜欢研究新技术，有一天发现了一个大学实验室搞出来的"液氮冷冻技术"——可以在**半小时内对食材进行-169℃的秒冻锁鲜处理，保鲜期可达一年**。

**关键判断**：隐隐觉得有商业化的机会。

### 2.2 预热思考题——彭雪起带所有学习者仿真代入

> **第一道题**：如果有一天你在实验室发现了一个新技术，比如液氮冷冻技术，你隐隐觉得有商业化的机会，你具体怎么做呢？会直接买下它吗？还是直接开始创业？

> **第二道题**：你现在创业，容错率高吗？能失败和转型几次？能不能通过一些策略，让自己在大量犯错的情况下，还能活下来？

**L6级核心认知**：彭雪起没有直接买下技术，也没有立刻全职创业。他先做了一件事——**做冷冻实验，验证技术可行性**。这个阶段的核心不是"这个技术能做什么"，而是"这个技术真的稳定可靠吗"。

## 三、第二阶段：预判阶段——"预判做的越充分，后面踩的坑越少"

### 3.1 为什么预判阶段如此关键

彭雪起的核心洞察：

> "当初我们几个合伙人，最好的一个点，就是我们都很务实，很尊重客观事实，很喜欢调研和做实验。预判做的充分了，后面很多工作就都很顺了。"

**反事实推演**：如果一边开店、一边工厂生产、一边还在测试冻小龙虾、冻土豆、冻牛肉——精力和资源全分散，大概率哪个都做不成。

### 3.2 行业预判的五个核心维度（OSCAR模型雏形）

| 维度 | 具体分析 | 结论 |
|---|---|---|
| **1.拆解行业链条** | 上游产虾端→生产端（集中化冷冻加工）→终端消费（门店/外卖） | 生产端是价值洼地——可以集中化、标准化 |
| **2.洞察行业里的变化** | 小龙虾靠冷冻技术可实现全年供应、高效运输；外卖平台正在快速起量，供不应求 | 冷冻技术=供给端革命；外卖=需求端红利 |
| **3.预判下一个稳态** | 集中化生产→全国批发→提升安全/卫生品质→标准化门店 | 从分散小作坊→集中化品牌连锁 |
| **4.判断行业周期** | 小龙虾正在爆发式增长早期，竞争还比较弱 | 进入时机合适——不是太早也不是太晚 |
| **5.行业天花板大小** | 小龙虾赛道一年300-400亿空间 | 天花板够高，足够容下一个大品牌 |

### 3.3 核心动作：算清楚天花板——"预判的核心，在于算清楚天花板"

**商业模式假设**：集中化预生产→门店批发→配送到店。

| 测算维度 | 数据 | 逻辑 |
|---|---|---|
| 全国餐饮门店 | 大几百万家 | 可以批发供货给小龙虾门店+酒楼升级 |
| 保守渗透率 | 3000家批发门店 | 按团队资源和类似模式的渗透率估算 |
| 单店年用虾量 | 约1.5吨 | 基于行业常识 |
| 年产销量 | 5000吨 | 3000家×1.5吨≈4500-5000吨 |
| 产业规模 | 300-400亿 | — |
| **商业模式产值** | **3个亿（占1%）** | 5000吨×6万/吨≈3亿 |

**L6级核心认知**：

> "周子敬在《实事求是》课上讲，务实做商业，最难的点在于'定量'。的确，预判环节最难的点，在于估算清楚天花板——这个生意未来极限能做多大，这个就是你的愿景，也是你心里基本的底气。"

天花板不需要100%精确，但必须有一个基于常识和数据的估算。**没有天花板，就没有战略定力。**

## 四、第三阶段：MVP阶段——批发被拒，转型外卖，4个月跑通

### 4.1 最初的商业模式：集中化生产→批发给餐厅

既然决定集中化生产、批发模式，而且有机会颠覆整个市场，那就开干。

**MVP动作**：
- 借了一个地方和场地，借了一套冷冻设备
- 花了**40万**，试验性地生产**10吨货**（约160万的小龙虾）
- 考虑到生产简化，只做了一个口味：**麻辣味**
- 兵分两路拓展市场

### 4.2 全线溃败：批发模式被所有餐厅拒绝

| 渠道 | 动作 | 结果 |
|---|---|---|
| **第一路** | 找了一个朋友的店，直接入驻测试 | 出现了软壳问题，用户能吃出冷冻和新鲜的区别 |
| **第二路** | 找了两个线下地推的人 | 跑了一两个月，**没有一个餐厅能接受** |

**餐厅的集体反应**：

> "小龙虾怎么能冻呢？！冻了还怎么吃？我家卖的就是新鲜，如果让顾客知道我们家是冷冻虾，生意该怎么做？"

**现场惨状**：
- 出现软壳问题→专门派人去餐厅蹲着，发现软壳就丢掉→效率极低
- 很多老客能吃出区别→一点点口味差距就流失

**彭雪起的真实感受**：
> "唉，理想是美好的，现实是骨感的。没想到行业预判这么好的机会，刚跑了一个月测试，结果就这么消极。下一步该怎么办呢？"

### 4.3 关键转折：发现外卖红利，从批发→外卖

**转机**：2015年，彭雪起发现了一个新的红利——**外卖崛起**。外卖业务正在各个城市快速起量，大量餐厅都在这一年朝着外卖迁移。

**逻辑重构**：
```text
批发给餐厅 ✗ → 餐厅不接受冷冻虾
自己做外卖 ✓ → 消费者不需要知道是冷冻虾，只需要"好吃+快"
```

**最粗糙的MVP外卖店**：

| 动作 | 细节 |
|---|---|
| 开店门槛 | 美团外卖开店，连营业执照都不需要 |
| 设备 | 买了个微波炉、冰箱 |
| 装修 | 挂了个门头 |
| 开业 | 直接上线 |

### 4.4 结果——外卖模型跑通！

| 时间 | 利润 | 含义 |
|---|---|---|
| **第一个月** | 赚了**2万块钱** | 当月回本！ |
| **第二个月** | 稍微调了调模型 | **4万块钱利润** |

**L6级核心认知**：当批发模式全线溃败时，彭雪起没有"坚持优化批发模型"，而是立刻切换方向——用外卖直接面对消费者。不是放弃冷冻技术，而是**换了一个离消费者更近的场景**。冷冻技术在批发模式下是"缺陷"（不如新鲜），但在外卖模式下是"优势"（标准化加热即出餐）。

### 4.5 科学试错的底层心法

彭雪起在关键假设课上的共鸣：

> "创业要多给自己留几条命。不能一次把所有钱都投进去，要留转型的余地。"

**堕落虾的多条命**：
- 40万测10吨货（不是400万测100吨）
- 只生产一个口味（麻辣味）先跑通
- 批发不行→立刻换外卖，没有因为"已经花了40万"而死扛
- 外卖店只要一个微波炉+冰箱就可以开业

## 五、第四阶段：开始复制——6个月从1到几十

### 5.1 单店模型跑通后的关键决策

外卖店模型验证通过后，彭雪起面临的核心问题变成了：**这个模型能复制吗？**

| 复制阶段的关键问题 | 彭雪起的做法 |
|---|---|
| 门店标准化 | 核心产品统一生产（冷冻锁鲜）+门店只需加热=高度标准化 |
| 加盟商招募 | 前端招募外卖加盟商，低门槛、快回本 |
| 供应链支撑 | 集中化生产→全国分仓→冷链配送到店 |
| 品质控制 | 冷冻技术保证口味一致性——不同门店同一口味 |

### 5.2 用户端的完整闭环

```text
用户在美团外卖/饿了么下单
        ↓
加盟店收到订单 → 从冰箱取出冷冻小龙虾
        ↓
微波炉加热几分钟 → 打包
        ↓
骑手取餐 → 直接送到消费者手里
```

**L6级核心认知**：堕落虾的商业模式本质上是一个**"冷冻供应链+外卖渠道"的飞轮**——供应链越集中，产品越标准；产品越标准，复制越快；复制越快，规模越大；规模越大，供应链成本越低。

## 六、第五阶段：快速增长——从几十到1500家

### 6.1 增长飞轮全景

| 时间 | 门店数 | 关键驱动 |
|---|---|---|
| 2016年初 | 几十家 | 外卖红利+单店模型验证 |
| 2017年 | **1000家** | 加盟复制+品牌势能+融资助力 |
| 2018年 | **1500家** | 全国扩张+多口味+供应链深化 |
| 2019年初 | — | 退出业务，业务继续运营，融资两次 |

### 6.2 从复制到增长的核心支撑

| 支撑要素 | 具体内容 |
|---|---|
| **冷冻技术壁垒** | 液氮-169℃秒冻锁鲜，一年保鲜——新进入者短期难以复制 |
| **供应链集中化** | 集中化工厂生产→全国分仓→规模化降本 |
| **加盟商低门槛** | 只需微波炉+冰箱，几分钟加热即可出餐，不需要专业厨师 |
| **外卖平台红利** | 2015-2018年外卖平台高速增长，流量成本低 |
| **品牌势能** | "堕落虾"IP化——防偷吃外卖盒、精美包装、品牌故事 |

## 七、跨案例提炼：L6 级底层模型

### 模型一：科学创业五阶段模型（彭雪起原创）

```text
第1阶段：兴趣阶段
  核心问题：这个技术/想法值得深入吗？
  关键动作：做基础实验验证可行性——不花钱，用借来的设备
  核心原则：不要让"兴趣"直接跳到"全量投入"

第2阶段：预判阶段
  核心问题：这个行业有机会吗？天花板在哪？
  关键动作：OSCAR五维度分析+定量估算天花板
  核心原则："预判做的越充分，后面踩的坑越少"

第3阶段：MVP阶段
  核心问题：怎么用最低成本验证商业模式？
  关键动作：40万测10吨货→批发不行立刻换外卖
  核心原则：多留几条命，不赌身家，不因沉没成本死扛

第4阶段：开始复制
  核心问题：单店模型能复制吗？
  关键动作：标准化+加盟招募+供应链支撑
  核心原则：复制之前先确认模型健康

第5阶段：快速增长
  核心问题：如何从区域到全国？
  关键动作：融资+品牌+供应链深化+全渠道
  核心原则：规模本身就是壁垒
```

### 模型二：商业模式转型的「场景重配」模型

```text
同一项核心技术（液氮冷冻），不同场景下完全不同命运：

批发给餐厅场景：
  用户：餐厅老板 → 核心需求："新鲜"
  冷冻技术：❌ 劣势 —— "冻了还怎么吃？"
  
外卖直接ToC场景：
  用户：消费者 → 核心需求："好吃+快"
  冷冻技术：✅ 优势 —— 标准化加热即出餐，不需要专业厨师

核心公式：不是技术不行，是场景没配好。
  同一个技术，换一个离消费者更近的场景，劣势可能变优势。
```

### 模型三：行业预判的「天花板定量估算」五步法

```text
Step 1：确定商业模式假设
  → 集中化预生产→门店批发→配送到店

Step 2：保守估计可覆盖的终端数量
  → 全国大几百万家餐饮门店
  → 参考类似模式渗透率，保守估计3000家批发门店

Step 3：计算单个终端的年均用量
  → 单店约1.5吨/年

Step 4：计算总产销量
  → 3000家×1.5吨≈4500-5000吨

Step 5：计算总产值
  → 5000吨×6万/吨≈3亿（占300-400亿市场的1%）

核心原则：天花板=底气。算清楚了天花板，就知道值不值得全力投入。
```

### 模型四：科学试错的「多留几条命」原则

```text
彭雪起的"命数管理"：
  ✅ 借场地、借设备——不买，先测
  ✅ 40万测10吨货——不是400万测100吨
  ✅ 只做一个口味——先跑通单口味模型
  ✅ 批发不行立刻换外卖——不因沉没成本死扛
  ✅ 第一家外卖店只需微波炉+冰箱——精益到极致
  ✅ 第一家店当月盈利2万——快速拿到正反馈

传统做法对比：
  ❌ 买下技术 → 建工厂 → 同时测多个品类 → 全渠道铺货
  ❌ 批发被拒 → "再坚持坚持" → 继续砸钱 → 现金流断裂
```

### 模型五：连续创业者的「可迁移规律」

```text
彭雪起三次创业的共同规律：
  男装电商（年3亿） → 小龙虾外卖（1500家店） → 跨境电商（年1亿美金）

不是"碰巧成功"，而是：
  ✅ 每次都用假设驱动思考
  ✅ 每次都用精益验证起盘
  ✅ 每次都先算天花板再决定投入
  ✅ 每次都在大量试错中调通模型
  ✅ 每次都在发现新红利时果断切入

Truman的评语：
  "一次成功可能是偶然，连续成功的背后，大概率是有规律的。"
```

## 九、可直接带走的最小行动清单

### 如果你正考虑把一个新技术商业化：

1. **先做预判，再下场**：彭雪起花了2个月做行业分析+天花板计算。别急着买技术、建工厂、招团队——先在纸面上把行业链条、变化趋势、天花板算清楚
2. **拆你的关键假设，逐条验证**：冷冻技术→小龙虾→批发给餐厅——每一步都是一个关键假设。不是一次性验证所有假设，而是一条一条剥离、一条一条验证
3. **被拒绝了，换场景而不是死扛**：批发被所有餐厅拒绝→立刻换外卖。不是你的技术不行，可能是你的场景没配好——换一个离消费者更近的场景试试

### 如果你想建立科学试错习惯：

4. **40万测10吨，不是400万测100吨**：每次实验都压到最小规模——够拿认知就行，不追求规模验证
5. **多留几条命**：算算你的可用资金除以单次实验成本等于几条命。如果只有1-2条命，说明实验还不够精益
6. **用好红利窗口**：彭雪起抓住了2015年外卖崛起的红利——你所在的行业现在有什么结构性变化？早一步看到就多一分先发优势

---

> **一句话收束**：彭雪起用四年时间、从实验室里的一项冷冻技术到全国1500家门店的完整历程证明了同一件事——**科学创业不是"想清楚了再干"，也不是"先干了再说"，而是"先预判、再试错、调不通就换方向、调通了就全力复制"。** 当他在2个月预判中算清了3亿天花板、用40万测了10吨货、被所有餐厅拒绝后48小时内切换到外卖、第一家外卖店当月盈利2万——每一个动作都在践行同一个信念：**"预判做的越充分，后面踩的坑越少。创业要多给自己留几条命，在大量犯错的情况下，还能活下来。"** 而这句朴素到近乎常识的话，或许就是科学创业最底层的真相：**创业不是比谁更聪明，而是比谁活得更久、试得更多、调得更快。而活下来的前提，是每一次试错都不要赌上全部身家。**
