# 规模对抗开源：周子敬的以太大航海复盘 —— L6 最佳实践清单体笔记

> **源课**：一堂开源之夜第01号案例  
> **案主**：周子敬（以太创服CEO / 一堂荣誉校长）  
> **核心命题**：一个天生"规模不经济"的FA业务，如何做到传统FA公司10倍规模、吃掉一半市场份额？  
> **笔记定位**：不只还原打法，更提炼"对抗规模不经济"的可迁移底层模型

## 一、先看全局：这道题为什么难？

### 1.1 以太的成绩单

| 指标 | 行业常态 | 以太 |
|---|---|---|
| 团队规模 | 5-15人（很少突破20人） | 200+人 |
| 规模倍数 | 1x | **10x** |
| 市占率 | 碎片化 | **近50%** |
| 营收 | — | 亿级 |
| 融资 | — | 大几千万 |

**一句话总结**：一个天生绑在专家身上的业务，硬是被拆开、重组、工业化，做成了平台。

### 1.2 FA业务的天然"规模不经济"基因

| FA的四重复制难度 | 具体表现 |
|---|---|
| **更非标** | 背景、擅长领域、工作方法都不一样 |
| **更优秀** | 名校/名企/知名VC出身，人才供给极少 |
| **更高薪** | 资深FA常年年入百万，养人成本极高 |
| **更独立** | 工作协作少，一个人能完成闭环，"凭什么跟你干" |

**核心矛盾**：

```
单FA模型基准值：每年融资成功 2-3 个项目
风险：资本环境不好、融资成功率低于30%时 → 很难养活FA → 团队流失
```

**子敬的核心命题**：怎么让一堆聪明、高薪、独立、非标的专家，在一个平台上稳定协作产出，而不是各自飞走？

### 1.3 全局预判：终极目标不是FA团队

```text
"我们是国内最知名的FA公司之一，但其实我们的终极目标并不是FA团队。"
```

周子敬从一开始就没有把以太定义成"一个更大的FA公司"，而是**用平台模式重新定义FA**。这个认知差，是后续所有对抗策略的思想地基。

## 二、核心框架："规模经济对抗表"全景

### 2.1 一个总公式

```text
找到最规模经济的点 → 把它发扬光大
找到最规模不经济的点 → 把它对抗掉
```

### 2.2 以太规模经济对抗全景表（本课最核心资产）

| 分类 | 要素 | 策略 | 具体工作/设计要点 |
|---|---|---|---|
| **规模经济（发扬光大）** | 双边市场 | 开发APP | 率先发布以太优选APP，自动化+持续优化，提升信息效率 |
| | 品牌建设 | 品牌营销 | 以太之夜、以太行业论坛、以太Bit大会、投资黑名单 |
| | 建数据库 | 统一数据库 | 线索库、项目库、投资人库 |
| | 规模效应 | 开放平台 | 对外开放平台，引入外部FA |
| **规模不经济（对抗掉）** | 专家依赖 | 岗位分解 | 拆解专家岗位职能，把专家工作不断程序化、运营化、工具化 |
| | | 练基本功 | 拆解基本功，全员刻意练习 |
| | | 文化建设 | 统一思想，使命愿景价值观驱动 |
| | | 建知识库 | 通过建立知识库（SalesKit等），苦练基本功 |

**这张表不是一个静态分类，而是一个动态对抗系统。左侧扩张平台能力，右侧消解专家依赖，两者同时推进。** 

**关键成果**：FA从原来平均每月服务1个新案子，变成了平均能谈5-7个——服务带宽翻了5-7倍。

## 三、规模经济侧：四个扩张引擎

### 3.1 双边市场：以太优选APP

**洞察**：FA本质是双边市场——创业者找钱，投资人找项目。匹配效率是这个生意的命门。

**动作**：率先发布以太优选APP，把信息匹配自动化，持续优化匹配效率。

**为什么这是规模经济**：每多一个创业者入驻，平台对投资人的价值就大一分；每多一个活跃投资人，平台对创业者的吸引力就大一分——**典型双边网络效应**。

### 3.2 品牌建设：从服务品牌到平台品牌

| 品牌动作 | 目的 |
|---|---|
| 以太之夜 | 建立投资人社区心智 |
| 以太行业论坛 | 占领行业认知高地 |
| 以太Bit大会 | 规模化影响力输出 |
| 投资黑名单 | 建立行业话语权和信任 |

**关键认知**：传统FA公司品牌绑在个人身上（"某某大佬"），以太把品牌建在平台上（"以太优选"）。人走了品牌还在。

### 3.3 建数据库：三个核心库

| 数据库 | 内容 | 规模经济来源 |
|---|---|---|
| 线索库 | 全网200+信息源持续扫描，算法收录+人工打分 | 项目供给工业化，不受单个FA人脉限制 |
| 项目库 | 结构化项目信息 | 新人不需要从零建认知，库里有标准 |
| 投资人库 | 机构偏好、活跃度、历史成交 | 匹配效率随数据积累持续提升 |

**获客流水线**：全网扫描 → 收录算法处理 → 人工打分 → CC（电话跟进） → 进入项目库

### 3.4 开放平台：引入外部FA

把平台能力开放出去，不只养自己的FA，也让外部FA用以太的平台做交易。

**规模经济逻辑**：平台固定成本（技术、数据库、品牌）摊到更多交易上，边际成本趋近于零。

## 四、规模不经济侧：四个对抗策略（本课最深处）

### 核心洞察

```text
"对于一个团队来说，人不是能力的最小单位，基本功才是。"
```

这句话是整个对抗策略的哲学基石。周子敬的底层逻辑是：**如果你把人当作最小单元，那每多一个人就多一份不可控非标成本；如果你把基本功当作最小单元，那人是可拆解、可训练、可替换的。**

---

### 对抗策略一：岗位分解——把专家拆成零件

#### 团队拆分全景

| 拆分出的团队 | 职能 | 对抗逻辑 |
|---|---|---|
| 客服团队 | 标准化客户对接 | 把非标的"关系维护"拆成可流程化的服务 |
| 手推团队 | 项目推送匹配 | 把"撮合"拆成可操作的推荐动作 |
| CC团队（Cold Call） | 项目初筛和跟进 | 把"判断项目质量"的初级环节拆出来 |
| 线索团队 | 全网扫描+线索收集 | 把"找项目"拆成工业化流程 |
| SP团队（Support） | 支持FA核心工作 | 把专家工作中的支持性环节剥离 |
| 法律服务团队 | 交易法律支持 | 把专业法律服务集中化、标准化 |

**关键认知**：不是让FA不干活了，而是把FA工作中**可标准化、可流程化的部分拆出来，交给专门团队**，让FA只做最核心、最不可替代的事——项目谈判、业务梳理、融资节奏把控、故事包装。

**效果**：FA从月均服务1个新案子 → 5-7个。不是因为FA更努力了，而是因为**整个系统替FA承担了大量"非核心但必须做"的工作**。

---

### 对抗策略二：练基本功——全员刻意练习

#### 核心命题

岗位分解够了吗？不够。因为**最核心的专业工作还是在FA身上**——项目谈判、业务梳理、融资节奏、故事讲述——这些市场上合格的候选人极少，培养难度极高。

#### 解法：把能力拆到基本功颗粒度

```text
"对于一个团队来说，人不是能力的最小单位，基本功才是。"
```

**操作**：
- 把FA的核心能力拆解成若干项基本功（不是"会做FA"，而是"会做XX动作"）
- 每项基本功都有刻意练习体系
- 新人不需要一上来就成为全能FA，而是逐项练基本功

**对抗逻辑**：当一个能力被拆成10项基本功，你不需要找到一个"10项全能的专家"，而是可以找10个分别擅长不同基本功的人，或者让一个新人逐项练起来。**人才供给池瞬间扩大了10倍。**

---

### 对抗策略三：文化建设——使命愿景价值观驱动

#### 为什么文化建设是对抗策略？

聪明、独立、高薪的专家，天然离心力强。

**不能只靠管控**（管不住，他们比你聪明）  
**不能只靠薪酬**（总有人出价更高）  
**必须靠文化**（让他们自己愿意留下）

**以太的解法**：统一思想，使命愿景价值观驱动。让聪明人不是因为"没地方去"而留下，而是因为"这里做的事值得做"而留下。

---

### 对抗策略四：建知识库——SalesKit

#### 知识库在对抗中的角色

| 知识库类型 | 解决的问题 |
|---|---|
| FA SalesKit | 让新人快速掌握"怎么跟创业者聊""怎么跟投资人聊"的标准话术和案例 |
| 项目案例库 | 让FA能看到同类项目的处理路径，减少从零摸索 |
| 投资人偏好库 | 让匹配效率提升，减少"乱推项目" |

**对抗逻辑**：传统FA的知识在脑子里，新FA的知识在平台上。人走了知识还在，新人来了知识在手边。

## 五、两轮大航海的商业演化

### 5.1 第一次大航海：规模驱动（2014-2017）

| 维度 | 内容 |
|---|---|
| 核心驱动力 | 双边网络 + 规模优势 + 品牌 |
| 商业模式 | 佣金占融资额1-5%，FA提成30-50% |
| 增长策略 | 狂上单（用供给拉需求，双边市场） |
| 单FA模型基准值 | 每年融资成功2-3个项目 |
| 业务天花板预估 | 服务上万项目，年帮助1000-2000个项目融资成功，年营收5-10亿 |

### 5.2 市场转折：凛冬将至

| 信号 | 表现 |
|---|---|
| 市场预期下滑 | 实际市场规模和增速显著低于预期 |
| 产品内核下滑 | 好项目变少，信噪比明显变差，优秀机构陆续流失 |
| 团队信心下滑 | 不够有愿景的项目无法支撑一个Top团队 |

**动态预测触发**：当融资成功率开始低于30%时，单FA模型跑不通 → 必须做结构性调整。

### 5.3 第二次大航海：拆分与对抗深化

| 拆分动作 | 内容 |
|---|---|
| FA业务与平台业务拆分 | FA业务归入"易项"，独立运作 |
| FA业务往早期探索 | 做"百一"（更早期的项目服务） |
| 探索教育业务 | 以太内部孵化一堂——从"帮项目融资"到"帮创始人成长" |

**三个最终业务板块**：FA（易项） + 投融资平台 + 教育（一堂）

## 六、以太的五步法全景拆解

### 全量五步法画布

| 维度 | 关键要素 |
|---|---|
| **需求** | 投资人端：每月找到3个值得约聊的项目；创业者端：融资成功率30%+专业辅导 |
| **解决方案** | 工业化Leads收集 + 工业化FA复制 + 质量控制持续升级 |
| **商业模式** | 佣金1-5%，FA提成30-50%；核心驱动力=双边网络+规模优势+品牌 |
| **增长** | 狂上单（供给拉需求）；品牌活动+大规模拜访；信噪比领先+效率领先 |
| **壁垒** | 双边网络效应（非技术壁垒/非转化成本/非成本优势） |

### FA复制难度的深层认知

| 四重非标 | 以太的对抗 |
|---|---|
| 背景/擅长/方法都不太一样 | → 岗位分解 + 标准化团队 |
| 名校/名企/知名VC出身 | → 降低人才门槛，拆成基本功 |
| 资深FA年入百万 | → 平台提升服务带宽，让FA收入不降反升 |
| 可以独立完成目标，协作少 | → 文化建设 + 平台价值绑定 |

**核心公式**：

```text
服务宽度 × 预期收入提成 ≥ 市场人才的薪资水平
```

只要平台能让FA的服务宽度从1个案子变成5-7个案子，即使单个案子提成略低，总收入依然不逊于自己单飞——**这就是平台留住专家的底层经济逻辑**。

## 七、跨案例提炼：规模不经济对抗 L6 级底层模型

### 模型一：规模经济/不经济双螺旋

```text
规模经济侧（发扬光大）：     规模不经济侧（对抗掉）：
┌─────────────────┐       ┌─────────────────┐
│ 双边市场/网络效应  │       │ 岗位分解          │
│ 品牌规模效应      │  ←→  │ 练基本功          │
│ 数据库/案例积累   │       │ 文化建设          │
│ 开放平台          │       │ 建知识库          │
└─────────────────┘       └─────────────────┘
         ↓                        ↓
    平台能力越强           专家依赖越弱
         ↓                        ↓
         └──────── 同时推进 ────────┘
                      ↓
              规模天花板不断上移
```

### 模型二：专家依赖业务的四步对抗法（以太原创）

| 步骤 | 策略 | 核心问题 | 以太的操作 |
|---|---|---|---|
| 第1步 | 岗位分解 | 专家工作里哪些可以拆出来？ | 拆出客服/手推/CC/线索/SP/法律6个团队 |
| 第2步 | 练基本功 | 拆完剩下的核心能力还能继续拆吗？ | 把FA能力拆到底层基本功，逐项刻意练习 |
| 第3步 | 文化建设 | 拆散后怎么让不同团队依然合力？ | 使命愿景价值观统一，不靠管控靠信仰 |
| 第4步 | 建知识库 | 怎么让新人快速接近专家水平？ | SalesKit+案例库+投资人偏好库 |

**关键认知**：这四步不是线性关系，是并行推进。你不可能等岗位分解完美了再练基本功，也不可能等知识库完整了再推文化。**四步同时跑，互相加速。**

### 模型三：人不是最小单元，基本功才是

```text
传统思维：
  专家 = 最小单元 → 每多一个专家就多一份非标成本 → 天花板=能找到多少专家

以太思维：
  基本功 = 最小单元 → 专家 = 多项基本功的组合 → 天花板=能训练多少项基本功
```

**适用场景**：任何"优秀人才很难找、很难培养、很难复制"的业务——咨询、投资、销售、设计、教研、医疗诊断、法律服务……

### 模型四：平台留人的底层公式

```text
传统FA：个人服务带宽 × 佣金率 = 个人收入
         （月均1个案子 × 高佣金 = 高收入）

以太FA：平台服务带宽 × 平台佣金率 = 个人收入
         （月均5-7个案子 × 略低佣金 = 依然高收入）
```

**平台的价值**：不是压低专家收入，而是**放大专家的产出效率**。让专家在平台上赚的钱不比自己单飞少，同时享受平台的品牌、数据库、支持团队。

### 模型五：规模不经济的五个常见面孔（对照自查）

| 你的业务依赖什么… | 规模不经济的来源 | 以太式对抗思路 |
|---|---|---|
| 专家个人判断 | 好专家太少，培养太慢 | 岗位分解 + 拆成基本功 + 知识库替代 |
| 销售个人关系 | 好销售太贵，带走客户 | 把获客工业化 + 把服务标准化 + CRM知识库 |
| 主播/内容创作者 | 头部通吃，腰部难活 | 平台流量分配 + 内容模板化 + 供应链支持 |
| 高端手艺人（设计师/律师/医生） | 时间=产能上限 | 拆出支持团队 + 模板化 + 知识库辅助 |
| 管理者个人能力 | 好店长/好校长太少 | 标准化SOP + 降低决策难度 + 集中化支持 |

## 八、L6 级别审美清单：好的规模对抗长什么样

| 维度 | 60分合格 | 85分优秀 | L6无限进步 |
|---|---|---|---|
| **识别能力** | 知道业务有规模不经济 | 能定位最规模不经济的要素 | 能动态预测哪些要素在什么阶段变成瓶颈 |
| **对抗策略** | 只有一招（如多招人/加钱） | 有2-3个策略并行推进 | 四步并行——岗位分解+基本功+文化+知识库，形成对抗系统 |
| **岗位分解深度** | 把"打杂"的活分出去 | 把支持性工作拆成专门团队 | 把核心专业工作本身也拆成可训练的基本功单元 |
| **基本功颗粒度** | 把能力当最小单元 | 把技能当最小单元 | 把基本功当最小单元——人不是最小单位 |
| **平台价值** | 品牌+工具 | 品牌+数据+匹配效率 | 双边网络效应 + 品牌 + 数据库 + 开放生态 |
| **应对变化** | 市场变了被动收缩 | 提前预判+拆分业务 | 从模型变化中识别战略机会+孵化新业务 |

## 九、可直接带走的行动清单

1. **画一张你自己的规模经济对抗表**：左边列出你业务里最规模经济的要素（怎么放大），右边列出最规模不经济的要素（怎么对抗）

2. **做一次岗位分解**：把你最关键的那个"专家角色"拆开——哪些工作可以程序化、运营化、工具化？哪些必须专家亲自做？

3. **拆到基本功颗粒度**：选一个核心能力，把它拆成5-10项基本功。每项基本功有没有刻意练习的方法？

4. **检查你的知识库**：你的业务知识是在人脑子里，还是在文档里？人走了知识还在吗？新人来了知识在手边吗？

5. **算一条核心公式**：你的"专家"服务带宽是多少？平台能把带宽放大几倍？放大后的收入还能留住ta吗？

6. **建三道预警线**：像以太关注"融资成功率低于30%"一样，你的单专家模型里，什么指标下滑到多少时，模型会崩？

7. **如果做平台，先想双边**：你平台的哪一端更难获取？用供给拉需求还是需求拉供给？以太的选择是"狂上单"——用项目供给拉投资人。

---

> **一句话收束**：周子敬用一堂五步法画出了以太的全景图，但真正让以太从15人变成200人的，不是画布本身，而是画布右侧那四个字——"对抗规模不经济"。拆岗位、练基本功、建文化、沉淀知识库——四步并行，把FA从一个"人"的生意，变成了一个"系统"的生意。
