# 知识管理开源：小红书、医疗和个人 —— L6 最佳实践清单体笔记

> **源课**：一堂开源之夜·知识管理专题  
> **三位案主**：张甘木（文案）· 饶冠华（医疗）· 古董（跨阶段）  
> **笔记定位**：不只还原案例，更提炼可迁移的底层模型与审美标准

## 一、先看全局：三个案例，一条主线

| 案主 | 领域 | 核心命题 | 知识管理段位跃迁 |
|---|---|---|---|
| 张甘木 | 小红书文案 | 如何用知识管理从零修炼一项专业能力，并复制给团队 | 备忘 → IPO → 主题学习 → 自建体系 → 团队复制 |
| 饶冠华 | 医疗检测 | 如何用知识管理降低专家依赖，实现规模培养 | 问题诊断 → 工作流拆解 → 知识萃取 → 知识库搭建 → 段位图培养 |
| 古董 | 咨询/管理/创业 | 不同人生阶段，如何切换知识管理策略 | 最佳实践档案馆 → 团队管理知识库 → 创业决策全景图 |

**三个案例共同回答一个问题**：知识管理不是"收藏更多资料"，而是**把外部知识变成自己解决问题的能力，进而变成团队的基本功**。

## 二、张甘木：十年知识管理，练出文案能力体系

### 阶段一：做备忘（L3——全部沉淀，方便调用）

**核心动作**：
- 使用印象笔记一键保存，原封不动收藏
- 用 EverMemo 随手记碎片灵感和金句
- 关键词：**确定性**——"沉淀的内容都能搜索，心里不慌"

**卡点**：收藏了上千篇，收藏了就等于学会了，用的时候全忘了。

### 阶段二：大量IPO（从收藏走向消化）

**核心动作**：
- **全文手打**：对着视频每3秒暂停一次，一个字一个字敲出来
- **思维导图**：学PPT教程时第一次做思维导图辅助吸收
- 笨功夫哲学："没有好办法的时候，笨办法就是最好的办法"

**关键认知**：知识不处理就是死数据，处理了才开始变成自己的。

### 阶段三：主题学习 + 二次笔记

**核心动作**：
- 围绕"市场营销"做集中主题学习，购买学习多位大咖的课程
- **第一版笔记**：记录60-80%内容，越不理解的地方记录越详细
- **第二版笔记**：在顶部只保留每章节最核心的知识点/方法论，去掉解释性信息和案例
- 李叫兽公众号140多篇，全部"关键知识点笔记化"，单篇笔记手打6万多字

**关键认知**：第一版笔记容易陷入细节，"不识庐山真面目"；第二版笔记让你看见章节之间的联系。

### 阶段四：自建文案知识体系（L4→L5 的跃迁）

**核心动作——三步法**：
1. **逆向拆解**：拆解文案最佳实践，分析成功要素
2. **提炼共性**：提炼共性要素，形成好文案框架
3. **总结路径**：参考多位老师方法论，总结自己的实现路径

**产出**：2套文案体系（长文案 + 短文案），形成自己的"文案写作教程和弹药包"

**关键认知**：不同老师的课程视角不同、盲点不同，单独遵循任何一位都不够。必须**自己整合出一套适合自己场景的体系**。

### 阶段五：复制给团队

**核心动作**：
- 将个人文案知识体系教程化
- 帮助团队文案小白实现文案变现
- 日常全场景偶遇 → 微信文件传输助手 → 印象笔记中转站 → 整理分发到各笔记

**成果**：小红书推广从0到1实现内容变现，打造低成本可复制团队内容生产流程，全年ROI 1:17，年营销额超千万。

### 张甘木的"库"体系（开源资产）

| 库名 | 内容 | 用途 |
|---|---|---|
| 概念&方法论库 | 不同老师的方法论碎片 | 基础砖块，随时调用 |
| 商业创业概念库 | 一堂课程体系+商业认知 | 建立商业全局框架 |
| 金句&10w+库 | 高传播价值表达素材 | 文案弹药储备 |

## 三、饶冠华：用知识管理对抗专家依赖

### 背景

南开大学分子遗传学博士，医疗检测公司。面临核心问题：**病原判断严重依赖专家，新人培养靠"传帮带"，业务规模被专家数量锁死**。

### 第一步：知识发现

**动作链**：拆解工作流 → 找到核心项 → 做知识萃取

**工作流拆解**（病原报告解读全流程）：

| 步骤 | 时间占比 | 是否依赖专家 |
|---|---|---|
| 排除异常数据 | 10% | 否 |
| 设定参考阈值 | 5% | 否 |
| 分析患者临床信息 | 10% | 否 |
| **病原判断** | **70%** | **强依赖** |
| 二次审核 | 5% | 否 |
| 售后解答 | 仅5%客户需要 | 强依赖（影响品牌声誉） |

**ROI判断**：病原判断优化ROI最高，售后解答影响最大。这两项优先知识库化。

**三大萃取来源**：
- 书籍：经典理论和案例（框架型知识）
- 顶级学术期刊论文：前沿研究和新发现
- 当前业务案例：特殊情况和边界阈值

**全量爆炸式研究**：把所有能收集到的信息做收集、整理、归纳、建模。

### 第二步：知识整理

**三条核心原则**：

| 原则 | 具体做法 |
|---|---|
| 知识目录结构化 | 按业务需要设计分类，**必须有用户视角**——多问使用者"你怎么用这个知识库" |
| 定好关键负责人 | 主目录由业务leader担任；细颗粒文档让一线善于沉淀的组员担任（激发责任感+更懂需求+更新及时） |
| 典型案例多重复 | 借真实痛点推动文化——"谁苦谁知道"；周会固定汇报知识管理进度；纳入KPI和晋升 |

**推动飞轮案例**：一个组长因专家离职自己顶上，忙了一个月绩效反而最低，复盘发现缺的就是知识管理。此后"谁苦谁知道"成为团队文化触发器。

### 第三步：知识应用

**新人培养段位图（L1-L6）**：

> 每个段位对应特定基本功，每项基本功背后有对应知识库。新人入职即清晰看见：我在哪个段位→该练哪些基本功→该学哪些文档→通过哪些考试→获得晋升。

**核心洞察**：**晋升的确定性，大幅提升了员工主动成长的积极性。**

**业务成果**：
- 病原判断在80%场景中已可用"非专家 + 知识库"替代
- 售后解答基本不需要创始人亲自上阵
- 合作近30+家三甲医院
- 知识库与医院病例形成正向循环：更多医院→更多病例→更丰富知识库→更强竞争力

### 饶冠华的三句话

1. **知识库要从问题出发**——没有业务问题，不必为沉淀而沉淀；搭知识库要算ROI
2. **知识库要有用户思维**——沉淀了精华但使用者不想用/不会用 = 毫无意义
3. **知识库要有推动方法**——周报机制、晋升激励、段位图，消除阻力，形成文化飞轮

## 四、古董：三个阶段的三种知识管理策略

### 核心前提

> **不同阶段的问题不一样，目标不一样，知识管理的策略和方法必须不一样。**

| 阶段 | 角色 | 核心问题 | 知识库类型 | 策略关键词 |
|---|---|---|---|---|
| 咨询阶段 | 管理咨询顾问 | 从小白快速变专家 | **最佳实践档案馆** | 追求足够多、可快速调用 |
| HR阶段 | 500强招聘负责人 | 通过他人拿结果 | **团队管理知识库** | 追求标准和复制 |
| 创业阶段 | 连锁奶茶店创始人 | 用全局视角做决策 | **创业决策全景图** | 追求体系、全局和本质 |

### 学生时代前传：一页纸复习工具

- 整本书知识点压缩到一页纸，做好层次和勾连
- 空间限制 → **倒逼抽象和结构化能力**
- 一目了然 → **构建全局视角/上帝视角**

### 阶段一：咨询阶段——最佳实践档案馆

**目标**：从小白快速蜕变为能与身价十亿老板平等对话的咨询顾问。

**搭建方式**：
- 利用Windows本地文件夹搭建个人MIS系统
- 覆盖战略/股权/HR/财务/营销/变革管理等数十个领域
- 覆盖麦肯锡/贝恩/波士顿等优秀咨询公司最佳实践
- 覆盖华为/宝洁/联想/三星等知名企业研究资料
- **体量**：近4个G，近15000个文档

**使用方式**：每次客户访谈前，提前列出结构化访谈清单。不怵和大佬对话——用提前准备和刻意练习补足经验不足。

**成果**：从小白到执行董事助理兼上海办公室2号位。

### 阶段二：HR阶段——团队管理知识库

**目标**：通过标准化知识库让三四十人的招聘团队稳定输出。

**核心转变**：从"我要成为专家"变成"我要让团队里的每个人都能稳定交付"。

**策略**：流程标准化、知识可复制、减少对个人能力的依赖。

### 阶段三：创业阶段——创业决策全景图

**目标**：用足够宽、足够深的认知体系对抗习惯性路径依赖。

**核心动作**：
- 读过的书、学过的课本身不再重要，重要的是**抽离成要素，变成地图上的点**
- 以一堂五步法为基础构建商业知识地图，涵盖1200+个知识点
- 持续更新——每次学到与五步法相关的内容就打开地图更新

**关键认知**："有了这张作战地图，就不会慌张。"

### 古董的三句话（L6级别认知）

1. **知识管理的目的不是为了管理知识，而是为了解决问题**
   - 咨询→追求足够多，管理→追求标准和复制，创业→追求体系、全局和本质
   
2. **有效的知识管理需要把知识变成解决问题的能力**
   - 别人的知识≠你的能力；中间必须完成IPO内化（萃取→抽象→结构化→重构→系统化）
   - 每个阶段都有IPO，只是输入量、处理深度、输出形式不同

3. **知识管理的最高阶追求是知行合一**
   - 知行合一 = Y模型：别人的理论→内化成自己的理论→应用到解决真实问题→产生新认知→持续迭代
   - 伴随着理论和实践的叠加，逐步升级变成高手

## 五、跨案例提炼：知识管理 L6 级底层模型

### 模型一：知识管理四阶段进化论

| 段位 | 核心动作 | 典型特征 | 代表性案主阶段 |
|---|---|---|---|
| L1-L2 低水平收集 | 偶遇式收藏，堆积不处理 | 收藏如山倒，使用如抽丝 | 张甘木第一阶段初期 |
| L3 做备忘 | 全部沉淀，可搜索调用 | 有确定性，但用不上=白存 | 张甘木第一阶段 |
| L4 建体系 | 主题学习+IPO处理+结构化 | 知识有框架，但还不够个人化 | 张甘木第二阶段 |
| L5 练能力 | 围绕专项能力自建知识体系 | 知识变成弹药包，能指导实战 | 张甘木第三/四阶段 |
| L6 无限进步 | 知识体系持续迭代+复制给团队+跨场景迁移 | 知识管理变成组织基本功 | 饶冠华全流程·古董三阶段 |

### 模型二：知识管理 WZK-P 公式

```
WorkSite（工作场景）→ ZHISHI（知识发现）→ KnowledgeBase（知识整理）→ Practice（知识应用）
```

**展开为三步动作链**：

| 步骤 | 核心问题 | 饶冠华示范 |
|---|---|---|
| 知识发现 | 从工作流里找到最值得萃取的知识节点 | 拆解工作流→找ROI最高项→全量爆炸式研究 |
| 知识整理 | 把知识变成可长期使用、他人可调用的文档/知识库 | 结构化目录+设置负责人+文化推动 |
| 知识应用 | 真正让团队用起来，变成能力和生产力 | 新人段位图+周会机制+晋升激励 |

### 模型三：IPO 内化深度层级

不是所有IPO都一样。三位案主展示了IPO的不同深度：

| IPO 层级 | 处理深度 | 输出形式 | 代表动作 |
|---|---|---|---|
| 浅层IPO | 标注+分类 | 整理后的笔记 | 张甘木第一版笔记 |
| 中层IPO | 提炼+结构化 | 思维导图/二次笔记 | 张甘木第二版笔记 |
| 深层IPO | 跨来源整合+自建框架 | 自己的方法论体系 | 张甘木文案体系·饶冠华病原判断知识库 |
| 终极IPO | 抽象为底层模型+跨场景迁移 | 可迁移的认知地图 | 古董创业决策全景图 |

### 模型四：知识管理飞轮

```
业务问题驱动 → 知识收集 → IPO内化 → 知识库沉淀 → 
团队应用 → 产生新案例/新问题 → 反向丰富知识库 → (循环加速)
```

**关键**：这不是一次性的，而是以月/年为单位持续迭代。饶冠华的"更多医院→更多病例→更丰富知识库"就是这个飞轮在医疗领域的实例。

### 模型五：知识管理策略选择矩阵

| 如果你当前的问题是… | 你应该追求… | 参考案主 |
|---|---|---|
| 个人能力不足，需要快速上手 | 大量主题学习+深度IPO | 张甘木阶段二/三 |
| 有经验但散乱，需要形成自己的方法论 | 逆向拆解最佳实践+提炼共性+自建体系 | 张甘木阶段四 |
| 业务依赖某个专家，无法规模化 | 拆解专家工作流→萃取知识→搭建知识库→培养新人 | 饶冠华 |
| 需要做更高质量的决策 | 构建全景认知地图，追求足够宽和足够深 | 古董创业阶段 |
| 需要把个人能力复制给团队 | 教程化+弹药包+新人成长段位图 | 张甘木阶段五·饶冠华 |
| 不同人生阶段需要不同策略 | 先诊断当前核心矛盾，再选择匹配的知识管理策略 | 古董三阶段 |

## 六、L6 级别审美清单：好的知识管理长什么样

| 维度 | 60分合格 | 85分优秀 | L6无限进步 |
|---|---|---|---|
| **驱动方式** | 偶遇式收集 | 有意识主题学习 | 问题驱动，以终为始 |
| **处理深度** | 一键收藏 | 手打笔记+思维导图 | 跨来源整合，自建体系 |
| **结构化程度** | 文件夹分类 | 知识树/目录体系 | 认知地图，多点连线 |
| **个人→团队** | 只有自己能用 | 文档可共享 | 知识库+段位图+激励机制，团队可自主成长 |
| **迭代频率** | 几乎不更新 | 偶尔更新 | 每次遇到新案例/反馈就更新，形成飞轮 |
| **可迁移性** | 绑死在具体业务 | 可迁移到同类场景 | 抽象为底层模型，跨领域适用 |

## 七、可直接带走的最小行动清单

1. **诊断你当前的知识管理段位**：对照"四阶段进化论"，诚实评估自己在L1-L6的哪一段
2. **找到一个高ROI的业务问题**：像饶冠华一样问——哪个环节最卡业务规模？
3. **做一次深度IPO**：选一个你认可的高质量内容，全文手打+二次提炼，感受"笨功夫"带来的理解深度差异
4. **自建一个最小知识库**：哪怕只有一个飞书文档，把动作清单、好案例、常见坑放进去
5. **设计一个推动机制**：如果你是团队管理者，试试把知识管理放进周会固定议程
6. **画一张自己的认知地图**：像古董一样，把已学的内容抽离成要素，连线成图，找到盲区

---

> **一句话收束**：知识管理不是把别人的知识存进硬盘，而是把外部的信息，一轮轮IPO内化成自己的判断力，再变成团队可复制的基本功。张甘木用十年证明了这件事，饶冠华用知识库解放了专家，古董用三张地图穿越了三种人生角色。他们的共同起点，都是"从问题出发"。
