## 一、课程定位

> **一句话**：三个手握王炸级资源的创业者，三种截然不同的搞砸姿势——资源不是免死金牌，认知才是。

| 维度 | 信息 |
|---|---|
| 课程 | 搞砸之夜第二期 |
| 案例数 | 3个 |
| 案主 | 赵耀军（幼儿园监控）、吴超（校车平台）、杜明睿（线下门店APP） |
| 总学费 | 约2500万+ 不可量化的人生代价 |
| 共同底色 | 都曾有过辉煌战绩、都手握关键资源、都在某个节点做出了"事后看致命"的决策 |

## 二、3个案例逐一深挖

### 案例 ①｜赵耀军：幼儿园远程监控，赔掉沈阳4套别墅

**背景速览**

| 维度 | 信息 |
|---|---|
| 案主 | 赵耀军，联想辽宁分区大客户总监出身 |
| 过往战绩 | 大客户销售能力极强，被评价为"当先锋的好手"；独立创业后做能源弱电工程顺风顺水 |
| 项目 | 幼儿园远程视频监控——免费给幼儿园装设备，家长通过APP付费观看实时影像 |
| 商业模式 | 与移动公司合作，家长每人每月付20元话费，6个月后分成（赵耀军60%，移动40%） |
| 学费 | 赔了约1000多万（沈阳4套别墅） |
| 转折点 | 2019年认识一堂但没认真学，2年后亏光才"重回一堂"认真写作业 |

**搞砸路径**

```text
联想销冠出身 → 独立创业顺风顺水 → 
2014年获"改命级机遇" → 发现幼儿园监控商机 →
免费铺设备跑通MVP → 扩张后才发现单元模型不成立 →
调通单元模型后错过高速发展期 → 受竞争压力被迫转型 →
全量开发但错判市场 → 整个项目赔了1000多万
```

**五个关键节点的致命决策**

| 阶段 | 做了什么 | 问题在哪 |
|---|---|---|
| 阶段一：冷启动 | 免费给幼儿园装摄像头等设备，让家长付费远程监控 | 商业模式很新，冷启动非常快——这一步是对的 |
| 阶段二：扩张 | 跑通MVP后开始扩张 | **单元模型根本没算对**，扩张只是加速失血 |
| 阶段三：修正 | 调通单元模型 | 但**已经错过了高速发展期**，竞争格局变了 |
| 阶段四：被迫转型 | 受竞争压力转型 | 被动转型而非主动升级，丧失了节奏感 |
| 阶段五：全量开发 | 全量投入新产品 | **再次错判市场**，重蹈全量开发覆辙 |

**四个核心认知**

| # | 认知点 | 深度解读 |
|---|---|---|
| 1 | **单元模型是一切** | 这个案例最核心的教训——单元模型没算对就扩张，等于闭着眼烧钱。案主原话的懊悔感贯穿始终：如果早点认真算账，至少能少赔一套别墅 |
| 2 | **"认识"和"学到"差了一个写作业的距离** | 2019年就接触了一堂，但"赚了些小钱，特别傲娇"，只是听课不写作业。2年后亏光了才重回课堂。一年多修了513个学分，进入Top100巅峰榜。案主原话："早点在一堂写作业就好了" |
| 3 | **时机窗口+单元模型的双重错过** | 调通模型时窗口期已过——这是很多创业者最痛的一种死法：不是方向错，而是节奏错 |
| 4 | **精益创业不是口号** | 全量开发、全量投入的姿势在案主身上出现了不止一次。"用小钱验证"不是保守，是保命 |

> **🔑 L6级洞察**：赵耀军的案例是一面镜子——"认识一堂"和"在一堂写作业"之间差了两年，也差了4套别墅。**知识不进入练习系统，就只是聊天的谈资**。傲娇是创业者最贵的情绪。

### 案例 ②｜吴超：校车服务平台，烧光500万+

**背景速览**

| 维度 | 信息 |
|---|---|
| 案主 | 吴超，20年互联网产品和运营经验，多个互联网大厂背景 |
| 初心 | 没有时间接送女儿上下学，又找不到合适的校车，调研发现很多家长都有这个困扰 |
| 项目 | 对接校车和家长、保障学生安全出行的平台 |
| 起盘姿势 | 相当科学——有调研、很精益、低成本起盘。用一个**假页面就获得了600+用户** |
| 融资 | 2015年创业黄金期，顺利拿到种子轮、天使轮 |
| 高光 | 受过哈尔滨市委书记、黑龙江省委书记接见，一时风光无两 |
| 结果 | 烧光500万+，项目没有完全跑通 |
| 赛道 | 最早一批物联网/车联网项目 |

**搞砸路径**

```text
自己有痛点（没空接女儿） → 调研发现家长普遍有需求 →
精益起盘（假页面验证，600+用户）→ 顺利融资 →
政府关注、一时风光 → 缺乏行业常识 →
缺乏实事求是地预判 → 关键假设未验证 →
产品上线一波三折 → 烧光500万+ → 项目未跑通
```

**三个核心认知**

| # | 认知点 | 深度解读 |
|---|---|
| 1 | **精益起盘不等于全程精益** | 这是最令人唏嘘的地方——起盘姿势非常科学（假页面验证、低成本的MVP），但后来在关键假设验证上却不够实事求是。**早期精益不能替代全周期的假设驱动** |
| 2 | **跨行业的"常识诅咒"** | 20年互联网老兵，在物联网/车联网这个新赛道里，行业常识的缺乏是致命的。你在大厂积累的判断力，在新领域未必能迁移 |
| 3 | **风光是最危险的麻醉剂** | 被省市领导接见、媒体报道，这些"高光时刻"会制造一种"我们已经成功了"的错觉，让人跳过那些本该认真验证的假设 |

> **🔑 L6级洞察**：最可怕的失败不是从一开始就错，而是**开头对、中间飘、后面崩**。吴超的案例说明：精益是一种持续状态，不是一次性的起盘姿势。尤其当外部认可（融资、政府接见）涌入时，保持"假设还没验证完"的清醒是最难的。

### 案例 ③｜杜明睿：线下门店导流APP，烧光1000万

**背景速览**

| 维度 | 信息 |
|---|---|
| 案主 | 杜明睿，电商操盘手，线上千万级营收 |
| 资源量级 | 手握西安Top级别商圈资源 + 银行资源 + 银联资源 |
| 项目第一阶段 | 2014年左右，用APP给线下各个门店做导流 |
| 失败原因一 | 没有精准找到逛商场用户的需求和门店客户的需求 |
| 项目第二阶段 | 尝试用"智能收银台"为切口，给B端门店做供应链 |
| 失败原因二 | 自身对于供应链缺乏认知 |
| 总学费 | 约1000万 |

**搞砸路径（双阶段失败）**

```text
阶段一：线上 → 线下
电商千万级操盘手 + 手握顶级商圈/银行/银联资源 →
做APP给门店导流 → 没找准需求（C端用户+ B端门店）→ 失败

阶段二：从C端转到B端
智能收银台 → 给门店做供应链 →
缺乏供应链认知 → 再次失败 → 共烧约1000万
```

**三个核心认知**

| # | 认知点 | 深度解读 |
|---|---|
| 1 | **资源最多的人，最容易跳过需求验证** | "手握西安Top级别商圈资源+银行资源+银联资源"——这反而让她以为自己不需要从最基础的需求验证开始。资源幻觉让你以为"资源能弥补需求没找准" |
| 2 | **线上→线下的认知鸿沟** | 千万级电商操盘手，转到线下时发现用户需求逻辑完全不同。"老人做新业务"需要极强的敬畏心，过去的成功经验在这个新场景里可能是错的 |
| 3 | **"大公司高配"的创业陷阱** | 从大公司带来的"高配"习惯（大手笔投入、重资产起盘）和创业应有的"低成本试错"之间存在尖锐矛盾。复盘不只反思业务决策，也反思了创业姿势本身 |

> **🔑 L6级洞察**：杜明睿的案例独特之处在于**双阶段、双失败**——第一阶段死在需求没找准（五步法第一步），第二阶段死在供应链认知不足。两段失败之间缺失的，是一次真正诚实的、触及底层的复盘。如果第一阶段失败后能深刻反思"我为什么没找对需求"，第二阶段可能就不会再犯"缺乏行业认知就硬冲"的同类错误。

## 三、跨案例共性规律（L6级提炼）

### 规律 1：资源诅咒的三种面孔——「认知替代律」

| 案主 | 资源类型 | 被资源跳过的环节 |
|---|---|---|
| 赵耀军 | 联想大客户总监出身 + 移动公司合作 | 单元模型精算 |
| 吴超 | 20年互联网经验 + 顺利融资 + 政府接见 | 行业常识补课 + 关键假设验证 |
| 杜明睿 | 顶级商圈资源 + 银行资源 + 银联资源 | 需求验证 |

**资源不是问题，资源让你觉得"不需要验证"才是问题。** 三个案主都在自己最自信的领域，跳过了最不该跳过的步骤。

### 规律 2：老兵新战场——「经验不迁移律」

```
赵耀军：大客户销售 → 幼儿园监控业务，销售能力强但管不好公司
吴超：   互联网产品 → 物联网/车联网，精益起盘但行业常识缺乏
杜明睿：线上电商   → 线下门店/供应链，千万操盘手但需求逻辑不同
```

**你过去的强项在这个新领域里，可能只是入门券，不是通关密码。**

### 规律 3：一堂五步法的「哪一步死」分布

| 案主 | 需求/假设 | 解决方案 | 商业模式（单元模型） | 增长 | 壁垒 |
|---|---|---|---|---|---|
| 赵耀军 | — | — | **🔴 致命** | 🔴 节奏错 | 🟡 |
| 吴超 | **🔴 致命** | 🟡 | 🟡 | — | — |
| 杜明睿(阶段一) | **🔴 致命** | 🟡 | — | — | — |
| 杜明睿(阶段二) | 🟡 | **🔴 致命** | 🟡 | — | — |

- **赵耀军死在第三步（单元模型）**：需求对、方案对、模型错
- **吴超死在第一步（关键假设）**：早期验证好，后期假设飘
- **杜明睿两段都在前端（需求/方案）**：需求没找准就换方向，方向换了但认知没换

### 规律 4：傲娇是创业者最贵的情绪

```text
赵耀军："赚了些小钱，特别傲娇，瞧不上一堂这种务实的、土土的课"
→ 两年后亏了4套别墅钱
→ 重回课堂，一年修了513个学分
→ 案主原话："早点在一堂写作业就好了"
```

这不是一个孤立的教训。三个案主在失败前，都有过"我已经很厉害了"的时刻。**傲娇不是性格问题，是认知问题——它让你停止验证。**

### 规律 5：窗外掌声最危险

```
吴超：省市领导接见 → 一时风光无两 → 关键假设未验证
赵耀军：移动公司合作 + 快速扩张 → 感觉"王炸级资源" → 单元模型没算对
杜明睿：手握银联级资源 → 觉得"资源能搞定一切" → 需求没找准
```

**当外面的人开始鼓掌的时候，最该做的不是享受掌声，而是回头检查那些还没验证的假设。**

## 四、L6级行动清单

### 🔴 如果你手握"好资源"：

| # | 行动 | 对应案例 |
|---|---|---|
| 1 | 列出你的资源清单，然后问自己："这些资源最容易让我跳过哪一步验证？" | 杜明睿 |
| 2 | 假装你没有这些资源，最该先验证的是什么？先做那个 | 赵耀军 |
| 3 | 资源越多，单元模型越要算三遍以上 | 赵耀军 |

### 🟡 如果你是领域老兵进入新赛道：

| # | 行动 | 对应案例 |
|---|---|---|
| 4 | 列出这个新领域你"不知道什么"，而不是你"知道什么" | 吴超 |
| 5 | 找一个行业里踩过坑的人聊一次，比做三个月调研更有用 | 吴超 |
| 6 | 精益起盘之后，给每个阶段设一个"假设验证清单"——不因为早期验证成功就放松后期 | 吴超 |

### 🟢 如果你正在从线上转线下（或反之）：

| # | 行动 | 对应案例 |
|---|---|---|
| 7 | 用户需求不要猜，走到门店里待三天 | 杜明睿 |
| 8 | 供应链不是"我有资源就能搞定"的事——先跟三个供应商聊透 | 杜明睿 |
| 9 | 不要用大公司的预算习惯做创业验证——"高配"是创业的加速毒药 | 杜明睿 |

### 🔵 如果你想保护自己永远不成为下一个案例：

| # | 行动 | 对应案例 |
|---|---|---|
| 10 | 把单元模型打印出来放在桌上——每次做决策前看三分钟 | 赵耀军 |
| 11 | 当别人夸你的时候，立刻打开假设清单，看看有没有还没验证的就跳过了 | 吴超 |
| 12 | 失败后不要立刻换方向，先做一次触及底层的复盘——否则你会带着同样的认知缺陷进入下一个失败 | 杜明睿 |

---

> **最后一句话**：这三个案例的总学费超过**2500万+**。赵耀军用4套别墅、吴超用500万+、杜明睿用1000万，共同买来的教训核心只有一条——**无论你手握多少资源、有过多少战绩、获得多少认可，创业的第一性原理永远不变：假设驱动、低成本验证、算清单元模型。跳过这三件事，资源只会让你死得更体面，但不会让你死得更慢。**
