# 《搞砸3：团购、品牌和新能源》L6 清单体笔记

---

## 一、课程定位

> **一句话**：三个案主，三种赛道，同一个结局——烧掉近亿学费买来的认知，浓缩成一晚的「搞砸之夜」。

| 维度   | 信息                                  |
| ---- | ----------------------------------- |
| 课程   | 搞砸之夜第三期                             |
| 案例数  | 3个                                  |
| 案主   | 杨晓光（社群团购）、裴成辉（餐饮品牌）、邬迪 Woody（新能源光伏） |
| 总学费  | 合计近亿人民币 + 不可量化的人生代价                 |
| 共同底色 | 都在各自领域有过耀眼战绩；都曾无限接近成功；最终都败在同一类问题上   |

## 二、3个案例逐一深挖

---

### 案例 ①｜杨晓光：中国最早社群团购，烧光千万倒在黎明前

**背景速览**

| 维度 | 信息 |
|---|---|
| 案主 | 杨晓光，小镇青年，靠学习改变命运来到北京 |
| 底色 | 鹅厂程序员出身，T6/P8级别，擅长用技术解决问题 |
| 项目 | 「51带饭」→「朋友说」，中国最早一批社群团购平台 |
| 起点 | 2013年因帝都雾霾+地沟油泛滥，做论坛让同事互相带饭 |
| 高光 | 用户从8000暴增到69万，获1580万融资，从五环外破办公室搬到黄浦江边高大上办公楼 |
| 转折 | 犯了大量盲目扩张的错误 |
| 结局 | 烧光上千万，倒在社区团购行业全面爆发的前夜（黎明前） |
| 近况 | 加入一堂学习时学分仅28分，认真学后拿了7月复盘营MVP |

**搞砸路径**

```text
程序员出身，用技术解决问题 → 发现"带饭"需求 →
论坛裂变（摇苹果裂变69万用户）→ 给宝妈团长提供平台 →
用户暴增→ 获1580万融资 → 心态膨胀、盲目扩张 →
单元模型未算对 → 烧光上千万 → 倒在社区团购行业黎明前
```

**案主原话**

> "原来我们烧了2000万才拿到的认知，在4块9的复盘营里就有答案。不过人生嘛，就是这样，没有当年250的教训，怎知今天259的珍贵。"

**四个核心认知**

| # | 认知点 | 深度解读 |
|---|---|---|
| 1 | **时机对了，不等于一切对了** | 两次站上风口——最早做社群团购，最早做O2O——但风口只解决"方向对"，不解决"姿势对"。用户从8000暴增到69万的曲线会制造"我们已经跑通了"的幻觉 |
| 2 | **"烧钱=增长"是创业最大的认知陷阱** | 拿了1580万融资后，从五环外搬到黄浦江边——钱多了，验证少了。增长掩盖了单元模型的问题，直到钱烧光问题才暴露 |
| 3 | **技术思维 vs 商业思维** | 程序员出身，擅长用技术解决问题，但在商业预判、单元模型、假设驱动这些维度上，技术能力几乎帮不上忙 |
| 4 | **黎明前倒下是最残酷的结局** | 社区团购后来全面爆发，拼多多、美团等巨头入局——方向完全正确，但死在行业起飞前。这不是方向错，是节奏和模型错 |

> **🔑 L6级洞察**：杨晓光的案例回答了"为什么风口上的猪也会摔死"——风口是电梯，但电梯里也需要知道按几楼。**增长会掩盖一切问题，直到钱烧光的那一天，所有被跳过的问题会同时找你算账。**

### 案例 ②｜裴成辉：餐饮行业顶级操盘手，创业三起三落烧千万

**背景速览**

| 维度 | 信息 |
|---|---|
| 案主 | 裴成辉，餐饮行业营销专家，餐创云咨询创始人 |
| 职场战绩 | 海底捞从0到1搭建品牌营销策划部（第一次品牌升级）；金百万餐饮集团营销中心总经理（外卖业务从0做到4年7亿）；前小肥羊品牌营销负责人；美团点评高级智囊团成员 |
| 创业经历 | 做连锁快餐店（踩坑赔钱）；做互联网内容平台（踩坑赔钱）；做餐饮培训咨询（踩坑赔钱） |
| 模式 | 职场升级打怪 ⇄ 下场创业踩坑，反复横跳，三起三落 |
| 总学费 | 累计烧掉上千万 |

**搞砸路径**

```text
大公司风生水起 → 产生"我也可以"的错觉 →
下场创业 → 用大公司思维做小创业 →
缺少假设驱动意识 → 不做科学预判 →
踩坑赔钱 → 回归职场 → 再次风生水起 →
再次被"我能行"的感觉驱动 → 再次下场 → 再次踩坑
…如此往复，三起三落
```

**三个核心认知**

| # | 认知点 | 深度解读 |
|---|---|---|
| 1 | **大公司能力 ≠ 创业能力** | 你在海底捞从0搭建品牌，不代表你能从0搭建一家公司。大公司给你平台、资源、团队、品牌背书——创业时这些都归零。操盘手和创始人是两个完全不同的物种 |
| 2 | **"反复横跳"背后的认知缺陷** | 三次创业三次失败，每次回归职场又能风生水起——这说明不是能力问题，是认知框架问题。如果每一次失败后的复盘都停留在"这次运气不好""赛道不对"，而不触及"我缺假设驱动意识"，下一次还会踩同样的坑 |
| 3 | **没有假设驱动 = 闭眼开车** | 裴成辉加入一堂之前的复盘是"浅层认知"，加入一堂后才触及更底层、更本质的原因。这也解释了为什么一个顶级操盘手会反复创业失败——缺的不是行业经验，是科学方法论 |

> **🔑 L6级洞察**：裴成辉的案例是一面最残酷的镜子——**你越是在大公司厉害，越容易低估创业的难度。** 因为大公司给了你一个"能力放大器"，你很难分清哪些结果来自你的能力，哪些来自平台。三次创业三次失败，不是在惩罚他的能力，而是在惩罚他没有把"假设驱动"写进自己的认知操作系统。

### 案例 ③｜邬迪 Woody：新能源投资老兵，创业两年赔光离场

**背景速览**

| 维度 | 信息 |
|---|---|
| 案主 | 邬迪（Woody），北美电力专家 |
| 背景 | 前国企资深投资人，12年行业经验，超2GW新能源资本运作 |
| 投资战绩 | 操盘过几十亿资金，投过不少A股和科创板公司，业绩非常亮眼 |
| 创业方向 | 自己下场建立投资基金，布局全球新能源 |
| 资源 | 有人、有钱、有资源——几乎是"梦之队"级起盘 |
| 结局 | 对行业长期预判不足，对国家队下场准备不足，成为新能源行业"先烈"，赔光资本，黯然离场 |

**搞砸路径**

```text
资深投资人 + 亮眼业绩 + 深厚行业积累 →
建立自己的投资帝国（有人、有钱、有资源）→
对行业长期趋势预判失误 → 
国家队下场（意料之外的竞争者）→ 
准备不足、应变不够 → 
成为行业"先烈" → 赔光资本离场
```

**三个核心认知**

| # | 认知点 | 深度解读 |
|---|---|---|
| 1 | **投资能力 ≠ 创业能力** | 投出过很多成功公司，不代表自己能做成一家公司。投资是从外部判断价值，创业是从内部创造价值——视角、能力结构、风险承担方式完全不同 |
| 2 | **"国家队变量"的致命性** | 在一个强政策行业（新能源），没有把"国家队可能下场"作为关键假设来推演——这是战略级盲区。在新能源这种赛道，宏观变量不是背景噪音，是可能直接决定生死的变量 |
| 3 | **平台能力 vs 个人能力** | Woody复盘时坦诚：离开了国企平台之后，才真正看清哪些能力是自己的、哪些是平台赋予的。这是一个从"投资人视角"到"创业者视角"的残酷转型 |

> **🔑 L6级洞察**：Woody的案例是"专家创业"的高级版本——你不是普通专家，你是投资过很多公司的投资人，你见过最多的失败案例，你理论上最知道什么会死。**但知道别人为什么死，和能让自己不死，中间隔着一个"亲自下场"。** 当所有资源都到位时，最容易被忽略的往往是最大的那个变量——行业长期趋势里那些不可控的宏观力量。

## 三、跨案例共性规律（L6级提炼）

### 规律 1：平台光环的剥离——「能力归属律」

```
杨晓光：鹅厂T6/P8 → 出来创业 → 技术能力保住了，商业判断归零了
裴成辉：海底捞/金百万/小肥羊顶层操盘手 → 出来创业 → 操盘能力保住了，从0到1能力归零了
Woody：  国企资深投资人 → 出来创业 → 投资判断保住了，创业运营能力归零了
```

**你在大平台上的成功，有多少来自平台，有多少来自自己——只有离开平台那一刻才知道。** 三个案主都在自己最自信的维度上，被现实重新教育了一次。

### 规律 2：专家思维 vs 创业者思维——「视角断裂律」

| 案主 | 专家思维 | 创业者需要但缺失的 |
|---|---|---|
| 杨晓光 | 用技术解决一切 | 商业预判、单元模型、假设驱动 |
| 裴成辉 | 用营销/操盘解决一切 | 从0到1的精益验证、低成本试错 |
| Woody | 用投资判断解决一切 | 创业运营、面对宏观变量的韧性 |

**专家思维的陷阱：你越擅长一个维度，越容易用它解释和解决所有问题。但创业是一个多维度、非线性的复杂系统。**

### 规律 3：增长会掩盖一切——「增长麻醉律」

杨晓光的案例最典型：

```text
用户从8000→69万 → "我们跑通了！"
拿到1580万融资 → "我们被验证了！"
搬到黄浦江边 → "我们成功了！"

但实际上：
- 单元模型还没算对
- 假设还没验证完  
- 盲目扩张已经开始

增长不是答案，增长是提问的开始。
```

### 规律 4：一堂五步法的「死因分布」

| 案主 | 需求/假设 | 解决方案 | 商业模式（单元模型） | 增长 | 壁垒 |
|---|---|---|---|---|---|
| 杨晓光 | 🟡 | 🟡 | **🔴 致命** | 🔴 盲目 | 🟡 |
| 裴成辉 | **🔴 致命** | 🔴 | 🟡 | — | — |
| Woody | **🔴 致命** | — | 🟡 | — | 🔴 |

- **杨晓光死在第三步**：需求对、增长对、单元模型错
- **裴成辉死在第一步**：没有假设驱动意识，反复在同一个地方跌倒
- **Woody死在第一步+第五步**：长期预判错（第一步），且没有形成抵御宏观变量的壁垒（第五步）

### 规律 5：黎明前倒下——最残酷的失败类型

```text
杨晓光：倒在中国社区团购全面爆发的前夜
裴成辉：每次都倒在"再坚持一下可能就突破了"的阶段
Woody：  成为新能源行业的"先烈"——方向全对，但死在太早
```

**"倒在黎明前"的核心原因从来不是运气，而是单元模型撑不到天亮。**

## 四、L6级行动清单

### 🔴 如果你正在从大厂/大平台出来创业：

| # | 行动 | 对应案例 |
|---|---|---|
| 1 | 写一份「能力归属清单」：哪些能力是你自己的，哪些是平台给的 | 裴成辉、Woody |
| 2 | 忘掉过去的预算习惯——用"穷人的方式"做第一轮验证 | 杨晓光 |
| 3 | 不要因为有人给你钱就觉得被验证了——融资是加速器，不是验证器 | 杨晓光 |

### 🟡 如果你发现自己在同一个地方反复失败：

| # | 行动 | 对应案例 |
|---|---|---|
| 4 | 做一次"触及底层"的复盘：不是"这次运气不好"，而是"我缺什么认知框架" | 裴成辉 |
| 5 | 检查有没有"假设驱动"意识——每次行动前有没有写下关键假设 | 裴成辉 |
| 6 | 如果三次都失败在同一类问题上，问题不在执行，在认知操作系统 | 裴成辉 |

### 🟢 如果你正在一个高速增长的赛道：

| # | 行动 | 对应案例 |
|---|---|---|
| 7 | 增长越快，越要停下来算单元模型——增长会掩盖一切问题 | 杨晓光 |
| 8 | 问自己：如果明天融资停了，模型还能不能转？ | 杨晓光 |
| 9 | 不要用"风口"来解释增长——风口退了才知道谁在裸泳 | 杨晓光 |

### 🔵 如果你在强政策行业/赛道创业：

| # | 行动 | 对应案例 |
|---|---|---|
| 10 | 把"宏观变量"写进关键假设清单——国家队会不会下场？政策会不会变？ | Woody |
| 11 | 不要因为自己在这个行业深耕多年，就低估宏观变量的威力 | Woody |
| 12 | 投资人和创业者的区别是：投资人判断方向，创业者要活过每一个黑夜 | Woody |

---

> **最后一句话**：这三个人烧掉的学费加起来接近**一个亿**。杨晓光说他烧了2000万才拿到的认知在4块9的复盘营里就有答案，裴成辉反复创业反复失败才发现自己缺的不是经验是方法论，Woody在国企平台上的所有辉煌在创业面前都要重新验证。**搞砸之夜的本质不是消费失败，而是把失败变成后来者可以"低成本获得"的认知资产。你不需要再交一遍这近亿的学费。**
