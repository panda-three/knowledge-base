## 二、核心词：实事求是——四个关键词拆解

### 2.1 四词关系全景

```text
情报调研 + 尊重规律 = 实事求是的基础
        ↓
科学决策 = 运用实事求是的过程
        ↓
螺旋上升 = 因为实事求是而带来的结果
```

**张阳的自述**："在2018年，我就看了一堂的《实事求是》，而且不是看一遍，当时我觉得悟不透，所以这5年来回看了几十遍《实事求是》。实事求是已经在我灵魂上，在我骨子里，舍弃了这个就不是我。"

**花匠的感叹**："张阳身上有一种看起来反差极大，但又非常自洽的特质：该做营销的时候做营销，做公司、带团队、做业务，该务实的时候都非常务实。这在市场上是非常难得和稀缺的，因为很多人就是反着做的。"

### 2.2 关键词一：情报调研——充分调研，不做无知决策

| 维度 | 含义 | 张阳的示范 |
|---|---|---|
| **调研的ROI** | 别人三天做调研一年去弥补；他选择一年做调研 | 入局餐饮赛道时，花一年半监控美团/大众点评品类数据 |
| **调研的颗粒度** | 不是"大概了解一下"，而是"把行业全量信息摸一遍" | 50万家火锅店评论用AI分析高频词→人工建模→找出口味规律 |
| **调研的持续度** | 不是调研一次就完了 | 持续监控竞对数据、持续走访门店 |

**L6级核心认知**：情报和数据是实事求是的第一支柱。没有充分的情报，后面的"尊重规律"和"科学决策"都是空中楼阁。

### 2.3 关键词二：尊重规律——不跟规律对着干

```text
规律是什么？
  → 不是"我以为"，不是"别人说"，不是"行业常识"
  → 是从大量真实数据和行为中总结出来的客观因果

尊重规律 = 承认现实 + 顺应因果 + 不侥幸
```

**一个被反复提及的规律案例**——"嫉妒/吃醋的力量很可怕！尤其对于女人！这也是规律！"

张阳在谈足力健合作时，没有直接"秀肌肉"证明自己多牛，而是让足力健的张小姐姐**从头见证猫大力从0到100万到500万到1000万的完整过程**。一个月一个月地看着对手成长，她的心态从"观望"变成了"为什么成功的不是我？"——这不是话术，这是对人性的深刻理解。

### 2.4 关键词三：科学决策——不做差的决策就是好决策

**张阳的决策三层模型**：

| 层级 | 决策方式 | 评价 |
|---|---|---|
| 第一层 | 靠感觉，拍脑袋 | 最差 |
| 第二层 | 靠理论，但不考虑人和执行的损耗率 | 不够好 |
| **第三层** | **综合判断：基于现有资源和人，做螺旋上升的决策** | **最优** |

**张阳的决策心法**：

> "什么是最好的决策？就是我现有资源里最有可能概率成的方案。"

> "怎么做出高质量决策？你只要不做差的决策就好。实际中，我决策的方法就是想出12345个办法，其中可能有4个是明显有60分以下的决策。然后只有一个勉强显得像60分方案，那就是他了，然后再努力用一流执行，死抠细节，把它做出结果来。"

### 2.5 关键词四：螺旋上升——实事求是的结果

> "今天的成绩，就是靠打一个个小仗做出来的，是螺旋上升而非直线上升。"

从牛肉哥→小关老师→华熙生物→认养一头牛→周洲→猫大力→足力健——**每一个项目都是下一个项目的跳板，每一个成果都在打开下一扇门。**

## 三、第一阶段：迷茫试错——"我是从游戏行业出来的人，啥认知也没有"

### 3.1 开局：2个人，有活就接

| 时间 | 关键事件 |
|---|---|
| 2018年 | 改名为"张阳"，创立水松咨询 |
| 第1个客户 | 利农国际——红杉投资人介绍，朴朴供货商，3万亩现代化农场 |
| 目标 | 帮助传统企业实现线下向线上转型 |

### 3.2 关键决策：All in 抖音——"这个决定吓坏了所有人"

**背景**：早期什么平台都试——快手、腾讯、直播、短视频……但发现精力越分散，越做不好。

**决策**：关掉其他快手和腾讯业务线，聚焦精力到all in 抖音。

**结果**：
- **几十人的团队，走得只剩5个**，真正实现了"人均一个办公室"
- 但很快，和「牛肉哥」合作完成了抖音第一批白酒直播间的冷启动（月销100万）
- 因为这个业绩，结识了牛肉哥的操盘手李荣鑫→又被介绍合作「小关老师」

**L6级核心认知**："如果和牛肉哥没有合作顺利，怎么可能有机会有后续的机会。这就是事业上的一种螺旋上升。"

### 3.3 全面惨败：陪跑10+个项目全部失利

在牛肉哥成功之后，张阳一度觉得自己"做一个客户就能成一个"。他从水松课程的学员里筛了十几个项目，一起陪跑——**结果全部失利**。

**关键反思**：不是"有流量"就够了，也不是"有方法"就够了。客户的基因、产品、供应链、团队执行力——每一个变量都影响最终结果。**实事求是不是只调研外部，更要实事求是地评估自己和客户的真实能力边界。**

## 四、猫大力孵化全案：白牌从0到月收三千万

### 4.1 项目全景

| 阶段 | 时间 | 难题 | 关键工作 | 成果 |
|---|---|---|---|---|
| 前期准备 | 2021年7-8月 | 做好前期准备工作 | 达成合作、产品生产、前期运营准备 | GMV：10+万/月 |
| 开始起盘 | 2021年9-10月 | 落地拍播玩法 | 建直播间、拍摄短视频、工业化生产 | GMV：100+万/月 |
| 复制放量 | 2021年11月起 | 遭遇公关危机 | 解决公关危机、持续上新品 | GMV：1000万/月，最高3000万 |

### 4.2 为什么要做猫大力？——"竞争激烈的程度不是取决于玩家数量，而是取决于质量"

**行业判断**：
- 宠物食品市场约500亿左右
- 5000万用户，光线上品牌就有5万家——平均每个品牌1000个用户
- **但是**：1年10亿以上的头部企业数量一只手就能数出来

**L6级核心认知**："这就意味着头部玩家还很弱。只要提升自身实力渡过那个新手云集的低端区，跑到中高端战场，赢的概率就大起来了。竞争激烈的程度不是取决于玩家数量，而是取决于质量。"

### 4.3 猫大力成功背后的实事求是

张阳用猫大力的成功不只赚了咨询费，更完成了一个极其精妙的商业布局——**他让足力健的张小姐姐全程见证了猫大力的崛起**。

| 时间 | 猫大力 GMV | 足力健张小姐姐的心态 |
|---|---|---|
| 2021年9月 | 0（刚起步） | "知道他们在做，观望" |
| 2021年10月 | 100万 | "这么快？" |
| 2021年11月 | 500万 | "为什么成功的不是我？" |
| 2021年12月 | 1000万 | "我比他强这么多，居然还不如他？" |
| 2022年2月 | — | **签约足力健** |

## 五、足力健全案：传统老公司在抖音做到月收过亿

### 5.1 足力健的底牌

| 维度 | 数据 |
|---|---|
| 行业地位 | 银发经济佼佼者，老人鞋品类冠军 |
| 线下巅峰 | 8000+家门店，年营收40-50亿 |
| 抖音现状 | 内部2个团队在做，没有太大起色 |
| 合作形式 | 张阳团队近百人提供抖音营销全案：短视频×主播×投放×运营 |

### 5.2 难度被严重低估的一道题

```text
不是"足力健如何做抖音"的问题
而是"创二代如何接班"的问题
```

张阳识别出：足力健内部的真正卡点不是"抖音打法"，而是创始人（张老爷子）与接班人（张小姐姐）之间的决策权和战略方向的交接。如果这个底层问题不解决，再好的抖音策略也无法落地。

**L6级核心认知**：真正的实事求是，不是只看业务数据，而是**看清业务背后的人和组织的真实状态**。

### 5.3 关键营销决策——"不要卖给老人，卖给子女"

**团队最初的想法**：足力健央视广告铺天盖地，直接抄央视广告讲产品卖点就行。

**结果**：用这个思路做了一版主播话术，每天只能卖三五万。

**张阳的重新判断**：
- 目标客户变了——抖音上的购买者是**子女**，不是老人
- 老人看电视广告被触达→子女在抖音被触达
- 卖点不是"透气面料、软弹鞋底"，而是**"送礼"**

**动作**：将所有话术从"产品功能"转向"送礼场景"——回家看长辈、长辈过生日、送大品牌不丢人不浪费钱。

**结果**：不到两周，业绩增长了**10倍**。

### 5.4 足力健新增用户验证

有人质疑："足力健盘子大，把原有客户做一做就能达成业绩了吧？"

**张阳的验证**：对比了下单手机号——**重合度只有10%**。90%的线上销量来自全新客户。

### 5.5 前6个月为什么不做业绩？

接手足力健的头6个月，张阳没有急着做GMV。他在做三件事：

| 动作 | 说明 |
|---|---|
| **全面情报调研** | 了解足力健内部组织、关键角色、决策链路、产品体系、供应链 |
| **识别真正卡点** | 不只是"怎么在抖音卖鞋"，而是"创二代怎么接班"、"组织怎么配合" |
| **建立基本功体系** | 营销文案三板斧、主播逐字稿标准化、工业化生产流程——这些能力必须长在组织上，不能只靠外部的几个专家 |

**L6级核心认知**："如果你想赚3年的钱，你就不要练基本功；如果赚10年20年的钱，你就不能自己练，还得带着团队练。"

## 六、苦练基本功：从依赖专家到可复制的工业化体系

### 6.1 服务足力健之前的卡点

| 卡点 | 具体表现 |
|---|---|
| 团队规模 | 只有小几十号人，服务上限有限 |
| 核心能力 | 集中在张阳和合伙人老关身上（文案、营销、操盘） |
| 主播成本 | 优秀主播月薪2-3万，业绩方差极大 |
| 规模天花板 | 要服务足力健需要把内容+直播规模翻**10倍** |

**张阳的底层认知**："作为老板，不做标准化，就是在做懒政——希望招个贵的人，就能解决难题。"

### 6.2 卡点一：带货依赖营销能力→＂营销文案三板斧＂

**提炼模型**：激发欲望、赢得信任、引导下单。

每句话背后都有设计逻辑：【下单场景】【选择竞品的后果】【送礼失败的结果】【损失厌恶】【对比差异】【引导下单】——**每一句话都不是随便讲的，每一句话都不是废话。**

有了这个模型，文案能力可以从"只有老关会写"变成"团队可训练、可复制"。

### 6.3 卡点二：主播ROI方差50%→逐字稿标准化

**做法**：提供**5分钟卖货逐字稿**——完全标准模版。所有主播最基本的基本功：一字不落地背下来。

**主播被重新定义**：主播 = 演员。逐字稿 = 剧本。拿到剧本→先研究台词→再研究动作→再研究表情。

**主播培训三板斧**：话术背诵、产品展示、情绪表达。

**标准化到令人震撼的程度**：教研团队蹲守直播间三天——话术、动作、语气词**全部标准化**。不管是哪个主播，一模一样。

**结果**：主播月薪从2-3万降到5000元，ROI方差从50%降到**0.3%**。

### 6.4 卡点三：执行依赖个人状态→＂日常抽查+双重监督＂

| 策略 | 操作 |
|---|---|
| **日常抽查** | 通知第二天抽查，拉到屋子里集体考核话术背诵 |
| **日常监督** | 专门督查组检查主播是否按话术讲 |
| **双重加锁** | 除了监督，还有一个人监督"监督者有没有监督"——督查组+督战队共**20人** |

### 6.5 基本功落地的核心心法

> "如果你想搭建自己公司最最核心的基本功，一定需要一个灵魂人物来把控全场，就像整场音乐会的指挥一样——有全量信息，能把控方向，能优化迭代，能推进整个团队执行。而这个发动机最合适的人选，就是公司一号位。"

## 七、跨案例提炼：L6 级底层模型

### 模型一：实事求是四词飞轮

```text
情报调研 → 尊重规律 → 科学决策 → 螺旋上升
    ↑                                  ↓
    └———— 每次上升后回到新一轮调研 ←————┘

每个飞轮循环：
  → 新阶段新问题 → 重新做情报调研 → 
  → 发现新的规律 → 重新做科学决策 → 
  → 拿到新结果 → 螺旋上升进入下一层
```

### 模型二：从小客户到大客户的「用事实潜移默化」模型

```text
传统做法：秀案例、讲方法、说服对方
  → 对方听过就算了，很难真正信任

张阳的做法：让对方从头见证你把一个项目从0做到1000万
  → 9月：她知道你是0状态
  → 10月：发现已经100万了
  → 11月：发现500万了
  → 12月：发现1000万了
  → 她的心态从"观望"→"为什么成功的不是我？"→主动找你合作

核心：事实比案例更有说服力。过程中积累的信任比任何提案都牢固。
```

### 模型三：科学决策的「勉强60分方案」法则

```text
不是追求"最好的决策"
而是排出12345个方案
  → 其中4个明显是60分以下 → 直接排除
  → 只有一个勉强像60分 → 那就是它了
  → 用一流执行、死抠细节，把它做出结果来

核心公式：高质量决策 = 排除所有60分以下的方案 + 把唯一可行的方案执行到极致
```

### 模型四：竞对分析的「质量>数量」法则

```text
常规思维：玩家数量多=竞争激烈=不适合入场
张阳思维：竞争激烈程度不是取决于玩家数量，而是取决于玩家质量

判断方法：
  → 看头部集中度：头部的玩家数量和份额
  → 看质量分布：90%的玩家是不是在低端区扎堆
  → 如果头部弱+低端竞争多→只要冲过低端区，中高端战场反而很空

猫大力验证：5万个宠物品牌，年10亿以上的不到5家——中高端战场极度空旷
```

### 模型五：从依赖专家到可复制体系的「三层标准化」模型

```text
第一层：创造类工作（文案/内容/创意）
  → 拆成最小单元 → 提炼模型 → 建立脚本和子弹库
  张阳做法：营销文案三板斧（激发欲望+赢得信任+引导下单）

第二层：专业类工作（主播/销售/服务）
  → 逐字稿+标准化动作 → 演员式管理 → SABC分级
  张阳做法：5分钟卖货逐字稿，主播=演员，逐字稿=剧本

第三层：执行监督（品控/检查/迭代）
  → 日抽+督查+双重锁
  张阳做法：抽查考核+督查组+督战队，20人确保标准执行
```

### 模型六：选择客户的「雪中送炭 > 锦上添花」原则

```text
足力健内部已经有两个团队在做抖音，没有太大起色
  → 他们已经知道这件事很难
  → 如果我把抖音拉起来 → 雪中送炭 → 合作能长期
  → 如果我只是锦上添花 → 对方觉得"没你也行" → 合作不可持续

选择客户的判断标准：
  ① 对方有没有"自己试过但没做成"的经历？（有→雪中送炭，更值钱）
  ② 合作成功对对方是"增量"还是"可替代"？（增量→长期绑定）
  ③ 一年只服务一个新客户 → 精力聚焦 → 成功率最大化
```

## 八、L6 级别审美清单：好的实事求是创业者长什么样

|---|---|---|---|
| **情报调研** | 看几份行业报告 | 花几周调研 | 花一年半监控全量数据+50万家门店评论AI分析+人工建模——"别人三天调研一年弥补，他一年调研" |
| **尊重规律** | 知道一些行业常识 | 能总结规律 | 不只尊重业务规律，更尊重人性的规律——"嫉妒的力量很可怕，这也是规律" |

| **螺旋上升** | 做完一个项目接下一个 | 有意识积累和迭代 | 每一个项目都是下一个的跳板——牛肉哥→小关老师→华熙生物→猫大力→足力健 |

## 九、可直接带走的最小行动清单

### 如果你想用实事求是改造自己的决策方式：

1. **先做一轮全量情报调研**：像张阳入局餐饮那样——花足够长时间把行业全量数据摸一遍，再做判断。别三天调研一年弥补
2. **每次决策前列12345个方案**：把明显60分以下的全部排除，选定那个勉强60分的方案，然后用一流执行做到80分
3. **问自己"我是不是在做差的决策"**：高质量决策的秘诀不是找到"最优解"，而是不做差的决策。只要每次避开了60分以下的选项，长期来看赢面就大得多

### 如果你想从小客户升级到大客户：

4. **不要秀案例，要让人"见证过程"**：如果你的目标是某个大客户，想办法让他们从头看到你做一个项目的完整过程。事实的感染力远超任何PPT
5. **选择"雪中送炭"型客户**：重点找那些"自己试过但没做成"的客户——他们知道这件事有多难，一旦你做成了，信任是不可逆的
6. **一年只深度服务一个核心客户**：张阳2022年只服务了足力健一个新客户。精力不分散，成功率才能最大化

---

> **一句话收束**：张阳用5年时间、从游戏行业跨界到抖音营销头部、从2个人几十万到近百人服务年营收10亿客户的完整历程证明了同一件事——**"实事求是"不是口号，而是一套可操作、可迭代、可迁移的操作系统。** 当他把情报调研做成决策的前提、把尊重规律刻进肌肉记忆、把科学决策变成排除60分以下方案的习惯、把螺旋上升变成每一个项目都在为下一个项目铺路——一个草根创业者可以从"啥认知也没有"做到"行业头部"。而他那句"竞争激烈的程度不是取决于玩家数量，而是取决于质量"，和那句"什么是最好的决策？就是我现有资源里最有可能概率成的方案"，或许是所有草根创业者最该记住的两句话：**实事求是，不是不做梦，而是把梦建在真实的地基上。而所谓螺旋上升，不过是每一次都诚实地面对现实、尊重规律、在现有资源里找到最优解，然后把一流的执行死磕到底。**
