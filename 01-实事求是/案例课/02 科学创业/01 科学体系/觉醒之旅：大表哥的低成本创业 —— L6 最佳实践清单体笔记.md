# 觉醒之旅：大表哥的低成本创业 —— L6 最佳实践清单体笔记

> **源课**：一堂「觉醒之旅：大表哥的低成本创业」  
> **案主**：刘涛（大表哥）——体育硕士，连续创业者，创业爱好者  
> **核心命题**：一个曾经"闭门造车"亏过几百万的X型创业者，如何转变为一个用3万块起盘、4个月卖出150台电动哈雷的Y型科学创业者  
> **笔记定位**：不只还原从"赔钱"到"落地"的完整蜕变过程，更提炼「X型→Y型创业者的四维转变」「破案式调研六部曲」「三五万起盘硬件的精益全链条」「低成本验证五层递进」等可迁移底层模型

## 一、先看全局：大表哥的三段创业人生

### 1.1 大表哥是谁

| 维度 | 身份标签 |
|---|---|
| 学历 | 体育硕士，在体育相关领域探索过多个创业方向 |
| 身份 | 连续创业者，也是创业爱好者——"喜欢从0到1，赔过钱，也拿到过一些结果" |
| 战绩一 | 不花钱做抖音账号（运动育儿66教练），一个月粉丝破百万 |
| 战绩二 | 有一家体育场馆服务公司，目前每年都有稳定的利润 |
| 战绩三 | 目前在做直播电商，测出的爆品平均单场销售额在30万 |
| 加入一堂 | 2021年加入，MBA同学 |
| 课程缘起 | Truman一直在找一个"用三五十万甚至三五万起盘"的小本创业案例——大表哥就是那个人 |

### 1.2 三段创业人生全景

| 阶段 | 时间 | 创业姿势 | 典型项目 | 结果 | 核心特征 |
|---|---|---|---|---|---|
| **第一阶段：兴趣创业** | 学一堂前 | X型创业者——闭门造车，凭兴趣和灵感驱动 | 健身房自助售卖机（卖健身补剂） | ❌ 赔钱 | 愿景驱动、缺少验证、全量投入 |
| **第二阶段：初放创业** | 学一堂前 | X型创业者——继续凭灵感，但开始有初步商业意识 | 多次创业尝试 | 有亏有赚 | 开始关注需求，但仍缺少系统方法 |
| **第三阶段：科学创业** | 学一堂后 | Y型创业者——精益验证、破案式调研、低成本起盘 | **电动哈雷单车** | ✅ 3万元造车，4个月卖出150台 | 假设驱动、极致调研、精益到骨子里 |

### 1.3 Truman为什么邀请大表哥来讲课

> "一直有同学说，一堂讲的案例动不动就是几百万、几千万的项目，有没有那种小本儿创业的案例？而大表哥就是那种非常典型的，用三五十万，甚至三五万起盘做新业务的例子。"

**大表哥的独特价值**：不是那些"高举高打"的操盘手，而是**每一个普通创业者都能仿真的样本**——没钱、没资源、没特殊背景，但有一套可以习得的科学方法。

## 二、X型创业的典型样本：健身房自助售卖机——"原来根本没有人需要我们的产品"

### 2.1 项目缘起：一次灵光乍现

大表哥早期草莽创业阶段的一个项目——往健身房放一个自助售卖机，里面卖的是健身补剂。

**逻辑链**：
```text
健身房 = 健身人群聚集地 → 健身人群需要补剂 → 
放个售卖机在健身房 = 精准获客 + 即时消费 → 一定赚钱
```

**结果**：**"原来根本没有人需要我们的产品。"**

### 2.2 X型创业者的典型特征（大表哥自画像）

| X型特征 | 具体表现 |
|---|---|
| **兴趣驱动** | 始于生活中的灵光乍现，一般人想不到——但也因此缺少客观验证 |
| **愿景驱动** | "我觉得这个需求很大""我觉得用户会需要"——全是"我觉得" |
| **闭门造车** | 不调研、不验证、不测试——直接全量投入 |
| **全量开发** | 想到就做，做就做全，不设止损线 |
| **赔钱常态** | "赔过钱"——这三个字是大表哥前两个阶段的底色 |

**L6级核心认知**：X型创业者不是"不努力"，而是**努力的姿势不对**。大表哥的健身房售卖机项目，如果当时做一轮最基础的调研——找几个健身爱好者聊一聊、在闲鱼上挂个链接测一测需求——可能几天就能拿到"没人需要"的结论，根本不需要投入全部成本。

## 三、电动哈雷单车：3万元起盘，4个月卖出150台

### 3.1 项目缘起：一个"又贵又慢"的个人痛点

| 起因 | 细节 |
|---|---|
| 个人兴趣 | 大表哥喜欢骑摩托车，享受自由和速度感 |
| 核心痛点 | 夏天戴头盔实在太闷热 |
| 理想产品 | 既能便捷出行、彰显个性，又无需佩戴头盔的交通工具 |
| 发现对标 | 在抖音上发现了一款国外电动车——**完美符合需求** |

**但有两个致命问题**：
- 价格：**3万人民币**
- 等待时间：**5-6个月**

**创业灵感的闪现**："既然我有这样的需求，其他人是否也有？我能否在国内制造这款车，满足这一潜在市场？"

### 3.2 需求验证：四层递进，从朋友圈到闲鱼

大表哥没有像X型时代那样"觉得有需求就直接造"，而是做了四层递进验证：

| 层级 | 验证动作 | 结果 | 认知收获 |
|---|---|---|---|
| **第一层：朋友圈测试** | 发朋友圈展示这款车 | 迅速收获几十个赞和评论，很多人表示感兴趣 | 朋友圈有初步关注——但朋友不是目标用户，可能评估不客观 |
| **第二层：社交媒体验证** | 搜索抖音和小红书相关内容 | 一个服装IP账号50条带这款车的作品，点赞数（1万+）远超普通视频（200-300）；评论区大量兴趣表达 | 公域流量也在关注这款车——不是"只有我觉得酷" |
| **第三层：闲鱼仿真测试** | 将国外产品图片挂在闲鱼上"销售" | 10天内有**7-8人**咨询购买 | 有人愿意掏钱！需求从"点赞"变成了"下单" |
| **第四层：国外对标验证** | 研究国外对标公司数据 | 2016年成立，已融资**3000万美元**，产品在欧美日韩市场畅销，社交媒体热度很高 | 全球市场已经验证过了——不是伪需求 |

**四层全过 → 结论：需求真实存在。可以自己先造一台试试——"如果不赚钱就自己玩了。"**

### 3.3 从"造车需要多少钱"到"3万元搞定"的极致精益

**常规做法**（大表哥X型时代会做的）：
```text
直接找整车厂 → 全量开发 → 开模 → 量产 → 至少50-100万投入
```

**大表哥的科学做法**——"关关难过关关过"：

#### 第一关：找不到整车厂 → 拆解到最小单元

| 步骤 | 动作 |
|---|---|
| 全网搜索 | 找不到能做整车的代工厂 |
| **关键破局：拆解整车** | 从配件入手——把一百多个配件拆开，先找核心配件的供应商，再通过供应商反向对接整车厂 |
| **选择切入点：电池** | 电池是核心部件、集中度高、合作方多、信息量大 |

#### 第二关：找到电池厂 → 反向对接整车厂

| 步骤 | 动作 |
|---|---|
| 平台搜索 | 通过阿里巴巴，拿着产品图联系了**10多家**电池厂老板 |
| 关键话术 | 希望电池厂帮忙对接能做整车的工厂 |
| 结果 | 按图索骥，找到**4个**可以做整车的厂子 |
| 最终选择 | 一家规模适中、沟通顺畅、主要做欧洲出口的工厂 |

初步谈判突破：起订量100台，单台成本约5000元。**但仍然太高。**

#### 第三关：车架开模费太高 → 破案式调研找现成供应商

整车厂能生产整车，但无法解决**车架开模**问题。开模费极高，大表哥付不起。

**破案式调研六部曲**：

| 步骤 | 动作 | 突破节点 |
|---|---|---|
| **Step 1：知乎发现线索** | 在知乎上发现国内有人在做类似产品 | 找到了一个竞品——他也在做这款车！ |
| **Step 2：假扮客户加微信** | 加了对方微信，假扮客户交流 | 对方说最新设计稿还在迭代——说明供应链是活的 |
| **Step 3：翻朋友圈找供应商** | 花了**3小时**一点点翻阅对方朋友圈 | 找到一张破局的图——带有**车架**、带有**供应商logo** |
| **Step 4：企查查搜公司** | 利用企查查搜到公司名称 | 但电话打不通——只有公司地址 |
| **Step 5：抖音搜商标名** | 去抖音搜索品牌商标名 | 找到车架供应商的账号！ |
| **Step 6：评论区逐一私信** | 私信账号没人回→老板关注列表隐私设置不可见→通过作品评论区逐一私信潜在联系人 | **第6次尝试**终于有人回复，拿到老板联系方式 |

**最终成果**：
- 联系上车架厂老板→最小起订量**40台**车架→签订合作
- 回到整车厂再次谈判→利用市场前景+自身营销能力+风险共担→说服老板**他出资20台，对方出资80台**
- 继续谈判→最终只支付**30%定金（3万多元）**→获得一台样车

**对比震惊**：
| 方案 | 成本 |
|---|---|
| 全量研发 | 百万级 |
| 开模做原型车 | 50万 |
| **大表哥的科学做法** | **3万元** |

### 3.4 结果

- 生产完成后，通过图片和视频在**抖音、小红书、闲鱼**上进行宣传
- 很快就直接卖出了**70单**
- 4个月内累计销量突破**150台**
- "目前这个项目现在还在进行，还有订单"

### 3.5 L6级核心认知

> "一个本身可能投入百万级的项目，如果做原型车也得50万，没想到通过一次次深入破案似的调研，最终定金就付了3万块钱。不止试错成本大幅降低，赚钱成功率也获得了成倍的提升。"

大表哥的电动哈雷案例，是**"能借就借、能租不买、能用现成绝不自己造"**的极致范本。车架不开模（找现成供应商）、电池不研发（找现成工厂）、整车不囤货（先卖再产）、样车不全款（谈判到30%定金）——每一步都在砍成本，但每一步拿到的认知都足够指导下一步。

## 四、解锁大表哥式调研——"念念不忘，必有回响"

### 4.1 大表哥的其他调研战绩（部分清单）

| 调研项目 | 破案方式 | 认知收获 |
|---|---|---|
| 抖音团长 | 企查查→Boss直聘→朋友圈验证→抖音后台查GMV→**面试七八家公司** | 验证了"2个月900万营收"是真的，但也发现红利在后期、壁垒很低→**最终决定不做** |
| 社交软件转化率 | **以服务员身份在酒吧干了15天** | 拿到关键转化率数据 |
| 送水SaaS业务 | **"直接面试和入职"送水公司**，装成憨厚结巴的小伙子 | 摸清楚了整个业务细节 |
| 夏令营新打法 | 面试了**20个行业大神** | 找到打法，形成行业Knowhow |
| 私域直播 | 投了**2万块成为合伙人** | 通过1个月了解了运营打法 |
| 体育场馆运营 | 带着下属去面试，**短期入职多家公司** | 快速了解电话销售打法 |
| 阿里拍卖押金 | 研究了一晚上拍卖法，找到拍卖漏洞 | **要回6万押金** |

### 4.2 大表哥调研的核心心法

```text
第一：一直挖。没挖到也不放弃，总能想到办法。
第二：多手段。伪装身份/入职竞对/暗访/面试/卧底/朋友圈/闲鱼/抖音后台……
第三：信念感。"念念不忘，必有回响"——他真的相信拿到关键情报很重要。
```

**为什么大表哥能在调研上"挖得深"？**

Truman的评价："大表哥深度挖掘和执行非常透，'挖得深'一直是他一以贯之的作风。看似没有出口的地方，也能有光照进来。他在磨课的时候跟教研伙伴说，'念念不忘，必有回响'。"

## 五、跨案例提炼：L6 级底层模型

### 模型一：X型→Y型创业者的四维转变

```text
维度一：驱动力转变
  X型：兴趣驱动 + 愿景驱动（"我觉得""我想到"）
  Y型：假设驱动 + 验证驱动（"我假设……我验证了……"）

维度二：投入方式转变
  X型：全量开发、闭门造车、赌身家
  Y型：极致精益、低成本验证、"不验证不下注"

维度三：调研深度转变
  X型：不调研或浅调研（"大概了解一下"）
  Y型：破案式调研（"一直挖，挖到真相为止"）

维度四：对待失败转变
  X型：失败了换一个方向，下次继续凭感觉
  Y型：每一次失败都变成可迁移的认知资产
```

### 模型二：三五万起盘硬件的「拆解反向对接法」

```text
常规路径（X型）：整车厂 → 全量开发 → 开模 → 量产 → 50万+
科学路径（Y型）：拆解整车到配件 → 找核心配件商 → 反向对接整车厂

Step 1：拆——把一百多个配件拆开
Step 2：选——选择集中度高、合作方多、信息量大的核心配件切入（电池）
Step 3：联——联系10+家配件供应商，拿到整车厂线索
Step 4：筛——从4家整车厂中筛出最匹配的
Step 5：谈——利用信息差和筹码谈判，压到最小起订量+最低定金
```

### 模型三：挖供应商信息的「社交平台六步法」

```text
Step 1：加竞品微信，假扮客户交流
Step 2：翻阅竞品朋友圈（3小时），找到带供应商logo的图片
Step 3：企查查搜供应商公司名称→查地址和电话
Step 4：电话不通→去抖音搜品牌商标名→找到供应商账号
Step 5：私信不回→看关注列表（可能隐私设置）→翻作品评论区
Step 6：逐一私信评论区潜在联系人→第6次尝试成功→拿到老板联系方式
```

### 模型四：低成本验证需求的「五层递进法」

```text
第1层：朋友圈/熟人测试（成本：0）
  → 测初步关注度，但不作为决策依据（熟人不等于用户）

第2层：公域平台验证（成本：0）
  → 搜抖音/小红书，看同类内容的互动数据

第3层：仿真购买测试（成本：0）
  → 闲鱼挂链接，看有没有人真的咨询/下单

第4层：国外对标研究（成本：0）
  → 看国外同类公司的融资/销量/社媒热度

第5层：种子用户预购（成本：低）
  → 收定金/预售，用真金白银验证最真实的需求

五层全过 → 可以投入最小成本做原型验证
任何一层没过 → 回头重新思考需求假设
```

### 模型五：大表哥式破案调研的「五字诀」

| 字 | 含义 | 示范 |
|---|---|---|
| **追** | 咬住一条线索不放手 | 抖音团长：从"只知姓名"一路追到GMV数据和行业格局 |
| **换** | 此路不通就换方法 | 车架供应商：企查查→电话不通→抖音搜→私信不回→翻评论→逐一私信→第6次成功 |
| **装** | 伪装身份拿信任 | 假扮客户加竞品微信、面试七八家公司拿内部数据、以服务员身份在酒吧干15天 |
| **串** | 从碎片拼出全貌 | 朋友圈照片+企查查+抖音+评论=完整供应商线索链 |
| **验** | 拿到信息后交叉验证 | Boss直聘办公室照片 vs 朋友圈照片 vs 企查查公司信息——三源对照 |

## 六、L6 级别审美清单：好的低成本创业者长什么样

| 维度 | 60分合格 | 85分优秀 | L6无限进步 |
|---|---|---|---|
| **创业姿势** | 凭兴趣和灵感入场 | 有调研意识 | 假设驱动+极致精益——不验证不下注，不拿认知不投入 |
| **需求验证** | 做了个简单调研 | 有多层验证手段 | 五层递进全跑通——朋友圈→公域平台→闲鱼仿真→国外对标→种子预购 |
| **硬件起盘** | 100万标准姿势 | 50万做原型 | 3万元搞出样车——拆解到配件→反向对接→不开模找现成→谈判压到30%定金 |
| **信息获取** | 网上搜一搜 | 找几个行业人士聊 | 破案式调研六部曲——咬住线索不放手，第六次尝试才成功，念念不忘必有回响 |
| **成本控制** | 能省则省 | 有精益意识 | "能借就借、能租不买、能用现成绝不自己造"——每一步都在砍成本，每一步都在拿认知 |
| **成长轨迹** | 一个项目做成/做败后继续下一个 | 能从失败中吸取教训 | X型→Y型的完整蜕变——从"赔过钱"到"3万块造车4个月卖150台" |

## 七、可直接带走的最小行动清单

### 如果你想用三五万起盘一个新业务：

1. **先做五层需求验证**：不要从"我觉得有需求"直接跳到"我要造产品"。朋友圈→公域平台→闲鱼/淘宝仿真→国外对标→种子预购——五层全过再动手
2. **拆到最小单元再找供应商**：如果找不到整车厂，就从配件找起。电池、电机、车架——每个配件的供应商都是整车厂的渠道入口
3. **用大表哥的"社交平台六步法"找隐藏供应商**：加竞品微信→翻朋友圈找logo→企查查→抖音搜商标→翻评论→逐一私信——看似无路的地方，第六次尝试就有光

### 如果你想建立调研深度：

4. **学大表哥的"念念不忘"**：不是"搜一下没找到就算了"，而是"这条线索断了，换一条继续挖"。车架供应商找了5次都没找到——第6次找到了
5. **装成不同身份拿不同信息**：大表哥装过客户、装过求职者、装过服务员、装过合伙人——每个身份拿到的信息都不一样
6. **交叉验证每一个关键数据**：Boss直聘照片 vs 朋友圈照片 vs 企查查信息——一个来源的真相可能是片面的

---

> **一句话收束**：大表哥用三段创业人生、一次健身房售卖机的赔钱经历、一次电动哈雷的3万元起盘证明了同一件事——**X型创业者和Y型创业者之间的差距，不是资金、不是资源、不是背景，而是会不会把"我觉得"变成"我验证了"、把"闭门造车"变成"破案式调研"、把"全量投入"变成"3万元先搞出一台样车"。** 当他把朋友圈测试、闲鱼仿真、社交平台六步法、拆解反向对接、30%定金谈判这五个动作全串起来之后——一个本来需要100万的项目，3万块就拿到了认知和结果。而他那句"念念不忘，必有回响"，或许是所有草根创业者最该记住的一句话：**创业路上最大的壁垒不是资金不足，而是"搜了一下没找到"就放弃了。看似没有出口的地方，也能有光照进来——前提是你一直在找。**
