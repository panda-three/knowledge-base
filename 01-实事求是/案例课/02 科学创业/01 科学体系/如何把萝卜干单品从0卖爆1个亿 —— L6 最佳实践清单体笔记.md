# 如何把萝卜干单品从0卖爆1个亿 —— L6 最佳实践清单体笔记

> **源课**：一堂 Live 160「爆品案例复盘必修课——萝卜干单品全网销量第一，1年卖爆1个亿」  
> **案主**：何发——屋头食品董事长，川禾川调创始人，串串香Top3品牌联合创始人  
> **核心命题**：一个100万预算、半年窗口期、连续淘汰六七款产品的团队，如何用科学方法从0做到单品全网破亿  
> **笔记定位**：不只还原一个消费品从0到亿的完整决策链，更提炼「工业化选品×场景化测品×sharp内核迭代×渠道精益测试×供应链暗访式调研」的可迁移全链条底层模型

## 一、先看全局：一堂第一个「爆品全链条决策」案例

### 1.1 何发是谁

| 维度 | 身份标签 |
|---|---|
| 出身 | 17岁离开学校随家人做餐饮，17年餐饮从业者 |
| 战绩一 | 屋头串串香联合创始人，带领品牌从10+→650+加盟店，品类Top3 |
| 战绩二 | 创办川禾川调，ToB餐饮调料供应商，为1万+家门店供货，营收破亿 |
| 战绩三 | 2020年探索ToC，打造高山脆萝卜干爆品，2023年单品全网破亿 |
| 一堂身份 | 2023年4月加入，大会员，学分288分 |
| 课程地位 | Truman评价「做业务的扎实程度超过了张磊」「填补了一堂案例课空白——第一个涵盖爆品全链条决策路径的案例」 |

### 1.2 起盘时的真实底牌——不是"有很多资源"，而是"被限制得很死"

| 约束条件 | 具体内容 |
|---|---|
| **资金** | 总预算100万，烧光不再追加 |
| **时间** | 最长1年，测不出来不能无限期尝试 |
| **团队** | 不专门招聘，原ToB底料业务电商团队**兼职**来做 |
| **唯一优势** | 原有ToB业务供应链资源可优先调用 |
| **预期** | 100万最好能测5-6个产品，每个单品3个月+10-20万投放测试 |

**筛选标准**：ROI跑平 + 3个月复购率≥15%。何发有一个底层判断——"流量可能会越来越贵，单纯依靠投放来做增长，长期是不可取的，如果复购率可以做上去，增长才会更健康。"

### 1.3 全链条决策全景图

| 决策环节 | 核心问题 | 何发的做法 |
|---|---|---|
| **选品** | 100万测什么？ | 工业化扫描→60个备选池→模型筛选→多轮盲测→淘汰六七款后才锁定 |
| **产品打磨** | 凭什么让用户选你？ | 从"跟风"到发现"脆"→立体卖点→包装迭代匹配最佳赏味期 |
| **渠道** | 主战场在哪？ | 渠道评估三标准（快/低成本/红利）→排除拼多多/京东/线下→兵分三路，重点抖音中小达人 |
| **壁垒** | 竞对抄不走什么？ | 大规模复制小达人合作能力+供应链自控（建厂）+"脆家族"品牌心智 |
| **供应链** | 如何应对红利期后的价格战？ | 建厂自控供应链——预算1000-1500万→通过"保安暗访"实际只花300万 |

### 1.4 预热思考题——何发带你仿真代入

> "从现在开始，你就是何发。不要站在现在的上帝视角，而是仿真地代入我的视角：在有限资源和信息的情况下，如果是你，你会怎么做，我又是怎么做的。"

## 二、选品：工业化扫描→60个备选池→模型筛选→多轮盲测

### 2.1 选品之前的风险预判排序

何发的判断：**需求 > 产品打磨 > 渠道 > 壁垒 >> 商业模式**。

"商业模式相对还是成熟的，风险并不是最大的。选什么样的产品，解决用户什么样的需求才是最难的。其次是渠道。"

### 2.2 工业化扫描——五路并进建60个备选池

| 扫描来源 | 具体动作 |
|---|---|
| **淘系后台数据** | 看淘宝后台数据，哪些品目前卖得比较好 |
| **抖音食品榜单** | 看抖音平台数据，食品类目下的销量排行榜 |
| **紧盯头部风向** | 看行业内的头部品牌和IP，在主推哪些产品 |
| **参加行业展会** | 看行业的线下展会，有哪些参展的品 |
| **鼓励同事推荐** | 推荐有奖10-50元，立项500元，上线推广2000-5000元 |

### 2.3 模型筛选——五维度筛掉70%

| 筛选维度 | 标准 | 逻辑 |
|---|---|---|
| **行业赛道** | 聚焦下饭菜赛道，刚需高频，与过往业务有交集 | 能力可迁移 |
| **成长空间** | 消费高频、场景广泛、覆盖人群多 | 有利于复购和场景拓展 |
| **产地优势** | 产业带最好在四川 | 发挥产地优势和特色 |
| **天花板评估** | 5到10亿之间 | 太小不值得做，太大竞争激烈、以小博大难 |
| **竞争态势** | 无成熟的头部/能打的对手 | 有头部品牌→小成本很难撬动 |

### 2.4 多轮盲测——从公司内部到门店食客

| 轮次 | 测试对象 | 通过标准 |
|---|---|---|
| 第1轮 | 电商部门试吃 | ≥50%表示口味不错、会购买和复购→进入下一轮 |
| 第2轮 | 其他部门试吃 | 同上 |
| 第3轮 | 研发生产试吃 | 同上 |
| 第4轮 | 挑剔亲友试吃 | 同上 |
| 第5轮 | 串串香直营门店试吃 | 同上 |

**最关键的两轮**：把萝卜干放到底料工厂食堂和屋头串串香流量最好的门店去测试——
- 两个场景下**70%-80%**的人主动尝试
- 拿走的人**80%**都把萝卜干吃光

**首轮上线验证**：找生产线下了最小订单量5000瓶→天猫上线第一周→**基本没做投放**→捡到流量→单月做到20万销售额→30日复购率10%以上。明显优于之前测试过的所有产品。

### 2.5 在此之前：六七款产品的淘汰史——最值钱的认知资产

| 产品 | 策略 | 结果 | 核心教训 |
|---|---|---|---|
| 油泼辣子、拌菜红油 | "我有什么就卖什么"——自有生产线 | 月销40万，广告费30万，ROI根本跑不平 | 品类太成熟，辣椒油变种竞争惨烈 |
| 红油豆腐乳 | 跳出"自有产品"逻辑 | ROI勉强跑平，但复购率仅7%-8% | 头部品牌线上年销两三千万，市场已被占领 |
| 外婆菜 | 继续探索新品类 | ROI勉强跑平，但复购率仍不理想 | 湖南产业带极度成熟，Top品牌心智已被锁定 |

**L6级核心认知**：如果一个品类市场上已经有跑出来的头部品牌，想用小成本去选产品测试、以小博大，是非常非常难的。这几个淘汰品让何发拿到了一条黄金法则：**找新品类，找还没有头部品牌占据心智的品类。**

## 三、产品内核打磨：从"跟风"到"脆"的sharp突破

### 3.1 内核1.0：跟风策略

`麻辣 + 下饭 + 川味地道`

这是当时萝卜干品类的普遍卖点，何发团队也跟着竞品走。

### 3.2 转折点：被用户评价"雷击"

> "这个萝卜干，偶尔会吃到几颗特别脆的，嚼在嘴里，嘎嘣嘎嘣的，感觉还挺解压，比捏碎方便面还要解压。"

**何发的反应**："这不就是我们苦苦找寻的立体的卖点吗？有声音有画面，甚至还有延伸的情绪价值！画面上：鲜亮的红油白芝麻，搭配白饭白粥，视觉对比强烈。声音上：有嘎吱嘎吱的声音，听起来很过瘾，很解压。更重要的是，**没有一个同行主打突出这个卖点！**"

### 3.3 内核2.0：把"脆"做成立体卖点

| 动作 | 具体操作 |
|---|---|
| 四处探寻原材料 | 萝卜产地不同→配方影响大→口感差异大 |
| 内部盲测10+轮 | 各地原材料带回公司，调试最佳麻度、辣度、咸度→找到口感TOP批次 |
| 粉丝测试验证 | 寄给150+铁杆粉丝，"普遍觉得颗颗能嚼出声音的脆" |
| 选出黄金配方 | 最终确定→正式投产 |

**结果**：单月销售量从百万左右→一路上涨到四五百万，三个月复购率约**25%**。

### 3.4 内核3.0：包装重构——让"脆"不只停在开盖第一天

**新问题**：用户反馈打开几天后口感变硬、颜色不再鲜亮。

| 步骤 | 动作 | 发现 |
|---|---|---|
| 用户回访 | 联系反馈用户：几口人吃、一瓶多久、几天后变差 | — |
| 内部测试 | 一人/两口/三口之家，分别测试消耗速度和口感保质期 | 当前320g/瓶，打开后约7天内口感爽脆，最佳消耗量约200g |

**迭代**：规格从320g→200g左右。但担心用户对克重敏感→没有直接推单品，而是推出**19.9元两瓶组合装**（香辣+麻辣）。

**意想不到的多重收益**：
- 客单价从单品12.8元→组合装19.9元
- 小罐装消耗快，"长时间吃不完变差"的差评消失
- 达人佣金更高→更愿带货
- 年复购率达**40%**

**每次改动都只用最小范围验证**："我们只订购了5000瓶小罐装的包材，生产之后就开始推向市场。如果我们每次都是赌上全部身家，那测试结果不好时想刹车会非常吃力。"

### 3.5 从"脆"到"脆家族"——品牌延伸

以"脆"为核心特质推出"脆家族"产品——高山脆大头菜、红油笋丁、红油酱黄瓜等，进一步提升复购。

## 四、渠道选择：兵分三路，重点发力中小达人

### 4.1 渠道评估三标准

| 标准 | 含义 | 核心理由 |
|---|---|---|
| **快** | 最好是现有团队能力可hold住的 | 快速上线、快速拿认知 |
| **低成本** | 可接受小范围投放，通过数据做实验和调整 | 100万预算下必须算ROI |
| **有红利** | 有政策倾斜和扶持 | 少花钱办大事 |

### 4.2 渠道优先级排序

| 渠道 | 判断 | 最终排序 |
|---|---|---|
| 拼多多 | ❌ 价格战太激烈 | 排除 |
| 京东 | ❌ 自营门槛高 | 排除 |
| 线下 | ❌ 重模式 | 排除 |
| 天猫 | 有经验，可小范围投 | ★★★ |
| 抖音自播 | 需学习，可小范围，有红利 | ★★★ |
| **抖音达人** | 可快速合作，按效果付费，**强红利** | **★★★★★ 核心发力** |
| 快手达人 | 可合作，按效果，有红利 | ★★★★ |

**最终策略**：兵分三路，但**有所侧重——重点发力抖音中小达人**。

### 4.3 为什么选中腰部以下达人——"大力出奇迹"

| 维度 | 数据 |
|---|---|
| 中小达人单场GMV | 约700元/场（看似不高） |
| 合作总量 | **9万+** 合作过的小达人 |
| 日常带货 | 每天**七八百个小主播**同时直播带货 |
| 月均曝光 | 抖音快手合计**6亿** |

**L6级核心认知**：中小达人单场GMV虽低，但合作量大就能"大力出奇迹"。大规模复制小达人合作能力，最终成为业务壁垒之一。

## 五、建厂自控供应链：从1000万预算到300万搞定

### 5.1 为什么要建厂

何发判断：萝卜干品类正处在红利期，但红利期过后免不了一场价格战。**要应对未来竞争，必须自己掌控供应链。**

### 5.2 预算规划

| 项目 | 预算 | 实际 |
|---|---|---|
| 高盐淡化设备 | 800-1000万 | — |
| 整体投入 | **1000-1500万** | **300万**（+100万运营费） |
| 建厂周期 | 10-12个月+3-4个月磨合期 | — |
| 盈利时间 | — | **第二个月即盈利** |

### 5.3 选址难题——花一个月找不到合适厂址

**动作链**：
- 把供应商约到一起→了解建厂需要的证照、要求、组织架构、人员配置
- 初步筛选20-30个工业园区→实地考察
- 萝卜干厂涉及环保问题（排放要求高）→大部分园区不合适
- 找业内20-30年经验老大姐牵头→花了一个月仍找不到

### 5.4 破局：发动全体员工

| 动作 | 细节 |
|---|---|
| 管理层会议 | 反复强调3-4次 |
| 员工大群 | 发3-4次通知，推荐成功有奖励 |

**关键线索**：采购同事反馈——发现一个小供应商产能没完全发挥，还出过食品安全问题停产了10-15天，是不是可以收购？

### 5.5 暗访：一根烟撬动八百万的情报

何发派建厂统筹同事+驻场品控伙伴一起"暗访"。

**信息获取路径**：

| 尝试对象 | 结果 |
|---|---|
| 工厂工人 | 没透露太多经营信息 |
| 工厂管理层 | 没透露太多经营信息 |
| **保安亭的保安** | ✅ 突破！ |

**为什么是保安？** 保安24小时住厂里，对公司信息最熟悉，且通常是老板亲戚。

**操作细节**：同事不抽烟，但每次驻场都揣着烟→每天找保安大叔拉家常、派烟→混几次脸熟→处成朋友→发现保安果然跟工厂某股东有亲戚关系。

**套到的关键情报**：
- 股东之间原本是同学/好友，但背后矛盾很多
- 老板是外行，对行业认知不足，效益不好
- **最重要的是**：工厂所在工业园区排污设备齐全、资质齐全→接手只需升级设备→**能省掉近800万**（原本预算1000万）

**L6级核心认知**：一根烟、一个保安、一次暗访，撬动了800万的信息差。调研不只是找专家和行业报告——**最值钱的情报，往往藏在最不起眼的人身上。**
