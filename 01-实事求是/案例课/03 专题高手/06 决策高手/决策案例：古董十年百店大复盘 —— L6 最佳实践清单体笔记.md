# 决策案例：古董十年百店大复盘 —— L6 最佳实践清单体笔记

> **源课**：一堂 Live 144「科学决策·十年百店大复盘」  
> **案主**：古董（董晓峰）——创业十年，门店过百，营收过亿  
> **核心命题**：一个前世界500强招聘负责人，如何用科学决策在7年半开出100+直营奶茶店  
> **笔记定位**：不只还原20+张ROI画布，更提炼「用长期目标做短期决策」「灰度决策」「ROI作为十年基本功」的可迁移底层模型

## 一、先看全局：这门课为什么"独一无二"

### 1.1 成绩单

| 指标 | 数据 |
|---|---|
| 时间 | 7年半 |
| 门店 | 100+家直营店 |
| 营收 | 破亿 |
| 身份 | 某头部茶饮品牌区域市场，从0到100 |
| 决策画布 | 20+张完整ROI决策画布 |
| 特殊身份 | 一堂MBA学员、一堂Gap计划参与者、连锁经营专家 |

### 1.2 这门课的三个"反常识"

| 反常识点 | 普通创业者 | 古董 |
|---|---|---|
| 创业姿势 | 加盟=听总部的 | 总部建议开5-6家/年→他做了完整ROI分析后决定**一年开10+家** |
| 决策方式 | 凭经验、拍脑袋、跟同行 | 几乎所有重大决策都在**ROI画布上跑一遍** |
| 思考时间跨度 | 看眼下、看这个月 | 十年前下场时就明确目标「十年百店、营收过亿、不依赖我能自运转」 |

### 1.3 Truman的评价

> "别人的案例课是一两份满分作业，而古董这节课是把十份满分作业串在了一起，包含了大半本小黄书（《一堂最佳实践》）。"

### 1.4 听课建议（古董原话）

> "你可以尝试在听课的过程中，代入我的视角：如果你是当时的我，你会怎么做？这样会大幅提升你的课程参与度，增加你的课程收获感。"

## 二、创业全景：十年百店的六个阶段

| 阶段 | 门店数 | 核心矛盾 | 关键决策类型 |
|---|---|---|---|
| 方向选择 | 0 | 从上市公司离职，选择什么方向 | 机会预判、行业选择 |
| 冷启动 | 0→1 | 第一家店怎么开 | 选址、招聘、精益验证 |
| 快速复制 | 1→14 | 开多快？跟总部节奏还是自己节奏？ | 速度决策、资金分配、风险承受 |
| 规模扩张 | 14→60+ | 人才复制跟不上开店速度 | 培训vs营运、招聘渠道创新、薪酬设计 |
| 组织调整 | 60+→100 | 组织能力如何匹配规模 | 管理层级、文化稀释、品控体系 |
| 壁垒构建 | 100+ | 如何持续领先 | 品牌势能、供应链深耕、人才梯队 |

## 三、决策一：开店速度——用长期目标做短期决策

### 3.1 背景

| 维度 | 状况 |
|---|---|
| 目标 | 十年百店，青岛奶茶头部 |
| 预判 | 成为青岛头部的窗口期只有**2-3年** |
| 总部建议 | 正常速度5-6家/年，每两个月开一家，"超过这个量级会有很大经营风险" |
| 高段位创业者建议 | "先开一家，精益测试，拿到Benchmark再扩张" |
| 两个选择 | ①听总部的，稳健5-6家/年 ②按自己节奏，快速10+家/年 |

### 3.2 ROI决策画布1.0——常规起盘（5-6店/年）

| 维度 | 收益项 | 成本项 |
|---|---|---|
| 基础ROI | 稳健发展：极高选址成功率 | — |
| | 员工方面：按部就班招聘和培训 | — |
| | 门店品质：更高品控保证运营可靠 | — |
| | 资金充足：几乎没有资金压力 | — |
| 长期视角 | — | **规模小，品牌势能起得慢** |
| 公司视角 | 稳健，没有崩盘风险 | — |
| 机会成本 | — | **预判窗口期有2-3年** |

**结论**：按照常规节奏，窗口期内2-3年整体规模上不去，品牌力和市场份额都无法实现，更谈不上"十年百店"的目标。**常规节奏开店，不能接受。**

### 3.3 ROI决策画布2.0——快速起盘（10+店/年）

古董接着画了第二张画布，把快速开店的收益和成本全量列出来。他判断：**面对最多60万的损失，换一个十年百店、亿级营收的时间窗口的机会——足够让他下定决心。**

### 3.4 结果

- 做出决策后迅速执行
- **16个月内，从0开出14家直营店**
- 创造了"全国最快开店记录"
- 就连品牌方总部的领导都觉得不可思议

### 3.5 L6级核心认知

> "用长期的目标，做短期的决策。"

古董不是在"快"和"稳"之间二选一，而是**把十年百店的目标代入短期决策**——如果窗口期只有2-3年，每年5-6家店几乎不可能在窗口期内建立品牌势能。这不是"冒险"，而是**算清楚了不这么做的机会成本**。

## 四、决策二：培训 vs 营运——灰度决策

### 4.1 困境

随着门店快速扩张，出现了一个两难：

| 选项 | 数据 | 困境 |
|---|---|---|
| **保营运** | 营运数据更好 | 旺季利润更高 |
| **保培训** | 培训新人影响短期营收 | 但长期需要源源不断的人才 |

### 4.2 古董的思考——不止看定量数据

**第一层思考：定性的部分，没算进去**

| 被忽略的定性要素 | 长期价值 |
|---|---|
| 培训质量 | 决定了未来店长和督导的能力上限 |
| 培训速度 | 决定了开店速度的上限 |
| "十年百店的人员支持" | 没有培训体系，十年百店就是空谈 |

**第二层思考：回到现实情况**

当时的现实是——**招聘能力已经拉满，还招聘不到足够的人**。为了业务发展，必须选择保培训，保住更多员工，即便牺牲一些峰值利润。

### 4.3 决策：灰度——不选非此即彼

```
旺季 → 保营运（抢营收窗口）
淡季 → 保培训（练人才内功）
```

**效果**：各门店店长、督导在遇到培训和营运冲突时，再也不用纠结。同时在营收和培训新人上达到了平衡。

### 4.4 L6级核心认知

> "决策不一定非此即彼。"

古董没有在"保培训"和"保营运"之间二选一，而是**拆出了时间维度**——旺季和淡季的矛盾不同，策略就可以不同。世界上大部分"两难决策"，缺口不在选项本身，而在**拆解的颗粒度不够细**。

## 五、古董的ROI画布方法论全景

### 5.1 为什么ROI是"值得练习10年的科学工具"

| 层次 | 含义 | 古董的示范 |
|---|---|---|
| **宽度视角** | 不只算财务，算全量收益和成本项 | 培训的价值不算进去，只看营运数据就一定选错 |
| **深度视角** | 不只算短期，算长期和机会成本 | "最多60万损失换十年百店时间窗口" |
| **高度视角** | 不只算自己，算公司视角、团队视角 | 招聘能力拉满是现实约束，不代入现实做不出对的选择 |

### 5.2 古董的ROI画布操作步骤

```text
第一步：列出全部成本项和收益项
  不偷懒，不跳步——连"长期品牌势能""机会成本窗口期"
  这些很难定量的要素也写上去

第二步：区分"能定量的"和"不能定量的"
  定量数据是参考，不是全部
  定性要素（培训质量、窗口期、团队信心）同样重要

第三步：代入现实约束
  招聘能力拉满了吗？资金还有多少？
  团队当前能力能执行哪个选项？

第四步：做灰度判断
  不一定是A或B
  可能是A季节做A、B季节做B
  可能是先A后B
```

### 5.3 一张ROI画布的最小结构

| 维度 | 收益项 | 成本项 |
|---|---|---|
| 基础ROI（短期/直接） | 直接的、可定量的收益 | 直接的、可定量的成本 |
| 长期视角 | 品牌、人才、能力积累 | 机会成本、时间窗口 |
| 公司视角 | 系统性收益 | 系统性风险 |

**古董的原则**：三个维度的收益和成本都摆上去之后，决策往往就自己浮现了。

## 六、跨案例提炼：L6 级底层模型

### 模型一：科学决策三角形——古董的十年决策框架

```text
        目标（长期追求）
         /\
        /  \
       /    \
      /  决策 \
     /  三角形 \
    /            \
   信息 ──────── 资源
```

| 三角 | 古董的实践 |
|---|---|
| **目标** | 十年百店，营收过亿，不依赖他能自运转——从下场第一天就明确了 |
| **信息** | 总部数据、同行经验、自身业务数据、定性和定量全量收集 |
| **资源** | 每个阶段诚实评估：招聘能力是否拉满、资金是否充足、团队是否能执行 |

**核心原则**：三个角全部对齐，决策质量才高。很多创业者只看了信息和资源，没有代入长期目标，所以决策总是"短视"。

### 模型二：决策的三种类型——从"非此即彼"到"灰度"

| 类型 | 特征 | 古董案例 |
|---|---|---|
| **二元决策** | A或B，必须选一个 | 选不选奶茶创业？选哪个品牌？ |
| **灰度决策** | 拆维度，不同场景选不同 | 旺季保营运，淡季保培训 |
| **时序决策** | 先A后B，分阶段走 | 先快速开店抢窗口→再回头补组织和培训 |

### 模型三：ROI决策的"三层五问"

```text
第一层：基础ROI——直接收益 vs 直接成本（能定量吗？算全了吗？）
第二层：长期ROI——长期收益 vs 机会成本（窗口期还有多久？不做的代价是什么？）
第三层：系统ROI——组织收益 vs 系统风险（团队能执行吗？会对组织产生什么影响？）
```

**五个必问**：
1. 我有没有把**所有**收益项列全？（包括定性的）
2. 我有没有把**所有**成本项列全？（包括机会成本）
3. 有没有只看定量、忽略了定性？
4. 有没有只看短期、忽略了长期？
5. 现实约束是什么？（钱够吗？人够吗？时间够吗？）

### 模型四：长期目标与短期决策的统一公式

```text
短期决策质量 = f（代入长期目标的程度）

没有长期目标 → 短期决策容易"什么容易做什么" → 长期看一盘散沙
有长期目标 → 短期决策可以"什么对长期最有利做什么" → 每个决策都在积累势能
```

**古董的示范**：十年百店不是一句口号，而是**每一次"开多快""保培训还是保营运""要不要降品质换速度"时，都拿出来重新秤一秤的那把秤**。

### 模型五：古董的"决策-执行-复盘"循环

```text
决策（画ROI画布）
    ↓
执行（按决策坚定执行）
    ↓
复盘（拿结果数据和当初画布对比）
    ↓
迭代（更新认知，下次画布更准）
    ↓
回到决策 → (循环加速)
```

**核心习惯**：不只是"做决策时画ROI"，更重要的是**做完之后回头对照**——当初列的那些收益项真的发生了吗？那些成本项真的那么高/低吗？每一次对照都让下一次画布更精准。

## 七、L6 级别审美清单：好的科学决策者长什么样

| 维度 | 60分合格 | 85分优秀 | L6无限进步 |
|---|---|---|---|
| **决策依据** | 凭经验、拍脑袋 | 会算成本和收益 | 所有重大决策都画ROI画布——宽度/深度/高度三层视角，定量定性全量列，长期短期都算 |
| **面对两难** | 纠结后选一个 | 列出利弊再选 | 拆维度做灰度——不一定是A或B，可能是旺季A淡季B，可能是先A后B |
| **目标使用** | 大概知道想做成什么样 | 会把目标写下来 | "用长期的目标做短期的决策"——每次做决策时都把十年目标拿出来重新秤 |
| **窗口期判断** | 不知道有时间窗口 | 大概知道有窗口 | 能精确预判窗口期长度→倒推每年必须做到什么规模→不达标就调整策略 |
| **定性要素** | 只看定量数据 | 会考虑定性要素 | 能识别"培训质量""品牌势能""窗口期"等不可定量但极其关键的要素——并给它们在画布里留位置 |
| **事后复盘** | 做完就完了 | 偶尔回头看看 | 每次重大决策后对照ROI画布复盘→当初列的成本收益真实发生了吗→持续校准判断力 |

## 八、可直接带走的最小行动清单

### 如果你面临一个重大决策：

1. **先明确你的"十年目标"是什么**：像古董一样——下场第一天就知道自己要"十年百店、营收过亿、不依赖我自运转"。如果你自己都说不清长期目标，没有人能替你做高质量决策
2. **画一张三层ROI画布**：把所有收益项和成本项列出来——包括"很难定量但很重要"的那些（窗口期、品牌势能、团队信心、培训质量）
3. **问自己三个问题**：①有没有只看定量没看定性？②有没有只看短期没看长期？③有没有代入现实约束？
4. **如果卡在"两难"，试着拆维度**：不一定是A或B——能不能旺季A淡季B？能不能先A后B？能不能A业务用A方案、B业务用B方案？

### 如果你想提升决策能力：

5. **把ROI当成十年基本功来练**：古董的20+张画布不是一天画出来的——是十年里每一次重大决策积累下来的
6. **做"决策复盘"**：下次做完一个重要决策后，把你的ROI画布留着。半年或一年后拿出来对照——当初的判断哪些对了哪些错了？这个习惯会让你的决策能力加速成长
7. **养成"不只看定量"的肌肉记忆**：很多最关键的要素（窗口期、团队状态、品牌势能）都很难定量——但它们往往比可定量的数据更重要

---

> **一句话收束**：古董用十年时间、100+门店、20+张ROI画布证明了同一件事——**科学决策不是商学院里的理论，而是在每一次"开多快""保培训还是保营运""要不要降品质换速度"时，都能拿出一张纸、列全收益成本、代入长期目标、做出不后悔的选择。** 而他那句"用长期的目标，做短期的决策"，和那句"决策不一定非此即彼"，或许是关于决策最朴素也最有力的两条心法。当你把ROI画成习惯、把灰度变成本能、把长期目标变成每一次选择的那把秤——一个加盟商可以在16个月内开出14家店创造全国纪录，一个前HR负责人可以把奶茶店做到区域头部、营收破亿。**决策的质量，不取决于你有多聪明，而取决于你在按下"确定"之前，愿不愿意先画一张画布。**
