# 十倍成长：3个刻意练习最佳实践 —— L6 最佳实践清单体笔记

> **源课**：一堂「十倍成长：3个刻意练习最佳实践」  
> **三位案主**：兰军（表达能力）· 张林卫（德州扑克）· 秦鹏（学习型组织/逐字稿）  
> **笔记定位**：三个完全不同领域的能力速成样本——社恐变千人讲师、小白变世界级德扑玩家、1号位把逐字稿练成组织基本功。刻意练习不是天赋的专利，而是一套可以被任何人学会的「十倍速成长」底层操作系统。

## 一、先看全局：三个案例，一条「十倍速成长」的主线

| 案主 | 领域 | 起点状态 | 核心命题 | 方法关键词 | 成果 |
|---|---|---|---|---|---|
| 兰军 | 表达能力 | 超级社恐，产品经理专家 | 社恐如何练成能面对成百上千人侃侃而谈的讲师 | 冲出舒适区+建能力模型+自己到团队复制 | 产品经理课程业内口碑极好，演讲表达能力成为团队可复制资产 |
| 张林卫 | 德州扑克 | 大学宿舍小白，平台免费币反复输光 | 如何用刻意练习从德扑小白到世界Top级职业玩家 | 找反馈工具+建参数模型+专业书+持续挑战更高级别 | 世界Top级别职业玩家，创办德扑培训机构 |
| 秦鹏 | 学习型组织 | 一堂写了20万+字作业的1号位 | 如何把一堂方法论变成整个公司的基本功体系 | 全案开源基本功图谱+逐字稿基本功+以身作则 | 公司通用基本功+部门核心基本功完整体系，大幅提升协作效率 |

**三个案例共同回答一个问题**：刻意练习不是「有天赋的人才能用」的玄学。兰军证明了社恐也能练成讲师，张林卫证明了小白也能练成世界级玩家，秦鹏证明了1号位可以把科学成长变成整个组织的操作系统。**当长期追求、固定套路、非舒适区、及时反馈、大量重复这五个要素被凑齐时，成长速度不是线性提升，而是5倍、10倍地加速。**

## 二、兰军：从超级社恐到千人讲师——表达能力的刻意练习

### 2.1 背景：一个不甘现状的少年

| 维度 | 兰军的牌 |
|---|---|
| 专业 | 产品经理专家，产品经理课程业内口碑极好 |
| 起点 | **超级社恐**——很难想象这样一位能同时面对成百上千人讲课的人，曾经是社恐 |
| 转变 | 不甘现状的少年一跃而起冲出舒适区，后来的销售和产品经理，都是挑战自我的努力 |

### 2.2 刻意练习的核心要素凑齐

| 要素 | 兰军的凑法 |
|---|---|
| **长期追求** | 不甘现状——「确认了方向之后，相信自己，并找一切机会去练习，去提高」 |
| **非舒适区** | 从社恐→做销售→做产品经理→面对成百上千人讲课——每一步都在冲出舒适区 |
| **固定套路** | 把沟通/表达能力建立成**可复制的模型**，不停迭代 |
| **及时反馈** | 每一次讲课、每一次公开发言都是反馈机会 |
| **大量重复** | 找一切机会去练习，从自己练到带团队练 |

### 2.3 从个人到团队：能力建模与复制

兰军的能力复制路径：

```text
自己先练成 → 把能力拆解成可教学的模型 → 传递给整个团队
```

**L6级核心认知**：很多人只能自己厉害，但兰军把「自己怎么练成的」也变成了可以教别人的东西。**能力的最高境界不是自己拥有，而是能让别人也拥有。**

### 2.4 兰军的三句话

| 心法 | 含义 |
|---|---|
| **极有勇气** | 不甘现状的少年一跃而起冲出舒适区——后来的销售和产品经理，都是挑战自我的努力 |
| **相信成长** | 确认了方向之后，相信自己，并找一切机会去练习、去提高 |
| **能力模型** | 对沟通/表达能力的不停迭代，从自己到团队的能力复制 |

## 三、张林卫：从德扑小白到世界Top级职业玩家——德州扑克的刻意练习

### 3.1 背景：一个「只要不充钱就没人能打败我」的小白

| 维度 | 张林卫的牌 |
|---|---|
| 起点 | 大学宿舍和同学打德扑，兴趣驱动，水平差不多，次数很少 |
| 拐点 | 2019年聚会，朋友便哥带入线上平台，起步资金是赠送的50美金 |
| 第一阶段 | 50美金很快输光→便哥转3-5美元又输光→各种找平台找免费币→**输光、结束、睡觉** |
| 策略 | 「只要我不充钱，就没人能真正打败我！」 |

**第一阶段资金曲线**：典型的「凭感觉、凭直觉、凭运气」——偶尔能赢，但输多赢少，经常破产，不得要领。

**第一阶段水平停滞不前的最大原因**：**没有有效反馈。** 很多手牌打了也不知道是对是错、不知道最优打法是什么。而且在德扑上，赢不等于打得好，输不等于打得不好。

### 3.2 第二阶段：发现「灯塔」——4个参数改变一切

**拐点**：从便哥那里知道有一套数据分析软件——和专业练习的工具不一样：**多了4个参数！**

| 关键认知 | 内容 |
|---|---|
| 参数的意义 | 参数能够描述一个人的打法特征，可以用参数来提升决策质量 |
| 感觉 | 「就像在茫茫的大海上，看见了灯塔，他终于找到了前进的方向！」 |
| 训练计划 | 拿着4个参数，给自己制定训练计划 |

**结果**：大概打几个月，在白银段位（NL10级别）拿到非常高的胜率（10BB/百手），超过当前段位90%以上的玩家。

**L6级核心认知**：这个阶段最重要的，是他有了**模型的意识**——能用简单的4个参数指导决策。从「凭感觉打」到「按模型打」，是刻意练习最关键的分水岭。

### 3.3 第三阶段：进入黄金级别——4个调整应对更强者

经过半年练习晋升到「黄金」级别后，对手实力越来越强——大家基本都有理论体系、很多实战经验。刚进入时明显更吃力，胜率也没以前稳定。

**4个调整**：

| 调整 | 具体动作 |
|---|---|
| **看专业书** | 《德州扑克圣经》《超级系统》《哈林顿在现金桌》《无限德州扑克理论与实践》《德州扑克小绿皮书》…… |
| **研究底层学科** | 除了研究德扑，还通过研究**数学、心理学**，大幅提升胜率 |
| **持续挑战更高级别** | 从小白到职业玩家，一直在挑战更高级别的对手 |
| **持续建模** | 随着水平升高，持续给自己建立更复杂的模型 |

**最终成果**：从德扑小白→世界Top级别职业玩家→创办自己的德扑培训机构。

### 3.4 张林卫的刻意练习要素凑齐表

| 要素 | 张林卫的凑法 |
|---|---|
| **长期追求** | 从「免费币随便玩玩」→「成为职业玩家」→「创办培训机构」 |
| **固定套路** | 4个参数→专业书体系→越来越复杂的决策模型→持续建模 |
| **非舒适区** | 白银→黄金→更高级别→每次晋级对手更强、金额更大、压力更大 |
| **及时反馈** | 数据分析软件（核心转折点！）→每手牌都有参数反馈→赢不等于打得好，输不等于打得不好 |
| **大量重复** | 线上平台随时可以练，不依赖别人攒局→练习次数大幅提升 |

### 3.5 L6级核心认知：第一阶段为什么停滞不前？

> 「缺少有效反馈」——很多手牌打了也不知道是对是错、不知道最优打法是什么。赢不等于打得好，输不等于打得不好。

**这个洞察适用于所有刻意练习**：如果你的练习没有反馈，你做对了不知道对在哪、做错了不知道错在哪——**练100次和练1次没有本质区别。**

### 3.6 张林卫的三句话

| 心法 | 含义 |
|---|---|
| **勇于挑战** | 从小白到职业玩家，一直在挑战更高级别的选手 |
| **持续建模** | 随着水平升高，持续给自己建立更复杂的模型 |
| **深入研究** | 除了研究德扑，还通过研究数学、心理学，大幅提升胜率 |

## 四、秦鹏：把一堂变成公司的操作系统——学习型组织的刻意练习

### 4.1 背景：一个写了20万+字作业的1号位

| 维度 | 秦鹏的牌 |
|---|---|
| 身份 | 一堂学霸同学，1号位 |
| 作业量 | 一堂写了**20万+字作业** |
| Truman评价 | 「当时我听完这个案例，发了一个朋友圈说：感觉已经超越我讲的方法论框架了，牛逼。」 |
| 许愿 | Truman当场许愿：「未来挖掘100个秦鹏、徐剑这种优秀大师兄」 |

### 4.2 核心开源资产：公司基本功图谱

秦鹏把整个公司的基本功分成了两类，全部开源：

| 类型 | 内容 | 定位 |
|---|---|---|
| **公司通用基本功** | 全公司每一个人都要练的基本能力 | 组织共同操作系统 |
| **部门核心基本功** | 每个部门最关键的专项能力 | 部门专业能力壁垒 |

**L6级核心认知**：秦鹏不是「自己学了一堂然后用一用」，而是**把一堂的方法论变成了整个公司的基本功体系**。每个员工都知道「我要练什么」「标准是什么」「怎么练」。

### 4.3 逐字稿基本功——从学到用的完整落地

秦鹏学完一堂《逐字稿》课程后，把它在公司里全面落地：

| 落地动作 | 具体做法 |
|---|---|
| 自己先练 | 1号位以身作则，先严格写逐字稿 |
| 要求团队 | 重要会议、公开发言前写逐字稿 |
| 建立标准 | 逐字稿的质量标准、格式规范 |
| 持续迭代 | 每次用完后复盘，更新最佳实践 |

**效果**：大幅提升协作效率——「开会前逐字稿提交→前10分钟先看逐字稿→再讨论→会议效率质的飞跃。」

### 4.4 1号位如何以身作则打造学习成长氛围

秦鹏的做法回答了「学习型组织怎么建」这个最难的问题：

| 动作 | 含义 |
|---|---|
| **现身说法** | 难得的1号位视角，毫无保留地分享自己怎么学、怎么练 |
| **以身作则** | 不是「你们去学」，而是「我先练给你们看」——20万+字作业就是证据 |
| **建立制度** | 不只靠氛围，更靠机制——基本功纳入日常工作流 |
| **全案开源** | 把整个公司的基本功图谱公开，让团队能看到全局和路径 |

### 4.5 秦鹏的三句话

| 心法 | 含义 |
|---|---|
| **全案开源** | 有秦鹏整个公司的基本功图谱，包括公司通用基本功和部门核心基本功，可以直接抄作业 |
| **现身说法** | 难得的1号位视角，毫无保留地分享如何以身作则，打造学习成长氛围 |
| **落地案例** | 学完一堂逐字稿之后在公司落地，详细分享了如何苦练逐字稿基本功，大幅提升协作效率 |

## 五、跨案例提炼：刻意练习 L6 级底层模型

### 模型一：刻意练习五要素加速公式

```text
成长速度 = (练习质量 × 练习数量) × 要素齐全度

长期追求：决定你「愿不愿意练」——没有这个，一切免谈
固定套路：决定你「练什么」——没有套路=随机发挥=无法迭代
非舒适区：决定你「有没有在进步」——只在舒适区=熟练但不更强
及时反馈：决定你「知不知道哪里要改」——没有反馈=不知道自己是对是错
大量重复：决定你「练了多少次」——次数不够=理解停在脑子里，没到手上

每增加一个要素，成长速度可能翻倍；
每缺少一个要素，练习效果可能成倍打折。
```

### 模型二：刻意练习五要素的「有无对比表」

| 要素 | 没有它 | 有了它 |
|---|---|---|
| **长期追求** | 被任务推着走，遇到难点容易停，练习三天打鱼两天晒网 | 愿意持续投入，能扛过笨拙期，愿意凑齐其他要素 |
| **固定套路** | 每次凭手感，做得好无法保留，做得差无法定位 | 动作可重复，反馈有抓手，能力可迭代 |
| **非舒适区** | 越来越熟练，但不一定变强——「做了很多年，水平差不多」 | 持续逼近能力边界，每一轮都产生真实升级 |
| **及时反馈** | 重复错误动作，误以为自己在进步——张林卫第一阶段 | 看见差距，知道下一次调哪里——张林卫拿到4个参数后 |
| **大量重复** | 理解停在脑子里，没有形成能力——「听了很多课，能力没上去」 | 次数堆起来，套路和反馈形成飞轮，能力长到手上 |

### 模型三：张林卫的「四阶段刻意练习跃迁」——从小白到世界级的完整路径

```text
第一阶段：粗浅尝试（无套路+无反馈）
  特征：凭感觉、凭直觉、凭运气
  状态：偶尔能赢，输多赢少，经常破产，不得要领
  最大卡点：没有有效反馈——赢不知道哪里赢，输不知道哪里输

第二阶段：找到套路（有简单模型）
  特征：发现4个参数→按模型决策
  状态：几个月后在白银段位胜率超过90%玩家
  关键转折：从「凭感觉」→「按模型」——这是刻意练习第一道分水岭

第三阶段：升级模型（更复杂的理论体系）
  特征：看专业书+研究数学+研究心理学
  状态：晋升黄金级别，对手更强，模型更复杂
  关键动作：不只练德扑，还研究底层学科

第四阶段：成为专家（可持续输出+可教别人）
  特征：世界Top级别+创办培训机构
  状态：从「自己厉害」→「能让别人也厉害」
```

### 模型四：反馈质量决定练习质量——张林卫第一阶段的教训

```text
错误信念：「我打了很多手牌=我在练习」
残酷真相：「打了很多手牌但没有反馈=不知道对错=练了白练」

有效反馈的三个标准：
  1. 能告诉你「对在哪、错在哪」，而不是只有结果（赢/输）
  2. 能让你下一次动作有调整方向
  3. 离练习动作越近越好（即时反馈 > 延迟反馈）

张林卫的转折点：
  从「只能用输赢判断」→「有4个参数描述打法特征」
  从「赢不等于打得好，输不等于打得不好」→「每个决策都能被参数评价」
```

### 模型五：秦鹏的「学习型组织三环模型」

```text
        1号位以身作则
        （20万+字作业）
           /\
          /  \
         /    \
        /      \
  基本功图谱 ──── 制度保障
（通用+部门）（逐字稿纳入工作流）

三个环同时运转：
  1号位不是「要求你们学」，而是「我先练给你们看」
  基本功图谱让每个人知道「我要练什么、标准是什么」
  制度保障让练习不只是「靠自觉」而是「被机制托住」
```

### 模型六：Truman的五步法刻意练习三阶段

| 阶段 | 目标 | 核心动作 | 状态 |
|---|---|---|---|
| **第一阶段** | 帮助从0到1的项目梳理盲区 | 大量拆解不同项目的五步法画布 | 基础练习 |
| **第二阶段** | 从定性到定量+动态预测 | 提高难度，努力在五步法各环节成为专家 | 进入非舒适区 |
| **第三阶段** | 和高水平的人平等对话 | 从科大讯飞高管到古典，从顶级机构投资人到周子敬 | 用五步法在最高阶商业层面平等对话 |

**L6级核心认知**：Truman不是在「学五步法」，而是在「用五步法训练自己」。从自己做→辅导新项目→教给别人→和高水平的人平等对话——**每一层都在刻意练习。**

### 模型七：三种练习目标的分层模型

```text
快速上手：超越80%的人，60分够用 → 20小时
成为专家：超越95%的人，追求85分 → 几百小时
无限进步：超越99.99%的人，追求100分 → 几千上万小时

核心练习：主动大量练，认真做加法
其他练习：顺带着练，拉长时间等复利
```

**关键认知**：刻意练习不需要10000个小时——往往20个小时就能立竿见影练出效果。市场上绝大多数人从来没刻意练习过，你只要稍微认真练几轮，就能超越多数人。

| **长期追求** | 大概知道想练什么 | 能写出几项核心练习 | 能区分核心练习/顺带练习+定期回顾+用十年视角ROI思维理解基本功 |
| **固定套路** | 跟着教程做 | 有自己的模型和框架 | 随水平升高持续建模+模型越来越复杂+能从自己复制到团队 |
| **非舒适区** | 偶尔挑战新东西 | 持续待在能力边界 | 每次晋级都主动找更强的对手/更难的任务/更高水平的人对标 |
| **及时反馈** | 看结果好坏 | 有具体反馈机制 | 找到「能看见每个动作对错」的反馈工具+反馈能进入下一轮调整 |
| **大量重复** | 偶尔练一次 | 每周固定练习 | 主动找各种机会+融入日常+拆解小练习+叠加暗时间+准备系数成百上千倍 |
| **从个人到组织** | 自己练 | 带团队一起练 | 全案开源基本功图谱+以身作则+制度保障+能力建模可复制 |

## 七、可直接带走的最小行动清单

### 如果你也想刻意练习一项核心能力：

1. **先判断你现在卡在哪个要素**：长期追求不够笃定？没有固定套路？一直待在舒适区？反馈太少？重复不够？——缺什么补什么
2. **找到你的「4个参数」**：像张林卫一样——有没有一个工具/框架/参数能让你不再只靠「感觉好坏」来判断？这就是你从第一阶段跃迁到第二阶段的关键
3. **拆你的核心练习和顺带练习**：不需要把所有想练的都放进「核心练习」——选1-2个主动大量练，其他的顺带磨、等长期复利
4. **用20小时先跑通一个小能力**：不要一上来就奔着10000小时——选一个20小时能快速上手的能力，凑齐四要素认真练一轮，**感受一次「十倍速成长」的体感**

### 如果你想带团队一起练：

5. **1号位先自己练出体感**：像秦鹏一样——20万+字作业，自己先成为内部标杆案例，才有资格要求团队
6. **建你的公司基本功图谱**：拆成通用基本功（全公司都要练）+部门核心基本功（各部门专业壁垒），让每个人知道自己要练什么
7. **练逐字稿这个超级基本功**：重要会议、公开发言前写逐字稿——这可能是ROI最高的单一练习动作

---

> **一句话收束**：兰军用「不甘现状+冲出舒适区+建模型+找一切机会练习」证明了社恐也能练成千人讲师，张林卫用「4个参数+专业书+持续挑战更高级别」证明了小白也能练成世界级德扑玩家，秦鹏用「20万+字作业+基本功图谱+逐字稿落地」证明了1号位可以把一堂变成整个公司的操作系统。三个人的共同起点，都是同一句朴素的话：**刻意练习不是天赋的专利，而是一套可以被任何人学会的「十倍速成长」底层操作系统。当你把长期追求、固定套路、非舒适区、及时反馈和大量重复这五个要素全部凑齐时——成长不是线性爬坡，而是翻倍加速。** 而张林卫拿到4个参数那一刻「就像在茫茫大海上看见了灯塔」的感觉，或许就是刻意练习最准确的隐喻：**大部分人不是不努力，而是一直在黑暗中凭感觉挥拳。刻意练习给你的，就是那盏让你看清每一次动作对错的灯。**
