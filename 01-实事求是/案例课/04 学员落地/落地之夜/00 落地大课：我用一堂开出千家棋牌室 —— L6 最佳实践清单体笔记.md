# 落地大课：我用一堂开出千家棋牌室 —— L6 最佳实践清单体笔记

> **源课**：一堂Live 184·24年落地案例大课  
> **案主**：杜金科（一堂MBA学员 / 久雀自助棋牌室创始人）  
> **核心命题**：一个没上过大学、没打过麻将、几乎没钱起盘的连续创业者，如何用一堂方法论在不到2年时间把自助棋牌室从0做到全国1500+店？  
> **笔记定位**：不只还原打法，更提炼「科学创业从预判到规模化」的全周期底层模型与L6审美清单

## 一、先看全局：一个"反常识"的创业样本

### 1.1 成绩单

| 指标 | 数据 |
|---|---|
| 签约门店 | 1500+家（全国第二） |
| 落地开业 | 1300+家 |
| 重庆市场 | 绝对第一（第2到第30名加起来不如一个品牌） |
| 美团销量 | 全国第一，超第二名两倍多 |
| 美团上榜率 | 门店上榜率85%以上 |
| 覆盖城市 | 20+个省、100+个城市 |
| 融资 | 已到账第一笔机构融资 |
| 起盘时间 | 2022年2月首店 → 2023年3个月破百店 → 2024年破千店 |

### 1.2 这个案例为什么"反常识"

| 反常识点 | 普通人的直觉 | 杜金科的实际 |
|---|---|---|
| 学历 | 创业者得是名校/MBA | 没读过大学，破格进阿里 |
| 行业经验 | 得深耕一个行业多年 | 不打麻将、不熟悉棋牌室 |
| 资金 | 起盘得烧大钱 | 几乎没钱，用**众筹房间**开了第一家店 |
| 速度 | 慢慢来比较稳 | 3个月破百店，6个月从300跃到1000+ |
| 姿势 | 有机会就赶紧干 | 学了50+节课按住不动，先做4轮调研 |

### 1.3 关联一堂课程全景（10+门核心课的系统落地）

| 一堂课程 | 在案例中的应用 |
|---|---|
| 调研课 | 4轮调研（拆单店→找报告→访门店→伪装加盟）+ 持续自动式调研 |
| 精益课 | 众筹房间开首店、低成本MVP、不提前复制未验证模式 |
| 五步法 | 双版本画布（ToC + ToB）、3轮加减法预判、假设池拆解 |
| 单元模型 | 测算3种店型UE、建立benchmark、动态迭代 |
| 预判课 | 天花板测算、竞品推演、风险提前消除 |
| 壁垒课 | 品牌壁垒预判、产品细节创新（开门关灯体验） |
| ROI课 | 收不收费→收多少→优先代理还是单店→说服团队 |
| 增长课 | 从直销到代理、获客渠道组合、自然流量运营 |
| 融资课 | 调整BP、拿到融资 |
| 抖音课 | 孵化爆款账号、加盟商赋能 |

## 三、阶段一：机会发现——"以前的我大概直接开干了"

### 3.1 缘起

| 节点 | 事件 |
|---|---|
| 2022年2月 | 因股权问题退出上一个创业项目（酒店自助售货盒，全国30+万台，行业第一） |
| 2022年2月 | 加入一堂，半年学完50+节课，建立调研/精益/单元模型/预判/ROI/融资的框架审美 |
| 2022年6月 | 一位有30+年传统线下门店经验的朋友找到他，说自己开了家自助棋牌室，4个月数据很好，想拉他合伙做招商加盟 |

### 3.2 "按住不干"的决策——第一道分水岭

```text
"如果是以前没学一堂的我，大概率会跟着他一起立刻开干。
但是幸运的是，自己已经学习了一堂，所以就把这个想法按住了，决定要先调研一番。"
```

**核心认知**：以前是"差不多想清楚就干"，学了一堂之后是"先充分调研拿认知，再决定下不下场"。

### 3.3 第一轮调研：能直接拿到的信息

| 调研动作 | 内容 | 认知收获 |
|---|---|---|
| 拆单店 | 把朋友已开那家店的单店模型拆一遍 | 第一家店数据确实好 |
| 找报告 | 看行业报告算天花板 | 市场有空间 |
| 访门店 | 走访传统棋牌室（自助棋牌室竞品） | 了解经营现状和替代空间 |

**初步判断**：有机会，但还不够——需要好好研究同行。

### 3.4 第二轮调研：从张磊那里学到的"假装"大法

**灵感来源**：想起张磊在案例课上分享的——假装合作、假装应聘、假装加盟、甚至入职竞品公司。

**实战操作——潜入友商会销场**：

| 操作 | 细节 |
|---|---|
| 提前潜入 | 提前进入合作群，了解哪些加盟商会到场 |
| 分散座位 | 几个人坐在不同区域，能接触更多加盟商 |
| 多身份套信息 | ①假装加盟→找官方了解招商细节 ②假装加盟商前辈→问真实经营状况和困难 ③伪装投资人→"我不会做，能不能出钱请你经营"以获取信任 |

**产出**：拿到友商真实的用户需求、解决方案、经营数据，**还给友商画了一张五步法推演图**。

## 四、阶段二：预判验证——"从几百个选项里选出一组排列组合"

### 4.1 心态转变

```text
"之前的赌性比较大，拍脑袋，差不多想清楚就开始干。
但这次不一样——我差不多了，可以成xN，我不能再输了，输不起了。"
```

### 4.2 拆假设池——把选择题全部摆出来

面对项目，先不急着做决定，而是把所有假设一个一个摊开：

| 假设编号 | 问题 | 类型 |
|---|---|---|
| 选择1 | 门店消费怎么定价？走高端还是性价比？ | ToC |
| 选择2 | 选址选哪里？要不要门脸？门头怎么装修？ | ToC |
| 选择3 | 里面怎么装修？深色稳重还是鲜艳简洁？ | ToC |
| 选择4 | 门店运营自己做还是找代运营？未来是否提供运营服务？ | ToB |
| 选择5 | 招商只做新店加盟还是可以对传统门店改造？ | ToB |
| 选择6 | 招不招代理？做不做分销？ | ToB |
| 选择7 | 技术是自建团队还是外包？ | 能力 |

### 4.3 关键认知：ToC和ToB两版画布都要拆

```text
"如果ToC端画布不拆好，会影响门店经营数据，最终影响的是ToB的招商。
只有两个画布综合作用，同时成立，业务才能长期稳定地走下去。"
```

### 4.4 ToC画布——相对好判断的问题

| ToC维度 | 判断 | 依据 |
|---|---|---|
| 定价 | 走性价比 | 客人普遍年轻人，在意便宜 |
| 包间 | 全包间 | 私密性好是核心需求 |
| 装修风格 | 鲜艳简洁 | 同行普遍装修颜色明艳 |
| 选址 | 年轻人群聚集的高流量商圈 | 客人靠线下自然流量+线上美团 |
| 门头 | 需要显眼的牌子，用「幺鸡」作标识 | 友商很多店不开在一楼，牌子小；用麻将牌做标识最明显 |

### 4.5 ToB画布——需要更多信息才能判断

基于调研拿到的信息，最终画出ToB版五步法：

| 五步法维度 | 内容 |
|---|---|
| **需求** | 用户想要低成本新开门店 / 门店小白不懂经营 / 不愿意守店或请人 / 不会选址和营销 |
| **解决方案** | 提供选址 + 标准化装修+系统支持自助服务 + 运营支持帮助门店推广获客 |
| **商业模式** | 装修和设备差价 + 直销赚加盟费+技术服务费 + 代理赚代理费+技术服务费 |
| **增长** | 直销招加盟+招代理（短期先不做分销） |
| **壁垒** | 直接成本低 + 管理成本低 + 运营成本低 → **品牌** |

### 4.6 3轮加减法——从几百个选项到一组高成功率组合

```text
充分做加法，尽量做减法，风险提前消除。
找到一个五步法组合，排除掉了12345，预判成功率Max。
```

**课堂原话**："你们觉得这样选择之后的五步法和之前看到一个机会就直接下场的情况相比，成功率是不是至少翻了好几倍？至少心态上，你也会更加笃定，而不是觉得自己在赌博吧。"

### 4.7 预判壁垒——品牌 + 产品细节

- 预判壁垒方向：**品牌**——行业集中度极低，夫妻店为主，品牌有窗口期
- 同时打造产品创新细节：开门自动亮灯、关门自动关灯——微小体验差异积累品牌温度

## 五、阶段三：精益起盘——"没有钱，怎么开店？"

### 5.1 最大难题：一个店20万，没钱没人信

| 条件 | 现状 |
|---|---|
| 自有资金 | 几乎没有 |
| 信任度 | 周围人不信——"你自己先开几家让我们看看" |
| 课程提醒 | 反复告诫自己：要测算模型，不要过早复制未经验证的商业模式 |

### 5.2 破局一：众筹房间开店

**灵感来源**：想起一堂案例——张磊借货测试 + 有人通过众筹做产品。

**操作**：把一家店按房间分，让大家用投房间的方式开店，降低单个出资人的风险和阻力。

**结果**：说服亲戚朋友众筹3家店，低成本测了额外3种店型。

### 5.3 破局二：能力建模招聘——外卖小哥当选址员

| 常规做法 | 杜金科的做法 |
|---|---|
| 搜招聘网站"选址员"→ 薪资都很高 → 发高薪JD → 面试说给不了那么高 → 招不到人 | 先拆能力模型：只需要一个熟悉区域、能拿着SOP勤奋扫街的人 |

**关键追问**："如果只是这个能力，谁更匹配？"

**答案**：做过骑手的外卖小哥——避开同行的人才竞争，成功解决招聘难题。

### 5.4 破局三：搞定自然流量——混进业主群

| 获客动作 | 细节 |
|---|---|
| 门头设计 | 最显眼的「幺鸡」标识，让人远远就能看到 |
| 搞定物业保安 | 发烟、聊天、建立关系 |
| 混进业主群 | 靠搞定保安进入小区业主群，直接触达目标用户 |

### 5.5 起盘成果

- 开了3+2个店（众筹3家 + 后续2家），半年多跑通单元模型
- 评估基准：1到1年半回本就很好 → **全部跑通，都能盈利**
- 建立了完整的单元模型benchmark
- 很多人主动来问想加盟，但**忍住没开放**——先跑稳模型

## 六、阶段四：早期增长——跑通加盟商模型

### 6.1 早期增长策略

- 不收加盟费（和同行一样），营收靠设备差价 + 技术服务费（营收5%）
- 6个月开出100+店，签约300+家，重庆市场占有率第一
- 转化率数据：老客户50%→20%，老客户3%（一段后下降）

### 6.2 致命问题出现：现金流卡死

| 表面 | 实际 |
|---|---|
| 发展特别好、特别迅速 | 始终没有盈利，仅仅保本 |
| 市占率西南第一 | 总部账上没有多余现金流 |
| 目标2026年开1万家店 | 需要5000万现金储备，根本拿不出 |

**连锁反应**：
- 投资人嫌财务模型不健康 → 融不到资
- 跨地区招代理困难 → 代理商不愿加入不赚钱的品牌
- 团队薪水低 → 难吸引优秀人才

### 6.3 两难困局

```text
不收加盟费 → 财务模型差 → 融不到资 → 无法支撑下一阶段增长
收加盟费 → 可能降低开店速度 → 错过3年竞争窗口期
```

## 七、阶段五：规模化对抗——用ROI打破两难

### 7.1 关键决策一：从不收费到收费——ROI画布破局

**对照测试**：在重庆（免费）和成都（收费）同时跑。

| 维度 | 重庆（免费） | 成都（收费） |
|---|---|---|
| 加盟费 | 0元 | 区域代理50万 |
| 开店速度 | 稳步增长 | 不降反升（代理信心更强） |
| 总部现金流 | 紧缺 | 大幅改善 |
| 服务投入 | 有心无力 | 敢派3人出差1个月帮选址 |

**成都标杆效应**：
- 第一家店生意好 → 代理补交149万升级为市级代理
- 有标杆 → 加盟拓展速度大幅加快
- 1个月后拿到投资人几百万天使轮融资

**结论**：收取加盟费并不影响签约速度，反而因为现金流改善和服务投入增加，形成了正向飞轮。

### 7.2 关键决策二：优先代理还是优先单店？——ROI画布再破局

| 选项 | 拓店模型 | 现金流 | 开店速度 |
|---|---|---|---|
| 总部直接拓店 | **线性**：每月50家→50家→50家 | 一家店1万加盟费 | 线性增长 |
| **招代理拓店** | **指数**：1代理→2代理→4代理→6代理（每个代理同时拓店） | 一个代理几十万代理费 | **指数增长** |

**收益 >> 成本**，决策很清晰：**优先代理**。

### 7.3 说服团队——站在员工角度画ROI

```text
"大家其实不想优先谈代理，主要是签单店更容易，周期很短，
大家短平快地拿到提成，很开心。
但签约代理的不确定太强了，大家担心自己的收入有影响。"
```

**解法**：修改绩效激励——签下代理按代理费提成20%，让大家觉得签代理收入更高。

**公司配套动作**：
- 统一话术，所有线索引导客户成为代理
- 投放广告和品牌策略调整为优先招聘代理

### 7.4 结果：进入指数增长飞轮

| 时间 | 门店数 | 关键动作 |
|---|---|---|
| 6个月 | 100→300+ | 不收加盟费，直销为主 |
| 随后6个月 | 300→1000+ | 收加盟费 + 优先代理 |
| 至今 | 1500+ | 20+省、100+城市 |

## 八、阶段六：全国复制——自动式调研与数据驱动

### 8.1 "首战即决战"：城市选择不能靠拍脑袋

```text
"敌我双方第一次正面交锋，就能决定整个战争的走向。
不能用单一维度单点决策。"
```

### 8.2 数据驱动的城市选择

**动作**：安排人去各个竞对小程序，把门店数一个城市一个城市数出来，找到top10城市 + 拉出各城市近3个月单月增长数据。

**震撼发现**：
- 竞对在广东一个市场单月增量100家——而杜金科全公司一个月才签几十到100家
- 竞对在广东和广西放了同样的重兵，广东900+店、广西三年才几十家

**认知升级**：
```text
"同行已经帮我们去做了一轮的验证。
如果当初只看棋牌室存量市场，因为一个地方棋牌室多、竞品少就做选择，
那可能真的要踩坑了。"
```

### 8.3 自动式调研系统——持续监控竞对

| 机制 | 具体操作 |
|---|---|
| 新人必修课 | 所有新人必须伪装成加盟商给竞对打电话，快速找体感 |
| 微信小号矩阵 | 所有销售用个人微信加同行，围观朋友圈，定期伪装加盟商联络 |
| 月度竞对汇报 | 每月总监级别汇报竞对信息，纳入月会固定议程 |
| 设备供应链渗透 | 顺藤摸瓜找到竞对设备供应商，以合作为由套取成本结构、出货量、部署计划 |
| 门店体验制度 | 总监/装修/运营每月必须体验同行最新门店，收集流程升级和加盟商经营数据 |

### 8.4 竞对情报转化为实际行动的两个案例

**案例一：设备升级**
- 潜伏竞对社群 → 发现竞对更新招商PPT说设备升级
- 顺藤摸瓜找到供应商 → 套到成本结构和真实出货数
- **还提前获知竞对要进军自助台球厅和KTV**（内部都还没公开）
- 用来衬托自己"更专注棋牌室，不会换赛道，不是割韭菜"

**案例二：钛金板**
- 在昆明体验一家小品牌店 → 发现用了钛金板装修，成本没增加但更亮眼
- 回去立刻升级自家门店材料

### 8.5 自建运营能力——与同行的差异化

| 同行做法 | 久雀做法 |
|---|---|
| 不提供运营服务 | 自建运营部，帮加盟商把门店经营做好 |
| 或请代运营来做 | 美团销量全国第一，超第二名两倍多 |
| — | 门店上榜率85%以上 |

## 九、杜金科的学习三阶段：为什么他能"知行合一"

### 9.1 学习储备期（2022.2-2022.6）

- 因股权问题退出上一段创业，反而有了充足学习时间
- 每周内测课必学 + 再选一节上架课
- 不到半年完成50+节课：调研、精益、单元模型、预判、融资、ROI，全部建立审美和框架
- 核心心态："虽然眼下不做业务，但未来一定还要创业，这些课程早晚都会用得到"

### 9.2 实战应用期（2022.6起）

- 每一个关键决策都能追溯到一堂具体课程
- 遇到问题 → 翻出对应课程重新学 → 应用
- 带着团队7人去ROI线下训战营学习
- 办公室最显眼位置放一堂周边

### 9.3 团队复制期（持续至今）

- 核心团队全员学一堂
- 运营负责人+品牌负责人均为MBA学员
- "每周打多久麻将才不会影响工作"——团队成员也用ROI画布做决策
- 带着合伙人从重庆飞到深圳/成都参加线下训战营

## 十、跨案例提炼：杜金科案例的 L6 级底层模型

### 模型一：科学创业全周期里程碑

| 阶段 | 核心命题 | 一堂工具 | 杜金科的关键动作 |
|---|---|---|---|
| 机会发现 | 这个机会值不值得看？ | 调研课 | 4轮调研，从能直接拿的到模仿张磊"假装" |

| 精益起盘 | 怎么低成本拿认知？ | 精益课 | 众筹房间→3种店型→不提前复制 |

### 模型二：预判阶段的加减法框架

```
第一步：充分做加法——把所有能想到的选项、假设、风险都列出来
第二步：专业化减法——用调研拿信息、用五步法做推演、用模型做验证
第三步：找到一组排列组合——排除掉12345，预判成功率Max
```

### 模型三：ToC + ToB 双画布联动模型

```text
ToC画布（门店经营）          ToB画布（招商加盟）
┌──────────────────┐       ┌──────────────────┐
│ 需求：年轻人要便宜方便  │       │ 需求：小白想开店但不会  │
│ 方案：24h自助+全包间   │  ←→  │ 方案：选址+装修+运营    │
│ 增长：自然流量+美团    │       │ 增长：加盟+代理         │
└──────────────────┘       └──────────────────┘
         ↓                        ↓
    ToC不成立              ToB不可能长期
    → 门店数据差           → 招商不可持续
         ↓                        ↓
         └────── 两版画布必须同时成立 ──────┘
```

### 模型四：ROI驱动的规模化决策框架

| 决策场景 | 杜金科的操作 | 底层逻辑 |
|---|---|---|
| 收不收费 | 对照测试重庆vs成都 | 不靠直觉，靠数据对照 |
| 优先什么渠道 | 画两版ROI画布（直销vs代理） | 不只算财务收益，还算速度（时间窗口） |
| 说服团队 | 站在员工角度画ROI + 改绩效激励 | 不只自己算清楚，让团队也算清楚 |
| 选什么城市 | 竞对数据驱动 + "首战即决战" | 不用单一维度，用多维数据交叉验证 |

### 模型五：自动式调研系统——从个人动作到组织能力

```text
个人动作（早期）：
  伪装加盟商打电话 → 潜入竞对社群 → 参加会销场套信息

制度化（成长期）：
  新人必修课 → 微信小号矩阵 → 月度竞对汇报 → 供应商渗透 → 门店体验制度

组织能力（成熟期）：
  竞对信息自动流入 → 月度分析 → 驱动产品迭代 + 城市选择 + 话术升级
```

### 模型六：精益起盘的三层"不花冤枉钱"

| 层级 | 问题 | 杜金科解法 | 传统做法 |
|---|---|---|---|
| 系统开发 | 需要技术但没钱 | 用上一段创业的技术直接改一版小程序 | 从头开发/外包 |
| 开店验证 | 需要多店数据但没钱 | 众筹房间→把一家店按房间分→多人投 | 自己掏钱或融资 |
| 人才招聘 | 需要选址员但同行薪资太高 | 能力建模→拆出真正需要的能力→找外卖小哥 | 对标同行薪资硬招 |

## 十一、L6 级别审美清单：好的科学创业者长什么样

| 维度 | 60分合格 | 85分优秀 | L6无限进步 |
|---|---|---|---|
| **面对机会** | 觉得不错就试试 | 调研一圈再决定 | 4轮调研+双版画布+3轮加减法+预判壁垒，才决定下场 |
| **起盘方式** | 凑钱开一家试试 | 先做MVP验证 | 众筹房间+测3种店型+忍住不提前复制+有了benchmark才开放加盟 |
| **遇到两难** | 拍脑袋选一个 | 跟团队讨论一下 | 画ROI画布+对照测试+站在员工角度算账+改激励+统一话术 |
| **团队决策** | 老板说了算 | 开会讨论 | 每个人都能画ROI、看数据、讲道理——"上下笃定，需要一个讲道理的老板" |
| **竞对关注** | 偶尔看看竞对在干嘛 | 定期关注竞对动态 | 自动式调研系统：新人必修课+小号矩阵+月度汇报+供应商渗透+门店体验制度 |
| **学习转化** | 听完课记了笔记 | 拿一个方法试试 | 50+节课建立完整框架→每个关键决策都能追溯到具体课程→带团队一起学→知行合一 |
| **扩张决策** | 看哪个城市感觉有机会 | 看存量数据选城市 | 竞对数据驱动+多维交叉验证+"首战即决战"的战略敬畏 |

## 十二、可直接带走的最小行动清单

### 如果你正准备起盘一个新业务：

1. **先别干，先调研**：像杜金科一样，至少做三轮——拆单店模型、找行业报告、实地走访
2. **学"假装"大法**：假装加盟、假装合作、假装投资，用不同身份拿不同维度的信息
3. **画出你的双版画布**：你的业务有没有ToC和ToB两面？两版都拆，看是否同时成立
4. **做一次加减法**：把能想到的所有选项列出来→用调研信息逐个排除→找到一组成功率最高的组合
5. **用ROI破解两难**：面对"进退两难"的决策时，画一张ROI画布，把收益和成本都摆上去

### 如果你已经在增长阶段但卡住了：

6. **检查你的单元模型**：单店/单客户模型真的跑通了吗？有没有benchmark？敢不敢忍住不提前复制？
7. **建立自动式调研系统**：新人伪装加盟商打电话、销售用小号加同行微信、每月固定汇报竞对动态
8. **用ROI说服团队**：不只自己算清楚，也让团队算清楚——调整激励让他们愿意做"更难但更对"的事

### 对所有人：

9. **提前储备见识**：杜金科学了50+节课半年后才用上——"虽然眼下用不到，但说不准哪一天会帮到你"
10. **遇到问题就翻课**：杜金科每次遇到卡点（收不收费、招什么人、选什么城市），都会翻出对应的课重新学一遍

---

> **一句话收束**：杜金科证明了四件事。第一，没上过大学不打麻将也能做好棋牌室——因为科学创业和行业经验是两码事。第二，一堂的课不是"听听有道理"，是真的能在每一个关键决策上被调用。第三，精益不是抠门，是"众筹房间开店"的创造力和"忍住不提前复制"的纪律性。第四，一个讲道理的老板 + 一群能画ROI的团队 = 上下同欲。而这一切的起点，是他看到机会时说的那句话——"如果是以前的我，大概直接开干了。但这次，我先调研了一番。"
