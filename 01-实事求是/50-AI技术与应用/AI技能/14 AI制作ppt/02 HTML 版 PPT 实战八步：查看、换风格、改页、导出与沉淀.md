# 课程：PPT实战八步·02

**一句话结论：** HTML PPT 八步闭环 = 装 Skill→读资料→出大纲→看初版→备份换风格→截图/注释改页→导出 PDF/PPT→沉淀项目级 AGENTS.md；**HTML 是迭代场，PDF/PPT 才是交付场**。

---

## 一、核心交付

- 一条 8 步可复用工作流。
- 一对改页工具：截图 vs 注释。
- 一个沉淀动作：把流程写进**项目级** AGENTS.md（不写全局）。

## 二、八步工作流

| 步 | 动作 | 关键要点 |
|---|---|---|
| 1 | 装 Skill | guizang-ppt-skill；装后重启；用 $Skill/@Skill 验证 |
| 2 | 读项目资料 | 资料放同目录；「使用现有文件夹」；边界：不编造未提供内容 |
| 3 | 出大纲再调试 | 开计划模式、推理调高；先定页数/结构/Logo/字体/版式 |
| 4 | 看 HTML 初版 | 产物 index.html + assets；查主题/顺序/排版/缺字/异常信息/数据来源 |
| 5 | 先备份再换风格 | 备份 zip 防覆盖；让 AI 先推荐风格，**新增文件**不覆盖 |
| 6 | 逐页改 | 截图+注释；提示词写清页码/问题/保留项/限制 |
| 7 | 导出 PDF/PPT | 16:9 横版、不裁切不拉伸、超出等比缩放 |
| 8 | 沉淀 AGENTS.md | 写项目级，不写全局（全局费 Token） |

## 三、第 4-5 步：初版检查与换风格

**检查清单：** 主题一致 / 顺序合理 / 排版可接受 / 无缺字 / 无不该出现的信息 / 数据截图结论均来自参考资料。

**换风格推荐提示词：**
```
根据上面的内容，我想要换其他的视觉风格，有何推荐；
根据 Guizang Ppt Skill，只要提供建议不要修改现有资料
```
- AI 推荐排序参考：靛蓝瓷 > 墨水经典 > 沙丘；仅换 IKB 主色不算换视觉语言。
- **新增**提示词：
```
帮我新增一个 HTML PPT，风格是 电子杂志×电子墨水 + 靛蓝瓷，不要覆盖现有资料
```

## 四、第 6 步：截图 vs 注释

> **截图 = 让 Codex 看见问题；注释 = 让 Codex 精准修问题。**

| 对比 | 截图 | 注释 |
|---|---|---|
| 本质 | 静态画面证据 | 页面上的精确反馈点 |
| 理解 | 看整图 + 文字说明 | 知道你点的是哪个元素 |
| 适合 | 记录状态/对比/给参考图 | UI 微调、指按钮/间距/颜色 |
| 精准 | 中，需补充描述 | 高，绑定位置 |

**改页提示词要写清：** 页码 + 问题 + 期望 + 必须保留 + 允许调整 + 不能影响的页。
> 例：「修正第 4 页第三列超底；保留标题/三项/暗色；只改三列布局；不影响其他页。」

**踩坑：** 额度用尽→用重置点；模型拥挤（at capacity）→推理从高降到中。

## 五、第 7 步：导出

**导 PDF 提示词：**
```
请把 [文件名].html 导出为 PDF，每页 16:9 横版；
完整保留画面比例与内容，不裁切、不拉伸；
内容超出时等比缩放适配到页面内
```
**导 PPT：** 同 PDF，把 PDF 换成 PPT，可补指定输出目录。
- 若内部接受 HTML 形式，此步可跳过。

## 六、第 8 步：沉淀项目级 AGENTS.md

**沉淀提示词：**
```
请根据今天生成 PPT 的完整过程，把经验沉淀到当前项目目录的 AGENTS.md；
只更新本项目级，不改全局、不写其他项目；
写成可复用流程：适用场景/步骤/格式/常见问题/踩坑/下次硬规则。
```

### AGENTS.md 硬规则精华（10 条）

1. 先读素材后定大纲，不编造内容。
2. 先定风格/主题/版式/页映射，后写 HTML。
3. **默认新增文件，不覆盖旧版**（确需覆盖先征得同意）。
4. 每页保留隐藏来源注释；每份 Word 对应 1-2 页。
5. 一份 deck 只用一套视觉系统，杂志风/瑞士风不混用。
6. 生成后必做：静态检查 + 两种分辨率（1920×1080 / 1366×768）视觉检查 + 交互检查。
7. 用户批注做最小修改，不顺手改未被请求的页。
8. PDF 用逐页 1920×1080 截图 → 960×540 pt 封装，严格 16:9。
9. PDF 重新渲染逐页目视检查后才交付。
10. 成功结论须有最新验证；临时文件用完即删。

> AGENTS.md 要持续迭代，不是写完一次就不改。

## 七、金句与判断

> 「HTML PPT 是初稿和迭代场，PDF & PPT 才是稳定交付场。」
> 「不建议把项目规则写进全局 AGENTS.md——每次都参考，很费 Token。」

## 八、行动建议

| 层级 | 行动 |
|---|---|
| 基础 | 跑通八步，重点练「截图+注释」改页 |
| 进阶 | 把本次流程沉淀成项目级 AGENTS.md |
| 高阶 | 按 10 条硬规则迭代 AGENTS.md，形成自己的出 PPT 范式 |

## 九、我的批注（双轨）

- 我的：「默认新增文件不覆盖」「最小修改不顺手改别处」正好是我该守的编辑纪律。
- 待验证：导出参数（Playwright/Poppler、960×540pt）随工具版本可能变化。
