# 📕 05号任务说明书

这是一堂官方挑战任务包的“**第05号任务**”：**建知识库；**

## 📙 快速介绍

![](01-实事求是/50-AI技术与应用/AI技能/一堂AI任务书01-05/任务书05：建知识库/imgs/p01_002.png)

AI 友好的知识管理，和“给人看”的知识管理是两套范式。

推荐 **Obsidian + 本地 Markdown**：多 Agent 可协作、格式对 AI 友好、足够简单。

> 📘 **重点不是工具，而是：把工作从“聊天记录”搬到“文档库”。**

**本轮任务为：搭一个 AI 读得懂、人和 Agent 一起写的知识库。**

## 📗 完成的价值

![](01-实事求是/50-AI技术与应用/AI技能/一堂AI任务书01-05/任务书05：建知识库/imgs/p01_003.png)

🟡 **和 Agent 一起工作，常见的痛点是：**

- 一直用聊天 / 各种文件，AI 很难稳定读取和协作。
- 每次靠 Session，上下文一关就“一夜回到 0”。
- 信息在聊天里传纸条，反复重述。

🟠 **通过练习这个任务，希望你感受到：**

- 手敲率从 50% 降到 5%。
- 人和 Agent 共享一套上下文。
- 能同时带多个 Agent 工作。

> 🔴 通过完成这个任务，开始把“知识库”当成 AI 的工作台，找到**「回不去」**的感觉。

## 📘 具体任务说明

![](01-实事求是/50-AI技术与应用/AI技能/一堂AI任务书01-05/任务书05：建知识库/imgs/p01_004.png)

为了支撑不同的难度，我们设定了两个难度的任务：

> 🔵 **标准版任务**
> 
> 选一个工作范围（营销 / 客服 / 学习），搭一个 Obsidian 目录，人和 Agent 一起读写。
> 
> 适合：一堂会员 / 大航海 / AI 俱乐部

> 🔴 **挑战版任务**
> 
> 完成一个 Obsidian 循环的执行项目：用编号 + 清单体做“上下文微操”。
> 
> 适合：AI 落地高手营 / AI 俱乐部专家

你可以根据不同的历史经验来完成这个任务：

**♥️ 情形1：**如果你已经有本地库，补上目录规范和一次人机共写记录，然后直接提交。

**♥️ 情形2：**如果你尚未开始，建议你可以按照这三个步骤学习和搭建：

1. 安装 Obsidian，选一个工作范围建目录。
2. 写 00 顶层，定好编号与命名规则。
3. 让 Agent 和你一起读写这个目录，跑完一个真实任务。

👉然后回看这次协作，感受到“上下文不再丢”的爽点。

请你把目录截图、你和 AI 沟通记录和使用体会，提交一个飞书一页纸提交。

- **🔵 标准版最好包含：**
  目录截图，一次共写记录，使用体会。
- **🔴 挑战版最好包含：**
  编号设计，微操流程，跑通的项目。
