# 📙 03 号任务说明书

这是一堂官方挑战任务包的“**第03号任务**”：**封装Skill；**

## 📘 快速介绍

![](01-实事求是/50-AI技术与应用/AI技能/一堂AI任务书01-05/任务书03：封装Skill技能/imgs/p01_002.png)

技能（Skill）是和 Agent 一起工作，**几乎最常见、最重要的“经验封装工具”。**

把一个你**经常重复做、已经有些经验**的动作，封装成一份可调用的 Skill 或标准指令。

> 📘 **重点不是复杂，而是第一次体会：经验不只存在脑子里，也可以成为 AI 的能力。**

本轮任务为：**封装一个长期有用的技能。**

## 📗 完成的价值

![](01-实事求是/50-AI技术与应用/AI技能/一堂AI任务书01-05/任务书03：封装Skill技能/imgs/p01_003.png)

🟡 **和 Agent 一起工作，常见的痛点是：**

- Agent 每次工作都是新的，历史经验无法复用。
- 封了很多，质量很随机，不知道哪一版能用。
- 高频工作每次都要重新口喷一遍，重复劳动。

🟠 **通过练习这个任务，希望你感受到：**

- 一句话触发，AI 以最高水准完成整类任务。
- 自己封的哪怕再小，几乎都很好用。
- 工作开始有“复利积累”感。

> 🔴 通过完成这个任务，开始把“Skill”变成自己日常重要的工作之一，找到**「回不去」**的感觉。

## 📕 具体任务说明

![](01-实事求是/50-AI技术与应用/AI技能/一堂AI任务书01-05/任务书03：封装Skill技能/imgs/p01_004.png)

为了支撑不同的难度，我们设定了两个难度的任务：

> 🔵 **标准版任务**
> 
> 封装一个自己用的技能，未来愿意持续用。
> 
> 适合：一堂会员 / 大航海 / AI 俱乐部

> 🔴 **挑战版任务**
> 
> 针对某一类问题，封装一个通用的技能，开放给大家一起使用。
> 
> 适合：AI 落地高手营 / AI 俱乐部专家

你可以根据不同的历史经验来完成这个任务：

**♥️ 情形1：**如果你过去有现成的“好用的技能”，你可以补充说明、介绍和价值，然后直接提交。

**♥️ 情形2：**如果你尚未开始，建议你可以按照这三个步骤学习和封装：

1. 梳理自己和 Agent 工作的常见工作，找到一些重复的细分场景。
2. 搜集资料，复盘整理，整理 Skill 需要的材料和资料。
3. 封装 Skill，测试让 Agent 调用，感受 Skill 封装的质量和效果。

👉 然后在真实的工作场景里测试使用，感受到封装技能的价值和爽点。

请你把这个技能的完整思考和分析过程、Skill 完整源文件，提交一个飞书一页纸提交。

- **🔵**
  **标准版最好包含：**
  **技能场景，解决的痛点，技能文档。**
- **🔴**
  **挑战版最好包含：**
  **价值讲香，技能边界，封装过程，具体使用方法。**
