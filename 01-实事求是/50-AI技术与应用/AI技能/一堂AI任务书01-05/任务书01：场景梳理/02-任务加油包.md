## 🔴 加油包1：纯新上手包

![](01-实事求是/50-AI技术与应用/AI技能/一堂AI任务书01-05/任务书01：场景梳理/imgs/p02_002.png)

如果你完全没有基础，也不知道从哪下手，用下面这段话，30 秒就能开始。

和你的 Agent（workbuddy，codex，豆包都可以）直接说：

```

我是做【你的岗位，如销售/运营/教师】的，最近一周主要在忙【写 1–2 件具体的事】。

请帮我把这两件事里能用 AI 的地方，拆成 20 个具体场景；再按「这周就能动手试」的标准，帮我挑出 3 个，每个用一句话说明为什么它值得先做。

```

> 鼠标滑动到代码块，右上角可点一键【复制】👆

做完你就会得到一张 20 个 AI 场景清单和 3 个首选。

完成之后，恭喜你就解锁了场景梳理的从0到1。

## 🔵 加油包4：专业方法包

![](01-实事求是/50-AI技术与应用/AI技能/一堂AI任务书01-05/任务书01：场景梳理/imgs/p02_006.png)

> 🔵 **🎓 全员必修：AI场景第一课** [查看课程↗](https://yitang.top/lesson/D24Q690b18f8d450)
> 
> 用一张四象限矩阵把 AI 场景分成探索、变革、提速、落地四类，先判断自己该从哪类切。
> 
> *一句话亮点：先把场景放进四类判断框，再决定从哪类切入，避免一上来就零散找场景。*

| AI场景取舍评估画布 |  |
| --- | --- |
| **价值侧：实现以后的收益** | **成本侧：实现过程的卡点** |
| **A1.价值差异**<br>*AI化以后，对效率/价值影响多大，能否量化成财务指标* | **B1.容错高低**<br>*是否有人判断，对于错误的宽容度如何* |
| **A2.复现频率**<br>*多久执行一次，是低频还是高频* | **B2.流程清晰**<br>*业务流程是否清晰标准化* |
| **A3.规模卡点**<br>*是否是你们复制规模化的规模经济卡点* | **B3.决策明确**<br>*是否有清晰的判断和评价逻辑* |
| **A4.核心能力**<br>*是否是你们对外的核心竞争力* | **B4.数据可行**<br>*是否有足够多的数据，AI友好可以接入AI使用* |
| *注：可以1-10分打分，并且增加事实论证解释* |  |
