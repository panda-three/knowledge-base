# 课程：海报预装六角·青少年营

**一句话结论：** 一句话能生成海报但无法验收；正式生成前先把六角一次性预装——参考图不是灵感堆而是被分工被取舍的数据，人的判断放在每一步关键位置。

---

## 一、核心交付

- 一个对照：空手 Before（六角 0/6）vs 预装 After。
- 一个方法：三个视觉方向各自分工、再组合取舍。
- 一张诊断卡：六问选一个下一步补角。

## 二、关键框架

### 2.1 空手 Before 的状态

| 维度 | 状态 |
|---|---|
| 输入 | 一句话 |
| 六角准备 | 0/6 |
| 结果判断 | 能生成，但无法验收 |

- 模型已能生成，却没有判断好坏的依据。

### 2.2 行动前预装六角

| 三角 | 六角内容 |
|---|---|
| 人类 | 审美：材质/层级/留白标准+反例清单 |
| 人类 | 体系：发散→比较→选择→参考→生成→核查→修改 |
| 人类 | 创造力：三个可比较视觉假设 |
| AI | 基本功：图像能力选择/参考图控制/文字核验 |
| AI | 数据：活动文案/校园元素/三张参考图/禁止项 |
| AI | 场景：校园学生·手机信息流·竖版传播 |

- **把功夫花在 AI 开工之前。**

### 2.3 三方向分工与组合

| 方向 | 贡献 | 不负责 |
|---|---|---|
| 手账拼贴 | 材质/校园感/手工温度 | 标题层级与留白 |
| 现代编辑设计 | 信息层级/留白/传播效率 | 场景情绪与材质温度 |
| 纸上微缩世界 | 核心场景/情绪"想法成真" | 材质细节与字号层级 |

- 人的判断不是三选一，是解释每张贡献再组合。
- 最终锁定：核心场景←纸上微缩世界；材质←手账；层级←编辑设计。

### 2.4 生成—核查—修改五步

```
组织输入(人) → 生成(AI) → 文字核查(人) → 局部修改(人定范围/AI执行) → 最终确认(人)
```

- 查占位文字、只改局部不整张重来。

### 2.5 迁移：六问诊断卡

| 角 | 自问 |
|---|---|
| 审美 | 我看得出好坏吗 |
| 体系 | 我有稳定流程吗 |
| 创造力 | 我有自己的新解法吗 |
| 基本功 | 我知道选什么模型吗 |
| 数据 | 材料可靠吗 |
| 场景 | 场景清楚吗 |

- 选缺角不是打分，是确定下一次协作起点。
- 收口飞轮：人变强调教更强 AI；强 AI 辅助人更强。

## 三、金句与判断

> 「参考图不是灵感堆，而是被分工、被取舍的数据。」
> 「预装没有取消人的工作，而是把人的判断放进每一步关键位置。」

## 四、行动建议

| 层级 | 行动 |
|---|---|
| 基础 | 下次生成前列出六角各是什么 |
| 进阶 | 给每张参考图写清它贡献什么 |
| 高阶 | 用六问诊断卡定一个下次补的角 |
