# 课程：系统入门AI调研·03

**一句话结论：** 快速补齐一个新领域认知盲区的打法——花 3-10 小时把 100-2000 个案例/教程过一遍、合并同类项、建段位图/难度表，之后再遇到新工具新观点基本都落进你已有的体系，不再慌。

---

## 一、核心交付

- 一个方法：饱和搜集案例 → 合并同类项 → 建模（段位图/难度表/玩法清单）。
- 四个自学案例：Coze、VibeCoding、OpenClaw、多模态。
- 一套文生图/文生视频工作框架。

> 说明：本篇含 4 个自学小案例，均为「一人一方法」的证据，未独立拆分，分节呈现。

## 二、案例一：Coze 教程又多又乱

**做法：**
1. 开文档列案例来源：官方/自媒体/社区/有趣项目/短视频。
2. 扫 100+ 案例，2-3 小时合并同类项出《完整拆解笔记》。
3. 抽象成 **L1-L10 段位图**：

| 段位 | 阶段 | 学习点 |
|---|---|---|
| L1-L2 | 上手 | 一页纸框架 / 最小闭环发布 |
| L3-L4 | 入门 | 用插件 / 完整用工作流+知识库+数据库 |
| L5 | 进阶 | 自建资源库（自做插件/知识库/触发器） |
| L6-L10 | 专家 | Coze IDE / 工具迁移 / 创意解决 / 领域迁移 / 咨询讲课 |

> 4-5 小时换得对 Coze 完整体系/最佳实践的完备认识。

## 三、案例二：VibeCoding

**按编程参与深度分 L1-L4：**

| 深度 | 适合 | 工具 |
|---|---|---|
| L1 提示词编程 | 纯前端 Demo/小工具 | 搭叩/Bolt/Figma |
| L2 一步步编程 | 复杂点、有风险 | 搭叩/Trae |
| L3 里程碑评审 | 前后台复杂、多模块耦合 | Trae Solo / ClaudeCode 子 Agent |
| L4 原子式编程 | 超专业多人工程 | ClaudeCode / Cursor |

**L2 大策略：** 先问原理找对标 → 勇敢减法砍需求 → 循序渐进先前端 → 封装复用不重造 → 直接报错喂 AI 调试 → 跑通就 Git commit。

| 小龙虾 | AI 动手 | 工具自动化 |

## 五、案例四：多模态（文生图/文生视频）

### 文生图玩法清单（保 30 争 50）
调整画面 / AB 组合 / 风格替换 / 增强修改 / 商业案例 / 手绘草图 / 进阶玩法（场景连贯/分镜批量/局部作图）。

### Sora2 调研
- 看社区 ≥2000 条高热视频 → 合并出 7 大类。
- 第一次激活「AI 原生」短视频创意，感受时间×空间穿越。

### Top 审美建立
- 刷即梦/可灵 500-1000 条短片，选 Top10 作者+作品（汗青/AI魔法詹/事故唠怪等）。

### 文生图视频工作框架

| 阶段 | 关键 |
|---|---|
| 最简单 | 一句话生图/文生图图生图 |
| 进阶 | 复杂 Prompt + 参考图组合 |
| 专业 | 正/负提示词 + 案例库临摹 |
| 参数 | 采样/引导/种子 + LoRA |
| 完整 | ComfyUI 工作流 + 自训 LoRA |

**关键环节：** 故事设计 → 分镜脚本 → 生成提示词 → 一致性处理（人物/风格）→ 做关键图（景别/角度/抽选/放大）→ 生成视频（运镜+主体动作）→ 合成剪辑（节奏/BGM/配音）。

## 六、收尾：方法价值

- 每轮 3-10 小时，看着笨，就是一点点分类建模。
- 有了框架就不慌：新案例/工具/观点基本落进已有体系，不会推翻重建。

## 七、金句与判断

> 「缺的不是实践，而是基本的见识和审美。」
> 「一点点合并、分类、建模——之后再遇到新东西，基本都在我的体系里。」

## 八、行动建议

| 层级 | 行动 |
|---|---|
| 基础 | 挑一个新工具，花一晚过 50+ 案例建一页框架 |
| 进阶 | 把案例抽象成 L1-L10 段位图或难度表 |
| 高阶 | 建自己领域的「玩法清单 + Top 审美库」 |

## 九、我的批注（双轨）

- 我的：这套「饱和案例→段位图」可直接用于我快速学一个新教学工具。
- 待验证：各工具/模型/价格为作者 2025 年时点快照，需自行更新。
