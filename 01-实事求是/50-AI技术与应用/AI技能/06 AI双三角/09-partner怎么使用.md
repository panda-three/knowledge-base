# 课程：双三角·09挖掘师对话

**一句话结论：** 双三角挖掘师不直接给答案，只追问——帮你把脑里经验归到六角、找主控角补强、落到可实践画布。

---

## 一、核心交付
- 一段实录：拆"AI做线下教材"场景15min对话
- 一套打法：对齐边界→归六角→排序找主次→补强→出备忘录
- 一个结论：实践前结构化准备，先试一个模块

## 二、关键框架

### 2.1 挖掘师五步对话法
| 步 | 动作 |
|---|---|
| 1对齐边界 | 复述场景，问清教材指哪类/AI参与到什么程度 |
| 2归六角 | 想到啥说啥，归到场景/审美/体系/数据/基本功/创造力 |
| 3排序找主次 | 哪角边界清楚暂放，哪角虚就主挖 |
| 4补强 | 追问正面标准+反面案例+分轮验收 |
| 5出备忘录 | 束成阶段版画布+信心分+下一步 |

### 2.2 本案例六角结果
| 角 | 状态 |
|---|---|
| 场景 | 已确认：现场学员教材，不重新研发不替代讲课 |
| 审美 | 主控角：正面4条+反面3类+分轮6层 |
| 体系 | 副挖角：六步流程，Step1喷魂最易失控 |
| 数据 | 部分就绪：3-4本精品样本+本轮课稿 |
| 基本功 | 待验证：长文本拆分/索引/一致性 |
| 创造力 | 暂放：不做线上资料线下版 |

### 2.3 审美正反标准
| 正面 | 反面 |
|---|---|
| 节奏对齐现场教学 | 像逐字稿只压缩改写 |
| 方法论独占版面 | 像线上讲义平铺 |
| 有目的的空白 | 像资料包无教学节奏 |
| 学员视角非讲义 | |

### 2.4 体系六步流程
1. 对齐魂和大纲（人先喷清，最易失控）
2. AI学3-4本精品样本（只学格式不学意图）
3. 学本次课稿/Keynote/逐字稿
4. 模块生成初稿（教材感不够）
5. 多轮迭代10-15轮（易冲掉前面成果）
6. 人做终版调整

- 缓解策略：审美文档化为三份规则
- 《教材审美规则》《模块生成规范》《迭代检查清单》

## 三、金句与判断
> 「双三角价值不是马上给答案，而是别只盯提示词工具，把高水平交付背后的东西看全」
> 「这不是最终答案，而是实践前的一次结构化准备」

## 四、速查卡
┌ 一句话记住本课 ┐
└ 挖掘师只追问不给答案；对齐边界→归六角→主挖短板→出备忘录 ┘

## 五、行动建议
| 层级 | 行动 |
|---|---|
| 基础 | 挑一个场景和挖掘师聊10-30min |
| 进阶 | 把审美标准文档化为规则清单 |
| 高阶 | 先试一个模块再铺整本 |
