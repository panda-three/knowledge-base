# 课程：双三角·08画布模板

**一句话结论：** 双三角画布三版（空白/解释/清单）+两个填好示例，是筹备用的直接工具。

---

## 一、核心交付
- 三版画布模板：空白/解释/清单
- 两个示例：论文评审、商标设计
- 通用三提醒：多做加法/排优先级/先测最高优先

## 二、关键框架

### 2.1 画布六格
| 格 | 含义 |
|---|---|
| A场景（起点） | 细分场景核心问题边界 |
| H审美（终点） | 高水平判断力标准 |
| H体系（过程） | 确定性流程模型框架 |
| A数据（资产） | 数据资产正负案例DataPack |
| A基本功（能力） | AI工具技术特性Feature |
| H创造力（创新） | 跳出同行的新思路 |

- 提醒：先充分做加法，再抓主要矛盾
- 初期只挑优先级最高的执行测试

### 2.2 示例一：论文初稿AI评审
| 格 | 要点 |
|---|---|
| 场景 | 筛基本问题，深层问题留给导师 |
| 边界 | 不判录用/不检测造假/不润色 |
| 审美 | 导师视角+五维评分 |
| 体系 | 三色灯阻断+期刊基线Tier0-8 |
| 数据 | 期刊yaml基线+AI味儿库+测试集 |
| 基本功 | PDF解析+统计检验+数值交叉比对 |
| 创造力 | AI味儿量化、尾数偏好检测 |

### 2.3 示例二：商标设计
| 格 | 要点 |
|---|---|
| 场景 | 业务未定型两天出60分可用版 |
| 审美 | 黑盒直觉+白盒标准（图标字体线条） |
| 体系 | 设想-具象-打磨-复盘路径 |
| 数据 | 风险梳理+心智模型+最佳实践池 |
| 基本功 | 即梦/banana/豆包多模型+手绘微调 |
| 创造力 | 抓图形Logo主要矛盾+MS负形猫咪方向 |

## 三、金句与判断
> 「边界=主动说不做什么」
> 「创新是在业务约束下提出更现实更高ROI的解法」

## 四、速查卡
┌ 一句话记住本课 ┐
└ 六格三版模板；填时先加法后取舍，边界比内容更重要 ┘
