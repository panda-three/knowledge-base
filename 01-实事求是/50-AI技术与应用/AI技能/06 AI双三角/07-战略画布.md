# 课程：双三角·07战略画布

**一句话结论：** 一堂把商业战略构建在五步法画布上，四版递进：故事版→取舍版→定量版→分工版。

---

## 一、核心交付
- 五步法画布五格：需求/解决方案/商业模式/增长/壁垒
- 四个版本：故事版、取舍版、定量版、分工版
- 用途：战略用·底牌配套

## 二、关键框架

### 2.1 五步法画布四版递进
| 版本 | 加什么 |
|---|---|
| 故事版 | 基本画像与渠道壁垒 |
| 取舍版 | 非用户/非内核/非壁垒/试错搁置 |
| 定量版 | 人群规模/ROI/续费率/里程碑 |
| 分工版 | 按SKU拆/工业化生产/团队分工 |

### 2.2 一堂实际填写要点
| 格 | 核心 |
|---|---|
| 需求 | 想做大创业者/B轮前/务实有陪伴需求 |
| 解决方案 | 真实创业问题+成体系必修课 |
| 商业模式 | 投放+直播体验+年费+MBA |
| 增长 | 公众号/私域/抖音/视频号投放 |
| 壁垒 | 早期创业必修课第一品牌（强） |

- 非壁垒：技术无、knowhow长期无、网络效应暂无
- 定量：作业率50-60%、续费率60%、首单ROI1.5-2
- 反规模不经济：替代专家身份/IT算法化/基本功/SKU标准化

## 三、速查卡
┌ 一句话记住本课 ┐
└ 五步法五格四版：故事→取舍→定量→分工；非用户非内核非壁垒都要写 ┘

## 四、我的批注（双轨）
- 我的：写"非用户/非内核"比写"是"更见功力，可迁移到自己方案
