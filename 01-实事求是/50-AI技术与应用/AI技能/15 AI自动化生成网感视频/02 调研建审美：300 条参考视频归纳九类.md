# 课程：调研建审美·02

**一句话结论：** 网感不玄，拆开就是**画面节奏**——刷数千条挑 300+ 条、人工分 9 类，把人物/素材/剪辑元素归纳成可程序化的清单，工具判断标准随之收敛。

---

## 一、核心交付

- 一套调研方法：数千条→300+ 条→9 类→本地预览站。
- 一张 9 类视频分类表。
- 一个本质判断：**网感 = 画面节奏**。
- 一套可程序化的画面元素清单。

## 二、怎么挑 300 条

- 在视频号刷数千条，挑 300+ 条与业务相关。
- 入选标准：
  - 有信息/观点输出（非搞笑/跳舞/表演/解说）。
  - 不能完全无制作痕迹。
  - **不看点赞转发**（受粉丝数干扰），看成品后的画面效果——因为要解决的是制作流程。
- 用 AI 编程批量下载 + 搭本地预览/分类网站。
- [配图：6 列竖屏缩略图矩阵；左下载脚本进度、右本地预览站]

## 三、9 类视频分类

| 大类 | 小类 | 特征 |
|---|---|---|
| **人像** | 竖屏 | 竖屏半身出镜，穿插图文 |
| | 横屏 | 横屏半身出镜 |
| | 小窗 | 画中画头像，文字/素材全程当主信息 |
| | 多视角 | 横竖/画中画/抠像混合 |
| | 板书 | 半身出镜+黑板/白板讲解 |
| **信息流** | AI 生图/视频 | 无人像，口播+AI 生成素材 |
| | 含装饰 | 无人像，真实素材+上下装饰文字 |
| | 无装饰 | 无人像，真实素材无装饰 |
| | 音乐 | 无人像无口播，仅音乐+素材 |

> 参考素材库已开放：331 个视频，含首帧/标题/时长/原链接，约 3.09GB。

## 四、网感的本质：画面节奏

> 所谓网感，靠的就是**画面节奏**——不玄，可拆。

文字结构有钩子（3 秒留人）；画面结构要回答：
- 人物放哪里？
- 什么时候切画面？
- 素材怎么穿插？
- 重点文字何时出现？

## 五、画面元素可程序化

| 元素类 | 具体项 |
|---|---|
| 人物 | 声音、形象 |
| 素材 | 图片、视频 |
| 剪辑 | 字体、字幕、文本预设、形象包装、素材动画、转场、MG 动画、空镜、音效、音乐、封面 |

> [配图：6 个人物形象包装示例]
> 表面差异大，底层反复用相似表达 → **可程序化，不必纯凭感觉**。

## 六、工具判断标准（收敛后）

对每个技术/工具只问两句：
1. 对 80 分口播质感，它能承担**多少**剪辑工作？
2. 它承担**哪部分**？

- 已做得好 → 不重复造轮子。
- 待开发空间大 → 自己做。

## 七、金句与判断

> 「网感不是玄学，拆开就是画面节奏。」
> 「我们要解决的是制作流程，所以看成品后的画面效果，不看点赞转发。」

## 八、行动建议

| 层级 | 行动 |
|---|---|
| 基础 | 按 9 类给自己常刷的视频建一个分类收藏 |
| 进阶 | 把喜欢的 30 条按人物/素材/剪辑元素拆解 |
| 高阶 | 用「承担多少/哪部分」给候选工具打分 |

## 九、我的批注（双轨）

- 我的：「不看数据看制作流程」这个筛选标准很清醒，可迁移到我选教学视频模板。
- 待验证：9 类划分是作者个人归纳，覆盖度待更多样本验证。
