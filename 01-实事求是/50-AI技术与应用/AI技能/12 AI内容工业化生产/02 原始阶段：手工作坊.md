# 课程：内容工业化·02手工作坊

**一句话结论：** 手工作坊阶段靠师傅言传身教最痛苦，解法是把脑子里隐性的判断显性化——这是工业化第一步。

---

## 一、核心交付
- 一个调研法：10主关键词+26字母法爆炸式研究
- 一个选题法：JTBD焦糖布丁=痛点+解决方案
- 一个痛点：判断在脑子里说不出来，7小时选题会
- 一句结论：把隐性判断显性化

## 二、关键框架

### 2.1 爆炸式研究建审美
- 量级：看2000篇选10-20个学1个
- 工具：10个主关键词（产品/购买/场景类）+26字母法
- 筛选：最多收藏图文半年内，赞藏>500评论>10
- 原理：看得少只见个例，看多才见共性

### 2.2 审美六看
| 看 | 内容 |
|---|---|
| 选题 | 平台人到底在关心什么 |
| 标题 | 换个词流量可能全变 |
| 封面 | 短图长图信息图手写感 |
| 结构 | What/How/Why |
| 转化 | 路径和玩法 |
| 账号 | 装修和定位 |

- What吸引执行层、How吸引业务负责人、Why吸引一号位
- 一堂最想吸引Why层人

### 2.3 JTBD焦糖布丁选题法
- 用户要的不是钻头是墙上的洞
- 三合一/四合一笔记=流量+人设+转化+长尾
- 公式：宽口径人群痛点+解决方案+关键词布局

### 2.4 手工作坊痛苦
| 环节 | 痛苦 |
|---|---|
| 选题会 | 开7小时全程一人输出 |
| 找选题 | 只追爆款不看受众一致 |
| 填表 | 怕填参考维度改写建议 |
| 写稿 | 师傅1h徒弟7-8h |
| 带教 | 言传身教一遍遍重复 |

- 懒人改变世界，决定蒸馏自己

## 三、金句与判断
> 「内容工业化第一步：把隐性的判断显性化」
> 「看很多，选一些，学一个」
