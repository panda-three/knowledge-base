我给大家讲讲，大概2016-2017年，我当年真实的经历吧：

2016年，知识付费很火，我当时特别"爱学习"，听了几乎全部罗辑思维，定期刷36Kr，看知乎，RSS订阅博客，每周阅读大量的文章和内容。

但我发现一个很糟糕的事实：我开始跟一些高阶的美团同学在做新业务/新产品啊，我工作里的重要难题，几乎这些知识都帮不上忙，要么距离很远，要么只是个碎片观点，要么比较浅显、彼此矛盾。

当我想解决任何一个具体问题的时候，发现我500万字的知识库，竟然没有500个字能用，甚至一个字都没有。

我感觉我认识了世界（极度自信），但我无法改造世界（极度不自信）。

经历了差不多一年的极度焦虑，我才深刻认识到一件事情：『**知道』和『能用』是两件事，没有办法转化为能力的那些文章、书和课程，对我来说价值很低，我得拥有一套属于我的，能真正指导实践的模型。**

我得从头搭建我的模型。于是也就是差不多从2016年开始，我果断废掉了我的"知识大脑"，开始躬身入局，去解决一个个具体的问题，然后**去寻找每一个具体问题的因果关系**。

这个时间开始，我才真正做到知行合一。

我开始建了一篇篇笔记：如何做出一堂好课，如何写出一个好标题，如何分析行业机会，如何判断创业成败概率，如何拆解商业，如何分析商业可行性，从一条、两条、三条开始积累，慢慢长出了一个可以为我所用的知识体系。

**【思考🙋‍♂️】**对于真实问题的因果关系，拥有一个确定性的认知/模型，真的重要吗？

————

 极其必要且关键，当你开始形成了认知-问题的因果关系，你才能显性化，才能沉淀，才能承载你未来的一步步迭代和反馈。

就像我刚才讲的，当我意识到"**时间管理效率 - 3个模型**"那一刻，我的科学时间管理才算真正入门，后面我不断借用理论、建模、测试、调研，都是围绕着3个模型迭代的，最终才能更好地解决问题。

最近两年我特别喜欢讲的一句话：一个人真正入门的标志，是形成了对于一个复杂事情的基本的、朴素的、框架性的认知。

这个框架就是基本的因果关系，可以显性化，可以沉淀，可以迭代，就像一棵树的树干一样，可以承载各种叶子：你的学习、调研、测试和各种各样的工作。

2. 一次次优秀的**马拉松礼品**，背后的因果关系是什么？

在一堂，但凡是独立的业务负责人，重大的决策和产品设计，我基本都会问这个问题，算上对自己的提问，这两年，我至少问了七八十次"因果关系"的问题了。

在面试时候，我也经常问一个问题：**决定这个结果，最重要的3个要素是什么？**答案本身不重要，但有没有思考过，迭代过这个因果关系很重要。

在面试里，回答说"**不知道，没想过**"往往不是最糟糕的，非常自信地高谈阔论讲了一大堆道理，模型，心法，混沌不清的抽象概念，但一追问，一个例子都举不出来，这才是最糟的。

对于一堂的关键岗位面试的话，如果勇敢说『不知道』算是0分的话，还在喜欢模糊理论，沾沾自喜的情况，往往就是负分了。

所以知行合一（解决问题&因果认知）很重要，这是一个容器，如果连一个1.0的模型都没有，就没办法被讨论，被复用，被迭代和升级了。

假设你有了下面一叉，有了一个非常简单、非常简陋的一个认知模型1.0，如何迭代呢？

借用别人现成的理论就是一个非常棒的手段。

我们一定要尽量避免重复造轮子，你解决过的问题，（极大概率）历史上已经有无数人解决过了，而且抽象成了方法论、模型、工具，你只需要学习就好了。

这些抽象过的、二手的、概括性的模型，在市场上普遍存在，如果你能找到合适的、匹配的方法，就能大幅增加你的认知迭代速度。

你要想**科学定价**，你不能自己瞎琢磨，至少得全面学习一下常见的定价策略吧，比如成本定价、竞争定价、撇脂定价、渗透定价、阶梯定价等等；

你要想科学投放，你不能自己瞎琢磨，至少得了解一下主流公司的投放评估方法，渠道选择方法，ROI测算方法，MVP试验方法吧？

注意，**模型易得，使用要慎重。**

如何建模呢？具体实操这个很难教，我在一堂内部也是一直在每天带着大家建模，依然必须要承认，建立一个有效可用的模型，依然是一个很难的，需要反复练的事情。

先简单送给大家我常用的5件套吧：

![](01-实事求是/个人必修/【Y%20模型实操行动营】重新理解科学理念/imgs/p04_015.png)

![](01-实事求是/个人必修/【Y%20模型实操行动营】重新理解科学理念/imgs/p04_016.png)

**【划重点💡】**我自己用的最多的5件套：**深度复盘 < 深度思考 < 模型武器库 <  辩证讨论  < 爆炸式研究。**

- **深度复盘**：从主观到事实，从事实到原因，从原因到方法，从方法到能力。
- **深度思考**：透过表象，看到事情背后的3-7层规律和逻辑。
- **模型武器库**：常见的模型就是大概几十种，建立一个范式库，调用就好了。
- **辩证讨论**：类似苏格拉底式提问，用反例和反省，来获得更好的知识。
- **爆炸式研究**：能力拉满，做大量案例收集、分类、定性甚至定量研究，总结规律。

我在《人生红点》课上，分享了我对于我人生核心能力的预判，里面有一条是『体系建模』，这五条就是我这些年一直在反复刻意练习的工作。

右边一叉非常重要，你要回到真实的客观世界里，去观察，去调查，去分析，甚至自己动手测试，做实验，这是真实的世界，这是一手信息，这是原始的，未经处理过的事实。

我们做个测试吧，大家基本都参与过定价，如何科学定价呢？

**【自测🙋‍♂️】**下面工作，你可以自信回答到多少分（百分制）：
1. 你的对标模式，定价方面的最佳实践是谁？请列出3-5家。
2. 他们的定价是多少，有哪些规律？背后有哪些共性？
3. 你有定量跟踪、测算过他们的定价变化和成本结构吗？
4. 关于你的定价，你提出过一些假设吗？1个？3个？5个？10+个？
5. 关于你的定价，你做过定价实验吗？如何设计定价实验？

大家应该可以感受得到，什么是验证了吧？基于同行的做法，基于你的实验，来分析结论，形成认知。

这就是为什么，我一直不断鼓励大家学习"**最佳实践**"，因为我们绝大多数的答案，其实都在最佳实践里。一堂每个月，大概都会有至少十几轮的最佳实践专题学习。

比如最近一个月，光从我这发起，团队学习的最佳实践就有：最佳实践落地页，最佳实践朋友圈，最佳实践私域模型，最佳实践短视频剪辑，最佳实践会议室，最佳实践说人话聊天等等。

下面，讲讲这里面的两个关键难点。

![](01-实事求是/个人必修/【Y%20模型实操行动营】重新理解科学理念/imgs/p04_020.png)

![](01-实事求是/个人必修/【Y%20模型实操行动营】重新理解科学理念/imgs/p04_021.png)

周子敬在《实事求是》课上，重点强调了，我们要理解客观事实，难点在于精准，在于定量。

模模糊糊描述时间管理，模模糊糊描述文案，模模糊糊描述招聘，模模糊糊描述科学决策，总是容易的，但一旦尝试区间定量、数字定量，甚至精准定量的时候，往往才是我们的难点。

**比如时间管理：模糊大块时间 <  具体小时 <  具体小时x具体的产能。**

> 当然对于一些确定性较高的工作，有人能精确到分钟，但不常见。

**比如科学招聘：模糊好感 < 定性分级 <  分维度打分。**

> 常用的定性分级：No Hire，Hire，Strong Hire。

**比如科学决策：模糊直觉 <  优先级定性 <  局部定量 < 定量公式  < 严格财务定量。**

> 参考必修：《科学决策深度篇》有完整介绍。

**比如科学文案：模糊手感 <  用户投票 <  数据分析。**

> 还未做课，欢迎大家未来一起共建这套方法。

当然，本着科学的原则，还要强调，**定量是有成本的**，要考虑ROI问题。当你的决策足够重要，更需要用更高纬度的定量来要求自己。

下面还有一个难题：很多问题不是调研最佳实践、分析同行就够用的，往往没有现成参考，需要自己动手提一些假设，做一些实验，验证一些事情。
