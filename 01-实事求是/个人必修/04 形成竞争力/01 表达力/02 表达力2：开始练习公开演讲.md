# 《表达力2：开始练习公开演讲》L6 清单体笔记

> 主讲：Truman｜一堂 CEO｜前美团产品专家
> 定位：表达力系列第二课｜「公开路演」场景的专项实战课｜表达力火箭模型在 1vs多 场景的完整落地
> 核心命题：**创业者需要讲好自己的故事。路演不是「把BP念一遍」，而是用三部曲（内容准备→提前彩排→现场表达），在 5-15 分钟内讲清楚、有逻辑、打动人。**
> Truman 原话：「谁做演讲都紧张，越是彩排越不慌。」「逐字稿改变世界。」「听懂了不代表你能学会，真正掌握 → 请刻意练习。」

## 一、课前定位：这节课在表达力系列里的位置

### 1.1 表达力系列全景

| 课程 | 核心交付 | 解决的场景 |
|---|---|---|
| **表达力1：科学表达必修课** | 建立完整的表达认知模型（火箭模型）和实操武器库 | 所有关键商业表达场景的底层方法论 |
| **表达力2：开始练习公开演讲（本课）** | 在公开路演场景讲好商业故事 | 融资路演、DEMO DAY、公开项目宣讲 |
| 逐字稿实操：从入门到高手 | 把筹备固化成可执行的表达剧本 | 录播课、重要演讲的逐字稿撰写 |
| 讲香实操：一堂十指模型 | 把产品价值呈现得有价值感 | 销售文案、落地页、直播话术 |

> **L6 洞察**：表达力1 给了你火箭模型（方向系统→动力系统×2→推力系统），表达力2 就是把这枚火箭发射到「公开路演」这个特定星球上的完整操作手册。它是从「知道」到「做到」的第一站——**在真实的、高压的、1vs多 的路演场景中，把科学表达的所有武器全部用一遍。**

### 1.2 Truman 为什么做这节课？

```text
Truman 组织了十几场路演日（DEMO DAY），听了几百个同学的现场路演。
```

## 二、核心模型：公开路演三部曲

Truman 将公开路演的完整筹备拆成三步，每一步对最终结果的影响权重截然不同：

### 2.1 三部曲全景

| 执行环节 | 工作内容 | 对结果的影响 | 核心工具 |
|---|---|---|---|
| **第一步：内容准备** | 梳理卖点、逻辑、故事技巧 | **50%** | 3×3 路演筹备画布 + 融资卖点 Checklist + 讲好故事技巧集 |
| **第二步：提前彩排** | 刻意练习、控制时间、提升自信 | **30%** | 逐字稿 + 四个彩排重点工作 |
| **第三步：现场表达** | 自信表达、临场 Checklist | **20%** | 现场表达 Checklist + 两个关键建议 |

### 2.2 L6 洞察：大多数人把权重搞反了

```text
大多数人花 80% 的时间在做 PPT（内容准备的「美化」部分），
花 10% 的时间随便念两遍（假装彩排），
花 10% 的时间在现场紧张发抖。

正确姿势是：
花 50% 的时间在「内容准备」的真正核心——卖点提炼、故事线设计、张力布局。
花 30% 的时间在「提前彩排」——不是念一遍，而是逐字稿 + 计时 + 反复打磨 + 心理建设。
花 20% 的时间关注「现场表达」——对象感、自信、声音、眼神、语速。

PPT 美化是内容准备里最不重要的一环。
```

### 2.3 一句心法贯穿始终

```text
要讲清楚，有逻辑，打动人。

讲清楚 = 用户是谁？解决什么问题？怎么赚钱？
有逻辑 = 听众能跟上你的思路，不迷路
打动人 = 有故事、有张力、有记忆点
```

## 三、第一步：内容准备（50%）——3×3 路演筹备画布

这是整节课最核心的交付。Truman 把内容准备收敛为一张 **3×3 画布**（三个关键任务 × 每个任务三句话）：

### 3.1 3×3 画布全景

| 关键任务 | 工作 | 你的提炼 |
|---|---|---|
| **提炼卖点** | 用三句话提炼路演卖点——对方想要什么？ | 1.____ 2.____ 3.____ |
| **讲清项目** | 三句话讲清楚项目——你是干什么的？ | 1.____ 2.____ 3.____ |
| **印象深刻** | 选三个让人印象深刻的技巧 | 1.____ 2.____ 3.____ |

### 3.2 任务一：提炼卖点

**核心问题**：如果你出来融资，面对几个 VC 路演，对方最在乎什么？

| 融资亮点 | 示例 |
|---|---|
| **数据**（收入、利润、用户数、增速、留存等） | 马蜂窝：用户数超 8000 万 |
| **商业模式**（唯一性、颠覆性、创新性） | 拼多多：微信裂变 |
| **团队**（越早期项目优先级越高） | 瑞幸咖啡：神州专车高层团队打造 |
| **历史资方**（知名品牌背书） | 真格投资的 K12 大语文教育 |
| **目标用户**（有特色） | 拼多多：四五线城市下沉市场 |
| **解决痛点** | 摩拜：解决最后一公里出行问题 |
| **其他** | 使命初心、模式、技术、垂直领域等 |

**底层逻辑**：卖点的选择要落回到融资公式——你当前阶段，投资人最看重什么，你就突出什么。早期看团队，成长期看数据，成熟期看壁垒。

**一堂自己的提炼示例**：

```text
卖点 1：以太创服孵化，超强的决心和使命感。
卖点 2：强大团队，采用创新教研模式，提供高质量标准课程。
卖点 3：模式已验证，增速快，可以跑到头部。
```

### 3.3 任务二：讲清项目

**核心问题**：三句话让人听懂你是干什么的。

**一些特别糟糕的表达**：

```text
❌「我做的是校企合作的 2B 教育平台」
❌「我做的是某某行业的 B2B2C / C2F / S2B2b2C / O2O / OMO / S2B2C 平台」
❌「我做的是中国的 Udacity、Headspace、Techstars」
```

**最起码的三件事，越早讲清楚越好**：

| 讲清楚什么 | 具体问题 |
|---|---|
| **你的用户（客户）是谁？** | 谁在为你的产品付费？谁在使用？ |
| **你的场景和解决了什么问题？** | 他们在什么情况下需要你？你帮他们解决了什么痛点？ |
| **你的商业模式和怎么赚钱？** | 你的钱从哪来？怎么可持续？ |

**一堂自己的讲清项目示例**：

```text
用户：未来渴望做大的早期创业者，B 轮以前。
场景/问题：遇到具体的业务难题，缺高质量的教练和陪跑者。
模式：会员选课服务 + VIP 专项训练服务。
```

> **L6 洞察**：如果你用「类比法」来讲清项目（「我们是中国的 XX」），必须在下一句话立刻补上具体差异。因为类比只能让用户「有一个模糊概念」，但不能让用户「准确理解你」。正确姿势是：「我们有点像 XX，但最大的不同是____」。

### 3.4 任务三：印象深刻

**核心问题**：选三个让人印象深刻的技巧，让听众听完后不会忘记你。

Truman 提供了完整的《讲好故事技巧集》（与表达力1 的张力武器库打通），包括但不限于：

| 技巧类型 | 具体手法 |
|---|---|
| **价值呈现** | 用数据强调（类比/对比/单位换算）、用 Magic Words（强调词/规律词/稀缺词） |
| **竞争位置** | 颠覆常识（「你是错的，你听我说」）、强烈对比（Before/After） |
| **有故事** | 真诚坦白、添加悬念、英雄之旅、拯救者模型 |
| **有逻辑线** | 按时间线、按因果、按递进 |
| **有张力** | 画面法、时空法、寻找韵律、重复扣题、本质升华 |

**一堂自己的印象深刻示例**：

```text
技巧 1：选时间线开始展开（从加入以太 → 遇到创业者 → 发现普遍问题 → 构建产品）
技巧 2：初心故事开始（为什么 Truman 要做这件事）
技巧 3：MagicWords（用强调词和稀缺词增强说服力）
```

### 3.5 一堂完整故事线示例（升级版）

Truman 在课上以一堂自身为例，展示了如何用一条逻辑线把卖点、项目和印象深刻全部串联起来：

```text
【开头：以小见大讲故事】
我从美团加入以太，遇到了一个做线下共享睡眠舱的创业者，
融资很受挫，一遍遍犯错。
我研究发现：背后是业务问题、商业模式数据问题、验证问题，甚至是方向选择问题。
后来发现，这样的创业者太多了，国内有 50-100 万。

【过渡：提出问题】
但是这些问题，我们 FA 帮不了——
一来能力不够，二来咨询价格太高了。

【中间：构建产品】
我们找到了一个机会：研发顶级的、成体系的标准化课程，大规模服务大家。
我们组建了创业研究团队，有来自美团、腾讯、人人的同学，
也有今日头条天使投资人作为荣誉校长，
还有诸多投资人、年营收 5000w 以上的创业老兵参与课程研发。
还把以太这些年上千个项目融资的辅导案例，做了深度案例拆解。

【数据验证】
两年时间，课程价值和商业模型基本验证通过：
14000+ 创业者学习过，平均 NPS 82%，6000 人近 3000 万字的业务复盘作业。
最近半年已实现盈亏平衡，最近三个季度收入增速 75%，
未来 3-5 个季度预期 5-10 倍增长。

【结尾：未来展望】
如果未来做到 10% 的市场渗透率，也就是 5 万人，
这个业务有机会成为国内创投领域的第一名，
成为中国创业者名副其实的黄埔军校。
```

> **L6 洞察**：这条故事线融合了「英雄之旅」（难题→破解→新难题→又破解）+「按时间」（从过去→现在→未来）+「按因果」（发现问题→分析原因→构建方案→验证结果）。**高手的路演不是「背卖点清单」，而是「带听众走一段旅程」。**

## 四、第二步：提前彩排（30%）——四个彩排重点工作

### 4.1 彩排的本质

```text
彩排不是「把稿子念一遍」。
彩排是「在接近真实环境的条件下，把逐字稿练到肌肉记忆」。

马克·吐温说：世界上只有两种演讲者——紧张的和假装不紧张的。
Truman 说：谁做演讲都紧张，越是彩排越不慌。
```

### 4.2 四个彩排重点工作

| 重点 | 核心操作 | 常见问题 |
|---|---|---|
| **重点1：捋顺口语表达** | 把逐字稿大声念出来，耳朵不舒服的地方就是需要改的地方 | 写的时候很顺，念的时候舌头打结 |
| **重点2：练习时间分配** | 计时演练，确保每个段落的时间分配合理，不超时、不空洞 | 前 3 分钟讲了 80% 的内容，后面疯狂赶进度 |
| **重点3：重复直到自信** | 反复练习，直到不需要看稿也能流畅讲完 | 练了 2 遍就觉得「差不多了」 |
| **重点4：做好心理建设** | 接受「紧张是正常的」，把紧张的能量转化为表达的能量 | 试图消灭紧张，结果更紧张 |

### 4.3 准备系数 N

Truman 在课上引入了一个关键概念——**准备系数 N**：

```text
N = 你为这场路演准备的时间 ÷ 路演时长

如果你要做一场 10 分钟的路演：
- N = 1：准备了 10 分钟 → 临场发挥，大概率翻车
- N = 5：准备了 50 分钟 → 勉强能讲，但容易卡壳
- N = 20：准备了 200 分钟 → 比较流畅，但张力不够
- N = 100：准备了 1000 分钟 → 游刃有余，可以自由发挥

核心原则：N 越大越好。
乔布斯一场 90 分钟的演讲，准备时间是几百个小时。
老罗的每一场演讲，逐字稿里每一句话的声调、停顿、眼神、表情、肢体动作都经过精心设计。

你必须非常努力，才能看起来毫不费力。
```

### 4.4 彩排的核心工具：逐字稿

```text
公开路演的逐字稿，不是「把想说的话写下来」，
而是「把每一句话、每一个停顿、每一个强调词、每一个故事节奏都写成剧本」。

逐字稿改变世界。
——Truman，2016 年 4 月 6 日
```

## 五、第三步：现场表达（20%）——Checklist + 两条关键建议

### 5.1 现场表达 Checklist

| 关键项 | 核心要点 |
|---|---|
| **对象感** | 你是面对观众讲故事 & 介绍项目，而不是读一遍 PPT |
| **自信** | 保持自信，相信自己和项目，感染场上氛围 |
| **大声** | 声音适当放大，很自信笃定地介绍自己的项目 |
| **眼神** | 不要游离或盯紧 PPT，和观众有眼神交流，最好循环环视大家 |
| **语速** | 建议语速适当快，同时适当留白，控制一下表达节奏 |
| **插入语** | 可以加入一些承上启下的过渡，提升表达的逻辑性和前后衔接 |

### 5.2 两条关键建议

**关键建议一：默认听众是小白。**

```text
不要假设听众了解你的行业、你的术语、你的背景。
用最朴素的语言，从零开始讲。
如果听众听不懂前 30 秒，后面 10 分钟都不会再听了。
```

**关键建议二：不要过度展开。**

```text
项目清晰 = 精彩打动人 >> 具体完整。

有些问题，如果大家感兴趣或有疑问会主动问的，
你不用把所有答案都说完了。比如：
- 「你说的天花板 3000 亿，是怎么计算的？」
- 「你想融资 1000 万，打算花在哪儿？」
- 「你的商业模式，凭什么能做到三个月回本？」
- 「我团队的背景都很棒，每个人都很优秀……」

每一条展开解释大概需要 1-3 分钟，划不划算？
→ 除非是项目重要卖点，可以适当展开，不然快速跳过。
```

## 六、五类常见问题全景诊断

Truman 从几百场路演中总结了五类最常见的问题：

| 问题类型 | 表现 | 根因 | 解法 |
|---|---|---|---|
| **没讲清楚** | 听众听完不知道你是干什么的 | 缺少「最起码三件事」的清晰表达 | 回到 3×3 画布，先练「讲清项目」 |
| **内容跑偏** | 讲了太多细节，主线模糊 | 逻辑线不清晰，贪多求全 | 选一条主逻辑线（推荐「时间线+因果」），其他砍掉 |
| **没控制时间** | 超时严重或前松后紧 | 没有计时彩排，没有分配段落时间 | 彩排重点2：练习时间分配 |
| **无聊冗长** | 听众走神、看手机 | 缺少张力布局，全是平铺直叙 | 回到「印象深刻」，至少埋 3-5 个张力点 |
| **不自信** | 声音小、眼神飘、语速乱 | 准备系数太低，彩排不够 | N 往上拉，重复直到自信 |

```text

│   └── 印象深刻：《讲好故事技巧集》

└── 准备工具：逐字稿

【提前彩排】（30%）
├── 公开路演三部曲

【现场表达】（20%）

└── 关键建议2：不要过度展开
```

## 八、三个 L6 级洞察

### 洞察一：路演三部曲的权重分配打破了大多数人的直觉

```text
多数人以为：现场表达最重要 → 花 80% 时间练台风、练手势、练声音。
实际上：内容准备占 50%，提前彩排占 30%，现场表达只占 20%。

为什么？
因为现场表达的上限，由内容准备和彩排的下限决定。
如果你的逐字稿是 60 分，彩排是 2 遍，再好的台风也救不了。
如果你的逐字稿是 85 分，彩排了 30 遍，就算现场紧张一点，底线也在 70 分以上。

内容准备和彩排，决定的是你「最差能差到什么程度」。
这就是 Truman 说的：越是彩排越不慌。
```

### 洞察二：「准备系数 N」是路演自信的唯一科学来源

```text
没有人天生不紧张。
乔布斯紧张，老罗紧张，Truman 紧张。

区别在于：
普通人 N=1（路演 10 分钟，准备 10 分钟），紧张是毁灭性的。
高手 N=100+（路演 10 分钟，准备 1000+ 分钟），紧张只是背景噪音。

当你把逐字稿练了 50 遍之后，
你的嘴巴比你的脑子更知道下一句该说什么。
这时候紧张还在，但它不影响你的表达——
因为表达已经变成了肌肉记忆。

这就是「你必须非常努力，才能看起来毫不费力」的科学解释。
```

### 洞察三：路演不是「展示你有多厉害」，而是「让听众觉得你很厉害」

```text
很多创业者的路演翻车，不是因为项目不行，
而是因为一直在「展示自己」而不是「照顾听众」。

「我做的是 B2B2C 的 OMO 平台」→ 展示自己的专业度
「我帮早期创业者用一门课解决一个具体的业务难题」→ 照顾听众的理解力

关键建议一「默认听众是小白」和关键建议二「不要过度展开」，
本质上都在说同一件事：
路演的主角不是你，是听众。
你讲得越清楚，听众越觉得你厉害。
```

## 九、L6 自检清单：你的公开路演能力在第几层？

### 关于认知

1. 你看过多少场真正好的路演？有没有自己的《公开路演案例集》？
2. 你上一次路演/公开演讲，是「临场发挥」还是「提前准备」？准备系数 N 大概是多少？

### 关于内容准备（50%）

3. 你的 3×3 画布填完了吗？
   - 提炼卖点：你选的三句话卖点，是投资人最在乎的吗？还是你最想讲的？
   - 讲清项目：三句话能让一个完全不了解你的人听懂你是干什么的吗？
   - 印象深刻：你选了哪三个技巧？是「用了」还是「用好了」？

4. 你的路演有没有一条清晰的主逻辑线？是按时间、按因果、还是英雄之旅？

### 关于彩排（30%）

5. 你有没有写逐字稿？还是只写了提纲？
6. 你上一次路演彩排了几遍？是「念了一遍」还是「练到能脱稿」？
7. 你有没有计时彩排过？知道每个段落大概几分钟吗？

### 关于现场表达（20%）

8. 你的 Checklist 过了吗？对象感、自信、大声、眼神、语速、插入语——每一项给自己打几分？
9. 你有没有犯过「默认听众懂你」的错误？有没有说过「B2B2C」「OMO」「中国的 XX」？

### 关于刻意练习

10. 你未来一年有多少次路演/公开演讲的机会？你有没有给自己设定 N=50 的练习目标？
11. 你能不能找到一个人，听完你的路演后诚实告诉你「哪里没听懂」「哪里走神了」？

## 十、一句话总结

```text
创业者需要讲好自己的故事。
但好的路演不是天赋，不是口才，不是临场发挥——
而是用公开路演三部曲，
把 50% 的精力花在内容准备（卖点 + 讲清 + 印象深刻），
30% 的精力花在提前彩排（逐字稿 + 计时 + 重复直到自信），
20% 的精力关注现场表达（对象感 + 自信 + Checklist）。

准备系数 N 越大越好。
谁做演讲都紧张，越是彩排越不慌。
逐字稿改变世界。

Truman 用几百场路演日的观察总结了一件事：
有些项目真的还不错，但看大家讲不出来。
这不是业务的问题，这是表达的问题。
而表达的问题，恰好是可以通过科学方法被解决的那个问题。
```
