# 《泛产品实操3：落地篇》L6 清单体笔记

> 主讲：Truman｜一堂 CEO｜前美团产品专家
> 定位：泛产品设计系列第五课｜实操第三课｜击穿三大自我修养之「永远以无限进步为迭代」
> 核心命题：**好的产品，都是改出来的。顶级的作品，都是一轮轮磨出来的。当「理解用户」和「最佳实践」帮你打好了方向和标准的地基，「无限进步」就是让你从「眼高手低」到「手眼合一」的终极能力。这是泛产品设计三组工具箱中最大、最难、也最值得用10年去修炼的一组。**
> Truman 原话：「眼高手低——明明知道不够好，明明知道和最佳实践还有距离，眼睛、审美上去了，但是手上不去，改不动了。这些问题的本质都是，打磨的手段、工具太少了。」「这节课是集体成果——大家对于持续打磨的思考和探索、分享的实践案例，都成为了这节课的共建内容。」「这节课工具太多了，一节课比过去两节课的工具箱加一起都多。」

## 一、课前定位：这节课在泛产品系列里的位置

### 1.1 系列课全景（五节课完整版）

| 课程 | 核心交付 | 段位跃迁 |
|---|---|---|
| 认知篇 | 建立审美+信念+三大自我修养 | L2→L3：开始有泛产品敏感性 |
| 框架篇 | 打造36张卡牌工具箱+出牌逻辑 | L3→L4：开始积累和沉淀工具箱 |
| 实操1：需求篇 | 击穿「理解用户」的13张卡牌 | L4→L5：深度刻意练习需求挖掘 |
| 实操2：审美篇 | 击穿「最佳实践」的4张卡牌+4次飞跃 | L4→L5：深度刻意练习审美拉升 |
| **实操3：落地篇（本课）** | **击穿「无限进步」的19张卡牌** | **L4→L5：深度刻意练习持续打磨** |

### 1.2 为什么「落地篇」是最后一节实操课？

```text
在三大自我修养中，落地篇放在最后，不是因为它最不重要，而是因为它最依赖前两者：

没有理解用户 → 你不知道为谁打磨
没有最佳实践 → 你不知道往什么方向打磨

但当这两个地基打好之后——
落地篇就是决定你从「眼高手低」到「手眼合一」的终极修炼。

眼高 = 审美上去了，知道什么是好
手低 = 但手上功夫跟不上，改不动了
落地篇 = 补上「手」的能力，让你从「看得出差距」到「能缩小差距」
```

### 1.3 这节课的独特之处

```text
Truman 在课上特意强调：

「这节课是集体成果——框架篇讲完后，我们收到了1047份、超过136万字作业。
教研团队进行了全量阅读和挖掘，大家对于持续打磨的思考和探索、分享的实践案例，
都成为了这节课的共建内容。」

同时，这节课的工具箱容量是碾压级的：
「这节课工具太多了，一节课比过去两节课的工具箱加一起都多。」

如果说需求篇和审美篇是精准的单点突破，这节落地篇就是整套泛产品设计能力最完整的「武器库总装」。
```

## 二、课前必答：你的「打磨肌肉」有多强？

### 2.1 两个预热思考题

Truman 在课上给出了两道自测题，帮你定位自己「无限进步」的段位：

**第一题：习惯复盘题**

```text
回顾一下，你平时做一个东西（方案/PPT/设计图），
是习惯「交付一版就差不多了」，
还是经常觉得「还得再改改」？

回顾一个你「反复修改」过的作品——
你大概迭代了多少版本？效果怎么样？有显著提高最后的交付质量吗？
反复打磨修改，背后的价值和区别是什么？
```

**第二题：案例推演题（三档难度递增）**

```text
L1难度：老板说你的海报「勉强60分，整体还是不够香，不够亮眼，
         再打磨一下，一个小时后给我一个最好版本」。
         只有一个小时，你会怎么做？有没有科学的、确定有效的优化手段？

L2难度：你想拍一个《我的十年》短视频，刷过大量最佳实践，有审美了，
         梳理了一个大概故事框架，但总感觉不够好，跟最佳实践还有差距。
         怎么迭代优化？是凭感觉，还是有一套相对系统的方法？

L3难度：老板让你设计一个千人共学共创的AI+项目线上活动，
         已经没有多少最佳实践可以参考了。
         如何打磨方案？如何不断迭代甚至创新？
```

### 2.2 核心诊断：你卡在哪一层？

| 状态 | 表现 | 根因 |
|---|---|---|
| **「一版交付」型** | 做完第一版就发出去，没有「改」的习惯 | 缺少打磨意识 |
| **「眼高手低」型** | 知道不够好，但不知道怎么改，改不动了 | 缺少打磨手段 |
| **「有审美能打磨」型** | 知道哪里不够好，也知道怎么改，稳定提升 | 已进入无限进步的正循环 |
| **「无限超越」型** | 没有标杆也能自己创造标杆，持续逼近「美好作品」 | 这是落地篇的终极目标 |

## 三、核心认知：无限进步的本质

### 3.1 为什么「好的产品都是改出来的」？

Truman 在课上给出了一组顶级从业者的共识：

```text
顶级作家说：伟大的作品，都是改出来的。
顶级PM说：好的方案都是讨论、打磨出来的。
顶级设计师说：好的方案，都是一轮轮磨出来的。

这不是某个领域的特殊规律，而是所有创造性工作的共同规律。
```

但当有了对用户需求的理解（需求篇）和最佳实践的审美见识（审美篇）之后，最常见的困境来了：

```text
「觉得不满意，但改不动了。」

明明知道不够好，把自己的作品和最佳实践放在一起，知道差距很大，
但就是没办法动手优化了。

甚至很多人就是一口气，设计了第一个版本就结束了。
或者想打磨、想优化，但不知道从何下手，卡住上不去了。

这些问题的本质都是：打磨的手段、工具太少了。
```

### 3.2 「无限进步」的三个层次

| 层次 | 核心能力 | 典型状态 |
|---|---|---|
| **第一层：能打磨** | 知道怎么改——有基本的迭代工具和流程 | 做完后能改一轮，比第一版好一些 |
| **第二层：持续打磨** | 有稳定的打磨习惯和系统——不止改一轮 | 酝酿式打磨，48小时内迭代20+版本，直到满意 |
| **第三层：无限超越** | 没有标杆时也能自己定义方向——用想象力和方法论创造新标杆 | 追平所有标杆后，用「美好作品想象」继续前进 |

> **L6 洞察**：大多数人停在第一层（改一轮就停了）。少数人进入第二层（多轮迭代）。极少数人抵达第三层（没有标杆也能持续进化）。**落地篇的19张卡牌，就是帮你在三层之间逐级攀登的完整阶梯。**

## 四、核心框架：落地篇19张卡牌全景

### 4.1 三级别卡牌总览

落地篇是泛产品设计三组工具箱中数量最多、覆盖面最广的一组——**共计19张卡牌**，按三个级别分布：

```text
A. 小作品设计（5张）：内核和边界、酝酿式打磨、善用佳软、设计原则、努力仿真

B. 泛产品设计（5张）：管理三段论、ROI分析、逻辑MECE、里程碑拆解、复盘迭代

C. 泛产品创新（9张）：风险管理、业务建模、低成本测试MVP、
                     灵感闪现、攻坚会、解放思想、十指讲香、项目背景分析、一堂五步法
```

| 级别 | 卡牌数量 | 核心逻辑 | 典型场景 |
|---|---|---|---|
| **A. 小作品设计** | 5张 | 独立完成、快速迭代、从粗糙到精致 | 海报、文案、工位、一封邮件 |
| **B. 泛产品设计** | 5张 | 重资源投入、多人协作、长周期交付 | 直播间、课程、年会、SaaS系统 |
| **C. 泛产品创新** | 9张 | 创新探索、高风险、没有对标 | 新业务、0到1产品、无人区创新 |

### 4.2 四级上升结构回顾

Truman 在课程末尾用「从叶子到森林」的四层结构，帮大家建立了全局视角：

```text
第一层（最表层）：具体的卡牌工具箱
    ↓
第二层：三套工具箱——理解用户（需求篇）、最佳实践（审美篇）、落地执行（本课）
    ↓
第三层：泛产品的工作理念——不想成为某一类APP专家/AI专家/装修专家，
        而是把能力构建在一个「可迁移的大底座」上
    ↓
第四层（最底层）：产品交付能力，是不是你未来10-30年的核心能力之一？
```

> **L6 洞察**：在第四层的视角下看落地篇的19张牌——它们不是「学完就过的工具」，而是你「未来10-30年持续更新的个人武器库」。每多精通一张牌，你的产品交付能力就多一分确定性。

## 五、A级卡牌逐一击穿：小作品设计·落地执行（5张）

这是落地篇最基础的一组牌——解决「一个人能独立完成」的打磨问题。

### 5.1 内核和边界

| 要素 | 内容 |
|---|---|
| **一句话** | 剥离中心思想和边界——面对一个多角度的、复杂的、甚至混沌的产品设计时，努力厘清内核和边界，脑子立刻清晰 |
| **核心操作** | 内核：最中心思想/核心表达/长期追求的东西。边界：跨过边界即与我无关的东西 |
| **典型场景** | 设计复杂产品或思考复杂事物时——先画内核圈和边界圈，再往下走 |
| **训练方法** | 养成「锁定内核，划分边界」的习惯。每次面对混沌需求，先问：什么必须坚守？什么可以妥协？什么根本不关我事？ |

### 5.2 酝酿式打磨

| 要素 | 内容 |
|---|---|
| **一句话** | 科学式的灵感管理——不追求一气呵成，而是多轮迭代 |
| **核心操作** | 写一版 → 放一放 → 看最佳实践 → 再改一版 → 再放一放 → 再改 |
| **一堂经典案例** | 动力三曲线图：48小时内连续打磨大大小小20+个版本，从「10个关键词太碎」到「编口诀太生硬」到「放弃背诵追求理解」到「双曲线逻辑可视化」，最终成为一堂最核心的图示之一 |
| **训练方法** | 养成「产品持续酝酿」的工作习惯。不是一口气做完，而是「做一版→离开→回来再看→继续改」。脑力空余时间是打磨的最好时机 |

### 5.3 善用佳软

| 要素 | 内容 |
|---|---|
| **一句话** | 多学习一些简单产品工具——更多工具，生活工作更多彩一些 |
| **核心操作** | 手绘画图（纸笔/白板/Pad手绘）→ 低保真草图（飞书协作画板）→ 高保真原型（墨刀/Sketch/Pixso）。脑暴工具（白板分区、多色便签、飞书文档共建）。AI工具（ChatGPT/Kimi/Suno等）。装修设计（酷家乐/SketchUp） |
| **训练方法** | 练习「学习教程快速入门工具」的学习能力。不要求精通所有工具，但每次面对新任务时知道「这类任务用哪类工具最快」 |

### 5.4 设计原则

| 要素 | 内容 |
|---|---|
| **一句话** | 掌握基本的UI/UE审美原则——了解如何评价一个页面设计的专业性和交互效率 |
| **核心操作** | 推荐阅读《写给大家看的设计书》《Designing Interfaces（界面设计模式）》。掌握核心四原则：对齐、对比、重复、亲密性 |
| **适用场景** | 涉及专业页面设计和内容排版的场景——海报、PPT、落地页、文档排版 |
| **训练方法** | 读入门书，掌握一组专业的评价原则。下次看到任何页面时，用四原则评价一下：「对齐了吗？对比够强吗？重复一致吗？相关内容放一起了吗？」 |

### 5.5 努力仿真

| 要素 | 内容 |
|---|---|
| **一句话** | 在真实场景做真东西——不要在假的场景、假的流程里凭空设计产品 |
| **核心操作** | 穷尽所能，用尽量真实的场景，迭代和测试产品设计质量 |
| **一些典型的错误习惯** | 用电脑看本身在手机上的页面、用飞书文档看本身微信聊天的文案、用电子版看本身打印出来的物料 |
| **训练方法** | 努力追求「100%仿真」的工作习惯。做海报就打印出来贴在墙上看，做手机页面就在手机上预览，做微信文案就在微信里测试发送 |

## 六、B级卡牌逐一击穿：泛产品设计·落地执行（5张）

这是落地篇的中级牌——解决「多人协作、复杂项目」的打磨问题。

### 6.1 ROI分析

| 要素 | 内容 |
|---|---|
| **一句话** | 可行性取舍——不是所有好想法都值得做 |
| **核心操作** | 面对多个方案时，用投入产出比排序。列出关键成本项和关键收益项，量化比较。从长期视角、公司视角、高度三个角度审视 |
| **适用场景** | 需要重投入设计资源或成本敏感的场景 |
| **核心心法** | 不要用战术上的勤奋掩盖战略上的懒惰。打磨不是「所有地方都改到完美」，而是「找到ROI最高的地方，把有限的精力投进去」 |

### 6.2 管理三段论

| 要素 | 内容 |
|---|---|
| **一句话** | 面对长期重要的工作，努力避免碎片化思考，尽量有逻辑、尽量完备、尽量有推理 |
| **核心操作** | 目标：最终你想实现的结果和价值。路径：实现目标的关键过程。资源：这条路径所需要的钱/人/能力 |
| **适用场景** | 所有重要项目和业务管理场景 |
| **拆解事物的四层级** | 碎片的散点 → Top N优先级 → 不重不漏MECE → 有推理的逻辑链MECE |

### 6.3 逻辑MECE

| 要素 | 内容 |
|---|---|
| **一句话** | 做个有逻辑的人——面对复杂业务和高资源投入的项目，管理逻辑不要乱作一团 |
| **核心操作** | 习惯性按照逻辑链条，一步一步推演，执行策略。拆分维度不重不漏 |
| **适用场景** | 所有复杂/重要/需要协作的工作场景 |
| **与审美篇的逻辑MECE重叠** | 在审美篇中强调「结构完整性」，在落地篇中强调「执行有章可循」。同一张牌，不同阶段出 |

### 6.4 里程碑拆解

| 要素 | 内容 |
|---|---|
| **一句话** | 主动设定交付中间节点——尽量避免推翻重来和一蹴而就的幻想 |
| **核心操作** | 把一个重要的交付分解成一个个循序渐进的里程碑 |
| **适用场景** | 所有重要投入的、容易失败的、容易推诿的产品设计 |
| **核心心法** | 泛产品设计往往是长周期项目，没有里程碑就会烂尾。里程碑的价值：让每一次交付都可见、可验证、可复盘 |

### 6.5 复盘迭代

| 要素 | 内容 |
|---|---|
| **一句话** | 善于向自己的经验学习——做完不是结束 |
| **核心操作** | 每一轮交付后问：和最佳实践的GAP在哪？下一轮改哪3个点？使用深度复盘冰山图（主观感受→客观事实→背后原因→底层模型→能力建设） |
| **适用场景** | 所有重复迭代的、高难挑战的产品设计 |
| **推荐工具** | 学一堂课「深度复盘第一课」——没有什么不是一堂课解决不了的，如果不行，那就两堂课 |

## 七、C级卡牌逐一击穿：泛产品创新·落地执行（9张）

这是落地篇最高级的一组牌——解决「创新探索、高风险、没有对标」的打磨问题。也是三组工具箱中数量最多、难度最高的一组。

### 7.1 风险管理

| 要素 | 内容 |
|---|---|
| **一句话** | 把风险从意外变成确定性——掌握底线思维 |
| **核心操作** | ①预判风险：提前设想有哪些意外可能性；②监控风险：设计机制，及时发现风险发生；③应对策略：提前设定应对思路和方案 |
| **适用场景** | 所有重大/关键/不容有失的产品设计 |
| **训练方法** | 强迫自己思考并练习风险的预判和应对。每次产品设计前问：最大的三个风险是什么？如果发生怎么办？ |

### 7.2 业务建模

| 要素 | 内容 |
|---|---|
| **一句话** | 学习拆解业务公式——站在全局思考和管理复杂的业务 |
| **核心操作** | 不是「我觉得这个功能好」，而是「这个功能通过什么因果链条影响核心指标」。把业务拆成可量化的公式：业务结果 = A + B + C + D × E × F…… |
| **适用场景** | 站在全局思考和管理复杂的业务 |
| **一堂推荐** | 学「业务公式」系列课——充分理解加法和乘法，挖掘2-3倍的转化率参数 |

### 7.3 低成本测试MVP

| 要素 | 内容 |
|---|---|
| **一句话** | 用实验思维10倍速验证假设——从试错成本的角度：常识（专家访谈）＜情报（调研）＜＜实验（低成本验证） |
| **核心操作** | 从左到右MVP成本越来越高：不开发（直接验证/提供VIP服务/用现成工具导量/用人替代）→ 极小开发（最小成本）→ 正式开发（憋大招） |

### 7.4 灵感闪现

| **适用场景** | 所有需要灵感的、创造性解法的产品设计 |
| **推荐课程** | 学「灵感闪现认知篇+工具篇」——保20争30的勇敢Flag，一个人就能完成最高杠杆动作 |

### 7.5 攻坚会

| 要素 | 内容 |
|---|---|
| **一句话** | 重点课题all-in攻坚——在一个封闭空间，集中时间，拉上所有关键角色，进行一场大汗淋漓的、不达目的不散会式的攻坚讨论 |

## 八、出牌层次再回顾：从L3到L1的逐步细化

### 8.1 三级出牌模型（贯穿系列课的核心理念）

```text
L3（泛产品创新级别）：先用五步法周边的牌，做全局产品决策
    ↓ 拆成独立项目
L2（泛产品设计级别）：按管理三段论、ROI分析、逻辑MECE、里程碑拆解、复盘迭代，管理项目落地
    ↓ 拆成具体触点
L1（小作品设计级别）：在每个具体触点，按内核和边界、酝酿式打磨、善用佳软、设计原则、努力仿真，精细化打磨
```

### 8.2 Truman 的完整案例：AI项目出牌推演

```text
L3全局产品决策：
设定一个大概的商业目标 → 做到什么规模or收入利润。
需求：拆推评算，重点拆解客户类型&广告类型，看细分市场预算空间。
解决方案：品牌方合作内核+消费者认可，分别思考决定性的3-5条要素。
商业模式：单项目模型/单视频模型，测算ROI是否健康、可持续。
增长：预判渠道清单，规模化获客后打磨ROI和业务公式。
壁垒：提升规模经济要素（品牌/规模效应/KnowHow）对抗规模不经济（人工和审美）。

→拆成独立项目后，按L2出牌：
ROI分析 + 管理三段论 + 里程碑拆解 + 复盘迭代

→在每个具体触点，按L1出牌：
内核和边界 + 酝酿式打磨 + 善用佳软 + 努力仿真
```

> **L6 洞察**：注意这个三级模型不是线性的瀑布流，而是**循环嵌套的迭代系统**——L1的打磨结果可能触发L2的复盘和重新决策，L2的复盘可能触发L3的重新假设。**真正的「无限进步」，是三个层级之间持续的信息流动和相互修正。** Truman 描述那种典型项目——「大方向正确，但任何单一模式成功率都不太高（10%内）」，五步法可以一步步做预判，做验证，剥离风险，有机会用高频试错跑出来一个不错的创新商业模式。

## 九、一个完整的教学案例：「一小时打磨海报」

Truman 在课首给了一道练习题，在课程末尾用落地篇的工具逐一回应——这是理解「打磨工具怎么用」的最佳演示：

```text
场景：老板说你的海报「勉强60分，整体还是不够香，不够亮眼，
      再打磨一下，一个小时后给我一个最好版本」。

无意识的做法：
凭感觉乱改——换个字体，调个颜色，挪一下位置。改完还是60分。

出牌做法（在一个小时内集中出牌）：
① 确定内核和边界：这张海报最核心想传达什么？（内核）什么信息可以弱化或删掉？（边界）
② 扔进最佳实践池子：把海报扔进之前建好的海报池子，快速定位差距最大的1-2个维度
③ 设计原则检查：对齐了吗？对比够强吗？重复一致吗？相关内容放一起了吗？
④ 善用佳软：用设计工具的快速调整功能，批量替换和对比
⑤ 努力仿真：在真实场景预览——在手机上、在朋友圈截图里、在打印纸上
⑥ 一轮结束后复盘迭代：这一版比上一版改进了什么？下一轮改哪3个点？
```

## 十一、Truman 的个人武器库：墙上的一句话

Truman 在课程末尾分享了他书房墙上的两句话，这是理解「无限进步」精神内核的最佳入口：

```text
「作为一个产品主义者，我始终认为，不断创造好的产品，
也许是一家公司存在的最大意义。」

「趁着活着多创造作品，因为我们将死去很久。」
```

**L6 解读**：

```text
这不是浪漫主义的口号，而是「无限进步」的终极动力来源。

如果你相信「创造好产品是有意义的」——
你就不会满足于「第一版差不多就行」。
你就不会在「改到第5版」的时候停下来。
你就会在追平所有标杆后，继续想象「还能更好成什么样」。

这就是「无限进步」的精神内核：
不是因为有人逼你，而是因为你觉得「值得」。
```

## 十二、四个 L6 级洞察

### 洞察一：落地篇的卡牌数量碾压级领先，因为「改」比「想」难10倍

```text
需求篇13张 + 审美篇4张 = 17张。
落地篇独占19张——比前两节课的工具箱加一起还多。

这不是偶然。
因为「理解用户」和「建立审美」更多是思维活动——你想清楚了，就跨过去了。
但「无限进步」是肌肉活动——每一轮打磨都需要具体的方法、工具、流程。

想清楚一次 vs 打磨20轮——后者需要的工具量天然是前者的数倍。
这就是为什么落地篇是泛产品设计三组工具箱中「最大、最难、最值得用10年修炼」的一组。
```

### 洞察二：三节课实操篇的完整逻辑链——从「眼高」到「手高」

```text
需求篇解决：你能不能「理解用户真正需要什么」？
→ 如果理解错了，后面再努力打磨也白费（眼的问题）

审美篇解决：你能不能「知道什么叫好」？
→ 如果不知道什么是好，打磨没有方向（眼的问题）

落地篇解决：你能不能「从不够好改到足够好」？
→ 有了方向之后，有没有手段缩小差距（手的问题）

完整逻辑：
需求篇 → 知道为谁改
审美篇 → 知道往哪改
落地篇 → 知道怎么改

这三节课合在一起，才构成一个完整的「泛产品设计者」——
不只「眼高手低」，而是「手眼合一」。
```

### 洞察三：「无限进步」的真正含义——不是一次极致地改，而是一轮轮永远在改

```text
很多人把「打磨」理解成「一口气改到完美」。

错。

Truman的「酝酿式打磨」告诉我们：
真正的高手不是「一口气改到完美」，
而是「改一轮→放一放→再看→再改→再放→再改」。

为什么「放一放」如此重要？
因为你在「放」的时候，潜意识在后台继续加工。
因为你在「放」的时候，可能会偶遇新的最佳实践。
因为你在「放」的间隙，情绪从「改不动了」恢复到「又可以了」。

酝酿式打磨 = 给大脑留出发酵的时间 + 给情绪留出恢复的空间。
这才是「无限进步」可持续的秘密——
不是冲刺，是马拉松。
```

### 洞察四：「眼高手低」不是贬义词，是通往高手的必经阶段

```text
眼高手低 = 审美已经上去了，但手上功夫还没跟上。

这个状态让人很痛苦——你「看得出差距」但「缩小不了差距」。
但从成长的角度看，「眼高手低」恰恰说明你已经完成了最难的那一步：

审美建立。

手上功夫可以靠落地篇的19张卡牌逐一修炼。
但如果审美没上去（眼低），你永远觉得自己「做得挺好的」，
根本不会进入「打磨」这个动作。

所以如果你现在感到「眼高手低」的痛苦——
恭喜你，说明你的最佳实践收集和池子建模已经生效了。
你现在需要的不是焦虑，而是落地篇的19张牌。
```

## 十三、L6 自检清单：你的「无限进步」落地能力在什么水平？

### 关于意识

1. 你现在是「一版交付」型，还是「持续打磨」型？回顾你最近三个交付，分别改了几版？
2. 你上一次觉得「眼高手低」是什么时候？你是怎么应对的——停下来接受60分，还是找到方法继续改？

### 关于A级卡牌（小作品设计·落地）

3. 你做任何一个东西之前，有没有先厘清「内核和边界」？什么必须坚守？什么可以妥协？
4. 你是否习惯「酝酿式打磨」——改一轮、放一放、再看、再改？还是总想一口气搞定？
5. 你的工具栈（善用佳软）够丰富吗？面对一个新任务，你知道「这类任务用哪类工具最快」吗？
6. 你的设计四原则（对齐、对比、重复、亲密性）过关吗？
7. 你习惯在真实场景预览吗？还是经常在电脑上看手机页面？

### 关于B级卡牌（泛产品设计·落地）

8. 面对复杂项目，你有没有做ROI分析——把有限精力投在回报最高的打磨方向上？
9. 你的项目管理有没有用管理三段论（目标-路径-资源）和里程碑拆解？
10. 你上一次做完项目后，有没有做复盘迭代——不只判断「好不好」，而是定位具体GAP并指导下一轮？

### 关于C级卡牌（泛产品创新·落地）

11. 你做创新项目时，有没有预判风险并准备应对策略？
12. 你能不能把业务拆成可量化的业务模型（业务建模）？
13. 你有没有用过低成本测试MVP——先验证最关键假设，再大规模投入？
14. 灵感闪现和攻坚会——你用过吗？哪一次印象最深刻？
15. 「找到更底层规律，然后在上层突破规律做创新」——这句话你理解了吗？能用你自己的话解释吗？

### 关于10年尺度

16. 落地篇的19张牌，你现在最常用的是哪几张？哪些是你的盲区？
17. 如果以10年为单位修炼落地篇的19张牌，你准备先击穿哪一张？下一张是什么？
18. 「趁着活着多创造作品，因为我们将死去很久」——这句话给你什么感觉？

## 十四、一句话总结

```text
好的产品，都是改出来的。

泛产品设计的三大自我修养中：
需求篇让你知道为谁改，
审美篇让你知道往哪改，
落地篇让你知道怎么改。

但「怎么改」是最大的工具箱——19张卡牌，
比需求篇和审美篇加在一起还多。

A级（5张）让你一个人也能持续打磨小作品——
厘清内核和边界、酝酿式打磨、善用佳软、掌握设计原则、努力仿真。

B级（5张）让你带着团队管理复杂项目的落地——
ROI分析、管理三段论、逻辑MECE、里程碑拆解、复盘迭代。

C级（9张）让你在创新和无人区也能不断突破——
风险管理、业务建模、低成本测试MVP、灵感闪现、攻坚会、解放思想。

三级之间不是线性瀑布，而是循环嵌套的迭代系统——
L1的打磨触发L2的复盘，L2的复盘触发L3的重新假设，如此循环，无限进步。

Truman 用方法论小抄的20+轮迭代、直播间的四次进化、大地图的15轮打磨证明了一件事：
「眼高手低」不是贬义词，是通往高手的必经阶段。
而落地篇的19张牌，就是帮你从「眼高」走到「手高」的完整武器库。

坏消息是：牌有点多，每一个都得费力气练。
好消息是：大家都是一样难，这是一条「足够确定能赢」的路。
趁着活着多创造作品，因为我们将死去很久。
```
