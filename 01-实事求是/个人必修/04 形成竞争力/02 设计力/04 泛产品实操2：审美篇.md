# 《泛产品实操2：审美篇》L6 清单体笔记

> 主讲：Truman｜一堂 CEO｜前美团产品专家
> 定位：泛产品设计系列第四课｜实操第二课｜击穿三大自我修养之「永远以最佳实践为追求」
> 核心命题：**不夸张地说，我至少有 50% 的成长来自对于「最佳实践」的持续追求。如果没有掌握最佳实践的做事方法，估计很难有一堂这家公司。最佳实践不是让你抄作业，而是解决了见识和审美问题——只有足够强的审美，才有机会有进步空间（GAP）。**
> Truman 原话：「我愿意/敢于花 70% 的时间调研，这个本身就是正式工作，而且是更重要的工作。」「逻辑会把你从 A 带到 B，想象力能带你去任何地方。」

### 1.2 为什么「最佳实践」是三大修养中 ROI 最高的？

```text
Truman 的判断：
不夸张地说，我至少有50%的成长，就来自对于「最佳实践」的持续追求。
我不止一次提到，如果没有掌握"最佳实践"的做事方法，估计很难有一堂这家公司。

理解用户 → 知道为谁做（方向正确）
最佳实践 → 知道做成什么样算好（标准够高）  ← 这节课
无限进步 → 知道怎么一步步逼近那个标准（执行到位）

三个修养的协同关系：
没有理解用户 → 最佳实践对标的是「谁的最佳实践」？
没有最佳实践 → 无限进步不知道「往哪个方向改」。
没有无限进步 → 审美再高也落不了地（下一节课解决）。
```

### 1.3 一堂做课的真实案例：70% 时间花在建立审美

Truman 在课上分享了一个改变他一生的故事：

```text
2018年底，一堂第一次做课。
第一期是「融资实战课」，周子敬主讲。
我作为一个还算专业的互联网PM，完全没做过系统的最佳实践级别的课程。

时间只剩4周就要交付。
第一周，我带着团队学习，没找子敬。
第二周，我带着团队学习，没找子敬。
时间进度过了70%，子敬实在忍不住了，把我叫过去偷偷打听：
「课程做得怎么样了？还有一周多就要交付了啊。」

我记得我给的答案是：「差不多了，我已经有审美了。」

我用了70%的时间去做全网课程调研，去看最佳实践：
运营模型：对标三节课（背后是Udacity）
文稿模型：对标得到（口语化品控）
文化模型：对标碳9学社（教育理念）

通过看大量高分「严肃课程」，建立了一个三层评价模型：
本质：通透深刻（对应好评：醍醐灌顶）
框架：方法完备（对应好评：科学体系）
工具：落地实操（对应好评：落地有用）

有了这套审美，后面我只花了10天就做出了第一节课。
我作为一个外行，从第一节课，质量就还不错，
基本上跟同行比就有了很强的产品侧的竞争力。
```

> **L6 洞察**：这个案例完美展示了「审美优先」的逻辑。大多数人一上来就开始做，做了 90% 的时间才发现方向不对。Truman 是反过来的——先花 70% 的时间建立审美（「知道什么是好」），再花 30% 的时间执行（「做到那个好」）。**审美就是你的天花板。审美有多高，产品的上限就有多高。**

## 二、核心认知：最佳实践的本质

### 2.1 最佳实践的三个关键特点

很多人对最佳实践有一个巨大误区：**「我怎么知道是不是最最最最佳实践呢？我觉得都有缺点啊，真的是最佳实践吗？学错了怎么办？」**

Truman 用三个关键词破解了这个执念：

| 特点 | 含义 | 实操指引 |
|---|---|---|
| **相对而非绝对** | 显著比你好，就可以 | 不必盲目追求全行业/全球最佳。团队内最好→身边最好→业内最好→全球最好——每一步都是进步 |
| **具体而非模糊** | 一定是非常具体的手段和对标案例 | 甚至细到一句话、一张卡片、一个按钮文案。越具体，越可学 |
| **手段而非目的** | 解决问题的手段而已 | 除了最佳实践，你还可以学理论/自己从0测试/做实验/头脑风暴。不要执着于「找到完美的那个」 |

**一个通俗案例**：

```text
你商务送礼，挑礼物和送礼物总是很不擅长，经常弄得场面很尴尬。

最佳实践可以是：
- 相对：不必盲目追求全球送礼大师的水平，身边送礼最得体的那个人就是你的最佳实践
- 具体：哪怕就是小卡片上的一句话、见面时说的一句话，只要很好用，都是最佳实践
- 手段：除了学别人的送礼方式，你也可以学心理学、做实验、自己头脑风暴找点子
```

### 2.2 四个基本认知

| 认知 | 含义 | 反例 |
|---|---|---|
| **看到才能想到** | 你没见过好的，就想象不到更好的样子 | 一直用着 60 分的方案，觉得「差不多就行了」 |
| **知道才能做到** | 只有知道了什么是好，才能往那个方向努力 | 「我觉得不够好，但不知道往哪改」 |
| **对比才有 GAP** | 把自己的东西扔进最佳实践池子，差距一目了然 | 只跟自己的上一版比 → 永远在小幅度「优化」，不会有「跃迁」 |
| **GAP 才是进步空间** | 足够强的审美，才有机会有进步空间 | 审美低 → 看什么都觉得「还不错」→ 没有进步动力 |

## 三、核心框架：审美提升的四阶段 × 四张卡牌

### 3.1 四阶段全景

```text
看纵轴（天花板）：基础 → 进阶 → 高阶 → 无限进步，逐步突破天花板
看横轴（策略集）：搜集 → 池子（黑盒）→ 建模（白盒）→ 大胆想象

四个阶段：
第一阶段：我能看见   → 把市面上能找到的最佳实践都搜集过来，养眼睛
第二阶段：不比人差   → 筛选最好的建池子，把作品扔进去对比，打磨到不怂
第三阶段：稳定优秀   → 把黑盒白盒化，建评价模型，稳定在Top水平
第四阶段：探索超越   → 大胆幻想，放飞想象力，创造超越现有最佳实践的作品
```

### 3.2 四张卡牌与四次飞跃的对应

| 卡牌 | 阶段 | 核心逻辑 | 一句话 |
|---|---|---|---|
| **最佳实践收集** | 第一次飞跃：我能看见 | 从闭门造车到打开眼界 | 「一次性『卧槽』够」 |
| **最佳实践池子** | 第二次飞跃：不比人差 | 从模糊感觉到精准对标 | 「扔进去不怂才算及格」 |
| **最佳实践建模** | 第三次飞跃：稳定优秀 | 从黑盒感受到白盒标准 | 「把'我觉得好'翻译成'这几个维度几分'」 |
| **美好作品想象** | 第四次飞跃：探索超越 | 从对标现实到创造未来 | 「逻辑带你去A到B，想象力带你去任何地方」 |

## 四、第一次飞跃：我能看见（最佳实践收集）

### 4.1 飞跃前的状态与飞跃后的状态

| | 飞跃前 | 飞跃后 |
|---|---|---|
| **典型状态** | 习惯性自己琢磨，按过去经验和惯性来做，习惯性闭门造车，没有「专门建立审美」的环节 | 做一个重要工作时，会刻意花时间提前建立审美，会固定花 30% 甚至 70% 的时间建立审美 |
| **导致的问题** | 一直在一个50-70分的水平，想提升也不知道空间在哪儿，想打磨也打磨不了两轮 | 有了审美，有了判断力，知道了打磨的方向和结束的基准线（Benchmark） |

### 4.2 飞跃的关键判断标准

```text
Truman 的判断标准很简单：
看这个人有没有进入一个状态——
「很有信心，又持续不满意。」

很有信心：有了审美，有了判断力，知道了打磨的方向和结束的基准线。
持续不满意：对于眼下方案，持续不满意，持续打磨，持续提升，持续升级。

反例（没飞跃）：
对于未来未知，对于现在结果贼满意。
做了一个版本，还没怎么打磨，就沾沾自喜，觉得自己可棒了。
```

### 4.3 实操策略

| 策略 | 核心动作 | 示例 |
|---|---|---|
| **大量搜集** | 把市面上能找到的相关最佳实践全部搜集过来 | 互联网文化衫：苹果/字节跳动/小米/Google……；大型活动服装：年度大课/双十一大促/年会……；员工直接推荐 |
| **养眼睛** | 大量刷最佳实践，不急于分析，先「养眼睛」 | 一次性「卧槽」够——让大脑充分感受「原来还可以这样」 |
| **建立初步审美体感** | 搜集完后，问自己：哪些让我有「我也要做到这个水平就好了」的感受？ | 筛选出最有感觉的案例，作为后续建池子的候选 |

### 4.4 三个练习题（Truman 课上给出的）

```text
简单题：小红书博主做北美旅居租房中介，想用个人说明建人设+引流，
        应该调研的最佳实践是什么？

进阶题：作为城市中心主理人，想做城市共学活动，
        但认知和经验不够，怎么快速建立最佳实践审美？

高阶题：想写一本偏商业管理的书（比如商业表达力），
        用什么方法能找到最佳实践？
```

**参考思路**：

```text
小红书：直接对标同风格头部IP；小红书×抖音×视频号交叉搜索。

城市活动：拆成4-7个要素（场地/流程/互动/传播/内容），分别调研最佳实践。

未来写书：拆解4-7个要素（结构/案例密度/工具化程度/可读性/金句密度……），
          作为篮子长期积累建立审美。截图+Flomo+知识库。
```

## 五、第二次飞跃：不比人差（最佳实践池子）

### 5.1 飞跃前的状态与飞跃后的状态

| | 飞跃前 | 飞跃后 |
|---|---|---|
| **典型状态** | 大量看最佳实践、养眼睛，但对于什么是优秀的水平，还只是模模糊糊的感受。参考的最佳实践很多、很混乱，很难判断设计出来的产品水平到底怎么样 | 基于某一个具体的项目/任务，筛选出最好的 3-20 个最佳实践放到一起，建一个「池子」。产品设计完了，扔进去看看——如果显著差很多，就继续打磨、迭代，直到扔进去发现差不多为止 |

### 5.2 池子操作法

```text
核心操作：筛选入围 → 对比打磨 → 不怂即停

Step 1 筛选入围：
拿案例问自己，是否有「我要能做到这个水平就好了」的感受，有就收入池子。

Step 2 对比打磨：
把自己的作品扔到这个池子里比比——
如果明显差很多 → 继续打磨。
如果扔进去发现也不差 → 可以停了。

Step 3 不怂即停：
改到扔进去一点都不怂了，ok可以停了。
```

### 5.3 一堂的真实池子案例

**Logo 设计的五轮扔池子**：

```text
一堂设计 Logo 时，审美和经验不够，怎么简单来做呢？找一堆 Logo 池子。

第一组：感觉创意挺有趣，但放进去发现完全不行。
第二组：也完全不行。
第三组：还不行。
第四组：好了一些，还是弱。
第五组：ok，足够简单、略有风格，大概像是一个层次的水平了，可以停了。
```

**方法论小抄的池子对标**：

```text
一堂做方法论小抄，改到 20 多个版本，扔进池子里一点都不怂了。
```

**一堂这些年做过的池子**：

```text
马拉松选题池、书名/封面池、招生海报池、金句图池、
文化墙池、磨课笔记池、获奖证书池……
```

**同学们建立过的池子**：

```text
需求文档池子、优秀投标池子、数据库池子、复盘文档池子、
UI设计池子、乡村振兴案例池子、获奖证书池子、
小红书选题/标题/封面池子……
```

### 5.4 三个练习题

```text
入门题：想做一个自己公司的定制杯子，怎么思考最佳实践和设计？
进阶题：想拍一个《我的十年》短视频，怎么思考最佳实践和设计？
高阶题：想设计一场婚礼，怎么思考最佳实践和设计？
```

**参考思路**：

```text
杯子：找小红书、问供应商要标杆案例做成池子。
     重点是「我要是也能设计成这样就好了」。

我的十年：找一个对标的池子，拆解成选题+风格+剪辑+故事线等维度分别设计和打磨。

婚礼：拆解成VI+流程+仪式感+誓词+惊喜等环节，分别搭建一个个池子。

提醒：不要试图把整体最牛逼的池子拉出来——
     头部IP和明星婚礼是我们根本做不到的。
     池子要对标「比你强但够得着」的水平。
```

### 5.5 池子的进阶用法：虚拟池子

```text
初级：用知识库、文档管理，把案例存下来随时对照。

进阶：慢慢熟悉以后，可以用「虚拟池子」——
在脑子里做头脑实验，
得跟过去你见过/做过的最好的一批比较，
在同一个大概的水平才行。
```

## 六、第三次飞跃：稳定优秀（最佳实践建模）

### 6.1 飞跃前的状态与飞跃后的状态

| | 飞跃前 | 飞跃后 |
|---|---|---|
| **典型状态** | 通过池子可以做到「不比人差」。但对于什么是好的标准，还是个黑盒——通过自己一些非标的感受来衡量。导致设计水平不稳定，下一次再设计很难保持同样的 Top 水平，也很难和别人协作对齐 | 尝试把黑盒白盒化——找到大量最佳实践的共性，提炼一个尽可能完备的评价模型，用相对理性、稳定的框架来衡量产品的质量高低 |

### 6.2 一堂的真实案例：马拉松续费礼品的审美建模

Truman 在课上分享了一个非常经典的建模过程：

```text
背景：一堂每次马拉松，最艰难的「续费礼品攻坚」都是一个大难题。
讨论过大量选项，但全部主观，10+个同学一起协作，几乎不可能完成。

如果只用池子：很难判断——每个礼品都不一样，
没有共同的评价标准，根本无法比较。

于是我们认真坐下来，试着给礼物的审美建了一个模型：
- 维度1：____
- 维度2：____
- ……

有了这个模型，整个讨论的效率就大幅提升了：
好处1 团队共识：为什么行、为什么不行，有了明确的目标。
好处2 避免无效：一些明显不合适的就不用提案了，大大提升效率。
好处3 集中脑暴：在一个礼品符合70%条件时，集中打磨补全所有条件。
```

### 6.3 建模的工具推荐：雷达图

```text
Truman：「雷达图是一个大大被大家低估的好用模型。」

雷达图的好处：
- 多维度的雷达图，可以让不同产品放在同一套标准下比较
- 一目了然看到强项和弱项
- 团队协作的绝佳沟通工具——不需要争论「好不好」，只需要争论「在这个维度上几分」

追问：你们过去建立过多少个雷达图？
```

### 6.4 建模的应用场景

```text
招聘高阶岗位的胜任力模型：
- 对着招：照着xx同学来招聘（搜集）
- 用池子：试着把Ta放进现在对应的同学里，看看什么水平（池子）
- 建模型：建立一个胜任力模型，用模型来稳定评估和打分（建模）

课程质量的评价模型：
本质：通透深刻（好评：醍醐灌顶）
框架：方法完备（好评：科学体系）
工具：落地实操（好评：落地有用）

文化衫的评价模型：
好的文化衫要满足的N个条件——
面料质感/设计独特性/品牌表达/穿着舒适度/性价比……
每个维度给出60分/70分/85分的具体评价标准
```

## 七、第四次飞跃：探索超越（美好作品想象）

### 7.1 飞跃前的状态与飞跃后的状态

| | 飞跃前 | 飞跃后 |
|---|---|---|
| **典型状态** | 基于现有的最佳实践，总结客观规律，能做到「实事求是」的稳定优秀水平 | 大胆突破，敢于创新，「解放思想」——当市面上已经没有最佳实践可对标，或者你有更高的追求时，用想象力创造新的标杆 |

### 7.2 Truman 的精神内核

```text
爱因斯坦：「逻辑会把你从A带到B，想象力能带你去任何地方。」

Truman：
「从设计产品角度来说，最佳实践是真实在世界上的，
还是我们幻想的，并不太重要。
做产品到最后，唯一能够限制住我们的，只有极限想象力。」
```

### 7.3 一堂的真实案例：大地图与灵感闪现

```text
过去两年，Truman 开始带着团队练更高阶的基本功：
灵感闪现、十层解读。

定一个高目标的Flag，然后从各个角度激发灵感，
去YY、去探索、去不断拔高自己的交付的极限想象力。

比如最近新做了一个很香的《大地图》，
就是先立一个10层解读的目标：
靠幻想「收到的惊喜感」「虚拟课程推荐官」「学习鼓励师」
才能想到这么多idea来驱动我们一直打磨，
大概打磨了15轮才能定稿。
```

### 7.4 美好作品想象的实操问法

```text
做T恤：
- 什么样的文化衫，会让用户/员工收到的时候有惊喜感？
- 什么样的文化衫，大家会很喜欢穿出去/给朋友炫耀？
- 什么样的文化衫，可以传递品牌故事和调性？

做课程：
- 如果世界上存在一门完美的创业课，它应该长什么样？
- 学员学完3年后，还会记得什么？
- 什么会让学员主动推荐给朋友？

做直播间：
- 一堂TV、神奇穿越功能、自动发奖状……
- 这些不是从竞品抄来的，是从「美好作品想象」里长出来的。
```

## 九、T恤设计案例：四阶段的完整推演

Truman 在课上用「10小时做一件T恤」的案例，完整演示了四张卡牌如何逐级出牌：

| 阶段 | 卡牌 | 核心动作 | 产出水平 |
|---|---|---|---|
| **第一阶段：我能看见** | 最佳实践收集 | 把市面上能找到的文化衫最佳实践都搜集过来：互联网文化衫（苹果/字节/小米/Facebook/Google/腾讯）、大型活动服装（年度大课/双十一/年会/团建）、员工直接推荐。大量刷，养眼睛，一次性「卧槽」够 | 审美有了模模糊糊的体感，可以开始设计了，但只能做到还行的入门水平 |
| **第二阶段：不比人差** | 最佳实践池子 | 从搜集到的文化衫中找到最好的5-10个，建池子。筛选入围→把自己的作品扔进去对比→如果明显差很多就继续打磨，直到扔进去不差为止 | 已经能到一个「设计得比较好」的水平。但因为是黑盒，设计体感很容易不稳定 |
| **第三阶段：稳定优秀** | 最佳实践建模 | 建立一个稳定的评价模型来衡量文化衫的质量高低：寻找规律→尝试建模（比如「好的文化衫要满足的五个条件」）→最好量化（每个维度60/70/85分的标准） | 审美从主观感受变成理性标准，能达到稳定 Top 水平 |
| **第四阶段：探索超越** | 美好作品想象 | 大胆幻想：什么样的文化衫会让用户收到时有惊喜感？会喜欢穿出去/给朋友炫耀？可以传递品牌故事和调性？放飞想象力 | 有可能设计出超越现有最佳实践的文化衫 |

## 十、四个 L6 级洞察

### 洞察一：「很有信心，又持续不满意」——这是审美飞跃的唯一标志

```text
Truman 提出了一个极其精准的判据：

没飞跃的状态：对于未来未知，对于现在结果贼满意。
             做了一个版本，还没怎么打磨，就沾沾自喜。

飞跃后的状态：很有信心，又持续不满意。
             很有信心 = 知道好的标准是什么，知道打磨的方向在哪。
             持续不满意 = 知道现在还不够好，还能更好。

这两个状态看似矛盾，实则一体两面。
信心来自「我知道什么是好」（最佳实践），
不满意来自「我还没做到那么好」（GAP）。

一旦你同时拥有这两种感觉，你就再也回不到「差不多就行了」的状态。
这就是审美建立后的不可逆效应。
```

### 洞察二：池子的精髓在于「扔进去不怂」

```text
很多人把最佳实践当「欣赏材料」——看看觉得很好，然后继续做自己的。

池子操作法改变了这个关系：你不是「仰望」最佳实践，你是「把自己扔进去跟它比」。

这个「扔」的动作极其重要：
- 不扔 → 最佳实践是别人的，跟我无关
- 扔了 → 差距一目了然，GAP 刺痛你，逼你继续打磨

池子把「崇拜」变成了「对标」，把「欣赏」变成了「竞争」。
一旦你习惯了「扔池子」，你就再也不会满足于「看起来还行」——
因为池子会诚实地告诉你：不，还不行。
```

### 洞察三：建模的能力 = 从「一次做好」到「次次做好」的能力

```text
池子让你单次做到「不比人差」。
建模让你稳定地保持在这个水平。

区别在哪？
池子靠「感觉」——这次运气好，感觉对了，做得好；下次感觉不对，又掉回60分。
建模靠「标准」——每一次都按同一个维度检查，每一次都能稳定输出70分以上。

建模的另一个巨大价值：团队协作。
池子是「一个人」的工具——靠你自己的感觉来判断。
建模是「一群人」的工具——有了共同的评价维度，团队才有了共同语言。
不需要争论「好不好」，只需要争论「在这个维度上几分」。
```

### 洞察四：「美好作品想象」是泛产品设计从 L5 跃迁到 L6 的关键能力

```text
当前三张牌打完（收集→池子→建模），你已经是「稳定优秀」水平了。
追平了所有同行标杆。

然后呢？

大多数人的天花板就在这里——被已有的最佳实践框住了。
而 Truman 的答案：「做产品到最后，唯一能够限制住我们的，只有极限想象力。」

美好作品想象不是空想，而是——
在深度理解用户（需求篇）和深度掌握审美（审美篇前三张牌）的基础上，
用想象力创造出一个「还不存在但应该存在」的完美版本，
然后把它当成新的最佳实践去追赶。

这可能是泛产品设计者从优秀到卓越、
从「能追平标杆」到「能创造标杆」的最关键思维习惯。
```

## 十一、L6 自检清单：你的「最佳实践」审美能力在什么水平？

### 关于意识

1. 你上一次做一个重要东西（方案/海报/活动/任何交付），有没有专门花时间「建立审美」？花了多少比例的时间？
2. 你现在更接近哪个状态：「做了一个版本就挺满意」还是「很有信心，又持续不满意」？

### 关于第一次飞跃（收集）

3. 你有自己的「最佳实践素材库」吗？还是每次做新东西都从零开始搜？
4. 你最近一次「被打开眼界」是什么时候？看到了什么让你觉得「原来还可以这样」？

### 关于第二次飞跃（池子）

5. 你有没有建过任何一个「最佳实践池子」？如果有，你上一次「把自己的作品扔进去」是什么时候？
6. 你的设计/交付，扔进池子里「怂不怂」？还是你一直在避免和标杆放一起比较？

### 关于第三次飞跃（建模）

7. 你有没有为你的核心交付建过评价模型/雷达图？如果有，它有几个维度？能稳定指导团队协作吗？
8. 你的判断标准是「我感觉这个还行」，还是「在XX维度上这个有70分，YY维度上只有50分」？

### 关于第四次飞跃（想象）

9. 你有没有用过「美好作品想象」？上一次你在脑子里构建一个「还不存在但应该存在的完美版本」是什么时候？
10. 当你发现市面上已经没有可对标的标杆时，你的第一反应是「那我也没法做得更好了」，还是「太好了，我可以自己定义什么是好了」？

### 关于刻意练习

11. 未来一个月，你最想练习四张牌中的哪一张？是收集（补见识）、池子（补对标）、建模（补稳定）还是想象（补创新）？
12. 你能不能把你当前最重要的一项交付（方案/产品/活动），用四阶段完整推演一遍？

## 十二、一句话总结

```text
不夸张地说，Truman 至少有 50% 的成长来自对「最佳实践」的持续追求。

但最佳实践不是让你抄作业，而是解决一个更根本的问题：
只有足够强的审美，才有机会有进步空间（GAP）。
如果你的审美一直停留在 60 分，你永远不知道自己能到 85 分。

四张卡牌逐级递进：
最佳实践收集 → 打开眼界，一次性「卧槽」够。
最佳实践池子 → 把自己的作品扔进去，不怂才算及格。
最佳实践建模 → 把黑盒变白盒，稳定在 Top 水平。
美好作品想象 → 用想象力创造还不存在但应该存在的完美版本。

四次飞跃对应四种状态：
第一次飞跃：从「闭门造车」到「我能看见」。
第二次飞跃：从「模糊感觉」到「不比人差」。
第三次飞跃：从「黑盒审美」到「稳定优秀」。
第四次飞跃：从「对标现实」到「探索超越」。

Truman 做一堂第一节课，敢花 70% 的时间调研和建立审美，再用 30% 的时间执行。
他证明了一件事：
审美就是你的天花板。审美有多高，产品的上限就有多高。
而审美，恰好是可以通过四张卡牌被刻意练习的能力。

逻辑会把你从 A 带到 B，想象力能带你去任何地方。
```
