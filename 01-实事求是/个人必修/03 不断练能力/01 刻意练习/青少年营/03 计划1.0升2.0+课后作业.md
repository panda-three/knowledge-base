# 课程：刻意练习计划·青少年营

**一句话结论：** 好计划不是写得完整，而是让下一次练习真实发生——写出1.0，三问自检升到2.0，7天内完成第一轮真实循环。

---

## 一、诊断案例：王浩的数学计划

> 王浩初三数学70分上下，连续每天刷一套整卷，4周刷12套120个错题，分数还在77分原地踏步。

### 问题诊断

| 检查项 | 王浩的问题 |
|---|---|
| 动作够小吗 | 会做的和不会做的混在一起，时间被平均分掉 |
| 难度合适吗 | 没先摸底卡在哪类题哪一步，谈不上逐级加难 |
| 反馈及时吗 | 只看最终答案对错，没定位思路断在哪步 |
| 练到稳定了吗 | 错题抄完没单独拿出来重练，下一套和上一套没区别 |

### 改版后

- 方向：做应用题时稳定找全关键条件。
- 小动作：不急着解完整题，只练审题第一步（读题、圈条件、用自己的话说在问什么）。
- 逐级加难：第一轮10道摸底（漏4个条件），下一轮降到2个以内。
- 及时反馈：圈出的条件和解析逐项对照，标记漏的是数字/单位/"至少最多剩余"这类关键词。
- 反复练对：再找10道带限制词的题只练圈条件；第二天换组复测；稳定后放回完整解题。

> **题做得少了，真正被练到的东西反而多了。**

## 二、写练习计划1.0（一条+四格）

> 方向是你想练到什么程度；四格是：小动作、加难度、拿反馈、练到位。

| 格 | 示范（英语） |
|---|---|
| 方向 | 不看稿，用英语讲清昨天发生的一件事 |
| 小动作 | 只练一分钟叙述里的过去时 |
| 挑战标准 | 第一轮先录一分钟数有几句时态对；下一轮争取多两句 |
| 反馈 | 手机录音回听，只检查过去时 |
| 练到位 | 根据录音里最常出现的错误调整一处，再把改过的句子连续说对三次 |

## 三、三问自检升到2.0

1. 小动作能不能在10-20分钟里单独练？不能就再缩小。
2. 挑战标准练完能不能看出变化？"认真一点""做到最好"换成可观察结果。
3. 反馈方式能不能告诉你下一轮先改什么？"看感觉"换成录音/错题步骤/明确检查项。

> 改清楚最模糊的一处，就从1.0升到2.0。

## 四、课后作业：7天真实循环

1. 按计划2.0完成一次10-20分钟真实练习。
2. 用选好的反馈方式检查结果。
3. 根据反馈调整一个问题，把改过的动作再练一轮。
4. 提交四行：
   - 我这次拆出的小动作是？
   - 摸底/第一轮真实结果是？
   - 反馈告诉了我什么？
   - 我调整了什么，又把它练到了什么程度？

> 五句话带走：认准方向、拆小动作、逐级加难、及时反馈、反复练对。场景会变，循环不变。
