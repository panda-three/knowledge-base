# 课程：红点十二问·青少年营

**一句话结论：** 先定位你在六段位地图的哪一格，再用十二问把"我好像喜欢"变成具体经历、感受和选择依据。

---

## 一、六段位修炼地图

| 段位 | 状态 | 缺失 |
|---|---|---|
| L1 | 缺少追求，随性人生 | 缺终局意识，随遇而安/纠结/浪费经验 |
| L2 | 有追求缺方向 | 红点太浅/太远/太虚 |
| L3 | 有2-3个高优先级备选 | 缺笃定唯一、缺取舍、缺愿意妥协 |
| L4 | 有第一红点，开始规划 | 缺具象红点、缺路径、缺复利 |
| L5 | 落地开始形成复利 | 缺动态修正、缺持续复盘 |
| L6 | 动态迭代，保持开放 | 无限进步 |

> 提升路径：有红点意识→找到第一红点→有路径规划→知行合一→动态迭代。

### 小航定位练习

- 他知道不能只看热门就业，手上有两条说不清的线索。
- 但说不出两三个具体方向，也没真正了解过任何一个。
- 结论：**更接近L2**。

## 二、人生红点十二问

| 分类 | 提问角度 | 描述 |
|---|---|---|
| **问过往** | 关键选择 | 回顾关键选择中呈现的偏好 |
| | 峰值瞬间 | 回顾让自己激励的点 |
| | 低谷瞬间 | 回顾让自己不喜欢的经历 |
| **问未来** | 对标标杆 | 对标身边或名人的"最佳实践" |
| | 无限想象 | 不考虑资源时间，未来最想怎样 |
| | 具体画面 | 熟悉行业中想象几种红点可能的样子 |
| **问抽象** | 挖掘共性 | 过往选择与未来想象中的共性 |
| | 找寻冲突 | 在矛盾中确认真正的热爱 |
| | 往上抽象 | 重新定义问题背后的共性迁移 |
| **问取舍** | 红点排除 | 先排除绝对不会选的 |
| | 设置底线 | 明确哪些是底线而非追求 |
| | 强制排序 | 两两比较选出Top1 |

### 小航线索抽象示范

- 线索1：看机器人视频到很晚（技术本身有兴趣）。
- 线索2：一下午教爷爷用手机很开心（喜欢帮别人学会用它）。
- 拿掉"机器人""手机"两个词，剩下两条更抽象的线索。

## 三、[练习1] 峰值瞬间

> 写下一次**没人要求你、你却愿意投入很长时间**的经历，写到能看见画面：

1. 那件事是什么？什么时候、和谁一起？
2. 当时你在做什么动作？想、做、还是讲？
3. 哪个瞬间让你觉得"这个还挺爽的"？

> 线索攒到五六条，共性自己浮现。只回头看不够——经历少、没接触过的领域想象不出来，下一步要走出去增加信息。
