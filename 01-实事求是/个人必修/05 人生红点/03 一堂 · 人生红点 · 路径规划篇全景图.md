# 一堂 · 人生红点 · 路径规划篇全景图

**定位**：人生红点系列第三节实操课——从 L4（有第一红点）修炼到 L5（有落地复利）。认知篇给了框架和九大红点，笃定篇给了锁定第一红点的武器库，这一篇是**把抽象的红点变成具象的计划**——让红点从「天上的意义感」变成「脚下的路」。
**一句话定义**：人生红点路径规划 = 把几十年后那个最远最亮的点，拆成今天就能迈出第一步的阶梯——每一步都在逼近红点，每一步都在获得正反馈，每一步都在成为下一步的起点。
**核心命题**：很多人有了红点，但红点高高在上、虚无缥缈——和日常工作生活没有关系，和眼下每一步没有连接。这节课回答的就是：你到你的红点之间的那条线，到底长什么样。
**Truman 原话**：这节课才是把红点价值发挥出来，产生人生巨大复利的一节课。人生红点，是你人生中性价比最高的决策。
**课程数据**：400+ 位同学共建、25 万+ 字作业。大量同学的路径规划画布和人生故事融入了这节课。

## 一、核心命题 · 为什么有了红点还不够

**典型困境**：

- 红点有了（比如作品型），但和眼下的日常工作感觉毫无关系——「我在做运营/写代码/教课，和'做出传世作品'有什么关系？」
- 红点太远了，远到缺乏正反馈——「那是我 20 年后的事吧，现在想了也没用」
- 没有路径，每年积累的不是同一个方向上的东西——「我感觉自己每年都在努力，但五年后发现还在原地」

**Truman 的比喻**：

> 你到你的红点之间的那条线，是一个比较直的线？还是转着圈的线？还是歪七扭八的线？不同的选择和决策，决定了不同的人生状态和终局。这条线你想得越多、越清楚，你的人生就活得越通透。

**这节课要解决的问题**：把天上的红点，变成地上的路——让你每一步都知道「这一步在逼近红点吗？逼近了多少？」

## 二、两个核心概念 · 傻叉速率与逼近速率

**一句话**：把抽象的「成长速度」变成可自我感知的两个定量指标。

---

### 概念① · 傻叉速率

**来源**：瑞·达里奥（Ray Dalio），桥水基金创始人，《原则》作者。

**原文**：如果你没发现一年前的自己是个白痴，那么意味着你这一年并没有获得成长。

**含义**：你在多久的时间段内，会发现过去的自己是一个傻叉？这个代表你的学习速度。
- 10 年？
- 3 年？
- 1 年？
- 还是一个季度？

**用法**：这是一个自我追问的指标——不是和别人比，是和过去的自己比。如果你看一年前的自己没有任何「我当时怎么这么蠢」的感觉——这一年可能没怎么成长。

---

### 概念② · 逼近速率

**来源**：Truman 在磨课时类比「傻叉速率」创造的概念。

**定义**：如果你从来没感觉「你在以年为单位显著逼近你更远大的红点」，那么就意味着你的红点推进效率很一般。

**核心问法**：你经过了多久时间，发现自己距离红点的实现**显著拉近**了？这代表你的人生效率。
- 10 年？
- 3 年？
- 1 年？
- 还是一个季度？

**Truman 自己的标准**：这几年一直努力让自己的逼近速率 ≤ 1 年——每一年复盘，产品能力、做课水平、做出 Top 作品的信心，都有显著变化。和 365 天前的自己相比，同样做一个有难度的课题或泛产品创新设计，极限水平或极限工作效率至少有 30% 的进步。

**两点之间直线最短，但没有人可以做到 100% 笔直。** 但是「转圈」「很大弯路」「小弯路」「接近笔直」是可以一步步努力追求和做到的。站在宏观来看，最短路径和动态取舍，才是人生红点的精髓。

## 三、人生红点落地五步法 · 核心框架

**一句话**：人生的顶层方案 = 能力 → 资源 → 进步方式 → 里程碑 → 人生红点。五个格子，从你今天的真实起点出发，一步步推到最远的那个点。

**五个格子的完整含义**：

| 顺序 | 格子 | 含义 | 核心问法 |
|---|---|---|---|
| ① | **能力** | 你需要持续积累的核心能力 | 为了实现红点，我必须把什么能力练到顶尖？ |
| ② | **资源** | 你需要逐渐获取的关键资源 | 什么资源是我必须拿到手里的？钱、人脉、品牌、团队？ |
| ③ | **进步方式** | 你靠什么方式持续进步 | 最佳实践？刻意练习？深度思考？高效 IPO？ |
| ④ | **里程碑** | 从今天到终局的 3-5 个关键节点 | 一步步怎么扩大？每个节点的标志性成果是什么？ |
| ⑤ | **人生红点** | 终局方向 | 你几十年逼近的那个最远最亮的点 |

**三个科学成事的共识（模型底层逻辑）**：

| 共识 | 含义 |
|---|---|
| **分解里程碑，各个击破** | 把几十年的红点拆成一步步可执行、可检查的里程碑 |
| **目标 ← 路径 ← 资源** | 先定红点，再规划里程碑，再确定需要的资源和能力 |
| **能力 → 资源** | 能力是资源的源头——有了核心能力，资源会自然汇聚过来 |

**填写顺序（两条路都可走）**：

- **正推法（12345）**：从能力开始 → 积累资源 → 确定进步方式 → 规划里程碑 → 锁定红点。适合「从今天开始、向未来推演」的务实派。
- **倒拆法（54123）**：先具象红点 → 再规划里程碑 → 再确定需要的能力和资源 → 再找进步方式。适合「先想清楚终局、再倒推今天」的理想派。

**建议**：从后往前做倒拆，从前往后做推演，从事实出发——往往决策更扎实。两种方法交叉使用，像两个探照灯对打，总能打出一个大概轮廓。

## 四、红点路径规划的核心心法 · 阶梯式递进

**一句话**：红点不是「一个遥远虚无的点」，而是「一个连续的、不断推进的人生方向」——从小往大，每一阶段都在实现你的人生红点，都在拉升你的天花板，都在获得正反馈，都在成为下一个红点的起点和基础。

**Truman 举的三个例子（理解阶梯式递进）**：

---

### 案例 1 · 赚钱型的阶梯

| 阶段 | 里程碑 | 拉升了什么 |
|---|---|---|
| 大学 | 先养活自己，不要家里给生活费 | 自立 |
| 毕业 | 在一个岗位上做到月薪 2 万 | 专业能力变现 |
| 副业 | 多角度副业，每年总收入 50 万 | 多元收入能力 |
| 生意 | 一线城市买一个房子 | 资产积累 |
| 富有 | 买一个大 House，赚够钱财务自由 | 财富自由 |
| 巨富 | 买一个海岛，成为亿万富翁背后的亿万富翁 | 财富顶点 |

---

### 案例 2 · 体验型的阶梯

| 阶段 | 里程碑 | 拉升了什么 |
|---|---|---|
| 读书阶段 | 去中国 5 个城市旅行 | 体验边界打开 |
| 工作开始 | 赚够钱，去欧洲旅行一个月 | 体验范围扩大 |
| 深度阅读 | 理解各地文化，练习摄影，写出深度旅行游记 | 体验深度加深 |
| 成为博主 | 成为一个旅行博主，可以养活自己 | 体验变成工作 |
| 出书 | 出一本游记，做一本世界探索畅销书 | 体验变成作品 |

**Truman 点评**：这些都是体验——开始很小，越来越大。完不成最后的愿景很正常啊，又如何呢？**这一路的风景和探索很深，就足够意义非凡了。**

---

### 案例 3 · 作品型的阶梯（Truman 自己）

| 阶段 | 里程碑 | 拉升了什么 |
|---|---|---|
| 大厂阶段 | 做周围 PM 里 Top10% 的方案和产品设计 | 产品基本功 |
| 泛化阶段 | 有能力像做产品一样做婚礼、装修、课程 | 泛产品能力 |
| 一堂阶段 | 做出国内 Top 级别的课程体系 | 教育+产品能力 |
| 公司阶段 | 做出一家受人尊重的教育公司 | 组织能力 |
| 开放阶段 | 和各个垂直领域最 Top 的人合作做产品 | 跨界能力 |
| 未来学家 | 做一个未来学家，影响更多人，洞察和预见未来 | 影响力 |
| 存世 | 做出在国际上有影响力、能影响 100 年的产品体系 | 作品存世 |

**核心心法**：每一步都在一步步提升作品型的成果，一步步拉升天花板，获得正反馈，然后重新出发，作为基础去一步步实现更大反馈的红点。

## 五、路径规划实操工具包

### 工具① · 人生红点落地五步法画布

**一句话**：一张画布，五格填满——这就是你的《人生顶层方案》。

**画布模板**：

| 格子 | 填写内容 | 我的填写 |
|---|---|---|
| ⑤ 人生红点 | 终局方向——类型 + 领域 + 具象标签 | |
| ④ 里程碑 | 3-5 个关键节点——从小往大、逐级拉升 | |
| ③ 进步方式 | 靠什么持续进步——刻意练习/最佳实践/深度思考/IPO | |
| ② 资源 | 必须拿到的关键资源——关系/团队/品牌/资金 | |
| ① 能力 | 必须练到顶尖的核心能力——3-5 个 | |

**填写后必做三件事**：
- **闭卷考试**：能否默写出五个格子填了什么？如果默不出来——说明红点还没「长在脑子里」
- **定期迭代**：每季度/半年 Review 一次——哪些能力变强了？哪些里程碑明显有进展？哪些格子需要更新？
- **审美对标**：写完忘 < 能找到 < 大概记得 < 准确记得 < 有意识积累 < 动态迭代。你在哪个阶段？

---

### 工具② · 逼近速率自测

**自测问题**：
1. 针对你的第一红点——你过去一年的逼近速率够高吗？大概是多长时间的时间段？
2. 和一年前的自己比，你的极限水平或极限工作效率有多少进步？
3. 2025-2026 年，你希望你的逼近速率缩短到什么程度？

**关键心态**：这个没法横向对比，完全取决于你的进步速度、红点远大和自我认知。不必比较，努力说服自己，让自己满意，跟自己和解就好了。

## 六、自我修养 · 拥抱变化，持续调整

**一句话**：五步法画布不是一次填完就封存——是活的，每年要迭代。

**核心原则**：
- 红点方向通常相对稳定——类型很少突变
- 但里程碑会调整——有些里程碑没价值就删，新的机遇出现就加
- 能力也会进化——有些能力不需要了，有些新能力需要补
- 资源会累积——一个里程碑达成的资源，能带到下一个

**Truman 的画布迭代案例**：
- 2019 年：删除「投资人」里程碑（一堂给的成就感足够了）
- 2020 年：新增「泛产品设计」核心能力
- 2021 年：删除「极度复杂管理能力」（非必要）

## 八、2025-2026 的自我拷问

**Truman 在课上抛出的灵魂拷问**：

- 回顾过去一年，你的人生红点五步法画布有新的认知吗？有迭代吗？
- 哪些能力变强了？哪些资源、里程碑明显有进展吗？
- **扎心问题**：当初你填写的画布，现在闭卷考试，你能默写出来五个格子写了什么吗？

**四个自评等级**：
- **肯定能**：滚瓜烂熟，100%
- **大概吧**：大概记得，70-80% 不成问题
- **估计悬**：估计能记住 40-50% 内容
- **不能了**：完全忘了我当时填的是什么了

**Truman 的提醒**：人生中最最重要的东西，如果你都记不住，都不在你脑子里，只是藏在某一篇笔记里，你怎么可能长期迭代、有意识地训练和培养呢？

**审美阶梯**：写完忘 < 能找到 < 大概记得 < 准确记得 < 有意识积累 < 动态迭代。

## 九、最小启动动作

**即刻动手三步**：

1. **默写你的五步法画布**：不看笔记，闭卷默写——⑤ 红点 → ④ 里程碑 → ③ 进步方式 → ② 资源 → ① 能力。如果默不出来——这就是你第一步要做的事：把它记在脑子里。
2. **自测逼近速率**：问自己——和一年前的自己比，距离红点显著拉近了吗？拉近了多少？你的逼近速率是 1 年、3 年、还是 10 年？
3. **迭代一个格子**：五个格子里，哪个最需要更新？只改一个——删一个里程碑、加一个新能力、换一个进步方式。只改一个，改到满意。
