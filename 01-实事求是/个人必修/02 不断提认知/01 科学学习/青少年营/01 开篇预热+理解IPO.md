# 课程：IPO学习法·青少年营

**一句话结论：** 学习效果=输入×处理×输出；你不是懒，只是缺一套所有科目都能用的"手机系统"式学习方法。

---

## 一、三种"卡住"的面孔

| 面孔 | 表现 | 根 |
|---|---|---|
| 跳步型（小A） | 数学不复习直接套公式；语文不看题就通读；英语凭语感选 | 没复习，靠回想碰运气 |
| 死磕型（小B） | 几何题一种辅助线画不出换三种，耗半小时 | 不知何时该停、何时回到第一步 |
| 刷题型（小C） | 错题本抄好几本，做完就过，从不问错因 | 用身体勤奋盖住脑子没跟上 |

> 三张面孔不同，根是同一个：面对任何一科作业，大脑里缺一个"先做什么再做什么卡住怎么办"的通用方法。

## 二、X型 vs Y型学习者

| X型（靠回想碰运气） | Y型（有方法有套路） |
|---|---|
| 数学打开作业直接写 | 数学先花5分钟翻笔记回顾公式 |
| 语文打开阅读直接通读 | 语文先看题目问什么再带着问题读 |
| 英语打开完形凭语感选 | 英语先浏览判断空格考点 |
| 知识是散的，做题拼命回想"老师怎么讲的" | 先温习，做题直接拿来用"这类题按这个步骤走" |

> 打比方：X型每次发照片都去聊天记录里翻；Y型把各科存进分类清晰的收藏夹，一秒找到。每科开始前5分钟就是在做这件事。

## 三、IPO学习法三环

> 用手机逻辑把学习跑成闭环。

| 环节 | 手机比喻 | 学习对应 |
|---|---|---|
| Goal 目标 | 你想用手机做什么？ | 这科学这科想解决什么问题 |
| Input 输入 | 打开哪个App | 知识怎么进脑子 |
| Process 处理 | App里怎么操作 | 题目怎么思考 |
| Output 输出 | 得到什么结果 | 能不能讲出来写出来 |
| Feedback 反馈 | 结果满意吗下次怎么更好 | 真懂了吗 |
| Pattern 整理 | 存成快捷指令 | 好用步骤存下来复用 |

- 现实中大部分同学只做了"处理"——上来就做题。
- **学习效果 = 输入 × 处理 × 输出**，缺一环方法就不完整。

## 四、先定跨学科小目标

- 目标不用大到"数学考满分"，小而具体：
  - 数学："今天解决动点题何时做垂直辅助线。"
  - 语文："练习快速圈出每段核心句。"
  - 英语："刻意判断每个空格是不是考介词。"
- 为你最需要提升的两科各定一个小目标。

## 五、本课带走三样东西

1. 理解方法：你的学习方法——IPO学习法。
2. 实操步骤：三板斧解决学习卡点。
3. 实用小抄：跨学科IPO小循环。
