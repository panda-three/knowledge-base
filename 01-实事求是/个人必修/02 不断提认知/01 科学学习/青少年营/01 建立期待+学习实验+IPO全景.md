# 课程：IPO五张卡·青少年营

**一句话结论：** 看懂≠学会；真正学会=关掉视频还能独立完成+面对新情况能调整+能讲给别人听。

---

## 一、布林结实验

- 看完打布林结视频，问"你能独立打吗"——多数人说能。
- 不看视频凭记忆写3-5个关键步骤——沉默。
- **结论**：画面流过眼睛，不代表能力留下。

### 学习三层次

| 层次 | 含义 | 布林结例子 |
|---|---|---|
| 知道 | 接触过、听说过（信息来自外界） | 看过视频，知道它是绳结 |
| 理解 | 能说清为什么（建立自己的认知模型） | 知道为什么这个结构能固定 |
| 掌握 | 能脱离帮助独立应用，还能教别人 | 不同情况判断何时使用，甚至教会别人 |

> **能力=经过实践验证后的理解。**

## 二、IPO全景图

> 普通学习为什么容易中途断掉？输入→记忆→结束。问题是中间少过了好几关。

一次真正高效的学习要过五关：

| 环节 | 回答的问题 |
|---|---|
| Goal 目标 | 我要学会什么？做到什么算过关？ |
| Input 输入 | 为了过关，我究竟缺什么信息？ |
| Process 加工 | 怎样把外部信息变成自己的理解？ |
| Output 输出 | 怎样证明我能脱离帮助独立完成？ |
| Feedback 反馈 | 没过关，问题出在哪一环？ |

- Feedback不是终点，是下一轮学习的起点。
- 五环节不是独立方法，是**不断循环的系统**——元学习能力。

## 三、五张学习卡

| 卡 | 核心问题 | 检查什么 |
|---|---|---|
| 1 目标卡 | 我要去哪里？ | 方向不清楚，努力只是绕圈子 |
| 2 输入卡 | 我要准备什么？ | 找真正需要的信息，不是全塞脑子 |
| 3 加工卡 | 我怎么把别人的知识变成自己的？ | 看懂听懂只是开始 |
| 4 输出卡 | 我怎么证明自己真的会了？ | 不靠感觉，靠行动验证 |
| 5 反馈卡 | 我下一步怎么进步？ | 找问题、调方法、进入下一轮 |

> 拿出一张纸写"学习系统一页纸"，边听边记：我的学习卡在哪一环？下一步怎么调？
