# 课程：IPO收尾·青少年营

**一句话结论：** Output核心原则八个字"撤掉帮助，留下表现"；Feedback不是评价我行不行，而是像系统诊断一样定位卡在哪一环。

---

## 一、第四张卡：Output 输出卡

> "我感觉懂了"只是自己的感觉，不能盖章。学习需要验证过程：把理解通过行动表现出来。

### 掌握三层次

| 层次 | 含义 | 对应 |
|---|---|---|
| 复现 | 脱离资料重做出来 | 知道 |
| 解释 | 说清为什么这样做 | 理解 |
| 迁移 | 条件变化新情境还能应用 | 掌握 |

### 四种输出方式

| 方式 | 适合检查 |
|---|---|
| 简单复现（做题/背诵/还原步骤） | 基础掌握 |
| 整理总结（思维导图/专题笔记/规律） | 理解 |
| 解释分享（讲给同学/写总结） | 深度理解 |
| 创造应用（解决真实问题/作品/方案） | 迁移能力 |

> 核心原则：**撤掉帮助，留下表现**。合上答案、关掉视频、不看提示；做出答案、完成作品、讲清思路。

## 二、第五张卡：Feedback 反馈卡

> 小林周日验收：第1题独立做对；第5题刚开头卡住；第8题做到一半发现条件判断错了。
> 以前他会想"我不行""我太粗心""白学了"——这些只评价结果，没告诉下一步改哪里。

### 用五张卡定位问题

| 问题表现 | 回到哪一环 |
|---|---|
| 不知道要达到什么标准 | 回 Goal |
| 不知道缺什么知识信息 | 回 Input |
| 知道知识但无法解释迁移 | 回 Process |
| 理解了但脱离帮助做不出 | 加强 Output |
| 已经能完成 | 增加延迟检测确认稳定 |

> **Feedback不是评价，而是定位问题。**

## 三、两种使用模式

| 模式 | 场景 | 走法 |
|---|---|---|
| 顺序模式 | 开始新学习任务 | Goal→Input→Process→Output→Feedback 顺序走 |
| 诊断模式 | 学到一半卡住不知问题在哪 | 先抽Feedback，让它带你回真正要修的那环 |

- "根本不知道做到什么程度"→回 Goal。
- "看答案都会，合上就不会"→重点查Output，同时看Process有没有真发生。

## 四、课后作业

- 选一个一周内要解决的真实学习问题，完整跑一轮IPO。
- 验收后用Feedback卡记录：
  - 哪一环有效；
  - 哪一环需要修复；
  - 下一轮的新Goal；
  - 一条已经发生的进步。

> 下次学习卡住，别先问"我是不是不够聪明/不够努力"，先问：我卡在哪一环？
