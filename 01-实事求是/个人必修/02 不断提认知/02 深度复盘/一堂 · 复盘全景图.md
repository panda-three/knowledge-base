# 一堂 · 复盘全景图

**核心心法**：失败不是成功之母，高质量复盘才是。
**一句话定义**：复盘是基于过去真实经验、面向未来工作的学习——把做过的事拆开，找到差距、事实、原因、行动。

---

## 一、复盘深度冰山：你在挖第几层？

**一句话**：复盘的价值不取决于「有没有复盘」，取决于「挖到第几层」。

**五层递进（从上到下越来越难、也越来越值钱）**：

| 层级 | 挖什么 | 关键飞跃 | 典型问法 |
|---|---|---|---|
| L1 主观感受 | 我觉得做得好不好 | 从忽视到回顾 | 「整体感觉怎么样？」 |
| L2 客观事实 | 实际发生了什么 | 从主观到客观 | 「数据是多少？实际做了哪些动作？」 |
| L3 背后原因 | 为什么会这样 | 从现象到原因 | 「差距背后是什么？关键假设是什么？」 |
| L4 底层模型 | 能迁移到哪 | 从具体到迁移 | 「这个规律能抽成什么模型、用到哪些新场景？」 |
| L5 能力建设 | 我缺什么基本功 | 从事情到能力 | 「这件事暴露了我什么能力短板？怎么练？」 |

**一通百通的判断标准**：L1-L2 只解决「这一次怎么看」；L3 开始解决「下一次怎么做」；L4-L5 解决「这一类事怎么越做越好」。

**一堂自身案例 · mini 访谈的五次迭代复盘**：
- L1 感觉：一百万字，阅读效率太低
- L2 事实：分析数量，统计具体工作量
- L3 原因：排序混乱 → 全量阅读无重点
- L4 模型：增加排序规则（按学分排序，挑 top30%）→ 加雷达图 → 加 KSF
- L5 能力：mini 访谈变成标准动作，成为一堂 Top3 磨课手段

## 二、深度复盘四步法（16 字法则）

**整体逻辑**：成败认定（找差距）→ 场景还原（找事实）→ 得失分析（找原因）→ 总结提炼（找行动）。四步递进，缺一步深度就打折。

### 准备阶段：会前要做三件事

- **明确复盘目标**：这次复盘到底是为了优化决策、还是优化执行？
  - 决策复盘：当时选 A 不选 B 对不对？（用科学决策三角形）
  - 执行复盘：动作有没有做到位？流程有没有跑通？
- **确定复盘人员**：谁来参加？核心原则——在场的人 + 能拍板的人 + 关键干系人
- **提前收集材料**：目标文件、过程数据、关键节点记录、关联方反馈——会前收齐，会上不等人回忆

---

### 第一步 · 成败认定（找差距）

**这一步的目的**：定「这事到底是成是败」——找三种差距。

**三种差距类型**：

- **结果差距**：可定量指标的实现情况。比如转化率、销售额、参与人数
- **感知差距**：不可定量的反馈和感受。比如交付质量、体感、情绪
- **认知差距**：不同层级目标、不同视角的理解差异。比如老板觉得差、你觉得自己做得好——不是谁错了，是目标优先级没对齐

**两个必备动作**：

1. **整体认定**：复盘整体目标是否达成
  - 以核心目标为导向，不是分支目标
  - 以结果为导向，不是过程和时间点
  - ❌ 错误示范：「项目牛逼，大家特给力」
  - ✅ 正确示范：「项目符合预期。目标送 2000 件，实际送出 2234 件。延期 2 天，原因为疫情不可抗力。367 条正面反馈，8 条负反馈」

2. **分层目标**：按层级拆开描述
  - 拆事情：主目标 / 分支目标
  - 拆人员：老板视角 / 团队视角 / 用户视角
  - 拆时间：里程碑目标 / 最终目标

**成败认定做到位的标志**：每个关键方对「项目到底成没成」有一致的判断，不靠形容词，靠数据和锚点。

---

### 第二步 · 场景还原（找事实）

**这一步的目的**：不讨论「我觉得」，先把客观事实摆出来。

**三个核心动作**：

- **一正**：多搜集定量信息
  - 数据类（转化率、完成量、时间线）
  - 操作动作类（计划怎么做、实际怎么做）
  - 关联方反馈类（用户怎么说、团队怎么说）
- **一反**：用反方视角驳回，少自我感觉——如果有个反对者坐在这，他会怎么描述这件事？
- **一应对**：区分事实和观点——「当时 PM 说资源不够」是事实；「资源不够所以做不完」是观点

**两个还原重点**：

1. **还原执行**：计划怎么做 → 实际怎么做 → 实际结果是什么 → 扑了多少资源（人力、钱、时间）→ 少了什么就无法推进？
2. **还原决策**：当时决策的逻辑是什么？参考了哪些信息？为什么选择了 A 而不是 B？

**场景还原六问（照着问）**：

1. 什么情况下、发生了什么？背景是？谁参与了？
2. 当时决策的逻辑是什么？参考了哪些信息？
3. 为实现目标，我们采用的方法是什么？
4. 计划怎么做？实际怎么做？实际结果怎样？
5. 扑了多少资源，花了多少人力/钱？
6. 少了什么就无法推进？

---

### 第三步 · 得失分析（找原因）

**这一步的目的**：不是找到「一个原因」就停了，而是追问到「关键假设」为止。

**提炼重要发现**：

- 围绕目标挖：有哪些事实支撑差距判断？
- 搜集现场团队/用户的判断：他们归因到哪？

**拆原因找关键假设（四个追问）**：

1. 哪些事情会引起什么变化？是因果关系还是关联关系？
2. 假设 A 不存在，BCD 还会引起 E 吗？这个事还会发生吗？
3. 主客观原因有哪些？起作用的关键成功 / 失败因素是什么？
4. 假设其他因素都是最好状态，我们自己还可以做点什么能让事情做得更好？

**提问框架（围绕目标达成公式/关键要素提问）**：

- 销售复盘：到达率 × 转化率 × 客单价，哪个环节掉了？
- 项目复盘：用五步法、项目管理模型、单元模型去拆——哪个里程碑卡了？
- 课程复盘：用 OSCAR、调研框架——哪一步没做到位？

**得失分析的底线**：没数据支撑的判断，很容易被否掉。没有追问到关键假设，复盘就没深度。

---

### 第四步 · 总结提炼（找行动）

**这一步的目的**：从「这一件事」里抽出来，变成「以后这一类事」都能用的资产。

**三项认知共识（先对齐再沉淀）**：

- **成败共识**：对于项目成败，有没有共识？
- **问题共识**：做错了什么？为什么？
- **亮点共识**：做对了什么？为什么？

**三项行动计划（必须具体）**：

- **坚持做**：需要继续做什么？（成功了，下次一定要保留的动作）
- **放弃做**：需要放弃做什么？（尝试了没效果，以后别做了）
- **新任务**：需要新增做什么？（复盘发现了新坑，下次要补上）

**过程提炼 · 八类沉淀资产（从低到高）**：

1. SOP
2. 检查清单
3. 流程文档
4. 话术清单
5. 工作手册
6. XX N 步法
7. XX N 个原则
8. XX 思考框架

**到底沉淀哪种？判断规则**：
- 这事以后会重复 → SOP / 检查清单 / 流程文档
- 这事需要多人协作 → 工作手册
- 这事背后有通用规律 → N 步法 / N 个原则 / 思考框架

## 四、复盘价值判断：什么项目值得深度复盘？

**不是所有项目都值得开复盘会。用五个维度判断**：

| 维度 | 问法 | 高价值信号 |
|---|---|---|
| 重复性 | 这类工作未来会不会重复？ | 会重复 → 沉淀一次，复用 N 次 |
| 重要性 | 对公司/团队重要吗？成本投入高吗？ | 重要 → 错了代价大，对了收益大 |
| 偏差大小 | 显著成功或未达预期吗？ | 偏差大 → 背后藏着关键认知 |
| 沉淀价值 | 有方法论/SOP 可以总结吗？ | 有 → 复盘产出能变成组织资产 |
| 确定性 | 风险高/容易失败/探索型项目？ | 高不确定性 → 需要更快迭代 |

**复盘目的方向三类**：
- **成败共识型**：成功还是失败？评价标准是什么？哪部分好、哪部分差？
- **决策提升型**：目标设置合理吗？当时的选择对吗？关键里程碑有丢失吗？
- **执行提升型**：关键任务 SOP 怎么迭代？重大问题怎么解决？最佳实践怎么提炼？

## 五、复盘文化落地（12 个策略）

**文化不是要求出来的，是动作堆出来的。**

### 提升 1：以身作则
- **反向汇报**：领导先复自己的盘，让团队看到标准
- **及时复盘**：做完就复，不等「有空再说」
- **充分重视**：领导出现在复盘会上，时间投进去

### 提升 2：挂在嘴边
- **引导分析**：日常聊工作时追问「你觉得背后原因是什么？」
- **引导沉淀**：「这件事你做完，有没有可以沉淀的东西？」
- **引导行动**：「下次再遇到类似情况，你会怎么做？」

### 提升 3：提出要求
- **强制 TopN**：每次只复盘最重要的 3–5 个点，不准摊大饼
- **做 Before/After**：要求拿出修改前后的对比，不是只讲感觉
- **3 分钟复盘**：小项目也做，不限长度但必须做完

### 提升 4：做出流程
- **固定例会复盘**：周/月/季度固定在日历上
- **关键项目复盘**：重大节点结束必须立刻复盘
- **统一复盘模板**：整个团队用一套画布、一套语言

## 六、复盘常见误区（避坑清单）

- **把复盘当批斗**：追责找替罪羊 → 停。复盘是对事不对人，目标是学习不是清算
- **只定性不定量**：「整体不错，有些小问题」→ 没说任何信息。必须带数据和锚点
- **停在 L1–L2 不往深挖**：事实摆完就散会 → 错过了 L3–L5 的真正价值
- **只分析不沉淀**：原因找到了、结论也讨论出来了，但没人写下来 → 下次照样犯
- **复盘太晚**：过了两周才复盘，记忆模糊、事实丢失 → 复盘质量大打折扣
- **不一致的复盘标准**：每个人对「成败」的定义不同就开始吵 → 先做成败认定对齐

## 七、一堂自己的复盘节奏（对标最佳实践）

**周级复盘**：每周 2–3 小时，看 7–10 个关键事实，做 3–10 轮对比，挖掘 5–10 个做课原则，升级几页知识库，运气好激发出 1–2 个新基本功假设。每年 40–50 轮。

**课程 PM 复盘三件事**：
1. 磨课过程事实：每种手段花了多少时间、哪些有效哪些无效、背后逻辑是什么
2. 意外之喜：哪个动作超出计划、下次能不能固定进流程
3. 灵感萃取：提炼成显性知识，现场和团队共识

**三个核心产出**：迭代课程 → 升级知识库 → 发现新基本功。

---

**最后一句**：一个人如果有明确目标，只要足够快地复盘和迭代，最后一定能过去。复盘不是多一个动作，是你比别人快的那一倍。
