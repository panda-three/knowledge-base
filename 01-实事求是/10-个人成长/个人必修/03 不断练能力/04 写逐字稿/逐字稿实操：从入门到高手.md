# 《逐字稿实操：从入门到高手》L6 清单体笔记

> 主讲：Truman｜一堂 CEO｜前美团产品专家
> 定位：一堂表达力火箭模型·推力系统｜一堂教研「第一基本功」的实操落地课
> 核心命题：**逐字稿不是写作，本质是现场说话能力的训练工具。天底下所有演讲的准备只有两种方式——准备提纲，或者逐字稿。而同样的交付质量，口才需要练 3 个月到 3 年，逐字稿只需要练 3 个小时到 3 周。**
> Truman 原话：「逐字稿，可以改变世界。」「一堂现在的做法：直播课靠大纲稿+半逐字稿，录播课纯靠逐字稿。」

> **L6 洞察**：方向系统和动力系统解决的是「讲什么」和「怎么讲更好」，推力系统解决的是「怎么确保现场真的讲出来了」。没有推力系统，前三层筹备在紧张之下全部归零。**逐字稿是表达力火箭的「燃料固化器」——它把模糊的准备变成可执行、可彩排、可迭代的精确剧本。**

### 1.2 为什么是「第一基本功」？

在一堂内部，逐字稿被列为所有教研必须迈过的第一条基本功门槛：

```text
沟通笔记都不记，我真的不太愿意带……（总丢事情）
学习笔记都不记，我真的不敢让做教研……（总靠脑子）
逐字稿都不会写，我真的不敢让上讲台……（总靠临场）
```

**Truman 的噩梦**：

```text
我曾经做过一个噩梦，让我一身冷汗——
梦见自己站在台上讲课，但逐字稿没准备好，
一张嘴就开始语无伦次、逻辑断裂、观众纷纷走神。
醒来之后，我更加笃定：临场发挥是靠不住的。
```

> **L6 判断**：逐字稿的价值不是「让你讲得更好」，而是「让你在最紧张的时候也不会讲得太差」。它是表达的**底线保险**，也是表达的**上限杠杆**。

## 二、建立信念：五个让你无法拒绝的理由

### 2.1 「天底下所有演讲的准备只有两种方式」

```text
第一种：准备提纲
第二种：逐字稿
```

**ROI 判断**：

```text
同样的交付质量——
口才：需要练 3 个月到 3 年
逐字稿：只需要练 3 个小时到 3 周

核心是个 ROI 问题，未来 10 年你有多少重要的表达场景，要不要练，自己评估。
```

### 2.2 逐字稿的三大核心价值

| 价值 | 含义 | 适用人群 |
|---|---|---|
| **打磨基础** | 把临场发挥拉到 3 天甚至 3 个月以前，提前筹备和练习 | 所有人 |
| **表达剧本** | 把内向和不善言辞藏在心里，扮演一个善于表达的演讲者 | 不善言辞、容易紧张的人 |
| **稳定交付** | 消除不确定性，在各个场合都能稳定发挥 | 重要场合、关键场景 |

### 2.3 吐槽大会提词器事件的 L6 解读

```text
很多人以为《吐槽大会》的演员是即兴发挥，
结果发现他们都在对着提词器读稿子。

观众觉得感情被欺骗了，
但站在产品操盘手的角度，这反而极其优秀——

他们把「前期写稿创作」和「现场发挥」拆开了：
编剧负责写逐字稿，IP 负责表演呈现。
这样就可以大规模工业化复制脱口秀作品。

逐字稿的价值同理：
它让口才没那么好的人、现场发挥比较弱的人，
也能稳定交付高质量的表达产品。
```

### 2.4 五种备稿类型全景

| 类型 | 内容质量 | 细节把控 | 交付稳定 | 撰写难度 | 练习难度 | 适用场景 |
|---|---|---|---|---|---|---|
| **即兴发挥** | 低 | 无 | 无 | / | / | 闲聊、内部随口说 |
| **提前腹稿** | 低 | 弱 | 低 | 低 | 低 | 内部分享、一般会议 |
| **大纲稿** | 中 | 中 | 低 | 中 | 中 | 讲课、中等优先级 |
| **逐字稿** | 高↑ | 强↑ | 高↑ | 难↓ | 难↓ | 公开演讲、重要路演 |
| **完整逐字稿** | 最高 | 最强 | 最高 | 最难 | 最难 | 录播课、战略发布会 |

> 完整逐字稿 = 写下每一句话、每一个动作、所有停顿点、升调降调点、眼神、手部动作以及身体语言。

**这节课的目标**：提升逐字稿的价值，降低逐字稿的成本，把它变成你一个可以用、愿意用的工具。

### 3.1 逐字稿段位全景

| 段位 | 标签 | 评价 Feature | 典型用户反馈 |
|---|---|---|---|
| **60 分** | **#能听** | 有对象感 · 口语化 · 路线清晰 | 「嗯，是在跟我说话」「说人话，能听懂」「逻辑性不错，我能跟上」 |
| **70 分** | **#好听** | 语言有节奏 · 用词有讲究 · 不时有金句 | 「语言听着很舒服」「用词很准确」「这句很精彩啊」 |

**合格线定义**：

```text
合格的逐字稿 = 使用自然语言 + 有对象感 + 没有长难句 + 易理解
写优秀逐字稿的过程，就像设计一台戏剧。
```

### 3.2 L6 洞察：逐字稿 ≠ 写作，场景完全不一样

```text
写作：脑 → 手（直接把脑子里的东西写出来，照顾眼睛）
逐字稿：脑 → 口 → 手（先把脑子里的东西说出来，再写下来，照顾耳朵）

书面写作和逐字稿是两种完全不同的能力。
很多写作很好的人，第一次写逐字稿也会翻车——
因为他们的语言习惯是「书面语」，而不是「口语」。
```

## 四、实操核心：逐字稿撰写 ABC + 口语化写作四策略

### 4.1 撰写 ABC 总览

Truman 将逐字稿撰写总结为「ABC 三步法」。假设你的主题、核心内容和大纲都已经有了，专注提升表达质量：

```text
A. 培养对象感   → 想象对面坐着一个真实的用户，讲给他听
B. 避免书面语   → 用嘴写作，说人话，不该省的字不要省
C. 避免长难句   → 用句要短，避免从句、复句、倒装句
```

### 4.2 口语化写作四策略

| 策略 | 书面化特征 | 口语化做法 |
|---|---|---|
| **策略1：用口语常用词** | 「综上所述」「例如」「迅速」「立即」「从而」「连日来」「地处」「同期」 | 「总结一下」「举个例子」「很快就」「马上」「这样就」「这些天」「位置在」「同一时期」 |
| **策略2：尽量选择短句式** | 复杂长句、从句、复句、倒装句 | 短句。一句话只说一件事。避免从句和倒装 |
| **策略3：增加语气词/插入语** | 避免 | 丰富：「尤其是」「特别是」「请注意」「你看」「感觉怎么样」「好啊」「很赞啊」「哈哈」 |
| **策略4：照顾的器官不一样** | 照顾眼睛（阅读） | 照顾耳朵（听）——信息必须一次过，无法回看 |

### 4.3 口语化写作具体技巧清单

| 分类 | 技巧 | 具体操作 |
|---|---|---|
| **培养对象感** | 想象对面坐着一个真实的用户 | 讲给他听。得到 APP 的逐字稿就是标杆 |
| **避免书面语** | 用嘴写作，不该省的字不要省 | 「综上所述」→「总结一下」；「例如」→「举个例子」；少用修饰语，尽量不用定语、状语和补语；尽量不用并列名词 |
| **避免长难句** | 用句要短 | 一句话只说一件事。避免从句、复句、倒装句 |
| **增加插入语** | 四类插入语组合使用 | ① 多用专有名词（人名、地名、事物——唤起画面感）；② 用插入语引导听众感受（「尤其是」「特别是」「请注意」「你看」「感觉怎么样」）；③ 用表逻辑关系的词增加框架感（「首先」「然后」「接下来」「最后」「总之」）；④ 用语气词让语言更生动（「好啊」「很赞啊」「哈哈」「这是什么意思呢」） |

### 4.4 刻意练习口诀

```text
练习从「脑→手」到「脑→口→手」的写作模式切换。

平时的书面写作：脑→手，直接把脑子里想的写出来
逐字稿的写法：先说出来，再写下来。

改逐字稿，需要培养逐字稿的语感——
读完以后大声念一遍，耳朵不舒服的地方就是需要改的地方。
```

## 七、执行难题：要不要背？忘词了怎么办？

### 7.1 两大派别之争

```text
A 派：当然要背诵！不然写逐字稿还有什么意义？
B 派：不要背诵！你的全部注意力都在背稿子上，怎么可能生动？
```

### 7.2 Truman 的答案：三种执行策略

| 策略 | 记住度 | 临场发挥 | 执行方式 | 建议场景 |
|---|---|---|---|---|
| **方法一：疯狂背诵彩排** | 100% | 0 | 全文背诵，逐字逐句。反复彩排直到游刃有余 | 极其重要的演讲/课程（发布会、录播课） |
| **方法二：只记重点内容** | 50% | 50% | 重点记忆开篇、核心观点、结束语、包袱、严谨数据 | 讲课等中等优先级 |
| **方法三：只记主线逻辑** | 20% | 80% | 只记大纲和重要句子，其他忘掉，现场发挥 | 内部等非重要场合 |

### 7.3 不全文背诵时，必须记住的五类内容

```text
最开篇的介绍：别上来就临场发挥或者忘词儿
最关键的几句话：最核心的卖点，重复的观点、印象深刻的论点
最后结尾的结束语：一个有仪式感或者让人印象深刻的结束语很重要
一些抖包袱的地方：预留的段子和活跃氛围的话
一些需要严谨的地方：数据和事实，要记清楚，不能讲错
```

### 7.4 现场忘词了的解法

```text
充分练习：大量练习，直到熟练，游刃有余
只记大纲：只提醒大纲和重要句子，其他逐字稿忘掉，现场发挥

关键心态：
逐字稿只是个工具，不要迷信，主动权在你，更不要被困在里面。
如果完全生硬背稿子，可能还不如没有逐字稿。

马克·吐温说：世界上只有两种演讲者——紧张的和假装不紧张的。
```

## 八、现场表达 Checklist

当逐字稿写完了、彩排好了，站上舞台后：

| 关键项 | 核心要点 |
|---|---|
| **对象感** | 你是面对观众讲故事/介绍项目，而不是读一遍 PPT |
| **自信** | 保持自信，相信自己和项目，感染场上氛围 |
| **声音** | 声音适当放大，很自信笃定地介绍自己的项目 |
| **眼神** | 不要游离或者盯紧 PPT，和观众有眼神交流，最好循环环视大家 |
| **语速** | 建议语速适当快，同时适当留白，控制一下表达节奏 |
| **插入语** | 可以加入一些承上启下的过渡，提升表达的逻辑性和前后衔接 |

## 九、一堂内部：逐字稿的团队刻意练习体系

这是整节课最稀缺的内容——Truman 罕见地打开了一堂内部如何训练教研团队逐字稿能力的完整体系。

### 9.1 四个阶段的进化

| 阶段 | 问题 | 解法 |
|---|---|---|
| **第一阶段：认知混乱** | 大家写的五花八门，合格率极低。Truman 几乎每一篇都得重新敲一遍 | Truman 反复宣贯本质：「逐字稿不是写文档/不是写作，而是一个优秀老师在台上讲课的表达文稿」 |
| **第二阶段：建立段位图** | 有意识了但进步太慢 | 建了两个版本段位图——前者认知很糙，后者有完整技巧和 Tips。终于能回答「糟糕的、合格的、优秀的逐字稿到底什么样子」 |
| **第三阶段：设计专项练习** | 新人上手困难，老人没时间辅导 | ① 拆经典课：找成熟度很高的课程，反向拆解亮点和策略，标记 30-50 条；② Landing 任务：新人写一篇小逐字稿，拉满→Mentor 反馈→再拉满写一轮 |
| **第四阶段：嵌入每周循环** | 训练和反馈次数太少 | 在每周课题研究循环中全面渗透逐字稿练习（见下一节） |

### 9.2 逐字稿在每周教研循环中的十大渗透点

```text
热身阶段      鼓励拆解老课，理解课程主旨、教学框架和教学耐心
交叉评审      多人协作，彼此交叉评审
分工协作      让更多人参与到局部撰写，增加练习机会
桌下练习      鼓励不是自己的课，也写一段作为练习参照
自我对比      每周会复盘 20-30 个点，做 Before/After 对比学习
Truman 点评   会再次回顾和强调逐字稿的撰写要点和教学追求
高价值练习    不断在下一周对比上周迭代的版本
```

> **练习密度**：到这个阶段，逐字稿基本上每个人平均每月都可以练 **20-30 次**，这个频率显著提升了大家的学习速度和交付质量。

### 9.3 L6 洞察：一堂 50% 以上的精力花在了基本功训练上

```text
Truman：大家现在应该知道在一堂，我 50% 以上的精力花在哪儿了。

这只是一堂一个几乎最小、最简单的基本功——
如果每一个基本功都速度提升 5 倍，意识提升 3 倍，
一年下来，会有多大的显著差异？

这就是学习型组织和普通公司的差距：
不是多上几节课，而是把基本功的刻意练习渗透到每周的工作循环里。
```

你的工作场景中——

## 十一、五个 L6 级洞察

### 洞察一：「逐字稿不是写作，是现场说话能力的训练工具」

```text
这是整节课最核心的认知纠偏。

很多人写逐字稿失败，不是因为文笔不好，
而是因为他们一直在「写文章」而不是「写说话」。

关键区分：
写作 = 脑→手（照顾眼睛，允许回看和重读）
逐字稿 = 脑→口→手（照顾耳朵，信息必须一次过）

一旦你理解了「逐字稿服务的是耳朵而不是眼睛」，
你的用词、句长、节奏、插入语都会自然改变。
```

### 洞察二：「逐字稿把临场发挥的不确定性降到了最低」

```text
闲聊的时候你可以连续讲好几个小时。
但做分享的时候：
- 你要考虑逻辑
- 你要考虑语速快慢
- 你要考虑听众是否理解你所说的话

临场发挥是靠不住的。
逐字稿的价值，就是让你在最紧张的时候，
也不会比你的「平均准备水平」差太多。
```

### 洞察三：「同样的内容 × 不同的表达 = 十倍差距」

```text
很多人都花了大量时间在「想内容」上，
但很少有人花同样多的时间在「打磨表达」上。

内容是「讲什么」，逐字稿是「怎么讲」。
同样的核心观点——
一个人靠临场发挥讲了 3 分钟，逻辑乱、没金句、没张力；
另一个人用逐字稿打磨了 3 小时，逻辑紧、有节奏、有升华。

观众感受到的差距是 10 倍，但内容本身的差距可能是 0。
这就是逐字稿的杠杆效应。
```

### 洞察四：「第一基本功」的真正含义——逐字稿是表达力的刻意练习最小单元

```text
在所有的表达力基本功中，逐字稿是最适合刻意练习的：

轻量级——一个人、一台电脑就能练
独立可完成——不依赖任何别人、任何条件
极高频——每次要公开说话之前都可以练
反馈来源多——自我 BA 对比、他人评审、现场效果反馈
天花板极高——从 60 分到 70 分到 85 分到无限逼近 100 分
```

### 洞察五：「逐字稿工业化」是学习型组织的核心竞争力

```text
吐槽大会的工业化：
编剧写逐字稿（创作环节）+ IP 对着提词器表演（表达环节）
= 不依赖单一明星的临场状态，稳定量产高质量内容

一堂的工业化：
教研写逐字稿（创作环节）+ Truman/讲师录制（表达环节）
= 每一节课的信息密度、逻辑清晰度、表达质量都稳定在 85 分以上

这就是 Truman 说的：「逐字稿，可以改变世界。」
因为它让高质量表达从「个人天赋」变成了「组织能力」。
```

## 十二、L6 自检清单：你的逐字稿能力在第几层？

### 关于认知

1. 你过去以为「逐字稿」是什么？听完这节课后，你的理解有没有改变？
2. 你能不能区分「即兴发挥 / 腹稿 / 大纲稿 / 逐字稿 / 完整逐字稿」五种类型？你现在最常用的是哪一种？

### 关于审美

3. 你见过真正好的逐字稿吗？有没有拆解过一堂课程的逐字稿？
4. 你现在写的逐字稿，自己判断在哪个段位？60 分（能听）？70 分（好听）？还是 85 分（入戏）？

### 关于口语化

5. 你的逐字稿里还有「综上所述」「从而」「连日来」这类书面语吗？
6. 你写完逐字稿之后，会大声念一遍吗？耳朵告诉你哪里不舒服？
7. 你的句子够短吗？有没有超过 20 个字的长难句？

### 关于逻辑和张力

8. 你的逐字稿用了哪条逻辑线？是只有一条，还是组合使用了多条？
9. 你的逐字稿里有多少个张力技巧？是 0 个、3 个还是 10 个以上？
10. 你有没有在「最关键的几句话」上花最多的时间打磨？

### 关于执行

11. 你的重要表达场合，现在用什么策略？100% 背诵 / 50% 重点记忆 / 20% 主线逻辑？
12. 你上一次彩排逐字稿，彩排了几遍？有没有录像回看自己的表现？

### 关于刻意练习

13. 你有没有建一个「最佳实践逐字稿池子」，收集你认为写得好的逐字稿范例？
14. 你准备如何把逐字稿练成基本功？每周练几次？每次怎么拿反馈？
