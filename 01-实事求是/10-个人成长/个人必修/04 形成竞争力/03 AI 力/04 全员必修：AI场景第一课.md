# 课程：AI场景第一课·全员必修

**一句话结论：** 别再拿着AI工具到处找钉子——先用 STAR 矩阵（个人/组织 × 上限/下限）给场景分类，再按 A→S→R→T 从改自己的苦活做起，用10年心态积累"哪里值得用AI"的判断力。

---

## 一、核心交付

- 一个认知：工具优先→场景优先，用"场景假设"驱动AI工作
- 一张地图：STAR矩阵四象限（S探索/T变革/A提速/R落地）
- 四个角色比喻：A=实习生、S=合伙人、R=新员工、T=一张大牌
- 一套落地心法：R落地三关（找真场景→拆小场景→做减法）
- 一个十年观：提升下限享受现在，提升上限拥有未来

## 四、关键框架：STAR矩阵（截图06-08）

### 4.1 三步推导过程

| 步骤 | 内容 |
|---|---|
| 第一步：定坐标轴 | 数百案例爆炸式研究后，两个最本质分类角度：①个人/组织（对自己vs对团队公司）②下限/上限（已有能力提效vs探索新机会扩边界） |
| 第二步：填四象限 | 探索=兴奋突破；变革=终局预判；提速=痛苦优化；落地=降本增效 |
| 第三步：加远端追求 | 每象限最远端锁定一个关键词，作为最终牵引 |
| 记忆锚点 | 从上往下、从左往右，四象限英文名拼成 STAR |

### 4.2 STAR矩阵总览（坐标轴：横轴个人/组织，纵轴上限/下限）

```
                 上限 ↑
        ┌─────────────────┬─────────────────┐
  个    │ S 探索场景       │ T 变革场景       │
  人    │ Seek 兴奋突破    │ Transform 终局预判│
  │     │ 远端：人生红点    │ 远端：使命愿景    │
  ├─────┼─────────────────┼─────────────────┤
  组    │ A 提速场景       │ R 落地场景       │
  织    │ Accelerate 痛苦优化│ ROI 降本增效    │
        │ 远端：时间倍增    │ 远端：提升利润    │
        └─────────────────┴─────────────────┘
                 下限 ↓
```

| 象限 | 位置 | 英文名 | 性质 | 远端追求 |
|---|---|---|---|---|
| S 探索 | 个人+上限 | Seek | 兴奋突破 | 人生红点 |
| T 变革 | 组织+上限 | Transform | 终局预判 | 使命愿景 |
| A 提速 | 个人+下限 | Accelerate | 痛苦优化 | 时间倍增 |
| R 落地 | 组织+下限 | ROI | 降本增效 | 提升利润 |

> 底部核心句：用10年心态探索构建AI场景；提升下限让我们享受现在，提升上限让我们拥有未来。

### 4.3 运用与心法（截图08）

- A是通常起点：从改造自己已有的、重复痛苦的工作开始
- T是理想终点：带领组织完成AI变革，形成行业竞争力
- 进步路径：按 ASRT 或 ARST 持续前进——短期→长期、下限→上限、个人→组织
- 长期只停"下限"→陷入单纯效率和"内卷"，失去未来
- 长期空谈"上限"→陷入美好幻觉和"好高骛远"，失去根基
- 现场挑战：每个象限想3-10个潜在高质量场景假设

## 五、A 提速场景（个人+下限）（截图09）

### 5.1 快速认识

- 定位：个人使用起点，找日常里基础、花时间、痛苦枯燥的工作
- 判断标准：无法回退——不让你用AI，回退会非常疼、非常痛苦
- 目标：解放低质量时间，时间倍增，去思考更值钱的问题

### 5.2 个人案例

| 同学 | 场景 | 做法与结果 |
|---|---|---|
| 朱琦 | 内容采集筛选 | n8n从Reddit自动采集到Notion，自动评分分类，每天只过精选 |
| 张同学 | 给老板做VIP新闻订阅器 | 多维表格配置关键词+AI总结提炼，每条简讯≤50字、分类/日期/内容/倒序编号 |
| 黄欢 | 专利分析 | COZE+多维表格：PDF读取→专利信息提取→写入表格，替代人工低效高门槛分析 |
| 徐里 | 共享办公抢工位 | 影刀RPA：开网页→输账号密码→"获取当前日期+格式化日期"变量→发版→每天6点定时自动订座 |

- 另8个同类案例：Gamma做内训PPT省60%；AI每天分析200条爆款视频；设计图1周→2天；Coze把教学视频转讲义；10倍速阅读10分钟出视觉笔记；学术日报自动化；10分钟搞定孩子短视频脚本；语音工单群消息汇总后获领导认可

### 5.3 A场景是"实习生"

| 关键词 | 含义 |
|---|---|
| 顶尖名校 | 很聪明、学东西快、记忆力好 |
| 无经验 | 需你给任务、给足够上下文引导 |
| 24小时 | 7×24待命，可无休工作 |
| 无薪 | 成本可忽略，可同时调10-100个 |

- 心态调整：别嫌基础琐碎不好意思用AI；AI没情绪，随便用
- 落点：找"经常让你叹气、经常复制粘贴"的痛苦工作

## 六、S 探索场景（个人+上限）（截图10-11）

### 6.1 快速认识

- 定位：不是"会做不想做"，而是探索新的能力边界
- 判断标准：两三年前你完全不会、甚至不敢想自己能做到这个水平
- 价值：AI不替代，而是"催化"——把半成品灵感变成完整高水平作品

### 6.3 S场景是"合伙人"

| 关键词 | 含义 |
|---|---|
| 合伙人 | 不再替你做事，而是互补、各有所长、深度合作 |

- 阶段任务：补长板、满足兴奋点，而非补短板
- 核心策略：短期靠兴奋感，长期靠人生红点

## 七、R 落地场景（组织+下限）（截图12）

### 7.1 快速认识

- 定位：公司内部AI落地；难度阻力瞬间倍增（多人协作、共识、准确度要求、旧习惯）
- 判断标准：大幅提升效率/收入/利润，很难回退，且能激励团队用AI

### 7.2 组织案例

| 案例 | 背景卡点 | 做法 | 结果 |
|---|---|---|---|
| 赵飞律师 | 资深律师忙、新手接待易丢单，经验难复制 | DeepSeek搭"高度优化提词器"，封装资深律师沟通逻辑；拆4环节工作流 | 已跟进10客户；客户以为"远超三年经验律师"；2-4h→1-1.5h；方案通过率90%+；重大问题仍由资深合伙人把关 |

> 四环节工作流（赵飞）：①事实梳理与问题定位 ②法律分析与风险评级 ③行动策略规划 ④沟通辅助与模拟。

### 7.3 概率性 vs 确定性

| 类型 | 擅长 | 结果要求 |
|---|---|---|
| AI大模型 | 概率性：总结、判断、创造 | 不必100%准确 |
| RPA机器人 | 确定性：打开浏览器、点击、填表、流程 | 必须100%准确 |

- AI弱点：执行确定性多步流程成功率下降——每步99%，20步后只剩82%
- 祛魅：别拿AI锤子到处找钉子；很多确定性场景里 RPA+AI 比纯AI Agent更落地

### 7.4 组织侧其他案例（8个）

- 家装设计方案AI辅助，减70%工作量；仓储验货照片AI自动整理判质检
- Agent做软件开发需求排期前检查；AI+RPA自动填保险保单
- 拟合电商竞争板块指数函数，年省至少6万；AI识别+多维表格帮船厂录入减一半工作量
- 消防检查AI读照片自动填表；在线教育AI自动批改作业生成报告，老师变导师

### 7.5 R场景是"新员工"

| 关键词 | 含义 |
|---|---|
| 员工 | 不是单纯工具，是能自己分析、自己解决问题的"虚拟员工" |
| 新 | 新加入公司，没上下文，要给足信息才上手 |
| 潜力很好 | 非常勤奋努力，可7×24支持 |
| 独特工作习惯 | 和人不同，需用AI的思维方式和工作流 |

### 7.6 R落地三关（重点）

**第一关：找真实场景——结果导向，真实交付价值**

- 忌：为练习做爆款视频/AI写PRD/做调研，做一堆"玩具"
- 要：带明确业务目标去分析，务实交付真实高价值

**第二关：太大了——先找第一个"关键小场景"**

- 误区：把AI当成熟黑盒，期待"一键输入、完美输出"
- 成功标志：真实有用、难以回退、建立信心、启动循环
- 方法：拆业务卡点，往往剥离到 2-3-4 甚至 5 层才够小
- 剥离示例：
  - "通用爆款脚本Agent"→只做素材投放类→拆节点→只解决"匹配10个idea"
  - "合同审核AI"→"某一类合同事实性校对"，效果就好
  - "绩效AI助理"→"绩效收集和沟通填表多轮对话"，效果就好
  - "AI诊断助手"→"替换手工填表/手写表AI自动录入"，微调后准确度高
  - "AI做课产品经理"→"给录音稿+知识点清单+对标参考写逐字稿初稿"，省50-80%时间
- 选象限：努力找"能拆得细 & 过去足够懂"的组合，最容易落地

**第三关：专业做减法——定优先级**

- 复习一堂科学决策三角形：宽度=关键收益项/关键成本项；高度=长期视角/公司视角/机会成本/时间窗口
- 复利逻辑：原来成本越高、越高频、越难复制，AI化价值越高
- 两个特别关键的参数：

| 参数 | 说明 | 例子 |
|---|---|---|
| 容错性 | 业务对错误的容忍度 | 写文案/做策划容错高；精准控制、大客户VIP客服、医疗诊断容错极低，需大量AB测试 |
| 数据可行性 | 是否有足够上下文、专家知识、标注优质数据 | 要建"AI数据闭环"：能持续生产数据、喂给AI、按结果调整 |

## 八、T 变革场景（组织+上限）（截图13）

### 8.1 快速认识

- Transform 义为"使彻底改观、使大变样"
- 不只是降本增效提利润，而是用AI提升上限、做之前人做不到的量级和新产品
- 这是一号位工程——一号位不笃定，很难推动落地

### 8.2 重磅案例一：文兜（投标服务公司AI转型）

| 维度 | 内容 |
|---|---|
| 主角 | 文兜，年营收几千万的投标服务公司；CEO葛佳音（一堂MBA学员） |
| 原有壁垒 | 行业权威文库"采购文件网"，10万+投标方案、100万+行业资料；"想中标，找文兜" |
| 转型动因 | 个性化标书人力成本将越来越高，传统标书业务将被AI颠覆的危机感 |
| 内部阻力 | 主营业务还在增长却启动AI；老业绩下滑；最夸张一天离职6人 |
| 三大核心功能 | 文兜智写（一键解析招标文件、图文生成标书）/ 标书扩写 / 标书检查（抓错别字格式） |
| 商业模型 | ToC按字1万字6元；ToB包年4999元；大企业私有化部署10万起 |
| 结果 | 新业务一年千万级营收；客服70%工作被解放、没被裁反而涨薪去"教客户用AI"；文案转AI产品经理、技术转AI工程师 |
| 组织动作 | 智能体创新小组、AI研究院、全员AI创新大赛发现金；版本V1.0(2023.8)→V8.0(2025.11) |

### 8.3 重磅案例二：杏树林（医疗AI转型）

| 维度 | 内容 |
|---|---|
| 主角 | 杏树林，医疗领域十多年、上百员工、年营收几个亿，ToC+ToB |
| 难点 | "高速行驶中换轮子"，保增长同时完成AI化 |
| 起步 | 2023.4 GPT4爆火，张遇升、刘辰辉亲自带队成立GPT解决方案小组 |
| 早期曲折 | 全员推工具无人用；医患ChatBox内部效果一般；2023年底才拿下第一笔AI商业订单（医药销售团队AI知识库） |
| 数据底气 | 国内最大、超2000万份医疗疑难杂症数据；认知"供给侧越稀缺，AI释放价值越大" |
| 2024选择 | 顶住"医疗垂类大模型"风口诱惑，继续深入药企大客户拿订单 |
| 转折点 | 内部智能体突破 + 2025 DeepSeek发布，客户主动上门 |
| 全员唤醒 | 高管AI培训"掀翻各部门底裤"现场演示；创始人与每位高管1V1；今年7月战略会宣布1-2年成为AI驱动公司 |
| 愿景 | 参考美国Tempus AI，可能更名"杏树林AI"；期待推动"医疗平权" |

### 8.4 组织侧其他案例（6个）

- 处理15TB数据、上千个商业标签标注，拿全国高质量数据集证书
- 万人软件公司工程师全栈化，生产力提升2-3倍、部分5倍
- 深度用AI做方案、做战略咨询，持续提升各行业ROI
- 教育公司为每位学员生成学习路径与反馈，"千人千面"建数据闭环壁垒
- 跨境电商团队不擅文案，全外包AI写专利/SEO/上架文案
- 从组织黑客松到AI创业，推动技术平权、打破行业信息孤岛

### 8.5 T场景是"一张大牌"

| 关键词 | 含义 |
|---|---|
| 大牌 | 不是几个实习生、一个员工，而是综合能力 |
| 宏大商业目标 | 组织视角，足够大的生意才需要 |
| 竞争 | 能不能和同行拉开身位、领先身位 |
| 胜负手 | 决定成败、战略级别的选项 |

- 心法：从终局倒推，找一找能力和快速变化机会
- 10倍质变判断：前端价值侧/后端成本侧，哪一环能被AI放大10倍甚至100倍？
- 例子：游戏NPC/情节千人千面实时生成；"实时语音互动教学"把课程变个性化实时版本

## 十、总结：上升两层看全景（截图14）

### 10.1 远端追求与四象限的连接

| 远端追求 | 连接象限 | 提醒 |
|---|---|---|
| 人生红点 | S | AI兴奋突破应与核心热情一致，避免盲目追热点 |
| 使命愿景 | T | AI能力构建必须服务长期战略 |
| 时间倍增 | A | 首先解决时间成本和效率瓶颈 |
| 提升利润 | R | 能力封装最终要导向商业价值与市场回报 |

### 10.2 动态平衡四条

1. 今天的上限，可能成为明天的下限
2. 今天的个人提效，可能成为明天的组织提效
3. 今天的时间倍增，才能更好实现人生红点
4. 今天的利润提升，更有机会达成使命愿景

### 10.3 上升一层：双三角模型

- AI三角：创造力（理解底层规律、解放思想、提出创造假设）+ 场景（业务拆解、ROI预判、AI打磨、组织部署）
- 飞轮：人变强→调教更强AI→有强AI辅助人变强→持续迭代
- 人类三角四能力：审美 / 体系 / 基本功 / 数据

### 10.4 再上一层：MUSE全景图 + 基本功全地图

- MUSE四层：M奇迹层 / U使用层 / S创业层 / E变革层
- 基本功全地图归宿：个人地图（核心=天花板）、管理地图（核心=段位）、创业地图（核心=概率）
- 最终都归到：个人人生红点 + 业务使命愿景
