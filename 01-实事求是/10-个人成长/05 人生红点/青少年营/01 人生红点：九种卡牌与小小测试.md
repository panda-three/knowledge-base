# 课程：红点九卡牌·青少年营

**一句话结论：** 九种人生红点卡牌没有对错，只有"动了一下"的那一种才是你的线索；答案不在老师这儿，在你身上。

---

## 一、九种红点卡牌速查

| 编号 | 类型 | 关键词 | 信奉信条 |
|---|---|---|---|
| 01 | 生活型·安顿 | 家人最重要 | 老婆孩子热炕头；出门是谋生，回家才是生活 |
| 02 | 体验型·探索 | 世界是游乐场 | 世界那么大我想去看看；诗和远方 |
| 03 | 过程型·沉浸 | 与谁同行 | 要和最优秀的人共事；目的地不重要 |
| 04 | 内心型·自洽 | 朝闻道 | 想持续搞明白世界底层逻辑；内心充盈 |
| 05 | 高手型·极致 | 十年磨一剑 | 匠人精神，成为顶尖高手 |
| 06 | 赚钱型·财富 | 财务自由 | 赚到钱就是正义；终极自由 |
| 07 | 出名型·认可 | 被看见 | 出名要趁早；走在街上被认出来 |
| 08 | 作品型·创造 | 留下痕迹 | 用作品证明我来过；几十年后仍有影响 |
| 09 | 成就型·巅峰 | 改变世界 | 你能为别人创造多大价值就有多大价值 |

## 二、小小测试：8题·4维度

> 准备纸笔，诚实作答。"动了一下"的地方就是今天最大收获。

| 维度 | 题号 | 提问 | 提示 |
|---|---|---|---|
| **追·问过往** | 01 | 你主动做的最重要决定是什么？ | 不是别人帮选的 |
| | 02 | 做什么事会完全忘了时间？ | 那种忘记时间的感觉 |
| | 03 | 做什么事你特别抗拒烦躁？ | 讨厌的比喜欢的更能告诉你你是谁 |
| **补·问未来** | 04 | 你羡慕谁的生活状态？ | 羡慕他身上的到底是什么 |
| | 05 | 没人评价你，你最想成为什么样？ | 真正憧憬什么 |
| | 06 | 你完美的一天从早到晚怎么过？ | 不用考虑别人怎么看 |
| **转·问抽象** | 07 | 前面所有内容里有没有反复出现的词？ | 属于你的小火苗 |
| **合·问取舍** | 08 | 九种红点里哪几种绝对不是你？ | 排除有时比选择更准 |
