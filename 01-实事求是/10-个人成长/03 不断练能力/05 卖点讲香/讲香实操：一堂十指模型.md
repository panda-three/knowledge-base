# 课程：十指讲香模型·实操

> 主讲：一堂教研专家 / 案例中心负责人（2020年加入一堂，2022年转入教研；业务公式系列、转化率系列、需求实操系列等核心方法论课程背后的PM；挖掘主笔过秦鹏物联网芯片、大表哥低成本创业、何发萝卜干、杜金科棋牌室等案例课）
> 定位：面向所有需要对外交付价值的人的表达基本功；非只写营销文案的课
> 集体成果：本课是一堂团队集体打磨的产物

**一句话结论：** 把产品打磨得有价值是本分，把产品呈现得有价值感是本事——用十指模型（5具象向下压+5抽象向上抬）把干巴巴的价值点一遍遍改到饱满动人。

## 一、为什么要学讲香（截图00-03）

### 1.1 三个尴尬场景（截图01）

| 场景 | 对方反应 |
|---|---|
| 销售介绍完功能参数价格 | 客户："好的我看看" |
| 会上讲半小时新方法 | 底下人低头，眼神写着"又要折腾了" |
| 面试讲清公司前景 | 候选人去了别家，评价"你们公司听起来挺普通的" |

- 共同诊断：手里的东西值80分，开口一讲只值30分
- 反复发生=明显工作缺失：**价值点找对了，但价值感没做出来**

### 1.2 核心命题（截图01）

- 方太原话："做好产品是本分，做好营销是本事"
- 一堂改写：**把产品打磨得有价值，是本分；把产品呈现得有价值感，是本事**
- 食材比喻：卖点/产品内核像顶级食材，不能直接端给用户，得加工烹饪才成美食（配图：生肉食材 vs 摆盘餐食对比图，水印"周凯说科技"）
- 课程沿革：两年前先有《讲香必修课》（聚焦讲实在产品）；时隔两年升级为面向所有对外交付价值者的基本功

### 1.3 讲香不只发生在营销岗（截图00）

- 做产品：让用户理解"为什么值得选"
- 做销售：让客户相信"为什么值得买"
- 做汇报：让老板愿意投资源
- 做招聘：让候选人愿意投入几年
- 做内容：让人愿意停下来听、听完记住认同、最好行动

### 1.4 预热思考题（截图02）

- 题1：挑一件正在做的真实任务，先用一句朴素话写核心价值，再想怎么讲给不了解的人——能写3条、5条还是10条策略？有逻辑吗？
- 题2：假设你是一堂教研负责人，3-5分钟录短视频讲一堂"很成体系"，你会怎么讲？

## 二、建立审美：两个主案例（截图04-07）

### 2.1 审美训练的意义

- 类比：学耳机测评要先能"听出好坏"，木耳朵分不清20块和800块耳机就入不了门（配图：20块白色有线耳机 vs 舒尔高端入耳式耳机对比图）
- 打分制贯穿全程：40没听懂 / 60有点兴趣 / 80很感兴趣 / 90特别想要 / 100再贵都想要

### 2.2 主案例一：天幕阳台（谢文超的业务）

- 背景：服务家里有大阳台的业主，早期线下会销为主

### 2.3 主案例二：一堂CLI 三个版本

| 版本 | 讲法 | 停留层级 |
|---|---|---|
| v1 技术黑话版 | 通过CLI与MCP协议，向外部Agent暴露知识资产与Partner能力；数据包和Partner调用完成加载、匹配、编排、执行；上下文接入、能力路由、结果生成 | 它怎么搭（协议/Agent/编排/能力路由），没技术背景听不懂 |
| v2 功能版 | 让Codex这类AI连接一堂资料库和AI Partner；读取方法论笔记材料作为上下文参与任务 | 它能做什么，大概懂了但想象不到明天在哪件事上用 |
| v3 万能插座版 | "知识资产的万能插座"：把课程方法论/资料库/笔记/作业打包成标准数据包，外部Agent一插就不再是白纸 | 它让你在什么时刻少费什么劲、得到什么变化、变成什么生产力 |

- v3痛点开场：每次用AI都要重新复制粘贴上下文，Agent不认识你的历史
- v3三大场景：

| 场景组 | 具体用法 |
|---|---|
| 自由调用数据包 | 说"去一堂学双三角帮我复盘"；"找五步法画布放PPT"；"拿阻力对抗小抄看下属方案盲区" |
| 直接操作YAI | 调清单体笔记专家转清单体；带上下文跟人生红点诊断Partner聊完拿报告；甩会议纪要给讲香Partner变演讲稿 |
| 自动化串任务 | 读作业笔记找精益创业故事→五步法整理框架→讲香Partner变成分享稿 |

- v3本质：提供商业/管理领域几乎最高质量的科学体系和上下文
- 三版差的就是：**把价值讲出来的能力**

## 三、背后框架（截图08-10）

### 3.1 讲香影响的四个结果

| # | 结果 | 含义 |
|---|---|---|
| 1 | 提升注意力 | 没重点没画面没张力，受众根本不会继续看 |
| 2 | 提升转化率 | 让对方真正感到"这和我有关，值得现在做决定" |
| 3 | 提升价格溢价 | 同样能力被讲得可见可信，用户才接受更高价格 |
| 4 | 提升品牌信任 | 反复感到这个品牌懂我在意什么、值得长期选 |

### 3.2 讲香的范围（三维度）

| 维度 | 范围 |
|---|---|
| 岗位 | 个人IP（观点经历专业被关注）/ CEO（方向战略愿景被相信）/ 产品运营（方案价值被使用）/ 销售谈判（合作被推进） |
| 场景 | 面向用户（产品页/获客宣讲/成交沟通）/ 面向公众（产品故事/品牌故事）/ 面向内部（招聘/向上汇报/跨部门协作项目） |
| 交付物 | 图文组合（招募文案/私信/BP/PPT）/ 长篇内容（详情页/落地页/短视频）/ 深度沟通（面试/电销/会销/直播）/ 公开宣讲（课程/启动会/发布会逐字稿） |

### 3.3 到底什么叫"香"：1拆2

- 旧版两大毛病：不够具体（使用/场景/价值/体验没讲）+ 不够抽象（理念/价值/意义没讲）
- 两条路径：
  - **向下做具体**：把抽象朴素干巴巴的表达，压到真实生活、真实事实、真实体验
  - **向上拉价值**：把平淡碎片化无记忆点的表达，拉到更值得在意的价值与意义
- [配图：训练目标图——横轴"朴素平淡"，纵轴"具体/抽象"；黄线=日常平淡表达，绿线=努力讲香]
- 两手配合才完整：只向下不向上→"你说的我都懂，但这东西有什么了不起"；只向上不向下→"听起来很厉害，但跟我有什么关系"

### 3.4 十指模型工具箱（2拆10）

| 方向 | 手指 | 一句话 |
|---|---|---|
| 向下具象 | ①场景化 | 代入具体的场景讲香 |
| 向下具象 | ②口语化 | 用直白的语言来讲香 |
| 向下具象 | ③数字化 | 用关键的数字来讲香 |
| 向下具象 | ④故事化 | 用讲故事的方式讲香 |
| 向下具象 | ⑤素材化 | 用一些具体素材讲香 |
| 向上抽象 | ⑥比喻化 | 用比喻构建锚点讲香 |
| 向上抽象 | ⑦情绪化 | 唤起客户情绪来讲香 |
| 向上抽象 | ⑧金句化 | 给精彩的金句来讲香 |
| 向上抽象 | ⑨冲突化 | 寻找反差对立来讲香 |
| 向上抽象 | ⑩升华化 | 提升价值维度来讲香 |

- 数据来源：300+各类案例、一堂最近2年刻意练习；覆盖90-95%常用策略

### 3.5 两个规律

- 规律一：具象侧=回到已发生的事实（有什么场景/数字/故事/素材）；抽象侧=主动创造表达（它像什么/唤起什么情绪/给出什么判断/有什么反差/落到什么意义）
- 规律二：循序渐进、组合使用——修炼路径（2拆4）：

| 阶段 | 手指组合 | 解决什么 |
|---|---|---|
| 👍基础上手（介绍能听懂） | 场景化 + 比喻化 | 让人先听进去、听得懂："这和我有什么关系" |
| 👍打动加强（流量短视频） | 口语化 + 情绪化 | 从"我知道了"推成"这件事我在意" |
| 👍强化信任（建立产品信任） | 数字化 + 金句化 | 从"和我有关"走到"愿意相信" |
| 👍无限进步（顶级故事/演讲/发布会） | 故事化 + 素材化 + 冲突化 + 升华化 | 觉得没过程就补故事、张力不够补冲突、还不信补素材、结尾没落点再升华 |

### 3.6 AI协作四层级

| 层级 | 做法 | 效果 |
|---|---|---|
| L1 | 扔稿给AI"帮我讲香一下" | 改出热闹句子但质量不可控，AI不知道你觉得哪不够香 |
| L2 | 指方向："这段太抽象，加点具体" / "这段太平，把价值拉高" | 效果好一些 |
| L3 | 指定位置+策略："开头场景化，中间数字化证据，结尾升华收束" | AI不再猜"什么叫讲香" |
| L4 | 指定手指+子策略 | AI拿到明确场景/价值/策略/材料/位置/目标，改写质量明显提高 |

### 3.7 三大原则

| 原则 | 内容 |
|---|---|
| 卖点优先 | 讲香是微观战术，服务动力阻力假设和品牌商业定位；不回答"讲什么"只回答"怎么讲"；讲香不能把错误讲正确 |
| 持续修改 | 好的表达都是一遍遍改出来的（酝酿式打磨）；从干瘪一点点加口语化/金句/素材；别期待一句"帮我讲香"出终稿 |
| 先慢再快 | 先翻小抄、判断问题、选手指、写一版；练多了判断才变直觉；先慢是为了后快 |

## 四、向下具象五根手指 + 40个二级策略（A1-J4超级策略集）

### 4.1 ①场景化（截图11）

- 定义：把产品/服务融入用户有体感的场景/故事，直接代入、激发需求
- 适用：讲不到重点、"与我无关/可有可无"
- 价值：在用户脑子里放块大屏幕，从无感到想要、甚至害怕失去
- 对照例：低噪吹风机——"采用低噪电机，运行噪声更低" vs "早上家人还在睡觉，你洗完头却不敢一开吹风机把全屋吵醒"

| 策略 | 关键 | 细分方向 |
|---|---|---|
| A1.熟悉场景 | 足够常见 | 高频场景 / 经典场景 / 普遍场景 |
| A2.卡点场景 | 足够需要 | 难题困扰 / 痛点麻烦 / 焦虑害怕 |
| A3.微观体感 | 足够想要 | 看到听到 / 美好感受 / 情感共鸣 |
| A4.蒙太奇法 | 足够震撼 | 场景排比 / 画面循环 / 用标签云 |

- 蒙太奇：把不同镜头拼接，表现单一镜头无法表现的含义；标签云=把场景/功能标签像云一样排列（配图：手机功能标签云截图）
- 案例：黄宝书12.0新增20+个AI Partner，用4个场景讲——

| 场景 | 原版 | 新版 |
|---|---|---|
| ROI讨论难共识 | 挤一起拿小抄讨论 | 每人扫码和"科学决策搭档"聊15分钟再合并答案 |
| 面试对齐人生红点 | 红九模型12问自己辅导60-90分钟 | 扫码和"人生红点架构师"聊30分钟看报告 |
| 单元模型讲不清 | 自己翻十大模型硬整理 | 扫码和"单元模型教学官"聊30分钟，被追问补课纠偏，拿学习报告和分享大纲 |
| 复盘材料取舍 | 边学边纠结删什么留什么 | 召唤"清单体笔记助理"一轮轮派活纠偏 |

- 案例：探月学校暑期新实验开营仪式——不先讲课程体系，请家长想象画面；"饭桌ROI"微观体感：孩子多问一个问题、多讲一点理由、多把真实难题带回家；同时管理预期（别只盯一次听懂一次作业）
- 案例：复盘营200期蒙太奇——第1期体验课/第6期专家+班班分离/第32期直播课/第32期公众号投放/第40期腾讯会议直播/第59期自研直播间/第60期学习委员/第80期MBA会员销售/第83期"我请客"/第102期直播间发奖状/第106期一页流产品化/第116期万人复盘营/第140期抖音投放/第141期K系数首达0.9/第166期首次真正万人复盘营/第196期视频号投放
- 更多例：充电宝小（裤兜放不下）/8核处理器（打游戏卡顿）/智能锁（钥匙丢、被锁屋外）/不粘锅（粘锅难洗）/冲锋衣（抗风不透气）/红牛"累了困了喝红牛"/奥利奥"扭一扭舔一舔泡一泡"/理发店"绝不推销"

### 4.2 ②口语化（截图13）

- 定义：用大白话讲出来；面对面能说明白，一写方案录视频就术语多、句子长、主语不见
- 适用：一堆专业术语、复杂句子，用户听不懂、有距离
- 价值：简单直白好懂，是说服的基础
- 对照：同CLI v1技术黑话 vs v2大白话（见 §2.3）

| 策略 | 关键 | 细分方向 |
|---|---|---|
| B1.长句变短句 | 更好理解 | 使用口喷 / 调整语序 / 多用逗号 |
| B2.增加对象感 | 更有对象 | 多用"你""我" / 模拟当面聊天 / 代入真实用户 |
| B3.增加韵律感 | 更有节奏 | 多用叠词热词 / 追求结尾押韵 / 多用排比对偶 |
| B4.适当互动提问 | 更能参与 | 代入情境提问 / 重点信息设问 / 加强语气反问 |

- 案例：赖同学护腕暖桌垫——把"分区发热""5V安全低压""PTC自限温"翻成用户听得懂的体验、动作和结果
- 案例：头戴式耳机——版本A"王牌降噪强势升级，聆醇音享静界" vs 版本B"降噪没话说，戴上地铁车厢瞬间变空了；像一个人听现场演唱会；耳罩软乎乎戴一天没感觉；充一次电够用好多天"
- 更多例：兰毅JD"每天上班哼着歌跳着舞去"三条原因；固体咖啡含片加油站版"喝咖啡担心找厕所？1片≈1杯"、网吧版"包夜神器，喝一瓶不如含一片，守护水晶不跑厕所"；理发店"不办会员没总监，只剪头发不聊天"；烧烤"肉串就是大，跟谁比都不怕"

### 4.3 ③数字化（截图14）

- 定义：用关键数字讲出来；适用"基本靠吹"、缺证据、空洞干瘪
- 吹风机对照："运行噪声更低" vs "低至30dB，相当于耳边轻声细语，比传统吹风机降噪近一半"

| 策略 | 关键 | 细分方向 |
|---|---|---|
| C1.使用数字 | 可感知 | 具体量化 / 引入参照 / 历史对比 |
| C2.选对数字 | 可信度 | 精简数字 / 选主数字 / 回归用户 |
| C3.对比数字 | 冲击力 | 纵向对比 / 横向对比 / 换算对比 |
| C4.巧用数字 | 易记忆 | 数字组合 / 制造规律 / 数字口号 |

- 案例：徐剑发票SaaS——230万+企业 / 13亿+单 / 2649亿+元GMV / 1000+客户 / 近100%电子化率 vs 市场平均不到30%
- 案例：一堂"十年武器库"——5年打磨 / 数百个案例 / 上千名同学访谈 / 10万美金图书开发成本 / 值回10年学费
- 更多例：充电宝20000mAh只有0.8cm比手机薄；打印机蓝牙30秒打印、小白3分钟上手；折叠床"午休30分钟变2小时"；灯泡1000小时 vs 用10年一天不到1毛钱；小米发布会红米1999"价格屠夫"

### 4.4 ④故事化（截图15）

- 定义：用故事方式讲出来；适用"讲了很多用户记不住"、太散太干
- 259画布对照："一句话总结你的项目" vs 京东P8辅导老师故事（一个品类20万+商家；原京东生态运营负责P8架构师画像、内部孵化2个成功项目；"不要卷第一，做你懂的那个第二"）
- 本质：不是把一句话变长，而是把"为什么是你、为什么做、怎么做、结果是什么"装进别人能记住的叙述

| 策略 | 关键 | 细分方向 |
|---|---|---|
| D1.用户故事 | 代入感 | 真实用户 / 问题解决 / 结果收获 |
| D2.标杆故事 | 向往感 | 标杆人物 / 标杆案例 / 数字背书 |
| D3.幕后故事 | 可信度 | 创始人初心 / 团队奋斗 / 研发制作 |
| D4.初心愿景 | 意义感 | 目标人群 / 创业初心 / 世界愿景 |

- 五个同学标签故事：

| 同学 | 原来 | 后来 |
|---|---|---|
| 杜金科 | 开棋牌室，赚钱但不体面 | 关掉棋牌室，打磨底层生意逻辑、体面赚钱 |
| 班铭阳 | 搞垃圾回收，年赚20万，累且被看不起 | 包装成方法论做自由职业，帮上百年轻人找更好工作 |
| 陈先敏 | 开美容院年赚1000万，但女儿不认、活在焦虑里 | 和女儿重建关系，找到人生新方向 |
| 陈肖卿 | 做交易0做到1000万，稳定盈利却被琐事内耗 | 不再追求超越别人，追求超越自己 |
| 潘弘海 | 修打印机小老板，缺商业知识吃了很多亏 | 靠调研方法论找到新方向，拯救公司 |

- 案例：何发萝卜干——花两年、走上千公里、试几十种萝卜；"我不是在卖萝卜干，我是在卖我寻萝卜的过程"
- 案例：探月新实验从Truman童年"被看见"讲起——内向普通城市长大，第一次被老师当众表扬，第一次意识到"原来我也可以做成一些事情"；教育最稀缺的是"被看见"的机会；招募第一句："我们希望每一个孩子，都能在'被看见'中长大"
- 更多例：课程销售"去年带100个实习生，今年在阿里、字节、小红书"；志愿者老师教50个孩子编程、一个拿全国金奖；包子铺"蒸了30年，15岁跟爸学，凌晨3点和面5点出笼"；学生数学30分跟一年考98分；养3只猫的客户"终于敢穿黑衣服了"

### 4.5 ⑤素材化（截图16）

- 定义：用看得见、摸得着、听得到的素材让价值更具体可信；适用干讲不直观
- 纱网对照：只看数字没概念，把两种纱网放同一场景同一视角看同一片景色，用户自己看出差别
- 原则：数字负责说服，素材负责让你看见

| 策略 | 关键 | 细分方向 |
|---|---|---|
| E1.用图片 | 直观感 | 对比图 / 细节图 / 实拍图 |
| E2.用视频 | 过程感 | 演示视频 / 过程视频 / 直播片段 |
| E3.用感官 | 体验感 | 声音体验 / 触觉体验 / 嗅觉味觉 |
| E4.夸张生动 | 记忆点 | 夸张比喻 / 生动表述 / 趣味化 |

- 案例：双三角画布礼品——A4大画布贴墙，正面写、背面快速参考；30秒快闪视频：画布贴墙写写画画，手机扫码变数字版
- 案例：何发萝卜干"嘎嘣脆"——专门录一段咬下去的脆响；销量从百万做到四五百万
- 案例：Peter牛仔裤——从二楼扔下柏油路拖行 / 挂车后石子路拖行 / 绑ATV沙漠拖行，磨损但不破
- 收束：天幕阳台=场景化+数字化(13.12% vs 2.27%)+素材化；CLI=场景化+比喻化+口语化；多手指组合才把价值变价值感

## 五、向上抽象五根手指（续表）

### 5.1 ⑥比喻化（截图17）

- 定义：用类比把抽象价值翻译成用户熟悉、易感知的东西；目的是给陌生东西一个已理解的参照物，不是把话说漂亮
- 挂脖空调对照："半导体制冷片、手机App调温" vs "挂在脖子上的小冰箱"

| 策略 | 关键 | 细分方向 |
|---|---|---|
| F1.理解比喻 | 秒懂 | 生活类比 / 功能类比 / 场景类比 |
| F2.形象比喻 | 画面感 | 具象类比 / 夸张类比 / 动态类比 |
| F3.结构比喻 | 逻辑感 | 系统类比 / 关系类比 / 组织类比 |
| F4.价值比喻 | 价值感 | 资产类比 / 成本类比 / 收益类比 |

- 案例：图拉斯"小冰块"——把"快速降温"变成夏天从冰箱拿一块冰贴脸上的画面
- 案例：表达力火箭模型——燃料=内容（决定飞多高飞多远）、箭体=逻辑（把力量转成方向）、外壳=呈现（用户第一眼愿不愿意停下来听）
- 案例：大会员"爬楼" vs MBA"爬山"——MBA爬山要请假花钱、固定时间跟固定路线；大会员爬楼每层不高、一天天往上走，不知道哪层突然打开新视野
- 更多例：心脏像水泵、肺像风箱、大脑像CPU；路由器是"水龙头"、墙壁是挡板、卧室是隔间、厕所是死角；皮肤像海绵先吸水再锁水；AI像"外挂大脑"；充电宝像"移动插座"

### 5.2 ⑦情绪化（截图18）

- 定义：调动用户情绪产生共鸣，激发购买/行动意愿；适用表达太理性、冷冰冰
- 表达课对照："课程体系完善学完表达能力提升" vs "肚子里有货，一开口就'嗯…那个…我觉得'，这种关键时刻掉链子的难受，我们都懂"

| 策略 | 关键 | 细分方向 |
|---|---|---|
| G1.恐惧情绪 | 紧迫感 | 后果放大 / 损失厌恶 / 错失焦虑 |
| G2.向往情绪 | 渴望感 | 美好画面 / 身份向往 / 成就向往 |
| G3.好奇情绪 | 悬念感 | 留白提问 / 意外反转 / 秘密揭秘 |
| G4.认同情绪 | 信任感 | 说出心声 / 共同经历 / 价值认可 |

- 案例：马易云盘销售——改前"多端同步、权限管理、数据加密" vs 改后"公司最值钱资产是数据，丢了、被泄露、被离职员工带走，要花几百万几千万补救；我们的云盘把最值钱资产锁进保险柜"（先恐惧失去，再向往拥有）
- 案例：案例打磨直播开场——先认同"很多同学觉得自己经历平平没什么好讲"，再向往"打动你的故事从来不是主角多厉害，而是面对困境做了什么选择"，收束"每个人，都值得被看见"
- 更多例：保险"明天和意外，你永远不知道哪个先来"；母婴"你也是第一次当妈妈"；招聘"你投的简历HR只看5秒"；教育"孩子的时间不可逆，别等错过了才说早知道"；养老"现在的每一分储蓄，都是未来的从容"

### 5.3 ⑧金句化（截图19）

- 定义：把核心价值凝练成有力量、易记住的话；适用太散太平、听完就忘
- 表达课对照："提升表达能力职场更有竞争力" vs "会干活的人，要让会表达的人，把你的价值说出去"

| 策略 | 关键 | 细分方向 |
|---|---|---|
| H1.金句临摹 | 有模板 | 句式拆解 / 结构套用 / 积累素材 |
| H2.合辙押韵 | 有韵律 | 对仗工整 / 结尾押韵 / 朗朗上口 |
| H3.勇下断言 | 有态度 | 肯定句 / 敢下结论 / 传递信念 |
| H4.洞察对比 | 有洞察 | 正反对比 / 新旧对比 / 认知对比 |

- 案例：雷军小米金句群——"为发烧而生" / "小米SU7的目标，是成为这个时代梦想之车" / "优秀的公司赚取利润，伟大的公司赢得人心" / "价格厚道，感动人心"
- 一堂金句——"把产品打磨得有价值，是本分；把产品呈现得有价值感，是本事" / "实事求是" / "少走弯路，多活十年" / "科学体系，实事求是" / "让每个人都能掌握科学的商业方法论"
- 市场金句——"今年过节不收礼，收礼只收脑白金" / "怕上火，喝王老吉" / "不是所有牛奶都叫特仑苏" / "你本来就很美" / "充电5分钟，通话2小时" / "好空调，格力造" / "农夫山泉有点甜" / "让天下没有难做的生意"

### 5.4 ⑨冲突化（截图20）

- 定义：制造反差、对立、冲突，让价值点更有张力；适用太平太顺、没记忆点
- 表达课对照："提升沟通能力更受欢迎" vs "你有100分的本事，别人只能看到30分，你真的甘心吗？"

| 策略 | 关键 | 细分方向 |
|---|---|---|
| I1.认知反差 | 打破认知 | 颠覆常识 / 揭示真相 / 重新定义 |
| I2.价值反差 | 价值凸显 | 低调高值 / 普通稀缺 / 便宜好用 |
| I3.竞争反差 | 优势凸显 | 对比竞品 / 对比普通做法 / 对比过去 |
| I4.逆袭反差 | 戏剧张力 | 绝境反转 / 逆袭故事 / 草根崛起 |

- 案例：马易"开会"视频——大多数公司20个人开会2小时、18人低头看手机、开完不知道干嘛；年薪500万销售VP只开20分钟、只讲三件事（目标/进度/障碍），剩下时间见客户
- 案例：一堂"严肃教育"反差——别人教"怎么快点赚钱"，我们教"怎么少走弯路、多活十年"；别人教"一招制胜"，我们教"底层规律"
- 更多例：手机"别人比参数，我们比体验"；餐饮"别人卖预制菜，我们卖现炒"；求职"别人教美化简历，我们教提升实力"；保险"别人教怎么买保险，我们教怎么不用保险"

### 5.5 ⑩升华化（截图21）

- 定义：把具体价值点提升到更高价值维度，让用户觉得"这不只是这件事"；适用价值点太小太日常
- 表达课对照："提升表达能力" vs "表达能力，是你把自己的价值说出去的能力；会干活也要会表达，你的价值才能被看见"

| 策略 | 关键 | 细分方向 |
|---|---|---|
| J1.个人价值 | 成长感 | 能力提升 / 身份认同 / 长期资产 |
| J2.关系价值 | 连接感 | 家庭幸福 / 朋友信任 / 团队协作 |
| J3.事业价值 | 事业感 | 职业发展 / 公司经营 / 行业影响 |
| J4.社会价值 | 意义感 | 社会问题 / 行业进步 / 时代意义 |

- 案例：Y30"探照灯"——不是一年一度颁奖，是一堂同学一年一度的"探照灯"；从上千真实案例挑30个最值得学的，像30盏探照灯照亮过去一年没看见的盲区、也照亮下一年可以走的路；每个都证明普通人也能做出不普通的事
- 案例：一堂招募关键候选人四层升华——①个人价值：和最优秀的人共事、能力边界不断打开 ②关系价值：每门课影响成千上万同学、成为他们商业认知的一部分 ③事业价值：参与"让每个人掌握科学的商业方法论" ④社会价值：推动商业方法论科学化
- 更多例：面包店卖"清晨第一口温暖"；健身"重新爱上自己"；咖啡"下午三点的灵感"；家居"家的温度"；教育"让每个孩子被看见"；保险"家人的安全感"

## 七、课程结尾三份礼物（截图22）

### 7.1 礼物一：《一堂讲香十指模型·超级武器库》小抄

- 10个讲香方向继续展开 = 40个核心策略、上百个具体角度和Tips
- 一份干巴巴的文案/方案/逐字稿，对照小抄逐项检查，至少能找到30-50个修改点
- 最大价值：把靠天赋靠灵感的"会表达"，变成可对照、可修改、可带团队反复练的基本功
- 领取：周三中午12点前成功邀请1人，领A3硬塑封版；评论区扣口令"我请客"拿带ID推荐卡（可收藏高清大图/可加餐领小抄/朋友免审绿色通道/朋友作业永久计入合伙人指数）

### 7.2 礼物二：L1-L6 修炼地图

| 层级 | 状态 |
|---|---|
| L1 入门 | 能听懂什么是讲香，能看懂好表达好在哪 |
| L2 上手 | 写东西时能对照小抄，主动补一个场景、补一个数字 |
| L3 熟练 | 能熟练用十指策略，知道一段话该补哪根手指 |
| L4 精通 | 能快速识别一段表达的问题，并给出修改方向 |
| L5 高手 | 能带团队练习讲香，把表达变成组织基本功 |
| L6 大师 | 把讲香变成本能反应，形成自己的风格和体系 |

### 7.3 礼物三：讲香AI Partner（十指讲香助理）

- 用法：让AI按策略要求产出候选版本；对照十指模型标注每段用了什么策略；拆解别人优秀案例学习
- 边界：AI只是执行工具，判断和策略永远在你自己手里

**案例：AI打磨招生文案（三部分结构）**

| 部分 | 内容 |
|---|---|
| 故事线5步 | ①接住处境（已花大量时间复盘、攒了案例稿）②揭示卡点（自嗨：只有记录没有交付）③给新标准（好交付稿唯一标准=别人听完能说出"我学到了什么"）④亮解决方案（从流水账打磨成逐字稿）⑤理性邀请（从记录者升级为分享者） |
| 讲香点清单 | 逐段配：场景/痛点/对比/金句/比喻/新标准/冲突/功能/结果/案例/升华/行动 |
| 新版参考稿 | 短句排比"没被看过，没用过，没产生过回响"；三字对仗"有记录无交付/有过程无重点/有辛苦无价值"；结尾强节奏收束"只带旧稿，只做打磨，只求交付" |

**案例：AI拆解一堂CLI文案**

- 三个挑战：概念门槛高（CLI/MCP对非技术是黑话）/ 价值过于抽象（"提供高质量上下文"离具体好处太远）/ 体验依赖想象（没法立刻试用，必须凭描述感到科幻感）
- 段落1：用比喻化 F1理解比喻——"不是给人用的，是给AI用的"，借"给人用的软件"这个熟悉参照，把CLI映射到完全不同的用途分类
- 段落6：用场景化 A2卡点拆解——锁定高痛点场景、人物具象化，起点是"项目组在做的困难"，终点是"做完的结果"

## 八、金句与判断

> 「把产品打磨得有价值，是本分；把产品呈现得有价值感，是本事。」

> 「你手里的东西明明值80分，但开口一讲，它听起来只值30分。」

> 「好的表达都是一遍遍改出来的。」

> 「从'它怎么搭'，到'它能做什么'，再到'它和我有什么关系、为什么我现在就想要'，中间差的就是把价值讲出来的能力。」

## 九、总结与作业

### 9.1 一个目标→1拆2→2拆10→四个阶段

- 一个目标：把你有的变成对方想要的，提升注意力/转化率/价格溢价/品牌信任
- 1拆2：向下做具体（让人理解）+ 向上拉价值（让人认同）
- 2拆10：具象五指 + 抽象五指
- 四个阶段：基础上手 / 打动加强 / 强化信任 / 无限进步

### 9.2 作业（三选一）

1. 讲香策略复盘：找最近一篇文案/方案/PPT/短视频，对照十指模型找出用了哪些、缺了哪些，把缺的补上出新版
2. AI讲香实战：用讲香AI Partner按你的策略要求改写，对比改前改后写下思考和选择
3. 拆解一个优秀案例：用AI拆解一个你觉得"讲得很香"的案例，学习它用了哪些十指策略，并模仿写一段

### 9.3 Flag

- 这周之内，用讲香基本功打磨好手头最重要的一个表达
