# ROI实操4：落地训练篇｜L6 清单体笔记

> 课程来源：一堂·科学决策ROI系列｜Truman

## 一、课程定位与核心命题

### 1.1 这节课回答了什么问题

```
❌ 只回答了"一个高质量的ROI长什么样"
✅ 补上了"一个重要的ROI决策，是怎么从无到有、一步步做出来的"
```

### 1.2 核心认知跃迁

| 旧认知 | 新认知 |
|---|---|
| ROI = 一个分析模型 | ROI = 一个**刻意练习的完整套路和策略集** |
| 决策 = 一次性想清楚 | 决策 = 反复纠结→反复推翻→反复调研→反复讨论→最终共识 |
| 决策能力靠天赋 | 决策能力可以**被训练、被迭代、无限进步** |

### 1.3 自我评估坐标系

```
关系不大 → 感兴趣 → 重要 → 非常重要 → 必经之路
                                        ↑
                               （拉满、无限进步、追求TOP Level）
```

## 二、核心框架：ROI高阶训练全景地图

### 2.1 五阶段落地模型

```
有意识 → 写初版 → 细打磨 → 有共识 → 做复盘
  ↑         ↑        ↑        ↑        ↑
"以为每年  "以为想  "以为决策  "以为团队  "以为决策是
做不了几次  一想就   一次性就  很容易理  独立而临时的
ROI决策"   足以"   能想清楚"  解和认可"  决策能力很难
                                   大幅提升"

  ↓         ↓        ↓        ↓        ↓
"其实海量  "其实写  "其实需要  "其实共识  "其实好的
决策需要   下来会   多轮打磨   是极其难   复盘能无限
分析"     完全不同"  提升"     的"       进步"
```

### 2.2 五阶段一句话理解

| 阶段 | 核心任务 | 关键突破 |
|---|---|---|
| **①有意识** | 发现决策机会，建立ROI敏感性 | 从"以为没几个决策"到"看见海量决策" |
| **②写初版** | 把脑内模糊判断可视化 | 从"想一想就够了"到"写下来完全不同" |
| **③细打磨** | 多轮迭代优化，拉价值降成本 | 从"一次性想清楚"到"第2/3版甚至5/10版才优秀" |
| **④有共识** | 让团队理解并认可决策逻辑 | 从"我定了你们执行"到"决策是爬山，共识是冰山" |
| **⑤做复盘** | 对比预判与结果，提取可迁移认知 | 从"做完就完了"到"复盘才能真正无限进步" |

## 三、阶段一：有意识——发现决策

### 3.1 核心认知

```
真正需要我们做的决策数量，远远超过我们"以为的"科学决策数量。
大到换工作、选项目，小到一个功能、一个策略、一个选项，
背后其实都是ROI的综合取舍。
```

### 3.2 决策分类体系

| 决策层级 | 决策类型 | 典型场景 |
|---|---|---|
| **个人决策** | 职业发展 | 是否跳槽/辞职/创业 |
| | 金钱投入 | 是否买房/换车/投资 |
| | 时间投入 | 打车还是开车/做饭还是外卖 |
| **团队决策** | 业务方案 | 自研还是外包 |
| | 资源投入 | 是否推广日报 |
| | 关键项目 | 是否做大航海 |
| **公司决策** | 重大选项 | 是否全员涨薪20% |
| | 业务线取舍 | 要不要做咨询/ToB |
| | 单元模型 | 要不要加盟/投资 |

### 3.3 关键问题自检

- 过去1-3年，你做了多少次有意识的ROI分析？
- 你的决策敏感性够强吗？有多少决策被"模糊快速决策"掉了？
- 哪些场景其实可以用ROI但你现在没用？

## 四、阶段二：写初版——可视化

### 4.1 核心认知

```
过去有多少ROI决策在脑子里想一想、聊一聊就定了？
有多少会写下来评估？

——其实写下来会完全不同。
```

### 4.2 「写初版」的四级阶梯

| 级别 | 做法 | 适用场景 | 关键动作 |
|---|---|---|---|
| **L1 脑子里想** | 在脑子里想一想，嘴里聊一聊就得出结论 | 低风险小事 | 至少意识到自己没写下来 |
| **L2 简单罗列** | 随手列在纸上/白板；做成表格/脑图/清单体笔记；有优先级；部分定量 | 日常团队决策 | 使用《一堂ROI画布·简单版》 |
| **L3 完整分析** | 完整全盘思考；基础要素+长期视角+公司视角+机会成本+时间窗口 | 重要决策 | 使用《一堂ROI画布·完整版》 |
| **L4 财务分析** | 把成本收益项都转化成财务指标；把确定性换成概率；严格公式定量 | 重大决策 | 精准定量测算 |

### 4.3 L3→L4 财务定量技巧

```
① 把数值换成现金值：例"需要研发3人日时间"→"研发人员工资XXXXX元"
② 把确定性换成概率：例"提升个人竞争力"→"可以比同龄人薪水上浮XX%"
③ 严格公式：努力定量，精确计算财务ROI
```

## 五、科学决策三角形（写初版的核心审美）

### 5.1 三角模型

```
           宽度（关键收益项 × 关键成本项）
          /                            \
         /                              \
    深度                                高度
（优先级定性→部分定量→定量公式）    （长期视角→公司视角→机会成本→时间窗口）
```

### 5.2 三维拆解

| 维度 | 含义 | 低级表现 | 高级表现 |
|---|---|---|---|
| **宽度** | 关键收益项和成本项是否找全 | 丢三落四，有盲区 | MECE穷举，关键项不遗漏 |
| **深度** | 评估是否具体、定量 | 模糊定性"有好处" | 精确数字、公式、概率 |
| **高度** | 是否考虑长期、公司、机会成本、时间窗口 | 只看眼前、只看自己 | 四层高度全面拉升 |

### 5.3 四层「高度」提升法

| 高度层 | 考量内容 | 典型盲区 |
|---|---|---|
| **长期视角** | 拉长到3年/5年或更长周期看成本/收益 | 忽略团队成长、习惯培养、持续回报、复利 |
| **公司视角** | 站在公司整体角度看额外成本/收益 | 忽略核心能力、壁垒、现金流、融资计划、品牌 |
| **机会成本** | 同样的投入还能做什么、带来什么收入 | 只比"做不做"不比"做哪个" |
| **时间窗口** | 现在做 vs. 以后做的差异 | 忽略竞争窗口期、资源窗口期、政策窗口期、流量红利期 |

### 5.4 常见稀缺资源清单（自查盲区）

| 资源类型 | 具体项 |
|---|---|
| 核心人力 | ①CEO的时间和注意力 ②管理精力/内部会议 ③团队成员（产品/研发/销售/运营） |
| 财务资源 | ④成本预算（投资款/投放成本/营销预算） |
| 物理资源 | ⑤物理空间（货柜/场地/橱窗） |
| 用户触达 | ⑥用户接触（销售时间/宣讲会） |

### 5.5 常见时间窗口清单

| 窗口类型 | 具体项 |
|---|---|
| 竞争窗口期 | 融资窗口/头部窗口期 |
| 资源窗口期 | 房租/难得合作 |
| 营销窗口期 | 法定假期/营销节日 |
| 流量窗口期 | 渠道红利期 |
| 政策窗口期 | 短期政策/政策红利 |

## 六、阶段三：细打磨——多轮迭代

### 6.1 核心认知

```
ROI往往不是一次性做出来的，
而是一次次调研、优化、打磨、排序，反复优化，最后形成的。

——优秀的ROI，往往出现在第2/3版，甚至5/10版里。
```

### 6.2 打磨动作链

```
写初版 → 发现盲区 → 补充调研 → 优化维度 → 调整权重 
    → 拉高价值/降低成本 → 第二版 → 再检查 → 再打磨 → ... → 第N版
```

### 6.3 微调方案四字诀

| 方向 | 核心问法 | 动作 |
|---|---|---|
| **往上拉** | 如何增加更多收益和价值？ | 补充被忽略的收益项，提升收益质量 |
| **往下降** | 如何降低更多成本和风险？ | 寻找平替方案，砍掉不必要的成本项 |
| **平替方案** | 有没有更好的选项？ | 多个选项中选出最佳 |
| **权重矫正** | 哪些权重出现了误判？ | 重新校准各维度的权重分配 |

### 6.4 四个里程碑信号

```
"有高敏感性" → "初步有一版" → "充分有共识" → "复盘变聪明"
     ↑                ↑               ↑              ↑
   阶段一            阶段二+三        阶段四         阶段五
```

## 七、阶段四：有共识——团队对齐

### 7.1 核心认知

```
面对决策有充分的理解和共识，是高效执行的基础。

高水平的决策是推出来的。
高水平的共识是挖出来的。
```

### 7.2 高水平共识曲线（IPO模型）

```
Step 4 行动层 (Level 1)
  ├── 决策结果：明确判断是不是要做
  ├── 明确目标：决策的核心目标/价值
  └── 配套资源：负责人/资源/里程碑
        ↑
Step 3 判断层 (Level 2)
  ├── 理性评估：综合评估成本/收益/风险
  └── 平替方案：多个选项里最佳
        ↑
Step 2 逻辑层 (Level 3)
  ├── 评估维度：成本/收益/风险是否全面
  ├── 对齐权重：不同维度权重是否认同
  └── 对齐标准：最终成功/失败标准一致
        ↑
Step 1 信息层 (Level 4)
  ├── 背景信息：面临的问题/目标
  ├── 已知信息：信息源/假设
  └── 关键数据：具体数据/口径/基准值

决策水平越高 → 越容易以理服人
前期做决策 → 后期做说服
越民主越开放 → 决策质量越高
```

### 7.3 共识四版本进化（以团队分工为例）

| 版本 | 做法 | 共识效果 |
|---|---|---|
| **V1 命令式** | "以后A就跟你汇报吧，你多带带他" | 弱共识，对方不知道你为什么这么想 |
| **V2 过程式** | "我考虑了三个方案，综合平衡ROI，觉得跟你汇报更合适" | 有一点过程感，但缺少维度 |
| **V3 维度式** | 列出成本123、收益123、对你好处1234、问题12 | 开诚布公，逻辑清晰 |
| **V4 信息式** | +关键背景信息（人生红点、过往结果、偏好） | 信息充足，对方自发认同 |

### 7.4 四个层次的共识

| 共识层次 | 内容 | 对齐什么 |
|---|---|---|
| **L1 行动共识** | 明确最终结论 + 目标 + 配套资源 | "谁来做，怎么做" |
| **L2 判断共识** | 综合评估 + 平替方案 | "这个决策是经过认真取舍的" |
| **L3 逻辑共识** | 评估维度 + 权重 + 成败标准 | "我们按同一套逻辑在思考" |
| **L4 信息共识** | 背景信息 + 已知信息 + 关键数据 | "我们看到的是同一组事实" |

## 八、阶段五：做复盘——无限进步

### 8.1 核心认知

```
我们之前预估的ROI，本质上是"假的假设"，
而真正验证的结果，才是假设验证的客观认知。

ROI不是个一次性工作，而是个螺旋上升的过程。
——好的复盘能无限进步。
```

### 8.2 复盘三层深度

| 复盘层级 | 核心问题 | 产出 |
|---|---|---|
| **L1 看结果** | 最终ROI和预判是否一致？收益达预期了吗？成本超了吗？ | 基本判断：做好还是做坏了 |
| **L2 看过程** | ROI分析过程是否和预判维度一致？忽略了哪些关键成本/收益/风险？哪些权重误判了？ | 精准归因：哪里出了问题 |
| **L3 看迁移** | 面向下一次决策，哪些维度/场景可以迁移？可能的关键成本/收益/风险是什么？类似场景还有哪些？ | 能力提升：下次会做得更好 |

### 8.3 深度复盘四追问（对应一堂复盘冰山模型）

| 追问层次 | 问题 | 对应复盘深度 |
|---|---|---|
| **第一问** | 回到起初，这个决策还做吗？划不划算？ | 主观感受→客观事实 |
| **第二问** | 具体什么原因？哪个维度/参数/风险误判了？ | 客观事实→背后原因 |
| **第三问** | 有哪些关键认知，可以迁移到未来哪些场景和决策？ | 背后原因→底层模型 |
| **第四问** | 当时这么想的最根本原因是什么？和什么能力/基本功相关？ | 底层模型→能力建设 |

### 8.4 复盘武器库四件套

| 工具 | 用法 |
|---|---|
| **结果复盘表** | √收益是否达到预期；√成本是否超出预期 |
| **过程复盘表** | √关键成本/收益/风险是否有忽略；√权重是否误判 |
| **广泛迁移表** | √可能维度：预判下一次可用的关键维度和可能场景 |
| **能力反思表** | √是否缺失：缺失了什么导致的问题；√是否可练：下次如何提升 |

### 9.2 L4 顶级动作详解

| L4 能力 | 具体做法 |
|---|---|
| **财务分析** | 把各种成本/收益项都转化成财务指标；把确定性换成概率 |
| **严格定量** | √定量公式：严格公式，努力定量；√平替方案：多个选项里最佳；√权重矫正 |
| **追求高度** | 长期视角 + 公司视角 + 机会成本 + 时间窗口，四层高度拉满 |
| **信息共识** | 背景信息/已知信息/关键数据/具体数据/口径/基准值全透明 |
| **复盘姿势** | √是否缺失：缺失了什么导致的问题；√是否可练：下次如何提升能力/基本功 |

## 十、L6 级行动纲领：如何刻意练习 ROI 决策能力

### 10.1 练习金字塔

```
            ┌──────────────┐
            │  广泛迁移    │ ← 每次复盘都问：这次认知能迁移到哪里？
            ├──────────────┤
            │  深度复盘    │ ← 不只复盘结果，更复盘过程、认知、能力
            ├──────────────┤
            │  高质量共识  │ ← 每次重要决策走完信息→逻辑→判断→行动四层
            ├──────────────┤
            │  多轮打磨    │ ← 默认所有优秀ROI都在第2/3版甚至5/10版
            ├──────────────┤
            │  写下来      │ ← 落纸面是一切进化的起点
            ├──────────────┤
            │  识别决策机会│ ← 首先意识到"这其实是个需要ROI分析的事"
            └──────────────┘
```

### 10.2 日常练习动作清单

| 练习类型 | 具体动作 | 频率 |
|---|---|---|
| **主动练习** | 每周至少写1个完整ROI决策分析 | 每周 |
| **顺手练习** | 每个日常选择（打车vs地铁、外卖vs做饭）快速过一遍成本收益 | 每天 |
| **叠加练习** | 每次开会讨论方案时，下意识做宽度-深度-高度三维检视 | 每次会议 |
| **迁移练习** | 每做完一个重要决策复盘后，明确写出1-3个可迁移认知 | 每次复盘 |
| **对标练习** | 找一个高手决策案例，用自己的ROI框架重做一遍，对比差异 | 每月 |

### 10.3 自检问题清单（建议每月回看）

```
□ 我过去一个月做了多少次有意识的ROI分析？（目标：≥10次）
□ 有多少重要决策是写下来而不是脑子里想的？（目标：100%）
□ 有多少决策经历了2版以上的打磨？（目标：重要决策100%）
□ 团队共识阶段走到了哪一层？有没有跳层？（目标：重要决策至少到逻辑层）
□ 复盘有没有进入"看过程"和"看迁移"？（目标：每次重要决策都做到）
□ 我的ROI分析在宽度/深度/高度上，和三个月前相比有进步吗？
```
