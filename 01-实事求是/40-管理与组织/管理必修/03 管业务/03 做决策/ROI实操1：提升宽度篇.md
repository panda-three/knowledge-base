## 一、为什么要学——破题篇

### 1.1 科学决策三角形回顾

> 在认知审美篇中，Truman交付了科学决策三角形——三个维度决定ROI评估质量。

```text
                    宽度（本课重点）
                关键收益项
                关键成本项
                   /\
                  /  \
                 /    \
                /  ROI \
               /  决策  \
              /  三角形  \
             /            \
            /              \
    深度                  高度
  优先级定性          长期视角
  部分定量            公司视角
  定量公式          机会成本
                    时间窗口
```

### 1.2 为什么宽度是第一优先级

> "在ROI决策里，宽度是第一步，也是判断一个ROI是不是合格最重要的一步。我们在磨课过程中，发现了大量'宽度不够'的问题。"

| 典型问题 | 具体表现 | 后果 |
|---|---|---|
| **决定个人发展** | 只看钱和福利，最重要的成长空间和核心能力修炼考虑甚少 | 高薪跳槽，两年后发现能力没成长，被行业淘汰 |
| **评估商业单元模型** | 早期忽略"货损"和账期，模式不成立却不自知 | 看似赚钱的业务实际巨亏 |
| **决定公司开年会** | 只简单看了看花钱不太高就拍板定了，没拆解价值项 | 钱花了，团队体验反而更差了 |
| **习惯性碎片决策** | 要么缺少宽度审美，要么缺少方法提升宽度 | 每次决策都在碰运气 |

> **核心判断：如果关键项都找不到，ROI好不了。** 宽度上的盲区会让后面所有深度分析和高度判断都建立在错误的前提上。

### 1.3 本课要解决的问题

```text
问题1：面对一个重要决策，我怎么能确保自己没有漏掉关键的成本项和收益项？
问题2：不同场景（个人/团队/公司）的决策，有哪些常见的"盲区"需要特别注意？
问题3：有没有一套可以反复使用的方法论，而不是每次都靠灵感和直觉？
```

## 二、第一部分：真实案例轰炸——3类9种ROI评估

> "我举了3类9种ROI评估的例子。分别从个人决策、团队决策、公司决策，给大家展示同学们是怎么用ROI的宽度做决策的。"

### 2.1 三类九种全景

```text
个人决策（3种）          团队决策（3种）          公司决策（3种）
①个人职业发展           ④业务方案选择           ⑦公司重大选项
②个人金钱投入           ⑤团队资源投入           ⑧业务线的取舍
③个人时间投入           ⑥关键项目决策           ⑨判断单元模型
```

---

### 2.2 个人决策三种

#### 第一类：个人职业发展

| 要素 | 内容 |
|---|---|
| **核心问题** | 是否跳槽/辞职/创业？要不要报考在职研究生？要不要从管理者转型自由职业者？ |
| **典型ROI评估案例** | 创业 vs 继续大厂工作——从收益上看：能力提升、工作收入、职位职级都有较大帮助；从成本上看：如果失败大概亏10万+资金成本+3个月试错时间。当表格列出来的时候，答案就已经出来了 |
| **常见举一反三** | 35岁要不要从国企辞职跳槽互联网？要不要离职休息一年重新换工作？要不要离开北京去老家发展？要不要为了晋升去外地拓展新业务？ |

#### 第二类：个人金钱投入

| 要素 | 内容 |
|---|---|
| **核心问题** | 该不该买这个？是否买房/换车/投资？ |
| **典型场景** | 个人重大消费和投资决策——不只看到"买了能得到什么"，还要看到"这笔钱如果不花在这，花在别处能得到什么"（机会成本思维） |

#### 第三类：个人时间投入

| 要素 | 内容 |
|---|---|
| **核心问题** | 该不该做这个？打车还是开车？做饭还是外卖？要不要花时间了解ChatGPT？要不要业余时间做小红书？ |
| **关键洞察** | 就连点外卖和自己做饭这样的事情，都可以用ROI科学决策。很多人习惯性凭感觉选，但这背后其实有清晰的时间成本、健康收益、金钱成本可以比较 |

#### 第四类：业务方案选择

| 要素 | 内容 |
|---|---|
| **核心问题** | 做不做这个方案？是自研还是外包？要不要做一个看似难得的政府项目？企业微信要不要增加AI运营？ |
| **常见举一反三** | 要不要启动新的技术业务线？要不要用无人机巡查？是否接科研外包？是否通过扫楼推广SaaS？ |

#### 第五类：团队资源投入

| 要素 | 内容 |
|---|---|
| **核心问题** | 投不投入资源？要不要送员工去外地参加行业会议？要不要购买昂贵设备？要不要内部推动OKR？ |
| **经典案例** | 送员工去外地参加行业会议的ROI——I（投入成本）容易计算（脱产工时损失+差旅成本），R（回报收益）却需要刻意追求：了解行业动态、链接上下游合作伙伴、链接专家资源、维护出差城市的老客户关系。如果员工只是当作免费旅游，不如在岗位好好工作 |
| **常见举一反三** | 要不要全公司推行OKR？要不要买昂贵设备？要不要开发线上小程序商城？要不要坚持开周会？销售部门要不要成立专门的客户维护团队？ |

#### 第六类：关键项目决策

| 要素 | 内容 |
|---|---|
| **核心问题** | 要不要上项目？要不要做"大航海计划"？ |
| **关键原则** | 关键项目的决策往往试错成本高、影响面大——需要比前两类投入更多的ROI分析时间 |

#### 第七类：公司重大选项

| 要素 | 内容 |
|---|---|
| **核心问题** | 是否全员涨薪20%？要不要做一轮大笔融资？要不要战略转型？ |
| **关键特征** | 影响面广、不可逆性强、需要从"高度"维度重点考量（长期视角+公司视角） |

| 要素 | 内容 |

## 三、第二部分：修炼ROI宽度基本功——四字诀

> "课程后半段，我又分享了修炼ROI宽度基本功的四字诀：列、推、建、查。"

### 3.1 四字诀全景

```text
列 —— 冷静清单法：努力冷静地罗列决策的成本和收益
推 —— 故事推演法：用一个订单、一个用户来推演整个故事
建 —— 建立体系法：建立一个MECE框架或者公式，严谨评估
查 —— 用专业检查：寻找专家咨询，或者用"盲区武器库"自查
```

### 3.2 训练1：「列」——冷静清单法

| 维度 | 说明 |
|---|---|
| **核心动作** | 把所有能想到的成本项、收益项逐条列在纸上/白板上/电子文档里 |
| **核心心态** | **"默认我会丢掉很多要素"**——用这个心态来逼迫自己"还有吗？还有吗？"不断追问 |
| **从L1到L2的升级** | L1：脑子里想一想就得出结论 → L2：随手列在纸上，落到纸面上才能方便讨论和迭代 |
| **关键原则** | 先做加法（列越多越好），再做整理归类 |

### 3.3 训练2：「推」——故事推演法

| 维度 | 说明 |
|---|---|
| **核心动作** | 用一个订单、一个用户、一件货、一个流程、一个项目时间表的视角进行推演，代入真实场景中走一遍 |
| **为什么有效** | 抽象思考时容易漏项，但一旦代入"一个用户从来到走"的完整故事线，漏掉的环节就会自然浮现 |
| **典型应用** | 评估一个新业务方案——按"一个客户从第一次接触到最终成交"的完整故事推演一遍，看看哪些成本项在故事里出现但之前被忽略了 |

### 3.4 训练3：「建」——建立体系法

| 维度 | 说明 |
|---|---|
| **核心动作** | 在业务线/业务公式等MECE框架下分类分析，建立结构化的评估体系 |
| **从L2到L3的升级** | L2简单罗列 → L3电子版：做成表格/画成脑图/写成清单体笔记，有优先级排序 |
| **核心价值** | 有了框架，每次新决策就不需要从零开始——直接在框架上增删改 |

### 3.5 训练4：「查」——用专业检查

| 维度 | 说明 |
|---|---|
| **核心动作** | ①专家访谈——问有经验的专家/同行"你做这类决策时通常会考虑什么？" ②AI检查——用AI穷举可能的盲区 ③盲区武器库自查——使用本课交付的三张超级小抄 |
| **核心价值** | 即使有了列推建的习惯，人还是会漏——用外部视角来补自己的认知盲区 |

## 五、ROI宽度修炼段位成长地图

| 段位 | 核心能力 | 典型表现 | 使用工具 |
|---|---|---|---|
| **L1 脑子里想** | 无宽度意识 | 在脑子里想一想，大家嘴里聊一聊就很快得出结论——丢三落四是常态 | 无 |
| **L2 简单罗列** | 有列出意识但不够系统 | 随手列在纸上/白板上，"至少我没完全拍脑袋" | 冷静清单法（随手列） |
| **L3 有优先级** | 能区分主要和次要成本/收益 | 做成表格/脑图，有简单定性优先级排序，能用MECE框架分析 | 冷静清单法 + 建立体系法 |
| **L4 能推演故事** | 能代入真实场景发现隐藏成本/收益 | 用故事推演法发现之前漏掉的关键项——"哦！原来这里还有一笔隐形成本" | 故事推演法 + 冷静清单法 |
| **L5 能专业检查** | 能用外部视角补盲区 | 使用盲区武器库自查、专家访谈、AI检查——不是"我以为全了"，而是"我主动找了可能漏的" | 四字诀全套 + 盲区武器库 |
| **L6 习惯成自然** | 遇事不决，自动启动ROI宽度分析 | 任何重要决策，第一反应是"列一列成本和收益"，团队有共同的ROI决策语言 | 四字诀内化为肌肉记忆 |

|---|---|
| "如果关键项都找不到，ROI好不了。" | 课程核心命题 |
| "遇事不决，ROI。" | 课程教学口号 |
