## 一、为什么要学——破题篇

### 1.1 开篇三个题目——一堂的真实转化率挑战

> Truman开篇直接抛出三个一堂亲身经历过的转化率提升题目，让学员意识到：你的业务里，有各种场景，存在着大量的转化率。

| 题目 | 转化率类型 | 核心挑战 |
|---|---|---|
| **题目1：作业转化率** | 每周五直播课的作业提交率 | 每周1500人上课，初始作业率仅10-20%，如何一轮轮提升到50-60%？ |
| **题目2：推荐转化率** | 老学员推荐新学员的K系数 | 初始综合K系数仅3-5%，一年各种老带新尝试全失败，如何最终拉到40-50%？ |
| **题目3：入职转化率** | 优秀候选人面试后到最终入职 | 初始约40-50%，如何在动力阻力触点上做调整，最终拉到80-100%？ |

### 1.2 面对转化率提升的三大普遍难题

| 难题 | 具体表现 | 根因 |
|---|---|---|
| **难题1：碎片随机** | 策略制定依赖手感和直觉，想到什么试什么，质量非常不稳定 | 缺少一个统一的分析框架 |
| **难题2：低效重复** | 这次提升了一点，下次换个场景又不会了，无法迁移 | 缺少可复用的方法论 |
| **难题3：浅尝辄止** | 提了几个假设发现没效果就放弃了，无法持续迭代到领先 | 缺少系统的假设生成和验证机制 |

### 1.3 核心命题

```text
想要提升这些转化率，有没有一套相对底层的、通用普适的分析框架，
让大家面对不同的转化率问题，都能够有抓手，
可以系统地做分析、提假设、定策略？
```

## 二、核心框架：推箱子实验——动力阻力触点三段论

> **"你的'关键策略'有且仅有三个：提升动力、减少阻力、发掘触点。"**

### 2.1 推箱子实验模型

```text
                    ┌──────────┐
    动力（P）→      │          │  ← 阻力（F）
    推力            │  箱子    │     摩擦力
                    │          │
                    └──────────┘
                         ↓
                    触点（T）
                  施加力的位置和时机
```

### 2.2 三段论详解

| 要素 | 物理类比 | 转化率场景中的含义 | 一句话定义 |
|---|---|---|---|
| **动力（P）** | 推箱子的推力 | 让用户/客户产生购买欲望和决策意愿的所有因素 | "我为什么要买/选？" |
| **阻力（F）** | 箱子黏在地上的摩擦力 | 让用户犹豫、顾虑、卡住的所有因素 | "我为什么还在犹豫？" |
| **触点（T）** | 手接触箱子的位置和时机 | 动力和阻力在什么时机、什么位置、以什么形式传递给用户 | "我在什么时候、什么地方、用什么方式影响用户？" |

### 2.3 三段论的核心公式

```text
转化率 = f（动力, 阻力, 触点）

当 ∑动力 > ∑阻力 时，转化发生。
触点的质量 = 动力表达效率 × 阻力消除效率 × 时机匹配度。

提升转化率的三个独立杠杆：
  ① 提升动力（三曲线：FAB → 名利权情 → 影响力法则）
  ② 减少阻力（三层深度 × 三类时机）
  ③ 发掘触点（12个触点策略 × 组合排序）
```

### 2.4 三段论和传统方法的本质差异

| 传统方法（❌） | 三段论方法（✅） |
|---|---|
| 转化率不行 → 打折促销 | 转化率不行 → 先拆动力阻力触点 → 三个杠杆分别提假设 |
| "我觉得应该强调产品优势" | "动力侧：FAB做到位了吗？名利权情叠加了吗？影响力法则用了吗？" |
| "客户说太贵了，降点价吧" | "阻力侧：这是L1降低/L2消除/L3逆转哪个层级？动嘴还是动钱？" |
| 想到什么渠道就在什么渠道推 | "触点侧：当前有多少个触点？还有哪些被浪费的触点？" |

### 3.4 三个案例的共性规律

```text
1. 没有一个转化率是靠"大力出奇迹"一次性拉起来的

2. 动力、阻力、触点是三个独立杠杆，必须分别做功
   → 作业率：动力（价值+奖励+学分） + 阻力（改时间+开放选项） + 触点（多个时机）

   → 入职率：动力（使命+成长+红点） + 阻力（背景背书+个性化挖） + 触点（面试+私聊）

3. 同一个要素在不同阶段扮演不同角色
   → "我请客"既增加了动力（稀缺正课），又消除了阻力（推荐没面子→"我请朋友"的社交货币）
```

## 四、核心路径：转化率黑客的三次能力飞跃

> "我把训练过程划分成三次能力的飞跃。"

### 4.1 三次能力飞跃全景

```text
第一次飞跃          第二次飞跃            第三次飞跃
手感碎片             专业工具箱           大量假设
  → 全局分析          → 善于提动力         → 广泛迁移
                      → 善于消阻力
                      → 善于挖触点

入门                进阶                 高阶
```

### 4.2 第一次飞跃：从手感碎片到全局分析

| 维度 | 说明 |
|---|---|
| **起始状态** | 做转化率全凭手感和直觉，碎片随机想到什么试什么，缺少体系 |
| **飞跃目标** | 能习惯性拆解"动力阻力触点"，持续练习用它拿结果，用它拆同行 |
| **核心动作** | 任何一个转化率问题，第一反应是"动力侧有什么？阻力侧有什么？触点侧有什么？" |
| **配套工具** | 动力阻力场景匹配小抄 + 转化率思考画布 |

### 4.3 第二次飞跃：专业工具箱

| 维度 | 说明 |
|---|---|
| **起始状态** | 有了三段论框架，但每个杠杆的具体手段太少——提动力只会打折，消阻力只会降价 |
| **飞跃目标** | 持续练习善于提动力（三曲线）、善于消阻力（三层×三类）、善于挖触点（12策略） |
| **核心动作** | 面对任何一个转化率问题，能在动力/阻力/触点三个方向上分别提出10+个高质量假设 |
| **配套工具** | 动力三曲线 + 待破解阻力清单 + 10大最易浪费触点 |

### 4.4 第三次飞跃：大量假设和广泛迁移

| 维度 | 说明 |
|---|---|
| **起始状态** | 在自己的核心业务场景里已经熟练，但换个场景就不会了 |
| **飞跃目标** | 跨领域跨场景条件反射式调用——做课作业率 → 马拉松 → pitch投资人 → pitch老师，都能快速提动力+降阻力+挖触点 |
| **核心动作** | 每年循环调用100次+，持续积累不同场景下的动力阻力触点案例库 |
| **Truman的自述** | "动力阻力触点这个模型，我每年差不多循环调用100次+，但依然迁移不熟练。这个很难啊，是我目前目光所及的山顶，我也刚刚开始，一起爬山吧。" |

## 五、核心地图：转化率黑客爬山地图——L1到L6

> "如果想在未来的3-10年内，持续（带团队）修炼转化率提升的段位，就按照这个爬山地图和基本功清单去练。"

### 5.1 六段位全景

| 段位 | 能力形态 | 核心特征 | 常见问题 | 提升路径 |
|---|---|---|---|---|
| **L1 不想提升** | 陷入低水平重复 | 没有欲望、与我无关、只盯结果不拆过程 | 缺少欲望 | 认识到"转化率提升就是收入/利润提升" |
| **L2 有追求** | 持续追求更好 | 有提升意愿但缺方法，碎片随机、浅尝辄止 | 缺三段论 | 学习"动力阻力触点"三段论并刻意分析 |
| **L3 全局分析** | 稳定使用三段论 | 能习惯性拆解动力阻力触点，用它拿结果、拆同行 | 缺专业分析 | 持续练习"善于提动力、善于消阻力、善于挖触点" |
| **L4 手段专业** | 善于提升动力阻力触点 | 动力三曲线熟练、阻力三层三类精通、触点策略丰富 | 假设太少 | 增加练习数量，让专业工具箱成为肌肉记忆 |
| **L5 迭代领先** | 能持续迭代到领先 | 在关键转化率上通过持续迭代达到行业领先水平 | 迭代不够 | 建立假设池和持续验证机制 |
| **L6 广泛迁移** | 善于迁移+第一次就专业 | 跨领域跨场景条件反射，"动力阻力触点"成为底层操作系统 | 认知难迁移 | 大量跨领域练习，每年循环调用100次+ |

### 5.2 爬山地图的长期价值

```text
转化率黑客不是一个"学了就会"的一次性课程，
而是一个需要3-10年持续修炼的基本功体系。

每爬一个段位：
  → 你面对转化率问题的第一反应就更专业一步
  → 你能提出的假设数量和质量就提升一档
  → 你带团队做转化率提升的效率和确定性就高一截
```

## 六、三个配套工具——认知篇交付的实操抓手

> Truman在认知篇给了三个工具，帮学员从第一节课就开始"动手"。

### 6.1 工具一：动力阻力场景匹配小抄

```text
用途：培养敏感性——面对任何一个转化率场景，
     能快速识别这个场景里典型的动力和阻力是什么。

使用方式：
```
