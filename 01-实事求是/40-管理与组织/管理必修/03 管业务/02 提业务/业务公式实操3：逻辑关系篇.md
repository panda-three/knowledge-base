## 一、为什么要学——破题篇

### 1.1 拆出50-100个参数之后怎么办

> "拆出来的这些参数都和我的结果有关系吗？应该是大还是小？时间有限的情况下，哪个才是我当下这个阶段应该主要关注的参数？"

| 问题 | 表现 | 需要的核心能力 |
|---|---|---|
| **参数太多无法聚焦** | 面对50-100个备选参数，不知道哪些该优先投入 | 逻辑关系判断——从相关到因果 |
| **不会做减法** | 所有参数看起来都重要，资源分散后什么都做不成 | 找到Top参数——抓主要矛盾 |
| **分不清相关和因果** | 把相关关系当成因果关系，盲目投入后发现没用 | 从模糊到相关到因果的三层区分 |
| **不会定量评估** | 只做定性判断（"这个参数很重要"），不做定量分析（"它还能提升多少、ROI多高"） | 从定性到定量 |

### 1.2 本课要回答的核心问题

```text
1. 备选参数中，哪些和结果之间是因果关系？哪些只是相关关系？
2. 哪些参数对结果提升最明显（Top参数）？
3. 哪些应该拉满了疯狂打磨细节，哪些做到60分就行？
4. 因果关系够稳定吗？环境变化后还成立吗？
5. 如何从模糊直觉逐步升级到动态建模？
```

## 二、核心推演：六位业务负责人——逻辑关系深度决定操盘高度

> 这是本课最核心的教学环节。Truman用一个全新案例教学法，假设你是Boss，招募一位业务负责人提升"周五直播作业量"。六位不同水平的业务负责人分别推演，让学员直观感受不同逻辑关系理解深度带来的巨大差距。

### 2.1 案例背景

| 要素 | 内容 |
|---|---|
| **核心指标** | 每周五直播课的学习和作业规模——一堂最重要的活跃粘性指标 |
| **现状** | 2022年，每周学习人数1500人，作业750份 |
| **目标** | 提升50-100% |
| **简化假设** | 教研每周稳定做课、会员在籍规模稳定 |

---

### 2.2 六位业务负责人的逐级推演

#### 第一个：Leo——一堆散点，看到什么抓什么

| 维度 | 状态 |
|---|---|
| **逻辑关系深度** | L1 模糊理解——模模糊糊有一些答案，模模糊糊地决策 |
| **典型动作** | 看数据、聊朋友、头脑风暴，找了很多"抓手"：课程维度/运营维度/产品维度/社群维度/质量维度 |
| **问题** | 拆出的所有参数看起来都重要——因为没有区分相关和因果、主要和次要 |

#### 第二个：Emma——找到了相关关系

| 维度 | 状态 |
|---|---|
| **逻辑关系深度** | L2 相关关系——能区分哪些参数和结果有相关性，哪些无关 |
| **关键进步** | 从一堆散点中剥离出真正有规律的相关参数，用来预测和监控 |

#### 第三个：Lily——找到了简单因果关系

| 维度 | 状态 |
|---|---|
| **逻辑关系深度** | L3 简单因果——找到了能有效做功的参数 |
| **关键进步** | 不再停留在"参数和结果有关"，而是"改这个参数，结果会变" |

#### 第四个：David——建立了业务公式

| 维度 | 状态 |
|---|---|
| **逻辑关系深度** | L4 业务公式——形成体系，能定位主要路径 |
| **关键进步** | 能区分主路径和分支路径。比如"90min留存率"是主要路径（占70%），"纯新人作业率"是分支路径（占30%） |

#### 第五个：Chris——定量公式，精准评估ROI

| 维度 | 状态 |
|---|---|
| **逻辑关系深度** | L5 定量公式——能量化评估空间和ROI |
| **关键洞察** | 定性判断错了——"90min留存率"虽然是主要路径，但提升空间只剩5%；而"纯新人作业率"虽然是分支路径，但空间有50%-100%。**资源投在纯新人的短中期ROI最高。** |
| **核心能力** | 从"定性说重要"到"定量说值得投多少资源" |

#### 第六个：Jay——动态建模，应对参数耦合

| 维度 | 状态 |
|---|---|
| **逻辑关系深度** | L6 动态建模——理解参数耦合和动态变化 |
| **关键发现** | 提升了90min留存率（靠悬念、钩子等），作业率只提升了20%而非预期的35%——因为留存率和留存作业率之间存在**负耦合**：被"钩子"拉进来的用户主动作业欲望更低 |
| **另一个例子** | 作业提醒不是越多越好——1-3轮有效，第4轮价值很低，超过阈值反而激发逆反心理（过犹不及的倒U曲线） |
| **终极能力** | 可以动态预测、勾勒出业务曲线——正常期/案例课/马拉松/春节黄金周，每个阶段的参数表现都不一样 |

### 2.3 六位负责人的核心差距

```text
从Tom到Jay，本质差距不是"谁更努力"，
而是"谁对业务逻辑关系的理解更深"。

Tom：一堆散点，模糊一片
Emma：能找到相关关系，区分什么有关、什么无关
Lily：找到因果关系，知道"动哪个参数有效"
David：形成完整的业务公式，区分主路径和分支
Chris：定量评估每个参数的空间和ROI，精准分配资源
Jay：理解参数间的动态耦合和变化规律，以不变应万变

通常中长周期，需要1-10个季度来迭代。
有些人3-6个月迭代到Jay的水平，
有些人三五年后还是Tom的水平。
```

## 三、核心框架：逻辑关系冰山模型——L1到L6六层

> 这是本课最核心的交付——《参数冰山》的姊妹篇《逻辑关系冰山》。

### 3.1 冰山六层全景

```text
水面之上（表层直觉）
  L1. 模糊理解 —— 安慰剂：模模糊糊有一些答案，模模糊糊地决策
  L2. 相关关系 —— 体温计：将模糊升级成相关性，可以预测和监控

水面之下（深层理性）
  L3. 简单因果 —— 方向盘：将相关性升级成因果性，有有效做功点
  L4. 业务公式 —— X光片：将因果性升级成公式，用体系找主要矛盾
  L5. 定量公式 —— 刻度尺：将公式升级成定量分析，可以精准分析ROI
  L6. 动态建模 —— 导航仪：将公式升级成动态模型，可以探索最佳参数
```

### 3.2 六层详解

| 层级 | 名称 | 价值类比 | 核心能力 | 典型动作 | 典型问题 |
|---|---|---|---|---|---|
| **L1** | 模糊理解 | 安慰剂 | 有一些模糊的直觉判断 | 凭经验、凭感觉、看别人怎么做 | "感觉有用但其实没用" |
| **L2** | 相关关系 | 体温计 | 区分有关和无关的参数 | ①观察规律 ②数据记录 ③专业统计 | "只能预测，不能做功" |
| **L3** | 简单因果 | 方向盘 | 找到能有效做功的因果关系 | ①常识判断 ②逻辑推理 ③控制变量测试 | "参数还不够完备" |
| **L4** | 业务公式 | X光片 | 形成体系，区分主路径和分支路径 | ①参考范式 ②自己创建 | "还不知道提升空间" |
| **L5** | 定量公式 | 刻度尺 | 量化每个参数的空间和ROI | ①逐步定量 ②找基准值 ③判断空间 | "静态理想模型，忽略动态" |
| **L6** | 动态建模 | 导航仪 | 理解参数耦合和动态变化 | ①内部变化 ②外部变化 ③预测建模 | "复杂度急剧攀升" |

### 3.3 一个完整的业务公式是一层层嵌套的

```text
注意边界：这张图研究的是某一层的因果，
而一个完整的业务公式是一层层嵌套的。

不存在完美的公式，
而是围绕重点，一层层往右推进、进化。

随着每一步升级，
你的判断质量、预测质量和假设质量，
都会持续提升和进步。
```

## 四、核心工具：五次飞跃——逻辑关系的逐级进化

> Truman将L1→L6的进化过程拆成五次飞跃，每次飞跃都给了具体的策略参考。

### 4.1 五次飞跃全景

```text
L1 模糊理解 ──第一次飞跃→ L2 相关关系 ──第二次飞跃→ L3 简单因果
                                                              ↓
L6 动态建模 ←──第五次飞跃── L5 定量公式 ←──第四次飞跃── L4 业务公式
```

### 4.2 第一次飞跃：从模糊到相关

| 维度 | 说明 |
|---|---|
| **起始条件** | 对业务模模糊糊的认识、直觉为主 |
| **飞跃动作** | 剥离各种现象，找到有明显规律的"相关关系" |
| **基础方法** | 人肉观察客观事实的规律 |
| **进阶方法** | 主动记录关键结果、过程和相关事实 |
| **专业方法** | 用统计工具做相关性分析 |

**典型场景：**

> 复盘营购买率——10个潜在参数中，哪些有关、哪些无关？学籍率？作业字数？一次作业率？我请客人数？Truman开心心情好？……看似简单，但做新业务早期往往陷入这种模糊一片的境地。

**关键提醒：**

```text
L1阶段通常大家都是直接跳过的——但凡有一些业务经验或业务成熟度较高，通常直接从L3-L5开始。

但有一种情况：没太多经验的新业务。
可能开始完全是模糊和一团黑，需要一点点剥离认知。
```

### 4.3 第二次飞跃：从相关到因果

| 维度 | 说明 |
|---|---|
| **起始条件** | 知道哪些参数和结果相关 |
| **核心挑战** | **相关 ≠ 因果**——很多看似魔术的数字其实不是因果关系 |
| **飞跃方法** | ①常识判断 ②逻辑推理 ③控制变量测试 |

**经典的反面案例（自媒体常见的相关≠因果陷阱）：**

| 新闻/观点 | 可能的真实逻辑 |
|---|---|
| "研究发现，越是成功人士，睡眠时间越短" | 可能是成功人士更愿意宣扬自己睡得少；也可能是经济压力导致睡眠少+拼命工作 |
| "女人结婚后变得更贫穷，男人结婚后更富有" | 可能是收入结构而非婚姻本身的因果关系 |
| "儿童时期吃西兰花越多，成年后职业收入越多" | 吃得起大量西兰花的家庭可能本身社会经济地位更高 |
| "越富有的人越幸福" | 阈值效应——超过一定收入后幸福感不再线性增长 |

### 4.4 第三次飞跃：从因果到业务公式

| 维度 | 说明 |
|---|---|
| **起始条件** | 找到了一些孤立的因果关系 |
| **飞跃动作** | 把散点因果关系组织成体系——区分主路径和分支路径、+-x÷关系 |
| **核心价值** | 不再是一个个孤立的因果判断，而是"我有了体系，知道该抓什么" |
| **方法** | ①参考范式（十大范式）②自己创建 |

### 4.5 第四次飞跃：从公式到定量

| 维度 | 说明 |
|---|---|
| **起始条件** | 有完整的业务公式，但判断停留在定性层 |
| **飞跃动作** | 逐步定量——找到基准值、判断每个参数的可提升空间、进行ROI评估 |
| **经典翻车** | 定性判断说"主要路径最重要"→ 定量一看，主要路径空间仅5%，分支路径空间50%+ |
| **方法** | ①逐步定量 ②找基准值 ③判断空间 |

### 4.6 第五次飞跃：从定量到动态

| 维度 | 说明 |
|---|---|
| **起始条件** | 静态理想模型——假设参数彼此独立 |
| **真实挑战** | 参数之间有复杂的耦合关系 |
| **经典案例** | 提升90min留存率35%，作业率只提升20%——因为留存率提升的"钩子"降低了用户的主动作业欲望（留存率↑ 导致 留存作业率↓） |
| **另一个案例** | 作业提醒1-3轮有效，第4轮价值极低，超过阈值反而引发逆反→过犹不及的倒U曲线 |
| **方法** | ①内部变化分析 ②外部变化预判 ③预测建模 |

## 六、逻辑关系的五大核心价值

> Truman从"挖掘逻辑关系"的角度，总结了五个从入门到高阶逐步形成的操盘能力。

| 价值 | 含义 | 从→到 | 典型应用 |
|---|---|---|---|
| **价值1：理解规律** | 理解结果和什么关键过程相关 | 避免模糊 | 知道作业率和哪些参数真正相关，而非凭感觉 |
| **价值2：找到抓手** | 找到可以驱动进步的做功点 | 避免徒劳 | 不再把所有参数都当抓手，而是聚焦到有效因果参数 |
| **价值3：主要矛盾** | 通过分析加减乘除找到主要路径 | 找突破口 | 区分主路径（贡献70%）和分支路径（贡献30%） |
| **价值4：定量评估** | 准确评估业务空间和数据 | 形成准确分析 | 定性+D定量综合判断（主路径空间5% vs 分支空间50%） |
| **价值5：动态理解** | 动态理解业务变化 | 以不变应万变 | 理解参数耦合、倒U曲线、季节性波动 |

## 七、业务公式的重新理解——业务负责人的核心任务

> Truman在课程最后，送给学员三句重新理解，提炼业务负责人的本质。

### 7.1 三句话

| 金句 | 含义 |
|---|---|
| **第一句** | 业务公式是业务负责人的"核心学习工具"——不是一个静态文档，而是不断迭代、螺旋上升的过程 |
| **第二句** | 参数篇训练你的"见识"（看到更多可能），逻辑关系篇训练你的"专业"（判断什么最重要） |
| **第三句** | 业务负责人最核心的任务，就是持续探索因果关系、提出高质量假设、用实验结果迭代认知 |

| 段位 | 核心能力 | 典型表现 | 对应L层 |
|---|---|---|---|
| **L1 模糊感觉** | 凭直觉、凭经验 | "我感觉这个参数应该有用"——没有数据、没有验证 | L1 |
| **L2 看相关** | 能区分有关和无关 | 知道哪些参数和结果有明显的相关性，可以预测和监控 | L2 |
| **L3 找因果** | 找到有效的做功点 | 通过控制变量/A/B测试，确认"改变A会带来B的变化" | L3 |
| **L4 建体系** | 形成完整业务公式 | 能区分主路径和分支路径，有完整的+-x÷体系 | L4 |
| **L5 精定量** | 精准评估空间和ROI | 知道每个参数还能提升多少、值不值得优先投入 | L5 |
| **L6 懂动态** | 理解参数耦合和变化规律 | 能预判参数间的相互影响、外部变化带来的冲击，能动态调整 | L6 |

## 十、L6 刻意练习自检清单

### 逻辑关系认知——你目前处在哪个阶段

- [ ] 对照六位业务负责人的推演（Tom→Emma→Lily→David→Chris→Jay），你更像哪一位？
- [ ] 回顾最近三个月的业务管理——你做决策更多靠"模糊直觉"还是"定性因果"还是"定量分析"？
- [ ] 你有没有过"原来是相关关系，不是因果关系"的觉醒时刻？

### 相关→因果——你是否在区分

- [ ] 你的业务公式里，哪些参数和结果之间是因果关系，哪些只是相关关系？
- [ ] 你有没有用控制变量/A/B测试验证过至少一个关键的因果关系？
- [ ] 你是否能识别"自媒体式的伪因果关系"（如"成功人士睡得少"）——在你的业务中有类似的自欺欺人吗？

### 主要矛盾——你是否找到了关键路径

- [ ] 你的业务公式里，主路径是什么（贡献最大的一条因果链）？分支路径是什么？
- [ ] 主路径上还有多少可提升空间？分支路径上呢？（能否给一个量化的判断？）
- [ ] 你有没有做过"定性判断被定量数据推翻"的经历？

### 定量评估——你是否在算账

- [ ] 你最重要的5-10个参数，每一个的基准值是什么？行业标杆值是多少？你还有多少提升空间？
- [ ] 你的资源当前主要投在主路径还是分支路径？ROI最高的投入方向是否清晰？

### 动态理解——你是否看到了耦合

- [ ] 你的业务中，有没有两个参数之间存在"此消彼长"的耦合关系（类似留存率↑→主动作业率↓）？
- [ ] 你有没有发现过"过犹不及"的倒U曲线——推某个参数过度反而导致整体结果下降？
- [ ] 你是否能区分业务曲线的不同阶段（正常期/活动期/节假日/特殊事件），并对每个阶段有不同的参数预期？

### 综合自检

- [ ] 对照逻辑关系冰山六层（L1-L6），你当前在哪一层？下一层最需要突破的是什么？
- [ ] 回顾过去一年，你对业务逻辑关系的理解有没有一次"质的飞跃"？是哪次实验/复盘带来的？
- [ ] 你的团队中，不同水平的业务负责人，是否处在不同的逻辑关系段位上？如何帮他们升级？
- [ ] 你是否愿意把"持续探索逻辑关系"作为一个长期刻意练习的高阶基本功——用10年周期去修炼？
