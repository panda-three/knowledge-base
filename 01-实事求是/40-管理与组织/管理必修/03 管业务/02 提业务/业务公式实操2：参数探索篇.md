## 一、为什么要学——破题篇

### 1.1 参数挖掘是业务认知的核心

> "我开篇说：做业务就是不断在探索参数的过程。"

| 状态 | 表现 | 根本原因 |
|---|---|---|
| **参数太少** | 公式里只有3-5个粗参数（流量×转化率×客单价），拆不出更多 | 没有系统化的参数挖掘方法，只会靠直觉列最明显的参数 |
| **参数太浅** | 全是基础参数和财务参数，没有深入到分层、转化、创新层 | 靠经验做事，没有靠分析、靠创新去挖掘更深层的参数 |
| **不会涌现** | 面对一个业务目标，找不到新的优化角度和增长假设 | 没有掌握"从上往下拆解"和"从下往上涌现"的双向参数挖掘方法 |

### 1.2 本课要回答的核心问题

```text
1. 除了那些"显而易见"的基础参数，我还能从哪些角度挖掘新参数？
2. 不同段位的业务负责人，挖掘参数的深度有什么不同？
3. 有没有一套"泛业务负责人"通用的参数挖掘框架——不管什么岗位、什么行业都能用？
4. 参数多了以后，怎么组织和管理（为下节课的"减法"做前置准备）？
```

## 二、热身案例：两个真实业务的参数挖掘

### 2.1 案例一：一堂复盘营

> Truman用复盘营4年200期的数据，展示了随着时间推移，围绕"完成作业率"这个目标，参数是如何从几个演化到几十个的。

| 阶段 | 参数数量 | 典型参数 |
|---|---|---|
| **早期** | 5-10个 | 用户数、作业提交率、完课率、NPS |
| **中期** | 20-30个 | 增加分层参数（按用户类型/报名渠道切）、转化参数（拆首单/拆LTV） |
| **后期** | 50+个 | 增加创新参数（如"3次作业率"这个魔法数字）、探索动作参数 |

### 2.2 案例二：杜金科西安地区门店运营

> 一个线下门店运营业务，展示如何从"看总营收"这种粗参数，一步步深入到分层、转化甚至创新参数。

**两个案例的共性规律：**

```text
参数越多 ≠ 越散乱。
真正的业务高手，能让参数形成体系——
从粗到细、从浅到深、从借鉴到创新。
```

## 三、核心框架：参数冰山模型——L1到L6六层参数

> 这是本课最核心的交付——一张被Truman称为"一张图用10年20年"的参数冰山模型。

### 3.1 设计初衷：服务"泛业务负责人"

```text
我们在想，能不能做一个模型服务于"泛业务负责人"——
各个岗位都能用，足够系统，足够底层本质，
能够长期修炼和跨领域迁移？

不管过去是什么项目/岗位，不管未来是什么项目/岗位，
都能用这套底层的方法来指导自己完成
从X（几个参数）到Y（几十上百个参数）的提升。

一旦习惯并且掌握，我们可以超越具体岗位，
跨领域迁移经验，用10年的周期去修炼自己的业务管理能力。
```

### 3.2 参数冰山六层全景

```text
水面之上（靠经验，初阶，直觉）
  L1. 基础参数：大块的、常规的参数
  L2. 财务参数：和钱直接相关的财务指标

水面之下（靠分析，进阶）
  L3. 分层参数：不同维度切片指标（加法为主）
  L4. 转化参数：不同环节转化指标（乘法为主）

水底深处（靠创新，高阶，本质）
  L5. 创新参数：自己挖掘/定义的特别的指标
  L6. 魔法参数：探寻撬动巨大价值的黄金参数
```

### 3.3 六层详解

#### L1. 基础参数——大块的、常规的参数

| 维度 | 说明 |
|---|---|
| **核心特征** | 粗粒度、标准化、凭直觉就能列出来 |
| **典型参数** | 粗流量（线上教育的"体验课用户数"、线下业务的"客流量"、线上流量的"注册用户数"、DAU/MAU） |
|  | 粗线索（落地页的"曝光量/点击量"、App的"下载量/激活量"） |
|  | 粗订单、粗收入 |
| **适用阶段** | 任何业务的起点——你至少得知道这些 |
| **局限性** | 只能描述"发生了什么"，不能解释"为什么发生"和"怎么优化" |

#### L2. 财务参数——和钱直接相关的财务指标

| 维度 | 说明 |
|---|---|
| **核心特征** | 考验算账能力——能不能把业务翻译成财务语言 |
| **典型参数** | 收入部分：客单价、转化率、ARPU（平均每用户收入）、LTV（用户生命周期价值） |
|  | 成本部分：获客成本CAC、货损率、退费率、坏账率 |
|  | 单元模型：算单元模型、算关键指标、算财务模型 |
| **核心价值** | 从"感觉赚钱"到"算清楚赚不赚钱" |
| **一堂关联** | Truman强调："如果大家没有刻意训练过商业分析，强烈建议大家认真学一下《单元模型》系列课" |

#### L3. 分层参数——不同维度切片指标（加法为主）

| 维度 | 说明 |
|---|---|
| **核心特征** | 考验切片能力——能不能把整体拆成有意义的分群 |
| **五大切片方向** | ①切用户（客观标签：收入/性别/成绩/年龄/学历/婚育/城市/职业身份；认知深度：资深-小白/入门-进阶-高阶/入行年限） |
|  | ②切渠道（不同来源的用户表现差异） |
|  | ③切行为（不同行为路径的用户分群） |
|  | ④切场景（线上vs线下、不同门店、不同时段） |
|  | ⑤切SKU（不同产品/服务的表现差异） |
| **ToB额外维度** | 公司水平（是否连锁/公司收入/是否500强/行业位置）、公司特性（账期要求/是否新开业务/信息化程度） |

#### L4. 转化参数——不同环节转化指标（乘法为主）

| 维度 | 说明 |
|---|---|
| **核心特征** | 考验拆解能力——能不能把用户/客户旅程拆成独立的转化环节 |
| **四大拆解方向** | ①拆首单（转化漏斗：ToC页面停留率/点击率/付费率、门店捕获率/试衣率/付款率、线上到场率/意向率/成交率、ToB沟通率/定金率/尾款率） |
|  | ②拆LTV（续转：二次转化率/三次转化率、升单：连带率/升高客单率） |
|  | ③拆动作（PC学习率/PC作业率、复盘营3次作业率、会销亲子现场相互感谢率、阅读免费章节读完率） |
|  | ④拆筛选 |
| **核心价值** | 从"整体转化率低"变成"第3步到第4步的转化率特别低，优先优化这里" |

#### L5. 创新参数——自己挖掘/定义的特别的指标

| 维度 | 说明 |
|---|---|
| **核心特征** | 考验探索能力——能不能定义出行业内没有、但对你业务特别关键的指标 |
| **三大探索方向** | ①探索动作（人无我有——预定租房的"踩点率"、2B谈客户的"投屏连接率"、百货超市的"商品拿起率"） |
|  | ②探索数值（公众号投放的"单阅价值"、门店的"服装试衣率"） |
|  | ③探索组合 |
| **核心价值** | 从"抄同行指标"到"定义自己的竞争壁垒指标" |

#### L6. 魔法参数——探寻撬动巨大价值的黄金参数

| 维度 | 说明 |
|---|---|
| **核心特征** | 考验本质洞察——找到那些看似微小、但一旦改变就能撬动巨大结果的"魔法数字" |
| **三大本质方向** | ①销售本质（高转化率背后的核心驱动动作） |
|  | ②留存本质（持续使用的关键行为节点） |
|  | ③复购本质（反复购买的核心触发条件） |
| **经典魔法参数案例** | Slack：新客户团队交换2000条消息→后续留存和复购奇高 |
|  | 某2B SaaS：60天内完成系统部署→第二年续费率非常高 |
|  | 某手机游戏：新手获得3次MVP→7日留存率显著增高 |
|  | 某会议软件：新用户发起3次会议→90天留存率显著提升 |
|  | Facebook：新用户7天内添加≥10个好友→次月留存率大幅提升 |
|  | Duolingo：用户连续5天完成课程→1年留存率大幅提升 |
|  | 某儿童教育会销：家长相互感谢成长→成交率大幅提升 |
|  | 一堂复盘营：3次作业率→长期留存和复购显著提高 |

> **⚠️ Truman的重要提醒："很多看似魔术的数字，其实不是因果关系只是相关关系，可以预测但是价值低了很多，很难直接提升业务。这个背后得靠严谨的数据和逻辑判断，这是下节课的内容。"**

## 四、参数的五大价值——为什么要持续挖掘参数

> Truman在课上总结了挖掘参数、获得更高水平公式的五大价值。

| 价值类型 | 价值 | 含义 | 具体作用 |
|---|---|---|---|
| **业务价值** | **价值1：激发假设** | 可以大量提优化假设，无限提&轰炸假设 | 不再是"想不出新招"，而是沿着新参数自然涌现优化方向 |
| | **价值2：辅助决策** | 辅助定价、用户、重大策略调整 | 当你要调整价格/切换目标用户/改策略时，参数体系提供决策依据 |
| | **价值3：预测复盘** | 可以提前做预测，事后做复盘 | 预测"改这个参数，目标会变多少"；复盘"实际和预测差在哪" |
| **管理价值** | **价值4：专业分工** | 可以更好地做目标管理和组织分工 | 不同参数对应不同团队/岗位，分工边界清晰 |
| | **价值5：专业协作** | 可以更好向上汇报，靠谱同事协作 | 向上汇报有数据支撑；横向协作有共同语言 |

| 参数层 | 策略 | 核心动作 | 典型参数示例 |
|---|---|---|---|
| **L3. 分层参数** | 考验切片 | ①切用户 ②切渠道 ③切行为 ④切场景 ⑤切SKU | 用户客观标签（收入/性别/年龄/城市）、认知深度（资深-小白）、公司水平（是否500强/行业位置）、ToB账期要求 |

| 参数层 | 策略 | 核心动作 | 典型参数示例 |
|---|---|---|---|
| **L5. 创新参数** | 考验探索 | ①探索动作 ②探索数值 ③探索组合 | 预定租房踩点率、2B投屏连接率、百货商品拿起率、公众号单阅价值、服装门店试衣服率 |
| **L6. 魔法参数** | 考验本质 | ①销售本质 ②留存本质 ③复购本质 | 3次作业率、2000条消息、60天内部署、3次MVP、10个好友、连续5天 |

### 5.5 两条参数挖掘路径

```text
从上往下拆解（初阶→进阶）：
  流程梳理 → 已有经验 → 逻辑推理 → 最佳实践
  把粗参数一层层拆细——适合L1-L4

从下往上涌现（高阶）：
  异常分析 → 变化归因 → 范式迁移 → 大胆假设
  从业务现场的反常信号中发现新参数——适合L5-L6
```

## 六、重新理解业务公式的六大关键价值

> Truman从"面向现在、面向未来、面向协作"三个维度总结了业务公式的六个核心价值。

| 面向 | 维度 | 从→到 | 价值 |
|---|---|---|---|
| **面向现在** | 全局 | 从局部到全局 | 维度很多，基于维度找到忽略的参数 |
| | 效率 | 从直觉到高效 | 沿着公式提假设，才不是散点的，能判断是不是主要路径 |
| **面向未来** | 迭代 | 从卡住到突破 | 可以源源不断的优化、迭代和创新 |
| | 想法 | 从临时到持续 | 系统性的分析方法，可以大量涌现 |
| **面向协作** | 协作 | 从独立到协作 | 可以用来说服团队，形成共识，协作 |
| | 心态 | 从焦虑到笃定 | 能解释业务，能说服自己，有了信心和笃定 |

## 七、参数迭代的节奏规律

> "这是大概的经验值，不同业务、层级的具体数量都不太一样。"

| 周期 | 参数状态 | 典型动作 |
|---|---|---|
| **单次项目** | 参数很少（5-10个） | 从基础参数和财务参数开始 |
| **1-3个季度** | 参数逐步增加（20-50个） | 加入分层参数和转化参数 |
| **3-10个季度** | 参数体系成熟（50-100+个） | 涌现创新参数，探索魔法参数 |

> **核心规律：通常中长周期，需要1-10个季度来迭代。不是一次性能拆出来的，而是在业务实战中一层层深入的。**

## 八、从参数探索到逻辑关系——承上启下

> Truman在课程结尾，为下节课《逻辑关系篇》做了铺垫。

```text
本课（参数探索篇）：加法——拆出了几十上百个参数。
下节（逻辑关系篇）：减法——

面对50-100个备选参数：
  → 哪些参数和结果之间是因果关系，哪些只是相关关系？
  → 哪些参数对结果提升最明显（Top参数）？
  → 哪些应该拉满了疯狂打磨细节，哪些做到60分就行？

加法考验见识，减法考验专业。
这节课很难，但是很高阶——
这基本上是成熟业务负责人最核心的能力了。
```

## 九、参数修炼段位成长地图

| 段位 | 核心能力 | 典型参数状态 | 核心动作 |
|---|---|---|---|
| **L1 只有粗参数** | 凭直觉列参数 | 3-5个基础参数（流量×转化率×客单价） | 先把业务公式写出来 |
| **L2 会算账** | 有财务参数 | 基础参数 + 客单价/转化率/CAC/LTV等财务参数 | 算单元模型、算财务模型 |
| **L3 会切片** | 有分层参数 | 按用户/渠道/行为/场景/SKU切出多维度参数 | 找到不同分群的表现差异 |
| **L4 会拆解** | 有转化参数 | 完整的多环节转化漏斗参数 | 定位"哪一步转化最差" |
| **L5 能创新** | 有创新参数 | 能定义出行业内没有、但对业务关键的新参数 | 从异常分析和范式迁移中发现新参数 |
| **L6 懂本质** | 有魔法参数 | 找到了撬动巨大价值的黄金参数 | 从相关关系中识别出因果关系并验证 |

## 十一、L6 刻意练习自检清单

### 参数数量——你的参数够多吗

- [ ] 你当前业务的公式里，总共有多少个参数？（5个以下？10-20个？50+个？）
- [ ] 对照参数冰山六层（L1-L6），你的参数目前覆盖了哪几层？最缺的是哪一层？
- [ ] 你是否能沿着"从上往下拆解"的路径，把现有的粗参数继续往下拆2-3层？

### 参数质量——你的参数在哪个段位

- [ ] L1基础参数：你的粗流量/粗线索/粗订单/粗收入参数是否已经被更细的参数替代了？
- [ ] L2财务参数：你是否算清楚了单元模型、客单价、CAC、LTV这些关键财务指标？
- [ ] L3分层参数：你是否按至少2-3个维度（用户/渠道/行为/场景/SKU）切分过参数？
- [ ] L4转化参数：你是否把客户旅程拆成了独立的转化环节，并追踪每个环节的转化率？
- [ ] L5创新参数：你有没有一个"人无我有"的、自己定义的关键参数？
- [ ] L6魔法参数：你有没有找到一个看似微小、但一旦改变就撬动巨大结果的黄金参数？

### 参数挖掘——你在用哪条路径

- [ ] 你更常用"从上往下拆解"（流程梳理→已有经验→逻辑推理→最佳实践），还是"从下往上涌现"（异常分析→变化归因→范式迁移→大胆假设）？
- [ ] 你上一次从"异常分析"中发现一个新参数，是什么时候？
- [ ] 你有没有跨行业借鉴过参数（范式迁移）——看看别的行业的公式，能不能启发你的参数挖掘？

### 参数价值——参数是否在驱动业务

- [ ] 你的参数是否在"激发假设"——你最近一次沿着新参数提出的增长假设是什么？
- [ ] 你的参数是否在"辅助决策"——你上一次用参数来支撑一个重大业务决策是什么？
- [ ] 你的参数是否在"预测复盘"——你能不能预判"改这个参数，目标会变多少"？
