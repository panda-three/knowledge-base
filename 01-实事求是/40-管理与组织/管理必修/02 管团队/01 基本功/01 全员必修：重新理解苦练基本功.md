## 〇、课程总纲

> **"新手都在走捷径，高手都在苦练基本功。基本功才是一个人，一家公司，真正的底牌。"** —— Truman

这门课是一堂业务地图到管理地图的衔接器，是一个优秀业务通向优秀团队建设最核心的"业务连接器"。它回答了创业者和管理者长期困惑的核心问题：**到底什么是基本功？如何高效、科学地修炼基本功？**

## 一、为什么必须学——破题篇

### 1.1 三位高手的共识

| 人物 | 身份 | 核心观点 |
|---|---|---|
| **王兴** | 美团创始人 | "在互联网上半场，基本功不太好，还可以靠红利、靠战略、靠资源。在互联网下半场，基本功不过关，活下去都很难。" |
| **刘润** | 知名顾问 | "越是不确定，越要修炼基本功。真正的高手，都在苦练基本功。" |
| **韩宇** | 《这就是街舞》总冠军 | "大家跳舞总是关心动作帅不帅，大家真的别把重点搞反了——基本功决定一切。" |

> **共同关键词：基础套路、极其重要、高手背后的策略、长期重复。**

### 1.2 市场上关于"基本功"的普遍问题

| 问题 | 表现 |
|---|---|
| **概念不清** | 要么观点碎片不成体系，要么只谈概念不明所以 |
| **缺少明确定义** | 团队经常出现理解分歧，很难一层层向下灌输 |
| **无法拆解** | 知道内容/投放/销售/私域能力强，但说不清这些能力背后是怎么一步步刻意练出来的 |
| **没有方法论** | 找不到一套真正普适有效的、底层的方法论 |

### 1.3 大多数人没认真想过的问题

```text
1. 到底什么才是基本功，底层逻辑是什么？
2. 如何从日常工作里，识别出背后的基本功？
3. 练基本功的要素有哪些？如何最高效率练习基本功？
4. 基本功如何从个人能力变成团队可复制的组织能力？
```

## 二、核心定义——基本功的实质

### 2.1 一句话定义

> **"基本功"是团队能力的最小单位。**

| 对比维度 | 传统理解 | 一堂定义 |
|---|---|---|
| **组织能力的颗粒度** | 人是最小单位 | 基本功才是最小单位 |
| **能力复制的对象** | 招对的人、靠个人经验带 | 把一个一个基本功拆出来、建模、复制 |
| **对标概念** | —— | 如同"单元模型是商业模式的最小单位"，基本功是组织能力的最小单位 |

### 2.2 基本功的本质逻辑

```text
公司能力的增长，在于培养人
人的能力复制，本质上是在复制一个个基本功

不管你有没有意识到
不管你是主动复制还是凭直觉和手感
客观事实上，团队做事能力的背后，就是由一个个基本功组成的
```

### 2.3 公司只有两类基本功

| 类型 | 核心目标 | 举例 |
|---|---|---|
| **确定性工作** | 总结套路，保证稳定执行，不出错 | SOP、清单、标准化流程 |
| **不确定性工作** | 总结套路，保证持续提升，越练越好 | 创意方法、决策模型、萃取框架 |

## 三、核心工具①：基本功三环分析模型

> **"一个好的基本功，是针对具体的工作场景，找到独立、可检验的动作，来实现不断重复练习，最终形成长期巨大复利。"**

### 3.1 三环全景图

```text
               足够务实（场景性 + 具体性）
                      ↑
                      |
    足够可练 ← —— 关键基本功 —— → 足够价值
  （独立性+检验性）              （重复性+复利性）
```

### 3.2 六维度详解

| 维度 | 核心问题 | 正例 | 反例 |
|---|---|---|---|
| **场景性** | 是否服务真实的工作场景？ | 写预热思考题（做课场景） | 练口才（场景太泛） |
| **具体性** | 是否非常具体，可以建模和教学？ | 写逐字稿、记笔记、灵感闪现 | 提高表达能力（太模糊） |
| **独立性** | 是否是一连串完整动作，可独立交付？ | 开项目启动会 | "说话清晰"（不是完整动作） |
| **检验性** | 是否一动手就知道会不会、水平高低？ | 画线框图、做BA对比 | "有产品感"（无法检验） |
| **重复性** | 是否可以大量重复、大量迁移、高频使用？ | 写逐字稿（每次做课都能练） | 一次性的特殊任务 |
| **复利性** | 持续进步对于团队、公司的长期价值是否大？ | 记笔记（知识资产复利） | 换灯泡（没有复利积累） |

### 3.3 三环铁律

| 铁律 | 说明 |
|---|---|
| **不能过大** | 违背具体性，不能建模，模糊宏大没有意义 |
| **不能过小** | 违背独立性，无法独立使用和检验，也很难迁移 |
| **六维度权重** | 占越多越好，但不要求满分；按实际场景取舍 |
| **找金三角交集** | 足够务实 × 足够可练 × 足够价值三圈交汇处 = 关键基本功 |

### 3.4 颗粒度阶梯（同一能力的向下拆解）

```text
做课能力
  → 写作能力
    → 写逐字稿能力
      → 预热思考题能力    ← 这个层级最贴近"可练"的基本功

销售能力
  → 1v1电话销售能力
    → 开场白基本功
      → 开场一句话打招呼   ← 具体、独立、可检验
```

> **颗粒度判断原则：在哪一个层级上，六维度的交集最大、最均衡，那个层级就是当前阶段最该练的基本功。**

## 四、基本功实施的四大难关 = 四大必备要素（拆·建·推·练）

> 真正能把四步走完，并且扎扎实实，哪怕就长期练一个基本功的团队，市场上占比都很低。

### 4.1 四大难关全景

```text
拆 ← → 建 ← → 推 ← → 练
(拆出关键)  (建立模型)  (推动落地)  (大量重复)
```

| 要素 | 核心任务 | 一句话解释 |
|---|---|---|
| **拆 — 拆解出来** | 识别背后重复工作 | 从日常工作中，把那些反复出现、决定质量的关键动作剥离出来 |
| **建 — 建立模型** | 建立做事的固定套路 | 把剥离出来的动作写成可执行、可检查、可迭代的模型/套路 |
| **推 — 推动落地** | 让基本功真正发挥作用 | 用氛围、制度、话语体系让团队真正接受并开始练习 |
| **练 — 反复重复** | 不断鼓励大量重复 | 通过机制保障，让团队持续大量重复，练出肌肉记忆和核心能力 |

### 4.2 四大难关详细拆解

#### 第一关：拆（缺意识）

| 卡点 | 表现 | 解法方向 |
|---|---|---|
| 没有意识到能力背后有重复工作 | 只埋头做事，不思考"这件事背后的底层动作是什么" | 建立基本功意识，从复盘开始 |
| 识别不出来 | 觉得每件事都是独特的，看不出可复用的动作单元 | 用工作流拆解、专家拆解、复盘拆解 |
| 拆得太粗/太细 | 要么是"销售能力"这种大词，要么是"拿笔"这种无意义动作 | 用三环模型的六维度校准颗粒度 |

#### 第二关：建（缺建模）

| 卡点 | 表现 | 解法方向 |
|---|---|---|
| 没有形成固定套路 | 有经验但全在脑子里，别人学不会 | 写出来、可视化、做成文档/模型 |
| 模型太模糊 | "要做好""要认真"这种无法执行的原则 | 做到N步法、公式、清单、Checklist级别 |
| 缺知识萃取能力 | 专家不愿意分享"绝活"，或说不清楚 | 攻坚会、头脑风暴、建池子、复盘萃取 |

#### 第三关：推（缺落地）

| 卡点 | 表现 | 解法方向 |
|---|---|---|
| 大家不喜欢苦和重复 | 口头说好，行为不变，继续老习惯 | 文化先行（挂在嘴边+文化墙+口号化） |
| 觉得"太基本了"不屑练 | 老员工觉得简单，新人觉得太难 | 段位划分（SABC分级），匹配阶段练习 |
| 看不到短期成效就放弃 | 练了一两周没效果就停了 | 过程激励、小胜仗、Flag驱动（每次追求20%迭代） |

#### 第四关：练（缺重复）

| 卡点 | 表现 | 解法方向 |
|---|---|---|
| 热乎一下应付领导 | 启动时热火朝天，几周后恢复原样 | 机制化：制定计划+记录过程+定期复盘 |
| 很难持续 | 练了几次就断 | 用制度保障：考核+晋升+薪酬激励绑定 |
| 很难大量重复 | 练习机会少、频次低 | 训练任务+复盘会议+日常例会强调基本功 |

## 五、基本功的四大分类与四大追求

### 5.1 四大分类

| 分类 | 特点 | 示例 | 核心追求 |
|---|---|---|---|
| **A. 创造类工作** | 开放选项，成功率不高，需要手感甚至创意 | 写文案、写脚本、选址、选品、做创意、做选择 | **专业化** — 摆脱运气和手感 |
| **B. 专业类工作** | 需要非常专业，市场上有大量最佳实践 | 销售、投放、私域运营、面试、开会、复盘、写作、逐字稿 | **领先化** — 摆脱业余和新手 |
| **C. 领先类工作** | 公司甚至行业的核心能力，有机会领先 | 做课、IP孵化、编导、规模获客、精细运营 | **标准化** — 摆脱固化和守旧 |
| **D. 标准类/SOP类工作** | 确定性极强，很标准，稳定执行不出错 | 社群运营、门店运营、品控、邮寄、排班、闭店 | **SOP化** — 摆脱不稳和风险 |

### 5.2 四类工作的演化路径

```text
创造类工作 ──专业化→ 专业类工作 ──领先化→ 领先类工作 ──标准化→ 标准类工作 ──SOP化→ SOP类工作

越往左：越靠灵感和手感，开放性强，不确定性高
越往右：越靠标准和流程，确定性高，可复制性强
```

### 5.3 四大追求一句话总结

| 追求 | 一句话 |
|---|---|
| **专业化** | 把靠运气和手感的工作，变成有方法、有审美的专业能力 |
| **领先化** | 把专业能力练到行业领先水平，形成竞争壁垒 |
| **标准化** | 把领先能力抽象成可复制、可教学的稳定模型 |
| **SOP化** | 把标准模型固化成100%执行、不出错的流程 |

## 六、一个完整基本功的五个关键要素

> **基本功不是一蹴而就的，而是一步步从模糊到具体，从混乱到一致，从空壳到完整。**

| 要素 | 含义 | 示例（以"十层解读"为例） |
|---|---|---|
| **1. 名字** | 有一个明确的、独一无二的名字 | "十层解读" |
| **2. 场景** | 明确哪些场景需要使用这个基本功 | 做课时需要深入解读一个核心概念/Y模型 |
| **3. 原则方法** | 基本功的模型或指导原则 | 挑战用10个不同角度解读同一个东西 |
| **4. Case** | 参考案例（正面/负面），帮助理解好与坏 | Truman用10个角度解读Y模型的案例 |
| **5. 配套练习** | 有哪些课程/材料/机会可以练习 | 教研做课时每次都可以用，新人Landing训练任务 |

> **演化规律：绝大多数基本功都是从初步想法（假设），一步步补全、从残缺到完整，最后升级为全面的。**

## 七、苦练基本功修炼段位图（L1-L6）

> 这是一堂发布的完整六段位成长地图。

| 段位 | 状态 | 核心能力 | 常见卡点 | 提升路径 |
|---|---|---|---|---|
| **L1 不想练习** | 只埋头做事，不练习 | 能够完成业务任务 | 缺练习意识、只埋头做事、只空喊口号、嫌弃"太基本"、不愿意吃苦 | 建立基本功意识——从"做事"到"练功" |
| **L2 渴望练习** | 鼓励团队练习基本功 | 有练习的渴望和意识 | 缺拆解能力、缺认真拆解、不善起名字 | 拆——学会从工作里拆出关键基本功 |
| **L3 能拆基本功** | 能分解出关键基本功 | 能识别和拆解出团队的核心基本功 | 缺建模能力、缺建模意识、缺知识萃取、缺统一标准 | 建——把拆出来的动作建立成可执行的模型 |
| **L4 善于建模** | 建立稳定的练习模型 | 能把基本功做成固定套路和模型 | 缺带练能力、缺以身作则、缺循序渐进、缺全员练习 | 推+练——推动团队共识，开始大量练习 |
| **L5 大量练习** | 逐步推动大量练习 | 团队稳定地、大量地、标准地练习基本功 | 缺无限迭代、缺持续反馈、缺持续复盘、缺无限进步 | 持续迭代——建立反馈和复盘机制 |
| **L6 快速迭代** | 持续迭代，无限进步 | 基本功体系持续升级，团队能力螺旋上升 | 自我满足、停止对标更高标准 | 无限进步——保持不满足，持续对标最佳实践 |

### 7.1 一堂自己的进阶历程（Truman实战参照）

| 阶段 | Truman的管理状态 | 标志性事件 |
|---|---|---|
| **第一阶段：个人刻意练习** | 2015-2016年接触《刻意练习》，自己练写作、用户场景分析、讲课、标题、产品设计、ROI讲道理 | "一年的成长比过去三年都多得多。竟然有人开始觉得我是文案高手、讲课高手、产品高手了。" |

## 八、关键基本功拆解落地最佳路径图

> **中心思想：不见兔子不撒鹰（ROI 思维），随着认知和价值逐步增加，逐步细化和加重投入。**

### 8.1 拆解的四个来源

| 拆解方法 | 具体内容 |
|---|---|
| **靠框架拆** | 工作流/业务模块拆解 |
| **靠专家拆** | 高手/师傅/销冠的隐性经验萃取 |
| **靠外部拆** | 同行/最佳实践的逆向工程 |
| **靠复盘拆** | 项目复盘/复盘会中发现的重复成功/失败动作 |

### 8.2 基本功演化的两个模式

```text
模式一（自下而上）：先练素质，再搭架构
  先让团队在一个具体基本功上练出体感 → 再扩展到更多基本功 → 再形成体系

模式二（自上而下）：先搭架构，再填内容
  先规划好团队需要哪些基本功体系 → 再逐步拆解每个基本功 → 再落地练习
```

> **关键建议：先从下往上练素质，再从上往下搭架构。**
>
> — 不要过早细化未经验证的基本功。
> — 不要过早推行未经思考的基本功。

### 8.3 基本功升级的质变点

当出现以下信号时，意味着基本功需要进入下一阶段：

| 质变信号 | 说明 |
|---|---|
| **稳定重复** | 发现某个动作被反复做，而且每次的做法和结果有规律 |
| **必经之路** | 发现某个动作是绕不开的关键环节，做不好就整体失败 |
| **认知成熟** | 对某个动作的理解已经足够清晰，可以写出来教给别人 |
| **分层矛盾** | 老手觉得太简单、新手觉得太难——需要划分段位SABC |
| **组织扩大** | 团队人数增加，靠口头传帮带不够用了，需要文档化和制度化 |

## 九、基本功化的本质：把工作单元变成团队的刻意练习

### 9.1 核心底层逻辑

> **"我本身就在执行SOP/写逐字稿/开周会，为什么还要提'基本功化'？"**

```text
完全不一样。

执行SOP的核心目标：把这件事稳定做完。
基本功化的核心目标：把一个工作单元，转化成团队的刻意练习。

刻意练习的基础：刻意（强目标感，专注，高追求）
刻意练习4大必要要素：套路 + 非舒适区 + 重复 + 反馈
```

### 9.2 基本功 vs 普通执行

| 维度 | 普通执行 | 基本功化 |
|---|---|---|
| **目标** | 完成这次任务 | 让团队这次比上次做得更好 |
| **标准** | 不出错就行 | 每次追求20%迭代升级 |
| **过程** | 做完就结束 | 做完后复盘、提炼、更新模型 |
| **沉淀** | 经验留在个人脑子里 | 经验变成团队的文档/模型/SOP |
| **重复** | 下次凭手感做 | 下次按升级后的套路做 |

## 十一、L6 刻意练习自检清单

### 意识层——你是否具备了基本功意识

- [ ] 你是否能从日常工作中，识别出那些反复出现、决定质量的关键动作（而不只是"把活干完"）？
- [ ] 你是否能从团队成员的"高手"和"普通"表现差异中，倒推出哪些可练的基本功导致了差异？
- [ ] 你是否经常问："这件事背后，有没有可以被反复练习的基本功？"
- [ ] 你是否理解并接受了"基本功是团队能力的最小单位"这个底层逻辑？

### 判断层——你拆出来的基本功是否够"关键"

- [ ] 你用三环模型六维度（场景性/具体性/独立性/检验性/重复性/复利性）检查过你拆出的基本功吗？
- [ ] 这个基本功是否在"足够务实 × 足够可练 × 足够价值"的三圈交集处？
- [ ] 这个基本功的颗粒度是否恰当——既不过大导致无法建模，也不过小导致无法独立使用？
- [ ] 你是否给它起了一个明确、独一无二的名字？

### 建模层——你的套路是否可执行

- [ ] 这个基本功是否有明确的原则方法（N步法/公式/清单/框架）？
- [ ] 是否有正反面Case作为参考标杆？
- [ ] 是否可以被一个不了解背景的新人看懂并开始尝试执行？
- [ ] 配套的练习材料/机会是否已经准备好？

### 推动层——团队是否真正接受了

- [ ] 你是否建立了"苦练基本功"的团队话语体系（口号/文化墙/挂在嘴边）？
- [ ] 管理者是否以身作则，自己先练起来？
- [ ] 是否有先锋示范选手/团队作为标杆？
- [ ] 是否根据团队不同水平做了段位划分（SABC），让大家各有目标而非一刀切？
- [ ] 是否做到了"先灰度发布、循序渐进"，而不是一刀切推行？

### 练习层——是否真的练起来了

- [ ] 是否有固定的练习计划（个人/团队）和练习节奏？
- [ ] 是否有记录过程（时间/次数/版本）的机制？
- [ ] 是否有复盘机制（日常例会+专项复盘会），让每一轮练习都有反馈？
- [ ] 是否有新人Landing/入职集训，让基本功从入职第一天就进入练习体系？
- [ ] 是否建立了团队共建的基本功知识库/文档库？

### 制度层——是否可持续

- [ ] 基本功是否和考核/薪酬/晋升体系挂钩（不只是"提倡"，而是"要求"）？
- [ ] 是否有监督考察/辅导机制？
- [ ] 基本功是否从"这一季的热门词"变成了"长期坚持的制度"？
- [ ] 你是否会定期回顾——哪些基本功已经过时需要淘汰，哪些需要升级？

### 综合自检

- [ ] 你对苦练基本功的段位（L1-L6），当前最接近哪一档？下一档的突破口在哪里？
- [ ] 你能说出你们团队当前最重要的 3 个关键基本功吗？每个的六个维度分别打几分？
- [ ] 过去一个季度，你们团队的基本功有没有可感知的进步？
- [ ] 你今天有没有把"苦练基本功"这个概念，从"听了一节好课"变成"我愿意长期刻意练习的事"？
