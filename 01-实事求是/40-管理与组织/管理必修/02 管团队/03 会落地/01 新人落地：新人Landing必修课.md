## 一、为什么要学——破题篇

### 1.1 招聘漏斗最容易断裂的一环

> 一聊到管理，大家都会提招聘、绩效、目标管理、培训——但大量管理的低效，问题根源都出现在**新员工入职的第一天**。

| 普遍现象 | 具体表现 | 严重后果 |
|---|---|---|
| **放养式入职** | 招聘时很上心，新人到岗后直接扔进老人队伍一起干活，连基本引导都没有 | 团队融入难、成长缓慢、摩擦很大 |
| **半年才发现不合格** | 拖拖拉拉过了试用期才意识到能力不行 | 半年工资白花了，重新招人的成本更高 |
| **高潜人才快速流失** | 好不容易招到一个好苗子，待不了几周就走了 | "我们花了很多力气招他进来，不到一个月就不干了" |
| **全靠新人自驱** | 假设新人会自己搞懂一切——公司怎么运转、该找谁、什么文化 | 信息黑洞，新人每天都在焦虑和猜 |

### 1.2 新人落地的ROI公式

```text
新人落地阶段花 1 分钟 = 后面日常管理花 10 分钟的效果

反过来说：
新人落地阶段省下的每一分钟 = 后面管理要花 10 分钟来补
```

### 1.3 课程要回答的核心问题

```text
1. 新人落地，究竟"落"什么？（五层冰山）
2. 新人落地的十大常见难题是什么？
3. 不同层级的新人（实习生/专员/业务负责人/高管）需要落到哪一层？
4. 有哪些工具、方法、机制可以拿来就用？（全套武器库）
```

## 二、核心框架：新人落地冰山图

> **"业务背后是能力，协作背后是信任，价值观是最底层的基石。"**
>
> 这是本节课最核心的认知模型。新人落地不是"把活干了"这么简单，而是一座从上到下的五层冰山——浮在水面上的只是业务，水下还有四层在决定着新人能不能真正留下、真正胜任。

### 2.1 冰山五层全景

```text
水面之上 ──→ 第一层：业务Landing（看得见）
         ──→ 第二层：能力Landing
         ──→ 第三层：协作Landing
         ──→ 第四层：信任Landing
水底之下 ──→ 第五层：文化Landing（最深、最重要、最容易被忽略）
```

### 2.2 五层详解

| 层数 | 名称 | 核心问题 | 糟糕做法 | 优秀做法 |
|---|---|---|---|---|
| **第一层** | **业务Landing** | 能不能上手干活？能不能出活？ | 不管放养 / 只派工作 | **设计里程碑**——给新人清晰的阶段性目标 |
| **第二层** | **能力Landing** | 是真的有能力，还是运气好/靠资源？ | 只看结果不看原因 / 全靠新人自己悟 | **安排Mentor**（导师）——有人带、有人教、有人纠偏 |
| **第三层** | **协作Landing** | 能顺利和其他人协作吗？知道找谁吗？ | 不知找谁、全靠自驱去社交 | **带走一圈公司**（认识人）+ **发新人介绍**（让别人认识他） |
| **第四层** | **信任Landing** | 同事信任他吗？老板信任他吗？他信任公司和老板吗？ | 不建信任、只事不人 | **CEO背书**（公开介绍其价值）+ **临时日报/周报**（高频透明建立双向信任） |
| **第五层** | **文化Landing** | 价值观磨一致了吗？做事姿势和习惯一致吗？ | 不懂公司、不懂做事的意义 | **CEO一封信** / 战略讨论 / 文化故事传递 |

> **一句话记住五层：业务背后是能力，协作背后是信任，文化价值观是最底层的基石。**

### 2.3 不同层级的新人，需要落到哪一层

```text
越资深的岗位，越应该往下扎。
```

| 新人类型 | 最低要求的层数 | 原因 |
|---|---|---|
| **实习生** | 第一层（业务）就够了 | 能做事就行，能力和文化要求不高 |
| **HR专员** | 做到第四层（信任），追求第五层 | 需要团队信任，文化匹配影响工作质量 |
| **业务负责人** | **必须做到第五层（文化）** | 价值观不匹配，早晚出问题——而且职位越高，出问题时损失越大 |
| **高管** | 五层全部必须做到，且第四五层是重点 | 高管离职的主要原因往往不是能力，而是信任和文化 |

### 2.4 经典案例：一个空降高管的15个月滑铁卢

| 阶段 | 发生了什么 | 五层冰山哪层出了问题 |
|---|---|---|
| **入职第一天** | CEO花了2分钟简单介绍了他，但多数人不认识他、不知道他的特殊背景和价值 | **信任Landing缺失**——没有CEO正式背书和信任塑造 |
| **协作过程** | 其他部门同事不配合，总是提尖锐问题 | **协作Landing不足**——没有人帮他建立协作关系 |
| **工作方式冲突** | 他按大厂习惯私下拉微信群派活，被CEO公开批评——公司文化要"极度透明"，公开大群讨论 | **文化Landing缺失**——不知道公司的做事姿势和文化底线 |
| **信息孤岛** | 起早贪黑拿了很多结果，但只能拿到自己部门信息，不知道公司整体战略和长远规划 | **文化Landing + 信任Landing双重缺失** |
| **结局** | 一年后部门业绩翻三倍，但他主动离职了 | "工作不开心，跟同事信任不够、时有摩擦，看不到公司前景" |

> **这个案例的反直觉之处：业绩翻了三倍，人却走了。** 说明对于高管，即使业务和能力都在水面之上表现良好，水下三层的崩塌仍然能毁掉一切。

## 三、新人落地十大难题：5不5只模型

> 春萍将大量创业公司踩过的坑，提炼成十个最常见的"负面信号"——每个管理者都可以用它来对照自己团队的问题。

### 3.1 十大难题全景

| 类型 | 难题 | 具体表现 | 背后是哪层冰山的问题 |
|---|---|---|---|
| **"5不"** | 1. 不管放养 | 入职后没人管，全靠自驱 | **业务** |
| | 2. 不见信任 | 老员工对新人怀有戒心，配合不积极 | **信任** |
| | 3. 不懂公司 | 不知道公司战略/规划/做事逻辑 | **文化** |
| | 4. 不懂做事意义 | 只被派活，不知道为什么做 | **文化** |
| | 5. 不知找谁 | 遇到问题不知道该问谁、该找哪个部门 | **协作** |
| **"5只"** | 6. 只派工作 | 只交代任务，不给目标/不给反馈 | **业务 + 能力** |
| | 7. 只看结果 | 不关心能力是不是真的，是不是运气好/作弊 | **能力** |
| | 8. 只靠自驱 | 新人要全靠自己建立人脉、找到资源 | **协作** |
| | 9. 只事不人 | 只谈工作不谈人，不建立任何信任关系 | **信任** |
| | 10. 只能靠悟 | 公司的方法论/审美/标准全在老人脑子里，新人要自己"悟" | **能力 + 文化** |

### 3.2 十大难题的自检用法

```text
对照清单，问自己三个问题：

1. 我们团队的新人目前在经历哪几条？
2. 最严重的是哪一条？
3. 这条对应冰山哪一层——我们该优先补什么？
```

## 四、核心工具：一堂教研新人Landing案例——14天魔鬼训练

> 这可能是课程中最扎实的一个内部案例，展示了春萍（课程讲师本人）和于陆（一堂教研新人）经历的真实Landing过程。**"我已经不是两个星期前的我了。"**

### 4.1 三个新人，三种起点

| 新人 | 背景 | 入职前状态 |
|---|---|---|
| **春萍** | 头部在线教育机构待过，经验丰富，能力优秀 | 有做课经验，是"专家型新人" |
| **轶初** | 教育行业产品经理，熟悉行业，自己也参与过课程研发 | 有机智出众的底子，是"相关领域新人" |
| **于陆** | 过往大多时间跟代码打交道，对教研"不能说一无所知，只能说一知半解" | 完全是跨领域新人，是"一张白纸" |

### 4.2 14天训练任务设计

```text
第一周：5个闯关任务 + 配套成长资料
  新人需要凭借对任务和参考资料的理解来独立完成交付
  周日晚提交5个训练报告

第一周后：Truman交付3小时线上内训课
  一次性讲透教研必须掌握的核心知识
  同时展示其他同学做得好的地方、做得不好的地方
  展示历史上Truman和花匠写过的最佳实践

第二周：基于内训课反馈，继续迭代和完善第一轮的交付
```

### 4.3 于陆的Before/After——一个星期能改变什么

| 节点 | 于陆的状态 |
|---|---|
| **第一轮提交后** | "不出所料，获得了铜牌"——除了一个任务还不错，其他差距都很明显。还贡献了清单体笔记课程里一个Before案例 |
| **参加内训课后** | 一次性知道了：一堂要求的课程审美是什么样 / 一堂的做课流程是什么样 / 这阶段需要重点训练的基本功是什么 / 自己距离最佳实践有多远 / 可以怎么改进 |
| **第二轮迭代后** | 笔记案例从Before变成了Before+After案例——**两份笔记只差一个星期** |

> **"我已经不是两个星期前的我了，因为我'阳过'了，我肉眼可见的变强了！"** —— 于陆

### 4.4 从案例中提炼的新人Landing设计原则

| 原则 | 一堂的做法 | 可迁移动作 |
|---|---|---|
| **不给答案，给任务和反馈** | 第一周靠自己完成，第二周收到内训课后自己迭代 | 新人先做→给具体反馈→让新人自己改 |
| **用最佳实践拉高审美** | 展示Truman和花匠的历史最佳版本 | 让新人看到"好"长什么样 |
| **用同伴对比找到差距** | 同时看到其他新人做得好和不好的地方 | 不是打击，而是"原来可以做到这样" |
| **给出清晰的标准** | 一次性讲透课程审美标准、做课流程、基本功要求 | 新人不再靠"悟"，而是有明确标尺 |

## 五、全套武器库：新人落地武器库 V0.8

> 这个武器库来自教研组访谈大厂和创业公司专家、一堂自身实践、70+同学共建、几百份作业的思考——**总计4大类14个工具，每个工具里还有延伸技巧，至少几十个可选动作。**

### 5.1 武器库四大分类

```text
2小时工具（快速见效的入职第一天行动）
    ↑
个性辅导（Mentor导师制的长期陪伴）
    ↑
团队机制（把新人融入团队的制度化动作）
    ↑
模拟训练（用实战任务检验和加速Landing）
```

### 5.2 第一类：2小时工具——入职第一天就能用的速效动作

| 工具 | 一句话介绍 | 解决冰山哪层 |
|---|---|---|
| **新人一页纸** | 把新人需要知道的关键信息（找谁、用什么工具、第一周目标）写在一页纸上 | 业务 + 协作 |
| **带走一圈公司** | 亲自带新人走一圈，介绍给每个人，帮Ta建立第一批人脉 | 协作 |
| **发新人介绍** | 用邮件/群里正式介绍新人，重点说明Ta的亮点和稀缺性 | 信任 + 协作 |
| **CEO背书** | CEO公开强调"这个人为什么重要"——塑造信任，减少后面的无意义摩擦 | 信任 |
| **CEO一封信** | 一封入职欢迎信，讲公司愿景、做事逻辑、对新人的期待 | 文化 |
| **入职欢迎仪式** | 哪怕只是群里刷一波欢迎，只要稍微刻意设计出仪式感，状态就很不一样 | 协作 + 信任 |

### 5.3 第二类：个性辅导——Mentor导师制和长期陪伴

| 工具 | 一句话介绍 | 解决冰山哪层 |
|---|---|---|
| **安排Mentor（导师）** | 指定一个老员工作为新人的专属导师 | 能力 + 协作 |
| **临时日报/周报** | 新人前几周写日报或周报，高频透明建立双向信任 | 信任 |
| **设计里程碑** | 不给模糊任务，给清晰的阶段性目标和检查节点 | 业务 + 能力 |
| **CEO定期1v1** | 对于业务负责人或高管，CEO定期做深度沟通：聊战略、聊文化、聊信任 | 信任 + 文化 |

### 5.4 第三类：团队机制——制度化融入动作

| 工具 | 一句话介绍 | 解决冰山哪层 |
|---|---|---|
| **新人Landing训练任务** | 设计一套标准化训练任务（类似一堂的14天闯关任务） | 能力 |
| **新人述职** | 入职1/3/6个月后正式述职，检验能力和文化匹配 | 能力 + 文化 |
| **团队知识库开放** | 把团队的方法论、最佳实践、SOP、Case都放在知识库里，新人可以随时查阅 | 能力（从"靠悟"变成"有资料"） |

### 5.5 第四类：模拟训练——用实战检验和加速

| 工具 | 一句话介绍 | 解决冰山哪层 |
|---|---|---|
| **模拟店/模拟环境** | 像古董奶茶店让新人先在模拟店练一周再上岗 | 能力 |
| **实战任务 + 反馈迭代** | 像一堂教研第一周自己做、第二周拿反馈再改 | 能力 + 文化 |

### 5.6 武器库使用规则

```text
1. 不是一次性全用——根据新人层级和公司阶段挑选
2. 先保证"2小时工具"一个不漏——这些是底线
3. 越资深的新人，越要在"个性辅导"和"团队机制"上投入
4. 文化Landing不是一朝一夕——但"CEO一封信""战略讨论""入职仪式"能在一开始就打开局面
```

## 六、打破一个常见误区：新人落地不是只有"大公司"才做

### 6.1 春萍的核心提醒

> "新人进来，哪怕只给1天的落地时间，你也需要帮Ta完成那个转变。"

```text
很多创业公司觉得自己太小了，没法做新人Landing：
"我们公司才10个人，哪有资源做新人培训？"

但春萍的反驳是：
"你回顾自己过去作为新人的经历，或多或少都有过糟糕的体验。
那为什么自己带人的时候，不把它作为一个产品，好好设计一下呢？"
```

### 6.2 小公司也能做到的最小Landing动作

| 公司阶段 | 最小可行动作 | 投入时间 |
|---|---|---|
| **3-5人** | 新人一页纸 + 带走一圈 + 群里欢迎 | 1-2小时 |
| **10-20人** | 以上 + 新人介绍邮件 + Mentor安排 | 半天 |
| **50人+** | 以上 + 训练任务 + 新人述职机制 + 知识库 | 系统化设计 |

## 七、高管落地的三把杀手锏

> 来自课程案例——CEO如何帮助空降高管成功落地。这三件事不是普通新人Landing的标配，但对于高管是"必须做"。

### 7.1 高管落地三件事

| 动作 | 具体做法 | 核心目标 | 解决冰山哪层 |
|---|---|---|---|
| **第一件事：塑造团队信任** | CEO在全员面前正式介绍，认真夸一下履历，强调邀请他加入有多么不容易 | 塑造人设，避免后面出现无意义的摩擦和私下揣测 | **信任** |
| **第二件事：公司战略讨论** | 拉着做半天闭门讨论，分享对长期发展、近期目标和核心能力的思考，形成共识 | 让高管理解公司全局，明确Ta在未来发展的关键意义 | **文化 + 信任** |
| **第三件事：帮助建立领导力** | 空降高管先负责确定性的老事情，或先跟CEO做两个月助理——一边做一边磨合，一边帮Ta在同事面前形成领导力 | 避免空降领导力不足导致的协作崩溃 | **信任 + 协作** |

> **核心规律：高管落地最大的问题是空降的信任问题。CEO必须主动、刻意、用系统的方法去解决——不能假设"能力强自然会被认可"。**

## 八、新人落地段位成长地图

| 段位 | 核心能力 | 典型表现 |
|---|---|---|
| **L1 放养式** | 无Landing意识 | 新人入职=扔进工位开始干活，没有引导、没有介绍、没有目标 |
| **L2 有引导** | 会做基础Landing动作 | 会带新人走一圈公司、发个介绍、给个简单任务说明 |
| **L3 有标准流程** | 有固定的Landing SOP | 新人一页纸 + 训练任务 + Mentor安排 + 例行检查节点 |
| **L4 深到信任层** | 重视信任和文化的Landing | CEO参与关键新人背书，有定期1v1，有文化传递机制 |
| **L5 五层全通** | 完整的Landing体系 | 有新人落地武器库，能根据新人层级精准匹配Landing深度 |
| **L6 持续迭代** | 用反馈修正Landing模型 | 每次新人入职/离职都复盘Landing过程，持续迭代武器库 |

## 九、同一个动作，不同深度——信息量差异的经典案例

> 春萍在课上给了一个非常有穿透力的例子：**同样是"在群里欢迎新人"，不同话术背后的深度完全不同。**

| 做法 | 话术示例 | 解决了哪层冰山 | 深度 |
|---|---|---|---|
| **简单欢迎** | "欢迎XXX加入我们！👏" | 协作（最浅） | 建立基础认识 |
| **介绍亮点和稀缺性** | "XXX之前在XX公司负责XX业务，拿到了XX结果。我们花了很多功夫才把Ta请来。以后XX方向大家可以多找Ta聊聊。" | 协作 + **信任** | 公开塑造信任和认可 |
| **同步强调文化** | "XXX之前在XX公司负责XX业务。我们特别欣赏Ta在XX项目里'死磕到底'的做事方式，跟我们公司的价值观非常契合。Ta接下来会负责XX方向，这个方向对公司的意义是……" | 协作 + 信任 + **文化** | 一次欢迎同时传递三层信息 |

> **核心启示：同样的动作，用不同方式做，效果天差地别。管理者要的是"刻意设计"，而不是"随意完成"。**

## 十、春萍的核心金句

| 金句 | 出处/场景 |
|---|---|
| "你在新人落地阶段花1分钟，抵得上后面日常管理花10分钟。" | 课程核心ROI公式 |
| "业务背后是能力，协作背后是信任，价值观是最底层的基石。" | 冰山五层的核心逻辑 |
| "你的成功新人Landing，背后因为这5条；你的失败新人Landing，背后也是因为这5条。" | 冰山模型的普适性 |
| "新人进来，哪怕只给1天的落地时间，你也需要帮Ta完成那个转变。" | 最小可行Landing |
| "稍微刻意设计出一点仪式感，新人落地的状态就会很不一样。" | 仪式感的价值 |
| "越资深的岗位，越应该往下扎。" | 不同层级不同深度 |
| "我已经不是两个星期前的我了——我肉眼可见的变强了！" | 于陆14天Landing后的感慨 |
| "为什么自己带人的时候，不把它作为一个产品，好好设计一下呢？" | 把Landing当作产品来设计 |
| "实习生离职往往因为不能干活；主管离职往往因为能力和协作；高管离职最主要的原因往往是信任和文化问题。" | 不同层级离职的根因差异 |

## 十一、L6 刻意练习自检清单

### 认知层——你是否建立了Iceberg意识

- [ ] 你是否能用五层冰山模型（业务/能力/协作/信任/文化）诊断自己团队的新人Landing现状？
- [ ] 你的团队目前最容易在哪一层出问题？最常被忽略的是哪一层？
- [ ] 你是否理解"越资深的岗位越应该往下扎"？你最近招的高管/业务负责人做到了第几层？

### 业务Landing——新人能不能上手

- [ ] 新人入职第一天，有没有一页纸告诉他：找谁、用什么工具、第一周目标是什么？
- [ ] 新人有没有清晰的里程碑（不是"先熟悉一下"，而是"第一周交付XX"）？
- [ ] 你是否避免了"只派工作不给目标"和"只管放养"？

### 能力Landing——新人是真有能力还是运气

- [ ] 你是否为新人安排了Mentor（导师），而不是全凭自己悟？
- [ ] 你是否区分了"结果好"和"能力好"——有没有设计机制验证能力真伪？
- [ ] 团队的知识库/方法论/SOP是否对新人开放、易于查阅（还是"全在老员工脑子里"）？

### 协作Landing——新人能不能找到人

- [ ] 你是否亲自带新人走过一圈公司，介绍给关键同事？
- [ ] 你是否发了正式的新人介绍（邮件/群里），让其他人知道Ta是谁、负责什么？
- [ ] 新人是否知道遇到XX问题该找谁——而不需要靠自己硬猜？

### 信任Landing——新人和团队是否互信

- [ ] 对于关键岗位新人，CEO是否有公开背书和信任塑造？
- [ ] 新人前几周是否有临时日报/周报机制，建立高频透明的双向信任？
- [ ] 你有没有把新人当作"一个需要被团队接纳的人"来设计融入动作，而不是只谈工作不谈人？

### 文化Landing——价值观是否磨一致

- [ ] 新人在入职初期是否了解过公司的愿景、战略方向和做事逻辑（不只是听口号）？
- [ ] 对于业务负责人/高管，CEO是否做过闭门战略讨论？
- [ ] 你是否传递过"我们为什么做这件事""我们怎么做事的"——而不只是一个入职文档？

### 综合自检

- [ ] 对照新人落地十大难题（5不5只），你的团队当前最严重的是哪三条？下一步先解决哪一条？
- [ ] 你过去最失败的一次新人入职经历是什么？用五层冰山回溯——是哪一层出了问题？
- [ ] 你过去最成功的一次新人入职经历是什么？做对了什么？
- [ ] 你现在是否愿意把"新人Landing"当作一个产品来设计——而不仅是"完成入职手续"？
- [ ] 对照段位地图，你现在更像L几？你下一个阶段最需要补充的武器是什么？
