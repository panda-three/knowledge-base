# 课程：HTML版PPT·01

**一句话结论：** 用 Codex 做 PPT 有两条路——HTML PPT 像可调试工程（好改、可迭代），Image PPT 像设计海报（视觉冲击强）；本讲用 guizang-ppt-skill 把初稿从手工排版变成可生成、可修改的结构化流程。

---

## 一、核心交付

- 两条路线对比：HTML PPT vs Image PPT。
- 一个工具：guizang-ppt-skill（支持 Claude Code/Codex/Cursor）。
- 一套起步四步：装 Skill → 读资料 → 出大纲 → 调试。

## 二、两条路线

| 路线 | 本质 | 优势 | 适合 |
|---|---|---|---|
| **HTML PPT** | 内容/布局/交互写在网页里 | 可改、可验证、可迭代 | 快速修改、现场演示、视觉表达 |
| **Image PPT** | 每页由 GPT Image 生成 | 构图/材质/气质一次性压进一张图 | 发布传播、完整画面感 |

> 两者不互相取代：HTML 是可调试的中间稿，Image 是设计海报。

### HTML 版六大优势

生成快 / 改色改字只改 CSS / 每页模块化 / 金句页课程页可套模板 / 直接接 CSV/Excel/JSON 出图 / 浏览器预览+一键部署。

## 三、guizang-ppt-skill 简介

- 来源：github.com/op7418/guizang-ppt-skill（stars 2060，AGPL-3.0）。
- 适合杂志风/分享型/汇报类 HTML PPT，内置自检清单。
- **两套视觉系统：**

| 风格 | 气质 | 适合 |
|---|---|---|
| A 电子杂志×电子墨水 | 像 Monocle 贴上代码 | 叙事、观点、分享、个人表达 |
| B 瑞士国际主义 | 网格至上、高饱和锚点色、发丝线、字号对比 | 事实、产品、分析、方法论 |

> 生成内容是否准确、资料是否有据，仍需自行核实判断。

## 四、起步四步

### 第 1 步：安装

```bash
安装 guizang-ppt-skill 且是全局级 Skill，来源 https://github.com/op7418/guizang-ppt-skill
```
- 不想全局可改「项目级 Skill」；安装后建议重启 Codex。
- 验证：`$ Skill名` 列清单，或左侧 @插件→技能 里找。

### 第 2 步：让 AI 读项目资料

- 资料放同一目录 → Codex「使用现有文件夹」指定。
- 别让它凭空设计；先讲清用哪些素材、有何限制。
- 边界提示词：**盘点资料；请不要编造没有提供的数据与内容。**

```bash
请先分析此目录 HTML PPT，这是打算采用 Guizang Ppt Skill 且风格是 瑞士国际主义，目标是产生限定 10 页
```

### 第 3 步：生成大纲 + 调试（开计划模式）

- 开**计划模式**，推理调「高/超高」，先出大纲减少大改。

```bash
根据上面的内容，帮我设计10页的大纲内容，采用 Guizang Ppt Skill 生成 HTML PPT
```

- 计划模式会主动问你：图片怎么处理（纯信息设计/少量关键截图/截图优先）、听众是谁（初学者/进阶用户/宣传）。
- 可追加：Logo、Style&font、文字、版式规则。

## 五、关键纪律（分析阶段）

- 只压缩重组已有 Word，**不补充外部事实/虚构数字**。
- 版本号/价格等时效信息，须标原文日期或「个人实测」。
- 重复课程广告、本机路径默认不纳入。
- [配图：Codex 10 页实施方案 Summary——标题《Codex：从对话到执行》、克莱因蓝 IKB 强调色、S01-S10 映射、每页来源用 HTML 注释记录]

## 六、金句与判断

> 「HTML 版 PPT 不是一张扁平图片，而是一份可以持续调试的中间稿。」
> 「不建议一开始就让 Codex 凭空设计，先让它看文件夹、讲清素材和限制。」

## 七、行动建议

| 层级 | 行动 |
|---|---|
| 基础 | 装好 Skill，用一份现成资料跑通「读目录→出大纲」 |
| 进阶 | 按项目选 A/B 风格，开计划模式出第一版 10 页 |
| 高阶 | 建自己的版式规则（Logo/字体/主题色/来源注释）复用 |

## 八、我的批注（双轨）

- 我的：「先盘点资料再出大纲、不编造数据」正好对应用户给我的工作纪律。
- 待验证：Skill 为第三方（歸藏），版本与平台支持随时间变化。
