# 课程：PPT收尾总结·04

**一句话结论：** Image PPT 八步闭环最后落到「导出 + 沉淀专属 Skill」；三个关键节点把判断权拿回来——**内容你定、风格你定、验收你定**。

---

## 一、核心交付

- 导出两法：图片版 PPT（稳）vs 关键页可编辑（可改字但费时）。
- 一个沉淀动作：把流程做成项目级 image-ppt-skill。
- 三个判断权节点 + 三句金句。

## 二、第 6-7 步：改图与导出

### ChatGPT 网页改图四步
编辑 icon → 评论 icon → 写修改（如「删除文字『来源：Word A』」）→ 发送。改完需**手动下载到本地目录**。

### 导 PPT/PDF（Presentations 插件）

```
@Presentations 将输出图片按页码顺序插入 PPT；
16:9、每张铺满整页、按 01.png 02.png... 顺序、不裁切；
生成 .pptx 名 Image_PPT，同时导出 .pdf
```

| 导出方式 | 特点 |
|---|---|
| **图片版 PPT/PDF** | 视觉最稳定，10 秒完成 |
| 关键页转可编辑 | 文字/数字变文本框、卡片线条用原生形状；但**单页耗时近 57 分钟**，效果有损失 |

> 敲黑板：AI 擅长做视觉，但**图片里的文字 ≠ 可验证文本**。

## 三、第 8 步：沉淀专属 Skill

```
请根据本项目 Image PPT Demo 完整流程，生成项目级 Codex Skill，
名称 image-ppt-skill，放在此目录；
含：适用场景/输入要求/标准目录/盘点流程/三份规范/Product Design 时机/
批量生图/单页迭代/导出流程/质检清单/常见错误/一键提示词模板
```
- 会自动调 skill-creator；推荐落 `.agents/skills/`（项目级）。
- 想全局级就改「全局级 Skill」装到 ~/.codex/skills。

## 四、Image PPT 八步总览

1. 项目目录整理上下文
2. Codex 盘点 → asset_inventory.md（每份 Word 1-2 页、不编造）
3. Product Design 做风格 → ASCII 线框 + visual_style_guide.md
4. 先出 1-2 页样张（定风格/密度/Logo）
5. 批量生图（文字过多先压层级）
6. 逐页改图（截图/注释/评论；先脱敏）
7. Presentations 导出（16:9 整页铺满）
8. 沉淀 image-ppt-skill

**核心提醒：** 先盘点再生图；先样张后批量；真实截图优先+敏感遮蔽；不生成可读 UI/代码/价格/Logo。

## 五、双三角看「AI 做 PPT」

| 人类三角 | 应用 |
|---|---|
| 审美 | 你知道什么叫清楚、好看、能代表你 |
| 体系 | 附件映射、提示词、Skill、版本、QA |
| 创造力 | 同份内容选 HTML / Image / 混合 |

| AI 三角 | 应用 |
|---|---|
| 场景 | 知道何时用 HTML、何时用 Image |
| 基本功 | guizang-ppt-skill / Image Gen / Product Design / Presentations |
| 数据 | Word、MD、图片、案例、模板、历史对话 |

## 六、三个判断权节点

1. **内容方案确认前**——你决定讲什么。
2. **风格定调时**——你决定什么叫好看。
3. **最终验收时**——你决定能不能代表你见人。

## 七、金句（三句敲黑板）

> 「Codex 跑得很快，方向错了也会浪费得更快。」
> 「AI 负责执行，人负责内容、审美与最终责任。」
> 「先思考后设计，先验证后批量；先复查才交付。」

## 八、行动建议

| 层级 | 行动 |
|---|---|
| 基础 | 按八步跑一份自己的 PPT，记住「先样张后批量」 |
| 进阶 | 把流程沉淀成项目级 image-ppt-skill |
| 高阶 | 用双三角自检：内容/风格/验收三关是否都握在自己手里 |

## 九、我的批注（双轨）

- 我的：三个判断权节点正好提醒我——工具再强，审美与责任不能外包。
- 待验证：关键页转可编辑「57 分钟/页」为单次实测，随模型与复杂度变化。
