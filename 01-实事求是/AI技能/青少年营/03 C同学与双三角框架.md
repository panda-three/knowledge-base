# 课程：C同学与双三角框架·青少年营

**一句话结论：** C 不急着让 AI 答，先备齐真实问题+本校正式资料+整理好的数据+写好的提示词，于是每句回答都能回到依据——六个角正式拼成一堂双三角。

---

## 一、核心交付

- 一个范本：C 的四样准备=真问题/本校资料/整理数据/写好提示词。
- 一张总图：人类三角（创造力/审美/体系）×AI 三角（场景/基本功/数据）。
- 一个关系：人变强→调教更强 AI→AI 辅助人更强。

## 二、关键框架

### 2.1 C 的第一步：先准备再出手

| 已准备 | 内容 |
|---|---|
| 真实问题 | 成绩不错就一定能转计算机吗 |
| 本校正式资料 | 2026 转专业管理办法.pdf |
| 整理好的数据 | 学院要求与时间节点.csv |
| 写好的提示词 | 回答结构与边界要求.md |

### 2.2 C 的回答：四段结构

| 段落 | 内容 |
|---|---|
| 答案 | 不保证转成，有条件有名额 |
| 依据 | 按本校 2026 办法，春学期开放 |
| 下一步 | 查目标学院要求、备材料按时交 |
| 边界 | 以学院审核为准，不替学校承诺 |

- 每一句都能回到依据=C 版的标志。

### 2.3 ABC 同题对照

| 同学 | 特征 | 本质 |
|---|---|---|
| A | 只带热心人设 | 没材料·没标准 |
| B | 材料很多没治理 | 混校·跨年·截图 |
| C | 场景材料标准都备好 | 本校·正式·本年度 |

### 2.4 一堂双三角总图

| 三角 | 顶点 | 内涵 |
|---|---|---|
| 人类（黄） | 创造力 | 理解规律、解放思想、提创造假设 |
| 人类 | 审美 | 专业见识、最佳实践、评价标准 |
| 人类 | 体系 | 科学思维、假设验证、稳定结构 |
| AI（青） | 场景 | 业务拆解、ROI 预判、组织部署 |
| AI | 基本功 | 提示词/智能体/多模态/微调 |
| AI | 数据 | 非结构化+结构化数据形成资产 |

- 灵魂拷问：人侧"同会用 AI 为何结果差大"；AI 侧"同是高手为何 AI 结果差大"。
- 人类侧支撑：审美+体系→创造力；没标准体系，新想法易成臆想。

## 三、金句与判断

> 「每一句都能回到依据——这就是 C 把准备好的内容发出去之后得到的回答。」
> 「只让 AI 包办、不比较不判断不复盘，人的能力可能变弱。」

## 四、行动建议

| 层级 | 行动 |
|---|---|
| 基础 | 下次用 AI 前，先备齐 C 的四样 |
| 进阶 | 检查回答能否逐句回到依据 |
| 高阶 | 给双三角六角打星，找最弱角 |
