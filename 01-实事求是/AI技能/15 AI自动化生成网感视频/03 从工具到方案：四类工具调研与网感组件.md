# 课程：工具与网感组件·03

**一句话结论：** 调研后确认市场上**还没有一键出 80 分网感口播的工具**——最缺的是自动化剪辑（=一套审美模板）；**网感和用什么技术无关，网感本身就是最佳实践模板**。

---

## 一、核心交付

- 四类工具盘点：剪辑 / 数字人 / 开源自动化 / Skill 类。
- 一个血泪教训：被新工具（HyperFrames）耽误三个月，顺序做反了。
- 一个本质：**网感 = 审美模板，与技术无关**。
- 一张环节→AI 实现路径表。

## 二、四类工具盘点

| 类 | 代表 | 观察 |
|---|---|---|
| ① 综合剪辑 | 剪映/度加/开拍 | 自动化成片效果待看；大家都熟 |
| ② 数字人 | 蝉镜/闪剪/万兴播爆/讯飞智作 + 口播智能体 | 不想拍可走这条；**画面易单调，靠人工剪辑补网感** |
| ③ 开源自动化 | MoneyPrinterTurbo/MoneyPrinter/ShortGPT/Pixelle/FireRed | 流程能串起来，但**成片无网感，只是流程实现** |
| ④ Skill 类 | Remotion/HyperFrames/ChatCut/VectCutAPI/PPT2Video | 为 Agent 设计，风格模板仍要人定 |

### 关键启发

- 口播潜在群体巨大（想获客的都想拍）；工具渗透率/集中度极低，**信息差即服务窗口**。
- 即使用数字人也能做出有网感的片——**核心都在自动化剪辑细节**。
- 判断是否数字人：看更新频率（一两天一条真人做不到）；但效果好的都有明显人工剪辑痕迹。

## 三、血泪教训：被新东西耽误三个月

- 天天用 Codex，累计烧 **137.3 亿 Token**、连续 61 天。
- 一上来花 3 周研究 HyperFrames 怎么神奇，想把对话流程改成可直接运行的工作流。
- 看别人用 HyperFrames 做的视频「哪都不对劲」——**它和网感几乎没关系**。
- 根因：当时没搞清楚网感视频长什么样，**陷入对新技术的追捧**。

> 正确顺序应是「先建审美，再选技术」；作者实际做反了，是最近一个月才补的 300 条拆解。

## 四、本质：网感就是审美模板

> 网感用的规则，和 HyperFrames 这类 Skill 约束的规则**不是一套东西**。
> 网感 = 一套特定最佳实践、特定审美模板，**和用什么技术无关**。

### 调研结论

产品上：
- 现有工具只解决一部分，或与主流网感口播差得远。
- 最缺**自动化剪辑**（既 know-how 又要操作，门槛高）。
- 用户直接拿结果 > 花时间学原理。

市场上：
- 集中度低，2-3 年的数字人产品仍有海量需求。
- 会用 Codex/Claude Code 的人很少，HyperFrames 不构成威胁。

## 五、环节 → AI 实现路径

| 环节 | 细分 | AI 路径 |
|---|---|---|
| 选题 | 提纲 / 口播稿 | 大语言模型 |
| 拍摄 | 声音 / 形象 | 语音合成 / 数字人 |
| 素材 | 现有 / 生成 | OCR·视觉模型 / AI 生图·生视频 |
| 剪辑 | 字幕/包装/动画/音效/封面 | **网感组件** |

## 六、网感组件：三类难度

| 难度 | 内容 | 做法 |
|---|---|---|
| 无现成最佳实践，须人工归纳 | 人物形象包装、素材滚动/高亮/定位 | 人工归纳后程序化 |
| 有最佳实践、易做 | 音效/音乐/字体（静态资源） | 看博主视频→记录→下载→集成 |
| 有最佳实践、难做 | 文本预设效果、动画 | **vibe coding 才可能快速做** |

**快速程序化做法：**
- 淘宝/视频号买现成剪映预设资源。
- 让 Codex 解析资源文件，**像素级还原**成自己的程序。
- 原则：能用商用 API 就用 API，先跑起来再优化，别陷部署细节。

## 七、金句与判断

> 「即便用数字人，也能做出有网感的短视频，核心都在自动化剪辑细节上。」
> 「网感和用什么技术没有关系，网感本身就是一套审美模板。」
> 「顺序做反了——先建审美，再选技术，这是惨痛教训。」

## 八、行动建议

| 层级 | 行动 |
|---|---|
| 基础 | 做内容前先回答「80 分长什么样」，再选工具 |
| 进阶 | 把音效/字体/字幕预设当静态资源先集成 |
| 高阶 | 用 Codex 解析一套你喜欢的字幕预设，像素级复刻 |

## 九、我的批注（双轨）

- 我的：「先建审美再选技术」和我讲技术课时强调「先懂要什么效果」一致。
- 待验证：各开源项目 Star 数、能力边界为作者调研时点快照，会快速变化。
