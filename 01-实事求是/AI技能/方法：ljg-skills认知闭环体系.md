# 李继刚ljg-skills全解析：19个工具串联「Read→Think→Write→Publish」的认知闭环体系

## 🧠 摘要
### 📌 项目基础背景

李继刚是国内最早探索结构化Prompt的先行者之一，2023年6月就发布了「如何写好Prompt，结构化」相关内容，推动Prompt向类编程的组织方向发展，其`lijigang/prompts`仓库长期作为中文用户的结构化Prompt样板仓库。
目前他的`ljg-skills` GitHub仓库已获得**5.6k Star**、**600+ Fork**，属于典型的口碑驱动增长，而非短期爆文冲量获得的流量。整个工具体系的核心设计理念完全对应他个人主页的简介：**Read → Think → Write → Publish**，19个工具并非零散的功能集合，而是一条完整的认知转化链路。

### 🔍 第一阶段：理解事物（10个工具，完成从「知道」到「真懂」的跨越）

这一阶段的所有工具核心目标，是把仅能背诵定义的浅层认知，转化为拥有画面、结构、专属表达的深度理解。

| 工具名称 | 核心定位 | 功能细节 | 设计亮点 |
| :--- | :--- | :--- | :--- |
| **ljg-learn** | 概念解剖 | 从历史、辩证、现象、语言、形式、存在、美感、元反思8个维度拆解概念，最终输出一句顿悟式总结 | 并非检索现有解释，而是通过多认知维度重新建构概念，例如拆解「贝叶斯推断」最终提炼出「用新的证据更新你对世界的信念」的核心顿悟句 |
| **ljg-plain** | 白话引擎 | 将复杂内容改写至聪明的12岁小孩也能理解的程度 | 远超普通「通俗易懂」的标准，不是替换专业词，而是用日常经验的类比重构逻辑，甚至能识别出复杂公文里伪装成内容的废话 |
| **ljg-word** | 单词精通 | 拆解英语单词的词根意象、历史演化、核心语义、顿悟时刻 | 打破死记硬背的词汇学习模式，让学习者感知到英语词汇体系的内在纹理 |
| **ljg-rank** | 降秩引擎 | 为指定领域找出背后不可再少的独立生成器 | 提炼领域底层核心元素，比如经济学核心生成器是「激励」，进化生物学是「变异加选择」，从根源提升知识理解效率 |
| **ljg-think** | 追本之箭 | 对观点/现象纵向深钻，直达不可再分的本质 | 和ljg-learn的横向多维度拆解形成互补，例如拆解「拖延」最终推导到「不确定性引发的自我保护机制」的底层逻辑 |
| **ljg-read** | 文本伴读 | 支持英文三层翻译（信达雅）、结构标注、深度提问、跨领域旁逸 | 核心价值是让新信息和用户已有知识体系发生反应，而非单向灌输内容 |
| **ljg-paper** | 论文阅读 | 面向非学术人士提取论文核心想法 | 坚持「重理解不重批判」的思路，先帮助用户真正读懂内容，再进行后续的评判工作 |
| **ljg-paper-river** | 论文溯源 | 采用「倒读法」递归挖出目标论文引用的前序论文，最多追溯5层，同时整合最新进展，梳理问题演化史 | 解决读论文时因不了解概念诞生的背景而产生的理解障碍问题 |
| **ljg-book** | 深度拆书 | 从核心问题、基础假设、分析框架、核心观点、上帝之眼总结5个维度拆解书籍 | 区别于普通的目录、金句摘录，直接提取整本书的骨架与灵魂 |
| **ljg-qa** | 信息提问机 | 将内容核心观点抽成Q-A链，答案包含结论、形式化表达、步骤、边界条件四部分 | 首次将「边界条件」作为知识输出的强制要素，输出的知识卡片完整性远超市面同类工具 |

### ✍️ 第二阶段：判断与表达（4个工具，完成认知的校验与落地）

在深度理解信息的基础上，形成独立判断、完成内容表达，并通过多视角校验打磨内容的严谨性。

| 工具名称 | 核心定位 | 功能细节 | 设计亮点 |
| :--- | :--- | :--- | :--- |
| **ljg-writes** | 写作引擎 | 以1000-1500字的篇幅剖开一个观点，层层深入到底层 | 输出内容带有明确人格与立场，而非堆砌信息的无观点水文 |
| **ljg-invest** | 投资分析 | 以「秩序创造机器」为核心判断框架评估项目 | 跳出传统DCF、EBITDA等财务指标，用「项目是否持续将混沌转化为可复制的秩序」的底层视角评估项目，也可用于评估个人项目、公司价值 |
| **ljg-relationship** | 关系分析 | 通过五层结构诊断加精神分析的对话引导，帮助用户看见关系的真实结构 | 不直接给出结论，通过逐层提问让用户自己梳理出关系里的真实动力，很多用户反馈「原本答案就在自己心里，只是没有机会说出来」 |
| **ljg-roundtable** | 圆桌讨论 | 模拟多立场角色开展求真导向的结构化辩证对话，每轮生成ASCII思考框架图 | 强制挖掘观点的脆弱环节，测试观点严谨性的效果远高于自我辩论 |

### 📢 第三阶段：交付与传播（5个工具，完成认知成果的落地与扩散）

将打磨完成的内容转化为可传播、可落地的形态，完成整个认知链路的闭环。

| 工具名称 | 核心定位 | 功能细节 | 设计亮点 |
| :--- | :--- | :--- | :--- |
| **ljg-card** | 内容铸卡 | 将内容转为PNG视觉卡片，支持长图、信息图、多卡、视觉笔记、漫画、白板、大字7种模式 | 独家的漫画模式可将严肃知识点转化为叙事性漫画，大幅提升内容传播力，是全仓库唯一依赖外部资源的工具，需安装Playwright和Chromium |
| **ljg-present** | 演讲铸造器 | 提供两种演讲风格：高桥流（一页一关键词，白底墨字）、标语流（黑红双色块粗体断言） | 高桥流适配需要深度思考节奏的分享场景，标语流适配需要强冲击感的演讲场景 |
| **ljg-travel** | 旅行研究 | 输入城市名生成深度文化研究文档+便携PNG卡片 | 跳出传统行程规划逻辑，先梳理城市的历史、文化、当下特质，让旅行脱离浅层打卡，回归深度体验 |
| **ljg-skill-map** | 技能地图 | 扫描所有已安装的ljg系列技能，生成可视化全景总览 | 解决用户工具越装越多、无法清晰掌握所有工具用途的痛点 |
| **ljg-push** | 推送引擎 | 将本地ljg系列技能一键同步到GitHub仓库，同时推送master和md双分支 | 面向技能维护者与贡献者的生产工具，降低内容同步的操作成本 |

### ⚙️ 官方预设串联工作流

李继刚亲自定义了两个低摩擦工作流，打通「理解」到「交付」的路径：
1.  **ljg-paper-flow**：`ljg-paper` + `ljg-card -c`，读完论文直接生成漫画卡片，一键完成内容消化到传播素材产出。
2.  **ljg-word-flow**：`ljg-word` + `ljg-card -i`，深度拆解单词后自动生成信息图卡片，大幅降低知识整理的操作成本。

### 🛠️ 安装方式
- 全量安装命令：`npx skills add lijigang/ljg-skills#md -g --all`，添加`#md`参数输出Markdown格式，适配Obsidian、VSCode等工具；默认是org-mode格式，适配Emacs用户。
- ljg-card额外依赖安装：`cd ~/.claude/skills/ljg-card && npm install && npx playwright install chromium`

### 💡 关键洞察

这套工具体系最核心的价值并非单点的效率提升，而是完整落地了`Read→Think→Write→Publish`的全链路认知闭环：它没有使用「智能」「AI赋能」这类营销化词汇，所有工具命名都采用「动词+极简名词」的直白结构，本质是帮助用户建立一套把混乱外部信息转化为专属个人语言的方法，就像中世纪炼金术士追寻哲人石的过程中意外催生了现代化学，这套工具最终会帮用户搭建起属于自己的认知处理体系。
