# 课程：内容工业化·03写稿agent

**一句话结论：** 写稿agent不只是帮写快，而是把老板审美装进小伙伴脑子，带她刻意练习形成肌肉记忆。

---

## 一、核心交付
- 一个agent：小红书内容转译专家（WorkBuddy）
- 两层价值：审美引导+提效
- 八轮迭代：V1到V8每次补一个角
- 一组数据：写稿7-8h压到3h

## 二、关键框架

### 2.1 两层价值
| 层 | 以前 | 现在 |
|---|---|---|
| 审美 | 只知"好像挺火" | 引导拆标题/结构/画像/评论/What-How-Why |
| 提效 | 看标题想很久 | 一眼识What/How/Why型，7-8h→3h |

- 把思考方式装进脑子形成肌肉记忆
- 从"靠我讲"到"她自己有判断"

### 2.2 V1-V8迭代要点
| 版 | 新增 |
|---|---|
| V1 | 粗流程：开场→收原文→拆爆款→插一堂→核查 |
| V2 | 加评论区分析，顺序按评论热度可调 |
| V3 | 引入双三角+爆款分析 |
| V4 | 加去AI味提示词，反向拆同行agent |
| V5 | 多轮对话关键处纠偏 |
| V6 | 加讲香标准+十指模型+可回退打磨 |
| V7 | 流程升级加YAI挖掘+范例对照 |
| V8 | 加定稿后重合度检查 |

- 转译公式：保留70%爆款框架+30%一堂方法论

## 三、金句与判断
> 「这个agent对她的价值，不只是写快一点，而是每篇都在带她刻意练习」
> 「以前她死熬我死讲，现在她知道跟着什么流程走」

## 四、速查卡

└ agent=装老板审美进员工脑子；V1-V8每轮补一个角；70%爆款+30%一堂 ┘
