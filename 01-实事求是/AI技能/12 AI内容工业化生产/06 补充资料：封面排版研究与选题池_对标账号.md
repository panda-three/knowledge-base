# 课程：封面排版对标·06

**一句话结论：** 封面要「吸引人 + 内容可读」兼得——长图文+IP 大脑袋最被推荐，思维导图式已过时；选题池和对标账号用飞书多维表格各存约 250 / 30 条，按数据筛爆款。

---

## 一、核心交付

- 一套封面风格清单：7 类，含推荐/不推荐判断。
- 两张表结构：选题池表、对标账号表（列字段可照抄）。
- 一组已验证选题样例（含赞/评数据）。
- 一张投放路径备选图（4 条转化路径）。

## 二、封面排版：7 类风格对比

| 风格 | 特征 | 判断 |
|---|---|---|
| **长图文+IP大脑袋** | 暖色纯色底，顶部大头照，下方大标题 | **chuck 更推荐** |
| 大字报+信息凸显 | 纯色/浅底，超大字报式标题 | IP 向可用 |
| 长图文+大标题（故事向） | 白底卡片，标注全文字数+阅读时长，标题+导语 | 故事向有效 |
| 思维导图 | 密集文字思维导图 | **不推荐，过时** |
| 比例统一+内容垂直 | 同系列模板，固定版式 | 注意设计不当易显 low |
| AI 信息图/漫画 | 卡通信息密集图；或手绘插画风 | 上版替代方案 |
| 手抄模型 | 手写笔记照片+手绘流程图 | 有辨识度、真诚（需字好看） |
| 名人语录 | 人物照+金句 | 媒体号可用，做 low 像营销号 |

**代表标题样例（可拆解语感）：**
- 「想赚 100 万，你只需要每天重复 6 小时」
- 「全文 2260 字，阅读需 4 分钟：带团队后如何杜绝幼稚表现」
- 「管理者的大忌：嘴快」
- [配图：各类封面样例拼图，见飞书原文]

## 三、选题池表（约 250 条）

**字段：** 笔记标题 / 封面标题 / 选题状态 / 选题时间 / 封面 / 改写方向 / 点赞 / 评论 / 内文 / 笔记正文 / 链接。

**已采纳高数据选题样例：**

| 选题 | 赞 | 评 |
|---|---|---|
| 花点时间去练一身赚钱的事真的不难 | 5.3w | 3.9w |
| 拥有老板思维的女生，不是年薪可以衡量 | 4.5w | 240 |
| 咋深度思考？ | 2.8w | 250 |
| 重塑你的职业生涯｜像CEO一样去赚钱 | 2.4w | 93 |
| 管理不是带人，而是搭系统和工作SOP | 7397 | 41 |
| 用AI把12人裁到3人，效率提升还是陷阱？ | 3868 | 1536 |

> 选题状态打「已采纳 / 待定」标签。

## 四、对标账号表（约 30 个）

**字段：** 账号名称 / 头像 / 简介 / 置顶 / 备注 / 类型 / 链接 / 等级。
**类型标签：** 案例、干货、AI模型图、AI漫画、AI信息图、手写模型、口播；重点账号标「非常重要」。

## 五、投放与转化路径（补充）

四条可选路径（原文残缺，细节待验证）：
1. 达人带货蓝链
2. 群聊-钩子转化
3. 伪装素人笔记钩子
4. 群聊-直播转化

> 待验证：原文此段截断，各路径适用条件与 ROI 未讲完，需回飞书补全。

## 六、行动建议

| 层级 | 行动 |
|---|---|
| 基础 | 照「选题池字段」建一张飞书表，先收 20 条对标 |
| 进阶 | 按「7 类封面」建自己的封面风格库，选定 1 类主用 |
| 高阶 | 把高数据选题按 What/How/Why 分层，定自己的借鉴下限 |

## 七、我的批注（双轨）

- 我的：「字数+阅读时长标注」的故事向封面很适合我做教学类内容封面。
- 待验证：投放 4 路径原文残缺，结论待补。
