# 课程：AI口喷·05单项到流淌

**一句话结论：** L5是连续3-10小时"全程只口喷、AI干活"的OPT心流状态，难的是AI团队产出达到人类高水准而非AI Slop。

---

## 一、核心交付
- 一个状态：连续3-10小时持续口喷心流
- 一个案例：6小时重做一套360内训课
- 五个关键词：知识库/多线程/全打通/封装/方法论
- 一个段位：连续口喷心流3-10h即L5

## 二、关键框架

### 2.1 从单条拉满到持续流淌
- L4是"某一次"前后拉满
- L5是持续拉满+持续流淌+持续心流
- 原则：拉满脑力，AI能闲人不能闲
- 卡点：人做的手工活太多，节奏卡卡的

### 2.2 极限案例：一晚重做一套课
| 项 | 数据 |
|---|---|
| 用时 | 6小时（人工原需1-2周） |
| PPT页数 | 191页 |
| 中文字数 | 约5812字 |
| 图片 | 72张（文生图约30） |
| Agent | 约10个Codex交叉分工 |

- 背景：360内训第一天反馈不够击穿，半夜决定重做第二天
- 做法：只手搓双三角+任务分解里程碑，其余全口喷
- 一口气喷3500字顶层文档，AI整理后派各Agent
- 窗口：飞书/Obsidian/Codex 5-7Session/笔记本备用

### 2.3 OPT英雄之旅六幕
| 幕 | 动作 |
|---|---|
| 1召唤 | 泛产品出牌，先出牌不列功能 |
| 2迷雾 | 启动调研，把资料压成判断 |
| 3地图 | 形成文档资产，文档是项目地图 |
| 4集结 | 双三角筹备，开战前先验信心 |
| 5战场 | 完成MVP，MVP是不确定性探针 |
| 6火种 | 申请立项，带证据要下一轮 |

### 2.4 高阶5个必要关键词
| 关键词 | 说明 |
|---|---|
| 知识库 | 本地知识库（Obsidian/WriteLess） |
| 多线程 | 多Agent并行，需多窗口多屏 |
| 全打通 | 飞书/一堂CLI随时可调用 |
| 做封装 | 数据包/Skill/设计宪法/AI员工 |
| 方法论 | 大量科学方法论随时调用 |

- 真高阶不是说得更多，而是底座随时响应

### 2.5 设备4代（价值<10%）
| 代 | 产品 |
|---|---|
| 1远程按键 | 自定义按键 |
| 2蓝牙口喷 | 按键+麦克风 |
| 3罗技鼠标 | 自定义按键+指针（用最多） |
| 4自编程 | m5stack硬件 |

- 新手不必拘泥，撞天花板再求设备

## 三、金句与判断
> 「AI能闲，人不能闲」
> 「难的是AI团队一轮下来达到人类高水准，而非一堆半截子产品」

## 四、行动建议
| 层级 | 行动 |
|---|---|
| 基础 | 重要项目先喷顶层文档再派活 |
| 进阶 | 搭双屏+多Agent窗口 |
| 高阶 | 挑战一次3-10h OPT心流 |

## 五、我的批注（双轨）
- 我的：六幕英雄之旅可迁移到自己做课
- 待验证：设备价值不到10%是老师经验
