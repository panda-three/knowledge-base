# 融资必修3：准备一份好的计划书

> L6 级别清单体笔记 ｜ 主讲：周子敬（以太创服CEO）
> 训练营3 · 一堂融资系列课

## 一、课程定位：BP 是融资的第一张名片

```text
BP = 融资的敲门砖。
内容不过关，后面所有努力都白费。
```

融资必修1 解决了「认知地基」——融资是什么、什么时候融。融资必修2 解决了「业务梳透」——商业模式、天花板、团队。融资必修3 把前两步的成果，转化为一份投资人有耐心看完、能看懂、能被说服的商业计划书。

| 维度 | 本课回答的问题 |
|---|---|
| 投资人视角 | 投资人看BP到底在看什么？TA怎么3分钟决定要不要继续聊？ |
| BP内容 | 一份合格BP必须回答哪7个核心问题？每页该写什么？ |
| BP结构 | 页面顺序怎么排？用什么逻辑串起来？ |
| BP格式 | 排版怎么不踩坑？颜色、图表、字体怎么选？ |
| BP打磨 | 写完第一版之后怎么迭代？用什么工具？ |
| 一句话介绍 | BP的封面第一行字怎么写？ |

**一句话定调：**

```text
BP不是产品说明书，不是战略规划文档，不是公司年鉴。
BP是一个逻辑自洽、数据诚实、让人在5分钟内理解并记住你的商业故事。
```

## 二、BP的核心逻辑：投资人在看什么

### 2.1 一句话说明BP的本质

```text
BP是围绕一个核心假设，讲一个逻辑清晰、自圆其说的商业故事。
投资人通过这个故事判断两件事：
1. 你的逻辑是否清晰；
2. 你的风格是否靠谱。
```

### 2.2 投资人的3大核心判断

| 投资人读完BP后必须能回答 | 你在BP里对应的内容 |
|---|---|
| **你是谁？（Who）** | 项目概况 + 团队介绍 |
| **你要做什么？（What）** | 产品或服务 + 解决的问题 |
| **你怎么做、怎么赚钱？（How）** | 商业模式 + 盈利模式 + 运营数据 |

### 2.3 投资人的7个必问问题

以太内部提炼的投资人视角七大问题——**你的BP必须逐条回答，一条不能漏**：

| 序号 | 问题 | BP对应页面 |
|---|---|---|
| 1 | **Who：你们是谁？** | 项目概况 + 团队介绍 |
| 2 | **Where：目标市场有多大？** | 市场规模 / 行业集中度 |
| 3 | **Why：所处行业痛点或用户需求？** | 痛点分析 / 需求场景 |
| 4 | **How：如何解决痛点？** | 业务模式 + 解决方案 |
| 5 | **Which：竞争对手如何？** | 竞品分析 + 差异化优势 |
| 6 | **What：运营现状及未来策略？** | 关键数据 + 发展规划 |
| 7 | **What：融资计划？** | 融资金额 + 资金用途 |

> 检验标准：找一个人，让他看完你的BP，然后问他这七个问题。任何一个答不上来，说明你的BP那一页没写清楚。

### 2.4 投资人看BP的三个残酷数字

| 数据 | 含义 |
|---|---|
| 投资人平均每天收到 50-100 份 BP | 你的BP在信息洪流中 |
| 只有 5-8 份会受到重视 | 淘汰率超过 90% |
| 阅读每份BP平均时间 **3分44秒** | 你没有长篇大论的时间 |

> 结论：BP不是越长越好。核心是把事情交代清楚，信息密度高，逻辑一目了然。

### 2.5 BP的浅层价值与深层价值

| 层次 | 价值 | 说明 |
|---|---|---|
| **浅层** | 让投资人快速了解项目 | 敲门砖，争取面谈机会 |
| **深层** | 帮创始人梳理创业思路 | 提炼产品逻辑、业务走向、发展规划、资金规划 |

**周子敬的核心观点：**

```text
亲自撰写与修改BP，是对自己创业逻辑的一次次梳理。
最终面对投资人的是创业者自己，FA无法取代。
```

## 三、BP的完整内容结构

### 3.1 BP标准页面结构（11-15页）

以太官方BP模板的推荐结构，自顶向下逻辑，层层推进：

| 页码 | 模块 | 核心内容 | 一句话自检 |
|---|---|---|---|
| P1 | **一句话介绍** | 你是谁，做什么 | 你妈能不能听懂？ |
| P2 | **痛点 & 需求** | 市场存在什么被忽视的问题 | 这个痛点够不够痛？ |
| P3 | **解决方案** | 你怎么解决这个问题 | 用户为什么选你？ |
| P4 | **市场机会** | 市场多大、增速、趋势 | 天花板够不够高？ |
| P5 | **商业模式** | 怎么赚钱、赚钱逻辑 | 收入-成本=？ |
| P6 | **竞品分析** | 竞争对手是谁，你和TA的区别 | 凭什么你赢？ |
| P7-8 | **核心数据 & 增长** | 用户、收入、增速、留存、复购 | 数据有没有说服力？ |
| P9 | **团队介绍** | 为什么是你们 | 不可替代性在哪？ |
| P10-11 | **发展规划** | 未来12-24个月怎么走 | 里程碑是否清晰？ |
| P12 | **融资需求 & 用款计划** | 要多少钱、怎么花、花到哪 | 钱花完能做到什么？ |
| P13 | **封底** | 联系方式 + 感谢 | 投资人想找你找得到吗？ |

### 3.2 两种推荐叙事逻辑

| 逻辑 | 适用场景 | 页面顺序 |
|---|---|---|
| **自顶向下（Top-Down）** | 市场机会驱动型项目 | 市场 → 痛点 → 方案 → 模式 → 团队 → 融资 |
| **问题驱动** | 技术创新/痛点到方案型项目 | 痛点 → 方案 → 市场 → 模式 → 竞品 → 团队 → 融资 |

> Airbnb天使轮BP采用的就是经典的自顶向下逻辑：先讲市场，再讲模式，然后细化竞争和团队，最后融资计划。这个逻辑优点在于每一层都为下一层提供推导依据。

### 3.3 每页内容的深度要求

**（1）一句话介绍——BP的封面第一行字**

```text
我们帮助【目标用户】，通过【核心方法】，解决【关键痛点】，
实现【可量化价值】。
```

必须让投资人3秒内知道你是谁、做什么。不要说「一家高科技公司」「一个创新平台」——这等于什么都没说。

**（2）痛点 & 需求——市场为何需要你**

- 不能说「这是一个万亿市场」。
- 要说「哪些用户，在什么场景下，遇到了什么具体问题，这个问题的严重程度」。
- 如果已有解决方案，说清现有方案的缺陷是什么。

| 错误写法 | 正确写法 |
|---|---|
| 「XXXX市场需求巨大」 | 「每年有X万企业因为XX问题损失了Y万元」 |
| 「用户有很多痛点」 | 「三类用户，分别卡在A/B/C环节」 |
| 「没有好的解决方案」 | 「现有方案A解决了X但没解决Y，方案B太贵」 |

**（3）解决方案——你带来什么不同**

- 不是产品说明书，而是价值主张。
- 说清楚：用户拿到你的产品/服务后，具体发生了什么改变。
- 用案例、截图、流程对比图辅助说明。

**（4）市场机会——天花板够不够高**

- TAM / SAM / SOM 三层拆解（方法见融资必修2）。
- 加一句「为什么是现在」——技术成熟了？政策放开了？用户习惯变了？
- 市场集中度预判：是分散市场还是终局会高度集中？

**（5）商业模式——你怎么赚钱**

- 收入来源 × 成本结构 = 盈利逻辑。
- 静态模式（1.0版本怎么赚钱）+ 动态规划（2.0版本叠加什么新盈利方式）。
- 如果还没盈利，至少说明「盈亏平衡点在哪，什么条件下能到」。

**（6）竞品分析——凭什么你赢**

| 必须说清 | 禁忌 |
|---|---|
| 直接竞品有哪些 | 「我们没有竞争对手」 |
| 间接竞品/替代方案有哪些 | 只列对手不分析差异 |
| 你和他们的本质差异 | 用主观感受代替客观对比 |
| 你的壁垒（技术/网络/品牌/规模） | 说「我有先发优势」但没有证据 |

> 没有竞争对手通常意味着要么没有市场，要么你没做调研。两个都是致命伤。

**（7）核心数据——最有说服力的一页**

- 不是列出所有数据，而是挑出最能证明增长模型成立的 3-5 个关键指标。
- 用户数、收入、增速、留存率、复购率、单位经济模型（UE）。
- **数据必须诚实。投资人一眼能看出水分。**

**（8）团队介绍——为什么是你们**

- 不是贴简历，是回答「不可替代性」。
- 结构：过去经历 → 发现机会 → 决定创业 → 凭什么比别人做得好。
- 如果团队有短板，坦率说比假装没有更好。但要说「知道怎么补」。

**（9）发展规划——接下来怎么走**

- 12-24个月的路线图。
- 每个里程碑要可验证：「Q3用户到X万」而不是「Q3实现快速增长」。
- 让投资人能想象：钱进来了，你们会变成什么样子。

**（10）融资需求——这是BP的收尾，也是开始**

- 融资金额、出让股权比例。
- 钱的具体用途：不是「用于公司运营」，而是「40%研发+30%市场+20%团队+10%储备」。
- 关键：「这笔钱花完后，公司能做到什么里程碑」。这是投资人决定投不投的最后一问。

## 四、BP的格式与美化：不踩坑的专业标准

### 4.1 总体格式要求（以太官方标准）

| 维度 | 要求 | 踩坑案例 |
|---|---|---|
| **页数** | 不超过12页，特殊情况不超过15页 | 动辄30页，投资人直接关掉 |
| **文件格式** | **必须用PPT**，导出为PDF | Word文档、长图文、网页链接 |
| **文字密度** | 字不如表，表不如图，不要大段堆字 | 一页300字密密麻麻，3分钟根本看不完 |
| **配色** | 每页不超过3种颜色（公司logo主色+黑+灰） | 荧光色、彩虹配色、五颜六色的图表 |
| **对齐** | 通篇字体、方框、表格、图表尽可能对齐 | 左飘右歪，一眼看出不用心 |
| **边框** | 每页内容不要超过安全边框范围 | 边距压到边，打印出来裁掉 |
| **风格** | 整体清新，布局留有空间 | 堆满内容，没有呼吸感 |
| **动画** | 不要花哨动画和音效 | 每一行字都设一个飞入动画 |

### 4.2 字体的推荐与禁忌

| 场景 | 推荐 | 禁忌 |
|---|---|---|
| 中文字体 | 思源黑体 / 微软雅黑 | 宋体（投影糊）、艺术字、手写体 |
| 英文 & 数字 | Arial / Helvetica | Comic Sans、花体字 |
| 字号 | 标题24-32pt，正文14-18pt | 正文字号小于12pt（根本看不清） |
| 强调 | 加粗 / 变色，不要同时用超过2种强调方式 | 又是加粗又是斜体又是下划线又是红字 |

### 4.3 图表的三个铁律

```text
1. 能用图表绝不用文字：趋势用折线、占比用饼图、对比用柱状图。
2. 一个图表只讲一件事：不要在同一个图里塞3个数据故事。
3. 每个图表都要有标注：没有数据来源、没有坐标轴说明 = 不可信。
```

### 4.4 BP文件命名规范

| 正确命名 | 错误命名 |
|---|---|
| `项目名_BP_2025年X月_V3.pdf` | `最终版真的最终版.pptx` |
| `XX科技_A轮商业计划书_Q1.pdf` | `新建文件夹/BP.ppt` |

## 五、BP写完后的打磨：三遍过

### 5.1 第一遍：逻辑自检（自己看）

逐页问自己三个问题：

| 页面 | 自检问题 |
|---|---|
| 每一页 | 这一页只讲了一件事吗？ |
| 每一页 | 前后的因果关系成立吗？ |
| 整份 | 从P1到P12，是一个完整的推导链，还是一堆散装信息的拼凑？ |

### 5.2 第二遍：陌生人测试（别人看）

把BP给**一个对你业务完全不了解的人**，限时3分钟看完。

| 测试问题 | 合格标准 |
|---|---|
| 我们是做什么的？ | 他能一句话说清 |
| 我们怎么赚钱？ | 他能讲出盈利逻辑 |
| 我们的竞争优势是什么？ | 他能说出1-2个关键差异点 |
| 我们要融多少钱、干什么？ | 他能记住 |

> 如果答不上来，不是他理解力差，是你的BP还不够清楚。

### 5.3 第三遍：投资人视角（换位看）

```text
假如你是投资人，每天收到100份BP，只有3分钟看一份。
你会不会把这100份里的这一份，放进「继续聊」的5-8份里面？
如果不会，哪一页让你犹豫了？
```

《BP打磨工具》是课程配套的工具材料，用于自查BP在每个维度是否达标。

## 六、一句话介绍：BP的灵魂

这一页在前面几门课里反复提到，但它对BP来说，是**封面第一行字**，决定了投资人会不会往下翻。

### 6.1 一句话介绍的公式

```text
我们帮助【目标用户】，通过【核心方法】，解决【关键痛点】，
实现【可量化价值】，已经做到【关键数据】。
```

### 6.2 案例对比

| 类型 | 错误 | 正确 |
|---|---|---|
| 平台型 | 我们是一个创新的电商平台 | 我们是母婴领域的拼多多，连接200+品牌与50万宝妈，月交易额突破XX万 |
| SaaS | 我们帮助企业提高效率 | 帮助企业解决客服人力成本过高问题，ARR已达XX万，续费率90% |
| 消费品 | 我们做新一代洗护品牌 | 专为敏感肌研发的氨基酸洁面品牌，复购率35%，单月GMV破XX万 |

### 6.3 一句话介绍的三个铁律

```text
1. 你妈能听懂：不用任何行业术语和虚词。
2. 有可量化数据：『已经做到X』比『目标是Y』强10倍。
3. 3秒能读完：超过30个字就砍。
```

> 课程附带 28 个真实一句话介绍案例集，建议对照参考。

## 七、4个典型行业的BP要点差异

BP框架相同，但不同行业的重点页面和投资人关注点不同。课程提炼了四个典型行业：

| 行业 | BP核心页 | 投资人最关注 |
|---|---|---|
| **SaaS / 企业服务** | 续费率、获客成本（CAC）、客户生命价值（LTV）、LTV/CAC | 续费模型是否成立 |
| **消费品 / 品牌** | 复购率、客单价、毛利率、渠道结构 | 品牌壁垒的真实性 |
| **平台型 / 双边市场** | 双边用户增长、交易额、抽佣率、网络效应 | 冷启动怎么破、飞轮是否转起来 |
| **硬科技 / 技术驱动** | 技术壁垒、专利、应用场景、产业化进度 | 技术是否可落地、商业化时间表 |

## 八、BP经典案例：Airbnb 天使轮复盘

课程附带 Airbnb 早期天使轮 BP 的完整案例解读。Airbnb 的 BP 一共 14 页，分了 8 个模块：

| 模块 | 页数 | 核心内容 |
|---|---|---|
| 首页 | 1页 | 一句话介绍 |
| 产品简介 | 2页 | 痛点 + 解决方案 |
| 市场介绍 | 2页 | 市场空间和规模 |
| 商业模式 | 2页 | 产品模式 + 运营模式 + 盈利模式 |
| 竞争分析 | 2页 | 外部条件 + 竞品差异 |
| 团队分析 | 1页 | 团队能力 |
| 产品进展 | 2页 | 媒体反馈 + 用户反馈 |
| 融资条件 | 2页 | 需要多少钱 + 下一步计划 |

**Airbnb BP 的三个关键启示：**

```text
1. 逻辑自顶向下，层层推导：先市场，再模式，再团队，最后融资。
2. 数字极其克制：早期没有收入数据，就用媒体反馈和用户评价代替。
3. 每一页都干净有力：14页讲完一个完整故事，没有一页是废话。
```

## 九、常见BP错误（自检清单）

| 序号 | 常见错误 | 严重程度 | 怎么改 |
|---|---|---|---|
| 1 | 首页没有一句话说清做什么 | ⭐⭐⭐⭐⭐ | 用第六节公式重写 |
| 2 | 写「我们没有竞争对手」 | ⭐⭐⭐⭐⭐ | 列出替代方案和间接竞品 |
| 3 | 大段文字堆砌，没有人能3分钟看完 | ⭐⭐⭐⭐⭐ | 一页一个观点，字不如表，表不如图 |
| 4 | 数据注水或来源不明 | ⭐⭐⭐⭐ | 每个数字标注来源和计算逻辑 |
| 5 | 用款计划写成「用于公司运营」 | ⭐⭐⭐⭐ | 拆成具体的用途和比例 |
| 6 | 团队介绍写成简历堆砌 | ⭐⭐⭐⭐ | 改成故事线 + 不可替代性论证 |
| 7 | 市场规模只写「千亿市场」 | ⭐⭐⭐ | 用TAM/SAM/SOM分层拆解 |
| 8 | 商业模式说不清怎么赚钱 | ⭐⭐⭐ | 收入来源 × 成本结构，说清第一块钱怎么来 |
| 9 | 文件格式混乱，排版不专业 | ⭐⭐⭐ | 用课程附带的《BP格式美化工具箱》调整 |
| 10 | 通篇没有数据，只有主观描述 | ⭐⭐⭐ | 补充关键指标：用户数/收入/增速/留存 |

## 十、拓展模块：转型升级与B轮后估值

课程还包含三个拓展模块：

### 10.1 拓展：转型升级项目的BP写法

- 不是「我们以前做A，现在做B」。
- 而是「我们积累了X资源/认知/用户，这些资产使我们在做B时有别人不具备的起点优势」。
- 关键是让投资人看到：转型不是被迫，而是基于已有资产的一次战略升级。

### 10.2 拓展：B轮以后的公司估值方法

- 天使/A轮：估值偏艺术，看团队+方向+早期信号。
- B轮及以后：估值偏科学，用可比公司分析（Comps）、DCF（现金流折现）、上一轮估值+里程碑溢价。
- 核心原则：B轮以后不只看「值多少钱」，更看「这个估值下一轮还融得进来吗」。

### 10.3 拓展：4个典型行业的深度拆解

课程针对 SaaS、消费品、平台、硬科技四个行业，提供了行业BP优秀作业集和更深度的BP分析。

## 十三、核心记忆点（30秒回顾）

```text
1. BP本质：一个逻辑自洽、数据诚实的商业故事。
2. 七大问题：Who / Where / Why / How / Which / What-运营 / What-融资，一页都不能漏。
3. 三分钟定生死：投资人平均只看3分44秒，页数不超15页。
4. 格式铁律：PPT格式、配色不超3种、字不如表、表不如图、坚决对齐。
5. 一句话介绍：你妈能听懂 + 有可量化数据 + 3秒能读完 = BP第一张名片。
6. 竞品分析：绝不写「我们没有竞争对手」。
7. 用款计划：不是「用于运营」，而是具体用途拆解 + 花完后做到什么里程碑。
8. 三遍打磨：逻辑自检 → 陌生人测试 → 投资人视角换位。
9. 亲自写：BP是对创业逻辑的梳理，FA没法替你思考。
10. BP写好 → 下一课：融资必修4，如何增加资本约见。
```
