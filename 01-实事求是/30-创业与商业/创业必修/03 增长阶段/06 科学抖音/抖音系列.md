| **执行框架** | 短视频测试三步法（不断地出关键假设，验证关键假设） |
| **加速策略** | 提升起盘效率的 5 种方法 |

| **真实案例** | 10+ 个学得会的案例拆解 |

### 关键小抄

> 起盘账号**总内容压到 7-10 秒**。为什么？——因为新手阶段，短内容更容易获得完整播放，数据反馈更快，测试循环更短。

### 抖音起盘的精细维度（从学员笔记提取）

| 维度 | 要决策的事项 |
|---|---|
| **时间** | 不同发布时间，你的目标用户什么时候看？ |
| **账号** | 封面、头图、头像、名字、个人简介——账号的门面就是线上门店的门面 |
| **选题** | 主题、热度等 |
| **文案** | 观点、干货、案例、金句 |
| **表现形式** | 口播、访谈、故事 |
| **内容结构** | 总分总、开头制造冲突、提问+答案 |
| **拍摄** | 画面（镜头、布景）、人物（形象、表情、表现方式） |

### 关键判断

> 千万别把 0 同于 1。流量工具，不必太在意一个账号的成败得失，要在于自己能有地从 0 到 1 的能力。最核心的一定是要触达用户、成交、变现。表象是流量，内核是把你的账号调到一个可复用的模型。

### 华熙生物五步法画布（脱敏版）

| 五步法维度 | 核心决策 |
|---|---|
| **1. 需求** | 用户画像：普通女性美妆用户（非成分党、非高学历）；场景：兴趣电商，刷视频偶然发现，需唤醒需求 |
| **2. 解决方案** | 主打面膜+眼膜；定价 300-400 元 N 盒套组；核心卖点：针对普遍眼周问题，拍 1 盒发 6 盒+20 片赠品 |
| **3. 商业模式** | 品牌店播为主，达人带货辅助；关键单元模型：旗舰店直播间 |
| **4. 增长** | 第一指标：点击转化率；增长关键：①专注商家店播 ②为抖音打造爆品 ③建立直播间矩阵 ④少就是多；早期通过付费投放提升规模 |
| **5. 壁垒** | 品牌；非壁垒：研发技术、SKU数量、达人带货、投放技巧、直播技巧 |

### 核心决策难题

| 决策点 | 选项 |
|---|---|
| 选模式 | 自播？还是达人？ |
| 选产品 | 已有爆品？还是新造？ |
| 选流量 | 付费流量为主？还是免费流量？ |

### 张阳的核心判断

> 不要觉得做抖音就是做一个号，玩玩看。抖音是一个创业过程，有预判，有概率，有商业分析，跟你做一个独立创业是完全一样的。

> 我从来没把做抖音当成做一个渠道，只思考搞流量。我做抖音操盘的每一个项目，都当成了一个独立创业项目来做。

### 足力健案例：如何把主播从月薪 2 万降到 5000

张阳通过三套标准化模型，完成了 10 倍营销规模的扩张：

**卡点1：带货依赖营销能力 → 营销文案三板斧**

```
激发欲望 → 赢得信任 → 引导下单
```

每一句文案背后都有设计意图。有了模型，文案能力可批量复制。

**卡点2：直播依赖个人能力 → 主播培训三板斧**

```
话术背诵 → 产品展示 → 情绪表达
```

主播定位为**演员**，逐字稿就是剧本。提供 5 分钟完整卖货逐字稿，包括语气词和肢体动作。所有主播一模一样。

**卡点3：执行依赖个人状态 → 主播运营三板斧**

```
日常抽查 → 日常监督 → 双重监督（督查组 + 督战队，共 20 人）
```

### 结果

> 60-80 人主播团队，ROI 业绩方差约 **0.3%**，下限控制极好。出了问题，两轮督导就能发现。
