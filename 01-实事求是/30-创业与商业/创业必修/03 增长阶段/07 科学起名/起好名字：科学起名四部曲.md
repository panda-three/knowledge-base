# 起好名字：科学起名四部曲

**讲师**：Truman（一堂CEO / 课程总设计师）
**课程起源**：汇集10+顶级营销专家集体智慧，磨出一套科学起名方法论
**课程定位**：科学专项系列课——用科学方法替代拍脑袋，系统解决「起名字」这个核心经营难题
**教研方法**：爆炸式研究——把市场上所有起名策略和类型聚合到一起，封装成《一堂爆炸式起名工具》
**核心矛盾**：第一天就得有名字，但往往有钱了才有资源请顾问（5-20w+）。最早的时候怎么起好名字？——学好这节课，别给自己留太多坑
**梁宁金句**：「名字是召唤，名字是你的文化资产，文化是召唤世界的咒语。当你要起一个名字的时候，你要知道你是在寻找一句咒语。」

## 一、为什么需要科学起名：普遍痛点

**五大典型困境**：
- **憋不出**：缺少才华，想不出好名字，憋两周写不出几个，只能草草定一个
- **拍脑袋**：翻词典、翻历史典故、开头脑风暴会，讨论太浅，没有场景设想、没有充分调研、没有足够激发
- **定早了**：早期随便起名，业务做大了才发现商业效能太低，推广传播口口推荐都出问题，改不了——如鲠在喉
- **缺保护**：忽略品牌资产积累，没有注册/申请知识产权，积累半天陷入商标纠纷，为别人做了嫁衣
- **走偏路**：不思考品类/产品卖点/用户心智，琢磨五行八字，喜欢去天桥下面找算命大师——掐指一算

**核心问题**：很多人送了10多年礼、记了10多年笔记，同样——很多人起了10多年名字，还是憋不出好名字、草草定下、用不起来、改不了

## 二、好名字的价值与本质

**名字的三个要素**：
- 目标用户：理解目标群体，用户是谁
- 产品：产品定位、产品边界、产品未来、产品心智
- 沟通：沟通场景，线上&线下，看&听&说

**两个商业目标**：
- 促成交易（短期）：让用户看懂/感兴趣/建立信任，更容易交易
- 形成品牌（长期）：形成品牌资产，知名度/美誉度/忠诚度

**名字的本质**：好的名字 = 帮助目标用户和产品持续沟通，促进交易，最终形成品牌。没有目标，就不要谈好坏和效率。

## 三、建立审美：起名四维模型

**口诀**：「传意安配」——传播性、意义性、安全性、匹配性

**四维总览**：

| 维度 | 一句话 | 核心问题 |
|:---|:---|:---|
| 传播性 | 好不好传 | 好念/好听/好记/好写/好打字吗？ |
| 意义性 | 有没有味 | 看得出是个品牌吗？有定位/正面情感/用户立意吗？ |
| 安全性 | 安不安全 | 可注册吗？有法律风险吗？可适应未来扩品类/国际化吗？ |
| 匹配性 | 能不能接 | 和团队文化/气质匹配吗？和长期营销匹配吗？ |

**核心取舍原则**：不要有太大硬伤（完全听不懂/无法读/无法记/错位/负能量）的基础上，**传播性和意义性可以有所侧重**

---

### 维度① · 传播性（五好原则）

**五好标准**：好读、好听、好懂、好记、好打字

**反面案例**：
- **罗辑思维**：哪四个字？罗振宇内部多次提到传播有问题
- **徕芬吹风机**：哪两个字？各地区能准确发音吗？能记住能输入吗？
- **Tiptoe Roll**（女装品牌）：连同事都记不住自己在什么名字的公司工作
- **卡特罗布：伊克斯珮瑞门特**（游戏名）：完全无法口头传播
- **茶颜悦色 vs 茶理宜世**：三天后能记住哪个？
- **栖子阁**（民宿）：小红书上看「很好看」，但口头推荐「能读准？能记住？能输入？」——内容种草/口碑推荐场景下是灾难

**正面案例**：
- **一堂**：作业里提及率30%（8.2万份），累计18.7万次，平均每份作业提2.3次——远超行业均值；如果叫「二堂/MVC/大望商学院」能有10%就不错了
- **hi&gogo → 长高高**（海外奶粉）：中英搭配，互为补充，降低门槛，会心一笑
- **BOP**（口腔护理）：三个字母，城市年轻人接受度高，易读易记易输入，还有品牌调性

**关键原则**：文学素养好的文化人，请努力忍住自己的表达冲动，多从用户和商业出发。英文/日文/符号使用是表象，核心是传播性判断——需结合目标群体和场景具体分析。

**场景差异**：
- **写很强的场景**（搜索/投放）：尽量不要用谐音，不要用生僻字
- **读很强的场景**（口口推荐）：发音不要太拗口，注意平舌翘舌/nl/hf不分
- **看很强的场景**（门牌/shoppingmall）：不会发音没事，文字一目了然最重要

---

### 维度② · 意义性（张力法则）

**什么是意义**：唤起一种特别的情绪、浓烈的情感、美好的幻想、品牌的信任——好名字有「张力」

**意义性的五种表现**：
- 寓意：反映一种文化价值观
- 逼格：很高级、很洋气
- 正能量：呈现美好的寓意
- 专业：体现特别的专业信任
- 定位：独特的价值和卖点

**传播性 vs 意义性的分工**：
- 传播性 → 对「知名度」更有帮助
- 意义性 → 对「美誉度和忠诚度」更直接帮助

**意义性 > 传播性的场景**：高端住宅、民宿、奢侈品、企业咨询——逼格/故事/品质远比容易读、容易记重要，有时会为了提升意义性而损失传播性，往往也是明智做法

**正面案例**：
- **结伴**（医院陪护）：唤起陪伴的想象
- **有知有行**（理财社区）：踏实的信任感
- **半自由**（洗护产品）：情绪张力

**反面案例**：
- **有你**（文化传播公司）：太泛了，不够精准，没有体现专业度
- **叫了个鸭子** → 后来有人叫「叫了个鸡」：容易引起不好联想、情绪对立
- **人人天使 / 明释 / 晋商贷(>大熊贷) / 望月资本 / 疯牛传媒 / 红羊基金**：不明所以

---

### 维度③ · 安全性（三问法）

**三个核心问题**：
- **注册问题**：是不是需要注册&可以注册，有没有法律风险？
- **内核问题**：长期是不是符合核心定位？
- **边界问题**：长期业务转型/扩品类/国际化，要不要考虑？

**反面案例**：
- **今日头条**：静态满分（易传播自带流量，极好意义和稀缺性），但长期拓展性一般，不能延展更多业务，只能新建品牌（字节跳动）
- **原咖啡**：自己和用户都喜欢，花几千块做Logo，顾客也喜欢——但「原」字没法通过咖啡类商标审核
- **叫个鸭子 / 一朵棉花（纸巾）**：更容易出爆品，但取小了，跟不上未来发展，品类很受限

**核心建议**：往往业务早期生存阶段无法两全，但如果未来有品类计划，还是要综合考虑，不能只看眼下。**宽一点还是爆一点——综合权衡。**

---

### 维度④ · 匹配性（系统工程）

**核心理念**：名字只有几个字，但这是个系统工程。最终要落到营销体系（logo/品牌故事/VI/广告）里，不能孤立看几个字。

**匹配性判断维度**：
- 和团队文化、气质匹配吗？
- 和长期营销匹配吗？
- 有营销能力和资源把故事讲清楚吗？

**正面案例**：
- **厨房硬件 + geek团队**：起科技/很酷的名字ok
- **厨房硬件 + 销售导向/白牌产品**：不如生活化，主打品质和性价比，和用户亲近一点

**操盘能力警示案例**：
- **俏江南**：其实是川菜，很好听的名字——你能hold住吗？
- **可可满分**：其实是椰乳饮料——你能hold住吗？
- **哆猫猫**（零食）：到底是给儿童还是宠物吃的？——如果营销资源不够，在各个包装/落地页/直播/种草场景里讲不清楚

**严重翻车案例**：
- **安心找家政**：市政府经济部门牵头的数字化项目，核心功能只是家政机构和家政服务员**信用背景查询**，并不提供撮合和下单功能。加个动词「找」→ 被人诟病「不能通过这个平台找到（直接下单）家政服务」——在起名阶段但凡有一丁点儿考虑不到，日后就如鲠在喉

## 四、科学起名四部曲

**核心流程**：分析 → 加法 → 减法 → 执行

---

### 第一步：分析目标（三要素画布）

**核心原则**：一定要代入场景设计。没有目标，就不要谈好坏和效率。

**三要素分析画布**：

**A. 目标用户**
- 自查1：小众能接受吗？还是尽量大众能懂？
  - 小众ok → 用圈子里面的词/黑话/晦涩语言（bilibili、36氪、青岑、己已巳民宿）
  - 尽量大众 → 让大家都知晓
- 自查2：用户有标签吗？至少写出2-3个
  - BOP（城市年轻人口腔护理）→ ok；老年人陪护 → 不合适
  - BeautyFit（城市女生健身房）→ 想做男性&下沉 → 要认真考虑

**B. 使用场景**（场景小抄三部分）
- **认识品牌**：电商列表、货架、门牌、携程推荐列表、短视频探店/直播带货
- **搜索品牌**：主动搜索输入、回忆后搜索购买
- **推荐品牌**：口头推荐给朋友、小红书种草、公众号推广

不同场景侧重点完全不同：货架 → 谐音梗问题不大；搜索 → 谐音很麻烦；门牌 → 不会发音没事；口碑推荐 → 发音和记忆极重要；投放 → 文字要一目了然、简单直接

**C. 名字边界**
- 有品类拓展计划吗？
- 有用户拓展计划吗？
- 有国际化的想法吗？

### 第二步：做好加法（三大策略 · 20+武器）

**核心原则**：加法越多越好，通常从100个名字里挑一个，比从5个里挑质量好得多。加法阶段尽量不批判，持续头脑风暴。

**三大策略总览**：

---

**策略一：从同行出发**
- 根据产品&渠道类型，寻找30-100个同类名字，然后类比、借鉴、改写
- 实操：把名字扔进Top名字堆里，如果看着差不多，基本就是好名字了
- 参考维度：Top名字（上市公司/行业头部）、对标模式（同样模式/同行渠道/同行客群）
- 案例：一堂 ← 高维（红岸）/ 五道口商学院（大望商学院）/ 混沌（熵增、盘古）/ 行动商学院（破土/节节高/破茧/起航商学院）/ 微软加速器（以太加速器）

---

**策略二：从产品出发**（7个子策略）

| 子策略 | 操作要点 | 典型案例 |
|:---|:---|:---|
| 产品属性 | 从原材料/产品特征出发 | 农夫山泉、纯棉时代、余额宝、胶囊茶语 |
| 从品类出发 | 品类词放入名字 | 蒸汽熊精酿、福气鲜活面包、辣么卤力、帅克宠物、书亦烧仙草 |
| 核心卖点（多快好省） | 多：量大/品类多；快：速度；好：品质；省：省钱 | 大众点评/闪送/飘柔/什么值得买 |
| 使用场景 | 每日系列/日常场景 | 每日黑巧、三顿半、一人食、下个街角 |
| 美好寓意 | 祝福含进去/吉利词含进去 | 太太乐（传统）/ 喜茶（新品牌）/ 好孩子 / 福临门 |
| 企业愿景 | 用户好/国家和世界好 | 一堂/和睦家 vs 华为/中兴通讯/华润 |
| 文化调性 | 品牌态度和调性 | 步履不停、太二酸菜鱼、跳海酒馆、江小白、吾皇驾到 |

### 第三步：做好减法（四层筛选）

**核心认知**：减法最最重要的是判断能不能注册下来。**能注册成商标的品牌名，才能算作长期资产**（赚快钱/山寨不在此范畴）。

**商标注册残酷真相**：
- 两个字注册商标 → 常用字/词基本不用想
- 三个字注册商标 → 看运气，好词/常用词概率很低
- 相对靠谱 → 注册四个字以上，或自己造词/用非常用字
- 如此反复几天，再过商标注册关，十不存一

**商标检索网站清单**：
- 重点推荐：政府官网 sbj.cnipa.gov.cn、阿里云商标 tm.aliyun.com（免费+图像检索）、飙局 biaoju01.com
- 其他备用：摩知轮、社标网、爱企查/企查查/天眼查商标、企信企服、八戒网

**三个折中策略**：① 偷偷用 ② 注册长标，用简化版 ③ 未来买
- 一堂案例：注册「以太创服一堂」（6个字），内部简称「一堂」，Logo用「以太一堂」——短期够用但单独出现时有风险

---

**减法四层筛选法**：

**① 可用性测试（商标注册）**：能注册下来的名字才算长期资产。和服务商讨论品类号范围。

**② 内部评价（团队共识）**：核心团队每人提交10个甚至几十个备选→一起商量。好的名字团队内部是有感觉的，团队本身也是名字最重要的使用者。可成立「品牌名攻坚小组」要求每人必须提交。

**③ 外部评价（业内反馈）**：找行业专家/合作伙伴/投资人征求意见——行业认可度、专业性、市场前瞻性。

**④ 用户测试（三种低成本方法）**：
- **搜索测试法**：发给10个朋友名字列表，过两天问「记得哪个」「怎么搜」「会怎么打字」
- **电话测试法**：介绍两次名字→5-10分钟后问「还记得我们品牌叫什么吗」「知道是哪几个字吗」——问三四个人就知道是不是简单易记
- **AB测试法**（互联网团队）：把几个名字做成Banner/海报→投流量看转化率/注册率/留存率；小红书种草换名字看反馈；直通车广告测认知转化率；抖音直播间换名字称呼看购买兴趣（花几千块钱测几轮，往往不失为科学的起名字方法）

### 第四步：落地执行（三维工程）

**核心理念**：起名字是个系统工程，不是定了名字就完了。

**① 品牌套装**：名字只是品牌营销整体的一部分。通常还需要：Logo / Slogan / 品牌故事 / VI。一堂实践：最早只有名字+一句话Slogan用了一年半→商标定下来后花几万做新Logo/配色规范/物料规则。

**② 全面注册**：一旦商标定了，尽早统一注册公司名称/域名/公众平台/社交媒体。尤其是公众号有排他性。商标类别除了主要2-3个，建议多注6-7个→后期考虑「商标储备和防御」（老干妈把所有老干爹系列全注册）。

**③ 改名难题**：核心是投入产出比——
- 品牌做到1亿奔百亿去 → 切换还行
- 市场规模不大但已经很大 → 改起来很难
- 折中思路：推出子品牌（猫眼/红米）、增加英文或中文名、升级Logo和VI、增加品牌解释
- **品牌改名往往很难操作，尽量在业务早期多设计思考，少给后面埋坑**

## 五、一堂内部实践：基本功起名的启发

**一堂起名的内部实践**：
- 如果概念模糊没有定义，很难稳定想到它，更别说培养条件反射式的肌肉记忆
- 统一名字的好处：统一话语体系、有行动号召、方便协作（讨论/搜索）、有效提升提及率和使用率
- 操作谨慎：最好确定必要性（不会轻易推翻）再去起名，配套知识库/Mentor/Q&A要跟上

**基本功起名审美五标准**：
- **宽而不泛**：尽量通用，但不要过于宽泛到常用词（如「表达基本功」「电话基本功」太宽）
- **短而有力**：能记住、能搜到、能讨论、能协作
- 案例Before → After：AI内容撰写→AI写稿 / 快速找到药品供应→找货品 / 提前调研目标场景→探店踩点 / 政府监管部门对接→对接监管 / 持续维护客户→客户跟进 / 表达→客户沟通

## 六、课程升华：名字的真正意义

**梁宁的话**：「名字是召唤，名字是你的文化资产，文化是召唤世界的咒语。通过这个咒语，你和你的同伴一起召唤你的产品，把它从无到有召唤到这个世界上。你的所有用户都是因为这个名字，这句咒语，定义你们所有的工作，与你们发生连接。」

**一堂内部小故事**：一本工具书叫《创业最佳实践》，内部各有称呼（教材/工具箱/小册子），缺一个打动人心的称呼。一次共建会有同学问「新一版小黄书什么时候到」——一下子有了独特称呼，大家都爱小黄书。**所有你想长期传颂的东西，都需要一个好名字。**

## 九、课程结构总图

```
科学起名四部曲
│
├─ 建立审美：起名四维模型
│   ├─ 传播性（五好：好读/好听/好懂/好记/好打字）
│   ├─ 意义性（张力：情绪/情感/幻想/信任）
│   ├─ 安全性（三问：注册？内核？边界？）

│   ├─ 目标用户（小众vs大众、用户标签2-3个）
│   ├─ 使用场景（认识/搜索/推荐 + 场景超级小抄）
│   └─ 名字边界（品类拓展/用户拓展/国际化）
│
├─ 第二步：做好加法（三大策略·20+武器）
│   ├─ 策略一：从同行出发（Top名字/对标模式）
│   ├─ 策略二：从产品出发（产品属性/品类/卖点/场景/寓意/愿景/调性/IP）
│   └─ 策略三：从语文出发（数字/植物/动物/故事/叠词/口语/谐音/动词/新词/IP/修辞）
│
├─ 第三步：做好减法（四层筛选）
│   ├─ 可用性测试（商标注册+检索网站清单）
│   ├─ 内部评价（团队共识+攻坚小组）
│   ├─ 外部评价（业内反馈）
│   └─ 用户测试（搜索测试/电话测试/AB测试）
│
└─ 第四步：落地执行（三维工程）
    ├─ 品牌套装（Logo/Slogan/品牌故事/VI）
    ├─ 全面注册（公司/域名/社交媒体/多类商标/防御注册）
    └─ 改名难题（投入产出比/折中思路：子品牌/升级VI）
```
