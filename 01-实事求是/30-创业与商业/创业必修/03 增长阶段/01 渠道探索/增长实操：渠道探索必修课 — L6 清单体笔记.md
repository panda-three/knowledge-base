# 增长实操：渠道探索必修课 — L6 清单体笔记

---

## 一、课程定位与核心金句

> **「获客以前觉得特别难，懵懵懂懂，天大难题，但一旦摸出来认知，就会觉得很基础很简单啊，不过如此。」**

> **「获客就像是捕鱼，你要去鱼多的地方捕鱼。」**

> **「优秀的渠道都是测出来的，不是烧出来的。」**

> **「很多人跳过了扫描和预判，想到了一个渠道就立即开始测试，因为盲区，可能就失去了很多高质量的机会。」**

**课程在增长系列中的位置**：

```text
一堂增长系列：
  五步法进阶4：重新理解「业务增长」（增长框架篇）
    → 增长实操：渠道探索必修课（渠道四步法）← 本节课
      → 增长实操：科学销售
        → 增长飞轮
          → 工业化生产
```

**本节段位目标**：帮你从**「凭手感随机获客」提升到「科学四步法系统探索渠道」**——从渠道扫描到渠道建模，形成一套可复制、可持续的获客体系。

**一句话交付模型**：**渠道探索四步法（扫描→预判→测试→建模）+ 渠道全清单 + 六大评估维度 + 三大测试策略。** 把获客从"玄学"变成"工程"。

**课程渊源**：一堂从2021年以来获客规模完成近10倍增长，以周为单位提假设、做实验、复盘认知。结合三年获客认知和大量学员真实案例，封装出这套科学探索渠道的方法论。

**推荐谁学**：业务模型基本跑通，但渠道一直打不开、获客艰难、依赖直觉手感、手段单一、盲目跟风、没有焦点的创业者和业务负责人。

## 三、核心认知：为什么大多数人的渠道探索是低效的

### 3.1 五种典型低效姿势

```text
┌─────────────────────────────────────────────────────────┐
│         渠道探索 · 五种典型低效姿势                        │
├──────────────┬──────────────────┬───────────────────────┤
│   问题类型    │      典型表现      │        本质            │
├──────────────┼──────────────────┼───────────────────────┤
│ 盲目跟风     │ 同行做什么，       │ 从来没有独立分析过       │
│              │ 我们也做什么       │ 自己的渠道适配性         │
├──────────────┼──────────────────┼───────────────────────┤
│ 缺少见识     │ 只有一个渠道，      │ 根本不知道还有其他        │
│              │ 不知道其他可能性    │ 可能性                  │
├──────────────┼──────────────────┼───────────────────────┤
│ 没有焦点     │ 什么渠道都想试，    │ 精力极度分散，            │
│              │ 每个都浅尝辄止     │ 没有优先级排序            │
├──────────────┼──────────────────┼───────────────────────┤
│ 不会预判     │ 逮着一个做一个，    │ 从来没有提前排序过        │
│              │ 从来没有提前预判   │ 渠道的优先级              │
├──────────────┼──────────────────┼───────────────────────┤
│ 缺少手段     │ 没有成体系的方法   │ 不会低成本测试，           │
│              │ 去探索测试验证     │ 不会建模，不会复盘         │
└──────────────┴──────────────────┴───────────────────────┘
```

### 3.2 最致命的跳步

```text
绝大多数人的渠道探索流程（错误版）：
  想到了一个渠道 → 立即开始测试 → 砸钱 → 亏了 → 换下一个

正确的渠道探索流程：
  扫描（全面罗列）→ 预判（优先级排序）→ 测试（低成本验证）→ 建模（稳定复制）

跳步的代价：
  跳了扫描 → 存在大量盲区，可能错过最优渠道
  跳了预判 → 资源分散，在低优先级渠道上浪费精力
  跳了测试 → 直接建模投入，渠道ROI不成立却已经烧了大量资金
```

## 五、第一步：扫描（Scan）— 做加法，消除盲区

### 5.1 核心任务

> **「渠道的第一步是渠道扫描，核心工作是尽量罗列你可能的渠道，争取不设限，多做加法，努力多拆解和罗列可能的获客方式。」**

### 5.2 三种扫描策略（从简单到创新）

```text
┌───────────────────────────────────────────────────────────────┐
│         渠道扫描 · 三种策略                                       │
├──────────┬──────────────────┬─────────────────────────────────┤
│   策略    │      核心动作      │              一句话              │
├──────────┼──────────────────┼─────────────────────────────────┤
│  策略一   │    借鉴同行       │ 同行已经验证过的渠道经验——          │
│          │                  │ Copy然后测试                       │
├──────────┼──────────────────┼─────────────────────────────────┤
│  策略二   │    使用小抄       │ 用《超级武器库》扫盲——              │
│          │                  │ 95%的常见渠道都在里面               │
├──────────┼──────────────────┼─────────────────────────────────┤
│  策略三   │    大胆推演       │ 基于用户/场景理解——                │
│          │                  │ 主动提假设、设想新渠道              │
└──────────┴──────────────────┴─────────────────────────────────┘
```

### 5.3 策略一：借鉴同行

```text
核心动作：用调研能力搜集同行/竞对的获客方法。

方法：使用调研OSCAR模型或武器库小抄。
逻辑：如果同行ABCD都是这么获客的，你试试看概率也会大很多。

注意：任何一个行业都有常识性的获客手段——
      如果你连行业都在用的渠道都没试过，就别急着创新。
```

### 5.4 策略二：使用小抄 — 渠道超级武器库

> **「很多人最大的卡点就是没见过渠道，很多渠道不在过去的工作经验和见识里。」**

Truman和教研团队准备了一份《渠道超级武器库》，覆盖95%的常见获客渠道，按四个列表分类：

| 列表 | 内容方向 | 典型渠道示例 |
|------|----------|------------|
| **线上付费** | 投放、广告、平台 | 抖音信息流/百度竞价/小红书种草/公众号投放/淘宝直通车 |
| **线上免费** | 内容、社群、SEO | 公众号文章/短视频/知乎回答/B站视频/SEO/社群裂变 |
| **线下主动** | 地推、展会、BD | 地推发单/行业展会/异业合作/扫楼陌拜/商会协会 |
| **线下被动** | 门店、自然流、渠道 | 门店自然流/渠道代理/经销商/加盟商/合作伙伴推荐 |

**使用建议**：花30分钟认真看两遍这个清单，看看有没有盲区——有没有一些逻辑上可能很可行的渠道作为备选。

### 5.5 策略三：大胆推演 — 寻找鱼多的地方

> **「获客就像是捕鱼，你要去鱼多的地方捕鱼。」**

**核心认知：解放思想，找到底层规律。**

```text
案例：一堂同学做驾校培训（客群：大学生）

大胆推演的结果：
  当学员考完科目二（最爽的体验峰值），教练夸Ta，
  并奖励送6杯奶茶，让Ta带给宿舍同学一起喝。

  转化率最高接近100%——平均六杯奶茶带来一个新客户。

背后的底层规律：
  ① 体验峰值时刻是传播意愿最强的时刻
  ② 大学生群体社交密度高，奶茶是天然社交货币
  ③ "教练送的奶茶"比"自己买的奶茶"更有分享价值
```

**推演三问**：

| # | 问题 | 目的 |
|---|------|------|
| 1 | 我的目标用户，在什么场景下「最集中」「最有需求」「最容易接受信息」？ | 找到「鱼最多的水域」 |
| 2 | 在那个场景下，什么方式最容易自然地触达他们？ | 找到「最适配的网」 |
| 3 | 有没有可以用「社交货币」「体验峰值」「互惠心理」来放大的机会？ | 找到「杠杆点」 |

## 六、第二步：预判（Judge）— 做减法，排序优先级

### 6.1 核心任务

> **「在起盘阶段，生存难度大、资源少：选速度快、ROI高、确定性高的渠道。在快速增长期，有收入有容错成本：选天花板高、确定性没那么高的渠道。」**

### 6.2 六大评估维度

```text
┌───────────────────────────────────────────────────────────────┐
│         渠道预判 · 六大评估维度                                    │
├──────────┬──────────────────┬─────────────────────────────────┤
│   维度    │      问什么        │             一句话               │
├──────────┼──────────────────┼─────────────────────────────────┤
│  大小    │ 这个渠道的天花板    │ 能带来多少客户？上限是多少？         │
│          │ 有多高？          │ 大渠道 vs 小渠道                   │
├──────────┼──────────────────┼─────────────────────────────────┤
│  成本    │ 获客成本和ROI      │ 每拿一个客户要花多少钱？             │
│          │ 是否健康？        │ ROI能否覆盖？                     │
├──────────┼──────────────────┼─────────────────────────────────┤
│  快慢    │ 多久能见到效果？   │ 是"今天投今天见效"还是"三个月后才能判断"？│
├──────────┼──────────────────┼─────────────────────────────────┤
│ 确定性   │ 有多大概率能跑通？  │ 同行有成功案例吗？我有必备能力吗？      │
├──────────┼──────────────────┼─────────────────────────────────┤
│  难度    │ 执行难度有多大？   │ 需要什么资源/能力/资金？我能搞定吗？    │
├──────────┼──────────────────┼─────────────────────────────────┤
│  红利    │ 有没有流量红利？   │ 新平台/新媒介/新政策/竞争洼地？        │
└──────────┴──────────────────┴─────────────────────────────────┘
```

### 6.3 产品与渠道匹配度检查

> **「销售渠道/类型的选择，本质上是个ROI问题：产品或服务的毛利能不能覆盖可规模化的销售成本。」**

**客单价与转化手段的经验参考**：

| 客单价区间 | 适合的转化手段 |
|:----------:|---------------|
| 1-300元 | 短视频/文章/图文、客服、AI直播 |
| 30-1000元 | 产品驱动转化（PLG） |
| 100-3000元 | 直播 |
| 300-1万元 | 社群/私域、促销人员 |
| 1万-10万 | 会销、电销、面销 |
| 10万-1000万 | 展销、顾问式销售 |
| 100万以上 | 公司合伙人级别转化 |

> ⚠️ 以上数字仅供参考，必须带入你自己的单元模型一起思考。

### 6.4 优先级排序实战框架

```text
第一步：用六大维度给每个候选渠道打分或定性（高/中/低）
第二步：结合产品匹配度（标准化程度×客单价×毛利空间）
第三步：结合自身能力（有资源/能学会/需要外包/完全搞不定）
第四步：按阶段需求排序——
  起盘阶段：速度>天花板（先活下来）
  增长阶段：天花板>速度（找规模空间）

最终目标：把20-30个候选渠道，收敛到1-5个最高优先级渠道。
```

### 6.5 经典案例：固体红牛的渠道预判

```text
产品：固体红牛（提神类能量食品）
目标人群：需要快速提神但不想上厕所的人群

渠道扫描结果：用户×场景×销售方式 ≥ 100种渠道商

第一轮收敛：
  → 调研红牛起盘策略：66%用户是司机，起盘从加油站开始
  → 聚焦：司机人群

第二轮收敛：
  → 驾驶时长：长时驾驶 ≫ 短时驾驶
  → 聚焦：长时驾驶司机

第三轮收敛：
  → 卡车司机 vs 网约车司机
  → 卡车司机触达困难（电商无法收货、高速加油站覆盖成本高）
  → 聚焦：网约车司机

第四轮：围绕网约车司机场景，列出10+种具体渠道——
  个人司机做代理/司机聚集饭店/网约车平台合作/
  充电站地推/司机社群/车队队长分销……

最终：从100+ → 聚焦1个核心人群 + 3-5个核心渠道
```

## 七、第三步：测试（Test）— 低成本拿认知

### 7.1 核心任务

> **「渠道测试，最重要的是要找到一个渠道的Benchmark（基准值）。你得有一把稳定的、好用的尺子，来评估不同渠道的可行性和优先级。」**

### 7.2 渠道测试的评估维度

```text
┌───────────────────────────────────────────────────────────────┐
│         渠道测试 · 评估维度                                       │
├──────────┬──────────────────┬─────────────────────────────────┤
│   维度    │      含义          │             一堂的真实标准        │
├──────────┼──────────────────┼─────────────────────────────────┤
│ 基础维度  │ 获客规模          │ 这个渠道能带来多少客户？            │
│          │ 成本/ROI         │ 首单ROI是否达标？                 │
├──────────┼──────────────────┼─────────────────────────────────┤
│ 加分维度  │ 天花板           │ 渠道放量后空间有多大？              │
│          │ 增速             │ 放量速度如何？                    │
│          │ 持续性           │ 未来趋势是向好还是向差？            │
└──────────┴──────────────────┴─────────────────────────────────┘
```

**一堂的真实案例**：

```text
行业常识：获客成本200-300元健康，首单ROI 1.5-2健康
一堂的真实标准：首单ROI ≈ 0.8-1就算合格线

为什么？
  → 因为有复购，ROI可以做到1-1.5
  → 因为有KOL推荐，ROI可以做到0.8-1
  → 所以首单ROI不需要行业标准那么高

核心认知：不要盲信行业基准值——归根结底，尺度是你的单元模型。
```

### 7.3 三大常见测试难题与解法

| 难题 | 表现 | 解法 |
|------|------|------|
| **不会测试** | 丢失过程数据，事后靠猜 | 提前设计数据埋点，记录每个环节的转化率和成本 |
| **没有标准** | 不知道测到什么程度算"跑通" | 测试前先定义：首单ROI ≥ X，或获客成本 ≤ Y，才算合格 |
| **亏损不知** | 多个渠道揉在一起算大账，分不清哪个亏 | 每个渠道独立核算，不做交叉补贴的假账 |

### 7.4 渠道测试三步动作链

```text
① 设计MVP测试：用最小成本跑一轮，拿到第一批真实数据
② 数据埋点+分析：记录关键转化节点的数据，计算渠道ROI
③ 完成判断：三个选项——
   坚持优化（数据接近基准值，微调可能达标）
   10倍放大（数据远超基准值，果断放量）
   放弃（数据差距太大，或优化空间不足）
```

## 八、第四步：建模（Model）— 持续化与工业化

### 8.1 核心任务

> **「给渠道建模+工业化，提升获客的稳定性、持续性。让获客不再依赖某个人的灵感和手感。」**

### 8.2 渠道建模的核心要素

| 要素 | 含义 | 典型动作 |
|------|------|----------|
| **流程标准化** | 把获客流程拆成可复制的SOP | 拍摄脚本模板、投放操作手册、销售话术库 |
| **数据驱动** | 用数据而非直觉做决策 | 建立渠道数据看板，持续追踪关键指标 |
| **团队分工** | 把渠道能力从个人能力变成组织能力 | 专人专岗、定期培训、能力复制 |
| **持续迭代** | 用Y模型持续提假设、做实验、复盘 | 每周渠道复盘会，持续优化转化漏斗 |

### 9.3 案例三：驾考工具平台的渠道增长

```text
背景：驾考培训线上课，刚跑通单元模型

  → 互联网驾考工具平台（老东家愿意合作）

  第一优先：老东家合作（确定性高、速度快）

  暂不考虑：抖音/小红书（需要更长时间验证）

  老东家：月给5000用户（预期20000），ROI=1.06，不上不下
  → 双方都勉强盈亏平衡，合作暂停

  头部平台（Top2）：只给1000流量测试
  → 转化率比预期更高（头部品牌信任背书）
```

### 9.4 案例四：智能扫码枪 — 渠道错配的教训

```text
产品：智能扫码枪
原计划：采用渠道推广（找代理商）
结果：渠道拓展严重受挫

复盘原因：
  → 业务毛利较低
  → 给渠道的利润空间过小
  → 渠道商没有动力推广

教训：
  渠道选择不只看「能不能触达用户」，
  更要看「渠道商的利润空间是否足够」。
  毛利低的业务 → 不适合高分成要求的渠道模式。
```

## 十四、L6 级别进阶认知

### 认知一：渠道探索的底层逻辑——「捕鱼」而不是「找鱼」

> 「获客就像是捕鱼，你要去鱼多的地方捕鱼。」这句话的真正含义是：**不要在一个用户天然不聚集的地方硬钓。** 渠道探索的本质不是"发明一个新的获客方式"，而是"发现用户已经在哪里聚集，然后在那里的最佳触达位置撒网"。扫描的意义就在于此——大部分好渠道不是你凭空想出来的，是用户已经在那边等你。

### 认知二：四步法不是四个步骤，而是四道质量关卡

> 很多人听完课觉得"就是四步嘛，我走完了"。但真正的问题在于**每一步的执行深度**。扫描是随便列了5个渠道，还是系统性地列了30个？预判是按一个维度排的，还是六个维度综合排的？测试是认真记录了每个转化节点，还是"大概感觉ROI还行"？**每一步的深度决定了最终质量的上限。**

### 认知三：渠道评估的尺度永远是你的单元模型，不是行业基准

> 很多人问"首单ROI多少算健康"，然后去查行业报告。但Truman的核心洞见是：**行业基准值是别人单元模型下的数字。如果你的复购率高、转介绍率高，你的首单ROI容错率就大。** 不要把行业常识当成你的真理——把你的单元模型打开，自己算。

### 认知四：渠道探索的本质是「用实验替代赌注」

> 很多团队选择渠道的逻辑是"赌一个最大的"。但四步法的逻辑是：先全部列出来(扫描)，再理性排序(预判)，再低成本验证(测试)，最后才重仓投入(建模)。**整个过程是在把你"赌渠道"的风险，拆成了一轮轮低成本的实验。** 这和精益创业的底层逻辑完全一致——用无数小失败替代一次大失败。

### 认知五：渠道能力是「可以刻意练习」的操盘基本功

> 渠道探索有一个有趣的特点——获客以前觉得特别难、懵懵懂懂像个天大难题，但一旦摸出来认知，就会觉得很基础很简单，不过如此。**这不是因为渠道本身变简单了，而是因为你从"凭手感"变成了"有方法论"。** 这套四步法不是一次性学完就扔的框架，而是应该在每个新项目、新业务、新阶段时反复使用的操盘肌肉。

## 十五、行动建议

| 层级 | 行动 |
|------|------|
| **基础** | 用《渠道超级武器库》扫描你当前业务的所有可能渠道——列出20个以上候选渠道。然后问自己：有哪些渠道是我之前完全不知道或没考虑过的？这些"盲区渠道"中，有没有1-2个值得优先测试的？ |
| **进阶** | 用六大维度（大小/成本/快慢/确定性/难度/红利）对你列出的候选渠道逐项打分，结合产品匹配度和自身能力，排出优先级Top 5。然后选Top 1，设计一个最低成本的测试方案——本周内能跑的，不要拖到下个月 |
| **高阶** | 把你当前已经在跑的渠道逐个拆开独立核算ROI（不要揉在一起算大账）。看看有没有「一直在做但其实在亏损」的渠道。如果有——要么果断砍掉，要么重新设计优化方案。同时建立每周渠道复盘机制，让渠道建模从"偶尔看看"变成"持续迭代" |
