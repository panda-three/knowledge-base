# 课程：解放思想·全员必修

**一句话结论：** 找到底层规律，就能在上层突破规律完成创新；修炼方向是把思考从L0一路抬到L5。

---

## 一、核心交付

- 一个定义：解放思想＝打破习惯思维与主观偏见，研究新情况、解决新问题。
- 一句话策略：找到底层规律，就能在上层突破规律做创新。
- 一张地图：L0-L5 五层深度思考模型。
- 一组对照：与《实事求是》互为一体，是其更高要求。
- 一份Candy：《Truman的本质思考清单》。

## 二、关键框架

### 2.1 课程定位

- 与2019年《实事求是》互为姊妹篇，创业地图最底层逻辑之一。
- 若经验悟性够强，掌握这两节即可自行萃取市场商业规律。
- 三关结构：心态关 → 认知关 → 修炼关。
- 蔡治对照：

| 原则 | 对应痛点 | 对抗对象 |
|---|---|---|
| 实事求是 | 看不清形式 | 对抗主观 |
| 解放思想 | 放不开手脚 | 对抗惯性 |

- [配图：实事求是×解放思想 硬币两面图]

### 2.2 预热思考题（2个）

| 题目 | 内容 |
|---|---|
| 现象观察题 | 身边总有人源源不断提"靠谱新想法"且成功率高，他们什么思维习惯？ |
| 真实操盘题 | 穿越回2019做课程平台，面对同行"4-6周营/头部IP/20-30min/不给逐字稿"等常识，哪些遵守哪些无视？ |

### 2.3 第一关·心态关

**什么是解放思想：** 打破习惯势力和主观偏见束缚，研究新情况、解决新问题。

**创新无处不在——六个例子全是创新：**

| 领域 | 创新动作 |
|---|---|
| 配货 | IT系统＋飞书多维表格替代店长决策 |
| 周会 | 全员逐字稿，80%用文稿异步解决 |
| 渠道 | 抖音新渠道，50%折扣反获更高利润 |
| 课程 | 系统教科书+作业，替代碎片IP课 |
| 翻译 | AR眼镜实时画面翻译 |
| 检测 | 浙大教授研发肝硬化早期新型检测 |

**破除三种糟糕心态：**

| 心态 | 表现 | 一句话破除 |
|---|---|---|
| 创新迷信 | "创新太伟大，跟我无关"，太老实、本本主义 | 创新无处不在，别怂别比，琢磨新手段解决自己问题 |
| 盲目追求创新 | "不创新创什么业"，灵感大师天马行空 | 创新只是手段，战略/目标/卡点才是目的，甚至是迫不得已最后手段 |
| 创新歧视 | 看不起小创新、瞧不上身边新做法 | 小流程小工具提升目标，都是创新 |

- [配图：三种糟糕创新心态示意图]

### 2.4 第二关·认知关（创新核心策略）

**六个"过来人挑战"及一堂应对：**

| # | 过来人的经验 | 来源 |
|---|---|---|
| 1 | 线上严肃商业培训不靠谱 | 2018年某知名教培前辈 |
| 2 | 做教育不能给逐字稿，PPT给一半护版权 | 2019年Truman纠结两月 |
| 3 | 教育最重要是老师IP，要包装大背景 | 2019年资深做课专家 |
| 4 | 线上注意力只10-40分钟，2-3小时很扯 | 2020年直播课测试期 |
| 5 | 成人会员制很扯，6-8周就冷 | 2020年头部培训公司总监 |
| 6 | 只做立刻变现的商业课，ROI/知识管理不好卖 | 2022年头部在线教育负责人 |

**三个一堂实践案例：**

| 案例 | 表层规律 | 挖到的底层规律 | 决策 |
|---|---|---|---|
| 9点上课 | 同行7-8点开课 | 必修课要"对所有人可安排"而非"对部分人舒服"；3轮调研多数投9点；试8点请假率反升 | 固定9点+录播回放 |
| 给逐字稿 | 不给详细内容护版权 | 算ROI：真想抄不差2小时转稿；用ABCD防抄 | 果断给，好评如潮 |
| 不迷信讲师IP | 卖课=卖老师背景 | 问题驱动+科学体系下，讲师观点不重要；"客观事实和道理大于天" | 推荐课不提讲师名字 |

- 防抄袭ABCD策略：大体系 / 品牌化 / 规模化 / 共建化。

**一句话核心策略：**

> 「真正找到底层规律，就可以在上层突破规律，完成创新。」

- 规律越底层，越可以解放思想；不是投机碰运气，是基于更本质规律做事。
- 邓小平南方谈话：社会主义本质＝解放生产力、发展生产力……共同富裕。

### 2.5 第三关·修炼关（L0-L5五层模型）

**总览：**

| 层级 | 名称 | 典型认识 | 适用建议 |
|---|---|---|---|
| L0 | 凭空创新 | 才不管别人，自己从头来 | 不可靠，最差 |
| L1 | 事实和经验 | 找个赚钱业务直接照抄 | 开始显著提升成功率 |
| L2 | 尊重常识 | 学资深专家行业普遍规律 | 确定性强的小生意勉强够用 |
| L3 | 方法模型 | 掌握方法论/思维框架 | 建议努力做到 |
| L4 | 本质理解 | 一句话看透底层逻辑 | 优秀 |
| L5 | 经典理论 | 重点学科重点概念（芒格多元思维模型） | 做大/底层创新/投资建议到此层 |

**课程时长设计的层级示范：**

| 层级 | 认识 | 工作方式 |
|---|---|---|
| L0 | 不管别人 | 30min、5h都行 |
| L1 | 调研同行2个最佳实践 | 10-30min |
| L2 | 问知识付费专家常识 | 20-40min |
| L3 | 看培训/知识/线下不同设计（地图+钩子） | 唤醒+预热+地图+钩子，30min-2h |
| L4 | 用户听课留存动力+阻力各5-10项 | 重构要素、创新动力阻力，随时长拉长 |

- 做到L3能设计各种知识付费；做到L4能设计各种线上线下培训产品。

**两个关键理解：**

1. 抽象程度越高、迁移性越强：事实无穷、常识几百、方法论几十上百、本质模型小几十个，解决95%问题。
2. 从类比，到底层原理。

**观察者偏差：**

| 视角 | 感受 |
|---|---|
| 外部观察者 | "他怎么这么会创新，好新颖" |
| 做事的人 | "我没创新啊，就是遵循了更底层逻辑" |

- 磨课时同学问"一堂好多创新怎么想到的"，Truman内心：这也算创新？

## 四、案例拆解（按层级）

### 4.1 L2案例：汉堡生熟夹子SOP（先敏同学）

| 层级 | 分析 |
|---|---|
| L1事实 | 大公司SOP：生菜用蓝色生夹、鸡腿肉用红色熟夹，弄混挨训 |
| L2常识 | 生熟分开是为防交叉污染；但生菜直接入口不再加热，为何夹子要分？ |
| 突破 | 判定SOP是对常识的生硬应用，找高层沟通后公司改流程、提效率 |

- 结果：先敏一路升到片区经理；当年只执行不思考的训练员只做到训练组长。

### 4.2 L3案例：泼翻可乐赔偿（先敏同学）

| 方向 | 账 |
|---|---|
| 负收益 | 丢顾客（拉新20+元，可乐成本不到1元）；调查工资十几二十块；口碑损失 |
| 正收益 | 良好体验带来复购与口碑 |

- 决策：一线员工直接操作，无论谁的原因，一律无条件主动赔偿。

**L3延伸：数字人外呼（徐剑）**

| 指标 | 数据 |
|---|---|
| 老用户完听率 | 超70%，增加20% |
| 新用户完听率 | 翻倍，超50% |
| 车险续保 | 一次AI电话转化率80%＝人工外呼两次 |
| 游戏沉默用户唤醒 | 超70% |
| 电商优惠券领用 | 30% → 80% |

- 思路：正收益（转化率，真人感互动）cover 微增成本，果断投入研发。

### 4.3 L4案例：奶茶店店员奖金设计（古董同学）

| 层级 | 分析 |
|---|---|
| L1事实 | 抄隔壁奶茶店奖金结构 |
| L2常识 | 行业惯例：店员奖金跟门店业绩挂钩 |
| L4本质 | 发奖金不是为奖励销售，本质是激励与业绩高度相关的特定行为 |

- 业绩四归因拆解：选址（老板主责）/品牌（店员作用小）/QSC（店员100%）/高峰产能（店员大部）。
- 最终挂钩：**业绩增量(YOY/MOM) + QSC + 生产效率 + 带教成果**；总业绩仅作"成果分享"小关联。
- 结果：员工满意度高，认可规则公平，不抵触业绩目标。

**L4延伸：教育产品本质**

- 本质三要素：问题（目标用户+真实难题）／解法（最佳实践+方法论+工具箱）／教学（循序渐进讲明白）。
- 由此推导出：线上可做严肃培训、工作坊可无教练、可连讲10小时、案例大爆炸互评。
- 落地模型：段位打分 / 平行时空 / 停车场——"看似创新，只是遵循循序渐进讲明白"。

### 4.4 L5案例：马斯克第一性原理造火箭

- 拆解：火箭＝航空铝合金+钛+铜+碳纤维；材料成本仅通行价**2%**，燃料仅**0.3%**。
- 贵的根源：层层外包组装层层加价。
- 创新动作：80%零部件自产／回收火箭重复使用／采购二手零件／统一发动机量产。
- 方法：一层层剥开表象到本质，再从本质往上推。

### 4.5 L5案例：林标扬肝硬化早期检测

- 背景：浙大教授、Y30学员；《Science》《Nature》论文90+篇；提出3P/4P医学。
- 中国每年38万人死于肝硬化肝癌，占全球肝癌死亡51%。
- 现有方法（沿用二三十年）：血液看转氨酶（只反映肝细胞）＋B超（见纤维化已晚期）。
- 突破：从系统生物学入手，肝脏三种细胞（肝细胞/巨噬细胞/星状细胞），传统指标只测其一。
- 3年研究几百例样本，发现**壳酶蛋白**——肝病极早期即可检出。
- 成果：80+三甲医院临床，3年检测破100万人次；"诊断领域第一个中国贡献给世界的指标"；美国Lab Corp引入。

## 五、速查卡

```
┌ 一句话记住本课 ┐
└ 越往底层挖规律，越敢在上层做创新 ┘
```

- 层级自检口诀：L0瞎想 → L1抄经验 → L2守常识 → L3用模型 → L4抓本质 → L5用经典学科。
- 总结本质三方法：辩证讨论 / 爆炸性研究 / 要素拆解。
- 解放思想＋实事求是同时修炼，互为一体。

## 六、行动建议

| 层级 | 行动 |
|---|---|
| 基础 | 挑一个天天在用的"行业常识"，追问它背后的Why |
| 进阶 | 把正在做的事按L0-L5自评层级，问自己停在哪一层 |
| 高阶 | 选一个业务难题，从L4本质/L5学科理论重推一遍方案 |

**三个作业（3选1）：**

1. 心得总结题：百分制自评你在L0-L5哪一层，擅长与盲区各是什么。
2. 深度案例题：讲你"基于底层规律、在上层打破规律"的一个实战。
3. 底层规律题：列出你用过的有效底层规律（一堂模型/经典理论均可），越多越好。
