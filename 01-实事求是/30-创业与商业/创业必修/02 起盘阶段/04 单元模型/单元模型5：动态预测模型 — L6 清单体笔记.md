# 单元模型5：动态预测模型 — L6 清单体笔记

---

## 一、课程定位与核心金句

> **「规模经济的实质，就是大规模复制以后，你的单元模型变好还是变差。」**
>
> — Truman，一堂CEO

> **「如果想做大，业务都是对抗出来的。」**

> **「我们得不停地在高速上换轮胎，不断升级模型，才能对抗掉模式的下滑。」**

> **「行业集中度的实现，一定是通过『对抗』来实现的。集中的逻辑就是对抗的逻辑。」**

> **「管理往往都是反规模效应的，而且随着发展，大概率是朝着规模不经济发展的。」**

**课程在一堂五步法中的位置**：

```text
一堂五步法 = 需求 → 解决方案 → 商业模式 → 增长 → 壁垒
                      ↑              ↑
                 单元模型在这里   动态预测连接增长与壁垒

单元模型五课：
  单元模型1（重新理解"商业模式"·L1-L3）
    → 单元模型2（选择核心模型·L3-L4）
      → 单元模型3（构建完整模型·L3→L4）
        → 单元模型4（找准基准值·L4→L5）
          → 单元模型5（动态预测模型·L5→L6）← 本节课（终章）
```

**本节段位目标**：帮你从 **L5（完整账+基准值）** 提升到 **L6（动态预测）**——能以年为尺度，预判业务的规模变化、外部变化和业务变化，持续对抗规模不经济，让生意越大越好做。

| 对比 | L5（上节课） | L6（本节目标） |
|------|-------------|---------------|
| 能力 | 有完整账+基准值，能定量判断 | 动态预测：能以终为始预判变化，提前对抗 |
| 典型动作 | 三点预测、乐观证伪、两口径验证 | 预测三部曲（加法→减法→对抗）、升级三大策略 |
| 时间尺度 | 单次判断 | 以年为单位，持续预判和对抗 |
| 核心问题 | 「现在通不通？」 | 「规模变大后，变好还是变差？怎么提前布局？」 |

**Truman对这节课的评价**：

> 「这节课是单元模型系列课的最后一节，也是当年我反复打磨了小一年才敢交付的课程。可以说，这是目前一堂五步法商业分析皇冠上最亮的那颗明珠，也深刻影响了这两年我做一堂的关键策略。」

**交付模型**：**规模经济分析武器库 + 预测三部曲（加法→减法→对抗）+ 3类对抗规模不经济策略清单。**

**推荐谁学**：已经在跑业务、正在考虑规模化复制、或已经感受到「越大越难受」的创业者。如果你只想做一家小而美的店，这门课对你的意义有限；但如果你想做大、想持续扩张——这门课就是你的必修课。

## 二、预热思考 · 三连问

| # | 问题 | 用意 |
|---|------|------|
| 1 | 如果你的业务规模翻10倍，你的单元模型会变好还是变差？哪些成本会上升？哪些会下降？ | 直接进入这节课的核心问题——规模经济的实质 |
| 2 | 管理100个人和管理10个人，是完全不同的能力。你的业务里，有没有一些今天靠「某个人」撑着、规模化后必然出问题的环节？ | 暴露「人」是规模不经济的最大来源 |
| 3 | 如果平行世界有两个你——一个从第一天就在为规模化做布局，另一个等到规模大了再打补丁。三年后，两个业务的差距会有多大？ | 建立「预判得越早，越早可以布局」的终局思维 |

## 三、课前三大案例 · 带着问题学习

### 案例一：医院设备租赁的「规模诅咒」

```text
业务：医院设备租赁
早期：依赖创始人关系，生意一直很好
扩张：拿融资 → 搭建BD团队 → 跨城市管理
结果：
  - 30%违约率（医院不续费，但搬走设备不划算 → 免费用）
  - 利润被吃光，业务举步维艰

根因：
  从CEO关系 → BD团队 → 跨级跨城市管理
  每一步扩张都在产生新的规模不经济
  但没有主动调整业务模型来对抗
```

### 案例二：扭蛋机柜子的动态预判

```text
做了大量调研，完成未来2年规模化会带来的变化：

规模经济（变好的部分）：
  ✅ 单柜成本由8000降到4000元（采购规模效应）
  ✅ 增加品类，收入提升20%（精细化运营）

规模不经济（变差的部分）：
  ❌ 城市BD团队和人员管理成本大幅上升
  ❌ 尝鲜人数降低，第二年收入至少下降30%

第三步，解决增长受限的点：
  → 主动做IP：打造原创IP，提升收入和复购
  → 城市代理：找当地合伙人选址、谈判点位
  → IT系统：AI分析补货和换SKU，降低运营成本
```

### 案例三：秋月梨的动态多模型

```text
业务变化（不同渠道）：
  批发市场 vs 生鲜连锁 vs 精品商超
  → 三种渠道，消费者不同 → 三个单客户模型

时间变化（季节性）：
  9月上市 → 波峰 → 回落 → 3月收尾
  → 四个阶段，不同周期的单元模型

规模变化（城市扩张）：
  一个城市做到多大规模 → 才能投放一个销售员？
  → 单城市单元模型

结论：只有多维度精细分析，才能清晰了解成本结构。
      经验主义 → 科学操盘，差距是指数级的。
```

## 五、规模经济的本质定义

### 5.1 狭义 vs 广义

| 定义 | 含义 | 一堂的用法 |
|------|------|-----------|
| **狭义** | 经济学上，特指分摊固定成本 | 生产成本随规模下降 |
| **广义** | 规模带来的各种效应：网络效应、迁移成本、品牌、连带效应等 | ✅ **一堂使用广义定义** |

### 5.2 三个核心维度

| 维度 | 问什么 | 示例 |
|------|--------|------|
| **空间有大小** | 全球→全国→省市→商圈，全人群→特定人群 | 不同规模的网络效应完全不同 |
| **时间有长短** | 管理劣势暴露快，迁移成本塑造较快，品牌需要2-5年 | 不同要素的时间节奏差异巨大 |
| **强度有强弱** | 全局网络效应 > 双边网络效应 > 局部规模效应 | 越强的规模效应，壁垒越深 |

### 5.3 规模经济的核心判断句

```text
「规模经济的实质，就是大规模复制以后，你的单元模型变好还是变差。」

变好了 = 规模经济（Economies of Scale）
变差了 = 规模不经济（Diseconomies of Scale）

你要做的，就是：
  ① 识别出哪些要素是规模经济的（放大它）
  ② 识别出哪些要素是规模不经济的（对抗它）
```

## 六、预测三部曲：加法 → 减法 → 对抗

```text
                加法                      减法                      对抗
           ┌──────────────┐      ┌──────────────┐      ┌──────────────────┐
           │  拆解规模经济  │  →  │  找到核心矛盾  │  →  │  调整策略，        │
           │  全部要素      │      │  分析优先级    │      │  不断优化，        │
           │              │      │  找到主要矛盾  │      │  对抗规模不经济    │
           └──────────────┘      └──────────────┘      └──────────────────┘
           
           60分：会拆              80分：会选              85分：会对抗
```

---

### 6.1 第一步：加法 — 拆解规模经济要素

**核心原则：先把规模变大后所有变化都列出来——哪些会变好，哪些会变差。**

| 类别 | 典型规模经济要素（变好） | 典型规模不经济要素（变差） |
|------|------------------------|--------------------------|
| **成本侧** | 采购议价能力增强、固定成本摊薄 | 管理成本上升、培训成本增加 |
| **收入侧** | 品牌溢价、网络效应增强 | 用户下沉导致客单价降低 |
| **运营侧** | 数据积累、算法优化 | 品控变难、客诉变多、腐败风险 |
| **组织侧** | 专业化分工、人才吸引 | 跨城市管理成本、沟通成本指数增长 |
| **竞争侧** | 规模壁垒加深 | 创新路径依赖、大公司病 |

**60分标准**：能拆出至少 10 个规模经济/不经济要素。

---

### 6.2 第二步：减法 — 找到核心矛盾

**核心原则：不是所有要素都同等重要。分析优先级，找到当前阶段的主要矛盾。**

```text
问自己三个问题：
  ① 哪个规模不经济要素，如果不解决，会直接杀死你的业务？
  ② 哪个规模经济要素，如果能放大，会带来最大的杠杆效应？
  ③ 当前阶段，你最应该集中精力对抗的是哪一个？
```

**经典减法案例：一堂的规模不经济核心矛盾**

```text
一堂的规模不经济最大来源：
  服务依赖人 → 专家依赖Truman → 非标沟通依赖班班

减法后核心矛盾：
  → 降低专家服务、降低高手依赖、降低人工服务、降低非标管理、降低临时工作
```

---

### 6.3 第三步：对抗 — 三类策略持续升级

> **「如果你想复制和获得更高规模，中心思想就是不断降低非标服务，不断降低专业的、人工的成分，来对抗规模不经济。」**

---

| # | 策略 | 一句话 | 典型案例 |

## 八、动态预测：三重视角

### 8.1 三种不可忽略的变化

```text
┌──────────────────────────────────────────────────────┐
│           动态预测 · 三重视角                           │
├──────────────┬────────────────┬──────────────────────┤
│  规模变化     │   外部变化      │     业务变化          │
├──────────────┼────────────────┼──────────────────────┤
│ 规模扩大后，  │ 行业/政策/竞争  │ 业务模式/渠道/团队   │
│ 单元模型怎么变│ 环境变化的影响   │ 演进带来的变化        │
├──────────────┼────────────────┼──────────────────────┤
│ 典型L5→L6    │ 典型L5→L6      │ 典型L5→L6            │
│ 常见错误：    │ 常见错误：      │ 常见错误：            │
│ 忽略规模变化  │ 忽略外部变化    │ 忽略业务变化          │
└──────────────┴────────────────┴──────────────────────┘
```

### 8.2 视角一：规模变化

```text
核心问题：从10 → 100 → 1000 → 10000，单元模型会发生什么？

规模经济的典型变化：
  ✅ 采购成本下降（量大议价）
  ✅ 固定成本摊薄
  ✅ 品牌效应增强
  ✅ 数据积累产生复利

规模不经济的典型变化：
  ❌ 管理成本指数增长
  ❌ 跨城市/跨区域管理难度加大
  ❌ 用户下沉 → 客单价下降
  ❌ 品控变难、客诉增加
  ❌ 腐败风险上升
  ❌ 创新路径依赖
```

**经典踩坑案例**：

```text
❌ 医院设备租赁：从创始人关系 → BD团队 → 跨城市管理，违约率30%
❌ 校园O2O：没搞清为什么有些学校赚钱有些亏钱，就以城市为单位铺全国
❌ 淘宝电商：10倍增长计划招5-10倍客服，却忽略了AI客服可以替代大部分人工
```

**正确姿势**：

```text
✅ 扭蛋机：提前预判2年后的规模变化，主动布局城市代理+IT系统
✅ 一堂：从1w会员到1.6w会员，服务成本只上涨20-30%（显著规模经济）
✅ 秋月梨：多维度分析——不同渠道、不同季节、不同城市的独立单元模型
```

---

### 8.3 视角二：外部变化

```text
核心问题：行业变了、政策变了、竞争格局变了，你的单元模型还能成立吗？

外部变化的类型：
  - 政策变化（如国税总局升级"数电票" → 税控盘硬件加速退出）
  - 技术变化（如AI能力突然跃升 → 某些人工环节可以被替代）
  - 竞争变化（如巨头入场 → 获客成本暴增）
  - 市场变化（如融资环境遇冷 → 必须更早实现盈利）
```

**徐剑案例：政策变化的冲击与应对**

```text
事件：国税总局全面升级"数电票"体系
  → 税控盘硬件加速退出历史舞台
  → 硬件采购成本这一项消失了
  → 但收入项不受直接影响
  → 对业务是巨大利好

关键认知：单元模型理解得越透，越能快速判断外部变化的影响。
```

### 8.4 视角三：业务变化

```text
核心问题：当你的业务模式、渠道、团队结构发生质变，单元模型还适用吗？

业务变化的典型场景：
  - 从直销 → 渠道（模型完全不同）
  - 从单城市 → 多城市（新增单城市模型）
  - 从服务头部 → 服务腰部（用户画像变了）
  - 从CEO亲力亲为 → 团队分工（人的成本变了）
```

**秋月梨案例的三维动态预测**：

```text
业务变化（不同渠道）：
  批发市场/生鲜连锁/精品商超 → 三个独立的单客户模型

时间变化（季节性）：
  起势→波峰→回落→收尾 → 四个阶段的单元模型

规模变化（城市扩张）：
  一个城市做到多大规模 → 才能撑一个销售员 → 单城市模型

结果：从「只知道不赚钱但不知道为什么」→「每一个维度的盈亏都清清楚楚」
```

## 十五、L6 级别进阶认知

### 认知一：L6 的本质不是「算得更准」，而是「看得更远」

> 从L1到L5，每一级都在解决「算账」的问题。但L6解决的是「预判」的问题——在变化发生之前，你就已经知道会发生什么，并提前布局。**L5的人等变化发生了再反应，L6的人在变化发生之前就已经在对抗了。** 预判得越早，越早可以布局，越早可以笃定。

### 认知二：「对抗」是L6最核心的关键词

> 行业集中度的实现，一定是通过「对抗」来实现的。集中的逻辑就是对抗的逻辑。管理天然是反规模效应的——你每增加一层管理、每进入一个新城市、每服务一类新用户，都会产生新的规模不经济。**不想对抗的人，就不该追求规模。**

### 认知三：规模不经济的最大来源，永远是人

> 人的招聘、培训、管理、沟通、激励、离职——每一个环节都在随着规模变差。所以对抗规模不经济的中心思想，就是**不断降低非标服务，不断降低专业的、人工的成分**。用系统替代人，用SOP替代判断，用算法替代经验，用品牌替代个人IP。

### 认知四：三个周期的跨越，是创业者最难的蜕变

> 获客驱动 → 系统驱动 → 对抗驱动，每一个周期的跨越都要求完全不同的核心能力。很多创业者卡在获客驱动——找不到可持续渠道；更多人卡在系统驱动——有了流量但没有稳定的增长模型；而真正能走到对抗驱动的，少之又少。**不是因为他们不努力，而是因为对抗需要的不是执行力，而是「在高速上换轮胎」的战略勇气。**

### 认知五：预判能力，本身就是一种壁垒

> 如果你从第一天就在为规模化做布局——选择教科书级选题、构建标准化SOP、用系统替代人工——三年后，你和那些规模大了才开始打补丁的同行之间，差距不是一点半点。**预判能力就是「把未来的钱省在今天」的能力。** 这也是为什么这节课被 Truman 称为「一堂五步法商业分析皇冠上最亮的那颗明珠」。
