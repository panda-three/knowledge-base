# 全员必修：一堂五步法落地篇 · 清单体笔记

---

## 一、课程定位与价值

**课程定位**：一堂五步法系列的「总纲落地课」，是连接认知篇与全套实操课的枢纽——讲解五步法如何从第1版粗糙画布一步步进化到第100版作战地图。

**课程身份卡**：

| 维度 | 信息 |
|---|---|
| **讲师** | Truman，一堂 CEO |
| **定位** | 五步法进阶收官课，难度极高 |
| **依赖前置** | 15节+核心课，五步法全系列认知课+实操课 |
| **选课口令** | 我选五步法落地 |
| **系列位置** | 重新理解五步法（认知）→ 五步法落地篇（落地）→ 五步法各模块实操课 |

**一句话内核**：
- **五步法最大的价值，不是填一张画布，而是帮你剥离出大量决定创业成败的「关键假设」**——然后用极低成本去验证那个最关键的环节

**课程金句开场**：
- 「拿走吧，没有五步法我不看，我要的不是一个项目经理的执行方案，而是一个业务负责人的商业分析方案，下次带着五步法画布过来找我」
- 老兵高段位的同学觉得五步法极其值钱、反复应用；第一次做事的新人常常觉得形式而已、没什么价值——**这个差距，就是这节课要解决的**

## 二、为什么必须学：五大常见模糊

**一堂发现**：大量同学对五步法的理解存在各种模糊和片面。

| 误区 | 表现 | 真相 |
|---|---|---|
| **以为静态** | 认为画布填完就不改了 | 画布是**迭代的**——从第1版到第100版持续进化 |
| **心态太傲** | 觉得自己牛逼，不知道自己菜 | 老兵画过200+版才真正入门，先承认「我不会」 |
| **见识太少** | 分析不够本质，没见过好的 | 没见过高段位画布，不知道好在哪里、为什么好 |
| **不够显性** | 需求写「爱美」「虚荣心强」 | 无法评判、无法指导业务——必须可观测、可衡量 |
| **不够定量** | 太虚，喜欢定性和大词 | 不会用数字分析——定性＜定量＜定钱 |

**核心病因**：不是五步法没用，而是多数人**只把它当填表工具**，没有理解它的真正内核——**关键假设的剥离与证伪**。

## 四、第一阶段 · 讲故事：可解释（第 1-3 版）

### 4.1 定位与价值

**核心任务**：能够用五步法把业务**讲清楚**——面向投资人、面向团队、写BP、竞争调研。

**适用场景**：
- 介绍业务 / 讲香故事 / 写计划书 / 竞争调研

**一句话判断**：故事版主要对外或早期使用——这个阶段**还没真正开始用五步法指导业务**。

### 4.2 五列核心内容

| 五步 | 核心填写内容 |
|---|---|
| **需求** | 人群和需求：具体的用户/客户是谁？解决什么问题？ |
| **解决方案** | 产品价值：提供什么产品？产品的主要特点？ |
| **商业模式** | 收入模式：商业模式类型？商业转化链路？靠什么赚钱？转化方式？ |
| **增长** | 获客方式：怎么获客？ |
| **壁垒** | 竞争壁垒：领先同行的优势？ |

**典型版本数**：1-3 版——第一版是粗框架，边讲边改，边听反馈边迭代表述。

## 五、第二阶段 · 做选择：可决策（第 3-10 版）

### 5.1 定位与价值

**核心任务**：五步法真正发挥价值的起点——**关键假设的证伪**。Truman 原话：「如果前面五步法值几百块，这个环节对你就是几千几万了。」

**适用场景**：
- 机会预判 / 路径选择 / 咨询诊断 / 开战略会

**一句话判断**：**这个段位才是合格线**——你能够勉强使用五步法指导业务、提升成功率的分界线。

### 5.2 取舍版各列核心动作

| 五步 | 核心取舍动作 | 关键工具 |
|---|---|---|
| **需求** | 选核心用户：最核心的用户是谁？未来扩展的用户？不服务的用户？选场景和痛点：推演关键使用场景、评估普遍性/刚性/频次 | 用户分层小抄、场景推演造句、需求评估三角 |
| **解决方案** | 拆内核要素：产品内核要素有哪些？哪些优化非内核要素？用**加法方法**列全→用**减法方法**砍到最少 | 产品内核画布、加法方法（按经验列/完美列/调研列/结构列）、减法方法 |
| **商业模式** | 选单元模型：按销售分（单订单/单SKU）、按人头分（单用户/单客户/单销售/单履约）、按空间分（单柜子/单门店/单商圈/单城市） | 十大单元模型清单 |
| **增长** | 选第一指标：单一增长指标是什么？组合增长指标？警惕虚荣指标。选渠道：获客渠道/非渠道，预判天花板和速度 | 8个常见虚荣指标、第一指标6大参考维度、渠道探索小抄 |
| **壁垒** | 壁垒的取舍：第一壁垒是什么？重要壁垒？非壁垒？六大壁垒类型中选主攻方向 | 持续打造壁垒完整小抄（无形资产/转化成本/技术壁垒/网络效应/规模效应/成本优势） |

### 5.3 取舍版核心心法

- **加法→减法**：先列全所有可能性，再砍到要害——「分做加法，专业做减法」
- **持续复制**：找到有风险易赔钱的关键点，优先验证
- **关键假设评估区间**：聊-问-查-测-盘-赌，按成本从低到高逐级验证

## 六、第三阶段 · 做迭代：可测量（第 10-30 版）

### 6.1 定位与价值

**核心任务**：不能满足于排序和选择，要**努力定量**，用关键数据完成商业评估。尤其是在决定下场、决定扩张、决定投资、决定转型的时候，定量评估往往是**最关键**的。

**适用场景**：
- 扩张判断 / 转型判断 / 投资判断 / 退出判断

### 6.2 定量版各列升级

| 五步 | 定量升级 | 核心工具 |
|---|---|---|
| **需求** | 评估需求：用户规模定量、赛道规模（细分赛道规模）、公司最大规模 | TAM/SAM/SOM、多砍几刀切分法 |
| **解决方案** | 产品内核定量：转化率定量（定性→拥有指标→数字定量）。内核要素定量：获客环节（销转率/动销率/捕获率）、服务环节（留存率/完课率/退款率/满意率）、复购环节（复购率/续费率/推荐率） | 列·冷静清单法、推·故事推演法、建·建立体系法、查·用专业检查 |
| **商业模式** | 找全关键项：经营成本/财务成本/管理成本不丢。基准值三点预测：悲观版/合理版/乐观版。找准方法：第三方数据/自顶向下/自底向上/寻找对标 | 三大易丢成本小抄、单元模型画布（三点版）、10大业务拆解范式 |
| **增长** | 增长目标定量：业务公式ABC模型、渠道ROI、渠道增速。不同维度细拆：用户分层SABC、不同品类/价格带/SKU细拆五步法 | 业务公式、增长/销售展开、交叉测算 |
| **壁垒** | N倍单元模型变化：规模经济要素（优秀/良好/一般三级）、规模不经济要素（很难/较难/尚可三级） | 规模变化影响因素清单、规模经济对抗策略 |

### 6.3 三大类型假设

| 假设类型 | 含义 | 处理方式 |
|---|---|---|
| **决定性假设** | 对转化率/成功率有显著影响 | 优先级最高，必须精准验证 |
| **优化性假设** | 对转化率影响不大 | 可延后，不阻塞主线 |
| **完备性假设** | N条都达到才能拿到好结果 | 拆开逐条验证，不混在一起 |

## 七、第四阶段 · 做对齐：可分工（第 30-100 版）

### 7.1 定位与价值

**核心任务**：如何把公司的全局商业战略，和**各个团队、各个业务环节**结合在一起？

**核心转变**：
- 从「一个人画布」→「团队共同语言」
- 从「分析工具」→「组织操作系统」

### 7.2 分工版四大支柱

**① 话语体系**
- 团队共用五步法语言讨论业务——不再出现「你说的需求和我想的不是一回事」
- 统一五步定义、统一画布格式、统一评估标准

**② 团队分工**
- **拆**：拆解核心动作——谁负责需求端调研、谁负责产品内核迭代、谁负责增长渠道
- **建**：建立固定套路——每个模块沉淀团队SOP
- **推**：形成共识落地——关键决策会基于五步法讨论
- **练**：大量刻意练习——团队级别的假设能力训练

**③ BCD讨论**
- B（Baseline）：当前版本画布
- C（Challenge）：挑战现有假设——「这个假设如果错了，整个逻辑还成立吗？」
- D（Decision）：基于讨论做决策和更新

**④ 动态迭代**
- 随着**规模变化**更新画布（小规模→大规模，模型是否还成立？）
- 随着**外部变化**更新画布（竞争、政策、技术变化）
- 随着**业务变化**更新画布（新品类、新渠道、新用户群）

### 7.3 组织升级配套工具箱

| 升级方向 | 具体策略 | 对应小抄 |
|---|---|---|
| **升级人工策略** | 拆解1号位/替代顶级IP/替代专家/自动化/AI化 | 升级人工策略Top10 |
| **升级管理策略** | 文化建设/苦练基本功/培训体系/目标管理/薪酬绩效 | 升级管理策略Top10 |
| **升级业务策略** | 需求端换用户画像、解决方案简化SKU、商业模式调成本结构、增长端自营改加盟 | 升级业务策略Top10、阻力对抗小抄 |
| **升级工具系统** | IT系统/数据库/知识库/工业化流程/SOP | 苦练基本功武器库 |

### 7.4 一堂自身案例

**一堂当前状态**：五步法在第四阶段，7-10个商业单元（MBA/训战营/私董会/咨询/AI/内训等）分别在2-3个阶段进化中。

**Truman带团队的五个阶段**：
1. 从不算账到算账——有账的意识
2. 形成工具——开始用五步法+ROI
3. 推给团队——从一个人用到团队用
4. 用进日常——评估业务都用画布
5. 带团队训练——培养团队级别的假设能力

**团队训练四步**：必须学课（统一方法论）→ 开放透明（平等对话）→ 给工具箱（A3超级小抄）→ 练基本功（复盘会/灵感闪现/攻坚会）

**成果数据**：团队独立提出大量假设——线下练习20+玩法、新人复盘50+假设、获客渠道200+假设。结果：推荐率K>50%（行业平均5-10倍）、每年30-50%综合增长、作业率/续费率/留存率行业头部。

## 八、五步法的四次认知升级

| 层级 | 理解深度 | 一句话 |
|---|---|---|
| **第一层** | 五步法是个填表工具 | 「我把项目填进去了，是不是就完事了？」 |
| **第二层** | 五步法是全局分析框架 | 「用五步拆清楚业务的每个环节」 |
| **第三层** | 五步法是关键假设剥离器 | 「每一层都可能藏着导致项目失败的假设」 |
| **第四层** | 五步法是团队操作系统 | 「全公司统一话语体系，持续迭代作战地图」 |

**Truman核心判断**：「没有关键假设的五步法，就是个空壳。」

## 九、两大核心假设（始终贯穿）

### 9.1 价值假设 + 增长假设

| 假设 | 核心问题 | 判断逻辑 |
|---|---|---|
| **价值假设** | 你的产品有没有真正的价值？用户真的需要吗？ | 没验证价值假设就谈增长 → 扩张越多亏损越多 |
| **增长假设** | 如果有价值，能不能快速复制、扩张、传播？ | 价值假设验证后，才轮到增长假设 |

**铁律**：**不要过早复制未经验证的商业模式。**

### 9.2 关键假设的四个关键词

| 关键词 | 含义 |
|---|---|
| **业务问题** | 极度务实，针对非常具体的目标 |
| **高难度** | 足够大的任务才值得用假设分析 |
| **前提假设** | 关注因而不是果——把结果转化成一组前提条件去验证 |
| **确定性** | 追求稳定的、可迭代的、可对话的模型 |

```

    ↓

```
