# 调研专项：高质量的专家访谈 · L6 萃取笔记

> **课程定位**：调研模块实操课 | 讲师 Truman | 评分 9.2 | 11510 位创业者上过 | 180.2 万字笔记
> **核心交付**：专家访谈黄金 10 步法 + 早期项目常见专家清单 + ABC 小抄

---

## 一、这门课解决什么问题

**核心场景**：刚创业 / 刚转型，对新模式新赛道认知明显不够 → 最高效的提升业务认知方法 = **专家访谈**。

**五类常见错误（90% 的访谈不合格）**：
- 错把专家访谈当社交 → 变普通聊天，没拿回认知
- 只看专家"名头大" → 不判断对方是否有你要的答案
- 访谈前零准备 → 没带关键问题，纯靠运气碰撞
- 只"访"不"谈" → 像记者收集信息，无互动、无深挖、无交叉验证
- 一小时只想"交个朋友随便聊聊" → 浪费彼此时间

---

## 二、五大认知纠偏（核心心法）

| 不是 | 而是 | 关键含义 |
|---|---|---|
| 交个朋友 | **价值交换** | 不为社交，为拿认知 |
| 收集观点 | **收集事实** | 观点易得，事实稀缺 |
| 调研问题 | **验证假设** | 带着关键假设去确认 |
| 辩论比赛 | **深入探讨** | 追问逻辑，不争输赢 |
| 单向采访 | **双向互动** | 平等碰撞，不是记者提问 |

> **12 字核心原则**：**带问题，有体系，拿答案，不盲信。**

## 三、方法全景：专家访谈黄金 10 步法

```
阶段          步骤                    核心能力要求
─────────────────────────────────────────────
A. 挖问题  →  ① 梳理大盲区           常识识别力＋判断力
              ② 理解真价值
─────────────────────────────────────────────
B. 找专家  →  ③ 理解好专家           专家判断力＋连接力
              ④ 建连接渠道
              ⑤ 说服做沟通
─────────────────────────────────────────────
C. 做访谈  →  ⑥ 认真做功课           访谈准备力＋提问力
              ⑦ 选合适场景
              ⑧ 破冰建信任
              ⑨ 做专业探讨
              ⑩ 交叉拿结果
```

## 四、阶段 A：挖问题

### 步骤① · 梳理大盲区

**核心动作**：用「信息冰山图」定位你的认知层次—

| 冰山层次 | 信息类型 | 获取难度 | 价值 |
|---|---|---|---|
| 冰山上部 | 公开信息（搜索引擎/行业报告/财报） | 低 | 低 |
| 冰山中部 | 半公开信息（用户访谈/竞争调查） | 中 | 中 |
| 冰山下部 | 专家信息（专家脑子里的经验判断） | 高 | **极高** |

> **关键判断**：在你看不懂一个行业/模式、需要做重要判断时，适时引入专家访谈 → 快速完成一次高质量判断。

**执行要点**：带着你业务 1–2 个真实问题往下学，每听完一步就整理一次新思考。

### 步骤② · 理解真价值

**问自己**：如果专家能帮你找到一个缺失的指标，对你创业值多少钱？找一个专家聊 1 小时，通常需要多少钱？

**结论**：专家很难直接给你指路，而是给你关键数据和判断，让你自己做更优选择。路还是要自己走。

## 五、阶段 B：找专家

### 步骤③ · 理解好专家（起底专家库＋画像）

#### A. 起底专家库：谁是专家

**早期项目常见专家清单（5 类）**：

| 专家身份 | 画像 | 核心价值 |
|---|---|---|
| 业务负责人 | 大厂/头部公司负责过某业务线 | 有真实一手洞察、判断和数据 |
| 资深创业者 | 打过仗，做到一定轮次/体量 | 头部选手，真实实操经验 |
| 失败创业者 | 做过同样模式，烧过钱 | 知道坑在哪儿，尸体有原因 |
| 二级市场分析师 | 日常工作就是行业研究 | 很专、信息量大、有深度 |
| 专业投资人/FA | 日常工作就是大量拜访 | 市场情报和观察极多 |

#### B. 给专家画像：三维分析法

按 **行业 / 模式 / 能力** 三个维度拆解你的业务盲区：

| 盲区类型 | 该找谁 |
|---|---|
| 行业问题 | 行业老兵 / VC |
| 模式问题 | 类似模式的业务负责人 |
| 单点能力 | 有实操经验的同学 |

> **三个关键词**：**要拆、要拆细、要务实。**

#### C. 判断专家质量（三个优先级）

- **有没有实操过**：建过系统 ＞ 见过系统
- **有没有提炼过**：有过抽象提炼 ＞ 没提炼过
- **有没有做成过**：做成功过 ＞ 没做成功过

#### D. 擅长及边界清单（不同专家问什么/不问什么）

| 专家身份 | 多问（擅长） | 少问（边界） |
|---|---|---|
| 投资人 | 竞争格局、头部项目、单元模型、规模经济 → **多问预判** | 选品/投放/获客执行 → **少问执行** |
| 咨询师 | 思考框架、解决方案体系、最佳实践标杆 → **多问框架** | 具体 Benchmark、怎么做实验 → **少问细节** |
| 行业老兵 | 行业现状、客户分层、业务尝试过的新方法 → **多问常识** | 行业未来趋势预测 → **少问趋势** |
| 做过类似业务 | 业务死掉的原因、当时的大致策略、具体怎么操作 → **多问细节** | 另一个领域怎么看、大趋势 → **少问领域** |

---

### 步骤④ · 建连接渠道

**4 类连接渠道**：

| 渠道类型 | 具体方式 |
|---|---|
| 有关系 | 朋友介绍的关系 |
| 有资源 | 未来有潜在合作 |
| 付费渠道 | 在行、专家网络（适合有预算者） |
| 公开信息 | 搜索引擎、微博、知乎、天眼查、脉脉、领英 |

> **提醒**：30%–50% 的专家在网上有公开线索，像黑客一样搜索即可找到。推荐：诸葛思远《超级人脉术》。不迷信专家网络——美团、拼多多基本找不到人。

---

### 步骤⑤ · 说服做沟通

**核心原则**：**最好身份对等，起码价值交换。**

**5 个常见价值交换手段**：

| 手段 | 示例 |
|---|---|
| 有关系 | 朋友介绍的关系 |
| 有资源 | 未来有潜在合作 |
| 有认知 | 能碰撞新的认知 |
| 有背书 | 有大名字 / Big Name 背书 |
| 有付费 | 直接给咨询费 |

**自问三个问题**：
1. 对方目前在做什么？你手里有对方想要的资源吗？
2. 对方可能缺什么？你有什么认知可以平等分享？
3. 对方在乎什么？你能用 Big Name 增强信任吗？

**关于"假装身份"**：不触犯法律道德底线前提下，自己判断「真诚」和「假装身份」哪个更容易解决问题。

## 六、阶段 C：做访谈

### 步骤⑥ · 认真做功课（最重要、最易被忽略）

**核心原则**：**专家不是用来帮你做基础科普的**。公开信息研究往前放，专家访谈往后放。

**三不问**：
- 百度百科里有的 → 不问
- 知乎讨论里有的 → 不问
- 基本认知概念 → 不问

**时间投入**：最少 2–3 小时完整准备，重要专家花 5–20 小时都不为过。

#### 专家访谈功课准备清单（4 步 Checklist）

| 步骤 | 分类 | 具体清单项 |
|---|---|---|
| **① 调研履历** | 了解对方 | 对方资历背景及项目 |
| | | 擅长和不擅长 / 做过或投过的项目 |
| | 评估专业度 | 准备 2–3 个可评估专业度的问题 |
| | | 抛出来看对方是否回答得大差不差 |
| | 交换价值 | 认真思考可以交换的价值 |
| | | 思考对方的诉求 |
| **② 做好功课** | 成为半个专家 | 快速全网调研 |
| | | 熟悉基本概念和玩家 |
| | 整理数据 | 已调研出来 / 拿到的数据 |
| | | 一些具体的困扰和疑惑 |
| **③ 明确目标** | 确定议题 | 重点讨论问题 Top 3 |
| | | 哪些现在问、哪些跑完 MVP 问 |
| | | 准备一个大纲 |
| | 规划后续 | 进一步可能的持续沟通和资源 |
| **④ 准备模型** | 匹配框架 | 创业机会：预判五步法 |
| | | 行业机会：行业分析画布 |
| | | 业务认知：一堂五步法 |
| | | 商业模式：单元模型 |
| | | 用户方案：用户洞察 |

> **核心逻辑**：没有模型就没有共同话语体系 → 两人不同频，讨论无结果。

---

### 步骤⑦ · 选合适场景

**场景策略**：不只咖啡馆。访谈场景可以配合「展示你的价值」——比如邀请对方来你公司，让对方看到你的组织、团队和你在做的事，本身就是建立信任的方式。

---

### 步骤⑧ · 破冰建信任

**破冰的三个练习建议**：
- **练习 1**：60 秒快速破冰
- **练习 2**：主动提升价值和信任（用权威背书、强调双方价值点）
- **练习 3**：判断对方长短板（用准备好的常识问题开场，同时验证专家专业度）

**验证专家专业度的两个技巧**：
- **技巧 1**：准备细节交叉验证 → 问他行业增速/集中度等你知道答案的数据，判断他的判断力
- **技巧 2**：问对方背景明确能力边界 → 问他操盘过的项目、核心难点在哪

**破冰的四个技巧**：
- 让对方感到被尊重
- 真诚地夸奖对方
- 用人情快速拉近关系
- 带点小伴手礼

---

### 步骤⑨ · 做专业探讨（核心——不是"访谈"而是"探讨"）

**关键区分**：

| | 访谈 | 探讨 |
|---|---|---|
| 方向 | 单向，像记者 | **双向，平等对话** |
| 性质 | 收集信息（Input） | **碰撞结论（Input＋Process）** |
| 质量 | 浅 | **深** |

#### 平等探讨的三个关键原则（分数量表）

**原则一 · 60 分合格线：要多问擅长，少问大而全**

> **超级技巧**：**对方靠什么吃饭，你就问他什么。**

例：投资人靠投资判断吃饭 → 问他"什么程度能拿钱""赛道窗口期还在不在"，别问他怎么做业务。

**原则二 · 70 分良好线：要多问深挖信息，少问怎么看**

> **四个追问词**：**问事实、问定量、问细节、问逻辑。**

反复追问，把对方隐藏遗漏的信息挖出来。真正的高手可以挖掘事物背后的原因和推导过程。

案例对比：
- ❌ 创业者 A：宠物医院能用 O2O 吗？专家说"低频不行"→ A："哦好，那我做消费品吧"
- ✅ 创业者 B：同上提问 → "为什么下这个判断？"→"低频获客成本高"→"那闪送为什么行？"→"闪送不是服务对接型 O2O"→"那新氧为什么行？"→"新氧客单价高、决策成本高、全国选"

> **深入挖掘 3 个提问技巧**：**为什么？底层逻辑是什么？反例怎么看？**

**原则三 · 80 分优秀线：要多做推理，少关注结论**

> **四个批判词**：**问前提、问推理、问意外情况、问底层原因。**

例：专家说"你别做了，做不大"→
1. 问结论：做不大是多少？能定量吗？天花板多大？
2. 问论证：什么逻辑证明做不大？市场有大玩家？天花板低？集中度低？哪个环节出问题？能被解决吗？
3. 提反例：为什么 XX 公司在同样条件下做成了？

> **提醒**：可以较真，但不要抬杠。较真 = 追逻辑；抬杠 = 争输赢。

**访谈收尾动作清单**：
- 访谈后做一个备忘，细节笔记记下来
- 条件允许录音备忘
- 问对方是否还能介绍两个人
- 直接真诚感谢对方的时间
- 保持长期沟通语境（约下次你公司见 / 500–1000 红包 / 咨询费）

### 步骤⑩ · 交叉拿结果

**三轮交叉验证体系**：

| 轮次 | 方法 | 操作 |
|---|---|---|
| **第一轮** | 前期功课 ＋ 专家访谈 | 把你调研出的数据矛盾、分歧、冲突 → 当访谈材料去验证 |
| **第二轮** | 专家判断 ＋ 提一个反例 | 专家给了一个重要判断 → 你努力找一个反例抛出来验证 |
| **第三轮** | 专家判断 ＋ 后期检查 | 访谈拿到的信息拿不准 → 回来做准确校对（找案例、找第二个专家） |

> **核心信念**：**没有逻辑和交叉验证过的信息，我可以知道，但是我默认不信。**

**一堂自身的失败教训**（三节课案例）：
- 找到 Top 级公司内部专家 → 听了建议全盘调整 → 半年后发现对方数据错了、模型错了、核心产品价值理解错了 → 浪费大半年 → 根源：专家选择 / 提问方式 / 交叉验证全没做。

## 八、课程总结金句

> 1. 不是交个朋友，而是价值交换。
> 2. 不是收集观点，而是收集事实。
> 3. 不是调研问题，而是验证假设。
> 4. 不是辩论比赛，而是深入探讨。
> 5. 不是单向采访，而是双向互动。
> 6. **带问题，有体系，拿答案，不盲信。**
> 7. 对方靠什么吃饭，你就问他什么。
> 8. 专家不是帮你做基础科普的——是用来确认和交叉验证的。
> 9. 建过系统的 ＞ 见过系统的。
> 10. 没有逻辑和交叉验证过的信息，我可以知道，但是我默认不信。
> 11. 多收集事实，少关注结论。多辩证讨论，不迷信专家。多关注取舍，不只做加法。
> 12. 专家很难给你直接指路，更多的是给你关键数据和判断。路还是要靠你自己走。

## 九、课后作业（2 题）

**作业 1 · 业务题**：用三维分析法（行业/模式/能力）审视你当前业务的认知盲区。是什么？用课上方法找专家补齐是否可行？推演解决路径。

**作业 2 · 招募题**：一堂组建专家库，你愿不愿意报名？（在某领域有 3–5 年以上积累者）回答：① 用三维分析法，你擅长哪个部分？② 你的经验和履历（越具体越好）。③ 你能提供什么专业支持？
