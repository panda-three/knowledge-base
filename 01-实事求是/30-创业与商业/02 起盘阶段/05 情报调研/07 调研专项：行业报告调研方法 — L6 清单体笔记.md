# 调研专项：行业报告调研方法 — L6 清单体笔记

---

## 一、课程定位与核心金句

> **「很多人都知道行业报告很重要，但是不知道从哪找比较靠谱。找到了也只会从中拿几个数据，而且很多时候，拿到的数据还是错的。其实行业报告的价值远远不止这些。」**

> **「当你根据自己的行业经验推论出来的数据，跟报告里看到的数据差别比较大，或者读到两份报告里同样的数据差别比较大——你应该信谁？这时候，你可以考虑去约写报告的人聊一聊。」**

— Doris，产品专家

**课程在调研系列中的位置**：

```text
一堂高阶调研系列 · 全景地图：
  全员必修：重新理解「情报调研」（认知入门篇）
    → 调研黑客：系统式调研认知篇
      → 调研黑客：系统式调研实操篇
        → 调研黑客：挖掘式调研武器库
          → 调研专项：行业报告调研方法 ← 本节课
            → 调研专项：读懂上市公司报告
              → 调研专项：高质量的专家访谈
                → 调研专项：高质量的用户访谈
```

**本节核心交付**：**行业报告调研四步法 + 实操技巧 + 优质报告信息源清单。** 解决三个核心问题：①行业报告如何精准搜索、②行业报告质量如何甄别、③如何通过报告快速建立行业认知。

**推荐谁学**：好奇高手如何快速通过「行业报告」深入了解行业，想从行业小白到资深专家。

**课程渊源**：Doris 以自身创业经历为蓝本——她如何一步一步用行业报告做调研，从外行变成行业产品专家。课里包含大量实操技巧和行业报告渠道。

## 二、预热思考 · 三连问

| # | 问题 | 用意 |
|---|------|------|
| 1 | 你上一次看行业报告时，是直接拿来就用里面的数据，还是先问过「这份报告是谁写的？他有什么动机？数据是怎么来的？」 | 暴露「拿来就用」的盲信心态——这是读报告最大的坑 |
| 2 | 如果现在让你在24小时内通过行业报告快速建立对一个陌生行业的认知，你的第一步是什么？你知道该去哪里找第一份高质量报告吗？ | 检验你是否有「信息源优先级」的意识 |
| 3 | 两份不同机构出的同一行业报告，市场规模差了3倍——你应该信谁？除了「选择更权威的」，你还有什么方法？ | 引入「交叉验证」和「联系报告作者」的高阶做法 |

## 三、课程核心认知：行业报告是被忽视的公开宝藏

### 3.1 大多数人对行业报告的三种低效使用姿势

```text
┌─────────────────────────────────────────────────────────┐
│         行业报告使用的三种低效姿势                          │
├──────────────┬──────────────────┬───────────────────────┤
│   问题类型    │      表现         │        本质           │
├──────────────┼──────────────────┼───────────────────────┤
│  找不到      │ 知道有行业报告    │ 不知道从哪里搜——        │
│              │ 但不知道去哪找   │ 缺少优质信息源清单       │
│              │ 搜出来的都是PR稿 │                       │
├──────────────┼──────────────────┼───────────────────────┤
│  不会辨      │ 找到报告就直接用  │ 不会甄别报告质量——       │
│              │ 里面的数据       │ 不知道什么报告可信       │
│              │ 结果数据是错的    │ 什么报告有水分           │
├──────────────┼──────────────────┼───────────────────────┤
│  不会用      │ 只会从中拿几个    │ 不会通过报告建立         │
│              │ 孤立的数据       │ 系统性行业认知           │
│              │ 不会深度解读     │ 不会交叉验证             │
└──────────────┴──────────────────┴───────────────────────┘
```

### 3.2 行业报告的真正价值（远不止几个数据）

```text
行业报告能给你的，不只是数据：

第一层：数据 —— 市场规模、增长率、集中度、各细分占比
第二层：框架 —— 行业怎么分类？产业链怎么划分？竞争格局什么样？
第三层：趋势 —— 驱动因素是什么？阻碍因素是什么？未来往哪里走？
第四层：情报 —— 头部玩家是谁？各自的策略和优劣势是什么？
第五层：审美 —— 多看高质量报告，你会培养出"这个行业该关注什么"的判断力
```

## 五、第一步：搜索与发现 — 知道去哪找，知道怎么搜

### 5.1 核心搜索技巧

**关键词组合法**：不要只搜一个词。把关键词做组合，像搜索引擎的「高级玩法」。

```text
基础组合：
  行业名 + 报告
  行业名 + 行业报告
  行业名 + 趋势报告
  行业名 + 市场分析

进阶组合：
  行业名 + 投资分析
  行业名 + 招股书
  行业名 + 市场规模
  行业名 + 产业链
  行业名 + 竞争格局

高阶组合：
  行业名 + 券商 + 深度
  行业名 + 咨询 + 白皮书
  行业名 + 政府 + 规划
  行业名 + 协会 + 统计
```

**搜索渠道优先级**：

```text
第一优先：直接搜索「行业名+报告」即可触及的高质量公开报告
第二优先：通过特定渠道定向搜索（券商/咨询/数据平台/行业协会）
第三优先：用AI辅助搜索（AI可以帮你快速聚合和初筛）
```

### 5.2 优质报告信息源清单

| 报告类型 | 典型来源 | 适合场景 | 可信度 |
|----------|----------|----------|--------|
| **券商研究报告** | 各大券商研究所（Wind/Choice/东方财富） | 上市公司深度分析、行业格局 | ⭐⭐⭐⭐（有专业背书，但可能偏乐观） |
| **咨询公司报告** | 麦肯锡/BCG/贝恩/埃森哲/德勤 | 行业趋势和战略分析 | ⭐⭐⭐⭐（方法论扎实，但覆盖面有限） |
| **第三方研究机构** | 艾瑞/易观/QuestMobile/极光 | 互联网行业数据 | ⭐⭐⭐（数据较全，需注意方法论） |
| **数据公司报告** | 七麦数据/蝉妈妈/CBNData | 特定维度数据（App/电商/消费） | ⭐⭐⭐（原始数据价值高于结论） |
| **创投媒体报告** | 36Kr/创业邦/虎嗅/亿欧 | 创业生态、新兴赛道 | ⭐⭐⭐（速度快，深度参差不齐） |
| **政府/行业协会报告** | 各部委/行业协会官网/统计局 | 宏观政策和行业标准 | ⭐⭐⭐⭐⭐（权威性最高） |
| **大公司报告** | 阿里/腾讯/字节/京东等大厂研究院 | 平台生态和消费趋势 | ⭐⭐⭐（有数据优势，但有利益视角） |
| **国际机构报告** | 世界银行/IMF/OECD/Statista | 全球市场数据 | ⭐⭐⭐⭐（方法论严谨，但不够本土化） |
| **招股书和财报** | 上市公司公开披露 | 行业龙头最完整的信息披露 | ⭐⭐⭐⭐⭐（真实数据，可交叉验证） |
| **学术论文** | 知网/Google Scholar | 前沿技术路线和理论 | ⭐⭐⭐⭐（深度好，时效性弱） |

## 六、第二步：甄别与筛选 — 判断报告质量

> **「找到了报告只是第一步。更大的问题是：这份报告可不可信？」**

### 6.1 报告质量甄别五维框架

```text
┌─────────────────────────────────────────────────────────┐
│           行业报告质量甄别 · 五维框架                       │
├──────────┬──────────────────┬───────────────────────────┤
│  维度    │      问什么        │        红旗信号             │
├──────────┼──────────────────┼───────────────────────────┤
│  作者    │ 谁写的？           │ 没有署名/作者无行业背景       │
│          │ 有什么专业资质？    │ PR公司写的/明显是软文        │
│          │ 有什么利益动机？    │ 作者所在公司与被分析对象      │
│          │                  │ 有利益关系                   │
├──────────┼──────────────────┼───────────────────────────┤
│  数据    │ 数据怎么来的？      │ 没有说明数据来源             │
│          │ 样本量多大？       │ 样本量过小/采样方法不透明     │
│          │ 什么时间采集的？    │ 数据超过2年未更新            │
│          │ 覆盖了什么范围？    │ 只有百分比没有绝对值          │
├──────────┼──────────────────┼───────────────────────────┤
│  方法    │ 研究方法是什么？    │ 没有说明研究方法              │
│          │ 是否可复现？       │ "专家估计"但不说明            │
│          │                  │ 是哪位专家/怎么估计的         │
├──────────┼──────────────────┼───────────────────────────┤
│  逻辑    │ 结论和数据是否      │ 数据支撑不了结论             │
│          │ 有因果关系？       │ 过度外推/以偏概全            │
│          │ 逻辑是否自洽？     │ 选择性使用数据               │
├──────────┼──────────────────┼───────────────────────────┤
│  时效    │ 什么时候发布的？    │ 超过2年的行业数据             │
│          │ 数据采集时间       │ 快节奏行业超过6个月           │
│          │ 和发布时间差多少？  │ 数据可能已经过时              │
└──────────┴──────────────────┴───────────────────────────┘
```

### 6.2 快速甄别三问

拿到一份报告，30秒内先问三个问题：

```text
① 这份报告是谁写的？
  → 券商研究所 > 知名咨询公司 > 第三方数据机构 > 创投媒体 > 匿名来源
  → PR公司写的、明显是某公司赞助的 → 直接标记为低可信度

② 数据是哪来的？
  → 有明确数据来源和方法说明 → 可以继续看
  → 「据估计」「业内人士透露」但没有具体说明 → 存疑

③ 这份报告想说服我什么？
  → 客观分析 → 高价值
  → 明显在推销某个观点/产品/公司 → 低价值，但仍可提取事实数据
```

### 6.3 两份报告数据矛盾时怎么办

> **「这时候，不要简单选择'更权威的那份'。Doris在课里给了一个很有趣的做法：去联系写报告的人。」**

```text
当两份报告的数据矛盾时，你的动作链：

① 先追溯每份报告的数据来源和方法论 → 找到差异的根本原因
② 尝试联系报告作者——写邮件、打电话
  → 问：你的数据是怎么得出的？样本是什么？
  → 很多时候作者会坦诚告诉你数据的局限性
③ 引入第三份报告做交叉验证
④ 如果仍然无法判断，取两份报告中更保守的数据，并标注低信心度
```

## 七、第三步：深度阅读 — 不只拿数据，建立认知框架

> **「很多人读报告只读第3页的数据表格，然后就把报告关掉了。但真正有价值的东西在后面——报告的分析框架、产业链拆解、竞争格局判断。」**

### 7.1 深度阅读四层法

```text
第一层：读摘要和目录（5分钟）
  → 了解报告覆盖范围、核心结论、整体结构
  → 判断这份报告值不值得继续深读

第二层：读数据和图表（10分钟）
  → 市场规模、增长率、集中度、细分占比
  → 标注你关心的关键数据，但不急于下结论

第三层：读分析框架（20分钟）
  → 报告是怎么划分行业的？用了什么分析模型？
  → 产业链怎么拆？竞争格局怎么画？
  → 这是报告最有价值的部分——框架比数据更值钱

第四层：读判断和预测（15分钟）
  → 报告的核心判断是什么？预测了什么趋势？
  → 这些判断的依据充分吗？逻辑自洽吗？
  → 和你自己的行业经验对比——有什么一致？有什么矛盾？
```

### 7.2 阅读时必做的三件事

| 动作 | 具体做法 | 价值 |
|------|----------|------|
| **标注信源** | 每个关键数据旁边标注原始来源 | 追溯数据可靠性，交叉验证 |
| **提取框架** | 把报告的行业分类/产业链/竞争格局框架单独摘出来 | 框架是报告最有长期价值的部分 |
| **记录矛盾** | 遇到和自己的认知、或其他报告矛盾的地方，专门标注 | 矛盾点是深度认知的入口 |

## 八、第四步：交叉验证 — 多份报告互相印证，必要时联系作者

### 8.1 交叉验证三原则

```text
① 同一数据，至少从2-3份独立来源的报告里看到相近数字，才基本可信
② 不同报告的数据差异本身也是情报——差异的原因常常揭示行业的关键特征
③ 没有任何一份报告是100%准确的。交叉验证不是为了找到"唯一正确的数字"，
   而是为了找到一个"可信的区间"
```

### 8.2 交叉验证矩阵

```text
┌─────────────────────────────────────────────────────┐
│              交叉验证矩阵                              │
├──────────┬──────────┬──────────┬──────────┬─────────┤
│  数据项   │  报告A    │  报告B    │  报告C    │  可信区间 │
├──────────┼──────────┼──────────┼──────────┼─────────┤
│ 市场规模  │  500亿   │  430亿   │  520亿   │ 430-520亿│
│ 年增长率  │  15%    │  12%    │  18%    │  12-18%  │
│ CR3      │  45%    │  48%    │  —      │  45-48%  │
└──────────┴──────────┴──────────┴──────────┴─────────┘
```

### 8.3 联系报告作者 — 被低估的高阶动作

```text
什么时候联系作者：
  ✅ 两份高质量报告的数据差异很大，追溯方法论后仍无法解释
  ✅ 报告里某个关键判断对你极其重要，但论据不够充分
  ✅ 你基于自己的行业经验，看到的和报告说的完全不同

怎么联系：
  → 查找报告封面或末尾的作者信息和联系方式
  → 写一封简短专业的邮件：说明你是谁、为什么关注这个数据、
    具体哪个问题需要澄清
  → 也可以尝试LinkedIn/脉脉等职业社交平台

为什么有效：
  → 大多数报告作者其实很高兴有人认真读他们的作品
  → 作者常常会坦诚数据的局限性——这些局限在报告中不会写
  → 一次高质量交流，可能帮你建立长期行业人脉
```

## 九、如何通过报告快速建立行业认知

> **这是Doris课程最核心的价值——不只教你「搜」和「辨」，更教你「用报告从外行变成内行」。**

### 9.1 行业认知速建五步法

```text
Step 1：找3份高质量行业概览报告（券商行业深度/咨询白皮书/头部数据机构报告）
  → 目标：建立行业全景图——规模、增速、格局、趋势
  → 时间：2-3小时

Step 2：从报告中提取「行业分析框架」
  → 行业怎么分类？产业链怎么划分？关键竞争要素是什么？
  → 这个框架比数据本身更有长期价值
  → 时间：1小时

Step 3：找到行业龙头的招股书或深度研报
  → 上市公司招股书里的「行业概览」章节是无价之宝
  → 看头部玩家怎么描述这个行业、怎么定义竞争格局
  → 时间：2-3小时

Step 4：聚焦你关心的细分领域，做一轮深挖
  → 用关键词组合搜索细分报告
  → 结合专家访谈补充报告里没有的「水下信息」
  → 时间：3-5小时

Step 5：形成你自己的行业认知框架
  → 不是记住数据，而是能用3-5句话说清：
    「这个行业有多大、谁在玩、钱在哪、趋势往哪走」
  → 时间：1小时整理输出
```

### 9.2 14天从外行到资深的节奏建议

```text
第一周（基础认知）：
```

## 十、行业报告的常见陷阱与对策

| 陷阱 | 表现 | 对策 |
|------|------|------|
| **PR报告当研究** | 某公司赞助的报告，整篇在论证"这个市场很大、前景很好" | 看作者和赞助方——有利益关联的报告，事实可取，判断要打折扣 |
| **过期数据当最新** | 用3年前的数据讨论当下市场 | 检查数据采集时间。快节奏行业（互联网/AI），超过1年基本作废 |
| **幸存者偏差** | 只看成功案例，不谈失败率 | 问自己：这份报告提了失败的玩家吗？如果没有，可能有选择偏差 |
| **全球数据当中国** | 把全球市场规模当中国市场规模 | 检查报告的覆盖地域范围——"The global market..." ≠ 中国市场 |
| **预测当事实** | 报告预测"2028年市场规模将达到X"——你当事实用 | 预测永远只是预测。看预测背后的假设是否合理，而不是看数字本身 |
| **单一来源下结论** | 只看一份报告就下判断 | 永远至少看3份不同来源的报告，做交叉验证 |

## 十一、AI + 行业报告调研

### 11.1 AI能加速的环节

| 环节 | AI能做什么 | 人仍然需要做什么 |
|------|-----------|-----------------|
| 搜索 | 多源聚合行业报告链接、自动翻译外文报告 | 判断信息源质量 |
| 甄别 | 快速对比多份报告的数据差异 | 判断哪份报告更可信、为什么 |
| 阅读 | 快速摘要报告核心内容、提取关键数据 | 理解分析框架、做行业判断 |
| 验证 | 多源搜索同一数据、自动对比 | 联系报告作者、做深度归因 |

### 11.2 AI使用注意事项

```text
⚠️ AI在行业报告调研中的三个短板：
  ① 幻觉严重：AI可能会"编"一些看起来很专业的报告名和数据
  ② 不懂时效：AI可能引用5年前已过时的报告
  ③ 不会判断动机：AI不懂"这份报告是谁赞助的"
  
✅ 正确使用姿势：
  → 让AI帮你做初筛和聚合，你来判断质量
  → 让AI对比多份报告的数据差异，你来归因
  → 让AI写摘要，你来深度解读框架
```

## 十三、L6 级别进阶认知

### 认知一：行业报告的最高价值不是数据，而是「框架」

> 很多人读报告只看市场规模那一页。但Doris的核心洞察是：**数据的保质期通常只有1-2年，但一份好报告提供的行业分析框架——行业怎么分类、产业链怎么划分、竞争要素是什么——可以反复使用。** 学会从报告中「偷框架」，是从外行变内行的捷径。

### 认知二：甄别报告质量的能力，是调研高手的核心壁垒

> 互联网上90%的「行业报告」其实是PR软文。能快速判断一份报告质量的能力，比能搜到报告的能力更稀缺。五维甄别框架（作者/数据/方法/逻辑/时效）是一个可以在30秒内完成的肌肉记忆训练。

### 认知三：联系报告作者——被99%的人忽视的高阶操作

> 大多数人把行业报告当成「死文档」。但Doris在课里提到一个很少人做的动作：**直接联系报告作者。** 写一封邮件、打一个电话，坦诚地问对方「你这个数据是怎么得的？」——大部分作者会友好回应，而且会告诉你报告里不会写的局限性。这是拿到「元信息」的最短路径。

### 认知四：行业报告 + 专家访谈 = 外行变内行的最优组合

> 行业报告的弱点是「宽而浅」——覆盖广但深度不够。专家访谈的弱点是「深而窄」——深度够但视角有限。**先用行业报告建立全景框架，再带着框架和矛盾去找专家聊——这是从外行到资深最高效的路径。**

### 认知五：一堂同学的实战案例 —— 提神含片创业者的半年报告调研

> 一堂有位做提神含片的同学，预判阶段花了半年时间看了几百份行业报告，分析了不同品类的提神产品（咖啡因口香糖、含片、软糖、爆珠、冲剂、糕点等），极大加深了对整个行业的了解。通过全网调研发现——咖啡因口腔吸收速度远远快过胃肠吸收（口腔2-3分钟，肠胃20-30分钟），于是果断否定了食物和饮料品类。**从「我有个想法」到「笃定地知道该做什么产品」——中间隔的就是几百份行业报告和一套科学的调研方法。**

## 十四、行动建议

| 层级 | 行动 |
|------|------|
| **基础** | 选一个你感兴趣但不熟悉的行业，用「行业名+报告」等关键词组合，收集10份行业报告。然后用五维甄别框架筛选出3份最可信的，从每份报告中提取至少3个关键数据和1个分析框架 |
| **进阶** | 找到这个行业的一家龙头上市公司，下载它的招股书。阅读「行业概览」章节——对比招股书里的数据和行业报告里的数据，看看有没有差异。如果有差异，尝试追溯差异的原因 |
| **高阶** | 选一份对你特别有价值但数据让你存疑的报告，找到作者的联系方式——写一封邮件或发一条LinkedIn消息，坦诚地问一个具体问题。记录下对方的回复，以及这个过程让你对行业理解发生了什么变化 |
