# 课程：一张卷子三层世界·青少年营

**一句话结论：** 手段≠需求；把"为什么做"多问几层，同一道难题从硬扛/摆烂二选一，变成第三条路——见自己、见他人、见世界。

---

## 一、核心交付

- 一个分法：手段=你在干什么，需求=你到底要什么。
- 一条线：个人困境→沟通共识→普遍需求→商业机会。
- 一张地图：一堂五步法第一步=需求分析，四武器拆推评算。
- 一段段位：本课走 L1→L3（模糊→主动拆→定性评估）。

## 二、关键框架

### 2.1 一张卷子三个世界

| 世界 | 问自己 | 做法 |
|---|---|---|
| 见自己 | 我做这些题为了什么 | 从"做完卷子"到"查缺补漏" |
| 见他人 | 老师的需求是什么 | 找共识，不在手段上争论 |
| 见世界 | 不止我一人这样吧 | 几千万初中生=一个细分市场 |

- 目标=查缺补漏时：先做代数找节奏、几何选类型、允许做不完。
- 跟老师沟通话术："代数全做，几何选三类，不会的标出来，您看我思路卡哪"。

### 2.2 同类商业案例

| 产品 | 抓的需求 | 手段 |
|---|---|---|
| 简单学习网 | 要更准的题 | 不搞题海搞精准 |
| 洋葱学院 | 要能听懂的讲法 | 5-6分钟动画短视频 |
| 百词斩 | 要记住单词 | 一词配一图 |

### 2.3 需求分析四武器

1. **拆**：拆用户需求（基本功）。
2. **推**：推使用场景（理解问题）。
3. **评**：定性评可行性（判断价值）。
4. **算**：定量算市场大小（理性）。

### 2.4 需求分析段位（L1-L6）

| 段 | 能力 | 特征 |
|---|---|---|
| L1 | 模糊理解 | 只谈初心，想服务所有人 |
| L2 | 主动拆解 | 拆出差异，剥离非用户 |
| L3 | 定性可行 | 推场景，三维评估 |
| L4 | 定量天花板 | 对标、估算、交叉验证 |
| L5 | 全局决策 | 需求/商业/增长匹配 |
| L6 | 动态预测 | 短期/中期/长期变化 |

## 三、金句与判断

> 「很多冲突不是有人错了，是需求没说清，大家在手段上争论。」
> 「需求分析不是逃避要求，而是更负责地说明怎么达成目标。」

## 四、行动建议

| 层级 | 行动 |
|---|---|
| 基础 | 心烦时问：我在做什么？为什么要做？ |
| 进阶 | 找一个和你冲突的人，问：我们的共识是什么 |
| 高阶 | 把个人抱怨往上多推一步，看是不是普遍需求 |
