# 五步法进阶4：重新理解「业务增长」

**讲师**：Truman（一堂CEO / 课程总设计师）
**课程性质**：五步法第四步"业务增长"的认知总纲课——增长篇核心入口
**课程迭代**：2021.7 首次内测 → 2022.10 首版上架 → 2024.12 推翻式升级（第二次交付），合并一堂近几年约10倍增长的一手实践
**教研支撑**：访谈多位专家同学 + 22万+字共建作业融入课程 + 磨课研究组集体成果
**课程使命**：从碎片技巧到系统思维——增长不是碰运气、不是追求单个技巧或免费获客的奇技淫巧，增长是系统工程，通过科学方法可以实现高效、持续性、可规模化的增长
**前置关联**：需求（拆推评算）→ 解决方案（产品内核）→ 商业模式（单元模型）→ **增长（本课）** → 壁垒（规模经济）

**一句话定位**：增长是从价值验证到增长验证的最大一次质变点跨越——把油门踩到底，翻车就清零

## 一、为什么增长需要科学方法：普遍痛点

**旧版课程的不足**：增长环节一直很单薄，三年前为五步法完整性做过内测版，但一堂自己也太早期、认知不够，「没有勇气二次升级」

**真实困境——各阶段普遍焦虑**：
- 过了验证阶段后，增长变成整个公司头号超级难题，直接关乎收入和利润，同样九死一生
- 随机技巧、奇技淫巧、工具和技巧太多——但系统方法、核心能力思考太少
- 大量公司「增长失速」甚至「翻下悬崖」：轻则停滞亏损，重则清零立即关停

**核心信念**：「增长是有科学方法的。增长不是碰运气，不是追求单个技巧。增长是个系统工程，通过科学方法，可以带来高效、持续性、可规模化的增长。」

## 二、增长阶段的特殊性：五步法中最大的一次质变点

**增长与其他步骤的本质差异**：

| 对比维度 | 前三步（需-解-商） | 增长阶段 |
|:---|:---|:---|
| 核心任务 | 验证价值/验证商业 | 规模复制 |
| 团队规模 | 1-3人小团队测试模型 | N倍团队，瞬间加10-100倍杠杆 |
| 决策杠杆 | 单个决策影响有限 | 正确决策被放大，错误也被放大 |
| 工作本质 | 专注模式本身 | 系统操盘 |

**Truman的经典比喻——开车上高速**：
- ✅ 好消息：单元模型已跑通（车辆调试），有钱了（有车有油）
- ⚠️ 坏消息：需要把油门踩到底（杠杆），必须全神贯注看路（竞争环境）、扶好方向盘（决策）
- ☠️ 致命：一出问题直接翻车掉下去——增长阶段犯错的代价被瞬间放大

**关键原则**：「不要过早复制，未经验证的商业模式。」

**增长框架要回答的三个问题**：
1. 如何理解增长的确定性和底层规律
2. 如何抓住增长的眼下主要矛盾
3. 如何拥有一套「增长武器库」级别的策略地图

## 三、核心交付：增长周期模型（三个周期）

**模型精髓**：三个周期，三个主要矛盾，三套关键工作，三个典型卡点

```
增长周期模型总览

周期1：获客增长（渠道驱动）
  → 主要矛盾：找到一个可持续的渠道
  → 关键工作：渠道探索→预判→测试→建模
  → 典型卡点：非标渠道× / 渠道错配× / 销售太弱×
  → 最糟结果：无法复制

     ↓（突破后进入）

周期2：系统增长（模型驱动）
  → 主要矛盾：构建一个稳定的增长模型
  → 关键工作：围绕业务公式每个参数优化
  → 典型卡点：指标跑偏× / 缺少模型× / 缺少假设×
  → 最糟结果：现金流崩溃

     ↓（突破后进入）

周期3：对抗增长（壁垒驱动）
  → 主要矛盾：对抗规模不经济
  → 关键工作：竞争优势 + 对抗劣势 + 苦练基本功
  → 典型卡点：忽略壁垒× / 不擅对抗× / 转型太慢×
  → 最糟结果：越大越亏
```

**核心洞察**：三个周期是层层递进的——先在渠道上站稳，再建系统提效，最后走向对抗构建壁垒。不是一次性走完，而是每进入一个新渠道/新品类/新客群，「123123一遍遍重复」。

## 四、一堂自身增长实践（开源完整复盘）

### 商业验证阶段

**背景**：2019年，打磨出体系+最佳实践的教研方法后正式发布课程。
**终局判断**：早期创业&管理必修课第一品牌，市占率20-40%，规模经济、年营收2-5亿。大概3-5年窗口期，大家都很早期。

**商业模式测试历程**：
- 选课券售卖模型 → 转化率和复购很差 → ❌
- 券包模型 → 转化率依然很差 → ❌
- 多训练营模型 → 复制很困难 → ❌

### 增长三周期的实际演进

**周期1·获客增长（渠道驱动）**：
- 核心任务：找到一个可持续的获客渠道
- 渠道探索：公众号推文/直播/体验课/朋友圈/老带新/合作渠道
- 渠道预判：判断天花板、速度、匹配度
- 渠道测试：小范围验证能否跑通
- 渠道建模：把跑通的渠道逐步标准化
- 核心指标：获客量×转化率×客单价

**周期2·系统增长（模型驱动）**：
- 核心任务：围绕业务公式优化每个参数
- 不再只靠获客硬拉，而是系统性地提升转化、留存、复购、推荐
- 一堂实践：从单一获客→多模块业务公式优化

**周期3·对抗增长（壁垒驱动）**：
- 核心任务：构建竞争优势、对抗规模不经济
- 一堂现状：整个公司五步法在第四阶段，约7-10个商业单元（MBA/训战营/私董会/咨询/AI/内训等）分别在2-3个阶段进化中

## 五、周期1：获客增长（渠道驱动）

**一句话主矛盾**：找到一个可持续的渠道

**核心公式**：获客量 × 转化率 × 客单价

**关键工作四步走**：
- **渠道探索**：广泛尝试，列出渠道清单（线上/线下/投放/合作/内容/老带新）
- **渠道预判**：判断天花板、增长速度、与产品匹配度
- **渠道测试**：小范围验证ROI和可持续性
- **渠道建模**：跑通后标准化、工业化，形成可复制的渠道模型

**三个典型致命卡点**：

| 卡点 | 表现 | 后果 |
|:---|:---|:---|
| 非标渠道 | 渠道高度依赖个人关系/能力，不可复制 | 无法放大，卡死 |
| 渠道错配 | 选错渠道类型（如重销售的产品选了内容渠道） | 大量资源浪费 |
| 销售太弱 | 渠道质量不错但销售团队跟不上 | 转化率极低，渠道白做 |

**最糟结果**：无法复制——永远停在靠创始人/合伙人拉关系的阶段

## 六、周期2：系统增长（模型驱动）

**一句话主矛盾**：构建一个稳定的增长模型

**核心认知**：第一阶段靠获客和销售粗暴硬拉问题不大。但规模拉大后，继续粗放增长 → 单元模型变差、利润下滑、甚至立刻进入亏损和现金流崩溃。

**关键转变**：
- 从「获客驱动」→「系统驱动」
- 围绕业务目标展开的业务公式，每个参数的进步都可以贡献增长

**典型致命踩坑案例**：

**案例1 · 指标跑偏——臻票云经销商教训**（徐剑复盘）
- 问题：把经销商数量快速增加作为核心增长目标（占坑思维）
- 结果：低门槛签回大量能力弱/意愿差的经销商，对终端用户覆盖无作用
- 代价：浪费大量渠道开发资源、客户成功资源，对长期战略产生负面影响
- 启发：增长指标必须对准业务的本质——是终端用户数量，不是经销商数量

**案例2 · 指标跑偏——以太创业者社群教训**（Truman亲述）
- 问题：把「活跃度 = 商业变现价值」当核心指标
- 结果：用红包/优化海报/鼓励灌水提升活跃度，运营数据好看但产品价值快速被削弱→劣币驱逐良币，优秀用户闭嘴退出
- 启发：把新业务当确定性的「运营KPI」来做，会朝反方向越跑越远

**案例3 · 指标跑偏——线下连锁大卖场教训**
- 问题：管理层焦虑，给运营定「增加收入」KPI，设折扣红线
- 结果：团队做大量平进平出、不盈利的非核心业务，请临时工促销，没成果
- 启发：KPI设置偏差导致业务动作全面变形

**案例4 · 缺少模型——医疗设备租赁违约教训**
- 问题：老板通过关系让设备进医院收租金，利润不错→招销售团队扩张新医院→新客户开始大面积违约不付租金
- 本质：一开始就没有预判违约可能性，没有对违约建模——最早那批客户靠关系没问题，但复制时暴露了
- 启发：增长之前必须把单元模型里的风险变量找全、建好模型

**案例5 · 缺少模型——汉堡连锁选址教训**（陈先敏）
- 问题：3个合伙人亲自去实地看加盟选址，根本跑不过来→差旅高、时间机会成本高、加盟商流失、好点位流失
- 突破：学习最佳实践，建立工业化选址模型，才实现加盟商加速增长
- 启发：手工操作在规模面前是死路——必须建模+工业化

**案例6 · 缺少假设——代理记账电商获客教训**（吉春宇）
- 场景：天猫淘宝获客路径：详情页→咨询客服→下单
- 问题：只盯最终下单数据，没有对转化链路上每个环节提假设、做优化
- 启发：没有假设的增长就是碰运气

**三个典型致命卡点**：

| 卡点 | 表现 | 后果 |
|:---|:---|:---|
| 指标跑偏 | KPI设定不对，团队动作全面变形 | 越努力越糟糕 |
| 缺少模型 | 没有对关键变量建模和预判 | 复制时隐藏风险爆发 |
| 缺少假设 | 增长靠惯性，不主动提假设优化 | 停滞、落后、被淘汰 |

**最糟结果**：现金流崩溃——数据好看，钱没了

## 七、周期3：对抗增长（壁垒驱动）

**一句话主矛盾**：对抗规模不经济

**核心认知**：规模变大的过程中，好事会发生（规模优势），坏事也会发生（规模不经济）。真正的高手不是只看增长数字，而是**对抗出来的**——规模的本质是对抗出来的。

**案例——陈先敏的增长教训（续）**：
- 加盟模式：规模小时一家家考察还行，想开上百上千家就崩溃了
- 如果没有工业化选址模型，规模越大，质量越差，加盟商投诉越多

**关键工作三维法——优/劣/基**：

### ① 优势：持续构建竞争优势
- 壁垒：无形资产/转化成本/技术/网络效应/规模效应
- 增长飞轮：让增长要素之间形成正反馈循环
- 定位：在关键环节形成领先优势

### ② 劣势：持续对抗规模不经济
- 工业化生产 = 三步法：建筛选模型 → 充分做加法 → 专业做减法
- 升级人工策略：从依赖顶级IP→替代专家→标准化培养
- 升级管理策略：文化建设/基本功训练/培训体系/薪酬绩效
- 升级业务策略：换用户画像/简化SKU/标准化/长周期产品
- 用IT解决：自动化/算法化/系统化/AI化/机器化

### ③ 基本功：完成团队能力分解和标准化
- 把复杂能力拆成可训练的动作单元
- 用SOP/Checklist/培训体系固化
- 团队下限 = 人才杠杆的基础

**对抗规模不经济清单**：

| 难度 | 类型 | 对抗方向 |
|:---|:---|:---|
| 很难 | 人的招聘培训/日常管理/特殊岗位管理/议价沟通 | 工业化+IT化 |
| 较难 | 产品质量下降/合规成本/跨城市扩张 | 建体系+标准化 |
| 尚可 | 品控变难/客诉变难/加盟商管控/创新路径依赖 | 流程+管理 |

**三个典型致命卡点**：

| 卡点 | 表现 | 后果 |
|:---|:---|:---|
| 忽略壁垒 | 只做增长不建壁垒，越做越脆弱 | 竞争一来就被打掉 |
| 不擅对抗 | 看到规模不经济但不知道怎么对抗 | 越大越痛苦 |
| 转型太慢 | 靠获客驱动的惯性太久，迟迟不进入第三周期 | 错失窗口期 |

**最糟结果**：越大越亏——规模上来，利润下去

## 八、增长五力模型（增长武器库补充）

**五力**：探渠道、建模型、做实验、定指标、带团队

**核心回答**：创业团队增长问题背后需要的核心素质和驱动要素

**五力与增长周期的对应**：
- 周期1（获客增长）：探渠道 + 带团队（销售搭建）
- 周期2（系统增长）：建模型 + 定指标 + 做实验
- 周期3（对抗增长）：建模型（工业化） + 带团队（基本功）

## 九、十万美金小抄（三大对抗工具）

> ⚠️ 课程中Truman强调：「这是一张价值十万美金的超级小抄」

**第一张：规模经济对抗小抄**
- 持续识别规模经济要素（网络效应/品牌/技术/KnowHow沉淀）
- 持续识别规模不经济要素（管理复杂度/质量下降/沟通成本）
- 每次有效对抗、化简、升级&降级，都会推高业务天花板

**第二张：业务公式小抄**
- 拆业务公式的每一个参数
- 找到瓶颈参数，持续提假设、做实验、优化
- 增长 ≠ 只有获客一个参数

**第三张：关键假设评估区间**
- 悲观版→合理版→乐观版三点预测
- 不同假设下完全不同的打法

**工业化生产三步法**：建筛选模型 → 充分做加法 → 专业做减法

## 十、长期修炼地图：段位与提升

**增长段位追求**：

| 段位 | 典型能力 | 核心标志 |
|:---|:---|:---|
| L1 | 获客起步 | 能跑通一个渠道，开始有增长 |
| L2 | 渠道建模 | 能把渠道标准化、可复制 |
| L3 | 系统建模 | 能建业务公式，优化多个参数 |
| L4 | 动态对抗 | 能持续对抗规模不经济 |
| L5 | 全局操盘 | 三个周期切换自如，预判趋势 |
| L6 | 动态预测 | 对市场变化和竞争格局有精准预判 |

**Truman自评**：「我现在在不同的业务上大概在L3.5-L5之间横跳，希望两年后可以稳定在L5-6。」

**三段位飞跃路径**：
- 获客增长 → 系统增长（关键：从单参数→多参数思维）
- 系统增长 → 对抗增长（关键：从做加法→做减法和对抗）
- 单业务操盘 → 多业务全局操盘（关键：新渠道/新品类/新客群 = 123一遍遍重复）

## 十一、最后收尾：守住底线，期待惊喜

**核心行动准则——两句话**：

**前半句：守住底线**。时刻记得工作本质是科学地复制单元模型，持续用单元模型作为尺子调整，管理好现金流，确保公司稳定经营——「不冲出高速公路」。

**后半句：期待惊喜**。对商业终局和结果保持最美好的期待和渴望，去分析壁垒、去积累优势、去勇敢对抗、去积极提假设、去塑造行业里最稀缺的核心能力。

**最后一句话**：「只要做到了守住底线，期待惊喜，坚持科学，坚持实事求是，坚持正确归因，不管增长最后的结果是赚钱多少，是否取胜，我们都是"科学创业"的真正赢家。」
