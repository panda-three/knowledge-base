# 课程：判读纠偏·五步法总结

**一句话结论：** 五步法不是预测机器，而是一张行动前的检查地图——把"我觉得"拆成"事实/假设/待验证"，用最小成本逼近真相。

## 一、核心交付

- 一个认知：推理再顺，也只是假设，不是事实。
- 一个动作：动手前标出 ✓事实 / ?假设 / →待验证。
- 一个判断力：找出"错了会全盘翻盘"的那条高风险假设。

## 二、关键框架

### 2.1 两次游戏交易：同一男孩，两种判断

| 维度 | 第一次（亏了） | 第二次（更清醒） |
|---|---|---|
| 触发 | 看到利好消息 | 看到可能机会 |
| 动作 | 直接推断涨价、马上买入 | 先写假设清单再决定 |
| 漏掉 | 替代品/供给/规则 | 收益·等待·机会成本·最大损失 |
| 结果 | 价格反跌 | 即使错也知道风险在哪 |

### 2.2 失败推理里藏的未验证假设

- 玩家一定会选原配套装备吗？
- 有没有更便宜或性能更好的替代品？
- 这件装备的供给会不会同时增加？
- 新版本会不会改变获取方式？

### 2.3 为什么聪明人也判断错

> 只看到支持自己的信息，不找让判断失效的条件。

- 别只问"对了赚多少"，要问"什么发生我就错了"。

## 三、金句与判断

> 「科学判断不是永不犯错，而是行动前找出关键假设。」
> 「商业判断不比谁第一次猜得准，比谁拆得细、试得便宜。」
> 「写下"不知道"，本身就是分析结果。」

## 四、迁移练习：用五个问题拆自己的事

1. **选题**：挑一件你真正熟悉的事（小摊/奶茶店/游戏道具/校园活动）。
2. **五问**：
   - 谁在什么场景真需要？别写"所有人"。
   - 用什么办法解决？缺什么用户就不选？
   - 一笔钱划得来吗？成本含时间情绪，不知道就写"待查"。
   - 哪个有效动作可复制？第一批人从哪来？
   - 被模仿后凭什么选你？没壁垒就诚实写"暂没有"。
3. **打标**：每条前标 ✓事实 / ?假设 / →待验证。
4. **找雷**：从 ? 里挑一条"错了最致命"的 = 高风险假设。
5. **最小验证**：成本尽量小、证据尽量真（访谈10人/收个小订金/做个样品）。

## 五、速查卡

```
┌ 一句话记住本课 ┐
└ 别把"可能"当"一定"；拆假设、标证据、小步试。 ┘
```

## 六、行动建议

| 层级 | 行动 |
|---|---|
| 基础 | 选熟悉对象，完成五问 + 三标记 |
| 进阶 | 找出 1 条高风险假设，设计最小验证 |
| 作业 | 挑一件买后悔/看好过的东西，用五问复盘 |
