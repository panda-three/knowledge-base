# 五步法进阶1：重新理解「需求原点」

**讲师**：Truman（一堂CEO / 课程总设计师）
**课程性质**：五步法第一步"需求分析"的认知入门课——需求实操系列课的总纲
**课程序列**：本节（认知篇）→ 实操1：剥离拆解篇 → 实操2：场景推演篇 → 实操3：定性评估篇 → 实操4：算天花板篇
**课程渊源**：旧版《重新理解需求原点》的全面升级，回应两年多来"最基础最重要的需求环节为啥没有实操系列课"的呼声
**教研背景**：失败案例大爆炸中，上千个案例标签里有超过30%-50%甚至更多的错误集中在第一步——很多人搞砸后才意识到自己从没认真分析过要解决的真正问题
**课程使命**：从"模糊理解需求"到"科学分析需求"，建立审美、掌握工具、形成笃定，为后续所有商业决策打地基

## 一、为什么需求分析ROI最高：五步法中最被低估的一步

**五步法各步的定位**：最难的是壁垒，最省钱的是单元模型，最容易忽略的是产品内核，而**最基础也ROI最高的就是第一步：需求分析**

**普遍痛点——失败案例大爆炸的数据**：
- 上千个失败案例标签，30%-50%+的错误集中在第一步
- 很多人搞砸以后才意识到：从没认真分析过要解决的真正问题——没拆解、没细分、没判断、没定量

**典型「乍一听」陷阱**：
- 乍一听项目很牛逼 → 仔细一看没解决什么具体的问题（如何看？）
- 乍一听很多人需要 → 仔细一拆目标用户非常少（如何拆？）
- 乍一听项目非常大 → 仔细一算天花板小得可怕（如何算？）

**一堆商业失策**：
- 开始以为能做很大，最后发现只能做很小的生意
- 设计模式/定价/渠道效率极低，最后发现因为误判了用户需求
- 想做一个业余兼职，产品设计转化率很差，最后发现需求太泛了
- 没有产品分析能力的人，乍一听都挺好，但一分析全有硬伤

## 二、先对齐姿势：别在名词概念里纠缠

**需求名词大杂烩**：强需求、弱需求、真需求、假需求、伪需求、刚性需求（经济学概念）、软性需求——除了"刚性需求"在经济学中有基本定义，其余都很难简单解释清楚

**一堂的核心态度**：**回归问题本身，避免概念纠缠**
- 就用最基础、最直接、最朴素的方式思考：**你究竟要解决什么问题？**
- Truman金句：「做课越多，我越发现一个问题：多数时候，越基础的问题，往往越重要。」

## 三、需求探索的三大价值

**价值①：选择题（尽早验证/证伪，低成本试错）**
- 有些项目本身人群需求很弱、天花板很低、需求不稳定，注定很难做
- 如果能在第一天、不花钱就拿到答案，就能最高效地用五步法做业务

**价值②：设计题（全面提升所有决策质量）**
- 当对人群/画像/场景/用户分层/规模理解越清晰，后面所有决策质量随之提升
- 影响范围：产品设计、定价、选址、探渠道、做品牌……

**价值③：数学题（形成笃定，理解业务空间）**
- 创业一直背着一个定时炸弹的感觉太难受了
- 提前研究市场和需求，形成对用户问题和天花板的笃定 → 管理心态从容很多

## 四、核心框架：需求分析六段位

**六段位总览**：

| 段位 | 名称 | 典型能力 | 核心动作 |
|:---|:---|:---|:---|
| L1 | 模糊理解 | 我一定行 | 只谈我有什么、只谈初心概念、想服务所有人 |
| L2 | 主动拆解 | 我能拆解 | 会有效对标、识别出差异性、剥离出非用户 |
| L3 | 定性可行性 | 我能分析 | 能细拆解用户、推演使用场景、定性三维评估（普遍性/频次/刚性）、会交叉验证 |
| L4 | 定量天花板 | 我能估算 | 会估算规模（自下而上/自顶向下/行业报告交叉验证） |
| L5 | 全局决策 | 我能匹配 | 需求产品匹配、需求商业匹配、需求增长匹配 |
| L6 | 动态预测 | 我能预判 | 短期规模变化、中期竞争变化、长期市场变化、专业需求取舍 |

**段位地图三原则**：①入门快速完成 ②L6无法达成 ③中间循序渐进

## 五、训练工具：需求分析四字诀

**口诀**：**拆、推、评、算**——从简单到复杂，从定性到定量

| 字诀 | 训练目标 | 核心价值 |
|:---|:---|:---|
| **拆** | 训练拆解用户需求的意识 | 这是基本功——会拆，就不会"想服务所有人" |
| **推** | 训练推演用户使用场景 | 理解问题——进入用户视角，推演真实场景痛点 |
| **评** | 训练定性评估需求可行性 | 判断价值——普遍性/频次/刚性三维评估 |
| **算** | 训练定量估算市场大小 | 理性思考——知道自己手里的牌是大牌还是小牌 |

**使用原则**："拆推评算"是工具组合，不是严丝合缝的工作流——可以在某一步得到答案或证伪就结束，也可以跳步，不一定需全部完整执行

**拆的终极原则**：拆到证伪，拆到高效——不是无限细化，时刻记得需求分析的价值要么是证伪，要么是足够高效

## 六、案例推演：移动充电桩项目的六段位演进

**项目设定**：共享充电服务——相对于"固定充电桩"和"换电"方案的第三类创新方案："移动充电桩"。车主线上预约，立刻享受充电服务。出行领域10年背景，凑了几百万启动资金。

---

### 第一位同学 Leo · L1水平（5-10分）

**动作**：搜集信息 → 发现三大痛点：物业装不了 / 价格贵 / 应急充电难 → 结论"痛点极为明确，需求特别刚，市场至少100亿"

**致命问题**：证实性判断——全是优点，用户疼，市场大，增速快
- 需求分析是一个严谨的科学论证过程，而不是一个"证实报喜"的自我安慰
- 如果只停在这个阶段，会给后面所有产品设计、商业模式、增长埋下大坑

---

### 第二位同学 Joe · L2水平（30分）

**动作**：主动拆解 → 按物业角度拆（普通小区/高端小区/商场/公共楼）、按位置拆（地面/地下/立体）、按规模拆（小/中/大）、按人群拆（日常充电/应急充电）

**进步**：能避免基础错误——砍掉了很多选项（普通小区、地面停车场、立体停车场、小停车场），决策效率大幅提升
**不足**：太糙，只有基本简单的拆解和取舍，对具体分析不够

---

### 第三位同学 Tom · L3水平（60分）

**动作**：深度推演真实使用场景 → 区分两类完全不同场景（日常vs应急）→ 画用户体验地图 → 推演物业内部决策链 → 分离出4组商业模型（办公楼日常/应急、商场日常/应急）→ 按普遍性/频次/刚性三维排序

**关键发现**：这些场景不能同时用一个解决方案满足，需要二选一或做两套流程
**评价**：相对不错，能比较细颗粒度理解用户场景和痛点

---

### 第四位同学 Jason · L4水平（70分）

**动作**：定量估算天花板——三种方法交叉验证
- **自下而上**：物业数量×入驻率×平均设备数量×单套收入 = 200亿（→砍掉非目标场景→5-10亿）
- **自顶向下**：10年预期保有量×充电费用×共享占比 = 100亿
- **行业报告**：全球充电桩市场×中国占比×移动充电占比 = 60亿

**关键认知**：知道手里的牌是大牌还是小牌很重要，可以辅助做更多决策

---

### 第五位同学 Peter · L5水平（80分）

**动作**：全局匹配——不同需求对应完全不同的产品内核/商业模型：
- 应急：充电快、确定性高、充电x%够应急就行
- 日常：便宜、需要充满、高稳定性可用、不能久等
- 不同价格带/付费方式/服务方式/毛利和回本周期完全不同

**评价**：能站在全局角度理解商业，完成各环节匹配

---

### 第六位同学 Jay · L6水平（动态预测）

**动作**：从短期/中期/长期动态视角理解业务变化
- **短期**：冷启动投放密度——3-5个充电车不够，投放密度超X%才能独立闭环
- **中期**：全国40+企业竞逐，特斯拉/宁德时代/国轩高科已入局；部分城市明确政策补贴
- **长期**：电动车和充电桩趋势有利，电池和充电技术变化影响解决方案

**核心判断**：综合动态看，这是一个3-5年的快速生意，还是一个10-20+年的长期生意？越做越好做还是越做越难做？

## 七、三次能力飞跃与自我修养

### 第一次飞跃：从模糊到拆解

**飞跃前**：只谈我有/初心/想服务所有人
**飞跃后**：会有效对标、识别差异性、剥离出非用户
**核心基本功**：**「拆」**——两个建议 + 两个拆解原则
- 原则一：拆到证伪，拆到高效
- 原则二：最大差异化 / 最小颗粒度——拆出内部矛盾，才能做取舍

### 第二次飞跃：从简单到专业

**飞跃前**：有基础拆解但太糙
**飞跃后**：会用多工具做专业分析——推演使用场景 + 定性三维评估 + 交叉验证 + 估算规模
**核心基本功**：**「推 + 评 + 算」**——进入用户视角和决策现场

### 第三次飞跃：从局部到全局

**飞跃前**：单次评估，局部最优解
**飞跃后**：全局战略思考 + 动态调整——不断站在短期/中期/长期角度预判市场变化
**核心基本功**：**「动态预测」**——这是高阶能力，L6无法真正达成，只能无限逼近

## 八、常见需求评估维度

**定性三维评估框架**：
- **普遍性**：多少人会有这个问题？
- **频次**：一生/年/月/周/日/时发生几次？
- **刚性**：可用可不用？免费才用？哪怕付费/加钱也非用不可？

**伪需求判断**：看似有需求，但经不起使用频次、用户体验及使用依附性的考验——频次很低，刚性很弱

**程浩四象限框架**（高频×刚需）：
- 高频+刚需 = 最佳战场
- 高频+非刚需 = 可培养习惯
- 低频+刚需 = 知名但难做大
- 低频+非刚需 = 最差组合

## 九、课程收尾：重新理解「需求原点」

**核心信念**：
- 需求分析是发现**客观事实**，而不是创造事实——臆测需求的情况太多，很多人都在泛泛而谈
- 需求是五步法的第一步，也是**商业的原点**——原点分析越清楚，后面决策质量越高
- 在创业开始，对目标用户的理解往往是模糊的、定性的——但持续理解用户是每个CEO必须持续做的事

**修炼路径**：回到真实场景 → 理解真正问题 → 慢慢定量 → 慢慢精确 → 慢慢清晰 → 把自己和公司都变得通透

**最后的关键词**：实事求是——用关键假设的方式，先拆解，再一步步验证。没有关键假设的创业，就是一个空壳

**Truman的提醒**：需求分析，永无止境

## 十、五步法完整课程关系

```
一堂五步法：商业里程碑管理
│
├─ 第一步：需求（问题存在，的确需要解决？） ★ 本课所在
│   └─ 研究客观问题
│
├─ 第二步：解决方案（价值成立，可以解决问题？）
│   └─ 完成从0到1
│
├─ 第三步：商业模式（商业成立，可以模式跑通？）
│   └─ 完成从1到10
│
├─ 第四步：增长（持续获客，完成增长？）
│   └─ 构建增长模型
│
└─ 第五步：壁垒（预判壁垒，形成竞争优势？）
    └─ 占领稀缺资源
```
