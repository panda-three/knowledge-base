> L6 级别清单体笔记 ｜ 主讲：周子敬（以太创服合伙人）

## 一、顶层判断：2 个根本问题——「能不能」与「要不要」

在动手融资前，先回答两个前置问题。答错了，后面全错。

### 1. 能不能融资？

| 维度 | 硬门槛 |
|---|---|
| 赛道 | 市场天花板够大，投资人退出路径清晰 |
| 阶段 | 种子/天使看团队，A轮看数据，B轮看增长模型 |
| 壁垒 | 至少在一个维度上有「别人抄不走」的东西 |
| 团队 | 创始人对业务的思考深度，投资人一眼能看穿 |

**一句话判断**：如果你的业务拿到钱和拿不到钱，三年后的结局差不多，那你就不该融资。

### 2. 要不要融资？

- 不是所有好生意都需要融资。
- 融资的本质是用股权换时间，不是用股权换生存。
- 如果现金流健康、增长可控，自造血比稀释股权更划算。
- 如果窗口期极短、需要抢市场、需要建立壁垒，融资是合理杠杆。

## 二、融资全流程：3 大环节一张图

```
掌握基础（Know-Why）→ 对内梳理（Know-What）→ 对外展示（Know-How）
```

三大环节，缺一环都是赌博：

| 环节 | 核心任务 | 交付物 |
|---|---|---|
| **掌握基础** | 理解VC怎么想、融资本质是什么 | 融资认知框架 |
| **对内梳理** | 把业务讲清楚，天花板算明白 | 业务梳理 + 数据 + 团队故事 |
| **对外展示** | 一句话、BP、路演、约见、谈判 | BP + 安利文 + 路演能力 |

## 三、知己：拿钱的 7 个必经之路

创业者视角的融资 SOP，不允许跳步：

| 序号 | 步骤 | 一句话说明 |
|---|---|---|
| 1 | **融资决策** | 先确认「能不能、要不要」 |
| 2 | **业务梳理** | 你不把业务想清楚，投资人替你想 |
| 3 | **材料准备** | 一句话介绍 → 安利文 → BP |
| 4 | **机构筛选** | 不是所有钱都叫好钱 |
| 5 | **投资人约见** | 第一天就要奔着成交去 |
| 6 | **路演 & 沟通** | 讲故事 + 回应质疑 = 建立信任 |
| 7 | **条款谈判 & 交割** | 不只看估值，更要看条款 |

## 四、知彼：VC 投你的内部工作流程

你以为投资人是「看一眼就决定」，实际上机构内部有一套完整流程：

```
项目源 → 分析师初筛 → 投资经理访谈 → 合伙人面谈 → 投决会表决 → TS → DD → 交割
```

关键洞察：

- 每个环节都在淘汰项目，你必须在每一关都给出「继续往下推」的理由。
- 投资经理是你的第一个守门人，不要跳过 TA 直接堵合伙人。
- 投资决策是集体行为，你每一次出现都在为「投决会上的辩护者」提供弹药。

## 五、融资筹备自检清单

见投资人之前，对照这份清单逐个过：

### 5.1 思考层

- [ ] 我为什么需要这笔钱？（不是「为了活下去」，而是「为了更快做到什么」）
- [ ] 我这轮融资的合理金额是多少？（不是越多越好）
- [ ] 我现在处于什么阶段？（种子/天使/A轮，不同轮次不同打法）
- [ ] 我上一轮的里程碑完成了吗？（没完成就融下一轮，投资人会问）

### 5.2 业务层

- [ ] 一句话说清业务（见第七节）
- [ ] 天花板算过吗？（TAM / SAM / SOM）
- [ ] 商业模式画布画过了吗？
- [ ] 核心数据能脱口而出吗？（用户数、收入、增速、留存、复购、单位经济模型）
- [ ] 竞争对手是谁？为什么是你赢？

### 5.3 团队层

- [ ] 为什么是我？为什么是这个团队？
- [ ] 创始团队的故事线清晰吗？
- [ ] 股权结构合理吗？（有没有明显的坑）

### 5.4 材料层

- [ ] 一句话介绍写好了吗？
- [ ] 安利文写好了吗？
- [ ] BP 不仅做了，而且经过至少 3 轮打磨了吗？

## 六、投资人常问问题清单

投资人的问题不是随机的。**所有问题都在验证一件事：你的增长模型是否成立，你这个人是否可信。**

| 类别 | 高频问题 |
|---|---|
| **市场** | 这个市场有多大？为什么现在是正确时机？ |
| **产品 & 模式** | 你解决了什么痛点？商业模式怎么跑通？复购/续费率多少？ |
| **竞争** | 谁是你的竞争对手？你和他们本质区别是什么？ |
| **增长** | 过去 6 个月的增长驱动是什么？下一步怎么放大？ |
| **团队** | 为什么是你们？核心团队怎么走到一起的？ |
| **财务** | 钱怎么花？下一个里程碑是什么？需要多少时间？ |
| **风险 & 终局** | 最大的失败可能是什么？这个生意的终局是什么样？ |

> 推荐应对策略：「投资人不是在找正确答案，而是在找逻辑一致、深度思考的创始人。」

## 七、一句话介绍：融资第一张名片

### 7.1 为什么重要

- BP 可能没人打开，但一句话介绍一定会被看到。
- **微信转发、邮件标题、当面开口的第一句，就是这句话。**
- 投资人在 3 秒内决定「继续聊」还是「礼貌结束」。

### 7.2 公式

```text
我们帮助【目标用户】，通过【核心方法】，解决【关键痛点】，
实现【可量化价值】，已经做到【关键数据】。
```

### 7.3 参考案例

| 类型 | 示例 |
|---|---|
| 平台型 | 我们是 XX 领域的美团，连接 X 与 Y，目前月交易额已到 Z 万 |
| SaaS | 帮助企业解决 XX 效率问题，ARR 已达 Y 万，续费率 Z% |
| 消费品 | 新一代 XX 品牌，复购率 Y%，单月 GMV 已破 Z 万 |

> 28 个一句话介绍案例 → 参考课程附带的《案例集：28 个一句话介绍》

## 八、梳理业务的 3 个核心难点

这是训练营 2 的核心内容，也是创业者最容易「自欺欺人」的地方。

### 难点 1：项目到底在做什么——讲清商业模式

- 不用复杂术语，**让你妈也能听懂你在做什么**。
- 工具：商业模式画布（课程提供）。
- 核心检验：「用户是谁 → 你给他什么 → 他怎么给你钱 → 你花多少钱获得他 → 为什么他会一直用/买」。

### 难点 2：项目能做多大——估算天花板

- 「这是一个千亿市场」是废话。
- 分层计算：TAM（总市场）→ SAM（可服务市场）→ SOM（可获取市场）。
- 天花板不是拍脑袋，而是**从定价、用户基数、复购频率倒推**。
- 参考课程附带的《往期天花板计算优秀作业集》+《100 行业数据/分析报告》。

### 难点 3：为什么你能做成——讲清团队

- 不是写简历，而是回答：「为什么是你们，不是别人？」
- 团队故事线：过去经历 → 发现机会 → 决定创业 → 凭什么比别人做得好。
- 投资人投的是「不可替代性」，不是「优秀」。

## 九、准备一份好的 BP

### 9.1 好 BP 的 4 个标准

| 标准 | 说明 |
|---|---|
| **逻辑自洽** | 从痛点到方案到增长，是一条完整的因果链 |
| **数据诚实** | 不注水，投资人一眼能看出水分 |
| **故事有力** | 让对方在 5 分钟内理解并记住你 |
| **格式专业** | 不花哨，但信息密度高、关键数字醒目 |

### 9.2 BP 必备页面

1. 一句话定位
2. 痛点 & 方案
3. 市场机会
4. 商业模式
5. 竞品分析
6. 核心数据 & 增长
7. 团队介绍
8. 融资需求 & 用款计划

### 9.3 常见错误

- 把 BP 写成产品说明书（×）
- 每一页都塞满文字（×）
- 没有给出「为什么是现在」（×）
- 竞品分析写成「我们没有竞争对手」（×）
- 用款计划写成「用于公司运营」（× —— 太模糊）

> 工具：课程附带《BP 格式和美化工具箱》《部分行业 BP 模板》《Airbnb 完整案例解读》

## 十、如何增加资本约见

**投资人不缺项目，缺的是「值得花时间」的理由。**

### 10.1 高效对接 VC 的渠道优先级

1. **老股东/老投资人引荐** → 最高转化率
2. **被投企业创始人推荐** → 第二高
3. **FA 机构合作** → 覆盖广，但需要筛选（课程附带 FA 机构清单）
4. **精准邮件** → 不是群发模板化邮件，而是认真研究对方机构的投过什么
5. **公开路演/创业大赛** → 适合增加曝光，但成交率有限

### 10.2 安利文撰写 4 个核心

- **第一段**：一句话说清你是谁（呼应第七节）。
- **第二段**：为什么这件事值得做（市场机会 + 时机）。
- **第三段**：你已经做到了什么（关键数据，不是感受）。
- **第四段**：你需要什么 + 这轮融资后你会变成什么。

> 课程附带《投资机构邮箱清单》《FA 机构清单》和《风声 FA 榜单》

## 十一、如何在路演中抓住机会

### 11.1 路演前

- 把 BP 脱稿讲 20 遍，直到每一个数字都能自然说出。
- 提前准备好 20 个可能被问到的问题和简短回答。
- 了解这个投资人的背景和 TA 已经投过的项目。

### 11.2 路演中

| 要点 | 说明 |
|---|---|
| **前 30 秒定生死** | 一开始就说最让人记住的事 |
| **逻辑 > 激情** | 激情是加分项，但逻辑漏洞是致命项 |
| **直面质疑** | 被挑战时，先承认价值，再说你的思考 > 防御性反应 |
| **留白** | 别把 30 分钟全讲满，留时间给投资人对你提问 |
| **结束 3 要素** | 总结核心 → 明确下一步 → 让对方记住你是谁 |

### 11.3 路演后

- 24 小时内发感谢信 + 补充材料（不是群发模板）。
- 约见不是结束，是开始：定期更新进展，给投资人持续的信心。

> 课程附带《合伙中国人》精彩案例拆解，以及两个真实融资路演案例（无人机自动巡飞系统 / 私有云企业网盘）。

## 十二、融资的底层逻辑：投资人到底在投什么

这不是讲「技巧」，而是讲「本质」。

### 12.1 投资人的 7 个底层投资逻辑

| 逻辑 | 一句话解释 |
|---|---|
| 1. 只投确定性增长 | 资本不赌梦想，只赌已验证的增长信号 |
| 2. 要可复制的生意 | 轻资产、标准化、高杠杆 = 能快速放大 |
| 3. 没有壁垒不重仓 | 技术/网络/品牌/规模，至少有一项 |
| 4. 团队 > 模式 > 项目 | 人是第一变量 |
| 5. 专注 > 发散 | 把一件事做到极致比什么都碰更值钱 |
| 6. 行动 > 模型 | 只有 PPT 没有执行 = 零 |
| 7. 拿适量钱 | 钱太少扛不住；太多稀释过度，后面没钱追投 |

### 12.2 融资的终极公式

```text
融资成功率 = 业务质量 × 创始人思考深度 × 时机匹配度 × 接触规模
```

- **业务质量**：数据要硬，逻辑要通。
- **思考深度**：投资人一眼能看出你在这个事情上花了多少心。
- **时机匹配度**：行业热度 × 基金手上有没有钱 × 你的轮次。
- **接触规模**：见一个不成是正常的，见 30 个不成才需要反思。
