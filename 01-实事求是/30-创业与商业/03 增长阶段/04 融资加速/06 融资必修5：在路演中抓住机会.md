# 融资必修5：在路演中抓住机会

> L6 级别清单体笔记 ｜ 主讲：周子敬（以太创服CEO）
> 训练营5 · 一堂融资系列课

## 一、课程定位：约见搞定了，下一步是路演中拿下机会

```text
路演不是汇报工作，不是演讲比赛，不是产品演示。
路演的本质，是在有限时间内让投资人建立对你的信任。
```

融资必修1-4 完成了四件事：认知地基 → 业务梳透 → 写出 BP → 撬开约见。融资必修5 解决的是融资流程中**最关键的一步——见面之后怎么赢。**

| 维度 | 本课回答的问题 |
|---|---|
| 路演前 | 见投资人之前，必须准备好哪五件事？ |
| 开场 | 前30秒怎么说才能让投资人放下手机？ |
| 讲述 | 怎么把BP变成一个有说服力的口头故事？ |
| 应对质疑 | 投资人挑战你的时候，怎么接住、转化、反杀？ |
| 收尾 | 怎么结束才能让投资人想继续推进？ |
| 跟进 | 路演结束后24小时内必须做什么？ |

**一句话定调：**

```text
融资路演是创始人最重要的销售时刻。
你卖的不仅是公司，更是你这个人的判断力、诚实度和抗压能力。
```

## 二、路演的本质：三件事比「讲得好」更重要

### 2.1 路演不是演讲

很多创始人把路演当成 TED 演讲来准备：背稿子、练台风、做炫酷 PPT。但投资人的判断逻辑不是「他讲得真好」，而是：

| 投资人在路演中真正判断的三件事 | 含义 |
|---|---|
| **你这个人靠不靠谱** | 对业务的思考深度、面对质疑的反应、是否诚实 |
| **你的逻辑是否自洽** | 从痛点到方案到增长，有没有明显的因果断裂 |
| **你是不是那个能把这件事做成的人** | 有没有不可替代的认知、资源或执行能力 |

### 2.2 一场路演的投资人心理时间线

```text
前30秒：这个人值不值得我认真听 → 决定放下手机还是敷衍
前3分钟：这个方向有没有道理 → 决定继续深聊还是礼貌结束
前10分钟：这个增长逻辑是否成立 → 决定推进还是婉拒
最后5分钟（Q&A）：这个创始人面对挑战时什么样 → 最终判断
```

**核心洞察**：

```text
你不需要在路演中「完美无缺」。
但你必须在每一个阶段，给出投资人继续往下听的理由。
```

## 三、路演前的准备：五件事不做完，不要见投资人

### 3.1 准备一：把BP脱稿讲 20 遍

这是最朴素、最容易被跳过、也最重要的一条。

| 遍数 | 目标 |
|---|---|
| 1-5 遍 | 熟悉逻辑流，找到哪几页衔接生硬 |
| 6-10 遍 | 每个关键数字能自然说出，不用看PPT |
| 11-15 遍 | 能根据投资人表情调整节奏，哪个地方对方皱眉就多解释一句 |
| 16-20 遍 | 达到「像在聊天而不是在背稿」的自然度 |

**检验标准**：找一个人，关掉投影仪，你对着他空白讲一遍 BP。如果关键数字、逻辑推导、团队故事都能自然说出，这 20 遍才算过了。

### 3.2 准备二：预判 20 个被问概率最高的问题

投资人问的问题不是随机的。课程梳理了高频问题库：

| 类别 | 高频问题 | 你该准备什么 |
|---|---|---|
| **市场** | 这个市场到底多大？为什么是现在？ | 天花板数据 + 「为什么是现在」的一个具体信号 |
| **竞争** | 谁是你真正的竞争对手？ | 直接竞品 + 间接替代方案 + 你的差异化 |
| **壁垒** | 为什么别人抄不了你？ | 技术/网络/品牌/规模，至少一项有证据 |
| **增长** | 增长从哪来？天花板在哪？ | 过去增长的驱动因素 + 未来增长的具体路径 |
| **团队** | 为什么是你们？ | 不可替代性故事线 |
| **财务** | 钱怎么花？下一个里程碑？ | 用款计划 + 里程碑数字 |
| **风险** | 最大的失败可能是什么？ | 诚实说出风险 + 应对方案 |
| **估值** | 为什么是这个估值？ | 同赛道可比公司数据 + 你的增速溢价 |

**准备方法**：把每个问题的回答压缩到 30 秒以内，写下来，对着镜子讲 5 遍。

### 3.3 准备三：研究坐在你对面的投资人

```text
千万不要对每个投资人讲完全相同的路演。
```

课前必查清单：

| 必查信息 | 怎么查 | 怎么用 |
|---|---|---|
| TA 投过什么项目 | 公开资料 / 创投数据库 | 路演中提一句：「我注意到您之前投了 XX，我们在这个维度上有相似逻辑」 |
| TA 的赛道偏好 | 看 TA 最近 2 年的投资组合 | 如果你的业务恰好是 TA 关注的赛道，重点讲 |
| TA 的基金规模和阶段 | 公开信息 | 天使基金问 A 轮问题 = 不匹配，提前判断是否值得花时间 |
| TA 在哪些项目上赚了钱 | 关注 IPO/并购案例 | 了解 TA 的退出逻辑，判断 TA 对你的期望值 |

### 3.4 准备四：设计一个「前 30 秒开场」

```text
前30秒决定投资人会不会放下手机认真听。
```

**错误的开场**：

- 「大家好，我是 XX 科技的创始人张三……」（信息量为零）
- 「首先感谢大家今天来听我的路演……」 （浪费时间）
- 「我先介绍一下我们公司的背景……」 （太慢热）

**正确的开场**：一句话介绍 + 一个让投资人产生好奇的数据或事实。

| 类型 | 示例 |
|---|---|
| 数据冲击型 | 「我们帮中小电商用 AI 替代 50% 人工客服，续费率 92%，这是一个 500 亿的市场。」 |
| 痛点共鸣型 | 「你知道每年有 30 万家中小企业因为客服成本过高而倒闭吗？我们解决了这个问题。」 |
| 增长震撼型 | 「过去 12 个月，我们的用户数从 0 涨到了 50 万，而且没有花一分钱做广告。」 |
| 类比锚定型 | 「我们是母婴领域的拼多多——连接 200+ 品牌和 50 万宝妈，月交易额已破千万。」 |

### 3.5 准备五：明确路演的「一个核心信息」

```text
一场路演结束后，投资人最多记住一件事。
你要主动设计这件事是什么。
```

| 项目类型 | 建议的核心信息 |
|---|---|
| 平台型 | 「双边网络效应已经启动，冷启动做完了」 |
| SaaS | 「续费率 92%，LTV/CAC > 5，模型已经跑通了」 |
| 消费品 | 「复购率 35%，不是靠投放堆出来的」 |
| 技术驱动 | 「这个技术壁垒至少领先行业 18 个月」 |

**检验标准**：路演结束后 5 分钟，问任何一个听众「你记住了什么」，如果 TA 说不出你设计的核心信息，说明路演不够聚焦。

## 四、路演中的沟通：每个阶段都在建立或摧毁信任

### 4.1 阶段一：开场的黄金 30 秒

```text
投资人在路演开始的前 30 秒，就在做一个决定：
这个人值不值得我认真听完。
```

| 要点 | 怎么做 |
|---|---|
| **第一句就是核心信息** | 不要铺垫、不要自我介绍、不要感谢。开口第一句就让人想听下去 |
| **速度适中，不赶** | 紧张时人容易加速。第一句说完，停顿一秒 |
| **看投资人眼睛，不看你背后的屏幕** | 背对投资人念PPT = 最差的路演姿势 |
| **一句话说清你是谁** | 在核心信息之后，紧接一句话介绍（融资必修3&4的公式） |

### 4.2 阶段二：讲故事的「三明治法则」

用「三明治法则」组织路演主体内容：每一段都是**结论先行，再给论据**。

```text
结论 → 论据 → 小结
 ↓       ↓       ↓
「我们做到了X」→「怎么做到的 / 数据支撑」→「所以这意味着Y机会」
```

**正面对比**：

| 错误讲法（平铺直叙） | 正确讲法（结论先行） |
|---|---|
| 「我们的产品有A功能、B功能、C功能……用户反馈还不错……」 | 「我们的续费率是92%。为什么能做到？因为三个核心设计：第一……第二……第三……所以客户一旦用了就不会走。」 |
| 「这个市场很大，根据XX报告……」 | 「这是一个500亿的市场，而且是高度分散的——前五名加起来不到15%。这意味着谁先跑通标准化模型，谁就有机会吃掉大部分份额。」 |

### 4.3 阶段三：被挑战时的「三不三要」原则

这是本课最核心的实操模块。投资人挑战你，不是在否定你——而是**在测试你**。

| 三不 | 说明 |
|---|---|
| **不要防御** | 被质疑第一反应不是「你不懂」或「我解释一下」——哪怕心里这么想，表情和语气不能防御 |
| **不要硬扛** | 如果问题确实指出了你的盲区，不承认比硬扛更致命 |
| **不要绕弯** | 投资人问A你答B，是消耗信任最快的方式 |

| 三要 | 说明 |
|---|---|
| **先接住** | 「这是一个很好的问题。」「谢谢，这个问题确实很关键。」——不是客套，是给自己1-2秒整理思路 |
| **再展开** | 直接回答问题的核心，不绕弯、不铺垫。如果答不上来，就说「这个我们还在探索，目前我们的思路是……」 |
| **最后回到你的核心信息** | 不管什么问题，回答完之后都找机会回到你设计的核心信息上 |

**示例：被质疑「你有什么壁垒？」**

```text
错误的回答（防御型）：
「我们的壁垒很多。我们的技术很强，团队也很优秀，而且我们已经有了先发优势……」

正确的回答（先接住再展开）：
「这是一个很好的问题。（接住）
目前我们的壁垒主要体现在两个方面：第一，我们积累了50万用户的交易数据，用于训练推荐模型，新进入者没有这个数据量；第二，我们已经和上游200+品牌签了独家合作协议，这是时间和信任积累出来的。
坦白说，这两个壁垒都不是永久性的。所以我们这轮融资的核心，就是把数据优势进一步转化为规模优势和品牌心智。（诚实 + 回到核心信息）」
```

### 4.4 阶段四：收尾的「3 要素法则」

路演结束时的最后 2 分钟，决定了投资人会不会继续推进。

| 要素 | 内容 | 禁忌 |
|---|---|---|
| **总结核心** | 用一句话重复你今天最想让 TA 记住的事 | 不要引入新信息 |
| **明确下一步** | 「我们这轮融资 500 万，目前已经有 1 家机构给了 TS，我们希望在未来 2-3 周内确定领投方。」 | 不要以「谢谢大家」直接结束 |
| **让对方记住你是谁** | 再次说出你的名字和项目名，因为投资人每天见太多创业者 | 不要假设TA一定记住了 |

## 五、路演后的跟进：24 小时黄金窗口

### 5.1 路演结束后立刻做三件事

| 序号 | 行动 | 说明 |
|---|---|---|
| 1 | **当场记录** | 退出会议室后立刻用手机记下：投资人问了什么问题、TA 对哪个环节最有兴趣、TA 有什么顾虑。不要等晚上再回忆，会忘 50%。 |
| 2 | **评估投资人是真的感兴趣还是客气** | 真兴趣信号：TA 主动问了你的融资时间表、主动提出要见团队其他成员、主动问了条款偏好。客套信号：TA 说「挺有意思的，我们内部讨论一下」但没有追问具体问题。 |
| 3 | **24 小时内发跟进消息** | 见第七节。 |

### 5.2 跟进消息的模板

```text
标题：感谢今天的交流 + 项目名

正文：
XX总您好，感谢您今天抽出时间听我们的路演。

针对您今天提到的[某个具体问题]，我补充了一些数据/思考：
[简短解答]

我们这轮融资[金额]，目前[进展状态]。
如果您有兴趣继续深入交流，我们下周[具体时间]可以安排一次更详细的业务探讨。

附上今天的BP和安利文，方便您回顾。

[名字] | 手机 + 微信
```

**关键要点**：

- 必须提到「投资人今天具体问了什么」——证明你在认真听，不是在群发模板。
- 给出一个具体的下一步，而不是「希望有机会再聊」。
- 如果投资人在路演中问了负面问题（比如质疑数据），在跟进消息里直面回答，而不是假装没发生过。

### 5.3 投资人没回复时的节奏控制

| 时间点 | 行动 |
|---|---|
| 跟进消息发出后第 3 天 | 如果没回复，再发一条简短消息，更新一个好消息（新客户、新数据里程碑、媒体报道），保持曝光但不催促 |
| 跟进消息发出后第 7 天 | 如果仍没回复，可以发最后一条：「XX总，我知道您这边比较忙。如果本轮时机不合适，希望未来有机会合作。我会定期给您更新我们的进展。」 |
| 之后 | 不再主动追问是否投资。但每 1-2 个月发一次进展简报（不是催融资，而是建立长期印象） |

## 六、经典案例拆解

### 6.1 《合伙中国人》案例的五个关键洞察

课程配套了《合伙中国人》精彩案例拆解。从这档真实创投节目中可以提炼五个核心教训：

| 洞察 | 案例表现 | 教训 |
|---|---|---|
| **逻辑漏洞是致命项** | 创业者说不清「为什么用户选你」，投资人当场失去兴趣 | 路演前必须把商业模式和竞争差异的每个环节自查一遍 |
| **数据诚实决定信任** | 有创业者注水数据被当场揭穿，场面无法挽回 | 投资人的圈子很小，一个谎言会毁掉所有机会 |
| **防御反应是减分项** | 被质疑时立马挡回去的创始人，投资人都给了低评价 | 「先接住再展开」的反应模式需要刻意练习 |
| **情绪控制是隐形考题** | 有创始人在被追问时明显慌乱，逻辑断掉 | 事先把20个高频问题的回答练到肌肉记忆级别 |
| **坦诚面对短板是加分项** | 有位创始人被问「你最弱的一环是什么」，坦率回答并给出补位方案，反而获得认可 | 完美人设不可信，「知道自己的短板并且知道怎么补」最加分 |

### 6.2 融资路演真实案例：无人机自动巡飞系统

课程配套了完整的路演案例复盘。该项目的路演有两个关键亮点：

- **技术壁垒的展示方式**：不用复杂术语，而是用「我们的系统已经完成了XX次飞行任务，零事故率」让投资人瞬间理解技术可靠性。
- **市场规模的非典型论证**：没有引用通用报告，而是从「巡检市场人工成本倒推」算出了真实可替代空间。

### 6.3 融资路演真实案例：私有云企业网盘

课程配套的另一个完整路演案例。亮点在于：

- **竞争格局的差异化表述**：面对巨头，项目没有说「我们比巨头更好」，而是说「我们在巨头看不上的细分场景里，做到了他们做不到的深度」——这是投资人能听进去的逻辑。
- **团队背景的非简历式讲述**：创始团队没有列履历，而是讲述了他们为什么在这个行业深耕了8年，以及他们看到了什么别人没看到的机会。

## 七、融资必修1-5 系列完整知识地图

```text
融资认知（前置课）→ 搞懂融资的底层逻辑
     ↓
融资必修1 → 掌握了融资必备的认知地基
     ↓
融资必修2 → 把业务梳透了：商业模式、天花板、团队
     ↓
融资必修3 → 把梳理好的内容写成了一份合格的 BP
     ↓
融资必修4 → 用 BP + 安利文撬开了投资人的门
     ↓
融资必修5 → 在路演中把信任建立起来，把机会抓到手
```

## 八、路演全流程自检清单

### 8.1 路演前

- [ ] BP 脱稿讲了至少 15-20 遍，每一遍都能流畅说出关键数字
- [ ] 预判了 20 个高频问题，每个问题的回答压缩在 30 秒以内，并写下来练过
- [ ] 研究了今天这位投资人的背景：投过什么、赛道偏好、基金规模
- [ ] 设计了前 30 秒的开场：一句核心信息 + 一个让人好奇的数据
- [ ] 明确了你最想让投资人记住的「一个核心信息」
- [ ] 检查了路演环境（投影、翻页笔、时间提醒）

### 8.2 路演中

- [ ] 开场 30 秒内说出了核心信息，没有铺垫、没有废话
- [ ] 用了三明治法则：结论 → 论据 → 小结，而不是平铺直叙
- [ ] 被质疑时先接住了问题，再展开回答，没有防御反应
- [ ] 对答不上的问题坦诚说「还在探索」，并给出目前的思考方向
- [ ] 收尾时总结了核心信息 + 明确了下一步 + 让对方记住了你是谁
- [ ] 没有超时

### 8.3 路演后

- [ ] 退出会议室后立刻记录了投资人关注点和顾虑点
- [ ] 24 小时内发了跟进消息，消息里提到了投资人今天的具体关注点
- [ ] 建立了后续跟进节奏（第3天 → 第7天 → 长期进展简报）

## 十、核心记忆点（30 秒回顾）

```text
1. 路演不是演讲，是建立信任。投资人判断三件事：人靠不靠谱、逻辑是否自洽、你是不是对的人。
2. 路演前五准备：脱稿20遍、预判20个高频问题、研究投资人背景、设计前30秒开场、明确一个核心信息。
3. 前30秒定生死：第一句就是核心信息，不铺垫、不感谢、不自我介绍。
4. 三明治法则：结论 → 论据 → 小结，每一段都让人先知道你的判断再听证据。
5. 被挑战三不三要：不防御、不硬扛、不绕弯；先接住、再展开、回到核心信息。
6. 最致命的错误：数据注水、防御反应、被指出逻辑漏洞时死不承认。
7. 路演后24小时发跟进消息，必须提到投资人今天的具体关注点。
8. 坦诚面对短板是加分项，完美人设最不可信。
9. 融资系列五课完成：从认知地基到路演抓机会，完整闭环。
10. 路演是创始人最重要的销售时刻——你卖的是你的判断力、诚实度和抗压能力。
```
