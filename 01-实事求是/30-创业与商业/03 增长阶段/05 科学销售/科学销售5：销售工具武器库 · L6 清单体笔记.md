# 科学销售5：销售工具武器库 · L6 清单体笔记

> 课程：科学销售5：销售工具武器库｜讲师：李蕊｜平台：一堂
> L6 标准：不只罗列知识点——拆底层结构、建咬合关系、标常见误区、重构完整武器库体系。

## 一、先看清位置：这节课在五步法中的坐标

### 1.1 一句话定位
**销售工具是科学销售第五步——前面四步（卖点、过程拆解、业绩推进、激励）都是「设计」，这一步是把所有设计落到销售手上能用的武器。没有这一步，再好的设计也停在脑子里。**

李蕊老师在课程里讲得很直白：

> "前面的用户分层、卖点、过程拆解，都只是销售设计而已。再好的销售设计，也需要有地方落地。那怎么落，落到哪里呢？就需要使用我们这节课的重点——「销售工具箱」。"

### 1.2 它在五步全景中的位置

```
科学销售五步法：
A. 提炼卖点 ──→ 对谁说什么
B. 拆解过程 ──→ 在哪个节点用力
C. 推进业绩 ──→ 怎么盯过程、拿结果
D. 激励团队 ──→ 怎么让团队愿意持续打仗
E. 打造销售工具 ← 本节 ──→ 所有设计的落地载体
```

### 1.3 这节课的核心交付

| 交付 | 内容 |
|---|---|
| **一个好工具的审美标准** | 先知道「好工具长什么样」，再动手做 |
| **60→75→85 分三层武器库** | 6 个大类、17 个武器、39 个销售工具，完整覆盖 |
| **打造工具三步法** | 提炼使用 → 培训落地 → 复盘迭代 |
| **三种思维视角升级** | 球员思维 → 裁判思维 → 教练思维 |

## 二、先建立审美：好的销售工具符合什么标准

### 2.1 课程开篇的核心判断

李蕊老师没有一上来就罗列工具清单，而是先建立审美。因为**你不知道「好」长什么样，给你再多模板你也用不好**。

课程提炼了好的销售工具的三个标准：

| 标准 | 含义 | 反面案例 |
|---|---|---|
| **能降低销售的学习门槛** | 小白拿到就能用，不需要口口相传 | 只有老销售脑子里有、新人三个月摸不到门 |
| **能标准化销售的关键动作** | 同一个场景下，不同销售说出来的东西一致 | 每个人讲的都不一样，无法复盘优化 |
| **能随着业务迭代持续升级** | 不是一次写完就锁死，而是活文档 | 工具两年没更新，市场早变了 |

> **L6 解读**：这三个标准本质上在回答同一个问题——**工具到底是给谁用的？** 答案是：给「下一个新销售」用的。如果你的工具只有你自己看得懂、只有老销售会用，它就不是组织资产，只是个人笔记。

### 2.2 为什么「工具是落地载体」——一个底层公式

```text
销售体系化复制 = 卖点 × 过程 × 业绩推进 × 激励  →  全部装进工具里

工具是前面四步的「物化」：
→ 卖点 → 变成话术文档、产品介绍PPT、成功案例集
→ 过程拆解 → 变成节点图、跟进模板、客户档案模板
→ 业绩推进 → 变成日报模板、大项目地图、数据看板
→ 激励 → 变成荣誉榜单模板、PK赛规则、晋升标准表
```

> 没有工具的「物化」，前面四步永远停在「管理者脑子里」，无法变成「销售手上的动作」。

## 三、60→75→85 分三层武器库：全图景

### 3.0 三层分级的逻辑

李蕊老师不是简单地把工具分类，而是按**公司发展阶段**做了梯度分层：

| 分数 | 公司阶段 | 核心目标 | 六维雷达图侧重 |
|---|---|---|---|
| **60分** | 从初期就可以开始做，而且可以精益求精 | 让销售「能开口、有底气」 | 公司有实力 + 话术说人话 |
| **75分** | 已经跑通模型，开始复制销售人员 | 让销售「能独立、显专业」 | 服务很专业 + 销售有能力 |
| **80-85分** | 模型相对稳定，内部资源相对丰富，有比较充分的提炼素材 | 让团队「有效率、能攻坚」 | 团队有效率 + 攻坚有策略 |

> **关键认知**：这不是「60分够用就行」——这是「60分是地基，75分是框架，85分是装修」。不能跳过60分直接建75分工具，就像不能没有地基就盖楼。

### 3.1 销售武器库六维雷达图

```text
            公司有实力
               /\
              /  \
    攻坚有策略    话术说人话
            |      |
    团队有效率    服务很专业
              \  /
               \/
            销售有能力
```

**六维与三层分级的对应关系**：

| 六维 | 60分层 | 75分层 | 85分层 |
|---|---|---|---|
| 公司有实力 | ✅ 基础材料 | — | — |
| 话术说人话 | ✅ 常见话术 | — | — |
| 服务很专业 | — | ✅ 交付物+模板 | — |
| 销售有能力 | — | ✅ 专项技能+专业知识 | — |
| 团队有效率 | — | — | ✅ 信息化+数据 |
| 攻坚有策略 | — | — | ✅ 动作策略+棘手应对 |

## 四、打造工具三步法：从写出来到用起来

### 4.0 课程不仅给了武器库，还给了「怎么打造」的方法

很多同学反馈这节课「不仅传授了工具库，还贴心地加上了第二步和第三步——工具提炼使用，以及复盘迭代」。

### 4.1 三步法全景

| 步骤 | 核心任务 | 关键问题 |
|---|---|---|
| **第一步：提炼使用** | 从销冠和最佳实践中提炼，写出工具初版并投入使用 | 最好的销售在这个环节做了什么？能不能把它写下来？ |
| **第二步：培训落地** | 不只是发文档——要培训 + Role Play + 考核 | 销售真的会用吗？还是只是「收到了」？ |
| **第三步：复盘迭代** | 用实战反馈持续打磨工具，不断升级版本 | 工具用起来之后暴露了什么问题？下一版改哪里？ |

### 4.2 第一步：提炼使用

**四个提炼来源**（与过程拆解中「做加法」的方法一脉相承）：

| 来源 | 做什么 |
|---|---|
| **分析销冠** | 最好的销售在这个环节做了什么？说什么？写下来 |
| **调研同行** | 竞品给销售配了什么工具？哪些可以借鉴？ |
| **问客户** | 客户觉得什么材料有用？什么话打动了他？ |
| **拆自己** | 回顾历史成交/丢单，哪些工具起到了关键作用？ |

### 4.3 第二步：培训落地

**这是最容易被跳过、但最决定工具价值的一步**。

李蕊老师在涂料公司用 Role Play 让工具从文档变成能力：

```text
培训会的核心目的，就是让销售模拟实战 Role Play：
两个销售，一个扮演客户，一个当销售去做工作，仿真地去做。
其他销售在看的过程中也能学习，会去模仿好的销售。
做得好的销售也很开心，觉得自己的做法受到肯定了。
```

| 错误做法 | 正确做法 |
|---|---|
| 工具写完群发文档 | 开培训会，逐条讲解为什么这么设计 |
| 让销售「自己回去看」 | Role Play 模拟实战，现场用、现场纠偏 |
| 只培训一次 | 新人入职培训 + 老销售定期复习 + 工具更新后同步培训 |

### 4.4 第三步：复盘迭代

工具的终点不是「写完了」，而是「一直在变好」。

```text
迭代节奏建议：
→ 每次丢单后：复盘时检查「是不是工具没跟上」
→ 每次销冠分享后：把新经验提炼进工具
→ 每季度：系统性过一遍工具库，标记哪些要更新
```

> **L6 解读**：这三步和五步法的底层逻辑完全同构——提炼=「做加法」（穷举可能性），培训=「做减法」（聚焦关键动作），迭代=「持续验证校准」。销售工具的打造不是一次性的「写文档」，而是一个「假设→验证→升级」的循环。

## 五、六维雷达图 × 三层分级：怎样从 60 分走到 85 分

### 5.1 不同层级的适用边界

| 层级 | 适用阶段 | 核心问题 | 资源配置建议 |
|---|---|---|---|
| **60分** | 业务探索期 | 「销售出去连基本的东西都讲不清」 | 先补齐：公司介绍 + 产品介绍 + 基础话术 + 成功案例 |
| **75分** | 开始复制期 | 「销售能开口了，但不够专业、不稳定」 | 叠加：交付物模板 + 专业物料 + 内部资料 + 专项技能培训 |
| **85分** | 快速增长/成熟期 | 「团队大了，效率和攻坚能力跟不上」 | 叠加：CRM系统 + 数据看板 + 攻坚策略包 + 异议处理手册 |

### 5.2 进阶路径：不是线性替换，是层层叠加

```text
60分基础 ──→ 不能跳过，先把「能开口」解决
    +
75分进阶 ──→ 在60分基础上加「显专业」
    +
85分高阶 ──→ 在75分基础上加「系统化」

不是「到了85分就不要60分工具了」。
三层工具在任何阶段都同时存在，只是侧重点不同。
```

### 5.3 六维雷达图自诊

用一个简单问题给每个维度快速打分（1-5）：

| 维度 | 自诊问题 | 你的分数 |
|---|---|---|
| 公司有实力 | 销售能否在 3 分钟内让客户觉得「这家公司靠谱」？ |  |
| 话术说人话 | 不同销售打同一个电话，客户听到的内容一致吗？ |  |
| 服务很专业 | 销售给客户的文档、方案、合同，看起来专业吗？ |  |
| 销售有能力 | 新销售入职多久能独立见客户？ |  |
| 团队有效率 | CRM 里的数据是活的还是死的？管理者能看到真实进展吗？ |  |
| 攻坚有策略 | 遇到卡住的单子，销售知道按什么步骤排查和突破吗？ |  |

> 画出你自己的六维雷达图，最凹陷的那个维度 = 下一步最该补工具的方向。

## 六、三种思维视角升级：这节课被最低估的认知交付

### 6.1 李蕊老师的球员/裁判/教练模型

> 这是课程学员反馈中「最刷新格局」的一个认知框架。

| 思维层次 | 特征 | 典型表现 | 对应角色 |
|---|---|---|---|
| **球员思维** | 只关注「我这次怎么做」 | 容易出现大量重复低级错误 | 普通销售 |
| **裁判思维** | 能回看「哪里做对了、哪里做错了」 | 能够查错改错、把关出品 | 销售主管 |
| **教练思维** | 能提炼「为什么对、怎么教别人」 | 能够复制能力、培养人才 | 销售总监 / 领导者 |

### 6.2 这个模型和销售工具的关系

```text
球员思维 → 「给我工具，我照着用」
裁判思维 → 「这个工具哪里不好用，我能看出来」
教练思维 → 「我能把好销售的做法提炼成新工具，让其他人也能用」

销售工具武器库的最高境界不是「管理者给销售发工具」，
而是「团队里越来越多人能用裁判甚至教练思维，
主动复盘、主动提炼、主动迭代工具」。
```

> **一课学员的真实反思**：「我们作为管理者，有没有给员工赋能？如果我们把他们局限在球员境界，他们是很难跳出去主动复盘和迭代自己的问题的。我们鼓励他们开始转换思维角度，以裁判思维和教练思维来调整自己的动作，我们可能都会被结果惊讶到。而这一切，不是依赖于个体能力的，而是要靠团队能力的打造来实现的。」

### 6.3 三种视角的有无对比

| 只有球员思维 | 有裁判+教练思维 |
|---|---|
| 工具靠管理者一个人写 | 销冠的经验主动沉淀成工具 |
| 错误反复出现，没人总结 | 每次丢单都变成工具升级的机会 |
| 新人成长全靠老销售口口相传 | 新人拿着工具就能做到60分 |
| 管理者离开，工具体系崩盘 | 工具体系是组织的，不依赖任何人 |

## 七、这节课在五步法中的咬合关系（L6 理解）

```text
提炼卖点（科学销售1）
    ↓
过程拆解（科学销售2）
    ↓
业绩推进（科学销售3）
    ↓
激励团队（科学销售4）
    ↓
    前四步解决的是「设计什么」
    ↓
打造销售工具（科学销售5）← 本节
    ↓
    这一步解决的是「设计落在哪里」
    ↓
    卖点 → 变成话术文档、产品PPT、成功案例集
    过程拆解 → 变成节点图、跟进模板、客户档案模板
    业绩推进 → 变成日报模板、大项目地图、数据看板
    激励 → 变成荣誉榜单、PK规则、晋升标准表
```

**一句话咬合**：

```text
工具是前面四步的「物化」。
没有工具，卖点是管理者脑子里的想法，过程拆解是墙上的图，
业绩推进是周会上的口号，激励是随口说的承诺。
有了工具，这一切才变成销售手上真正能用的武器。
```

## 八、常见误区雷达

| 编号 | 误区 | 为什么是错的 | 正确做法 |
|---|---|---|---|
| ① | 销售工具单一，只有 PPT 和跟踪表 | 销售在不同节点需要不同武器，一把刀打不了所有仗 | 按六维雷达图补齐，至少覆盖 60 分层的全部工具 |
| ② | 工具只写不用，写完群发就完了 | 销售「收到了」≠「会用了」。不培训不演练 = 白写 | 培训 + Role Play + 考核，确保每个销售真会用 |
| ③ | 工具不做升级，两年前什么样现在还什么样 | 市场变、客户变、竞品变，旧工具可能已经失效 | 每季度复盘迭代，配合丢单复盘更新 |
| ④ | 跳过 60 分直接做 85 分工具 | 没有地基就盖楼——CRM 上了但销售连基础话术都讲不清 | 按三层分级循序渐进，60→75→85 |
| ⑤ | 话术不重要，让销售自由发挥 | 每个人讲的都不一样，无法复盘优化，新人成长慢 | 提炼标准化话术，培训后上场，定期迭代 |
| ⑥ | 工具是管理者的事，销售只管用 | 销冠的隐性经验永远沉淀不下来 | 培养裁判思维和教练思维，让团队参与提炼和迭代 |
| ⑦ | 工具越多越好，全部配齐 | 资源分散，重点不清，销售被工具淹没 | 按阶段做减法，先补齐当前最制约转化率的工具 |

## 九、如果你只能带走三样东西

1. **「60→75→85」不是分数游戏，是成长路径**。60分让销售「能开口」，75分让销售「显专业」，85分让团队「有系统」。不要跳过 60 分追求 CRM 和数据看板——基础话术和公司介绍都没统一，上系统也是空壳。

2. **工具的生命周期是「提炼→培训→迭代」，不是「写完→群发→归档」**。绝大多数公司的销售工具死在第二步——写完了、群发了，但没有 Role Play、没有考核、没有迭代。工具不是文档，是武器。武器不上手练，上战场就是废铁。

3. **从「球员思维」升级到「教练思维」，是工具体系能自我进化的关键**。管理者一个人写工具，永远追不上业务变化。当团队里越来越多人开始总结「为什么这个动作有效」并沉淀成工具时，你拥有的不是一套工具库，而是一个能自我进化的组织能力系统。
