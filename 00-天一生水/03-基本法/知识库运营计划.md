## 2. 文件规则（每个文件必须遵守）

### 2.1 文件名



* 公式：`类型前缀 + 主题`，不超过 15 字。

* 类型前缀库：`概念：` `方法：` `案例：` `复盘：` `素材：` `问题：` `思考：` `模板：` `配置：` `判断：` `研究：` `术语：`

* 文件名不鼓励加序号和版本号；版本放 YAML `version` 字段（唯一例外：成套课程大纲）。

### 2.2 YAML frontmatter（必填）



```
\---

type: 概念 | 方法 | 案例 | 复盘 | 素材 | 问题 | 思考 | 基本法 | 配置 | 术语

status: 原料 | 初稿 | 已验证 | 已应用 | 待应用

date: YYYY-MM-DD

source: 来源（链接/书名/课程/对话/自创）

audience: 面向谁（可选：自己/学员/家长/同行）

tags: \[]        # 领域标签，如 AI教育、刻意练习

related: \[]     # 关联笔记 \[\[链接]]

\---
```

### 2.3 状态流转（AI 负责推进）

`原料`（外部输入刚转档）→ `初稿`（加工过）→ `已验证`（实践验证过）→ `已应用`（在真实场景用过）。

* 03 物理目录与 status 对应：`00-待应用` 内 status = 待应用；`90-已应用` 内 status = 已应用。

* AI 在备课调用后，主动把相关卡片状态推进一档。

### 2.4 待应用 / 已应用 区隔协议（证据驱动，2026-09-15 定）

**唯一标准：有没有「应用凭证」——真实使用过的证据链。AI 永远不能在线下看到你上课，所以"用过了"必须可验证、可追溯；凭证缺失即视为未应用。**

| 状态 | 定义 | 判定 |
| --- | --- | --- |
| 待应用 | 内容完整、达到可用标准，但尚无真实使用记录 | 无任何应用凭证 |
| 已应用 | 在真实教学 / 实践场景中至少用过一次 | 有 ≥1 条应用凭证 |

**应用凭证（四选一，AI 可自动捕获）：**

1. **用户声明**：用户在对话 / 飞书明说「用了 / 上完了 / 试讲了 xxx」，AI 记录日期 + 场景。
2. **复盘产物**：出现关联的 `复盘：xxx` 笔记（含真实反馈内容），证明该作品已被使用。
3. **迭代痕迹**：同一作品出现 V2+ 版本或基于真实反馈的修改记录。
4. **作品库状态**：用户在飞书作品索引 Base 手动把状态改为「已应用」（用户有权直接改）。

**AI 自动执行规则：**

* 触发时机：课后复盘完成时、用户声明应用时、作品产生迭代时，AI 自动检查目标作品有无凭证。
* 有凭证 → 四同步迁移：移动文件到 `90-已应用` + YAML status 改「已应用」+ Base 作品索引状态同步 + vault-log 记一笔（作品名 / 凭证类型 / 日期）。
* 无凭证 → 保持待应用，AI 不催不问（宁可漏判，不可误判）。
* **例外（始终先问）**：涉及质量评价的内容（如「这课讲砸了 / 效果不好」），AI 不自动迁移、不自动评价，先问用户如何处理。
* 过渡期（7 天）内：每次迁移前给用户「状态变更提案」，用户纠正一次即沉淀一条规则进《沉淀审美规则》。

**判断口诀**：不是「放了多久」，而是「有没有证据」；证据不到，状态不动。

### 2.5 过程数据规则（2026-09-15 定 · 复盘核心资产）

**定义**：同一主题的多个版本文件（V1→V2→V3→V4…）= 过程数据，记录「第一版长啥样、第二版怎么改、第三版又怎么改」，是复盘（含 AI 复盘）的核心素材。

**铁律**：
1. **过程数据必须保留**：版本文件不删除、不覆盖、不合并（用户 2026-09-15 确认「全部保留不动」）；
2. 版本号保留在文件名（V1/V2 或 -V2 后缀），不手动删版本号；
3. 新增版本文件时，YAML 增加 `series: <主题名>` 标识同一演进序列；如能一句话说明，加 `changelog: 本版相对上一版的核心改动`；
4. AI 复盘时**按版本序列阅读**：对比相邻版本改动 → 提炼演进规律（改了什么、为什么改、结果如何）→ 复盘报告落 00-天一生水/06-评估报告 或 03-项目复盘；
5. 存量版本文件不批量改（沿用 2026-09-15 决策），规则只对新增内容生效。

### 2.6 AI 过程产物落位规则（2026-09-15 定）

AI 在服务过程中产生的文档分两类，**落位不同，互不污染**：

| 类别 | 例子 | 落位 |
| --- | --- | --- |
| 知识库运营类 | 任务记录 / 转化说明 / 体检报告 / 决策记录 / 规则沉淀 / 评估 | 00-天一生水：任务记录→01-系统文档；规则→03-基本法；体检评估→06-评估报告；画像→04-灵魂校准；运行日志→00-vault-log |
| 内容生产类 | 为备课生成的教案 / 课件 / 逐字稿 / 素材 / 复盘 | 03-知行合一 对应子域（作为你的产物）；达到成品标准→04-作品出口 |
| 工作伙伴过程产物 | 伙伴任务生成的调研 / 分析 / 初稿 / 过程版本 / 汇报文档 | 归档前 AI 先列全部候选清单，用户确认或主动触发后才落位；不静默自动写入（2026-09-16 修订） |

**原则**：运营类文档不落内容层（01/02/03/04），避免污染内容检索；内容类产物不塞系统层。工作伙伴过程产物同此原则；每日任务只生成待归档清单，落位须用户确认或主动触发。

## 3. 输入流水线：各类输入 → 文档 → 入库（用户零操作）

### 3.1 输入形态细分



| 输入形态     | 例子             | AI 处理动作                                       | 默认去向                                |
| -------- | -------------- | --------------------------------------------- | ----------------------------------- |
| 文字片段     | 看到好的提示词 / 一段想法 | 提炼核心 → 转档                                     | 提示词 → `03/95-素材/AI提示词`；想法 → 02 或 03 |
| 链接・微信公众号 | 公众号文章          | web\_fetch 抓正文 → 转结构化笔记（保留出处）；抓取受限则存链接 + 摘要待补 | 01 - 实事求是                           |
| 链接・飞书    | 飞书文档 / 知识库链接   | lark 技能读取 → 转笔记                               | 01 或按内容归类                           |
| 文件・PDF   | PDF 文档         | 解析内容 → 提炼要点 → 转文档                             | 按内容归类（01 外部 / 03 素材）                |
| 文件・图片    | 截图 / 海报        | OCR 识别 → 提炼 → 转文档                             | 按内容归类                               |

### 3.2 处理流程（5 步）



1. **接收**：用户在对话 / 飞书发链接、文件或文字，AI 全部接收。

2. **判定类型**：文字？链接（公众号 / 飞书 / 其他）？文件（PDF / 图片 / Office）？

3. **处理转档**：抓取 / 解析 / OCR → 结构化笔记，`source` 记录出处。

4. **入库归档**：按 1.2 口诀定文件夹 → 补全 YAML → 文件名按 2.1；无法判定的先落 `05-收件箱`，当天归档。

5. **汇报**：一句话告知「已存入 路径」。

**服务层承诺**：用户不需要告诉 AI "存哪"；存哪是 AI 的职责。

## 4. 备课调用与过程沉淀

### 4.1 备课调用（决策支持）

用户说「备 xx 课」时，AI 自动拉取：



* 01：相关方法论（如 教材 = 问题 + 解法、双三角）；

* 02：相关思考与新模型（AI 双三角、选题设计）；

* 03：历史教案与复盘（哪些方法上过、效果如何）；

* 素材：可复用案例、金句、数据。

产出备课包：教学目标 / 教学主线 / 关键案例 / 互动设计 / 课后练习。

### 4.2 过程沉淀：审美学习期 → 自动执行

**目标**：AI 学会用户的「审美」—— 什么样的内容值得沉淀、沉淀到哪、怎么加工。

**阶段一・过渡期（第 1-7 天，从启用日起）**



* AI 每次沉淀前给出「沉淀提案」：要沉淀的内容 + 建议去向 + 建议加工方式；

* 用户确认或纠正（一句话即可）；

* **每次纠正 = 审美信号**，AI 当场把信号提炼成一条规则，累积到 `00-天一生水/03-基本法/沉淀审美规则.md`；

* 例：用户说「提示词不要放 01，放 AI 提示词区」→ 规则：`提示词类 → 03/95-素材/AI提示词`。

**阶段二・自动期（第 8 天起）**



* 默认自动沉淀：按已提炼的审美规则执行，沉淀后一句话告知；

* **例外：涉及个人隐私、未定稿内容、对外发布相关内容，仍然先问用户**。

**转自动的判定**：第 7 天 AI 自检 —— 近 7 天用户纠正率 < 20% 且规则覆盖常见类型 → 进入自动期；否则延长过渡期。

### 4.3 作品升级

内容达到「敢直接发给学员」标准 → AI 推送飞书作品展厅（Wiki + Doc + Base），Obsidian 只留 `[[链接]]` 与状态标记。
