# 文件夹定义规范

> 用途：为知识库**每一个文件夹**定义边界——放什么、不放什么、和相邻文件夹怎么区分。
> AI 自动分拣入库时以此为准；用户手动放文件时也以此为准。
> 配套：《知识库运营计划》（顶层规则）、《沉淀审美规则》（具体判断经验）。

---

## 0. 总则：一句话边界

**四层 + 两个辅助区：**

| 文件夹 | 一句话定义 | 判定口诀 |
|---|---|---|
| 00-天一生水 | 系统层：你是谁 + 知识库怎么运转 | 规则文件 |
| 01-实事求是 | 原文层：**成熟可信的外部知识体系**与可验证事实 | 成熟的、外部的、可信的 → 01 |
| 02-解放思想 | 框架层：新观点、假设、思考、自创方法论 | 新的、想的、未验证的 → 02 |
| 03-知行合一 | 产出层：亲身实践与可复用素材 | 做过的 → 03 |
| 04-作品出口 | 成品层：敢发给学员的成品（实体在飞书） | 敢发学员 → 04 |
| 05-收件箱 | 暂存层：判不了去向的输入，AI 当天归档 | 先收着 → 05 |

**核心边界（01 vs 02）**：区别不在「内部/外部」，而在「**验证度**」——
- 01 装的是**已经成熟、可信、你可以放心调用**的体系（如一堂课程体系、经典理论、可验证数据）；
- 02 装的是**新理念、个人观点、未经验证的假设**（要拿去审视、验证，验证通过才可能升入 01）。

## 2. 01-实事求是（原文层 · 成熟体系区）

**本层现状**：目前存放的是**成熟的课程体系（一堂体系）**，基本由用户亲自放入——这正是本层该有的样子。

**总体定义**：成熟、可信、经得起验证的外部知识体系 + 可验证的一手事实资料。进入本层的内容，用户可以直接放心调用，不需要再怀疑它。

**总体准入（三道闸）**：
1. **成熟**：体系完整、经过时间或社区检验（如一堂课程体系、经典方法论）；
2. **可信**：来源可靠、可追溯（`source` 必填）；
3. **可验证**：事实/数据可核验，理论有出处。

**01 准入闸（2026-09-19 定 · 默认拒入）**：01 是「升级目的地」不是「接收口」——外部新素材一律先落 02，仅以下四类经用户拍板才升 01：①一堂官方课程体系；②经典/公认体系（教科书、行业标准、权威机构发布）；③高验证度外部作品（来源权威＋时间/规模检验＋事实可核验＋成体系，四者缺一不可）；④本人反复验证、真·成体系可对外调用的成熟产物（否则留 03）。「来源真实」只是及格线；拿不准一律降 02。进 01 的文件须写 `verification:`（方式/证据/日期）。详见《每日收件箱分拣SOP》三之二。

**总体排除**：
- ❌ 个人观点、新理念、未经实证的断言 → 02-解放思想
- ❌ 时效性评测、行业观察 → 02-解放思想
- ❌ 自己的实践产物、教案、复盘 → 03-知行合一
- ❌ 你消化吸收后的再加工 → 02-解放思想（加工后的归 02，原料归 01）

| 文件夹 | 定义 | 放什么 | 排除 |
|---|---|---|---|
| （散件）在线教育的本质等 | 成熟独立的一手知识/本质清单 | 一堂本质清单、在线教育本质、交互设计等独立成熟内容 | 你改造过的版本（→02） |
| 创业必修 | 一堂·创业课程体系 | 一堂创业课笔记/全景图/清单（预判→起盘→增长→底层逻辑） | 你基于它做的创业思考（→02） |
| 管理必修 | 一堂·管理课程体系 | 一堂管理课笔记（管项目/管团队/管业务/管公司） | 你的管理实践复盘（→03） |
| 案例课 | 一堂·案例课程体系 | 一堂案例课材料（搞砸案例/科学创业/专题高手/学员落地/开源复盘/马拉松） | 你亲身经历的案例（→03/项目复盘） |
| 个人必修 | 一堂·个人成长课程体系 | 一堂个人课笔记（时间管理/提认知/练能力/竞争力/人生红点） | 你的练习记录（→03/02 刻意练习） |

**判定辅助**：01 与 02 同主题并存时，01 存「原版原料」，02 存「你的加工/质疑/改造」。

## 3. 02-解放思想（框架层 · 思考区）

**总体定义**：新理念、假设、个人观点、思考、自创方法论。这里是 IP 化的原材料——**只要「是新的、值得审视」，就可以进 02，不需要成熟**。

| 文件夹 | 定义 | 放什么 | 排除 |
|---|---|---|---|
| 00-假设池 | 开放问题与半成品想法 | 问题：xxx（未验证问题）、假设、待验证观点 | 成型方法论（→10-新模型） |
| 01-AI思考 | 关于 AI 的思考 | 知识库设计思考、AI 双三角思考、AI 相关设计 | AI 应用产物（→03/06-AI应用） |
| 02-一堂 | 对一堂内容的思考加工 | 你消化/质疑/改造一堂后的思考 | 一堂原版笔记（→01） |
| 03 实事求是 | 对「实事求是」原则的思考 | 相关思考碎片 | — |
| 04 知行合一 | 对「知行合一」原则的思考 | 相关思考碎片 | — |
| 10-新模型 | 成型自创方法论 | 你打磨成熟的框架（如 AI双三角的成型版） | 半成品（→00-假设池） |
| 20-思想实验 | 「如果…会怎样」 | 思想实验、推演 | 已有答案的（→01 或 03） |
| 99-其他 | 未分类思考 | 暂时无归属的思考 | 长期不整理会滞留 |

**02 的生命周期**：假设池/思考 → 打磨成型 → 10-新模型 → 实践验证 → 升入 03（已应用）或沉淀为作品。
## 3.5 02 vs 03 判定树（重点 · 最容易混淆）

**一句话分界：02 装「想的」，03 装「干的」。**

判断顺序（只看一个问题）：

1. **这件事，你做过了吗？**
   - 没做过 / 刚想到 / 还没验证 → **02-解放思想**
   - 做过 / 正在做 / 已验证 → **03-知行合一**
2. **它是什么性质？**
   - 想法、假设、观点、模型设计 → 02
   - 教案、课件、复盘、工具、素材、练习记录 → 03

**为什么容易混淆**：02 和 03 有同名的文件夹（AI 双三角 / 最佳实践 / 新模型），但**同名 ≠ 同性质**——02 存的是「设计/构想」，03 存的是「实践/产物」。

| 主题 | 进 02 的样子（想的） | 进 03 的样子（干的） |
|---|---|---|
| 双三角 | 「我构想的一种 AI 教学法」模型设计 | 用双三角备的三天公开课教案、画布、复盘 |
| 最佳实践 | 听到/想到「可以这样教」，未验证 | 自己练过、验证有效的实践总结 |
| 提示词 | 设计思路，还没跑过 | 跑通、验证可用的提示词 |
| AI Partner | 构想与设计稿 | 搭好、用过的 Partner（含版本目录） |

**流转方向（双向）**：02 的成熟想法 → 做成产物 → 进 03（00-待应用 → 用过 → 90-已应用）；03 实践产生的新认知 → 反哺 02（新问题/新假设）。这是「实事求是 → 解放思想 → 知行合一」的循环，不是单向管道。

## 4. 03-知行合一（产出层 · 实践区）

**总体定义**：亲身实践过的、项目产出、可复用素材。**状态目录是当前工作流，领域目录是历史实践存档**（AI 在调用中按需迁移）。

| 文件夹 | 类型 | 定义 | 放什么 |
|---|---|---|---|
| 00-待应用 | 状态 | 新产出待实践（行动队列） | 新备课产物、新方法卡片，`status: 待应用` |
| 90-已应用 | 状态 | 实践验证过 | 用过并验证的内容，`status: 已应用` |
| 95-素材 | 状态 | 可复用片段 | 提示词、案例、金句、模板、工具规范副本 |
| 01 AI 教育 | 领域·存档 | AI 教育实践 | 公开课、C语言教学、备课与复盘方法 |
| 02 刻意练习 | 领域·存档 | 刻意练习记录 | IPO、双三角、最佳实践池、练习系列 |
| 03 项目复盘 | 领域·存档 | 项目复盘 | `复盘：xxx`（48h 规则触发） |
| 06-AI应用 | 领域·存档 | AI 工具应用沉淀 | AI partner/skill/提示词/生图/组织/工作流；**AI 案例=研究资产**（对他人实践的 L6 研究，保留于此） |
| 07-泛产品设计 | 领域·存档 | 泛产品设计实践 | 设计练习、工位整理等 |
| 08-元知识 | 领域·存档 | 关于知识管理的元方法 | 时间管理、清单体笔记等方法 |
| 99-其他 | 领域·存档 | 未分类实践 | 临时实践产物 |

**03 内部流转**：新产出 → 00-待应用 → 用过一次 → 90-已应用（AI 自动迁移）；可复用片段 → 95-素材。

**03 排除规则（体检沉淀 2026-09-15）**：
- ❌ 外部他人资料（Get达人/get_biji 等抓取内容）不得混入 03 → 统一进 02/99-其他 或 01
- ❌ 对他人实践的「研究笔记」（L6 萃取他人案例）→ 归 02，或在 03 的 **AI 案例=研究资产** 子类中集中管理
- ❌ 对话总结/行动基线 = 过程产物，归 03（不留在 02）

## 5. 05-收件箱（暂存层 · 缓冲）

**定义**：所有暂时无法判定去向的输入先落这里——它是**装卸区，不是一层知识**，文件每日 12:00 集中分拣。

**流转路径（你的输入 → 收件箱 → 分流）**：

```
你（飞书发：文字 / 链接 / PDF / 文档）
        │
        ▼
05-收件箱（缓冲 · 每日一清）
        │  AI 每日 12:00 按《每日收件箱分拣SOP》分拣
        ▼
┌──────────────┬──────────────┬──────────────┬──────────────┐
│ 成熟可信外部  │ 新观点/假设  │ 做过的/产物  │ 规则/关于你  │
│ → 01 实事求是 │ → 02 解放思想│ → 03 知行合一│ → 00 天一生水 │
└──────────────┴──────────────┴──────────────┴──────────────┘
        │
        ▼ （在 03 打磨到敢发学员的成品）
04-作品出口（飞书展厅）
```

**规则**：AI 每日 12:00 集中归档（先存后分，见《每日收件箱分拣SOP》）；**不允许长期滞留**（当日判不了次日继续判，需用户裁决的单独标注）。
