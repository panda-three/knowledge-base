# 文件夹定义规范

> 用途：为知识库**每一个文件夹**定义边界——放什么、不放什么、和相邻文件夹怎么区分。
> AI 自动分拣入库时以此为准；用户手动放文件时也以此为准。
> 配套：《知识库运营计划》（顶层规则）、《沉淀审美规则》（具体判断经验）、《03_知识库改造计划》（改造路线）。

---

## 0. 总则：顶层一句话边界

**四层 + 两个辅助区：**

| 文件夹 | 一句话定义 | 判定口诀 |
|---|---|---|
| 00-天一生水 | 系统层：你是谁 + 知识库怎么运转 | 规则文件 |
| 01-实事求是 | 原文层：**成熟可信的外部知识体系**与可验证事实 | 成熟的、外部的、可信的 → 01 |
| 02-解放思想 | 框架层：新观点、假设、思考、自创方法论 | 新的、想的、未验证的 → 02 |
| 03-知行合一 | 产出层：亲身实践与可复用素材 | 做过的 → 03 |
| 04-作品出口 | 成品层：敢发给学员的成品（实体在飞书） | 敢发学员 → 04 |
| 05-收件箱 | 暂存层：判不了去向的输入，AI 当天归档 | 先收着 → 05 |

**核心边界（01 vs 02）**：区别不在「内部/外部」，而在「**验证度**」——
- 01 装的是**已经成熟、可信、你可以放心调用**的体系（如一堂课程体系、经典理论、可验证数据）；
- 02 装的是**新理念、个人观点、未经验证的假设**（要拿去审视、验证，验证通过才可能升入 01）。

## 1. 核心分类原则（V2.0 新增 · 铁律）

**三个天然不同的维度，必须分开，不能在同一层级并列：**

1. **认知阶段**（顶层）：01 实事求是 / 02 解放思想 / 03 知行合一 —— 已定，不动；
2. **主题领域**（二级主轴）：这是什么知识（个人成长 / 产品 / 创业 / 管理 / AI / 教育 / 案例）；
3. **加工形式 + 生命周期**（用 YAML 表达）：是原文还是笔记、是假设还是已应用。

**铁律：**
- **一个层级只用一个分类轴。** 二级目录统一用「主题领域」，三库共用同一套编号；
- **加工形式、生命周期状态不建平行物理目录**，统一写进 YAML 的 `type` / `status`；
- **物理分类要稳定，流动的东西（状态）不进物理路径。** 一个知识点属于哪个领域很少变，但它会从「假设」变「已验证」、从「待应用」变「已应用」——这种变化只改 YAML，不移动文件。

**为什么三库共用一套领域编号：** 同一个主题（如刻意练习）会在三库分别留下「原料 / 我的想法 / 我的实践」三篇不同文档。编号一致，三库天然横向对齐，直接支撑「三库交叉验证」（01 捞事实、02 捞假设、03 捞实践，沿同一领域对齐）。

| 20 | 产品与设计 | 做产品、懂需求、做设计 | 泛产品设计、需求分析、产品内核、用户、交互设计、设计理念 |

| 50 | AI 技术与应用 | AI 技术、工具、方法论、自己用 AI | AI 双三角、AI 技能、AI 口喷、Agent/Skill、提示词、AI 数据、AI 生图、vibe coding、AI 工具 |
| 60 | 教育与教学 | 教学的本质、备课、讲课 | 在线教育本质、教育理论、教案、逐字稿、讲课记录、备课与复盘方法 |

| 90 | 其他 | 暂时无法归类 | 过渡期内容，定期清理 |

**领域交叉时的归类规则（按「文档性质 / 我何时用它」）：**
- **刻意练习**：方法论本身 → 10；「我用刻意练习练 AI 口喷」的练习记录，主体是 AI 练习 → 50，并打 `#刻意练习`；
- **AI 教育**：教别人 AI 的教案、讲课记录（性质是教学）→ 60；AI 双三角、提示词等技术本身 → 50；
- **AI 生图**：生图工具/技术 → 50；设计理念/作品 → 20；
- **调研情报**：服务商业决策 → 30；
- 拿不准主体领域 → 90，并在收件箱/清单中标注，由用户拍板。

**案例（70）与各领域的关系：** 案例物理上集中在 70（备课时找案例一站式），每篇用 `tags` 标注所属领域（如 `#创业`、`#AI`），并通过「案例链」与该领域的方法论双向链接。

## 3. 各层定义与 YAML 字段

### 3.1 YAML 字段规范（复用现有字段，不新增）

- **`type`（加工形式）**：`原文转录` / `萃取笔记` / `案例` / `实践记录` / `思考` / `方法论` / `基本法` / `索引`；
- **`status`（生命周期状态）**：
  - 01：`成熟`（默认，可省略）；
  - 02：`假设`（开放问题/半成品）→ `成型`（打磨成新模型）；
  - 03：`待应用`（新产出待实践）→ `已应用`（用过并验证）；
- 其他必备：`source`（来源，01 必填）、`tags`、`updated`；01 升层文件须写 `verification`（方式/证据/日期）。

### 3.2 01-实事求是（原文层 · 成熟体系区）

**总体定义**：成熟、可信、经得起验证的外部知识体系 + 可验证的一手事实资料。

**01 准入闸（默认拒入）**：01 是「升级目的地」不是「接收口」——外部新素材一律先落 02，仅以下四类经用户拍板才升 01：①一堂官方课程体系；②经典/公认体系（教科书、行业标准、权威机构）；③高验证度外部作品（来源权威＋时间/规模检验＋事实可核验＋成体系）；④本人反复验证、真·成体系可对外调用的成熟产物。拿不准一律降 02。

**排除**：个人观点/新理念/时效观察 → 02；自己的实践/教案/复盘 → 03；消化后的再加工 → 02。

### 3.3 02-解放思想（框架层 · 思考区）

**总体定义**：新理念、假设、个人观点、思考、自创方法论。只要「是新的、值得审视」就可以进，不需要成熟。

- 原「假设池 / 新模型 / 思想实验」不再是物理目录，改为 `status`：`假设` → `成型`；
- 原「AI 思考 / vibecoding / 一堂 / 原则思考」按主题归并到对应领域（AI 相关 → 50；对一堂的加工 → 对应领域或 90）。

### 3.4 03-知行合一（产出层 · 实践区）

**总体定义**：亲身实践过的项目产出与可复用素材。

- 原「待应用 / 已应用 / 素材」状态：`待应用` → `已应用` 用 `status` 表达；可复用片段（提示词/金句/模板）按其领域归位，用 `type: 实践记录` 或 `素材` 标记；
- 原「01 AI 教育」→ 60（教学）；原「06-AI 应用」→ 50（AI 技术/自用），二者重叠由此消除；
- 原「02 刻意练习」按主体归 10 或对应练习领域；原「08 元知识」→ 10（学习方法论）。

- **「探月」与「课程原文」是同一批课程的两份拷贝（已逐字节验证）**：每门课只保留一份，按领域归位；

- 版本文件（`_vN`、`V0.x`）一律保留，不视为重复。

## 6. 判定速查（存东西时）

**按顺序问（或直接扔 05 收件箱，AI 帮你判）：**

1. 这是**我做过的**吗？（教案/练习/项目/复盘）→ **03**
2. 这是**一堂官方课 / 经典教科书**吗？→ **01**
3. 都不是（我看到的 / 我想的 / 不确定的）→ **02**，拿不准一律先放 02
4. 实在判不了 → **05 收件箱**

**02 vs 03 一句话分界：** 02 装「想的」，03 装「干的」。同名 ≠ 同性质——02 是设计/构想，03 是实践/产物。
