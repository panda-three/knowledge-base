# 断链检查脚本

> **用途**：扫描知识库所有 Obsidian `[[双链]]`，找出指向不存在文件的断链并修复。
> **触发场景**：每批转写完成后必须运行；断链率 >2% 的批次必须修复后才算完成。

---

## 一、快速使用

### 扫描模式（只报告，不修改）

```bash
cd /Users/panda/Desktop/knowledge-base
python3 00-天一生水/01-系统文档/AI教育课沉淀/meta/fix_broken_links.py --scan
```

输出：总链接数 / 断链数 / 断链率 / 断链明细（文件 + 链接原文 + 目标名）。

### 修复模式（自动修复 + 备份）

```bash
python3 00-天一生水/01-系统文档/AI教育课沉淀/meta/fix_broken_links.py --fix
```

- 修改前自动备份到 `meta/.backup_before_fix/`
- 可修复的自动修正为实际文件名
- 不可修复的（历史旧链接/英文slug/旧路径）删除 `[[ ]]` 保留纯文字

### 独立验证（排除 meta 报告目录）

```bash
python3 -c "
import os, re
existing = set()
for root, dirs, files in os.walk('.'):
    if '.git' in root or '.obsidian' in root: continue
    for f in files:
        if f.endswith('.md'): existing.add(f[:-3])
total = broken = 0
for root, dirs, files in os.walk('.'):
    if any(x in root for x in ['.git','.obsidian','AI教育课沉淀/raw','AI教育课沉淀/meta']): continue
    for f in files:
        if not f.endswith('.md'): continue
        with open(os.path.join(root,f)) as fh: c = fh.read()
        c = re.sub(r'\`\`\`.*?\`\`\`', '', c, flags=re.DOTALL)
        c = re.sub(r'\`[^\`]*\`', '', c)
        for link in re.findall(r'\[\[([^\]]+)\]\]', c):
            total += 1
            t = link.split('|')[0].split('#')[0].strip()
            if t and t not in existing and '/' not in t: broken += 1
print(f'总链接={total}, 断链={broken}, 断链率={broken/total*100:.1f}%')
"
```

## 二、断链分类与处理规则

| 类别 | 识别特征 | 处理方式 |
|------|----------|----------|
| **可自动修正** | 目标文件存在，仅命名差异（全半角括号/空格/连接符） | 自动替换为实际文件名 |
| **映射修正** | 英文slug → 有对应中文笔记（如 `product-core` → 产品内核） | 按映射表替换 |
| **历史旧路径** | 含 `05 Man/`、`03 Areas/` 等旧库路径 | 删除 `[[ ]]` 保留文字 |
| **英文slug** | 全小写连字符（如 `inspiration-flash`），无对应文件 | 删除 `[[ ]]` 保留文字 |
| **人名slug** | 拼音人名（如 `ban-mingyang`），无对应文件 | 删除 `[[ ]]` 保留文字 |
| **目录式链接** | 指向目录而非文件（如 `[[Home]]`） | 删除 `[[ ]]` 保留文字 |
| **路径式链接** | 含 `/` 的完整路径（Obsidian 可解析） | 保留，不算断链 |

## 三、转写时的断链预防

1. **related 字段只写已确认存在的文件名**——不写预期文件名。
2. **用文件 basename**（不含路径），Obsidian 会自动解析。
3. **转写后运行扫描**，断链率 >2% 必须修复。
4. **新文件命名后立即验证**——`ls` 确认文件实际存在，再写 related。
