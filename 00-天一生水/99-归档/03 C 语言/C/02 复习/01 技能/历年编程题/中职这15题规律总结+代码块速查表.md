# 一、总规律

这 15 道题虽然题面不同，但底层其实主要就 5 类规律。

## 规律 1：字符串扫描
满足这个规律的题目：
- 2025：1、3、5、6、8、9、10、11、12
- 2024：205、206

一句话：
> 从左到右扫描字符串，找到有用的字符或有用的一段。

## 规律 2：字符串分段
满足这个规律的题目：
- 2025：1、3、11、12
- 2024：205

一句话：
> 一整串不好处理，就按空格、字母段、数字段切成小块。

## 规律 3：判断某一段是否满足条件
满足这个规律的题目：
- 2025：5、8、9、12
- 2024：205、206

一句话：
> 先找出来，再判断这一段合不合格。

## 规律 4：排序
满足这个规律的题目：
- 2025：1、4、5、8
- 2024：201、203

一句话：
> 两层循环，比大小，交换。

## 规律 5：数字拆位 / 数位处理
满足这个规律的题目：
- 2025：6、7
- 2024：206

一句话：
> `%` 取位，`/` 去位，反复处理。

# 二、代码块对照表

## 代码块 1：扫描整个字符串

这几个题目都满足这个规律：
- 2025：1、3、5、6、8、9、10、11、12
- 2024：205、206

**代码模板**
```c
for(i = 0; str[i]; i++)
{
    ...
}
```

**实现功能**
- 从左到右扫描整个字符串
- 是所有字符串题的起点

**学生对比重点**
- 所有字符串题几乎都先有这一句
- 变化只是 `...` 里面做什么不同

---

## 代码块 2：找到一个片段开始

这几个题目都满足这个规律：
- 2025：1、3、10、11、12
- 2024：205、206

**代码模板**
```c
if(str[i] != ' ')
{
    ...
}
```

或

```c
if(isalpha(str[i]))
{
    ...
}
```

或

```c
if(isdigit(str[i]))
{
    ...
}
```

**实现功能**
- 找到一个单词开始
- 找到一段字母开始
- 找到一段数字开始

**学生对比重点**
- 本质一样，都是“发现一段开始”
- 区别只在“什么条件算开始”

---

## 代码块 3：进入片段内部继续处理

这几个题目都满足这个规律：
- 2025：1、3、10、11、12
- 2024：205、206

**代码模板**
```c
for(; str[i] && str[i] != ' '; i++)
{
    ...
}
```

或

```c
for(; str[i] && isalpha(str[i]); i++)
{
    ...
}
```

或

```c
for(; str[i] && isdigit(str[i]); i++)
{
    ...
}
```

**实现功能**
- 处理一个单词内部
- 处理一段连续字母
- 处理一段连续数字

**学生对比重点**
- 外层循环负责“找段”
- 内层循环负责“处理这一段”

---

## 代码块 4：提取一段字符保存成字符串

这几个题目都满足这个规律：
- 2025：1、3、11、12、8

**代码模板**
```c
char temp[20];
int k = 0;
for(; ...; i++)
{
    temp[k++] = str[i];
}
temp[k] = '\0';
```

**实现功能**
- 把当前这一段保存下来
- 形成一个新字符串

**学生对比重点**
- 这类题不是直接处理整个原串
- 而是先把一小段摘出来再处理

---

## 代码块 5：拼整数

这几个题目都满足这个规律：
- 2025：6、10
- 2024：205、206

**代码模板**
```c
y = y * 10 + str[i] - '0';
```

**实现功能**
- 把多个数字字符拼成一个整数

**学生对比重点**
- 这是“字符串抽数字题”的核心句
- 看到这句就知道在“拼数字”

---

## 代码块 6：标志位判断条件

这几个题目都满足这个规律：
- 2025：5、9、12
- 2024：205、206

**代码模板**
```c
int flag = 1;
...
if(不满足条件)
    flag = 0;
...
if(flag)
{
    保存结果;
}
```

或

```c
int flag1 = 1;
int flag2 = 1;
```

**实现功能**
- 判断这一段是否合格
- 常见用途：
  - 是否是混合单词
  - 是否满足升序/降序
  - 是否满足某种规则

**学生对比重点**
- flag 本质就是“做记号”
- 不是新知识，是帮程序记住“有没有满足条件”

---

## 代码块 7：统计长度 / 找最长

这几个题目都满足这个规律：
- 2025：8
- 2024：205

**代码模板**
```c
int len = 0;
...
len++;
```

以及

```c
if(len > max_len)
{
    max_len = len;
    start = m;
}
```

**实现功能**
- 统计当前片段长度
- 找最长片段

**学生对比重点**
- 先有“当前值”
- 再和“历史最优值”比较

---

## 代码块 8：统计个数 / 结果下标

这几个题目都满足这个规律：
- 2025：1、3、10、12
- 2024：205、206

**代码模板**
```c
int cnt = 0;
...
a[cnt++] = 某个结果;
```

或

```c
cnt++;
```

**实现功能**
- 统计结果数量
- 控制数组存放位置

**学生对比重点**
- `cnt` 很多题都出现
- 一般表示“第几个结果”

---

## 代码块 9：冒泡排序骨架

这几个题目都满足这个规律：
- 2025：1、4、5、8
- 2024：201、203

**代码模板**
```c
for(i = 0; i < n - 1; i++)
{
    for(j = 0; j < n - 1 - i; j++)
    {
        if(前一个应该和后一个交换)
        {
            交换;
        }
    }
}
```

**实现功能**
- 排整数
- 排字符串
- 排编号或成绩

**学生对比重点**
- 排序骨架几乎一模一样
- 变化只在：
  - 比较什么
  - 交换什么

---

## 代码块 10：交换两个整数

这几个题目都满足这个规律：
- 2025：4、5
- 2024：203

**代码模板**
```c
int temp = a[j];
a[j] = a[j+1];
a[j+1] = temp;
```

**实现功能**
- 交换两个整数元素

**学生对比重点**
- 最基础交换模板

---

## 代码块 11：交换两个字符串

这几个题目都满足这个规律：
- 2025：1、8
- 2024：201

**代码模板**
```c
char temp[50];
strcpy(temp, s1);
strcpy(s1, s2);
strcpy(s2, temp);
```

**实现功能**
- 交换两个字符串

**学生对比重点**
- 字符串不能直接 `=` 交换
- 要借助临时数组

---

## 代码块 12：数字拆位

这几个题目都满足这个规律：
- 2025：6、7
- 2024：206

**代码模板**
```c
while(n)
{
    int wei = n % 10;
    n = n / 10;
}
```

**实现功能**
- 一位一位取数字
- 处理数位问题

**学生对比重点**
- 所有“处理整数每一位”的题都很像

---

## 代码块 13：按别的进制拆位

这几个题目都满足这个规律：
- 2025：7

**代码模板**
```c
while(temp)
{
    int wei = temp % 12;
    temp = temp / 12;
}
```

或

```c
while(temp)
{
    int wei = temp % 16;
    temp = temp / 16;
}
```

**实现功能**
- 按 12 进制、16 进制拆位

**学生对比重点**
- 和 `%10 / 10` 本质一样
- 只是把 10 改成别的底数

---

## 代码块 14：提取固定位置的信息

这几个题目都满足这个规律：
- 2024：201、203

**代码模板**
```c
int x = num / 100;
int y = num % 10;
```

或

```c
mid(str, p, w)
```

**实现功能**
- 从编号、成绩、字符串固定位置中提取信息

**学生对比重点**
- 有时候不是整段扫描
- 而是按固定位置拿信息

# 四、上课时怎么收口

## 一句话总分类
这 15 题其实就是 3 大母题：

### 第一类：字符串题
代表：
- 1、3、5、6、8、9、10、11、12、205、206

核心动作：
- 扫描
- 分段
- 判断
- 提取

### 第二类：排序题
代表：
- 1、4、5、8、201、203

核心动作：
- 两层循环
- 比较
- 交换

### 第三类：数位题
代表：
- 6、7、206

核心动作：
- `%`
- `/`
- 一位一位拆
