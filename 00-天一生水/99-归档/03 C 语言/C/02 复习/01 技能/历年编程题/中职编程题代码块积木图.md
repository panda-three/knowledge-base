# 中职编程题代码块积木图（投屏版）

## 一句话
**后面的新题，很多都不是新题，而是老代码块重新拼。**

## 收录规则
- 只有在不同历年题里重复出现至少 2～3 次的可复用代码块，才进入这张积木图。
- 只在单个题里出现一次的做法，放在具体题目的讲解里，不单独升级成积木。
- 过于基础的语法外壳，不单独算积木。

# 01. 基础积木

## 先说明：哪些不再单独算积木
下面这几个动作在很多题里都会出现，但它们更像“小零件”，不再单独算一个主积木：
- `flag = 1` 这种记号变量
- `cnt++` 这种单独计数推进
- 单独的“交换整数 / 交换字符串”语句

原因很简单：
- 它们太小，离开上下文很难单独教
- 真正能迁移的是“排序”“筛选”“切段处理”这类完整动作
- 学生背太多小碎片，反而更乱

---

## 积木 1：扫描整串
```c
for(i = 0; str[i]; i++)
{
    ...
}
```
**作用**：从左到右扫描整个字符串。

## 积木 2：找到一段并处理这一段
```c
if(str[i] != ' ')
{
    for(; str[i] && str[i] != ' '; i++)
    {
        ...
    }
}
```
或：
```c
if(isdigit(str[i]))
{
    for(; str[i] && isdigit(str[i]); i++)
    {
        ...
    }
}
```
或：
```c
if(a[i] != '#')
{
    for(; a[i] && a[i] != '#'; i++)
    {
        ...
    }
}
```
**作用**：找到一个单词 / 数字段 / 分隔片段的开始，并把这一整段处理完。

## 积木 3：把这一段存成字符串
```c
char temp[20];
int k = 0;
for(; ...; i++)
{
    temp[k++] = str[i];
}
temp[k] = '\0';
```
**作用**：把当前片段摘出来，形成一个新字符串。

## 积木 4：拼整数 / 按进制拼整数
```c
y = y * 10 + str[i] - '0';
```
**作用**：把数字字符按顺序拼成十进制整数。

八进制变形：
```c
y = y * 8 + str[i] - '0';
```

十六进制变形：
```c
y = y * 16 + 当前十六进制位的值;
```

带符号变形：
```c
int sign = 1;
if(str[i] == '-')
    sign = -1;
```

**作用**：把十进制 / 八进制 / 十六进制数字字符子串拼成整数。

## 积木 5：找最优结果（最长 / 最大 / 最小 / 次大 / 次小）
找最长：
```c
int len = 0;
len++;
if(len > max_len)
{
    max_len = len;
    start = m;
}
```

找最大 / 最小：
```c
max = a[0];
min = a[0];
for(i = 0; i < n; i++)
{
    if(a[i] > max)
        max = a[i];
    if(a[i] < min)
        min = a[i];
}
```

找次大、次小：
```c
if(a[i] > max)
{
    max1 = max;
    max = a[i];
}
else if(a[i] > max1)
{
    max1 = a[i];
}
```

**作用**：从一段内容或一组数据里找“最优结果”，包括最长、最大、最小、次大、次小。

## 积木 6：排序（含交换变形）
```c
for(i = 0; i < n - 1; i++)
{
    for(j = 0; j < n - 1 - i; j++)
    {
        if(应该交换)
        {
            交换;
        }
    }
}
```
交换整数：
```c
int temp = a[j];
a[j] = a[j + 1];
a[j + 1] = temp;
```
交换字符串：
```c
char temp[50];
strcpy(temp, s1);
strcpy(s1, s2);
strcpy(s2, temp);
```
**作用**：完成整数、字符串、编码信息的排序。

## 积木 7：拆位 / 拆编码 / 进制转换
十进制拆位：
```c
while(n)
{
    int wei = n % 10;
    n = n / 10;
}
```

按进制拆位：
```c
while(num)
{
    int wei = num % base;
    num = num / base;
}
```

从编码整数里拆信息：
```c
score = num / 100;
sex = num % 10;
```

从固定位置里拆信息：
```c
mid(str, p, w)
```

**作用**：把一个数或一个固定格式字符串拆开，取出我们真正要用的信息。

**为什么继续合并**：
- 学生真正面对的其实都是同一类题感：**一个东西里藏了信息，要拆出来**
- 有的是按位拆，有的是按进制拆，有的是按固定位置拆
- 合成一个母积木后，更容易形成“先拆，再用”的做题反射

## 积木 8：删除后整体前移
```c
for(i = 删除位置 + 1; i < n; i++)
{
    a[i - 1] = a[i];
}
```
或：
```c
for(i = 删除位置 + 1; i < n; i++)
{
    strcpy(a[i - 1], a[i]);
}
```
**作用**：删除数组中的一项后，让后面的内容整体往前补。

## 积木 9：判断素数
```c
int flag = 1;
for(j = 2; j < num; j++)
{
    if(num % j == 0)
    {
        flag = 0;
        break;
    }
}
```
**作用**：判断一个整数是不是素数。

## 积木 10：计数数组
```c
int count[10] = {0};
count[x]++;
```
或：
```c
int used[256] = {0};
```
**作用**：统计数字 / 字符出现次数，找重复、找缺失、做去重标记。

## 积木 11：相邻字符关系判断
```c
if(str[i] < str[i - 1])
{
    flag = 0;
}
```
或：
```c
if(str[i] == str[i - 1] - 1)
{
    ...
}
```
**作用**：判断相邻字符是否满足不降、递减、相等、连续等关系。

## 积木 12：按字符规则累加值
```c
sum = sum + str[i];
```
或：
```c
if(islower(ch))
    sum = sum + 规则值;
```
**作用**：逐个字符计算并累加某种值，例如 ASCII 和、字符能量值。
