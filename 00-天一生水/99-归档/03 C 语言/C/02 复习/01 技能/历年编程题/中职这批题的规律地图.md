# 中职这批题的规律地图

## 先说给学生听的一句话
这十几道题，看起来很多，实际上不是十几种新做法。

你做题时，不要先想“这题我没见过怎么办”，而要先想：

> **这题让我先切段？先判断？先拼数字？还是先算结果再排序？**

只要先看出这一点，题目就会轻很多。

---

# 地图 1：先切成一段一段，再处理

## 学生视角的感觉
当题目给我一长串字符串，我不要整串一起想。

我应该先想：
> 这里面是不是藏着很多“小块”？
> 我能不能先把一小块一小块找出来？

如果能，那就先切段，再处理每一段。

## 这类题的共同规律
- 先扫描整串
- 再找到一个片段开始
- 再处理这一段
- 做完这一段，再做下一段

## 适用题目
- `2025/1.c`
- `2025/3.c`
- `2025/10.c`
- `2025/12.c`
- `2024/205.c`

## 这些题分别要你写什么函数

### `2025/1.c`
- `int tqszc(char s[],char str[][10])`
  - 从空格分隔的子串中，提取数字字符，组成纯数字子串
- `void Sort(char str[][10],int n)`
  - 把这些数字子串排序，使拼接后的总数最大

### `2025/3.c`
- `int extractWords(char str[], char words[][M])`
  - 从字符串中提取特殊单词
- `int findDuplicates(char words[][M],char dck[][M],int n)`
  - 用词库去匹配这些特殊单词，只留下匹配成功的

### `2025/10.c`
- `void getNumber(char s[], double fnum[])`
  - 从空格分隔的字符串中取出 5 个数
- `double find(double fnum[])`
  - 利用这 5 个数求区间内的根

### `2025/12.c`
- `int split(char words[][20], char str[])`
  - 按空格把单词一个个提取出来
- `int check(char ascend[][20],char words[][20],int n)`
  - 从这些单词中找不降单词

### `2024/205.c`
- `int sLoc(char str[])`
  - 找到第 1 个最长数码单词的起始位置
- `int getNum(char str[],int n[])`
  - 提取每个数码单词中的数字字符，组成整数

## 这类题共用的代码骨架

### 骨架 1：扫描整串
```c
for(i = 0; str[i]; i++)
{
    ...
}
```

### 骨架 2：找到一段开始
```c
if(str[i] != ' ')
{
    ...
}
```

### 骨架 3：进入这一段内部
```c
for(; str[i] && str[i] != ' '; i++)
{
    ...
}
```

### 骨架 4：把这一段存下来
```c
char temp[20];
int k = 0;
for(; str[i] && str[i] != ' '; i++)
{
    temp[k++] = str[i];
}
temp[k] = '\0';
```

## 学生该记住的话
> 一长串不好做，就先切成一段一段。

# 地图 2：不是每一段都要，先判断合不合格

## 学生视角的感觉
我找到一段以后，不要着急保存。

我要先想：
> 这一段是不是题目真正想要的？

如果不是，就丢掉。
如果是，再留下。

## 这类题的共同规律
- 先找到一段
- 再判断这段是否符合条件
- 合格才保存
- 有时还要在合格里找“最长”或“最优”

## 适用题目
- `2025/3.c`
- `2025/5.c`
- `2025/8.c`
- `2025/9.c`
- `2025/12.c`
- `2024/205.c`
- `2024/206.c`

## 这些题分别要你写什么函数

### `2025/3.c`
- `extractWords(...)`
  - 提取“特殊单词”
- `findDuplicates(...)`
  - 只保留匹配成功的单词

### `2025/5.c`
- `int wordsearch(char str[], char words[][N],int sum[])`
  - 提取单词并计算和值，只保留和值是素数的单词
- `void sort(char words[][N],int n,int sum[])`
  - 对这些合格单词排序

### `2025/8.c`
- `void trans(char str[],char a[])`
  - 找最长降序子串
- `void sort(char b[][N])`
  - 对找到的子串排序

### `2025/9.c`
- `int GetStr(char str[],char Seq[][10])`
  - 按逗号取出多个数字串
- `int Check(char str[])`
  - 判断一个数字串是否有错误，必要时修正

### `2025/12.c`
- `int check(char ascend[][20],char words[][20],int n)`
  - 只保留不降单词

### `2024/205.c`
- `int sLoc(char str[])`
  - 只在数码单词里找“最长”
- `int getNum(char str[],int n[])`
  - 只提取数码单词中的数字

### `2024/206.c`
- `int check(int n)`
  - 判断整数是不是幻方数

## 这类题共用的代码骨架

### 骨架 1：flag 做记号
```c
int flag = 1;
```
或
```c
int flag1 = 1;
int flag2 = 1;
```

### 骨架 2：边处理边判断
```c
for(...)
{
    if(不满足条件)
        flag = 0;
}
```

### 骨架 3：合格才保存
```c
if(flag)
{
    保存结果;
}
```

### 骨架 4：找最好 / 最长
```c
if(当前值 > 最优值)
{
    更新最优值;
}
```

## 学生该记住的话
> 不是找到就要，先审一下，合格再留。

# 地图 3：看到数字字符，不是加，是拼

## 学生视角的感觉
如果题目给我的不是现成整数，而是字符串里的数字字符，
那我第一反应不应该是“加起来”，而应该是：

> 把这些数字按顺序拼成一个数。

## 这类题的共同规律
- 扫描字符串
- 遇到数字字符
- 按顺序拼成整数
- 存起来继续用

## 适用题目
- `2025/1.c`
- `2025/6.c`
- `2025/10.c`
- `2024/205.c`
- `2024/206.c`

## 这些题分别要你写什么函数

### `2025/1.c`
- `tqszc(...)`
  - 从每段中取数字字符，组成纯数字子串

### `2025/6.c`
- `int abstract(char s[],int a[])`
  - 从特定格式的子串中抽出整数
- `void convert(int a[], char nine[][N], int m)`
  - 再把整数转成九进制字符串

### `2025/10.c`
- `void getNumber(char s[], double fnum[])`
  - 从字符串里取出 5 个数值

### `2024/205.c`
- `int getNum(char str[],int n[])`
  - 提取数码单词中的数字字符，组成整数

### `2024/206.c`
- `int take(char a[],int k)`
  - 取前 k 个数字字符，组成整数

## 这类题共用的代码骨架

### 骨架 1：拼整数
```c
y = y * 10 + str[i] - '0';
```

### 骨架 2：连续拼接
```c
int y = 0;
for(; str[i] && isdigit(str[i]); i++)
{
    y = y * 10 + str[i] - '0';
}
```

### 骨架 3：保存结果
```c
a[cnt++] = y;
```

### 骨架 4：考虑符号（有些题会用）
```c
int sign = 1;
if(str[i] == '-')
    sign = -1;
```

## 学生该记住的话
> 看到数字字符，就想到“拼数”。

# 地图 4：排序不是起点，是最后整理结果

## 学生视角的感觉
有些题看起来在考排序，
但其实排序之前，你得先想清楚：

> 我要排的东西是什么？
> 排序依据是什么？

所以排序通常不是第一步，而是最后一步。

## 这类题的共同规律
- 先得到结果
- 再确定排序依据
- 最后统一排序

## 适用题目
- `2025/1.c`
- `2025/4.c`
- `2025/5.c`
- `2025/8.c`
- `2024/201.c`
- `2024/203.c`

## 这些题分别要你写什么函数

### `2025/1.c`
- `Sort(char str[][10],int n)`
  - 排列数字子串，使拼接值最大

### `2025/4.c`
- `int calculate_energy(char sen[])`
  - 先算每个字符串的总能量值
- `void sort(char sen[][100], int energy[], int n)`
  - 再按能量值排序

### `2025/5.c`
- `void sort(char words[][N],int n,int sum[])`
  - 按和值排序，和值相同按字典序排序

### `2025/8.c`
- `void sort(char b[][N])`
  - 对最长降序子串排序

### `2024/201.c`
- `void sort(char stu_name[][10],char stu_id[][19])`
  - 按出生日期排序学生信息

### `2024/203.c`
- `void sort(int score[])`
  - 按成绩降序排序
- `void rewards(int rwd[],int score[])`
  - 再根据规则选出前三名

## 这类题共用的代码骨架

### 骨架 1：冒泡排序
```c
for(i = 0; i < n - 1; i++)
{
    for(j = 0; j < n - 1 - i; j++)
    {
        if(应该交换)
        {
            交换;
        }
    }
}
```

### 骨架 2：交换整数
```c
int temp = a[j];
a[j] = a[j+1];
a[j+1] = temp;
```

### 骨架 3：交换字符串
```c
char temp[50];
strcpy(temp, s1);
strcpy(s1, s2);
strcpy(s2, temp);
```

### 骨架 4：同步交换两个数组
```c
先交换 words[j] 和 words[j+1]
再交换 sum[j] 和 sum[j+1]
```

## 学生该记住的话
> 先把东西找齐，再排；别一上来就写排序。

# 地图 5：整数整体太大，就一位一位拆

## 学生视角的感觉
题目给一个整数时，
我不要把它当成“一个大整体”，
而要想：

> 我能不能把它拆成一位一位来看？

## 这类题的共同规律
- 先取最后一位
- 再去掉最后一位
- 重复这个过程
- 对每一位做判断或转换

## 适用题目
- `2025/6.c`
- `2025/7.c`
- `2024/203.c`
- `2024/206.c`

## 这些题分别要你写什么函数

### `2025/6.c`
- `void convert(int a[], char nine[][N], int m)`
  - 把整数转成九进制字符串

### `2025/7.c`
- `int isEqual(int num)`
  - 判断十进制、十二进制、十六进制各位和是否相等
- `void calculateDate(int m,int date[])`
  - 计算第 m 天的日期

### `2024/203.c`
- `void sort(int score[])`
  - 从整数中拆出成绩进行排序
- `void rewards(int rwd[],int score[])`
  - 从整数中拆出学号、性别信息

### `2024/206.c`
- `int check(int n)`
  - 判断一个整数是不是幻方数

## 这类题共用的代码骨架

### 骨架 1：十进制拆位
```c
while(n)
{
    int wei = n % 10;
    n = n / 10;
}
```

### 骨架 2：其他进制拆位
```c
while(n)
{
    int wei = n % 12;
    n = n / 12;
}
```
或
```c
while(n)
{
    int wei = n % 16;
    n = n / 16;
}
```

### 骨架 3：从一个编码整数里拆多个信息
```c
score = num / 100;
sex = num % 10;
```

## 学生该记住的话
> 数字题里，很多时候不是“算”，而是“拆”。

---

# 最后给学生的总收口

做这批题，不要先想“题号”。
要先想自己现在落在哪张地图里：

1. **先切段再处理**
2. **先判断合不合格**
3. **看到数字字符就拼成数**
4. **先算结果再排序**
5. **整数太大就一位一位拆**

如果先落对地图，题目就不会显得那么乱。
