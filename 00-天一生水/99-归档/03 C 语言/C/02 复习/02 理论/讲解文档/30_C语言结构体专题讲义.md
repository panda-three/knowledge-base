# C语言结构体专题讲义（学生版）

## 一、这节课学什么

这节课我们学习 C 语言里的一个重要知识点：**结构体**。

结构体常出现在程序阅读题、填空题和综合应用题中。考试里经常会问：

- 结构体从哪里开始定义？
- 结构体里有哪些成员？
- 怎样访问结构体成员？
- 结构体数组是什么意思？
- 怎样输入、输出结构体里的数据？

学完这份讲义，你要能看懂下面这种代码：

```c
struct Worker
{
    char name[20];
    int salary;
}per[20];
```

---

## 二、为什么需要结构体

我们先想一个问题：如果要保存一个工人的信息，需要保存什么？

比如：

| 信息 | 数据类型 |
|---|---|
| 姓名 | 字符数组 |
| 工资 | 整型 |
| 年龄 | 整型 |
| 性别 | 字符型 |

这些数据类型不完全一样。

如果只用普通变量，可能要这样写：

```c
char name[20];
int salary;
int age;
char sex;
```

但是这些变量彼此是分散的，不方便表示“一个完整的人”。

所以 C 语言提供了结构体。

结构体的作用就是：

```md
把多个不同类型的数据，打包成一个整体。
```

一句话记住：

```md
结构体 = 一条完整记录。
```

---

## 三、结构体的基本格式

结构体的基本写法是：

```c
struct 结构体名
{
    成员1;
    成员2;
    成员3;
};
```

例如：

```c
struct Worker
{
    char name[20];
    int salary;
};
```

这段代码定义了一个结构体类型，名字叫 `Worker`。

它里面有两个成员：

| 成员 | 含义 | 类型 |
|---|---|---|
| `name` | 姓名 | 字符数组 |
| `salary` | 工资 | 整型 |

注意：

```md
struct Worker 只是定义了一种“类型”，还没有真正存数据。
```

就像 `int` 是一种类型，只有写出 `int a;` 才有变量 `a`。

---

## 四、定义结构体变量

### 1. 先定义类型，再定义变量

```c
struct Worker
{
    char name[20];
    int salary;
};

struct Worker w;
```

这里：

- `struct Worker` 是结构体类型
- `w` 是结构体变量

可以理解为：

```md
w 是一个工人记录，里面有 name 和 salary 两项信息。
```

---

### 2. 定义结构体时顺便定义变量

```c
struct Worker
{
    char name[20];
    int salary;
}w;
```

这里在定义结构体类型的同时，也定义了变量 `w`。

---

### 3. 定义结构体数组

```c
struct Worker per[20];
```

意思是定义了一个结构体数组 `per`，可以保存 20 个工人的信息。

也可以写成：

```c
struct Worker
{
    char name[20];
    int salary;
}per[20];
```

这里的 `per[20]` 表示有 20 条工人记录。

其中：

- `per[0]` 是第 1 个工人
- `per[1]` 是第 2 个工人
- `per[2]` 是第 3 个工人

注意：C 语言数组下标从 `0` 开始。

---

## 五、访问结构体成员

访问结构体成员要使用点号：

```c
结构体变量名.成员名
```

例如：

```c
w.salary
w.name
```

意思是：

- `w.salary`：工人 `w` 的工资
- `w.name`：工人 `w` 的姓名

如果是结构体数组，要这样写：

```c
per[i].name
per[i].salary
```

意思是：

- `per[i].name`：第 `i` 个工人的姓名
- `per[i].salary`：第 `i` 个工人的工资

拿分口诀：

```md
结构体成员用点号，数组元素先下标。
```

也就是：

```c
per[i].salary
```

不要写成：

```c
per.salary[i]   // 错误理解
```

---

## 六、结构体数据的输入

看下面代码：

```c
scanf("%s", per[i].name);
scanf("%d", &per[i].salary);
```

第一句：

```c
scanf("%s", per[i].name);
```

表示输入第 `i` 个工人的姓名。

注意：字符数组名本身就代表地址，所以这里不用写 `&`。

第二句：

```c
scanf("%d", &per[i].salary);
```

表示输入第 `i` 个工人的工资。

工资是普通整型变量，所以要加 `&`。

易错点：

```md
输入字符串数组名，不加 &；
输入普通 int 成员，要加 &。
```

---

## 七、结构体数据的输出

输出结构体成员，还是用成员访问格式。

例如：

```c
printf("%s\n", per[i].name);
```

表示输出第 `i` 个工人的姓名。

如果输出工资，可以写：

```c
printf("%d\n", per[i].salary);
```

考试中看到 `printf`，要知道它是输出函数。

拿分口诀：

```md
输入看 scanf，输出看 printf。
```

---

## 八、用一道题完整看懂结构体

题目代码：

```c
#include<stdio.h>
struct Worker
{
    char name[20];
    int salary;
}per[20];
int main()
{
    int i=0;
    for(i=0;i<3;i++)
    {
        scanf("%s",per[i].name);
        scanf("%d",&per[i].salary);
    }
    for(i=0;i<3;i++)
    {
        if(per[i].salary>=1500)
            printf("%s\n",per[i].name);
    }
    return 0;
}
```

### 1. 程序整体功能

这段程序的作用是：

```md
输入 3 个工人的姓名和工资，输出工资大于等于 1500 的工人姓名。
```

---

### 2. 第一段 for 循环

```c
for(i=0;i<3;i++)
{
    scanf("%s",per[i].name);
    scanf("%d",&per[i].salary);
}
```

这段代码循环 3 次。

每次输入一名工人的：

- 姓名
- 工资

| i | 操作 |
|---|---|
| 0 | 输入第 1 个工人的姓名和工资 |
| 1 | 输入第 2 个工人的姓名和工资 |
| 2 | 输入第 3 个工人的姓名和工资 |

---

### 3. 第二段 for 循环

```c
for(i=0;i<3;i++)
{
    if(per[i].salary>=1500)
        printf("%s\n",per[i].name);
}
```

这段代码也是循环 3 次。

每次判断：

```c
per[i].salary >= 1500
```

如果第 `i` 个工人的工资大于等于 1500，就输出他的姓名。

---

### 4. 本题答案

题目问：

> 用于输出数据的函数位于第 ① 行。

输出函数是：

```c
printf("%s\n",per[i].name);
```

所以：

```md
① = 18
```

题目问：

> 从第 ② 行开始声明了结构体类型。

结构体从：

```c
struct Worker
```

开始，所以：

```md
② = 2
```

题目问：

> 主函数 main 的返回值是 ③。

代码最后是：

```c
return 0;
```

所以：

```md
③ = 0
```

题目问：

> 将源程序转换为目标程序的过程，称为 ④。

这个过程叫：

```md
④ = 编译
```

## 九、结构体和数组的区别

| 对比 | 数组 | 结构体 |
|---|---|---|
| 存放内容 | 多个同类型数据 | 多个不同类型数据 |
| 例子 | 多个成绩 | 一个人的姓名、年龄、工资 |
| 访问方式 | `a[i]` | `w.name`、`w.salary` |

一句话区分：

```md
数组管一列同类数据，结构体管一条完整记录。
```

## 十、结构体数组怎么理解

结构体数组就是：

```md
很多条完整记录排成一排。
```

比如：

```c
struct Worker per[3];
```

可以理解为：

| 数组元素 | 表示 |
|---|---|
| `per[0]` | 第 1 个工人 |
| `per[1]` | 第 2 个工人 |
| `per[2]` | 第 3 个工人 |

每个工人里面又有：

- `name`
- `salary`

所以：

| 表达式 | 含义 |
|---|---|
| `per[0].name` | 第 1 个工人的姓名 |
| `per[0].salary` | 第 1 个工人的工资 |
| `per[1].name` | 第 2 个工人的姓名 |
| `per[1].salary` | 第 2 个工人的工资 |

## 十一、考试常见考法

### 考法1：问结构体从哪一行开始

看到：

```c
struct 结构体名
```

这就是结构体声明的开始。

---

### 考法2：问结构体有哪些成员

看大括号里面的内容：

```c
{
    char name[20];
    int salary;
}
```

成员就是：

- `name`
- `salary`

---

### 考法3：问怎样访问成员

普通结构体变量：

```c
w.salary
```

结构体数组元素：

```c
per[i].salary
```

---

### 考法4：问输入输出语句

输入函数：

```c
scanf
```

输出函数：

```c
printf
```

---

### 考法5：问筛选条件

例如：

```c
if(per[i].salary>=1500)
```

意思是筛选工资大于等于 1500 的工人。

## 十二、结构体题的解题步骤

遇到结构体题，按下面 5 步做：

### 第1步：找 `struct`

先找到结构体从哪里开始定义。

### 第2步：看结构体名

例如：

```c
struct Worker
```

结构体名是 `Worker`。

### 第3步：看成员

大括号里面就是成员。

例如：

```c
char name[20];
int salary;
```

### 第4步：看变量

大括号后面的变量也要看。

例如：

```c
}per[20];
```

说明 `per` 是结构体数组。

### 第5步：看成员访问

看到：

```c
per[i].salary
```

就翻译成：

```md
第 i 个工人的工资。
```

---

## 十三、常见易错点

### 易错点1：把结构体名当成变量名

```c
struct Worker
```

这里的 `Worker` 是结构体类型名，不是普通变量。

---

### 易错点2：忘记点号

正确：

```c
per[i].salary
```

错误：

```c
per[i]salary
```

---

### 易错点3：结构体数组下标从 0 开始

```c
per[0]
```

表示第 1 个工人，不是第 0 个工人。

---

### 易错点4：输入整型成员忘记加 `&`

正确：

```c
scanf("%d", &per[i].salary);
```

错误：

```c
scanf("%d", per[i].salary);
```

---

### 易错点5：输入字符数组成员时乱加 `&`

常见写法：

```c
scanf("%s", per[i].name);
```

因为 `name` 是字符数组，数组名本身表示地址。

```c
struct Student
```

答案：

```md
结构体名：Student
成员：name、score
```

```c
stu[i].score
```

```md
第 i 个学生的成绩。
```

```c
scanf("%d", &stu[i].score);
```

```md
printf("%d", stu[i].score);
```
