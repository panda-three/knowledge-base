# C语言 for 循环语句课程讲解

## 一、课程导入

同学们好。本节课学习 C 语言三种循环结构中的 `for` 语句。

前面已经学习了 `while` 和 `do while`。当循环次数比较明确，或者循环变量的初值、条件、变化规律都比较清楚时，通常使用 `for` 语句更简洁。

本节课学习目标：

1. 掌握 `for` 语句的一般形式。
2. 理解 `for` 语句中三个表达式的作用。
3. 能够分析 `for` 循环的执行过程。
4. 能够用 `for` 语句完成累加、累乘和输出控制。

## 二、for 语句的一般形式

`for` 语句的一般形式如下：

```c
for (表达式1; 表达式2; 表达式3)
{
    循环体;
}
```

三个表达式的作用分别是：

1. 表达式 1：设置循环变量初值，只在循环开始前执行一次。
2. 表达式 2：循环条件，每次进入循环体前判断。
3. 表达式 3：循环变量变化，每次循环体执行完后执行。

执行流程是：

```text
表达式1 -> 判断表达式2 -> 执行循环体 -> 执行表达式3 -> 再判断表达式2
```

如果表达式 2 为非 0，继续循环；如果为 0，循环结束。

## 三、例题讲解

### 例题 1：输出 1 到 10

```c
int i;

for (i = 1; i <= 10; i++)
{
    printf("%d ", i);
}
```

分析：

`i` 从 1 开始，每次加 1，只要 `i <= 10` 就继续执行。因此输出 1 到 10。

### 例题 2：求 1 到 100 的和

```c
#include <stdio.h>

int main()
{
    int i, sum = 0;

    for (i = 1; i <= 100; i++)
    {
        sum += i;
    }

    printf("sum = %d\n", sum);
    return 0;
}
```

分析：

`sum` 是累加器，初值为 0。`i` 从 1 到 100 循环 100 次，每次把当前 `i` 加到 `sum` 中。

### 例题 3：求 n 的阶乘

```c
#include <stdio.h>

int main()
{
    int i, n;
    long fact = 1;

    scanf("%d", &n);

    for (i = 1; i <= n; i++)
    {
        fact *= i;
    }

    printf("%d! = %ld\n", n, fact);
    return 0;
}
```

分析：

阶乘是累乘问题，累乘器 `fact` 的初值应为 1。

### 例题 4：输出奇数项

```c
int i;

for (i = 1; i <= 10; i += 2)
{
    printf("*");
}
```

`i` 的取值为 1、3、5、7、9，共循环 5 次，所以输出 5 个星号。

## 四、for 语句的灵活形式

`for` 的三个表达式都可以省略，但两个分号不能省略。

例如：

```c
for (;;)
{
    printf("hello");
}
```

这是一个无限循环。

也可以把多个表达式写在一起：

```c
for (i = 1, sum = 0; i <= 100; i++)
{
    sum += i;
}
```

这里使用了逗号表达式，同时初始化多个变量。

## 五、易错点

1. 忘记两个分号。

   `for` 括号中必须有两个分号。

2. 循环次数多算或少算。

   例如 `i < 10` 和 `i <= 10` 的循环次数不同。

3. 循环变量在循环体内被额外修改。

   如果循环体内又修改 `i`，要重新分析循环次数。

4. 累加器和累乘器初值写错。

   累加初值一般为 0，累乘初值一般为 1。

## 六、本讲小结

本节课学习了 `for` 循环。`for` 语句把初值、循环条件、变量变化集中写在一行中，适合循环次数明确的问题。

分析 `for` 循环时，要按执行顺序看：先初值，再判断，再循环体，再变量变化。
