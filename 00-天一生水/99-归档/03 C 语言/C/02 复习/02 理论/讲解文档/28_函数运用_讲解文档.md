## 二、形参与实参

函数定义或声明中的参数称为形式参数，简称形参。

函数调用时传入的参数称为实际参数，简称实参。

例如：

```c
int max(int x, int y)
{
    return x > y ? x : y;
}

z = max(a, b);
```

`x`、`y` 是形参，`a`、`b` 是实参。

形参与实参通过函数调用建立联系。基本数据类型参数通常是值传递，实参的值单向传递给形参，形参变化不会影响实参。

## 三、函数嵌套调用

C 语言中函数不能嵌套定义，但可以嵌套调用。

不能这样写：

```c
void f1()
{
    void f2()
    {
    }
}
```

可以这样调用：

```c
void f1()
{
    f2();
}
```

## 四、递归调用

函数直接或间接调用自身，称为递归调用。

递归函数必须有结束条件，否则会无限调用。

例如用递归求最大公约数：

```c
int gcd(int a, int b)
{
    if (b == 0)
        return a;
    else
        return gcd(b, a % b);
}
```

## 五、数组作函数参数

### 1. 数组元素作参数

数组元素作为实参时，相当于普通变量，属于值传递。

```c
void printValue(int x)
{
    if (x > 0)
        printf("%d ", x);
    else
        printf("0 ");
}

printValue(a[i]);
```

### 2. 数组名作参数

数组名作为实参时，传递的是数组首地址。函数中对数组元素的修改会影响原数组。

```c
void printArray(int a[], int n)
{
    int i;
    for (i = 0; i < n; i++)
        printf("%d ", a[i]);
}
```

数组形参可以不写长度：

```c
void f(int a[])
```

通常需要额外传入数组长度。

## 六、例题讲解

### 例题 1：判断素数函数

```c
int prime(int n)
{
    int i;

    if (n < 2)
        return 0;

    for (i = 2; i < n; i++)
    {
        if (n % i == 0)
            return 0;
    }

    return 1;
}
```

函数返回 1 表示是素数，返回 0 表示不是素数。

### 例题 2：整数逆序函数

```c
int reverse(int n)
{
    int m = 0;

    while (n != 0)
    {
        m = m * 10 + n % 10;
        n /= 10;
    }

    return m;
}
```

分析：

每次取 `n` 的个位，放到 `m` 的末尾，同时 `m` 原来的数位向左移动一位。

### 例题 3：数组逆序

```c
void reverseArray(int a[], int n)
{
    int i, t;

    for (i = 0; i < n / 2; i++)
    {
        t = a[i];
        a[i] = a[n - 1 - i];
        a[n - 1 - i] = t;
    }
}
```

分析：

长度为 10 的数组，交换下标：

```text
0 和 9
1 和 8
2 和 7
...
```

因此对应位置是 `n - 1 - i`。

## 七、变量作用域和存储类别

### 1. 局部变量

在函数内部或复合语句内部定义的变量称为局部变量，只在定义它的范围内有效。

形参也是被调函数中的局部变量。

局部变量如果没有初始化，其值是不确定的。

### 2. 全局变量

在函数外部定义的变量称为全局变量。它的作用范围通常是从定义位置到本文件结束。

全局变量如果没有初始化，初值为 0。

### 3. 静态变量 static

静态局部变量在函数调用结束后仍保留原值。下次调用函数时，可以继续使用上一次的值。

```c
void f()
{
    static int x = 0;
    x++;
    printf("%d", x);
}
```

## 八、易错点

1. 形参和实参只看名字，不看位置。

   实参与形参按位置对应，名字可以不同。

2. 基本类型参数误认为能改变实参。

   值传递中，形参改变不影响实参。

3. 数组名作参数时忽略地址传递。

   函数中修改数组元素会影响原数组。

4. 递归函数没有结束条件。

5. 局部变量没有初始化就使用。
