# 一维数组的移动、插入与删除教学课程

## 一、课程导入

同学们好。本节课继续学习一维数组，重点是一维数组元素的移动、插入和删除。

数组是一段连续存储空间。如果要在数组中间插入一个元素，就需要把后面的元素向后移动；如果要删除一个元素，就需要把后面的元素向前覆盖。

本节课学习目标：

1. 理解数组元素移动的方向。
2. 掌握一维数组插入元素的方法。
3. 掌握一维数组删除元素的方法。
4. 能够在有序数组中插入一个新元素。
5. 能够删除指定值的数组元素。

## 二、数组插入的基本思想

插入元素一般分三步：

1. 找到插入位置。
2. 从后向前移动元素，腾出位置。
3. 把新元素放入指定位置。

为什么要从后向前移动？

因为如果从前往后移动，后面的原始数据可能会被覆盖。

插入核心代码：

```c
for (i = n - 1; i >= pos; i--)
{
    a[i + 1] = a[i];
}
a[pos] = x;
n++;
```

## 三、数组删除的基本思想

删除元素一般分两步：

1. 找到要删除的位置。
2. 从该位置开始，把后面的元素依次向前覆盖。

删除核心代码：

```c
for (i = pos; i < n - 1; i++)
{
    a[i] = a[i + 1];
}
n--;
```

## 四、例题讲解

### 例题 1：将一个数插入有序数组

题目：

```text
有一个升序数组，将输入的 x 插入到合适位置，使数组仍然有序。
```

参考程序：

```c
#include <stdio.h>

int main()
{
    int a[20] = {3, 8, 12, 18, 24};
    int n = 5;
    int x, p, i;

    scanf("%d", &x);

    for (p = n - 1; p >= 0; p--)
    {
        if (x > a[p])
            break;
    }

    for (i = n - 1; i > p; i--)
    {
        a[i + 1] = a[i];
    }

    a[p + 1] = x;
    n++;

    for (i = 0; i < n; i++)
        printf("%d ", a[i]);

    return 0;
}
```

分析：

从后往前找位置。如果 `x > a[p]`，说明 `x` 应插在 `a[p]` 后面，即 `p + 1` 位置。

### 例题 2：删除指定值

题目：

```text
从数组中删除值为 x 的元素。
```

参考程序：

```c
#include <stdio.h>

int main()
{
    int a[10] = {12, 18, 24, 56, 97, 22};
    int n = 6;
    int x, p, i;

    scanf("%d", &x);

    for (p = 0; p < n; p++)
    {
        if (a[p] == x)
            break;
    }

    if (p != n)
    {
        for (i = p; i < n - 1; i++)
        {
            a[i] = a[i + 1];
        }
        n--;
    }

    for (i = 0; i < n; i++)
        printf("%d ", a[i]);

    return 0;
}
```

分析：

如果 `p != n`，说明找到了要删除的位置。删除时从 `p` 开始，把后面的元素向前覆盖，最后 `n--`。

### 例题 3：正数和负数分区存放

题目：

```text
将数组中的负数放到新数组左侧，正数放到新数组右侧。
```

思路：

1. `p` 从左向右控制负数存放位置。
2. `r` 从右向左控制正数存放位置。

```c
if (a[i] < 0)
    b[p++] = a[i];
else
    b[r--] = a[i];
```

## 五、易错点

1. 插入时移动方向错误。

   插入要从后向前移动，避免覆盖数据。

2. 删除时忘记 `n--`。

   删除后数组有效元素个数减少 1。

3. 插入位置和删除位置混淆。

   插入位置通常是 `p + 1`，删除位置就是找到的 `p`。

4. 找不到元素时仍然执行删除。

   应先判断 `p != n`。

## 六、本讲小结

本节课学习了一维数组的移动、插入和删除。插入的核心是“后移腾位置”，删除的核心是“前移覆盖位置”。做题时要特别注意移动方向和数组有效长度的变化。
