学完本讲后，需要掌握以下内容：

2. 了解程序设计语言的三种类型：机器语言、汇编语言、高级语言。
3. 理解程序、程序设计和程序设计语言之间的关系。
4. 掌握程序设计的一般步骤。
5. 理解算法的概念、基本特征和常用表示方法。
6. 初步认识算法的三种基本结构：顺序结构、分支结构、循环结构。

## 二、C 语言程序设计课程简介

C 语言是一种面向过程的程序设计语言，也是学习计算机程序设计的重要基础。它结构清晰、执行效率较高，在考试和实际编程学习中都很重要。

在职教高考计算机专业中，C 语言程序设计是重要考试内容，总分值为 140 分。其中，理论考试 60 分，上机考试 80 分。因此，学习本课程时既要理解基本概念，也要重视程序编写和调试能力。

一个最简单的 C 语言程序通常可以输出一句话，例如：

```c
#include <stdio.h>

int main(void)
{
    printf("Hello World");
    return 0;
}
```

其中，`printf("Hello World");` 的作用是在屏幕上输出 `Hello World`。后续课程会逐步学习 C 程序的基本结构、输入输出、变量、运算符、分支、循环、数组、函数和文件等内容。

## 三、计算机语言

### 1. 什么是计算机语言

如果要让计算机按照人的意图工作，就必须使用计算机能够理解和执行的指令。人与人交流需要自然语言，人与计算机交流也需要特定语言，这就是计算机语言。

简单地说，计算机语言是人与计算机之间交流的工具。更准确地说，计算机语言是一套能够完整、准确表达人们意图，并能指挥或控制计算机工作的符号系统。

### 2. 计算机语言的分类

计算机语言通常分为三类：

1. 机器语言
2. 汇编语言
3. 高级语言

机器语言和汇编语言通常称为低级语言；高级语言更接近自然语言或数学表达方式。

## 四、机器语言

### 1. 机器语言的概念

计算机本质上只能识别由 `0` 和 `1` 组成的二进制信息。由二进制代码表示、能够被计算机直接识别和执行的指令，称为机器指令。

某种计算机全部机器指令的集合，就是该计算机的机器语言，也可以称为该计算机的指令系统。

### 2. 机器语言的特点

机器语言的优点：

1. 能被计算机直接识别和执行。
2. 执行效率高。

机器语言的缺点：

1. 由大量 `0` 和 `1` 组成，直观性差。
2. 编写困难，容易出错。
3. 不易阅读和维护。
4. 依赖具体硬件，不同类型计算机的机器语言不同，通用性差。
5. 可移植性差。

因此，除了少数特殊场景，程序员通常不会直接使用机器语言编写程序。

## 五、汇编语言

### 1. 汇编语言的概念

为了克服机器语言难读、难写、难记、易出错等缺点，人们使用与机器指令含义相近的英文缩写、字母、数字等符号来代替二进制机器指令。

这些符号称为助记符。例如：

```text
ADD  表示加法操作
MOV  表示传送操作
```

用助记符代替机器指令的语言，称为汇编语言，也称为符号语言。

### 2. 汇编语言的特点

汇编语言比机器语言更容易阅读和书写，但它仍然和具体机器密切相关，仍属于面向机器的语言。

汇编语言源程序不能被计算机直接执行，必须经过汇编程序翻译，生成机器能够直接识别和执行的目标程序。

基本过程可以理解为：

```text
汇编语言源程序 -> 汇编程序翻译 -> 目标程序 -> 计算机执行
```

汇编语言的优点：

1. 比机器语言更直观。
2. 生成的目标程序占用内存少。
3. 运行速度快。

汇编语言的缺点：

1. 仍然面向机器。
2. 编写仍较繁琐。
3. 通用性差。
4. 可移植性差。

## 六、高级语言

### 1. 高级语言的概念

高级语言是接近自然语言或数学表达方式的计算机语言。它不要求程序员过多考虑计算机内部硬件结构，而是按照解决问题的过程来编写程序。

例如，在多数高级语言中：

```text
+ 表示加法
= 表示赋值
```

C 语言就是一种高级语言。

### 2. 高级语言的特点

高级语言的主要特点：

1. 更接近自然语言和数学表达式。
2. 不再直接面向机器，而是面向过程。
3. 通用性强。
4. 可读性好，便于修改和维护。
5. 可移植性较好。

高级语言编写的程序称为源程序。源程序不能被计算机直接执行，需要经过编译或解释，最终转换成机器语言后才能运行。

可以理解为：

```text
高级语言源程序 -> 编译或解释 -> 机器语言程序 -> 计算机执行
```

## 七、程序与程序设计

### 1. 什么是程序

程序是按照一定语法规则组织起来，用来完成特定任务的一组代码或指令序列。

例如，要求计算三门课程的平均分，就需要写出一组能输入成绩、计算平均值、输出结果的代码。

### 2. 什么是程序设计

程序设计是根据要完成的任务，设计解决问题的步骤，编写相应的程序代码，并测试代码是否正确，直到程序能够得到预期结果的过程。

程序设计不是随意写代码，而是要遵循一定的方法和原则。良好的程序设计风格能够提高程序的可靠性、可读性和可维护性。

### 3. 程序设计的一般步骤

程序设计通常包括以下五步：

1. 明确需求

明确要解决什么问题，需要处理哪些数据，希望得到什么结果，有哪些限制条件。

例如：输入语文、数学、英语三门成绩，求平均分，并要求平均分保留一位小数。

2. 确定数据结构和算法

确定输入数据和输出结果如何表示，并选择合适的解题方法。

例如，求三门成绩平均值的算法可以写成：

```text
平均分 = (语文成绩 + 数学成绩 + 英语成绩) / 3
```

3. 编写程序

根据确定的数据结构和算法，使用某种程序设计语言，按照语法规则写出程序。

4. 测试程序

运行程序，检查结果是否符合预期。如果不符合，需要分析错误原因。

如果算法有问题，应回到“确定数据结构和算法”这一步；如果代码编写有问题，应修改程序代码。

5. 维护程序

程序投入使用后，可能还需要修改未发现的错误，或根据新的需求调整程序。

## 八、课堂练习：计算机语言

### 练习 1

计算机能够直接执行的语言是：

```text
A. 高级语言源程序
B. 机器语言程序
C. 英语程序
D. 十进制程序
```

答案：B

解析：计算机能够直接识别和执行的是机器语言程序。高级语言源程序必须经过编译或解释后才能运行。

### 练习 2

```text
A. 解释和编译
B. 文字处理和图形处理
C. 图像处理和翻译
D. 语音处理和文字编辑
```

答案：A

解析：高级语言程序不能直接执行，通常需要通过解释或编译转换为机器能够执行的形式。

### 练习 3

用助记符代替操作码、地址符号代替操作数的面向机器的语言是：

```text
A. 机器语言

C. 高级语言
```

答案：B

## 九、算法

### 1. 什么是算法

算法就是解决问题的方法或步骤。

同一个问题可以有不同的解决方法，也就是可以有不同算法。选择算法时，应尽量选择方法简单、步骤少、运行快、占用内存小的算法。

例如，要求 `1 + 2 + 3 + ... + 100` 的和，可以逐个相加，也可以使用更简便的配对方法。不同方法都能得到结果，但效率不同。

### 2. 算法的基本特征

算法通常具有以下特征：

1. 可行性

算法中的每一步都必须能够执行，并能得到有效结果。

2. 确定性

算法的每一步都必须有明确含义，不能含糊不清，也不能有歧义。

3. 有穷性

算法必须在执行有限步之后结束，不能无限执行下去。

例如，让同学跑 10 圈，必须记录已经跑了几圈，并在达到 10 圈时停止。如果没有停止条件，就会形成死循环。

4. 输入

算法可以有零个或多个输入。输入是算法加工处理的对象。

5. 输出

算法必须至少有一个输出。输出是算法解决问题后得到的结果。

### 3. 算法的常用表示方法

算法的表示方法有很多，常用的有三种：

1. 自然语言
2. 流程图
3. 伪代码

自然语言就是用日常语言描述解题步骤，优点是容易理解，缺点是可能不够严谨。

流程图是用图形符号表示操作，用箭头表示执行流程，直观、易理解。

伪代码介于自然语言和程序设计语言之间，用文字和符号描述算法，没有严格语法要求，书写方便，便于向程序代码过渡。

## 十、流程图常用符号

常见流程图符号包括：

1. 起止框

表示算法或程序的开始和结束。

2. 输入输出框

通常用平行四边形表示，用来表示输入数据或输出结果。

3. 处理框

通常用矩形表示，用来表示计算、赋值等处理操作。

4. 判断框

通常用菱形表示，用来判断条件是否成立。判断框一般有一个入口、两个出口，分别对应“是”和“否”。

例如，判断平均分是否达到 90 分：

```text
如果 平均分 >= 90
    输出“优秀”
否则
    输出“继续加油”
```

## 十一、算法的三种基本结构

任何算法都可以分解为三种基本结构及其组合：

1. 顺序结构
2. 分支结构
3. 循环结构

### 1. 顺序结构

顺序结构是最简单的结构，按照书写顺序一步一步执行。

例如：

```text
输入三门成绩
计算平均分
输出平均分
```

### 2. 分支结构

分支结构根据条件判断结果选择不同的执行路径。

例如：

```text
如果是绿灯
    前进
否则
    停下
```

在程序中，分支结构常用于“满足某条件就执行某操作，否则执行另一种操作”的问题。

### 3. 循环结构

循环结构用于重复执行某些操作。

例如，跑步 10 圈可以描述为：

```text
已跑圈数 = 0
当 已跑圈数 < 10 时
    跑一圈
    已跑圈数 = 已跑圈数 + 1
```

循环结构必须有明确的结束条件，否则容易造成死循环。

## 十二、算法例题

### 例题 1：求三个整数的和

问题：输入三个整数，求它们的和。

算法可以写成：

```text
输入 a, b, c
sum = a + b + c
输出 sum
```

这个算法使用顺序结构即可完成。

### 例题 2：求 100 个整数的和

如果使用顺序结构逐个写出 100 次加法，指令会很长，效率也不高。此时可以使用循环结构。

伪代码如下：

```text
sum = 0
count = 0
当 count < 100 时
    输入 x
    sum = sum + x
    count = count + 1
输出 sum
```

说明：

1. `sum = 0` 表示累加前总和为 0。
2. `count = 0` 表示一开始还没有输入任何整数。
3. 每输入一个整数 `x`，就把它加到 `sum` 中。
4. 每加一次，`count` 增加 1。
5. 当 `count` 达到 100 时，循环结束，输出总和。

### 例题 3：求 1 到 8 的乘积

这是一个累乘问题。累加通常从 0 开始，累乘通常从 1 开始。

伪代码如下：

```text
t = 1
x = 1
当 x <= 8 时
    t = t * x
    x = x + 1
输出 t
```

说明：

1. `t = 1` 是累乘的初始值。
2. `x` 从 1 开始。
3. 每次把当前的 `x` 乘到 `t` 上。
4. 每乘一次，`x` 增加 1。
5. 当 `x` 大于 8 时，循环结束，输出乘积。

## 十三、本讲小结

本讲主要学习了以下内容：

1. 计算机语言是人与计算机交流的工具。
2. 计算机语言分为机器语言、汇编语言和高级语言。
3. 机器语言能被计算机直接执行，但难写、难读、难维护。
4. 汇编语言使用助记符，比机器语言直观，但仍然面向机器。
5. 高级语言接近自然语言或数学表达方式，通用性强，是程序设计的主流语言。
6. 程序设计一般包括明确需求、确定数据结构和算法、编写程序、测试程序、维护程序五个步骤。
7. 算法是解决问题的方法或步骤。
8. 算法具有可行性、确定性、有穷性、输入和输出等特征。
9. 算法可以用自然语言、流程图和伪代码表示。
10. 算法的三种基本结构是顺序结构、分支结构和循环结构。
