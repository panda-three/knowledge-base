## 二、C 语言的诞生与发展

在 C 语言诞生之前，系统软件主要使用汇编语言编写。汇编语言与计算机硬件关系密切，运行效率较高，但它依赖具体机器，可读性和可移植性较差。

一般高级语言虽然更接近自然语言，容易阅读和编写，但又难以直接实现对计算机硬件的底层操作。因此，人们希望出现一种语言，既具有汇编语言接近硬件、运行效率高的特点，又具有高级语言可读性好、可移植性较强的特点。C 语言正是在这样的背景下产生的。

C 语言的出现与 Unix 操作系统密切相关。C 语言由贝尔实验室在 20 世纪 70 年代初研制出来，后来经过多次改进，出现了多个版本。

20 世纪 80 年代初，美国国家标准化协会根据 C 语言问世以来的各种版本，对 C 语言的发展和扩充制定了新的标准，使 C 语言逐步规范化。

目前常用的 C 语言编译系统包括 Visual C++、Dev-C++ 等。在职教高考上机考试中，常用的集成开发环境是 Dev-C++。

随着面向对象技术和可视化程序设计的发展，在 C 语言基础上又产生了 C++、Visual C++、Java、C# 等程序设计语言。面向对象程序设计的基础仍然离不开面向过程的思想，因此，学好 C 语言可以为以后学习 C++ 等语言打下坚实基础。

## 三、C 语言的基本特点

C 语言是一种高级程序设计语言，也是一种面向过程的程序设计语言。

在 C 语言中，可以实现程序设计中的三种基本结构：

1. 顺序结构
2. 分支结构
3. 循环结构

C 语言还提供了多种控制语句，例如：

```c
if ... else
for
while
do ... while
goto
continue
break
return
```

C 语言中的输入输出操作通常由标准库函数完成。例如，`printf` 是常用的输出函数，它定义在标准输入输出头文件 `stdio.h` 中。

## 四、程序与程序设计

程序是遵循一定语法规则组织起来，用来完成特定任务的代码或指令序列。

程序设计是根据所要完成的任务，设计解决问题的步骤，编写相应的程序代码，并测试代码正确性的过程。只有程序能够得到正确的运行结果，程序设计过程才算基本完成。

程序设计语言是一种规范，用来描述问题的解决方案和步骤。程序设计语言具有固定的语法格式、特定的语义和使用环境，比自然语言要求更加严格，不能出现二义性。

这也对应了算法的一个重要特征：确定性。也就是说，程序中的每一步必须含义明确，不能模糊不清。

## 五、一个简单的 C 程序

下面是一个简单、完整的 C 程序：

```c
/* 这是第一个 C 程序 */
#include <stdio.h>

int main(void)
{
    printf("This is my first C program.\n");
    return 0;
}
```

这个程序的作用是在屏幕上输出一行文字。

其中，`main` 是主函数。一个完整的 C 程序可以只由一个 `main` 函数组成，也可以由一个 `main` 函数和若干个其他函数组成。

需要特别注意：

一个 C 程序有且只有一个 `main` 函数。

其他函数可以有，也可以没有；可以有一个，也可以有多个。

程序执行时，总是从 `main` 函数开始执行，并在 `main` 函数中结束。

## 六、C 程序的基本结构

一个 C 程序通常包括以下几个部分：

1. 注释
2. 编译预处理命令
3. 函数
4. 函数体中的语句

### 1. 注释

注释用于说明程序的作用，帮助阅读和理解程序。注释不会参与程序的编译和执行。

C 程序中常见的注释方式有两种。

第一种是多行注释：

```c
/* 这里是注释内容 */
```

这种注释以 `/*` 开始，以 `*/` 结束，可以写在程序的任意位置，也可以跨行书写。

第二种是单行注释：

```c
// 这里是注释内容
```

这种注释从 `//` 开始，到本行结束为止。它不能跨行，注释后面不能继续书写程序语句。

在实际编程中，应当在必要的位置添加注释。注释不宜过多，也不能完全没有。好的注释可以提高程序的可读性和可维护性。

### 2. 编译预处理命令

例如：

```c
#include <stdio.h>
```

这一行以 `#` 开头，是编译预处理命令。

`include` 表示“包含”，`stdio.h` 是系统标准输入输出头文件。

其中：

`std` 是 standard 的缩写，表示“标准”；

`i` 表示 input，输入；

`o` 表示 output，输出；

`.h` 表示头文件。

所以，`#include <stdio.h>` 的作用是包含系统标准输入输出头文件。程序中使用 `printf`、`scanf` 等标准输入输出函数时，通常需要包含这个头文件。

### 3. main 函数

例如：

```c
int main(void)
{
    printf("Hello World");
    return 0;
}
```

`int main(void)` 是函数头。

一对花括号 `{ }` 之间的部分称为函数体。

函数体中可以包含若干条语句，每条语句通常以分号 `;` 结束。

`return 0;` 表示 `main` 函数正常结束，并向操作系统返回状态码 0。状态码 0 通常表示程序正常终止。

## 七、C 程序的格式特点

C 程序具有以下格式特点。

第一，一个 C 程序有且只有一个 `main` 函数，还可以有若干个其他函数。

第二，C 程序中的每条语句通常必须以分号 `;` 结束。

第三，除函数外，编译预处理命令也是构成 C 程序的重要部分。

第四，C 语言严格区分大小写。例如，小写字母 `a` 和大写字母 `A` 会被看作两个不同的字符。

第五，C 程序通常采用缩进格式。缩进不会影响程序运行，但可以使程序结构更清晰，便于阅读和修改。

例如：

```c
if (score >= 60)
{
    printf("pass");
}
else
{
    printf("fail");
}
```

第六，C 语言书写格式比较灵活。一条语句可以写在多行上，一行也可以写多条语句。但为了提高可读性，建议按规范格式书写。

## 八、程序设计的一般步骤

程序设计通常包括五个步骤：

1. 明确需求
2. 确定数据结构和算法
3. 编写程序
4. 测试程序
5. 维护程序

### 1. 明确需求

首先要把问题陈述清楚，明确程序要处理哪些数据，希望得到什么结果，解决方案有哪些约束条件。

### 2. 确定数据结构和算法

根据问题需求，确定输入数据和输出结果的存储方式，并选择合适的解题方法。

### 3. 编写程序

按照确定的数据结构和算法，使用 C 语言语法编写程序代码。

### 4. 测试程序

运行程序，检查程序是否能得到预期结果。如果结果不正确，需要分析错误原因并修改。

### 5. 维护程序

程序完成后，仍可能需要修改未发现的错误，或根据新的需求进行调整。

## 九、C 程序的设计步骤

C 程序从编写到运行，一般要经过以下步骤：

```text
编辑源程序 -> 编译 -> 连接 -> 运行
```

### 1. 编辑

编辑就是输入和修改源代码。可以使用记事本、写字板等文本编辑器，也可以使用 Visual C++、Dev-C++ 等集成开发环境。

C 语言源程序通常以文件形式保存，扩展名为 `.c`。

有些开发环境默认保存为 `.cpp`，这是 C++ 源程序扩展名。由于 C++ 兼容大部分 C 程序，因此在 Dev-C++ 中也可能使用 `.cpp` 文件进行练习。但在学习 C 语言时，通常应掌握 `.c` 是 C 语言源程序扩展名。

### 2. 编译

编辑好的源程序不能直接运行，必须先经过 C 语言编译程序编译。

编译后会生成目标程序，目标程序的扩展名通常为 `.obj`。

`.obj` 是 object 的缩写，表示目标文件。

### 3. 连接

目标程序还不能直接作为最终程序运行。连接程序会把目标程序与需要的库函数连接起来，生成可执行文件。

可执行文件的扩展名通常为 `.exe`。

在很多集成开发环境中，编译和连接可以一次完成。

### 4. 运行

运行就是执行生成的可执行文件，并观察程序运行结果。

如果运行结果正确，程序设计过程可以结束；如果运行结果不正确，需要返回检查源程序、算法或编译连接过程中的问题。

如果编译和连接都正常，生成了 `.exe` 文件，那么该程序可以脱离开发环境，在操作系统下直接运行。

## 十、Dev-C++ 中运行 C 程序的一般过程

在 Dev-C++ 集成开发环境中，运行一个 C 程序通常包括以下过程：

1. 启动 Dev-C++，进入集成开发环境。
2. 在编辑窗口中输入源程序。
3. 编译程序。如果编译失败，需要根据错误提示修改程序，直到编译成功。
4. 连接程序。如果连接失败，也需要修改程序或配置，直到连接成功。
5. 运行程序，观察运行结果是否正确。
6. 如果结果不正确，继续修改和调试，直到程序正确运行。
7. 退出 Dev-C++，结束本次程序运行。

Dev-C++ 是集源程序编辑、编译、连接、运行、调试于一体的集成开发环境。

## 十一、重要知识点总结

计算机的工作依赖于程序，程序由人编写，计算机按照人的意图工作。

机器语言和汇编语言都与具体计算机密切相关，属于低级语言。高级语言更接近自然语言和数学语言，容易学习和推广。

C 语言是目前广泛使用的一种高级程序设计语言。

高级语言编写的源程序不能直接运行，必须经过编译、连接后形成机器指令，才能被计算机执行。

C 程序由函数构成，函数是 C 程序的基本单位。

一个 C 程序必须有且只有一个 `main` 函数。

C 程序总是从 `main` 函数开始执行。

C 语言严格区分大小写。

C 语言源程序扩展名通常为 `.c`，目标文件扩展名通常为 `.obj`，可执行文件扩展名通常为 `.exe`。

## 十二、课堂练习

### 练习 1

计算机语言的发展是从哪种语言开始的？

答案：机器语言。

解析：计算机最早能够直接识别和执行的是由 `0` 和 `1` 组成的机器语言。

### 练习 2

扩展名为 `.exe` 的文件称为什么文件？

答案：可执行文件。

解析：C 源程序经过编译和连接后，生成扩展名为 `.exe` 的可执行文件。

### 练习 3

扩展名为 `.obj` 的文件称为什么文件？

答案：目标程序文件或目标文件。

解析：C 源程序经过编译后，生成目标程序文件，扩展名通常为 `.obj`。

### 练习 4

以下说法正确的是：

```text
A. C 语言程序总是从第一个定义的函数开始执行
B. 在 C 语言程序中，要调用的函数必须在 main 函数中定义
C. C 语言程序总是从 main 函数开始执行
D. C 语言程序中的 main 函数必须放在程序的开始部分
```

答案：C。

解析：C 程序总是从 `main` 函数开始执行。`main` 函数在程序中的位置可以是任意的，不一定必须放在文件开头。

### 练习 5

下面关于 C 语言的叙述错误的是：

```text
A. 一个 C 语言源程序由一个或多个函数组成
B. 若一条语句较长，可以分写在下一行上
C. 构成 C 语言源程序的基本单位是算术表达式
D. C 语言程序必须有一个 main 函数
```

答案：C。

解析：构成 C 语言程序的基本单位是函数，不是算术表达式。

### 练习 6

C 语言程序从哪里开始执行？

答案：从程序中的 `main` 函数开始执行。

解析：无论 `main` 函数写在程序的什么位置，程序总是从 `main` 函数开始执行。

### 练习 7

C 语言源程序的扩展名是什么？

答案：`.c`。

解析：`.c` 是 C 语言源程序的常用扩展名；`.exe` 是可执行文件扩展名；`.obj` 是目标文件扩展名。

### 练习 8

C 语言程序只能包含一个主函数，但可以包含多少个其他函数？

答案：若干个。

解析：C 程序必须有且只有一个 `main` 函数，其他函数可以没有，也可以有多个。

## 十三、填空与判断要点

能把高级语言源程序变成机器语言可执行程序或目标程序的方法有两种：编译和解释。

C 语言的函数由函数头和函数体两部分组成。

C 语言中可执行文件的扩展名是 `.exe`。

以 `#` 开头的命令称为编译预处理命令。

函数体以左花括号 `{` 开始，以右花括号 `}` 结束。

机器语言由 `0` 和 `1` 组成的二进制代码构成。

注释可以使用 `/* ... */`，也可以使用 `//`。

`printf` 是输出函数，不是输入函数。

C 语言采用编译方式，把源程序编译成目标文件，再通过连接生成可执行文件。

C 语言严格区分大小写，因此 `main` 不能写成 `Main` 或 `MAIN`。
