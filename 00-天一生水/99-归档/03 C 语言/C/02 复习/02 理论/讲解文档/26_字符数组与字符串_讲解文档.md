# C语言字符数组与字符串课程讲解

## 一、课程导入

同学们好。本节课学习数组中的最后一个基础知识点：字符数组和字符串。

字符数组用于存放一组字符。当字符数组中以 `'\0'` 作为结束标志时，就可以把它看作字符串。

本节课学习目标：

1. 掌握字符数组的定义、初始化和引用。
2. 理解字符串的结束标志 `'\0'`。
3. 掌握字符数组的输入和输出。
4. 能够完成字符串逆序、大写转小写、数字字符转换等常见操作。

## 二、字符数组与字符串

字符数组定义形式：

```c
char c[20];
```

表示定义了一个长度为 20 的字符数组。

字符串由一串字符组成，并以 `'\0'` 作为结束标志。例如：

```c
char s[] = "China";
```

实际存储为：

```text
C h i n a \0
```

因此，存放字符串时，数组长度要至少比实际字符个数多 1，用来存放结束标志。

## 三、字符数组初始化

逐个字符初始化：

```c
char c[6] = {'C', 'h', 'i', 'n', 'a', '\0'};
```

字符串方式初始化：

```c
char c[6] = "China";
```

如果初始化字符个数不足，后面的元素默认为 0，也就是 `'\0'`。

二维字符数组也可以按行初始化：

```c
char a[4][5] = {
    "abcd",
    "efgh",
    "ijkl",
    "mnop"
};
```

## 四、字符数组的引用

字符数组元素像普通数组元素一样引用：

```c
printf("%c", c[i]);
```

如果按字符逐个输出，应使用 `%c`。如果按字符串整体输出，应使用 `%s`。

```c
printf("%s", c);
```

## 五、例题讲解

### 例题 1：复制字符数组

```c
char c[9] = "Jiangsu";
char d[9];
int i;

for (i = 0; i < 9; i++)
{
    d[i] = c[i];
}

for (i = 0; i < 9; i++)
    printf("%c", d[i]);
```

分析：

复制时要把字符串结束标志 `'\0'` 一起复制过去，否则目标字符数组不能作为完整字符串使用。

### 例题 2：输入一串字符并逆序输出

```c
char a[50];
int i = 0;

do
{
    scanf("%c", &a[i]);
} while (a[i++] != '\n');

i = i - 2;

while (i >= 0)
{
    printf("%c", a[i]);
    i--;
}
```

分析：

输入以换行符结束。由于 `i++` 是后置自增，循环结束时 `i` 已经指向换行符后面的下一个位置。逆序输出时要先退两格，跳过空位置和换行符。

### 例题 3：大写字母转小写字母

```c
for (j = 0; j < i - 1; j++)
{
    if (a[j] >= 'A' && a[j] <= 'Z')
        a[j] = a[j] + 32;
}
```

分析：

大写字母的 ASCII 码比对应小写字母小 32。因此大写转小写加 32，小写转大写减 32。

### 例题 4：数字字符转数值

数字字符和整数数值不同。例如字符 `'2'` 的 ASCII 码不是整数 2。

数字字符转数值：

```c
x = ch - '0';
```

例如：

```c
'5' - '0' == 5
```

这是字符串题和高考题中的常见考点。

### 例题 5：删除字符串中的数字字符

思路：

用 `i` 扫描原字符串，用 `j` 控制新字符串位置。遇到非数字字符就保留，遇到数字字符就跳过。

```c
int i = 0, j = 0;

while (s[i] != '\0')
{
    if (!(s[i] >= '0' && s[i] <= '9'))
    {
        s[j] = s[i];
        j++;
    }
    i++;
}
s[j] = '\0';
```

## 六、易错点

1. 忘记字符串结束标志 `'\0'`。

2. 字符输出和字符串输出混淆。

   单个字符用 `%c`，字符串用 `%s`。

3. 数字字符和数值混淆。

   `'2'` 不是整数 `2`，转换时用 `ch - '0'`。

4. 大小写转换方向写反。

   大写转小写加 32，小写转大写减 32。

5. 逆序输出时下标退位错误。

   遇到换行符输入时，要注意 `i++` 后的实际位置。

## 七、本讲小结

本节课学习了字符数组和字符串。字符串本质上是以 `'\0'` 结尾的字符数组。做字符串题时，要重点关注结束标志、下标位置、字符与 ASCII 码之间的关系。
