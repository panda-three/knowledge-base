# C语言循环程序结构跳转语句教学课程

## 一、课程导入

同学们好。本节课学习循环程序结构中的跳转语句，重点是 `break` 和 `continue`。

在循环程序中，有时需要提前结束整个循环，有时只需要跳过本次循环的后续语句，直接进入下一次循环。这就需要使用跳转语句。

本节课学习目标：

1. 了解 `goto` 语句的基本功能。
2. 掌握 `break` 语句的作用。
3. 掌握 `continue` 语句的作用。
4. 能够区分 `break` 和 `continue`。
5. 能够分析含跳转语句的循环程序。

## 二、goto、break 和 continue

### 1. goto 语句

`goto` 表示跳转到指定标号处继续执行。

```c
goto label;

label:
    语句;
```

实际程序设计中不推荐频繁使用 `goto`，考试中主要了解其功能即可。

### 2. break 语句

`break` 的作用是终止当前包含它的循环或 `switch` 语句。

```c
for (i = 1; i <= 10; i++)
{
    if (i == 3)
        break;
    printf("%d ", i);
}
```

当 `i == 3` 时，直接跳出整个 `for` 循环。

### 3. continue 语句

`continue` 的作用是结束本次循环，跳过循环体后续语句，直接进入下一次循环。

```c
for (i = 1; i <= 5; i++)
{
    if (i == 3)
        continue;
    printf("%d ", i);
}
```

当 `i == 3` 时，不输出 3，直接进入下一次循环。

## 三、break 与 continue 的区别

`break`：结束整个循环。

`continue`：只结束本次循环，下一次循环仍然继续。

示例：

```c
for (i = 0; i <= 4; i++)
{
    if (i == 2)
        break;
    printf("%d", i);
}
```

输出：

```text
01
```

如果改为：

```c
for (i = 0; i <= 4; i++)
{
    if (i == 2)
        continue;
    printf("%d", i);
}
```

输出：

```text
0134
```

## 四、例题讲解

### 例题 1：break 提前结束循环

```c
int i;

for (i = 1; i < 6; i++)
{
    if (i == 3)
        break;
}

printf("i = %d\n", i);
```

分析：

循环本来准备执行 `i = 1` 到 `i = 5`。当 `i == 3` 时遇到 `break`，循环立即终止。因此最后输出：

```text
i = 3
```

### 例题 2：求不超过 20 的累加和

```c
int i, s = 0;

for (i = 1; ; i++)
{
    s += i;
    if (s > 20)
        break;
}

printf("%d %d\n", s, i - 1);
```

分析：

当加到 6 时，`1 + 2 + ... + 6 = 21`，超过 20，循环终止。`i - 1` 表示超过前最后一个不超过 20 的项是 5。

### 例题 3：continue 跳过能被 3 整除的数

```c
int i;

for (i = 1; i <= 10; i++)
{
    if (i % 3 == 0)
        continue;
    printf("%d ", i);
}
```

输出：

```text
1 2 4 5 7 8 10
```

分析：

当 `i` 能被 3 整除时，执行 `continue`，跳过本次循环后面的输出语句。

### 例题 4：嵌套循环中的 break

```c
for (i = 1; i <= 3; i++)
{
    for (j = 1; j <= 5; j++)
    {
        if (j == 3)
            break;
        printf("%d ", j);
    }
    printf("\n");
}
```

分析：

内层 `break` 只跳出当前内层循环，不会跳出外层循环。因此每一行都输出：

```text
1 2
```

共输出 3 行。

## 五、易错点

1. 误以为 `continue` 会结束整个循环。

   `continue` 只结束本次循环。

2. 误以为内层 `break` 会跳出所有循环。

   `break` 只跳出当前包含它的那一层循环。

3. `continue` 后面的语句不会执行。

   只要执行到 `continue`，本次循环中它后面的语句都会被跳过。

4. 在 `switch` 中的 `break` 与循环中的 `break` 都是跳出当前包含结构。

## 六、本讲小结

本节课学习了跳转语句。`break` 用来终止当前循环或 `switch`，`continue` 用来跳过本次循环的后续语句。分析题目时，要看清楚跳转语句位于哪一层结构中。
