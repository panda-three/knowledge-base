# 数组排序第二课时：直接插入排序法与顺序比较排序法教学

## 一、课程导入

同学们好。本节课继续学习数组排序，重点是直接插入排序法和顺序比较排序法。

上一节课学习了直接选择排序和冒泡排序。本节课的两种方法同样是考试中常见的排序算法，尤其要掌握循环边界、移动过程和交换条件。

本节课学习目标：

1. 理解直接插入排序法的基本思想。
2. 掌握直接插入排序的移动过程。
3. 理解顺序比较排序法的基本思想。
4. 能够分析指定下标范围或指定下标间隔的排序。

## 二、直接插入排序法

直接插入排序可以类比整理扑克牌。

基本思想：

1. 前面的若干个元素已经有序。
2. 取出下一个待插入元素。
3. 在前面有序序列中找到合适位置。
4. 将比它大的元素后移。
5. 把待插入元素放入空出的位置。

升序排序核心代码：

```c
for (i = 1; i < n; i++)
{
    x = a[i];
    j = i - 1;

    while (j >= 0 && a[j] > x)
    {
        a[j + 1] = a[j];
        j--;
    }

    a[j + 1] = x;
}
```

这里 `x` 保存待插入元素，`j` 从已排序部分的末尾向前查找。

## 三、顺序比较排序法

顺序比较排序法的基本思想：

固定一个位置 `i`，用它依次与后面所有元素比较。如果发现后面的元素更小，就立即交换。

升序排序核心代码：

```c
for (i = 0; i < n - 1; i++)
{
    for (j = i + 1; j < n; j++)
    {
        if (a[i] > a[j])
        {
            t = a[i];
            a[i] = a[j];
            a[j] = t;
        }
    }
}
```

这种方法代码比较简洁，但交换次数可能较多。

## 四、例题讲解

### 例题 1：直接插入排序过程

原数组：

```text
20 16 34 7 23 10 48 5
```

第一趟从下标 1 开始，取出 `16`，与前面的 `20` 比较。因为 `20 > 16`，所以 `20` 后移，`16` 插入前面：

```text
16 20 34 7 23 10 48 5
```

接着处理第三个元素、第四个元素，依次插入到前面已经有序的部分中。

### 例题 2：顺序比较排序

```c
int a[6] = {34, 56, 22, 48, 18, 9};
int i, j, t;

for (i = 0; i < 5; i++)
{
    for (j = i + 1; j < 6; j++)
    {
        if (a[i] > a[j])
        {
            t = a[i];
            a[i] = a[j];
            a[j] = t;
        }
    }
}
```

分析：

`i = 0` 时，拿 `a[0]` 依次与后面的元素比较，只要后面更小就交换。第一趟结束后，最小值会出现在 `a[0]`。

### 例题 3：按个位升序、个位相同按十位降序排序

分析：

两个数比较时，不再直接比较整个数，而是先取个位：

```c
x = a[i] % 10;
y = a[j] % 10;
```

如果个位不同，按个位升序；如果个位相同，再比较十位：

```c
m = a[i] / 10;
n = a[j] / 10;
```

排序条件可以写成：

```c
if (x > y || (x == y && m < n))
{
    t = a[i];
    a[i] = a[j];
    a[j] = t;
}
```

### 例题 4：只对偶数下标元素排序

如果题目要求只对下标为偶数的元素排序，可以让循环变量每次加 2：

```c
for (i = 0; i < n - 2; i += 2)
{
    for (j = i + 2; j < n; j += 2)
    {
        if (a[i] > a[j])
        {
            t = a[i];
            a[i] = a[j];
            a[j] = t;
        }
    }
}
```

分析：

`i` 和 `j` 都只取偶数下标，因此只排序偶数下标位置上的元素，奇数下标元素不参与排序。

## 五、易错点

1. 插入排序中没有保存待插入元素。

   移动元素前必须先 `x = a[i]`。

2. 插入位置写错。

   循环结束后，应把 `x` 放到 `a[j + 1]`。

3. 顺序比较排序与直接选择排序混淆。

   顺序比较是发现更小就立即交换；直接选择是先记录最小位置，一趟结束后再交换。

4. 指定下标范围排序时边界错误。

   如下标 2 到 7，应注意循环是否包含 7。

## 六、本讲小结

本节课学习了直接插入排序和顺序比较排序。插入排序的核心是“后移腾位置再插入”，顺序比较排序的核心是“固定当前位置，与后面逐个比较，不符合就交换”。
