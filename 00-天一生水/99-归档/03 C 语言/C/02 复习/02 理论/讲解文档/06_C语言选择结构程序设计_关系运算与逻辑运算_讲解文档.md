# C语言选择结构程序设计：关系运算与逻辑运算课程讲解

## 一、课程导入

同学们好，前面第三章我们学习了顺序结构程序设计。

在顺序结构中，各条语句按照自上而下的顺序依次执行。执行完上一条语句后，程序会自动执行下一条语句。这是最简单、最基础的程序结构。

但是，在现实生活和实际程序设计中，很多问题并不是简单地从上到下执行就能解决的。很多时候，程序需要根据某个条件是否成立，决定接下来执行哪一部分内容。

例如：

输入一个数，如果它是正数，就输出它；否则不输出。

输入一个年份，判断它是否是闰年。

输入一个考试成绩，判断它属于优秀、良好、中等、及格还是不及格。

这些问题都需要根据条件进行判断，并根据判断结果选择不同的执行路径。这就是选择结构程序设计。

本章的学习目标主要包括：

1. 掌握关系表达式和逻辑表达式的应用。
2. 掌握 `if` 条件语句的使用方法。
3. 能够使用 `if` 语句的多种形式设计选择结构程序。
4. 掌握 `switch` 语句的用法。
5. 能够合理运用 `switch` 语句进行程序设计。

本节课重点学习选择结构的基础：关系运算和逻辑运算。

## 二、问题的提出

顺序结构能够编写一些简单程序，完成基本运算。但是人们对计算机的要求并不只限于简单运算，经常需要程序进行逻辑判断。

所谓逻辑判断，就是让程序判断是否满足某个给定条件，并根据判断结果进行不同处理。

例如：

```text
从键盘输入一个数，如果它是正数，则输出；否则不输出。
```

这个问题中，程序要判断输入的数是否大于 0。

如果大于 0，说明它是正数，程序输出它。

如果小于或等于 0，说明它不是正数，程序不输出。

再如：

```text
输入一个四位年份，判断它是否是闰年。
```

闰年的判断条件是：

四年一闰，百年不闰，四百年又闰。

也就是说，一个年份如果能被 4 整除但不能被 100 整除，或者能被 400 整除，就是闰年。

再如：

```text
输入一个考试成绩，判断它的等级。
```

成绩等级可能包括优秀、良好、中等、及格、不及格。这是典型的多分支选择结构。

这些问题在进入不同程序分支之前，都需要先进行条件判断。条件判断的基础就是关系运算和逻辑运算。

## 三、关系运算

在前面的学习中，我们已经学习了算术运算。算术运算主要完成加、减、乘、除、取余等数值计算。

关系运算本质上是比较运算，用来比较两个数据之间是否满足某种关系。

例如：

```c
a > b
```

其中，`>` 表示“大于”关系运算。

如果 `a = 5`，`b = 3`，那么 `a > b` 成立，结果为真。

如果 `a = 2`，`b = 3`，那么 `a > b` 不成立，结果为假。

关系运算的结果只有两种：真或假。

由于 C 语言没有专门的逻辑型数据，通常用整数 `1` 表示真，用整数 `0` 表示假。

## 四、关系运算符

C 语言中常用的关系运算符共有六个：

```text
<    小于
<=   小于或等于
>    大于
>=   大于或等于
==   等于
!=   不等于
```

需要特别注意：

第一，小于等于必须写成 `<=`，不能写成数学中的 `≤`。

第二，大于等于必须写成 `>=`，不能写成数学中的 `≥`。

第三，判断两个值是否相等时，要使用双等号 `==`。

第四，单等号 `=` 是赋值运算符，不是相等关系运算符。

例如：

```c
a = 3;
```

表示把 3 赋给变量 `a`。

而：

```c
a == 3
```

表示判断 `a` 的值是否等于 3。

第五，不等于要写成 `!=`。

这些符号在后续选择结构程序中会频繁使用，特别是 `==` 和 `=` 的区别一定要记牢。

## 五、关系运算符的优先级和结合性

关系运算符都是双目运算符，也就是说，它们左右两边都需要有运算对象。

例如：

```c
a > b
a <= b
a != b
```

关系运算符的结合方向都是自左向右。

在优先级方面：

`<`、`<=`、`>`、`>=` 的优先级相同。

`==`、`!=` 的优先级相同。

并且，`<`、`<=`、`>`、`>=` 的优先级高于 `==`、`!=`。

关系运算符与其他运算符相比：

关系运算符的优先级低于算术运算符。

关系运算符的优先级高于赋值运算符。

例如：

```c
b = a > 3 + 1;
```

先计算 `3 + 1`，得到 4。

再计算 `a > 4`。

最后把关系表达式的结果赋给 `b`。

如果 `a = 5`，则 `a > 4` 成立，结果为 1，所以 `b` 的值为 1。

## 六、关系表达式

由关系运算符把两个表达式连接起来，就构成关系表达式。

例如：

```c
a > b
a + b > c - d
(a = 3) <= (b = 5)
'a' >= 'b'
```

在表达式：

```c
a + b > c - d
```

中，由于算术运算符优先级高于关系运算符，所以先计算 `a + b` 和 `c - d`，再比较大小。

在表达式：

```c
'a' >= 'b'
```

中，字符会按 ASCII 码参与比较。小写字母 `'a'` 的 ASCII 码是 97，小写字母 `'b'` 的 ASCII 码是 98，因此 `'a' >= 'b'` 不成立，表达式结果为 0。

关系表达式的值是逻辑值，也就是“真”或“假”。在 C 语言中，真用 1 表示，假用 0 表示。

## 七、关系表达式例题

设：

```c
int number1 = 3, number2 = 4, number3 = 5;
```

### 例 1

```c
number1 > number2
```

相当于：

```c
3 > 4
```

不成立，所以表达式值为 0。

### 例 2

```c
number1 > number2 != number3
```

先计算：

```c
number1 > number2
```

即：

```c
3 > 4
```

结果为 0。

再计算：

```c
0 != 5
```

成立，所以整个表达式值为 1。

### 例 3

```c
number1 < number2 < number3
```

不要直接按数学中的连续不等式理解。

在 C 语言中，关系运算符从左向右结合。

先计算：

```c
3 < 4
```

结果为 1。

再计算：

```c
1 < 5
```

成立，所以表达式值为 1。

需要注意，如果写成类似 `a < b < c`，它并不等价于数学中的 `a < b 且 b < c`。在 C 语言中，如果要表达两个条件同时成立，需要使用逻辑与运算。

## 八、关系表达式练习

设：

```c
int a = 3, b = 2, c = 1;
```

请分析以下表达式的值。

### 1. `a - b > c`

先算：

```c
a - b = 3 - 2 = 1
```

再判断：

```c
1 > 1
```

不成立，所以结果为 0。

### 2. `a > b + c`

先算：

```c
b + c = 2 + 1 = 3
```

再判断：

```c
3 > 3
```

不成立，所以结果为 0。

### 3. `a > b > c`

关系运算从左向右结合。

先算：

```c
3 > 2
```

成立，结果为 1。

再算：

```c
1 > 1
```

不成立，所以结果为 0。

### 4. `a < b < c`

先算：

```c
3 < 2
```

不成立，结果为 0。

再算：

```c
0 < 1
```

成立，所以结果为 1。

这个结果和数学直觉不同，因此连续关系表达式一定要特别小心。

### 5. `a == b == c`

先算：

```c
3 == 2
```

不成立，结果为 0。

再算：

```c
0 == 1
```

不成立，所以结果为 0。

### 6. `a = b = c`

这里不是关系运算，而是赋值运算。

赋值运算从右向左结合。

先把 `c` 的值 1 赋给 `b`，再把 `b` 的值 1 赋给 `a`。

表达式最终值为 1，执行后 `a`、`b`、`c` 的值都为 1。

### 7. `a != b != c`

先算：

```c
3 != 2
```

成立，结果为 1。

再算：

```c
1 != 1
```

不成立，所以结果为 0。

## 九、逻辑运算

关系表达式只能描述单一条件。

例如：

```c
x >= 0
```

只能表示 `x` 大于或等于 0。

如果要表达：

```text
x 大于等于 0，并且 x 小于 10
```

就需要使用逻辑运算。

在 C 语言中不能写成数学形式：

```c
0 <= x < 10
```

因为它会被解释为：

```c
(0 <= x) < 10
```

这种写法不能正确表达数学中的区间关系。

正确写法应该是：

```c
x >= 0 && x < 10
```

其中，`&&` 表示逻辑与，意思是两个条件都必须成立。

## 十、逻辑运算符

C 语言提供三种逻辑运算符：

```text
!    逻辑非
&&   逻辑与
||   逻辑或
```

### 1. 逻辑非 `!`

逻辑非是单目运算符，只有一个运算对象。

它的作用是把真变成假，把假变成真。

例如：

```c
!0
```

结果为 1。

```c
!3
```

结果为 0。

在 C 语言中，0 表示假，非 0 表示真。因此，任何非 0 数进行逻辑非运算，结果都是 0。

逻辑非的优先级较高，结合方向是从右向左。

### 2. 逻辑与 `&&`

逻辑与是双目运算符。

只有当两个运算对象都为真，也就是都为非 0 时，结果才为 1。

只要有一个运算对象为假，结果就是 0。

例如：

```c
a >= 180 && sex == 1
```

可以表示“身高大于等于 180，并且性别满足要求”。两个条件都成立时，整个表达式才成立。

### 3. 逻辑或 `||`

逻辑或也是双目运算符。

只要两个运算对象中有一个为真，结果就是 1。

只有两个运算对象都为假时，结果才为 0。

例如：

```c
hasLicenseA || hasLicenseB
```

表示“甲或乙至少有一个人有驾照”。只要有一个条件成立，整个表达式就成立。

## 十一、逻辑运算规则表

设 `a` 和 `b` 的逻辑值可能为 0 或非 0。

| a | b | !a | !b | a && b | a || b |
|---|---|----|----|--------|--------|
| 0 | 0 | 1 | 1 | 0 | 0 |
| 0 | 非0 | 1 | 0 | 0 | 1 |
| 非0 | 0 | 0 | 1 | 0 | 1 |
| 非0 | 非0 | 0 | 0 | 1 | 1 |

这张表要重点掌握：

逻辑非：0 变 1，非 0 变 0。

逻辑与：两边都真才真。

逻辑或：有一边真就真。

## 十二、逻辑运算符的优先级

三个逻辑运算符的优先级顺序是：

```text
!  最高
&& 次之
|| 最低
```

逻辑非 `!` 的优先级高于算术运算符和关系运算符。

逻辑与 `&&` 和逻辑或 `||` 的优先级低于算术运算符和关系运算符。

例如：

```c
!a > b || c > d && e == d
```

可以按照优先级理解为：

```c
((!a) > b) || ((c > d) && (e == d))
```

在分析复杂逻辑表达式时，建议先根据优先级加上括号，再逐步计算。

## 十三、逻辑运算的短路规则

C 语言中的逻辑与和逻辑或具有短路特性。

### 1. 逻辑与的短路

对于逻辑与表达式：

```c
表达式1 && 表达式2
```

如果前面的 `表达式1` 已经为假，也就是值为 0，那么整个逻辑与表达式一定为假，后面的表达式就不再计算。

这可以理解为“一票否决”。

例如：

```c
x > 2 && y < z && x + y > z
```

如果 `x > 2` 已经不成立，后面的部分就不会再计算。

### 2. 逻辑或的短路

对于逻辑或表达式：

```c
表达式1 || 表达式2
```

如果前面的 `表达式1` 已经为真，也就是值为 1，那么整个逻辑或表达式一定为真，后面的表达式就不再计算。

例如：

```c
x < 2 || y > z || y + 1 > z
```

如果 `x < 2` 已经成立，后面的部分就不会再计算。

短路规则在分析带有自增、自减或赋值操作的表达式时尤其重要。

## 十四、逻辑表达式例题

设：

```c
int a = 3, b = 2;
```

分析以下表达式。

### 1. `!b`

`b` 的值是 2，是非 0，表示真。

`!b` 的结果为 0。

### 2. `a && b`

`a` 和 `b` 都是非 0。

逻辑与两边都为真，结果为 1。

### 3. `!a || b`

`a` 是 3，非 0，所以 `!a` 为 0。

`b` 是 2，非 0。

`0 || 2` 的结果为 1。

### 4. `a || b`

`a` 和 `b` 都是非 0。

逻辑或只要有一边为真即可，因此结果为 1。

### 5. `4 && 0 || 2`

先算逻辑与，因为 `&&` 优先级高于 `||`。

```c
4 && 0
```

一个真，一个假，结果为 0。

再算：

```c
0 || 2
```

有一个非 0，结果为 1。

所以整个表达式值为 1。

## 十五、判断三个整数是否从大到小排列

题目：从键盘输入三个互不相同的整数，判断它们是否按从大到小排列。

错误写法：

```c
a > b > c
```

这种写法不能表示数学中的 `a > b 且 b > c`。

正确写法应该是：

```c
a > b && b > c
```

程序如下：

```c
#include <stdio.h>

int main(void)
{
    int a, b, c;

    scanf("%d%d%d", &a, &b, &c);
    printf("%d\n", a > b && b > c);

    return 0;
}
```

如果三个数确实从大到小排列，输出 1；否则输出 0。

## 十六、表达式例题分析

### 例 1：判断 a 和 b 同时为正或同时为负

要求：`a` 和 `b` 同时为正，或者同时为负。

表达式应写为：

```c
(a > 0 && b > 0) || (a < 0 && b < 0)
```

也可以根据两个数乘积为正来判断：

```c
a * b > 0
```

如果两个数同号，乘积大于 0；如果异号，乘积小于 0。

### 例 2：判断字符 ch 是否为大写字母

大写字母范围是 `'A'` 到 `'Z'`。

判断表达式为：

```c
ch >= 'A' && ch <= 'Z'
```

如果成立，说明 `ch` 是大写字母。

可以用条件运算符把大写字母转换为小写字母：

```c
ch = (ch >= 'A' && ch <= 'Z') ? ch + 32 : ch;
```

如果 `ch` 是大写字母，就加 32 转换为小写字母；否则保持不变。

### 例 3：短路运算中的变量变化

设：

```c
int a = 5, b = 6, m = 1, n = 2;
m = a > b && n++;
```

由于 `a > b` 不成立，逻辑与左边已经为 0，右边 `n++` 不再执行。

因此，`n` 的值仍然是 2。

这个例子说明：逻辑与左边为假时，右边不会再计算。

再如：

```c
int a = 1, b = 2, m = 0, n = 0, k;
k = b > a || m++;
```

由于 `b > a` 成立，逻辑或左边已经为真，右边 `m++` 不再执行。

所以 `m` 的值仍然是 0，`k` 的值为 1。

## 十七、常见错误提醒

第一，把 `==` 写成 `=`。

```c
if (a = 3)
```

这不是判断 `a` 是否等于 3，而是把 3 赋给 `a`。

判断相等应写为：

```c
if (a == 3)
```

第二，把连续比较写成数学形式。

错误写法：

```c
0 <= x < 10
```

正确写法：

```c
x >= 0 && x < 10
```

第三，把大于等于、小于等于写成数学符号。

错误写法：

```text
x ≥ 0
x ≤ 10
```

C 语言中应写为：

```c
x >= 0
x <= 10
```

第四，忽略逻辑运算的短路特性。

当逻辑与左边为假时，右边不计算。

当逻辑或左边为真时，右边不计算。

如果右边含有自增、自减或赋值操作，一定要判断它是否真的会被执行。

## 十八、本讲小结

本节课主要学习了选择结构程序设计的基础内容：关系运算和逻辑运算。

需要重点掌握：

1. 关系运算用于比较两个表达式之间的关系。
2. 关系表达式的值只有真和假，C 语言中用 1 表示真，用 0 表示假。
3. 常用关系运算符有 `<`、`<=`、`>`、`>=`、`==`、`!=`。
4. 判断相等必须使用 `==`，不能写成赋值符号 `=`。
5. 逻辑运算符有 `!`、`&&`、`||`。
6. `!` 表示逻辑非，0 变 1，非 0 变 0。
7. `&&` 表示逻辑与，两边都真才真。
8. `||` 表示逻辑或，有一边真就真。
9. 不能用 `a < b < c` 表示数学中的连续比较，应写成 `a < b && b < c`。
10. 逻辑与和逻辑或具有短路特性。

关系运算和逻辑运算是后续学习 `if` 语句、`switch` 语句和选择结构程序设计的基础。课后请同学们多做表达式计算练习，熟练掌握优先级、结合性和短路规则。
