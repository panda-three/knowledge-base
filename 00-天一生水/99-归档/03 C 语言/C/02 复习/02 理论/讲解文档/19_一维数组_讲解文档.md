# C语言第六章一维数组入门讲解

## 一、课程导入

同学们好。本节课开始学习第六章数组。

数组是 C 语言中最简单的构造类型，用来存放一组相同类型的数据。前面学习的变量一次只能保存一个值，而数组可以用一个名字管理多个同类型数据。

本节课学习目标：

1. 理解一维数组的概念。
2. 掌握一维数组的定义方法。
3. 掌握数组元素的引用方法。
4. 掌握一维数组的初始化规则。
5. 能够用数组处理一组成绩或一组数据。

## 二、一维数组的定义

一维数组的定义形式为：

```c
类型名 数组名[常量表达式];
```

例如：

```c
int a[10];
```

表示定义了一个整型数组 `a`，共有 10 个元素。

注意：

1. 数组名表示整组数据的名称。
2. 方括号中的常量表达式表示数组长度。
3. 数组长度必须是整型常量表达式。
4. 数组必须先定义后使用。

## 三、数组元素的引用

数组元素通过下标引用。

```c
a[0], a[1], a[2], ..., a[9]
```

对于长度为 10 的数组，下标从 0 到 9。第一个元素是 `a[0]`，最后一个元素是 `a[9]`。

数组元素可以像普通变量一样使用：

```c
a[2] = 5;
printf("%d", a[2]);
scanf("%d", &a[2]);
```

输入数组元素时要加地址符 `&`。

## 四、一维数组的初始化

数组可以在定义时初始化：

```c
int a[5] = {1, 2, 3, 4, 5};
```

如果只给部分元素赋值，后面没有赋值的元素默认为 0：

```c
int a[10] = {1, 2, 3, 4, 5};
```

则：

```text
a[0] 到 a[4] 分别为 1,2,3,4,5
a[5] 到 a[9] 默认为 0
```

如果初始化时给出了全部元素，可以省略数组长度：

```c
int a[] = {1, 2, 3, 4, 5};
```

系统会根据初值个数确定数组长度为 5。

## 五、例题讲解

### 例题 1：输出数组中大于 4 的元素

```c
float b[] = {3.0, 3.7, 4.9, 5.9, 2.6, 7.8};
int i;

for (i = 0; i < 6; i++)
{
    if (b[i] > 4)
        printf("%.1f\t", b[i]);
}
```

输出：

```text
4.9    5.9    7.8
```

分析：

数组初始化时省略了长度，系统根据 6 个初值确定数组长度为 6。

### 例题 2：计算学生总评成绩

题目：

```text
输入某学生平时、实习、测验、期末成绩，分别按 10%、20%、20%、50% 计算总评成绩。
```

参考程序：

```c
#include <stdio.h>

int main()
{
    int i;
    float score[5];
    float rate[4] = {0.1, 0.2, 0.2, 0.5};

    score[4] = 0;

    for (i = 0; i < 4; i++)
    {
        scanf("%f", &score[i]);
        score[4] += score[i] * rate[i];
    }

    printf("总评成绩为%6.1f\n", score[4]);
    return 0;
}
```

分析：

`score[0]` 到 `score[3]` 存放四项成绩，`score[4]` 存放总评成绩。`rate` 数组存放对应权重。

### 例题 3：判断数组是否对称

思路：

一维数组如果左右对应元素相等，则为对称数组。

```c
for (i = 0; i < n / 2; i++)
{
    if (a[i] != a[n - 1 - i])
    {
        flag = 0;
        break;
    }
}
```

例如长度为 6 时，需要比较：

```text
a[0] 和 a[5]
a[1] 和 a[4]
a[2] 和 a[3]
```

## 六、易错点

1. 数组下标从 0 开始。

   长度为 `n` 的数组，最后一个元素是 `a[n - 1]`。

2. 定义数组时长度必须是常量表达式。

3. 输入数组元素时忘记地址符。

   应写 `scanf("%d", &a[i]);`。

4. 部分初始化时误以为未赋值元素没有值。

   未赋值元素默认初始化为 0。

## 七、本讲小结

本节课学习了一维数组的定义、初始化和引用。数组用于保存一组相同类型的数据，数组元素可以像普通变量一样参与输入、输出和运算。
