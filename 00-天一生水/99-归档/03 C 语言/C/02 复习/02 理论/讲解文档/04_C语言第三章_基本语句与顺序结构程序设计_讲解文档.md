# C语言第三章：基本语句与顺序结构程序设计

## 一、课程导入

同学们好，现在我们开始第三章的学习。本章内容是“基本语句与顺序结构程序设计”。

在程序中，常量、变量、运算符和表达式是构成程序的基本成分。从本章开始，我们将学习如何把这些基本成分有效地组合在一起，构成合法、有意义的 C 程序。

顺序结构是程序结构化设计的基础，也是最简单、最常用的基本结构。本章的学习目标是：

1. 了解结构化程序设计的基本思想。
2. 掌握 C 语言语句的基本分类。
3. 掌握字符输入输出函数 `getchar` 和 `putchar` 的使用。
4. 掌握格式化输出函数 `printf` 的基本用法。
5. 能够正确设计简单的顺序结构程序。

## 二、C 语言语句

在 C 语言中，语句通常是以分号 `;` 结束的一段字符序列。每条语句后面一般都要加分号。

高级语言源程序的基本单位是语句。C 语言中的语句可以分为两大类：

1. 简单语句
2. 结构语句

简单语句用于完成简单动作；结构语句用于实现程序的控制流程。

## 三、简单语句

### 1. 空语句

空语句只有一个分号：

```c
;
```

空语句前面没有任何表达式或操作，只有一个分号。空语句常出现在选择结构和循环结构中。

### 2. 表达式语句

表达式后面加分号，就构成表达式语句。例如：

```c
i++;
i = i + 10;
a = b + c;
```

这些语句都通过表达式完成一定的计算或赋值操作。

### 3. 函数调用语句

函数调用后面加分号，就构成函数调用语句。例如：

```c
printf("Hello");
```

其中，`printf` 是输出函数，整条语句的作用是在屏幕上输出内容。

### 4. 复合语句

复合语句是用一对大括号 `{ }` 把若干条有序语句组合在一起构成的语句。

例如：

```c
{
    a = 10;
    b = 20;
    c = a + b;
}
```

在逻辑上，复合语句可以看作一条语句。需要注意的是，复合语句的大括号后面一般不需要再加分号。

## 四、结构语句与流程控制

结构语句主要用于控制程序的执行流程，包括选择语句和循环语句。

### 1. 选择语句

选择语句用于根据条件选择不同的执行路径，主要包括：

```c
if
if ... else
switch
```

其中，`if` 语句是条件语句，`switch` 语句用于多分支选择结构。这部分内容会在后续章节中详细学习。

### 2. 循环语句

循环语句用于重复执行某些操作，主要包括：

```c
for
while
do ... while
```

循环语句是后续程序设计中的重点内容。

### 3. 非结构化控制语句

C 语言中还提供了一些改变程序流程的语句：

`break` 语句用于退出循环结构或 `switch` 结构。

`continue` 语句用于循环结构中，它的作用是结束本次循环，不再执行循环体中 `continue` 后面的语句，直接进入下一次循环。

`return` 语句用于函数返回。例如前面程序中常见的：

```c
return 0;
```

表示函数结束，并返回状态值 0。

`goto` 语句是无条件转向语句，可以把程序控制转向某个标号位置。例如：

```c
goto k1;
```

表示程序跳转到标号 `k1` 所在的位置。实际编程中不提倡使用 `goto`，本阶段只要求能够看懂。

## 五、数据的输入与输出

在计算机系统中，输入和输出是以计算机主机为主体而言的。

从主机向输出设备传送数据，称为输出，英文是 `output`。

从输入设备向计算机传送数据，称为输入，英文是 `input`。常见输入设备包括键盘、鼠标等。

C 语言本身没有定义专门处理输入输出的关键字，程序的输入输出通常通过系统库函数完成。

C 语言的输入输出函数信息主要包含在标准输入输出头文件中：

```c
stdio.h
```

其中，`std` 是 standard 的缩写，表示“标准”；`io` 表示 input 和 output，即输入和输出；`.h` 表示头文件。

因此，使用标准输入输出函数时，通常要在程序开头写：

```c
#include <stdio.h>
```

## 六、include 命令与头文件

在使用系统库函数时，要用编译预处理命令 `#include` 把有关头文件包含到本程序中。

常见写法有两种：

```c
#include <stdio.h>
```

```c
#include "stdio.h"
```

使用尖括号 `< >` 时，编译系统会到系统库函数头文件目录中查找要包含的文件，这称为标准方式。

使用双引号 `" "` 时，系统会先在用户当前目录中查找要包含的文件；如果找不到，再按标准方式查找。

一般来说，如果要包含系统库函数，建议使用尖括号形式：

```c
#include <stdio.h>
```

这样可以节约查找时间。

如果要包含用户自己编写的头文件，通常使用双引号形式。

需要注意，在 C 语言字符串中，如果目录路径中要表示反斜杠，需要使用两个反斜杠 `\\`，因为 `\\` 才表示一个反斜杠字符。

## 七、字符输入输出函数

最简单的字符输入输出函数是：

```c
getchar()
putchar()
```

它们都定义在 `stdio.h` 中。

`getchar` 的功能是从键盘读入一个字符。

`putchar` 的功能是向屏幕输出一个字符。

### 1. getchar 函数

`getchar` 用于从键盘输入一个字符。它是无参函数，括号中不写参数。

例如：

```c
c = getchar();
```

这条语句表示从键盘读入一个字符，并把该字符赋给变量 `c`。

如果从键盘输入小写字母 `a`，那么执行后变量 `c` 的值就是字符 `'a'`。

需要注意，`getchar` 一次只能接收一个字符。

### 2. putchar 函数

`putchar` 用于向屏幕输出一个字符。

例如：

```c
putchar(c);
```

这条语句表示把变量 `c` 中存放的字符输出到屏幕当前光标位置。

`putchar` 是有参函数，括号中的 `c` 是它的参数。

## 八、字符输入输出程序示例

来看一个简单程序：

```c
#include <stdio.h>

int main(void)
{
    char c;
    c = getchar();
    putchar(c);
    return 0;
}
```

程序说明：

第一，定义字符型变量 `c`。

第二，执行 `c = getchar();`，从键盘读入一个字符，并赋给变量 `c`。

第三，执行 `putchar(c);`，把变量 `c` 的值输出到屏幕上。

如果输入字符 `a`，屏幕上就会输出字符 `a`。

## 九、小写字母转换为大写字母

再看一个程序：

```c
#include <stdio.h>

int main(void)
{
    char ch;
    ch = getchar();
    putchar(ch - 32);
    return 0;
}
```

如果输入小写字母 `e`，程序会输出大写字母 `E`。

原因是字符在计算机中按 ASCII 码存储。小写字母 `a` 的 ASCII 码是 97，大写字母 `A` 的 ASCII 码是 65，二者相差 32。

所以，小写字母减去 32，就可以得到对应的大写字母。

例如：

小写 `e` 的 ASCII 码是 101。

`101 - 32 = 69`。

ASCII 码 69 对应大写字母 `E`。

这里要注意，`putchar(ch - 32);` 并没有改变变量 `ch` 本身的值，只是把 `ch - 32` 的结果对应的字符输出出来。

## 十、getchar 与 putchar 的注意事项

第一，`getchar` 一次只能接收一个字符。

如果要输入整数 `365`，不能使用 `getchar` 一次完成，因为它只能读入一个字符。虽然字符型数据可以和整型数据参与运算，但 `365` 已经不是一个单个字符。

第二，`putchar` 一次也只能输出一个字符。

第三，`getchar` 接收到的字符可以赋给字符型变量，也可以赋给整型变量。

第四，`getchar` 的返回值也可以不赋给变量，而直接作为表达式的一部分使用。例如：

```c
putchar(getchar());
```

这条语句表示从键盘读入一个字符，并立即把这个字符输出到屏幕上。

书写时要注意括号配对。`putchar` 有一对括号，`getchar` 也有一对括号，不能漏写。

## 十一、getch 和 getche

有些程序中可能会看到：

```c
getch()
getche()
```

它们和 `getchar` 类似，也用于从键盘接收字符，但通常定义在其他头文件中，例如 `conio.h`。

`getch` 和 `getche` 的特点是直接从键盘接收字符，不需要按 Enter 键确认。

二者区别是：

`getch` 输入后不回显到屏幕上。

`getche` 输入后会回显到屏幕上。

在高中阶段，这两个函数一般不要求重点使用，只需要能够识别。

## 十二、字符与 ASCII 码输出示例

题目：从键盘输入一个字符，输出该字符以及它对应的 ASCII 码。

程序如下：

```c
#include <stdio.h>

int main(void)
{
    char x;
    x = getchar();
    putchar(x);
    printf("\n%d", x);
    return 0;
}
```

程序说明：

`x = getchar();` 输入一个字符。

`putchar(x);` 输出该字符。

`printf("\n%d", x);` 换行后输出该字符对应的 ASCII 码值。

其中，`%d` 是十进制整型输出格式符。

## 十三、格式化输出函数 printf

`printf` 和 `scanf` 是最常用的输入输出函数。`printf` 用于格式化输出，`scanf` 用于格式化输入。本节重点学习 `printf`。

`printf` 的功能是按照用户指定的格式，把指定的数据输出到显示屏上。

`printf` 是标准库函数，使用前通常需要包含头文件：

```c
#include <stdio.h>
```

`printf` 的基本调用形式是：

```c
printf("格式控制字符串", 输出项列表);
```

其中，输出项列表可以省略。

如果省略输出项列表，`printf` 只输出格式控制字符串中的普通内容。例如：

```c
printf("Hello");
```

输出结果是：

```text
Hello
```

但是，如果格式控制字符串中包含格式说明符，例如 `%d`、`%f`、`%c`，就需要在后面提供对应的输出项。

例如：

```c
printf("%d,%d", i, j);
```

其中，`"%d,%d"` 是格式控制字符串，`i, j` 是输出项列表。

输出项可以是变量、常量，也可以是表达式。但输出项的数量和类型要与前面的格式说明符一一对应。

## 十四、格式控制字符串

格式控制字符串由两部分组成：

1. 格式字符串
2. 非格式字符串

格式字符串以 `%` 开头，用来指定输出格式。例如：

```c
%d
%5d
%f
%.2f
%c
```

非格式字符串会原样输出。例如：

```c
printf("a=%d,b=%d", a, b);
```

其中，`a=`、`,b=` 都是非格式字符串，会照样输出；两个 `%d` 是格式字符串，分别由 `a` 和 `b` 的值替换。

## 十五、输出宽度

格式说明中可以指定输出宽度。例如：

```c
printf("%5d", a);
```

表示以 5 个字符宽度输出整数 `a`。

如果实际数据不足 5 位，默认在前面补空格，右对齐输出。

例如，若 `a = 3`：

```c
printf("%5d", a);
```

输出时，`3` 前面会有 4 个空格。

如果实际数据超过指定宽度，则按实际位数输出，不会截断数据。

例如，若 `a = 30000`：

```c
printf("%3d", a);
```

仍然会输出：

```text
30000
```

不会因为指定宽度是 3 就舍去前面的数字。

## 十六、左对齐与右对齐

默认情况下，带宽度的输出是右对齐。

例如：

```c
printf("%5d", 3);
```

表示右对齐输出，前面补空格。

如果要左对齐，可以在 `%` 后面加负号：

```c
printf("%-5d", 3);
```

表示以 5 个字符宽度左对齐输出，`3` 后面补空格。

如果使用：

```c
printf("%+5d", 3);
```

正数前会显示加号，负数前显示负号，并按指定宽度右对齐。

## 十七、浮点数输出

浮点数常用 `%f` 输出。

如果没有指定小数位数，`%f` 默认输出小数点后 6 位。

例如：

```c
printf("%f", 3.14);
```

输出结果为：

```text
3.140000
```

可以使用 `m.n` 的形式指定总宽度和小数位数：

```c
printf("%5.2f", x);
```

其中，`5` 表示总宽度，`2` 表示保留 2 位小数。

例如，若 `x = 3.14`，则 `%5.2f` 表示整个输出宽度为 5，其中包括：

1. 整数部分
2. 小数点
3. 两位小数

如果小数位不足，会用 `0` 补足。

如果小数位超出指定小数位数，会按四舍五入处理。

例如：

```c
printf("%.4f", 3.1415926);
```

输出：

```text
3.1416
```

注意，浮点数格式化输出的小数截取会四舍五入；而把实型数据赋给整型变量时，小数部分会直接舍去，不进行四舍五入。

## 十八、常用格式字符

常用格式字符如下：

`%c` 按字符形式输出。

`%d` 按十进制整型输出。

`%ld` 按十进制长整型输出。

`%f` 按浮点型输出，默认保留 6 位小数。

`%e` 或 `%E` 按科学计数法输出。

`%o` 按八进制整型输出。

`%s` 按字符串形式输出。

`%u` 按无符号十进制整型输出。

`%x` 或 `%X` 按十六进制整型输出。

`%%` 输出一个百分号 `%`。

例如，若字符变量 `a` 的值为 `'A'`：

```c
printf("%c", a);
```

输出字符：

```text
A
```

如果用 `%d` 输出：

```c
printf("%d", a);
```

输出的是字符 `A` 对应的 ASCII 码：

```text
65
```

如果用 `%o` 输出整数 65，会得到八进制形式：

```text
101
```

如果用 `%x` 输出整数 65，会得到十六进制形式：

```text
41
```

## 十九、printf 示例分析

示例：

```c
#include <stdio.h>

int main(void)
{
    int number = 9;
    float cups = 13.5;
    float pi = 3.14;

    printf("%d CEOs drank %f cups of coffee\n", number, cups);
    printf("The value of pi is %f\n", pi);
    printf("A fine day\n");
    printf("$%d\n", 2 * 3100);

    return 0;
}
```

第一条输出语句中，`%d` 由 `number` 的值替换，`%f` 由 `cups` 的值替换。由于 `%f` 默认保留 6 位小数，`13.5` 会输出为 `13.500000`。

第二条输出语句中，`pi` 按 `%f` 格式输出，结果为 `3.140000`。

第三条输出语句没有格式说明符，会原样输出字符串内容。

第四条输出语句中，`2 * 3100` 是表达式，先计算表达式的值，再按 `%d` 输出，结果为 `6200`。

## 二十、表达式输出示例

示例：

```c
int a = 3, b = 2;
float c = 5, d = 2.5;
printf("%.2f", a + b / 2 + c / d);
```

分析：

`b / 2` 是整数除以整数，结果取整，为 `1`。

`c / d` 是实型运算，结果为 `2.0`。

所以表达式结果为：

```text
3 + 1 + 2.0 = 6.0
```

如果按 `%.2f` 输出，则保留两位小数。

在分析这类题目时，要特别注意整数除法和实型除法的区别。

## 二十一、类型转换与输出宽度示例

示例：

```c
float a;
int b;

a = 24.5 / 5;
b = a;

printf("%6.2f%3d", a, b);
```

分析：

`24.5 / 5` 的结果是 `4.9`，赋给实型变量 `a`，所以 `a` 的值为 `4.9`。

再把 `a` 赋给整型变量 `b` 时，小数部分被舍去，所以 `b` 的值为 `4`。

`%6.2f` 表示以总宽度 6、保留 2 位小数输出 `a`，结果为 `4.90`，前面补空格。

`%3d` 表示以 3 位宽度输出整数 `b`，不足宽度时前面补空格。

## 二十二、复合赋值与条件表达式输出

示例：

```c
int x = 1, y = 2, z = 3;
x += y += z;
printf("%d\t%d", x, x < y ? x : y);
```

分析：

`y += z` 等价于：

```c
y = y + z;
```

所以 `y` 变为 `5`。

`x += y` 等价于：

```c
x = x + y;
```

所以 `x` 变为 `6`。

`\t` 是水平制表符，用于跳到下一个制表位置。

条件表达式：

```c
x < y ? x : y
```

表示如果 `x < y` 成立，就取 `x` 的值；否则取 `y` 的值。

此时 `x = 6`，`y = 5`，条件 `x < y` 不成立，所以输出 `y` 的值，即 `5`。
