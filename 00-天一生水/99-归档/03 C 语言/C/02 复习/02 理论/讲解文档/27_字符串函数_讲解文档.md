# C语言字符串函数课程讲解

## 一、课程导入

同学们好。本节课学习字符串函数。

上一节课学习了字符数组和字符串的基础操作，本节课进一步学习 C 语言中处理字符串的常用函数，包括输入输出、连接、复制、比较和长度统计等。

本节课学习目标：

1. 掌握 `gets`、`puts` 的基本用法。
2. 掌握字符串连接函数 `strcat`。
3. 掌握字符串复制函数 `strcpy`。
4. 掌握字符串比较函数 `strcmp`。
5. 掌握字符串长度函数 `strlen`。
6. 能够完成字符串统计、进制转换和综合处理题。

使用字符串函数时，应包含头文件：

```c
#include <string.h>
```

## 二、字符串输入输出函数

### 1. gets 函数

`gets` 可以接收包含空格的一整行字符串。

```c
gets(s);
```

`scanf("%s", s)` 遇到空格会停止输入，而 `gets` 可以读入空格，直到换行结束。

### 2. puts 函数

`puts` 用于输出字符串，并自动换行。

```c
puts(s);
```

## 三、常用字符串函数

### 1. strlen

求字符串长度，不包含结束标志 `'\0'`。

```c
n = strlen(s);
```

### 2. strcat

字符串连接函数，把第二个字符串连接到第一个字符串后面。

```c
strcat(s1, s2);
```

注意：第一个字符数组空间必须足够大。

### 3. strcpy

字符串复制函数。

```c
strcpy(s1, s2);
```

把 `s2` 复制到 `s1` 中。

### 4. strcmp

字符串比较函数。

```c
strcmp(s1, s2)
```

返回值含义：

1. 大于 0：`s1` 大于 `s2`。
2. 小于 0：`s1` 小于 `s2`。
3. 等于 0：两个字符串相等。

字符串比较是从第一个字符开始逐个比较 ASCII 码，只要遇到不同字符，就可以确定大小。

## 四、例题讲解

### 例题 1：比较两个字符串

```c
char s1[] = "woman is";
char s2[30];

gets(s2);

if (strcmp(s1, s2) == 0)
    printf("%s = %s\n", s1, s2);
else if (strcmp(s1, s2) > 0)
    printf("%s > %s\n", s1, s2);
else
    printf("%s < %s\n", s1, s2);
```

如果输入完全相同的 `woman is`，则输出相等。

如果输入 `man is`，第一个字符 `w` 的 ASCII 码大于 `m`，所以 `woman is` 大于 `man is`。

### 例题 2：统计字符串中各类字符个数

```c
char ch[100];
int i;
int upper = 0, lower = 0, digit = 0, other = 0;

gets(ch);

for (i = 0; ch[i] != '\0'; i++)
{
    if (ch[i] >= 'A' && ch[i] <= 'Z')
        upper++;
    else if (ch[i] >= 'a' && ch[i] <= 'z')
        lower++;
    else if (ch[i] >= '0' && ch[i] <= '9')
        digit++;
    else
        other++;
}
```

分析：

从头到尾扫描字符串，根据字符范围统计大写字母、小写字母、数字字符和其他字符的个数。

### 例题 3：十进制整数转十六进制

思路：

用一个字符数组保存十六进制字符：

```c
char b[] = "0123456789ABCDEF";
```

每次对 16 取余，得到的余数作为 `b` 数组的下标。

```c
while (y != 0)
{
    a[i] = y % 16;
    y = y / 16;
    i++;
}

for (j = i - 1; j >= 0; j--)
    printf("%c", b[a[j]]);
```

例如 44 转换为十六进制：

```text
44 / 16 = 2 余 12
12 对应 C
结果为 2C
```

### 例题 4：统计英文句子中的单词个数

如果输入的是一整句英文，不能使用 `scanf("%s", s)`，应使用 `gets(s)` 或其他整行输入方法。

统计单词时，通常根据空格和非空格的转换关系判断一个新单词的开始。

## 五、易错点

1. 使用字符串函数忘记包含 `string.h`。

2. `scanf("%s", s)` 不能读入空格后的内容。

3. `strlen` 统计长度时不包括 `'\0'`。

4. `strcat` 前一个数组空间不足。

5. `strcmp` 不是返回固定的 1、0、-1，只需要判断大于 0、小于 0、等于 0。

6. 数组元素可以作为另一个数组的下标，例如 `b[a[j]]`。
