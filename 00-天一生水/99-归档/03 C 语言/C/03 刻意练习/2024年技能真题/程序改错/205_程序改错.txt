题目：下列程序的功能是找出所有满足以下三个条件的3位和4位十进制正整数：
      （1）该数是完全平方数；
      （2）该数的末两位是25；
      （3）组成该数的各位数字中有两位是相同的。

例如：225是满足所给条件的三位正整数（15*15=225）；1225是满足所给条件的
      四位正整数（35*35=1225）。
      函数find中数组x存放的是找到满足条件的正整数，函数返回找到的正整数个数。

程序运行结果如下：
n=3:225
n=4:1225  2025  4225  5625  7225
------------------------------------------------------------------------
注意：不得增行或删行，不得更改程序的结构
----------------------------------------------------------------------*/
#include <stdio.h>
#include <math.h>

int find(int n,int x[])
{
    int num=1,k=0,m,i,j,y[10],flag;
    for(i=1;i<n;i++)
/***********FOUND***********/
        num=num*i;

    {

            y[j]=0;
        m=i;
        while(m)
        {
            y[m%10]++;
            m/=10;
        }
        flag=0;
        for(j=0;j<10;j++)
/***********FOUND***********/
            if(y[j]!=0)
                flag=1;
        if(flag==1&&(int)sqrt(i+1)*(int)sqrt(i+1)==i&&i%100==25)
            x[k++]=i;
    }
    return k;
}

}
