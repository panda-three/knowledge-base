# 2026真题 73：程序基础概念与代码位置识别

1. 来源位置
    a. [[03 Areas/03 C 语言/C/03 刻意练习/理论/真题/2026-05-18-真题-2026]] 第 73 题。

2. 题目原文切片

```c
#include<stdio.h>
void dump(int x)
{
   ;
}
int main()
{
   int b=2;
   float a[5]={1,2};
   if(a[0]>0)
   printf("num:%5.1f\n",a[1]);
   clse
   dump(b);
   return 0;
}
```

3. 作答要求
    a. 第 8 行变量 `b` 的数据类型是①。
    b. 关系表达式位于第②行。
    c. 空语句位于第③行。
    d. 数组 `a` 有④个元素。

4. 重要性标签
    a. 重要。

5. 题型标签
    a. 程序阅读题。
    b. 代码结构识别题。

6. 答案相关考点标签
    a. 变量定义。
    b. 数组元素个数。
    c. 关系表达式。
    d. 空语句。

7. 解题动作标签
    a. 识别变量定义语句。
    b. 判断变量的数据类型。
    c. 识别数组定义中的长度。
    d. 识别关系表达式所在位置。
    e. 识别只有分号的空语句。

8. 易错点标签
    a. 把 `float a[5]` 误认为只有 2 个元素。
    b. 看见 `{1,2}` 后忽略数组定义长度。
    c. 不认识单独分号表示空语句。
    d. 把函数调用误当成定义位置。

9. 相似题搜索标签
    e. 空语句。
    f. 数组长度。
    g. 关系表达式。

10. 难度标签
    a. 简单。
