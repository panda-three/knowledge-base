# 2026真题 74：switch 分支赋值与格式化输出

1. 来源位置
    a. [[03 Areas/03 C 语言/C/03 刻意练习/理论/真题/2026-05-18-真题-2026]] 第 74 题。

2. 题目原文切片

```c
#include <stdio.h>
int main()
{
    int r=200,d=3,level=1;
    float dct;
    printf("Welcome!\n");
    printf("DailyRate:%dRMB\n",r);
    switch(level){
        case 1:dct=0.7;printf("Discount:0.7\n");break;
        case 2:dct=0.9;printf("Discount:0.9\n");break;
        default:dct=1.0;printf("Discount:1.0\n");
    }
    printf("charge:%7.2fRMB\n",r * d * dct);
    return 0;
}
```

3. 作答要求
    a. 写出程序运行结果。
    b. 输出结果要包含文本、换行、计算结果和小数格式。

4. 重要性标签
    a. 重要。

5. 题型标签
    a. 程序阅读题。
    b. 输出结果题。
    c. 分支执行题。

6. 答案相关考点标签
    a. `switch-case`。
    b. `break`。
    c. `printf` 格式化输出。
    d. `%7.2f` 浮点输出。

7. 解题动作标签
    a. 判断 `level` 的初值。
    b. 判断 switch 进入哪个 case。
    c. 判断 `break` 是否终止 switch。
    d. 追踪 `dct` 的最终值。
    e. 计算 `r * d * dct`。
    f. 按 `printf` 顺序写输出。
    g. 按 `%7.2f` 处理小数位和宽度。

8. 易错点标签
    a. 漏看 `break`。
    b. 选错 switch 入口。
    c. `dct` 最终值判断错。
    d. 小数位数写错。
    e. 输出宽度空格数忽略。

9. 相似题搜索标签
    a. `switch`。
    b. `case`。
    c. `break`。
    e. `%7.2f`。
    f. `%.2f`。
    

10. 难度标签
    a. 简单。

11. V2 校准说明
    a. 不标 `int`、`float` 等泛出现考点。
    b. 考点只保留影响输出答案的分支和格式控制。
