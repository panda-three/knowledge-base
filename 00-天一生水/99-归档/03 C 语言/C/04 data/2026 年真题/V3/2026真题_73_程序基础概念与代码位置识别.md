# 2026真题 73：程序基础概念与代码位置识别

1. 完整题目
    a. 题号
        i. 73。
    b. 题干
        i. 阅读下列程序，请将①~④表示的内容填写在答题卡上相应位置。
    c. 代码

```c
#include<stdio.h>
void dump(int x)
{
   ;
}
int main()
{
   int b=2;
   float a[5]={1,2};
   if(a[0]>0)
   printf("num:%5.1f\n",a[1]);
   clse
   dump(b);
   return 0;
}
```

    d. 作答要求
        i. 上述程序中，第 8 行变量 `b` 的数据类型是 __①__。
        i. 关系表达式位于第 __②__ 行。
        i. 空语句位于第 __③__ 行。
        i. 数组 `a` 有 __④__ 个元素。

2. 重要性标签
    a. 重要。

3. 题型标签
    a. 程序阅读题。
    b. 代码结构识别题。

4. 答案相关考点标签
    a. 变量定义。
    b. 数组元素个数。
    c. 关系表达式。
    d. 空语句。

5. 解题动作标签
    a. 识别变量定义语句。
    b. 判断变量的数据类型。
    c. 识别数组定义中的长度。
    d. 识别关系表达式所在位置。
    e. 识别只有分号的空语句。

6. 易错点标签
    a. 把 `{1,2}` 误认为数组只有 2 个元素。
    b. 不认识单独分号表示空语句。
    c. 找关系表达式时忽略 `a[0]>0`。
    d. 只看代码运行，不看题目问的是语法位置。
