# 2026真题 74：switch 分支赋值与格式化输出

1. 完整题目
    a. 题号
        i. 74。
    b. 题干
        i. 阅读下列程序，请将运行结果填写在答题卡上相应位置。
    c. 代码

```c
#include <stdio.h>
int main()
{
    int r=200,d=3,level=1;
    float dct;
    printf("Welcome!\n");
    printf("DailyRate:%dRMB\n",r);
    switch(level){
        case 1:dct=0.7;printf("Discount:0.7\n");break;
        case 2:dct=0.9;printf("Discount:0.9\n");break;
        default:dct=1.0;printf("Discount:1.0\n");
    }
    printf("charge:%7.2fRMB\n",r * d * dct);
    return 0;
}
```

2. 重要性标签
    a. 重要。

3. 题型标签
    a. 程序阅读题。
    b. 输出结果题。
    c. 分支执行题。

4. 答案相关考点标签
    a. `switch-case`。
    b. `break`。
    c. `printf` 格式化输出。
    d. `%7.2f` 浮点输出。

5. 解题动作标签
    a. 判断 `level` 的初值。
    b. 判断 switch 进入哪个 case。
    c. 判断 `break` 是否终止 switch。
    d. 追踪 `dct` 的最终值。
    e. 计算 `r * d * dct`。
    f. 按 `printf` 顺序写输出。
    g. 按 `%7.2f` 处理小数位和宽度。

6. 易错点标签
    a. 选错 switch 入口。
    b. 漏看 `break`。
    c. `dct` 最终值判断错。
    d. 小数位数写错。
    e. 输出宽度空格数忽略。
