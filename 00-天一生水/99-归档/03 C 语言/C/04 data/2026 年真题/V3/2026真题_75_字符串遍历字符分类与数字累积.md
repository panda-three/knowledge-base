# 2026真题 75：字符串遍历、字符分类与数字累积

1. 完整题目
    a. 题号
        i. 75。
    b. 题干
        i. 阅读下列程序，请将运行结果填写在答题卡上相应位置。
    c. 代码

```c
#include<stdio.h>
#include<string.h>
int main()
{
    char s1[]={"RIV12greatER34"},subs[100]={};
    int i,j=0,sum=0,len=strlen(s1);
    printf("split:\n");
    printf("%s\n",s1);
    for(i=0;i<len;i++){
        if(s1[i]>='0'&&s1[i]<='9'){
            sum=sum * 10+s1[i]-48;
        }else if(s1[i]>='A'&&.s1[i]<'Z'){
            subs[j++]=s1[i];
        }else
            printf("%c",s1[i]);
    }
    subs[j]='\0';
    printf("\n%s\t%d\n",subs,sum);
}
```

    h. 判断普通字符何时直接输出。
    i. 补字符串结束符。
    j. 匹配最终输出格式。

6. 易错点标签
    a. 忘记 `strlen` 不包含 `\0`。
    b. 数字字符转数值时忘记减 `'0'` 或 48。
    c. `sum=sum*10+...` 的连续数字累积过程判断错。
    d. 忘记 `subs[j]='\0'` 后才是字符串。
    e. 字符分类顺序判断错。
    f. 原文 `.s1[i]` 疑似 OCR 错误，做题时需先识别。
