## 二、标签

- 重要性：不重要（拆解题——涉及文件读写、字符串比对、排序去重多个模块拼接，整体性弱，不适合作为整题复练对象。可按模块拆练：排序条件单独练、去重更新单独练、逐字符比对单独练）
- 题型：程序填空题
- 答案相关考点：
    - 排序多关键字复合条件——先按手机号升序、同手机号按正确数降序（③空的核心：`strcmp(tel[j-1], tel[j]) > 0` 控制主关键字，`yes[j-1] < yes[j]` 控制次关键字，两个方向相反容易写反）
    - 去重后记录总数更新——连续同名区间压缩后，`ct` 需减去被删掉的记录数（④空的核心：`ct -= (p - i)`，必须放在文件重写之前）
- 解题动作：
    - ①空填函数名：从 `main` 中 `ct = get_rec(teln, asw, yes)` 倒推，函数名和参数类型已给出
    - ②空填逐字符比对：`asw[i][p] == key[p]`，字符串逐字符判等标准写法
    - ③空填复合排序条件：先判 `strcmp(tel[j-1], tel[j]) > 0`（手机号降序），再判同名时 `yes[j-1] < yes[j]`（正确数降序），两个条件用 `||` 连接
    - ④空填去重更新：`ct -= (p - i)`，排序后同名记录已聚拢，删掉区间内多余的只留第一条（正确率最高那条），`i` 跳到 `p` 位置继续处理下一组
- 易错点：
    - ③空 `strcmp` 方向写反——`> 0` 写 `> 1` 或 `< 0`，导致排序全乱
    - ③空漏了次关键字条件——只写 `strcmp(tel[j-1], tel[j]) > 0`，同名手机号的记录顺序不保证正确率高的在前
    - ④空位置放错——放在文件重写之后才更新 `ct`，`fprintf` 循环仍按旧 `ct` 输出多余记录
    - ②空多判了逻辑——写成 `asw[i][p] == key[p] && key[p] != '\0'`，但循环条件已经管了 `'\0'`，多此一举还容易写错
- 相似题搜索标签：`排序去重` `多关键字排序` `strcmp排序方向` `记录数更新` `ct减法` `逐字符比对`
- 难度：⭐⭐⭐⭐（困难——四星理由：③④两空都是"复合逻辑推导"，不是靠记住某个知识点就能填对的。③空需要同时理解 `strcmp` 返回值方向 + 多关键字 `||` 和 `&&` 的优先级关系；④空需要脑跑整个去重删除流程、算出记录减少了多少条）
