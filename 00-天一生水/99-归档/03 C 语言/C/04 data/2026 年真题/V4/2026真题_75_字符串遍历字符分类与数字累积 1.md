# 2026 真题 · 75 · 字符串遍历、字符分类与数字累积

## 一、题目内容

- 题号：75
- 题型：程序阅读题（写出运行结果）
- 题干：阅读下列程序，将运行结果填写在答题卡相应位置。

```c
#include<stdio.h>
#include<string.h>
int main()
{
    char s1[]={"RIV12greatER34"},subs[100]={};
    int i,j=0,sum=0,len=strlen(s1);
    printf("split:\n");
    printf("%s\n",s1);
    for(i=0;i<len;i++){
        if(s1[i]>='0'&&s1[i]<='9'){
            sum=sum * 10+s1[i]-48;
        }else if(s1[i]>='A'&&s1[i]<'Z'){
            subs[j++]=s1[i];
        }else
            printf("%c",s1[i]);
    }
    subs[j]='\0';
    printf("\n%s\t%d\n",subs,sum);
    return 0;
}
```

## 二、标签

- 重要性：重要
- 题型：程序阅读题
- 答案相关考点：
    - 字符串遍历与字符三分类（数字 / 大写 / 其他，各走各的分支）
    - 连续数字的逐位累积算法（`sum = sum × 10 + 当前位`，不是累加）
- 解题动作：
    - 遍历 `s1`，逐字符判三分类：数字 → 进位累积 sum，大写 → 追加 subs，其他 → 即时输出
    - 追踪 sum 的逐位变化（1 → 12 → 123 → 1234），注意是十进制进位不是简单累加
    - 追踪 subs 的收集顺序，确认循环后补 `\0`
    - 按输出顺序拼接：前两行固定输出 → 即时输出的字符 → subs 和 sum 的最终值
- 易错点：
    - `sum = sum * 10 + digit` 误当成累加（以为 1+2+3+4=10，实际是 1234）
    - 大写判断条件 `< 'Z'` 不含 Z 本身，换一个含 Z 的字符串就错
    - 即时输出的字符（`great`）夹在中间容易漏排顺序
- 相似题搜索标签：`字符串遍历` `字符三分类` `数字累积` `sum乘10加` `\0补位`
- 难度：⭐⭐⭐（中等）
