# 2026 真题 · 73 · 代码结构元素识别与数组定义陷阱

## 一、题目内容

- 题号：73
- 题型：程序阅读题（填空，代码结构识别）
- 题干：阅读下列程序，请将①~④表示的内容填写在答题卡上相应位置。

```c
#include<stdio.h>
void dump(int x)
{
   ;
}
int main()
{
   int b=2;
   float a[5]={1,2};
   if(a[0]>0)
   printf("num:%5.1f\n",a[1]);
   else
   dump(b);
   return 0;
}
```

- 作答要求：
    - 第 8 行变量 `b` 的数据类型是 __①__
    - 关系表达式位于第 __②__ 行
    - 空语句位于第 __③__ 行
    - 数组 `a` 有 __④__ 个元素

## 二、标签

- 重要性：重要
- 题型：程序阅读题（代码结构识别）
- 答案相关考点：
    - 数组声明长度 ≠ 初始化列表个数（`a[5]` 声明 5 个元素，`{1,2}` 只初始化前两个）
    - 空语句的形态识别（单独 `;` 是一条合法空语句，不是书写错误）
- 解题动作：
    - 定位 `b` 的声明行，读出类型关键字
    - 扫代码找比较运算符（`>` `<` `==` 等），定位关系表达式行
    - 识别 `;` 作为独立语句——不在 `for`/`while` 括号后、不在语句末尾，独占一行的分号
    - 看数组 `[]` 内的数字，不看初始化列表 `{}` 里放了几个
- 易错点：
    - `{1,2}` 看错，填 2 个元素而实际声明是 5 个
    - 不认识空语句，以为 `;` 是笔误或跳过不填
    - 行号数错（从 `#include` 开始算第 1 行）
- 相似题搜索标签：`数组定义` `空语句` `声明长度` `代码结构识别`
- 难度：⭐⭐（简单——唯一陷阱是数组长度，其余考的是读代码基本功）
