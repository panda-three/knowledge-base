# 2026 真题 · 74 · switch 分支赋值与格式化输出

## 一、题目内容

- 题号：74
- 题型：程序阅读题（写出运行结果）
- 题干：阅读下列程序，将运行结果填写在答题卡相应位置。

```c
#include <stdio.h>
int main()
{
    int r=200,d=3,level=1;
    float dct;
    printf("Welcome!\n");
    printf("DailyRate:%dRMB\n",r);
    switch(level){
        case 1:dct=0.7;printf("Discount:0.7\n");break;
        case 2:dct=0.9;printf("Discount:0.9\n");break;
        default:dct=1.0;printf("Discount:1.0\n");
    }
    printf("charge:%7.2fRMB\n",r * d * dct);
    return 0;
}
```

## 二、标签

- 重要性：常考
- 题型：程序阅读题
- 答案相关考点：
    - switch-case 的分支入口判断
    - printf 格式化输出（`%7.2f` 宽度与小数位）
- 解题动作：
    - 判断 `level` 初值，匹配 case 入口
    - 确认 `break` 终止 switch，`dct` 最终取值
    - 计算 `r * d * dct` 结果
    - 按 `printf` 顺序和 `%7.2f` 格式写出完整输出
- 易错点：
    - 选错 case 入口（level 初值看错）
    - `%7.2f` 小数位数写错或宽度空格漏写
- 相似题搜索标签：`switch` `case` `break` `%7.2f` `折扣` `等级`
- 难度：⭐⭐（简单）
