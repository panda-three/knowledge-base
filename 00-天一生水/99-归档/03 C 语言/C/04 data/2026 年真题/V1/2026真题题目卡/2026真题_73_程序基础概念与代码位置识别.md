2. 题目原文切片

```c
#include<stdio.h>
void dump(int x)
{
   ;
}
int main()
{
   int b=2;
   float a[5]={1,2};
   if(a[0]>0)
   printf("num:%5.1f\n",a[1]);
   else
   dump(b);
   return 0;
}
```

3. 作答要求
    a. 判断变量 `b` 的数据类型。
    b. 找出关系表达式所在行。
    c. 找出空语句所在行。
    d. 判断数组 `a` 的元素个数。

    b. `float` 一维数组。
    c. 数组元素个数。
    d. 关系表达式。
    e. if 语句。
    f. 空语句。
    g. 函数调用。

6. 解题动作标签
    a. 判断变量定义语句的数据类型。
    b. 识别数组定义中的长度。
    c. 识别关系表达式所在位置。
