# 2026真题 75：字符串遍历、字符分类与数字累积

1. 来源位置
    a. [[03 Areas/03 C 语言/C/03 刻意练习/理论/真题/2026-05-18-真题-2026]] 第 75 题。

2. 题目原文切片

```c
#include<stdio.h>
#include<string.h>
int main()
{
    char s1[]={"RIV12greatER34"},subs[100]={};
    int i,j=0,sum=0,len=strlen(s1);
    printf("split:\n");
    printf("%s\n",s1);
    for(i=0;i<len;i++){
        if(s1[i]>='0'&&s1[i]<='9'){
            sum=sum * 10+s1[i]-48;
        }else if(s1[i]>='A'&&.s1[i]<'Z'){
            subs[j++]=s1[i];
        }else
            printf("%c",s1[i]);
    }
    subs[j]='\0';
    printf("\n%s\t%d\n",subs,sum);
}
```

    c. `strlen`。
    d. for 循环。
    e. 字符范围判断。
    f. 逻辑与 `&&`。
    g. 数字字符转数值。

    d. 判断字符是否为大写字母。
    e. 将数字字符转换为数值。
    f. 追踪 `sum` 的累积变化。
    g. 追踪 `subs[j++]` 的存入过程。
    h. 判断普通字符何时直接输出。
    i. 补字符串结束符。
    j. 匹配最终输出格式。
