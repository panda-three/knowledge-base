**递推法与穷举法概念讲解**
* **递推法定义**：递推法是用若干步可重复运算描述复杂问题的方法，通过计算序列的前面项得出指定项的值。
* **穷举法定义**：穷举法是逐个考察某类事件的所有可能情况，在确定的答案范围内逐一验证，最终得出可靠结论的归纳方法。

**斐波那契数列递推求解**
* **题目要求**：编写程序求出斐波那契数列的前20个数，斐波那契数列的前两项均为1，后续每一项等于前两项之和。
* **递推逻辑**：通过交换赋值的方式实现迭代，每次计算新项后，将原第二项赋值给第一项，将新计算的和赋值给第二项，重复循环输出前20项。

**分数数列累加求解**
* **题目规律**：给定数列前几项为1/2、2/3、3/5、5/8，规律为当前项的分母是下一项的分子，当前项分子加分母的和作为下一项的分母。
* **解题细节**：需要提前用变量t记录当前项的分子，再将分母赋值给下一项的分子，最后计算新分母为原分母加记录的原分子，总共循环10次完成累加。

**小球自由下落路程计算**
* **题目设定**：小球从100米高度自由落下，每次落地后反弹回原高度的一半，求第十次落地时一共经过多少米，以及第十次反弹的高度。
* **解题逻辑**：初始高度h定义为100米，每次落地后反弹高度h更新为原高度的一半，每一次反弹后再下落会经过2倍当前高度的路程，最终总路程需要减去最后一次反弹的高度h，第十次反弹的高度就是最终计算得到的h。

**百元换钞穷举题讲解**
* **题目要求**：将100元人民币换成5元、1元、0.5元三种面额的钞票，要求总张数为100张，且每种面额不少于1张，统计共有多少种换法。
* **解题逻辑**：定义i为5元张数，j为1元张数，k为0.5元张数，需要同时满足两个条件：一是5*i+1*j+0.5*k=100（总金额100元），二是i+j+k=100（总张数100张），每满足一次条件就将换法计数n加1。

**方程整数解穷举题讲解**
* **题目设定**：求方程4X+5Y=0在X、Y取值范围为-50到50之间的整数解，统计解的数量。
* **解题逻辑**：X从-50开始循环到50，Y也从-50开始循环到50，逐一验证每一组(X,Y)是否满足方程，满足条件就将解的计数n加1。

**阶乘累加递推题讲解**
* **题目要求**：计算从1!分之一加到n!分之一的累加和，输入n为从键盘获取的正整数。
* **解题要点**：阶乘累乘的初始值为1，计算每一项的时候，必须使用1.0除以阶乘，不能用1除以阶乘，否则会因为整数运算得到0，无法保留小数结果。

**分数累加递推题讲解**
* **题目要求**：计算1 + 1/2 + 1/(2*3) + ... + 1/(2*3*...*n)的累加和。
* **解题逻辑**：定义变量K保存当前项的值，初始K为0，每一轮循环在当前K的基础上加上1/i，再将K累加到总和S中，循环n次后得到最终结果，计算1/i也需要使用1.0除以i保证结果为小数。

**回文素数穷举题讲解**
* **题目要求**：找出100到1000之间所有既是回文数又是素数的数。
* **解题逻辑**：先判断三位数是否为回文数：提取个位和百位，若个位和百位相等则为回文数；再对回文数判断是否为素数，初始标记素数标记为1，若能被除1和自身外的数整除则将标记改为0，最终标记仍为1则输出该数。

**各位不同三位数穷举题讲解**
* **题目要求**：输出所有个位、十位、百位数字都不相同的三位数。
* **解题逻辑**：遍历范围100到999确保是三位数，分别提取百位、十位、个位数字，若任意两个位置数字相同，就用continue跳过该数，不相同则输出该三位数，判断条件使用或连接三种相同情况，任意一种满足就跳过。

**卖鸭子递推题讲解**
* **题目设定**：一个人赶鸭子去卖，每经过一个村子就卖出所剩鸭子的一半又一只，经过7个村子后还剩2只鸭子，求进入每个村子前的鸭子数量和卖出的数量。
* **解题逻辑**：从后往前逆序递推，初始剩余鸭子为2只，上一个村子的鸭子数量等于（当前剩余鸭子数+1）乘以2，卖出的鸭子数量等于进入村子时的鸭子数量减去离开村子时的剩余鸭子数量，从第七个村子往前逆推到第一个村子即可。

**百鸡百钱穷举题讲解**
* **题目要求**：用100元买100只鸡，公鸡5元一只，母鸡3元一只，小鸡1元三只，每种鸡都要有，求所有符合条件的购买组合。
* **解题逻辑**：使用双重循环，公鸡数量范围为1到18，母鸡数量范围为1到32，小鸡数量直接用100减去公鸡数量再减去母鸡数量得到，验证总金额是否等于100即可，符合条件就输出组合。

**分半计数题讲解**
* **题目要求**：输入一个实数，不断对半拆分，直到拆分后的结果小于0.01，统计一共拆分了多少次。
* **解题逻辑**：初始计数n为0，当输入的数大于等于0.01时，就将数除以2，计数n加1，重复循环直到数小于0.01，最后输出计数n。

**整数分解质因子题讲解**
* **题目要求**：将输入的整数分解为质因子乘积的形式。
* **解题逻辑**：如果输入是负数，先输出负号，再对绝对值分解质因子；从2开始循环尝试整除，能整除就输出该因子，然后将原数除以该因子，重复整除直到无法整除，再尝试下一个因子，直到所有因子分解完成。

**完全数判断题讲解**
* **题目要求**：判断输入的数是否为完全数，完全数定义为所有真因子（除自身外的约数）的和等于该数本身。
* **解题逻辑**：从1到原数的一半遍历，能整除原数就将因子累加，最后判断累加和是否等于原数，相等就是完全数，否则不是。

**哥德巴赫猜想验证题讲解**
* **题目要求**：验证大于4的偶数都可以拆成两个素数的和。
* **题目逻辑**：输入大于4的偶数后，从小到大遍历拆分出第一个数X1，先判断X1是否为素数，如果X1是素数，再判断拆分出的第二个数X2（偶数减去X1）是否为素数，如果两个都是素数，就输出拆分结果。

[00:18:33](https://getnotes.seek:1113) **阶乘累加递推题讲解**

[00:20:58](https://getnotes.seek:1258) **分数累乘累加递推题讲解**

[00:22:44](https://getnotes.seek:1364) **回文素数穷举题讲解**

题目要求找出100到1000之间所有既是回文数又是素数的数。讲解了判断逻辑：先判断三位数是否为回文数，提取个位和百位数字，若个位等于百位则为回文数；再对回文数判断是否为素数，初始素数标记为1，若能被除1和自身外的数整除，就将标记改为0，最终标记仍为1就输出该数。说明本次采用先判断回文再判断素数的顺序，和之前先判断素数再判断回文的顺序不同，两种方法都可行。

[00:24:10](https://getnotes.seek:1450) **各位不同三位数穷举题讲解**

题目要求输出所有个位、十位、百位数字都不相同的三位数。确定了循环范围：遍历100到999，保证所有数都是三位数。讲解了数字提取方法：可以通过先除以100取整得到百位，先除以10再模除10得到十位，模除10得到个位，两种提取十位的方法都可行。判断逻辑：只要百位、十位、个位中有任意两个数字相同，就用continue跳过该数，所有数字都不相同就输出该三位数。

[00:28:28](https://getnotes.seek:1708) **卖鸭子逆递推题讲解**

[00:32:00](https://getnotes.seek:1920) **百鸡百钱穷举题讲解**

题目要求输入一个实数，不断对半拆分，直到拆分后的结果小于0.01，统计拆分的总次数。讲解了循环逻辑：初始计数n为0，只要输入的数大于等于0.01，就将数除以2，计数n加1，重复循环直到数小于0.01，最后输出计数n，举例演示了13拆分的过程，验证了逻辑正确性。

[00:35:21](https://getnotes.seek:2121) **整数分解质因子题讲解**

题目要求将输入的整数分解为质因子乘积的形式。讲解了处理逻辑：如果输入是负数，先输出负号，再对绝对值进行分解。循环从2开始，依次尝试整除原数，能整除就输出该因子，然后将原数除以该因子，重复整除直到无法整除，再尝试下一个因子，直到原数被分解为1，结束分解。以27和36为例演示了分解过程，验证了逻辑正确性。

[00:39:15](https://getnotes.seek:2355) **完全数判断题讲解**

题目要求判断输入的数是否为完全数，完全数定义为所有真因子（除自身外的约数）的和等于该数本身。讲解了判断逻辑：从1到原数的一半遍历所有数，能整除原数就将该因子累加到总和中，最后判断累加和是否等于原数，如果相等就是完全数，否则就不是完全数，以数字6为例验证了逻辑。

[00:40:56](https://getnotes.seek:2456) **哥德巴赫猜想验证题讲解**
