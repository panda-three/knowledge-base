#### 知识精讲
本次课为C语言程序改错题讲评课，围绕数组筛选与二维数组填数的改错题，讲解题目理解方法与三类常见错误的排查修正技巧，总结了改错题的通用解题思路。

**题目要求梳理**
* **核心任务**：从一维数组`a`中筛选满足条件的元素存入一维数组`b`，再将`b`中元素按要求填入二维数组`c`的右上角。
* **筛选条件定义**：待筛选元素`a[i]`，其**之后连续三个元素**需满足两种形态之一：
  1. **鼓形（大小大）**：`a[i+1] > a[i+2] && a[i+2] < a[i+3]`，即先降后升，示例：31、14、18，满足大小大。
  2. **分形（小大小）**：`a[i+1] < a[i+2] && a[i+2] > a[i+3]`，即先升后降，示例：14、18、16，满足小大小。
* **反例说明**：若后续三个元素为单调序列（如18、16、5一直递减），则不满足条件，不存入数组`b`。
* 🚩重点：解题核心是通过示例反推题目定义，题干描述晦涩时优先看示例理解规则。

**改错题第一处错误：函数参数定义错误**
* **错误分析**：原函数定义的参数顺序与调用时的传参顺序颠倒，且二维数组未指定列数。原定义为`void fun(int a[], int c[][])`，调用时先传二维数组`c`，再传一维数组`a`。
* **修正方法**：
  1. 交换参数顺序，改为`void fun(int a[], int c[][M])`
  2. 补充二维数组的列数`M`（根据题目定义的数组维度，C语言规定二维数组形参必须指定第二维长度）
* 🚩重点：改错题中函数标注错误，99%概率是参数出问题，优先检查参数顺序、维度。C语言中一维数组形参可以不写长度，**二维数组形参必须指定列数**，这是常考的语法点。

**改错题第二处错误：循环边界错误**
* **错误分析**：原循环条件为`i < N`，会导致数组下标越界。由于要判断`a[i]`，必须保证`a[i]`之后有连续三个元素，即`i+3`不能超过数组最大下标`N-1`。
* **修正推导**：
  由不等式`i+3 ≤ N-1`推导可得：`i ≤ N-4`，等价于`i < N-3`，因此原循环条件`i < N`修正为`i < N-3`（或写成`i <= N-4`均可）。
* 🚩重点：需要访问当前元素后续固定数量元素时，循环边界必须提前扣除对应的长度，防止数组下标越界，这是改考题的高频考点，可直接通过范围规则推理出答案。
* *公式推导*：
  $$i + 3 \leq N-1 \implies i \leq N-4 \iff i < N-3$$

**改错题第三处错误：二维数组填数位置错误**
* **错误分析**：题目要求将筛选出的元素填入二维数组的右上角，原代码从第0列（第一列）开始正向放置，不符合要求。
* **修正方法**：初始列下标从`M-1`开始（即二维数组最后一列），从右上角开始从右向左放置元素，原代码`j = 0`修正为`j = M-1`。
* 🚩重点：注意题干要求的放置位置，右上角对应最大列下标，不要想当然从0开始放。

**改错题通用解题技巧**
* **蒙猜策略**：题干看不懂不影响找错误，典型错误有固定规律：
  1. 函数定义错误优先查参数顺序、参数维度；
  2. 循环条件错误优先查边界，判断是否会越界；
  3. 赋值初始值错误优先结合题目要求分析起始位置。

#### 💡 核心概念
- **鼓形（大小大）**：三个连续元素满足`x1 > x2 && x2 < x3`，先降后升。
- **分形（小大小）**：三个连续元素满足`x1 < x2 && x2 > x3`，先升后降。
- **循环边界公式**：
$$i < N - k \iff i \leq N - k - 1$$
其中$k$为当前元素后需要保留的元素个数，本题$k=3$。
