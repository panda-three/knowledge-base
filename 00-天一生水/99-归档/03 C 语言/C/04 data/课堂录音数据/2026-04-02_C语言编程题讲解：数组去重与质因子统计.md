#### 知识精讲
本次课讲解两道编程基础经典习题，一道是数组去重问题，一道是合数质因子计数改错题，重点分析了循环边界问题、逻辑错误定位，同时补充了编程考试的答题规范。

**第一题：数组去重问题（提取不重复元素到新数组）**
* **核心思路**：遍历原数组每个元素，依次到已保存的新数组中查找重复元素，如果没有找到重复元素则将该元素存入新数组。
* **循环边界易错点**：
   - 🚩重点：原数组长度为`n`，最大下标为`n-1`；遍历完原数组后，循环变量`i`会因为最后一次自增变成`n`，刚好是新数组下一个待插入元素的下标，因此新数组的起始插入位置直接写`i`即可，不需要额外`+1`，这是本题最容易出错的考点。
   - 等价写法：也可以写`k=n`，结果同样正确。
* **查找重复逻辑**：双层循环实现查找，内层循环遍历已存入的元素，如果找到相同元素执行`break`跳出循环。若内层循环正常结束（遍历完所有元素都未触发`break`），则说明没有重复，将当前元素存入新数组。这种查找逻辑和基础查找算法的写法完全一致。

**第二题：质因子个数统计程序改错题**
* **题目需求**：任意大于1的合数都可以分解为质因子的乘积，实现函数统计输入合数的质因子个数，例如：`18=2×3×3`，质因子个数为3；`128=2^7`，质因子个数为7；`35=5×7`，质因子个数为2。
* **数据存储结构**：定义`2行×n列`二维数组，**第一行存储待统计的合数**，**第二行存储对应合数的质因子个数**。
* **第一处错误定位：主函数传参错误**：
   - 原代码调用函数时传入参数为`a[1][i]`，并将结果存入`a[0][i]`，这和数组存储逻辑完全写反了；待统计的原始合数存在第一行（0行），结果需要存入第二行（1行）。
   - 修正方法：将调用改为`a[0][i]`传入参数，结果存入`a[1][i]`即可。
* **第二处错误定位：质因子遍历逻辑错误**：
   - 原代码逻辑：每次找到质因子后立刻对素数下标`k`执行自增，导致下一次直接去遍历下一个素数，同一个素数的多次因子无法被统计（例如18被2整除后，直接跳到3，漏掉第二次对2的判断）。
   - 修正方法：将`k++`从`if`分支内部移到`if`分支外部，只有当当前素数无法整除当前x时，才移动素数下标到下一个素数，同一个素数可以多次整除统计。
* **第三处错误定位：循环边界条件错误**：
   - 原代码循环条件为`while(1 <= x)`（即`x >= 1`），当x被分解为1后，循环仍然会继续执行，遍历所有剩余素数产生大量无效操作。
   - 🚩重点：修正方法为将循环条件改为`while(x > 1)`，写`x >= 2`也判定正确，此时x分解到1就会停止循环，避免无效操作。

**编程考试答题规范**
* 🚩重点：改错题只能修改题目要求修改的行，其他行禁止修改，更不能删除题目给出的待修改行；系统自动判分按行匹配答案，删除待修改行会导致系统无法匹配，直接判错。
* 🚩重点：系统判分采用答案匹配制，只有答案和标准答案范围匹配才会判定正确；即使你的代码可以运行出正确结果，但写法不在标准答案范围内，依然会被判错，因此必须按照题目要求的逻辑修改。

[00:09:15](https://getnotes.seek:555) **数据结构分析**

[00:10:17](https://getnotes.seek:617) **主循环逻辑分析**

[00:10:43](https://getnotes.seek:643) **第一处错误定位**
原代码调用函数时，传入的是第二行`a[1][i]`，并将结果存入第一行`a[0][i]`，这一逻辑完全写反；第一行存储原始待统计合数，第二行存储结果，因此传参和赋值写反了。代入i=0验证：初始时第二行元素全为0，传入0完全不符合逻辑，很容易定位该错误。

[00:11:38](https://getnotes.seek:698) **第一处错误修正**
将传参改为`a[0][i]`，将结果赋值给`a[1][i]`即可修正该错误。

[00:12:21](https://getnotes.seek:741) **进入核心函数逻辑分析**
开始逐句分析计数函数的逻辑，以18为例代入验证。

[00:13:25](https://getnotes.seek:805) **素数数组的作用**
全局数组`prime`中存储了前20个素数，函数依次遍历该数组中的素数，判断是否是当前x的质因子。

[00:13:34](https://getnotes.seek:814) **代入18验证初始状态**
初始状态：x=18，计数变量`cnt=0`，素数下标`k=0`，循环条件`1 <= x`成立进入循环。

[00:13:51](https://getnotes.seek:831) **第二处错误定位**
原代码中，当找到一个可整除x的素数后，计数cnt加1，然后立刻执行`k++`移动到下一个素数，再执行`x /= prime[k]`；对于18的例子，此时k已经从0变成1，`prime[k]`是3，x除以3得到6，本该多次统计同一个素数（18应该先除以2，得到9后再继续判断2），这里直接跳到下一个素数，逻辑错误。

[00:15:07](https://getnotes.seek:907) **第二处错误修正**
将`k++`从if分支中移出，只有当当前素数无法整除x时，才移动k到下一个素数；修正后重新代入验证：18对`prime[0]=2`取余等于0，cnt变成1，x变成9，继续循环，9再次对2取余不等于0，此时k才加1变成1，走到下一个素数3，符合逻辑。继续验证：9对3取余等于0，cnt变成2，x变成3，循环继续，3再次对3取余等于0，cnt变成3，x变成1，符合18有3个质因子的正确结果。

[00:16:50](https://getnotes.seek:1010) **第三处错误定位**
修正上述错误后，当x变成1后，循环条件`1 <= x`仍然成立，会继续遍历所有后续素数，执行大量无效的判断操作，逻辑冗余错误。

[00:17:58](https://getnotes.seek:1078) **第三处错误修正**
将循环条件改为`x > 1`即可，写`x >= 2`也判定正确，x变成1后循环直接结束，避免无效操作。

#### 💡 核心概念
- **数组去重**：遍历原数组，通过查找排除重复元素，将不重复元素存入新数组的算法，核心是查找重复的逻辑。
- **质因子分解**：任何大于1的合数都可以分解为若干个质数的乘积，质因子就是分解后得到的质数，可重复统计。
