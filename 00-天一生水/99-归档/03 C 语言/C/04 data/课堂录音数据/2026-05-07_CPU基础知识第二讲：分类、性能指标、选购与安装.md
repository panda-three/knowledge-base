# CPU基础知识第二讲：分类、性能指标、选购与安装

## 原始正文

### 📑 智能总结

#### 录音总结
本次课程为CPU硬件知识第二讲，讲解了CPU的基础定义、分类、接口架构、核心性能指标、选购方法、进阶概念与安装步骤，搭配例题讲解帮助学习者掌握考点知识。

**CPU基础定义与课程目标**
* **课程学习目标**：本次CPU课程要求学习者了解CPU的分类及型号，掌握CPU的性能指标，掌握CPU的选购和安装方法，其中性能指标是本次课程的核心重点。
* **CPU基础结构**：中央处理器简称CPU，是一块超大规模集成电路芯片，是整个计算机系统的核心，所有数据信息都由它处理。
* **CPU核心部件组成**：CPU主要包含运算器、控制器、寄存器三个部件，三个部件相互协调完成分析、判断、运算，并控制计算机各部分协调工作。

**CPU品牌、分类与型号**
* **全球两大CPU生产厂商**：目前市场上的两大CPU品牌分别是英特尔和AMD，国产CPU品牌有华为麒麟等。
* **主流产品型号划分**：英特尔的主流产品型号为酷睿i3、i5、i7、i9，此外还有赛扬、奔腾系列；AMD的主流产品型号为锐龙2、3、5、7、9，此外还有速龙系列。
* **CPU接口架构分类**：按照主板CPU插座可分为Socket架构和slot架构，目前英特尔主流酷睿系列采用LGA 115X接口，AMD主流产品采用Socket AM3+、AM4等接口。

**CPU主频、外频与倍频性能指标**
* **参数定义与换算关系**：主频是CPU内核工作的时钟频率，单位为G赫兹；外频是系统总线的工作频率，单位为兆赫兹；倍频是主频与外频的比值，无单位，三者关系为主频=外频×倍频。
* **典型例题计算示例**：已知主频为2.8G赫兹、外频为200MHz，计算可得倍频为14；已知倍频跳线设置为10、外频为200MHz，计算可得主频为2000MHz即2G赫兹。
* **超频实现原理**：CPU超频是指让CPU工作在高于标称的时钟频率，可通过提高倍频或者提高外频来实现，提升CPU运行性能。

**CPU其他核心性能指标讲解**
* **前端总线频率与字长**：前端总线频率是CPU连接到北桥芯片的总线速度，是CPU和二级缓存、内存之间的通信线路速度。字长是CPU同一时间内处理的一组二进制位数，和CPU数据总线宽度一致，目前主流CPU的字长为64位，字长越长，CPU处理数据的精度越高、运行速度越快。
* **CPU缓存分级**：缓存是位于CPU与内存之间的临时存储器，容量比内存小，但交换速度远快于内存，用于缓冲CPU和内存之间的速度差。目前CPU内置三级缓存：一级缓存离核心最近、速度最快、容量最小，分为一级数据缓存和一级指令缓存，容量通常为8KB-16KB；二级缓存容量中等，通常为128KB-512KB；三级缓存容量最大，通常为8MB-32MB。
* **制造工艺**：CPU制造工艺也叫CPU制程，目前以纳米为单位，制造工艺数值越小，加工精度越高，CPU越先进，核心电压越低，功耗越小。目前酷睿i7-8700K的制造工艺为14nm，不是22nm。
* **工作电压与扩展指令集**：CPU工作电压分为核心电压和IO电压，通常核心电压低于IO电压，常见核心电压为1.3V-1.4V，电压越低CPU功耗越小。扩展指令集用于提升CPU多媒体、3D图形、浮点运算能力，英特尔主流扩展指令集为MMX和SSE系列，AMD主流扩展指令集为3D Now!系列。

**CPU选购知识讲解**
* **选购核心原则**：CPU选购优先选择主流产品，不要购买刚上市未经过市场测试的新产品；选购需要重视实用性，同时必须考虑和主板的兼容性，要选择主板支持的接口类型，避免买回来无法安装。
* **选购参考指标**：选购CPU主要参考性能指标，包括主频、接口类型、缓存容量、制造工艺、工作电压。同等条件下，优先选择主频更高、缓存容量更大、制造工艺更精细的产品。
* **典型习题解析**：外形不是CPU的主要性能指标；某标注为“LGA 775 3.0G赫兹 6MB L2”的CPU型号，包含了接口类型、主频、二级缓存容量三类信息，未标注核心数量。

**CPU进阶概念讲解**
* **超频注意事项**：超频可以提升系统性能，但需要搭配匹配的主板、内存、硬盘、显卡，同时必须解决散热问题；过度超频会缩短CPU寿命，还可能损坏其他硬件，只能适当超频，不能无限制超频，超频可通过硬件跳线或软件设置实现。
* **超线程技术定义**：超线程技术是将一个物理处理器虚拟成两个逻辑处理器，可以同时处理两个独立线程，提升系统运行效率。常见的“6核心12线程”就是超线程技术的应用，每核心对应2个线程，若核心数和线程数相等，则未开启超线程。

**CPU安装步骤讲解**
* **安装前准备**：安装CPU时，第一步需要掀起CPU插槽的拉杆，打开插槽金属保护板，找到CPU和插槽对应的定位标记，如缺角、小三角标识。
* **核心安装步骤**：将CPU垂直插入插槽，让定位标记对准后，压下插座，将拉杆卡入插槽卡扣固定CPU；之后在CPU核心位置涂抹少量硅脂，用刮片涂成薄于一张白纸的均匀厚度，硅脂用于提升CPU和散热器的导热效率，改善散热效果。
* **散热器安装步骤**：将散热器对准主板对应的孔位，把螺丝向右旋转约45°固定，完成CPU和散热器的安装。

**课堂练习讲解**
* **常见基础考题解析**：32位CPU中的32指的是CPU字长，目前主流CPU的字长为64位；决定CPU可访问物理地址空间大小的是地址总线宽度；一级缓存容量普遍较小，不同CPU之间容量差距不大，二级缓存是衡量CPU性能好坏的重要依据。
* **课程内容总结**：CPU课程核心内容分为三大块，分别是CPU的分类与型号、CPU的性能指标、CPU的选购与安装，其中性能指标是考核的重点内容。

讲解制造工艺：CPU制造工艺又称CPU制程，工艺的先进程度直接决定CPU性能，更精细的工艺能缩小晶体管体积，降低CPU功耗，当前制造工艺单位为纳米，工艺数值越小，CPU越先进；指出酷睿i7 8700K的制造工艺为14nm，不是题干中的22nm，结合例题讲解了制造工艺类考题的答题思路。讲解工作电压：CPU工作电压分为核心电压和IO电压，核心电压通常低于IO电压，常见核心电压在1.3V-1.4V之间，电压越低CPU功耗越小；结合习题纠正了“CPU主频提升工作电压也随之升高”的错误说法。讲解扩展指令集：扩展指令集用于提升CPU多媒体、3D图形、浮点运算能力，英特尔主流指令集为MMX和SSE系列，AMD主流指令集为3D Now!系列，结合3D渲染选型例题给出了正确选择方向。

[00:25:51](https://getnotes.seek:1551) **超频与超线程进阶概念讲解**

讲解超频进阶知识：超频是通过提高外频或倍频提升CPU主频，从而提升整个系统性能的操作；超频需要主板芯片组、内存、硬盘、显卡都能匹配性能，否则会出现系统不稳定，最需要注意的是散热问题，过度超频会缩短CPU寿命，还可能损坏其他硬件，只能适当超频，不能无限制超频，超频可通过硬件跳线或软件设置实现。讲解超线程技术：超线程是将一个物理处理器虚拟为两个逻辑处理器，可以同时处理两个独立线程，提升系统工作效率；常见的“6核12线程”就是超线程技术，核心数和线程数为1:2时，即开启了超线程，若核心数和线程数相等，则未开启超线程。

[00:30:22](https://getnotes.seek:1822) **CPU安装步骤讲解**

讲解CPU安装的完整步骤：第一步掀起CPU插槽的拉杆，打开插槽的金属保护板；第二步找到CPU和插槽对应的定位标记，通常是缺角或三角形标识，将CPU垂直插入插槽，对准定位标记；第三步压下插座，将拉杆卡入插槽的卡扣，完成CPU的固定。固定CPU后，需要在CPU核心位置涂抹少量硅脂，用刮片涂成一张白纸厚度的均匀薄层，硅脂用于提升导热效率，帮助CPU散热。之后安装散热器，将散热器对准主板的对应孔位，把螺丝向右旋转45°完成固定，整个安装过程完成。
