**字符数组的基础定义**
* **字符数组的定义规则**：字符数组是存放字符型数据的数组，每个元素都是字符型变量，定义格式为「字符类型 + 数组名 + 方括号内的长度」，例如长度为10的字符数组A、长度为20的字符数组C都符合定义规则。
* **字符串的定义规则**：字符串是特殊的一维字符数组，以`\0`作为结束标识；若要存放30个实际字符，字符数组长度至少为31，课程中一般直接写长度30即可。
* **字符数组的下标规则**：和普通数组一致，下标从0开始，长度为N的数组下标范围是0到N-1；长度为7的字符数组，下标范围就是C0到C6。

**字符数组的初始化规则**
* **一维字符数组初始化**：按顺序给每个元素赋值，未赋值的末尾元素自动补`\0`作为结束标识；例如长度为10的字符数组，给前9个元素赋值后，第10个元素C9自动赋值为`\0`。
* **未完全赋值的默认值**：定义长度为6的字符数组，只给前5个元素赋值时，最后一个元素默认赋值为`\0`，ASCII码值0对应的字符就是`\0`。
* **二维字符数组初始化**：和普通二维数组定义规则一致，是一维数组的嵌套，用双层大括号按行赋值；例如可以定义一个4行5列的二维字符数组，按行依次给每行赋值。

**字符数组的引用方法与基础例题**
* **字符输出格式**：引用字符数组输出单个字符时，需要使用`%c`格式符指定输出为字符型。
* **输出字符串例题演示**：定义长度为9的字符数组，循环9次依次输出每个字符，最终输出结果为“江苏”。
* **字符复制例题演示**：定义长度都为9的两个字符数组C和D，C赋值8个字符后末尾自动补`\0`，通过for循环从C0到C8依次把每个字符复制到D的对应下标位置，再循环输出D的所有字符即可完成复制。

**字符数组输入逆序输出例题讲解**
* **输入循环逻辑**：要求输入不超过50个字符，以换行符结束存入数组A，使用do-while循环实现输入；从下标0开始逐个输入字符，当前字符不等于换行符时继续循环，遇到换行符退出循环，最终下标I停在最后输入位置的后一位。
* **逆序输出初始调整**：I停在换行符的后一位，不能输出换行符，因此需要把I减去2，定位到最后一个有效字符的位置开始输出。
* **逆序输出循环逻辑**：循环条件为I≥0，每输出一个字符后I减1，直到输出完下标0的字符后结束循环，完成逆序输出。

**字符串大小写转换例题讲解**
* **循环范围确定**：使用和上一题相同的do-while输入逻辑，I最终停在换行符后一位，因此循环转换的范围是J从0开始到J<I-1，不处理换行符。
* **大小写转换规则**：大写字母的ASCII码比对应小写字母小32，因此大写转小写需要给字符值加32，小写转大写则需要给字符值减32。
* **判断条件**：仅当字符值大于等于'A'且小于等于'Z'时，才执行大写转小写操作；输出时同样只输出到J<I-1，不输出换行符。

**数字字符转数值例题讲解**
* **知识点考察频率**：该知识点是高考C语言考题的高频考点，每套考题几乎都会涉及，包括理论题和上机题。
* **转换规则**：数字字符转换为对应数值，需要用数字字符减去字符'0'，也可以减去ASCII码值48，两种写法都可以得到正确的数值结果。
* **存储与输出逻辑**：转换后的数值存入数组B，每存入一个有效数值后数组下标N自增，输出时for循环从0开始，到J<N结束，输出所有提取出的数值。

**字符串存储与初始化规则**
* **存储要求**：C语言没有专门的字符串变量，通常用字符数组存放字符串；字符数组的长度至少要比字符串实际字符数多1，多余的位置用来存放结束标识`\0`。
* **输出规则**：使用printf函数输出字符串时，用`%s`作为格式符，遇到第一个`\0`就停止输出，不再输出`\0`之后的任何字符。
* **输入规则**：使用scanf函数输入字符串时，用`%s`作为格式符；输入的字符总长度必须小于数组定义长度，需要留出1个位置存放`\0`；scanf无法接收空格、换行、Tab等空白符，遇到空白符就会结束输入。

**printf与scanf使用考点讲解**
* **字符串输出陷阱题**：定义字符串为`c program\0design`，使用printf输出时，遇到第一个`\0`就停止，最终输出结果仅为`c program`，这是考试常见的陷阱题。
* **数组名地址特性**：给字符串输入时，数组名本身就代表数组的首地址，因此scanf参数中数组名前不需要加地址符`&`，这是改错题的常见考点。
* **含空格字符串输入示例**：输入`this is a book`时，因为包含空格，scanf会在第一个空格处结束输入，最终只能得到`this`；如果要完整输入，需要定义4个独立的字符串分别存放四个单词，每个字符串名前都不需要加地址符`&`。

**字符串比较逻辑与对应例题**
* **比较规则**：字符串比较需要逐个字符依次比较ASCII码，直到出现不相等的字符或其中一个字符串结束；如果其中一个字符串已经结束，另一个还有字符，那么未结束的字符串更大。
* **比较循环逻辑**：输入两个字符串分别存入数组A和B，初始I=0，当`A[I] == B[I]`且A、B都没有遇到`\0`时，I自增继续比较，直到出现不相等或某一个字符串结束，停止循环后比较当前字符得到结果。
* **变体例题规则**：例题要求两个字符相等时，大写转小写、小写转大写，不相等就转换为星号；Tom和time比较时仅比较3次，到第一个字符串遇到`\0`就停止循环。

**特殊考点与字符串操作例题**
* **转义字符与continue考点**：遇到`\0`时要注意转义字符的识别，`\0`本身就是一个转义字符，代表字符串结束；continue语句会直接结束当前轮循环，进入下一轮，满足条件遇到continue后，对应字符不会输出。
* **switch语句穿透特性**：case分支如果没有break语句，会继续执行后续分支的代码，这就是switch的穿透性，题目中经常考察该特性。
* **删除数字字符例题**：遍历字符串直到遇到`\0`，如果当前字符不是数字字符，就保留该字符；如果是数字字符就跳过不保留，从而实现删除字符串中所有数字字符的功能。
