#### 知识精讲
本次课讲解C语言语句分类，重点讲解格式化输入输出中printf的格式规则、常用格式符的用法与考点，覆盖了考试常考的宽度控制、对齐方式、小数保留等核心内容。

**C语言语句分类**
* **简单语句分类**：
  1. 空语句：仅由一个分号`;`构成，程序可正常运行，无实际执行效果。
  2. 表达式语句：由表达式加分号构成，例如`i++;`、`b+c;`等。
  3. 函数调用语句：调用函数并加分号构成，例如调用`printf`输出内容，可直接传入字符串或带占位符加对应变量。
  4. 复合语句：用一对大括号`{}`将多条有序语句组合而成，语法合法，仅在分支、循环结构中规范使用，单独使用不违规但不规范。
  - 🚩重点：复合语句只有在控制结构（分支、循环）中才需要使用，单独包裹单条语句不报错但不规范。
* **结构语句分类**：
  1. 选择语句：`if`、`if-else`等分支语句。
  2. 循环语句：`for`、`while`、`do-while`三种循环。
  3. 非结构化控制语句：`break`、`continue`、`return`、`goto`。
  - 🚩重点：`goto`是无条件转向语句，**考试不做要求**，只需掌握前三个控制语句即可。

**字符输入输出函数：getchar()与putchar()**
* **基本用法**：
  - `getchar()`：从输入读取一个字符，返回值为读取到的字符，一般赋值给字符变量，写法为`char c = getchar();`。
  - `putchar(参数)`：输出参数对应的单个字符，参数可以是字符变量、字符常量、转义字符甚至表达式。
  - 🚩重点：getchar一次只能读取**一个字符**，putchar一次只能输出**一个字符**。
* **典型应用：小写字母转大写字母**：
  小写字母的ASCII码比对应大写字母大32，因此通过`putchar(ch - 32)`即可实现转换。
  *代码示例*：
```c
char ch = getchar();
putchar(ch - 32); // 小写转大写
// 也可以直接简写为 putchar(getchar() - 32); 无需定义变量
```
* **ASCII码输出规则**：如果需要输出字符对应的ASCII码，需要用`printf("%d", c)`以整数格式输出，即可得到对应十进制ASCII值；转义字符`\n`也可以通过`putchar('\n')`输出实现换行。

**格式化输出函数printf()**
* **基本语法**：
```c
printf("格式控制字符串", 变量1, 变量2, ...);
```
格式控制字符串中：占位符（以`%`开头）会被后续变量的值替换，**非格式字符串会原样输出**，不能省略。例如`printf("a=%d, b=%d", a, b);`中`a=`、`, b=`都会原样输出。
* **输出宽度规则**：
  格式符`%nd`表示以宽度`n`输出整数：
  - 如果实际位数小于n：左侧补空格，默认右对齐。
  - 如果实际位数大于n：**按实际位数输出，不会截断**。
  - 🚩重点：考试常考`%5d`中数字`5`的含义，标准答案是**输出宽度为5**，不要写“占5个格子”这种非标准表述。
* **对齐规则**：
  - 默认无符号：右对齐，不足宽度左补空格。
  - 添加负号`%-nd`：左对齐，不足宽度右补空格。
* **符号输出规则**：添加`%+nd`：正数会自动输出正号`+`，负数正常输出负号，不常用，了解即可。
* **浮点数输出规则**：
  - `%f`默认输出**6位小数**，不指定保留位数时遵循默认规则。
  - `%m.nf`：`m`表示总输出宽度，`n`表示保留n位小数，小数点也占1个宽度；保留小数时遵循**四舍五入**规则。
  - 🚩重点：四舍五入规则属于考点范围，考试可能考保留小数后的结果。

**常用格式符汇总**
* **`%d`**：输出十进制有符号整数。
* **`%ld`**：输出长整型（`long`类型）整数，仅作类型标识，输出结果和`%d`在多数编译器下一致。
* **`%c`**：输出单个字符。
* **`%f`**：输出十进制浮点数（float/double）。
* **`%e`/`%E`**：以科学计数法输出浮点数，考试很少考，了解即可。
* **`%o`**：**注意是字母o，不是数字0**，将输入的十进制数转换为八进制输出。
* **`%x`/`%X`**：将输入的十进制数转换为十六进制输出，小写`x`输出小写字母，大写`X`输出大写字母。
* **`%s`**：输出字符串。
* **`%u`**：输出无符号十进制整数（对应`unsigned int`类型），只能输出正数，输入负数会得到不确定结果。
* **输出百分号**：需要连续写两个`%%`，才会输出一个`%`，例如`printf("%%%d", 5);`的输出结果为`%5`，该考法曾经出现过，需要注意。

[00:15:17](https://getnotes.seek:917) **输出宽度考点强调**
🚩重点：之前考试考到过格式符中数字的含义，例如`%8d`中`8`的标准答案是**表示输出宽度为8**，不能写“占5个格子”这种非标准表述。如果整数实际位数小于指定宽度，会在左侧补空格，默认右对齐输出。

[00:16:40](https://getnotes.seek:1000) **超宽度输出规则**
🚩重点：如果实际数据的位数超过指定宽度，会按照实际位数输出，不会截断，只有位数不足时才补空格，例如指定宽度为3，实际数是`30000`，依然会完整输出`30000`，不会截断。

[00:18:07](https://getnotes.seek:1087) **对齐规则讲解**
默认输出是右对齐，即位数不足时左侧补空格；如果在宽度前加负号`%-5d`，则变为左对齐，位数不足时右侧补空格，负号表示对齐方向反转。

[00:19:13](https://getnotes.seek:1153) **加号修饰符说明**
`%+5d`的加号作用是：正数会显示正号，例如`printf("%+d", 3)`会输出`+3`，负数正常显示负号，该用法不常用，了解即可。

[00:21:00](https://getnotes.seek:1260) **浮点数输出规则**
- `%f`默认保留6位小数，不指定保留位数时遵循默认规则。
- `%.2f`表示保留两位小数，`%5.2f`中`5`依然表示总输出宽度，宽度不足时左侧补空格，小数点也计算在总宽度内。
- 🚩重点：保留小数时默认遵循四舍五入规则，该知识点属于考点范围，即使多年没考，也要掌握。例如对`3.14159`保留四位小数，第五位是9≥5，因此结果为`3.1416`；如果原数是`3.14154`，第五位是4<5，结果为`3.1415`。

[00:24:24](https://getnotes.seek:1464) **扩展格式符讲解**
补充讲解不常考的格式符，完善知识体系：
- `%ld`：表示输出长整型，对应`long long`类型变量，加`l`仅作类型标识，输出结果和`%d`基本一致。
- `%e`：表示以科学计数法输出浮点数，例如`0.01`会输出为`1e-02`，考试几乎不考，了解即可。

[00:27:32](https://getnotes.seek:1652) **进制转换输出格式符**
- `%d`是输出十进制整数，还有其他进制的输出格式符：
- `%o`：注意是字母O，不是数字0，作用是将输入的十进制数转换为八进制输出，例如十进制12转换为八进制是14，因此`printf("%o", 12)`会输出14。
- `%x`/`%X`：将十进制数转换为十六进制输出，小写`x`输出小写字母，大写`X`输出大写字母，例如十进制12转换为十六进制是`c`（小写`x`）或`C`（大写`X`）。

[00:30:22](https://getnotes.seek:1822) **字符串与无符号数格式符**
- `%s`：输出字符串，用法之前已经讲过，直接输出字符串内容。
- `%u`：输出无符号十进制整数，对应`unsigned int`类型，无符号数只能表示正数，如果输出负数会得到不确定的结果。

[00:32:27](https://getnotes.seek:1947) **输出百分号的特殊写法**
🚩重点：如果要输出一个百分号`%`，需要在格式字符串中写两个连续的百分号`%%`，例如`printf("%%%d", 5)`会输出`%5`，该考法曾经出现过，需要注意。

#### 💡 核心概念
- **空语句**：仅由单个分号`;`构成的语句，语法合法，无实际执行功能。
- **复合语句**：用一对大括号`{}`包裹多条语句构成的语句块，一般用于控制结构。
- **getchar()**：C语言字符输入函数，一次读取一个字符，返回读取到的字符。
- **putchar(c)**：C语言字符输出函数，一次输出一个字符。
- **printf格式宽度`%nd`**：
  $$\%nd \text{ 表示：以宽度n输出整数，不足n位补空格，默认右对齐，超宽按实际输出}$$
- **printf保留小数`%m.nf`**：
  $$\%m.nf \text{ 表示：总宽度m，保留n位小数，小数点占1位宽度，遵循四舍五入}$$
- **常见格式符对应输出**：
  | 格式符 | 作用 |
  |--------|------|
  | `%d` | 十进制整数 |
  | `%c` | 单个字符 |
  | `%f` | 浮点数 |
  | `%o` | 八进制整数 |
  | `%x/%X` | 十六进制整数 |
  | `%s` | 字符串 |
  | `%%` | 输出百分号 |
