本次课为C语言排序题习题讲评课，针对学生常见的死套模板问题纠错，讲解字符串冒泡排序的正确实现方法，要求学生重练所有排序题型，举一反三掌握不同需求的排序逻辑。

**C语言排序题常见错误分析**
* **死套旧模板问题**：学生解题时不看题目需求，盲目套用之前做过的其他排序题的代码结构，导致逻辑错误，常见错误套模板场景包括：
  - 套最大整数拼接题模板：题目要求是直接比较字符串大小，不需要提前拼接候选顺序
  - 错误套用其他多数组排序题模板，凭空生成多余数组/变量，逻辑冗余错误
   - 🚩重点：**不能死记硬背代码结构，必须根据题目需求调整代码逻辑，要做到举一反三**
* **字符串比较的常见语法错误**：很多同学直接使用大于号`>`比较两个字符串的大小，这是C语言的典型错误
   - 🚩重点：C语言中比较字符串大小，必须使用`strcmp`字符串比较函数，不能直接用关系运算符

**字符串冒泡排序代码实现**
* **冒泡排序框架**：对于`m`行的二维字符串数组，外层循环框架和整数排序完全一致，固定写法为：
  ```c
  for (int i = 0; i < m - 1; i++) {
      for (int j = 0; j < m - 1 - i; j++) {
          // 比较交换逻辑写在此处
      }
  }
  ```
* **比较逻辑实现**：使用`strcmp`函数比较相邻两个字符串`B[j]`和`B[j+1]`的大小，若需要升序排序，当`strcmp(B[j], B[j+1]) > 0`时，说明前一个字符串字典序大于后一个，需要交换二者位置。
* **字符串交换实现**：不需要额外的复杂拷贝操作，直接交换二维数组的行指针即可完成交换，代码简化为：
  ```c
  char* temp = B[j];
  B[j] = B[j+1];
  B[j+1] = temp;
  ```
* 补充：本道题仅需要对当前字符串数组本身排序，不需要额外创建新数组，也不需要联动其他数组排序。

**特殊排序题的逻辑差异**
* **多数组联动排序**：部分题目要求同时对两个关联数组按照同一规则排序，交换时需要同时交换两个数组对应位置的元素，逻辑和单数组排序不同。
* **多条件排序**：部分题目要求先按照第一关键字排序，第一关键字相等时再按照第二关键字排序，需要增加额外的条件判断，代码逻辑和单条件排序有区别。
  - 例如题目要求：先按照字符串的和排序，和相等时再按照字符串本身的字典序排序，需要嵌套判断条件实现。

#### 💡 核心概念
- **C语言字符串比较**：必须使用库函数`int strcmp(const char *s1, const char *s2)`，当`s1`字典序大于`s2`时，返回值大于0。
- **字符串冒泡排序（升序）核心代码**：
```c
// 对m行字符串数组B排序
for (int i = 0; i < m - 1; i++) {
    for (int j = 0; j < m - 1 - i; j++) {
        if (strcmp(B[j], B[j+1]) > 0) {
            // 交换两个字符串行
            char *temp = B[j];
            B[j] = B[j+1];
            B[j+1] = temp;
        }
    }
}
```
