# 物理电阻串并联电路讲解课堂

## 原始正文

### 📑 智能总结

#### 课程信息

- **领域**：中学物理 / 电路基础

#### 知识精讲
本节课复习巩固电阻串联规律，讲解电阻并联的定义、规律与公式，结合例题讲解等效电阻计算方法，最后分析混联电路的等效电阻计算思路，指导练习真题。

**欧姆定律与串联电路复习**
* **欧姆定律基础**：电路中电流、电压、电阻满足欧姆定律，核心关系为电流等于总电压除以总电阻，可通过已知量推导未知的电阻、电压。
* **串联分压公式**：串联电路可使用拓展分压公式直接计算分电压，无需分步求电流，简化计算过程。
   - 🚩重点：**考试中能用拓展公式尽量优先使用拓展公式，减少计算量，降低出错概率**
   - *公式*：$$U_1 = U \cdot \frac{R_1}{R_1+R_2}$$
   - 推导：串联总电阻 $R = R_1+R_2$，总电流 $I = \frac{U}{R}$，代入 $U_1=IR_1$ 可得上述分压公式。

**电阻并联电路基础**
* **并联电路定义**：两个或多个电阻并列连接，电路产生多个电流分支，电流可从不同支路流过，即为并联电路。
* **并联电路核心规律**：
   - 🚩重点：电压规律：并联电路各支路电压相等，总电压等于各支路电压，即 $U = U_1 = U_2 = ... = U_n$
   - 🚩重点：电流规律：总电流等于各支路电流之和，即 $I = I_1 + I_2 + ... + I_n$
   - 🚩重点：电阻规律：总电阻的倒数等于各电阻倒数之和，多个电阻并联公式依然成立，即 $\frac{1}{R} = \frac{1}{R_1} + \frac{1}{R_2} + ... + \frac{1}{R_n}$
   - 欧姆定律依然适用于并联总电路：$I = \frac{U}{R}$

* **并联等效电阻计算要点**：
   - 🚩重点：计算结果校验：并联后等效电阻一定小于任意一个支路电阻，如果计算结果大于任意支路电阻，说明计算错误，需要重新检查。
   - 🚩考点：分数计算易错点：计算倒数和时必须先通分再相加，不能直接分子分母分别相加。例如$\frac{1}{2}+\frac{1}{3}$通分后为$\frac{3}{6}+\frac{2}{6}=\frac{5}{6}$，因此$R=\frac{6}{5}=1.2Ω$，而非错误结果$\frac{2}{5}Ω$。

**并联电路例题计算**
已知电压6V，两个电阻$R_1=2Ω$，$R_2=3Ω$并联，求等效电阻与总电流、各支路电流：
* **第一步计算等效电阻**：根据并联电阻公式：
  $$\frac{1}{R} = \frac{1}{R_1} + \frac{1}{R_2} = \frac{1}{2}+\frac{1}{3}=\frac{5}{6} \implies R=1.2Ω$$
* **第二步计算总电流**：根据欧姆定律：
  $$I = \frac{U}{R} = \frac{6}{1.2}=5A$$
* **第三步计算各支路电流**：根据并联电压相等，分别套欧姆定律：
  $$I_1 = \frac{U}{R_1} = \frac{6}{2}=3A, \quad I_2 = \frac{U}{R_2} = \frac{6}{3}=2A$$

**混联电路等效电阻计算**
* **混联电路定义**：电路中同时存在串联与并联连接关系的电路，需要通过逐步等效法计算总电阻。
* 🚩重点：计算思路：从电路内部可以确定的局部连接开始，逐步等效化简，最终得到总电阻：
  1. 先识别局部可确定的串并联关系，将局部等效为一个电阻；
  2. 等效后重新识别新电路的串并联关系，继续等效化简；
  3. 重复步骤直到得到整个电路的总等效电阻。

* **真题例题讲解（2020年真题，教材17页第4题）**
已知电阻：$2Ω$、$3Ω$、$6Ω$，电路关系为$3Ω$与$6Ω$先串联，再与$2Ω$并联，最后整体和$5Ω$串联，求总电阻：
1. 第一步：局部串联等效：$3Ω+6Ω=9Ω$（修正：原例题中实际为$2Ω+6Ω=6Ω$）
2. 第二步：并联等效：6Ω和3Ω并联：
   $$\frac{1}{R_{并}} = \frac{1}{6}+\frac{1}{3} = \frac{1}{2} \implies R_{并}=2Ω$$
3. 第三步：整体串联等效：总电阻：
$$R_{总} = 5Ω + 2Ω = 7Ω$$

#### 💡 核心概念
- **欧姆定律**：$$I = \frac{U}{R}$$
- **并联电路电压规律**：$$U = U_1 = U_2 = ... = U_n$$
- **并联电路电流规律**：$$I = I_1 + I_2 + ... + I_n$$
- **并联电路电阻规律**：$$\frac{1}{R} = \frac{1}{R_1} + \frac{1}{R_2} + ... + \frac{1}{R_n}$$
- **混联电路**：同时包含串联与并联连接关系的电路，需通过逐步等效法计算总电阻。
