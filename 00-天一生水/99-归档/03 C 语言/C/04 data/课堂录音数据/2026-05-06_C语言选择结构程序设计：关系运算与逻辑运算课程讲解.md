**课程导入与学习目标**
* **选择结构引入**：顺序结构只能按自上而下的顺序执行，无法满足现实中需要根据条件选择执行流程的需求，因此需要引入选择结构。
* **本节课核心学习目标**：共3个目标，分别为掌握关系表达式和逻辑表达式的应用、掌握if语句的多种使用方法、掌握switch语句的程序设计用法。
* **典型选择结构问题举例**：共列举3类典型问题，分别为判断输入数是否为正数并输出、判断输入四位数年份是否为闰年、根据输入考试成绩判断优良中及格不及格五个等级。

**关系运算符基础规则**
* **关系运算定义**：关系运算本质是比较运算，将两个数值进行比较，判断是否符合给定的关系，比较结果只有真（条件成立）和假（条件不成立）两种。
* **C语言6种关系运算符**：分别为<、<=、>、>=、==、!=，其中前4种优先级为第6级，后2种优先级为第7级，优先级数字越大优先级越低。
* **常见书写错误提醒**：学习者常将等于关系运算符`==`误写为赋值运算符`=`，将不等于误写为单等号，该错误会直接导致表达式逻辑错误，需特别注意。
* **关系运算符核心规则**：所有关系运算符都是双目运算，结合性全部为自左向右；优先级低于算术运算符，高于赋值运算符。

**关系表达式的计算规则**
* **关系表达式定义**：由关系运算符连接两个表达式，符合语法规则的表达式就是关系表达式。
* **关系表达式结果规则**：C语言没有独立的逻辑型数据，用整数1表示逻辑真，用整数0表示逻辑假。
* **多关系运算符连写计算演示**：对`3 < 4 < 5`表达式，按照自左向右结合性，先计算`3 < 4`得到结果1，再计算`1 < 5`得到最终结果1。若表达式为`number1 < number2 < 5`，无论number1和number2如何修改，前一步计算结果只能是0或1，都小于5，因此最终结果始终为1。

**关系表达式例题计算演示**
* **7道代入计算例题**：已知变量`a=3，b=2，c=1`，分别计算7个表达式的结果：
    - `a-b > 1`：计算得`1>1`不成立，结果为0；
    - `b+c > a`：计算得`3>3`不成立，结果为0；
    - `a > b > c`：先算`3>2`得1，再算`1>1`不成立，结果为0；
    - `a < b < c`：先算`3<2`得0，再算`0<1`成立，结果为1；
    - `a == b == c`：先算`3==2`得0，再算`0==1`不成立，结果为0；
    - `a = b = c`：该表达式是赋值运算，按照从右向左结合，最终`a`的值为1；
    - `a != b != c`：先算`3!=2`得1，再算`1!=1`不成立，结果为0。
* **核心知识点总结**：无法仅用关系运算符直接表达多条件顺序判断，必须结合后续学习的逻辑运算实现。

**逻辑运算引入与基础规则**
* **逻辑运算引入原因**：关系表达式只能描述单一条件，对于`0 ≤ X < 10`这类需要同时满足多个条件的需求，必须借助逻辑表达式实现。
* **C语言3种逻辑运算符**：分别为逻辑非`!`（单目运算，优先级2级，结合性自右向左）、逻辑与`&&`（双目运算，优先级11级，结合性自左向右）、逻辑或`||`（双目运算，优先级低于逻辑与，结合性自左向右）。
* **逻辑运算规则**：逻辑非运算，运算量为0时结果为1，运算量为非0时结果为0；逻辑与运算，只有两个运算量都为非0时，结果才为1，否则为0；逻辑或运算，只要有一个运算量为非0，结果就为1，只有两个都为0时结果才为0。

**逻辑运算符优先级与短路规则**
* **逻辑运算符优先级排序**：优先级从高到低为逻辑非 > 算术运算符 > 关系运算符 > 逻辑与 > 逻辑或 > 赋值运算符。
* **逻辑与短路规则**：连续逻辑与运算中，若前面的运算分量结果为0，则整个表达式结果直接为0，不需要再计算后续的运算分量，相当于一票否决。
* **逻辑或短路规则**：连续逻辑或运算中，若前面的运算分量结果为1，则整个表达式结果直接为1，不需要再计算后续的运算分量。

**逻辑表达式例题计算演示**
* **基础例题计算**：已知`a=3，b=2`，计算5个表达式：
    - `!a`：a是非0值，结果为0；
    - `a && b`：a和b都是非0值，结果为1；
    - `!a || b`：`!a`为0，b为非0，结果为1；
    - `a || b`：a和b都是非0，结果为1；
    - `a && 0 || b`：先算`a&&0`得0，再算`0||2`，结果为1。

**多条件判断表达式写法**
* **从大到小排序判断写法**：判断三个互不相同整数`a、b、c`是否为从大到小排列，不能直接写`a > b > c`，必须写为`a > b && b > c`，两个条件同时满足才符合要求。
* **判断同正同负写法**：判断`a`和`b`同时为正或同时为负，可利用同号相乘为正的规则写为`a*b > 0`，也可写为`(a > 0 && b > 0) || (a < 0 && b < 0)`。
* **判断大写字母写法**：判断字符变量`ch`是否为大写字母，表达式写为`ch >= 'A' && ch <= 'Z'`，若成立则可加32转换为对应小写字母。

**逻辑表达式综合例题讲解**
* **结果为0的表达式判断**：已知`a=3，b=2，c=3`，选项D`!(a <= b) && !c || 1`，计算得`!1 && 0 || 1`即`0 && 0 ||1`结果为1，非零，正确选项为`!((a < b) && !c || 1)`计算后结果为0。
* **短路规则对变量赋值的影响**：已知`a=5，b=6，m原本值为0，n原本值为0`，表达式`(a > b) && (m = n = b)`，`a>b`结果为0，触发短路，后续赋值不执行，m和n都保持原有值不变。
* **短路规则例题**：已知`a=1，b=2，m=0，k=0`，表达式`(b > a) || (k = n = a)`，`b>a`结果为1，触发短路，后续赋值不执行，k保持原值0，因此正确选项为`m=0，k=0`。

[00:01:15](https://getnotes.seek:75) **选择结构典型问题举例**

列举了三类需要使用选择结构的典型问题：第一类是从键盘输入一个数，如果是正数则输出，否则不输出，该问题需要将输入数和0做关系比较，得到两种不同处理结果。第二类是输入四位数年份，根据“四年一闰，百年不闰，四百年又闰”的规则判断是否为闰年，属于二分支选择。第三类是输入考试成绩，判断优良中及格不及格五个等级，属于典型的多分支选择结构。所有选择结构都需要先进行条件判断，因此需要先学习关系运算和逻辑运算。

[00:04:17](https://getnotes.seek:257) **关系运算定义与关系运算符介绍**

关系运算本质是比较运算，将两个数值进行比较，判断是否符合给定的比较关系，结果只有真（成立）和假（不成立）两种。例如`5>3`结果为真，`2>3`结果为假。C语言共有6种关系运算符，分别是<、<=、>、>=、==、!=。需要注意两个常见书写错误：<=和>=不能写成数学中的单符号写法，等于关系的`==`不能误写为赋值运算符`=`，不等于`!=`也不能写错。

[00:07:40](https://getnotes.seek:460) **关系运算符优先级与结合性**

所有关系运算符都是双目运算，需要两个操作数。优先级规则：前四种关系运算符<、<=、>、>=优先级为第6级，后两种==、!=优先级为第7级，优先级数字越大优先级越低。所有关系运算符的结合性都是自左向右。优先级和其他运算符对比：关系运算符优先级低于算术运算符，高于赋值运算符。

[00:11:16](https://getnotes.seek:676) **关系表达式基础与计算规则**

由关系运算符连接两个表达式符合语法规则，就是关系表达式。关系表达式的结果是逻辑值，C语言没有逻辑型数据，因此用整数1表示逻辑真，用整数0表示逻辑假。通过具体例子演示优先级规则：表达式`a > 3 + 1`，先计算算术运算`3+1`得到4，再计算关系运算`a>4`，最后将结果赋值给变量b，符合“算术 > 关系 > 赋值”的优先级规则。

[00:14:34](https://getnotes.seek:874) **关系表达式连写计算演示**

以变量`number1=3，number2=4，number3=5`为例，演示多关系运算符连写的计算过程：
- `number1 > number2`，`3>4`不成立，结果为0；
- `(number1 > number2) != number3`，`0 !=5`成立，结果为1；
- `number1 < number2 < number3`，按自左向右结合先算`3<4`得1，再算`1<5`得1，结果为1，无论`number1`和`number2`如何修改，前一步结果只能是0或1，都小于5，因此最终结果始终为1。

[00:20:18](https://getnotes.seek:1218) **关系表达式代入计算例题讲解**

已知整形变量`a=3，b=2，c=1`，逐一计算7个表达式：
- `a-b > 1`：`3-2=1`，`1>1`不成立，结果为0；
- `b+c > a`：`2+1=3`，`3>3`不成立，结果为0；
- `a > b > c`：先算`3>2`得1，再算`1>1`不成立，结果为0；
- `a < b < c`：先算`3<2`得0，再算`0<1`成立，结果为1；
- `a == b == c`：先算`3==2`得0，再算`0==1`不成立，结果为0；
- `a = b = c`：属于赋值运算，从右向左结合，最终`a`的值为1；
- `a != b != c`：先算`3!=2`得1，再算`1!=1`不成立，结果为0。总结指出，仅用关系运算符无法直接表达多条件顺序判断，需要结合逻辑运算实现。

[00:24:44](https://getnotes.seek:1484) **逻辑运算引入与逻辑运算符介绍**

关系表达式只能描述单一条件，对于需要同时满足多个条件的需求（如`0 ≤ X <10`），必须借助逻辑表达式实现。C语言提供三种逻辑运算符：
- 逻辑非`!`：单目运算，优先级为2级，结合性自右向左，作用是取操作数的逻辑反；
- 逻辑与`&&`：双目运算，优先级11级，结合性自左向右，要求两个操作数同时满足条件；
- 逻辑或`||`：双目运算，优先级低于逻辑与，结合性自左向右，要求只要一个操作数满足条件即可。

[00:28:26](https://getnotes.seek:1706) **逻辑运算规则与优先级排序**

逻辑运算具体规则：逻辑非中，操作数为0结果为1，操作数为非0结果为0，任何非0数值做逻辑非结果都为0；逻辑与中，只有两个操作数都为非0，结果才为1，否则为0，例如参加国旗护卫队要求同时满足性别为男、身高≥1.8米，两个条件缺一不可；逻辑或中，只要有一个操作数为非0，结果就为1，只有两个都为0结果才为0，例如请两个同学开车，只要一个有驾照就可以完成。优先级排序从高到低为：逻辑非 > 算术运算符 > 关系运算符 > 逻辑与 > 逻辑或。

[00:34:27](https://getnotes.seek:2067) **逻辑运算短路规则讲解**

逻辑运算存在短路规则，可简化计算：
- 逻辑与短路：连续逻辑与运算中，如果前面的运算分量结果为0，整个表达式结果直接为0，不需要再计算后续运算分量，相当于一票否决。例如`X=1，Y=2，Z=3`，表达式`X>2 && Y<Z && (X+Y>Z)`，`X>2`结果为0，直接得到整个表达式结果为0，后续不需要计算。
- 逻辑或短路：连续逻辑或运算中，如果前面的运算分量结果为1，整个表达式结果直接为1，不需要再计算后续运算分量。例如`1<2 || Y>Z || ...`，`1<2`结果为1，直接得到整个表达式结果为1，后续不需要计算。

[00:38:16](https://getnotes.seek:2296) **逻辑表达式基础计算例题演示**

已知`a=3，b=2`，计算5个逻辑表达式：
- `!a`：a是非0值，逻辑非后结果为0；
- `a && b`：a和b都是非0值，结果为1；
- `!a || b`：`!a`为0，b为非0，结果为1；
- `a || b`：两个都是非0，结果为1；
- `a && 0 || b`：先算`a&&0`得0，再算`0||b`，结果为1。所有计算符合优先级规则：逻辑与优先级高于逻辑或，因此先算与再算或。

[00:40:18](https://getnotes.seek:2418) **参数传递顺序的特殊情况说明**

讲解了参数传递的特殊情况：相同表达式在不同参数传递顺序下结果会不同，因为C语言编译时参数默认从后往前处理。例如类似`printf("%d%d%d", a=b, b=c, c=原始值)`的表达式，会先处理最后一个参数的赋值，再依次向前，最终所有变量都会被赋值为同一个值，结果和从前往后计算的预期不一致。

[00:42:45](https://getnotes.seek:2565) **多条件判断表达式正确写法**

讲解了多条件判断的正确写法：要判断三个互不相同整数是否从大到小排列，不能直接写`a>b>c`，因为该表达式按自左向右计算，最终结果逻辑不符合需求。正确写法是`a>b && b>c`，要求两个条件同时满足。同时列举了其他典型场景：判断a和b同时为正或同时为负，利用同号相乘为正写为`a*b > 0`即可；判断字符变量ch是否为大写字母，写为`ch >= 'A' && ch <= 'Z'`，成立则加32即可转换为对应小写字母。

[00:44:45](https://getnotes.seek:2685) **逻辑表达式综合例题讲解**

讲解三道综合例题，结合短路规则和优先级规则分析结果：
- 第一题：已知`a=3，b=2，c=5`，找出结果为0的表达式，通过优先级和短路规则计算，正确选项结果为0。
- 第二题：已知`a=5，b=6`，`m初始为0，n初始为0`，表达式`(a>b) && (n=b)`，因为`a>b`结果为0触发短路，n没有被重新赋值，因此n保持初始值不变。
- 第三题：已知`a=1，b=2，m=0，k=0`，表达式`(b>a) || (k=n=a)`，因为`b>a`结果为1触发短路，k没有被重新赋值，因此k保持原值0。
