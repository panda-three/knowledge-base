**滑动窗口最大值问题题意理解**
* **问题定义**：给定一个长度为`n`的数组和滑动窗口长度`k`，窗口从数组左端向右依次滑动，每次滑动后取当前窗口内的最大值，最后将所有最大值按**降序排序**输出结果。
* **示例说明**：当数组长度为8，窗口长度k=3时，一共可以划分出`8-3+1=6`个滑动窗口，对应6个窗口最大值。
   - 第一个窗口元素为`[4, 3, -1]`，最大值为4，后续窗口依次右移一位重复计算。

**单个滑动窗口找最大值的基础方法：枚举法（原ASR转写的“宫内法”“功类法”为语音识别错误，修正为枚举法）**
* **核心思路**：🚩考点，算法找最值的基础思路，也是考试常考的基础代码
   1. 先假设窗口第一个元素为当前最大值
   2. 遍历窗口内剩余所有元素，依次和当前最大值比较
   3. 如果当前元素大于记录的最大值，则更新最大值为当前元素
* **基础代码逻辑**：
```c
// 假设窗口起始下标为i，窗口长度为k
int max_val = arr[i];
for (int j = i+1; j <= i + k - 1; j++) {
    if (arr[j] > max_val) {
        max_val = arr[j];
    }
}
```
* **解题技巧**：🚩重点 不确定边界公式时，用特殊值代入验证：当i=0，k=3时，终止条件为`0+3-1=2`，刚好遍历0、1、2三个下标，符合要求。

**多个滑动窗口的遍历逻辑**
* **窗口总数计算**：长度为`n`的数组，窗口长度为`k`，窗口总数为`n - k + 1`，窗口起始下标`i`的范围是`0 ≤ i ≤ n-k`。
* **双层循环结构**：外层循环遍历所有窗口的起始下标，内层循环在每个窗口内部找最大值，结果保存到最大值结果数组中。

**排序模块：基于排名的降序排序实现**
* **算法思路**：对每个元素，统计整个数组中比它大的元素个数，该统计值就是元素在升序排列中的插入位置；再通过转换得到降序的插入位置。
* **具体步骤**：
  1. 外层遍历每个待排序元素`result[i]`，初始化计数器`k=0`
  2. 内层再次遍历整个数组，若当前元素`result[i]`大于`result[j]`，则计数器`k++`，此时k就是该元素在升序数组中的插入位置
  3. 若需要得到降序排列，需要将升序位置转换为降序位置：🚩重点 转换公式为 `pos = (index - 1) - k`，其中`index`是结果数组的元素总个数。
* **示例验证**：对于元素4，数组长度`index=6`，计算得到升序位置`k=1`，代入公式得`pos = 5 - 1 = 4`，刚好符合降序数组`[7,6,5,5,4,3]`中4的下标位置，验证正确。

**代码填空解题技巧**
* 🚩重点 考试不要求看懂每一行代码，只需要看懂核心逻辑即可作答
* 🚩重点 不确定边界公式时，代入题目给的特殊值验证，就能推导出正确结果
* 不要追求一次看懂复杂代码，开发中也需要多次调试修改才能得到正确结果，学习中循序渐进理解即可。

[00:18:09](https://getnotes.seek:1089) **排序代码逻辑分析**
这段排序代码和我们之前学的顺序、选择、冒泡、插入排序都不一样，只能逐句读代码分析逻辑：排序代码中，index是结果数组的元素个数，外层遍历每个元素，每次外层循环都把k重置为0，然后内层再遍历一遍整个数组，如果当前外层元素大于内层元素，k就自增1。

[00:20:37](https://getnotes.seek:1237) **推导排序逻辑：k的含义**
推导得出k的含义：k统计了比当前元素小的元素个数，也就是当前元素在升序排列中的插入位置。结合示例验证：当前元素是4，遍历整个数组后，只有3比4小，因此k=1，说明4在升序排列中应该插入下标1的位置，符合逻辑。

[00:22:33](https://getnotes.seek:1353) **降序位置转换推导**
题目要求降序排序，我们得到的是升序位置，需要转换为降序位置：降序最终结果为`[7,6,5,5,4,3]`，元素4应该放在下标4的位置；升序位置k=1，index=6，最大下标为`index-1=5`，转换公式为 `pos = 5 - 1 = 4`，刚好得到正确位置，因此得出转换公式：`pos = index - 1 - k`，这就是第二个空缺的答案。

[00:25:32](https://getnotes.seek:1532) **整体逻辑再梳理**
重新梳理一遍整体逻辑：首先把数组划分为多个滑动窗口，外层循环遍历每个窗口的起始下标i；每个窗口内，假设第一个元素为最大值，然后从i+1开始遍历到`i+k-1`，依次比较更新最大值，把最大值存入结果数组；然后对结果数组排序，用排名法得到每个元素的升序位置k，再转换为降序位置`index-1-k`，完成排序。

[00:28:08](https://getnotes.seek:1688) **排序算法逻辑再总结**
这个排序是基于排名的算法：对每个元素，统计比它大的元素个数得到排名，转换得到插入位置；升序转降序只需要用最大下标减去升序位置即可得到正确的降序插入位置。

#### 💡 核心概念
- **滑动窗口**：长度固定为K的连续子数组，从数组左端向右依次移动，每次移动一位，用于处理连续子数组相关问题。
- **滑动窗口总数公式**：长度为`n`的数组，窗口长度`k`，窗口总数为 `n - k + 1`
- **滑动窗口结束下标公式**：起始下标为`i`，结束下标为：
  $$ end = i + k - 1 $$
- **降序位置转换公式**：升序位置为`k`，数组长度为`index`，降序插入位置为：
  $$ pos = (index - 1) - k $$
