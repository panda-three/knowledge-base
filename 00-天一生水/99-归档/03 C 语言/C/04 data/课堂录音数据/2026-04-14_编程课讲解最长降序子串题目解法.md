**题目要求解读**
* **题目核心需求**：给定M行字符串的二维数组，每行包含多个降序子串，要求找出每行的**最长降序子串**存入二维数组`B`；若一行中存在多个长度相同的最长降序子串，仅存入最后一个；最终对`B`中所有字符串按升序排序。
* **降序子串定义**：降序子串指串中字符的ASCII码值依次递减1，例如`ED`、`543`、`gfe`都符合要求。
* **得分规则**：第一问（找最长降序子串）和第二问（升序排序）为分开判分，第一问写不出不影响第二问得分，第二问仅排序一般可得15分，第一问写出结构即可得3分，起步总分约18分。
   - 🚩重点：两个问题分开判分，第一问不会时也要尽可能写出结构、完成第二问，不要空题。

**找最长降序子串的解题思路**
* **核心步骤拆分**：解题分为三步：①找出所有降序子串；②找出其中长度最长的子串；③记录最长子串的起始与结束下标，提取子串存入结果数组。
* **“最值问题”的通用解法：穷尽法（打擂台法）**：题目中出现“最长”关键词属于最值问题，必须使用穷尽法（打擂台法）解决，记录当前最大值，遇到更长的就更新最大值。
   - 🚩重点：只要出现“最”字，都属于最值问题，必须用穷尽法实现，哪怕不会完整实现也要写出穷尽法的框架。
* **记录起止位置的必要性**：找到最长长度后，必须记录最长子串的起始下标和结束下标，才能从原字符串中正确截取目标子串。

**找降序子串的代码框架**
* **整体遍历逻辑**：由于需要判断当前字符和前一个字符的关系，循环必须从下标`1`开始遍历，避免下标越界。核心判断条件为：当前字符ASCII码等于前一个字符ASCII码减1，该条件满足时说明当前字符属于当前降序子串。
* **核心循环结构**：
```c
int n = strlen(str);
int max_len = 1; // 初始最长长度
int start, end; // 记录起止位置

for (int i = 1; i < n; i++) {
    int cur_len = 1; // 当前降序子串长度，至少为1
    // 找到降序起始位置后，向后遍历直到不满足降序条件
    while (i < n && str[i] == str[i-1] - 1) {
        cur_len++;
        i++;
    }

    // 更新最长长度与起止位置
    if (cur_len >= max_len) { // >=保证相同长度时更新为最后一个
        max_len = cur_len;
        start = i - cur_len;
        end = i - 1;
    }
}
```
   - 🚩重点：当存在多个相同长度最长子串时，条件必须写`>=`（大于等于），而不能只写`>`，保证会更新为最后遇到的最长子串，满足题目要求。
   - 🚩易错点：循环必须从`i=1`开始，否则`i-1`会下标越界。

**结果截取与字符串规范**
* **截取子串代码逻辑**：根据记录的起始、结束下标，将对应字符逐一复制到结果数组中，最后必须手动添加字符串结束符`\0`。
* **截取代码示例**：
```c
int k = 0;
for (int j = start; j <= end; j++) {
    result[k++] = str[j];
}
result[k] = '\0'; // 手动添加字符串结束符
```
   - 🚩重点：C语言字符串必须以`\0`结尾，忘记添加会导致输出乱码，属于高频扣分点。

**常见代码错误调试**
* **错误1：忘记添加字符串结束符`\0`**：会导致结果字符串末尾出现多余乱码，解决方法是复制完字符后手动添加`\0`。
* **错误2：长度比较只使用`>`**：当存在多个相同长度的最长降序子串时，不会更新为后面的子串，不满足题目“只存最后一个”的要求，解决方法是将`>`改为`>=`。

**题目需求梳理**
* **问题定义**：给定M行字符串的二维数组，每行包含多个降序子串；降序子串定义为串中字符ASCII码值依次递减1。要求找出每行的**最长降序子串**存入二维数组B；若一行中存在多个长度相同的最长降序子串，**仅存入最后出现的一个**；最后对B中所有字符串进行升序排序。
* **评分规则说明**：本题分两问判分，第一问写结构即可得3-5分，第二问排序只要代码正确即可得分，第一问写不出不影响第二问得分，起步得分约18-20分。

**找最长降序子串的解题思路**
* **三步法框架**：第一步遍历字符串找出所有降序子串；第二步用**打擂法（功利法）**找出长度最大的最长降序子串；第三步记录最长降序子串的起始下标和结束下标，最后将子串复制到结果数组中。
   - 🚩重点：看到「最」字要敏感，最长/最大/最小问题统一使用打擂法解决，哪怕不会写完整代码也要把打擂法的框架写上。
* **降序子串判定条件**：只有满足`str[i] == str[i-1] - 1`时，当前字符才属于连续降序子串，由于条件中使用`i-1`，遍历必须从下标`1`（第二个字符）开始，避免下标越界。

**第一问函数代码框架实现**
* **第一步：遍历找连续降序子串**
```c
int n = strlen(str);
int max_len = 1; // 记录最长长度，初始为最小长度1
int start = 0, end = 0; // 记录最长子串的起止位置

for (int i = 1; i < n; i++) {
    int current_len = 1; // 当前子串长度，初始为1
    // 找到降序起始位置后，持续往后遍历，直到不满足降序条件
    while (i < n && str[i] == str[i-1] - 1) {
        current_len++;
        i++;
    }
```
* **第二步：打擂法更新最长信息**
满足当前长度大于（等于）最长长度时，更新最长长度并记录新的起止位置：
```c
    // 长度相等时也要更新，保证保留最后一个最长子串
    if (current_len >= max_len) {
        max_len = current_len;
        start = i - current_len; // 计算起始位置
        end = i - 1; // 计算结束位置
    }
}
```
* **第三步：复制结果到输出数组**
根据记录的起止位置，将最长子串逐个字符复制到结果数组，**必须添加字符串结束符`\0`**：
```c
int k = 0;
for (int j = start; j <= end; j++) {
    res[k++] = str[j];
}
res[k] = '\0'; // 🚩重点：C语言字符串必须手动加结束符，否则会输出乱码
```
   - 🚩考点：多个长度相同的最长子串需要保留最后一个，因此判断条件必须写`>=`，不能写`>`；如果只写`>`，只会保留第一个最长子串，不符合题目要求。
   - 🚩易错点：C语言字符串结尾必须手动添加`\0`结束符，否则会输出多余乱码，这是非常常见的扣分点。

**代码调试与常见bug修正**
* **bug1：未添加`\0`结束符**：现象是输出结果末尾会带上多余的乱码字符，修复方法就是在复制完所有字符后手动添加`res[k] = '\0'`。
* **bug2：判断条件写`current_len > max_len`**：题目要求相同长度保留最后一个最长子串，仅写大于无法更新后续等长的子串，会输出更早出现的子串，不符合题目要求，将`>`改为`>=`即可修复。

**第二问排序要求**
* **任务说明**：将二维数组B中所有存储好的最长降序子串，按照字符串大小进行升序排序。该问题为常规字符串排序问题，直接使用字符串比较函数实现排序即可，只要代码逻辑正确即可得分。
