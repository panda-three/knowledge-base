**C语言语句分类与各类语句规则**
* **语句基础规则**：C语言的语句以分号作为结束标记，高级语言源程序的基本单位是语句。
* **语句大类划分**：C语言语句分为简单语句和结构语句两类，简单语句用于完成基本操作，结构语句用于实现程序的控制流程。
* **具体语句类型规则**：空语句仅由一个分号构成，常出现在选择和循环结构中；表达式语句由表达式加一个分号构成，例如`i++`、`i=i+10`；函数调用语句由函数调用加一个分号构成，例如`printf`输出语句；复合语句用一对大括号将多条有序语句组合而成，逻辑上视为一条语句，大括号外不需要额外加分号。
* **流程控制语句分类**：流程控制语句也叫结构语句，分为选择语句、循环语句和非结构化语句；选择语句包含if条件语句和switch多分支语句，将在第四章详细讲解；循环语句包含for、while、do while三种语句。
* **常用控制语句功能**：break语句用于退出循环结构或switch结构；continue语句用于结束循环的本次循环，直接进入下一次循环；return语句用于函数返回，通常作为程序结束标志；goto语句为无条件转向语句，不提倡使用，仅要求学习者能够看懂即可。

**C语言输入输出基础规则**
* **输入输出定义**：输入输出以计算机主机为主体，从输入设备向主机传输数据称为输入，从主机向输出设备传输数据称为输出。
* **输入输出实现方式**：C语言本身没有定义输入输出关键字，所有输入输出功能都通过调用系统库函数实现。
* **头文件包含规则**：输入输出相关函数的声明都保存在标准输入输出头文件`stdio.h`中，使用前需要通过`#include`预处理指令将该头文件包含到程序中。
* **两种包含格式区别**：使用尖括号包含系统头文件时，编译系统直接在系统库函数头文件目录中查找，可节约查找时间；使用双引号包含头文件时，编译系统先在用户当前目录查找，找不到再按标准方式查找，适合包含用户自定义的头文件；如果路径包含多级目录，需要使用两个反斜杠表示一个路径分隔符，这是转义字符的规则。

**字符输入输出函数`getchar`与`putchar`使用讲解**
* **函数基础功能**：`getchar`用于从键盘读入一个字符，`putchar`用于向屏幕输出一个字符。
* **`getchar`运行逻辑**：`getchar`将输入字符先放入缓冲区，用户按下回车键后才会获取字符，并将结果回显到屏幕，每次只能读入一个字符；接收到的字符可以赋值给字符型或整型变量，也可以不赋值直接作为表达式的一部分使用。
* **`putchar`运行逻辑**：`putchar`需要传入一个字符参数，将参数对应的字符输出到显示屏当前光标位置，每次只能输出一个字符，参数可以是字符变量、字符运算表达式。
* **大小写转换示例演示**：定义字符变量`ch`接收输入的小写字母e，ASCII码为101，通过`putchar(ch - 32)`的方式输出，101-32=69，对应ASCII码的大写字母E，即可完成从小写字母到对应大写字母的转换，该操作不会改变原变量`ch`的值。
* **使用注意事项**：`getchar`一次只能接收一个字符，不适合用来接收多位数的整型数据，365这类数值已经超出ASCII码可表达的范围，无法通过`getchar`正确处理；两个函数都定义在`stdio.h`中，使用前需要通过`#include`包含该头文件。

**补充同类字符输入函数说明**
* **与getchar的核心区别**：另外两个同类输入函数不需要用户按下回车键确认，可直接接收键盘输入的字符。
* **两个函数的区别**：一个函数接收字符后不会回显到屏幕，另一个函数接收字符后会回显到屏幕；高中阶段不要求使用这两个函数，仅要求学习者遇到时能够识别即可。

**格式化输出函数`printf`基础规则**
* **`printf`定位**：`printf`是最常用的格式化输出标准库函数，几乎每道编程题都会用到，它可以按照用户指定的格式将指定数据输出到屏幕，需要包含`stdio.h`头文件才能使用。
* **调用格式说明**：`printf`的调用格式为`printf(格式控制字符串, 参数列表)`，参数列表用方括号标记，代表可省略；省略参数列表时，`printf`仅输出格式控制字符串的内容，此时格式控制字符串不能包含格式转换说明符。
* **参数规则说明**：如果有多个输出参数，参数之间用逗号分隔；输出项可以是变量、常量或表达式，输出项的数量和类型必须和格式控制字符串中的格式项一一对应。

**`printf`格式控制字符串规则**
* **格式字符串分类**：格式控制字符串分为格式字符串和非格式字符串两类；格式字符串以百分号`%`开头，用于指定输出数据的格式；非格式字符串会原样输出，主要用于输出提示信息。
* **对齐规则说明**：格式字符串中，`+`表示右对齐，正数前会输出正号，负数前会输出负号；`-`表示左对齐，其余默认都为右对齐；如果格式字符串前加空格，正数前会保留一个空格位置，负数对应位置输出负号。
* **输出宽度规则说明**：设置输出宽度为`M`位时，如果数据实际宽度不足`M`位，会前置补空格按右对齐输出；如果超出`M`位，会按照实际位数输出；如果不设置输出宽度，会按照数据实际位数输出。
* **浮点数格式规则**：浮点数格式为`m.a`，`m`是输出总宽度，`a`是小数位数，小数点占1位宽度；如果整数部分超出限定位数，按实际输出；如果小数位数不足，补零凑够位数；如果小数位数超出，按照四舍五入截取；不设置小数位数时，默认输出6位小数，不足补零。

**常用格式转换字符说明**
* **基础类型格式字符**：`%d`用于输出十进制整型，`%ld`用于输出十进制长整型，`%c`按字符型输出，`%f`按浮点型小数输出，`%e/%E`按科学计数法输出，`%o`按八进制整型输出，`%s`输出字符串，`%u`按无符号整型输出，`%x/%X`按十六进制整型输出。
* **特殊格式说明**：如果需要输出一个百分号，需要写两个连续的百分号`%%`才能正确输出一个百分号；指定输出宽度后，宽度不足时会用空格补足位置。

**`printf`使用示例讲解**
* **类型转换示例**：实型变量`a`赋值为`4.9`，再赋值给整型变量`b`，C语言整型赋值会直接舍弃小数部分，不会四舍五入，因此`b`的值为`4`，`a`保留`4.9`。
* **运算结果示例**：算术运算`5/2`是整数除以整数，C语言中会自动取整，结果为`2`；加上`5/2.0`的结果`2.0`，总结果是`4.0`，按照两位小数输出为`4.00`。
* **连续赋值示例**：`20/3`结果约为`6.666`，赋值给实型变量d得到`6.666`，再赋值给整型变量l会舍弃小数得到`6`，后续再赋值给实型变量f，f的值也为`6.0`，无法恢复之前的小数部分。
* **复合运算符与条件运算符示例**：复合赋值运算`y += z`会将`y+z`的结果赋值给y，y原本值为3，z为2，运算后y变为5，再执行`x += y`后x从1变为6；条件运算符`x<y?x:y`中，x为6y为5，条件不成立，因此输出y的值5。

[00:09:53](https://getnotes.seek:593) **字符输入输出函数`getchar`与`putchar`基础功能讲解**

最简单的字符输入输出函数是`getchar`和`putchar`，分别用于从键盘读入一个字符、向屏幕输出一个字符，可实现程序的交互效果。`getchar`会将输入字符放入缓冲区，用户按下回车键后才获取字符，并将结果回显到屏幕。`putchar`会将字符输出到显示屏的当前光标位置，所有函数都需要带一对括号，`getchar`是无参函数，`putchar`需要传入一个字符参数。

[00:11:48](https://getnotes.seek:708) **`getchar`与`putchar`使用示例与大小写转换演示**

第一个示例中，使用两个函数前需要先包含`stdio.h`头文件，定义字符型变量c，通过`c = getchar()`从键盘读入一个字符存入c，如果输入小写字母a，c的值就为a，再通过`putchar(c)`将c的值输出到屏幕，最后通过`return 0`结束程序，明确`getchar`无参数、`putchar`需要传入参数的规则。第二个示例实现小写字母转大写：定义字符变量ch接收输入的小写e，小写e的ASCII码为101，通过`putchar(ch - 32)`输出，小写字母ASCII码减去32即可得到对应大写字母的ASCII码，101-32=69对应大写E，因此会输出大写E，该操作不会改变原变量ch的值，ch仍然是小写e。

[00:16:43](https://getnotes.seek:1003) **`getchar`与`putchar`使用注意事项补充**

`getchar`一次只能接收一个字符，不适合接收多位数的整型数据，例如365已经超出ASCII码可表达的范围，无法用`getchar`正确处理。`putchar`一次也只能输出一个字符。`getchar`接收到的字符可以赋值给字符型或整型变量，也可以不赋值，直接作为表达式的一部分使用，例如`putchar(getchar())`可以直接将输入的字符输出，不需要存入变量。使用时需要注意括号配对，不要丢失括号。另外还有两个同类字符输入函数，不需要按回车键确认即可接收输入，一个不回显一个回显，高中阶段不要求使用，仅要求能识别即可。

[00:21:24](https://getnotes.seek:1284) **`printf`基础调用格式与参数规则讲解**

`printf`和`scanf`是最常用的输入输出函数，高考几乎每道编程题都会用到`printf`，可以按照用户指定格式实现数据输出。`printf`是标准库函数，需要包含`stdio.h`头文件才能使用。`printf`的调用格式为`printf(格式控制字符串, 参数列表)`，参数列表可省略，省略后仅输出格式控制字符串的内容，此时格式控制字符串不能包含格式转换说明符，例如`printf("hello")`可以直接输出`hello`。如果有多个输出参数，参数之间用逗号分隔，输出项可以是变量、常量或表达式，输出项的数量和类型必须和格式控制字符串中的格式项一一对应。

[00:25:06](https://getnotes.seek:1506) **`printf`格式控制字符串规则讲解**

格式控制字符串分为格式字符串和非格式字符串两类，非格式字符串会原样输出，例如普通文字、标点符号；格式字符串以百分号开头，用于指定输出数据的格式，格式包含对齐标识、输出宽度、格式转换字符三个部分。例如`%5d`表示以5位宽度输出整型数据，默认对齐方式为右对齐，宽度不足时前面补空格。对齐规则中，`+`表示右对齐，正数前输出正号，负数前输出负号；`-`表示左对齐，输出数据后剩余宽度补空格；空格标识表示右对齐，正数前保留一个空格位置，负数对应位置输出负号。

[00:30:45](https://getnotes.seek:1845) **输出宽度与浮点数格式规则讲解**

输出宽度规则：设置输出宽度为M位，如果数据实际宽度不足M位，前置补空格按右对齐输出；如果超出M位，按照实际位数输出，不会截断数据；如果不设置输出宽度，按照数据实际位数输出。浮点数格式为`m.a`，其中m是总宽度，a是小数位数，小数点占1位宽度；计算整数部分可用宽度为m减去a再减去1；如果整数部分超出限定位数，按实际输出；如果小数位数不足，补零凑数；如果小数位数超出，按照四舍五入截取；不设置小数位数时，默认输出6位小数，不足补零；类型转换中整型赋值会直接舍去小数不进位，和浮点数格式的四舍五入规则不同。

[00:35:10](https://getnotes.seek:2110) **常用格式转换字符说明**

格式字符用于说明输出变量的类型，常用规则包括：`%d`用于输出十进制整型，`%ld`用于输出十进制长整型，`%c`按字符型输出，`%f`按浮点型小数输出，`%e/%E`按科学计数法输出，`%o`按八进制整型输出，`%s`输出字符串，`%u`按无符号整型输出，`%x/%X`按十六进制整型输出。如果需要输出一个百分号，必须写两个连续的百分号`%%`才能输出一个百分号。举例说明：大写a的ASCII码是65，`%c`输出会得到字符a，`%5d`输出会在65前面补3个空格凑够5位宽度。

[00:37:05](https://getnotes.seek:2225) **`printf`多个应用示例计算讲解**

第一个示例：输出`9个 ceos drank 13.5 caps of coffee`，13.5不设置小数位数，默认输出6位小数，结果为`13.500000`；第二个示例：输出`2 * cost`的结果，会直接计算表达式的值并输出整形结果；第三个示例：算术运算`5/2`是整数除整数，结果取整为2，加上`5/2.0`得到的2.0，总结果是4.0，按两位小数输出为`4.00`；第四个示例：实型变量a赋值`4.9`，再赋值给整型变量b，整型会直接舍去小数部分，不四舍五入，因此b的值为4，a的值保留`4.9`。
