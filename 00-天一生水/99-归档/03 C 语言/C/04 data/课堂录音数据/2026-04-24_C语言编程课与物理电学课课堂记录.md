**C语言编程积木式解题法**
* **积木筛选规则**：仅收纳历年真题中重复出现≥2-3次的可复用代码块，单次题目出现的特殊写法、过于基础的语法不纳入积木库。
* **12个核心代码积木**：
   1. **扫描整个字符串**：推荐写法可避免循环常见错误（忘记初始化、忘记自增）。
      * 代码框架：
```c
for(int i = 0; i < strlen(str); i++){
    // 处理每个字符
}
```
   2. **找到一段并处理一段**：先通过if找到分段起点，再通过循环处理整段，分段条件根据题目要求设置（本题为不等于`#`）。🚩重点：不要死记条件，需根据题目要求灵活修改。
   3. **存储一段为字符串**：先定义空字符串，记录起始下标，循环中递增下标存储字符，最后添加字符串结束标记`\0`。
   4. **按进制拼整数**：核心逻辑为按权展开法，**十进制用`*10`，十六进制用`*16`，八进制用`*8`**。带符号整数需要额外增加符号标志位处理。
      - 🚩重点：核心公式为 $res = res \times base + val$，其中`base`为当前进制数，囊括所有进制转十进制的计算。
   5. **找最优结果（最大/最小/次大/次小）**：核心为遍历更新法，找最大/最小仅需单次遍历更新；找次大/次小需要定义两个变量，逻辑为：若当前值大于最大值，则原最大值更新为次大值，当前值更新为最大值；若当前值小于最大值但大于次大值，则仅更新次大值。
   6. **排序**：推荐使用冒泡排序，**注意交换整数和交换字符串的写法不同，不要混淆**。
   7. **拆位转换**：十进制拆位默认对10取余除10，按X进制拆位则对X取余除X，对应「除X取余法」转进制；从编码中拆信息使用除法取整、模运算取余提取对应位。
   8. **数组/字符串删除元素**：先找到待删除元素位置，从删除位置的下一个元素开始，依次向前移动一位，覆盖待删除元素。核心逻辑：`a[i-1] = a[i]`。
   9. **频数计数**：定义计数数组，遍历元素后执行`count[x]++`统计个数；统计小写字母个数时，下标可以用`当前字符 - 'a'(ASCII码97)`得到偏移量。
   10. **相邻字符关系判断**：判断相邻两个字符是否满足不降、递减、相等、连续等关系，常配合条件求和使用，🚩重点：若要求满足条件才求和，必须增加条件判断。
* **积木拼题法思路（以204题为例）**：
   1. 读题后**重点精读输入输出要求，至少读三遍**，不用纠结大段背景描述；
   2. 明确传入参数的具体形态和返回结果的具体形态：本题中第一个函数每次传入一行原始字符串，需要将其中井号分隔的十六进制转为十进制整数存入结果数组，第二个函数传入转换后的二维字符串数组，要删除升序排序后第三小的字符串；
   3. 从积木库选对应积木拼接：本题依次用到「扫描字符串」、「分段处理」、「十六进制拼整数」、「存储结果」四个积木，第二个问题用到「排序」、「删除元素」两个积木，组合后即可得到完整代码。
   - 🚩重点：新题都是老积木的重新拼接，把基础积木背熟就能轻松解题。

**电工电子：电阻的测量**
* **万用表欧姆档**：特点为反向刻度，刻度由大到小且不均匀。🚩考点：使用欧姆档时，红表笔接内部电源负极，黑表笔接内部电源正极，选择题常考。
* **伏安法测电阻**：
   * 原理：欧姆定律 $R = \frac{U}{I}$，通过测量电阻两端电压和通过的电流计算电阻。
   * 两种接法：
     1. **电流表内接法**：电流表在电压表的包裹范围内。
        - 误差分析：测量电压包含电流表的分压，因此测量值**大于真实值（偏大）**；
        - 🚩重点：适用测量**大电阻**，大电阻下电流表的分压可以忽略不计，误差更小。
     2. **电流表外接法**：电流表在电压表的包裹范围外。
        - 误差分析：测量电流包含电压表的分流，因此测量值**小于真实值（偏小）**；
        - 🚩重点：适用测量**小电阻**，小电阻下电压表的分流可以忽略不计，误差更小。
* **惠斯通电桥测电阻**：平衡条件为对臂电阻乘积相等：
$$ R_1 R_4 = R_2 R_3 $$
电桥平衡时，桥路电流为0，利用该公式即可计算未知电阻。该考点考察频率较低。

**等效电阻的串并联计算**
* 解题步骤：1. 标记两个端点；2. 识别节点（三条及以上线路的交点才是节点，两条线交点不算节点，相邻无元件的多个点可合并为一个节点）；3. 重新整理画出等效路径，找出所有通路；4. 从最内层开始逐步等效串并联，最终得到总电阻。
* 串并联公式：
  - 串联总电阻：$ R = R_1 + R_2 + ... + R_n $
  - 并联总电阻：$ \frac{1}{R} = \frac{1}{R_1} + \frac{1}{R_2} + ... + \frac{1}{R_n} $，两个电阻并联时可简化为 $ R = \frac{R_1 R_2}{R_1 + R_2} $

#### 💡 核心概念
- **代码积木**：历年真题重复出现的可复用代码块，做题时通过拼接积木快速写出完整代码。
- **伏安法内接法**：电流表在电压表测量范围内，测量值$R_{测}>R_{真}$，适合测量大电阻。
- **伏安法外接法**：电流表在电压表测量范围外，测量值$R_{测}<R_{真}$，适合测量小电阻。
- **惠斯通电桥平衡条件**：对臂电阻乘积相等，公式为：
$$ R_1 R_4 = R_2 R_3 $$
- **并联电阻总电阻公式**：
$$ \frac{1}{R} = \sum_{i=1}^{n} \frac{1}{R_i} $$
两个电阻并联简化公式：
$$ R = \frac{R_1 R_2}{R_1 + R_2} $$
