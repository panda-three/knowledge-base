#### 录音总结
本次课程为C语言程序设计课程，主要讲解了if语句的三种分支结构，结合例题演示了用法，分析了常见写法错误，并通过选择题和编程题巩固知识点，布置了课后复习任务。

**if语句分类与作用介绍**
* **if语句核心作用**：if语句是重要的程序控制流程，可根据给定条件是否满足选择执行对应操作。
* **if语句的三种结构**：if语句一共分为单分支、双分支、多分支三种结构，会根据表达式真假选择不同的执行路径。

**单分支if语句讲解**
* **单分支语法规则**：单分支结构在if后括号内写入表达式，若表达式值为非零（真），则执行if内语句，否则不执行该语句。
* **单分支例题演示**：例题要求输入整数，仅当该整数为正数时输出结果。若输入30，满足大于0的条件，程序会输出30；若输入0或-20，不满足条件，程序无输出。

**双分支if-else语句讲解**
* **双分支语法规则**：双分支结构为if-else语句，表达式成立则执行if内语句一，不成立则执行else内语句二，无论真假都会执行对应语句，因此称为双分支。
* **双分支语法注意事项**：表达式必须用括号括起来，else必须和if配对使用，不能单独存在；如果if或else下语句组超过1条，需要用花括号括起来，仅1条语句可以不用花括号。
* **双分支例题演示**：例题要求输入学生成绩，判断成绩是否合格。若输入65，满足≥60分的条件，程序输出“该生成绩合格”；若输入45，不满足条件，程序输出“该生成绩不合格”，两种情况仅会执行一个分支。

**多分支if-else-if结构讲解**
* **多分支执行逻辑**：多分支从上到下逐个判断条件，一旦某个表达式值为非零（成立），就执行对应语句，执行完后直接跳出整个if结构，执行后续代码；若所有条件都不成立，则执行最后else内的语句，最后else可根据实际情况省略。
* **多分支书写规则**：整个if-else-if结构本质上仍然是一条语句，不需要额外加分号；书写时需要注意缩进，if、else if、else属于同级结构，需要对齐排列，子语句需要缩进。
* **多分支常见错误分析**：错误写法是只写分数下限不加上限，比如仅写“x<60输出E，x≥60输出D”，输入75分或95分都会被判定为D等级，更高等级永远不会被匹配。正确写法是为每个区间加上下限，比如`60≤x<70`输出D，`70≤x<80`输出C，保证每个分数只会匹配到一个正确等级。
* **多分支例题演示**：例题要求输入成绩，输出对应等级：≥90输出A，80-89输出B，70-79输出C，60-69输出D，60分以下输出E，输入95会输出A，输入75会输出C，仅会匹配一个正确分支。

**if语句基础选择题讲解**
* **第1题讲解**：题目问if(x)什么时候执行语句，正确答案为x≠0，if语句只要表达式为非零就会执行，不需要x一定等于1。
* **第2题讲解**：题目问当A=3，B=4时哪个表达式值为1，正确答案为C选项`(A&&!B)||(A-B)`，该表达式最终计算结果为非零，因此值为1。
* **第3题讲解**：题目问哪个选项的功能和另外三个不同，正确答案为C选项，只有C选项中交换语句有两句不受if条件控制，无论a是否大于b都会执行，和其他三个功能不一致。
* **第4题讲解**：题目考察条件运算符，初始a=3，b=2，计算后最终k的值为2，正确答案为C选项。
* **第5题讲解**：题目if条件为`a=6`，这是赋值语句，赋值后a=6为非零值，条件成立，因此会输出a的值6，正确答案为B选项。

**奇偶判断编程题讲解**
* **输入格式要求**：需要用scanf输入整型x，输入变量前必须加地址符&。
* **判断逻辑**：偶数能被2整除，因此x模除2结果等于0，当结果为0时，条件为真，输出1；否则条件为假，输出0。输入12会输出1，输入13会输出0。

**大小写字母转换编程题讲解**
* **字符输入方式**：可以使用两种方法输入字符，分别是getchar()函数和scanf格式化输入函数。
* **判断与转换逻辑**：判断大写字母的表达式为`c>='A' && c<='Z'`，大写转小写需要将ASCII码加32；判断小写字母的表达式为`c>='a' && c<='z'`，小写转大写需要将ASCII码减32，最后输出转换后的字符即可。

**易混淆考点辨析**
* **赋值符号与相等运算符区分**：题目中条件为`x=4`，是赋值语句，赋值后x=4为非零值，因此条件成立，输出“真”，不要误把赋值符号当成相等运算符判断为条件不成立。
* **条件表达式等价判断**：题目要求将“能被3整除时值为1，否则为0”，不等价的选项是D选项，D选项将“有余数（不能被整除）”设为1，和要求相反。

**进阶if语句选择题讲解**
* **第3题（M/N/T题）讲解**：初始M=-1，N=1，T=-1，条件成立后T变为1，else外的`m=t`一定会执行，因此最终M的值为1。
* **第4题（a/b/c输出题）讲解**：初始a=2，b=3，c=1，a不大于b，因此不会执行第一个if内的分支，最后一定会输出c的值1，输出结果为1，正确答案为B选项。
* **第5题（交换变量题）讲解**：初始a=1，b=2，a<b条件成立，执行交换语句，交换后a=2，b=1，最终输出结果为2 1 2，正确答案为C选项。
* **第6题（自增自减题）讲解**：输入x初始值为6，x++不满足x>6，执行后x变为5，执行--x前置自减，x变为4，最终输出结果为4，正确答案为B选项。
* **第7题（空语句陷阱题）讲解**：第一个if后多写了分号，相当于一个空语句，后续if else和第一个if无关，z=1条件成立，执行a=3，最终a值为3，正确答案为D选项。

**典型编程题目思路梳理**
* **判断字符类型编程题**：判断是否为字母的表达式为`(c>='A'&&c<='Z') || (c>='a'&&c<='z')`；判断是否为数字字符的表达式为`c>='0' && c<='9'`，两种都不满足则输出“其他字符”，属于典型的多分支应用题。
* **水仙花数判断编程题**：水仙花数定义为三位数的个位、十位、百位的立方和等于该数本身，也叫阿姆斯特朗数；解题步骤为先输入三位数x，再分别取出个位（x模除10）、十位（x除以10后再模除10）、百位（x除以100），计算三个数位的立方和，若和等于x则输出该数是水仙花数。
* **闰年判断编程题**：该题将放在下节课进行讲解。
