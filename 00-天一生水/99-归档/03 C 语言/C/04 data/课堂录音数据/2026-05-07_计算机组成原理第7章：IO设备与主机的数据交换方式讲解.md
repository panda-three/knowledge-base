# 计算机组成原理第7章：IO设备与主机的数据交换方式讲解

#### 录音总结
本次课程讲解了计算机第7章输入输出系统中主机与外设的5种数据传送方式，分别介绍了各类方式的定义、特点、适用场景，并结合典型例题讲解考点，帮助学习者理解掌握相关内容。

**课程考纲要求梳理**
* **核心考点要求**：考纲要求包含三个部分，第一需理解IO设备与主机的信息交换方式，第二需要掌握中断的概念及中断响应过程，第三需要了解DMA方式。
* **章节特点说明**：输入输出系统是计算机系统中最复杂的部分，该章节概念多、专业术语多，理解难度较大，要求学习者重点理解几种交换方式及工作过程。

**主机与外设数据传送方式分类**
* **五种交换方式列表**：一共包含5种数据传送方式，分别为程序查询方式、程序中断方式、DMA直接存储器存取方式、通道方式、外围处理机PPU方式。
* **实现方式划分**：程序查询方式和程序中断方式主要由软件程序实现，DMA方式、通道方式、PPU方式主要由硬件实现。
* **适用设备与机型划分**：程序查询和程序中断方式适用于低传输速率的外设，多用于小型、微型计算机；DMA、通道、PPU方式适用于高传输速率的外设，通道和PPU方式多用于中大型计算机。

**程序查询方式讲解**
* **基本定义与特点**：程序查询方式也叫程序控制方式，完全由计算机程序控制，以软件实现为主，CPU主动查询外设状态，若外设未就绪，CPU只能等待，CPU与外设串行工作，CPU利用率低。
* **分类与特点**：分为无条件查询和条件查询两类；无条件查询不需要查询外设状态直接传送，实现简单但可靠性低；条件查询需要不断查询外设端口状态，准备就绪后才传送，可靠性高但CPU持续等待浪费资源。
* **相关考点例题**：CPU资源消耗最大的数据传输方式是程序查询方式，答案为对应选项A；随时对接口进行查询，未准备好就等待的传送方式就是程序查询方式。

**程序中断方式讲解**
* **基本定义与特点**：CPU启动外设后继续执行自身程序，由外设主动向CPU发送中断请求，CPU接到请求后暂停当前程序，完成数据传送后再回到原程序继续执行。这种方式为CPU与外设并行工作创造了条件，大幅提高了CPU利用率。
* **相关考点说明**：程序中断方式由外设主动发送数据请求，和程序查询方式中CPU主动发起请求形成区别；程序查询和程序中断方式都属于由程序实现的传送方式。
* **举例说明特点**：用幼儿园阿姨发饼干举例，每人发一块饼干，约定吃完举手再要，阿姨没收到报告时可以改作业，对应程序中断方式并行工作的特点。

**DMA直接存储器存取方式讲解**
* **基本定义与特点**：DMA方式是在外设和内存之间直接开辟数据传送通道，由DMA控制器控制数据交换，不需要CPU介入，形成以存储器为中心的体系结构，传送单位为数据块，适用于高速成组数据传送。
* **工作过程**：分为初始化阶段、数据传送阶段、结束阶段三个阶段；DMA控制器从CPU接管总线控制权完成传送，传送结束后将总线控制权交还给CPU。
* **相关考点例题**：主机和高速硬盘、光盘等高速IO设备进行数据传送，一般采用DMA方式；DMA用于实现内存与外设之间的信息交换，形成以存储器为中心的体系结构，直接存储器存取的缩写为DMA。

**通道方式讲解**
* **基本定义与特点**：通道方式是独立于CPU的专用IO部件，被多台外设共享，拥有独立的通道指令和通道程序，CPU将数据传输功能下放给通道，CPU和通道分时使用内存。该方式采用存储总线、IO总线两类总线结构，分为CPU对通道管理、通道对设备管理两级管理。
* **通道的三种类型**：第一类选择通道，可连接多台快速设备，每次只能选择一台工作，设备间串行工作，传输单位为数据块；第二类字节多路通道，可连接多台慢速设备，如键盘、打印机，以字节交叉方式传送数据；第三位数组多路通道，可连接多台快速设备，允许设备并行工作，以成组交叉方式传送数据，常用于管理磁带、磁盘等外存。
* **DMA与通道的区别**：两者都支持主存与外设直接交换数据，DMA完全依靠硬件实现，通道方式需要通过执行通道程序完成IO操作。

**外围处理机PPU方式讲解**
* **基本定位**：外围处理机PPU方式是通道方式的进一步发展，外围处理机基本独立于主机工作，结构接近通用处理机，部分甚至就是通用的微小型计算机。
* **特点说明**：相当于额外增加了一个专门处理IO的处理器，相比通道方式处理IO的速度更快。

**典型例题综合讲解**
* **综合习题解析**：5种IO交换方式中，工作效率最低的是程序查询方式，答案为对应选项B；主要由程序实现的传送方式包含程序查询方式和程序中断方式；用于实现内存与外设之间直接交换数据的是DMA方式，该题三个问题答案均为B。
* **学习要求说明**：要求学习者重点结合举例理解5种交换方式的核心特点，掌握对应考点。

本次课程讲解计算机输入输出系统第7章内容，核心讲解主机与外设的数据传送方式。考纲提出三点要求：理解IO设备的信息交换方式，掌握中断的概念及中断响应过程，了解DMA方式。该章节概念多、专业术语多，理解难度较大，要求学习者重点掌握几种交换方式的工作过程。

[00:01:38](https://getnotes.seek:98) **传送方式分类与基础判断题解析**

一共列出5种主机与外设的数据交换方式，分别为程序查询方式、程序中断方式、DMA直接存储器存取方式、通道方式、外围处理机PPU方式。针对判断题解析：由程序实现的交换方式是程序查询和程序中断两种，后三种由硬件实现；Cache是CPU内部的高速缓存，不属于CPU和外设的数据交换方式，对应题目选C。

[00:03:11](https://getnotes.seek:191) **程序查询方式详细讲解**

程序查询方式也叫程序控制方式，完全由程序控制，以软件实现为主。它的特点是CPU主动查询外设状态，外设未就绪时CPU只能等待，CPU和外设串行工作，CPU利用率低。用幼儿园阿姨给孩子分饼干举例，阿姨给一个孩子发饼干后需要盯着孩子吃完一块再发下一块，全程等待不能做其他工作，对应程序查询的特点。

[00:07:30](https://getnotes.seek:450) **程序查询方式分类与考点例题解析**

程序查询方式分为无条件查询和条件查询两类。无条件查询不需要查询外设状态，直接进行数据传送，实现简单但可靠性低；条件查询需要持续查询外设状态，外设准备就绪后才传送，可靠性高但CPU会持续等待浪费资源。针对考点例题解析：CPU资源消耗最大的传送方式是程序查询方式，对应选项A；不需要CPU介入的传送方式是DMA方式；不断查询等待就绪才传送的方式就是程序查询方式。

[00:10:16](https://getnotes.seek:616) **程序中断方式基本概念讲解**

程序中断方式的定义为：CPU启动外设后继续执行自身程序，外设准备就绪后主动向CPU发送中断请求，CPU暂停当前程序完成数据传送，处理完成后回到原程序继续执行。程序查询方式中CPU是主动方，程序中断方式中外设是主动方，这种方式为CPU和外设并行工作创造条件，大幅提高了CPU利用率。用敲门写作业、阿姨分饼干两个例子进行说明：写作业时听到敲门声暂停开门，开完成继续写；阿姨每人发一块，吃完举手再发，阿姨没收到报告时可以改作业，都对应程序中断的并行特点。

[00:15:02](https://getnotes.seek:902) **程序中断方式考点解析与DMA引入**

针对考点例题解析：由程序实现的交换方式包含程序中断方式，DMA、通道、PPU方式为硬件实现；程序中断方式进行数据传送时，由外设主动发送数据请求，和程序查询方式形成区别。引入DMA方式，DMA方式在外设和内存之间建立直接数据通道，由DMA控制器控制交换，适合高速成组数据传送。

[00:16:08](https://getnotes.seek:968) **DMA方式特点与考点例题讲解**

用阿姨分饼干举例，DMA方式对应每人直接拿4块饼干，吃完再一起报告，大幅提升阿姨的工作效率，对应DMA批量传送的特点。针对考点例题解析：主机和高速硬盘、光盘等高速外设交换数据，采用DMA方式，对应选项选择DMA方式；DMA方式是内存和外设直接交换数据，不需要CPU介入，形成以存储器为中心的体系结构，DMA是直接存储器存取的缩写，不要和CPU厂商AMD混淆。DMA传送单位是数据块，工作过程分为初始化、数据传送、结束三个阶段。

[00:17:27](https://getnotes.seek:1047) **通道方式概念与特点讲解**

通道方式是计算机系统中独立的IO部件，可以被多台外设共享，拥有独立的通道指令，通过执行通道程序完成IO操作，需要CPU启动和管理。用阿姨分饼干举例，对应阿姨把发饼干的工作下放给班干部，班干部完成后再向阿姨报告，对应CPU下放IO权限给通道的特点。通道也叫输入输出处理器，英文简称IOP；通道方式采用两类总线结构：CPU、通道、主存之间用存储总线，通道和外设之间用IO总线；分为CPU对通道管理、通道对设备管理两级管理；CPU和通道分时使用内存。

[00:32:36](https://getnotes.seek:1956) **通道类型分类与考点例题解析**

通道分为三种类型：第一选择通道，可连接多台快速设备，每次只能选一台工作，设备间串行工作，传输单位是数据块；第二字节多路通道，连接管理多台慢速设备，比如键盘、打印机，以字节交叉方式传送数据；第三数组多路通道，连接多台快速设备，允许设备并行工作，以成组交叉方式传送，常用于管理磁带、磁盘等外存。针对考点例题解析：可连接多台快速设备且允许并行工作的通道类型是数组多路通道；选择通道的数据传送单位是数据块；键盘作为慢速设备，采用字节多路通道。DMA和通道都支持主存外设直接交换，区别是DMA纯硬件实现，通道需要执行通道程序。

[00:19:09](https://getnotes.seek:1149) **外围处理机PPU方式讲解**

外围处理机PPU方式是通道方式的进一步发展，外围处理机基本独立于主机工作，结构接近通用处理机，部分就是通用的微小型计算机，相当于额外增加一个专门处理IO的处理器，处理IO的速度比通道方式更快。

[00:38:13](https://getnotes.seek:2293) **综合例题讲解与课程收尾**

本次课程最后讲解三道综合例题，答案均为B：5种交换方式中工作效率最低的是程序查询方式；主要由程序实现的交换方式包含程序中断方式；实现内存与外设之间交换数据的是DMA方式。最后要求学习者重点结合课程中的例子理解五种交换方式的核心特点，本次课程内容讲解结束。
