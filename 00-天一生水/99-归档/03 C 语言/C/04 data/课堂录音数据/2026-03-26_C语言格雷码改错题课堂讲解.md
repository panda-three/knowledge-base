# C语言格雷码改错题课堂讲解

#### 知识精讲
本次课程讲解一道n位格雷码生成的C语言改错题，先复习C语言字符串操作与二维数组基础知识，再逐一定位修正三处代码错误，明确改错题的解题思路与常见考点。

**格雷码生成规则讲解**
* **格雷码基础定义**：n位格雷码由n个0或1组成，共$2^n$个编码，例如n=4时共16个4位格雷码。
* **生成规则**：
  1. 第1个格雷码固定为n个0（示例n=4时为`0000`）
  2. 当序号i>1且i为偶数时，将第i-1个格雷码的**末位取反**，得到第i个格雷码
  3. 当序号i>1且i为奇数时，将第i-1个格雷码**从右往左查找**，找到第一个1后，将该1**左侧的一位取反**，得到第i个格雷码
  4. 重复上述步骤直到生成所有$2^n$个格雷码

**C语言字符串基础知识复习**
* **常用字符串操作函数**：
  - 获取字符串长度：`strlen()`
  - 字符串拼接：`strcat()`
  - 🚩重点：字符串复制`strcpy()`的参数顺序：`strcpy(目标字符串, 源字符串)`，即源字符串放第二个参数位置，目标放第一个，是考试高频易错点
* **二维字符串数组基础**：
  - 定义格式：`char 数组名[行数][列数];`，其中行数是字符串的个数，列数是单个字符串的最大长度（需预留`\0`结束符位置）
  - 🚩重点：二维数组取值规则：取整个字符串只需要写行下标；取单个字符才需要同时写行下标+列下标。例如定义`char c[2][4] = {"abc", "df"};`，取第一个字符串写`c[0]`，取第一个字符串的第二个字符写`c[0][1]`。

**改错题错误定位与修正**
本题共3个错误，每个错误10分，总分30分，以下是修正结果：
1. **strcpy参数顺序错误**：
   - 原代码：将当前格雷码复制给前一个格雷码，参数顺序颠倒
   - 🚩考点：考察`strcpy`参数顺序，修正方法：调换两个参数位置，将源字符串（i-1位置的格雷码）放到第二个参数，目标字符串（i位置的格雷码）放到第一个参数
2. **奇数规则查找循环条件错误**：
   - 原逻辑：从右往左找第一个1的循环条件使用逻辑或，且判断的是整数0
   - 🚩考点：循环条件逻辑与字符类型判断，分两步修正：
     1. 将逻辑或`||`改为逻辑与`&&`，因为需要同时满足循环条件才能继续查找
     2. 将判断整数0`0`改为判断字符`'0'`，因为存储的是字符类型的0/1，不是整数
     最终循环条件修改为：`i >= 0 && gray[i-1][i] == '0'`，表示：当前位置是字符0时才继续向左查找，找到第一个1就停止循环
3. **输出语句下标错误**：
   - 原代码：输出时直接使用`gray[j]`，无法正确遍历所有16个格雷码
   - 🚩考点：二维数组下标计算，修正方法：正确计算一维偏移下标：`j * 4 + i`，其中j是当前格雷码的行号，每个格雷码占4个字符位置，i是当前字符的列号，即输出语句改为：`printf("%s\n", gray[j*4 + i]);`（或对二维数组写法输出为`printf("%s\n", gray[j]);`）

#### 💡 核心概念
- **格雷码生成规则**：
  1. 首码：全0
  2. 偶数i：前一个末位取反得到当前码
  3. 奇数i：前一个从右找第一个1，左一位取反得到当前码
- **`strcpy`函数**：`strcpy(char *dest, const char *src)`，将src复制到dest，参数顺序不可颠倒
- **二维字符串数组取值**：
  - 取完整字符串：`arr[行号]`
  - 取单个字符：`arr[行号][列号]`
