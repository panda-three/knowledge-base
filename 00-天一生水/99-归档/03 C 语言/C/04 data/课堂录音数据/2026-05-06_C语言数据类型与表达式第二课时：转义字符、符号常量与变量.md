# C语言数据类型与表达式第二课时：转义字符、符号常量与变量

#### 录音总结
本次是C语言数据类型与表达式第二课时的课程讲解，介绍了转义字符、符号常量的规则，详细讲解了变量的定义、分类、初始化与使用方法，最后通过习题巩固知识点。

**转义字符基础规则**
* **常见转义字符定义**：`\n`代表换行，移到下一行行首；`\r`代表回车，移到本行行首；`\t`是水平制表符，移到下一个tab位置；`\0`是空字符，ASCII码值为0，作为字符串结束标识。
* **特殊转义字符规则**：`\'`代表输出一个单引号，`\"`代表输出一个双引号，`\?`代表输出一个问号，`\\`代表输出一个反斜杠，`\b`代表退格，输出位置后退一个字符。
* **数字转义字符规则**：反斜杠加数字代表八进制，转换为十进制后得到对应ASCII码字符；`\x`加数字代表十六进制，转换后得到对应ASCII码字符。

**字符串常量存储规则**
* **存储长度要求**：双引号包裹的单个字符`"A"`，存储长度为2，包含小写字母A和结束标识`\0`。
* **长度与大小的区别**：字符串长度是指包含字符的个数，不包含结束标识`\0`；字符串存储大小需要包含`\0`的1个字节。
* **特殊字符使用要求**：字符串常量中不能直接包含双引号和反斜杠，必须添加转义反斜杠后才能正常使用。

**符号常量规则与用法**
* **符号常量的优势**：含义清晰，见名知意，修改方便，仅需修改头部的宏定义，即可实现全程序值的修改。
* **宏定义的格式要求**：使用`#define`定义符号常量，宏定义不是C语言语句，行末不需要加分号，加分号会被编译器识别为符号串的一部分。
* **符号常量的约束**：习惯上符号常量标识符使用大写字母，符号常量的值在作用域内不能修改，也不能再次赋值。

**变量的基础定义与属性**
* **变量的核心定义**：变量是程序运行中值可以发生变化的量，每个变量都有对应的标识符作为变量名，属于确定的数据类型，在内存中占据对应的存储单元。
* **变量的四个属性**：变量包含内存地址、变量名、变量值、数据类型四个属性，数据类型决定了变量的存储大小和取值范围。
* **变量使用要求**：C语言要求变量必须先定义后使用，定义格式为「数据类型 + 变量名表」，多个变量用逗号分隔，行末用分号表示定义结束。

**整形变量分类与取值范围**
* **整形变量分类**：整形变量可以分为基本整形、长整形、短整形，都可以添加修饰符指定为有符号或无符号类型；默认所有整形都是有符号类型，有符号关键字可以省略。
* **DEV C++环境字节规则**：DEV C++中，基本整形、无符号整形、长整形、无符号长整形都占4个字节，短整形占2个字节。
* **不同类型取值范围**：4字节有符号整形取值范围为-2³¹到2³¹-1，4字节无符号整形取值范围为0到2³²-1；2字节短整形有符号取值范围约为-32768到32767，无符号约为0到65535。

**变量初始化规则**
* **合法初始化格式**：C语言允许定义变量的同时进行初始化，例如`int a=3`是合法格式，定义多个变量时可以仅给部分变量初始化，例如`int a,b,c=5`是合法格式。
* **错误初始化格式**：`int a,b,c=3`仅会将3赋值给c，a和b未完成定义，因此该语句是错误格式，不能一次性给多个变量批量赋值。
* **使用方式选择**：可以先定义变量，后续再给变量赋值，也可以定义的同时直接完成初始化，两种方式都符合C语言规则。

**实型变量分类与规则**
* **实型变量分类**：实型也称为浮点型，分为单精度（float）、双精度（double）、长双精度三类；DEV C++中，float占4个字节，double和长双精度占8个字节。
* **精度规则**：float类型有7位有效数字，无法存储过长的小数位，超出部分会被舍去；double类型有效位约为10位，可存储更多小数位。
* **输出格式符**：输出浮点数时，单精度和双精度使用格式符`f`，长双精度使用格式符`lf`。

**字符型变量规则与用法**
* **字符型变量基础**：字符型变量用来存放单个字符常量，一个字符变量只能存放一个字符，占1个字节；要存储多个字符需要使用数组中的字符串类型。
* **存储规则**：字符数据在C语言中以ASCII码形式存储，存储形式和整数类似，因此C语言规定字符数据和整形数据可以通用。
* **大小写转换方法**：小写字母的ASCII码比对应大写字母大32，因此小写字母减去32即可得到对应的大写字母，例如小写a的ASCII码为97，减去32得到65，对应大写A。

**用户标识符命名规则**
* **命名规则**：用户标识符必须由字母或下划线开头，只能包含字母、数字、下划线三种字符；C语言的关键字不能用作用户标识符。
* **常见错误示例**：`int`是C语言关键字，不能作为变量名；`while`是循环控制关键字，也不能作为合法变量名。

**课程习题讲解**
* **转义字符相关习题**：不正确的转义字符包括只有反斜杠、没有后续字符的形式，以及没有反斜杠的形式，这类转义字符不符合C语言规则。
* **ASCII码相关习题**：小写字母a的ASCII码为97，大写字母A的ASCII码为65，字符0的ASCII码为48，转义字符`\0`的ASCII码为0，这些数值需要记忆。
* **存储相关习题**：字符常量'A'占1个字节，字符串常量"A"因为隐含结束符`\0`，因此占2个字节。

[00:00:52](https://getnotes.seek:52) **转义字符规则讲解**

依次讲解C语言中各类转义字符的含义：
- `\n`代表换行，将输出位置移到下一行行首；`\r`代表回车，将输出位置移到本行行首；`\t`水平制表符，将输出位置移到下一个tab位置

- 反斜杠加数字代表八进制数，对应对应ASCII码字符；`\x`加数字代表十六进制数，对应对应ASCII码字符。

[00:02:01](https://getnotes.seek:121) **字符串常量存储规则讲解**

字符串常量`"A"`的存储长度是2，包含小写字母a和隐藏的结束标识`\0`。`\0`的ASCII码值为0，和字符'0'不同，字符'0'的ASCII码值为48。字符串常量中不能直接包含双引号和反斜杠，若要使用必须添加转义反斜杠。明确了字符串长度和存储大小的区别：字符串长度不包含结束标识`\0`，存储大小需要包含`\0`。

[00:03:49](https://getnotes.seek:229) **转义字符示例程序讲解**

结合示例对转义字符的输出效果做了演示，输出语句`printf`中，`\'`会输出一个单引号，`\\`会输出一个斜杠，普通字符A、B直接输出，`\"`会输出一个双引号。强调转义字符整体只代表一个字符，要求牢记不同转义字符的含义，不能遗忘规则。

[00:06:00](https://getnotes.seek:360) **符号常量规则讲解**

讲解符号常量的优势：含义清晰，见名知意，可以实现一改全改，例如定义符号`PI`代表圆周率3.1415926，修改时仅需要修改头部的宏定义即可。符号常量的定义方式为`#define 符号名 常量值`，习惯上符号常量使用大写字母命名。强调宏定义不是C语言语句，行末不需要加分号，加分号会被编译器识别为符号串的一部分。符号常量的值在作用域内不能修改，也不能再次赋值。

[00:09:11](https://getnotes.seek:551) **变量基础概念讲解**

对比不可变的转义字符和符号常量，说明变量是程序运行过程中值可以发生变化的量。每个变量有标识符作为变量名，属于确定的数据类型，在内存中开辟对应的存储单元存放变量值。变量有四个属性：内存地址、变量名、变量值、数据类型，用学校举例类比说明四个属性的意义：地址对应学校位置，名称对应校名，值对应学校的师生，类型对应学校的办学类型。

[00:11:04](https://getnotes.seek:664) **变量定义格式讲解**

强调C语言中变量必须先定义后使用，定义变量的一般形式是「数据类型 + 变量名表」，多个变量之间用逗号分隔，行末用分号表示定义结束。举例说明：`int i,j,number`定义了三个整形变量i、j、number；`float a,b,song`定义了三个实型变量a、b、song；`char c1,c2`定义了两个字符型变量c1、c2，多个变量统一用逗号分隔符合规则。

[00:12:35](https://getnotes.seek:755) **整形变量分类讲解**

整形是C语言最常用的变量类型，基本类型符为`int`，可以根据数值范围分为基本整形、长整形、短整形，可添加修饰符`short`和`long`。整形可以分为有符号和无符号两种，高考考察较少，但需要理解规则：默认所有整形都是有符号整形，有符号关键字可以省略。不同类型占不同字节，有不同的取值范围，DEV C++中基本整形、长整形都占4个字节，短整形占2个字节。有符号4字节整形取值范围是-2³¹到2³¹-1，无符号4字节整形取值范围是0到2³²-1，短整形占2字节，取值范围更小，计算大数字（如阶乘）时不能使用短整形。

[00:16:32](https://getnotes.seek:992) **整形变量赋值与输出讲解**

再次强调变量必须先定义后使用，这是C语言考试填空和改错题型的高频考点。举例说明整形变量的赋值方法：定义整形变量a、b，长整形变量c，无符号整形变量e后，可分别赋值a=-1、b=-523、c=620000多、e=89，输出时长整形需要使用对应格式符`%ld`。

[00:18:42](https://getnotes.seek:1122) **变量初始化规则讲解**

讲解变量初始化的概念：定义变量时预先设置初值称为初始化，C语言允许定义变量的同时完成初始化。举例说明：`int a=3`等价于先定义a再赋值3，`int a,b,c=5`仅给c初始化为5，a、b仅完成定义，是合法格式；`int a=3,b=3,c=3`可以分别给三个变量赋值，是合法格式；`int a,b,c=3`是错误格式，该写法仅定义了a，将3赋值给c，系统无法识别未定义的b，不能通过编译。

[00:20:21](https://getnotes.seek:1221) **实型变量规则讲解**

实型用于存储小数，分为单精度（float）、双精度（double）、长双精度三类，C语言没有统一规定不同实型的长度、精度和取值范围，DEV C++中float占4个字节，double和长双精度占8个字节。举例说明实型变量的定义和初始化：`float x,y`定义两个单精度实型变量，`float m=12.8`定义变量m并初始化为12.8，`double min`定义双精度实型变量min。float有7位有效数字，存储超过7位的小数时，超出部分会被舍去，double有效位约为10位，可存储更多有效数字。输出浮点数，单精度和双精度使用格式符`f`，长双精度使用`lf`。

[00:23:33](https://getnotes.seek:1413) **字符型变量基础规则讲解**

字符型变量用于存放字符常量，一个字符变量只能存放一个字符，占1个字节；需要存放多个字符时要使用字符串，字符串知识点会放在数组章节讲解。举例说明字符变量的定义和赋值：`char c1,c2`定义两个字符型变量c1、c2，每个占一个字节，可分别赋值为小写a和小写b，也可以定义时直接初始化。

[00:25:37](https://getnotes.seek:1537) **字符型变量与整形通用规则讲解**

字符数据在内存中以ASCII码形式存储，存储形式和整数一致，因此C语言规定字符数据和整形数据可以通用。举例说明大小写转换：小写a的ASCII码是97，减去32得到65，对应大写字母A，小写b减去32得到大写B，这是将小写字母转换为大写字母的经典方法。输出时，使用%c输出对应的字符，使用%d输出对应的ASCII码，该程序可以同时输出转换后的字符和对应的ASCII码。输出字符的指定格式符为`%c`。可以直接给字符型变量赋值ASCII码对应的整数，赋值97等价于赋值小写a，赋值98等价于赋值小写b，符合C语言规则。

[00:30:28](https://getnotes.seek:1828) **用户标识符与关键字习题讲解**

讲解用户标识符的命名规则：必须由字母或下划线开头，只能包含字母、数字、下划线，关键字不能作为用户标识符。指出`int`是C语言关键字，不能作为用户标识符。C语言的关键字是预先声明的具有特定意义的单词，`continue`、`float`、`return`、`for`都是C语言关键字，`while`也是循环控制关键字，不能作为合法变量名。

[00:33:19](https://getnotes.seek:1999) **常量与转义字符相关习题讲解**
- 整形常量有十进制、八进制、十六进制三种表达方式：八进制以0开头，十六进制以0x开头，以0开头的八进制中只能出现0-7的数字，出现9即为不合法。
- 字符常量必须用单引号包裹单个字符，用单引号包裹两个字符不属于合法字符常量。
- 考察ASCII码数值：小写a的ASCII码为97，大写A为65，多个选项不满足97，正确选项为多个不符合的选项。
- 变量必须属于确定的数据类型，整形变量可以分为基本整形、长整形、短整形。
- 不符合规则的转义字符：只有反斜杠没有后续字符、以及没有反斜杠的形式都不是正确的转义字符。
- 不合法常量的判断：单引号只能包裹一个字符，超出即为不合法。

[00:40:52](https://getnotes.seek:2452) **填空习题讲解与课程收尾**

讲解填空习题的核心考点：
- 需要记忆常用ASCII码值：小写a为97，字符0为48，`\0`为0，`\x42`转换为十进制是66，对应大写字母B。
- 存储大小区分：字符常量'A'占1个字节，字符串常量"A"因为包含隐藏结束符`\0`，占2个字节。
- 变量分为整形、实型、字符型三类，字符型占1个字节，字符型数据可以和整形通用，因为都以二进制形式存储。
