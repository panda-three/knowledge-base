**递推法基础**
* **定义**：递推法是通过已知的前若干项，推导出后续所有项的算法，核心是找到递推关系，即下一步由哪些已有量推导得到。
* **典型例子：斐波那契数列**：
  从第三项开始，每一项等于前两项之和，递推公式为：
  $$F(n)=\begin{cases}
  1 & n=1, n=2 \\
  F(n-1)+F(n-2) & n \geq 3
  \end{cases}$$
  递推过程需要通过变量移动更新前项的值，逐步计算后续项。
   - 🚩重点：递推法的核心难点是**变量更新保存**，计算新项前需要保留原变量的值，避免更新后原值丢失，导致推导错误。

* **分数序列求和例题**：对分数序列 $\frac{1}{2},\frac{2}{3},\frac{3}{5},\frac{5}{8}...$ 求和：
  推导得到递推规律：
  - 后一项分子 = 前一项分母
  - 后一项分母 = 前一项分子 + 前一项分母
  代码实现逻辑：
  1. 定义初始项`分子=1`，`分母=2`，和`sum = 1.0/2`
  2. 用临时变量保存原分子的值
  3. 将原分母赋值给新分子
  4. 新分母 = 保存的原分子 + 原分母
  5. 重复步骤2-4，计算所有项并累加求和
   - 🚩重点：必须使用`double`类型存储分子、分母和和值，如果使用`int`类型，整数除法会得到0，结果错误。
   - *代码核心逻辑片段*：
```c
double molecule = 1, denominator = 2;
double sum = molecule / denominator;
double temp;
for(int i = 2; i <= n; i++){
    temp = molecule;         // 保存原分子，避免覆盖后丢失
    molecule = denominator; // 新分子 = 原分母
    denominator = temp + denominator; // 新分母 = 原分子+原分母
    sum += molecule / denominator;
}
```

* **逆推法（反向递推）例题**：赶鸭子问题：每经过一个村子卖出一半又一只，经过7个村子后剩2只，求每个村子进入前的鸭子数量：
  推导递推关系：设进入当前村子前鸭子数为`before`，出村子后剩余为`after`，根据题意可得方程：
  $$\frac{before}{2} - 1 = after$$
  整理得到递推公式：
  $$before = 2 \times (after + 1)$$
  从最后剩余的`after=2`开始，从后往前逆推，依次得到第6、5...1个村子进入前的鸭子数量。
   - 🚩重点：逆推和正推本质都是递推，仅推导方向不同，核心都需要变量更新，推完当前项后，将`before`赋值给`after`，用于推导更前一项。

**穷举法基础**
* **定义**：在给定的取值范围内，逐个列举所有可能的情况，逐一验证是否满足条件，得到所有符合要求的解。
* 🚩重点：穷举法常用循环嵌套实现，内层循环的情况依赖于外层循环的结果，因此需要嵌套书写，逻辑上内层基于外层前提。

* **换钞票例题**：将100元换成5元、1元、0.5元，三种钞票每种至少1张，总张数刚好100张，求所有换法：
  数学建模：设5元x张、1元y张、0.5元z张，得到方程组：
  $$
  \begin{cases}
  5x + y + 0.5z = 100 \\
  x + y + z = 100 \\
  x \geq 1, y \geq 1, z \geq 1
  \end{cases}
  $$
  为避免小数运算，等式两边同乘2整理得：
  $$10x + 2y + z = 200$$
  代码实现逻辑：
  1. 外层循环穷举5元张数：范围`1 ≤ x ≤ 19`（因为1元和0.5元至少各1张，所以5元最多19张）
  2. 内层循环穷举1元张数：范围`1 ≤ y ≤ 94`（5元和0.5元至少各1张，所以1元最多94张）
  3. 根据总张数计算得到`z = 100 - x - y`
  4. 验证条件：`z ≥ 1`且满足整理后的金额方程，符合条件即为有效换法
  - 🚩重点：考试中常考穷举法的循环嵌套逻辑，2025年真题中就有一道同类型题目。

#### 💡 核心概念
- **递推法**：通过已知的前若干项，按照递推关系推导出后续所有项的算法，核心是找到递推关系与正确更新变量。
- **穷举法**：在给定范围内逐个列举所有可能情况，逐一验证是否满足条件，得到所有有效解的算法，常用循环嵌套实现。
- **反向递推（逆推法）公式**：
  $$before = 2 \times (after + 1)$$
- **分数序列递推规律**：`新分子 = 旧分母`，`新分母 = 旧分子 + 旧分母`
