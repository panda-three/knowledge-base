#### 知识精讲
本节课讲解C语言循环嵌套的定义、执行规律，结合多个例题分析循环嵌套的执行过程，进一步讲解利用循环嵌套实现阶乘累加、素数判断等经典问题，强调变量初始化位置、数据类型选择等易错考点。

**循环嵌套基础**
* **循环嵌套定义**：一个循环语句的循环体中完整包含另一个完整的循环语句，即为循环嵌套。
* **循环嵌套执行规律**：外层循环每执行1次，内层循环完整执行1轮。
   - 🚩重点：计算内层语句总执行次数 = 外层循环执行次数 × 内层循环单轮执行次数，这是结果分析的核心方法。
* **基础例题分析**：若外层循环执行4次，内层循环每轮执行10次，内层循环的输出语句总共执行40次，最终输出4行，每行10个星号。

**循环嵌套结果分析例题**
* **数字输出例题**：外层循环`i`取值`1~5`，内层循环`j`取值`1~5`，每行输出`i: 1 2 3 4 5`，共输出5行。
* **累加计算例题**：初始`S=10`，`T=0`，外层`i`取值`1~3`，内层`j`取值`1~4`，内层每次执行`S = S+2; T = T+2;`：
   - 总执行次数：`3 × 4 = 12`次
   - 最终结果：`S = 10 + 2×12 = 34`，`T = 0 + 2×12 = 24`
* **乘积输出例题**：外层`i`取值`1~3`，内层`j`取值`1~2`，每次输出`i×j`，内层循环结束后换行，最终结果为：
```
1 2
2 4
3 6
```
* **九九乘法口诀表实现**：外层`i`取值`1~9`，内层`j`取值`1~i`，每次输出`j×i = i*j`加制表符分隔，内层结束后换行，即可得到标准的左下三角九九乘法表，核心逻辑和上述乘积输出例题一致。

**累加累乘经典题：求 $S = 1 + \frac{1}{1!} + \frac{1}{2!} + ... + \frac{1}{N!}$**
* **整体思路（两层循环写法）**：
  1. 外层循环遍历1到N的每一个数`i`
  2. 内层循环计算`i`的阶乘
  3. 将`1/i!`累加到总和`sum`中
* **阶乘变量初始化位置考点**：
   - 🚩重点：如果使用两层循环计算每个`i`的阶乘，阶乘变量`fact`必须初始化在**外层循环内部、内层循环外部**。若放在外层循环外，会保留之前计算的乘积，导致每个`i`的阶乘错误累乘之前所有数，结果完全错误。
* **优化写法（一层循环）**：利用递推思想，阶乘变量`fact`初始化放在外层循环外，每次只需要在前一轮`(i-1)!`的基础上乘以`i`，即可得到`i!`，和两层循环结果完全一致，是更高效的写法。
* **数据类型易错点**：
   - 阶乘变量使用`long`长整型：因为阶乘增长速度快，普通`int`类型范围有限，数值过大会溢出，`long`可以扩大表示范围。
   - 🚩重点：累加和`sum`必须用`double`类型，且第一项必须写`1.0`而不能写`1`：因为整数除法中，整数除以整数结果仍为整数，当`i≥2`时`1/i! < 1`，结果会始终为0，得到错误总和，`1.0`是浮点数，运算后会自动转为浮点型，得到正确小数结果。

**素数判断拓展**
* 判断单个数是否为素数，使用单循环遍历该数的所有可能因数即可；若要输出1~100以内所有素数，需要使用循环嵌套：外层循环遍历1~100的所有数，内层循环对每个数判断是否为素数。
   - 🚩重点：素数判断代码**经常考**，要求至少能够读懂逻辑，建议独立编写实现。

#### 💡 核心概念
- **循环嵌套**：一个循环语句的循环体中完整包含另一个循环语句的结构，执行规律为外层每执行1次，内层完整执行1轮。
- **阶乘倒数和公式**：$$ S = 1 + \sum_{i=1}^{N} \frac{1}{i!} $$
- **素数**：大于1的自然数中，除了1和自身外没有其他因数的数。
