想要取出来该怎么办？通过数组元素的引用。首先写上数组名字，后面加上中括号。中括号里面放的是当前这个元素的下标。下标是从零开始。例如，第一个元素对应的下标是零，第二个元素是一。

所以，假设数组名是 `i`，想要取第二个元素，只需写 `i[1]`。同理，`i[0]` 表示取第一个元素，`i[1]` 表示取第二个元素，一直到 `i[9]` 表示取最后一个（第十个）元素。对于长度为10的数组，下标范围是0到9。

- 想要输出 `i[2]` 的值怎么办？用 `printf("%d")`。
- 想要给 `i[2]` 重新输入一个值怎么办？用 `scanf`。

注意，数组是存放了多个相同类型变量的集合。例如，可以写 `i[0] = 10`。

这个 `i` 和数组里的 `i[0]`、`i[1]`、`i[2]`，它们本质上没有区别，都表示一个变量。只不过数组里面可以放多个变量。变量的输入输出是那个样子，所以对数组里的元素进行输入和输出也是那个样子。这一块大家之前经常搞混，注意：
- 要对第二个元素进行输入，就写 `a[2]`。
- 要对它进行输出，也写 `a[2]`。

接下来，判断数组是否对称，大家还记得怎么写吗？判断一维数组左右对应的元素是否相等，写法是这样的：
- 设定 `i = 0`，循环条件为 `i < 数组长度 / 2`。
- 比较 `arr[i]` 和 `arr[arr.length - 1 - i]`。

例如，数组 `[1, 2, 3, 2, 1]` 有五个元素，它是对称的。第一个元素和最后一个元素比，第二个元素和倒数第二个元素比，以此类推。这个规律是固定的，判断数组是否对称的方法不会变。

此外，之前还讲过另一种写法，叫做双下标法：
- 设定 `left = 0`，`right = 数组长度 n - 1`。
- 在循环中，比较 `arr[left]` 和 `arr[right]`。
- 比较后，执行 `left++`，`right--`。
