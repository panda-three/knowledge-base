**课程基本信息介绍**

* **课程目标**：掌握运算符的运算规则、优先级，以及表达式的组成和应用。

**运算符基础概念讲解**
* **定义与功能分类**：运算符是程序中对变量或常量进行处理的符号；C语言按功能分为算术运算符、关系运算符、逻辑运算符、逗号运算符、位运算、赋值运算符等。
* **操作数分类**：按操作对象个数，运算符分为单目、双目和三目三类。
* **优先级与结合性**：运算符有不同优先级，优先级相同时运算次序由结合性决定，结合性分为左结合和右结合两种。

**表达式基础概念讲解**
* **表达式定义与组成**：表达式是用运算符和括号把操作数连接起来形成的式子，操作数可以是常量、变量和函数。
* **表达式运算规则**：任何复杂表达式都能依据优先级、结合性、数据类型转换规则计算出唯一值，该值的类型就是表达式的类型。
* **表达式分类**：C语言表达式分为算术表达式、赋值表达式、关系表达式、逻辑条件表达式和逗号表达式，其中关系和逻辑表达式放在第四章选择结构讲解。

**算术运算符规则讲解**
* **算术运算符分类与优先级**：C语言共有7个算术运算符，分别是加、减、乘、除、求模、求负、求正；优先级从高到低为：求负求正 > 乘除求模 > 加减。
* **运算规则特殊说明**：加减乘除规则和数学规则一致，乘号写法有规范要求，除法如果两个操作数都是整数，结果舍去小数取整，有一个为实型则结果为实型，负数结果向零舍入。
* **求模运算规则**：求模也叫取余，要求两个操作数都必须是整数，除数不能为0；余数的符号始终和分子也就是被除数保持一致，不遵循负负得正。
* **运算优先级例题演示**：针对`A + B * C`、`(A + B) * C`、`10 / 3`、`-5 / 2`、`5 % 3`、`-5 % -3`、`-5 % 3`、`5 % -3`等多个表达式做了运算演示，验证规则的正确性。
* **课堂练习题运算演示**：演示了8道课堂练习题的运算过程，包括`8 / 5`结果为1、`7 % 2`结果为1、`x=-1，x + 3 / 2`结果为2等，所有结果都符合既定运算规则。

**自增自减运算符讲解**
* **基本定义与适用范围**：自增自减是单目运算，作用是让变量的值增1或减1，支持整形、字符型、指针变量；只能用于变量，不能用于常量或表达式。
* **前置与后置的区别**：运算符放在变量前为前置运算，先改变变量值再参与其他运算；放在变量后为后置运算，先用变量原有值参与运算，再改变变量值。
* **优先级与结合性**：自增自减属于单目运算，优先级高于普通算术运算，结合性为从右向左。
* **运算例题演示**：针对多个不同前置后置组合的例题做了运算演示，例如`X=9，Y=X++`，结果Y为9，X变为10；`X=9，Y=++X`，结果X和Y都为10。

**其他单目运算符讲解**
* **sizeof长度运算符**：sizeof是单目长度运算符，以字节为单位计算操作数占用的内存长度，结果为整数；操作数可以是类型名也可以是表达式，结果必然是整数，例如sizeof(int)结果为4。
* **优先级规则**：sizeof的优先级为二级，结合性为自右向左，和其他单目运算保持一致。

**赋值运算符讲解**
* **基本规则**：赋值运算符的作用是将右侧表达式的值赋值给左侧变量，左侧必须是变量，不能是常量或表达式；赋值运算符是双目运算，优先级较低，为十四级，结合性为自右向左。
* **类型不一致的自动转换**：如果赋值两侧类型不一致，自动将右侧类型转换为左侧变量的类型，例如将13.6赋值给整形变量Y，Y的值会直接舍去小数，结果为13，不做四舍五入。
* **复合赋值运算符**：在赋值运算符前加其他运算符可构成复合赋值运算符，共10种，常见的是5种算术复合赋值，符合运算等价于先做运算再赋值给自身；课程要求学生能读懂即可，不建议日常写代码时使用，容易出错且难以调试。
* **复合赋值例题演示**：演示了多道复合赋值表达式的运算过程，例如`a初始值为10，a -= a * a; a += a`，最终a的值为-180。

**逗号运算符讲解**
* **基本规则**：逗号运算符可以将多个表达式连接起来，运算顺序是从左到右依次计算每个表达式，最终整个逗号表达式的值为最后一个表达式的值，因此也叫顺序求解表达式，支持嵌套。
* **优先级说明**：逗号运算符的优先级低于赋值运算符，运算时先计算赋值，再计算逗号后的表达式，最终取后者的值作为整个表达式的值。
* **运算例题演示**：针对多个逗号表达式做了运算演示，例如`a=3*5, a*4`，结果a为15，整个表达式的值为60。

**条件运算符讲解**
* **基本规则**：条件运算符是C语言中唯一的三目运算符，格式为`表达式1 ? 表达式2 : 表达式3`；表达式1结果为真时整个表达式取表达式2的值，为假时取表达式3的值。
* **优先级与结合性**：条件运算符优先级高于赋值运算符和逗号运算符，结合性为自右向左；常见用法是给变量赋值两个数中的较大值，例如`max = a > b ? a : b`。

**类型转换规则讲解**
* **自动类型转换**：自动转换分两种场景，赋值转换中将右侧值转换为左侧变量的类型，舍去不符合的部分；混合运算时自动将所有操作数转换为当前精度最高的类型，例如字符型转整形，float转double。
* **强制类型转换**：可以通过语法将某个表达式强制转换为指定类型，强制转换只会得到一个指定类型的中间量，不会改变原变量的类型和原有值。
* **强制转换例题演示**：例如将13.456强制转换为整形，结果为13，原变量x仍然保留13.456的值；针对多道混合自动转换和强制转换的练习题做了运算演示，验证了规则的正确性。

表达式由运算符和括号连接操作数组成，操作数可以是常量、变量、函数。任何表达式都可以根据优先级、结合性、数据类型转换计算出唯一值，值的类型就是表达式的类型。C语言表达式分为算术表达式、赋值表达式等多个类别，其中关系表达式和逻辑表达式放到第四章选择结构中讲解。

[00:02:59](https://getnotes.seek:179) **算术运算符基础规则讲解**

C语言共提供7个算术运算符，分别是加、减、乘、除、求模、求负、求正。其中加减乘除都是双目运算，规则和数学运算基本一致，需要注意写法规范：除法符号为左斜杠，不要误写为右斜杠。求负求正是单目运算，优先级高于乘除求模，结合性为自右向左。算术运算符整体优先级为：求负求正>乘除求模>加减，加减乘除求模都是左结合。

[00:04:20](https://getnotes.seek:260) **除法与求模运算特殊规则说明**

除法运算的操作数可以是整数或实型，只要有一个操作数是实型，结果就是实型；如果两个都是整数，结果直接舍去小数部分取整，不做四舍五入，负数结果向零舍入。求模也就是取余运算，要求两侧操作数都必须是整数，除数不能为零，余数的符号始终和分子也就是被除数保持一致，不遵循负负得正的规律。运算优先级中括号高于所有算术运算符，可以通过括号改变运算顺序。

[00:18:49](https://getnotes.seek:1129) **自增自减运算符规则讲解**

自增自减是单目运算，作用是让整形、字符型、指针类型变量的值增1或减1。运算符可以放在变量前（前置）或变量后（后置），二者有区别：前置先将变量自增/自减，再用改变后的值参与运算；后置先用变量原有值参与运算，再将变量自增/自减。自增自减只能用于变量，不能用于常量或表达式；优先级高于普通算术运算，属于单目运算，结合性为自右向左，常用于循环语句中改变循环变量的值。

[00:22:45](https://getnotes.seek:1365) **自增自减运算例题演示**

结合多个典型例题演示了运算结果：初始`X=9`，`Y=X++`是后置运算，Y先拿到X的原有值9，X再自增为10，最终Y=9，X=10；`Y=++X`是前置运算，X先自增为10，再赋值给Y，最终X和Y都等于10；针对自减运算也做了对应演示，结果符合前置后置的规则。

[00:25:58](https://getnotes.seek:1558) **sizeof运算符讲解**

sizeof是单目长度运算符，功能是以字节为单位计算操作数占用的内存长度，结果必然是整数。操作数可以是类型名，也可以是表达式，如果是表达式可以不加括号，为了避免混淆，建议都加上括号。例如`sizeof(int)`的结果为4，计算`sizeof(3+4)`，`3+4`是整形，结果也是4。sizeof优先级为二级，结合性为自右向左。

[00:27:29](https://getnotes.seek:1649) **赋值运算符规则讲解**

赋值运算符不要误读为等于号，C语言中的等于号是双等号，单个等号是赋值运算，作用是将右侧表达式的值赋值给左侧变量，左侧必须是变量，不能是常量或表达式。赋值运算符是双目运算，优先级为十四级，相对较低，结合性为自右向左。如果赋值两侧类型不一致，会自动将右侧类型转换为左侧变量的类型，转换时直接舍去不符合的部分，不做四舍五入。举例：将字符`'a'`减去32赋值给整形x，x的结果为97-32=65；将13.6赋值给整形y，y直接舍去小数，结果为13。

[00:31:32](https://getnotes.seek:1892) **复合赋值运算符讲解**

复合赋值运算符是在赋值运算符前加上其他运算符构成，共有10种，高中阶段只需要掌握5种算术复合赋值，位运算相关不需要掌握。复合赋值等价于先对变量做对应运算，再将运算结果赋值回变量自身，例如`X += 3`等价于`X = X + 3`。课程要求学生只需要能看懂他人写的复合赋值即可，不建议自己写代码时使用，因为两个运算符放在一起容易出错，调试难度高。随后演示了多道复合赋值的例题，例如初始a=10，`a -= a*a; a += a`，运算过程为`a=10-100=-90，再a=-90 + (-90) = -180`，最终结果为-180。

[00:35:25](https://getnotes.seek:2125) **不同进制赋值例题演示**

针对十六进制、八进制的赋值例题做了运算演示：十六进制`0X10`转为十进制是16，八进制`023`转为十进制是19，因此`B = 0X10 + 023`，结果为16+19=35，转为十六进制为`0X23`。继续演示了多道不同类型的复合赋值例题，所有结果都符合运算规则，包括针对双精度和整形混合运算的例题，验证了类型自动转换规则。

[00:39:14](https://getnotes.seek:2354) **逗号运算符讲解**

逗号运算符可以将多个表达式连接成一个逗号表达式，运算规则是从左到右依次计算每个表达式，整个逗号表达式的结果为最后一个表达式的值，因此也叫顺序求解表达式，支持嵌套。逗号运算符的优先级低于赋值运算符，因此运算时先计算赋值，再计算逗号后的表达式。结合多个例题演示了运算规则，例如`a = 3 * 5, a * 4`，先将`3*5=15`赋值给a，再计算`a*4=60`，整个表达式的值为60，a的值仍为15。

[00:41:57](https://getnotes.seek:2517) **条件运算符讲解**

条件运算符是C语言唯一的三目运算符，格式为`表达式1 ? 表达式2 : 表达式3`，运算规则为：如果表达式1结果为真，整个表达式取表达式2的值，否则取表达式3的值。条件运算符优先级高于赋值运算符和逗号运算符，结合性为自右向左。典型用法是获取两个变量中的较大值，例如`max = a > b ? a : b`，就可以将a和b中较大的值赋值给max。

[00:43:31](https://getnotes.seek:2611) **类型转换规则讲解**

C语言中的类型转换分为自动转换和强制转换两类。自动转换包括两种场景：赋值转换会将右侧值自动转换为左侧变量的类型，舍去不符合的小数部分；混合运算时，所有操作数会自动转换为当前精度最高的类型，例如字符型转整形，float转double，保证运算精度。强制转换可以手动将表达式转为指定类型，强制转换只会生成一个指定类型的中间量，不会改变原变量的类型和原有值。举例：将double类型的13.456强制转换为int，结果为13，原变量x仍然保留13.456的值。

[00:45:44](https://getnotes.seek:2744) **类型转换例题演示与课程收尾**

演示了多道包含自动转换和强制转换的练习题，验证了转换规则的正确性，例如z为整形，表达式结果为3.2，赋值给z后z的值为3，舍去小数部分。最后做课程总结：本节课讲解了C语言各类运算符的使用规则，以及自动类型转换和强制类型转换的规则，课程结束。
