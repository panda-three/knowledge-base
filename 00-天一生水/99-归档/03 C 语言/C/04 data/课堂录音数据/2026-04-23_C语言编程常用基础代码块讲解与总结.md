# C语言编程常用基础代码块讲解与总结

#### 知识精讲
本次课讲解编程题中常用的基础代码模板，梳理了字符串、排序、数位三类核心题型的解题思路，强调编程题本质是基础代码块的灵活组合。

**标志位（flag）思想**
* **核心作用**：通过标记变量记录程序状态，用于判断是否满足题目给定的条件，不是全新的知识点，是基础编程常用的辅助技巧。
* **常见场景**：判断字符串是否为混合数字字母的合法格式、验证是否满足升序/降序要求等合法性判断场景。

**统计长度与求最值模板**
* **统计长度实现思路**：初始化长度变量`len = 0`，遍历目标片段过程中执行`len++`即可得到总长度。
* **求最长/最大/最小值思路（**打擂法**）**：维护一个存储当前最值的变量，每次将当前值与最值变量比较，如果当前值更大/更小，就将当前值赋值给最值变量，完成更新；如果需要保存最值对应的位置信息，可以额外保存开始下标和结束下标。
   - 🚩重点：统计长度和求最值的思路一致，是很多复杂题目的基础组成部分，需要熟练记忆代码框架。

**统计个数模板**
* **核心逻辑**：初始化计数器`cnt = 0`，遍历过程中遇到符合条件的结果就执行`cnt++`，本质和统计长度的逻辑完全一致。
* **常见场景**：统计字符串中数字的个数、统计满足条件的元素数量等。

**冒泡排序框架**
* **框架逻辑（下标从零开始）**：外层循环`i`从`0`遍历到`n-2`（共`n-1`轮排序），内层循环`j`从`0`遍历到`n-1-i`，比较相邻两个元素，满足条件就交换。
* **框架调整（下标从一开始）**：内层循环终止条件调整为`n-i`即可。
   - 🚩重点：冒泡排序的框架几乎固定，**变化只在于比较的内容和交换的对象**：可以比较整数、整个字符串、字符串的指定片段；如果多个数组一一对应，交换时需要同时交换所有数组的对应元素，需要灵活运用。

**交换模板**
* **交换两个整数**：通过临时变量中转实现交换，属于编程基础操作。
* **交换两个字符串（C语言）**：需要使用`strcpy`函数完成内容交换，不能直接用赋值号。

**数位处理模板**
* **十进制数字拆位**：循环通过`n%10`取出当前最后一位，再通过`n = n / 10`去掉最后一位，重复直到`n`为0，即可逐位取出所有数位，取出的数位可以按需存储到数组中。
* **任意进制拆位**：将取余和除法的除数修改为目标进制即可，本质和十进制拆位完全一致，例如转十二进制就对12取余、除以12，转十六进制就对16取余、除以16。
* **提取固定位置数位**：利用除法和取余的特性灵活组合：
  - 除以100：去掉数字的最后两位，得到高位部分
  - 对10取余：取出数字最后1位
  - 对100取余：取出数字最后2位

**编程题型分类总结**
* **字符串类题目**：核心动作是**扫描、分段、判断、提取**，没有其他额外的复杂逻辑。
* **排序类题目**：核心动作是**两层循环、比较、交换**，框架固定，只需要调整比较和交换的内容。
* **数位类题目**：核心动作是**取余、除法，逐位拆分**，都是基础代码块的组合。
   - 🚩重点：目前所有编程题目都是上述基础代码块的组合，考察对基础模板的熟练运用和组合能力。

讲解统计长度的实现：初始化长度变量为0，在循环中执行长度自增即可完成统计。在统计长度的基础上，求最长/最大/最小值需要使用打擂法：将当前长度和已保存的最大长度比较，如果当前更大，就把当前长度更新给最大长度变量；如果需要保存最长片段的位置，额外保存开始下标和结束下标即可，整体逻辑和统计长度一致。该模块功能为统计片段长度、寻找最长目标片段，要求学生牢记框架。
[00:01:45](https://getnotes.seek:105) **代码块八：统计个数**
统计个数和统计长度逻辑一致：初始化计数器`cnt`为0，遇到符合条件的结果就让计数器自增。最常见的应用场景是统计字符串中数字的个数，所有编程题中都很常见这类写法。
[00:02:43](https://getnotes.seek:163) **代码块九：冒泡排序框架**
冒泡排序框架已经强调过多次：如果数组下标从零开始，外层循环`i`从0到`n-1`（循环`n-1`次），内层循环`j`从0到`n-1-i`；如果下标从一开始，内层循环终止条件调整为`n-i`即可。循环内一定是相邻的前一个元素和后一个元素比较，满足条件就交换。
🚩 这里的比较内容可以灵活变化：可以直接比较整数大小，也可以比较整个字符串，还可以只比较字符串的某一部分，比如之前做过的身份证号题目，只需要比较身份证号中的出生日期部分。如果题目中多个数组是一一对应的关系，交换的时候需要同时交换所有数组的对应元素。冒泡排序的框架几乎固定，变化只在"比较什么、交换什么"两个部分，需要学生根据题目灵活判断。

[00:04:59](https://getnotes.seek:299) **代码块十二：十进制数字拆位**
数字拆位就是逐位取出数字的每一位，基础框架固定，取出的数位可以根据题目需求存储，灵活调整即可。
[00:05:11](https://getnotes.seek:311) **代码块十三：任意进制拆位**
十进制拆位默认对10取余、除以10，如果要转换为其他进制，只需要把10换成目标进制即可，比如十二进制换为12，十六进制换为16，本质逻辑和十进制拆位完全一致。
[00:05:40](https://getnotes.seek:340) **代码块十四：提取固定位置的数位**
利用除法和取余的性质提取指定位数：除以100可以去掉数字的最后两位，对10取余可以取出最后一位，对100取余可以取出最后两位，灵活组合即可提取任意位置的数位信息。

#### 💡 核心概念
- **标志位（flag）**：用于记录程序状态，标记条件是否满足的变量，常用于合法性判断。
- **打擂法**：求最值的常用方法，不断用当前值更新最值变量得到最终结果。
- **冒泡排序（下标从零开始框架）**：
```c
for(int i = 0; i < n-1; i++){
    for(int j = 0; j < n-1-i; j++){
        if(arr[j] > arr[j+1]){ // 比较内容可替换
            // 交换arr[j]和arr[j+1]
        }
    }
}
```
- **十进制拆位框架**：
```c
while(n > 0){
    int digit = n % 10; // 取出当前最后一位
    // 存储digit
    n = n / 10; // 去掉最后一位
}
```
