**题目需求分析**
* **题目整体要求**：将输入字符串`S`中分隔的所有整数提取出来，存入一维数组，再将数组中每个十进制整数转换为九进制字符串，存入二维数组。
* **和上节课习题的对比**：上节课为提取空格分隔的单词，本题为提取`#`分隔的整数，核心分割思路一致，仅分隔符不同。
   - 🚩重点：本题新增两个难点——需要处理负号的整数、转换后得到的九进制需要倒序排列。

**第一步：提取字符串中的整数存入数组（第一个函数实现）**
* **核心思路**：遍历输入字符串，按`#`分割提取每个整数子串，将子串转换为整数存入数组，最终返回整数个数。
* **常见错误与解决方案**：使用while循环遍历很容易遗漏循环变量自增，推荐改用for循环避免错误。
   - 🚩重点：优先用for循环遍历字符串，先计算字符串长度`n = strlen(s)`，循环结构写为`for(i = 0; i < n; i++)`，自动完成变量自增，从根源避免遗漏自增的错误。
* **负数处理：标志位思想**
   - 🚩重点：处理负数使用**标志位法**，初始化符号标志`int sign = 1`（默认为正数），如果遇到负号，将`sign`修改为`-1`，最后转换完成后将结果乘以`sign`即可。
* **拼数转换逻辑**：将提取到的数字字符拼接为整数，核心是按权展开：
   - *核心公式*：初始`result = 0`，每次拼接：`result = result * 10 + (temp[j] - '0')`
   - 🚩重点：如果要拼接其他进制的数，只需要修改系数：拼八进制改为乘以`8`，拼十二进制改为乘以`12`，逻辑完全一致。
* **完整代码逻辑框架**：
```c
// 函数功能：将s中的#分隔整数提取到数组arr中，返回整数个数
int extractInt(char s[], int arr[]) {
    int cnt = 0; // 统计整数个数，要定义在循环外
    int n = strlen(s);
    for (i = 0; i < n; i++) {
        if (s[i] == '#') continue; // 遇到分隔符直接跳过，进入下一次循环
        int temp[100], k = 0; // temp临时存储当前整数的所有数字字符
        int sign = 1; // 符号标志位
        if (s[i] == '-') { // 判断负号
            sign = -1;
            i++;
        }
        // 提取当前整数的所有数字字符，直到遇到下一个#
        while (i < n && s[i] != '#') {
            if (isdigit(s[i])) {
                temp[k++] = s[i];
                i++;
            } else if (s[i] == ',') { // 逗号不需要处理，直接跳过
                i++;
            }
        }
        // 将数字字符拼接为整数
        int num = 0;
        for (int j = 0; j < k; j++) {
            num = num * 10 + (temp[j] - '0');
        }
        num = num * sign; // 乘以符号标志，处理负数
        arr[cnt++] = num; // 存入数组，个数加1
    }
    return cnt;
}
```
* **编码规范提醒**：不要给变量随意起`a/b/c/d`这类无意义名称，尽量使用见名知意的变量名（如`temp`表示临时存储、`cnt`表示计数）；大括号要对齐，保证成对出现，降低查错难度。

**第二步：十进制整数转九进制存入二维数组（第二个函数实现）**
* **核心思路**：遍历存储整数的一维数组，逐个将十进制整数通过除9取余法转换为九进制字符串，存入二维数组。
* 🚩重点：十进制转N进制的通用方法：**除N取余，逆序排列**。转换过程中得到的余数是从低位到高位的，因此最后需要逆序才是正确的九进制结果。
* **转换核心逻辑**：
```c
// 函数功能：将长度为m的数组arr中每个整数转为九进制，存入二维数组res
void convertToBase9(int arr[], int m, char res[][100]) {
    for (int i = 0; i < m; i++) { // 遍历每个整数
        int temp = arr[i]; // 用临时变量存储原数，避免修改原数组
        char tempStr[100]; int k = 0; // 临时存储余数
        // 除9取余
        while (temp != 0) {
            int rem = temp % 9; // 对9取余得到当前位
            tempStr[k++] = rem + '0'; // 整数转字符，加上'0'
            temp = temp / 9; // 除以9得到新的商
        }
        // 逆序后存入结果二维数组，本部分本节课未讲完，下节课继续
    }
}
```
* 🚩重点：必须要把整数余数转换为字符，因此`余数 + '0'`是必不可少的一步，否则存入的是ASCII码不对的乱码。
* **变量作用域提醒**：不同循环要使用独立的循环变量，不要复用已经修改过值的变量，避免逻辑错误。

#### 💡 核心概念
- **标志位思想**：通过一个变量标记状态（如正负号），最后根据标记修改结果，是处理二值状态问题的经典方法。
- **按权展开拼数**：将数字字符串转换为整数的方法，公式为：
$$ num = num \times base + (digit\_char - '0') $$
其中`base`是目标进制，十进制为10，八进制为8。
- **除N取余法**：十进制转任意N进制的通用方法，步骤：
  1. 十进制数除以N，得到余数和商
  2. 余数作为当前N进制的最低位
  3. 用商重复步骤1，直到商为0
  4. 将所有余数逆序排列得到最终N进制数。
