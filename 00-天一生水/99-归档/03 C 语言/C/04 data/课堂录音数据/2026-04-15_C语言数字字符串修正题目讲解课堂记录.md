#### 知识精讲
本次课程讲解了C语言中数字字符串纠错函数的实现方法，通过拆解步骤讲解了统计次数、查找缺失和重复字符、替换错误的完整逻辑，总结了字符串处理类题目的解题思路，强调编程练习的重要性。

**数字字符串纠错题目要求**
* **题目规则**：给定长度为10的数字子串，正确子串要求`0~9`每个数字字符必须出现且仅出现一次；题目说明输入最多仅存在一处错误，即一个数字重复一次、一个数字缺失，要求将**后一个重复数字**替换为缺失数字，无错误返回0，有错误处理后返回1。
   - 示例1：原串`1223456789`中，数字2重复、数字1缺失，将第二个2替换为1，得到正确串
   - 示例2：原串`0012456789`中，数字0重复、数字3缺失，将第二个0替换为3
* 🚩重点：题目要求替换的是**后一个重复的字符**，而非第一个，这是常见的易错扣分点；本题属于经典的数组统计+字符串查找应用题，考试中出现概率很高。

**解题步骤拆解**
* **第一步：统计每个数字出现次数**
利用计数数组统计0~9每个字符的出现次数，本质是经典的统计类问题，和统计字母个数的问题逻辑完全一致。
   - 定义长度为10的整形数组`count[10]`，初始化为全0；数组下标`j`对应数字字符`j`，数组值`count[j]`存储数字`j`出现的次数
   - 遍历输入字符串，将字符映射为对应数组下标：字符转数字的方法为 `num = str[i] - '0'`，将ASCII码转换为对应的0~9整数，避免下标越界
   - 每遍历到一个数字，对应计数加1：`count[num]++`
* **第二步：查找缺失和重复的数字**
遍历计数数组，根据计数值判断缺失和重复：
   - 计数值为0：对应数字就是缺失数字，存储到变量`miss`中，需要转换回字符格式：`miss = j + '0'`
   - 计数值为2：对应数字就是重复数字，存储到变量`repeat`中，同样转换回字符格式`repeat = j + '0'`
   - 初始定义`miss`和`repeat`为非0~9的无效值（如字符`'i'`），用于后续判断原串是否本身正确
* 🚩重点：题目限定最多只有一处错误，因此只会有一个计数值为0、一个计数值为2，不需要考虑多错误的复杂情况。

* **第三步：错误判断与替换**
先判断是否存在错误，再处理替换逻辑：
   - 无错误判断：如果`miss`和`repeat`仍然是初始无效值，说明不存在错误，直接`return 0`结束函数
   - 查找并替换重复字符：题目要求替换最后一个重复字符，因此需要**从字符串末尾向前倒序遍历**，找到第一个匹配的重复字符后，直接替换为缺失字符，跳出循环；如果正序遍历会替换第一个重复字符，不符合题目要求，会扣分
   - 替换完成后`return 1`结束函数，完成纠错

**字符串处理类题目通用思路**
* 所有提取、统计类字符串问题都可以拆解为多步简单操作，分步实现降低复杂度，判分按步骤给分，写出部分步骤也可以得分
* 循环是所有编程题目的核心，几乎所有编程题都离不开循环结构

#### 💡 核心概念
- **计数数组统计法**：利用数组下标对应待统计数字/字符，数组值存储对应出现次数，是统计类问题的通用解法，对于0~9的数字，计数数组定义为：
```c
int count[10] = {0};
```
- **字符与整数转换**：字符转对应整数：`int num = str[i] - '0';`，整数转对应字符：`char c = num + '0';`
- **本题核心代码片段（替换部分）**：
```c
// 倒序遍历替换最后一个重复字符
for (int i = n-1; i >= 0; i--) {
    if (str[i] == repeat) {
        str[i] = miss;
        break;
    }
}
return 1;
```
