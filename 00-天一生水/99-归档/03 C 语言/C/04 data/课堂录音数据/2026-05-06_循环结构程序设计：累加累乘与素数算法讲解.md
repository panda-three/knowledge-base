# 循环结构程序设计：累加累乘与素数算法讲解

#### 录音总结
本课程为C语言循环结构程序设计专题课，讲解了循环语句解决累加累乘问题的多种题型，以及素数的概念和4种素数判断算法，还拓展了素数相关的编程题，明确素数、累加累乘是考试重点。

**课程学习目标说明**
* **核心目标**：复习已学循环语句，掌握用循环解决累加累乘问题，理解素数概念，掌握素数判断算法。
* **考点说明**：累加累乘、素数算法均为该章节的考试重点内容。

**单层循环累加题型讲解**
* **题目要求**：给定N为10，计算从1加到N的累加结果，使用一层循环实现。
* **实现逻辑**：循环变量i从1递增到10，每次将i的值累加到累加器s中，最终输出s。
* **知识点关联**：该题目对应之前课程讲解的while、do while、for三种循环的累加知识点。

**单层循环累乘（阶乘）题型讲解**
* **题目要求**：循环变量i从1递增到6，每次将i累乘到累乘器s中。
* **最终结果**：该程序实现求6的阶乘，6的阶乘计算结果为720。

**阶乘累加题型讲解**
* **题目逻辑**：外层循环执行6次，每轮循环计算当前i的阶乘，再将结果累加到总和s中。
* **最终功能**：程序实现计算1!+2!+3!+4!+5!+6!的累加结果。

**分式累加题型讲解**
* **题目要求**：N为5，计算s=1+1/2+1/3+1/4+1/5，结果保留两位小数，最终结果为2.28。
* **关键知识点**：C语言中整形除以整形会得到整形结果，因此必须用浮点型的1.0除以i，才能保留小数结果。

**阶乘分式累加题型讲解**
* **实现逻辑**：每轮循环在上一轮阶乘结果基础上乘以当前i得到当前阶乘，再计算1.0除以当前阶乘，累加到总和s。
* **输出要求**：输出格式为「N值, s值」，s值保留两位小数。

**带正负交替的幂次分式题型讲解**
* **题目设定**：给定N=6，x=2，计算表达式x¹/1! -x²/2! +x³/3! -… -x⁶/6!。
* **实现细节**：使用内层循环单独计算每一项的x幂次和阶乘，使用变量f控制正负，f初始为1，每轮循环取反实现一正一负的交替。
* **循环次数**：该程序一共循环6次，i从1递增到6。

**带分母累加的正负交替题型讲解**
* **空题考点**：考试中本题通常设置4个填空，第一空送分，答案为i≤n；第二空为m *= x，用于计算x的幂次。
* **实现逻辑**：分子为变次的x幂，分母为阶乘的累加和，同样用变量f控制正负，将减项转换为加负数计算，最终结果累加到sum变量中输出。

**同数字多位数累加题型讲解**
* **题目设定**：给定a=2，N=6，计算2+22+222+…+222222的累加结果。
* **实现逻辑**：使用内层循环计算每一项，每一项通过「上一项*10 +a」得到新项，再将每一项累加到总和sum中。
* **知识点总结**：该方法是求每位数字相同的多位数的标准写法。

**素数概念讲解**
* **定义说明**：素数又称质数，是大于1的自然数，特点为除了1和自身外，无法被其他自然数整除，比如13就是素数。
* **判断逻辑**：判断整数n是否为素数，只需要验证2到n-1区间内是否有数能整除n，余数为0则不是素数。

**单个数素数判断的四种算法讲解**
* **算法一**：从2循环除到n-1，找到能整除的数就终止循环，使用标记变量记录结果，这是基础穷举法。
* **算法二**：从2循环除到n/2，减少循环次数，用于提升程序执行效率。
* **算法三**：从2循环除到n的平方根，大幅减少循环次数，需要引入头文件用sqrt函数开平方，效率更高，比如判断47只需要除到6即可完成判断。
* **算法四**：将平方根条件转换为i*i≤n，本质和算法三一致，不需要调用开平方函数。
* **考试说明**：考试中常用的是算法一和算法三，要求学生理解并掌握。

**1到100所有素数求解题型讲解**
* **实现逻辑**：外层循环从2到100遍历所有数，每遍历一个数都先假设它是素数（标记设为1），再用素数判断逻辑验证，如果标记仍为1则输出该数。
* **输出注意事项**：输出素数时必须添加分隔符（空格、跳格、逗号），避免所有数字连在一起无法分辨。

**素数拓展题型讲解**
* **100到300回文素数求解**：需要同时满足两个条件，是素数且是回文数（三位数的判断逻辑为百位和个位相等），两个条件同时满足则输出。
* **找100以内最大的5个素数**：从100开始递减遍历，找到素数就输出并计数，找到5个就终止循环。
* **1000以内素数每10个一行输出**：增加计数变量，每输出10个素数就换行控制排版。
* **找大于给定整数n的最近素数**：从n+1开始递增遍历，找到第一个素数就跳出外层循环终止程序。

给定N=6、x=2，要求计算x¹/1! - x²/2! + x³/3! -… -x⁶/6!。讲解实现逻辑，使用内层循环单独计算每一项的x幂次和阶乘，用变量f控制正负，f初始值为1，每轮循环对f取反即可实现一正一负的交替效果，一共循环6次完成计算。

[00:18:00](https://getnotes.seek:1080) **分母累加型正负交替例题讲解**

讲解带分母累加的复杂题目，该题在考试中常设置为4个空的填空题。第一个空为循环条件，答案是i≤n，属于送分题；第二个空用于累乘计算x的幂次，答案是m *= x。本题分子为递增的x幂，分母为阶乘的累加和，同样用f控制正负，将所有项累加后输出结果sum。

[00:21:00](https://getnotes.seek:1260) **同数字多位数累加例题讲解**

给定a=2、N=6，要求计算2+22+222+…+222222。讲解实现逻辑：每一项通过「上一项的值*10 +a」得到当前项，再将计算好的每一项累加到总和sum中。总结该方法是求每位数字相同的多位数的标准写法。

[00:26:00](https://getnotes.seek:1560) **素数概念与单个数素数基础判断讲解**

重新强化素数的概念：素数又称质数，是大于1的自然数，除了1和自身外无法被其他自然数整除。讲解基础判断逻辑：从键盘输入待判断的n，循环从2到n-1遍历，如果存在数能整除n，就将标记变量f从1改为0，最后如果f仍为1则判定为素数，否则不是素数，该方法为基础穷举法。

[00:29:00](https://getnotes.seek:1740) **优化版素数判断算法讲解**

讲解三种优化版素数判断算法，用于减少循环次数提升执行效率。第一种优化是循环到n/2就可以停止判断；第二种优化是循环到n的平方根就停止，需要引入头文件调用sqrt函数开平方，大幅减少循环次数，比如判断47只需要除到6即可完成；第三种优化是将平方根条件转换为i*i≤n，本质和第二种优化一致，不需要调用开平方函数。说明考试常用基础穷举法和平方根优化法，要求学生掌握。

[00:35:00](https://getnotes.seek:2100) **1到100所有素数求解讲解**

讲解求解1到100所有素数的编程逻辑：外层循环从2到100遍历所有数，每遍历一个数先假设它是素数，将标记f设为1，再用素数判断逻辑验证，如果验证后f仍为1就输出该数。提醒学生注意：输出素数必须添加分隔符，避免所有数字连在一起无法分辨。

[00:38:00](https://getnotes.seek:2280) **素数拓展题型讲解（一）**

讲解100到300的回文素数求解题目：回文数指正读反读都相同的数，本题要求输出同时满足是素数和回文数的三位数，三位数回文的判断逻辑为百位和个位相等即可。需要同时满足两个条件，才输出结果，同时提醒学生如果对逻辑运算符优先级不确定，可以添加括号明确优先级。

[00:40:00](https://getnotes.seek:2400) **素数拓展题型讲解（二）**

依次讲解剩下三道素数相关拓展题：第一题是从100开始递减查找，找出最大的5个素数，找到一个就计数，找到5个终止循环；第二题是输出1000以内所有素数，要求每10个素数换一行，通过计数变量控制换行；第三题是查找大于给定整数n的最近素数，从n+1开始递增遍历，找到第一个素数就跳出外层循环结束程序。最后宣布本节课结束，下课。
