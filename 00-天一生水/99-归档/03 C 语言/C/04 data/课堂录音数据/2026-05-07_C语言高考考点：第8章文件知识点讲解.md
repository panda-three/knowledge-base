本次课程讲解C语言第8章文件模块的高考考点知识，涵盖文件基础概念、操作方法、各类读写函数、定位与检测方法，搭配例题讲解帮助掌握考点，该模块在高考中分值不超过3分。

**C语言文件考点基本说明**
* **考点分值**：C语言文件知识点是高考C语言考点的最后一个知识点，通常出现在填空题或最后一题，总分值不会超过3分。
* **课程学习目标**：本次课程要求理解文件概念，掌握文件打开与关闭方法，掌握磁盘文件读写、文件定位方法以及文件检测方法。
* **高考考察情况**：2023年高考题考察了判断文件未结束的`feof`函数，2024年大概率不会再次考察文件检测相关知识点。

**文件基础概念与路径规则**
* **文件分类**：从用户角度划分，文件分为普通文件和设备文件；从存放格式划分，文件分为文本文件和二进制文件。
* **C语言路径表示规则**：C语言中反斜杠被用作转义字符，因此表示路径中的一个反斜杠，需要连续书写两个斜杠，文件夹之间需要用双斜杠隔开。
* **文件指针定义方法**：定义文件指针的格式为`FILE *指针变量名`，例如定义名为`FP`的文件指针写法为`FILE *FP`。

**文件打开与关闭操作**
* **文件打开函数规则**：打开文件使用`fopen`函数，调用格式为`文件指针 = fopen("文件名", "打开方式");`。
* **常见打开方式含义**：`r`为只读打开已有的文本文件；`w`为只写新建或清空已有文本文件；`a`为在已有文件末尾追加数据；`r+/w+/a+`分别对应可读写的对应模式；后缀加`B`表示对应操作针对二进制文件。
* **文件打开校验方法**：高考中常考文件打开校验，写法为如果`fopen`返回空指针，就输出打开失败信息并调用`exit(0)`退出程序。
* **文件关闭方法**：文件使用完毕后需要调用`fclose`函数关闭，调用格式为`fclose(文件指针);`。

**单字符读写函数讲解**
* **函数功能与要求**：`fgetc`从指定文件读取一个字符，要求文件以可读方式打开；`fputc`将一个字符写入指定文件，要求文件以可写或追加方式打开，`fputc`的两个参数依次为待写入字符、目标文件指针。
* **写入字符例题解析**：将键盘输入的以回车为结束符的字符写入文件，需要先以写方式打开文件，循环读取输入字符，遇到非回车字符就调用`fputc`写入文件，输入结束后调用`fclose`关闭文件，高考填空题常考此处的关闭语句。
* **读取字符例题解析**：从文本文件读取字符并输出到屏幕，需要先以读方式打开文件，循环调用`fgetc`读取字符，读取到的字符不是文件结束标识`EOF`就输出到屏幕，输入结束后关闭文件。

**格式化读写函数讲解**
* **函数规则说明**：格式化读写函数`fscanf`和`fprintf`，和标准输入输出函数`scanf`、`printf`功能类似，仅在函数名前加f，且第一个参数为目标文件指针；`fscanf`从指定文件读取数据，`fprintf`将数据写入指定文件。
* **整数排序写入例题解析**：将10个从键盘输入的整数排序后写入C盘文件，第一步需要先定义`FILE`类型的文件指针，第二步以写方式`w`打开文件，排序完成后调用`fprintf`将排序后的整数逐个写入目标文件。
* **杨辉三角读写例题解析**：将杨辉三角保存到文件再读取输出到屏幕，需要先以写方式打开文件，将杨辉三角逐行写入文件后关闭文件，再重新以读方式打开文件，逐行调用`fscanf`读取数据后输出到屏幕。

**数据块读写函数讲解**
* **函数参数规则**：`fread`和`fwrite`都包含4个参数，依次为数据块首地址、单个数据块的字节大小、要读写的数据块数量、目标文件指针。
* **函数功能示例**：`fread(a, sizeof(int), 5, fp)`表示从`fp`指向的文件中读取5个长度为`sizeof(int)`的数据块，存入数组`a`中；`fwrite(a, sizeof(int), 5, fp)`表示将数组`a`中的5个整数写入`fp`指向的文件。
* **素数存储例题解析**：随机生成50个两位整数，筛选出素数后一次性写入C盘文件，需要先遍历生成的随机数，将素数存入数组并统计素数个数`N`，最后调用`fwrite`，从素数数组首地址开始，一次性写入`N`个`sizeof(int)`大小的数据块到目标文件。

**字符串读写函数讲解**
* **函数参数与规则**：`fgets`用于从文件读取字符串，包含3个参数，依次为存储字符串的数组、读取长度`N`、目标文件指针；`fgets`最多读取`N-1`个字符，最后一位预留位置存储结束符`\0`，遇到换行符或文件结束就停止读取。
* **`fputs`函数规则**：`fputs`用于将字符串写入指定文件，不会额外添加换行符，函数返回0代表输出成功，非0代表输出错误。
* **文件复制例题解析**：将一个文本文件的内容复制到另一个文本文件，需要以读方式打开源文件，以写方式打开目标文件，循环调用`fgets`从源文件读取字符串，调用`fputs`将字符串写入目标文件，操作完成后依次关闭两个文件，高考填空题常考遗漏的源文件关闭语句。

**文件定位操作讲解**
* **`rewind`函数功能**：`rewind`函数的作用是将文件内部的位置指针重新定位到文件开头，通常用于先写入文件后需要从头读取的场景。
* **`fseek`函数参数规则**：`fseek`用于移动文件位置指针，包含3个参数，依次为文件指针、位移量、起始位置；起始位置0代表从文件头开始，1代表从当前位置开始，2代表从文件尾开始；位移量为正代表向文件尾部方向移动，为负代表向文件头部方向移动。
* **素数查询例题解析**：建立包含50个素数的二进制文件，根据输入序号查询对应素数，需要以`wb+`方式打开二进制文件，写入50个素数后调用`rewind`回到文件头，输入序号后调用`fseek`定位到对应素数位置，调用`fread`读取素数后输出。

**文件检测操作讲解**
* **`feof`函数功能**：`feof`用于判断文件是否结束，若文件结束返回值为1，否则返回值为0；通常在循环中使用`while(!feof(fp))`判断文件未结束，持续进行读写操作。
* **`ferror`函数功能**：`ferror`用于检查文件读写过程是否出错，返回值为0代表没有出错，返回值为非0代表读写出错。
* **有序文件合并例题解析**：将两个已经升序排列的文件合并为一个新的升序文件，两个源文件都需要以读方式`r`打开，循环比较两个文件当前取出的元素，将较小的元素写入新文件，再从对应源文件取出下一个元素，其中一个源文件读完后，将另一个源文件剩余元素全部写入新文件，最后依次关闭三个文件。

[00:32:00](https://getnotes.seek:1920) **字符串读写函数讲解与例题分析**

讲解字符串读写函数`fgets`和`fputs`的规则：`fgets`最多从文件读取`N-1`个字符存入数组，最后一位预留存储`\0`，遇到换行符或文件结束就停止；`fputs`将字符串写入文件，不会额外添加换行符，返回0代表输出成功。分析文件复制例题：将一个文本文件内容复制到另一个文本文件，源文件以`r`方式打开，目标文件以写方式打开，循环调用`fgets`读取源文件内容，调用`fputs`写入目标文件，操作完成后需要关闭两个文件，题目通常只关闭目标文件，需要补写源文件的关闭语句。说明多字符串读写的注意规则，`fgets`会将换行符保存在字符串中，再添加结束符。
