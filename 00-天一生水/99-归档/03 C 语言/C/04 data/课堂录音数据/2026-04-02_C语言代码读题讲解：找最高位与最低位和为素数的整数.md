**题目需求分析**
* **题目要求**：对给定的多个区间，找出区间内满足**最高位数字与最低位数字之和为素数**的所有整数，输出结果。
* **示例分析**：
  - 区间[26,28]：26(2+6=8非素)、27(2+7=9非素)、28(2+8=10非素)，无符合条件的数；
  - 区间[30,50]：30(3+0=3素)、32(3+2=5素)等满足条件；
  - 区间[80,113]：101(1+1=2素)满足条件。
* 🚩重点：易错点是**仅加最高位与最低位，不是所有位相加**，审题错误会直接导致结果错误。

**main函数逻辑分析**
* **二维数组定义**：题目给出的待查询区间存储在二维数组`FW`中，结构如下（根据老师讲解整理）：
  | 行下标i | FW[i][0]（区间左端点） | FW[i][1]（区间右端点） |
  |---------|-------------------------|-------------------------|
  | 0       | 26                      | 28                      |
  | 1       | 30                      | 50                      |
  | 2       | 80                      | 113                     |
* **循环过滤非法区间**：遍历三行区间，过滤掉不满足要求的区间：
  1. 若区间左端点 ≥ 右端点（`FW[i][0] > FW[i][1]`）：区间不合法，跳过；
  2. 若区间左端点 < 10：个位数无法区分最高位最低位，跳过；
  3. 若区间右端点 > 999：题目限定范围不超过999，跳过。
* 🚩重点：常见改错题错误点——函数传参类型不匹配
  原错误写法：调用`find`函数时仅写`FW[i]`，仅传行地址，实际传递了一维数组类型；但函数要求前两个参数为int类型，类型不匹配。
  正确修正：需要取出二维数组对应位置的整数值，修改为`find(FW[i][0], FW[i][1], FW)`。

**find函数核心逻辑——提前筛素数**
* **算法思路**：由于最高位+最低位最大为`9+9=18`，因此可以提前预处理出0~18所有数是否为素数，不需要每次判断素数，优化逻辑。
* **核心步骤（埃氏筛法预处理素数）**：
  1. 初始化：定义`flag[19]`数组，初始所有元素赋值为`1`，表示默认所有数都是素数；
  2. 🚩重点：原代码错误点1：错误写法为`flag[j] = 1`，逻辑矛盾。正确改法：`flag[i*j] = 0`；
     - 逻辑说明：若一个数能拆成两个大于等于2的整数的乘积，说明该数不是素数，标记为0；循环条件`i*j < 19`对应和最大不超过18的要求；
  3. 最终`flag[s] = 1`表示`s`是素数，`flag[s] = 0`表示`s`不是素数。
   - *公式逻辑*：对于所有 $2 \leq i < 19, 2 \leq j < 19$，满足 $i \times j < 19$，令 $flag[i \times j] = 0$。

**find函数核心逻辑——遍历区间判断符合条件的数**
* **提取最高位与最低位**：
  1. 遍历区间内所有整数`i`，定义`temp = i`，保留`i`的值不变，用`temp`做运算修改；
  2. 初始化`p = 1`，循环计算最高位对应的位权`p`：
     - 🚩重点：原代码错误点2：错误写法为循环条件`while(temp != 0)`，会导致`p`多乘一次10，最高位计算错误。正确改法：循环条件为`while(temp >= 10)`；
     - 逻辑说明：只要`temp`还是两位数及以上，就继续除以10，`p`乘以10，直到`temp`只剩下最高位，此时停止循环，`p`就是最高位对应的位权。
  3. 计算和：最高位为`i / p`，最低位为`i % 10`，求和得`s = (i/p) + (i%10)`。
* **结果存储**：若`flag[s] == 1`（和为素数）且`s >= 2`，将`i`存入结果数组。
* 🚩重点：原代码错误点3：函数声明为有返回值类型，需要返回结果数组中有效元素的个数，原代码缺失返回值语句，需要补充`return m;`（`m`为计数变量）。

[00:18:28](https://getnotes.seek:1108) **素数预处理逻辑讲解**
首先定义`flag`数组，初始化所有元素为1。老师引导学生思考双层循环`for(i=2; i<19; i++) for(j=2; i*j<19; j++)`的逻辑：原代码错误写为`flag[j] = 1`，逻辑矛盾，因为初始已经是1，重复赋值没有意义，且不符合素数筛选逻辑。

老师讲解为什么循环上限是19：由于最高位最大是9，最低位最大是9，和最大是18，因此只需要预处理0~18的素数即可。算法思路是用埃氏筛法：初始默认所有数都是素数（标记为1），然后把所有能分解为两个大于等于2的整数乘积的数（即合数）标记为0。因此正确改法是`flag[i*j] = 0`，凡是能拆成乘积的数都是合数，标记为0。🚩这个错误点难度较高，需要理解19的含义才能想到正确改法。

[00:30:07](https://getnotes.seek:1807) **区间遍历逻辑讲解**

[00:31:10](https://getnotes.seek:1870) **第二个改错题讲解**
接下来是循环计算位权`p`，原代码错误写为循环条件`while(temp != 0)`，老师代入26举例：如果条件是`temp != 0`，第一次循环`temp=26≠0`，`p`乘10变为10，`temp=26/10=2`；第二次循环`temp=2≠0`，`p`再乘10变为100，`temp=2/10=0`，循环结束。最终计算最高位`26 / 100 = 0`，结果错误。

正确改法是循环条件改为`while(temp >= 10)`，重新计算：第一次循环`26≥10`，`p=10`，`temp=2`；第二次判断`2≥10`不成立，循环结束。最高位`26 / 10 = 2`，结果正确。老师总结：`p`的作用是和数字的位数相关，n位数的最高位位权就是10的n-1次方，这个条件保证p不会多乘一次10。🚩这是本次真题新增的难度点，往年只需要写`temp != 0`，今年改为`temp >= 10`，考察对逻辑的深入理解。

[00:36:50](https://getnotes.seek:2210) **最终判断逻辑讲解**
循环结束后，计算`s = i/p + i%10`，`i/p`得到最高位，`i%10`得到最低位，相加得到和。然后判断：如果`flag[s] != 0`（即`flag[s] = 1`，说明s是素数）且`s >= 2`（素数最小为2），就把当前i存入结果数组，计数加1。

#### 💡 核心概念
- **二维数组元素访问**：`FW[i][j]`表示第i行第j列的元素，仅写`FW[i]`表示第i行的首地址，类型为一维数组指针。
- **埃氏筛法求素数**：对于范围N内的素数，初始默认所有数为素数，再将所有能拆为两个大于等于2整数乘积的数标记为合数。
- **提取数字最高位位权**：
  伪代码逻辑：
  ```c
  int temp = n;
  int p = 1;
  while(temp >= 10){
      p *= 10;
      temp /= 10;
  }
  int highest = n / p; // 得到最高位数字
  int lowest = n % 10; // 得到最低位数字
  ```
