# C语言循环嵌套与图形打印课程讲解

## 原始正文

### 📑 智能总结

#### 课程信息

#### 知识精讲

本节课讲解C语言循环嵌套的应用，通过多个图形打印例题拆解循环嵌套分析方法，总结文本图形打印的通用步骤和注意事项，强调循环嵌套是考试核心考点。

**循环嵌套次数计算**
* **三层嵌套循环执行次数推导**：给定初始`N=1`，三层循环结构为`I从3到3`、`J从1到3`、内层`K从1到J`，每次循环执行`N=N+1`，推导最终N的值。
   - 推导过程：J取1时，内层循环执行1次，加上J自身1次，共加2 → N=2；J取2时，内层执行2次，加J自身1次，共加3 → N=5；J取3时，内层执行3次，加J自身1次，共加4 → N=9，最终结果N=9。
   - 🚩重点：快速计算方法为：外层循环每轮，J执行1次+内层循环执行J次，总和为 $\sum_{J=1}^3 (J+1)=2+3+4=9$，核心是掌握嵌套循环的逐层执行逻辑。

**矩形文本图形打印**
* **固定长度星号矩形实现**：外层循环`I从1到4`控制行数，内层循环`J从1到10`控制每行星号数量，每次内层循环输出1个星，外层循环每轮结束后换行。
   - 最终输出结果：4行，每行10个星号的矩形。
   - 核心逻辑：外层循环控制行数，内层循环固定长度控制每行字符数。

**直角三角形文本图形打印**
* **正直角三角形（左下对齐）**：将内层循环的终止条件修改为`J≤I`，内层循环次数随外层I的值递增。
   - I=1输出1个星，I=2输出2个星，I=3输出3个星，I=4输出4个星，最终得到左下对齐的直角三角形。
   - 🚩考点：看到`J≤I`的条件，直接对应直角三角形图形，是考试常考的模式识别点。
* **倒直角三角形（左上对齐）**：内层循环终止条件修改为`J≤5-I`（共4行时，I=1→J≤4，I=4→J≤1）。
   - 输出结果：第一行4个星，逐行递减1个，最后一行1个星，得到左上对齐的倒直角三角形。

**带空格等腰三角形打印**
* **双内层嵌套结构分析**：外层循环控制行数，每一行包含两个连续内层循环：第一个内层循环输出空格，第二个内层循环输出星号。
   - 共4行的示例：I=1时，第一个内层循环`J≤4-I`输出3个空格，第二个内层循环`J≤I`输出1个星；I=2输出2个空格+2个星；I=3输出1个空格+3个星；I=4输出0个空格+4个星，最终得到等腰三角形。
   - 🚩重点：空格和星号分两个循环分别找规律，不要混在一起分析；每一轮外层循环后，内层变量都会重新从初始值开始计数。

**对称菱形打印（绝对值法）**
* **绝对值的应用**：利用绝对值函数实现上下对称的图形，外层循环I从-3到3（共7行），第一个内层循环输出空格，终止条件为`J≤abs(I)`，第二个内层循环输出星号，终止条件为`J≤4-abs(I)`。
   - 输出结果：第一行（I=-3）输出3个空格+1个星，逐行空格减少1个、星增加1个，到I=0时输出0个空格+4个星，之后逐行空格增加1个、星减少1个，最终得到对称的菱形。
   - 🚩重点：上下对称的图形用绝对值法可以简化代码，不需要分上下两部分单独写循环。

**文本图形打印通用步骤与注意事项**
* **通用分析步骤**：
1.  确定总行数，对应外层循环的范围
2.  分析每一行的空格数量，找规律对应第一个内层循环
3.  分析每一行的图形字符（星号等）数量，找规律对应第二个内层循环
4.  每一行输出完成后必须输出换行符
5.  上下对称图形可以拆分上下两部分，或直接用绝对值法实现
* **注意事项**：
   - 🚩重点：使用`abs`/`fabs`绝对值函数必须引入`math.h`头文件，否则会编译错误，是考试改错题常考的坑。
   - `math.h`头文件包含的常用数学函数：`abs`（整数绝对值）、`fabs`（浮点数绝对值）、`sqrt(x)`（对x开根号）、`pow(x,y)`（计算x的y次方）。

**课后练习要求**
* **素数输出练习**：🚩重点：素数判断是循环嵌套的经典考题，要求学生自行编写代码实现：输出1~100/1000以内所有素数，每10个素数换行输出，建议手动敲代码巩固。

[00:01:36](https://getnotes.seek:96) **逐层推导循环执行过程**

J=1满足`J≤3`，进入循环：K=1满足`K≤1`，执行`N+1`，N从1变为2；J自增为2，满足条件进入循环：K执行2次，N增加2，变为5；J自增为3，满足条件进入循环：K执行3次，N增加3，最终变为9。

[00:03:13](https://getnotes.seek:193) **快速计算方法总结**

J可以取1、2、3三个值，每个J对应执行1次J循环加J次K循环，总增量为 $(1+1)+(2+1)+(3+1)=9$，和逐步推导结果一致，核心考察对循环嵌套执行逻辑的理解。

#### 💡 核心概念
- **循环嵌套执行逻辑**：外层循环每执行1次，内层循环完整执行一遍，内层变量每次都会重新初始化
- **文本图形打印通用步骤**：
  1. 外层循环控制行数
  2. 内层循环1控制空格数量
  3. 内层循环2控制图形字符数量
  4. 每行结束输出换行
- **常用数学函数（math.h）**：
  - 绝对值：$abs(x)$（整数）、$fabs(x)$（浮点数）
  - 开根号：$\sqrt{x} = sqrt(x)$
  - 幂运算：$x^y = pow(x,y)$
