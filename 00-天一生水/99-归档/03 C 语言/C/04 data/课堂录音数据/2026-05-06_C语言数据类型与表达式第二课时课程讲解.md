#### 录音总结
本课程为C语言数据类型与表达式第二课时，讲解了转义字符、符号常量、各类变量的定义与使用规则，并配套习题解析，帮助学习者掌握相关知识点，明确易错考点。

**转义字符基础规则**
* **转义字符的定义与作用**：转义字符用于表示无法从键盘直接输入的字符，比如换行、退格，在C语言中以反斜杠开头，一个转义字符整体代表1个字符。
* **常见转义字符的含义**：`\n`代表换行，移到下一行行首；`\r`代表回车，移到当前行行首；`\t`代表水平制表，移到下一个tab位置；`\0`代表空字符，ASCII码值为0，是字符串的结束标识。
* **转义字符的数字表示规则**：反斜杠加数字代表对应八进制数转换为十进制后的ASCII码字符，`\x`加数字代表对应十六进制数转换为十进制后的ASCII码字符。

**字符串常量规则**
* **字符串常量的存储要求**：字符串常量默认会在末尾自动添加结束标识`\0`，`\0`的ASCII码值为0，和字符'0'不同，字符'0'的ASCII码为48。
* **字符串长度与大小的区别**：字符串长度指不包含`\0`的实际字符个数，字符串存储大小则需要包含`\0`占用的1个字节。
* **特殊字符的使用要求**：字符串中不能直接包含双引号和反斜杠，必须使用转义字符表示，即在对应字符前添加反斜杠。

**符号常量的定义与使用规则**
* **符号常量的优势**：符号常量含义清晰，做到见名知意，且修改值时只需修改头部的定义语句，即可实现一改全改。
* **符号常量的定义方式**：符号常量使用宏定义`#define`定义，习惯上符号常量名称使用大写字母。宏定义不是C语句，行末不需要加分号，否则分号会被识别为常量值的一部分。
* **符号常量的使用限制**：符号常量的值在作用域内不能修改，不能对符号常量进行赋值操作。

**变量的基础属性与定义规则**
* **变量的核心属性**：变量指程序运行中值可以改变的量，拥有四个核心属性：内存地址、变量名、变量值、数据类型。变量必须先定义后使用，这是C语言考试的高频考点。
* **变量的定义格式**：变量定义格式为「数据类型 + 变量名表」，多个变量之间用逗号分隔，行末用分号结束，例如`int i, j, number;`定义了3个int类型变量。
* **变量的初始化规则**：C语言允许在定义变量时同时初始化，例如`int a=3, b, c=5;`，但不能写`int a, b, c=3;`实现三个变量同时赋值为3，这种写法是错误语法。

**整形变量的分类与取值范围**
* **整形变量的分类方式**：整形可以通过修饰分为基本整形(int)、长整形(long)、短整形(short)，还可以分为有符号和无符号，默认所有整形都是有符号，有符号修饰符可以省略。
* **DEV C++环境下的内存占用**：DEV C++中基本整形和长整形都占用4个字节，短整形占用2个字节；4个字节对应32位二进制，有符号基本整形取值范围为 `-2^31` 到 `2^31-1`，无符号基本整形取值范围为 `0` 到 `2^32-1`。
* **短整形的使用限制**：短整形占用2字节共16位二进制，取值范围较小，计算阶乘等产生较大数值的场景不能使用短整形。

**实型变量的分类与规则**
* **实型变量的分类**：实型变量分为单精度(float)、双精度(double)、长双精度三类，DEV C++中单精度占用4个字节，双精度和长双精度占用8个字节。
* **实型变量的有效位数**：单精度float的有效位数为7位，双精度double的有效位数为15-16位，当赋值的小数位超过有效位数时，超出部分会被舍去。
* **实型变量的输出格式符**：在printf输出函数中，输出浮点数的格式符为`%f`，长双精度使用`%lf`作为格式符。

**字符型变量的定义与使用规则**
* **字符型变量的基础要求**：一个字符型变量只能存放1个字符，占用1个字节的内存空间，存放的内容为对应字符的ASCII码。
* **字符数据与整形数据的通用规则**：字符数据以ASCII码存储，存储形式和整形类似，因此C语言中字符数据和整形数据可以通用，可以直接给字符变量赋值对应的ASCII码整数值。
* **大小写转换的实现方法**：小写字母的ASCII码比对应大写字母大32，因此将小写字母减去32即可得到对应大写字母，这是C语言的经典应用题。

**用户标识符与关键字规则**
* **用户标识符的命名规则**：用户标识符必须以字母或下划线开头，只能由字母、数字、下划线组成，关键字不能作为用户标识符。
* **关键字的定义**：关键字是C语言预先声明、具有特定意义的单词，比如int、float、for、while都属于关键字，不能用作变量名。

**课程配套习题讲解**
* **选择题核心解析**：判断不合法的变量名时，关键字while不能作为变量名；八进制常量的数码只能是0-7，因此`0129`不是合法的整形常量；字符常量只能用单引号包裹单个字符，`'AB'`不是合法的字符常量。
* **填空题核心结论**：小写字母a的ASCII码是97，字符'0'的ASCII码是48，`\0`的ASCII码是0；字符常量'A'占1个字节，字符串常量"A"占2个字节（包含末尾的`\0`）。

### 📅 章节概要
[00:00:00](https://getnotes.seek:0) **课程开场与本节课内容介绍**

本节课是数据类型与表达式第二课时，上一课时已经讲解基础数据类型和部分常量的书写方法。本节课核心内容为字符常量中转义字符的含义、变量的定义/初始化和使用方法。其中提到字符类型中包含无法直接从键盘输入的换行、退格等特殊字符，需要用转义字符表示。

[00:00:52](https://getnotes.seek:52) **常见转义字符的含义讲解**

逐一讲解C语言中常见转义字符的作用：
- `\n`代表换行，将输出位置移到下一行行首；`\r`代表回车，将输出位置移到当前行行首
- `\t`代表水平制表符，将输出位置移到下一个tab位置；`\0`是空字符，ASCII码值为0，作为字符串的结束标识
- `\'`代表输出一个单引号，`\"`代表输出一个双引号，`\?`代表输出一个问号，`\\`代表输出一个反斜杠，`\b`代表退格，将输出位置后退一个位置
- 反斜杠加数字对应八进制ASCII码，`\x`加数字对应十六进制ASCII码。

[00:02:01](https://getnotes.seek:121) **字符串常量的存储规则讲解**

字符串常量默认自动添加结束标识`\0`，例如`"A"`的存储长度是2，包含字母A和末尾的`\0`。`\0`的ASCII码值为0，和字符'0'不同，字符'0'的ASCII码值是48。字符串常量中不能直接包含双引号和反斜杠，必须添加反斜杠转为转义字符才能使用。字符串长度不包含末尾的`\0`，存储大小需要包含`\0`。

[00:03:49](https://getnotes.seek:229) **转义字符与字符串长度例题讲解**

通过实例统计包含转义字符的字符串长度：字符串`A b \" c \"`的可见字符为5个，加上末尾的`\0`后存储长度为6。另一个例子`A\\b`中，`\\`是一个转义字符，整个字符串共有3个可见字符，加上`\0`后总存储长度为4。
随后通过实例演示printf输出转义字符的结果，最终输出内容为`' \ "A B" C "A \ B`，要求学习者牢记一个转义字符只代表一个字符。

[00:06:00](https://getnotes.seek:360) **符号常量的定义与优势讲解**

符号常量的优势是含义清楚、见名知意，且修改值时只需要修改头部定义即可实现一改全改。例如定义PI代表圆周率3.1415926，不需要在程序中重复书写数值。符号常量使用`#define`定义，习惯上符号常量名称使用大写字母。宏定义不是C语句，行末不需要加分号，否则分号会被识别为符号常量值的一部分。

[00:07:46](https://getnotes.seek:466) **符号常量的使用限制说明**

在求圆球表面积的示例程序中，符号常量PI在定义完成后，整个程序中都会替换为对应常量值。符号常量和变量不同，值在作用域内不能改变，不能对符号常量进行赋值操作，例如`PI = PI + 2`是不允许的非法操作。

[00:09:11](https://getnotes.seek:551) **变量的基础概念与核心属性讲解**

变量是程序运行过程中值可以发生改变的量，转义字符、符号常量的值都是固定不可变的，和变量形成区分。每个变量拥有四个核心属性：内存地址、变量名、变量值、数据类型，用学校举例类比：地址对应学校位置、名称对应学校名称、师生对应值、学校类型对应数据类型。

[00:11:04](https://getnotes.seek:664) **变量的定义规则讲解**

C语言规定变量必须先定义后使用，这是考试填空、改错题型的高频考点。变量定义的一般形式为「数据类型 + 变量名表」，多个变量之间用逗号分隔，行末用分号结束。例如`int i, j, number;`定义了三个int类型的整形变量；`float a, b, song;`定义了三个float类型的实型变量；`char c, ch;`定义了两个char类型的字符变量。

[00:12:35](https://getnotes.seek:755) **整形变量的分类与省略规则讲解**

整形的基础类型符是int，可以添加short、long修饰符分为基本整形、长整形、短整形，还可以添加有符号、无符号修饰。高考中有无符号考查较少，默认所有整形都是有符号，有符号修饰符可以省略，short后的int也可以省略，long后的int也可以省略。

[00:14:33](https://getnotes.seek:873) **不同整形的取值范围与内存占用讲解**

DEV C++环境下，基本整形、长整形都占用4个字节，一个字节包含8位二进制，因此4字节对应32位二进制。有符号基本整形的取值范围是 `-2^31` 到 `2^31 -1`；无符号基本整形将符号位用作存储数据，取值范围为`0`到`2^32 -1`，范围比有符号大近一倍。短整形占用2个字节共16位，取值范围较小，计算阶乘等大数值场景不能使用短整形。

[00:16:32](https://getnotes.seek:992) **整形变量的定义、赋值与初始化讲解**

整形变量必须先定义后使用，例如定义`int a, b; long c; unsigned int e;`之后，可以分别给变量赋值：`a=-1; b=-523; c=620000; e=89;`，输出时`%ld`是长整形的输出格式符。C语言允许在定义变量的同时初始化，例如`int a=3; int a=3, b, c=5; int a=3, b=3, c=3;`，这些写法都是合法的。但`int a, b, c=3;`无法给三个变量都赋值为3，这种写法是错误的，只会给c赋值，a和b未定义。

[00:20:21](https://getnotes.seek:1221) **实型变量的分类与内存占用讲解**

实型用于存储小数，分为单精度float、双精度double、长双精度三类，C语言未统一规定各类的长度和范围，DEV C++中float占4个字节，double和长双精度占8个字节，日常开发最常用float类型。

[00:21:08](https://getnotes.seek:1268) **实型变量的有效位规则讲解**

实型变量必须先定义后使用，例如`float x, y; float m=12.8; double min_val; long double t;`都是合法定义。float类型只有7位有效数字，若赋值超过7位小数，超出部分会被舍去；double类型有效位数更长，可存储更多小数位。输出浮点数的格式符为`%f`，长双精度使用`%lf`。

[00:23:33](https://getnotes.seek:1413) **字符型变量的基础规则讲解**

字符型变量用于存放字符常量，一个字符型变量只能存放一个字符，存放多个字符需要使用数组实现的字符串。一个字符型变量占用1个字节的内存空间。

[00:24:18](https://getnotes.seek:1458) **字符型变量的定义、赋值与通用规则讲解**

字符型变量的定义格式为`char c1, c2;`，两个变量各占1字节，可以分别赋值，也可以在定义时初始化。字符数据以ASCII码存储，存储形式和整形一致，因此C语言规定字符数据和整形数据可以通用。例如小写字母a的ASCII码是97，减去32后得到65，对应大写字母A的ASCII码，因此小写转大写只需要减去32。

[00:25:37](https://getnotes.seek:1537) **大小写转换经典程序讲解**

程序定义两个字符变量c1、c2，分别赋值小写a和小写b，然后执行`c1 = c1 - 32; c2 = c2 - 32;`，最后用`printf("%c %c\n%d %d", c1, c2, c1, c2);`输出。输出结果为第一行显示大写A和大写B，第二行显示对应ASCII码65和66，这是小写转大写的经典程序。输出单个字符的printf格式符为`%c`。

[00:29:07](https://getnotes.seek:1747) **字符变量赋值的特殊规则验证**

可以直接给字符变量赋值对应的ASCII码整数值，例如`c1=97; c2=98;`，等价于`c1='a'; c2='b';`，输出结果完全一致，进一步验证了字符和整形可以通用。

[00:30:28](https://getnotes.seek:1828) **用户标识符与关键字习题讲解**

讲解第一题：用户标识符必须以字母或下划线开头，只能包含字母、数字、下划线，关键字不能作为用户标识符，int是关键字，因此不能作为变量名。讲解第二题：int、float、return、for都是C语言的关键字，若题目问哪项不是关键字，本题没有正确选项。讲解第三题：while是循环关键字，不能作为合法变量名。

[00:33:19](https://getnotes.seek:1999) **常量相关选择题讲解**

第四题判断不合法的整形常量：八进制以0开头，数码只能是0-7，`0129`包含9，因此不是合法的八进制常量，本题选A。第五题判断不合法的常量：字符常量只能用单引号包裹单个字符，`'AB'`包含两个字符，因此不是合法常量，本题选A。第六题：小写a的ASCII码是97，`\101`八进制转换后是65，`\x41`十六进制转换后是65，都不是97，因此本题选ABC。

[00:38:25](https://getnotes.seek:2305) **转义字符与常量选择题讲解**

第十题判断不正确的转义字符：选项A只有单个反斜杠，没有后续字符，选项C没有反斜杠，因此AC都不是正确的转义字符。第十一题判断不能作为合法常量的选项：选项A`'-01'`用单引号包裹了三个字符，不符合字符常量规则，因此本题选A。

[00:40:52](https://getnotes.seek:2452) **填空题讲解与课程收尾**

讲解填空题核心结论：需要牢记小写a的ASCII码是97，字符'0'的ASCII码是48，`\0`的ASCII码是0；字符常量'A'占1个字节，字符串常量"A"占2个字节，因为末尾自动添加`\0`。定义单精度实型变量f2、初值为12.35的写法是`float f2=12.35;`。字符型c=98，说明字符型数据以ASCII码存储，和整形可以通用。数据类型决定了变量占用的内存字节数和取值范围，字符型占1个字节。最后说明本节课内容讲解完毕，下课。
