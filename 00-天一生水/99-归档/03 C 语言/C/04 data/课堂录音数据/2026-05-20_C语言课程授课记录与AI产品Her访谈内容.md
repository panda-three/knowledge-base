**一维数组的插入与删除**
* **数组插入的基本思想**：插入元素分为三步：① 找到待插入位置；② 从后向前移动元素，为插入元素空出位置；③ 将新元素放入指定位置，数组长度加1。
   - 移动元素的逻辑：`a[i] = a[i+1]` 表示将元素向右移动（右移），给新元素腾出位置。
   - 🚩重点：必须从后向前移动，若从前向后移动会导致后续元素被提前覆盖，插入位置出错。
   - 🚩考点：插入操作完成后，数组长度必须`+1`。
* **数组删除的基本思想**：删除元素分为两步：① 找到待删除元素的位置；② 从删除位置开始，后续元素依次向前移动覆盖，数组长度减1。
   - 移动元素的逻辑：`a[i] = a[i+1]` 这里表示元素向左移动（左移），覆盖待删除元素。
   - 🚩考点：删除操作完成后，数组长度必须`-1`，刚好和插入操作对应。
* **插入例题：升序数组插入元素保持有序**：步骤为查找插入位置 → 右移元素 → 插入元素 → 长度加1。从后向前遍历数组，找到第一个小于插入值`x`的位置，将该位置及之后元素右移，再插入x即可。
* **删除例题：删除数组中值为x的元素**：步骤为查找元素位置 → 找到后从该位置开始后续元素左移覆盖 → 长度减1。若没找到x则直接结束操作。

**字符串基础**
* **字符串本质与定义**：字符串本质上是**以`\0`结尾的字符数组**，定义格式为`char 数组名[长度];`。
   - 🚩重点：字符串必须以`\0`（ASCII码值为0，不是字符'0'）作为结束标志，判断字符串结束的条件为`s[i] != '\0'`，直接写`s[i] != 0`也等价。
* **多个字符串的定义**：多个字符串需要用二维字符数组定义，`char 数组名[行数][列数];`，取整串只需要写行下标`数组名[行下标]`，取单个字符需要同时写行下标和列下标。
* **输入输出格式**：单个字符用`%c`，整个字符串输出用`%s`；🚩重点：输入字符串时**不需要加取地址符`&`**，因为数组名本身就是地址。
* **数字字符转数值**：🚩重点🚩 **高考/考试必考**：字符数字转对应整数，必须减去字符`'0'`，例如`'5' - '0' = 5`。
* **删除字符串中的数字字符**：遍历原字符串，遇到非数字字符保留到新数组（或覆盖原数组），处理完成后必须在末尾添加`\0`结束标志。

**常用C语言字符串函数**
* 所有字符串函数都需要引入头文件 `<string.h>`。
* `gets(字符数组)`：读取一整行包含空格的字符串，遇到回车才结束输入；而`scanf`遇到空格就会停止输入。
* `puts(字符串)`：输出字符串，输出完成后自动换行，不需要手动加`\n`。
* `strlen(字符串)`：求字符串长度，返回值不包含结束标志`\0`。例如字符串"1234"返回长度为4，不是5。
* `strcat(s1, s2)`：将字符串`s2`连接到`s1`的末尾，🚩重点：`s1`的存储空间必须足够大，否则会溢出。
* `strcpy(s1, s2)`：将字符串`s2`复制给`s1`，是后参数复制给前参数。
* `strcmp(s1, s2)`：比较两个字符串大小：
  - 比较规则：从第一个字符开始依次比较ASCII码，第一个不同的字符的大小就是两个字符串的大小。
  - 返回值规则：若`s1 > s2`返回值大于0；若`s1 < s2`返回值小于0；若相等返回0。
  - 🚩重点：字符串比较必须使用`strcmp`，不能直接用`==`比较。

**十进制转十六进制**
* 转换方法：对16反复取余，将余数保存到数组中，最后将数组逆序输出得到十六进制结果。
* 使用字符数组预存十六进制数码：`char hex[] = "0123456789ABCDEF";`，取出余数后直接取对应数码即可完成转换。
* 🚩为什么要先保存到数组再逆序输出？因为第一次取余得到的是十六进制的最低位，最后一次取余得到最高位，所以需要逆序输出得到正确结果，这就是保存余数的意义。

**结构体基础**
* **结构体的作用**：将多个不同类型、相互关联的数据组合成一个自定义类型，保证数据的一一对应关系（例如一个学生的姓名、学号、性别需要绑定在一起）。
* **结构体类型定义语法**：
```c
struct 结构体类型名 {
    类型1 成员名1;
    类型2 成员名2;
    ...
}; // 末尾必须加分号
```
例如定义学生结构体：
```c
struct stu {
    char name[10];
    int id;
    int sex;
};
```
* **结构体变量的定义与赋值**：结构体定义完成后，可以像基础类型一样定义变量，赋值和访问成员需要使用`.`运算符：
```c
struct stu m; // 定义结构体变量m
m.id = 33; // 给id成员赋值
m.sex = 1;
```
* **结构体数组**：定义格式 `struct stu arr[20];`，表示定义长度为20的结构体数组，访问成员的格式为 `arr[i].成员名`，和普通数组用法一致，只是多了成员访问的`.`运算符。
* 🚩考点：考试一般不会要求自己完整写出结构体定义，只需要能读懂代码即可，核心掌握`.`运算符的访问规则。

**二维数组基础**
* **定义规则**：`类型 数组名[行数][列数];`，第一个中括号表示行长度，第二个表示列长度，行下标和列下标都从0开始计数。例如`int b[4][3];`表示定义4行3列的二维数组，总元素数为`4×3=12`，最后一个元素下标为`b[3][2]`。
* **二维数组本质**：本质是「数组的数组」，大数组中嵌套多个小数组，每一个小数组对应二维数组的一行。
* **初始化规则**：
  1. 按行初始化：按行分组赋值，未赋值的元素自动补0。例如`int a[3][4] = {{1,2}, {3}, {4,5,6}};`，第一行剩余两个元素补0，第二行剩余3个元素补0，第三行最后一个元素补0。
  2. 顺序初始化：按行顺序依次填入元素，未赋值元素自动补0。例如`int a[3][4] = {1,2,3,4,5,6};`，第一行为1 2 3 4，第二行前两个为5 6，剩余补0，第三行全补0。
  3. 省略行下标初始化：可以省略第一维（行）的长度，系统会根据初始化元素个数自动推算行数，但**不能省略第二维（列）的长度**。例如`int a[][3] = {1,2,3,4,5,6,7};`，列数固定为3，总共有7个元素，推算得到3行，第三行只有第一个元素为7，剩余两个补0。
* **杨辉三角生成规律**：
  1. 每行第一个元素为1；
  2. 对角线（行下标等于列下标）元素为1；
  3. 中间元素等于「上一行前一列元素」加「上一行当前列元素」，即 `a[i][j] = a[i-1][j-1] + a[i-1][j];`，这个公式是核心考点。
* **求每行最大值考点**：因为每一行对应一个最大值，所以最大值变量`max`必须定义在**行循环内部**，每一行开始遍历前，默认`max`为当前行第一个元素，再遍历后续元素更新最大值，不能把`max`定义在行循环外部。

[01:11:00](https://getnotes.seek:4260) **二维数组定义规则**
二维数组定义两个中括号，第一个中括号是行长度，第二个是列长度，行和列下标都从0开始。例如定义`int b[4][3]`表示4行3列，总元素12个，最后一个元素下标是`b[3][2]`。

[01:13:16](https://getnotes.seek:4396) **二维数组初始化方法**
1. 按行初始化：按行分组赋值，未赋值的元素自动补0。二维数组本质是数组的数组，大数组包含多个行小数组，所以按行分组符合本质。
2. 部分初始化：只给部分元素赋值，剩余元素自动补0，例如第一行给2个元素，剩余两个补0，以此类推。
3. 按存储顺序初始化：将所有元素写在一个大括号内，按行顺序依次填入，未填的元素补0。
4. 省略行下标初始化：可以省略行的长度，系统根据元素个数和列长度推算行数，但是绝对不能省略列的长度，否则无法确定每行有多少元素。

[01:17:35](https://getnotes.seek:4655) **二维数组输入输出**
二维数组输入需要双层for循环，外层循环遍历行，内层循环遍历列，元素是整型，输入时需要加取地址符`&`，输出再双层遍历即可。

[01:18:08](https://getnotes.seek:4688) **经典例题：杨辉三角**
杨辉三角规律：①每行第一个元素是1；②对角线（行下标等于列下标）元素是1；③中间元素等于上一行前一列加上上一行当前列，核心公式`a[i][j] = a[i-1][j-1] + a[i-1][j]`，这个公式是考点。

[01:20:06](https://getnotes.seek:4806) **经典例题：求二维数组每行最大值**
要求每一行的最大值，因此最大值变量必须定义在遍历行的循环内部，每一行开始前，默认最大值为当前行第一个元素，然后遍历该行所有元素更新最大值，不能把max定义在循环外部，否则会所有行共用一个最大值，结果错误。

#### 💡 核心概念
- **数组插入**：找到插入位置 → 从后向前右移元素 → 插入元素 → 长度+1
- **数组删除**：找到删除位置 → 从前向后左移覆盖 → 长度-1
- **字符串**：以`\0`结尾的字符数组，结束标志`\0`的ASCII码为0
- **`strcmp`返回值规则**：`s1 > s2` → 返回值>0；`s1 < s2` → 返回值<0；相等 → 返回0
- **结构体定义**：
```c
struct 类型名 {
    类型 成员名;
    ...
};
```
- **结构体成员访问**：`变量名.成员名`，结构体数组访问：`数组名[下标].成员名`
- **二维数组本质**：数组的数组，每行是一个一维数组，可以省略行下标，不能省略列下标
- **杨辉三角核心公式**：
$$a[i][j] = a[i-1][j-1] + a[i-1][j]$$
