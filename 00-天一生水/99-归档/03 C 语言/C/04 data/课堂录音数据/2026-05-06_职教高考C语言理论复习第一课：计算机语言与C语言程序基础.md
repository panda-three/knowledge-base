#### 知识精讲
本节课为职教高考C语言理论复习开篇课，梳理了计算机语言分类、程序与算法基础、C语言程序结构与运行流程，明确了理论复习的方向与考点。

**计算机语言分类**
* **计算机语言的分类规则**：计算机语言总共分为三类，分别是机器语言、汇编语言、高级语言；其中机器语言和汇编语言统称为**低级语言**，C语言属于高级语言，分类体系中无"中级语言"的划分。
   - 🚩重点：执行效率排序为 `机器语言 > 汇编语言 > 高级语言`，语言层级越低，执行效率越高，该结论为常考排序题考点；**C语言属于高级语言，而非低级/中级语言**是易错考点。
* **各类语言的特点**：
  1. 机器语言：本质是由0和1组成的二进制指令，可以被计算机直接识别和执行，不需要额外翻译，执行效率最高，仅面向机器，人类无法直接阅读。
  2. 汇编语言：为解决机器语言难读难记的缺点诞生，本质是用英文助记符（如`add`表示加法、`move`表示传送）代替二进制指令，可读性优于机器语言，执行速度略低于机器语言。
  3. 高级语言：语法接近自然语言和数学表达式，人类可读性好，通用性强，不需要直接面向机器，编写程序更简单；高级程序必须经过**编译/解释翻译为机器语言**后才能被计算机执行，因此执行效率低于低级语言。

**程序与算法基础**
* **程序的定义**：按照一定语法规则组织、用于完成特定任务的指令序列，即一组有序代码的集合。
* **程序设计的一般步骤**：共分为五步：
  1. 明确需求：即读题，确定要解决的问题、输入输出数据、限制条件
  2. 确定数据结构和算法：确定输入输出的数据形式，选择解题方法
  3. 编写程序：将算法转化为代码
  4. 测试运行：验证程序结果是否正确
  5. 维护修改：修复错误调整逻辑
* **算法的定义**：解决特定问题的方法和步骤，同一个问题可以有多种不同的算法。
* **算法的三种基本结构**：
  1. 顺序结构：代码从上到下依次执行，是默认的执行结构
  2. 分支结构（选择结构）：根据条件选择执行不同分支，对应`if`/`else`/`switch`语句
  3. 循环结构：重复执行指定操作，对应`for`/`while`/`do while`循环

**C语言程序概述**
* **C语言的基础特点**：属于高级程序设计语言，同样支持顺序、分支、循环三种基本结构；职教高考中要求使用的开发环境为Dev-C++。
* **循环控制语句的区别**：
  - `continue`：跳过本次循环，进入下一次循环判断，作用范围最小
  - `break`：结束当前整个循环，继续执行循环外的后续代码
  - `return`：结束整个当前函数，不仅跳出循环，还会终止整个函数的执行，作用范围最大
* **C语言程序的核心规则**：
  1. 一个完整C语言程序由**一个主函数（`main`函数）+ 若干个可选其他函数**组成，**主函数只能有一个**，程序运行一定从`main`函数开始，在`main`函数中结束。
  2. C语言严格区分大小写，建议使用缩进格式编写代码，提高代码可读性。
* **C语言程序的组成结构**：
  1. **注释**：分为两种：`/* ... */`为多行注释，`//`为单行注释；作用是帮助开发者阅读代码，**注释不会参与程序的编译与运行**。
     - 🚩重点：“注释是否参与程序运行”为历年真题填空题考点，分值3分，答案为**不参与**。
  2. **编译预处理命令**：以`#`开头，最常见的是`#include <stdio.h>`：`include`表示包含，`stdio.h`是标准输入输出头文件，要使用`printf`/`scanf`输入输出函数，必须提前引入该头文件。
  3. **`main`函数结构**：
     - 第一行：返回值类型 + 函数名 + 参数：如`int main(void)`，其中`int`表示返回值为整型，`main`是规定的主函数名，`void`表示无参数（可以省略不写），这一部分称为函数头。
     - 大括号包裹的部分称为函数体，内部包含若干执行语句，**每条语句都必须以分号`;`结尾**。
     - `return 0;`表示主函数正常结束，返回值0；如果只写`return;`表示结束函数，不返回任何值。

**C语言程序从编写到运行的步骤**
* 整个流程共分为四个步骤：
  1. **编辑**：编写C语言源代码，源文件扩展名必须为`.c`（不能写为`.cpp`）。
  2. **编译**：检查语法错误，将C源代码翻译为机器语言，生成目标文件，扩展名为`.obj`。
     - 🚩重点：编译完成后生成`.obj`目标文件是历年真题考点，需要牢记。
  3. **连接**：将`.obj`目标文件与系统库连接，生成可执行文件，扩展名为`.exe`。
  4. **运行**：执行生成的`.exe`可执行文件，得到运行结果。
