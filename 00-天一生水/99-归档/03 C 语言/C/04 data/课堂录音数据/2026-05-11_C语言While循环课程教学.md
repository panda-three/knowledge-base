#### 知识精讲

本节课讲解C语言循环结构中while语句的基本语法、执行流程，结合累加、累乘、素数判断等实例，分析while循环的常见易错点与边界问题。

**C语言循环结构基础**
* **循环的作用**：仅用来解决**重复执行代码**的问题，没有重复逻辑不需要使用循环。
* **循环的三要素**：
  1. 循环变量初始值
  2. 循环判断条件
  3. 循环体中循环变量的变化
  🚩重点：如果忘记在循环体中编写变量变化，会导致**死循环**，这是初学者最常见的错误。
* **C语言三种基本结构**：顺序结构、选择结构（已讲：if、switch）、循环结构（本节课内容）。

**while循环基本语法**
* **一般形式**：
```c
while(表达式)
{
    循环体语句;
}
```
* **执行流程**：
  1. 首先判断while后表达式的值：C语言中**非0即为真，0即为假**
  2. 若表达式为真（条件成立），执行循环体语句
  3. 执行完循环体后，回到步骤1重新判断表达式
  4. 直到表达式为0（条件不成立），循环结束
* 🚩重点：while循环的特点是**先判断，后执行**，如果第一次判断条件就不成立，循环体一次也不会执行。

**while循环经典例题分析**
* **边界值分析例题**：分析代码`int i = 1; while(i <= 100) { i++; }`最终i的值
  - 执行过程：i从1开始，每次满足条件就自增，直到i=101时，`101 <= 100`条件不成立，循环停止。
  - 最终结果：`i = 101`
  🚩重点：**循环停止边界是高频考点，也非常容易出错**，如果拿不准结果，一定要手动带入最后几个边界值多次执行验证，不要偷懒。

* **累加问题：计算1~100的和**
  - 思路：利用循环重复执行累加操作，也可直接用等差数列求和公式计算，效率远高于循环。
  - 等差数列求和公式（根据课堂内容推导）：
  $$ S = \frac{(a_1+a_n) \times n}{2} = \frac{(1+100) \times 100}{2} $$
  🚩考点提醒：编程要活学活用，不需要循环的场景不要硬写循环。

* **累乘问题：计算正整数N的阶乘**
  - 阶乘定义：$n! = 1 \times 2 \times 3 \times ... \times n$，属于典型的累乘问题。
  - 代码思路：
    1. 累乘变量初始值必须设为`1`（累加变量初始值为`0`，这是常见区分点）
    2. 循环变量i从1开始，循环条件为`i <= N`
    3. 循环体：`mul = mul * i;`，不能忘记写`i++`修改变量
  - 完整参考代码：
```c
// 求N的阶乘的函数实现
int fact(int n) {
    int mul = 1;
    int i = 1;
    while(i <= n) {
        mul = mul * i;
        i++; // 不能省略，否则会导致死循环
    }
    return mul;
}
```

* **拓展：阶乘和的计算（1! + 2! + ... + n!）**
  - 思路：将累加和累乘结合，外层循环遍历1~n，每次调用阶乘函数，将结果累加至sum变量即可，代码结构清晰易懂。
  - 拓展变形：计算$1!^2 + 2!^2 + ... + 5!^2$只需要修改累加项为`fact(i) * fact(i)`即可，要学会举一反三。
  - 反向累乘实现：也可以从N开始反向累乘到1，逻辑和正向累乘完全一致：
```c
int mul = 1;
while(n > 0) {
    mul = mul * n;
    n--;
}
```

**素数判断的两种while实现**
* **传统标志位写法**：
  1. 定义标志位`flag = 1`，默认N是素数
  2. i从2开始，循环条件`i < N`，每次判断`N % i == 0`
  3. 如果能整除，说明不是素数，修改标志位`flag = 0`，break跳出循环
  4. 循环结束后根据flag输出结果
* **条件内嵌写法（课堂例题写法）**：
  将`N % i != 0`直接作为while循环的判断条件，只要不能整除就继续循环，i自增。循环结束后，如果`i == N`说明没有找到能整除的数，就是素数，否则不是素数。两种写法本质逻辑一致。

**常见易错点总结**
1. 忘记在循环体添加循环变量变化，导致死循环
2. 混淆累加器和累乘器的初始值：🚩累加器初始值为0，累乘器初始值为1
3. 忽略循环边界条件，最终结果多1或少1，一定要手动验证边界

#### 💡 核心概念
- **循环结构**：C语言三种基本结构之一，用于处理需要重复执行的代码逻辑，无重复逻辑不需要使用循环。
- **while循环语法**：
```c
while(表达式) {
    循环体语句;
}
```
- **while执行流程**：判断表达式→非0则执行循环体→回到判断，直到表达式为0结束循环。
- **阶乘定义**：$n! = \prod_{i=1}^{n} i = 1 \times 2 \times ... \times n$
- **等差数列求和公式**：
$$ S_n = \frac{(a_1 + a_n) \times n}{2} $$
