# C语言数据类型与表达式第二课时：转义字符、常量与变量

#### 录音总结

本次是C语言数据类型与表达式第二课时的课程讲解，内容涵盖转义字符、符号常量、变量定义与分类，并配套习题讲解，帮助学习者掌握基础语法规则。

**C语言转义字符讲解**
* **转义字符核心规则**：C语言中，反斜杠加特定字符代表转义字符，一个转义字符整体代表1个字符。例如`\n`代表换行，`\r`代表回车到本行行首，`\0`ASCII码值为0，是字符串结束标识。
* **数字转义字符规则**：`\`加数字代表八进制ASCII码，`\x`加数字代表十六进制ASCII码，二者都可对应到指定字符。
* **字符串长度规则**：字符串`"A"`存储长度为2，包含字符`A`和隐藏的结束标识`\0`；字符串长度仅统计可见字符，不包含`\0`，存储总大小包含`\0`。

**C语言符号常量讲解**
* **符号常量优势**：符号常量采用`#define`定义，具备含义清晰、一改全改的优势，例如定义`PI`代表圆周率，修改值仅需修改头部定义语句。
* **符号常量语法规则**：宏定义不是C语言语句，不需要加分号，加分号会被编译程序识别为符号串的一部分。符号常量值在作用域内不能修改，也不能再次赋值。
* **符号常量命名规则**：习惯上符号常量标识使用大写字母，区分于小写字母命名的变量。

**C语言变量基础概念讲解**
* **变量核心属性**：变量指程序运行中值可发生变化的量，包含四个属性，分别是内存地址、变量名、值、数据类型。
* **变量定义规则**：C语言要求变量必须先定义后使用，定义格式为数据类型加变量名表，多个变量用逗号分隔，定义语句以分号结尾。

**C语言整型变量讲解**
* **整型变量分类**：整型分为基本整型int、短整型short、长整形long三种，默认都是有符号类型，有符号修饰符可以省略；增加无符号unsigned修饰后，取值范围仅包含非负数，范围近似扩大一倍。
* **DEV C++环境存储规则**：基本整型、长整型都占4个字节，对应32位二进制，短整型占2个字节对应16位二进制；有符号基本整型取值范围为`-2^31 ~ 2^31 -1`，无符号为`0 ~ 2^32 -1`。
* **整型变量初始化规则**：允许定义变量同时初始化，例如`int a = 3;`仅给部分变量初始化时，未赋值变量仅完成定义；`int a = 3, b =3, c=3;`是合法写法，`int a,b,c = 3;`仅给c赋值，`int a,b,c=3`不加分号是错误写法，`int a,b,c=3;`写法不会同时给三个变量赋值。

**C语言实型变量讲解**
* **实型变量分类**：实型分为单精度float、双精度double、长双精度三类，DEV C++环境中float占4个字节，double和长双精度占8个字节。
* **有效位数规则**：单精度float有效位数为7位，超过的小数位会被舍去；双精度double有效位数为10位，可存储更长位数的小数。
* **实型变量输出规则**：printf函数中，实型输出使用格式符`%f`，长双精度输出使用`%lf`。

**C语言字符型变量讲解**
* **字符型变量基础规则**：字符型变量用于存放单个字符常量，占1个字节，一个字符变量只能存储1个字符，存放多个字符需要使用数组实现。
* **字符型变量赋值规则**：既可以直接赋值字符，也可以直接赋值对应ASCII码的整数值，因为字符数据以ASCII码存储，存储形式和整型类似，C语言允许字符数据和整型数据通用。
* **大小写转换规则**：小写字母ASCII码比对应大写字母大32，因此小写字母减去32即可转换为对应大写字母，例如小写aASCII码为97，减去32得到65，对应大写A。

**C语言标识符与关键字规则讲解**
* **用户标识符命名规则**：用户标识符必须由字母或下划线开头，由字母、数字、下划线组成；C语言的关键字不能作为用户标识符使用。
* **常见关键字判定**：continue、float、return、for、while都是C语言的关键字，都不能用作变量名。

**课堂习题讲解**
* **常量形式判定题**：八进制常量只能包含0-7的数字，因此`0129`不是合法的八进制整型常量；`'AB'`不满足字符常量只能包含一个字符的要求，不是合法的字符常量。
* **ASCII码计算题**：`\101`是八进制转义，计算得十进制65，对应大写A，ASCII码不是97；`\x41`是十六进制转义，计算得十进制65，也不是97；小写a本身ASCII码为97，因此非97的选项为多个。
* **转义字符判定题**：只有反斜杠、没有后续字符，以及没有反斜杠的单引号都不是合法的转义字符。

**课后任务布置**
* 需要完成进制转换练习题，将八进制数转换为十进制再转换为十六进制。
* 需要对照ASCII码表，完成转义字符对应的字符推算题，以及字符串长度计算题。

本节课是C语言数据类型与表达式的第二课时，承接上一课时的数据类型、常量书写内容。本节课核心学习内容为字符常量中的转义字符，以及变量的定义、初始化和使用方法。引出字符类型中，存在换行、退格等无法直接通过键盘输入的特殊字符，需要转义字符实现。

[00:00:52](https://getnotes.seek:52) **常见转义字符规则讲解**

逐一讲解C语言中常见转义字符的定义与作用：`\n`代表换行，移动到下一行行首；`\r`代表回车，移动到本行行首；`\t`是水平制表符，移动到下一个tab位置；`\0`是空字符，ASCII码值为0，是字符串结束标识；`\'`输出单引号字符，`\"`输出双引号字符，`\?`输出问号字符，`\\`输出反斜杠字符，`\b`代表退格，输出位置后退一位；`\`加数字表示八进制ASCII码，`\x`加数字表示十六进制ASCII码，都可以对应指定字符。一个转义字符整体仅代表一个字符。

[00:02:01](https://getnotes.seek:121) **字符串常量存储规则讲解**

讲解字符串常量的存储规则，以`"A"`为例，存储长度为2，包含字符`A`和隐藏的结束标识`\0`。明确`\0`的ASCII码值为0，不等于字符'0'，字符'0'的ASCII码为48。说明字符串常量不能直接包含双引号和反斜杠，必须加反斜杠转义才能使用。举例说明带转义字符的字符串长度计算，明确字符串长度仅统计可见字符，不包含结束标识`\0`，存储总大小则包含`\0`。

[00:05:00](https://getnotes.seek:300) **转义字符输出实例演示**

通过一个包含多种转义字符的printf输出实例，演示转义字符的输出效果。实例中，`\'`输出1个单引号，`\\`输出1个反斜杠，普通字符原样输出，`\"`输出1个双引号，最终可以得到符合规则的输出结果。再次强调学习者需要牢记转义字符的含义，明确一个转义字符仅代表一个字符。

[00:06:00](https://getnotes.seek:360) **符号常量概念与语法讲解**

引入符号常量，说明符号常量的优势：含义清晰、见名知义，可以实现一改全改，举例说明`PI`代表圆周率就是典型的符号常量。讲解符号常量的定义语法，用`#define`加符号名加常量值定义，习惯上用大写字母命名符号常量。明确宏定义不是C语言语句，定义行不需要加分号，加分号会被编译程序识别为符号串的一部分，导致错误。说明符号常量的值在作用域内不能修改，也不能再次赋值。

[00:07:46](https://getnotes.seek:466) **符号常量使用实例演示**

通过圆球表面积计算的实例演示符号常量的使用：程序开头引入标准输入输出头文件后，通过`#define PI 3.14`定义符号常量，后续计算中直接使用PI参与计算即可。如果需要修改PI的值，仅需要修改头部的定义语句，不需要修改程序中所有用到PI的位置，再次验证了符号常量一改全改的优势。

[00:09:11](https://getnotes.seek:551) **变量基础概念讲解**

讲解变量的基础概念：变量是程序运行过程中值可以发生变化的量，和固定不变的转义字符、符号常量不同。每个变量都有对应的标识符作为变量名，都属于确定的数据类型，在内存中占据对应的存储单元，具备四个核心属性：内存地址、变量名、值、数据类型。类比学校的属性，地址对应内存地址，名称对应变量名，师生对应值，学校类型对应数据类型，帮助学习者理解。

[00:11:04](https://getnotes.seek:664) **变量定义语法讲解**

明确C语言的规则：变量必须先定义后使用，定义格式为数据类型加变量名表，多个变量之间用逗号分隔，定义语句以分号结尾。举例说明常见的变量定义：`int i, j, number`定义了3个整型变量i、j、number；`float a, b, song`定义了3个实型变量a、b、song；`char c, ch`定义了2个字符型变量c、ch，多个变量之间都用逗号分隔。

[00:12:35](https://getnotes.seek:755) **整型变量分类与范围讲解**

讲解整型变量的分类：整型的基础类型为int，可以添加short、long修饰符分为基本整型、短整型、长整型，还可以添加unsigned修饰符分为有符号和无符号类型，默认所有整型都是有符号类型，有符号修饰符可以省略。说明不同类型的存储字节和取值范围：DEV C++环境中，基本整型、长整形都占4个字节即32位二进制，有符号基本整型取值范围为`-2^31 ~ 2^31-1`，无符号类型将符号位用于存储数值，取值范围为`0 ~ 2^32-1`，近似扩大一倍；短整型占2个字节即16位二进制，计算大数阶乘时不能使用短整型，避免溢出。

[00:16:32](https://getnotes.seek:992) **整型变量定义与初始化讲解**

再次强调所有变量必须先定义后使用，该规则是C语言考试填空、改错题型的高频考点。举例说明不同整型变量的定义：`int a, b`定义有符号基本整型变量a、b，`long c`定义长整型变量c，`unsigned int e`定义无符号整型变量e。讲解变量初始化规则：允许在定义变量的同时进行初始化，`int a=3`等价于先定义a再赋值3；`int a, b, c=5`仅给c初始化赋值5；`int a=3, b=3, c=3`可以同时给三个变量赋值3；`int a, b, c=3`不会同时给三个变量赋值，`int a b c=3`省略分号且格式错误，无法通过编译。

[00:20:21](https://getnotes.seek:1221) **实型变量分类与规则讲解**

讲解实型变量的分类：实型用于存储小数，分为单精度float、双精度double、长双精度三类，C语言没有统一规定各类实型的长度、精度和取值范围，DEV C++环境中float占4个字节，double和长双精度占8个字节。举例说明实型变量的定义：`float x, y`定义两个单精度实型变量，`float m=12.8`定义变量同时初始化，`double min`定义双精度实型变量，`long double t`定义长双精度实型变量。说明单精度float有效位数为7位，存储超过7位的小数时，超出部分会被舍去；双精度double有效位数为10位，可以存储更长位数的小数。printf输出实型时，单精度和双精度使用格式符`%f`，长双精度使用`%lf`。

[00:23:33](https://getnotes.seek:1413) **字符型变量基础规则讲解**

讲解字符型变量的作用：字符型变量用于存放单个字符常量，一个字符变量只能存放一个字符，存放多个字符需要后续数组章节讲解的字符串实现。字符型变量占1个字节，定义格式为`char 变量名`，例如`char c1, c2`定义两个字符型变量，每个占1个字节，可以分别存放一个字符；支持定义同时初始化，例如`char c1='a', c2='b'`。说明字符数据以ASCII码存储，存储形式和整型一致，因此C语言允许字符数据和整型数据通用，可以直接给字符型变量赋值ASCII码对应的整数。

[00:25:37](https://getnotes.seek:1537) **大小写转换实例讲解**

通过小写转大写的经典实例演示字符型变量的使用：定义两个字符型变量c1、c2，分别赋值小写a和小写b，然后通过`c1 = c1 - 32`、`c2 = c2 - 32`完成转换。因为小写a的ASCII码为97，减去32得到65，对应大写A；小写bASCII码为98，减去32得到66，对应大写B。输出时，`%c`格式符输出转换后的字符，`%d`格式符输出对应ASCII码，最终可以得到正确的输出结果，验证了转换逻辑的正确性。

[00:30:28](https://getnotes.seek:1828) **标识符与关键字习题讲解**

讲解用户标识符命名规则的习题：用户标识符必须以字母或下划线开头，由字母、数字、下划线组成，关键字不能作为用户标识符，int是关键字，因此不能作为变量名。讲解关键字判定习题：continue、float、return、for都是C语言的关键字，若题目要求选出不是关键字的选项，则题目无正确选项。讲解合法变量名判定习题：while是循环关键字，不能作为合法变量名。总结所有要点，完成多道选择题、填空题的逐题讲解，覆盖常量形式、ASCII码计算、转义字符判定等多个考点。

[00:40:52](https://getnotes.seek:2452) **填空题讲解与课程收尾**

讲解填空题的核心要点：需要记住常用字符的ASCII码：小写a为97，字符0为48，`\0`为0；`\x42`转换为十进制是66，对应大写B；字符常量'A'占1个字节，字符串"A"因为包含隐藏的`\0`，占2个字节；变量分为整型、实型、字符型三类。布置课后任务：要求学习者自行完成进制转换、转义字符对应推算、字符串长度计算等练习题。说明本节课内容讲解完毕，宣布下课。
