# C语言编程题讲解：ASCII码和为素数单词提取排序

## 原始正文

#### 知识精讲
本节课讲解一道C语言字符串处理编程题，涵盖单词提取、ASCII码求和、素数判断、结果存储的完整实现思路，总结提取类题型的通用范式。

**题目要求分析**
* **题目描述**：输入一个由空格分隔、仅含大小写英文字母的字符串，要求：
  1. 计算每个单词所有字母的ASCII码值之和
  2. 筛选出和值为**素数**的单词
  3. 对筛选后的单词排序：先按和值升序排序，和值相同则按单词字典序排序，最后输出结果
* **示例说明**：示例初始化字符串中，共筛选出8个满足条件的单词，排序规则验证：`that`字典序小于`U`开头单词，因此和值相同时`that`排在前面。
  🚩重点：这道题是考试常见题型，只要记住范式就能写对，属于必拿分题。

**函数要求说明**
* **word_search函数定义**：函数接收三个参数，分别是存储结果单词的二维字符数组`words`、存储对应和值的一维整型数组`sami`（避免和求和变量重名）、输入的原始字符串`str`；函数功能为提取符合条件的单词并存储。
* **核心逻辑**：遍历原字符串提取每个单词 → 计算单词所有字符的ASCII码和 → 判断和是否为素数 → 如果是素数，将单词和对应和值分别存入结果数组，同时统计符合条件的单词个数。

**单词提取实现步骤**
* **通用范式**：这道题属于提取类题目，提取逻辑和之前讲过的题型完全一致，代码框架通用。
* **实现流程**：
  1. 外层循环遍历原字符串`str`，遇到非空格字符时，确认是单词的起始位置
  2. 从起始位置继续向后遍历，直到遇到空格或字符串结束，确认是单词的结束位置
  3. 遍历单词的过程中，同步完成两个操作：累加每个字符的ASCII码得到和值，将单词字符暂存到临时字符数组`temp`中
* 🚩重点：临时数组的长度要合理估计，本题单词长度都不超过20，因此定义长度为20即可，不要定义过小导致溢出。

**素数判断实现**
* **实现步骤**：
  1. 定义标志位`flag`，初始值设为1，代表默认当前和是素数
  2. 循环变量`j`从2开始遍历，到小于当前和值结束
  3. 如果当前和值能被`j`整除，说明不是素数，将`flag`设为0，跳出循环
  4. 循环结束后，若`flag`为1，说明和值是素数，进入结果存储步骤。
* 补充说明：素数判断是基础代码，本题只是把之前写过的素数判断代码嵌套进当前逻辑即可。

**结果存储实现**
* **存储要求**：单词存储在二维数组`words`，对应和值存储在一维数组`sami`，二者是一一对应的关系，索引位置相同。
* **实现要点**：
  1. 统计单词个数的计数器`cnt`必须定义在遍历字符串的循环外，初始值为0，不能定义在循环内部
  2. 存储单词前，需要给临时数组`temp`的末尾添加结束符`\0`，否则会出现字符串错误，这个步骤**必须写**，否则运行会出问题
  3. 使用`strcpy`将临时数组的单词复制到`words[cnt]`，将和值存入`sami[cnt]`，存入完成后`cnt`自增，统计个数。
  🚩重点：变量命名冲突是常见坑，求和变量已经叫`sum`，参数数组就不能再叫`sum`，必须改名，否则编译运行都会出错。

**编程技巧总结**
* 提取类题目的代码框架是固定范式，只要记住框架，考试就能得分
* 变量遵循**用到再定义**的原则，不确定位置时，在使用前定义即可，99%的情况都适用
* 写代码先理思路，思路清晰再敲代码，不要盲目敲代码。

#### 💡 核心概念
- **素数判断逻辑**：
```c
int flag = 1; // 1表示是素数
for(int j = 2; j < sum; j++){
    if(sum % j == 0){
        flag = 0;
        break;
    }
}
```
- **单词提取范式**：遍历字符串找非空格确定起始 → 继续遍历找空格/结束确定结尾 → 遍历过程同步处理计算和存储 → 判断条件 → 符合条件则存入结果。
