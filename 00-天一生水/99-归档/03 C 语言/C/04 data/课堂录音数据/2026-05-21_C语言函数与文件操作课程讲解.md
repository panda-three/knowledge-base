#### 知识精讲
本节课讲解C语言中函数的定义、调用、参数传递、嵌套递归、变量作用域，最后补充文件操作基础，覆盖考试常考理论考点与易错点。

**C语言函数基础概念**
* **函数的作用**：和数学函数定义无关，C语言中函数是将一段有特定功能的代码封装，在需要时调用，用于简化代码结构，**提高代码复用性**，避免所有代码都挤在`main`函数中。
* **函数定义语法**：
```c
返回值类型 函数名(形式参数表) {
    函数体;
}
```
  - 第一行称为函数头，花括号内称为函数体
  - 返回值类型决定返回值的类型，`int`对应返回整型，`float`对应返回浮点型；无返回值时写`void`
  - 形式参数（形参）只能是变量声明，不能是常量，多个形参用逗号分隔
* **函数的四种分类**：根据有无参数、有无返回值可分为四类：
  1. 无参无返回值：`void 函数名(void)`或`void 函数名()`
  2. 无参有返回值：`int 函数名()`，必须包含`return`语句返回对应类型的值
  3. 有参无返回值：`void 函数名(参数列表)`
  4. 有参有返回值：`int 函数名(参数列表)`
* 🚩 重点：`return`语句的两个作用：1. 返回指定值给调用者；2. 执行后立即结束整个函数，可出现在函数体任意位置，不一定要放在函数末尾。

**函数调用与声明规则**
* **函数调用要求**：定义后的函数无法自动执行，必须在`main`函数（或其他函数）中调用，调用格式：`函数名(实际参数表)`
* **实参定义**：调用时传入的有具体值的参数称为实际参数（实参），会将值传递给对应形参；可以用变量接收返回值，也可以直接使用返回值（如直接打印）。
* 🚩 重点：函数声明规则
  - 如果函数定义在`main`函数之后，必须在调用前（可在main函数外前侧，或main函数内部）进行函数声明
  - 声明格式就是将函数头抄写一遍后加分号，作用是让编译器在执行到调用语句时能找到函数定义
  - 声明写在main函数内部也不算语法错误。

**形参与实参、参数传递方式**
* **形参和实参的区分**：定义/声明函数时括号内的参数是形参，调用时传入的参数是实参；函数调用时实参将值/地址传递给对应形参，建立关联。
* 🚩 重点：值传递（基本数据类型参数）
  - 特点：只传递实参的值给形参，在函数内部修改形参的值，不会影响原实参的值
  - 示例：将值为5的变量`i`传入函数，函数内修改`i`为6，原变量的值仍然是5
* 🚩 重点：地址传递
  - 传递的是变量/数组的内存地址，函数内修改地址对应的数据，会影响原数据

**函数嵌套与递归调用**
* **嵌套调用定义**：一个函数内部调用另一个函数，调用方式和在main函数中调用完全一致。
* 🚩 重点：嵌套调用分析顺序：从外层调用进入内层，内层执行完后回到外层继续执行，是考试理论题的常考形式，一般出现在第4/5题。
* **递归调用定义**：函数直接或间接调用自身，必须要有明确的结束条件，否则会无限调用导致栈溢出。

**数组作为函数参数**
* 🚩 重点：两种传参情况的区别：
  1. **数组元素作为实参**：和普通变量一样，属于值传递，函数内修改形参不会影响原数组元素的值
  2. **数组名作为实参**：传递的是数组的首地址，属于地址传递，函数内修改数组元素的值会直接影响原数组
* 注意：调用时传递数组名不需要加中括号。

**变量的作用域**
* **局部变量定义**：定义在函数内部或复合语句（大括号包裹的代码块）内部的变量，只在定义它的大括号范围内有效
  - 示例：`while(i>7) { int b = 8; }`，变量`b`只在while的大括号内有效，大括号外使用会报“未声明”错误
  - 🚩 重点：局部变量未初始化时，值是不确定的，每次运行结果可能不同
* **全局变量定义**：定义在所有函数外部的变量，整个程序的所有函数都可以使用
  - 🚩 重点：全局变量未初始化时，默认初始值为0
* 🚩 重点：命名规则就近原则：如果全局变量和局部变量同名，在局部变量的作用域内，优先使用局部变量，离当前位置更近的变量生效。
* **静态局部变量**
  - 定义：局部变量前加`static`关键字修饰就是静态局部变量
  - 🚩 考点：核心特点：函数调用结束后，静态局部变量会保留原来的值，下次调用函数时会沿用上次的值，初始化语句只会执行一次
  - 示例：
```c
void f() {
    static int x = 0;
    x++;
    printf("%d", x);
}
// 连续调用两次f()，输出结果为1 2，如果去掉static输出结果为1 1
```

**C语言文件操作基础**
* **文件指针定义**：操作文件前需要先定义文件指针，格式为`FILE *fp;`
  - 🚩 考点：`FILE`所有字母都是大写，选择题/填空题常考，挖空要求写出`FILE`
* **文件打开与关闭**：
  - 打开：`fp = fopen("文件路径", "打开模式");`，支持相对路径（不带盘符）和绝对路径（带盘符）；`"r"`表示只读，`"w"`表示只写
  - 关闭：操作完成后必须调用`fclose(fp);`关闭文件
* **常用文件操作函数**：
  | 函数类型       | 写入函数       | 读取函数       | 功能说明                 |
  |----------------|----------------|----------------|--------------------------|
  | 字符读写       | `fputc(ch, fp)`| `fgetc(fp)`    | 写入/读取单个字符        |
  | 字符串读写     | `fputs(str, fp)`| `fgets(str, n, fp)` | 写入/读取字符串     |
  | 格式化读写     | `fprintf(fp, 格式字符串, 参数列表)` | `fscanf(fp, 格式字符串, 参数列表)` | 格式化读写文件，用法和`printf/scanf`类似 |
  | 二进制读写     | `fwrite(缓冲区, 单个元素大小, 元素个数, fp)` | `fread(缓冲区, 单个元素大小, 元素个数, fp)` | 读写二进制数据，参数分别表示：要写入/读取的内存地址、单个数据的字节数、要读写的数据个数 |
* **文件定位函数**：
  - `rewind(fp)`：将文件位置指针重新移动到文件开头
  - `fseek(fp, offset, origin)`：按照指定位置移动指针：`offset`为正向后移，为负向前移；`origin`：0从文件开头，1从当前位置，2从文件末尾
* **文件检测函数**：
  - `feof(fp)`：判断文件是否结束，常考用法：`while(!feof(fp)) { ... }`，表示文件未结束时循环读写。

[00:05:35](https://getnotes.seek:335) **函数的定义与作用**

提问：前面讲过什么是函数？和数学中的函数不一样，C语言的函数没有半毛钱关系。C语言中函数是用来封装一段特定功能的程序，需要的时候调用，简化程序结构，提高代码复用性。如果没有函数，所有代码都要放在main函数中，代码会非常拥挤，结构不清晰。

[00:06:50](https://getnotes.seek:410) **函数定义语法讲解**

讲解函数定义的语法：首先写返回值类型名，类型名决定了函数返回值的类型，写int就返回整形，写float就返回float类型；然后写自定义的函数名，后面括号里放形式参数表，定义时括号里的参数叫做形式参数，简称形参，调用时传入的叫做实参；括号后是花括号，函数第一行叫函数头，花括号里叫函数体。

如果函数有返回值，函数体中必须有return语句；如果没有返回值，返回值类型写void。形参只能是变量，不能放常量，多个形参用逗号分隔，格式如`int i, double b`。

[00:09:00](https://getnotes.seek:540) **函数的四种分类**

根据参数和返回值，扩展出函数的四种类型：
1. 无参无返回值：返回值类型写`void`，括号内不放参数
2. 无参有返回值：返回值类型写`int`，必须有return返回int类型的值，括号内不放参数
3. 有参无返回值：返回值类型写`void`，括号内添加形参列表
4. 有参有返回值：返回值写对应类型，括号内添加用逗号分隔的形参列表

[00:10:22](https://getnotes.seek:622) **函数调用规则**

定义完函数不能自动执行，必须在main函数中调用，调用方法为：函数名后加实际参数表，即实参。举例：调用求最大值的`max`函数，定义两个实参`int i=5, b=6`，调用`max(i,b)`，返回值可以用`int z`变量接收，最后打印z就能得到最大值6；也可以不定义变量，直接打印`max(i,b)`，两种写法都正确。

[00:13:13](https://getnotes.seek:793) **return语句的作用**

强调return语句的作用：不仅返回一个值，还会结束整个函数的执行，只要执行到return，整个函数就停止，所以return不一定写在函数最后，可以根据业务逻辑放在任意位置。例如求最大值可以写：`if(i>b) return i; else return b;`，思路清晰。

[00:14:27](https://getnotes.seek:867) **函数声明规则讲解**

如果函数定义在main函数前面，可以直接调用；如果定义在main函数后面，标准C语言要求必须先声明才能调用。声明的方法是：在main函数前（也可以写在main函数内部）抄写一遍函数头，末尾加分号，作用是让编译器从上到下执行时，能找到函数定义，否则找不到函数会报错。两种声明位置都是正确的。

[00:17:20](https://getnotes.seek:1040) **形参和实参的区分**

进入下一部分，讲解函数进阶内容：形参实参、嵌套递归、数组参数、变量作用域。明确概念：定义/声明中的参数叫形参，例如`int max(int x, int y)`中有两个形参`x`和`y`；调用时传入的参数叫实参，函数调用时实参把值传递给对应形参。

[00:18:46](https://getnotes.seek:1126) **值传递特性讲解**

基本数据类型的参数默认是值传递，举例说明：把`i=5, b=6`传入函数，函数内将`i`自增为6，`b`自增为7，返回b的值为7，但是函数外原来的`i`和`b`仍然是5和6，因为值传递只把实参的值复制一份给形参，修改形参不会影响原来的实参。

[00:21:01](https://getnotes.seek:1261) **地址传递特性讲解**

和值传递对应的是地址传递，传递的是内存地址，传递数组时默认就是地址传递。举例：定义数组`int b[3] = {1,2,3}`，把数组名`b`传递给函数，函数内修改`b[0]=2, b[1]=3, b[2]=4`，函数外输出原数组，结果就是2、3、4，因为修改的就是原地址对应的数据，所以原数组会被改变。数组调用时只需要写数组名，不需要加中括号。

[00:23:54](https://getnotes.seek:1434) **函数嵌套调用**

函数嵌套调用就是函数内部调用另外一个函数，不能在一个函数内部定义另一个函数，只能嵌套调用，调用方式和在main函数中调用完全一样。例如`main`函数调用`c`函数，`c`函数内部调用`y`函数，执行时先进入`c`函数，再进入`y`函数，执行完`y`回到`c`，执行完`c`回到`main`。

🚩 重点：函数嵌套是理论题常考内容，通常出现在试卷第4题之后，分值较高，需要重点掌握执行顺序分析。

[00:26:02](https://getnotes.seek:1562) **递归调用**

递归和嵌套的区别：嵌套是调用其他函数，递归是函数自己调用自己，可以直接调用自己，也可以间接调用自己，递归必须要有结束条件，否则会无限递归导致程序崩溃。

[00:26:47](https://getnotes.seek:1607) **数组作为函数参数考点总结**

复习数组做函数参数的规则：
1. 数组元素作为实参：和普通变量一样，属于值传递，函数内修改形参不影响原数组元素
2. 数组名作为实参：传递的是数组首地址，属于地址传递，函数内修改数组元素会直接修改原数组

举例：调用`max(b[0], b[1])`就是传递两个数组元素，属于值传递，修改形参不改变`b[0]`和`b[1]`的值，和普通变量没有区别。

[00:29:42](https://getnotes.seek:1782) **变量作用域引入：局部变量**

重点讲解上次考试考到的静态变量，先讲解局部变量和全局变量：局部变量是定义在函数内部或者复合语句（大括号包裹的代码块）内部的变量，只在定义它的范围内有效。举例子：`main`函数内部定义的`int i=5`是局部变量，因为`main`也是函数，所有函数内部定义的变量都是局部变量；`while(i>7) { int b=8; }`中，`b`定义在while的大括号内部，所以也是局部变量，只在这个大括号里有效，出了大括号再用`b`就会报变量未声明错误。

🚩 重点：局部变量如果没有初始化，它的值是不确定的，每次运行打印结果可能不同。

[00:35:28](https://getnotes.seek:2128) **全局变量定义与特性**

全局变量是定义在所有函数外部的变量，整个程序所有函数都可以使用。🚩 重点：全局变量如果没有初始化，默认初始值是0。

[00:37:46](https://getnotes.seek:2266) **就近原则考点**

如果全局变量和局部变量同名，遵循就近原则：谁离当前位置近，就使用谁。例如全局定义`int a=5`，`main`函数内部定义`int a=6`，在`main`函数里打印`a`输出6；另外一个函数没有定义`a`，打印`a`输出5。

[00:39:27](https://getnotes.seek:2367) **静态局部变量考点**

静态变量的核心特点：静态局部变量在函数调用结束后会保留原来的值，下次调用函数的时候会继续使用上次的值。举例说明：
```c
void f() {
    static int x = 0;
    x++;
    printf("%d ", x);
}
// 主函数中调用两次f()，输出结果是1 2
// 如果去掉static关键字，每次调用x都会重新初始化为0，输出结果是1 1
```
原因：静态变量的初始化语句只执行一次，第一次调用后x保留为1，第二次调用不会再执行`int x=0`，直接在1的基础上加1得到2。

[00:42:53](https://getnotes.seek:2573) **文件操作基础讲解**

快速过一遍文件操作知识点，开学已经讲过，这里复习常考考点：操作文件首先要定义文件指针`FILE *fp;`，填空题常把`FILE`挖空，要求填写，注意`FILE`所有字母都是大写。

打开文件的格式：`fp = fopen(文件路径, 打开方式);`，路径可以写相对路径（不带盘符）或者绝对路径（带盘符）；`"r"`是只读，`"w"`是只写，用完之后要调用`fclose(fp)`关闭文件。

讲解常用读写函数：
1. 字符读写：`fputc`写入字符，`fgetc`读取一个字符
2. 字符串读写：`fputs`写入字符串，`fgets`读取字符串
3. 格式化读写：`fprintf`格式化写入，`fscanf`格式化读取，用法和`printf`、`scanf`基本一致，只是多了第一个文件指针参数
4. 二进制读写：`fwrite`写入二进制数据，`fread`读取二进制数据，参数含义依次是：要读写的数据的内存地址、单个数据的字节大小（如`sizeof(int)`就是4字节）、要读写的数据个数、文件指针。

文件定位函数：`rewind`把文件位置指针重置到文件开头；`fseek`按照指定位置移动指针，偏移量为正向后移，为负向前移，起始位置参数：0从开头，1从当前位置，2从末尾。

文件检测：`feof(fp)`判断文件是否结束，常考写法`while(!feof(fp))`，表示文件没结束就循环读写。

[00:47:52](https://getnotes.seek:2872) **文件操作考题举例**

#### 💡 核心概念
- **函数定义语法**：
```c
返回值类型 函数名(形参列表) {
    函数体;
    [return 返回值;]
}
```
- **值传递**：基本数据类型默认传递方式，只复制实参的值给形参，修改形参不影响原实参
- **地址传递**：传递变量/数组的内存地址，修改地址内的数据会影响原数据，数组名作为参数默认是地址传递
- **嵌套调用**：一个函数内部调用另一个函数，C语言不允许嵌套定义，只允许嵌套调用
- **递归调用**：函数直接或间接调用自身，必须有结束条件
- **局部变量**：定义在函数/复合语句内部，只在当前范围内有效，未初始化值不确定
- **全局变量**：定义在所有函数外部，整个程序可访问，未初始化默认值为0
- **静态局部变量**：`static`修饰的局部变量，函数调用结束后保留原值，初始化只执行一次
