> 结论：数据工程（考点细化 → 题目标注 → 数据流转）是底层基础设施；
## 一、数据工程（怎么生产数据）

### 1. 考点细化
- 目标：考点数据尽可能细
- 动作：根据讲解文档打标签，越细越好
- 参考：一堂 AI 数据第一课·徐剑——
    - 标签映射表
    - 提示词工程
    - 持续训练优化

### 2. 题目标注
- 标注维度（7 维）：
    - 重要性：必考 / 常考 / 偶考
    - 题型：选择 / 填空 / 编程 / 简答
    - 关联考点：该题涉及的知识点编号
    - 解题动作：审题 → 建模 → 计算 → 验证
    - 易错点：学生高频出错的具体位置
    - 相似题：可替换的同类题目 ID
    - 难度：简单 / 中等 / 难 / 很难
- 标注格式：
    - 独立文件：一个题目一个文件
    - 维度标注：每个文件按 7 个维度逐项填写

### 3. 数据流转（完整链路）
1. **预判**：找相似题型 → 大量重复练习
    - 微观：题目搜索
    - 中观：练习 AI 化
    - 宏观：教育 AI 化
2. **识别**：我有啥（事实数据）→ 收获后立刻复盘沉淀
3. **收集**：真题 + 模拟题数据
4. **处理**（两线并行）：
    - 数据工程线：结构化（MD / 表格 / JSON / 标签）→ 切片（按主题做 RAG）→ 计算（代码分析规律）
    - 知识工程线：标注（正例 / 反例 / 场景 / 限制 / 来源）→ 萃取（→ 指南 / 方法论 / 模型）
5. **使用**：
    - 原则：发挥创造力，在高价值场景下用
    - 出口：给 AI 看，问 AI 有没有做得更好
    - 数据形式：多样数据（含错误数据）
6. **反馈**：
    - 每次使用后沉淀可复用数据，闭环增强系统
    - 数据出口反馈到数据工程，形成闭环

## 二、启动步骤

1. 看「一堂 AI 数据第一课」+ 徐剑的分享
   → 目的：建立标签维度、提示词工程、持续优化的底层认知
2. 看和 AI partner 的交流记录
   → 目的：对齐协作方式，明确数据出口
3. 从最小点出发：从一道题开始，找到三道相似题
   → 目的：用最小闭环跑通预判链路
4. 处理当前文件：围绕考点打标，拆成独立文件
   → 目的：把数据工程从设计落到执行
5. 批量打标看效果
	→ 目的：看是否能满足场景？
