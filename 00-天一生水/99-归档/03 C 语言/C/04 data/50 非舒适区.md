# C 语言教学系统 · 学生非舒适区设计完全体

> **核心定义**：非舒适区 = 学生每次练习都在「刚好够不着、但用已有能力能推导」的区间。
> 不是加大题量，不是加快进度，而是**设计练习的形态本身**，让学生无法靠惯性完成。
> 成长都发生在暂时不会的那部分——每一条设计都在制造「暂时不会」。

## 一、难度智能调控：永远让学生够不着

**① 自动爬坡**
- 当前考点正确率 ≥ 80% → 系统自动推送高一级难度
- 当前考点正确率 ≤ 40% → 回退一级，但换题型重新攻
- 原则：永远不让学生在舒适区反复刷已掌握的题

**② 永远 60 分显示**
- 正确率 95% → 系统不说「已掌握」，而说「速度不够，再快 20%」
- 易错点全避 → 系统不说「没犯错」，而说「组合考点还没测」
- 本质：不是打击，是让反馈永远指向「下一次可以更好」

**③ 冷启动挑战**
- 给一道涉及**未学知识点、但解题动作已练过**的题
- 不给讲解，只提示：「用你已掌握的两个动作推导」
- 学生会慌 → 一旦用已有动作推导出来，迁移能力和信心同时拉满
- 示例：没学链表，但练过「画内存图」+「边界测试」→ 给链表遍历题

## 二、任务形态变异：打破做题惯性

**④ 拆解对比模式**
- 学生做完提交 → 系统展示标准解题步骤（你标注的解题动作）→ 逐条对比：
  - 我哪一步漏了？
  - 我哪一步绕了弯路？
  - 标准解法为什么不走我那条路？
- 不是对答案，是对**解题路径**——比判对错难受得多

**⑤ 只给线索，不给题目**
- 系统输出：`考点=指针+内存管理 | 难度=进阶 | 动作=画内存图`
- 学生任务：根据标签**先猜这道题大概长什么样、核心陷阱在哪**，再看原题
- 猜错被题目打脸 → 记忆深度远超直接做题

**⑥ 反向出题模式**
- 学生做完一道题 → 系统不给下一道 →
  > 「这道题的核心考点是『数字进位累积』+『字符三分类』。请你出一道**考点相同、代码结构不同**的变体题。」
- 从做题者变成出题者——认知负荷最高，内化最深

**⑦ 代码审查模式**
- 不是写代码、不是读代码 → 给一段**有 3 个 bug 的代码**：
  > 「找出所有 bug。说明：① 每个 bug 在什么输入下触发 ② 修复方法」
- 做题只要自己跑通 → 审查要从别人的思维里找漏洞，难度翻倍

**⑧ 解释型强制输出**
- 每道题不只选答案 → 加一个必填框：
  > 「用一句话解释：这道题最关键的判断步骤是什么？」
- 能做对、说不清 = 没真懂。暴露出「我以为我懂了」的盲区

## 三、组合与干扰：打破条件反射

**⑨ 错题 + 同动作迁移混编**
- 不再只推送同类错题 → 错题（补弱）+ 同动作陌生考点题（拓新），混在同一组
- 学生会做熟悉考点但动作相同的新题 → 真掌握了动作，不是背题型

**⑩ 交替干扰训练**
- 同一组练习里：考点 A → 考点 B → 考点 A → 考点 C → 考点 B → 考点 A
- 不按类型集中排列 → 学生必须每条在大脑里切换解题模式
- 集中练是舒适区，交替练是考场真实状态

## 四、对比与暴露：制造可量化的差距感

**⑪ 最佳实践对照**
- 做完一道题，不只给答案，还展示：
  > 「全班最快解法：45 秒。你的时间：2 分 30 秒。差距在哪？」
- 不是羞辱 → 是给他一个**真实可追赶的目标**
- 知道差距，才知道往哪发力

**⑫ 知识盲区主动暴露**
- 不推送学生弱点的题 → 先出一道**看起来简单、但精准命中他盲区**的题
- 他以为会做 → 做错了 → 系统弹出：
  > 「这个考点你在『2026-75』已经错过一次。这是你的盲区。」
- 先犯错再告知 → 比提前提醒深刻十倍

## 五、边界加压：在极限处撕开成长空间

**⑬ 时间压力**
- 程序阅读题限时 = 真实考试时间的 80%
- 不是刁难 → 逼学生不能慢慢磨，练到「又快又准」
- 限时完成率纳入永久记录，持续追踪

**⑭ 上限挑战模式**
- 每次练习组末尾加一道**跨 2–3 个考点 + 高一级难度**的挑战题
- 做不出来没关系，但每次都被逼着跳一跳
- 长期效果：学生不再惧怕「没见过的题」

---

> **设计原则**：非舒适区的尽头不是让学生难受，而是让学生每次练习后都感到——「我今天够到了昨天够不到的东西。」
>
> **老师的心法**：这十四条不是一次全部上线。选 2–3 条先跑一个班，观察学生反应，迭代后再扩展。非舒适区本身，也要在非舒适区里迭代。
