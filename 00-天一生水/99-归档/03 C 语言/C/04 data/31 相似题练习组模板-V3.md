# 相似题练习组模板

> 核心判断：练习题组的本质是把"老师挑题"的判断逻辑翻译成标签+规则。 三道题按同构 → 变式 → 迁移的顺序排， 不是为了让学生"做更多题"，而是让学生从"认识这道题"变成"认识这类题"。

## 一、使用定位

📍 这个模板用于从一道起点题出发，在历年真题中搜索至少 3 道相似题，生成一个练习题组。

|场景|触发条件|产出|
|---|---|---|
|学生做完一道题错了|起点题有 V3 题目卡|立刻生成练习组，三题按序推送|
|提前建题库|重要题已打完标签|预生成练习组，学生需要时直接取用|
|验证标签质量|标签刚打完还没验证|生成一个练习组，看推荐是否合理|
|**不在练习组中写完整学生版讲解。** 练习组只负责选题和排序。讲解是另一个环节的事。|||

## 二、三道题的设计逻辑

|顺序|类型|相似度|学生感受|设计目标|
|---|---|---|---|---|
|第一题|同构题|8–9 分|"和刚才那道几乎一样"|巩固解题动作，建立信心|
|第二题|变式题|6–7 分|"有点像，但要稍微想一下"|考点迁移，测试是否真懂|
|第三题|迁移题|4–5 分|"表面不像，但思路一样"|跨题型内化，检验动作是否稳定|

> 💡 顺序不可颠倒。如果第一题就是迁移题，学生会觉得"每道都是新题"，形不成练习路径。 如果三道都是同构题，学生会觉得"都一样"，进入舒适区。

## 三、相似度打分规则

|条件|分值|为什么是这个权重|
|---|---|---|
|题型相同|+1|外壳，不是核心|
|**答案相关考点相同**|**+3**|考点是匹配的灵魂|
|**解题动作相同**|**+3**|动作是迁移的关键|
|易错点相同|+1|微调|
|难度接近|+1|微调|
|分数|级别|用途|
|---|---|---|
|8–9|高相似|第一题·同构|
|6–7|中相似|第二题·变式|
|4–5|迁移练习|第三题·迁移|

> ⚡ 答案相关考点 +3 + 解题动作 +3 = 6 分。这两项对了至少是中相似。推荐不准时优先查这两项标签。 ⚡ 低于 4 分不纳入练习组——相似度太低，学生感受不到关联，失去练习路径的意义。
