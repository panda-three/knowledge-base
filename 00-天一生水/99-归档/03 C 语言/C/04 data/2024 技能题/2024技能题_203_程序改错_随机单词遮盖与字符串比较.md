题目：为了测试学生对英文单词的掌握程度，程序在给出的五个单词中随机

输入：function
显示：Right!
另一次程序运行结果如下：
显示：The word is: i*clud* ,  Please input correct word:

------------------------------------------------------------------------
注意：不得增行或删行，不得更改程序的结构
----------------------------------------------------------------------*/
#include <stdio.h>
#include <string.h>
#include <stdlib.h>
#include <time.h>

int funtest(char cp[][20],int i)
{
    int ix=0,iy=0,ik=0;
    char ca[20]={0},cb[20]={0};
    strcpy(ca,cp[i]);
    ik=strlen(ca);
    ix=rand()%ik;
    iy=rand()%ik;
/***********FOUND***********/
    if(ix!=iy)
        iy=rand()%ik;
    ca[ix]='*';
    ca[iy]='*';
    printf("The word is:%s,  ",ca);
    printf("Please input correct word:");
    gets(cb);
/***********FOUND***********/
    if(cb==cp[i])
        return 1;
    else
        return 0;
}
int main(void)
{
    char cs[5][20]={"beautiful","student","China","function","include"};
    int i,ik;
    srand(time(0));
    i=rand()%5;
/***********FOUND***********/
    funtest(i,cs[][50]);
    if(ik==1)
        printf("Right! \n");
    else
        printf("Wrong! The word is:%s\n",cs[i]);
    return 0;
}

## 二、标签

- 重要性：重要
- 题型：程序改错题（随机单词遮盖与字符串比较）
- 答案相关考点：
    - 保证两个遮盖位置不同。
    - 用 strcmp 比较输入单词。
    - 接收 funtest 返回值。
- 解题动作：
    - 随机选中单词并复制。
    - 生成两个不同随机位置。
    - 用星号替换两个字符。
    - 读取学生输入并和正确单词比较。
    - 保存函数返回结果。
- 易错点：
    - if 不能保证重新生成到不同位置。
    - 用 == 比较字符串内容。
    - 函数调用实参顺序和形式错误。
