# 2024 技能真题 · 119 · 数字子串解析与因子和整数对

## 一、题目内容

- 题号：119
- 题型：编程题（函数设计题）
- 题干：下列程序将字符串中数字字符子串转换为整数，不考虑正负号，然后找出其中的最小数和最大数之间，满足下列条件的整数对 `(m,n)`：
    1. `m` 小于 `n`。
    2. `f(m)=f(n)=m+n+1`，其中 `f(m)` 表示 `m` 的所有因子和（包括 1 和 `m`），`f(n)` 表示 `n` 的所有因子和（包括 1 和 `n`）。

例如：`f(48)=1+2+3+4+6+8+12+16+24+48=124`，`f(75)=1+3+5+15+25+75=124`，`48+75+1=124`，因此 `(48,75)` 是满足条件的整数对。

- 测试数据：

```text
ASDB3yH15JIANG112SU*@#5+eH89rTR200HY117
```

- 程序运行结果：

```text
M=3,N=200
(48,75)
(140,195)
```

- 代码：

```c
#include <stdio.h>
#include <stdlib.h>
#include <math.h>
#include <ctype.h>

void abstract(char str[],int b[])
{
/**********Program**********/




/**********  End  **********/
}

int fun(int m,int n,int a[][2])
{
/**********Program**********/




/**********  End  **********/
}

int main(void)
{
    char str[]={"ASDB3yH15JIANG112SU*@#5+eH89rTR200HY117"};
    int i,num=0,m,n,b[100],a[100][2];
    FILE *fp;
    if((fp=fopen("DATA.dat","w"))==NULL)
    {
        printf("File open error\n");
        exit(0);
    }
    abstract(str,b);
    m=b[0];
    n=b[1];
    printf("M=%d,N=%d\n",m,n);
    fprintf(fp,"m=%d,n=%d\n",m,n);
    num=fun(m,n,a);
    for(i=0;i<num;i++)
    {
        printf("(%d,%d)\n",a[i][0],a[i][1]);
        fprintf(fp,"(%d,%d)\n",a[i][0],a[i][1]);
    }
    fclose(fp);
    return 0;
}
```

- 作答要求：
    - 编写函数 `void abstract(char str[],int b[])`，将字符串 `str` 中的数字字符子串转换为整数，并将最小数和最大数分别存入 `b[0]` 和 `b[1]` 中。
    - 编写函数 `int fun(int m,int n,int a[][2])`，在 `[m,n]` 中查找满足上述条件的整数对保存到 `a` 数组中，函数返回找到的整数对个数。

- 参考答案：

```c
int i,k,sum,max,min;
i=k=0;
while(str[i])
{
    if(isdigit(str[i]))
    {
        sum=0;
        while(isdigit(str[i]))
            sum=sum*10+str[i++]-48;
        b[k++]=sum;
    }
    else
        i++;
}
max=min=b[0];
for(i=0;i<k;i++)
{
    if(max<b[i])
        max=b[i];
    if(min>b[i])
        min=b[i];
}
b[0]=min;
b[1]=max;
```

```c
int i,j,k,num=0,s1,s2;
for(i=m;i<=n;i++)
{
    s1=0;
    for(j=1;j<=i;j++)
        if(i%j==0)
            s1=s1+j;
    for(j=i;j<=n;j++)
    {
        s2=0;
        for(k=1;k<=j;k++)
            if(j%k==0)
                s2=s2+k;
        if(s1==s2&&s1==i+j+1)
        {
            a[num][0]=i;
            a[num++][1]=j;
        }
    }
}
return num;
```

## 二、标签

- 重要性：重要；拆解题
- 题型：编程题（字符串处理 + 区间穷举筛选）
- 答案相关考点：
    - 连续数字字符子串解析：遇到数字字符后，用 `sum=sum*10+str[i]-48` 把连续数字合成为整数。
    - 数组最值提取：将解析出的数字存入数组后，求最小值和最大值并回写到 `b[0]`、`b[1]`。
    - 因子和枚举与整数对筛选：枚举区间内整数对，分别求因子和，再判断 `s1==s2&&s1==i+j+1`。
- 解题动作：
    - 遍历字符串并用 `isdigit` 判断是否进入数字子串。
    - 累积连续数字字符，形成完整整数。
    - 保存解析出的整数并记录有效个数。
    - 用第一个有效数字初始化最大值和最小值。
    - 遍历数组，更新 `max` 和 `min`。
    - 双重循环枚举区间内的整数对。
    - 枚举 1 到本身，累加能整除当前数的所有因子。
    - 判断因子和相等且等于 `i+j+1` 后保存结果并计数。
- 易错点：
    - 只把单个数字字符转成数字，忘记连续数字子串要合并成整数。
    - 内层 `while(isdigit(str[i]))` 中下标推进处理错，导致漏读或死循环。
    - 最值初始化随意设为 0，遇到数据范围变化时出错。
    - 因子和漏加 1 或漏加数字本身。
    - 双重循环边界写错，不能保证 `m<n` 的整数对关系。
    - 找到结果后没有正确写入二维数组并更新 `num`。
