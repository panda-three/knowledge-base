/*----------------------------------------------------------------------
【程序改错】
------------------------------------------------------------------------
题目：下列程序的功能是：将一组指数形式表示的实数字符串，转化为用十进
      制形式表示的实数。

例如：这组指数形式表示的实数字符串为"12.123e-3,-0.015e+5,3.141e+2,-0.618e-2"，
      则程序运行结果如下：

   12.123e-3 ---->0.012123
   -0.015e5 ---->-1500
   3.141e2 ---->314.1
   -0.618e-2 ---->-0.00618
------------------------------------------------------------------------
注意：不得增行或删行，不得更改程序的结构
----------------------------------------------------------------------*/
#include <stdio.h>
#include <ctype.h>
#include <math.h>

#define M 3

void change(double nums[][M],int length)
{
    int i,j;
    double base,num;
    for( i=0;i<length;i++)
    {
        base=10,num=nums[i][0];
        if(nums[i][1]<0)
            base=0.1;
/***********FOUND***********/
        for(j=1;j<nums[i][1];j++)
            num=num*base;
        nums[i][2]=num;
    }
}
int ext_num(char str[],double nums[][M])
{
    int i,len=0,sign,j;
    char temp[80];
    for(i=0;str[i];i++)
        if(isdigit(str[i]))
        {
            sign=1;
            j=0;
            if(str[i-1]=='-')
                sign=-1;
            while(isdigit(str[i])||str[i]=='.')
            /***********FOUND***********/
                temp[i]=str[j];
            temp[j]=0;
            nums[len/2][len%2]=sign*atof(temp);//atof(temp)的功能：将字符串temp转换为一个浮点数
            len++;
            i--;
        }
     return len/2;
}
int main(void)
{
    char num_table[]="12.123e-3,-0.015e+5,3.141e+2,-0.618e-2";
    double nums[4][M];
    int i,length;
/***********FOUND***********/
    ext_num(num_table[],nums[4][M]);
    change(nums,length);
    for(i=0;i<length;i++)
        printf("%10.3lfe%-2.0lf---->%g\n",nums[i][0],nums[i][1],nums[i][2]);
    return 0;
}
