## 二、标签

- 重要性：常考
- 题型：程序填空题（平均值计算与大于平均值筛选）
- 答案相关考点：
    - 累加时直接除以 N 求平均。
    - 筛选大于平均值元素并追加。
    - 用 -1 作为结果数组结束标记。
- 解题动作：
    - 遍历 x 数组累加平均值。
    - 判断 x[i] 是否大于平均值。
    - 把符合条件的元素写入 y[j] 并自增。
    - 写入哨兵值结束输出。
- 易错点：
    - 忘记除以 N 得到的是总和。
    - 筛选后没有 j++ 导致覆盖。
    - 不理解 y[j]=-1 是输出终止标记。
- 相似题搜索标签：`平均值` `数组筛选` `j++` `哨兵` `大于平均值`
