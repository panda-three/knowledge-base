题目：一维整型数组各元素已升序排列。如果补上一个值，则数组中所有元素值将连续。

例如：{0,1,3,4,5,6},如果补上2，则使数组中各元素值连续。
      {-47,-46,-45,-44,-43,-41,-40},如果补上-42，则使数组中各元素值连续。

函数void find(int a[])功能是在数组a中找出这个值。

程序运行结果如下：
2
-42
------------------------------------------------------------------------
注意：在填空标志处填写答案，并删除填空标志，勿改动程序中的其他部分。
----------------------------------------------------------------------*/
#include <stdio.h>

#define N 7

void find(int a[],int n)
{
    int lft,rgt,mid;
    lft=0;rgt=n-1;
    while(lft<=rgt)
    {
/***********FOUND***********/
        mid=(rgt-lft)/2;
/***********FOUND***********/
        if(mid==a[mid])
            lft=mid+1;
        else
            rgt=mid-1;
    }
/***********FOUND***********/
    printf("%d\n",a[lft]);
}
int main(void)
{
    int a[2][N]={{0,1,3,4,5,6},{-47,-46,-45,-44,-43,-41,-40}};
    int i;
    for(i=0;i<2;++i)
        find(a[i],i+6);
    return 0;
}

## 二、标签

- 重要性：重要
- 题型：程序改错题（升序数组缺失值二分查找）
- 答案相关考点：
    - 计算带左边界的 mid。
    - 用 a[0]+mid 判断是否连续。
    - 输出断点处缺失值。
- 解题动作：
    - 根据 lft 和 rgt 计算中点。
    - 比较 a[mid] 与理论连续值。
    - 移动左右边界定位第一个异常位置。
    - 由相邻元素推出缺失值。
- 易错点：
    - mid 漏加 lft。
    - 只适用于从 0 开始的数组。
    - 直接输出 a[lft] 而不是缺失值。
