# 2024 技能真题 · 117 · 回文单词扫描与二维字符串输出

## 一、题目内容

- 题号：117
- 题型：程序改错题（3 处错误）
- 题干：下列程序中函数 `wordsearch` 返回 `a` 数组中回文单词的个数。回文单词是指：一个单词自左向右读与自右向左读字母相同，字母不区分大小写。例如，`Dad` 是回文单词。

- 程序运行结果：

```text
Dad left home at noon.
发现 2 个回文单词：
Dad
noon
```

- 代码：

```c
#include <stdio.h>
#include <ctype.h>
#include <string.h>

int wordsearch( char a[] , char b[][10] )
{
    int i,k,m,n,t,c=0,d;
    for(i=0;a[i];i++)
    {
        if(isalpha(a[i]))
        {
            for(k=i;isalpha(a[k]);k++) ;
            m=i;
            n=k-1;
            while(toupper(a[m])==toupper(a[n])&&m<n)
            {
                m++; n--;
            }
        /***********FOUND***********/
            if(m==n)
            {
                for(d=0,t=i;t<k; t++)
                    b[c][d++]=a[t];
                b[c][d]='\0';
                c++;
            }
       /***********FOUND***********/
            i++;
        }
    }
    return c ;
}
int main(void)
{
    char s1[]=" Dad left  home at   noon.  " ;
    char s2[10][10] ;
    int i,j;
    puts(s1);
    j=wordsearch(s1,s2);
    printf("发现 %d 个回文单词：\n",j);
    for(i=0;i<j;i++)
    /***********FOUND***********/
        puts(s2);
    return 0;
}
```

- 作答要求：不得增行或删行，不得更改程序的结构。

- 参考答案：
    - 错误 1：`if(m==n)` 改为 `if(m>=n)`（或 `if(n<=m)`）
    - 错误 2：`i++` 改为 `i=k`（或 `i+=k-i`）
    - 错误 3：`puts(s2);` 改为 `puts(s2[i]);`（或 `puts(s2+i)`、`puts(i+s2)`、`puts(i[s2])`）

## 二、标签

- 重要性：重要
- 题型：程序改错题（字符串处理 + 二维字符数组输出）
- 答案相关考点：
    - 回文字符串双指针判断：奇数长度回文最终 `m==n`，偶数长度回文最终可能 `m>n`，所以应判断 `m>=n`。
    - 单词边界扫描与外层下标跳转：识别完一个单词后，应让 `i` 跳到 `k`，避免重复扫描单词内部字符。
    - 二维字符数组按行输出字符串：`s2` 是二维字符数组，输出第 `i` 个字符串应写 `s2[i]`。
- 解题动作：
    - 用 `isalpha` 定位当前单词的起点和终点。
    - 用 `m`、`n` 从单词两端向中间比较字符。
    - 用 `toupper` 消除大小写差异。
    - 判断双指针交错或相遇都表示回文成立。
    - 将回文单词复制到 `b[c]` 并补 `\0`。
    - 将外层循环下标跳到当前单词末尾。
    - 按下标输出二维字符数组中的第 `i` 行字符串。
- 易错点：
    - 只用 `m==n` 判断回文，导致偶数长度回文被误判。
    - 单词处理完只写 `i++`，同一单词内部字符会被重复扫描。
    - 把二维数组名 `s2` 直接传给 `puts`，没有指定输出哪一行。
    - 不理解 `toupper` 是为了满足“不区分大小写”的题干要求。
- 相似题搜索标签：`回文判断` `双指针` `isalpha` `toupper` `字符串遍历` `二维字符数组` `puts` `循环下标跳转`
- 难度：⭐⭐⭐
