# 2024 技能真题 · 114 · 带符号整数解析与平衡三进制转换

## 一、题目内容

- 题号：114
- 题型：编程题（函数设计题）
- 题干：将字符串中带符号整数转换成平衡三进制数 `b3`。

十进制数转换为平衡三进制数的方法：先将十进制数转换为三进制数，如 `210(10)=21210(3)`，然后从低位向高位逐位处理（处理每一位时需考虑低位的进位）：

- 若为 1 或 0，则保持不变。
- 若为 2，则替换为 `Z`，并向高位进位，即高位 `+1`。
- 若为 3（原来的 2 得到进位会变成 3），则替换为 `0`，并向高位进位，即高位 `+1`。

例如：`210(10)=21210(3)=10ZZ10(b3)`。

正整数的平衡三进制中的 `Z` 变成 `1`，`1` 变成 `Z`，即可得到对应负整数的平衡三进制。

```text
 210(10)=10ZZ10(b3)
-210(10)=Z011Z0(b3)
```

- 程序运行结果：

```text
4       -5      0       64      237     -237

4       11
-5      Z11
0       0
64      1Z101
237     100Z10
-237    Z001Z0
```

    - 编写函数 `int find(char s[],int d[])`，将字符数组 `s` 中的数字子串（带符号）转变成十进制整数存放在整型数组 `d` 中，函数返回整数的个数。

int i=0,len=0,t=0,f=1;
if(n<0) n=-n,f=-1;
do{
    b3[len]=n%3+48+t;
    if(b3[len]=='2')
        b3[len]='Z',t=1;

for(i=0;i<len/2;i++)

## 二、标签

- 重要性：重要；拆解题
- 题型：编程题（字符串解析 + 进制转换）
- 答案相关考点：
    - 带符号连续数字子串解析：识别数字子串前一位是否为 `'-'`，并用 `num=num*10+s[i]-48` 合成整数。
    - 平衡三进制低位到高位进位转换：普通三进制位为 2 时写 `Z` 并进位，为 3 时写 `0` 并继续进位。
    - 负数平衡三进制符号转换：正数结果中 `1` 与 `Z` 互换，得到对应负数表示。
- 解题动作：
    - 遍历字符串并用 `isdigit` 定位数字子串。
    - 向前检查数字子串前是否有负号。
    - 将连续数字字符累积为十进制整数并乘以符号。
    - 对整数反复取 `%3` 得到低位三进制位。
    - 结合低位进位 `t` 判断当前位写 `0`、`1` 或 `Z`。
    - 在最高位仍有进位时继续生成新位。
    - 反转低位优先生成的字符串。
    - 对负数结果执行 `1` 和 `Z` 的互换。
- 易错点：
    - 只解析无符号数字，漏看数字子串前面的 `'-'`。
    - 连续数字子串没有合并，导致 `237` 被拆成 `2、3、7`。
    - 平衡三进制中遇到 2 只改成 `Z`，忘记向高位进位。
    - 遇到 3 时没有写成 `0` 并继续进位。
    - 低位优先生成后忘记反转字符串。
    - 负数只加负号，忘记平衡三进制应把 `1` 和 `Z` 互换。
