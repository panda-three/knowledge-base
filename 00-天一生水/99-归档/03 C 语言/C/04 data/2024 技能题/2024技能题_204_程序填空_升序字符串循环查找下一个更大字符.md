## 二、标签

- 重要性：重要
- 题型：程序填空题（升序字符串循环查找下一个更大字符）
- 答案相关考点：
    - 顺序查找第一个大于 ch 的字符。
    - 用 i%len 处理越界回绕。
    - 调用 find 输出映射结果。
- 解题动作：
    - 遍历升序字符串直到找到更大字符。
    - 判断查找到末尾时回到 base[0]。
    - 用取模把下标限制在字符串长度内。
    - 在 main 中传入 base 和当前 tag 字符。
- 易错点：
    - 没有处理 ch 大于所有字符时回绕。
    - 把 i 直接作为下标导致越界。
    - 函数调用漏传参数。
