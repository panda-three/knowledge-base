# 2024 技能真题 · 114 · 身份证校验取余与字符转换

## 一、题目内容

- 题号：114
- 题型：程序填空题（2 空）
- 题干：程序采用以下步骤验证身份证号是否正确：
    1. 身份证号码前 17 位分别乘 `q[]` 中 17 位系数，并相加。
    2. 计算结果模 11 得余数。
    3. 余数和身份证号第 18 位数字相同，则身份证号正确，否则不正确。
    4. 注：余数为 10，对应身份证号第 18 位的字符 `X`。

- 程序运行结果：

```text
320125198711060020 error.
14010219700213604X OK.
340222196310093040 OK.
340222196303101242 error.
```

- 代码：

```c
#include <stdio.h>

#define N 4

int q[17]={7,9,10,5,8,4,2,1,6,3,7,9,10,5,8,4,2};
int js(char sfz[])
{
    int i,s=0;
    for(i=0;i<17;i++)
        s+=(sfz[i]-48)*q[i];
/**************************SPACE******************************/
    【?】;
}
int main(void)
{
    char sfz[N][20]={"320125198711060020","14010219700213604X",
                     "340222196310093040","340222196303101242"};
    int i,num;
    for(i=0; i<N; i++)
    {
        num=js(sfz[i]);
/**************************SPACE******************************/
        num=num==10?'X':【?】;
        if(sfz[i][17]==num)
            printf("%s OK.\n",sfz[i]);
        else
            printf("%s error.\n",sfz[i]);
    }
    return 0;
}
```

- 作答要求：在填空标志处填写答案，并删除填空标志，勿改动程序中的其他部分。

- 参考答案：
    - 空 1：`return s%11`（或 `return s=s%11`、`return s%=11`、`return(s%11)`、`return(s%=11)`）
    - 空 2：`num+48`（或 `48+num`、`num+'0'`、`'0'+num` 等）

## 二、标签

- 重要性：重要
- 题型：程序填空题（表达式补全 + 返回语句补全）
- 答案相关考点：
    - 取余运算返回校验位：`js` 函数必须返回加权和对 11 取余的结果。
    - 数字字符与数值之间的 ASCII 转换：前 17 位用 `sfz[i]-48` 转数值，第 18 位比较前要把 0–9 余数转回字符。
    - 条件运算符处理特殊校验位：余数为 10 时转换为字符 `'X'`，否则转换为数字字符。
- 解题动作：
    - 追踪 `js` 函数中 `s` 的加权累加含义。
    - 判断题干“模 11 得余数”对应代码应写 `return s%11`。
    - 判断 `num==10` 时应返回字符 `'X'`。
    - 将 0–9 的数值余数转换为对应数字字符。
    - 对比 `sfz[i][17]` 和 `num`，确认两边都必须是字符值。
- 易错点：
    - 只写 `s%11`，忘记函数必须 `return`。
    - 把取余写成除法，误写 `s/11`。
    - 直接用数值 `num` 和字符 `'0'`–`'9'` 比较，漏加 `48` 或 `'0'`。
    - 把字符 `'X'` 写成字符串 `"X"`。
- 相似题搜索标签：`取余运算` `return` `ASCII码` `数字字符转数值` `数值转数字字符` `条件运算符`
- 难度：⭐⭐⭐
