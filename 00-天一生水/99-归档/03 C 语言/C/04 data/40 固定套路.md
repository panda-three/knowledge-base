# C 语言题目标注系统 · 固定套路完全体

> **核心定义**：套路文档 = 标签体系 + 打标流程 + 匹配规则 + 校验标准 + 迭代记录
> 它不是你打标模板本身，而是**怎么打标、怎么匹配、怎么让它越用越聪明**的完整方法。

## 一、标签体系：七个不变字段

- **重要性**：重要 / 普通
- **题型**：程序阅读题 / 选择题 / 填空题 / 编程题 / 改错题
- **答案相关考点**：1–3 个，只标「做出这道题必须用到的」考点
- **解题动作**：动词开头，使用统一词表（画内存图 / 代入法 / 排除法 / 边界测试法…）
- **易错点**：能反向生成练习题的才算有效，不是泛泛的「粗心」「不仔细」
- **相似题搜索标签**：从考点 + 解题动作反推，用反引号包裹，空格分隔
- **难度**：基于学生实际错误率校准，非个人感觉

## 二、打标流程：每道题照此六步

1. **判断使用者**：学生拿到这道题需要什么信息才能练到位？
2. **拆考点**：只标答案相关的 1–3 个，不列「题目里出现了但不需要用」的知识点
3. **拆动作**：动词开头，从统一词表里选，不临时造词
4. **预判易错点**：每个易错点必须能反向出一道练习题，否则删除
5. **打相似题标签**：从考点 + 动作反推关键词，用反引号包裹
6. **过质量检查清单**：六项逐条打勾，不过不归档

## 三、匹配规则：四种模式找相似题

- **模式 A · 同考点强化**：锁定一个考点 → 拉出所有含该考点的题 → 按难度从低到高排列
- **模式 B · 易错点专项**：锁定一个易错点 → 拉出所有含该易错点的题 → 集中轰炸薄弱环节
- **模式 C · 综合组卷**：指定考点 + 题型 + 难度区间 → 多维度交叉匹配
- **模式 D · 同动作迁移**：解题动作重叠 ≥ 2 个 → 考点可完全不同
  - 价值：学生遇到陌生考点时，能靠已练过的解题动作推导
  - 示例：`画内存图` → 跨指针、数组、结构体、链表四类题

> **筛选优先级**：考点重叠 + 动作重叠 > 仅动作重叠 > 仅考点重叠

## 四、校验与反馈：三层回流让题库越用越聪明

**第一层 · 错题回流**
- 学生标记错题 → 自动打「高频错题」标签 → 下次组卷优先抽取
- 同一道题被 ≥ 3 个学生标记为错 → 升级为「教学重点题」

**第二层 · 难度校准**
- 正确率 ≥ 90% 但你标「中等」→ 实际是基础题，下调难度
- 正确率 ≤ 30% 但你标「基础」→ 上调难度，同时检查标签是否漏了考点

**第三层 · 标签修正**
- 学生实际错因 vs 你标的易错点不一致 → 补标签
- 学生反馈「这两道题根本不像」→ 修正相似题搜索标签

> **本质**：不是评卷，是让题库每被用一次就校准一次。

## 五、标注质量保障：内外双循环

**内循环 · 自校准（每季度一次）**
- 随机抽 10 道已标注的题 → 不看原标签，重标一遍
- 对比两份标签 → 不一致处 = 标注体系里的「不稳定点」
- 补规则、补词表、补边界判断

**外循环 · 标注思路外显（每道题加一行）**
- `标注思路：（一句话，为什么这样标）`
- 对你：三个月后回看能理解当初判断
- 对学生：是教学材料
- 对体系：是判断锚点

## 六、进阶扩展：从题库到教学操作系统

**知识前序依赖链**
- 标注 `知识前序`：这道题假设学生已掌握什么
- 学生做错 → 先查前序知识是否塌了 → 塌了补基础，不盲目刷同款

**错误模式库**
- 每个错误做法 → 映射到认知误区，不止标「错了什么」，更标「为什么这样错」
- 例：`sum = 1+2+3+4 = 10` → 不是粗心 → 脑子里只有累加模型，没建立进位概念

**题目演化链**
- 标注 `可演化维度`：数据类型换掉 / 字符串换掉 / 判断条件微调 / 嵌套一层
- 核心结构不变，生出变体 → 不需等新真题，自己就是题目生成器

**师生标注对比**
- 学生做完题也标：错在哪步、当时怎么想的、觉得难在哪
- 老师标的易错点 vs 学生自述错误原因 → 不一致处 = 教学盲区

**解题动作迁移地图**
- `画内存图` → 指针、数组、结构体、链表、函数调用栈
- `代入法` → 循环、递归、宏展开
- `边界测试法` → 数组越界、字符串终止、整数溢出

**标注语料的 AI 训练价值**
- 几百道题 × 每道 15–20 个标签字段 = 上万行结构化教学语料
- 未来喂给 AI：自动出题、自动批改、自动诊断

## 七、终局：领域级专业系统

- 新老师上手，不需攒三年经验 → 直接用标签体系
- 任何新题扔进来 → 自动归位、自动匹配、自动诊断
- 你的教学判断不再锁在脑子里 → 变成可传承、可迭代的资产
