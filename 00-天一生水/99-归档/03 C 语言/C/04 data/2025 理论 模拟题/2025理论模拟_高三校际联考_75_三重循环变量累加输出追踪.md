# 2025理论模拟 · 高三校际联考 75 · 三重循环变量累加输出追踪

## 一、题目内容

- 题号：75
- 题型：程序阅读题
- 原始试卷：2024-2025高三校际联考   计算机专业综合试卷.md
- 题目原文：

75.阅读下列程序，请将运行结果填写在答题卡上相应位置。

```c
#include"stdio.h"
main()
{
inti,j,k,s1,s2,s3;
s1=s2=0;s3=1;
for(j=1;j<=3;j++)
{ s1++;
for(k=1;k<=j;k++,s2+=k+2)
s2++;
for(i=-1;i<=k;i++)
s3=s3+i;
s3=-s3;
}
printf("s1=%d,s2=%d,s3=%d",s1,s2,s3);
}
```

## 二、标签

- 重要性：重要
- 题型：程序阅读题
- 答案相关考点：
    - 嵌套循环次数追踪
    - for循环更新表达式
    - 变量累加与取反
- 解题动作：
    - 追踪外层 j 的循环次数
    - 计算内层 k 循环和更新表达式对 s2 的影响
    - 追踪 i 循环对 s3 的累加
    - 每轮结束后处理 s3 取反
- 易错点：
    - 忽略 for 更新表达式里的 s2+=k+2
    - 内层循环结束后 k 的值判断错
    - s3=-s3 的时机看错
