- 题目原文：

74.阅读下列程序，请将运行结果填写在答题卡上相应位置。

```c
#include<stdio.h>
intmain()
{
chardates[]="20241006";
intmonth,ss;
printf("Todayis:");
printf("%10s\n",dates);
printf("Century:%5d\n",(dates[0]-48)*10+dates[1]-47);
printf("Season:");
month=(dates[4]-48)*10+dates[5]-48;
if(month==1)month=13;
ss=(month-2)/3;
switch(ss)
{ case0:printf("Spring.\n");break;
case1:printf("Summer.\n");break;
case2:printf("Autumn.\n");break;
case3:printf("Winter.\n");break;
default:printf("Dateerror!\n");break;
}
return0;
}
```
