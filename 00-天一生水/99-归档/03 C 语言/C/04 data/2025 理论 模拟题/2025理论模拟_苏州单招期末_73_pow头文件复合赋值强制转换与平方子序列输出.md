# 2025理论模拟 · 苏州单招期末 73 · pow头文件复合赋值强制转换与平方子序列输出

## 一、题目内容

- 题号：73
- 题型：综合理论题
- 原始试卷：2024-2025学年苏州市职业学校三年级单招期末调研测试卷-计算机.md
- 题目原文：

73. 阅读下列程序，请将①—④表示的内容填写在答题卡上相应的位置。

```c
(1)#include<stdio.h>
(2)#include< ① >
(3)void fun(int s[],int n)
(4){
(5) int i,t1,t2,p;
(6) for (i=0;i<n;i++)
(7) {
(8) p=10;
(9) t1=s[i];t2=pow(t1,2);
(10) while(t1>p)
(11) p*=10;
(12) while(t2>=t1)
(13) {
(14) if(t2%p==t1)
(15) {
(16) printf("%d是%d的子序列\n",t1,(int)pow(t1,2));break;}
(17) else t2=t2/10;
(18) }
(19) }
(20)}
(21)int main()
(22){
(23) int s[4]={14,545,259,60};
(24) fun(s,4);
(25)}
```

上述程序中，由于使用了pow()函数，则在第(2)行需要包含头文件 ① ；第(11)行中的表
达式在赋值运算前加上*运算，构成了 ② 运算符，等价于 p=p*10；第(16)行中在表达式
pow(t1,2)前加上(int)称为 ③ 类型转换，其功能是将pow(t1,2)的运行结果转换成整数输
出；本程序的运行结果是 ④ 。
