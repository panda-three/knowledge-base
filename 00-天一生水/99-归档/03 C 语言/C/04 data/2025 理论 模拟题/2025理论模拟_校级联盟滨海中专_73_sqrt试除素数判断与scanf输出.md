# 2025理论模拟 · 校级联盟滨海中专 73 · sqrt试除素数判断与scanf输出

## 一、题目内容

- 题号：73
- 题型：综合理论题
- 原始试卷：2025计算机-校级联盟滨海中专.md
- 题目原文：

73.阅读下列程序，请将①\~④表示的内容填写在答题卡上相应位置。

```c
(1） #include <stdio.h>
(2） #include <math.h>
(3）int main()
(4）{
(5) int i, j,n;
(6) scanf("%d",&n) ;
(7) for(i=2;i<=sqrt (n) ;i++)
(8) if (n%i==0)
(9) break;
(10) if(i>sqrt (n))
(11) printf("Yes") ;
(12) else
(13) printf("No") ;
(14) return 0;
(15)}
```

上述程序中，用于输入数据的函数位于第\_①\_行，程序第（7）行中 sqrt(n)作用是②，

第（5）行定义变量的类型是③；如果输入数据是10，程序运行结果是：④。
