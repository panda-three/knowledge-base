# C 语言刻意练习教学系统 · 网站需求文档

> **产品一句话定义**：一个让学生用刻意练习的方式学 C 语言的智能题库网站。 不是刷题网站——是**刻意练习引擎**。每个学生进来，系统知道他是谁、他哪里弱、下一步该练什么、怎么练最快。
> 
> **核心差异**：市面上的刷题网站只解决「有题可做」。这个网站解决「每一分钟都练在刀刃上」。

## 一、用户角色与权限

- **学生**：做题、看反馈、看成长数据、参与反向校准
- **教师（你）**：管理题库、打标、审核校准、查看全班数据驾驶舱
- **系统管理员**（未来）：管理账号、权限、数据备份

## 二、学生端核心流程

> 登录 → 首页仪表盘（段位身份 + 今日推荐 + 刻意指数）→ 设定练习意图 → 推荐引擎调度出题 → 做题 → 即时反馈（错因定位 + 动作链断点 + 对比三通道）→ 错题回流 → 推荐引擎更新学生画像 → 下一轮调度 → 每周叙事报告 → 段位晋升仪式

## 三、教师端核心流程

> 登录 → 题库管理（打标 / 复核 / 演化变体）→ 标签一致性校准 → 数据驾驶舱（全班刻意指数 + 考点正确率热力图 + 需干预学生名单）→ 引导话术库 → 标注语料导出

## 四、功能模块矩阵

### A. 题库引擎（固定套路落地）

|功能|描述|对应设计文档章节|
|---|---|---|
|题目录入与打标|逐题录入 + YAML 标签填写（七字段）|固定套路·一|
|批量导入|支持 Obsidian 已有题库一键导入|过渡方案|
|标签一致性校验|教师端——随机抽题重标 → 对比差异 → 定位不稳定标签|固定套路·五|
|题目演化生成器|基于「可演化维度」字段，一键生成变体|固定套路·九|
|知识前序依赖链|标注每道题的前置知识，错题自动追查前序塌方|固定套路·七|
|错误模式库|每个易错点 → 认知误区映射 → 诊断式反馈|固定套路·八|
|解题动作迁移地图|动作 × 考点交叉索引，支持模式 D 匹配|固定套路·十一|

### B. 推荐引擎（核心大脑）

> 详见独立文档《C 语言教学系统 · 推荐引擎需求文档》。 简要：基于学生画像 + 练习意图 + 四维调度策略（间隔重复 / 弱项渗透 / 非舒适区调控 / 多样性保障），实时决策下一道题。

### C. 反馈引擎（及时反馈落地）

|功能|描述|对应设计文档章节|
|---|---|---|
|错因自动归类|对照易错点标签，自动归类 → 输出诊断语句|反馈·①|
|动作链断点定位|学生错误精确到第几步 → 标注断点|反馈·②|
|对比反馈三通道|vs 标准解法 / vs 班级最快 / vs 上周的自己|反馈·③|
|错误演化追踪|同一考点多次错误 → 追踪模式变化（不会 → 不稳 → 慢）|反馈·④|
|解题策略元认知反馈|不只判对错 → 判「策略选择是否最优」|反馈·⑤|
|预判-验证循环|做前系统预判易错点 → 做后对照是否命中|反馈·⑥|
|反馈即入口|每条反馈带一键直达的下一步动作链接|反馈·⑪|
|盲区热力图|考点 × 正确率可视化矩阵|反馈·⑬|
|反馈叙事化周报|每周自动生成：突破 + 弱点 + 建议 + 趋势|反馈·⑩|
|最佳实践池子|收藏往届最优解法，做完可对照|反馈·⑫|
|三档反馈节奏|练习即时 / 挑战延迟 / 元认知先写后看|反馈·⑨|
|学生反向反馈|「标注不准」「太难/太简单」「不像」三按钮|反馈·⑦|
|同伴交叉反馈|组队互标解法差异，强制表达和论证|反馈·⑧|

### D. 动机引擎（刻意性落地）

|功能|描述|对应设计文档章节|
|---|---|---|
|段位可视化身份|首页第一行：姓名 + 段位 + 状态描述|刻意性·①|
|段位晋升仪式|晋级时全屏动画 + 称号授予 + 下一级标准展示|刻意性·⑩|
|高手特权解锁|Lv.4 解锁出题 / Lv.5 入解法池 / Lv.6 训 AI|刻意性·⑪|
|练习意图标签（必填）|每次练习前必选意图类型 → 推荐引擎据此调权重|刻意性·④|
|练前 30 秒宣言|每次练习前手写一句话：「这次练完我希望…」|刻意性·⑤|
|刻意 vs 随意对比面板|本月刻意练习次数 vs 随意刷题次数 + 正确率变化对比|刻意性·⑥|
|每周刻意复盘|刻意练习占比 + 效果对比 + 引导建议|刻意性·⑦|
|练习日志自动生成|每次刻意练习结束 → 自动萃取日志（意图+考点+变化+发现）|刻意性·⑧|
|刻意练习宣言墙|首次登录签名 → 每次登录随机展示一句宣言|刻意性·⑨|
|对标榜样追踪|选择往届高手追踪：速度差距 + 稳度差距|刻意性·②|
|阶段目标自设|每月初弹出目标设定 → 学生自己写 → 月底对照|刻意性·③|
|年度刻意练习档案|年末生成：总次数 + 刻意占比 + 年度突破 + 关键词 + 明年建议|刻意性·⑭|

### E. 教师驾驶舱

|功能|描述|
|---|---|
|全班刻意指数|设定意图率 / 非舒适区率 / 反馈闭环率 / 需要干预的学生|
|考点正确率热力图|全班 × 考点矩阵，红色 = 重灾区|
|标签质量监控|标签被学生反向反馈标记次数 → 需复核标签列表|
|教师引导话术库|根据学生状态自动匹配推荐话术|
|标注语料导出|全量标签数据导出，用于 AI 训练|
|题目演化审批|教师审核和批准 AI 生成的变体题|

## 五、页面结构

**学生端（6 个核心页面）**

1. **首页仪表盘**
    
    - 段位身份卡（大字）
    - 今日刻意练习推荐（1–3 道，带意图标签）
    - 本周刻意指数环图（刻意占比 + 非舒适区占比 + 反馈闭环率）
    - 最近一次练习的快速回顾
    - 每日一题入口
2. **练习页**
    
    - 意图选择区（补弱 / 提速 / 拓新 / 维稳，每次必选）
    - 练前宣言输入框（30 秒倒计时）
    - 题目区（代码高亮 + 选项 / 填空 / 编程区）
    - 限时倒计时（挑战模式 / 模拟模式）
    - 提交按钮 + 反馈结果区（折叠在下方，做完展开）
3. **反馈详情页**
    
    - 顶部：正确 / 错误 + 错因自动归类
    - 中部：解题动作链断点图（哪步断了，高亮标红）
    - 底部三栏：vs 标准解法 / vs 班级最快 / vs 上周的你
    - 底部按钮：「针对此考点再练 5 道」「加入错题本」「反向出变体题」
4. **成长档案**
    
    - 能力热力图（雷达图）
    - 解题速度追踪曲线（按动作分组）
    - 刻意 vs 随意对比柱状图
    - 练习日志时间线（自动生成）
    - 段位晋升历史
5. **最佳实践池子**
    
    - 按考点分类的最优解法展示
    - 每篇解法：解题人（匿名代号）+ 用时 + 步骤数 + 独特技巧
    - 按钮：「我的解法也来投稿」
6. **设定页**
    
    - 阶段目标自设
    - 对标榜样选择
    - 推送偏好（每日一题时间 / 碎片练习开关）
    - 宣言墙签名

**教师端（3 个核心页面）**

1. **题库管理**
    
    - 题目列表（搜索 / 筛选 / 排序）
    - 单题打标编辑器（YAML 表单 + 实时预览）
    - 批量导入（Obsidian Markdown → 数据库）
    - 题目演化生成器（一键出变体）
    - 标签一致性校验入口
2. **教学驾驶舱**
    
    - 全班刻意指数仪表盘
    - 考点正确率热力图
    - 需干预学生名单（按刻意指数排序）
    - 引导话术推荐面板
3. **数据导出中心**
    
    - 标注语料全量导出
    - 年度练习报告批量生成
    - AI 训练数据集打包

## 六、技术架构

- **前端**：Next.js + Tailwind CSS + shadcn/ui
    - 代码编辑器组件：Monaco Editor（嵌入练习页）
    - 图表库：Recharts / Chart.js（成长档案可视化）
- **后端**：Next.js API Routes + Server Actions
    - 推荐引擎：独立服务模块，运行在 Next.js 服务端
- **数据库**：Supabase（PostgreSQL）
    - 题库表 / 用户表 / 练习记录表 / 错题表 / 标签校准表 / 反馈表
    - Supabase Auth 做用户认证
    - Supabase Realtime 做实时练习数据推送（教师驾驶舱）
- **缓存与队列**：Redis（推荐引擎缓存 + 间隔调度任务队列）
- **推送**：Web Push API（每日一题 / 碎片练习）+ Resend（周报 / 年度报告邮件）
- **部署**：Vercel（Next.js）+ Supabase Cloud

## 七、MVP 与迭代路线

**MVP（跑通闭环，1–2 个月）**

1. 题库导入（你已打标的题直接进 Supabase）
2. 学生登录 + 意图选择 + 做题 + 对错判断
3. 错因自动归类（对照你的易错点标签）
4. 模式 A 同考点强化匹配
5. 教师端题库管理

**V1.1（推荐引擎基础版，+1 个月）** 6. 学生画像建模（考点掌握度 + 错题记录 + 速度数据） 7. 基于规则的推荐引擎（意图驱动 + 难度匹配 + 错题优先） 8. 间隔重复基础调度

**V1.2（反馈升级，+1 个月）** 9. 动作链断点定位 10. 对比反馈三通道 11. 反馈叙事化周报

**V1.3（刻意性上线，+1 个月）** 12. 练习意图标签 13. 练前 30 秒宣言 14. 刻意 vs 随意对比面板 15. 段位身份 + 晋升仪式

**V1.4（非舒适区 + 大量重复，+2 个月）** 16. 推荐引擎升级——非舒适区调控 + 多样性保障 17. 错题变异重生 18. 跨题型追击 19. 难度自动爬坡 20. 上限挑战模式 21. 暗时间碎片练习

**V2.0（完整版，+3–6 个月）** 22. 推荐引擎机器学习层（协同过滤 + 知识点关联挖掘） 23. AI 训练数据集导出 24. 开放 API（供未来 AI 助教接入） 25. 全部功能完整上线

> **设计铁律**：
> 
> 1. 网站是形式，推荐引擎是灵魂。精准调度 > 花哨交互。
> 2. MVP 只做一件事：让学生做完题后得到的反馈不是「正确答案是 B」，而是「你错在第几步 + 怎么修 + 下一步练什么」。
> 3. 题库标签质量决定系统天花板。标签打不好，推荐引擎再强也没用。
> 4. 推荐引擎必须从规则引擎起步——只有规则跑通了，才有资格谈机器学习。
> 
> **过渡期方案（Obsidian → 网站）**： 现在用 Obsidian + Dataview 先跑通以下流程：
> 
> - 老师打标 50+ 道题
> - 找 3–5 个学生试走「搜题 → 组练习 → 反馈」闭环
> - 收集至少 100 条学生错题数据
> - 验证标签体系是否需要修正
> 
> 以上跑通后，把题库数据和标签体系直接导入网站 MVP。
