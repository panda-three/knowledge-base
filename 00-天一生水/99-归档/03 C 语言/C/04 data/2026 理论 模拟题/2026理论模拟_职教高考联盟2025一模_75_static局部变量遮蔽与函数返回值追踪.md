# 2026理论模拟 · 职教高考联盟2025一模 75 · static局部变量遮蔽与函数返回值追踪

## 一、题目内容

- 题号：75
- 题型：程序阅读题
- 原始试卷：15-计算机专业-2025年职教高考联盟计算机一模试卷.md
- 题目原文：

75. 阅读下面程序，请将运行结果填写在答题卡上相应位置。

```c
#include <stdio.h>

int a = 7, b = 5;

int f(int c)
{
    static int a = 2;
    int t = 1;
    while (--c >= a)
        t = t * c;
    return (a++) + t;
}

void main()
{
    int i, s = 0;
    for (i = 1; i < 3; i++)
    {
        int a = 5;
        s += f(a);
        printf("%d\t", s);
        s += a + b;
        printf("%d\n", s);
    }
}
```

- 作答要求：写出程序运行结果。

## 二、标签

- 重要性：重要
- 题型：程序阅读题
- 答案相关考点：
    - static局部变量保值
    - 局部变量遮蔽全局变量
    - 函数返回值累加追踪
- 解题动作：
    - 区分全局 a、main 中局部 a、函数 f 中 static a
    - 追踪 static a 每次调用后的自增保留
    - 计算 while 循环得到的 t 值
    - 把函数返回值累加到 s 并匹配输出顺序
- 易错点：
    - 把 static a 每次调用都重新初始化为 2
    - 把 main 里的局部 a 当成全局 a
    - 忽略 return 中 a++ 先用后加
    - 没有按两次循环分别更新 s
- 相似题搜索标签：`static` `局部变量` `变量遮蔽` `函数返回值` `变量追踪`
- 难度：⭐⭐⭐
