- 题号：75
- 题型：程序阅读题
- 原始试卷：2026盐一调计算机专业试卷定稿.md

- 题目原文：

75.阅读下列程序，请将运行结果填写在答题卡上相应位置。

```c
#include <stdio.h>
int main()
{
int arr1[6] = {2, 8, 15, 20, 25, 30};
int arr2[5] = {5, 15, 20, 28, 35};
int i = 0, j = 0, count = 0, sum = 0;
for (; i < 4; i++)
printf("%4d ", arr1[i]);
printf("\n");
i = 0;
while (i < 6 && j < 5)
{
if (arr1[i] == arr2[j])
{  sum += arr1[i];
count++;
i++;
j++;}
else if (arr1[i] < arr2[j])  i++;
else   j++;
}
printf("sum=%d\n", sum);
printf("count=%d\n", count);
int max;
if (i>=6)   printf("max:not in arr1\n");
else  {max = arr1[i];
for (; i < 6; i++)
if (arr1[i] > max) max = arr1[i];
printf("max=%d\n", max);}
return 0;
}
```
