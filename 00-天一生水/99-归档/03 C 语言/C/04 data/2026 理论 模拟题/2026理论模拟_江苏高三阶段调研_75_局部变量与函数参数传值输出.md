# 2026理论模拟 · 江苏高三阶段调研 75 · 局部变量与函数参数传值输出

## 一、题目内容

- 题号：75
- 题型：程序阅读题
- 原始试卷：江苏省中职学校高三（2023级）学生阶段调研（计算机应用专业综合理论） .md
- 题目原文：

75. 阅读下列程序，请将运行结果填写在答题卡上相应位置。

```c
#include <stdio.h>

int reset(int i);
int workover(int i);
int i = 0;

int main()
{
    int i = 5;
    reset(i / 2);
    printf("i=%d
", i);

    reset(i = i / 2);
    printf("i= %d
", i);

    reset(i / 2);
    printf("i= %d
", i);

    workover(i);
    return 0;
}

int workover(int i)
{
    printf("i= %d
", i);
    return i;
}

int reset(int i)
{
    i = i <= 2 ? 5 : 0;
    return i;
}
```

- 作答要求：写出程序运行结果。

## 二、标签

- 重要性：重要
- 题型：程序阅读题
- 答案相关考点：
    - 函数参数值传递
    - 局部变量遮蔽
    - 赋值表达式实参
- 解题动作：
    - 区分全局 i 和 main 中局部 i
    - 判断 reset 形参修改不影响实参
    - 追踪赋值表达式 i=i/2 的副作用
    - 按 printf 顺序输出
- 易错点：
    - 以为形参修改会改变实参
    - 全局 i 和局部 i 混淆
    - 赋值表达式实参副作用漏算
- 相似题搜索标签：`值传递` `局部变量` `函数参数` `赋值表达式`
