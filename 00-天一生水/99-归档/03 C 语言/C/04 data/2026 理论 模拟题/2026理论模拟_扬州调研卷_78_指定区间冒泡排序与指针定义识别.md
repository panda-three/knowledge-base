# 2026理论模拟 · 扬州调研卷 78 · 指定区间冒泡排序与指针定义识别

## 一、题目内容

- 题号：78
- 题型：综合理论题
- 原始试卷：2026年扬州市职业学校职教高考调研卷 （计算机）.md
- 题目原文：

78. 阅读下列程序，答案填写在答题卡相应位置。（每空 3 分，共 12 分）

题目：函数 `sort(int a[], int left, int right)` 对数组 `a` 中下标在 `[left, right]` 间的元素进行升序排序。

例如：当 `sort` 函数参数 `left`、`right` 的值分别为 `2`、`5` 时，程序运行结果是：

```text
排序前：-6  9  18  0  -3  7  12  -4
排序后：-6  9  -3  0   7  18  12  -4
```

```c
void sort(int a[], int left, int right)
{
    int round, num, t;
    for (round = left; round < right; round++)
        for (num = left; num < right + left - round; num++)
            if (a[num] > a[num + 1])
            {
                t = a[num];
                a[num] = a[num + 1];
                a[num + 1] = t;
            }
}

void output(int a[], int N)
{
    int i;
    for (i = 0; i < N; ++i)
        printf("%4d", a[i]);
    printf("
");
}

int main()
{
    int s[N] = {-6, 9, 18, 0, -3, 7, 12, -4}, i, t1 = 9;
    int *km;
    printf("排序前:");
    km = &t1;
    *km = t1;
    sort(s, 2, 5);
    output(s, N);
    return 0;
}
```

上述程序中，第 `#include <...>` 行中 `< >` 按照 ① 方式查找；第(17)行中 `sort(s,2,5)` 为函数 ②，`s` 为 ③ 参数；第(14)行 `int *km` 的含义为 ④。

- 作答要求：填写 ①～④ 表示的内容。
