# 2026理论模拟 · 江苏高三阶段调研 73 · 宏定义无括号替换与循环求和

## 一、题目内容

- 题号：73
- 题型：综合理论题
- 原始试卷：江苏省中职学校高三（2023级）学生阶段调研（计算机应用专业综合理论） .md
- 题目原文：

73. 阅读下列程序，请将①～④表示的内容填写在答题卡上相应位置。（每空 3 分，共 12 分）

```c
#include <stdio.h>
#define N 2
#define M N + 1

int main()
{
    int i, s = 0;
    for (i = 1; i <= 2 * M + 1; i++)
        s = s + i;
    printf("s= %d\n", s);
    return 0;
}
```

若将 `i <= 2 * M + 1` 改成 `i <= 2 * (M) + 1`，则运行结果为 ④。

- 作答要求：填写 ①～④ 表示的内容。

## 二、标签

- 重要性：重要
- 题型：综合理论题
- 答案相关考点：
    - 宏定义文本替换
    - 宏表达式括号影响
    - 循环边界求和
- 解题动作：
    - 按文本替换展开 M 为 N+1
    - 比较 2*M+1 与 2*(M)+1 的真实表达式
    - 确定 for 循环终止边界
    - 累加 1 到边界值并写出输出
- 易错点：
    - 把宏 M 当成已经算好的 3
    - 忽略无括号宏替换后的运算优先级
    - 循环边界值多算或少算
