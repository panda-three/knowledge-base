### 75. 数组与循环程序运行结果

题干：阅读下列程序，请将运行结果填写在答题卡上相应位置。

```c
#include <stdio.h>

int main()
{
    int a[] = {
        5, 7, 4, 6, 8, 3}
        ;
        int b[2][3] = {
            {
                2, 4, 1}
                , {
                    3, 5, 2}
                }
                ;
                int i, j, n;

                for (i = 0;
                i < 6;
                i++)
                {
                    n = b[i / 2][i % 3] + a[i];
                    for (j = 1;
                    j <= 10;
                    j++)
                    {
                        if (j > n)
                            break;
                        if (j % 2 == 0)
                            continue;
                        printf("*");
                    }
                    printf("\n");
                }

                return 0;
            }
```

## 二、标签

- 重要性：重要
- 题型：程序阅读题
- 答案相关考点：
    - 二维数组下标映射
    - break与continue控制输出
    - 循环打印星号
- 解题动作：
    - 用 i/2 和 i%3 从二维数组 b 取值
    - 计算 n 控制每行最多判断次数
    - 遇到偶数 j 用 continue 跳过输出
    - 遇到 j>n 用 break 提前结束当前行
- 易错点：
    - i/2 和 i%3 的行列映射算错
    - continue 和 break 的作用混淆
    - 只数循环次数不数实际打印星号数
- 相似题搜索标签：`二维数组` `行列下标` `break` `continue` `图形输出`
