# 2026理论模拟 · 凤凰职教一模 73 · static递推数组与局部变量遮蔽输出

## 一、题目内容

- 题号：73
- 题型：程序填空题
- 原始试卷：凤凰职教一模.md

- 题目原文：

73.阅读下列程序，请将①~④处表示的内容填写在答题卡中的相应位置。

```c
(1) #include<stdio.h>
(2) intm=5,n=6,a[10]={0,1,2};
(3) voidfl(void);
(4) voidf2(intm);
(5) void main()
(6) { inti;
(7) for(i=0;i<7;i++)
(8) fl();
(9) f2(1);
(10) printf("\n%d,%d",a[m],a[n]);
(11) }
(12) voidfl(void)
(13) { staticintn=3;
(14) a[n]=a[n-1]+a[n-2]+a[n-3];
(15) n++;
(16) }
(17) voidf2(intm)
(18) { for(;m<3;m+=2)
(19) { intm;
(20) for(m=1;m<4;m++)
(21) printf("%d,",a[m++]);
(22) }
(23) }
```

上述程序中，根据定义的位置，变量m,n是 ① 变量；程序的第（3）（4）行
称为 ② 语句；程序运行时，输出结果的第一行是 ③ ,第二行是 ④ 。
