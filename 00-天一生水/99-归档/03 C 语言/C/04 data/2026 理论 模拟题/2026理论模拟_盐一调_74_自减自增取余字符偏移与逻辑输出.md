# 2026理论模拟 · 盐一调 74 · 自减自增、取余、字符偏移与逻辑输出

- 题号：74
- 题型：程序阅读题
- 原始试卷：2026盐一调计算机专业试卷定稿.md

- 题目原文：

74．阅读下列程序，请将运行结果填写在答题卡上相应位置。

```c
#include <stdio.h>
int main()
{
int x = 7, y = 3, z;
char ch = 'A';
printf("初始值：x=%d, ch=%c\n", x, ch);
z = (x-- * ++y) % 5;
ch = ch + z;
printf("运算后：z=%d, ch=%c\n", z, ch);
if (z > 2)     x = x + 5;
else if (z == 2)    x = x - 3;
else   x = x * 2;
printf("x更新后：%d\n", x);
printf("逻辑结果：%d\n", (x > 10) && (y < 5));
return 0;
}
```
