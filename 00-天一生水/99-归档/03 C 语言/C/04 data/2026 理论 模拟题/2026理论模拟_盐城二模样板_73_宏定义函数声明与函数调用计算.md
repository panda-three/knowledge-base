- 题目原文：

### 73. 函数定义与宏定义

题干：阅读下列程序，请将①~④表示的内容填写在答题卡上相应位置。

```c
(1) #include <stdio.h>
(2) #define NUM 10
(3) int add(int x, int y);
(4) int mul(int a, int b)
(5) {
    return a * b + NUM;
}
(6) }
(7) int main()
(8) {
    int x = 10, y = 20, res1, res2;
(9)     res1 = add(x, y);
(10)     res2 = mul(res1, y);
(11)     printf("res1=%d, res2=%d\n", res1, res2);
(12)     return 0;
(13) }
(14) int add(int x, int y)
(15) {
    return x + y * NUM;
}
```

设问：

1. 上述程序中第（2）行的功能是：①
2. 对 `add` 函数的函数定义在第：② 行
3. 程序执行后，`res1` 的值为：③
4. `res2` 的值为：④
