### 74. 循环与分支程序运行结果

题干：阅读下列程序，请将运行结果填写在答题卡上相应位置。

```c
#include <stdio.h>

int main()
{
    int i, j, k = 0;
    char ch = 'X';
    printf("k=%d, ch=%c\n", k, ch);

    for (i = 3;
    i > 0;
    i--)
    {
        for (j = 1;
        j <= i;
        j++)
        {
            k += i - j;
            ch = (ch - 'A' + 1) % 26 + 'A';
        }
    }

    printf("k=%d, ch=%c\n", k, ch);

    int temp;
    if (k % 3 == 0)
        temp = k + 5;
    else if (k % 2 == 0)
        temp = k - 1;
    else
        temp = k * 2;

    printf("temp=%d\n", temp);
    return 0;
}
```
