# 2026理论模拟 · 职教高考联盟2026一模 75 · 嵌套函数调用、static变量与实参副作用

## 一、题目内容

- 题号：75
- 题型：程序阅读题
- 原始试卷：2026年职教高考联盟计算机一模试卷.md

- 题目原文：

75.阅读下列程序，请将运行结果填写在答题卡上相应位置。

```c
#include <stdio.h>
int a=3;
int fun(int a,int b)
{ static int c;
a=a+b;
c+=b+a;
b=a+c;
return b;
}
```

```c
int main(void)
{int c=5,d;
d=fun(a++,fun(--a,c));
printf("%d %d %d",a,c,d) ;
return 0;
}
```

## 二、标签

- 重要性：重要
- 题型：程序阅读题
- 答案相关考点：
    - 嵌套函数调用求值
    - static局部变量累加
    - 实参自增自减副作用
- 解题动作：
    - 先计算内层 fun(--a,c) 的实参和返回值
    - 追踪 static c 在两次 fun 调用中的累加
    - 再计算外层 fun(a++, 内层返回值)
    - 整理最终 a、main中c、d 的输出
- 易错点：
    - 内外层 fun 调用顺序判断错
    - static c 和 main 中局部 c 混淆
    - a++ 与 --a 的副作用漏算
