## 一、题目内容

- 题号：73
- 题型：综合理论题
- 原始试卷：凤凰职教高考联盟2026届二轮复习调研测试  计算机二模试卷 .md
- 题目原文：

73.阅读下列程序，请将①～④表示的内容填写在答题卡上相应位置。

(1）#include<stdio.h>

(2） #define A 5

(3） #define B (A+2)

(4) #define C  A+2

(5） #define D C\*3+B

(6) int main(void)

(7）{ int x=C\*3,y=D\*3;

(8)printf("x=%d,y=%d/n",x,y);

（9) return 0;

(10)}

上述程序中，第(1)行中<stdio.h>两边的尖括号表示以\_ ①方式引入系统头文件；第(2)\~(5)行的 define 是编译预处理中的②命令，其中A、B、C、D称为③；本程序的运行结果为\_ ④ 。
