# 2026理论模拟 · 凤凰职教一模 75 · 三重循环变量累加与符号翻转

- 题号：75
- 题型：程序阅读题
- 原始试卷：凤凰职教一模.md

- 题目原文：

75.阅读下列程序，请将运行结果写在答题卡对应的题号处。

```c
#include"stdio.h"
void main()
{ intm1=0,m2=5,m3=-1,i,j,k;
for(i=3;i>=0;i--)
{ m1=m1+i;
m3++;
for(j=1;j<=3;j++)
{ m2++;m3--;
for(k=-2;k<=j;k++)
m1++;
m3=-m3;
}
m2-=6-j;
}
printf("m1=%d\tm2=%d\tm3=%d\n",m1,m2,m3);
}
```

- 重要性：重要

- 解题动作：

- 易错点：
    - 忽略循环结束后的 j 值
    - m3 取反时机看错
