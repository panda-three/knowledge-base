- 题型：程序阅读题
- 原始试卷：15-计算机专业-2025年职教高考联盟计算机一模试卷.md
- 题目原文：

74. 阅读下面程序，请将运行结果填写在答题卡上相应位置。

```c
#include <stdio.h>

int main()
{
    int sn[6] = {73, 60, 47, 35};
    int d[2] = {18, 43};
    int i, p, k;

    printf("The array is:\n");
    for (i = 0; i < 4; i++)
        printf("%4d", sn[i]);
    printf("\n");

    for (i = 0; i < 2; i++)
    {
        p = i + 3;
        while (d[i] > sn[p] && p >= 0)
        {
            sn[p + 1] = sn[p];
            p = p - 1;
        }
        sn[p + 1] = d[i];
        for (k = 0; k < 5 + i; k++)
            printf("%4d", sn[k]);
        printf("\n");
    }
    return 0;
}
```

- 作答要求：写出程序运行结果。
