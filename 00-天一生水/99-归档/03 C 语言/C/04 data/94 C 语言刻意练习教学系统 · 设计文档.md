## 二、数据库设计

### 2.1 表结构总览

共 11 张核心表，按职责分四组：

| 组 | 表名 | 职责 | 行数预估 |
|---|---|---|---|
| 用户与画像 | `users` | 账号与段位身份 | 100–1000 |
| | `student_profiles` | 考点/动作掌握度画像 | = users 学生数 |
| | `badge_records` | 徽章与段位晋升记录 | users × 5 |
| 题库 | `questions` | 题目原文与答案 | 200–2000 |
| | `question_labels` | 七字段标签（带版本号） | = questions 数 |
| | `solution_pool` | 最佳实践池子 | questions × 3 |
| 练习流水 | `practice_sessions` | 每次练习的会话 | users × 每天 1–3 |
| | `practice_answers` | 每道题的作答记录 | sessions × 3–10 |
| | `error_records` | 错题诊断记录 | answers × 错误率 |
| 系统日志 | `recommendation_logs` | 推荐引擎每次决策 | answers 数 |
| | `tag_calibration_logs` | 标签一致性校验记录 | 教师手动触发 |

### 3.2 核心接口详细设计

#### POST /api/recommend/next —— 推荐引擎核心接口

**请求体**：

```json
{
  "session_id": "uuid",
  "recent_questions": ["uuid", "uuid", "uuid"]
}
```

**处理流程**（在 API Route 内部）：

```
1. 根据 session_id 查出 student_id + intent + mode
2. 从 Redis 读学生画像缓存；miss 则查 Supabase 并回写缓存
3. 调用推荐引擎核心模块：
   - allocateIntentWeights(intent, profile)
   - generateCandidatePool(profile, weights, mode)
   - filterCandidates(candidates, recent_questions)
   - rankCandidates(candidates, profile, weights)
   - selectTop(rankedCandidates)
4. 写入 recommendation_logs
5. 更新 Redis 中学生画像的 practice_history
6. 返回拼装好的输出
```

**响应体**：


### 4.2 主入口伪代码

```typescript
// lib/recommendation/index.ts

export async function recommendNext(
  sessionId: string,
  recentQuestions: string[]
): Promise<RecommendationOutput> {
  // 1. 加载数据
  const session = await getSession(sessionId);
  const profile = await getStudentProfile(session.studentId);
  const intent = session.intent;
  const mode = session.mode;

  // 2. 分配意图权重
  const weights = allocateIntentWeights(intent, profile);

  // 3. 生成候选池（并行查询）
  const [intervalCandidates, weakCandidates, intentCandidates, nczCandidates] =
    await Promise.all([
      getIntervalDueQuestions(profile),           // 维度一
      getWeaknessInfiltrateQuestions(profile),    // 维度二
      getIntentQuestions(intent, profile),         // 维度四
      getNonComfortZoneQuestions(profile, mode),   // 维度三
    ]);

  // 4. 合并候选池
  let candidates = [
    ...intervalCandidates,
    ...weakCandidates,
    ...intentCandidates,
    ...nczCandidates,
  ];

  // 5. 过滤
  candidates = applyDiversityFilter(candidates, recentQuestions);
  candidates = applyRecencyFilter(candidates, recentQuestions, 3);
  candidates = deduplicateById(candidates);

  // 6. 打分排序
  const ranked = rankCandidates(candidates, profile, weights, intent);

  // 7. 取 Top 1
  const selected = ranked[0];

  // 8. 持久化日志
  await logRecommendation({
    studentId: session.studentId,
    sessionId,
    questionId: selected.id,
    intent,
    matchStrategy: buildMatchStrategy(selected, weights),
    scoreBreakdown: selected.scoreBreakdown,
  });

  // 9. 拼装输出
  const output = assembleOutput(selected, profile, intent);

  return output;
}
```

### 4.3 排序函数伪代码

```typescript

function rankCandidates(
  candidates: QuestionCandidate[],
  profile: StudentProfile,
  weights: IntentWeights,
  intent: IntentType
): RankedCandidate[] {
  return candidates
    .map((c) => {
      const intentMatch = calcIntentMatch(c, intent, weights);       // 0–10
      const intervalUrgency = calcIntervalUrgency(c, profile);       // 0–10
      const weaknessBoost = isWeaknessPoint(c, profile) ? 1 : 0;     // 0 or 1
      const nczFit = calcNonComfortZoneFit(c, profile);              // 0–10
      const diversityPenalty = calcDiversityPenalty(c);              // 0–5
      const recencyPenalty = calcRecencyPenalty(c);                  // 0–5

      const score =
        intentMatch * 10 +
        intervalUrgency * 8 +
        weaknessBoost * 6 +
        nczFit * 5 -
        diversityPenalty * 4 -
        recencyPenalty * 3;

      return {
        ...c,
        score,
        scoreBreakdown: {
          intentMatch,
          intervalUrgency,
          weaknessBoost,
          nczFit,
          diversityPenalty,
          recencyPenalty,
          total: score,
        },
      };
    })
    .sort((a, b) => b.score - a.score);
}
```

### 4.4 间隔调度算法

```typescript
// lib/recommendation/interval-scheduler.ts

const INTERVAL_SEQUENCE = [1, 3, 7, 30, 90]; // 天数

function getNextReviewDate(
  knowledgePoint: KnowledgePointState
): Date | null {
  if (knowledgePoint.accuracy >= 0.70 && knowledgePoint.consecutiveCorrect >= 3) {
    // 跳级
    const nextLevel = Math.min(
      knowledgePoint.intervalLevel + 2,
      INTERVAL_SEQUENCE.length - 1
    );
    return addDays(new Date(), INTERVAL_SEQUENCE[nextLevel]);
  }

  if (knowledgePoint.lastResult === 'correct') {
    const nextLevel = Math.min(
      knowledgePoint.intervalLevel + 1,
      INTERVAL_SEQUENCE.length - 1
    );
    return addDays(new Date(), INTERVAL_SEQUENCE[nextLevel]);
  }

  if (knowledgePoint.lastResult === 'error') {
    // 降级
    const prevLevel = Math.max(knowledgePoint.intervalLevel - 1, 0);
    return addDays(new Date(), INTERVAL_SEQUENCE[prevLevel]);
  }

  // 超过最长间隔 → 归入维稳池
  return null;
}
```

function calcDynamicDifficulty(
  labeledDifficulty: number,
  accuracy: number
): number {
  if (accuracy >= 0.85) return Math.min(labeledDifficulty + 1, 5);
  if (accuracy >= 0.60) return labeledDifficulty;
  if (accuracy >= 0.35) return labeledDifficulty; // 最佳区间，不动
  return Math.max(labeledDifficulty - 1, 1);       // 回退但换题型
}

## 七、安全与性能设计

### 7.1 安全

- **认证**：Supabase Auth（邮箱密码 + 可选 OAuth）
- **授权**：Middleware 检查角色——学生不能访问教师端路由
- **数据隔离**：所有查询加 `WHERE student_id = current_user_id`；教师查询加 `WHERE created_by = current_user_id OR role = 'admin'`
- **限流**：推荐引擎接口加 rate limit——同一学生每分钟最多 20 次请求
- **输入校验**：所有 API 入参用 Zod schema 校验

### 7.2 性能

- **学生画像**：Redis 缓存（TTL 1 小时）；练习后异步更新
- **候选池查询**：Supabase 加索引 + 限制 LIMIT 50；四路并行查询
- **推荐日志**：异步写入，不阻塞推荐返回
- **页面渲染**：学生仪表盘用 ISR（每小时重新生成静态部分）；练习页纯客户端渲染
- **代码编辑器**：Monaco Editor 动态导入（`next/dynamic` + `ssr: false`）
