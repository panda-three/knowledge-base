# C语言函数基础知识点讲解

## 一、课程导入

同学们好。本节课开始学习第七章函数。

C 语言程序由函数组成。函数可以把一段具有特定功能的程序封装起来，在需要时调用，从而简化程序结构，提高代码复用性。

函数是高考理论题和技能题中的常见考点。理论题常考函数概念、形参实参、函数声明；程序题常考函数调用、返回值和参数传递。

本节课学习目标：

1. 理解函数的概念。
2. 掌握函数定义的一般形式。
3. 掌握函数的四种基本类型。
4. 理解函数调用的方法。
5. 掌握函数声明、形参、实参和返回值。

## 二、函数的定义

函数定义的一般形式：

```c
类型名 函数名(形式参数表)
{
    数据定义部分;
    执行语句部分;
}
```

函数定义的第一行称为函数头，花括号中的部分称为函数体。

函数类型决定返回值类型。如果函数有返回值，函数体中通常应有 `return` 语句。如果函数没有返回值，类型应写为 `void`。

形参只能是变量，不能是常量或表达式。

## 三、函数的四种类型

### 1. 无参无返回值函数

```c
void printStar()
{
    int i;
    for (i = 1; i <= 10; i++)
        printf("*");
    printf("\n");
}
```

没有参数，也不返回结果。调用时只执行指定操作。

### 2. 无参有返回值函数

```c
int sumOdd()
{
    int i, sum = 0;

    for (i = 1; i < 100; i += 2)
        sum += i;

    return sum;
}
```

没有参数，但执行后返回一个值。

### 3. 有参无返回值函数

```c
void printChar(char c)
{
    int i;
    for (i = 1; i <= 10; i++)
        printf("%c", c);
    printf("\n");
}
```

调用时需要传入参数，但函数不返回结果。

### 4. 有参有返回值函数

```c
int max(int a, int b)
{
    if (a > b)
        return a;
    else
        return b;
}
```

调用时传入参数，函数执行后返回结果。

## 四、函数调用

函数调用的一般形式：

```c
函数名(实际参数表)
```

实参与形参要在数量、类型和顺序上对应。

例如：

```c
z = max(x, y);
```

这里 `x` 和 `y` 是实参，传递给 `max` 函数中的形参 `a` 和 `b`。函数返回的最大值赋给 `z`。

函数调用方式常见三种：

1. 函数语句调用：

   ```c
   printStar();
   ```

2. 函数表达式调用：

   ```c
   z = max(x, y);
   ```

3. 函数作为实参调用：

   ```c
   printf("%d", max(x, y));
   ```

## 五、函数声明

如果函数定义写在主函数后面，通常要在主函数前进行声明：

```c
int max(int a, int b);
```

函数声明告诉编译系统：函数名、返回值类型、参数类型是什么。

## 六、例题讲解

### 例题 1：求两数最大值

```c
#include <stdio.h>

int max(int x, int y);

int main()
{
    int a, b, z;

    scanf("%d%d", &a, &b);
    z = max(a, b);

    printf("最大值是%d\n", z);
    return 0;
}

int max(int x, int y)
{
    if (x > y)
        return x;
    else
        return y;
}
```

分析：

程序从 `main` 函数开始执行。`a`、`b` 作为实参传递给 `max` 函数的形参 `x`、`y`，函数返回较大值。

### 例题 2：求整数各位数字之和

```c
int p(int a)
{
    int b, s = 0;

    b = a;
    while (b != 0)
    {
        s += b % 10;
        b /= 10;
    }

    return s;
}
```

如果传入 `365`，则计算：

```text
5 + 6 + 3 = 14
```

函数功能是求参数中各位数字之和。

### 例题 3：求数组元素之和

```c
int sum(int a[], int n)
{
    int i, s = 0;

    for (i = 0; i < n; i++)
        s += a[i];

    return s;
}
```

分析：

数组作为参数传递时，函数可以访问数组中的元素。`n` 表示数组有效元素个数。

## 七、易错点

1. 函数声明后忘记分号。

2. 形参和实参概念混淆。

   函数定义中的参数是形参，函数调用时传入的是实参。

3. 误以为程序从第一个自定义函数开始执行。

   C 程序总是从 `main` 函数开始执行。

4. 有返回值函数没有 `return`。

5. 无参函数调用时忘记小括号。

   即使没有参数，也要写 `函数名()`。

## 八、本讲小结

本节课学习了函数的定义、声明和调用。函数可以分为有参、无参、有返回值、无返回值四种组合。做函数题时，要从 `main` 函数开始读，理清实参传给形参、函数返回值传回主调函数的过程。
