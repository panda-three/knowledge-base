# 一维数组排序：直接选择排序法与冒泡排序法教学

## 一、课程导入

同学们好。本节课继续学习一维数组的排序。

排序是指按照某种规则对一组数据重新排列。按从小到大排列称为升序，按从大到小排列称为降序。排序的目的通常是为了便于后续查找和处理。

本节课学习目标：

1. 理解排序的概念。
2. 掌握直接选择排序法的基本思想。
3. 掌握冒泡排序法的基本思想。
4. 能够分析排序程序的每一趟过程。
5. 能够编写数组升序、降序排序程序。

## 二、直接选择排序法

直接选择排序的基本思想：

1. 在所有未排序元素中找到最小值。
2. 将最小值与当前待排序位置交换。
3. 继续在剩余元素中找最小值。
4. 重复上述过程，直到排序完成。

对于 `n` 个数，只需要进行 `n - 1` 趟排序。最后一个数自然有序。

升序排序核心代码：

```c
for (i = 0; i < n - 1; i++)
{
    k = i;
    for (j = i + 1; j < n; j++)
    {
        if (a[j] < a[k])
            k = j;
    }

    if (k != i)
    {
        t = a[i];
        a[i] = a[k];
        a[k] = t;
    }
}
```

其中 `k` 用来记录当前最小值的位置。

## 三、冒泡排序法

冒泡排序的基本思想：

相邻两个元素进行比较，如果顺序不符合要求就交换。经过一趟比较后，一个最大值或最小值会被“冒”到最终位置。

从前往后冒泡的升序排序代码：

```c
for (i = 0; i < n - 1; i++)
{
    for (j = 0; j < n - 1 - i; j++)
    {
        if (a[j] > a[j + 1])
        {
            t = a[j];
            a[j] = a[j + 1];
            a[j + 1] = t;
        }
    }
}
```

如果要降序排列，只需要把比较符号改为 `<`。

## 四、例题讲解

### 例题 1：直接选择排序过程

原数组：

```text
34 56 22 48 18 9
```

第一趟：在所有元素中找到最小值 9，与第一个元素 34 交换：

```text
9 56 22 48 18 34
```

第二趟：在剩余元素中找到最小值 18，与第二个元素 56 交换：

```text
9 18 22 48 56 34
```

继续执行，直到数组升序排列。

### 例题 2：从键盘输入 10 个实数并从小到大排序

```c
#include <stdio.h>

int main()
{
    int i, j;
    float a[10], t;

    for (i = 0; i < 10; i++)
        scanf("%f", &a[i]);

    for (i = 0; i < 9; i++)
    {
        for (j = 0; j < 9 - i; j++)
        {
            if (a[j] > a[j + 1])
            {
                t = a[j];
                a[j] = a[j + 1];
                a[j + 1] = t;
            }
        }
    }

    for (i = 0; i < 10; i++)
        printf("%.1f ", a[i]);

    return 0;
}
```

分析：

外层循环控制排序趟数，共 `10 - 1` 趟。内层循环进行相邻元素比较和交换。

## 五、直接选择排序与冒泡排序比较

直接选择排序：

1. 每趟先找到最值位置。
2. 每趟最多交换一次。
3. 关键是记录最值下标。

冒泡排序：

1. 每趟进行相邻比较。
2. 不符合顺序就立即交换。
3. 交换次数可能较多。

## 六、易错点

1. 排序趟数写成 `n`。

   对 `n` 个元素排序，通常只需要 `n - 1` 趟。

2. 内层循环边界写错。

   冒泡排序中访问 `a[j + 1]`，必须保证 `j + 1` 不越界。

3. 升序和降序比较符号混淆。

   升序：前面大于后面时交换。降序：前面小于后面时交换。

4. 交换语句缺少临时变量。

   交换两个元素通常需要 `t` 临时保存。

## 七、本讲小结

本节课学习了直接选择排序和冒泡排序。直接选择排序每趟找最值再交换；冒泡排序通过相邻元素比较逐步把最大值或最小值移动到最终位置。
