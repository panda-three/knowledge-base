# C语言第五章循环结构程序设计：递推法与穷举法习题讲解

## 一、课程导入

同学们好。本节课是第五章循环结构程序设计的综合练习课，重点学习如何利用循环结构解决递推法和穷举法问题。

循环不仅可以重复执行语句，还可以表达“前一项推出后一项”“逐个尝试所有可能”等算法思想。掌握这两类方法，对后续数组、函数以及综合程序设计题都很重要。

本节课学习目标：

1. 理解递推法的基本思想。
2. 理解穷举法的基本思想。
3. 能够用循环结构求斐波那契数列、分数数列、小球反弹等递推问题。
4. 能够用穷举法解决换钱、百鸡百钱、三位数筛选等问题。
5. 能够分析循环填空题中变量的变化过程。

## 二、递推法

递推法是一种用若干步重复运算来描述复杂问题的方法。它通常通过已知的前面若干项，推出后面的项。

递推问题的关键是找到递推关系，也就是“下一步由哪几个已有量推出”。

例如斐波那契数列：

```text
1, 1, 2, 3, 5, 8, 13, ...
```

从第三项开始，每一项都是前两项之和：

```c
next = a + b;
```

然后要让变量向后移动：

```c
a = b;
b = next;
```

这样循环执行，就可以依次得到后面的数。

## 三、穷举法

穷举法是在给定范围内，把所有可能情况逐个列举并验证的方法。

穷举法的基本思想是：

1. 根据题意确定变量的可能范围。
2. 使用循环逐个产生可能值。
3. 用条件语句判断是否满足题目要求。
4. 满足条件时输出结果。

穷举法适合解决范围明确、情况有限的问题。例如换钱问题、百鸡百钱问题、三位数筛选问题等。

## 四、例题讲解

### 例题 1：求斐波那契数列前 20 项

题目：

```text
求斐波那契数列的前20个数。
```

分析：

斐波那契数列前两项已知，后面每一项等于前两项之和。循环中需要完成两件事：

1. 输出当前项。
2. 根据前两项推出下一项，并更新变量。

参考程序：

```c
#include <stdio.h>

int main()
{
    int i;
    int a = 1, b = 1, next;

    for (i = 1; i <= 20; i++)
    {
        printf("%d\t", a);
        next = a + b;
        a = b;
        b = next;
    }

    return 0;
}
```

### 例题 2：求分数数列前 10 项之和

题目：

```text
求 1/2 + 2/3 + 3/5 + 5/8 + ... 前10项之和。
```

分析：

观察数列可知：

1. 下一项的分子等于上一项的分母。
2. 下一项的分母等于上一项分子与分母之和。

更新时需要借助临时变量保存旧分子。

参考程序：

```c
#include <stdio.h>

int main()
{
    int i;
    double numerator = 1, denominator = 2, temp;
    double sum = 0;

    for (i = 1; i <= 10; i++)
    {
        sum += numerator / denominator;
        temp = numerator;
        numerator = denominator;
        denominator = denominator + temp;
    }

    printf("sum = %.2f\n", sum);
    return 0;
}
```

### 例题 3：小球反弹问题

题目：

```text
一个小球从100米高度自由落下，每次落地后反跳回原高度的一半，再落下。求第10次落地时共经过多少米，第10次反弹多高。
```

分析：

第一次落地只经过下落的 100 米。从第二次开始，每次都包含一次上升和一次下降。

参考程序：

```c
#include <stdio.h>

int main()
{
    int i;
    double h = 100.0;
    double sum = h;

    for (i = 2; i <= 10; i++)
    {
        h = h / 2;
        sum += 2 * h;
    }

    h = h / 2;

    printf("第10次落地时共经过 %.2f 米\n", sum);
    printf("第10次反弹高度为 %.2f 米\n", h);

    return 0;
}
```

### 例题 4：百元换百张

题目：

```text
将100元人民币换成5元、1元、0.5元若干张，要求共100张，且每种至少1张，求所有换法。
```

分析：

设 5 元张数为 `i`，1 元张数为 `j`，0.5 元张数为 `k`。需要同时满足：

```c
i + j + k == 100
5 * i + j + 0.5 * k == 100
```

为了避免小数，可以把钱数统一乘以 2：

```c
10 * i + 2 * j + k == 200
```

参考程序：

```c
#include <stdio.h>

int main()
{
    int i, j, k;

    for (i = 1; i <= 19; i++)
    {
        for (j = 1; j <= 94; j++)
        {
            k = 100 - i - j;
            if (k >= 1 && 10 * i + 2 * j + k == 200)
                printf("5元:%d张 1元:%d张 0.5元:%d张\n", i, j, k);
        }
    }

    return 0;
}
```

### 例题 5：卖鸭子递推问题

题目：

```text
一个人赶鸭子去村庄卖，每经过一个村子就卖去所赶鸭子的一半又一只。经过7个村子后还剩2只鸭子。求每个村子前有多少只鸭子。
```

分析：

这是反向递推。已知经过第 7 个村子后剩 2 只，进入第 7 个村子前的数量应为：

```c
(2 + 1) * 2 = 6
```

一般递推关系为：

```c
before = (after + 1) * 2;
```

参考程序：

```c
#include <stdio.h>

int main()
{
    int i;
    int after = 2;
    int before;

    for (i = 7; i >= 1; i--)
    {
        before = (after + 1) * 2;
        printf("第%d个村子前有%d只，卖出%d只，剩%d只\n",
               i, before, before - after, after);
        after = before;
    }

    return 0;
}
```

## 五、易错点

1. 递推题没有保存旧值。

   例如分数数列中，分子更新前要先保存旧分子，否则后面求分母时会丢失原来的值。

2. 穷举范围设置不合理。

   范围太小会漏解，范围太大会增加无效循环。应根据题意先缩小变量范围。

3. 混淆递推方向。

   有些题从前往后推，有些题需要从结果反推初始值，如卖鸭子问题。

4. 金额中出现小数时直接比较浮点数。

   换钱题中可以把所有金额统一乘以 2 或 10，转化为整数计算。

## 六、本讲小结

本节课主要学习了递推法和穷举法。

递推法的重点是找到前后项之间的关系，并在循环中正确更新变量。穷举法的重点是确定所有可能范围，并逐个验证条件。

做循环综合题时，要先读清楚题目要求，再确定循环变量、循环范围、循环条件和循环体中的变量变化。
