# 一维数组第二课时：最值查找、顺序查找与折半查找

## 一、课程导入

同学们好。本节课继续学习一维数组，重点是数组中的最大值、最小值，以及数组元素的查找。

数组不仅可以存放一组数据，还经常用于统计、查找和排序。本节课的三个重点是：最值查找、顺序查找和折半查找。

本节课学习目标：

1. 掌握一维数组最大值、最小值的查找方法。
2. 掌握顺序查找的基本思想。
3. 掌握折半查找的基本思想和关键语句。
4. 能够分析查找程序的运行过程。

## 二、最值查找

查找最大值或最小值常用“基准比较法”。

基本思想：

1. 先假设数组中的某个元素是最大值或最小值。
2. 再用它与后面的元素逐个比较。
3. 如果发现更大的值或更小的值，就更新基准。

通常把第一个元素作为基准，最安全。

```c
max = a[0];
for (i = 1; i < n; i++)
{
    if (a[i] > max)
        max = a[i];
}
```

不能随意把最大值初始为 0。因为如果数组中全是负数，初始值 0 就会导致结果错误。

## 三、顺序查找

顺序查找又称线性查找，是从数组的某个位置开始，逐个与目标值比较。

基本结构：

```c
flag = 0;
for (i = 0; i < n; i++)
{
    if (a[i] == x)
    {
        flag = 1;
        break;
    }
}
```

如果找到，`flag` 置为 1；如果从头到尾都没有找到，`flag` 保持 0。

## 四、折半查找

折半查找适用于已经有序的数组。

基本思想：

1. 确定查找区间的左端 `left` 和右端 `right`。
2. 计算中间位置 `mid = (left + right) / 2`。
3. 如果 `a[mid] == x`，查找成功。
4. 如果 `x > a[mid]`，到右半区间查找，令 `left = mid + 1`。
5. 如果 `x < a[mid]`，到左半区间查找，令 `right = mid - 1`。
6. 当 `left > right` 时，查找失败。

折半查找关键程序：

```c
left = 0;
right = n - 1;

while (left <= right)
{
    mid = (left + right) / 2;

    if (a[mid] == x)
        break;
    else if (x > a[mid])
        left = mid + 1;
    else
        right = mid - 1;
}
```

## 五、例题讲解

### 例题 1：找数组最大值

```c
int a[7] = {12, 45, 6, 89, 23, 17, 50};
int i, max;

max = a[0];
for (i = 1; i < 7; i++)
{
    if (a[i] > max)
        max = a[i];
}

printf("max = %d\n", max);
```

分析：

先假设 `a[0]` 最大，再从 `a[1]` 开始逐个比较。发现更大的元素就更新 `max`。

### 例题 2：把大于 60 的元素复制到另一个数组

```c
int a[6] = {45, 88, 59, 95, 66, 42};
int b[6], i, p = 0;

for (i = 0; i < 6; i++)
{
    if (a[i] > 60)
    {
        b[p] = a[i];
        p++;
    }
}
```

分析：

`p` 表示 `b` 数组中下一个可存放的位置。每找到一个大于 60 的元素，就复制到 `b[p]`，然后 `p++`。

### 例题 3：顺序查找 29

```c
int a[10] = {12, 18, 24, 29, 35, 40, 56, 77, 81, 90};
int i, x = 29, flag = 0;

for (i = 0; i < 10; i++)
{
    if (a[i] == x)
    {
        flag = 1;
        break;
    }
}

if (flag)
    printf("found %d\n", x);
else
    printf("no found %d\n", x);
```

### 例题 4：折半查找

```c
int a[10] = {12, 18, 24, 29, 34, 56, 77, 81, 90, 99};
int left = 0, right = 9, mid;
int x;

scanf("%d", &x);

while (left <= right)
{
    mid = (left + right) / 2;

    if (a[mid] == x)
        break;
    else if (x > a[mid])
        left = mid + 1;
    else
        right = mid - 1;
}

if (left <= right)
    printf("found at %d\n", mid);
else
    printf("no found\n");
```

分析：

折半查找的重点是区间变化。要找的数比中间值大，就移动左边界；比中间值小，就移动右边界。

## 六、易错点

1. 最大值初值随意设为 0。

   应优先用数组第一个元素作为初值。

2. 顺序查找找到后忘记 `break`。

   如果只需要判断是否存在，找到后可以提前退出循环。

3. 折半查找条件写成 `left < right`。

   通常应写 `left <= right`，否则可能漏掉最后一个候选元素。

4. 折半查找区间更新写反。

   `x > a[mid]` 时应改左边界：`left = mid + 1`。

## 七、本讲小结

本节课学习了最值查找、顺序查找和折半查找。最值查找要选好基准；顺序查找逐个比较；折半查找必须建立在有序数组基础上，重点掌握 `left`、`right` 和 `mid` 的变化。
