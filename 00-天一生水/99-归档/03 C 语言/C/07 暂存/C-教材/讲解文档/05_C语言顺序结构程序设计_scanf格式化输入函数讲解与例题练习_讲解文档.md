## 二、scanf 函数的基本功能

`scanf` 是 C 语言中的标准格式输入函数。

它的功能是从键盘读取输入数据，并按照指定格式，把数据保存到对应变量的存储单元中。

`scanf` 是标准库函数，定义在标准输入输出头文件 `stdio.h` 中。因此，使用 `scanf` 时，通常需要在程序开头写：

```c
#include <stdio.h>
```

`scanf` 的调用格式与 `printf` 类似：

```c
scanf("格式控制字符串", 地址列表);
```

其中：

`格式控制字符串` 用来指定输入数据的格式。

`地址列表` 用来说明输入的数据要保存到哪些变量中。

需要特别注意，`scanf` 后面的变量一般要加地址符 `&`。

例如：

```c
int age;
scanf("%d", &age);
```

这里 `&age` 表示变量 `age` 的地址。`scanf` 读取到一个整数后，会把这个整数保存到 `age` 所在的内存单元中。

如果有多个输入项，变量地址之间用逗号隔开：

```c
scanf("%d%f", &age, &asset);
```

格式说明符的数量、类型和后面的变量地址要一一对应。

## 三、scanf 基本示例

示例：输入年龄和资产，并输出。

```c
#include <stdio.h>

int main(void)
{
    int age;
    float asset;

    printf("Input age and asset:");
    scanf("%d%f", &age, &asset);
    printf("age=%d, asset=%.2f\n", age, asset);

    return 0;
}
```

程序说明：

第一，`printf` 用来输出提示信息。

第二，`scanf("%d%f", &age, &asset);` 表示从键盘输入一个整数和一个实数，分别保存到 `age` 和 `asset` 中。

第三，`%.2f` 表示输出实数时保留两位小数。小数位不足时补 0，超出时四舍五入。

## 四、scanf 常用格式说明符

`scanf` 的格式说明符与 `printf` 基本相似，但有些地方需要特别注意。

常用格式说明符如下：

`%c`：输入一个字符。

`%d`：输入十进制整数。

`%f`：输入 `float` 类型实数。

`%e`：输入指数形式的实数。

`%g`：输入实数。

`%i`：输入整数，可以识别十进制、八进制、十六进制形式。

`%o`：输入八进制整数。

`%s`：输入字符串，从第一个非空白字符开始，到下一个空白字符结束。

`%u`：输入无符号十进制整数。

`%x`：输入十六进制整数。

需要注意：

在 `scanf` 中，`%f`、`%e`、`%g` 用于输入 `float` 类型变量。

如果要输入 `double` 类型变量，需要使用 `%lf`。

例如：

```c
float x;
double y;

scanf("%f", &x);
scanf("%lf", &y);
```

## 五、scanf 的修饰符

`scanf` 中常见的修饰符有 `m`、`l` 和 `*`。

### 1. 宽度修饰符 m

`m` 表示一个正整数，用来指定输入数据的最大宽度。

例如：

```c
scanf("%10s", str);
```

表示最多读取 10 个字符作为字符串。

如果输入：

```text
hello Lee
```

由于 `%s` 遇到空格就停止读取，所以实际只会把 `hello` 保存到字符串变量中。

`scanf` 在读取输入项时，遇到最大宽度或第一个空白字符，就会停止读取当前输入项。

### 2. l 修饰符

`l` 可用于输入长整型或双精度实型。

例如：

```c
long n;
double x;

scanf("%ld", &n);
scanf("%lf", &x);
```

其中，`%ld` 用于输入长整型，`%lf` 用于输入 `double` 类型。

### 3. * 修饰符

`*` 表示读入对应数据，但不赋值给任何变量，也就是读入后舍弃。

例如：

```c
int a, b;
scanf("%2d%*3d%2d", &a, &b);
```

如果输入：

```text
12345678
```

执行过程为：

`%2d` 读取 `12`，赋给 `a`。

`%*3d` 读取 `345`，但舍弃，不赋给任何变量。

`%2d` 读取 `67`，赋给 `b`。

所以，最终 `a` 的值是 12，`b` 的值是 67。

## 六、scanf 输入规则

### 1. 输入结束

输入数据时，通常用回车键表示本次输入结束。

例如：

```c
scanf("%d", &age);
```

输入一个整数后按 Enter，数据才会被提交给程序。

### 2. 非格式字符必须原样输入

如果 `scanf` 的格式控制字符串中除了格式说明符之外，还有普通字符，那么输入时也必须输入相同的普通字符。

例如：

```c
int i, j;
scanf("i=%d,j=%d", &i, &j);
```

正确输入形式应为：

```text
i=10,j=1
```

其中的 `i=`、`,`、`j=` 都必须按照格式控制串原样输入。

### 3. 输入多个非字符数据的分隔方式

输入多个非字符数据时，可以使用以下方式分隔：

第一，使用空格、回车、制表符等空白字符分隔。

例如：

```c
scanf("%d%f", &a, &b);
```

输入时可以写成：

```text
12 3.5
```

也可以分两行输入：

```text
12
3.5
```

第二，按格式中指定的最大宽度分隔。

例如：

```c
scanf("%2d%3d", &a, &b);
```

输入：

```text
12345
```

则 `12` 赋给 `a`，`345` 赋给 `b`。

第三，用非法输入字符作为分隔。

例如，整数输入遇到非数字字符时，会停止读取当前整数。

## 七、字符型输入的特殊规则

使用 `%c` 输入字符时，要特别注意：

空格、回车、制表符等空白字符也会被当作有效字符接收。

例如：

```c
char c1, c2;
scanf("%c", &c1);
scanf("%c", &c2);
```

如果输入第一个字符后直接按 Enter，那么回车符可能会被第二个 `%c` 接收，导致 `c2` 得不到预期字符。

如果要让 `c1` 为 `'A'`，`c2` 为 `'B'`，不能输入完 `A` 后直接回车再输入 `B`。可以直接连续输入：

```text
AB
```

多个 `%c` 连续输入时，如果格式控制串中没有分隔符，输入时也不要加分隔符。

例如：

```c
scanf("%c%c", &c1, &c2);
```

应输入：

```text
AB
```

如果格式控制串中有逗号：

```c
scanf("%c,%c", &c1, &c2);
```

则输入时也必须输入逗号：

```text
A,B
```

## 八、小写字母转换为大写字母

题目：输入一个小写字母，转换为对应的大写字母输出。

思路：

小写字母的 ASCII 码比对应大写字母大 32。小写转大写，只需要把字符的 ASCII 码减去 32。

程序如下：

```c
#include <stdio.h>

int main(void)
{
    char a;

    scanf("%c", &a);
    putchar(a - 32);

    return 0;
}
```

例如输入：

```text
e
```

输出：

```text
E
```

因为小写字母 `e` 的 ASCII 码是 101，`101 - 32 = 69`，ASCII 码 69 对应大写字母 `E`。

## 九、大写字母转换为小写字母

题目：输入一个大写字母，输出该字母及其 ASCII 码，再转换为小写字母并输出小写字母及其 ASCII 码。

思路：

大写字母的 ASCII 码比对应小写字母小 32。大写转小写，只需要加 32。

程序如下：

```c
#include <stdio.h>

int main(void)
{
    char ch, lower;

    ch = getchar();
    lower = ch + 32;

    printf("%c %d\n", ch, ch);
    printf("%c %d\n", lower, lower);

    return 0;
}
```

例如输入：

```text
A
```

输出：

```text
A 65
a 97
```

需要注意，输出时要适当使用 `\n` 换行，否则多个结果会挤在同一行，影响阅读。

## 十、变量交换经典例题

题目：输入两个整数，交换它们的值后输出。

这是顺序结构中最经典的例题之一。

如果要交换两个变量 `a` 和 `b` 的值，不能直接写：

```c
a = b;
b = a;
```

因为第一句执行后，`a` 原来的值已经丢失。

正确方法是借助第三个变量作为中转。

程序如下：

```c
#include <stdio.h>

int main(void)
{
    int a, b, c;

    scanf("%d%d", &a, &b);

    c = a;
    a = b;
    b = c;

    printf("%d %d\n", a, b);

    return 0;
}
```

交换过程可以理解为：

第一步，把 `a` 的值保存到中间变量 `c` 中。

第二步，把 `b` 的值赋给 `a`。

第三步，把 `c` 中保存的原 `a` 值赋给 `b`。

这样就完成了两个变量值的交换。

## 十一、海伦公式求三角形面积

题目：输入三角形三条边长，使用海伦公式求三角形面积。

海伦公式为：

```text
p = (a + b + c) / 2
area = sqrt(p * (p - a) * (p - b) * (p - c))
```

其中，`p` 是半周长，`area` 是面积。

由于需要使用开平方函数 `sqrt`，程序中除了包含 `stdio.h`，还要包含数学头文件：

```c
#include <math.h>
```

程序如下：

```c
#include <stdio.h>
#include <math.h>

int main(void)
{
    float a, b, c;
    float p, area;

    scanf("%f%f%f", &a, &b, &c);

    p = (a + b + c) / 2.0;
    area = sqrt(p * (p - a) * (p - b) * (p - c));

    printf("a=%7.2f b=%7.2f c=%7.2f area=%7.2f\n", a, b, c, area);

    return 0;
}
```

程序说明：

第一，`math.h` 中包含 `sqrt` 函数的声明。

第二，`scanf("%f%f%f", &a, &b, &c);` 中每个变量前都要加地址符 `&`。

第三，`2.0` 用来保证计算按实型运算进行。

第四，`%7.2f` 表示总宽度为 7，保留两位小数；宽度不足时前面补空格。

## 十二、三位正整数逆序输出

题目：输入一个三位正整数，输出它的逆序。

例如：

```text
输入：123
输出：321
```

思路：

个位数：对 10 取模。

十位数：先除以 10 再对 10 取模，或者先对 100 取模再除以 10。

百位数：除以 100 取整。

程序如下：

```c
#include <stdio.h>

int main(void)
{
    int n;
    int a, b, c;

    scanf("%d", &n);

    a = n % 10;
    b = n / 10 % 10;
    c = n / 100;

    printf("%d%d%d\n", a, b, c);

    return 0;
}
```

若输入 `123`：

`123 % 10 = 3`，得到个位。

`123 / 10 % 10 = 12 % 10 = 2`，得到十位。

`123 / 100 = 1`，得到百位。

按个位、十位、百位输出，结果为 `321`。

## 十三、两个整数从小到大输出

题目：输入两个整数，按从小到大的顺序输出。

方法一：使用条件表达式。

```c
#include <stdio.h>

int main(void)
{
    int x, y, t;

    scanf("%d%d", &x, &y);

    t = x < y ? x : y;
    y = x + y - t;
    x = t;

    printf("%d %d\n", x, y);

    return 0;
}
```

分析：

`x < y ? x : y` 表示如果 `x < y` 成立，就取 `x`；否则取 `y`。因此，`t` 保存较小值。

`x + y - t` 得到较大值。

最后把较小值放到 `x`，较大值放到 `y`，再输出。

方法二：使用绝对值求较小值。

```c
t = (x + y - abs(x - y)) / 2;
```

这个表达式可以得到两个数中的较小值。使用 `abs` 时，需要包含：

```c
#include <stdlib.h>
```

## 十四、三位数各位数字求和

题目：输入一个三位整数，求各位数字之和。

思路和逆序输出类似，先取出个位、十位、百位，再相加。

```c
#include <stdio.h>

int main(void)
{
    int n;
    int a, b, c, sum;

    scanf("%d", &n);

    a = n % 10;
    b = n / 10 % 10;
    c = n / 100;
    sum = a + b + c;

    printf("%d\n", sum);

    return 0;
}
```

例如输入 `123`，输出结果为 `6`。

## 十五、符号常量与圆面积

在程序中，可以使用 `#define` 定义符号常量。

例如：

```c
#define PI 3.14
```

这条编译预处理语句的作用是定义符号常量 `PI`，以后程序中凡是出现 `PI` 的地方，都代表 `3.14`。

求圆面积示例：

```c
#include <stdio.h>
#define PI 3.14

int main(void)
{
    float r, s;

    scanf("%f", &r);
    s = PI * r * r;

    printf("%.2f\n", s);

    return 0;
}
```

C 语言程序从 `main` 函数的函数体开始执行。

## 十六、运算规则复习

本节课例题还涉及一些常见运算规则。

### 1. 强制类型转换

例如：

```c
(int)x
```

表示把变量 `x` 的值强制转换为整型。

如果 `x` 是浮点型，转换为整型时，小数部分会直接舍去，不进行四舍五入。

### 2. 模运算

模运算符 `%` 用于求余数。

例如：

```c
5 % 2
```

结果为：

```text
1
```

`%` 两边通常应为整数。

### 3. 运算优先级

做表达式计算题时，要注意运算优先级。

一般要重点掌握：

1. 自增、自减运算。
2. 乘法、除法、模运算。
3. 加法、减法。
4. 关系运算。
5. 逻辑运算。
6. 条件运算。
7. 赋值运算。

遇到复杂表达式时，要按照优先级和结合方向逐步计算。
