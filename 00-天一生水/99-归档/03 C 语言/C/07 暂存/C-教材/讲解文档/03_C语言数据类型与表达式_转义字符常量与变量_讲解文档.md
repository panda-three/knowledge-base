# C语言数据类型与表达式第二课时：转义字符、常量与变量

同学们好，本节课我们继续学习“数据类型与表达式”的第二课时内容。

上一节课中，我们已经了解了 C 语言中的基本数据类型，也学习了部分常量的书写方法。本节课主要学习三个方面的内容：第一，字符常量中的转义字符；第二，符号常量的定义和使用；第三，变量的定义、初始化和使用方法。

## 一、转义字符

在 C 语言中，有些字符可以直接从键盘输入，比如字母、数字和常见符号；但有些字符不能直接输入，例如换行、退格、制表符等。为了表示这些特殊字符，C 语言使用转义字符。

转义字符通常以反斜杠 `\` 开头。

常见的转义字符有：

`\n` 表示换行，输出位置移动到下一行的行首。

`\r` 表示回车，输出位置回到本行的行首。

`\t` 表示水平制表符，输出位置移动到下一个 tab 位置。

`\0` 表示空字符，ASCII 码值为 0，常作为字符串的结束标志。注意，`\0` 不等同于字符 `'0'`，字符 `'0'` 的 ASCII 码值是 48。

`\'` 表示单引号字符。

`\"` 表示双引号字符。

`\?` 表示问号字符。

`\\` 表示反斜杠字符。

`\b` 表示退格，输出位置向前退一个字符位置。

**另外，反斜杠后面跟八进制数，表示该八进制数对应的 ASCII 字符。例如 `\101` 表示 ASCII 码为八进制 101 的字符，也就是大写字母 `A`。**

**反斜杠后面跟 `x` 和十六进制数，表示该十六进制数对应的 ASCII 字符。例如 `\x41` 也表示大写字母 `A`。**

需要注意的是，转义字符虽然看起来可能由多个符号组成，但在 C 语言中，它表示的是一个字符。

## 二、字符串常量中的转义字符

字符串常量是用双引号括起来的一串字符。例如：

```c
"a"
```

这个字符串表面上只有一个字符 `a`，但它在内存中实际占用两个字符位置：第一个是字符 `a`，第二个是字符串结束标志 `\0`。

所以，字符串 `"a"` 的存储长度是 2，而字符串的实际长度是 1。

这里要区分两个概念：

字符串的长度：不包括结束标志 `\0`。

字符串的存储大小：包括结束标志 `\0`。

例如字符串：

```c
"ab\"c\"a\\b"
```

其中：

`a` 是一个字符；

`b` 是一个字符；

`\"` 表示一个双引号字符；

`c` 是一个字符；

`\"` 表示一个双引号字符；

`a` 是一个字符；

`\\` 表示一个反斜杠字符；

`b` 是一个字符。

转义字符虽然写法上有两个字符，但实际只表示一个字符。计算字符串长度时，要按实际字符个数计算，不要把反斜杠和后面的字符分开算。

## 三、printf 输出中的转义字符

来看一个输出语句：

```c
printf("\'\\ab\"c\"a\\b");
```

我们逐个分析：

`\'` 输出一个单引号；

`\\` 输出一个反斜杠；

`a` 和 `b` 原样输出；

`\"` 输出一个双引号；

`c` 原样输出；

`\"` 输出一个双引号；

`a` 原样输出；

`\\` 输出一个反斜杠；

`b` 原样输出。

所以，遇到转义字符时，一定要记住：它整体表示一个字符，而不是多个普通字符。

## 四、符号常量

符号常量是用一个符号名称来代表一个固定的常量值。

例如在数学中，我们经常用 `PI` 表示圆周率 3.14。在 C 语言中，也可以用类似方式定义符号常量：

```c
#define PI 3.14
```

这表示在程序中，凡是出现 `PI` 的地方，都代表常量 `3.14`。

符号常量的优点是含义清楚、见名知义，并且便于修改。如果程序中多处使用圆周率，将来需要修改精度时，只需要修改宏定义这一行即可。

需要注意：

```c
#define PI 3.14
```

这一行后面不加分号。

因为 `#define` 是宏定义命令，不是普通的 C 语言语句。如果加了分号，编译器会把分号也当作替换内容的一部分，可能导致错误。

例如：

```c
#include <stdio.h>
#define PI 3.14

int main()
{
    float r, s;
    r = 2;
    s = 4 * PI * r * r;
    printf("%f", s);
    return 0;
}
```

在这个程序中，`PI` 代表 3.14。

习惯上，符号常量名通常使用大写字母，变量名通常使用小写字母。

还要注意，符号常量不是变量，它的值在作用范围内不能被改变。例如：

```c
PI = PI + 2;
```

这是错误的。

## 五、变量的概念

变量是指在程序运行过程中，其值可以发生变化的量。

每一个变量都有一个名字，这个名字叫变量名。变量还必须属于某一种确定的数据类型，并且在内存中占据一定的存储单元。

一个变量通常包含四个基本属性：

第一，变量名；

第二，变量类型；

第三，变量的值；

第四，变量在内存中的地址。

例如：

```c
int a;
a = 10;
```

这里定义了一个整型变量 `a`，它的值是 10。系统会在内存中为它分配空间，并用变量名 `a` 来访问这个空间中的数据。

在 C 语言中，变量必须先定义，后使用。

变量定义的一般形式是：

```c
类型名 变量名表;
```

如果一次定义多个变量，变量名之间用逗号隔开，最后用分号结束。

例如：

```c
int i, j, number;
```

表示定义三个整型变量 `i`、`j` 和 `number`。

```c
float a, b, sum;
```

表示定义三个实型变量 `a`、`b` 和 `sum`。

```c
char c1, c2;
```

表示定义两个字符型变量 `c1` 和 `c2`。

## 六、整型变量

整型变量是 C 程序中最常用的变量类型之一。基本整型的类型名是：

```c
int
```

根据取值范围不同，整型变量可以分为：

基本整型：`int`

短整型：`short int`，也可以写作 `short`

长整型：`long int`，也可以写作 `long`

还可以根据是否带符号分为：

有符号整型：`signed`

无符号整型：`unsigned`

其中，`signed` 可以省略，因为整型默认就是有符号整型。

例如：

```c
int a, b;
long c;
unsigned int e;
```

分别表示定义整型变量 `a`、`b`，长整型变量 `c`，无符号整型变量 `e`。

赋值示例：

```c
a = -1;
b = -523;
c = 620000;
e = 89;
```

输出时，要根据变量类型选择合适的格式符。整型常用 `%d`，长整型常用 `%ld`。

## 七、整型变量的初始化

变量在定义的同时赋初值，叫做变量初始化。

例如：

```c
int a = 3;
```

这相当于先定义变量 `a`，再把 3 赋给 `a`。

也可以部分初始化：

```c
int a, b, c = 5;
```

这里 `a` 和 `b` 只是被定义，`c` 被初始化为 5。

如果要让多个变量都等于 3，应该写成：

```c
int a = 3, b = 3, c = 3;
```

不能写成：

```c
int a = b = c = 3;
```

这句是错误的，因为在定义语句中，`b` 和 `c` 还没有被定义，系统无法识别。

## 八、实型变量

实型变量用于存放小数，也就是浮点数。

C 语言中的实型变量主要有三类：

单精度实型：`float`

双精度实型：`double`

长双精度实型：`long double`

例如：

```c
float x, y;
float m = 12.8;
double min;
long double t;
```

其中，`float` 通常占 4 个字节，`double` 通常占 8 个字节。不同编译环境下，具体字节数可能有所不同。

实型变量的精度是有限的。例如 `float` 一般只能保证约 7 位有效数字。如果赋给它的小数位很多，系统只能保留一定精度，后面的部分会被舍去或近似处理。

输出实型变量时，常用格式符：

```c
%f
```

例如：

```c
printf("%f", x);
```

## 九、字符型变量

字符型变量用于存放字符常量。字符型变量的类型名是：

```c
char
```

一个字符型变量只能存放一个字符，并且通常占 1 个字节。

例如：

```c
char c1, c2;
c1 = 'a';
c2 = 'b';
```

也可以在定义时初始化：

```c
char c1 = 'a', c2 = 'b';
```

字符数据在内存中实际是以 ASCII 码形式存储的，因此字符型数据和整型数据在一定情况下可以通用。

例如：

```c
char c1, c2;
c1 = 'a';
c2 = 'b';

c1 = c1 - 32;
c2 = c2 - 32;

printf("%c %c\n", c1, c2);
printf("%d %d", c1, c2);
```

小写字母 `a` 的 ASCII 码是 97，减去 32 后得到 65，对应大写字母 `A`。

小写字母 `b` 的 ASCII 码是 98，减去 32 后得到 66，对应大写字母 `B`。

因此这个程序可以把小写字母转换成大写字母。

输出字符时使用格式符：

```c
%c
```

输出字符对应的 ASCII 码时，可以使用：

```c
%d
```

## 十、变量名与标识符

变量名属于用户标识符。C 语言中标识符的命名规则是：

只能由字母、数字和下划线组成；

必须以字母或下划线开头；

不能使用 C 语言关键字作为变量名。

例如：

```c
sum
number
_score
```

这些都可以作为合法变量名。

但是：

```c
2abc
a-b
while
int
```

这些不能作为合法变量名。其中 `2abc` 不能以数字开头，`a-b` 中含有非法字符 `-`，`while` 和 `int` 是 C 语言关键字。

## 十一、常见考点总结

本节课中需要重点掌握以下内容：

第一，转义字符整体表示一个字符，例如 `\n`、`\t`、`\\`、`\"`。

第二，`\0` 的 ASCII 码值是 0，而字符 `'0'` 的 ASCII 码值是 48。

第三，字符串常量末尾系统会自动添加结束标志 `\0`。

第四，符号常量用 `#define` 定义，定义语句末尾不加分号。

第五，变量必须先定义后使用。

第六，变量有变量名、数据类型、值和地址等属性。

第七，整型变量包括 `int`、`short`、`long`，还可以分为有符号和无符号。

第八，实型变量包括 `float`、`double` 和 `long double`。

第九，字符型变量用 `char` 定义，一个字符变量只能存放一个字符。

第十，字符型数据在内存中以 ASCII 码形式存储，因此字符型数据和整型数据可以相互转换使用。

## 课堂小结

本节课我们主要学习了 C 语言中的转义字符、符号常量和变量。

转义字符用于表示一些特殊字符，尤其要注意它们虽然写法上可能包含多个符号，但实际表示一个字符。

符号常量可以提高程序的可读性，也方便统一修改。

变量是程序运行过程中可以改变的量，使用变量时必须先定义，并且要明确它的数据类型。
