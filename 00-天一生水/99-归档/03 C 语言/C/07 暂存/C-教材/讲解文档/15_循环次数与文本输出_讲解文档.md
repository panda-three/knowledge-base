# 循环结构程序设计：循环次数计算与文本作图讲解

## 一、课程导入

同学们好。本节课继续学习循环结构程序设计，重点解决两个问题：循环次数计算和文本作图。

循环次数是分析循环程序的基础。只有先判断外层循环、内层循环分别执行多少次，才能准确写出程序结果。文本作图题则要求我们根据行数、空格数和字符数找规律。

本节课学习目标：

1. 掌握单层循环和多层循环的次数计算。
2. 能够分析嵌套循环中变量的最终值。
3. 掌握文本作图题的基本分析方法。
4. 能够输出矩形、直角三角形、倒三角形和菱形等图形。

## 二、循环次数分析方法

分析嵌套循环时，一般按以下顺序：

1. 先看外层循环执行几次。
2. 再看每次外层循环中，内层循环执行几次。
3. 如果某个变量在外层循环中被清零，只需要关注最后一次有效循环。
4. 如果内层循环次数与外层变量有关，要逐次列出每一轮次数。

例如：

```c
for (i = 1; i <= 3; i++)
{
    n = 0;
    for (j = 1; j <= i; j++)
        n++;
}
```

虽然外层循环执行 3 次，但每次开头都把 `n` 清零，所以最终只看 `i = 3` 时的情况，`n` 最终为 3。

## 三、例题讲解

### 例题 1：嵌套循环变量累加

```c
int i, j, k, n = 0;

for (i = 1; i <= 3; i++)
{
    n = 0;
    for (j = 1; j <= i; j++)
    {
        n++;
        for (k = 1; k <= j; k++)
            n++;
    }
}

printf("%d\n", n);
```

分析：

因为每次外层循环都会执行 `n = 0`，所以最终结果只需要分析最后一次 `i = 3`。

当 `i = 3` 时：

1. `j = 1`：外层 `n++` 一次，内层 `k` 循环一次。
2. `j = 2`：外层 `n++` 一次，内层 `k` 循环两次。
3. `j = 3`：外层 `n++` 一次，内层 `k` 循环三次。

总次数为：

```text
3 + (1 + 2 + 3) = 9
```

所以输出 `9`。

### 例题 2：输出矩形

输出 4 行 10 列星号：

```c
int i, j;

for (i = 1; i <= 4; i++)
{
    for (j = 1; j <= 10; j++)
        printf("*");
    printf("\n");
}
```

外层控制行数，内层控制每行字符数。每一行输出完后必须换行。

### 例题 3：输出直角三角形

图形：

```text
*
**
***
****
```

程序：

```c
int i, j;

for (i = 1; i <= 4; i++)
{
    for (j = 1; j <= i; j++)
        printf("*");
    printf("\n");
}
```

规律：第 `i` 行输出 `i` 个星号。

### 例题 4：输出倒三角形

图形：

```text
****
***
**
*
```

写法一：

```c
int i, j;

for (i = 1; i <= 4; i++)
{
    for (j = 1; j <= 5 - i; j++)
        printf("*");
    printf("\n");
}
```

规律：第 `i` 行输出 `5 - i` 个星号。

### 例题 5：输出右对齐三角形

图形：

```text
   *
  **
 ***
****
```

程序：

```c
int i, j;

for (i = 1; i <= 4; i++)
{
    for (j = 1; j <= 4 - i; j++)
        printf(" ");
    for (j = 1; j <= i; j++)
        printf("*");
    printf("\n");
}
```

文本作图时一般分三步：先输出空格，再输出星号，最后换行。

### 例题 6：用绝对值输出对称图形

如果图形上下对称，可以把行号设置为负数到正数，例如从 `-3` 到 `3`。通过 `abs(i)` 表示行号到中心行的距离。

```c
#include <stdio.h>
#include <math.h>

int main()
{
    int i, j;

    for (i = -3; i <= 3; i++)
    {
        for (j = 1; j <= abs(i); j++)
            printf(" ");
        for (j = 1; j <= 4 - abs(i); j++)
            printf("*");
        printf("\n");
    }

    return 0;
}
```

使用 `abs` 函数时，需要包含头文件：

```c
#include <math.h>
```

## 四、文本作图分析步骤

1. 先确定总行数，确定外层循环。
2. 再观察每一行前面有几个空格。
3. 再观察每一行有几个图形字符。
4. 每行结束后输出换行符。
5. 如果图形上下对称，可以考虑分上下两部分写，也可以用绝对值方法写。

## 五、易错点

1. 忘记换行。

   每一行输出完后必须 `printf("\n");`。

2. 空格数量和星号数量混在一起。

   应先分别找规律，再写两个内层循环。

3. 嵌套循环中变量被重新赋值。

   如果变量在外层循环中被清零，前几轮结果可能被覆盖。

4. 使用 `abs` 忘记包含头文件。

   应写 `#include <math.h>`。

## 六、本讲小结

本节课学习了循环次数计算和文本作图。循环次数题要分清外层、内层和变量是否被清零；文本作图题要抓住行数、空格数、字符数和换行四个关键点。
