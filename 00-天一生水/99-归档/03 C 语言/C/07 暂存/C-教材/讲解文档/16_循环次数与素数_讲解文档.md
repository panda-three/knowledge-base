这类题目是循环结构中的常见考点，尤其是素数判断、输出一定范围内的素数、每行控制输出个数等题型，在考试中经常出现。

## 二、累加与累乘

累加常用结构：

```c
sum = 0;
for (i = 1; i <= n; i++)
    sum += 项;
```

累乘常用结构：

```c
product = 1;
for (i = 1; i <= n; i++)
    product *= 项;
```

累加器初值通常为 0，累乘器初值通常为 1。

## 三、例题讲解

### 例题 1：求阶乘倒数和

题目：

```text
求 s = 1 + 1/2! + 1/3! + ... + 1/n!
```

参考程序：

```c
#include <stdio.h>

int main()
{
    int i, n;
    double s = 1.0;
    long fact = 1;

    scanf("%d", &n);

    for (i = 1; i <= n; i++)
    {
        fact *= i;
        s += 1.0 / fact;
    }

    printf("s = %.2f\n", s);
    return 0;
}
```

分析：

`fact` 保存当前项的阶乘。每次循环在原有阶乘基础上继续乘 `i`，再把 `1.0 / fact` 累加到 `s` 中。

### 例题 2：求含正负交替的级数

题目：

```text
求 x/1! - x^2/2! + x^3/3! - ... + (-1)^(n+1) x^n/n!
```

参考思路：

1. `power` 用来保存 `x` 的幂。
2. `fact` 用来保存阶乘。
3. `flag` 用来控制正负号。

```c
double sum = 0;
double power = 1;
long fact = 1;
int flag = 1;

for (i = 1; i <= n; i++)
{
    power *= x;
    fact *= i;
    sum += flag * power / fact;
    flag = -flag;
}
```

分析：

正负交替的项，可以把减法看成“加上一个负数”，用 `flag` 在 1 和 -1 之间切换。

### 例题 3：判断一个数是否为素数

素数是只能被 1 和自身整除的正整数。判断一个数 `n` 是否为素数，可以从 2 开始试除。

参考程序：

```c
#include <stdio.h>

int main()
{
    int n, i, flag = 1;

    scanf("%d", &n);

    if (n < 2)
        flag = 0;
    else
    {
        for (i = 2; i < n; i++)
        {
            if (n % i == 0)
            {
                flag = 0;
                break;
            }
        }
    }

    if (flag)
        printf("yes\n");
    else
        printf("no\n");

    return 0;
}
```

分析：

一旦找到一个能整除 `n` 的数，就说明 `n` 不是素数，可以用 `break` 提前结束循环。

### 例题 4：输出 1 到 100 以内所有素数

```c
#include <stdio.h>

int main()
{
    int i, j, flag;

    for (i = 2; i <= 100; i++)
    {
        flag = 1;

        for (j = 2; j < i; j++)
        {
            if (i % j == 0)
            {
                flag = 0;
                break;
            }
        }

        if (flag)
            printf("%d\t", i);
    }

    return 0;
}
```

分析：

外层循环控制待判断的数，内层循环判断当前数是否为素数。每判断一个新数时，都要重新把 `flag` 设为 1。

### 例题 5：输出 1000 以内素数，每 10 个一行

```c
#include <stdio.h>

int main()
{
    int i, j, flag, count = 0;

    for (i = 2; i <= 1000; i++)
    {
        flag = 1;
        for (j = 2; j < i; j++)
        {
            if (i % j == 0)
            {
                flag = 0;
                break;
            }
        }

        if (flag)
        {
            printf("%d\t", i);
            count++;
            if (count % 10 == 0)
                printf("\n");
        }
    }

    return 0;
}
```

分析：

`count` 用来统计已经输出了多少个素数。每输出 10 个，就换行一次。

## 四、易错点

1. 每判断一个新数时忘记重置 `flag`。

   `flag` 必须在外层循环内部重新赋值。

2. 素数输出时没有分隔符。

   如果直接连续输出整数，会看不清每个素数，应使用空格、制表符或换行。

3. `1` 被误判为素数。

   `1` 不是素数，素数判断通常从 2 开始。

4. 正负交替级数中符号处理混乱。

   可以使用 `flag = -flag;` 统一控制正负号。

## 五、本讲小结

本节课学习了累加、累乘和素数专题。累加累乘题要关注初值；素数题要掌握“外层枚举数、内层试除判断”的结构，并注意使用标记变量和 `break` 提高效率。
