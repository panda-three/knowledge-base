# C语言 if 语句教学课程

## 一、课程导入

同学们好，上一节课我们学习了关系运算和逻辑运算。通过关系表达式和逻辑表达式，我们可以根据给定条件判断表达式的真和假。

本节课开始学习 `if` 语句。

`if` 语句是一种非常重要的程序控制语句。它可以根据给定条件是否满足，选择执行相应的操作。

`if` 语句主要有三种结构：

1. 单分支结构
2. 双分支结构
3. 多分支结构

本节课学习目标：

1. 掌握单分支 `if` 语句的格式和执行过程。
2. 掌握双分支 `if ... else` 语句的格式和执行过程。
3. 掌握多分支 `if ... else if ... else` 语句的使用。
4. 能够使用 `if` 语句解决成绩判断、大小写转换、字符分类、水仙花数判断等问题。
5. 理解 `if` 语句中表达式“非 0 为真，0 为假”的规则。

## 二、单分支 if 语句

单分支 `if` 语句的基本格式是：

```c
if (表达式)
    语句;
```

它的含义是：

如果表达式的值为非 0，也就是真，则执行后面的语句。

如果表达式的值为 0，也就是假，则不执行后面的语句，直接跳过。

需要注意，`if` 后面的表达式必须写在小括号中。

## 三、单分支例题：正数输出

题目：输入一个整数，若该整数为正数，则输出；否则不输出。

程序如下：

```c
#include <stdio.h>

int main(void)
{
    int x;

    scanf("%d", &x);

    if (x > 0)
        printf("%d\n", x);

    return 0;
}
```

程序分析：

第一，`scanf("%d", &x);` 从键盘输入一个整数。

第二，`if (x > 0)` 判断 `x` 是否大于 0。

第三，如果 `x > 0` 成立，则执行：

```c
printf("%d\n", x);
```

第四，如果 `x > 0` 不成立，则跳过输出语句，程序直接执行 `return 0;`。

例如：

输入 `30`，因为 `30 > 0` 成立，所以输出 `30`。

输入 `0`，因为 `0 > 0` 不成立，所以没有输出。

输入 `-20`，因为 `-20 > 0` 不成立，所以也没有输出。

## 四、双分支 if ... else 语句

双分支结构用于在两种操作中选择一种执行。

基本格式是：

```c
if (表达式)
    语句1;
else
    语句2;
```

它的含义是：

如果表达式的值为非 0，也就是真，则执行语句 1。

否则，执行语句 2。

也就是说，双分支结构中，不管条件是否成立，都会执行其中一个分支。

需要注意：

1. `else` 是 `if` 语句的一部分，必须与 `if` 配对使用，不能单独出现。
2. 如果 `if` 或 `else` 后面只有一条语句，可以不加花括号。
3. 如果后面有多条语句，必须用花括号 `{ }` 括起来。

例如：

```c
if (x >= 60)
{
    printf("pass\n");
    printf("continue\n");
}
else
{
    printf("fail\n");
    printf("work harder\n");
}
```

## 五、双分支例题：成绩是否合格

题目：输入学生成绩，判断其是否合格。

程序如下：

```c
#include <stdio.h>

int main(void)
{
    int x;

    scanf("%d", &x);

    if (x >= 60)
        printf("该生成绩合格\n");
    else
        printf("该生成绩不合格\n");

    return 0;
}
```

程序分析：

如果输入 `65`，则 `65 >= 60` 成立，执行 `if` 后面的语句，输出：

```text
该生成绩合格
```

如果输入 `45`，则 `45 >= 60` 不成立，执行 `else` 后面的语句，输出：

```text
该生成绩不合格
```

这两个输出语句只会执行其中一个，不可能两个都执行。

## 六、多分支 if ... else if ... else 语句

当程序需要从多个分支中选择一个执行时，可以使用多分支 `if` 语句。

基本格式是：

```c
if (表达式1)
    语句1;
else if (表达式2)
    语句2;
else if (表达式3)
    语句3;
else
    语句n;
```

执行过程是：

从上到下依次判断各个表达式。

一旦发现某个表达式成立，就执行紧跟其后的语句。

执行完该语句后，跳过整个多分支结构，继续执行后面的程序。

如果前面所有表达式都不成立，则执行最后的 `else` 分支。

最后的 `else` 起到缺省条件的作用，也可以根据需要省略。

虽然 `if ... else if ... else` 结构在书写时可能占多行，但它整体仍然属于一条选择语句。

为了提高可读性，书写时应保持缩进：

```c
if (score >= 90)
    printf("A\n");
else if (score >= 80)
    printf("B\n");
else if (score >= 70)
    printf("C\n");
else if (score >= 60)
    printf("D\n");
else
    printf("E\n");
```

## 七、多分支例题：成绩等级判断

题目：输入一个成绩，输出对应等级。

规则：

90 分及以上为 A。

80 分及以上为 B。

70 分及以上为 C。

60 分及以上为 D。

60 分以下为 E。

程序如下：

```c
#include <stdio.h>

int main(void)
{
    int x;

    scanf("%d", &x);

    if (x >= 90)
        printf("A\n");
    else if (x >= 80)
        printf("B\n");
    else if (x >= 70)
        printf("C\n");
    else if (x >= 60)
        printf("D\n");
    else
        printf("E\n");

    return 0;
}
```

程序分析：

多分支结构从上往下判断。

如果 `x >= 90` 成立，直接输出 `A`，后面的条件不再判断。

如果 `x >= 90` 不成立，说明成绩已经低于 90，再判断 `x >= 80`。

依次类推。

最后的 `else` 表示前面条件都不满足，也就是成绩低于 60，输出 `E`。

这种写法的关键是条件顺序要合理。这里是从高分到低分依次判断。

## 八、多分支条件顺序的注意点

成绩等级判断也可以从低分到高分写，但必须写清楚每个区间的上下限。

错误写法：

```c
if (x < 60)
    printf("E\n");
else if (x >= 60)
    printf("D\n");
else if (x >= 70)
    printf("C\n");
else if (x >= 80)
    printf("B\n");
else
    printf("A\n");
```

这段程序有问题。

如果输入 `75`，它不小于 60，于是进入 `else if (x >= 60)`，直接输出 `D`。程序执行完该分支后就跳出整个选择结构，不会再判断 `x >= 70`。

如果输入 `95`，同样会在 `x >= 60` 处输出 `D`，无法得到 `A`。

原因是 `x >= 60` 的范围太大，没有写出上限。

正确写法可以是：

```c
if (x < 60)
    printf("E\n");
else if (x >= 60 && x < 70)
    printf("D\n");
else if (x >= 70 && x < 80)
    printf("C\n");
else if (x >= 80 && x < 90)
    printf("B\n");
else
    printf("A\n");
```

这种写法从低分到高分判断，每个等级区间都写出了上下限。

## 九、if 语句中的真假规则

在 C 语言中，`if` 后面的表达式不一定必须是关系表达式。

只要表达式的值为非 0，就认为是真。

表达式的值为 0，就认为是假。

例如：

```c
if (x)
    printf("执行\n");
```

当 `x != 0` 时，语句会执行。

当 `x == 0` 时，语句不会执行。

所以：

```c
if (x)
```

等价于：

```c
if (x != 0)
```

但为了提高可读性，在初学阶段建议把条件写清楚。

## 十、例题：判断偶数

题目：从键盘输入一个整数，如果这个数是偶数，则输出 1，否则输出 0。

偶数是能被 2 整除的整数，也就是对 2 取余结果为 0。

程序如下：

```c
#include <stdio.h>

int main(void)
{
    int x;

    scanf("%d", &x);
    printf("%d\n", x % 2 == 0);

    return 0;
}
```

程序分析：

`x % 2 == 0` 是判断偶数的条件表达式。

如果输入 `12`：

```text
12 % 2 = 0
```

所以 `12 % 2 == 0` 成立，表达式值为 1。

如果输入 `13`：

```text
13 % 2 = 1
```

所以 `13 % 2 == 0` 不成立，表达式值为 0。

## 十一、例题：大小写字母互换

题目：输入一个字符，若是大写字母，则转换为小写字母；若是小写字母，则转换为大写字母。

分析：

判断一个字符是否为大写字母：

```c
c >= 'A' && c <= 'Z'
```

判断一个字符是否为小写字母：

```c
c >= 'a' && c <= 'z'
```

大写字母转换为小写字母，需要加 32。

小写字母转换为大写字母，需要减 32。

程序如下：

```c
#include <stdio.h>

int main(void)
{
    char c;

    c = getchar();

    if (c >= 'A' && c <= 'Z')
        c = c + 32;
    else if (c >= 'a' && c <= 'z')
        c = c - 32;

    putchar(c);

    return 0;
}
```

如果输入大写字母 `A`，输出小写字母 `a`。

如果输入小写字母 `b`，输出大写字母 `B`。

如果输入的是数字字符、空格或其他符号，则不进行转换，原样输出。

## 十二、例题：字符分类

题目：输入任意字符，判断它是字母、数字字符，还是其他字符。

判断字母：

```c
(c >= 'A' && c <= 'Z') || (c >= 'a' && c <= 'z')
```

判断数字字符：

```c
c >= '0' && c <= '9'
```

程序如下：

```c
#include <stdio.h>

int main(void)
{
    char c;

    c = getchar();

    if ((c >= 'A' && c <= 'Z') || (c >= 'a' && c <= 'z'))
        printf("字母\n");
    else if (c >= '0' && c <= '9')
        printf("数字字符\n");
    else
        printf("其他字符\n");

    return 0;
}
```

这里需要注意：

字符 `'0'` 到 `'9'` 是数字字符，不等同于整数 0 到 9。

判断字符范围时，要使用字符常量，例如 `'0'`、`'9'`、`'A'`、`'Z'`。

## 十三、例题：水仙花数判断

题目：输入一个三位整数，判断它是否是水仙花数。

水仙花数是指一个三位数，它的个位、十位、百位数字的立方和等于它本身。

例如：

```text
153 = 1^3 + 5^3 + 3^3
```

所以 153 是水仙花数。

程序思路：

第一，输入一个三位整数 `x`。

第二，取出个位、十位、百位。

第三，判断三个数字的立方和是否等于原数。

程序如下：

```c
#include <stdio.h>

int main(void)
{
    int x;
    int ge, shi, bai;

    scanf("%d", &x);

    ge = x % 10;
    shi = x / 10 % 10;
    bai = x / 100;

    if (ge * ge * ge + shi * shi * shi + bai * bai * bai == x)
        printf("%d 是水仙花数\n", x);
    else
        printf("%d 不是水仙花数\n", x);

    return 0;
}
```

注意，C 语言中没有直接用 `^` 表示乘方。这里计算立方，应写成三个相同数字相乘。

## 十四、选择题与易错点讲解

### 1. `if (x)` 什么时候执行

如果有语句：

```c
if (x)
    printf("OK");
```

当 `x` 的值为非 0 时，条件成立，语句执行。

当 `x` 的值为 0 时，条件不成立，语句不执行。

所以 `if (x)` 等价于 `if (x != 0)`。

### 2. 赋值号和相等号的区别

例如：

```c
int x = 5;
if (x = 4)
    printf("T");
else
    printf("F");
```

这里 `x = 4` 不是判断 `x` 是否等于 4，而是把 4 赋给 `x`。

赋值表达式的值是 4，非 0，所以条件成立，输出：

```text
T
```

如果要判断是否相等，应写成：

```c
if (x == 4)
```

### 3. if 后面只控制一条语句

如果 `if` 后面没有花括号，它只控制紧跟其后的第一条语句。

例如：

```c
if (a > b)
    c = a;
a = b;
b = c;
```

这里 `if` 只控制：

```c
c = a;
```

后面的：

```c
a = b;
b = c;
```

不属于 `if` 的控制范围，无论条件是否成立都会执行。

如果希望三条语句都受 `if` 控制，必须写成：

```c
if (a > b)
{
    c = a;
    a = b;
    b = c;
}
```

### 4. if 后面空语句

例如：

```c
if (y);
    a = 3;
```

这里 `if (y);` 后面的分号构成空语句。

也就是说，`if` 控制的是一个空语句，而 `a = 3;` 不受 `if` 控制，会继续执行。

这是考试和程序调试中的常见错误。

## 十五、条件运算符与 if 语句

条件运算符 `?:` 有时可以完成简单选择。

例如：

```c
k = (--a == b++) ? a : b + 1;
```

执行这类表达式时，要注意：

前置自增自减：先改变，再使用。

后置自增自减：先使用，再改变。

条件表达式：

```c
条件 ? 表达式1 : 表达式2
```

如果条件成立，取表达式 1 的值；否则取表达式 2 的值。

简单选择可以用条件运算符表示，但较复杂的程序逻辑更适合使用 `if` 语句。

## 十六、本讲小结

本节课主要学习了 `if` 语句的三种结构。

需要重点掌握：

1. 单分支结构：条件成立才执行语句。
2. 双分支结构：条件成立执行一支，否则执行另一支。
3. 多分支结构：从上到下依次判断，满足某一条件后执行对应语句，并跳过后续分支。
4. `if` 后面的表达式非 0 为真，0 为假。
5. `else` 必须与 `if` 配对使用，不能单独出现。
6. 多条语句作为一个分支时，必须用 `{ }` 括起来。
7. 判断相等要写 `==`，赋值才写 `=`。
8. `if` 后面不要随意加分号，否则可能变成空语句。
9. 成绩等级判断要注意条件顺序和区间范围。
10. 字符范围判断常用 `c >= 'A' && c <= 'Z'` 这类表达式。
