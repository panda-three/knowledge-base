# C语言高考考点：第8章文件知识点讲解

## 一、课程导入

同学们好。本节课学习 C 语言第八章文件。

文件是 C 语言基础知识中的最后一个部分。在高考中，文件知识通常出现在填空题或综合题中，分值不高，但要求能够看懂文件打开、关闭、读写和定位等基本操作。

本节课学习目标：

1. 理解文件和文件指针的概念。
2. 掌握文件打开与关闭方法。
3. 掌握文本文件和二进制文件的读写函数。
4. 掌握文件定位函数。
5. 了解文件检测函数 `feof` 和 `ferror`。

## 二、文件指针与文件打开

文件操作通常需要定义文件指针：

```c
FILE *fp;
```

打开文件使用 `fopen`：

```c
fp = fopen("d:\\\\test.txt", "r");
```

注意路径中的反斜杠要写成双反斜杠。

关闭文件使用 `fclose`：

```c
fclose(fp);
```

## 三、文件打开方式

常见打开方式：

```text
"r"   只读方式打开文本文件，文件必须存在
"w"   只写方式打开文本文件，文件不存在则建立，存在则清空
"a"   追加方式打开文本文件，在文件末尾写入
"r+"  读写方式打开文本文件，文件必须存在
"w+"  读写方式建立文本文件
"a+"  读写或追加方式打开文本文件
"rb"  只读方式打开二进制文件
"wb"  只写方式打开二进制文件
"wb+" 读写方式打开或建立二进制文件
```

带 `b` 表示二进制文件。

## 四、字符读写函数

### 1. fputc

把一个字符写入文件：

```c
fputc(ch, fp);
```

### 2. fgetc

从文件读取一个字符：

```c
ch = fgetc(fp);
```

例题：将键盘输入的一行字符写入文件，直到回车结束。

```c
FILE *fp;
char ch;

fp = fopen("c:\\\\t.txt", "w");
scanf("%c", &ch);

while (ch != '\n')
{
    fputc(ch, fp);
    scanf("%c", &ch);
}

fclose(fp);
```

## 五、字符串读写函数

### 1. fputs

将字符串写入文件：

```c
fputs(str, fp);
```

### 2. fgets

从文件读取字符串：

```c
fgets(str, n, fp);
```

## 六、格式化读写函数

格式化写入文件：

```c
fprintf(fp, "%d %c", x, ch);
```

格式化读取文件：

```c
fscanf(fp, "%d", &x);
```

例如把杨辉三角写入文件，可以使用：

```c
fprintf(fp, "%3d", a[i][j]);
```

每输出完一行，再写入换行符：

```c
fputc('\n', fp);
```

## 七、二进制读写函数

### 1. fwrite

写入数据块：

```c
fwrite(a, sizeof(int), 50, fp);
```

表示每个数据块大小为 `sizeof(int)`，写入 50 个数据块。

### 2. fread

读取数据块：

```c
fread(&p, sizeof(int), 1, fp);
```

表示读取一个整型数据到变量 `p` 中。

## 八、文件定位函数

### 1. rewind

将文件位置指针重新定位到文件开头：

```c
rewind(fp);
```

当文件写完后要重新从头读，常使用 `rewind`。

### 2. fseek

按指定位置移动文件指针：

```c
fseek(fp, offset, origin);
```

`origin` 的含义：

```text
0：从文件开头开始
1：从当前位置开始
2：从文件末尾开始
```

`offset` 为正表示向后移动，为负表示向前移动。

## 九、文件检测函数

### 1. feof

判断文件是否结束：

```c
feof(fp)
```

文件结束时返回非 0，否则返回 0。

常见写法：

```c
while (!feof(fp))
{
    读写操作;
}
```

### 2. ferror

检测文件读写是否出错：

```c
ferror(fp)
```

返回 0 表示没有出错，非 0 表示出错。

## 十、例题讲解

### 例题 1：写入后再读取

```c
FILE *fp;
char ch;

fp = fopen("t.txt", "w+");

ch = getchar();
while (ch != '\n')
{
    fputc(ch, fp);
    ch = getchar();
}

rewind(fp);

ch = fgetc(fp);
while (ch != EOF)
{
    putchar(ch);
    ch = fgetc(fp);
}

fclose(fp);
```

分析：

文件以 `w+` 方式打开，既能写又能读。写完后文件指针在文件末尾，因此读取前必须用 `rewind(fp)` 回到文件开头。

### 例题 2：建立 50 个素数的二进制文件

思路：

1. 先循环判断素数。
2. 收集前 50 个素数到数组。
3. 用 `fwrite` 写入二进制文件。
4. 用 `rewind` 回到开头。
5. 根据输入的序号定位并读取对应素数。

关键函数：

```c
fwrite(a, sizeof(int), 50, fp);
fseek(fp, (n - 1) * sizeof(int), 0);
fread(&p, sizeof(int), 1, fp);
```

### 例题 3：合并两个有序文件

思路：

两个文件中的数据都已升序排列。分别从两个文件中读取一个数据，比较后把较小者写入第三个文件，并继续从对应文件读取下一个数据。某个文件结束后，把另一个文件剩余数据继续写入。

## 十一、易错点

1. 打开文件后忘记关闭。

2. 文件路径中的反斜杠没有写成双反斜杠。

3. 写完文件后直接读取，忘记 `rewind`。

4. 打开方式选择错误。

   写入用 `"w"` 或 `"a"`，读取用 `"r"`，读写用带 `+` 的方式。

5. 二进制读写中 `sizeof` 和数据块个数写反。

6. `feof` 的返回值理解错误。

   文件结束时返回非 0，未结束时返回 0。

## 十二、本讲小结

本节课学习了文件的打开、关闭、读写、定位和检测。文件题要重点看清楚文件打开方式、读写函数、文件指针位置以及是否需要 `rewind` 或 `fseek`。
