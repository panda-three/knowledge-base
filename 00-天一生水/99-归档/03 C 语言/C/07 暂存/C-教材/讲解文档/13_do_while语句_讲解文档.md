# C语言 do while 循环结构课程讲解

## 一、课程导入

同学们好。本节课继续学习循环结构，重点是 `do while` 语句。

前面学习的 `while` 语句是先判断条件，再执行循环体。`do while` 与它不同，它是先执行循环体，再判断条件。因此，`do while` 循环至少会执行一次。

本节课学习目标：

1. 掌握 `do while` 语句的一般形式。
2. 理解 `do while` 与 `while` 的区别。
3. 能够分析 `do while` 程序的循环次数和输出结果。
4. 能够用 `do while` 完成累加、输入控制和数位处理问题。

## 二、do while 语句的一般形式

`do while` 语句的一般形式如下：

```c
do
{
    循环体语句;
} while (表达式);
```

执行过程：

1. 先执行一次循环体。
2. 再判断 `while` 后面表达式的值。
3. 如果表达式为非 0，继续执行循环体。
4. 如果表达式为 0，结束循环。

注意：`while (表达式)` 后面的分号不能省略。

## 三、do while 与 while 的区别

`while` 循环：

```c
while (条件)
{
    循环体;
}
```

先判断条件，条件成立才执行循环体。

`do while` 循环：

```c
do
{
    循环体;
} while (条件);
```

先执行一次循环体，再判断条件。

因此，二者最大的区别是：

```text
while 循环可能一次也不执行；
do while 循环至少执行一次。
```

## 四、例题讲解

### 例题 1：分析 do while 的执行次数

程序：

```c
int i = 1;

do
{
    printf("%d ", i);
    i++;
} while (i <= 5);
```

分析：

`i` 依次为 1、2、3、4、5 时都会输出。输出 5 后，`i++` 变为 6，再判断 `6 <= 5` 不成立，循环结束。

输出结果：

```text
1 2 3 4 5
```

### 例题 2：条件一开始不成立时的区别

`while` 写法：

```c
int i = 10;

while (i < 5)
{
    printf("%d", i);
    i++;
}
```

循环体一次也不执行。

`do while` 写法：

```c
int i = 10;

do
{
    printf("%d", i);
    i++;
} while (i < 5);
```

先输出一次 `10`，再判断条件，条件不成立后结束。

### 例题 3：用 do while 求累加和

题目：

```text
求 1 + 2 + ... + 100 的和。
```

参考程序：

```c
#include <stdio.h>

int main()
{
    int i = 1;
    int sum = 0;

    do
    {
        sum += i;
        i++;
    } while (i <= 100);

    printf("sum = %d\n", sum);
    return 0;
}
```

分析：

循环体中先累加，再让 `i` 自增。直到 `i` 变为 101 时，条件不成立，循环结束。

### 例题 4：输入字符直到换行结束

字符数组输入中经常使用 `do while`，因为至少需要先读入一个字符。

```c
int i = 0;
char a[50];

do
{
    scanf("%c", &a[i]);
} while (a[i++] != '\n');
```

分析：

程序先输入一个字符，再判断该字符是不是换行符。如果不是换行符，就继续输入下一个字符。

这里 `i++` 是后置自增，先使用当前下标判断，再让 `i` 向后移动。

### 例题 5：求一个整数的各位数字之和

参考程序：

```c
#include <stdio.h>

int main()
{
    int n, sum = 0;

    scanf("%d", &n);

    do
    {
        sum += n % 10;
        n /= 10;
    } while (n != 0);

    printf("sum = %d\n", sum);
    return 0;
}
```

分析：

`n % 10` 取个位，`n / 10` 去掉个位。因为一个整数至少有一位，所以使用 `do while` 很自然。

## 五、易错点

1. 忘记 `while` 后面的分号。

   `do while` 的结束形式是：

   ```c
   } while (条件);
   ```

2. 误以为 `do while` 可能一次也不执行。

   它一定先执行一次循环体。

3. 后置自增位置分析错误。

   如 `a[i++]`，先使用 `i` 的当前值，再让 `i` 加 1。

4. 循环条件写成终止条件。

   `while` 后面写的是“继续循环”的条件，不是“结束循环”的条件。

## 六、本讲小结

本节课学习了 `do while` 循环。它的特点是先执行、后判断，循环体至少执行一次。

在分析 `do while` 程序时，要从循环体第一句开始看，然后再判断条件，同时注意最后的分号和循环变量的变化。
