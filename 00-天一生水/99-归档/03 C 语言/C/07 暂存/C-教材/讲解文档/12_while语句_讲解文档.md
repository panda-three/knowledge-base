# C语言循环结构：while 语句课程讲解

## 一、课程导入

同学们好。本节课开始学习第五章循环结构程序设计。

C 语言程序设计主要有三种基本结构：顺序结构、选择结构和循环结构。前面我们已经学习了顺序结构和选择结构，本章重点学习循环结构。

循环结构用于处理重复执行的问题。例如求 `1 + 2 + ... + 100`，如果逐项写出表达式会非常繁琐，而使用循环只需要设计好初值、循环条件和变量变化即可。

本节课学习目标：

1. 理解循环结构的作用。
2. 掌握 `while` 语句的一般形式。
3. 理解 `while` 语句的执行流程。
4. 能够用 `while` 语句完成累加、累乘和条件重复问题。
5. 能够分析 `while` 程序的运行结果。

## 二、while 语句的一般形式

`while` 语句的一般形式如下：

```c
while (表达式)
{
    循环体语句;
}
```

执行过程：

1. 先判断 `while` 后面表达式的值。
2. 如果表达式为非 0，即条件成立，则执行循环体。
3. 循环体执行完后，再回到 `while` 处重新判断。
4. 如果表达式为 0，即条件不成立，则结束循环，执行循环后面的语句。

因此，`while` 循环的特点是：先判断，后执行。若第一次判断条件就不成立，循环体一次也不会执行。

## 三、例题讲解

### 例题 1：分析 while 循环结束时变量的值

程序：

```c
int i = 1;

while (i <= 100)
    i++;

printf("%d\n", i);
```

分析：

`i` 初值为 1。只要 `i <= 100` 成立，就执行 `i++`。

当 `i = 100` 时，条件仍然成立，进入循环后执行 `i++`，此时 `i` 变为 101。

再次判断时，`101 <= 100` 不成立，循环结束。

输出结果：

```text
101
```

### 例题 2：求 1 到 100 的累加和

程序：

```c
#include <stdio.h>

int main()
{
    int i = 1;
    int sum = 0;

    while (i <= 100)
    {
        sum += i;
        i++;
    }

    printf("sum = %d\n", sum);
    return 0;
}
```

分析：

`sum` 是累加器，初值应设为 0。`i` 是循环控制变量，初值为 1，每循环一次自增 1。

循环体中有两件事：

1. 将当前 `i` 累加到 `sum` 中。
2. 让 `i` 自增，准备下一次循环。

最后循环到 `i = 101` 时退出，此时 `sum` 保存的就是 `1 + 2 + ... + 100` 的值。

### 例题 3：求 n 的阶乘

题目：

```text
输入一个正整数 n，求 n!。
```

参考程序：

```c
#include <stdio.h>

int main()
{
    int n, m;
    long fact = 1;

    printf("请输入n：");
    scanf("%d", &n);

    m = n;
    while (m > 0)
    {
        fact *= m;
        m--;
    }

    printf("%d! = %ld\n", n, fact);
    return 0;
}
```

分析：

阶乘属于累乘问题。累乘器的初值必须设为 1，不能设为 0，否则结果永远为 0。

`fact *= m` 表示把当前的 `m` 乘到 `fact` 上。循环中 `m--`，直到 `m` 变为 0 时循环结束。

### 例题 4：输出指定次数的星号

程序：

```c
int i = 1;

while (i <= 10)
{
    printf("*");
    i += 2;
}
```

分析：

`i` 的变化为：

```text
1, 3, 5, 7, 9, 11
```

其中 1、3、5、7、9 都满足 `i <= 10`，因此循环执行 5 次，输出 5 个星号。

### 例题 5：人口增长问题

题目：

```text
某年人口为11.3亿，年增长率为1.35%。求哪一年人口超过13亿。
```

参考程序：

```c
#include <stdio.h>

int main()
{
    int year = 1991;
    double x = 11.3;

    while (x <= 13)
    {
        x = x * (1 + 0.0135);
        year++;
    }

    printf("%d年人口超过13亿，为%.2f亿\n", year, x);
    return 0;
}
```

分析：

题目问“超过 13 亿”的年份，所以循环条件应是“还没有超过 13 亿”，即 `x <= 13`。

### 例题 6：判断一个数是否为素数

参考程序：

```c
#include <stdio.h>

int main()
{
    int x, i = 2;

    scanf("%d", &x);

    while (x % i != 0)
        i++;

    if (i == x)
        printf("yes\n");
    else
        printf("no\n");

    return 0;
}
```

分析：

从 2 开始试除。如果一直除到 `i == x` 才能整除，说明它只能被 1 和自身整除，是素数。如果在中途就被某个 `i` 整除，则不是素数。

## 四、易错点

1. 忘记改变循环控制变量。

   如果循环体中没有 `i++`、`i--` 等变化，可能形成死循环。

2. 累加器和累乘器初值混淆。

   累加器初值通常为 0，累乘器初值通常为 1。

3. 循环条件写反。

   例如人口题中，循环条件应写“未超过时继续计算”，不是“超过时继续计算”。

4. 忽略单位换算。

   纸张对折题中，纸厚是毫米，珠峰高度是米，必须统一单位后再比较。

## 五、本讲小结

本节课学习了 `while` 循环。`while` 循环先判断条件，再执行循环体，适合处理循环次数不一定固定、需要根据条件决定是否继续的问题。

分析 `while` 程序时，要重点关注三个要素：循环变量初值、循环条件、循环体中变量的变化。
