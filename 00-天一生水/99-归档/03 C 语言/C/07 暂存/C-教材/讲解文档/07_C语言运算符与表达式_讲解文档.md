# C语言运算符与表达式课程讲解

## 一、课程导入

同学们好，本节课学习第二章“数据类型和表达式”的第三个课时：运算符和表达式。

在前面的学习中，我们已经了解了数据类型、常量和变量的使用方法。本节课主要学习运算符的运算规则、优先级和结合性，并掌握表达式的组成及应用。

本节课学习目标：

2. 掌握算术运算符的使用规则。

7. 理解自动类型转换和强制类型转换。

## 二、运算符的概念

在程序中，对变量或常量进行处理的符号称为运算符。

例如：

```c
a + b
x = 3
i++
```

其中，`+`、`=`、`++` 都是运算符。

C 语言提供了丰富的运算符，按功能可以分为：

1. 算术运算符
2. 关系运算符
3. 逻辑运算符
4. 赋值运算符
5. 逗号运算符
6. 位运算符
7. 条件运算符

不同运算符要求的操作数个数不同。根据操作数个数，运算符可以分为三类：

单目运算符：只有一个操作数，例如 `-a`、`++i`、`sizeof`。

双目运算符：有两个操作数，例如 `a + b`、`a = b`。

三目运算符：有三个操作数，C 语言中典型的是条件运算符 `?:`。

运算符具有不同的优先级。同一优先级的运算符，运算次序由结合性决定。

结合性是指：当一个操作数左右两边的运算符优先级相同时，应该先向哪个方向结合。结合性主要分为左结合和右结合。

## 三、表达式的概念

表达式是由运算符、括号和操作数组成的式子。

操作数可以是：

1. 常量
2. 变量
3. 函数调用

例如：

```c
a + b
(x + y) * 3
abs(c) + 18
```

每个表达式不管多么复杂，都可以根据运算符的优先级、结合性和数据类型转换规则，计算出唯一的值。

表达式值的类型，就是表达式的类型。

C 语言表达式按功能可以分为：

1. 算术表达式
2. 赋值表达式
3. 关系表达式
4. 逻辑表达式
5. 条件表达式
6. 逗号表达式

其中，关系表达式和逻辑表达式会在选择结构程序设计中进一步学习。

## 四、算术运算符

C 语言常用的算术运算符包括：

```text
+    求正
-    求负
+    加法
-    减法
*    乘法
/    除法
%    求模，也叫取余
```

这里要区分：

单目 `+` 表示求正。

单目 `-` 表示求负。

双目 `+` 表示加法。

双目 `-` 表示减法。

### 1. 加、减、乘、除

加、减、乘、除的运算规则与数学中基本相同。

例如：

```c
a + b
a - b
a * b
a / b
```

需要注意，C 语言中乘号写作 `*`，不能写成数学中的 `×`。

除法写作 `/`，这是从左上到右下的斜杠，不是反斜杠 `\`。

### 2. 求模运算

求模运算符是：

```c
%
```

它的作用是求两个整数相除后的余数。

例如：

```c
5 % 3
```

表示 5 除以 3 的余数，结果为 2。

求模运算要求两边的操作数都为整数，并且除数不能为 0。

余数的符号始终与被除数，也就是分子的符号一致。

例如：

```c
5 % 3      // 结果为 2
-5 % 3     // 结果为 -2
-5 % -3    // 结果为 -2
5 % -3     // 结果为 2
```

### 3. 求正和求负

求正和求负是单目运算符。

例如：

```c
+a
-a
```

`-a` 表示求 `a` 的相反数。

因为单目运算符只作用于一个操作数，所以优先级较高，结合性是从右向左。

## 五、算术运算优先级

算术运算中，括号优先级最高。

例如：

```c
a + 4 * 5
```

先计算 `4 * 5`，再与 `a` 相加。

如果写成：

```c
(a + 4) * 5
```

则先计算括号中的 `a + 4`，再乘以 5。

算术运算符的优先级大致为：

1. 括号最高。
2. 单目求正、求负较高。
3. 乘法、除法、求模高于加法、减法。
4. 加法、减法优先级较低。

当同一级别的运算符连续出现时，通常按照结合性从左向右计算。

例如：

```c
a - b * c + d
```

先计算 `b * c`，再计算 `a - b * c`，最后加上 `d`。

## 六、除法运算规则

除法运算需要重点注意数据类型。

如果两个操作数都是整数，那么结果也是整数，直接舍去小数部分，不进行四舍五入。

例如：

```c
5 / 2
```

结果为：

```text
2
```

如果两个操作数中至少有一个是实型，那么结果就是实型。

例如：

```c
5 / 2.0
```

结果为：

```text
2.5
```

如果除法结果为负数，也是向 0 方向舍入。

例如：

```c
-5 / 2
```

结果为：

```text
-2
```

因为 `-5 / 2` 的数学结果是 `-2.5`，整数除法会向 0 舍入，得到 `-2`。

## 七、算术表达式练习

### 练习 1

```c
8 / 5
```

两个操作数都是整数，结果取整。

答案：

```text
1
```

### 练习 2

```c
7 % 2
```

7 除以 2，余数为 1。

答案：

```text
1
```

### 练习 3

设：

```c
int x = -1;
```

求：

```c
x + 3 / 2
```

先计算 `3 / 2`。由于两个操作数都是整数，结果为 1。

所以：

```text
-1 + 1 = 0
```

### 练习 4

设：

```c
int a = 16, b = 3, c = 12;
```

求：

```c
b * c % a
```

乘法和求模同级，从左向右计算。

先算：

```c
b * c = 3 * 12 = 36
```

再算：

```c
36 % 16 = 4
```

答案为 4。

### 练习 5

设：

```c
int x = 245;
```

求：

```c
x / 100 % 9
```

先算：

```c
245 / 100 = 2
```

再算：

```c
2 % 9 = 2
```

答案为 2。

## 八、自增和自减运算符

自增运算符：

```c
++ 
```

自减运算符：

```c
--
```

它们都是单目运算符，作用是使变量的值增加 1 或减少 1。

例如：

```c
++k
k++
--k
k--
```

自增、自减运算只能用于变量，不能用于常量或表达式。

错误写法：

```c
3++;
(a + b)++;
```

自增、自减运算符优先级较高，结合性从右向左。

## 九、前置与后置的区别

自增、自减运算符可以写在变量前面，也可以写在变量后面。

写在变量前面，称为前置运算。

写在变量后面，称为后置运算。

### 1. 前置运算

前置运算是先改变变量的值，再参与其他运算。

例如：

```c
y = ++x;
```

表示先让 `x` 加 1，再把新的 `x` 值赋给 `y`。

### 2. 后置运算

后置运算是先使用变量当前值参与运算，再改变变量的值。

例如：

```c
y = x++;
```

表示先把 `x` 当前值赋给 `y`，再让 `x` 加 1。

## 十、自增自减例题

### 例 1

设：

```c
int x = 9, y;
y = x++;
```

`x++` 是后置自增，先使用 `x` 的值，再自增。

所以：

```text
y = 9
x = 10
```

### 例 2

设：

```c
int x = 9, y;
y = ++x;
```

`++x` 是前置自增，先自增，再赋值。

所以：

```text
x = 10
y = 10
```

### 例 3

设：

```c
int k1 = 10, k2 = 10;
int x, y;
x = k1++;
y = ++k2;
```

`x = k1++;` 先把 `k1` 的值 10 赋给 `x`，再让 `k1` 变成 11。

`y = ++k2;` 先让 `k2` 变成 11，再赋给 `y`。

结果：

```text
x = 10
y = 11
k1 = 11
k2 = 11
```

### 例 4

设：

```c
int k1 = 10, k2 = 10;
int x, y;
x = --k1;
y = k2--;
```

`--k1` 是前置自减，先减 1，再赋给 `x`。

`k2--` 是后置自减，先把当前值赋给 `y`，再减 1。

结果：

```text
x = 9
y = 10
k1 = 9
k2 = 9
```

## 十一、sizeof 运算符

`sizeof` 是长度运算符，用于求数据类型或表达式所占的字节数。

它是单目运算符，优先级较高，结合性从右向左。

常见形式：

```c
sizeof(类型名)
sizeof(表达式)
```

例如：

```c
sizeof(int)
```

表示求 `int` 类型所占的字节数。

如果在当前编译环境中 `int` 占 4 个字节，那么结果就是 4。

再如：

```c
sizeof(3 + 4)
```

`3 + 4` 的结果是整数 7，因此整个表达式的类型是 `int`，所占字节数通常为 4。

`sizeof` 的结果一定是一个整数，单位是字节。

## 十二、赋值运算符

赋值运算符是：

```c
=
```

它不是数学中的等于号，而是赋值号。

作用是把右边表达式的值赋给左边变量。

例如：

```c
a = 3;
```

表示把 3 赋给变量 `a`，执行后 `a` 的值为 3。

赋值运算符是双目运算符，优先级较低，结合性从右向左。

赋值运算符左边必须是变量，右边可以是常量、变量或表达式。

例如：

```c
r = x % y;
```

表示把 `x` 除以 `y` 的余数赋给变量 `r`。

## 十三、赋值中的类型转换

如果赋值号左右两边的数据类型不一致，系统会把右边表达式的值转换成左边变量的类型，再进行赋值。

例如：

```c
int x;
x = 'a' - 32;
```

字符 `'a'` 的 ASCII 码是 97。

`97 - 32 = 65`。

所以 `x` 的值为 65。

再如：

```c
int y;
y = 8.7 + 4.9;
```

右边结果为：

```text
13.6
```

但 `y` 是整型变量，只能接收整数部分，因此小数部分直接舍去，`y` 的值为 13。

注意，这里不会四舍五入。

## 十四、复合赋值运算符

复合赋值运算符是在赋值运算符前加上其他运算符构成的。

常见复合赋值运算符有：

```c
+=
-=
*=
/=
%=
```

例如：

```c
x += 3;
```

等价于：

```c
x = x + 3;
```

再如：

```c
y *= y + z;
```

等价于：

```c
y = y * (y + z);
```

需要注意，复合赋值运算符右边的表达式通常作为一个整体参与运算。

例如：

```c
a -= a * a;
```

等价于：

```c
a = a - a * a;
```

复合赋值运算在考试中经常出现，需要能够读懂。平时初学编程时，为了减少错误，可以优先使用普通赋值形式。

## 十五、赋值与复合赋值例题

### 例 1

```c
int x = 3, y;
y = x * 3;
```

`x * 3 = 9`，所以 `y = 9`。

### 例 2

```c
int a, c;
a = 5 + (c = 6);
```

先执行：

```c
c = 6
```

再计算：

```c
5 + 6 = 11
```

所以：

```text
c = 6
a = 11
```

### 例 3

```c
int y = 4, z = 3;
y / z
```

两个操作数都是整数，`4 / 3` 结果取整，为 1。

### 例 4

设：

```c
int a = 10;
a -= a * a;
a += a;
```

第一句：

```c
a -= a * a;
```

等价于：

```c
a = a - a * a;
```

即：

```text
a = 10 - 100 = -90
```

第二句：

```c
a += a;
```

等价于：

```c
a = a + a;
```

即：

```text
a = -90 + (-90) = -180
```

最终 `a` 的值为 `-180`。

### 例 5

```c
int a = 0x10;
int b = a + 023;
```

`0x10` 是十六进制数，对应十进制 16。

`023` 是八进制数，对应十进制：

```text
2 * 8 + 3 = 19
```

所以：

```text
b = 16 + 19 = 35
```

如果把 35 转换为十六进制，结果是：

```text
0x23
```

### 例 6

设：

```c
int a = 10, b = 9, c = 8;
c = a -= b -= 5;
```

赋值运算和复合赋值运算从右向左结合。

先算：

```c
b -= 5;
```

即：

```text
b = 9 - 5 = 4
```

再算：

```c
a -= b;
```

即：

```text
a = 10 - 4 = 6
```

最后：

```c
c = a;
```

所以：

```text
a = 6
b = 4
c = 6
```

### 例 7

设：

```c
int a = 10, b = 9, c = 8;
c = a % 11 + (b += 3);
```

先算：

```c
a % 11
```

10 除以 11，没有除成，余数仍为 10。

再算：

```c
b += 3
```

即：

```text
b = 9 + 3 = 12
```

最后：

```text
c = 10 + 12 = 22
```

结果：

```text
a = 10
b = 12
c = 22
```

### 例 8

设：

```c
double d = 3.2;
int x, y;
x = 1.2;
y = (x + 3.8) / 5.0;
d *= y;
```

`x` 是整型变量，执行 `x = 1.2;` 时，小数部分被舍去，所以 `x = 1`。

`x + 3.8 = 1 + 3.8 = 4.8`。

`4.8 / 5.0 = 0.96`。

`y` 是整型变量，所以 `y = 0`。

`d *= y` 等价于：

```c
d = d * y;
```

即：

```text
d = 3.2 * 0 = 0
```

最终 `d` 的值为 0。

## 十六、逗号运算符与逗号表达式

逗号运算符用于把若干表达式连接起来。

例如：

```c
表达式1, 表达式2, 表达式3
```

逗号表达式从左到右依次求值，整个表达式的值取最后一个表达式的值。

例如：

```c
a = 3, b = 5, c = a * b
```

先执行：

```c
a = 3
```

再执行：

```c
b = 5
```

最后执行：

```c
c = a * b
```

所以 `c = 15`，整个逗号表达式的值也是 15。

逗号表达式也称为顺序求解表达式。

需要注意，逗号运算符的优先级很低，比赋值运算符还低。

例如：

```c
a = 3 * 5, a * 4
```

先算赋值：

```c
a = 15
```

再算：

```c
a * 4 = 60
```

所以整个逗号表达式的值是 60，但 `a` 的值仍然是 15。

再如：

```c
x = (a = 3, a + 15);
```

括号内先执行 `a = 3`，再计算 `a + 15 = 18`，整个括号表达式的值为 18，赋给 `x`。

因此：

```text
a = 3
x = 18
```

## 十七、条件运算符

条件运算符是：

```c
?:
```

它是 C 语言中唯一的三目运算符。

基本形式：

```c
表达式1 ? 表达式2 : 表达式3
```

含义是：

如果表达式 1 为真，则整个表达式的值为表达式 2 的值；否则，整个表达式的值为表达式 3 的值。

例如：

```c
a > 3 ? 1 : 0
```

表示如果 `a > 3` 成立，结果为 1；否则结果为 0。

再如：

```c
max = a > b ? a : b;
```

表示如果 `a > b` 成立，就把 `a` 的值赋给 `max`；否则把 `b` 的值赋给 `max`。

这个表达式可以用来求两个数中的较大值。

条件运算符优先级高于赋值运算符和逗号运算符，结合性从右向左。

## 十八、自动类型转换

当不同类型的数据混合运算时，系统会自动进行类型转换。

一般原则是：把精度较低、范围较小的类型转换为精度较高、范围较大的类型，再进行运算。

例如：

```c
int + double
```

系统会先把 `int` 转换为 `double`，再进行运算。

常见转换方向可以理解为：

```text
char、short -> int -> float -> double
```

例如，`float` 和 `double` 运算时，通常向 `double` 类型看齐。

字符型和短整型参与运算时，通常先转换为整型。

## 十九、强制类型转换

强制类型转换是程序员明确要求把某个表达式转换为指定类型。

基本形式：

```c
(类型名) 表达式
```

例如：

```c
(int)x
```

表示把 `x` 的值强制转换为整型。

### 例 1

```c
float x = 13.456;
int y;
y = (int)x;
```

`(int)x` 得到一个整型中间值 13，所以 `y = 13`。

但是，强制类型转换不会改变变量 `x` 本身的类型和值。

因此：

```text
x 仍然是 13.456
y 是 13
```

强制类型转换得到的是一个所需类型的中间量，原变量不变。

### 例 2

设：

```c
float x = 3.2, y = 3.9;
int a = 10, z;
```

求：

```c
z = x + a % 3 + (int)(x + y) % 2 / 4;
```

分析：

`a % 3 = 10 % 3 = 1`。

`x + y = 3.2 + 3.9 = 7.1`。

`(int)(x + y)` 得到 7。

`7 % 2 = 1`。

`1 / 4` 是整数除法，结果为 0。

所以右边表达式为：

```text
3.2 + 1 + 0 = 4.2
```

如果最终赋给整型变量 `z`，小数部分舍去，所以：

```text
z = 4
```

做这类题目时，要特别注意每一步结果的类型。

## 二十、本讲小结

本节课主要学习了 C 语言中的运算符和表达式。

需要重点掌握：

1. 运算符是对变量或常量进行处理的符号。
2. 表达式由运算符、括号和操作数组成，并能求出唯一的值。
3. 算术运算中，乘、除、求模优先级高于加、减。
4. 整数除以整数，结果仍为整数，小数部分直接舍去。
5. 求模运算要求两边都是整数，余数符号与被除数一致。
6. 自增自减只能用于变量，不能用于常量或表达式。
7. 前置自增先改变后使用，后置自增先使用后改变。
8. `sizeof` 用于求类型或表达式所占字节数。
9. 赋值号 `=` 表示赋值，不是数学中的等于。
10. 复合赋值运算符要注意等价展开。
11. 逗号表达式从左到右求值，整体值取最后一个表达式的值。
12. 条件表达式根据条件真假选择第二或第三个表达式的值。
13. 类型转换包括自动类型转换和强制类型转换。
