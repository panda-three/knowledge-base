# C语言 if 语句嵌套知识点讲解与例题练习

## 一、课程导入

同学们好，上一节课我们学习了 `if` 语句的使用方法，以及 `if` 语句的多种形式，包括单分支、双分支和多分支结构。

本节课继续学习 `if` 语句的嵌套。

在实际程序中，一个判断条件内部还可能包含新的判断条件。例如，先判断某个条件是否成立，如果成立，再继续判断另一个条件。这种情况就需要使用 `if` 语句嵌套。

本节课学习目标：

2. 理解 `if` 语句嵌套的概念。
3. 掌握 `else` 与 `if` 的配对规则。
4. 能够分析嵌套 `if` 程序的执行过程。

## 二、if 语句使用规则复习

在 `if` 语句中，`if` 后面的表达式通常是关系表达式或逻辑表达式，但也可以是其他表达式。

例如：

```c
if (a = 5)
    printf("OK");
```

这里 `a = 5` 是赋值表达式，不是判断相等。它先把 5 赋给 `a`，表达式的值为 5。由于 5 是非 0 值，所以条件成立。

再如：

```c
if (b)
    printf("OK");
```

这里的含义是：当 `b` 的值不等于 0 时，条件成立。

C 语言中，`if` 条件表达式的判断规则是：

表达式值为 0，表示假。

表达式值为非 0，表示真。

还要注意：

第一，`if` 后面的条件表达式必须用小括号括起来。

第二，`if` 或 `else` 后面要执行的语句必须以分号结束。

第三，如果 `if` 或 `else` 后面只有一条语句，可以不用花括号。

第四，如果要执行的语句不止一条，必须用花括号 `{ }` 括起来，构成复合语句。

第五，复合语句在逻辑上被视为一条语句，右花括号后面一般不再加分号。

第六，`else` 子句不能单独使用，它必须作为 `if` 语句的一部分，与 `if` 配对使用。

## 三、if 语句嵌套的概念

如果 `if` 语句中的执行语句又是一个 `if` 语句，就构成了 `if` 语句的嵌套。

例如：

```c
if (表达式1)
    if (表达式2)
        语句1;
    else
        语句2;
```

这里，外层 `if` 的语句部分又包含了一个内层 `if ... else` 语句，因此构成嵌套。

在嵌套结构中，可能出现多个 `if` 和多个 `else`，这时要特别注意 `if` 和 `else` 的配对关系。

## 四、else 的配对规则

C 语言规定：

`else` 总是与它前面最近的、尚未配对的 `if` 配对。

例如：

```c
if (表达式1)
    if (表达式2)
        语句1;
    else
        语句2;
```

这里的 `else` 与内层的 `if (表达式2)` 配对，而不是与外层的 `if (表达式1)` 配对。

它等价于：

```c
if (表达式1)
{
    if (表达式2)
        语句1;
    else
        语句2;
}
```

可以这样理解：

如果表达式 1 成立，才进入内层判断。

进入内层后，如果表达式 2 成立，执行语句 1；否则执行语句 2。

如果表达式 1 不成立，内层的 `if ... else` 整体都不执行。

为了避免歧义，建议初学时在嵌套结构中主动使用花括号。

## 五、例题：两个整数从大到小输出

题目：输入两个整数，按从大到小的顺序输出。

思路：

输入两个整数 `x` 和 `y`。

如果 `x < y`，说明前面的数比后面的数小，需要交换。

如果 `x >= y`，说明已经是从大到小的顺序，不需要交换。

程序如下：

```c
#include <stdio.h>

int main(void)
{
    int x, y, c;

    scanf("%d%d", &x, &y);

    if (x < y)
    {
        c = x;
        x = y;
        y = c;
    }

    printf("%d %d\n", x, y);

    return 0;
}
```

程序分析：

如果输入 `3 4`，因为 `3 < 4` 成立，所以交换两个变量的值，最后输出 `4 3`。

如果输入 `13 4`，因为 `13 < 4` 不成立，所以不交换，直接输出 `13 4`。

交换语句包含三条语句，因此必须用花括号括起来。

## 六、例题：比较两个数的大小

题目：输入两个整数，输出它们之间的大小关系。

两个数之间有三种关系：

1. 大于
2. 小于
3. 等于

程序写法一：先判断是否不相等。

```c
#include <stdio.h>

int main(void)
{
    int a, b;

    scanf("%d%d", &a, &b);

    if (a != b)
    {
        if (a > b)
            printf("a>b\n");
        else
            printf("a<b\n");
    }
    else
    {
        printf("a=b\n");
    }

    return 0;
}
```

程序分析：

如果 `a != b` 成立，说明两个数不相等，再继续判断 `a > b` 是否成立。

如果 `a > b` 成立，输出 `a>b`。

否则，在不相等的前提下，只能是 `a < b`，输出 `a<b`。

如果 `a != b` 不成立，说明 `a == b`，输出 `a=b`。

程序写法二：先判断是否相等。

```c
#include <stdio.h>

int main(void)
{
    int a, b;

    scanf("%d%d", &a, &b);

    if (a == b)
        printf("a=b\n");
    else
    {
        if (a > b)
            printf("a>b\n");
        else
            printf("a<b\n");
    }

    return 0;
}
```

这两个程序功能相同，只是判断顺序不同。

分析嵌套程序时，可以把变量值代入程序，逐步判断，这样更容易看清执行流程。

## 七、if 嵌套书写建议

嵌套 `if` 语句虽然能够表达复杂判断，但嵌套层数过多会降低程序可读性。

一般情况下，能用多分支 `else if` 结构表达的，尽量使用 `else if`，少写过深的嵌套结构。

例如成绩等级判断：

```c
if (score >= 90)
    printf("A\n");
else if (score >= 80)
    printf("B\n");
else if (score >= 70)
    printf("C\n");
else if (score >= 60)
    printf("D\n");
else
    printf("E\n");
```

这种结构通常比多层嵌套更清晰。

## 八、例题：分段函数求值

题目：输入 `x` 的值，按下面规则计算并输出函数值 `f`。

```text
x >= 5       f = 2 * x
0 <= x < 5   f = 2 * x + 1
x < 0        f = 2 * x - 1
```

程序如下：

```c
#include <stdio.h>

int main(void)
{
    int x, f;

    scanf("%d", &x);

    if (x >= 5)
        f = 2 * x;
    else
    {
        if (x >= 0)
            f = 2 * x + 1;
        else
            f = 2 * x - 1;
    }

    printf("x=%d, f=%d\n", x, f);

    return 0;
}
```

程序分析：

先判断 `x >= 5`。

如果成立，直接计算 `f = 2 * x`。

如果不成立，说明 `x < 5`，再判断 `x >= 0`。

如果 `x >= 0` 成立，说明 `0 <= x < 5`，计算 `f = 2 * x + 1`。

否则说明 `x < 0`，计算 `f = 2 * x - 1`。

也可以写成多分支结构：

```c
if (x >= 5)
    f = 2 * x;
else if (x >= 0)
    f = 2 * x + 1;
else
    f = 2 * x - 1;
```

这种写法更简洁。

## 九、例题：按整除条件求函数值

题目：输入整数 `x`，按以下规则计算 `y`：

```text
如果 x 能同时被 7 和 9 整除，y = x + 63
如果 x 不能被 7 整除，y = 7 * x
其他情况，y = x
```

分析：

能被 7 整除，可以写成：

```c
x % 7 == 0
```

能被 9 整除，可以写成：

```c
x % 9 == 0
```

程序如下：

```c
#include <stdio.h>

int main(void)
{
    int x, y;

    scanf("%d", &x);

    if (x % 7 == 0)
    {
        y = x;
        if (x % 9 == 0)
            y = x + 63;
    }
    else
    {
        y = 7 * x;
    }

    printf("%d\n", y);

    return 0;
}
```

程序分析：

如果 `x` 不能被 7 整除，直接执行 `y = 7 * x`。

如果 `x` 能被 7 整除，先把 `y` 赋值为 `x`。

然后继续判断是否能被 9 整除。

如果也能被 9 整除，说明同时满足被 7 和 9 整除，执行 `y = x + 63`。

例如：

输入 `6`，不能被 7 整除，`y = 7 * 6 = 42`。

输入 `21`，能被 7 整除，但不能被 9 整除，`y = 21`。

输入 `126`，既能被 7 整除，又能被 9 整除，`y = 126 + 63 = 189`。

## 十、例题：闰年判断

题目：输入一个年份，判断它是否是闰年。

闰年判断规则：

四年一闰，百年不闰，四百年又闰。

也就是：

能被 4 整除但不能被 100 整除，或者能被 400 整除，就是闰年。

表达式写作：

```c
(year % 4 == 0 && year % 100 != 0) || year % 400 == 0
```

## 十一、闰年判断写法一：使用标志变量

可以使用一个标志变量 `leap` 表示是否为闰年。

先假设不是闰年，把 `leap` 置为 0。

如果判断出是闰年，再把 `leap` 置为 1。

程序如下：

```c
#include <stdio.h>

int main(void)
{
    int year, leap = 0;

    printf("Input the year:");
    scanf("%d", &year);

    if (year % 4 == 0)
    {
        if (year % 100 != 0)
            leap = 1;
        else
        {
            if (year % 400 == 0)
                leap = 1;
        }
    }

    if (leap)
        printf("%d is a leap year\n", year);
    else
        printf("%d is not a leap year\n", year);

    return 0;
}
```

程序分析：

`leap = 0` 表示默认不是闰年。

如果满足闰年条件，才把 `leap` 改为 1。

最后根据 `leap` 的值输出结果。

例如：

1500 年能被 4 整除，也能被 100 整除，但不能被 400 整除，所以不是闰年。

2024 年能被 4 整除，不能被 100 整除，所以是闰年。

2400 年能被 400 整除，所以是闰年。

## 十二、闰年判断写法二：嵌套判断

也可以直接使用嵌套 `if` 输出结果。

```c
#include <stdio.h>

int main(void)
{
    int year;

    scanf("%d", &year);

    if (year % 4 == 0)
    {
        if (year % 100 == 0)
        {
            if (year % 400 == 0)
                printf("%d is a leap year\n", year);
            else
                printf("%d is not a leap year\n", year);
        }
        else
        {
            printf("%d is a leap year\n", year);
        }
    }
    else
    {
        printf("%d is not a leap year\n", year);
    }

    return 0;
}
```

这种写法更接近“能被 4 整除，再判断是否为百年，百年再判断是否能被 400 整除”的思路。

## 十三、闰年判断写法三：逻辑表达式优化

最简洁的写法是使用逻辑表达式：

```c
#include <stdio.h>

int main(void)
{
    int year;

    scanf("%d", &year);

    if ((year % 4 == 0 && year % 100 != 0) || year % 400 == 0)
        printf("%d is a leap year\n", year);
    else
        printf("%d is not a leap year\n", year);

    return 0;
}
```

这个表达式要重点掌握：

```c
(year % 4 == 0 && year % 100 != 0) || year % 400 == 0
```

其中：

`year % 4 == 0` 表示能被 4 整除。

`year % 100 != 0` 表示不能被 100 整除。

`year % 400 == 0` 表示能被 400 整除。

前半部分表示“四年一闰，百年不闰”。

后半部分表示“四百年又闰”。

## 十四、例题：嵌套 if 执行过程分析

分析嵌套程序时，要按顺序执行，并及时更新变量值。

例如：

```c
int x = 1, y = -2, z = 3;

if ((z = y) < 0)
    x = 2;
else
    x = 3;

if (y)
    x = 8;

if (x < y < z)
    x = 10;
else
    x = 12;

printf("%d,%d,%d\n", x, y, z);
x = z = y;
printf("%d,%d,%d\n", x, y, z);
```

分析：

第一句判断中，`z = y` 是赋值表达式，把 `y` 的值 `-2` 赋给 `z`，所以 `z = -2`。

`(z = y) < 0` 成立，因此 `x = 2`。

接着，`if (y)` 中 `y = -2`，是非 0 值，条件成立，所以 `x = 8`。

然后判断：

```c
x < y < z
```

它不能按数学连续不等式理解，应从左向右计算。

先算：

```c
8 < -2
```

不成立，结果为 0。

再算：

```c
0 < -2
```

也不成立，所以执行 `else`，`x = 12`。

第一次输出：

```text
12,-2,-2
```

然后执行：

```c
x = z = y;
```

赋值运算从右向左，`y` 的值 `-2` 先赋给 `z`，再赋给 `x`。

第二次输出：

```text
-2,-2,-2
```

## 十五、例题：if 后多条语句是否受控制

观察两段程序。

程序一：

```c
int a = 20, b = 30, c = 10;

if (a > b)
{
    c = a;
    a = b;
    b = c;
}

printf("%d,%d\n", a, b);
```

因为 `20 > 30` 不成立，花括号中的三条语句都不执行。

所以输出：

```text
20,30
```

程序二：

```c
int a = 20, b = 30, c = 10;

if (a > b)
    c = a;
a = b;
b = c;

printf("%d,%d\n", a, b);
```

这里 `if` 后面没有花括号，它只控制紧跟着的第一条语句：

```c
c = a;
```

因为 `20 > 30` 不成立，所以 `c = a;` 不执行。

但是后面的：

```c
a = b;
b = c;
```

不受 `if` 控制，仍然会执行。

于是：

`a = b` 后，`a = 30`。

`b = c` 后，`b = 10`。

输出：

```text
30,10
```

这个例题说明：如果希望多条语句都由 `if` 控制，必须使用花括号。

## 十六、例题：连续关系表达式与逻辑表达式

设：

```c
int a = -3, b = -2, c = 0;
```

判断：

```c
if (a < b < c)
    printf("T");
else
    printf("F");
```

先计算：

```c
-3 < -2
```

成立，结果为 1。

再计算：

```c
1 < 0
```

不成立，所以输出：

```text
F
```

如果要表达数学中的：

```text
a < b 且 b < c
```

应写成：

```c
if (a < b && b < c)
    printf("T");
else
    printf("F");
```

因为 `-3 < -2` 成立，且 `-2 < 0` 成立，所以输出：

```text
T
```

## 十七、例题：字符范围判断

设：

```c
char a = 'a';
int t = 10;
```

判断：

```c
if (!(a < 'a' || a > 'z'))
    t++;
```

分析：

`a < 'a'` 不成立。

`a > 'z'` 也不成立。

所以：

```c
a < 'a' || a > 'z'
```

结果为 0。

再取反：

```c
!0
```

结果为 1。

所以 `if` 条件成立，执行 `t++`。

最终 `t = 11`。

这个表达式的含义是：如果字符 `a` 不在小写字母范围之外，也就是它在 `'a'` 到 `'z'` 之间。

更直观的写法是：

```c
if (a >= 'a' && a <= 'z')
    t++;
```

## 十八、常见错误与改错

### 1. if 后多条语句没有加花括号

错误写法：

```c
if (条件)
    语句1;
    语句2;
else
    语句3;
```

这里 `if` 实际只控制 `语句1`，`语句2` 不属于 `if`。同时，`else` 也可能因为配对错误导致语法错误。

如果要让 `语句1` 和 `语句2` 都属于 `if` 分支，应写成：

```c
if (条件)
{
    语句1;
    语句2;
}
else
{
    语句3;
}
```

### 2. else 配对不清

嵌套结构中，`else` 默认与最近的未配对 `if` 配对。

如果希望 `else` 与外层 `if` 配对，必须使用花括号明确结构。

例如：

```c
if (a)
{
    if (b)
        printf("b");
}
else
{
    printf("a is false");
}
```

这里的 `else` 与外层 `if (a)` 配对。

### 3. if 后误加分号

错误写法：

```c
if (条件);
    语句;
```

分号构成空语句，导致 `if` 控制的是空语句，后面的 `语句` 会无条件执行。

正确写法：

```c
if (条件)
    语句;
```

本节课主要学习了 `if` 语句的嵌套。

需要重点掌握：

1. `if` 后面的表达式可以是关系表达式、逻辑表达式，也可以是赋值表达式、变量或常量。
2. 表达式值为 0 表示假，非 0 表示真。
3. `else` 不能单独使用，必须与 `if` 配对。
4. `else` 总是与前面最近的、尚未配对的 `if` 配对。

7. 判断闰年的核心表达式是 `(year % 4 == 0 && year % 100 != 0) || year % 400 == 0`。
8. 连续关系表达式不能按数学形式理解，应使用逻辑与连接多个条件。
9. `if` 后面不要误加分号。
