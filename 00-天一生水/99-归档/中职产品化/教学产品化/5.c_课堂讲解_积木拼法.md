# 5.c 课堂讲解：顺着题目拼积木

## 这道题的做法
5.c 容易让人以为只是“找单词”。其实它是三件事连在一起：

```md
先切单词
→ 再算每个单词的 ASCII 和
→ 再筛素数和值，最后排序
```

所以这道题不只是字符串题，它还混进了整数判断和排序。

先按这个顺序看：

```md
读题干 → 看参数 → 选积木 → 拼代码 → 检查结果
```

---

## 一、题目要我们做什么

> 先把原题题干放在最前面，方便我们一边看讲解，一边对照题目要求。

```c
/*----------------------------------------------------------------------
```

# 二、先看函数参数长什么样

## 1. `int wordsearch(char str[], char words[][N], int sum[])`

### 调用位置
```c
n = wordsearch(str, words, sum);
```

### 传进来的 `str[]` 长什么样
```c
"I used that size prime spank of bread to make a delicious sandwich"
```

它是由空格隔开的英文单词串。

### `words[][N]` 和 `sum[]` 要变成什么
题目要求：

```md
只保留 ASCII 和是素数的单词
```

所以函数执行后：

```md
words 里放符合条件的单词
sum   里放对应单词的 ASCII 和
```

例如：

```md
I      73
used   433
that   433
size   443
prime  541
spank  541
to     227
a      97
```

函数返回这些单词的个数。

---

## 2. `void sort(char words[][N], int n, int sum[])`

### 调用位置
```c
sort(words, n, sum);
```

### 排序前长什么样
调用前，`words` 和 `sum` 已经一一对应。

### 排序后要变成什么
先按 `sum` 升序；如果 `sum` 相同，再按字典序升序。

最后应该是：

```md
I->73
a->97
to->227
that->433
used->433
size->443
prime->541
spank->541
```

# 三、拼 `wordsearch()`：提取符合条件的单词

## 目标
从原始句子里，找出 ASCII 和是素数的单词。

这一步不是直接筛字符，而是：

```md
先拿到一个完整单词
再算这个单词的 ASCII 和
再判断这个和是不是素数
```

---

## 第一步：整串从左到右扫

用 **积木1：扫描整串**。

```c
while(str[i])
{
    ...
}
```

这块积木的作用：

```md
把整条句子走完，一个单词一个单词去处理。
```

---

## 第二步：遇到非空格，就说明一个单词开始了

用 **积木2：找到一段开始**。

```c
if(str[i] != ' ')
{
    ...
}
```

这块积木的作用：

```md
跳过空格，只在真正的单词开始处动手。
```

---

## 第三步：处理完整个单词，同时顺手累加 ASCII 和

这里结合 **积木3：进入这一段内部** 和积木19“按字符规则累加值”。

```c
while(str[i] && str[i] != ' ')
{
    sum1 = sum1 + str[i];
    temp[k++] = str[i];
    i++;
}
```

这块积木的作用：

```md
一边把单词收起来，一边把每个字符的 ASCII 码加起来。
```

例如：

```md
"to" → 116 + 111 = 227
"a"  → 97
```

---

## 第四步：判断这个和是不是素数

用 **积木15：判断素数**。

```c
int flag = 1;
for(j = 2; j < sum1; j++)
{
    if(sum1 % j == 0)
    {
        flag = 0;
        break;
    }
}
```

这块积木的作用：

```md
把 ASCII 和不是素数的单词淘汰掉。
```

例如：

```md
227 是素数，所以 "to" 保留。
```

---

## 第五步：把合格单词和它的和值一起保存

用 **积木7：统计个数 / 保存结果**。

```c
if(flag == 1)
{
    temp[k] = ' ';
    strcpy(words[cnt], temp);
    sum[cnt] = sum1;
    cnt++;
}
```

这块积木的作用：

```md
让 words[cnt] 和 sum[cnt] 始终对应同一个单词。
```

---

## `wordsearch()` 的积木顺序

```md
积木1：扫描整串
→ 积木2：找到单词开始
→ 积木3：处理完整个单词
→ 积木19：累加 ASCII 和
→ 积木15：判断素数
→ 积木7：保存单词和和值
```

---

# 三、拼 `sort()`：先按和值排，再按字典序排

## 目标
把符合条件的单词按题目要求排好。

排序规则有两层：

```md
第一层：和值小的放前面
第二层：和值相同，字典序小的放前面
```

---

## 第一步：先按 `sum[]` 做冒泡排序

用 **积木9：冒泡排序**。

```c
for(i = 0; i < n - 1; i++)
{
    for(j = 0; j < n - 1 - i; j++)
    {
        ...
    }
}
```

这块积木的作用：

```md
不断比较相邻两个单词的位置要不要换。
```

---

## 第二步：如果和值不同，就按和值排序

```c
if(sum[j] > sum[j+1])
{
    ...
}
```

这一步的作用：

```md
让和值小的单词往前走。
```

这里会同时用到：

- **积木10：交换整数**
- **积木11：交换字符串**

因为 `sum[]` 和 `words[][]` 必须一起换。

---

## 第三步：如果和值相同，再比较字典序

这是本题专用步骤。

```c
else if(sum[j] == sum[j+1])
{
    if(strcmp(words[j], words[j+1]) > 0)
    {
        ...
    }
}
```

这一步的作用：

```md
处理“that”和“used”这种和值相同的情况。
```

比如：

```md
that = 433
used = 433
```

因为：

```md
"that" < "used"
```

所以 `that` 应该放前面。

---

## `sort()` 的积木顺序

```md
积木9：冒泡排序
→ 先按 sum 比较
→ 积木10：交换整数
→ 积木11：交换字符串
→ 本题步骤：和值相同再按字典序比较
```

# 五、变式迁移

## 变式 1
如果题目要求“ASCII 和是偶数”而不是素数，要改：

```md
wordsearch() 里的素数判断部分。
```

## 变式 2
如果排序规则改成和值降序，要改：

```md
sort() 里 sum[j] > sum[j+1] 的方向。
```

## 变式 3
如果和值相同要按长度排，不按字典序排，要改：

```md
strcmp(words[j], words[j+1]) 这一段。
```

```c
/*----------------------------------------------------------------------

#include <stdio.h>
#include <stdlib.h>
#include <math.h>
#include <ctype.h>
#include <string.h>

#define M 10
#define N 20

int wordsearch(char str[], char words[][N],int sum[]) 
{
/**********Program**********/
  int i=0;
  int cnt=0;//统计个数 
  while(str[i]){
  	   if(str[i]!=' '){
  	   	    int sum1=0;
  	   	    char temp[20];
  	   	    int k=0;
  	   	    while(str[i]&&str[i]!=' '){
  	   	    	sum1=sum1+str[i];
  	   	    	temp[k++]=str[i];
  	   	    	i++;
			}
			int j;
			int flag=1;//1是素数

				 if(sum1%j==0){
				 	flag=0;
				 	break;
				 } 
			}
			if(flag==1){
				temp[k]='\0';
				strcpy(words[cnt],temp); 
				sum[cnt]=sum1;

			}
	   }else{
	   	  i++;
	   }
  	 
  } 
  return cnt; 


/**********  End  **********/
}

void sort(char words[][N],int n,int sum[]) 
{
/**********Program**********/
    int i,j;
    for(i=0;i<n-1;i++){

    		if(sum[j]>sum[j+1]){

    			temp=sum[j];

	    			strcpy(words[j],words[j+1]);

/**********  End  **********/
```
