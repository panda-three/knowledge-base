# 11.c 课堂讲解：顺着题目拼积木

## 这道题的做法
11.c 要做的不是一步，而是连续三步：

```md
先删掉非字母字符
→ 再把相同字符按出现顺序放在一起
→ 最后取出长度至少为 2 的等值子串
```

所以这题不是简单的“抽子串题”，而是：

```md
先整理字符串，再提取结果
```

---

## 一、题目要我们做什么

> 先把原题题干放在最前面，方便我们一边看讲解，一边对照题目要求。

```c
/*----------------------------------------------------------------------
【程序设计】
------------------------------------------------------------------------
题目：s是一个字符串，按以下步骤对其进行处理：
      1.删除s中的非字母字符；
      2.从左到右按字符出现的顺序将相同的字符放置在一起。
      3.对于上述两步处理后的字符串s，从中找出等值子串依次存放到二维数组
      str中。其中，等值子串是指由两个及两个以上相同字符组成的字符串。

例如：原字符串为 "#fac_Mah@jd,dc-kdaj!f2ff"， 经过上述两步处理后的字符串为 
      "ffffaaaccMhjjdddk"，从中找出的等值子串依次为 
      "ffff"、"aaa"、"cc"、"jj"、"ddd"

程序运行结果如下：
原字符串为：#fac_Mah@jd,dc-kdaj!f2ff
处理后字符串为：ffffaaaccMhjjdddk
取出的等值字符子串有:
ffff
aaa
cc
jj
ddd
   
1.编写函数void Delete_move(char s[])，删除s字符串中非字母字符，再从左到右
  按字符出现的顺序将相同的字符放置在一起。

2.编写函数int Substr(char s[], char str[][100])。将s中的等值字符子串依次
  取出并放入二维数组str中，每一个等值子串在str中放一行。函数返回等值子串
  的个数。  
---------------------------------------------------------

```

# 三、拼 `Delete_move()`：先把字符串整理好

## 目标
把：

```c
#fac_Mah@jd,dc-kdaj!f2ff
```

变成：

```md
ffffaaaccMhjjdddk
```

---

## 第一步：先把所有字母筛出来

用 **积木1：扫描整串**，再配合“判断是不是字母”。

```c
for(i = 0; i < n; i++)
{
    if(isalpha(s[i]))
        temp[k++] = s[i];
}
```

这块积木的作用：

```md
把 #、_、@、,、-、!、2 这些非字母全删掉。
```

筛完后，大概会得到：

```md
facMahjdckdajff
```

也就是：

```md
#fac_Mah@jd,dc-kdaj!f2ff
→ facMahjdckdajff
```

---

## 第二步：按“第一次出现的顺序”去聚集相同字符

这里要用 **积木16：计数数组** 的变形 —— `used[256]`。

```c
int used[256] = {0};
for(j = 0; j < k; j++)
{
    int m = temp[j];
    if(used[m] == 1)
        continue;
    for(l = 0; l < k; l++)
    {
        if(temp[l] == m)
            result[cnt++] = m;
    }
    used[m] = 1;
}
```

这块积木的作用：

```md
第一次遇到某个字符时，就把这个字符在整串里所有出现的位置全收集过来。
```

所以：

```md
f ... f f f  →  ffff
a a a        →  aaa
c c          →  cc
```

---

## 第三步：把整理后的结果写回 `s[]`

用 **积木11：字符串复制**。

```c
result[cnt] = ' ';
strcpy(s, result);
```

这块积木的作用：

```md
让后面的 Substr() 直接在整理后的字符串上工作。
```

---

## `Delete_move()` 的积木顺序

```md
积木1：扫描整串
→ 本题步骤：只保留字母
→ 积木16：记录哪些字符已经处理过
→ 本题步骤：按首次出现顺序聚集相同字符
→ 积木11：把整理结果写回 s[]
```

# 三、拼 `Substr()`：再把等值子串取出来

## 目标
从：

```md
ffffaaaccMhjjdddk
```

取出：

```md
ffff
aaa
cc
jj
ddd
```

题目说的“等值子串”意思是：

```md
由两个及两个以上相同字符组成
```

所以：

```md
M 不算
h 不算
k 不算
```

---

## 第一步：看当前字符和后一个字符是不是一样

用 **积木17：相邻字符关系判断**。

```c
if(s[i] == s[i+1])
{
    ...
}
```

这块积木的作用：

```md
只要当前字符和后一个字符相同，就说明一个等值子串开始了。
```

---

## 第二步：把这一整段相同字符都收起来

```c
temp[k++] = s[i];
for(; s[i] && s[i] == s[i+1]; i++)
{
    temp[k++] = s[i];
}
```

这一步的作用：

```md
把 ffff、aaa、cc 这种整段一起收完。
```

---

## 第三步：长度够 2 才保存

```c
if(k >= 2)
{
    temp[k] = ' ';
    strcpy(result[cnt++], temp);
}
```

这一步的作用：

```md
保证单个字符不会被误存进去。
```

---

## `Substr()` 的积木顺序

```md
积木17：判断相邻字符是否相同
→ 本题步骤：把整段相同字符收起来
→ 本题步骤：长度至少为 2 才保存
→ 积木7：统计结果个数
```

# 五、变式迁移

## 变式 1
如果题目要求保留字母和数字，要改：

```md
Delete_move() 里 isalpha(s[i]) 这个条件。
```

## 变式 2
如果等值子串要求长度至少为 3，要改：

```md
Substr() 里 k >= 2 这个条件。
```

## 变式 3
如果相同字符要按字母顺序聚集，不按第一次出现顺序，要改：

```md
Delete_move() 里外层遍历顺序。
```
