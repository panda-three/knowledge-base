# 8.c 课堂讲解：顺着题目拼积木

## 这道题的做法
8.c 不是简单找子串，它有两层：

```md
第一层：先在每一行里找“最长降序子串”。
第二层：再把每一行找到的结果拿出来做升序排序。
```

这里的“降序子串”不是字典序，而是：

```md
相邻字符的 ASCII 码值正好递减 1
```

例如：

```md
gfe    因为 g→f→e 每次都减 1
543    因为 5→4→3 每次都减 1
```

---

## 一、题目要我们做什么

> 先把原题题干放在最前面，方便我们一边看讲解，一边对照题目要求。

```c
/*----------------------------------------------------------------------
【程序设计】
------------------------------------------------------------------------
题目：二维字符数组 str[M][N]中存在 M 行字符串，每行字符串中存在多个降序
      子串，找出每行的最长降序子串存入二维数组b，并对数组b中的字符串
      按大小升序排序。 
 
"降序子串"指该串中字符 ASCII 码值依次递减 1。如：字符串"edadg543rsigfea" 
 中可找出的降序子串为："ed"、" 543 "、"gfe",只放入字串"gfe" 

程序运行结果如下：
每行字符串中最长的降序子串为:
srqp
edcba
gfe
76543

子串升序排序后:
76543
edcba
gfe
srqp

1.函数void trans(char str[],char a[])的功能是：将一维字符数组str中的最长 
降序子串找出，并放入数组a,若一行字符串中最长降序子串存在多个，只放入最后一个。

2.函数 void sort(char b[][N])中实现二维数组b中字符串升序排序。
------------------------------------------------------------------------------------------
注意：在指定范围内编写程序，勿修改指定范围外的任何内容。
------------------------------------------------------------------------------------------*/
```

# 二、先看函数参数长什么样

## 1. `void trans(char str[], char a[])`

### 调用位置
```c
trans(str[i], a);
```

### 传进来的 `str[]` 长什么样
例如：

```c
"edadg543rsigfea"
```

### `a[]` 要变成什么
这一行里最长的降序子串是：

```md
gfe
```

所以：

```c
a = "gfe"
```

如果一行里有多个同样长的最长降序子串，题目要求：

```md
只保留最后一个
```

---

## 2. `void sort(char b[][N])`

### 调用位置
```c
sort(b);
```

### 传进来的 `b[][N]` 长什么样
例如：

```md
srqp
edcba
gfe
76543
```

### 排序后要变成什么
按字符串升序：

```md
76543
edcba
gfe
srqp
```

# 三、拼 `trans()`：先找一行里最长的降序子串

## 目标
从：

```c
"edadg543rsigfea"
```

找出：

```md
gfe
```

---

## 第一步：先准备好“最长长度”和“最长子串位置”

```c
int max_len = 0;
int start = 0;
int end = 0;
```

这一步的作用：

```md
后面一旦发现更长的降序子串，就更新这三个量。
```

---

## 第二步：从第 2 个字符开始，看它和前一个是不是正好减 1

用 **积木17：相邻字符关系判断**。

```c
for(i = 1; i < len; i++)
{
    if(str[i] == str[i - 1] - 1)
    {
        ...
    }
}
```

这块积木的作用：

```md
只要当前字符比前一个字符小 1，就说明降序子串还在继续。
```

例如：

```md
g → f  成立
f → e  成立
```

但：

```md
d → a  不成立
```

---

## 第三步：一旦发现降序开头，就继续往后数长度

这里结合 **积木8：统计长度 / 找最长**。

```c
int m = i - 1;
int k = 1;
for(; str[i] == str[i - 1] - 1; i++)
{
    k++;
}
if(k >= max_len)
{
    max_len = k;
    start = m;
    end = m + k - 1;
}
```

这块积木的作用：

```md
把当前这段降序子串的长度数出来。
如果它更长，或者和当前最长一样长，就更新记录。
```

为什么用 `>=`，不是 `>`？

因为题目要求：

```md
如果最长降序子串有多个，只保留最后一个。
```

所以遇到同样长的后面那一段，也要更新掉前面的记录。

---

## 第四步：把记录好的最长子串拷出来

用 **积木4：把这一段存成字符串**。

```c
for(i = start; i <= end; i++)
{
    a[n++] = str[i];
}
a[n] = ' ';
```

这块积木的作用：

```md
把最长降序子串真正写进 a[]。
```

---

## `trans()` 的积木顺序

```md
先准备最长记录
→ 积木17：判断相邻字符是不是减 1
→ 积木8：统计长度并更新最长记录
→ 积木4：把最长子串存进 a[]
```

---

# 三、拼 `sort()`：把这些结果按字符串升序排好

## 目标
把：

```md
srqp
edcba
gfe
76543
```

排成：

```md
76543
edcba
gfe
srqp
```

---

## 第一步：用冒泡排序比较相邻两行

用 **积木9：冒泡排序**。

```c
for(i = 0; i < M - 1; i++)
{
    for(j = 0; j < M - 1 - i; j++)
    {
        if(strcmp(b[j], b[j+1]) > 0)
        {
            ...
        }
    }
}
```

这块积木的作用：

```md
如果前一个字符串更大，就把它往后放。
```

---

## 第二步：交换字符串位置

用 **积木11：交换字符串**。

```c
char temp[20];
strcpy(temp, b[j]);
strcpy(b[j], b[j+1]);
strcpy(b[j+1], temp);
```

这块积木的作用：

```md
把顺序不对的两行调过来。
```

---

## `sort()` 的积木顺序

```md
积木9：冒泡排序
→ strcmp 比较大小
→ 积木11：交换字符串
```

# 四、整道题的积木拼装图

```md
8.c
├── trans(str, a)
│   ├── 先准备最长记录
│   ├── 积木17：相邻字符关系判断

│   └── 积木4：把最长子串存成字符串
└── sort(b)

    └── 积木11：交换字符串
```

# 五、变式迁移

## 变式 1
如果题目要求找“最长不降子串”，要改：

```md
trans() 里 str[i] == str[i-1] - 1 这个条件。
```

## 变式 2
如果同样长时保留第一个，不保留最后一个，要改：

```md
if(k >= max_len) 这里的 >=。
```

## 变式 3
如果最后要求降序排序 `b[][]`，要改：

```md
sort() 里 strcmp(b[j], b[j+1]) > 0 的方向。
```
