# 3.c 课堂讲解：顺着题目拼积木

## 这道题的做法
做 3.c，不能只看到“提取单词”四个字。

这道题其实分两层：

```md
第一层：从一整条混合字符串里，提取出特殊单词。
第二层：把这些特殊单词拿去词库里匹配，找出真正匹配成功的。
```

所以我们要分成两个函数看：

```c
int extractWords(char str[], char words[][M])
int findDuplicates(char words[][M], char dck[][M], int n)
```

先按这个顺序看：

```md
读题干 → 看参数 → 选积木 → 拼代码 → 检查结果
```

---

## 一、题目要我们做什么

> 先把原题题干放在最前面，方便我们一边看讲解，一边对照题目要求。

```c
/*----------------------------------------------------------------------
【程序设计】
------------------------------------------------------------------------
题目：字符串str中包含若干个单词，单词是以1个大写字母开头，后跟0到多个小写
      字母组成。从这些单词中提取出所有的特殊单词，并将其存储到二维字符数组
      words中。所谓特殊单词是指以1个大写字母开头，后跟0到4个小写字母组成的
      单词。比如单词"Hello"、"Num"、"C"等都是特殊单词；"Deepseek"不是
      特殊单词。
           
      字符数组dck是一个单词库，存有若干个由小写字母组成的单词。将取出的
      特殊单词与单词库的单词进行匹配，匹配时不区分大小写字母。输出匹配
      成功的特殊单词。

程序的运行结果是：
   初始字符串：
   12HelloWorld34TimeCuntDeepseek*NumProgramOkDesktopCFine
   提取的特殊单词：
   Hello World Time Cunt Num Ok C Fine
   匹配成功的单词：
   Hello Time Cunt

1.编写函数 int extractWords(char str[], char words[][M])，从字符串str中
  提取所有特殊单词,存储到二维数组 words中，函数返回所提取的特殊单词个数。

2.编写函数 int findDuplicates(char words[][M],char dck[][M],int n)，对n个
  特殊单词 words依次与单词库dck中的单词进行匹配，匹配时不区分大小写字母。
  匹配成功的特殊单词依次存放在words中，函数返回匹配成功的特殊单词个数。

```

# 二、先看函数参数长什么样

## 1. `int extractWords(char str[], char words[][M])`

### 调用位置
```c
n = extractWords(str, words);
```

### 传进来的 `str[]` 长什么样
```c
"12HelloWorld34TimeCuntDeepseek*NumProgramOkDesktopCFine"
```

它不是空格分词，而是一整条连在一起的字符串。

里面真正的单词有这些：

```md
Hello  World  Time  Cunt  Deepseek  Num  Program  Ok  Desktop  C  Fine
```

但题目只要“特殊单词”：

```md
大写字母开头 + 后面 0 到 4 个小写字母
```

所以提取出来的应该是：

```md
Hello  World  Time  Cunt  Num  Ok  C  Fine
```

### `words[][M]` 要变成什么
函数执行后，`words` 每一行放一个特殊单词。

函数返回：

```c
n = 8
```

---

## 2. `int findDuplicates(char words[][M], char dck[][M], int n)`

### 调用位置
```c
n = findDuplicates(words, dck, n);
```

### 传进来的 `words[][M]` 长什么样
调用前：

```md
Hello  World  Time  Cunt  Num  Ok  C  Fine
```

### 传进来的 `dck[][M]` 长什么样
词库是：

```md
hello  time  cunt  false  deepseek
```

### 执行后 `words[][M]` 要变成什么
匹配成功的特殊单词要重新放回 `words` 前几行：

```md
Hello  Time  Cunt
```

函数返回：

```c
n = 3
```

# 三、拼 `extractWords()`：从整条字符串里抽特殊单词

## 目标
把：

```c
12HelloWorld34TimeCuntDeepseek*NumProgramOkDesktopCFine
```

变成：

```md
Hello  World  Time  Cunt  Num  Ok  C  Fine
```

这里最关键的不是“看见字母就取”，而是：

```md
必须是大写字母开头
后面跟 0 到多个小写字母
最后长度不能超过 5
```

---

## 第一步：整串从左到右扫

用 **积木1：扫描整串**。

```c
while(str[i])
{
    ...
}
```

这块积木的作用：

```md
把整条字符串走完，逐个位置判断。
```

---

## 第二步：看到大写字母，就说明可能是一个单词开始

用 **积木2：找到一段开始**。

```c
if(isupper(str[i]))
{
    ...
}
```

这块积木的作用：

```md
只在大写字母开头的位置，才尝试提取单词。
```

例如：

```md
12HelloWorld...
  ↑
  H 是大写，所以 Hello 从这里开始
```

---

## 第三步：把后面连续的小写字母接上

这里借用 **积木3：进入这一段内部**。

```c
temp[k++] = str[i++];
while(str[i] && islower(str[i]))
{
    temp[k++] = str[i];
    i++;
}
```

这块积木的作用：

```md
先放进开头的大写字母，再把后面紧跟的小写字母一起收进来。
```

例如：

```md
H + ello → Hello
C        → C
O + k    → Ok
```

---

## 第四步：判断是不是“特殊单词”

本题要求长度不能超过 5。

```c
if(k <= 5)
{
    temp[k] = ' ';
    strcpy(words[cnt], temp);
    cnt++;
}
```

这一步的作用：

```md
把太长的单词挡掉，只保留长度 1 到 5 的。
```

比如：

```md
Hello    长度 5，保留
C        长度 1，保留
Deepseek 长度 8，不保留
Program  长度 7，不保留
```

---

## `extractWords()` 的积木顺序

```md
积木1：扫描整串
→ 积木2：找到大写字母开头
→ 积木3：接上后面的连续小写字母
→ 本题步骤：判断长度是否超过 5
→ 积木7：保存特殊单词
```

# 三、拼 `findDuplicates()`：和词库做不区分大小写匹配

## 目标
从：

```md
Hello  World  Time  Cunt  Num  Ok  C  Fine
```

筛出：

```md
Hello  Time  Cunt
```

因为词库里只有：

```md
hello  time  cunt  false  deepseek
```

---

## 第一步：一个一个取出特殊单词

这里先遍历 `words` 数组。

```c
for(i = 0; i < n; i++)
{
    ...
}
```

这一步的作用：

```md
依次检查每一个特殊单词能不能在词库里找到。
```

---

## 第二步：先把开头大写改成小写

这是本题专用步骤。

```c
char temp[10];
strcpy(temp, words[i]);
temp[0] = tolower(temp[0]);
```

这一步的作用：

```md
把 Hello 变成 hello，把 Time 变成 time，方便和词库统一比较。
```

注意：这道题里特殊单词的结构就是“大写开头 + 后面小写”，所以只改第 1 个字符就够了。

---

## 第三步：去词库里顺序查找

```c
for(j = 0; j < N; j++)
{
    if(strcmp(temp, dck[j]) == 0)
    {
        strcpy(words[cnt], words[i]);
        cnt++;
    }
}
```

这里用到了 **积木11：字符串复制**。

这一步的作用：

```md
一旦匹配成功，就把原来的特殊单词保存下来。
```

为什么保存原来的 `words[i]`，不是保存 `temp`？

因为题目最后输出的是：

```md
Hello  Time  Cunt
```

不是全小写的：

```md
hello  time  cunt
```

---

## `findDuplicates()` 的积木顺序

```md
先遍历 words 中的每个特殊单词
→ 本题步骤：把首字母转成小写
→ 顺序查找词库
→ 积木11：保存匹配成功的原单词
```

# 四、整道题的积木拼装图

```md
3.c
├── extractWords(str, words)
│   ├── 积木1：扫描整串
│   ├── 积木2：找到大写字母开头
│   ├── 积木3：接上连续小写字母
│   ├── 本题步骤：判断长度不超过 5
│   └── 积木7：保存特殊单词
└── findDuplicates(words, dck, n)
    ├── 先遍历 words 中的每个单词
    ├── 本题步骤：首字母转小写
    ├── 顺序查找词库
    └── 积木11：保存匹配成功的单词
```

# 五、变式迁移

## 变式 1
如果题目要求“长度不超过 6”，要改：

```md
extractWords() 里 k <= 5 这个条件。
```

## 变式 2
如果题目要求“全部转成小写再输出”，要改：

```md
findDuplicates() 最后保存的时候，改成保存 temp，不保存原来的 words[i]。
```

## 变式 3
如果题目要求“必须以大写字母开头，后面恰好 3 个小写字母”，要改：

```md
extractWords() 里对长度的判断。
```

# 六、完整代码

```c
/*----------------------------------------------------------------------
【程序设计】
------------------------------------------------------------------------
题目：字符串str中包含若干个单词，单词是以1个大写字母开头，后跟0到多个小写
      字母组成。从这些单词中提取出所有的特殊单词，并将其存储到二维字符数组
      words中。所谓特殊单词是指以1个大写字母开头，后跟0到4个小写字母组成的
      单词。比如单词"Hello"、"Num"、"C"等都是特殊单词；"Deepseek"不是
      特殊单词。
           
      字符数组dck是一个单词库，存有若干个由小写字母组成的单词。将取出的
      特殊单词与单词库的单词进行匹配，匹配时不区分大小写字母。输出匹配
      成功的特殊单词。

程序的运行结果是：
   初始字符串：
   12HelloWorld34TimeCuntDeepseek*NumProgramOkDesktopCFine
   提取的特殊单词：
   Hello World Time Cunt Num Ok C Fine
   匹配成功的单词：
   Hello Time Cunt

1.编写函数 int extractWords(char str[], char words[][M])，从字符串str中
  提取所有特殊单词,存储到二维数组 words中，函数返回所提取的特殊单词个数。

2.编写函数 int findDuplicates(char words[][M],char dck[][M],int n)，对n个
  特殊单词 words依次与单词库dck中的单词进行匹配，匹配时不区分大小写字母。
  匹配成功的特殊单词依次存放在words中，函数返回匹配成功的特殊单词个数。
-----------------------------------------------------------------------
注意：在指定范围内编写程序，勿修改指定范围外的任何内容
---------------------------------------------------------------------*/
#include <stdio.h>
#include <stdlib.h>
#include <string.h>
#include <math.h>
#include <ctype.h>

#define M 20 
#define N 100

int extractWords(char str[], char words[][M])
{
/**********Program**********/
   int i=0;
   int cnt=0;
   while(str[i]){
   	   //提取特殊单词
		if(isupper(str[i])){
			 char temp[10];
			 int k=0;
			 temp[k++]=str[i++]; 
			 while(str[i]&&islower(str[i])){
			 	 temp[k++]=str[i];
			 	 i++;
			 }
			 if(k<=5){
			 	temp[k]='\0';
				strcpy(words[cnt],temp);
				cnt++;  
			 }
		} else{
			i++;
		}
   }
   return cnt;
/**********  End  **********/   
}

int findDuplicates(char words[][M],char dck[][M],int n)
{
/**********Program**********/
//    1.遍历words 
//    2.大写转小写
//    3.顺序查找 
     int i;
     int cnt=0;
	 for(i=0;i<n;i++){
	 	 char temp[10];
	 	 strcpy(temp,words[i]);
	 	 temp[0]=tolower(temp[0]);
	 	 int j;
	 	 for(j=0;j<N;j++){
	 	 	if(strcmp(temp,dck[j])==0){
	 	 		strcpy(words[cnt],words[i]);
	 	 		cnt++;
			}
		 }
	 }
    return cnt;
/**********  End  **********/  
}

int main() 
{
    char str[] = "12HelloWorld34TimeCuntDeepseek*NumProgramOkDesktopCFine";
    char dck[N][M]={"hello","time","cunt","false","deepseek"};
    char words[N][M]; 
    int n, k;
    FILE *fp;
    if((fp=fopen("DATA.dat","w"))==NULL)
    {
        printf("File open error\n");
        exit(0);
    }
    printf("初始字符串：\n");
    puts(str);
    n = extractWords(str, words);
    printf("提取的特殊单词：\n");
    for (k = 0; k < n; k++) 
    {
        printf("%s ", words[k]);
        fprintf(fp,"%s ",words[k]);
    }
    printf("\n");
    n = findDuplicates(words,dck, n);
    printf("匹配成功的单词：\n");
    for (k = 0; k < n; k++) 
    {
        printf("%s ", words[k]);
        fprintf(fp,"%s ",words[k]);
    }
    printf("\n");
    fclose(fp);
    return 0;

}
```
