# 200.c 课堂讲解：顺着题目拼积木

## 一、题目要我们做什么

> 先放原题，我们后面每拼一块代码，都回头对照这一题到底要我们做什么。

```c
/*----------------------------------------------------------------------
【程序设计】
------------------------------------------------------------------------
题目：将字符串str中负整数字符串转换为正整数保存到一维数组中，然后将该
      数组中符合以下条件的整数m及整数2^m -1，保存到二维数组中。
      条件是：
              1. 2^m -1是素数；
              2. 2^m -1的逆序数是奇数；
              3. 2^m -1的十进制表示中包含数字1。
      注意，题中的2^m表示2的m次方。 

测试数据：  
"&&B3yh-5AS-12HJ*@#35+eH-7pTR-15HY-17"

程序运行结果如下：         
5    12    7   15   17
5                   31
7                  127
17              131071

1.编写函数int abstract(char str[],int b[])，将字符串str中负整数字符串转换 
  为正整数保存在数组b中，函数返回b中元素个数。

2.编写函数int prime_m(int k,int b[],int x[][2])，将b数组中符合上述条件的
  所有整数m和2^m -1保存到二维数组中，函数返回二维数组的行数。
---------------------------------------------------------
注意：在指定范围内编写程序，勿修改指定范围外的任何内容
-------------------------------------------------------*/ 
```

我们先不急着看答案。  
先把题目拆成两个清楚的小任务：

```md
任务1：从字符串里抽负整数，去掉负号，存成正整数。
任务2：把这些整数当成 m，筛出满足条件的 m 和 2^m - 1。
```

---

## 二、先看函数参数长什么样

这一步不能省。  
因为我们后面拼代码，不是凭感觉拼，而是要先知道：**这个函数拿到什么，做完以后交回什么。**

### 1. `int abstract(char str[], int b[])`

#### 调用位置
```c
k = abstract(str, b);
```

#### `str[]` 长什么样
```c
"&&B3yh-5AS-12HJ*@#35+eH-7pTR-15HY-17"
```

我们先不要急着写代码，先用眼睛把它看懂。

这一串里真正符合题意的片段是：

```md
-5   -12   -7   -15   -17
```

`35` 虽然是数字，但前面没有负号，所以它不是我们要抽的目标。

#### `b[]` 执行后要变成什么
```c
b[0] = 5
b[1] = 12
b[2] = 7
b[3] = 15
b[4] = 17
```

#### 这个函数最后返回什么
```c
5
```

也就是：

```md
一共抽到了 5 个整数。
```

---

### 2. `int prime_m(int k, int b[], int x[][2])`

#### 调用位置
```c
n = prime_m(k, b, x);
```

#### `k` 是什么
`k` 就是上一个函数抽到的整数个数。

这里：

```c
k = 5
```

#### `b[]` 长什么样
```c
{5, 12, 7, 15, 17}
```

现在我们要把这里面的每一个数都当成 `m` 去检查。

#### `x[][2]` 要变成什么
每一行保存一组通过筛选的结果：

```md
第 0 列：m
第 1 列：2^m - 1
```

最后应该得到：

```c
x[0][0] = 5;   x[0][1] = 31;
x[1][0] = 7;   x[1][1] = 127;
x[2][0] = 17;  x[2][1] = 131071;
```

#### 这个函数最后返回什么
```c
3
```

也就是：

```md
有 3 个 m 通过了全部筛选条件。
```

---

## 三、拼 `abstract()`

现在我们已经知道这个函数的输入和输出了。

所以这一步我们的目标非常清楚：

```md
从一整条字符串里，找到所有负整数字符串，
把负号去掉，
把后面的数字拼成整数，
放进 b[]。
```

### 第 1 块：先把整串扫起来
先别想太多。  
题目给的是一整条字符串，所以第一步一定是：**从左到右扫描整串。**

用积木1「扫描整串」。

```c
for(i = 0; str[i]; i++)
{
    ...
}
```

这块积木的作用：我们先把所有字符都看一遍，后面才能在里面找目标。

---

### 第 2 块：积木2「找到一段并处理这一段」
这里最容易一上来写错。  
因为题目不是说“抽所有数字”，而是说：

```md
抽负整数字符串。
```

所以我们不能看到数字就收，必须先找到这一段负整数字符串的入口。
在这道题里，这个入口就是：

```md
当前字符是 `-`
```

所以这里先用积木2「找到一段并处理这一段」。

```c
if(str[i] == '-')
{
    i++;
    int y = 0;
    for(; str[i] && isdigit(str[i]); i++)
    {
        ...
    }
}
```

这块积木的作用：
- 先用 `-` 锁定我们要的这一段
- 再把后面这一整段数字一次处理完

这样 `35` 就不会被误抽进去，因为它前面根本没有 `-`。

---

### 第 3 块：进入这一段以后，用积木4把数字拼成整数
现在入口已经找到了。

如果当前这一段是：

```md
-12
```

那我们真正要留下来的不是负号，而是后面的：

```md
1、2
```

它们还是字符，所以接下来要做的事只有一件：
**边走这一段，边把数字字符拼成整数。**

这里用积木4「拼整数 / 按进制拼整数」：

```c
for(; str[i] && isdigit(str[i]); i++)
{
    y = y * 10 + str[i] - '0';
}
```

这块积木的作用：把 `1`、`2` 这种分开的数字字符，真正拼成整数 `12`。

这里我们可以自己在脑子里走一遍：

```md
开始 y = 0
读到 '1' → y = 1
读到 '2' → y = 12
```

到这里，我们就不是“看见字符串”了，而是真的拿到了一个整数。

---

### 第 4 块：拼出来以后，马上放进结果数组
现在 `y` 已经是我们要的正整数了。  
那下一步就很自然：**保存起来。**

```c
b[cnt++] = y;
```

这一步的作用：
- 把刚抽到的整数放进 `b[]`
- 同时把结果个数往后推一位

也就是说，我们现在已经能一组一组地产生结果了：

```md
-5  → 5
-12 → 12
-7  → 7
...
```

---

### `abstract()` 到这里就完整长出来了
```c
int abstract(char str[],int b[])
{
    int i;
    int cnt=0;
    for(i=0;str[i];i++){
        if(str[i]=='-'){
            i++;
            int y=0;
            for(;str[i]&&isdigit(str[i]);i++){
                y=y*10+str[i]-'0';
            }
            b[cnt++]=y;
        }
    }
    return cnt;
}
```

现在回头看，它不是突然冒出来的一整段代码。  
它是我们刚才一块一块拼出来的。

## 四、拼 `prime_m()`

这个函数的目标也先说清楚：

```md
把 b[] 里的每个数当成 m，
先算出 2^m - 1，
再一条条件一条条件筛。
```

这一步最重要的不是“公式”，而是顺序：

```md
先算目标数 q
再判断素数
再看逆序数奇偶
再看十进制里有没有 1
最后再保存
```

### 第 1 块：先把当前 m 变成真正要检查的 q
我们现在手里拿到的是 `m`，但题目一直在问的是：

```md
2^m - 1 是否满足条件
```

所以第一步不能直接判断，必须先把 `q = 2^m - 1` 算出来。

```c
int m = b[i];
int y = 1;
for(j=0;j<m;j++){
    y = y * 2;
}
int q = y - 1;
```

这一步的作用：先把“输入的 m”变成“真正被检查的 q”。

例如：

```md
m = 5
2^5 - 1 = 31
```

后面所有判断，都是围绕 `31` 做，不再围绕 `5` 做。

---

### 第 2 块：先过第一关——它是不是素数
题目第一个条件最直接：

```md
2^m - 1 是素数
```

所以现在马上用积木9「判断素数」。

```c
int flag = 1;
for(p = 2; p < q; p++){
    if(q % p == 0){
        flag = 0;
        break;
    }
}
if(flag == 0)
    continue;
```

注意这里的 `continue` 很重要。  
意思是：

```md
这一关都不过，后面两关就没必要看了。
```

这就是筛选题最常见的节奏：
> **一关不过，直接跳过。**

---

### 第 3 块：第二关——先把逆序数长出来，再判断奇偶
题目第二个条件不是直接问 `q` 的奇偶，
而是问：

```md
q 的逆序数是不是奇数
```

所以这里不要急着写 `if`。  
先问自己：

```md
逆序数怎么来？
```

答案是：先拆位，再反着拼。  
这里就要用积木7「拆位 / 拆编码 / 进制转换」。

```c
n = 0;
int temp = q;
while(temp){
    n = n * 10 + temp % 10;
    temp = temp / 10;
}
```

这一步不是多余，它是在“生产”逆序数。

例如：

```md
q = 31
先取 1，再取 3
最后 n = 13
```

逆序数长出来以后，才轮到判断：

```c
if(n % 2 == 0)
    continue;
```

也就是：
- 如果逆序数是偶数
- 当前这个 `m` 直接淘汰

---

### 第 4 块：第三关——十进制里到底有没有数字 1
题目第三个条件又是一个“拆开看里面有没有什么”的题感。

所以这里还是先想到积木7。

```c
int temp1 = q;
int flag1 = 1;
while(temp1){
    if(temp1 % 10 == 1){
        flag1 = 0;
        break;
    }
    temp1 = temp1 / 10;
}
if(flag1 == 1)
    continue;
```

这一步其实就是：

```md
把 q 一位一位拆开，
只要有一位等于 1，
这一关就算通过。
```

例如：

```md
q = 131071
拆出来有 1
所以通过
```

---

### 第 5 块：三关都过了，才有资格进结果表
到这里，如果程序还没有 `continue` 跳掉，
说明当前这个 `m` 已经三关全过。

那就可以放心保存：

```c
x[cnt][0] = m;
x[cnt++][1] = q;
```

这一步的作用：把这一组通过筛选的结果，作为一整行存进二维数组。

---

### `prime_m()` 到这里也完整长出来了
```c
int prime_m(int k,int b[],int x[][2])
{
    int i,j,p,n;
    int cnt=0;
    for(i=0;i<k;i++){
        int m=b[i];
        int y=1;
        for(j=0;j<m;j++){
            y=y*2;
        }
        int q=y-1;

        int flag=1;
        for(p=2;p<q;p++){
            if(q%p==0){
                flag=0;
                break;
            }
        }
        if(flag==0)
            continue;

        n=0;
        int temp=q;
        while(temp){
            n=n*10+temp%10;
            temp=temp/10;
        }
        if(n%2==0)
            continue;

        int temp1=q;
        int flag1=1;
        while(temp1){
            if(temp1%10==1){
                flag1=0;
                break;
            }
            temp1=temp1/10;
        }
        if(flag1==1)
            continue;

        x[cnt][0]=m;
        x[cnt++][1]=q;
    }
    return cnt;
}
```

## 五、整道题的积木拼装图

```md
200.c
├── abstract(...)
│   ├── 积木1：扫描整串
│   ├── 积木2：找到一段并处理这一段
│   ├── 积木4：拼整数 / 按进制拼整数
│   └── 本题步骤：把结果放进数组
└── prime_m(...)
    ├── 本题步骤：先算 2^m - 1
    ├── 积木9：判断素数
    ├── 积木7：拆位 / 拆编码 / 进制转换（生成逆序数）
    ├── 积木7：拆位 / 拆编码 / 进制转换（检查是否含 1）
    └── 本题步骤：把合格结果存进二维数组
```

## 六、变式迁移

- 如果题目改成“抽所有整数”，要改的是“看到负号才开始抽”这一步。
- 如果题目改成“2^m + 1”，要改的是“先算目标数”这一步。
- 如果题目改成“十进制表示中包含数字 7”，只要把检查 `1` 改成检查 `7`。
- 如果题目改成“逆序数是偶数”，只要把奇偶判断方向改掉。

## 七、完整代码

```c
#include <stdio.h>
#include <stdlib.h>
#include <math.h>
#include <ctype.h>

int abstract(char str[],int b[])
{
    int i;
    int cnt=0;
    for(i=0;str[i];i++){
        if(str[i]=='-'){
            i++;
            int y=0;
            for(;str[i]&&isdigit(str[i]);i++){
                y=y*10+str[i]-'0';
            }
            b[cnt++]=y;
        }
    }
    return cnt;
}

int prime_m(int k,int b[],int x[][2])
{
```
