# 205.c 课堂讲解：顺着题目拼积木

## 一、题目要我们做什么

> 先放原题。我们后面每拼一块代码，都回头看它是不是在替题目完成要求。

```c
/*----------------------------------------------------------------------
【程序设计】
------------------------------------------------------------------------
题目：数码单词是指由数字与字母构成的单词，例如"1T3h279e"就是一个数码单词。
      字符串str中存放用空格间隔的数码单词和非数码单词。程序实现两个功能：
      1．从str中找出第1个最长数码单词；
      2．提取str中每个数码单词中的数字字符，并按其在数码单词中的原有顺序
         组成一个新的整数。

测试数据：  "  1T3h9e 27C89 3Pro7gram 42is59 Beaut0iful administrator 1234567"
程序运行结果如下： 
第1个最长数码单词是: Beaut0iful, 其长度=10
共得到5个整数:       139    2789      37    4259       0
   
1．编写函数int sLoc(char str[])，功能是返回str[]中第1个最长数码单词的起始下标。
2．编写函数int getNum(char str[],int n[])，功能是将str[]中每个数码单词中的数字
   字符，转换成一个整数，保存在n[]中，函数返回n[]中整数个数。 

---------------------------------------------------------
注意：在指定范围内编写程序，勿修改指定范围外的任何内容
-------------------------------------------------------*/
```

先把题目翻成我们能直接执行的小任务：

```md
任务1：在一串由空格隔开的单词里，找到第1个最长数码单词。
任务2：把每个数码单词中的数字字符按原顺序抽出来，拼成整数。
```

这里最关键的不是“单词”，而是“数码单词”。

题干已经告诉我们：

```md
数码单词 = 同时含有字母和数字的单词
```

所以后面我们一直都在做两件事：
- 先切出一个单词
- 再判断它是不是数码单词

---

## 二、先看函数参数长什么样

这一步不能省。  
因为我们后面不是在背答案，而是在根据参数，自己把函数长出来。

### 1. `int sLoc(char str[])`

#### 调用位置
```c
sp = sLoc(str);
```

#### `str[]` 长什么样
```c
"  1T3h9e 27C89 3Pro7gram 42is59 Beaut0iful administrator 1234567"
```

它其实是很多单词，中间用空格分开：

```md
1T3h9e
27C89
3Pro7gram
42is59
Beaut0iful
administrator
1234567
```

#### 这个函数要返回什么
题目要求：

```md
返回第1个最长数码单词的起始下标
```

这里最长数码单词是：

```md
Beaut0iful
```

所以 `sp` 最后指向的是这个单词的开头位置。

也就是说，这个函数不是返回长度，不是返回单词内容，
而是返回：

```md
这个单词在原字符串里的起点。
```

---

### 2. `int getNum(char str[], int n[])`

#### 调用位置
```c
n = getNum(str, number);
```

#### `str[]` 还是谁
还是刚才那整条字符串。

#### `n[]` 要变成什么
`n[]` 里要保存每个数码单词中的数字部分。

例如：

```md
1T3h9e      → 139
27C89       → 2789
3Pro7gram   → 37
42is59      → 4259
Beaut0iful  → 0
```

注意最后这个：

```md
Beaut0iful 里只有一个数字 0
所以结果就是 0
```

#### 这个函数最后返回什么
返回一共得到了几个整数。

这里应该是：

```c
5
```

因为一共有 5 个数码单词。

---

## 三、拼 `sLoc()`

现在我们已经知道这个函数要干什么了：

```md
在整条字符串里，
一个单词一个单词地找，
判断它是不是数码单词，
如果是，再看它是不是目前最长，
最后返回第1个最长数码单词的起点。
```

### 第 1 块：先把整串扫起来
题目给的是一整条字符串，所以第一反应一定是：

> 先扫描整串。

用积木1「扫描整串」。

```c
for(i = 0; str[i]; i++)
{
    ...
}
```

这块积木的作用：把整条字符串从左到右先扫一遍，后面我们才能在里面找单词。

---

### 第 2 块：不是所有位置都能开一个单词，必须先找到单词的入口
这题里单词是用空格隔开的。  
所以一个单词的开始位置，一定满足：

```md
当前字符不是空格
```

这时候就用积木2「找到一段并处理这一段」。

```c
if(str[i] != ' ')
{
    int m = i;
    int len = 0;
    ...
    for(; str[i] && str[i] != ' '; i++)
    {
        ...
    }
}
```

这里的 `m = i` 很关键。  
因为我们后面要返回的是**起始下标**，所以一看到单词开始，就先把起点记住。

这块积木的作用：让我们一次完整处理一个单词，而不是一个字一个字零碎处理。

---

### 第 3 块：一边走这一段，一边判断它是不是数码单词
题干已经把“数码单词”的标准告诉我们了：

```md
同时含有字母和数字
```

所以现在我们处理一个单词的时候，要顺便记录两件事：
- 有没有字母
- 有没有数字

代码先这样长出来：

```c
int flag1 = 1;
int flag2 = 1;
for(; str[i] && str[i] != ' '; i++)
{
    if(isalpha(str[i]))
    {
        flag1 = 0;
    }
    if(isdigit(str[i]))
    {
        flag2 = 0;
    }
    len++;
}
```

这里不要只看变量名，先看意思：
- `flag1 == 0` 说明见过字母
- `flag2 == 0` 说明见过数字

所以一个单词处理完后，只要：

```c
flag1 == 0 && flag2 == 0
```

就说明它是数码单词。

---

### 第 4 块：如果它是数码单词，再判断它是不是目前最长
现在我们已经有两个信息了：
- 它是不是数码单词
- 它有多长

所以接下来就轮到积木5「找最优结果」。

```c
if(flag1 == 0 && flag2 == 0)
{
    if(len > max_len)
    {
        max_len = len;
        start = m;
    }
}
```

这块积木的作用：
- 只在“它是数码单词”的前提下，才参与最长比较
- 一旦更长，就更新当前最长长度和起点

题目说的是：

```md
第1个最长数码单词
```

所以这里用 `>` 而不是 `>=` 很重要。  
这样一旦前面已经出现过同样长度的最长单词，后面就不会把它顶掉。

---

### `sLoc()` 到这里就完整长出来了
```c
int sLoc(char str[])
{
   int i;
   int max_len = 0;
   int start = 0;
   for(i = 0; str[i]; i++){
       if(str[i] != ' '){
           int m = i;
           int len = 0;
           int flag1 = 1;
           int flag2 = 1;
           for(; str[i] && str[i] != ' '; i++){
               if(isalpha(str[i])){
                   flag1 = 0;
               }
               if(isdigit(str[i])){
                   flag2 = 0;
               }
               len++;
           }
           if(flag1 == 0 && flag2 == 0){
               if(len > max_len){
                   max_len = len;
                   start = m;
               }
           }
       }
   }
   return start;
}
```

## 四、拼 `getNum()`

这个函数和上一个函数很像。  
因为它也要：
- 扫整串
- 一个单词一个单词处理
- 判断是不是数码单词

只是这次目标从“找最长”变成了：

```md
把数码单词中的数字字符按原顺序拼成整数
```

### 第 1 块：还是先扫描整串
这一块和上一个函数完全一样。

```c
for(i = 0; str[i]; i++)
{
    ...
}
```

因为我们还是在同一条大字符串里逐个找单词。

---

### 第 2 块：还是先切出一个完整单词
所以仍然先用积木2「找到一段并处理这一段」。

```c
if(str[i] != ' ')
{
    int flag1 = 1;
    int flag2 = 1;
    int y = 0;
    for(; str[i] && str[i] != ' '; i++)
    {
        ...
    }
}
```

这里我们新加了一个变量：

```c
int y = 0;
```

因为这一次，我们不只想判断这个单词合不合格，
还要把其中的数字拼出来。

---

### 第 3 块：在处理单词的同时，把数字字符拼成整数
这里是这道题最核心的一步。

我们处理一个单词时：
- 如果见到字母，说明它有字母
- 如果见到数字，说明它有数字
- 而且见到数字时，要立刻把它拼进结果里

所以代码会长成这样：

```c
for(; str[i] && str[i] != ' '; i++){
    if(isalpha(str[i])){
        flag1 = 0;
    }
    if(isdigit(str[i])){
        flag2 = 0;
        y = y * 10 + str[i] - '0';
    }
}
```

这里同时用到了两种思路：
- 用标记判断它是不是数码单词
- 用积木4「拼整数 / 按进制拼整数」把数字部分拼出来

例如：

```md
42is59
读到 4 → y = 4
读到 2 → y = 42
读到 5 → y = 425
读到 9 → y = 4259
```

也就是说，这段代码一边判断合法性，一边把结果整数长出来。

---

### 第 4 块：只有它真的是数码单词，结果才保存
这里千万别忘了题目条件。  
不是所有单词里的数字都保存，必须是：

```md
这个单词同时有字母和数字
```

所以最后加上：

```c
if(flag1 == 0 && flag2 == 0)
{
    n[cnt++] = y;
}
```

这一步的作用：
- 只保存真正的数码单词结果
- 把整数存进 `n[]`
- 同时更新个数

---

### `getNum()` 到这里也完整长出来了
```c
int getNum(char str[],int n[])
{
   int i;
   int cnt = 0;
   for(i = 0; str[i]; i++){
       if(str[i] != ' '){
           int flag1 = 1;
           int flag2 = 1;
           int y = 0;
           for(; str[i] && str[i] != ' '; i++){
               if(isalpha(str[i])){
                   flag1 = 0;
               }
               if(isdigit(str[i])){
                   flag2 = 0;
                   y = y * 10 + str[i] - '0';
               }
           }
           if(flag1 == 0 && flag2 == 0){
               n[cnt++] = y;
           }
       }
   }
   return cnt;
}
```

## 六、变式迁移

- 如果题目改成“最长纯字母单词”，就把“数码单词判断”改成“只能有字母”。
- 如果题目改成“提取每个单词里的字母”，就不再用拼整数，而是改成存字符串。
- 如果题目改成“找最后一个最长数码单词”，就把 `len > max_len` 改成 `len >= max_len`。
- 如果题目改成“把数字倒序拼起来”，就不能直接按原顺序用积木4，而要先拆开再反过来拼。

## 八、用一堂体系把这道题学扎实

### 1. 这道题在练什么能力
从一堂体系看，这题练的不只是“字符串遍历”，更是在练：

- **输入能力 I**：从混杂的单词里识别哪一些是数码单词
- **处理能力 P**：判断资格、比较长度、提取数字、拼成整数
- **输出能力 O**：给出最长数码单词的位置，和所有提取出的整数

所以这题的核心是：

> **先识别，再比较，再提取。**

### 2. 这道题最值得刻意练习的点
1. 看到空格分词，先想到“一个单词一个单词处理”
2. 同时用两个标记判断“有字母、有数字”
3. 找最长时，记得更新长度和起点
4. 看到数字字符时，顺手就把它拼成整数

### 3. 这道题的小口诀

```md
先把单词切出来
有字有数才进来
更长就把起点换
数字顺手往后摘
```

### 4. 课后怎么复盘
做完这题，我们重点问自己：

- 我能不能自己说清楚“数码单词”的判断标准？
- 我能不能解释为什么 `Beaut0iful` 的结果是 `0`？
- 我下次看到“第1个最长”，还能不能记得用 `>` 而不是 `>=`？

如果能说清楚，这题就已经从“会抄”进入“会迁移”了。
