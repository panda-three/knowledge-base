# 9.c 课堂讲解：顺着题目拼积木

## 这道题的做法
9.c 分两步：

```md
先把逗号分隔的 10 位数字串切出来
→ 再检查哪一位录错了，并把后一个重复数字改成缺失数字
```

这里最关键的是题干这句：

```md
某些子串最多只有 1 处出错
```

所以我们不是做复杂纠错，而是：

```md
找哪个数字重复了
找哪个数字缺了
把“后一个重复数字”换成缺失数字
```

---

## 一、题目要我们做什么

> 先把原题题干放在最前面，方便我们一边看讲解，一边对照题目要求。

```c
/*----------------------------------------------------------------------
【程序设计】
------------------------------------------------------------------------
题目：字符数组str中存放了多个由10个数字字符组成的子串，每个子串之间由1个
      逗号","隔开，正确的子串是每个数字字符在子串中必须出现且仅能出
      现1次。但题目所给的str中的某些子串存在错误（最多只有1处出错），
      要求找出该子串中出错的数字字符，并将出错字符中的后一个替换为正确
      的数字字符。           
例如：字符串"0456987210"应改为"0456987213"。 

程序运行结果如下： 
    0922486375--->0921486375
    0962485371--->Right!
    0456987210--->0456987213
    2015987243--->2015987643

1.编写函数int GetStr(char str[],char Seq[][10])，从字符数组str中按要求取出
数字字符组成的子串放入二维字符数组Seq中，返回子串的个数。

2.编写函数int Check(char str[])，判断字符数组str中的数字字符有没有录入
  错误，如没有错误，则返回0；如有错误，请按题目要求进行替换，并返回1。   
-----------------------------------------------------------------------
注意：在指定范围内编写程序，勿修改指定范围外的任何内容
---------------------------------------------------------------------*/
```

# 二、先看函数参数长什么样

## 1. `int GetStr(char str[], char seq[][N])`

### 调用位置
```c
n = GetStr(str, seq);
```

### 传进来的 `str[]` 长什么样
```c
"0922486375,0962485371,0456987210,2015987243"
```

### `seq[][N]` 要变成什么
切出来以后：

```md
0922486375
0962485371
0456987210
2015987243
```

函数返回：

```c
n = 4
```

---

## 2. `int Check(char str[])`

### 调用位置
```c
if(Check(seq[i]) == 1)
```

### 传进来的 `str[]` 长什么样
例如：

```c
"0456987210"
```

### 执行后可能发生什么
如果没有错误：

```md
返回 0
字符串不变
```

如果有错误：

```md
返回 1
把后一个重复数字改成缺失数字
```

例如：

```md
0456987210 → 0456987213
```

# 三、拼 `GetStr()`：先把每个数字串切出来

## 目标
把：

```c
"0922486375,0962485371,0456987210,2015987243"
```

切成四条独立字符串。

---

## 第一步：整串从左到右扫

用 **积木1：扫描整串**。

```c
while(str[i])
{
    ...
}
```

这块积木的作用：

```md
从头走到尾，逐段找逗号之间的内容。
```

---

## 第二步：遇到不是逗号的地方，就说明一个数字串开始了

用 **积木2：找到一段开始**。

```c
if(str[i] != ',')
{
    ...
}
```

这块积木的作用：

```md
跳过逗号，只在真正的数字串开始处处理。
```

---

## 第三步：一直收，直到下一个逗号为止

用 **积木3：进入这一段内部**。

```c
while(str[i] && str[i] != ',')
{
    temp[k++] = str[i];
    i++;
}
```

这块积木的作用：

```md
把当前这个 10 位数字串完整取出来。
```

---

## 第四步：把这一段存进二维数组

用 **积木4：把这一段存成字符串**。

```c
temp[k] = ' ';
strcpy(seq[cnt++], temp);
```

这块积木的作用：

```md
让 seq 的每一行保存一个数字串。
```

---

## `GetStr()` 的积木顺序

```md
积木1：扫描整串
→ 积木2：找到不是逗号的地方
→ 积木3：处理到下一个逗号
→ 积木4：把这一段存成字符串
```

---

# 三、拼 `Check()`：找重复数字和缺失数字

## 目标
判断一个 10 位数字串是不是出错了。

如果出错，就按题目要求修成正确结果。

---

## 第一步：先统计每个数字出现了几次

用 **积木16：计数数组**。

```c
int count[10] = {0};
for(i = 0; i < n; i++)
{
    int m = str[i] - '0';
    count[m] = count[m] + 1;
}
```

这块积木的作用：

```md
把 0 到 9 每个数字出现几次都记下来。
```

如果是正确串，应该是：

```md
每个数字都正好出现 1 次
```

---

## 第二步：找哪个数字缺了，哪个数字重复了

这是本题专用步骤。

```c
for(j = 0; j < 10; j++)
{
    if(count[j] == 0)
        miss = j + '0';
    if(count[j] == 2)
        repeat = j + '0';
}
```

这一步的作用：

```md
count[j] == 0 说明 j 没出现
count[j] == 2 说明 j 重复了
```

例如：

```md
0456987210
```

里面：

```md
0 出现了两次
3 一次都没出现
```

所以：

```md
repeat = '0'
miss   = '3'
```

---

## 第三步：如果根本没错，就直接返回 0

```c
if(miss == 'a' && repeat == 'a')
{
    return 0;
}
```

这一步的作用：

```md
把正确串和错误串分开处理。
```

---

## 第四步：从后往前找“后一个重复数字”，把它换掉

这是本题最关键的一步。

```c
for(i = n - 1; i >= 0; i--)
{
    if(str[i] == repeat)
    {
        str[i] = miss;
        break;
    }
}
```

这一步的作用：

```md
题目要求改“后一个”重复数字，所以必须从后往前找。
```

例如：

```md
0456987210
         ↑
最后这个 0 才要改成 3
```

改完就变成：

```md
0456987213
```

---

## `Check()` 的积木顺序

```md
积木16：计数数组
→ 本题步骤：找缺失数字和重复数字
→ 本题步骤：如果没错直接返回 0
→ 本题步骤：从后往前替换后一个重复数字
```

# 四、整道题的积木拼装图

```md
9.c
├── GetStr(str, seq)
│   ├── 积木1：扫描整串
│   ├── 积木2：找到不是逗号的地方
│   ├── 积木3：处理到下一个逗号
│   └── 积木4：把这一段存成字符串
└── Check(str)
    ├── 积木16：计数数组
    ├── 本题步骤：找缺失数字和重复数字
    ├── 本题步骤：判断是否本来就正确
    └── 本题步骤：从后往前替换重复数字
```

# 五、变式迁移

## 变式 1
如果题目改成替换“前一个重复数字”，要改：

```md
最后替换时循环方向，改成从前往后找。
```

## 变式 2
如果分隔符从逗号改成分号，要改：

```md
GetStr() 里“找到一段开始”和“结束条件”。
```

## 变式 3
如果允许有两处错误，这套做法就不够了，要改：

```md
Check() 里只找一个缺失、一个重复的逻辑。
```

# 六、完整代码

```c
/*----------------------------------------------------------------------
【程序设计】
------------------------------------------------------------------------
题目：字符数组str中存放了多个由10个数字字符组成的子串，每个子串之间由1个
      逗号","隔开，正确的子串是每个数字字符在子串中必须出现且仅能出
      现1次。但题目所给的str中的某些子串存在错误（最多只有1处出错），
      要求找出该子串中出错的数字字符，并将出错字符中的后一个替换为正确
      的数字字符。           
例如：字符串"0456987210"应改为"0456987213"。 

程序运行结果如下： 
    0922486375--->0921486375
    0962485371--->Right!
    0456987210--->0456987213
    2015987243--->2015987643

1.编写函数int GetStr(char str[],char Seq[][10])，从字符数组str中按要求取出
数字字符组成的子串放入二维字符数组Seq中，返回子串的个数。

2.编写函数int Check(char str[])，判断字符数组str中的数字字符有没有录入
  错误，如没有错误，则返回0；如有错误，请按题目要求进行替换，并返回1。   
-----------------------------------------------------------------------
注意：在指定范围内编写程序，勿修改指定范围外的任何内容
---------------------------------------------------------------------*/
#include <stdio.h>
#include <stdlib.h>
#include <math.h>
#include <ctype.h>
#include <string.h>

#define N 11
#define M 8

int GetStr(char str[],char seq[][N])
{
/**********Program**********/
    int i=0;
    int cnt=0;
    while(str[i]){
    	if(str[i]!=','){
    		 int k=0;
    		 char temp[20]; 
    		 while(str[i]&&str[i]!=','){
    		 	 temp[k++]=str[i];
    		 	 i++;
			 }
			 temp[k]='\0';
			 strcpy(seq[cnt++],temp);
		}else{
			i++;
		}
	}
    return cnt;
     
/**********  End  **********/
}
int Check(char str[])
{
/**********Program**********/
    /*
       1.统计字符出现的次数
	   2.找缺和重复的字符
	   3.把重复替换成缺的 
    */
    // 1.统计字符出现的次数
    int count[10]={0}; 
    int i;
    int n=strlen(str);
    for(i=0;i<n;i++){
    	int m=str[i]-'0';
    	count[m]=count[m]+1;
	}
	// 2.找缺和重复的字符
	char miss='a';
	char repeat='a';
	int j;
	for(j=0;j<10;j++){
		if(count[j]==0){
			miss=j+'0';
		}
		if(count[j]==2){
			repeat=j+'0';
		}
	}
	if(miss=='a'&&repeat=='a'){
		return 0;
	}
	
//	3.把重复替换成缺的 :1)找重复字符
    for(i=n-1;i>=0;i--){
    	if(str[i]==repeat){
    		str[i]=miss;
    		break;
		} 
	}
	return 1;
/**********  End  **********/
}
 
int main()
{
    char str[100]={"0922486375,0962485371,0456987210,2015987243"};
    char seq[M][N]={""};
    char tmp[N]="";
    int i,n;        
    FILE *fp;
    if((fp=fopen("DATA.dat","w"))==NULL)
    {
        printf("File open error\n");
        exit(0);
    }
    n=GetStr(str,seq);      
    for(i=0;i<n;i++)
    {    
        strcpy(tmp,seq[i]);
        if(Check(seq[i])==1)
        {    
            printf("%s--->%s\n",tmp,seq[i]);
            fprintf(fp,"%s***>%s\n",tmp,seq[i]);
        }    
        else
        {
            printf("%s--->Right!\n",seq[i]);
            fprintf(fp,"%s***>Right!\n",seq[i]);
        }    
    }
    fclose(fp);
    return 0;
}
```
