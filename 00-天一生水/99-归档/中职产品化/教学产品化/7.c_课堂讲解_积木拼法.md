# 7.c 课堂讲解：顺着题目拼积木

## 这道题的做法
7.c 不是简单的日期题，它有两层判断：

```md
第一层：先找到满足“10进制、12进制、16进制各位和相等”的最小整数 m。
第二层：再根据这个 m，往后推日期。
```

也就是：

```md
先判数 → 再算日期
```

---

## 一、题目要我们做什么

> 先把原题题干放在最前面，方便我们一边看讲解，一边对照题目要求。

```c
/*----------------------------------------------------------------------
【程序设计】
------------------------------------------------------------------------
题目：已知m的范围 m>=2000,m<10000,在此范围内寻找满足以下条件的最小整数m的值：    
      m的各位数字之和分别等于其十六进制数和十二进制数的各位数字之和；若找到
      这样的m，则求2000年1月1日之后第m天的日期，若未找到这样的m，则输出
      “没有找到满足条件的整数”。 

例如：整数2992的各位数字之和为2+9+9+2=22，其十六进制数0xBB0之和为11+11+0=22， 
      十二进制数1894之和为1+8+9+4=22， 所以2992是满足条件的m的值。
      那么2000年1月1日之后第2992天的日期是2008年3月11日。 

程序运行结果如下：
满足条件的最小整数是2992
2000年1月1日之后第2992天的日期是2008年03月11日

1.编写函数int isEqual(int num)，判断num是否满足题目所要求的条件，满足，
  则函数返回1，否则返回0。

2.编写函数void calculateDate(int m,int date[]) ，计算从日期2000年1月1日之后第
  m天的日期，其年、月、日依次保存在date中，即date[0]存放年，date[1]存放月，
  date[2]存放日。
---------------------------------------------------------
注意：在指定范围内编写程序，勿修改指定范围外的任何内容
-------------------------------------------------------*/
```

# 二、先看函数参数长什么样

## 1. `int isEqual(int num)`

### 调用位置
```c
if(isEqual(m)) break;
```

### 传进来的 `num` 是什么
它是 2000 到 9999 范围里的某一个整数。

例如：

```c
2992
```

### 这个函数要判断什么
要判断：

```md
num 的 10进制各位和
num 的 12进制各位和
num 的 16进制各位和
```

这三个值是不是相等。

如果相等，返回 1；否则返回 0。

---

## 2. `void calculateDate(int m, int date[])`

### 调用位置
```c
calculateDate(m, date);
```

### 传进来的 `m` 是什么
它表示：

```md
从 2000年1月1日 之后往后推 m 天
```

### `date[]` 要变成什么
函数执行后：

```md
date[0] = 年
date[1] = 月
date[2] = 日
```

例如题目里的结果：

```md
2008  03  11
```

# 三、拼 `isEqual()`：先判断这个数合不合格

## 目标
判断一个整数是不是满足：

```md
10进制各位和 = 12进制各位和 = 16进制各位和
```

---

## 第一步：先算 10 进制各位和

用 **积木12：整数拆位**。

```c
while(temp1)
{
    int wei = temp1 % 10;
    s10 = s10 + wei;
    temp1 = temp1 / 10;
}
```

这块积木的作用：

```md
把十进制的每一位拆出来，再加起来。
```

例如：

```md
2992 → 2 + 9 + 9 + 2 = 22
```

---

## 第二步：再算 12 进制和 16 进制各位和

用 **积木18：其他进制拆位 / 转换**。

```c
while(temp2)
{
    int wei = temp2 % 12;
    s12 = s12 + wei;
    temp2 = temp2 / 12;
}

while(temp3)
{
    int wei = temp3 % 16;
    s16 = s16 + wei;
    temp3 = temp3 / 16;
}
```

这块积木的作用：

```md
把同一个整数换成别的进制来拆位，再把这些位加起来。
```

这一步和 6.c 的进制转换是同一路：

```md
核心都是 %base 和 /base。
```

---

## 第三步：比较三个结果是不是相等

这是本题专用步骤。

```c
if(s10 == s12 && s10 == s16)
    return 1;
else
    return 0;
```

这一步的作用：

```md
前面三次拆位只是算数据，最后这一句才是真正的判定。
```

---

## `isEqual()` 的积木顺序

```md
积木12：拆 10 进制各位
→ 积木18：拆 12 进制各位
→ 积木18：拆 16 进制各位
→ 本题步骤：比较三个和
```

---

# 三、拼 `calculateDate()`：根据 m 往后推日期

## 目标
从：

```md
2000年1月1日
```

往后推 `m` 天，得到最后日期。

---

## 第一步：先把起始日期定好

```c
int year = 2000;
int month = 1;
int day = 1;
```

这一步的作用：

```md
把计算的起点固定住。
```

---

## 第二步：一天一天往后推

```c
for(i = 0; i < m; i++)
{
    day++;
    ...
}
```

这一步的作用：

```md
每循环一次，就往后过一天。
```

---

## 第三步：判断这个月有多少天

这是本题专用步骤。

```c
int days = Month[month];
if(month == 2)
{
    if((year % 400 == 0) || (year % 4 == 0 && year % 100 != 0))
        days = days + 1;
}
```

这一步的作用：

```md
先拿到当前月份的天数。
如果是闰年的二月，再补 1 天。
```

---

## 第四步：如果这一天超了，就换月；如果月份超了，就换年

```c
if(day > days)
{
    month++;
    day = 1;
}
if(month > 12)
{
    year++;
    month = 1;
}
```

这一步的作用：

```md
保证日期始终合法。
```

---

## 第五步：把结果存进 `date[]`

用 **积木7：保存结果**。

```c
date[0] = year;
date[1] = month;
date[2] = day;
```

这块积木的作用：

```md
把最终算出来的年、月、日交出去。
```

---

## `calculateDate()` 的积木顺序

```md
先设置起始日期
→ 一天一天往后推
→ 本题步骤：判断当月天数和闰年
→ 本题步骤：处理换月和换年
→ 积木7：保存年月日
```

# 四、整道题的积木拼装图

```md
7.c
├── isEqual(num)
│   ├── 积木12：整数拆位

└── calculateDate(m, date)

```

# 五、变式迁移

## 变式 1
如果题目改成比较 8 进制和 10 进制各位和，要改：

```md
isEqual() 里 %12、/12 和 %16、/16 这些地方。
```

## 变式 2
如果起点日期改成 2010年1月1日，要改：

```md
calculateDate() 一开始的 year / month / day。
```

## 变式 3
如果要求“第 m 天之前”而不是“之后第 m 天”，要改：

```md
for 循环推进天数的边界和起点理解。
```

# 六、完整代码

```c
/*----------------------------------------------------------------------
【程序设计】
------------------------------------------------------------------------
题目：已知m的范围 m>=2000,m<10000,在此范围内寻找满足以下条件的最小整数m的值：    
      m的各位数字之和分别等于其十六进制数和十二进制数的各位数字之和；若找到
      这样的m，则求2000年1月1日之后第m天的日期，若未找到这样的m，则输出
      “没有找到满足条件的整数”。 

例如：整数2992的各位数字之和为2+9+9+2=22，其十六进制数0xBB0之和为11+11+0=22， 
      十二进制数1894之和为1+8+9+4=22， 所以2992是满足条件的m的值。
      那么2000年1月1日之后第2992天的日期是2008年3月11日。 

程序运行结果如下：
满足条件的最小整数是2992
2000年1月1日之后第2992天的日期是2008年03月11日

1.编写函数int isEqual(int num)，判断num是否满足题目所要求的条件，满足，
  则函数返回1，否则返回0。

2.编写函数void calculateDate(int m,int date[]) ，计算从日期2000年1月1日之后第
  m天的日期，其年、月、日依次保存在date中，即date[0]存放年，date[1]存放月，
  date[2]存放日。
---------------------------------------------------------
注意：在指定范围内编写程序，勿修改指定范围外的任何内容
-------------------------------------------------------*/
#include <stdio.h>
#include <stdlib.h>
#include <math.h>
#include <ctype.h>
#include <string.h>

int Month[13] = {0, 31, 28, 31, 30, 31, 30, 31, 31, 30, 31, 30, 31};

int isEqual(int num) 
{
/**********Program**********/
  //1.10、12、16进制的各位和 
    int s10=0;
    int temp1=num;
    while(temp1){
    	int wei=temp1%10;
    	s10=s10+wei;
    	temp1=temp1/10;
	}
	
	int s12=0;
	int temp2=num;
	while(temp2){
		int wei=temp2%12;
		s12=s12+wei;
		temp2=temp2/12;
	} 
	
    int s16=0;
	int temp3=num;
	while(temp3){
		int wei=temp3%16;
		s16=s16+wei;
		temp3=temp3/16;
	} 

    if(s10==s12&&s10==s16)
       return 1;
    else
       return 0;
   
/**********  End  **********/
}

void calculateDate(int m,int date[]) 
{
/**********Program**********/
  //思路：m总天数 加m天 day>30 month++ month>12 year++;       
  int year=2000;
  int month=1;
  int day=1;
  int i;
  for(i=0;i<m;i++){
  	  day++;
  	  int days=Month[month];
  	  if(month==2){
  	  	 if( (year%400==0) || (year%4==0&&year%100!=0) ){
  	  	 	days=days+1;
		 }
	  }
  	  if(day>days){
  	  	 month++;
  	  	 day=1;
	  }
	  if(month>12){
	  	 year++;
	  	 month=1;
	  }
  } 
date[0]=year;
date[1]=month;
date[2]=day;
/**********  End  **********/
}

int main() 
{
    int n=2000, m;
    int date[3];
    FILE *fp=fopen("DATA.dat","w");
    if(fp==NULL) 
    {
        printf("File open error\n"), exit(0);
    }
    for (m = n; m < 10000; m++) 
    {
        if (isEqual(m)) break;
    }
    if(m<10000) 
    {
        printf("满足条件的最小整数是%d\n", m);
        calculateDate(m,date);
        printf("2000年1月1日之后第%d天的日期是",m);
        fprintf(fp,"2000/01/01之后第[%d]天的日期是：",m);
        printf("%4d年%02d月%02d日\n", date[0],date[1], date[2]);
        fprintf(fp,"%02d/%02d/%4d\n", date[2],date[1], date[0]);
    } 
    else 
    {
        printf("没有找到满足条件的整数\n");
    }
    fclose(fp);
    return 0;
}
```
