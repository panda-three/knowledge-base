# 6.c 课堂讲解：顺着题目拼积木

## 这道题的做法
6.c 表面上是“字符串处理”，但实际上分成两次转换：

```md
第一次：把特殊格式的片段转换成整数。
第二次：再把这些整数转换成九进制数字字符串。
```

也就是：

```md
字符串 → 整数数组 → 九进制字符串数组
```

先按这个顺序看：

```md
读题干 → 看参数 → 选积木 → 拼代码 → 检查结果
```

---

## 一、题目要我们做什么

> 先把原题题干放在最前面，方便我们一边看讲解，一边对照题目要求。

```c
/*----------------------------------------------------------------------
【程序设计】
------------------------------------------------------------------------
题目：字符串s由若干形如"#2,134"格式的子串组成，首先将s中所有该格式的子串
      转换成整数，存入数组a中，然后将数组a中每个整数转换成九进制数字字符
      串存入二维字符数组nine中。
    
程序运行结果如下：
从串中抽取出的整数有:

它们对应的九进制数字字符串为:

  转换成整数，存入数组a中，函数返回整数个数。

2.编写函数void convert(int a[], char nine[][N], int m), 将长度为m的数组a中每个
  整数转换成九进制数字字符串，并存入二维字符数组nine中。
---------------------------------------------------------

```

# 二、先看函数参数长什么样

## 1. `int abstract(char s[], int a[])`

### 调用位置
```c
n = abstract(s, a);
```

### 传进来的 `s[]` 长什么样
```c
"#2,134#-31,56#5,998#711,7,#0"
```

它由多个 `#` 分隔的片段组成。每个片段里可能有：

- 数字
- 逗号
- 负号

题目真正要的是：

```md
把这些片段里的数字按顺序拼起来
负号保留下来
逗号不要
```

所以：

```md
#2,134   → 2134
#-31,56  → -3156
#5,998   → 5998
#711,7,  → 7117
#0       → 0
```

### `a[]` 要变成什么
函数执行后：

```md
a[0] = 2134
a[1] = -3156
a[2] = 5998
a[3] = 7117
a[4] = 0
```

函数返回：

```c
n = 5
```

---

## 2. `void convert(int a[], char nine[][N], int m)`

### 调用位置
```c
convert(a, nine, n);
```

### 传进来的 `a[]` 长什么样
```md
2134   -3156   5998   7117   0
```

### `nine[][N]` 要变成什么
这些整数转换成九进制后：

```md
2831   -4286   8204   10677   0
```

所以：

```md
nine[0] = "2831"
nine[1] = "-4286"
nine[2] = "8204"
nine[3] = "10677"
nine[4] = "0"
```

# 三、拼 `abstract()`：先把字符串里的整数抽出来

## 目标
把：

```c
"#2,134#-31,56#5,998#711,7,#0"
```

变成：

```md
2134   -3156   5998   7117   0
```

这一步最关键的是：

```md
# 只是分隔符
, 只是干扰符号
- 要决定正负
数字字符才是真正要拼的内容
```

---

## 第一步：整串从左到右扫

用 **积木1：扫描整串**。

```c
for(i = 0; s[i]; i++)
{
    ...
}
```

这块积木的作用：

```md
把整条字符串走完，找到每一个 # 分隔的片段。
```

---

## 第二步：遇到不是 `#` 的地方，就说明进到一个片段里了

用 **积木2：找到一段开始**。

```c
if(s[i] != '#')
{
    ...
}
```

这块积木的作用：

```md
跳过分隔符 #，只处理真正的内容片段。
```

---

## 第三步：在这一段里，只收数字，同时记住负号

这里借用 **积木3：进入这一段内部**。

```c
for(; s[i] && s[i] != '#'; i++)
{
    if(isdigit(s[i]))
        temp[k++] = s[i];
    if(s[i] == '-')
        sign = -1;
}
```

这块积木的作用：

```md
一直处理到下一个 # 为止。
```

在这个过程中：

- 逗号不保存
- 数字保存
- 负号只负责记正负，不进数字串

例如：

```md
-31,56 → 数字串 "3156"，sign = -1
```

---

## 第四步：把数字字符拼成整数

用 **积木5：拼整数**。

```c
while(temp[j])
{
    y = y * 10 + temp[j] - '0';
    j++;
}
```

这块积木的作用：

```md
把 "3156" 这样的数字字符，真正拼成整数 3156。
```

然后再乘上符号：

```c
a[cnt++] = sign * y;
```

---

## `abstract()` 的积木顺序

```md
积木1：扫描整串
→ 积木2：找到片段开始
→ 积木3：处理到下一个 #
→ 本题步骤：只收数字
→ 本题步骤：记录负号
→ 积木5：拼整数
→ 积木7：保存结果
```

# 三、拼 `convert()`：把整数改写成九进制字符串

## 目标
把：

```md
2134   -3156   5998   7117   0
```

变成：

```md
2831   -4286   8204   10677   0
```

---

## 第一步：先一个一个处理整数

```c
for(i = 0; i < m; i++)
{
    ...
}
```

这一步的作用：

```md
a[] 里有几个整数，我们就转换几次。
```

---

## 第二步：先处理 0 和负数这两个特殊情况

```c
if(temp == 0)
{
    strcpy(nine[cnt++], "0");
    continue;
}
if(temp < 0)
{
    sign = -1;
    temp = -temp;
}
```

这一步的作用：

```md
0 不能走普通拆位流程
负数要先变成正数拆位，最后再把负号补回去
```

---

## 第三步：按 9 进制拆位

用 **积木18：其他进制拆位 / 转换**。

```c
while(temp)
{
    int wei = temp % 9;
    temp1[k++] = wei + '0';
    temp = temp / 9;
}
```

这块积木的作用：

```md
不断取余，得到九进制的每一位。
```

例如：

```md
2134 ÷ 9
最后会依次拆出 1、3、8、2
```

注意：

```md
拆出来的顺序是反的。
```

---

## 第四步：把拆出来的结果倒过来，再补负号

这是本题专用步骤。

```c
if(sign == -1)
    temp2[n++] = '-';
for(j = k - 1; j >= 0; j--)
{
    temp2[n++] = temp1[j];
}
```

这一步的作用：

```md
把倒着拆出来的数字翻回正常顺序。
```

所以：

```md
1 3 8 2  →  2831
```

如果原来是负数，还要变成：

```md
-4286
```

---

## 第五步：把九进制字符串存进二维数组

用 **积木7：统计个数 / 保存结果**。

```c
strcpy(nine[cnt++], temp2);
```

这块积木的作用：

```md
每转换完一个整数，就把结果放到 nine 的一行里。
```

---

## `convert()` 的积木顺序

```md
先遍历 a[] 中的每个整数
→ 本题步骤：先处理 0 和负数
→ 积木18：按 9 进制拆位
→ 本题步骤：倒序恢复，并补负号
→ 积木7：保存九进制字符串
```

# 五、变式迁移

## 变式 1
如果题目要求转成八进制，要改：

```md
convert() 里 temp % 9 和 temp / 9。
```

## 变式 2
如果片段分隔符从 # 改成 @，要改：

```md
abstract() 里“找到一段开始”和“处理到哪里结束”的条件。
```

## 变式 3
如果题目说逗号也要保留，那就不能只收数字，要改：

```md
abstract() 里过滤字符的规则。
```

/*----------------------------------------------------------------------
【程序设计】
------------------------------------------------------------------------
题目：字符串s由若干形如"#2,134"格式的子串组成，首先将s中所有该格式的子串
      转换成整数，存入数组a中，然后将数组a中每个整数转换成九进制数字字符

从串中抽取出的整数有:
2134    -3156   5998    7117    0
它们对应的九进制数字字符串为:
2831    -4286   8204    10677   0

1.编写函数int abstract(char s[],int a[])，按上述规则将字符串s中的子串
  转换成整数，存入数组a中，函数返回整数个数。

2.编写函数void convert(int a[], char nine[][N], int m), 将长度为m的数组a中每个
  整数转换成九进制数字字符串，并存入二维字符数组nine中。
---------------------------------------------------------
注意：在指定范围内编写程序，勿修改指定范围外的任何内容。
-------------------------------------------------------*/
#include<stdio.h>
#include<stdlib.h>
#include<conio.h>
#include<ctype.h>
#include<math.h>

#define M 50
#define N 50

int abstract(char s[], int a[]) 
{
/**********Program**********/
//int a;int b;int c;int d;
    int i;
    int cnt=0;
    for(i=0;s[i];i++){
    	if(s[i]!='#'){
    		char temp[10];
    		int k=0;
    		int sign=1;
    		for(;s[i]&&s[i]!='#';i++){
    			if(isdigit(s[i])){
    				temp[k++]=s[i];
				}
				if(s[i]=='-'){
					sign=-1;
				}
			}
			temp[k]='\0';
			int y=0;

			while(temp[j]){
				y=y*10+temp[j]-'0';
				j++;
			}
    		a[cnt++]=sign*y;
		}
	}
    
	return cnt; 



/**********  End  **********/
}

void convert(int a[], char nine[][N], int m)
{
/**********Program**********/
   int i;

   for(i=0;i<m;i++){

	   }
   	   char temp1[10];
   	   int k=0;

	   //倒叙

	   if(sign==-1){
	   	   temp2[n++]='-';
	   }
	   for(j=k-1;j>=0;j--){
	   	   temp2[n++]=temp1[j];
