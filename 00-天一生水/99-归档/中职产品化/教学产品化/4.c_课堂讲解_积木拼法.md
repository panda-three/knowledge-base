# 4.c 课堂讲解：顺着题目拼积木

## 这道题的做法
4.c 看起来像“算分题”，其实它还是老积木在重新拼。

这道题分两步：

```md
第一步：先算出每个字符串的总能量值。
第二步：再按总能量值把字符串排好序。
```

所以我们要看两个函数：

```c
int calculate_energy(char sen[])
void sort(char sen[][100], int energy[], int n)
```

先按这个顺序看：

```md
读题干 → 看参数 → 选积木 → 拼代码 → 检查结果
```

---

## 一、题目要我们做什么

> 先把原题题干放在最前面，方便我们一边看讲解，一边对照题目要求。


# 二、先看函数参数长什么样

## 1. `int calculate_energy(char sen[])`

### 调用位置
```c
energy[i] = calculate_energy(sen[i]);
```

### 传进来的 `sen[]` 长什么样
例如：

```c
"Hello World"
```

### 这个函数要算出什么
题目规定：

```md
小写 a~z：26 到 1
大写 A~Z：52 到 27
空格：-1
其他字符：0
```

所以：

```c
calculate_energy("Hello World") = 197
```

函数返回的就是这一个字符串的总能量值。

---

## 2. `void sort(char sen[][100], int energy[], int n)`

### 调用位置
```c
sort(sen, energy, N);
```

### 传进来的 `sen[][100]` 和 `energy[]` 长什么样
排序前大概是：

```md
Hello World      197
C Programming    241
I Love coding    232
Python is fun!   154
Good Morning     217
```

### 排序后要变成什么
按能量值升序：

```md
Python is fun!   154
Hello World      197
Good Morning     217
I Love coding    232
C Programming    241
```

这里最关键的是：

```md
字符串和它对应的能量值不能分家。
```

# 三、拼 `calculate_energy()`：先把一个字符串的能量值算出来

## 目标
把：

```c
"Hello World"
```

算成：

```c
197
```

---

## 第一步：整串逐个字符看

用 **积木1：扫描整串**。

```c
while(sen[i])
{
    ...
}
```

这块积木的作用：

```md
把字符串里的每一个字符都检查一遍。
```

---

## 第二步：按字符类型套题目给的规则

这是本题专用步骤。

```c
if(islower(sen[i]))
    sum = sum + 123 - sen[i];
else if(isupper(sen[i]))
    sum = sum + 117 - sen[i];
else if(sen[i] == ' ')
    sum = sum - 1;
```

这一步的作用：

```md
把题目里的“能量值规则”真正写成程序。
```

为什么是：

```c
123 - sen[i]
```

因为：

```md
a 的 ASCII 是 97，123 - 97 = 26
z 的 ASCII 是 122，123 - 122 = 1
```

同理：

```md
A 的 ASCII 是 65，117 - 65 = 52
Z 的 ASCII 是 90，117 - 90 = 27
```

---

## 第三步：把每个字符的能量累加起来

```c
sum = sum + ...
```

这一步的作用：

```md
把一个字符串里所有字符的能量值加总，得到最后答案。
```

例如：

```md
空格字符也参与运算，而且是 -1。
```

所以：

```md
"Hello World" 不只是字母相加，中间那个空格也要减 1。
```

---

## `calculate_energy()` 的积木顺序

```md
积木1：扫描整串
→ 本题步骤：按小写/大写/空格规则算能量
→ 积木19：按字符规则累加值
```

# 三、拼 `sort()`：按能量值升序排列

## 目标
把：

```md
Hello World      197
C Programming    241
I Love coding    232
Python is fun!   154
Good Morning     217
```

排成：

```md
Python is fun!   154
Hello World      197
Good Morning     217
I Love coding    232
C Programming    241
```

---

## 第一步：按 `energy[]` 做冒泡排序

用 **积木9：冒泡排序**。

```c
for(i = 0; i < n - 1; i++)
{
    for(j = 0; j < n - 1 - i; j++)
    {
        if(energy[j] > energy[j+1])
        {
            ...
        }
    }
}
```

这块积木的作用：

```md
让能量值小的往前走，大的往后走。
```

---

## 第二步：交换能量值

用 **积木10：交换整数**。

```c
int temp = energy[j];
energy[j] = energy[j+1];
energy[j+1] = temp;
```

这块积木的作用：

```md
把两个字符串对应的能量值对调。
```

---

## 第三步：字符串也要跟着一起交换

用 **积木11：交换字符串**。

```c
char str[100];
strcpy(str, sen[j]);
strcpy(sen[j], sen[j+1]);
strcpy(sen[j+1], str);
```

这块积木的作用：

```md
保证 sen[j] 和 energy[j] 始终一一对应。
```

如果只换 energy，不换 sen，最后字符串和能量值就错位了。

---

## `sort()` 的积木顺序

```md
积木9：冒泡排序
→ 积木10：交换整数
→ 积木11：交换字符串
```

# 五、变式迁移

## 变式 1
如果空格的能量值改成 0，要改：

```md
calculate_energy() 里 sen[i] == ' ' 的处理。
```

## 变式 2
如果排序改成降序，要改：

```md
sort() 里 energy[j] > energy[j+1] 的方向。
```

## 变式 3
如果除了输出字符串，还要输出原下标，要改：

```md
排序时要再带一个下标数组一起交换。
```

# 六、完整代码

```c
/*----------------------------------------------------------------------
【程序设计】
------------------------------------------------------------------------
题目：为每个字符设定一个“能量值”，能量值的设定规则为：小写字母a到z的能量值
      分别为26到1；大写字母A到Z的能量值分别为52到27；空格字符的能量值
      为-1；其他字符的能量值为0。
      设二维字符数组sen中存放了若干字符串，编写程序，计算sen中每个字符串的
      总能量值，存入数组energy，并按照各字符串的总能量值按升序将所有字符串排序，
      输出排序后的字符串及其对应的总能量值。

程序运行结果示例：
原始字符串及能量值：
Hello World      =>197
C Programming    =>241
I Love coding    =>232
Python is fun!   =>154
Good Morning     =>217
 
排序后的字符串及能量值：
Python is fun!   =>154
Hello World      =>197
Good Morning     =>217
I Love coding    =>232
C Programming    =>241

1.编写函数 int calculate_energy(char sen[])，计算字符串 sen 的总能量值，
  并作为函数的返回值。

2.编写函数 void sort(char sen[][100], int energy[], int n)，根据字符数组
  sen中n个字符串的能量值energy，按升序将sen数组的字符串排序。
-----------------------------------------------------------------------
注意：在指定范围内编写程序，勿修改指定范围外的任何内容
---------------------------------------------------------------------*/
#include <stdio.h>
#include <stdlib.h>
#include <string.h>
#include <math.h>
#include <ctype.h>

#define N 5

int calculate_energy(char sen[]) 
{
/**********Program**********/
    int i=0;
    int sum=0;
    while(sen[i]){
    	 if(islower(sen[i])){
    	 	 sum=sum+123-sen[i];
		 }else if(isupper(sen[i])){
		 	 sum=sum+117-sen[i];
		 }else if(sen[i]==' ')
		     sum=sum-1;
	    i++;
	}
   return sum;
/**********  End  **********/
}

void sort(char sen[][100], int energy[], int n) 
{
/**********Program**********/
    int i,j;
    for(i=0;i<n-1;i++){
    	for(j=0;j<n-1-i;j++){
    		if(energy[j]>energy[j+1]){
    			 int temp=energy[j];
    			 energy[j]=energy[j+1];
    			 energy[j+1]=temp;
    			 
    			 char str[100];
    			 strcpy(str,sen[j]);
    			 strcpy(sen[j],sen[j+1]);
    			 strcpy(sen[j+1],str);
    			 
			}
		}
	}



/**********  End  **********/
}

int main() 
{
	// sen[0]  energy[0]
	// sen[1]  energy[1]
    char sen[N][100] = {"Hello World",
                        "C Programming",
                        "I Love coding",
                        "Python is fun!",
                        "Good Morning"};
    int energy[N], i;
    FILE *fp;
    if ((fp = fopen("DATA.dat", "w")) == NULL) 
    {
        printf("File open error\n");
        exit(0);
    }
    for (i = 0; i < N; i++)
        energy[i] = calculate_energy(sen[i]);

    printf("原始字符串及能量值：\n");
    for (i = 0; i < N; i++)
        printf("%s\t=>%d\n", sen[i], energy[i]);

    sort(sen, energy, N);

    printf("\n排序后的字符串及能量值：\n");
    for (i = 0; i < N; i++) 
    {
        printf("%s\t=>%d\n", sen[i], energy[i]);
        fprintf(fp, "%s->%d\n", sen[i], energy[i]);
    }
    fclose(fp);
    return 0;
}
```
