# 12.c 课堂讲解：顺着题目拼积木

## 这道题的做法
12.c 分两步：

```md
先把空格分隔的单词切出来
→ 再判断哪些单词是“不降单词”
```

题目里“不降”的意思不是字典序，而是：

```md
从左到右，每个字符的 ASCII 值都不能比前一个小
```

例如：

```md
aim    a ≤ i ≤ m
boost  b ≤ o ≤ o ≤ s ≤ t
```

---

## 一、题目要我们做什么

> 先把原题题干放在最前面，方便我们一边看讲解，一边对照题目要求。

```c
/*----------------------------------------------------------------------
【程序设计】
------------------------------------------------------------------------
题目：字符串str中存储着由空格分隔的英文单词。程序需先逐个提取这些单词，
      并将其存储于二维数组words的每一行。随后，从words中找出所有不降单词，
      并保存至二维数组ascend中。
      所谓不降单词是指从左至右单词的各字母的ASCII值非递减，例如"been"和
      "ghosy"便属于不降单词。
    
程序运行结果如下：
一共有8个单词
其中有6个不降单词，分别是:
aim
boost
begin
deeps
add
glory

1.编写函数int split(char words[][20], char str[])，将str中由空格分隔的
  英文单词，依次存放于二维数组words的每一行，最终返回单词的数量。

2.编写函数int check(char ascend[][20],char words[][20],int n)，从存储
  在words中的n个单词里找出所有不降单词，并将这些不降单词保存至ascend中，
  最后返回不降单词的数量。  
---------------------------------------------------------
注意：在指定范围内编写程序，勿修改指定范围外的任何内容。
-------------------------------------------------------*/
```

```c
n = split(words, str);
```

```c

```

切开以后是：

```md
aim
bright
boost
cheer
begin
deeps

glory
```

函数返回：

```c
n = 8
```

### 调用位置
```c
n = check(ascend, words, n);
```

```md
aim

```


# 三、拼 `split()`：先把单词切出来

## 目标
把：

```c
"aim bright boost cheer begin deeps add glory "
```

切成一行一个单词。

---

## 第一步：整串从左到右扫

用 **积木1：扫描整串**。

```c
while(str[i])
{
    ...
}
```

这块积木的作用：

```md
把整条字符串走完，逐段找单词。
```

---

## 第二步：遇到非空格，就说明单词开始了

用 **积木2：找到一段开始**。

```c
if(str[i] != ' ')
{
    ...
}
```

这块积木的作用：

```md
跳过空格，只在真正的单词开始处动手。
```

---

## 第三步：一直收到下一个空格为止

用 **积木3：进入这一段内部**。

```c
while(str[i] && str[i] != ' ')
{
    temp[k++] = str[i];
    i++;
}
```

这块积木的作用：

```md
把当前单词完整收起来。
```

---

## 第四步：把单词存进二维数组

用 **积木4：把这一段存成字符串**。

```c
temp[k] = ' ';
strcpy(words[cnt++], temp);
```

这块积木的作用：

```md
让 words 的每一行保存一个单词。
```

---

## `split()` 的积木顺序

```md
积木1：扫描整串
→ 积木2：找到单词开始
→ 积木3：处理到下一个空格
→ 积木4：把这一段存成字符串
```

---

# 三、拼 `check()`：筛出不降单词

## 目标
从：

```md
aim
bright
boost
cheer
begin
deeps
add
glory
```

筛出：

```md
aim
boost
begin
deeps
add
glory
```

---

## 第一步：先逐个取出单词

```c
for(i = 0; i < n; i++)
{
    char temp[20];
    strcpy(temp, words[i]);
    ...
}
```

这一步的作用：

```md
一个单词一个单词检查。
```

---

## 第二步：先假设它是不降单词

用 **积木6：flag 做记号**。

```c
int flag = 1;
```

这块积木的作用：

```md
先默认合格，只要后面发现不满足条件，就把 flag 改成 0。
```

---

## 第三步：比较相邻字符有没有“往下降”

用 **积木17：相邻字符关系判断**。

```c
for(j = 1; temp[j]; j++)
{
    if(temp[j] < temp[j-1])
    {
        flag = 0;
        break;
    }
}
```

这块积木的作用：

```md
只要后一个字符比前一个小，这个单词就不是不降单词。
```

例如：

```md
boost  b ≤ o ≤ o ≤ s ≤ t   合格
cheer  c < h 后面 e < h    不合格
```

---

## 第四步：如果 flag 还等于 1，就保存进去

用 **积木7：统计个数 / 保存结果**。

```c
if(flag == 1)
{
    strcpy(ascend[cnt++], temp);
}
```

这块积木的作用：

```md
把真正符合要求的不降单词放到 ascend 里。
```

---

## `check()` 的积木顺序

```md
先遍历每个单词
→ 积木6：flag 做记号
→ 积木17：判断相邻字符是否下降
→ 积木7：保存不降单词
```

# 四、整道题的积木拼装图

```md
12.c
├── split(words, str)
│   ├── 积木1：扫描整串
│   ├── 积木2：找到单词开始
│   ├── 积木3：处理到下一个空格
│   └── 积木4：把这一段存成字符串
└── check(ascend, words, n)
    ├── 先遍历每个单词
    ├── 积木6：flag 做记号
    ├── 积木17：相邻字符关系判断
    └── 积木7：保存不降单词
```

# 五、变式迁移

## 变式 1
如果题目要求的是“严格递增单词”，要改：

```md
if(temp[j] < temp[j-1]) 这句要改成 <= 的判断逻辑。
```

## 变式 2
如果分隔符从空格改成逗号，要改：

```md
split() 里处理一段开始和结束的条件。
```

## 变式 3
如果最后要按长度排序再输出，要改：

```md
check() 保存完之后，还要加一个排序函数。
```

# 六、完整代码

```c
/*----------------------------------------------------------------------
【程序设计】
------------------------------------------------------------------------
题目：字符串str中存储着由空格分隔的英文单词。程序需先逐个提取这些单词，
      并将其存储于二维数组words的每一行。随后，从words中找出所有不降单词，
      并保存至二维数组ascend中。
      所谓不降单词是指从左至右单词的各字母的ASCII值非递减，例如"been"和
      "ghosy"便属于不降单词。
    
程序运行结果如下：
一共有8个单词
其中有6个不降单词，分别是:
aim
boost
begin
deeps
add
glory

1.编写函数int split(char words[][20], char str[])，将str中由空格分隔的
  英文单词，依次存放于二维数组words的每一行，最终返回单词的数量。

2.编写函数int check(char ascend[][20],char words[][20],int n)，从存储
  在words中的n个单词里找出所有不降单词，并将这些不降单词保存至ascend中，
  最后返回不降单词的数量。  
---------------------------------------------------------
注意：在指定范围内编写程序，勿修改指定范围外的任何内容。
-------------------------------------------------------*/
#include <stdio.h>
#include <stdlib.h>
#include <math.h>
#include <ctype.h>
#include <string.h>

int split(char words[][20],char str[]) 
{
/**********Program**********/
	int i=0,cnt=0;
	while(str[i]){
		if(str[i]!=' '){
			char temp[20];int k=0;
			while(str[i]&&str[i]!=' '){
			  temp[k++]=str[i];
			   i++;
			}
			temp[k]='\0';
			strcpy(words[cnt++],temp);
		}else{
		  i++;
	    }		
	}
	return cnt;
/**********  End  **********/
}

int check(char ascend[][20],char words[][20],int n) 
{
/**********Program**********/
    /*
       1.遍历words这个数组，取出每一个单词
	   2.判断是否为不降单词  ：标志位
	   3.放入ascend中 
    */
     int i;
//      1.遍历words这个数组，取出每一个单词
     int cnt=0;
	 for(i=0;i<n;i++){
	 	char temp[20];
		strcpy(temp,words[i]) ;
//		 2.判断是否为不降单词  ：标志位
        int j;
        int flag=1;//是不降单词 
		for(j=1;temp[j];j++){
			if(temp[j]<temp[j-1]){
				flag=0; //不是不降单词
				break; 
			}
		}
		if(flag==1){
//			 3.放入ascend中 
			strcpy(ascend[cnt++],temp);
		}
	 } 
  
     return cnt;
/**********  End  **********/
}

int main(void) 
{
    char str[]= {"aim bright boost cheer begin deeps add glory "};
    char words[10][20], ascend[10][20];
    int i,j,n;
    FILE *fp=fopen("DATA.dat","w");
    if(fp==NULL)
    {
        printf("File open error\n"), exit(0);
    }    
    n=split(words,str);
    printf("一共有%d个单词\n",n);
    fprintf(fp, "单词个数[%d]\n",n);
    n=check(ascend,words,n);
    printf("其中有%d个不降单词，分别是:\n",n);
    fprintf(fp, "不降词数[%d]\n",n);
    for(i=0; i<n; i++) 
    {
        printf("%s\n",ascend[i]);   
        j=0;
        while(ascend[i][j])
            fprintf(fp, "%c",ascend[i][j++]+90);  
        fprintf(fp, "--");                
    }
    fclose(fp);
    return 0;
}
```
