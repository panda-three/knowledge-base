# 206.c 课堂讲解：顺着题目拼积木

## 一、题目要我们做什么

> 先放原题。我们后面每一块代码，都是在替题目补一个动作。

```c
/*----------------------------------------------------------------------
【程序设计】
------------------------------------------------------------------------
题目：从给定的字符串中依次取出前k个数字字符组成一个整数(不考虑正负号)，
      并判断该整数是否为幻方数，如果是则输出yes，否则输出no。
      幻方数是指：整数至少由三位数字组成，且整数的最高位+最低位数字之和
      等于次高位+次低位数字之和，依次类推，如果整数是奇数位数，
      则中间数的2倍等于最高位+最低位数字之和。

例如：8536974：8+4等于5+7等于3+9等于6*2，因此8536974是幻方数。
      14285：1+5不等于4+8，因此14285不是幻方数。

程序运行结果如下：
字符串为：Fei5-6abo45%6,$458@x
k=4,the number     5645 is yes
k=5,the number    56456 is no
k=6,the number   564564 is no
k=7,the number  5645645 is yes
k=8,the number 56456458 is no
k=9,the number 56456458 is no

1、编写函数int take(char a[],int k)，功能是从a字符串中取出前k个数字字符，
   转换为一个正整数并返回。如果字符串中不足k个数字则最多取k数字组成整数返回。
2、编写函数int check(int n)判断多位整数n是不是幻方数，如果是幻方数函数
   返回1，否则返回0。
--------------------------------------------------------
注意：在指定范围内编写程序，勿修改指定范围外的任何内容。
-------------------------------------------------------*/
```

这道题其实分成两个很清楚的小任务：

```md
任务1：从字符串里，按顺序拿前 k 个数字字符，拼成一个整数。
任务2：判断这个整数是不是幻方数。
```

---

## 二、先看函数参数长什么样

### 1. `int take(char a[], int k)`

#### 调用位置
```c
n = take(a, k);
```

#### `a[]` 长什么样
```c
"Fei5-6abo45%6,$458@x"
```

把里面的数字字符按顺序抽出来，其实是：

```md
5 6 4 5 6 4 5 8
```

#### `k` 是什么
`k` 表示这次要拿前几个数字字符。

例如：
- `k = 4` 时，要拿：`5 6 4 5`
- `k = 7` 时，要拿：`5 6 4 5 6 4 5`

#### 这个函数要返回什么
把前 `k` 个数字字符拼成一个整数后返回。

例如：

```md
k = 4 → 5645
k = 7 → 5645645
```

如果字符串里数字不够，就“最多拿到为止”。

---

### 2. `int check(int n)`

#### 调用位置
```c
check(n)
```

#### `n` 长什么样
`n` 就是上一个函数拼出来的整数。

例如：

```md
5645
56456
5645645
```

#### 这个函数要返回什么
- 如果 `n` 是幻方数，返回 `1`
- 如果不是，返回 `0`

也就是说，这个函数并不负责打印 `yes/no`，它只负责给出真假结果。

---

## 三、拼 `take()`

这个函数的目标先说清楚：

```md
在整条字符串里找数字字符，
按出现顺序一个一个拿，
一边拿一边拼成整数，
拿满 k 个就停。
```

### 第 1 块：先扫描整串
题目给的是整条字符串，所以第一步一定是用积木1「扫描整串」。

```c
for(i = 0; a[i]; i++)
{
    ...
}
```

这块积木的作用：把整条字符串先从左到右扫一遍。

---

### 第 2 块：只有看到数字字符，才把它接进结果里
这题不是切完整片段，而是：

```md
只要遇到数字字符，就把它拿走。
```

所以这里先加入口判断：

```c
if(isdigit(a[i]))
{
    ...
}
```

然后马上用积木4「拼整数 / 按进制拼整数」：

```c
s = s * 10 + a[i] - '0';
j++;
```

这一步的作用：
- 把当前数字接到结果整数后面
- 同时记录已经拿了几个数字

例如：

```md
先拿到 5 → s = 5
再拿到 6 → s = 56
再拿到 4 → s = 564
再拿到 5 → s = 5645
```

---

### 第 3 块：一旦拿满 k 个，就立刻停
题目要求的是“前 k 个数字字符”，不是“把所有数字都拿完”。

所以每拿到一个数字，我们都要问：

```md
够 k 个了吗？
```

代码就是：

```c
if(j == k)
{
    break;
}
```

这一步很关键。  
它保证我们拿的是“前 k 个”，而不是“所有数字”。

---

### `take()` 到这里就完整长出来了
```c
int take(char a[],int k)
{
    int i;
    int s = 0;
    int j = 0;
    for(i = 0; a[i]; i++){
        if(isdigit(a[i])){
            s = s * 10 + a[i] - '0';
            j++;
        }
        if(j == k){
            break;
        }
    }
    return s;
}
```

## 四、拼 `check()`

这个函数不要一上来就急着写判断。  
先问自己：

```md
幻方数到底怎么判断？
```

题目说的是：
- 最高位 + 最低位
- 次高位 + 次低位
- 再往里一层一层比

所以这题的核心不是直接比较，而是先把数字拆开，放到能从两头往中间看的位置上。

### 第 1 块：先把整数拆位
这里先用积木7「拆位 / 拆编码 / 进制转换」。

```c
int temp = n;
int a[10] = {0};
int k = 0;
while(temp){
    a[k++] = temp % 10;
    temp = temp / 10;
}
```

这一步的作用：把整数一位一位拆出来，放进数组。

例如：

```md
n = 5645645
拆完后数组里大致是：5 4 6 5 4 6 5
```

注意这里数组里是“从低位往高位”存的。  
但这没关系，因为我们后面正好要从两头往中间看。

---

### 第 2 块：设左右指针，从两边往中间夹
现在数字已经拆好了，接下来就不是继续拆，
而是开始比较每一层的两边和。

先把左右位置定出来：

```c
int i = 0;
int j = k - 1;
int flag = 1;
```

这里：
- `i` 指向一端
- `j` 指向另一端
- `flag` 表示目前默认它是幻方数

---

### 第 3 块：本题步骤「比较两端和是不是一直相等」
这一步是这道题自己的判断核心。

```c
while(i < j){
    if((a[i] + a[j]) != (a[i+1] + a[j-1])){
        flag = 0;
        break;
    }
    i++;
    j--;
}
```

这一步在做什么？

它其实是在不断比较：

```md
最外层和
= 下一层和
= 再下一层和
```

只要有一层对不上，就不是幻方数。

例如：

```md
5645
5 + 5 = 10
6 + 4 = 10
所以它通过
```

再比如：

```md
56456
5 + 6 = 11
6 + 5 = 11
中间是 4
但 4 * 2 = 8，不等于 11
所以它不通过
```

注意：这份题目代码的实现方式，是通过这一层一层的和比较来完成判断。
我们这里先顺着这份代码理解和讲解。

---

### `check()` 到这里就完整长出来了
```c
int check(int n)
{
    int temp = n;
    int a[10] = {0};
    int k = 0;
    while(temp){
        a[k++] = temp % 10;
        temp = temp / 10;
    }
    int i = 0, j = k - 1;
    int flag = 1;
    while(i < j){
        if((a[i] + a[j]) != (a[i+1] + a[j-1])){
            flag = 0;
            break;
        }
        i++;
        j--;
    }
    return flag;
}
```

## 六、变式迁移

- 如果题目改成“取前 k 个字母字符”，就把 `isdigit` 改成字母判断。
- 如果题目改成“取后 k 个数字字符”，就不能从左往右直接拿，要换思路。
- 如果题目改成“判断回文数”，就还是先拆位，但后面比较的是“对应位置是否相等”，不是“对应位置和是否相等”。
- 如果题目改成“各层和都等于某个固定值”，那本题步骤里的判断规则就要改。

## 八、用一堂体系把这道题学扎实

### 1. 这道题在练什么能力
从一堂体系看，这题在练：

- **输入能力 I**：从杂乱字符串里按顺序取出前 `k` 个数字字符
- **处理能力 P**：先拼整数，再拆位，再做结构判断
- **输出能力 O**：给出真假结果 `yes / no`

所以这题不是两道散题，而是：

> **先取数，再验结构。**

### 2. 这道题最值得刻意练习的点
1. 只在数字字符处取值
2. 取一个数字就往后拼一次
3. 拿满 `k` 个立刻停
4. 判断结构题时，先拆位，再两头夹着比

### 3. 这道题的小口诀

```md
先把前k数字拿
一位一位往后加
整数先拆再夹看
层层相等才算它
```

### 4. 课后怎么复盘
做完这题，我们重点复盘：

- 我有没有先看清 `take(a,k)` 和 `check(n)` 的分工？
- 我能不能说清楚“前 k 个数字字符”和“所有数字字符”的区别？
- 我下次看到“最高位、最低位、次高位、次低位”时，能不能立刻想到先拆位？

如果这几点能答清楚，这题就不只是会做，而是进入了可复用状态。
