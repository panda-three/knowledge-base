# 2024 编程题积木提取总表

这份表只做一件事：把 `2024编程题/195.c` 到 `206.c` 里的函数，拆成学生能复用的代码积木。  
判断标准：能在多道题里复用、不是单行小语法、能代表一个解题动作，才放进共享积木库。

## 二、2024 高频积木

### 1. 字符串扫描 + 找一段 + 进入一段
出现题：195、196、199、200、202、204、205、206。  
这是 2024 年最核心的底层动作。

```c
for(i = 0; str[i]; i++)
{
    if(找到一段开始)
    {
        for(; str[i] && 还在这一段; i++)
        {
            ...
        }
    }
}
```

### 2. 拼整数 / 按进制拼整数
出现题：195、196、199、200、204、205、206。  
其中 199 是八进制拼整数，204 是十六进制拼整数，所以“拼整数”已经从十进制扩展为“按进制拼整数”。

```c
y = y * 10 + str[i] - '0';
```

八进制变形：

```c
y = y * 8 + str[i] - '0';
```

十六进制变形：

```c
y = y * 16 + 当前十六进制位的值;
```

### 3. 整数拆位
出现题：198、200、206，也和 2025 年多道进制题相连。  
用于从编码整数中取信息、逆序、判断某一位是否出现。

```c
while(n)
{
    int wei = n % 10;
    n = n / 10;
}
```

### 4. 从编码整数 / 固定位置里拆信息
出现题：201、203。  
201 从身份证固定位置取性别和出生日期；203 从 `成绩+学号+性别` 编码整数中拆信息。

```c
score = num / 100;
sex = num % 10;
```

或：

```c
mid(str, p, w);
```

### 5. 排序 + 交换
出现题：198、199、201、203、204。  
排序条件会变，但外壳基本稳定。

```c
for(i = 0; i < n - 1; i++)
{
    for(j = 0; j < n - 1 - i; j++)
    {
        if(应该交换)
        {
            交换;
        }
    }
}
```

### 6. 新升级积木：找最大 / 最小 / 次大 / 次小
2024 里至少两题形成稳定动作：
- 195：提取所有数字后找最小数、最大数。
- 202：每位选手找最高、次高、最低、次低，再求平均。

因此本轮已升级为共享积木 20。

```c
max = a[0];
min = a[0];
for(i = 0; i < n; i++)
{
    if(a[i] > max)
        max = a[i];
    if(a[i] < min)
        min = a[i];
}
```

## 三、保留为“本题步骤”的动作

这些动作虽然重要，但目前更像具体题目的特殊规则，不单独升级成共享积木。

| 题号 | 本题步骤 | 不升级原因 |
|---|---|---|
| 195 | 求所有因子和，并比较 `f(m)=f(n)=m+n+1` | 条件强绑定本题，复用面暂不够宽 |
| 196 | 平衡三进制中 `2→Z`、`3→0` 并进位；负数 `1/Z` 互换 | 是特定进制规则，可放在进制转换积木 18 下面讲变形 |
| 197 | 左下三角填数，且增量逐次增加 | 结构和数据生成规则都很题目化 |
| 199 | 只对素数位置进行排序，非素数位置保持不变 | 可作为排序条件变形，暂不独立升级 |
| 200 | 计算 `2^m-1`、逆序奇偶、是否含数字 1 | 多个筛选条件组合，题目专用 |
| 202 | `atof` 字符串转 double | 只是库函数调用，不是完整解题积木 |
| 203 | 前三名必须男女都有，不满足则替换第三名 | 竞赛规则专用 |
| 206 | 两端夹逼判断幻方数 | 当前只在本题出现 |

## 四、给学生的 2024 做题口令

```md
1. 先看是不是字符串题：要不要扫整串？
2. 再看是不是连续一段：数字段、单词段、用 # 或逗号隔开的片段？
3. 如果是数字字符，问自己：十进制拼？八进制拼？十六进制拼？
4. 如果是编码整数，先拆位或用 /、% 拆信息。
5. 如果要排名，先套冒泡排序，再替换“应该交换”的条件。
6. 如果要删一个元素，记住：删除不是擦掉，是后面往前补。
7. 如果题目条件很特殊，先放进本题步骤，不急着背成新积木。
```
