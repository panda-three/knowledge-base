# 10.c 课堂讲解：顺着题目拼积木

## 这道题的做法
10.c 分两步：

```md
第一步：从字符串里取出 5 个数。
第二步：把前 3 个当方程系数，后 2 个当区间，用二分法找根。
```

所以它其实是：

```md
字符串取数 + 数学逼近
```

---

## 一、题目要我们做什么

> 先把原题题干放在最前面，方便我们一边看讲解，一边对照题目要求。

```c
/*----------------------------------------------------------------------
【程序设计】
------------------------------------------------------------------------
题目：已知一元二次方程ax^2+bx+c=0在区间[p,q]中有一个根，一元二次方程的
      系数a、b、c，以及p和q的值依次存储在一个以空格分隔的字符串str中，
      编写程序，分别从str中取出a、b、c、p和q的值，然后求出该方程在区间[p,q]
      的根(精确到小数点后2位)。

注意：str中存储的数值字符串或为整数或为小数形式的浮点数。
    
程序运行结果是：
取到的5个数分别是：
2.300  -7.520  4.630  -1.000  1.370
方程在区间[-1.000,1.370]的根是0.82

1.编写函数void getNumber(char s[], double fnum[])，从s中取出a、b、c、p和q
  的值依次保存在fnum中。

2.编写函数double find(double fnum[])，将fnum前3个元素作为一元二次方程的
  系数，后2个元素作为区间，并在该区间中求出该一元二次方程的根。函数返回该根。  
---------------------------------------------------------
注意：在指定范围内编写程序，勿修改指定范围外的任何内容。
-------------------------------------------------------*/
```

# 二、先看函数参数长什么样

## 1. `void getNumber(char s[], double fnum[])`

### 调用位置
```c
getNumber(s, fnum);
```

### 传进来的 `s[]` 长什么样
```c
" +2.3 -7.52   4.63  -1  1.37"
```

里面有：

```md
a = 2.3
b = -7.52
c = 4.63
p = -1
q = 1.37
```

### `fnum[]` 要变成什么
函数执行后：

```md
fnum[0] = 2.3
fnum[1] = -7.52
fnum[2] = 4.63
fnum[3] = -1
fnum[4] = 1.37
```

---

## 2. `double find(double fnum[])`

### 调用位置
```c
root = find(fnum);
```

### `fnum[]` 里每个位置代表什么
```md
fnum[0]  fnum[1]  fnum[2]  → a b c
fnum[3]  fnum[4]            → p q
```

### 这个函数要返回什么
返回：

```md
方程 ax^2 + bx + c = 0 在 [p, q] 里的那个根
```

题目结果是：

```md
0.82
```

# 三、拼 `getNumber()`：先把 5 个数从字符串里取出来

## 目标
把：

```c
" +2.3 -7.52   4.63  -1  1.37"
```

变成：

```md
2.3   -7.52   4.63   -1   1.37
```

---

## 第一步：整串从左到右扫

用 **积木1：扫描整串**。

```c
for(i = 0; s[i]; i++)
{
    ...
}
```

这块积木的作用：

```md
整条字符串都要看，空格多也不能漏。
```

---

## 第二步：遇到非空格，就说明一个数开始了

用 **积木2：找到一段开始**。

```c
if(s[i] != ' ')
{
    ...
}
```

这块积木的作用：

```md
每次只在一个新数的起点开始收集字符。
```

---

## 第三步：一直收到下一个空格为止

用 **积木3：进入这一段内部**。

```c
for(; s[i] && s[i] != ' '; i++)
{
    temp[k++] = s[i];
}
```

这块积木的作用：

```md
把一个完整的数值字符串取出来。
```

例如：

```md
+2.3
-7.52
1.37
```

都完整保留。

---

## 第四步：把数值字符串变成 `double`

这是本题专用步骤。

```c
double num = atof(temp);
fnum[cnt++] = num;
```

这一步的作用：

```md
把字符形式的数字真正变成浮点数。
```

这里不能用整数拼数，因为：

```md
有小数点，也可能有正负号。
```

---

## `getNumber()` 的积木顺序

```md
积木1：扫描整串
→ 积木2：找到非空格片段
→ 积木3：处理到下一个空格
→ 本题步骤：字符串转数值
→ 积木7：保存到 fnum[]
```

# 三、拼 `find()`：在区间里用二分法找根

## 目标
求：

```md
2.3x^2 - 7.52x + 4.63 = 0
```

在区间：

```md
[-1, 1.37]
```

里的根。

---

## 第一步：先写出左右端点和方程系数

```c
double a = fnum[0], b = fnum[1], c = fnum[2];
double left = fnum[3], right = fnum[4];
```

这一步的作用：

```md
把数组里的 5 个数分清角色。
```

---

## 第二步：每次取区间中点

```c
mid = (left + right) / 2;
```

这一步的作用：

```md
二分法的核心就是：每次把区间从中间切开。
```

---

## 第三步：看根落在左半边还是右半边

这是本题专用步骤。

```c
fleft = a * left * left + b * left + c;
fmid = a * mid * mid + b * mid + c;
if(fleft * fmid <= 0)
    right = mid;
else
    left = mid;
```

这一步的作用：

```md
如果左端点和中点函数值异号，说明根在左半边；
否则根在右半边。
```

例如一开始区间是：

```md
left = -1
right = 1.37
mid = 0.185
```

程序会分别算：

```md
f(left)
f(mid)
```

如果这两个值一正一负，就把 `right` 改成 `mid`；否则把 `left` 改成 `mid`。这样区间会越来越短，根的位置就越来越准。

---

## 第四步：不断缩小区间，直到足够精确

```c
while(right - left > 0.00001)
{
    ...
}
```

这一步的作用：

```md
让区间越来越小，最后中点就逼近真正的根。
```

---

## 第五步：返回中点

```c
return (left + right) / 2;
```

这一步的作用：

```md
把最后逼近出来的根交出去。
```

---

## `find()` 的积木顺序

```md
先取出系数和区间
→ 取中点
→ 本题步骤：比较异号关系
→ 不断缩小区间
→ 返回中点
```

# 五、变式迁移

## 变式 1
如果题目改成求三次方程根，要改：

```md
find() 里方程值的计算公式。
```

## 变式 2
如果要求精确到小数点后 3 位，要改：

```md

```

## 变式 3
如果字符串里的数值用逗号分隔，不用空格分隔，要改：


# 六、完整代码

```c
/*----------------------------------------------------------------------
【程序设计】
------------------------------------------------------------------------
题目：已知一元二次方程ax^2+bx+c=0在区间[p,q]中有一个根，一元二次方程的
      系数a、b、c，以及p和q的值依次存储在一个以空格分隔的字符串str中，
      编写程序，分别从str中取出a、b、c、p和q的值，然后求出该方程在区间[p,q]
      的根(精确到小数点后2位)。

注意：str中存储的数值字符串或为整数或为小数形式的浮点数。
    
程序运行结果是：
取到的5个数分别是：
2.300  -7.520  4.630  -1.000  1.370
方程在区间[-1.000,1.370]的根是0.82

1.编写函数void getNumber(char s[], double fnum[])，从s中取出a、b、c、p和q
  的值依次保存在fnum中。

2.编写函数double find(double fnum[])，将fnum前3个元素作为一元二次方程的
  系数，后2个元素作为区间，并在该区间中求出该一元二次方程的根。函数返回该根。  
---------------------------------------------------------
注意：在指定范围内编写程序，勿修改指定范围外的任何内容。
-------------------------------------------------------*/
#include <stdio.h>
#include <stdlib.h>
#include <math.h>
#include <ctype.h>
#include <string.h>

void getNumber(char s[], double fnum[]) 
{
/**********Program**********/
    int i;
    int cnt=0;
    for(i=0;s[i];i++){
    	if(s[i]!=' '){ //起始 
    	    char temp[10];
    	    int k=0;
    		for(;s[i]&&s[i]!=' ';i++){
    			temp[k++]=s[i];
			} 
			if(k>0){
				temp[k]='\0';
				double num=atof(temp);
				fnum[cnt++]=num;
			}
		}
	}

/**********  End  **********/
}

double find(double fnum[]) 
{
/**********Program**********/
    double a = fnum[0], b = fnum[1], c = fnum[2];
    double left = fnum[3], right = fnum[4];
    double mid, fleft, fmid;

    while(right - left > 0.00001)
    {
        mid = (left + right) / 2;
        fleft = a * left * left + b * left + c;
        fmid = a * mid * mid + b * mid + c;
        if(fleft * fmid <= 0)
            right = mid;
        else
            left = mid;
    }
    return (left + right) / 2;
/**********  End  **********/
}

int main() 
{
    char s[]=" +2.3 -7.52   4.63  -1  1.37";    
    int i;
    double fnum[5],root;
    FILE *fp=fopen("DATA.dat","w");
    if(fp==NULL) 
    {
        printf("File open error\n"), exit(0);
    }   
    getNumber(s,fnum);
    printf("取到的5个数分别是：\n"); 
    for(i=0; i<5; i++)
    {
        printf("%.3lf  ",fnum[i]);
        fprintf(fp,"[%.3lf]",fnum[i]);
    }    
    root = find(fnum);
    printf("\n方程在区间[%.3lf,%.3lf]的根是%.2lf\n",fnum[3],fnum[4],root);     
    fprintf(fp,"{%.2lf}\n",root);     
    fclose(fp);
    return 0;
}
```
