# 1.c 课堂讲解：顺着题目拼积木
## 这道题的做法
做 1.c，不能只把数字提取出来就结束。

这道题分两层：

```md
第一层：从每个空格分隔的子串里，抽出数字字符，形成数字子串。
第二层：这些数字子串不能拆开，要按某种顺序拼成最大的长数字。
```

比如 `ab9a3ds` 里面的数字不是 `9` 和 `3` 分开保存，而是按出现顺序拼成 `93`。排序时，`93` 也必须整体移动。

先按这个顺序看：

```md
读题干 → 看参数 → 选积木 → 拼代码 → 检查结果
```
---

## 一、题目要我们做什么
> 先把原题题干放在最前面，方便我们一边看讲解，一边对照题目要求。
```c
/*----------------------------------------------------------------------
【程序设计】
------------------------------------------------------------------------
题目：已知一维字符数组s中存放由若干空格分隔的连续子串，提取连续子串中的
      数字字符，按其在子串中的顺序拼成纯数字子串存入二维数组str中，对二维
      数组中数字子串进行某种排序，使得排序后的数字子串按照从前向后的顺序
      组合成的"长数字串"所表示的整数最大。数字子串必需作为一个整体参与组合。

提示：排序时，可以将两子串前后拼合再比较大小，以便确定是否要交换两子串。
 
程序运行结果如下：

原始串为：
 ab9a3ds  ab9r   mn79a pm9s1d
提取的数字子串为：
93  9  79  91
可以拼接的最大整数为：
9939179

1.编写函数int tqszc(char s[],char str[][10]), 从s串中提取由空格分隔的纯
数字子串，存入二维数组str中，函数返回数字子串的个数。

2.编写函数void Sort(char str[][10],int n)，将str中的n个数字子串进行
排序，使之按序输出即可拼合出最大的整数。
---------------------------------------------------------
注意：在指定范围内编写程序，勿修改指定范围外的任何内容。
-------------------------------------------------------*/
```

# 二、先看函数参数长什么样
## 1. `int tqszc(char s[], char str[][10])`

### 调用位置
```c
n = tqszc(s, str);
```

### 传进来的 `s[]` 长什么样
```c
" ab9a3ds  ab9r   mn79a pm9s1d "
```
它是一整条字符串，里面有空格。每一段里可能混着字母和数字。

### `str[][10]` 要变成什么
函数执行后，`str` 里保存纯数字子串：

```md
str[0] = "93"
str[1] = "9"
str[2] = "79"
str[3] = "91"
```

函数返回：

```c
n = 4
```

---

## 2. `void Sort(char str[][10], int n)`

### 调用位置
```c
Sort(str, n);
```

### 传进来的 `str` 长什么样
```md
93   9   79   91
```

### 排序后要变成什么
要让它们从前往后拼起来最大：

```md
9 + 93 + 91 + 79 = 9939179
```

所以排序后的顺序是：

```md
9   93   91   79
```

# 三、拼 `tqszc()`：从混合子串里抽数字

## 目标
把：

```c
" ab9a3ds  ab9r   mn79a pm9s1d "
```

变成：

```md
93   9   79   91
```

## 第一步：整串从左到右看

用 **积木1：扫描整串**。

```c
while(s[i])
{
    ...
}
```

这块积木的作用：

```md
从左到右走完整个字符串，不能漏掉任何一段。
```

---

## 第二步：遇到非空格，就说明一段开始了

用 **积木2：找到一段开始**。

```c
if(s[i] != ' ')
{
    ...
}
```

这块积木的作用：

```md
跳过空格，只处理真正的子串。
```

例如：

```md
空格 空格 ab9r 空格
        ↑
      从这里开始处理
```

---

## 第三步：在这一段内部，只留下数字

用 **积木3：进入这一段内部**，再配合“判断数字”。

```c
while(s[i] && s[i] != ' ')
{
    if(isdigit(s[i]))
    {
        temp[k++] = s[i];
    }
    i++;
}
```

这块积木的作用：

```md
把当前子串处理完，遇到空格就停。
```

这里最关键的是：字母不要，数字留下。

例如：

```md
ab9a3ds → 93
mn79a   → 79
pm9s1d  → 91
```

---

## 第四步：把抽出来的数字子串存进二维数组

用 **积木7：统计个数 / 保存结果**。

```c
if(k > 0)
{
    temp[k] = '\0';
    strcpy(str[cnt], temp);
    cnt++;
}
```

这块积木的作用：

```md
每得到一个数字子串，就放到 str 的一行里。
```

注意：如果这一段没有数字，`k == 0`，就不要保存。

---

## `tqszc()` 的积木顺序

```md
积木1：扫描整串
→ 积木2：找到非空格片段
→ 积木3：处理到下一个空格
→ 本题步骤：只保留数字字符
→ 积木7：保存数字子串
```

# 三、拼 `Sort()`：让拼出来的长数字最大

## 目标
现在有：

```md
93   9   79   91
```

不是按数值大小排序。因为如果只看数值，`93 > 9`，但拼接时：

```md
93 + 9 = 939
9 + 93 = 993
```

`993` 更大，所以 `9` 应该放在 `93` 前面。

---

## 第一步：用冒泡排序不断比较相邻两个子串

用 **积木9：冒泡排序**。

```c
for(i = 0; i < n - 1; i++)
{
    for(j = 0; j < n - 1 - i; j++)
    {
        ...
    }
}
```

这块积木的作用：

```md
每次只比较相邻两个数字子串，顺序不对就交换。
```

---

## 第二步：比较 `ab` 和 `ba`

这是本题专用步骤。

```c
char ab[20];
strcpy(ab, str[j]);
strcat(ab, str[j+1]);

char ba[20];
strcpy(ba, str[j+1]);
strcat(ba, str[j]);
```

这一步的作用：

```md
把两个子串前后拼两种结果，看哪一种更大。
```

例如比较 `93` 和 `9`：

```md
ab = "939"
ba = "993"
```

因为 `ab < ba`，说明 `9` 应该放前面。

---

## 第三步：顺序不对就交换字符串

用 **积木11：交换字符串**。

```c
if(strcmp(ab, ba) < 0)
{
    char temp[10];
    strcpy(temp, str[j]);
    strcpy(str[j], str[j+1]);
    strcpy(str[j+1], temp);
}
```

这块积木的作用：

```md
让更适合放前面的数字子串往前移动。
```

---

## `Sort()` 的积木顺序

```md
积木9：冒泡排序
→ 本题步骤：拼 ab / ba 比较
→ 积木11：交换字符串
```

# 五、变式迁移
## 变式 1
如果题目要求提取字母子串，不提取数字，要改：

```md
把 isdigit(s[i]) 改成 isalpha(s[i])。
```

## 变式 2
如果排序目标变成“拼接后最小”，要改：

```md
Sort() 里 strcmp(ab, ba) < 0 的方向。
```
