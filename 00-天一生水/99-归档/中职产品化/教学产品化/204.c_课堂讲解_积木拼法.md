# 204.c 课堂讲解：顺着题目拼积木

## 一、题目要我们做什么

> 先放原题，方便我们对照。

```c
/*----------------------------------------------------------------------
【程序设计】
------------------------------------------------------------------------
题目：将N个字符串中连续的十六进制数字字符子串转换成十进制整数，并
      按行存入一个新的二维字符数组，从而形成N个新的字符串。然后，
      根据字符串比较大小的规则，删除在从小到大的序列中排位第三的
      字符串，并保持其他字符串的相对位置不变。

程序运行结果如下：
提取后:
train
growt
compe
gwsuh
skill
ablit

删除后:
train
compe
gwsuh
skill
ablit

1.编写函数void abstract(char a[],char b[])，将字符串a中连续的十六进制
  数字字符转换成十进制整数，依次存放到字符数组b中，形成新的字符串。 
2.编写函数void delet(char t[][10]，int n)，遍历数组t中n个字符串，根据
  字符串比较大小的规则，找到从小到大序列为第三的字符串，删除它，其他
  字符串相对位置不变。 
---------------------------------------------------------
注意：在指定范围内编写程序，勿修改指定范围外的任何内容
-------------------------------------------------------*/
```

## 二、先看函数参数长什么样

这一步不能省。  
因为我们后面不是在背答案，而是要先看懂：**这个函数到底拿到了什么，改完以后又交回什么。**

### 1. `void abstract(char a[], char b[])`

#### 调用位置
```c
abstract(s[i], t[i]);
```

#### 参数1：`a[]` 是什么
`a[]` 是原始字符串中的一行，也就是还没有转换之前的内容。

例如：

```c
"74#72#61#69#6E"
```

把它按 `#` 分开，其实就是：

```md
74   72   61   69   6E
```

这些都不是普通十进制数，而是：

```md
十六进制数字字符片段
```

也就是说，`a[]` 是**输入**，它负责提供原材料。

#### 参数2：`b[]` 是什么
`b[]` 是新的字符数组，用来存转换后的结果。

一开始它是空的，执行后会变成：

```c
"train"
```

也就是说，`b[]` 是**输出位置**，它负责接住转换后的新字符串。

#### 这个函数执行前后，关系是什么
```md
a: "74#72#61#69#6E"
        ↓ 逐段转换
b: "train"
```

所以这个函数不是“改一个数”，而是：

```md
把一整行十六进制片段，转换成一整行新字符串。
```

---

### 2. `void delet(char t[][10], int n)`

#### 调用位置
```c
delet(t, N);
```

#### 参数1：`t[][10]` 是什么
`t` 是二维字符数组，里面装的已经不是原始十六进制串了，
而是 `abstract()` 转换完以后的字符串结果。

调用 `delet(t, N)` 之前，`t` 大概长这样：

```c
t[0] = "train"
t[1] = "growt"
t[2] = "compe"
t[3] = "gwsuh"
t[4] = "skill"
t[5] = "ablit"
```

也就是说，`t` 是这个函数真正要操作的对象。  
它既是输入，也是被改写后的输出。

#### 参数2：`n` 是什么
`n` 表示当前 `t` 里一共有几个字符串。

这里：

```c
n = 6
```

这个参数的作用不是存内容，而是告诉我们：

```md
排序和删除时，一共要处理多少行。
```

#### 这个函数执行前后，关系是什么
执行前：

```md
t 里有 6 个字符串
```

执行后：

```md
先按字符串从小到大排
再删掉排第 3 的那个
后面的整体前移
```

最后实际输出前 `n-1` 行，所以结果会变成：

```c
train
compe
gwsuh
skill
ablit
```

所以 `delet(t, n)` 的真正任务可以翻成一句话：

```md
拿到一个字符串数组，排好序，删掉第 3 个，再把后面往前补。
```

## 三、拼 `abstract()`

### 这一步到底要做什么
把一行像下面这样的十六进制片段：

```md
74#72#61#69#6E
```

变成：

```md
train
```

也就是：
- 先切出每一段十六进制片段
- 再把每段按 16 进制转成整数
- 再把整数当成字符存进 `b[]`

### 第 1 块：积木1「扫描整串」
为什么用这块：`a[]` 是一整条字符串，必须从左到右扫过去。

```c
for(i = 0; a[i]; i++)
{
    ...
}
```

这块积木的作用：把这一整行字符串先扫一遍。

### 第 2 块：积木2「找到一段并处理这一段」
为什么用这块：这道题里 `#` 是分隔符，只要当前字符不是 `#`，就说明一个十六进制片段开始了。

```c
if(a[i] != '#')
{
    int y = 0;
    for(; a[i] && a[i] != '#'; i++)
    {
        ...
    }
}
```

这块积木的作用：一次处理完整个十六进制片段。

### 第 3 块：积木4「拼整数 / 按进制拼整数」
为什么用这块：这题不是十进制拼数，而是十六进制拼数，所以思路还是“往后拼”，只是基数从 `10` 变成 `16`。

```c
if(isalpha(a[i])){
    a[i] = toupper(a[i]);
    a[i] = a[i] - 55;
}
if(isdigit(a[i])){
    a[i] = a[i] - 48;
}
y = y * 16 + a[i];
```

这块积木的作用：把 `74` 这种十六进制片段拼成十进制整数 `116`，也就是字符 `'t'`。

小例子：

```md
74(16)
= 7 * 16 + 4
= 116
116 对应字符 't'
```

### 第 4 块：本题步骤「把整数当字符存进新字符串」
为什么用这块：这道题最后要的是一个新字符串，而不是一个整数数组。

```c
b[cnt++] = y;
b[cnt] = '\0';
```

这一步的作用：把每段转换出来的整数直接当字符塞进 `b[]`。

### `abstract()` 拼完后的完整代码
```c
void abstract(char a[],char b[])
{
    int i;
    int cnt = 0;
    for(i = 0; a[i]; i++)
    {
        if(a[i] != '#')
        {
            int y = 0;
            for(; a[i] && a[i] != '#'; i++)
            {
                if(isalpha(a[i])){
                    a[i] = toupper(a[i]);
                    a[i] = a[i] - 55;
                }
                if(isdigit(a[i])){
                    a[i] = a[i] - 48;
                }
                y = y * 16 + a[i];
            }
            b[cnt++] = y;
        }
    }
    b[cnt] = '\0';
}
```

## 四、拼 `delet()`

### 这一步到底要做什么
题目要求：
1. 先按字符串比较规则从小到大排
2. 找到排第 3 的字符串
3. 删除它
4. 其他字符串相对位置不变

这道题给出的代码其实是：
- 先把整个二维字符串数组排好
- 再把下标 2 这个位置删掉

### 第 1 块：积木6「排序（含交换变形）」
为什么用这块：题目里明确出现了“从小到大序列”，所以必须先排序。

```c
for(i = 0; i < n; i++){
    for(j = 0; j < n - 1 - i; j++){
        if(strcmp(t[j], t[j+1]) > 0){
            char temp[10];
            strcpy(temp, t[j]);
            strcpy(t[j], t[j+1]);
            strcpy(t[j+1], temp);
        }
    }
}
```

这块积木的作用：把字符串数组按字典序从小到大排好。

### 第 2 块：积木8「删除后整体前移」
为什么用这块：排完以后，第 3 个字符串就在下标 `2`。删掉它以后，后面所有字符串要整体前移。

```c
for(i = 3; i < n; i++){
    strcpy(t[i - 1], t[i]);
}
```

这块积木的作用：删除排位第三的字符串，并让后面内容往前补。

### `delet()` 拼完后的完整代码
```c
void delet(char t[][10],int n)
{
    int i,j;
    for(i = 0; i < n; i++){
        for(j = 0; j < n - 1 - i; j++){
            if(strcmp(t[j], t[j+1]) > 0){
                char temp[10];
                strcpy(temp, t[j]);
                strcpy(t[j], t[j+1]);
                strcpy(t[j+1], temp);
            }
        }
    }
    for(i = 3; i < n; i++){
        strcpy(t[i - 1], t[i]);
    }
}
```

## 五、整道题的积木拼装图

```md
204.c
├── abstract(...)
│   ├── 积木1：扫描整串
│   ├── 积木2：找到一段并处理这一段
│   ├── 积木4：拼整数 / 按进制拼整数（16 进制变形）
│   └── 本题步骤：把整数当字符存进新字符串
└── delet(...)
    ├── 积木6：排序（含交换变形）
    └── 积木8：删除后整体前移
```

## 六、变式迁移

- 如果分隔符不是 `#`，只要把积木2里的停止条件改掉。
- 如果不是十六进制，而是八进制、九进制，改积木4里的基数就行。
- 如果不是删第 3 个，而是删第 2 个、第 4 个，只要改删除前移的起点。
- 如果题目要求“删除后保持原相对位置不变”，仍然优先想到积木8。

## 七、完整代码

```c
#include <stdio.h>
#include <stdlib.h>
#include <math.h>
#include <ctype.h>
#include <string.h>

#define N 6 
    
void abstract(char a[],char b[])
{
    int i;
    int cnt=0;
    for(i=0;a[i];i++){
        if(a[i]!='#'){
            int y=0;
            for(;a[i]&&a[i]!='#';i++){
                if(isalpha(a[i])){
                    a[i]=toupper(a[i]);
                    a[i]=a[i]-55;
                }
                if(isdigit(a[i])){
                    a[i]=a[i]-48;
                }
                y=y*16+a[i];
            }
            b[cnt++]=y;
        }
    }
    b[cnt]='\0';
}

void delet(char t[][10],int n)
{
    int i,j;
    for(i=0;i<n;i++){
        for(j=0;j<n-1-i;j++){
            if(strcmp(t[j],t[j+1])>0){
                char temp[10];
                strcpy(temp,t[j]);
                strcpy(t[j],t[j+1]);
                strcpy(t[j+1],temp);
            }
        }
    }
    for(i=3;i<n;i++){
        strcpy(t[i-1],t[i]);
    }
}
```
