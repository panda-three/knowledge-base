# 2025_77 课堂讲解：削峰法删 3 位，再到升序表中查找

## 这题最终要拿什么分

这题有 4 个空：

```c
① dn <= deln
② strn[k] = strn[k + 1]
③ h < b
④ return b
```

我们这节课只做一件事：看懂这 4 个空为什么这么填。

---

## 一、题目要我们做什么

题目说：输入一个不低于 3 位的正整数，不改变数字之间的顺序，用“削峰法”删除其中 3 个数字，得到一个值最小的新整数。

然后到文件 `sortdata.txt` 的升序表中查找这个新整数。

程序流程是：

```md
输入数字字符串
↓
get_min(strn, DEL)：用削峰法删除 3 个数字，得到最小整数
↓
find(newn)：在升序表中查找这个整数
↓
找到就输出序号，找不到就输出不存在
```

这题有两个核心函数：

```c
int get_min(char strn[], int deln);
int find(int num);
```

---

## 二、先看 `get_min` 函数在干什么

函数：

```c
int get_min(char strn[], int deln)
```

两个参数：

| 参数 | 含义 |
|---|---|
| `strn[]` | 输入的数字字符串，比如 `527682` |
| `deln` | 要删除几个数字，本题传入 `DEL`，也就是 3 |

调用位置：

```c
newn = get_min(strn, DEL);
```

所以它要做的是：

```md
从 strn 中删除 deln 个数字，再把剩余数字字符拼成整数返回。
```

注意：

```md
strn[] 里存的是字符，不是真正的整数。
```

比如输入 `527682`，数组里是：

```md
'5' '2' '7' '6' '8' '2'
```

---

## 三、第①空：为什么循环条件是 `dn <= deln`

代码：

```c
for(dn = 1; ① ; dn++)
{
    i = 0;
    while(strn[i] <= strn[i+1] && i < lenth - dn)
        i++;
    for(k = i; k < lenth - dn; k++)
        ②;
}
```

题目要求：

```md
删除其中三个数字。
```

程序里：

```c
#define DEL 3
newn = get_min(strn, DEL);
```

所以 `deln` 就是要删除的次数。

外层 `for` 循环每执行一次，就删除一个数字。

| `dn` | 含义 |
|---:|---|
| 1 | 删除第 1 个数字 |
| 2 | 删除第 2 个数字 |
| 3 | 删除第 3 个数字 |

因此循环要从 1 一直做到 `deln`：

```c
for(dn = 1; dn <= deln; dn++)
```

所以第①空填：

```c
dn <= deln
```

拿分口诀：

```md
要删 deln 次，循环变量从 1 开始，就写 dn <= deln。
```

---

## 四、削峰位置是怎么找到的

第①空不是削峰判断，但要看懂后面这一句：

```c
while(strn[i] <= strn[i+1] && i < lenth - dn)
    i++;
```

它的作用是：

```md
从左往右走，只要还在上升或相等，就继续往右。
```

一旦停下来，`i` 就是这轮要删除的位置。

举例：

```md
23681
```

比较过程：

```md
2 <= 3，继续
3 <= 6，继续
6 <= 8，继续
8 <= 1，不成立，停在 8
```

所以删 `8`。

再看：

```md
527682
```

一开始：

```md
5 <= 2 不成立
```

所以删最左边的 `5`。

拿分口诀：

```md
削峰先找上坡，走到上坡尽头；停下来的 i 就是删除位置。
```

---

## 五、第②空：删除后为什么填 `strn[k] = strn[k + 1]`

代码：

```c
for(k = i; k < lenth - dn; k++)
    ②;
```

上一步已经找到了要删除的位置 `i`。

数组中删除一个字符，不能真的空出一个洞，要让后面的字符往前补。

也就是：

```md
当前位置 k，由后一个位置 k+1 覆盖。
```

所以第②空填：

```c
strn[k] = strn[k + 1]
```

原代码后面已经有分号：

```c
②;
```

所以空里可以不额外写分号。

用例子看：

```md
527682
```

删除第 0 位的 `5`：

```md
strn[0] = strn[1]  → 2
strn[1] = strn[2]  → 7
strn[2] = strn[3]  → 6
strn[3] = strn[4]  → 8
strn[4] = strn[5]  → 2
```

有效部分变成：

```md
27682
```

拿分口诀：

```md
删除数组元素：后一个补前一个，a[k] = a[k+1]。
```

---

## 六、为什么删除后还要拼整数

删除完成后，剩下的仍然是字符。

代码：

```c
num = 0;
for(k = 0; k <= lenth - deln - 1; k++)
    num = num * 10 + strn[k] - 0x30;
```

`0x30` 就是字符 `'0'` 的 ASCII 码。

所以：

```c
strn[k] - 0x30
```

等价于：

```c
strn[k] - '0'
```

作用是把字符数字变成整数数字。

比如剩下：

```md
'2' '6' '2'
```

拼整数过程：

```md
num = 0
读 '2'：num = 0 * 10 + 2 = 2
读 '6'：num = 2 * 10 + 6 = 26
读 '2'：num = 26 * 10 + 2 = 262
```

拿分口诀：

```md
字符数字转数值：减 '0'，也就是减 0x30。
```

## 七、先看 `find` 函数在干什么

函数：

```c
int find(int num)
```

参数 `num` 是要查找的新整数。

调用位置：

```c
m = find(newn);
```

函数里先读文件：

```c
while(!feof(fpd))
{
    fscanf(fpd, "%d", &a[b]);
    b++;
}
fclose(fpd);
b--;
```

这里 `b` 一开始是 0。

每读入一个整数，就放到：

```c
a[b]
```

然后：

```c
b++;
```

读完以后，`b` 多走了一格，所以要：

```c
b--;
```

这样 `b` 就回到最后一个有效下标。

`h` 一开始已经在定义中初始化：

```c
int a[100], p, h = 0, b = 0;
```

所以二分查找的初始边界是：

```md
h = 0
b = 最后一个有效下标
```

---

## 八、第③空：二分循环为什么是 `h < b`

代码：

```c
while(③)
{
    p = (h + b) / 2;
    if(num > a[p])
        h = p + 1;
    else
        b = p;
}
```

这里用的是一种“不断缩小范围，最后缩到一个位置”的二分写法。

变量含义：

| 变量 | 含义 |
|---|---|
| `h` | 当前查找范围左边界 |
| `b` | 当前查找范围右边界 |
| `p` | 中间位置 |

只要左边界还小于右边界，就说明范围里不止一个候选位置，还要继续查：

```c
h < b
```

所以第③空填：

```c
h < b
```

循环里：

```c
if(num > a[p])
    h = p + 1;
else
    b = p;
```

意思是：

```md
如果 num 比中间值大，去右半边找。
否则，答案可能在 p 或 p 左边，就让右边界变成 p。
```

拿分口诀：

```md
二分缩边界：左右还没碰头，就继续；所以 while(h < b)。
```

---

## 九、第④空：找到以后为什么 `return b`

二分循环结束后：

```md
h == b
```

查找范围已经缩到一个候选位置。

代码：

```c
if(num == a[b]) ④;
else return(-1);
```

如果：

```c
num == a[b]
```

说明找到了这个数。

函数 `find` 的任务是返回它在数组中的下标。

当前候选下标就是 `b`，所以第④空填：

```c
return b
```

`main()` 中输出时：

```c
printf("在有序表中的序号:%d\n", m + 1);
```

为什么要 `m + 1`？

因为：

```md
C 语言下标从 0 开始，题目说的序号通常从 1 开始。
```

拿分口诀：

```md
find 函数找到就返回下标；没找到才 return(-1)。
```

---

## 十、这题的拿分套路

```md
1. 看到 DEL / deln：先判断外层循环要执行几次。
2. 看到删除数组元素：想到后一个往前补，strn[k] = strn[k+1]。
3. 看到 0x30：知道它就是字符 '0'，用于字符转数字。
4. 看到升序表查找：用二分，边界 h 和 b 不断缩小。
5. 看到 find 函数：找到返回下标，没找到返回 -1。
```

最后记一句：

```md
这题的空分别卡在：删除次数、删除前移、二分循环条件、找到后的返回值。
```
