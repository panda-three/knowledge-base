# 2026_77 课堂讲解：每个手机号只保留正确率最高的一条记录

## 这题最终要拿什么分

这题有 4 个空：

```c
① get_rec
② asw[i][p] == key[p]
③ strcmp(tel[j-1],tel[j])<0
④ ct -= p - i
```

我们这节课只做一件事：看懂这 4 个空为什么这么填。

---

## 一、题目要我们做什么

问卷有 8 道单选题。一个用户用手机号可以多次作答。

文件 `asw.txt` 里保存每次作答：

```txt
手机号        答案
13615164777  ABCABCDD
18920686220  ACCACCBC
17952667096  BCCACDBC
18920686220  AACCDADD
```

文件 `key.txt` 里保存标准答案。

题目要求：

```md
同一个手机号可能答了多次，最后只保留正确率最高的一条记录。
```

也就是：

```md
先算每条记录答对几题
再把同手机号放到一起
同手机号里答对多的放前面
最后每个手机号只保留第一条
```

---

## 二、先把三个数组看成一张表

程序里有三个数组：

```c
char teln[M][12] = {};
char asw[M][N+1] = {};
int yes[M] = {0};
```

不要分开看。它们是一张表的三列：

| 下标 | `teln[i]` 手机号 | `asw[i]` 答案 | `yes[i]` 答对数 |
|---:|---|---|---:|
| 0 | 13615164777 | ABCABCDD | 6 |
| 1 | 18920686220 | ACCACCBC | 5 |
| 2 | 18920686220 | AACCDADD | 7 |

一句话：

```md
teln[i] + asw[i] + yes[i] = 第 i 条完整作答记录
```

所以排序和删除时，三列必须一起动。

---

## 三、第①空：函数名从 main 里倒推

函数定义这里缺函数名：

```c
int __①__(char tel[][12], char asw[][N+1], int yes[])
```

不要猜，去 `main` 里找调用：

```c
ct = get_rec(teln, asw, yes);
```

`main` 里叫 `get_rec`，函数定义也必须叫 `get_rec`。

所以第①空：

```c
get_rec
```

拿分口诀：

```md
函数名缺了，先看 main 怎么调用。
```

---

## 四、第②空：一题一题对答案

代码：

```c
for(p=0; asw[i][p]!='\0' && key[p]!='\0'; p++)
    if(__②__)
        yes[i]++;
```

这里是在算第 `i` 条记录答对几题。

- `asw[i][p]`：第 `i` 条作答记录的第 `p` 题答案
- `key[p]`：标准答案的第 `p` 题答案

如果两个字符相等，就说明这一题答对了：

```c
asw[i][p] == key[p]
```

所以第②空：

```c
asw[i][p] == key[p]
```

拿分口诀：

```md
整串比较用 strcmp，一题一题比用 asw[i][p] == key[p]。
```

---

## 五、第③空：排序条件为什么是 `<0`

排序函数注释写得很清楚：

```c
//根据手机号和正确答案数降序排序
```

所以排序规则是：

```md
第一规则：手机号降序，大的手机号排前面
第二规则：如果手机号相同，yes 降序，答对多的排前面
```

关键代码：

```c
if(__③__ || strcmp(tel[j-1],tel[j])==0 && yes[j-1]<yes[j])
```

后半句已经给了：

```c
strcmp(tel[j-1],tel[j])==0 && yes[j-1]<yes[j]
```

意思是：

```md
如果两个手机号一样，但前一条答对数更少，就交换。
```

那第③空负责第一规则：手机号降序。

什么时候需要交换？

```md
前一个手机号比后一个手机号小，就说明大的在后面，顺序错了，要交换。
```

字符串比较用 `strcmp`：

```c
strcmp(tel[j-1],tel[j])<0
```

所以第③空：

```c
strcmp(tel[j-1],tel[j])<0
```

完整判断：

```c
if(strcmp(tel[j-1],tel[j])<0 ||
   strcmp(tel[j-1],tel[j])==0 && yes[j-1]<yes[j])
```

翻译成人话：

```md
如果前一个手机号更小，交换；
或者两个手机号一样，但前一个答对更少，也交换。
```

拿分口诀：

```md
题目说降序：前小后大就交换，所以 strcmp < 0。
```

## 六、为什么排序时要交换三列

代码：

```c
strcpy(s1,tel[j-1]);
strcpy(tel[j-1],tel[j]);
strcpy(tel[j],s1);

strcpy(s2,asw[j-1]);
strcpy(asw[j-1],asw[j]);
strcpy(asw[j],s2);

t=yes[j-1];
yes[j-1]=yes[j];
yes[j]=t;
```

它交换了三列：

```md
手机号 tel
答案 asw
答对数 yes
```

原因很简单：

```md
这三列合起来才是一条记录。
```

如果只换手机号，不换答案和分数，记录就乱了。

拿分口诀：

```md
同一个 i 是同一条记录，排序时整条记录一起换。
```

## 七、第④空：删除重复手机号，为什么是 `ct -= p - i`

这是全题最难的一段。

代码：

```c
for(i=0;i<ct;i++){
    p=i;
    while(strcmp(teln[i],teln[p+1])==0 && p+1<ct)
        p++;
    for(m=i+1,n=p+1; n<ct && i<p; m++,n++){
        strcpy(teln[m],teln[n]);
        strcpy(asw[m],asw[n]);
        yes[m]=yes[n];
    }
    __④__;
}
```

前面已经排好序：

```md
同手机号排在一起；
同手机号里，yes 最高的排第一。
```

所以删除时：

```md
每组手机号保留第一条，删除后面的重复记录。
```

### 1. 变量先看懂

| 变量 | 意思 |
|---|---|
| `i` | 当前手机号这一组的第一条，要保留 |
| `p` | 当前手机号这一组的最后一条 |
| `i+1 ~ p` | 要删除的重复记录 |
| `p+1` | 下一组的第一条 |
| `m` | 删除后空出来的位置 |
| `n` | 后面要搬过来的记录 |
| `ct` | 当前有效记录总数 |

### 2. 用一个例子看

排序后：

| 下标 | 手机号 | yes |
|---:|---|---:|
| 0 | 189 | 7 |
| 1 | 189 | 5 |
| 2 | 189 | 3 |
| 3 | 136 | 6 |
| 4 | 120 | 4 |

当前：

```md
i = 0
```

先：

```c
p = i;
```

所以：

```md
p = 0
```

while 会一直找同手机号的最后一条：

```md
p 从 0 走到 2
```

现在：

```md
i = 0
p = 2
```

说明：

```md
下标 0、1、2 是同一组手机号。
```

其中：

```md
下标 0 保留
下标 1、2 删除
```

删除数量是多少？

```md
p - i = 2 - 0 = 2
```

所以第④空就是：

```c
ct -= p - i
```

### 3. 为什么不是 `ct--`

因为一次可能删除多条。

刚才 189 有 3 条，保留 1 条，删除 2 条。只写 `ct--` 就少删了。

### 4. 为什么不是 `ct -= p - i + 1`

因为第一条要保留。

这一组总数是：

```md
p - i + 1
```

但删除的是：

```md
i+1 到 p
```

所以删除数量是：

```md
p - i
```

### 5. 第二个 for 在干什么

```c
for(m=i+1,n=p+1; n<ct && i<p; m++,n++){
    strcpy(teln[m],teln[n]);
    strcpy(asw[m],asw[n]);
    yes[m]=yes[n];
}
```

它的意思是：

```md
从 p+1 开始的后续记录，往 i+1 开始的位置搬。
```

也就是把后面的组往前顶，覆盖掉要删除的重复记录。

拿分口诀：

```md
i 是本组第一条，p 是本组最后条；
保留 i，删除 i 后面的 p-i 条；
所以 ct -= p-i。
```

## 八、四个空最终答案

```c
① get_rec
② asw[i][p] == key[p]
③ strcmp(tel[j-1],tel[j])<0
④ ct -= p - i
```

## 九、完整补全代码

```c
#include<stdio.h>
#include<stdlib.h>
#include<string.h>
#define M 50
#define N 8

//获取问卷作答记录，统计正确答案数
int get_rec(char tel[][12],char asw[][N+1],int yes[])
{
    FILE *fa,*fk;
    char key[N+1];
    int i=0,p;
    if((fa=fopen("asw.txt","r")) ==NULL||(fk=fopen("key.txt","r")) ==NULL){
        printf("File cannot open!\n");exit(0);
    }
    fscanf(fk,"%s",key);
    while(!feof(fa)){
        fscanf(fa,"%s  %s",tel[i],asw[i]);
        if(strlen(tel[i])!=0){
            for(p=0;asw[i][p]!='\0'&&key[p]!='\0';p++)
                if(asw[i][p] == key[p])
                    yes[i]++;
            i++;
        }
    }
    fclose(fa);fclose(fk);
    return i;
}

//根据手机号和正确答案数降序排序
void sort(char tel[][12],char asw[][N+1],int yes[],int ct)
{
    int i,j,t;
    char s1[12],s2[N+1];
    for(i=0;i<ct-1;i++)
        for(j=1;j<ct-i;j++)
            if(strcmp(tel[j-1],tel[j])<0 || strcmp(tel[j-1],tel[j])==0&&yes[j-1]<yes[j]){
                strcpy(s1,tel[j-1]);strcpy(tel[j-1],tel[j]);strcpy(tel[j],s1);
                strcpy(s2,asw[j-1]);strcpy(asw[j-1],asw[j]);strcpy(asw[j],s2);
                t=yes[j-1];yes[j-1]=yes[j];yes[j]=t;
            }
}

int main()
{
    FILE *fp;
    char teln[M][12]={},asw[M][N+1]={};
    int yes[M]={0},i,m,n,p,ct;
    ct=get_rec(teln,asw,yes);
    sort(teln,asw,yes,ct);
    for(i=0;i<ct;i++){
        p=i;
        while(strcmp(teln[i],teln[p+1])==0&&p+1<ct)
            p++;
        for(m=i+1,n=p+1;n<ct&&i<p;m++,n++){
            strcpy(teln[m],teln[n]);
            strcpy(asw[m],asw[n]);
            yes[m]=yes[n];
        }
        ct -= p - i;
    }
    if((fp=fopen("asw.txt","w"))==NULL){
        printf("File cannot open!\n");exit(0);
    }
    for(i=0;i<ct;i++)
        fprintf(fp,"%s  %s\n",teln[i],asw[i]);
    fclose(fp);
    return 0;
}
```

## 十、考场最后记这 4 句

```md
① 函数名缺了，看 main 调用：get_rec。
② 一题一题对答案：asw[i][p] == key[p]。
③ 题目说降序，前小后大就交换：strcmp(...) < 0。
④ 保留第一条，删掉 p-i 条：ct -= p - i。
```
