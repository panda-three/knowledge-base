# 2026_76 课堂讲解：输入姓名，统计这个人的总收入

## 这题最终要拿什么分

这题有 4 个空：

```c
① strcmp(name[mid], xm) <= 0
② FILE
③ regn++
④ sum
```

我们这节课只做一件事：看懂这 4 个空为什么这么填。

---

## 一、题目要我们做什么

文件 `gz.txt` 里保存收入记录，每条记录有两个内容：

```md
姓名 收入
```

例子：

```txt
Jack 300
Kate 450
Kate 400
Rose 350
```

题目说：文件中的记录已经按照姓名升序排列。

现在程序要实现：

```md
输入一个姓名，统计这个人名下所有收入。
```

比如输入：

```txt
Kate
```

文件里有：

```txt
Kate 450
Kate 400
```

那么总收入就是：

```md
450 + 400 = 850
```

---

## 二、先把两个数组看成一张表

程序里有两个数组：

```c
char name[100][20] = {};
int sr[100] = {0};
```

它们不是分开的。它们是一张表的两列：

| 下标 | `name[i]` 姓名 | `sr[i]` 收入 |
|---:|---|---:|
| 0 | Jack | 300 |
| 1 | Kate | 450 |
| 2 | Kate | 400 |
| 3 | Rose | 350 |

一句话：

```md
name[i] 和 sr[i] 是同一条收入记录。
```

所以只要找到 `Kate` 在 `name` 里的位置，就可以用同一个下标去拿她的收入 `sr[i]`。

---

## 三、第②空：文件指针类型怎么填

先讲最简单的第②空。

代码：

```c
__②__ *fgz;
```

后面有：

```c
fgz = fopen("gz.txt", "r")
```

`fopen` 打开文件，返回的是文件指针。

文件指针类型写：

```c
FILE *
```

所以第②空填：

```c
FILE
```

合起来：

```c
FILE *fgz;
```

拿分口诀：

```md
看到 fopen，前面文件变量就是 FILE *。
```

---

## 四、先看 search 函数在干什么

函数：

```c
int search(char xm[], char name[][20], int n)
```

三个参数：

| 参数 | 含义 |
|---|---|
| `xm[]` | 要查找的姓名，比如 `Kate` |
| `name[][20]` | 文件里读出来的姓名表 |
| `n` | 一共有多少条记录 |

它的任务：

```md
在已经按姓名升序排列的 name 表中，找到 xm 的位置。
```

因为姓名表有序，所以它用了二分查找。

---

## 五、第①空：字符串二分查找，为什么是 `strcmp(name[mid], xm) <= 0`

代码：

```c
while(head<=tail){
    mid=head+(tail-head)/2;
    if(__①__)
        head=mid+1;
    else
        tail=mid-1;
}
```

如果这是数字数组，我们可能会写：

```c
if(a[mid] <= x)
```

但是这里比较的是姓名，是字符串。

字符串不能直接写：

```c
name[mid] <= xm   // 错
```

字符串要用：

```c
strcmp(name[mid], xm)
```

`strcmp` 记法：

| 写法 | 意思 |
|---|---|
| `strcmp(a,b)==0` | a 和 b 相等 |
| `strcmp(a,b)<0` | a 排在 b 前面 |
| `strcmp(a,b)>0` | a 排在 b 后面 |

这段二分查找想表达：

```md
如果 name[mid] <= xm，就继续往右找。
```

换成字符串写法就是：

```c
strcmp(name[mid], xm) <= 0
```

所以第①空填：

```c
strcmp(name[mid], xm) <= 0
```

拿分口诀：

```md
字符串不能直接比大小，<= 要写成 strcmp(...) <= 0。
```

---

## 六、为什么找到以后还要往前退

`search` 返回一个位置 `regn`。

但同一个人可能有多条收入，比如：

| 下标 | 姓名 | 收入 |
|---:|---|---:|
| 0 | Jack | 300 |
| 1 | Kate | 450 |
| 2 | Kate | 400 |
| 3 | Rose | 350 |

如果 `search` 找到的是下标 2，也就是第二条 `Kate`，我们不能只加这一条。

要先回到这一组 `Kate` 的第一条。

代码：

```c
while(strcmp(name[regn],fname)==0)
    regn--;
__③__;
```

这段的意思是：

```md
只要当前位置还是 Kate，就继续往前退。
```

用例子走一遍：

```md
regn = 2，name[2] 是 Kate，regn--，变成 1
regn = 1，name[1] 是 Kate，regn--，变成 0
regn = 0，name[0] 是 Jack，不再循环
```

注意：循环停下来的时候，`regn` 已经退到了 `Kate` 前面的 `Jack`。

也就是说，多退了一格。

所以要回来一格：

```c
regn++;
```

第③空填：

```c
regn++
```

拿分口诀：

```md
往前退，退到不是它；多退一格，加回来。
```

---

## 七、开始累加收入

修正以后，`regn` 回到了第一条 `Kate`。

然后代码继续：

```c
while(strcmp(name[regn],fname)==0){
    sum += sr[regn];
    regn++;
}
```

这段意思是：

```md
从第一条 Kate 开始，往后走；
只要还是 Kate，就把收入加到 sum 里。
```

例子：

| 下标 | 姓名 | 收入 | 动作 |
|---:|---|---:|---|
| 1 | Kate | 450 | sum += 450 |
| 2 | Kate | 400 | sum += 400 |
| 3 | Rose | 350 | 不是 Kate，停止 |

最后：

```md
sum = 850
```

---

## 八、第④空：最后输出谁

代码：

```c
printf("%s名下总收入:%d\n",fname,__④__);
```

前面所有收入都加到了：

```c
sum
```

所以第④空填：

```c
sum
```

拿分口诀：

```md
最后填谁，往前找谁一直在被累加。
```

## 九、四个空最终答案

```c
① strcmp(name[mid], xm) <= 0
② FILE
③ regn++
④ sum
```

## 十、完整补全代码

```c
#include<stdio.h>
#include<string.h>
#include<stdlib.h>

//搜索姓名(xm)在有序表(name)中的位置
int search(char xm[],char name[][20],int n)
{
    int head=0,tail=n-1,mid,ret=-1;
    while(head<=tail){
        mid=head+(tail-head)/2;
        if(strcmp(name[mid], xm) <= 0)
            head=mid+1;
        else
            tail=mid-1;
    }
    if(strcmp(name[tail],xm)==0) ret=tail;
    return ret;
}

int main()
{
    FILE *fgz;
    char name[100][20]={},fname[20];
    int sr[100]={0},n=0,sum=0;
    if((fgz=fopen("gz.txt","r"))==NULL){
        puts("File cannot open!\n");exit(0);
    }
    while(!feof(fgz)){
        fscanf(fgz,"%s  %d",name[n],&sr[n]);n++;
    }
    fclose(fgz);
    scanf("%s",fname);
    int regn=search(fname,name,n);
    if(regn!=-1){
        while(strcmp(name[regn],fname)==0)
            regn--;
        regn++;
        while(strcmp(name[regn],fname)==0){
            sum+=sr[regn];regn++;
        }
        printf("%s名下总收入:%d\n",fname,sum);
    }else
        printf("查无此人:%s\n",fname);
    return 0;
}
```

---

## 十一、考场最后记这 4 句

```md
① 字符串比大小：strcmp(name[mid], xm) <= 0。
② 文件指针类型：FILE。
③ 往前退多了一格：regn++ 回来。
④ 总收入加到 sum：输出 sum。
```

---

## 十二、最容易错的地方

### 1. 第①空写成 `name[mid] <= xm`

错。字符串不能直接比大小。

正确：

```c
strcmp(name[mid], xm) <= 0
```

### 2. 第③空忘记 `regn++`

如果忘记回来一格，`regn` 停在 `Jack`，后面的累加循环进不去。

### 3. 第④空写成 `sr[regn]`

错。`sr[regn]` 只是某一条收入。

题目要总收入，前面已经累加到：

```c
sum
```

所以输出 `sum`。
