# 2025_76 课堂讲解：按总分排序，再按志愿录用

## 这题最终要拿什么分

这题有 4 个空：

```c
① fp
② get_rank(nv, gd, len)
③ i < len
④ gd[j][2] > gd[p][2]
```

我们这节课只做一件事：看懂这 4 个空为什么这么填。

---

## 一、题目要我们做什么

文件 `grade.dat` 里保存考生信息，每条记录有：

```md
姓名 第1志愿 第2志愿 笔试成绩 面试成绩
```

题目要求按招录规则输出 A、B、C 三个单位的录用名册。

招录规则有三条：

```md
1. 总分 = 笔试成绩 + 面试成绩。
2. 按总分从高到低录用；总分相同，面试成绩高者优先。
3. 每个考生先看第1志愿；第1志愿满了，再看第2志愿；两个都满就落选。
```

所以程序整体流程是：

```md
打开 grade.dat
↓
读入考生姓名、志愿、笔试、面试
↓
计算总分
↓
按总分和面试成绩排序
↓
按两个志愿依次录用，写入 A.txt / B.txt / C.txt
```

---

## 二、先把两个数组看成一张考生表

程序里有两个数组：

```c
char nv[200][3][20];
int gd[200][3] = {0};
```

它们不是分开的。它们合起来是一张考生表。

| 下标 | `nv[i][0]` | `nv[i][1]` | `nv[i][2]` | `gd[i][0]` | `gd[i][1]` | `gd[i][2]` |
|---:|---|---|---|---:|---:|---:|
| i | 姓名 | 第1志愿 | 第2志愿 | 笔试 | 面试 | 总分 |

一句话：

```md
同一个 i，就是同一个考生。
```

所以排序时，`nv` 和 `gd` 必须一起动。

拿分口诀：

```md
多个数组共用同一个下标，排序交换时整条记录一起换。
```

---

## 三、第①空：打开文件时为什么填 `fp`

代码：

```c
FILE * fp, * fp1, * fp2, * fp3;
...
if(! (  ①  = fopen("grade.dat", "r+")))
{
    printf("无法打开文件! \n");
    exit(0);
}
```

这里要打开的是原始数据文件：

```md
grade.dat
```

后面读数据时，用的是：

```c
fscanf(fp, "%s%s%s", nv[len][0], nv[len][1], nv[len][2]);
fscanf(fp, "%d%d", &gd[len][0], &gd[len][1]);
```

也就是说，`grade.dat` 必须赋给文件指针 `fp`。

所以第①空填：

```c
fp
```

合起来是：

```c
if(!(fp = fopen("grade.dat", "r+")))
```

拿分口诀：

```md
看 fopen 后面谁在 fscanf 里使用，谁就是要接收文件的指针。
```

## 四、第②空：为什么这里要调用 `get_rank(nv, gd, len)`

代码位置：

```c
while(!feof(fp))
{
    fscanf(fp, "%s%s%s", nv[len][0], nv[len][1], nv[len][2]);
    fscanf(fp, "%d%d", &gd[len][0], &gd[len][1]);
    gd[len][2] = gd[len][0] + gd[len][1];
    len++;
}
②;
if(!((fp1=fopen("A.txt","w")) && ...))
```

前面 `while` 已经完成了：

```md
读入考生信息
计算每个考生总分
统计考生人数 len
```

后面马上要开始录用。题目说录用前必须：

```md
根据总分由高到低按序录用；总分相同，面试成绩高者优先。
```

所以在录用前必须先排序。

程序前面声明了排序函数：

```c
void get_rank(char na[][3][20], int gd[][3], int);
```

三个实参应该是：

| 形参 | 实参 | 含义 |
|---|---|---|
| `na[][3][20]` | `nv` | 姓名和两个志愿 |
| `gd[][3]` | `gd` | 笔试、面试、总分 |
| `int` | `len` | 考生人数 |

所以第②空填：

```c
get_rank(nv, gd, len)
```

因为原代码后面已经有分号：

```c
②;
```

所以空里不用再写分号。

拿分口诀：

```md
读完数据、录用之前，先按题目规则排序。
函数实参按声明顺序填：表、成绩、人数。
```

## 五、第③空：录用循环为什么要写 `i < len`

代码：

```c
i = 0;
while((ct[0] < MAX || ct[1] < MAX || ct[2] < MAX) && ③)
{
    ...按第1志愿、第2志愿录用...
    i++;
}
```

前半句：

```c
ct[0] < MAX || ct[1] < MAX || ct[2] < MAX
```

意思是：

```md
只要 A/B/C 三个单位中还有一个没招满，就还有录用空间。
```

但只有这个条件还不够。

还要防止 `i` 超过考生总人数。

`len` 表示读入了多少个考生，有效下标是：

```md
0 ~ len-1
```

所以循环必须保证：

```c
i < len
```

第③空填：

```c
i < len
```

完整意思是：

```md
还有单位没招满，并且还有考生没处理完，才继续循环。
```

拿分口诀：

```md
数组下标 i 扫记录，不能超过记录数 len，所以条件写 i < len。
```

## 六、先看 `get_rank` 函数在干什么

函数：

```c
void get_rank(char nv[][3][20], int gd[][3], int size)
```

它的任务是：

```md
把考生按录用优先级排好。
```

排序规则来自题干：

```md
第一规则：总分高的排前面。
第二规则：总分相同，面试高的排前面。
```

代码：

```c
for(i = 0; i < size - 1; i++)
{
    p = i;
    for(j = i + 1; j <= size - 1; j++)
    {
        if(④)
            p = j;
        else if(gd[p][2] == gd[j][2] && gd[p][1] < gd[j][1])
            p = j;
        ...交换...
    }
}
```

这里：

| 变量 | 含义 |
|---|---|
| `i` | 当前要确定排名的位置 |
| `p` | 当前找到的最优考生位置 |
| `j` | 正在拿来比较的新考生位置 |

## 七、第④空：总分高者优先，为什么填 `gd[j][2] > gd[p][2]`

先看成绩数组列号：

```md
gd[][0]：笔试成绩
gd[][1]：面试成绩
gd[][2]：总分
```

题目第一排序规则是：

```md
根据总分由高到低按序录用。
```

当前最优位置是 `p`，正在比较的新位置是 `j`。

如果新来的 `j` 总分更高，就应该让 `p` 改成 `j`：

```c
if(gd[j][2] > gd[p][2])
    p = j;
```

所以第④空填：

```c
gd[j][2] > gd[p][2]
```

后面的 `else if` 是第二规则：

```c
else if(gd[p][2] == gd[j][2] && gd[p][1] < gd[j][1])
    p = j;
```

意思是：

```md
如果总分相同，但 j 的面试成绩更高，也让 j 成为当前最优。
```

拿分口诀：

```md
先比总分 gd[][2]，再比面试 gd[][1]。
总分从高到低，所以用 j > p。
```

---

## 八、这题的拿分套路

```md
1. 文件空：看后面 fscanf 用哪个文件指针。
2. 函数调用空：看前面函数声明，再看此处流程缺哪一步。
3. 循环条件空：看循环变量 i 扫的是谁，边界通常是记录数 len。
4. 排序条件空：先找题干排序规则，再找数组列号。
5. 多数组题：同一个下标是一条完整记录，交换时姓名、志愿、成绩一起换。
```

最后记一句：

```md
这题的核心是：读完先排序，排序看 gd[][2] 总分，录用循环不能让 i 超过 len。
```
