# 73题 原题

阅读下列程序，请将①~④表示的内容填写在答题卡上相应位置。

```c
#include <stdio.h>
int main(void)
{
    char s[ ]="This is a C pro\0gram.";
    int k;
    char c;
    s[8]='\0';
    puts(s);
    for(k=2;k<6;k++)
    {
        switch(c=s[k])
        {
            case 'i': printf("%s","Fil");
            case 's': ++k;break;
            default : puts("Users");
            case 'r': puts("include");
            continue;
        }
        printf("%8s\n","Files");
    }
    return 0;
}
```

上述程序中，第 (3) 行中数组 `s` 在内存中的占用空间为 **①** 字节；第 (6) 行中的字符串结束符 `'\0'` 属于 **②** 字符；第 (14) 行 `continue;` 语句执行结束后，程序将继续执行第 **③** 行；第 (16) 行中 `%8s` 中的 8 用于指定输出数据的 **④**。
