# 75题 原题

阅读下列程序，请将运行结果填写在答题卡上相应位置。

> 注：原合并文件中 `int a=3;` 和 `c+=b+a;` 容易被 OCR/录入误读，本文按标准答案口径整理。

```c
#include <stdio.h>
int a=3;
int fun(int a, int b)
{
    static int c;
    a=a+b;
    c+=b+a;
    b=a+c;
    return b;
}

int main(void)
{
    int c=5,d;
    d=fun(a++,fun(--a,c));
    printf("%d %d %d",a,c,d);
    return 0;
}
```
