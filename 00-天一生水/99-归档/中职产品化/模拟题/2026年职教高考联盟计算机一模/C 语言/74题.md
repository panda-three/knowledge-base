# 74题 原题

阅读下列程序，请将运行结果填写在答题卡上相应位置。

```c
#include <stdio.h>
int main(void)
{
    int i, j, arr1[8]={2,4,6,8,10},arr2[8]={1,3,4,6,9,10,12};
    for(i=0;i<5;i++)
        printf("%-3d",arr1[i]);
    printf("\n");
    for(j=0;j<7;j++)
        printf("%-3d",arr2[j]);
    printf("\n");
    i=j=0;
    while(i<5 && j<7)
    {
        if(arr1[i]<arr2[j])
            printf("%-3d",arr1[i++]);
        else if(arr1[i]>arr2[j])
            j++;
        else
            i++,j++;
    }
    while(i<5)
        printf("%-3d",arr1[i++]);
    printf("\n");
    return 0;
}
```
