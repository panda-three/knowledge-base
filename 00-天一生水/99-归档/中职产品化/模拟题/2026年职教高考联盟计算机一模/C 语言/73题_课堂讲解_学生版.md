# 73题 课堂讲解：字符串、switch 和输出宽度综合判断

## 这题最终要拿什么分

这题有 4 个空：

```c
① 22
② 转义
③ for语句所在行（下一轮循环，通常填第8行/第9行，按试卷行号为准）
④ 宽度
```

我们这节课只做一件事：看懂这 4 个空为什么这么填。

---

## 一、题目要我们做什么

这题不是让我们写程序，而是考 4 个基础概念：

1. 字符数组用字符串初始化时，占多少字节；
2. `'\0'` 是什么类型的字符写法；
3. `continue` 在 `for` 循环里会跳到哪里；
4. `%8s` 里的数字 8 表示什么。

---

## 二、先把关键代码看懂

关键程序是：

```c
char s[ ]="This is a C pro\0gram.";
s[8]='\0';
...
for(k=2;k<6;k++)
{
    switch(c=s[k])
    {
        ...
        continue;
    }
    printf("%8s\n","Files");
}
```

做这题不要先急着跑完整程序，先把每个空对应的语法点抓出来。

---

## 三、第①空：数组 s 占多少字节

代码：

```c
char s[ ]="This is a C pro\0gram.";
```

线索：

- `char` 类型一个字符占 1 字节；
- 字符串中间的 `\0` 也是一个字符；
- 字符串末尾还会自动补一个结束符 `\0`；
- 数组没有写长度，长度由初始化字符串决定。

逐个数：

```text
This        4
空格         1  -> 5
is          2  -> 7
空格         1  -> 8
a           1  -> 9
空格         1  -> 10
C           1  -> 11
空格         1  -> 12
pro         3  -> 15
\0          1  -> 16
gram.       5  -> 21
末尾自动\0   1  -> 22
```

所以第①空填：

```c
22
```

拿分口诀：

```md
字符数组数空间：中间\0要算，末尾自动\0也要算。
```

---

## 四、第②空：`'\0'` 属于什么字符

代码：

```c
s[8]='\0';
```

线索：

- 只要看到反斜杠 `\` 加字符，就先想到“转义字符”；
- `'\0'` 是字符串结束标志，也叫空字符；
- 题干问“属于什么字符”，通常填“转义字符”。

所以第②空填：

```c
转义
```

拿分口诀：

```md
反斜杠开头，优先想到转义字符；\0 是字符串结束标志。
```

---

## 五、第③空：`continue` 后继续执行哪一行

代码：

```c
for(k=2;k<6;k++)
{
    switch(c=s[k])
    {
        ...
        continue;
    }
    printf("%8s\n","Files");
}
```

线索：

- `continue` 作用在离它最近的循环上；
- 这里离它最近的循环是 `for(k=2;k<6;k++)`；
- `continue` 会跳过本轮循环后面的语句，也就是不执行下面的 `printf`；
- 在 `for` 循环里，`continue` 后会进入下一轮循环的更新与判断。

所以第③空填：

```md
for语句所在行（下一轮循环，按试卷行号填写）
```

如果试卷把 `for(k=2;k<6;k++)` 标成第 8 行，就填：

```c
8
```

拿分口诀：

```md
for 里遇到 continue：跳过后面语句，回到 for 的下一轮。
```

---

## 六、第④空：`%8s` 中的 8 表示什么

代码：

```c
printf("%8s\n","Files");
```

线索：

- `%s` 表示输出字符串；
- `%8s` 表示输出字符串时，占至少 8 个字符宽度；
- 如果字符串不够 8 位，默认在左边补空格。

所以第④空填：

```c
宽度
```

也可以写成：

```md
输出宽度 / 最小字段宽度
```

拿分口诀：

```md
百分号后面的数字，不是小数位，就是宽度；%8s 的 8 是最小输出宽度。
```

---

## 七、这题的拿分套路

```md
1. 字符数组空间题：逐字符数，中间\0和末尾\0都算。
2. 看到反斜杠：先判断是不是转义字符。
3. continue 在 for 中：跳过本轮剩余语句，进入下一轮循环。
4. printf 格式控制：%8s 中的 8 是输出宽度。
```

最后记一句：

```md
这题考的不是运行结果，而是 C 语言基础概念的精准叫法。
```
