# 74题 课堂讲解：双数组下标移动求运行结果

## 这题最终要拿什么分

这题要写程序运行结果：

```text
2  4  6  8  10 
1  3  4  6  9  10 12 
2  8  
```

我们这节课只做一件事：看懂第三行为什么输出 `2  8`。

> 校正说明：原合并材料里这一行容易被误读成 `arr1[i]==arr2[j]`。如果标准答案是 `2  8`，关键判断应为 `arr1[i]<arr2[j]`。

---

## 一、题目要我们做什么

程序先输出两个数组前面的有效元素：

```c
arr1: 2,4,6,8,10
arr2: 1,3,4,6,9,10,12
```

然后重新令：

```c
i=j=0;
```

用 `i` 扫 `arr1`，用 `j` 扫 `arr2`，根据两个数的大小关系决定输出谁、移动哪个下标。

---

## 二、先把关键循环看懂

代码：

```c
i=j=0;
while(i<5 && j<7)
{
    if(arr1[i]<arr2[j])
        printf("%-3d",arr1[i++]);
    else if(arr1[i]>arr2[j])
        j++;
    else
        i++,j++;
}
while(i<5)
    printf("%-3d",arr1[i++]);
```

核心规则：

```md
arr1 小：输出 arr1[i]，然后 i++
arr1 大：j++，让 arr2 往后追
相等：i++、j++，两个都跳过，不输出
```

---

## 三、第一行输出：arr1 的内容

代码：

```c
for(i=0;i<5;i++)
    printf("%-3d",arr1[i]);
```

`arr1` 前 5 个数是：

```text
2 4 6 8 10
```

`%-3d` 表示每个整数左对齐，占 3 个字符宽度。

所以第一行输出：

```text
2  4  6  8  10 
```

拿分口诀：

```md
%-3d：左对齐，占3格；写结果时数字之间要留空位。
```

---

## 四、第二行输出：arr2 的内容

代码：

```c
for(j=0;j<7;j++)
    printf("%-3d",arr2[j]);
```

`arr2` 前 7 个数是：

```text
1 3 4 6 9 10 12
```

所以第二行输出：

```text
1  3  4  6  9  10 12 
```

拿分口诀：

```md
数组初始化没写满不影响这里，因为循环只输出前面指定的有效个数。
```

---

## 五、第三行输出：while 比较过程

代码：

```c
while(i<5 && j<7)
```

重新令：

```c
i=j=0;
```

逐步比较：

```text
arr1[0]=2,  arr2[0]=1   2>1   -> j++
arr1[0]=2,  arr2[1]=3   2<3   -> 输出2，i++
arr1[1]=4,  arr2[1]=3   4>3   -> j++
arr1[1]=4,  arr2[2]=4   相等  -> i++,j++，不输出
arr1[2]=6,  arr2[3]=6   相等  -> i++,j++，不输出
arr1[3]=8,  arr2[4]=9   8<9   -> 输出8，i++
arr1[4]=10, arr2[4]=9   10>9  -> j++
arr1[4]=10, arr2[5]=10  相等  -> i++,j++，不输出
```

此时 `i=5`，`while(i<5 && j<7)` 不成立，退出。

后面的循环：

```c
while(i<5)
    printf("%-3d",arr1[i++]);
```

因为 `i` 已经等于 5，所以不再输出。

所以第三行输出：

```text
2  8  
```

拿分口诀：

```md
这题不是输出相同项，而是输出 arr1 中“小于当前 arr2”的项；相等时两个下标都走，不输出。
```

---

## 六、这题的拿分套路

```md
1. 先把前两个 for 循环的直接输出写出来。
2. 再画 i、j 两根指针，不要靠脑子硬记。
3. 重点看 if 条件：这里是 arr1[i] < arr2[j] 才输出。
4. 相等时执行 else：i++,j++，两个都跳过，不输出。
5. 看到 %-3d，要注意输出宽度和空格。
```

最后记一句：

```md
运行结果题不能只看数组，要死盯 if 条件；条件一变，输出完全变。
```
