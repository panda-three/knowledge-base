# 77题 课堂讲解：结构体成绩表排序并写入文件

## 这题最终要拿什么分

这题有 4 个空：

```c
① STU temp
② n-1-i
③ s[i].sc[j] / 3.0
④ &s[i], LEN, 1, fout
```

我们这节课只做一件事：看懂这 4 个空为什么这么填。

---

## 一、题目要我们做什么

程序要完成 4 件事：

1. 输入 N 个学生的姓名和三门成绩；
2. 计算每个学生三门课的平均分；
3. 按平均分从高到低排序；
4. 把排序后的结构体数组写入二进制文件 `fd.dat`。

---

## 二、先把关键数据结构看懂

代码：

```c
typedef struct node
{
    char nam[10];
    int sc[3];
    float av;
}STU;
```

一个 `STU` 就是一名学生：

| 成员 | 含义 |
|---|---|
| `nam[10]` | 姓名 |
| `sc[3]` | 三门成绩 |
| `av` | 平均分 |

`STU s[N];` 表示有 N 个学生。

---

## 三、第①空：交换两个学生记录需要临时变量

代码：

```c
void sort(STU s[], int n)
{
    int i, j;
    ①;
    for(i=0; i<n-1;i++)
        for(j=0; j< ② ;j++)
            if(s[j].av<s[j+1].av)
            {
                temp=s[j];s[j]=s[j+1];s[j+1]=temp;
            }
}
```

线索：

- 后面使用了 `temp=s[j]`；
- `s[j]` 是 `STU` 类型的一条学生记录；
- 所以 `temp` 也必须是 `STU` 类型；
- 这里是结构体整体交换，不是只交换平均分。

所以第①空填：

```c
STU temp
```

拿分口诀：

```md
交换结构体数组元素：temp 的类型必须和数组元素类型一样。
```

---

## 四、第②空：冒泡排序内层循环边界

代码：

```c
for(i=0; i<n-1;i++)
    for(j=0; j< ② ;j++)
        if(s[j].av<s[j+1].av)
```

线索：

- 比较的是 `s[j]` 和 `s[j+1]`；
- 所以 `j+1` 不能越界；
- 冒泡排序第 `i` 趟后，后面已经有 `i` 个位置排好；
- 内层循环常见边界是 `n-1-i`。

所以第②空填：

```c
n-1-i
```

拿分口诀：

```md
冒泡比较 j 和 j+1：内层上界看 n-1-i。
```

---

## 五、第③空：三门成绩累加成平均分

代码：

```c
s[i].av=0;
for(j=0;j<3;j++)
{
    scanf("%d",&s[i].sc[j]);
    s[i].av+= ③;
}
```

线索：

- `s[i].sc[j]` 是第 `i` 个学生第 `j` 门课成绩；
- 三门课求平均分，就是每门成绩除以 3 后累加；
- `av` 是 `float`，最好用 `3.0`，避免只做整数除法。

所以第③空填：

```c
s[i].sc[j] / 3.0
```

拿分口诀：

```md
平均分空：成绩字段 / 科目数；想保留小数，用 3.0。
```

---

## 六、第④空：fwrite 写入一条结构体记录

代码：

```c
fout=fopen("fd.dat","wb");
for(i=0;i<N;i++)
    fwrite(  ④  );
fclose(fout);
```

线索：

`fwrite` 的格式是：

```c
fwrite(数据地址, 每块大小, 块数, 文件指针);
```

本题中：

| 参数 | 应填内容 | 原因 |
|---|---|---|
| 数据地址 | `&s[i]` | 写第 i 个学生结构体的地址 |
| 每块大小 | `LEN` | 前面定义了 `#define LEN sizeof(STU)` |
| 块数 | `1` | 每次写一条学生记录 |
| 文件指针 | `fout` | 前面 `fopen` 得到的输出文件指针 |

所以第④空填：

```c
&s[i], LEN, 1, fout
```

拿分口诀：

```md
fwrite 四参数：地址、大小、个数、文件指针。
```

---

## 七、这题的拿分套路

```md
1. 结构体排序交换：先找 temp，类型跟数组元素一样。
2. 冒泡排序边界：比较 j 和 j+1，常用 n-1-i。
3. 平均分：成员成绩 / 3.0，再累加到 av。
4. 二进制写文件：fwrite(地址, 大小, 个数, 文件指针)。
```

最后记一句：

```md
结构体题不要只盯一个字段，排序和写文件都是在处理整条记录。
```
