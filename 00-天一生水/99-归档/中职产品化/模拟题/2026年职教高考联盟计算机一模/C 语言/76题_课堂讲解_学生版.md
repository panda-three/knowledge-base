# 76题 课堂讲解：A/B 字符串积分程序填空

## 这题最终要拿什么分

这题有 4 个空：

```c
① sum = sum + t
② str[i++] == 'B'
③ i--, t = 1
④ count(str[i])
```

我们这节课只做一件事：看懂这 4 个空为什么这么填。

---

## 一、题目要我们做什么

积分规则：

```md
连续 A：第1个A得1分，第2个A得2分，第3个A得3分……
连续 B：不管有几个连续B，这一段只得1分
```

所以程序需要做两件事：

1. 遇到连续的 `A`，用 `t` 记录当前是第几个连续 A，并把 `t` 加到 `sum`；
2. 遇到连续的 `B`，整段只加 1 分，然后跳过后面的 B。

---

## 二、先把关键变量看懂

代码：

```c
int i=0,sum=0,t=1;
```

三个变量分工：

| 变量 | 作用 |
|---|---|
| `i` | 当前检查到字符串第几个字符 |
| `sum` | 当前总分 |
| `t` | 连续 A 的当前得分，第一次 A 是 1，第二次 A 是 2 |

---

## 三、第①空：遇到 A 时把当前 A 的分数加进去

代码：

```c
while(str[i]=='A')
{
    ①;
    t++;
    i++;
}
```

线索：

- 这个 `while` 专门处理连续的 `A`；
- `t` 表示当前这个 A 应得多少分；
- 每处理一个 A，应该把 `t` 加到总分 `sum`；
- 然后 `t++`，为下一个连续 A 做准备。

所以第①空填：

```c
sum = sum + t
```

也可以写：

```c
sum += t
```

拿分口诀：

```md
连续A看 t：当前A得几分，就把 t 加进 sum。
```

---

## 四、第②空：跳过后面连续的 B

代码：

```c
if(str[i++] == 'B')
{
    sum = sum + 1;
    while(②);
}
```

线索：

- `if(str[i++] == 'B')` 已经吃掉了第一个 B；
- 连续 B 只算 1 分，所以后面的 B 不能再加分；
- `while(②);` 后面只有一个分号，说明循环体是空的；
- 因此②里必须一边判断是不是 B，一边让 `i` 往后走。

所以第②空填：

```c
str[i++] == 'B'
```

这句的作用是：只要当前位置还是 B，就继续让 `i` 后移；遇到不是 B 的字符时停止。

拿分口诀：

```md
空循环要有副作用：while 后面只有分号，括号里就要负责移动下标。
```

---

## 五、第③空：把多走的一步退回来，并重置 A 的计数

代码：

```c
③;
```

线索 1：第②空会多读一个不是 B 的字符。

例如遇到 `BBB A`：

```text
while(str[i++] == 'B')
```

最后一次判断到 `A` 时条件为假，但 `i++` 已经执行了，所以 `i` 会跑到 `A` 后面。为了下一轮还能处理这个 `A`，必须退回一步。

线索 2：一段 A 结束后，下一段 A 要重新从 1 分开始。

所以要把 `t` 重新变成 1。

因此第③空填：

```c
i--, t = 1
```

也可以写成：

```c
t = 1, i--
```

拿分口诀：

```md
i++ 判断多走一步，就用 i-- 退一步；A 段断了，t 回到1。
```

---

## 六、第④空：调用 count 计算当前字符串积分

代码：

```c
for(i=0;i<3;i++)
    printf("%s的积分为： %d\n",str[i],④);
```

线索：

- `printf` 第一个 `%s` 已经输出当前字符串 `str[i]`；
- 第二个 `%d` 要输出这个字符串的积分；
- 上面写好的函数是 `count(char str[])`，作用就是计算积分；
- 所以要把当前字符串 `str[i]` 传进去。

所以第④空填：

```c
count(str[i])
```

拿分口诀：

```md
主函数输出结果空：先找前面写好的功能函数，再把当前这一行数据传进去。
```

---

## 七、这题的拿分套路

```md
1. 连续A：sum 加 t，t 再加1。
2. 连续B：一整段只加1，然后用空循环跳过后面的B。
3. 看到 str[i++]：一定检查有没有多走一步。
4. 每一段处理完，t 要重置为1。
5. main 里结果输出空，通常是调用前面写好的函数。
```

最后记一句：

```md
这题的核心不是 A 和 B，而是 i++ 有没有多走一步。
```
