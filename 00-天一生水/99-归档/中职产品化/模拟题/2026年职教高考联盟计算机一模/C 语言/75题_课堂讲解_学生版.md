# 75题 课堂讲解：全局变量、局部变量和 static 变量

## 这题最终要拿什么分

这题要写运行结果：

```text
3 5 73
```

我们这节课只做一件事：分清 3 个变量 `a`、`c` 到底是谁，再按函数调用顺序算出 `d`。

> 校正说明：如果答案是 `3 5 73`，函数里的关键语句应为 `c+=b+a;`，不是 `c+=b*a;`。

---

## 一、题目要我们做什么

核心代码：

```c
#include <stdio.h>
int a=3;
int fun(int a, int b)
{
    static int c;
    a=a+b;
    c+=b+a;
    b=a+c;
    return b;
}

int main(void)
{
    int c=5,d;
    d=fun(a++,fun(--a,c));
    printf("%d %d %d",a,c,d);
    return 0;
}
```

这里最容易错的地方：

```md
全局 a：main 里 a++、--a 改的是它
fun 的形参 a：进入 fun 后是另一个局部变量
main 的 c：值是 5
fun 的 static c：第一次默认为 0，并且多次调用会保留值
```

---

## 二、先把变量关系看懂

| 名字         | 位置                 | 特点                    |
| ---------- | ------------------ | --------------------- |
| 全局 `a`     | `int a=3;`         | `main` 中直接用到的 a       |
| 形参 `a`     | `fun(int a,int b)` | 进入函数后的局部变量，和全局 a 不是一个 |
| main 的 `c` | `int c=5,d;`       | 打印时第二个 `%d` 输出它       |
| static `c` | `fun` 内部           | 只初始化一次，函数调用结束后值保留     |
|            |                    |                       |

---

## 三、第一步：先算内层 `fun(--a,c)`

代码：

```c
d=fun(a++,fun(--a,c));
```

这类中职题通常按教材口径：先算内层函数调用 `fun(--a,c)`。

开始时：

```text
全局 a = 3
main 的 c = 5
fun 的 static c = 0
```

`--a` 是先减后用：

```text
全局 a: 3 -> 2
传入 fun 的第一个参数 a = 2
第二个参数 b = 5
```

进入 `fun(2,5)`：

```c
a=a+b;      // a = 2+5 = 7
c+=b+a;     // static c = 0+5+7 = 12
b=a+c;      // b = 7+12 = 19
return b;   // 返回19
```

所以内层函数返回：

```c
19
```

拿分口诀：

```md
--a 先改再用；static c 第一次从0开始，算完要留下来。
```

---

## 四、第二步：再算外层左边的 `a++`

代码：

```c
a++
```

此时全局 `a` 已经是 2。

`a++` 是先用后加：

```text
传给外层 fun 的第一个参数 = 2
全局 a 变成 3
```

拿分口诀：

```md
a++ 先把旧值拿去用，再把自己加1。
```

---

## 五、第三步：计算外层 `fun(2,19)`

代码相当于：

```c
fun(2,19)
```

注意：`fun` 里的 `static c` 上一次已经变成 12，不会重新变 0。

进入 `fun(2,19)`：

```c
a=a+b;      // a = 2+19 = 21
c+=b+a;     // static c = 12+19+21 = 52
b=a+c;      // b = 21+52 = 73
return b;   // 返回73
```

所以：

```c
d = 73;
```

拿分口诀：

```md
static 变量不是每次进函数都清零；第二次调用要接着上一次的值算。
```

---

## 六、第四步：看 printf 打印谁

代码：

```c
printf("%d %d %d",a,c,d);
```

这里在 `main` 中打印：

```text
a：全局 a，最后是 3
c：main 的局部 c，一直是 5
d：外层 fun 的返回值，73
```

所以运行结果是：

```text
3 5 73
```

拿分口诀：

```md
printf 在 main 里，能看到 main 的 c；fun 里的 static c 不会被直接打印。
```

---

## 七、这题的拿分套路

```md
1. 先圈出同名变量：全局 a、形参 a、main 的 c、static c。
2. --a 先变再用，a++ 先用再变。
3. static 变量第一次默认为0，后面调用保留旧值。
4. 注意 c+=b+a 是加法，不是乘法。
5. 最后 printf 在哪个函数里，就打印那个作用域里的变量。
```

最后记一句：

```md
同名变量题，先分“是谁”，再算“是多少”；static c 要接着上一次算。
```
