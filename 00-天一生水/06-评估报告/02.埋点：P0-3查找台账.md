# P0-3 查找埋点台账（2026-11-18 起）

> **一句话本质**：每次查库顺手记一笔（用时 + 命中与否），把「准全快」从感觉变成可测趋势。
> **验收口径**：记账规则立起来（字段极简、10 秒能记完）；初始基线落纸；每周复盘能出趋势对比。

## 一、记账规则（C-3 直接引用）

1. **何时记**：每次让 Agent 查库（找文档/找数据/找答案），结果到手就记，一笔 10 秒内。
2. **记什么**：一行六格——日期、查找问题（一句白话）、检索轮数、命中（✓/✗/✓拒答）、现象（命中/找不到/不准/转太久）、备注。一问一行。（2026-11-19 起「用时」改记「检索轮数」：AI 没有可靠的计时手段，旧行的 ~5s/~15s 本来就是按轮数估的；轮数 = 给出答案前发了几批检索，含召回自检。）
3. **谁记**：Agent 查完顺手补记（默认）；用户自查的口头报一笔也行。
4. **记哪**：本文件「三、流水」，只追加不改旧行。

## 二、20 问基线（2026-11-18 实测）

> 测法：Agent 模拟日常查找状态（无提示词约束、无关键词字段），逐问真查，如实记录。题目源自卡点清单 12 例真实摩擦 + 真实备课场景，含 3 个「库里没有」探针（测拒答）。总耗时 149 秒 / 25 次检索。

| 指标 | 基线值 | 备注 |
|---|---|---|
| 20 问命中数 | 20/20（最终答对） | 但一轮直中仅 **10/20（50%）** |
| 一轮直中 | 10 问 | 文件名独特或问题贴文档标题时直中 |
| 二轮才中（转太久） | 6 问 | 关键词噪声淹没目标（Q1/5/7/8/9/10） |
| 正确拒答 | 3 问（Q6/19/20） | 库里真没有，敢说没有 |
| 重名歧义 | 1 问（Q14） | 「图注台账」8 个同名文件需人工挑 |
| 幻觉数 | **0** | 一票否决项，过线 |
| 用时 | 平均约 7.5 秒/问 | 一轮问 ~5s；二轮问 ~15s，超 10 秒线 |

**基线三条发现（回流 P0-4/P0-7）**：
1. **噪声主犯是 meta(查库本身、而不是查库里的课)/备份文件**（local_files.json、体检报告、.backup_before_fix）——正文关键词撞上 meta 重复文本。P0-4 加关键词字段时必须排除或降权 meta/备份目录。
2. **文件名独特 = 一轮命中**（发票SaaS、RASCI、涂料类全直中）——命名规范与关键词字段同等重要，归 P1-9。
3. **同名文件无消歧手段**（图注台账 ×8）——靠路径/课程名辨析，纯人工。
