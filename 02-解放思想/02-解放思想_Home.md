# 02-解放思想 · Home（框架层）

## 本层定义（准入标准）

> 框架层：**新观点、假设、思考、自创方法论**。回答「你想出了什么新的」。
> 判定口诀：**新的、想的、未验证的 → 02**。
> 只要「是新的、值得审视」就可以进，不需要成熟。加工形式与生命周期用 YAML `type`/`status` 表达（`假设` → `成型`），不建状态物理目录。

**准入（宽松）**：任何新理念、假设、个人观点、思考、自创方法论 → 02；外部新素材**默认先进 02 审视**，验证通过才可能升 01。

**排除（分流）**：成熟可信的体系/事实 → 01（升层需用户拍板）；我做过的实践/产物 → 03。

**判定速查（存东西时按顺序问）**：

1. 这是我**做过**的吗？（教案/练习/项目/复盘）→ **03**
2. 这是**一堂官方课 / 经典教科书**吗？→ **01**
3. 都不是（看到的 / 想的 / 不确定）→ **02**（本层是默认落点），拿不准一律先放 02
4. 实在判不了 → **05 收件箱**
