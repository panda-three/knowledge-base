# Feature 层思维与提示词工程的关系

## 问题

Truman 在 AI 操作系统大课中提出了 feature-minimum-capability-unit（Feature）概念，将其定义为 AI 操作的最小动作单位。但 Feature 层思维与现有的提示词工程（Prompt Engineering）框架之间的关系尚未被澄清：

- Feature 层思维是提示词工程的替代框架，还是补充框架？
- Feature 的粒度（定角色、给案例、控温度等）与提示词工程中的技术（few-shot、chain-of-thought、角色设定等）如何对应？
- 从 Feature 层理解 AI 是否能解决提示词工程中"知道技巧但不知道何时用哪个"的问题？

## 相关概念

- feature-minimum-capability-unit：最小能力单元，可被假设、AB 测试、替换、组合
- encapsulation-hierarchy：五层封装层级，Feature 是各层的基础构件
- ai-four-elements：Feature 是四要素之一

## 待探索方向

- Feature 的分类体系是否可以与现有提示词工程技术谱系建立映射？
- Feature 层思维是否更适合团队协作和系统化 AI 设计（相对于个人级别的提示词技巧）？
