# 夙愿直播·Agent三本账与快速打标（2026-11-18 萃取）

> 一句话本质：Agent 用得好 = 管好三本账（单次请求的 token 账、请求频率的模型账、人自己的注意力账），再配一个飞轮（快速打标，把说不清的判断蒸馏成 skill）。

## 与库内既有内容的关系

1. 6 月《夙愿·AI Agent聪明度管理框架》回答「AI 为什么变蠢」；本篇回答「钱、频率、注意力怎么省」——续集关系，重叠点仅乔哈里视窗。
2. 本篇每条均出自逐字稿原文（时间戳可回溯），未经亲测 → 放 02 框架层；跑通后迁 03。

## 一、token 账：每次请求都是一座冰山

1. 你以为发了一句话，实际发的是：系统提示词 + 内置工具说明 + MCP + skill 清单 + 规则文件 + 对话历史。新会话一句话没发，先吃 5 万 token（夙愿 00:02–00:05；何锦成实测一句「你好」开局即 8 万，00:09）。
2. 瘦身四刀：①扫 30 天使用日志，零调用的 skill 隐藏/归档（何锦成 318 个 skill，243 个近 30 天零调用）；②skill 家族懒加载——同类聚合成一个入口 skill（如 lark-cli），进了需求才展开下层；③设为「模型不可见、斜杠可调」；④MCP/内置工具去重，有更好替代就关官方的（01:05–01:10）。
3. 规则文件同理做渐进式加载，任务相关才读；AGENTS.md 超过 32K 时 codex 读不完会漏内容（00:49–00:51）。
4. 实测锚点：何锦成清理上百个 skill 后，/context 里 skill 段显示 9.9K；此前他新会话一句「你好」开局即 8 万 token（00:48 对照 00:09，两个数字口径不同，不直接构成前后对比）。

## 二、频率账：请求次数与模型档位

1. 上下文缓存约 1 小时过期；会话超 1 小时，续聊等于重建缓存重新烧钱（01:33–01:35）。
2. 压缩省钱法：先切 haiku 模型 → 执行 /compact → 切回主力模型。压缩对模型要求不高，用便宜模型做（01:36–01:37）。
3. 上下文上限从 100 万调到 40–50 万自动压缩：单次请求和总量同时变小，长任务质量影响不大（01:13–01:15）。
4. 压缩后拿到的是摘要，不完整——全局配置写死一条「压缩完干活前，主动回翻压缩前的日志」；关键任务进展另写 task log 文件，防压缩丢进度（01:17–01:19、02:40）。
5. sub-agent 当工具用：主会话是任务主理人；扫描统计等杂活派 haiku，重活才配 opus/fable——全局配置写一张「模型派工表」；后台小任务交 codex 无头模式更省（01:23–01:30）。
6. 记忆整理类自动任务换便宜模型跑，别烧主力模型（01:21–01:22）。

## 三、注意力账：人才是瓶颈

1. 关掉输入框「下一句预测」：一下 tab+回车，把你的思考剥夺成 yes/no，且它本身调模型烧 token（01:11–01:13）。
2. 只看结果不看过程：派活后不盯中间工具调用，验收最终产出——把注意力从「看它怎么干」挪到「验收」（02:16–02:21）。
3. 会话管理交给主控 bot：不知道找谁就直接找主控，它自己开新会话传话、收结果（super agent 思路，02:18–02:20）。
4. 「你觉得自己用 AI 已经够激进了，往往还远远不够」——旧经验（AI 以前做不到）会禁锢许愿的胆量（02:04–02:09）。

## 四、飞轮：快速打标，蒸馏说不清的判断

1. 场景：写不出 85 分的教程，但一眼能看出 A 比 B 好——让 AI 批量产出（20 张封面/20 段文案），人像批奏折一样边批注边录音，逐字稿转写后丢回给 AI 迭代 skill（00:56–00:57、02:32–02:34）。
2. 有无标准答案是分界线：
   - 有可置信外部验证的领域（如 VPS 配置有测试工具兜底）→ 文档丢给 AI 就能学会；
   - 无验证标准的领域（文案、直播、剪辑审美）→ AI 单独拆解是半斤八两，必须人机一起拉片打标（02:25–02:29）。
3. 盲评循环：高分范例当标准 → 生成 → 另一个模型盲评打分 → 优化迭代几十轮；模型打分会好坏颠倒，大步骤要拆小、人及时插手反馈（02:29–02:31）。
4. 本质（何锦成总结）：快速蒸馏人的判断——「我们说不清楚好在哪，但能感受出来」（02:31–02:32）。

## 五、对你的三个落点

### 讲课素材（企业 AI 课可直接用）

1. 冰山请求图：一句话背后是系统提示+工具+skill+历史——解释「为什么你的 AI 又贵又笨」的第一张图。
2. 三本账框架：token 账省钱、频率账省时、注意力账省人——比提示词技巧高一层级的认知框架。
3. 快速打标：「说不出好在哪，但能选出来」——把隐性判断变资产的路径。

### 知识库运营印证（与本周底座迭代同构）

4. 懒加载/渐进式加载 ≈ 本库「一课一卡」：索引页是入口，正文按需读。
5. task log + 压缩后回翻 ≈ 本库 MEMORY_LOG + 查找台账：进展落在文件，不依赖会话记忆。
6. 复利循环（每晚定时扫会话+微信+飞书+屏幕时间→多维建议，01:39–01:40、02:00–02:02）≈ 复盘回流流程的自动化升级版，方向与本库「agent 员工化」裁决一致。
