## 一、WorkBuddy

一） 初识 WorkBuddy

### 1、它是什么？

WorkBuddy 是腾讯出品的全场景 AI 工作台。你用大白话把需求说清楚，它像同事一样自己拆任务、读你授权的电脑文件，把成果（文档、表格、PPT、代码、网页）做出来交给你。

### 2、和普通聊天 AI 的区别？

普通 AI 只跟你聊，你问它答；WorkBuddy 能直接动手，操作你授权的文件夹、批量处理文件、跑命令，把能用的成果做出来，而不只给你一段文字建议。

### 3、为什么选它做 AI 编程？

•内置 Skill（可复用工作流）：把「搭网页、改 bug、生成脚本」这类活儿沉淀成一键技能；

•内置 自动化：定时跑任务，不用你每次手动触发；

•内置 MCP 连接器：能接外部工具和数据源；

•内置 资料库：直接读你授权的本地项目文件夹做批量处理；

•中文友好、国内直连、不用翻墙，新手门槛低。

三）WorkBuddy 常用功能（重点：AI 编程）

### 1、三种权限模式（写代码必懂）

输入区上方可切换：

•Ask（问）：只回答、不碰文件，适合咨询讨论；

•Plan（计划）：先出方案再执行，全程可见、可喊停，日常 90% 任务用它；

•Craft（执行）：直接动手改文件、写代码，效率高但要盯紧每一步。做 AI 编程大多用 Craft 或 Plan。

### 2、输入框周围的关键入口（编程必认）


![img_018.png](02-解放思想/70%20案例库/AI破局12期-AI编程实战手册/AI编程（小程序、网站）实战手册_images/img_018.png)


![img_019.png](02-解放思想/70%20案例库/AI破局12期-AI编程实战手册/AI编程（小程序、网站）实战手册_images/img_019.png)

下指令前先认这几个符号，写代码时天天用：

•+：添加文件、图片等外部资料；

•@：引用上下文，或文件夹里的文件、资料、已有对话；

•/：调用已可用的 Skill 或其他快捷指令；

•模型菜单：选当前任务用的模型（新人保持默认即可）；

•文件夹菜单：选工作空间 / 项目文件夹；

•权限菜单：选默认权限或完全访问权限；

•发送按钮：开始执行任务。

### 3、对话式编程

直接下指令就能生成代码，例如：

•「用 Python 写一个批量重命名文件的脚本」

•「帮我把这段 JS 函数改成 TypeScript，并加上类型注解」

•「生成一个落地页 HTML，主色用 slate + indigo」

### 4、资料库 + 本地文件操作

把项目文件夹授权给 WorkBuddy 后，它能读里面的代码、文档、表格，做批量处理、跨文件重构、按规则生成报告。

### 5、Skill（可复用工作流）

把一类固定活儿（如「修 lint 错误」「生成组件」「按规范写接口」）固化成 Skill，下次一句话调用，不必每次重新描述。训练营后期会带大家写自己的第一个编程 Skill。

### 6、自动化

把稳定的编程任务设成定时自动跑，例如「每天凌晨拉取仓库、跑测试、把失败用例汇总成报告」。

### 7、MCP 连接器

需要时接外部工具 / 数据源（如代码仓库、云存储、数据库），让 WorkBuddy 在授权范围内调用。

### 8、工作空间与权限管控（新手防翻车）

这是 AI 编程最容易出事的地方，记住这几条：

•第一次别直接授权「桌面 / 下载 / 重要资料」文件夹，单独建一个练习目录，只把本次任务的资料副本放进去；

•默认权限够用，它能在正常任务范围内干活；只有当操作可能影响重要文件、工作空间外位置或电脑状态时，才会请你确认；

•弹确认窗口时，看不懂内容就先取消，别盲点通过；

•不长时间用「完全访问权限」，干完就收回。

四）给学员的 AI 编程实操建议

•先用 Plan 模式让它列方案，确认再让 Craft 动手；

•一次只交一个小任务，跑通再扩；

•让它改代码前，先确认已授权「正确的项目文件夹」；

•关键改动让它先说明改了哪几个文件、为什么，你 review（检查） 后再定稿；

•先跑通一个最小闭环（哪怕只是「写个脚本并重命名一批文件」），后面的 Skill、自动化都是锦上添花，一步步来。

## 二、Codex（ChatGPT 桌面版）

一）初识 Codex

### 1、它是什么？

Codex 是 OpenAI 的编码智能体，现已内置进 ChatGPT 桌面版。它能直接读取你电脑上的项目文件夹，写代码、改代码、运行命令、跑测试、审查差异，处理较长的软件开发任务，相当于一个能动手的编程同事。

### 2、和网页版 ChatGPT 的区别？

•网页版：在对话框里聊，代码得你自己复制出来跑，报错再粘回去问；

•桌面版（Codex）：直接在你的电脑上动手，读整个项目、改文件、跑脚本、自己看报错自己修，你拿到的是能直接用的结果。

### 3、为什么用它做 AI 编程？

•项目级编码：直接操作本地代码仓库，不是「半截代码片段」；

•自驱执行：写完自己跑、跑错自己改，改到通过为止；

•随手唤起：快捷键一按，框选屏幕直接问，报错不用截图三连。

### 1、主界面结构和功能


![img_037.png](02-解放思想/70%20案例库/AI破局12期-AI编程实战手册/AI编程（小程序、网站）实战手册_images/img_037.png)

整个界面分成三大区域：

左边 = 导航栏。 这里有所有功能入口，包括快速对话、搜索、插件、自动化、项目等。

中间 = 工作区。 这是你和Codex对话、下任务的主要区域。你会看到一个输入框，上面写着类似"我们该做什么？"的提示文字。

左下角 = 设置入口。 语言、权限、用量这些关键配置，都要从这里进去。

这就是Codex和普通聊天框最大的差别。它不只有一个聊天窗口，它有一个完整的工作台。

现在我们来逐个认识左边导航栏的每个功能。

### 1.1、功能一：快速对话


![img_038.png](02-解放思想/70%20案例库/AI破局12期-AI编程实战手册/AI编程（小程序、网站）实战手册_images/img_038.png)

左侧第一个入口，也是你最先应该用起来的功能。

你可以把它理解成一个"临时聊天窗口"。就像ChatGPT一样，你有什么想问的，直接在这里用中文说就行。

它和ChatGPT的聊天框使用感受几乎一样。你问它问题，它回答你。你让它写东西，它帮你写。

什么时候用它？

当你只是想临时问个问题的时候。当你想换一个话题聊的时候。当你不想让对话和任何项目挂钩，就想随便问问的时候。

新手第一天应该做的事： 就是在这里开始跟Codex对话。不要一上来就碰文件、配项目。先在这里聊起来，找到感觉。

### 1.2、功能二：搜索


![img_039.png](02-解放思想/70%20案例库/AI破局12期-AI编程实战手册/AI编程（小程序、网站）实战手册_images/img_039.png)

搜索非常好理解，就是帮你找历史聊天记录的。

你今天跟Codex聊了一个关于制作计划表的话题，过了两天想找回来，就可以在搜索里输入关键词，快速定位到那次对话。

刚开始用的时候可能用不太上，但聊得多了之后你就会发现它很实用。先知道它在这里就行。

### 1.3、功能三：插件


![img_blk_05.png](img_blk_05.png)

这是让Codex变得更强的关键。

你可以把插件理解成给Codex加装各种"技能包"。

Codex本身有基础的对话和文件处理能力。但如果你想让它做更多事情，比如控制浏览器、处理表格、操作文档，你就需要给它装对应的插件。

点击左侧的"插件"入口，你会看到一个插件列表。每个插件都有名字和能力说明（可能是英文的，可以截图翻译一下看看）。

推荐新手优先了解的插件：

① 文档插件（Docs）

装上后Codex可以帮你创建和编辑Word文档。比如你让它"帮我写一份项目计划书"，它就能直接给你生成一份.docx文件。

② 表格插件（Sheets）

装上后Codex可以帮你创建和编辑Excel表格。比如你说"帮我做一个本月支出统计表"，它就能直接生成表格文件。

③ 浏览器插件（Chrome/Browser）

这个是让很多人感到兴奋的插件。装上之后，Codex可以直接控制你的浏览器。比如打开一个网页、搜索信息、点击按钮、填写表单等等。

④ 演示文稿插件（Slides/PPT）

装上后可以让Codex帮你制作演示文稿。你只需要告诉它主题和内容要求，它就能帮你生成一份PPT。

⑤ 代码执行插件（Code Interpreter）

如果你需要Codex帮你做一些数据分析、图表绘制、文件格式转换之类的任务，这个插件会让它具备执行代码的能力。

新手建议： 刚开始不用把所有插件都装上，Codex通常已经默认装好了一些基础插件（比如文档和表格）。等你用着用着遇到了需要其他能力的场景，再去装对应的插件就行。不要贪多。

### 1.4、功能四：自动化


![img_040.png](02-解放思想/70%20案例库/AI破局12期-AI编程实战手册/AI编程（小程序、网站）实战手册_images/img_040.png)

自动化听起来很高级，但概念其实很简单。

它就是让Codex帮你定时或重复执行某些任务。

举个例子。

如果你每天早上都要打开五个网站看看行业新闻，然后把标题整理到一个表格里。这件事很机械、很重复，但每天都要做。

有了自动化功能，你可以告诉Codex："每天早上9点帮我去这几个网站看一下今日头条新闻，把标题整理成表格放到我的项目文件夹里。"

设置好之后，Codex就会按时帮你做这件事。你起床之后，打开文件夹，结果已经在那里了。

适合做自动化的事情：

每天都要做的信息搜集和整理。定期要做的数据汇总和报告。任何你发现自己在重复做的、流程固定的操作。

新手建议： 自动化是Codex里比较进阶的功能。第一天不需要碰它。等你先把"快速对话"和"项目"用顺了，有了使用经验之后，再来研究自动化。

### 1.5、功能五：项目


![img_041.png](02-解放思想/70%20案例库/AI破局12期-AI编程实战手册/AI编程（小程序、网站）实战手册_images/img_041.png)

如果只能记住一个概念，就记住这个。

项目是Codex和普通聊天工具最大的区别所在。

我先用一句话解释清楚：

项目 = 让Codex知道它应该在哪个文件夹里工作。

为什么这很重要？

因为Codex不只是能聊天。它还能帮你读取文件、修改文件、创建新文件。但问题是——你电脑上有那么多文件夹，它怎么知道该碰哪个？

答案就是：你需要告诉它。

这就是"项目"的作用。

打个比方。你请了一个新助理来公司上班。第一天你不可能说"这栋楼所有东西你随便动"，对吧？你肯定是说"你的工位在这里，今天要处理的资料在这个文件夹里"。

项目，就是给Codex划定的"工位"和"工作范围"。

怎么创建一个项目？


![img_042.png](02-解放思想/70%20案例库/AI破局12期-AI编程实战手册/AI编程（小程序、网站）实战手册_images/img_042.png)

点击左侧导航栏的"项目"，然后选择"使用现有的文件夹"（或者"创建新文件夹"）。

接着选择你电脑上的一个文件夹。比如你创建了一个叫做"自媒体创作"的文件夹，选中它。

这样就创建好了一个项目。以后你在这个项目里和Codex对话，它就知道自己的工作范围是这个文件夹。

新手建议： 先在桌面创建一个专门用来练习的空文件夹，比如叫"Codex练习"。用这个文件夹创建一个项目。这样你可以放心大胆地让Codex在里面操作，不用担心影响到你其他重要文件。

## 二、新手使用 Codex 建议

一）先聊天再做事

### 4、不要怕用错

在练习文件夹里，没有什么操作是不可逆的。大胆试，试错才是学习最快的方式。

功德累计值持久化：本地缓存保存（wx.setStorageSync）。重新打开小程序时恢复累计值。提供“清零”按钮（放在设置里，避免误触），清零前二次确认。​

每次累加值：+1 / +3 / +9（默认 +1）。​

六）总结

### 1、需求描述不清楚

正常的小白用户是描述不清楚需求的，所以需要借助 AI 画原型、总结成文档的方式，来确认需求、确认样式，这个是区别于传统小程序开发的，传统开发有专门的产品经理先确认好需求，再让 UI 设计师设计 UI 样式。有了 AI，我们可以让 AI 先出 UI 图，我们直接看图来确认需求、确认 UI 样式。

如果是商单，这个环节更重要，很多甲方是不清楚自己想要什么的，完整的设计稿相当于一个产品雏形，有了这个去沟通需求会更加清晰、减少后期扯皮。

### 2、为了约束 AI 不胡乱发挥

我们需要遵循传统开发的规范，让 AI 帮我们写系统设计文档、接口设计文档、数据库设计文档，这样结合 UI，后续 AI 就不会走偏。

现在基本上还处于人+AI 协作的方式，另外如果是大型项目，大模型的上下文也不支持，我们需要一些手段来约束 AI 的产出。

### 3、好的工具学会用

CodeX 的 Computer Use 对于小白用户来说很友好，它可以直接帮我们操作电脑，碰到不会操作的软件、琐碎的操作，比如测试，都可以通过这个插件来完成，这个案例中的测试工作也基本上是由 Computer Use 来完成的，又快又好，只是有点耗 Token。

### 4、碰到错误不要慌

在电脑端预览打开 vConsole 获取到错误信息之后，扔给 CodeX，它会帮你修复的。

另外，为了防止 AI 将好用的代码改呲，大家可以将 AI 生成的代码保存到 GitHub 上，直接让 codex 操作即可。

## 一、服务器，域名购买及备案 @予贝

大家平常肯定会有这么一个疑问：在自己电脑上写好的网站，怎么让别人通过一个网址访问到。

这件事卡住过很多人，卡点不在技术，在流程。

三样东西技术含量都不高，纯属流程活。但环节多、审核严、等待时间长，一个细节没对上就得多等十天半个月。

这一节我将把整套流程拆成能照着操作的步骤。

服务器是一台放在机房里的电脑，24 小时不断电不断网，有一个固定的公网 IP，比如 129.204.x.x。

网站代码运行在这台机器上。用户访问网址，本质上就是在访问这台机器。

### 2、域名

域名是给人记的地址，比如 example.com。

它本身不存任何东西，唯一作用是指向一个 IP。没人愿意记一串数字，但谁都能记住一个名字。

### 3、备案

备案是把网站信息登记到主管部门，让每一个网站都能追到责任人。只要服务器在中国内地，这一步绕不开。

好消息是它免费，也不用跑腿，全程线上完成。

二）开工前的四个决定

### 1、个人备案还是单位备案

判断标准只有一条：这个网站以后要不要收钱。

个人备案需要身份证和视频核验，网站性质只能填个人博客、个人主页这类非经营性内容。

单位备案需要营业执照、法定代表人身份证、网站负责人身份证，网站性质可以填单位官网，能放公司介绍、产品展示、联系方式。

先记住一条硬红线：个人备案的网站不允许开展经营性活动，包括在线收费、电商交易、支付功能。管局会看网站内容，一旦发现，备案可能被注销。

所以如果你明确知道这个网站以后要卖东西、要收款，现在就去办个体工商户营业执照，直接走单位备案。注册成本很低，远低于事后返工。

### 2、域名起什么名字

域名定下来，后面所有材料都跟着它走。

选名字的原则就三条：短、好念、能打出品牌感。个人站用名字拼音或英文名加常用后缀就够了。

要避开三类词：

•涉及国家、政府、国际组织的词，比如 china、gov、中华、全国

•涉及金融、教育、医疗、新闻、出版、视听等需要前置审批的行业词，个人备案基本过不了

•他人品牌名和商标，轻则驳回，重则被投诉仲裁

后缀怎么选？.com 通用性最好，.cn 便宜且在国内信任度高，.net 偏技术。预算紧的可以看看 .icu、.site、.cloud 这类新后缀，新注首年常常只要几块钱。

### 3、服务器买什么型号

零基础起步，直接买轻量应用服务器，不要一上来就折腾云服务器 CVM。

原因是轻量应用服务器把计算、带宽、存储打包好了，控制台简单，还自带应用模板，装环境不用从零敲命令。CVM 灵活，但安全组、路由、VPC 都得自己配，对新手是额外负担。

打个比方：轻量是精装公寓，拎包入住；CVM 是毛坯房，想怎么改都行，水电得自己接。

参考配置，新手买最便宜的即可，后续有需要可升级配置


| 用途 | 建议配置 | 首年参考价 |
|---|---|---|
| 个人博客、作品集、静态站 | 2核2G 3M | 约 38 到 100 元 |
| 带数据库的管理系统、小程序后端 | 2核4G 5M | 约 100 到 200 元 |
| 跑 AI 应用、多人协作 | 4核8G 10M 以上 | 约 450 到 630 元 |

三个点要特别注意。

地域必须选中国内地（广州、上海、北京、南京、成都等都可以）。选了中国香港、新加坡、硅谷这些节点，因为不属于内地管辖，没法备案，域名也无法合规解析。

计费必须是包年包月，且购买时长 3 个月及以上。按量计费、试用期的实例不支持备案。反正一年也就多几十块，直接买一年最省事。

备案期间服务器剩余有效期要大于 1 个月。也就是说别卡着到期前一个月去备案，容易在审核途中失效。

新用户活动价通常只限首年，续费会回到原价。下单前看一眼商品页有没有标注续费同价或买 1 年送 3 个月，有就优先选。

## 二、程序开发 @许沐

一）前后端介绍

一个完整的 Web 应用一般由「前端」和「后端」两部分组成，它们分工协作，共同构成我们平时使用的网站和系统。

前端：运行在浏览器中的部分，负责用户能看到的界面和交互，例如页面布局、按钮点击、数据展示等。核心三大技术是 HTML（页面结构）、CSS（样式）、JavaScript（交互逻辑），实际开发中常使用 Vue、React 等框架提升效率。

后端：运行在服务器上的部分，负责业务逻辑和数据处理，例如用户登录校验、数据的增删改查等。前端通过 HTTP 请求调用后端提供的 API 接口，数据一般以 JSON 格式传输。后端常用语言有 Python（Flask / FastAPI）、Java、Node.js 等。

数据库：负责把数据持久化地保存下来，本次使用的是 MySQL。


![img_155.png](02-解放思想/70%20案例库/AI破局12期-AI编程实战手册/AI编程（小程序、网站）实战手册_images/img_155.png)

简单来说：用户在浏览器中操作（前端）→ 前端把请求发给后端 → 后端处理业务逻辑并读写数据库 → 把结果返回给前端 → 前端渲染展示给用户。

本课程的技术栈为：前端 Vue3 + 后端 Python FastAPI + 数据库 MySQL，代码主要由 AI 编程工具帮我们生成，我们负责把环境搭好、把需求描述清楚。
