# 时间管理·勇敢假设清单1.0版

| 分类               | 假设技巧           | 具体假设描述                                                                                                                                                                                                                                      |
| ---------------- | -------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **按任务**          | 复杂任务拆成多件小事     | <ul><li>把写作，拆分成“灵感”“大纲”“填大纲”三个时间块</li><li>把做方案，拆分成“酝酿”“内部会议场景激发”“L3全神贯注开始写”“打磨”</li><li>把网站开发，拆分成“L5 构思文案”“L3 SEO优化”“L1 开始做网页”</li></ul>                                                                                                    |
|                  | 制定每日任务清单       | <ul><li>每天早晨列出当天必须完成的任务，按重要性排序</li><li>计划将待办事项详细记录在任务管理软件中，并按照重要性和紧急性进行分类</li></ul>                                                                                                                                                         |
|                  | 优化日常工作流程       | <ul><li>花时间分析日常工作流程，识别出卡点和冗余步骤，尝试简化和自动化这些流程</li></ul>                                                                                                                                                                                       |
|                  | 五彩任务可视化        | <ul><li>对待不同类型的任务，心理排斥感不同，视觉上色彩区分也许可以帮助调整心态</li></ul>                                                                                                                                                                                       |
|                  | 团队协作           | <ul><li>据工作量+gap排期给团队</li><li>.团队协作沟通写备忘可以显著提高团队合作效率</li><li>开启团队周报或者周会，并记录，每周一上午执行</li></ul>                                                                                                                                               |
| **按时间<br>(含场景)** | 工作时间分段/分块      | <ul><li>把时间切成大中小块分配给相应活动，比如大块3~4小时，中块1~2小时，小块1小时一下</li></ul>                                                                                                                                                                                |
|                  | 尝试短暂休息时间       | <ul><li>每个60~90分钟进行5~10分钟的休息，帮助大脑恢复活力，提高长时间工作效率，减少身体和心理疲劳</li></ul>比如，进行轻松活动 / 眼保健操 / 冥想                                                                                                                                                    |
|                  | 设定专注工作时段(深度思考) | 每天规划几个小时的专注工作时段，完成避免使用电子设备，选择安静的环境进行L4深度工作。<br><br>比如，晚上9点之后的一段时间 / 夜深人静家人睡着时 / 清晨早起家人未醒时                                                                                                                                                   |
|                  | 灵感进发的时间+场景     | <ul><li>受到环境、时间等多种因素影响激发灵感，以下是同学们提及灵感迸发的场景和时间：</li></ul>上班地铁通勤+降噪耳机+flomo记录 / 独处静坐或冥想 / 洗澡时间 / 无干扰空间放轻音巴赫肖邦等 / 图书馆看杂志 / 慢跑中 / 练瑜伽 / 打八段锦 / 公园走路散步 / 晒太阳 / 坐上座位的公交车看着风景变化 / 听一堂课时 / 睡前&睡醒                                                    |
|                  | 记录不同场景地点的影响    | <ul><li>把自己的场景和时间段分成分类二维表格，在将任务分配进去，每晚及时复盘不同场景的效率和状态</li></ul>常见工作场景地点，比如 大开间办公/封闭办公室 / 书房 / 咖啡厅 / 图书馆 / 酒店房间 / 通勤路上                                                                                                                        |
|                  | 清晨型夜晚型对比试验     | <ul><li>什么时间段状态最好？效率最高？早晨or深夜？需要早起or晚睡？</li><li>测试每天增加30分钟高质量深度工作时间，分别测试放在早上or 下午or晚上，哪个时间最好</li></ul>                                                                                                                                      |
|                  | 故事化时间块         | <ul><li>分配时间块太机械，给每一个时间块赋予一个故事背景，比如“攻坚克难的英雄时刻”</li></ul>                                                                                                                                                                                    |
|                  | 压缩时间提升时间质量     | <ul><li>比如，听音频课，用2~3倍速，强迫自己聚精会神避免走神</li></ul>                                                                                                                                                                                               |
|                  | 起床后前半小时“无屏幕时间” | <ul><li>不查看电子设备，而是进行其他活动，比如洗漱，晨练，冥想，阅读纸张书籍，吃早餐等减少信息过载带来的压力</li></ul>                                                                                                                                                                        |
|                  | 尝试使用双峰工作法      | 比如，与团队明确自己专注不被打扰的时间，自己准备笔记本电脑在单独的办公室办公<br>比如，周一三在公司处理内部工作，外出工作尽量安排二四五<br>比如，不止“独立-协作”的分法，还有“前期假设-中期构思”，“灵感-雏形”                                                                                                                              |
|                  | BGM歌单提神        | <ul><li>高度专注的工作：节奏平稳、旋律柔和、枯燥重复的工作：更加活泼、激励性</li><li>听音乐能够带来动力，写出自己的动力源用SUNO创作成一首歌</li><li>有些歌曲听到之后就会特别心绪安宁又充满动力，测试哪些音乐对应我不同的工作</li><li>准备工作前：播放一些很燃的，工作时播放白噪音/纯音乐/莫扎特/民谣</li><li>创建几个BGM歌单对应不同工作深度 比如，专注工作 / 创作灵感 / 运动 / 休息 / 深度思考</li></ul> |
|                  | 如何利用好“暗时间”     | 比如，散步时思考工作方向 / 锻炼时复盘当天工作 / 出差交通时，使用降噪耳机获得L3时间或打电话沟通协作 / 等车或人的时候刷剧积累信息 / 开会时除去自己板块，顺手处理随时可以中断的工作 / 水水老师拆书边听直播边记笔记边写作业                                                                                                                        |
|                  | 定期进行时间管理复盘     | 比如，吃早餐前完成复盘 / 下班路上边听音乐边回顾复盘 / 在现场完成复盘，利用现场呈现的所有资源 / 重要事项隔日复盘，避免情绪和深度时间保证                                                                                                                                                                    |
| **按匹配<br>(更高效)** | 工作前先热身运动       | <ul><li>专注的有氧运动半小时后工作，身体和大脑处于兴奋状态，精力集中度高</li><li>早晨起床增加20分钟运动时间 + 一杯咖啡，提升精力</li></ul>                                                                                                                                                       |
|                  | 利用倒计时DDL保持专注   | <ul><li>利用倒计时来进行心理暗示，保持DDL的专注度，是否能提高我的效率？</li></ul>                                                                                                                                                                                         |
|                  | 降低期待先开始        | <ul><li>先进入工作流，烂开始，比如写作就先从抄写一些美文进入状态</li></ul>                                                                                                                                                                                              |
|                  | 金句激励法          | <ul><li>在需要能量时，写一写提升自己动力和自信的金句</li><li>在需要能量时，看正史、看伟人，从他们身上得到力量</li></ul>                                                                                                                                                                   |
|                  | 吃喜欢的食物         | 比如，喝喜茶的芝士芒芒效率提高 / 吃几颗较贵的水果带来幸福感                                                                                                                                                                                                             |
