# 预判与试错的最优时间分配如何确定？

## 问题

Truman 提出预判基本功公式为「用 10–20% 的总时间/成本，换整体成功率 3–10 倍的提升」，并给出了预判时间经验值表（副业一两个晚上 → 上市两三个月）。但一堂自身从 -1 到 0 用了 4–6 个季度才摸出方向——预判时间经验值与一堂自身实践存在量级差异。

## 子问题

1. 10–20% 的经验值是否有更精确的决策标准？不同行业、不同阶段的预判时间分配是否应该有差异化公式？
2. 预判的边际收益递减点在哪里？什么时候应该停止预判、开始试错？
3. 如何判断一个项目是「预判不足」还是「过度预判」？
4. 预判时间经验值表的样本量是多少？是否存在幸存者偏差——只统计了成功的案例？
