# 01.本质：一堂本质定义全清单

> 一句话本质：本质是**用一句话或几个要素，讲清复杂现象最底层的逻辑**；想透它，就能从底层往上推出上层创新，做到「无招胜有招」。
> 本清单汇总库内 6 篇原文的本质定义，去重后按主题编号，供讲课直接取用。原文标注「严禁转载」，仅限内部学习。

---

## 一、什么是本质

1. 本质 = 复杂现象的最底层逻辑，一句话 or 几个要素就能讲明白。
2. 提炼极难：需一遍遍深度思考、不断推翻修正、反复推演使用。
3. 用途链：本质（道）→ 方法模型（法）→ 工具小抄（器）→ 作业与刻意练习（用），四层统一自洽。
4. 思考深化的四层：L1 事实经验 → L2 尊重常识 → L4 本质理解 → 经典理论。
（出处：L4.本质理解 / Truman 清单 Part I）

---

## 二、教育的本质

1. 教育 = 积极改变 = 教材 + 教学。
   - 教材 = 问题 + 解法
   - 教学 = 制定计划 + 解读教材 + 督促学习 + 给反馈
2. 问题 = 预期和现实之差（可解释「不满」「惊喜」）。
3. 知识付费 = 商品逻辑（卖完结束，对履约无强预期）；教育 = 用户出发、解决问题、保证品质。
4. 公司内训 = 逐步落地：统一话语（现场讲）+ 动手实践（给工具）+ 持续落地（留作业）。
（出处：Truman Part II / 教育的本质统一模型 / L4.本质理解）

## 三、创业与商业的本质

1. 创业 = 概率游戏。
2. 产品内核 = 用户愿意选择你的最小解决方案。
3. 单元模型 = 业务复制的最小经济单元。
4. 增长飞轮 = 把增长要素的因果关系串成「增强回路」。
5. 科学销售 = 用一套有效方法降低销售本身的不确定性。
6. 壁垒 = 发现行业内核心竞争资源，并努力占领它。
7. 精益 = 用少量试错成本，大幅降低系统性风险。
8. 调研 = 回答问题，帮助指导关键决策。
9. 融资 = 让 VC 赚钱。
（出处：一堂创业本质清单）

---

## 四、组织与管理的本质

1. 逐字稿 = 现场说话能力的训练工具。
2. 知识管理 = ROI 考量（成本=收集整理管理，收益=长期做事能力提升）。
3. 成长 = 刻意练习的速度和质量。
4. 学习 = IPO 的速度和质量。
5. 复盘 = 把一次性工作，变成团队未来的能力。
6. 项目管理 = 在有限时间、有限资源下完成一个目标。
7. 开会 = 用集体讨论的时间，换业务结果。
8. 新人落地 = 高效完成人岗匹配。
（出处：一堂组织本质清单）

## 五、产品、增长与说服的本质（Truman 日常工作）

1. 说服 = 动力 + 阻力 + 触点（动力=名利权情+稀缺+影响力；阻力=贵/不懂/没时间/怕被骗；触点=关键接触节点）。
2. 续费 = 构建脱离成本（课程 / 活动 / 数据 / 社交）。
3. 产品 = 一切以用户价值为依归（商业价值←产品价值←用户需求）。
4. 产品运营 = 做对 vs 做好（产品经理把事做对，运营经理把事做好）。
5. 系统性增长 = 找到并推动系统中的正向增强回路（线性增长缺闭环，增强回路可自增强成壁垒）。
6. 招聘 = 补认知 + 补操盘 + 补做事。
7. 战略会 = 关键生死决策的艰难选择（选择 / 生死 / 艰难）。
（出处：Truman 清单 Part II）

## 六、其他常用本质（Truman 更多总结）

1. 补贴 = 临时增长手段（测内核和单元模型阶段慎用，容易死）。
2. 竞争方向 = 看壁垒要素（规模驱动低打高，品牌驱动高打低）。
3. Cheatsheet vs Checklist = 备忘（全都在）vs 检查（一个都不能少）。
4. 激励要素 = 名利权情。
5. 产品起名 = 帮目标用户和产品持续沟通、促进交易、形成品牌。
6. 长期主义 = 愿意在更长时间跨度上，持续积累复利的要素。
（出处：Truman 清单 Part III）
