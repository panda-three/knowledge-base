## 一句话核心

自有服务器 + Hermes Agent + Codex，把「PPT 代做」拆成 5 个角色 Agent 的流水线（需求收集 → 大纲 → 样稿 → 批量生产 → 质检），两个月做到 2.7 万营收。

## 结构

- 一~三：为什么要有自己的服务器 / RackNerd 购买 / 首次登录改密码
- 四：装 Hermes Agent（可视化管理）+ 接 Codex（大脑）+ 接 Telegram（手机派活）
- 五：5 个 Agent 的角色设定（唐僧 / 孙悟空 / 猪八戒 / 沙和尚 / 白龙马）与提示词全文
- 六：Skills 进阶；七：适合谁、劝退谁；八：5 个高频疑问

## 可复用点

1. 「一个 AI 从头干到尾」是瓶颈 → 按角色拆分（对应五层框架的第四层「带员工」）；
2. 真正决定交付质量的是总控提示词 + 质检清单，不是模型本身；
3. 服务器自持（RackNerd）是 24h 在线接单的成本前提。
