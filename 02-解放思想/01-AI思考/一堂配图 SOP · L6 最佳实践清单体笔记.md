## 一、场景与出口定义

### 1.1 这个 SOP 解决什么问题

| 维度 | 内容 |
|---|---|
| **业务场景** | 一堂每周有多门课程上架，每门课需要一张「选课卡片」（类似电影海报）——用户在课表里看到它，决定要不要选这门课 |
| **核心痛点** | 如果每张卡片都从零设计，依赖设计师的「灵感」和「状态」——质量不稳定、速度慢、换人做就变样 |
| **SOP 的价值** | 把「设计一张好头图」从「艺术创作」变成「标准操作」——任何人按 SOP 执行，都能产出达到一堂审美底线的头图 |
| **数量规模** | 200 门课 × 每门至少 1 张选课卡片 + 每节课内知识点卡片若干 + 逐字稿配图 + 公众号/Banner 图 = 大量重复性配图需求 |

### 1.2 出口定义

```
出口 = 一张「美观且契合课程主题」的选课卡片

什么叫「美观」？
  ✅ 色彩克制统一——不超过 2-3 个主色
  ✅ 字体规范——标题和正文有清晰层级
  ✅ 留白恰当——信息不拥挤，有呼吸感
  ✅ 蒙层均匀——文字在任何背景图上都可读

什么叫「契合课程主题」？
  ✅ 配图与课程内容有关联（不是随便一张好看的图）
  ✅ 标题准确传达课程价值——不是「课程名」，而是「这门课能帮你解决什么」

什么叫「不美观」（常见错误）？
  ❌ 五颜六色没有主色调
  ❌ 字体大小混乱，层级不清
  ❌ 文字直接放在复杂背景上，看不清
  ❌ 配图和课程内容毫无关系
```

### 1.3 为什么这个 SOP 被标注为「【中等💡】」而非「【简单💡】」

在马拉松大课的基本功训练清单中，SOP 按难度分五档：简单、中等、较难、高难、极难。

| 难度档位 | 判断标准 | 此 SOP 为什么是中等 |
|---|---|---|
| 简单 | 纯流程类——照着清单做就行，没有审美判断 | — |
| **中等** | 需要**一定的审美判断力**——不是纯流程，要知道「什么算好看」 | 配图 SOP 需要操作者判断：这张图适不适合这门课？蒙层透明度够不够？字体大小对不对？ |
| 较难 | 多环节协作 + 外部不确定性 | — |
| 高难 | 长周期、跨部门 | — |
| 极难 | 极度复杂、多方博弈 | — |

> 🔑 **关键洞察**：配图 SOP 被定为「中等」而非「简单」，说明它**不是纯机械操作**。操作者需要具备的「审美判断力」虽然不像 Truman 做官网 VibeCoding 那么高，但也需要建立基准线——知道「什么算通过、什么算不合格」。

## 二、整体工作流全景图（逻辑推演）

```
第一步            第二步              第三步            第四步
找素材         → 做蒙层+排版      → 加标题文字      → 质量检查
 Unsplash         Sketch/PPT/Keynote   可商用字体        审美门控
 10min            10-15min             5-10min          5min

单张卡片总耗时：约 30-40min（熟练后）
```

### 2.1 四步工作流总览

| 步骤 | 名称 | 工具 | 核心动作 | 产出物 |
|---|---|---|---|---|
| **第一步** | 找素材 | Unsplash | 根据课程主题搜索高清无版权图片 | 1-3 张候选背景图 |
| **第二步** | 做蒙层+排版 | Sketch/PPT/Keynote | 将背景图放入画板，叠加黑色半透明蒙层，确定标题位置 | 带蒙层的底图 |
| **第三步** | 加标题文字 | 可商用字体 | 在蒙层上添加课程标题和副标题，调整字体大小和层级 | 完整头图设计 |
| **第四步** | 质量检查 | 人眼 | 按 SOP 的质量门控清单逐项检查 | 可发布的选课卡片 |

## 三、步骤一：找素材——怎么选对一张背景图

### 3.1 为什么用 Unsplash

```
【已确认】图片源：https://unsplash.com/
```

| 选择 Unsplash 的原因 | 具体优势 |
|---|---|
| **无版权风险** | 所有图片免费可商用，无需署名——这是商业场景的头号硬约束 |
| **质量基线高** | 社区精选机制保证了最低审美标准——不像某些图库充斥着「商务握手」式低质量素材 |
| **搜索效率高** | 英文关键词搜索，覆盖面广——一张「technology abstract」能出几百张高质量选项 |
| **风格统一** | Unsplash 的整体审美风格偏「克制、现代、有质感」——和一堂的品牌调性在一定程度上天然契合 |

### 3.2 素材筛选的审美标准（推测复原）

不是「搜一张好看的就用」。一堂的选图标准推测如下：

| 筛选维度 | ✅ 选 | ❌ 不选 |
|---|---|---|
| **主色调** | 偏暗、偏冷、偏克制——深蓝、深灰、墨绿、暗金 | 五彩斑斓、大红大绿、高饱和度 |
| **画面复杂度** | 抽象纹理、几何图形、自然光影、远景——**文字放在上面可读** | 细节极多的近景特写、人脸特写、复杂图表——**文字放上去眼花** |
| **留白空间** | 画面中有天然的大面积同色区域或渐变区域——给标题留位置 | 全画面信息密度极高，没有「放文字」的余地 |
| **与课程的关联** | 能抽象地呼应课程主题——如「科学决策」用极简几何，「人生红点」用辽阔自然 | 与课程主题毫无关联的纯装饰图——如「财务课」配沙滩度假 |
| **图片质量** | 高清、无压缩伪影、噪点可控 | 模糊、有明显压缩痕迹、噪点多到影响观感 |

### 3.3 一个关键决策：选图时就要「看见最终成品」

```
普通操作者：搜一张好看的图 → 放上文字 → 发现文字看不清 → 换一张 → 来回试
SOP 操作者：搜图时脑子里已经叠加了「蒙层+文字」的最终画面
            → 只选那些「天然为文字留了呼吸空间」的图
            → 试一张就过

这个差距不在技能，在「心法」——你是在「找一张图」，还是在「为最终成品找底材」。
```

## 四、步骤二：做蒙层+排版——让任何背景图都能承载文字

### 4.1 黑色蒙层的四重作用

```
【已确认】背景图加黑色蒙层
```

| 作用 | 为什么必不可少 |
|---|---|
| **保证文字可读性** | 无论背景图是什么颜色，文字永远在深色底上——这是「工业化稳定输出」的核心保证 |
| **统一视觉风格** | 所有选课卡片的「底色」趋同——用户浏览课表时不会因为某张卡太跳而错失信息 |
| **降低选图门槛** | 有了蒙层，背景图不需要「完美」——大幅度降低了素材筛选的难度和时间 |
| **制造品牌识别度** | 一堂的一整套卡片都有统一的「暗底+亮字」视觉特征——这就是品牌资产 |

### 4.2 蒙层参数推测

```
推测蒙层参数：
  颜色：纯黑 #000000
  透明度：50%-70%（根据背景图的明暗调整）
  覆盖范围：全图覆盖（边缘不留白边）
  渐变：可能需要「底部更深、顶部略浅」的渐变蒙层
        ——如果标题在底部，底部蒙层加深保证文字可读
        ——顶部稍浅保留背景图的视觉纹理
```

### 4.3 排版布局推测

```
一堂选课卡片的布局（推测）：

┌──────────────────────────────┐
│                              │
│         [背景图]              │
│       + 全图蒙层              │
│                              │
│                              │
│     ┌──────────────────┐     │
│     │  🏷 课程系列标签   │     │
│     │                  │     │
│     │  课程主标题       │     │
│     │  （大字, 1-2行）  │     │
│     │                  │     │
│     │  副标题/一句话    │     │
│     │  （小字, 1行）    │     │
│     └──────────────────┘     │
│                              │
└──────────────────────────────┘

标题位置：通常在卡片的下1/3处或居中偏下
原因：视觉重心下沉，给人「稳重、扎实」的感觉——和一堂不贩卖焦虑的品牌调性一致
```

## 五、步骤三：加标题文字——字体选择和层级设计

### 5.1 为什么必须用「可商用字体」

```
【已确认】使用可商用的字体
```

| 风险 | 如果用了不可商用的字体 |
|---|---|
| **法律风险** | 字体公司可能发律师函——商业场景的字体侵权赔偿额可高达数万/款 |
| **品牌风险** | 一堂作为教育平台，不能因为字体侵权被用作负面案例 |
| **可复制性风险** | SOP 的目标是「任何人都能执行」——如果字体需要额外购买和授权，就增加了操作门槛 |

> 🔑 **L6 洞察**：SOP 里的每一个选择都有「可复制性」这个隐形约束。选 Unsplash 因为它免费可商用，选可商用字体同理。**一个好的 SOP，不只在教「怎么做」，还在帮执行者规避「不该踩的坑」。**

### 5.2 一堂可能使用的可商用字体（推测）

基于一堂公开设计物的视觉风格反推：

| 用途 | 推测字体 | 字体风格 | 为什么选它 |
|---|---|---|---|
| **主标题** | 思源黑体 Bold / 阿里巴巴普惠体 Bold | 现代、干净、有力 | 免费可商用、中文支持好、多字重可选 |
| **副标题** | 思源黑体 Regular / 阿里巴巴普惠体 Regular | 与主标题同系列，保持一致性 | 与主标题同家族，层级差异通过字重而非字体切换来实现 |
| **特殊强调** | 思源宋体 Bold（极少数场景） | 学术感、厚重感 | 方法论类课程的标题偶尔用宋体增加「严肃学术」的气质 |

### 5.3 标题层级的黄金法则

```
一堂选课卡片的三层标题体系（推测）：

第一层：课程系列标签（最小字）
  - 如「全员必修」「MBA专修」「探索营」
  - 字体大小：约 12-14pt
  - 作用：帮用户快速识别课程类型

第二层：课程主标题（最大字）
  - 如「重新理解科学决策」「人生红点探索营」
  - 字体大小：约 28-36pt（根据卡片尺寸调整）
  - 1-2 行，绝不超过 3 行
  - 作用：3 秒内让用户知道「这门课讲什么」

第三层：副标题/一句话价值主张（中等字）
  - 如「掌握十倍成功率提升的核心方法」
  - 字体大小：约 16-20pt
  - 只 1 行
  - 作用：告诉用户「学了这门课能得到什么」
```

## 六、步骤四：质量检查——审美门控清单

### 6.1 为什么 SOP 的最后一步是「人做质量检查」

这和 Truman 在 Skill 最佳实践案例里「每模块 2-5 轮不够好」的逻辑一致——**AI 或工具只能保证「下限」，人做最终审美判断才能逼近「上限」**。

### 6.2 一堂配图 SOP 的质量门控清单（推测复原）

| 检查项 | 判断标准 | 不通过时做什么 |
|---|---|---|
| **文字可读性** | 在任何光线条件下，标题都清晰可辨？蒙层是否够深？ | 加深蒙层透明度 |
| **字体统一** | 同一批卡片是否使用了相同的字体？没有混用？ | 替换为统一字体 |
| **标题层级** | 3 秒能分辨出「系列标签」「主标题」「副标题」的视觉层级？ | 调整字体大小或字重 |
| **标题长度** | 主标题在 1-2 行内？副标题在 1 行内？ | 精简标题文案 |
| **配色克制** | 除图片本身外，文字和装饰元素不超过 2 个颜色？ | 去掉多余的彩色元素 |
| **呼吸感** | 标题和卡片边缘之间有足够留白？文字不贴着边？ | 调整标题位置 |
| **图片关联** | 背景图和课程主题有抽象关联？不是随便一张漂亮图？ | 换图 |
| **与其他卡片的一致性** | 放在课表里，和相邻的选课卡片风格统一？不跳、不突兀？ | 检查蒙层深度和字体大小是否偏离规范 |

### 6.3 质量门控的「通过标准」

Truman 在「知识点卡片打磨 20+ 版本」案例中给出了设计的三个终极要求：

```
1. 能可视化——这张图要能做到逻辑可视化
2. 深度理解——这张图要能让用户深度理解
3. 落地应用——这张图要能让用户方便地落地应用
```

对应到选课卡片：

| 一堂终极要求 | 选课卡片的表现 |
|---|---|
| **可视化** | 用户 3 秒内被视觉吸引，愿意多看 3 秒 |
| **深度理解** | 标题+配图传达了「这是讲什么的课」 |
| **落地应用** | 用户看完卡片后产生了「我要选这门课」的冲动 |

## 七、工具链详解——为什么是 Sketch/PPT/Keynote 而非 Photoshop

### 7.1 「砍工具复杂度」是 SOP 设计的一部分

```
【已确认】工具选择：Sketch / PPT / Keynote
```

这是一个极其重要的架构决策：

| 如果选了 Photoshop | 如果选了 Sketch/PPT/Keynote |
|---|---|
| 需要专业设计师才能操作 | 会做 PPT 的人就能上手 |
| 学习曲线陡峭 | 学习曲线几乎为零 |
| 操作复杂——容易出错 | 操作简单——出错概率低 |
| 换人做需要重新培训 | 换人做，打开 PPT 模板就能开始 |
| 人才依赖度高 | 人才依赖度低——这是 SOP 的核心目标之一 |

### 7.2 三个工具的分工

| 工具 | 在一堂设计体系中的角色 | 适用场景 |
|---|---|---|
| **Sketch** | 主力设计工具——适合高频、高质量、需要模板化的设计输出 | 选课卡片、知识卡片、模型图的「标准版本」 |
| **PPT** | 轻量替代——适合非设计师同事的快速制作 | 内测课卡片、临时活动图、需要非设计师协作的场景 |
| **Keynote** | Mac 用户替代——和 PPT 同等定位 | 同上，Mac 生态 |

### 7.3 SOP 的「模板化」——为什么比工具选择更重要

```
SOP 的真正价值不在「用 Sketch 还是 PPT」，而在于：

已经预制好的模板文件：
  ├── 画板尺寸（如 1200×628px 或 1920×1080px）
  ├── 蒙层组件（已调好透明度，拖进来直接用）
  ├── 标题文本框（已设好字体、字号、颜色）
  ├── 系列标签（已设好位置和样式）
  └── 导出设置（已设好分辨率和格式）

新任务 = 打开模板 → 换背景图 → 改标题文字 → 导出
```

> 🔑 **L6 洞察**：SOP 的极致，不是「步骤写得细」，而是**把判断和操作都前置封装进模板**。操作者只需要做「替换内容」这一件事，审美基线已经嵌在模板里了。这和 Truman 在 Skill 案例里「系统提示词 + 数据资产包」的原子单元思维完全一致——**模板 = 配图原子单元，背景图和标题 = 可变参数**。

## 八、SOP 化基本功的四个要求在这个案例中的体现

马拉松大课中明确提出标准类工作 SOP 化的四项基本功要求：拆得细、写得细、执行到位、迭代检查。以下是它们在一堂配图 SOP 中的具体映射：

### 8.1 拆得细

| 拆解维度 | 对配图 SOP 的意义 |
|---|---|
| **步骤拆到原子级** | 不是「做一张选课卡片」→ 而是拆成：找素材 → 选图 → 建画板 → 拖入背景 → 加蒙层 → 调透明度 → 加标题 → 调字号 → 加标签 → 导出 → 检查 |
| **每个原子步骤可独立执行** | 换人做其中任何一步，不依赖前一步的「隐性知识」 |
| **工具和快捷键标清楚** | 不是「加一个蒙层」→ 而是「插入形状 → 矩形 → 填充纯黑 → 透明度 60% → 覆盖全画板」 |

### 8.2 写得细

| 写的维度 | 对配图 SOP 的意义 |
|---|---|
| **参数明确** | 蒙层色号、透明度百分比、字体名、字号、行距、画板尺寸——全部数字化，零模糊空间 |
| **正确和错误示范并列** | 不只是「标题要大」→ 而是「✅ 正确：36pt Bold，单行；❌ 错误：24pt Regular，强制折三行」 |
| **边界条件写清楚** | 「如果标题超过 15 个字怎么办？」「如果背景图本身就很暗怎么办？」——不留给执行者自己判断 |

### 8.3 执行到位

| 执行维度 | 对配图 SOP 的意义 |
|---|---|
| **不跳步** | 哪怕这节课很急、哪怕「看着还行」，质量门控清单里的每一项都必须打勾才能发布 |
| **不凭感觉** | 不是「我觉得蒙层差不多了」，而是「透明度 60%±5%，对照 checklist 通过」 |
| **执行记录留痕** | 每次制作的最终版本 + 使用的素材源 + 修改记录，存档在固定文件夹 |

### 8.4 迭代检查

| 迭代维度 | 对配图 SOP 的意义 |
|---|---|
| **定期回顾** | 每月看一遍最近做的 20 张选课卡片，有没有质量漂移？ |
| **SOP 本身也更新** | 发现更好的蒙层参数、更好的字体、更好的搜索关键词 → 更新 SOP，全员同步 |
| **错误复盘** | 如果有用户反馈「这张卡看不清标题」→ 不是改这一张，而是修 SOP 防止下次再出现 |

## 九、这个 SOP 与 Truman 知识卡片打磨案例的同构性

Truman 在「泛产品设计」课程中公开了「动力模型知识卡片」的迭代过程——3 个大版本，23 个小版本，48 小时连续打磨。虽然那个案例是「模型图设计」而非「配图」，但底层方法论完全一致：

### 9.1 同构对比

| 方法论要素 | 知识卡片打磨案例（Truman） | 配图 SOP（一堂内部） |
|---|---|---|
| **锁定目标** | 「能可视化 + 深度理解 + 落地应用」 | 「美观且契合课程主题」 |
| **工具链** | 不关键——重点是「谁在打磨」 | Sketch/PPT/Keynote——关键是「模板降低了操作门槛」 |
| **多轮迭代** | 3 大版本 + 23 小版本 | SOP 本身也在迭代——参数优化、模板升级 |
| **人守审美** | Truman 亲自守——「配得上在一堂的地位」 | 质量门控清单是人做最终判断——「这张图过不过」 |
| **模板化沉淀** | 最终版本成为后续课程可直接复用的资产 | 模板文件 = 所有人可复用的配图原子单元 |
| **拒绝将就** | 「放弃让大家背下来的想法，而是让大家能更好地理解」——核心决策 | 「不因为赶时间就跳过质量检查」——执行纪律 |

### 9.2 最关键的共性——「拒绝将就」的审美纪律

```
Truman 在知识卡片打磨中的关键决策：
  第一个版本已经「能用」了——能背下来，能表达内容。
  但 Truman 说：不够精准、没有达到审美的极限。
  于是推倒重来。

配图 SOP 的执行纪律：
  做出来的卡片「看着还行」不算通过。
  必须逐项打勾质量门控清单。
  「还行」不是标准——「稳定达标」才是。
```

> 🔑 **L6 洞察**：一堂设计物的高水准，不是靠「设计师有天赋」，而是靠**一套拒绝将就的 SOP 和审美纪律**。SOP 保证下限，纪律逼近上限。

## 十、可迁移的 L6 原则清单

### 10.1 不要做的事

| 错误 | 为什么不行 | 一堂的正确替代 |
|---|---|---|
| 每张图从零设计 | 质量不稳定、速度慢、换人做就变样 | 模板化——预制画板、蒙层、字体、布局 |
| 用有版权风险的图片/字体 | 法律风险 + 品牌风险 | Unsplash + 可商用字体——零风险 |
| 不加蒙层，文字直接放在复杂背景上 | 可读性极差——用户的视觉焦点会被背景抢走 | 全图黑色蒙层，透明度 50-70% |
| 「看着还行」就算通过 | 「还行」没有标准——下次可能「不行」 | 质量门控清单逐项打勾——有客观标准 |
| 做完不沉淀模板 | 下次从头来，永远在重复造轮子 | 每次做完更新模板，模板就是「最佳实践的固化」 |
| 工具选最专业的（Photoshop） | 抬高了操作门槛——只有设计师能做 | 工具选门槛最低的（PPT/Keynote）——会做 PPT 就能做配图 |
| SOP 写完就锁死不更新 | 设计趋势在变，旧参数会过时 | 定期回顾 + 发现更好的做法就迭代 SOP |

### 10.2 一定要做的事

| 原则 | 具体动作 | L6 标识 |
|---|---|---|
| **模板化封装** | 预制带蒙层、标题框、标签位的模板文件——操作者只需替换背景图和文字 | 原子单元思维——模板 = 配图的最小可复用单元 |
| **素材源标准化** | 固定 Unsplash 为唯一图源——不要「随便搜一下」，要「从标准库里选」 | 标准化 = 降低选图审美门槛 |
| **字体可商用化** | 固定 1-2 款可商用字体——不在字体选择上留自由度 | 自由度越低，出错概率越低 |
| **蒙层参数数字化** | 不是「加个深色蒙层」，而是「纯黑，透明度 60%±5%，全画板覆盖」 | 数字 = 无争议、可执行、可检查 |
| **质量门控清单化** | 7-8 个检查项，逐项打勾——每一项有明确的通过标准和 fail 动作 | 清单 = 把审美判断变成可执行动作 |
| **SOP 本身可迭代** | 定期回顾 + 发现更好的做法就更新 SOP——不是锁死，是持续进化 | SOP 是活的，不是死的 |
| **拆得细 × 写得细 × 执行到位 × 迭代检查** | 马拉松大课的四项基本功要求，每一项都能在配图 SOP 里找到具体落脚点 | 基本功训练不是口号，是落实到每个 SOP 里的动作 |

## 十一、L6 段位自检清单

逐条自检——以下任何一条做不到，你还没到这个案例的 L6：

- [ ] 我是否理解「配图 SOP」的本质不是「教你怎么做一张好看的图」，而是**把「好看」从个人天赋变成可复制、可执行、可检查的标准流程**？
- [ ] 我的团队里是否有任何「依赖某个人审美」的重复性工作——如果有，我能否把它像一堂配图 SOP 一样拆成「模板 + 质量门控清单」？
- [ ] 我能否为我的 SOP 设计一个「最低门槛工具链」——不是选最专业的工具，而是选团队里最多人会用的工具？
- [ ] 我能否做到「参数数字化」——蒙层透明度不是「深一点」，而是「60%±5%」？
- [ ] 我能否把 SOP 的质量门控设计成一张 checklist——每一项有明确的通过标准和 fail 动作——而不是「做完自己看着办」？
- [ ] 我能否识别 SOP 里哪些地方需要「迭代更新」——定期回顾、收集反馈、持续优化参数？
- [ ] 我能否说清「字体版权」「图片版权」在商业场景中的风险——并在 SOP 里从源头规避？
- [ ] 我能否在别人的 SOP 里看到「拆得细 × 写得细 × 执行到位 × 迭代检查」四项基本功的落实情况？

---

> **一句话总结**：一堂配图 SOP 的 L6 精髓，不是「他们用 Unsplash 和 Sketch 做图」。而是他们**把「配图」这个看起来依赖个人审美的工作，拆解成了一整套可复制、可检查、可迭代的工业流程**——固定唯一的免费图源（杜绝版权风险 + 统一审美基线）、数字化蒙层参数（纯黑 60%±5%，零模糊空间）、预制模板文件（操作者只需替换内容）、可商用字体库（固定 1-2 款，不在字体选择上留自由度）、质量门控 checklist（逐项打勾，不凭感觉通过）。做完一次后，模板就是「配图的原子单元」——换人做、批量做、赶时间做，产出都在一堂的审美底线之上。**这不是设计师的「作品」，这是组织的基本功——把「靠天赋」变成「靠流程」，把「一次性的好看」变成「可复用的稳定」。** 而这个 SOP 被标注为「中等」难度而非「简单」，说明哪怕到了工业化阶段，配图仍然需要操作者具备一定的审美判断力——SOP 托住下限，人的审美才能逼近上限。
