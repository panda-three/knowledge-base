#### 知识精讲
本节课复习循环基础，讲解了循环高级内容，包括无限循环的三种写法，重点分析了`break`关键字的使用规则，结合例题讲解了`break`在实际编程中的应用与常见易错点。

**循环基础回顾**
* **三种循环结构**：C语言提供三种循环写法，分别是`for`循环、`while`循环、`do while`循环。
* **执行流程差异**：
   - `for`循环和`while`循环都是**先判断条件，再执行循环体**；
   - `do while`循环是**先执行循环体，再判断条件**，因此循环体至少会执行1次。
   - 🚩重点：三种循环的执行顺序是本次考试常考点，需要重点区分`do while`和另外两种循环的差异。

**无限循环的三种写法**
* **for循环无限循环**：循环的初始化、条件判断、条件控制三个部分都省略不写，即`for(;;)`，代码会一直执行循环体。
* **while循环无限循环**：条件判断位置写恒为真的表达式，即`while(1)`，循环体一直执行。
* **do while循环无限循环**：同样在条件判断位置写`while(1)`，即：
  ```c
  do{
    // 循环体
  }while(1);
  ```
* 🚩重点：三种无限循环的写法必须记住，考试中常考填空题写出对应循环的无限循环格式。

**break关键字**
* **使用规则**：
  - 不能单独书写，只能存在于`switch`语句或者循环语句中；
  - 在`switch`中表示结束当前`switch`语句；
  - 在循环中表示**跳出/结束当前整个循环**，循环直接终止。
* 🚩考点：`break`不能用在`switch`和循环之外，这个是选择题常考的易错点。
* **应用场景：找第一个满足条件的数**
  - 题目要求：找出1～100中既能被3整除也能被5整除的第一个数。
  - 思路：遍历1～100，找到第一个满足条件的数后，用`break`直接跳出循环，不需要继续遍历剩下的数。
  - 🚩易错点：输出语句的位置必须放在`break`之前，且在满足条件的`if`判断内部。如果放在`break`之后，`break`跳出循环后不会执行输出；如果放在`if`外部，会输出满足条件之前所有不满足条件的数。

**break应用：程序阅读题分析**
* **题目代码（根据课堂描述整理）**：
```c
int S = 0;
int I = 1;
while(I <= 10)
{
    if(S >= 6)
        break;
    S = S + I;
    I++;
}
printf("%d", S);
```
* **分析思路**：
  1. 初始`S=0`，`I=1`，判断`I <= 10`成立，`S>=6`不成立，所以执行`S = 0+1=1`，`I++`变为2；
  2. 循环继续，`I=2 <= 10`成立，`S=1 >=6`不成立，执行`S=1+2=3`，`I++`变为3；
  3. 循环继续，`I=3 <=10`成立，`S=3 >=6`不成立，执行`S=3+3=6`，`I++`变为4；
  4. 循环继续，`I=4 <=10`成立，此时`S=6 >=6`成立，执行`break`跳出循环；
  5. 最终输出结果为`6`。
* **快速解题技巧**：先看懂代码整体功能，这段代码本质是求1～10的累加和，当累加和大于等于给定值时就跳出循环输出结果。因此不管阈值是多少，只需要从1开始累加，直到满足阈值就可以得到结果，不需要一步步逐行分析，节省时间。

**break应用：编程题实例**
* **题目要求**：求出200以内能被13整除的最大的数。
* **解题思路**：要找最大的数，应该从200开始**从后往前遍历**，找到第一个满足被13整除的数后，直接用`break`跳出循环，这个数就是最大的满足要求的数。
* **常见错误分析**：
  1. 忘记写循环条件控制语句：使用`while`循环时很容易漏写`i--`，这是非常常见的错误，`for`循环一般不容易漏；
  2. `i--`写在`if`判断内部：只有满足条件才会自减，会导致死循环，`i--`必须写在`if`外部，每一次循环都要执行；
  3. 输出位置错误：输出必须放在`break`之前，如果放在`break`之后，跳出循环后不会执行输出，得不到正确结果。
* **正确代码（课堂整理版）**：
```c
#include <stdio.h>
int main()
{
    int i = 200;
    while(i >= 1)
    {
        if(i % 13 == 0)
        {
            printf("%d", i);
            break;
        }
        i--; // 必须写在if外部
    }
    return 0;
}
```
