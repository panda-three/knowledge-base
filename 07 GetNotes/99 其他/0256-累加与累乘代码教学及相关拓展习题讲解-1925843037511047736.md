#### 知识精讲

本节课围绕C语言中“累加”与“累乘”两大基本代码模板展开，核心议题是如何以这两个模板为“母版”，通过局部修改（改运算符、改初值、改类型、改通项）解决阶乘求和、分数序列求和、幂次方求和等变式问题，并重点强调了整数除法陷阱与变量类型联动修改的细节。

**累加基本模板（1～n求和）**
* **输入与循环框架**：先输入上限 `n`（`scanf("%d",&n)`），再定义循环变量 `i`，`for(i=1;i<=n;i++)`。
* **累加器定义**：在循环外定义 `sum=0`，循环体内执行 `sum=sum+i`。
   - 🚩重点：输出语句 `printf` 必须放在循环**外面**，否则会打印每一次中间结果。
   - *代码*：
```c
int n, i, sum = 0;
scanf("%d", &n);
for(i = 1; i <= n; i++)
    sum = sum + i;
printf("%d", sum);
```

**累乘基本模板（求n的阶乘）**
* **与累加模板的差异**：仅两处改动——累乘变量初值由 `0` 改为 `1`，循环体内 `+` 改为 `*`。
* **累乘器定义**：一般命名为 `mul`，初值为 `1`，循环体内 `mul=mul*i`。
   - 🚩重点：累乘变量初值必须是 **1**，若写成 0 则结果恒为 0。
   - *代码*：
```c
int n, i, mul = 1;
scanf("%d", &n);
for(i = 1; i <= n; i++)
    mul = mul * i;
printf("%d", mul);
```

**变式一：分数累加（1 + 1/2 + 1/3 + … + 1/n）**
* **思路**：逻辑仍是累加，只是把通项 `i` 换成 `1/i`。
* **整数除法陷阱**：若直接写 `1/i`，由于整数与整数运算结果仍为整数，`1/2` 得 0，最终 `sum` 恒为 1。
   - 🚩重点：必须写成 `1.0/i` 强制产生浮点运算。
   - 🚩重点：**牵一发而动全身**——通项变为小数后，存放通项的变量 `t` 与累加器 `sum` 都必须定义为 `float` 或 `double`，否则小数部分被截断。
   - *代码*：
```c
int n, i;
double t, sum = 0;
scanf("%d", &n);
for(i = 1; i <= n; i++){
    t = 1.0 / i;
    sum = sum + t;
}
printf("%f", sum);
```

**变式二：阶乘求和（1! + 2! + … + 5!）的简便写法**
* **核心洞察**：在同一个循环中，`mul` 每轮累乘后的值恰好依次是 1!、2!、3!……，因此无需双重循环，直接在循环体内把 `mul` 累加到 `sum` 即可。
* **执行过程**：i=1 时 mul=1（1!）；i=2 时 mul=2（2!）；i=3 时 mul=6（3!）……每轮把当前 mul 加入 sum。
   - 🚩重点：这是“通用方法”之外的简便写法，但通用性较弱；遇到课后练第1题这类变式时可能失效，需回退到上周讲的通用方法。
   - *代码*：
```c
int i, mul = 1, sum = 0;
for(i = 1; i <= 5; i++){
    mul = mul * i;
    sum = sum + mul;
}
printf("%d", sum);
```

**变式三：阶乘倒数求和（1/1! + 1/2! + … + 1/n!）**
* **思路**：在变式二基础上，把累加项由 `mul` 改为 `1.0/mul`。
* **类型联动**：因出现 `1.0/mul`，`sum` 必须改为 `double`（`mul` 本身仍可为 `int`）。
   - 🚩重点：再次体现“改一处、连带改类型”的规律。
   - *代码*：
```c
int n, i, mul = 1;
double sum = 0;
scanf("%d", &n);
for(i = 1; i <= n; i++){
    mul = mul * i;
    sum = sum + 1.0 / mul;
}
printf("%f", sum);
```

**变式四：幂次方求和（x + x² + x³ + … 型，第5题）**
* **核心洞察**：`x` 的 `k` 次方本质也是累乘，只是每次乘的数是固定的 `x` 而非变化的 `i`；阶乘是“每次乘不同的数”，幂是“每次乘同一个数”。
* **实现**：用两个累乘变量，一个算分母（阶乘 `mul`），一个算分子（幂 `b`，初值 `1.0`，每轮 `b=b*x`），最后 `s = s + b/mul`。
   - 🚩重点：分子 `b` 定义为 `1.0` 后必须声明为 `float`/`double`，否则类型不匹配报错（板演同学正是在此出错）。
   - 🚩重点：`x` 与 `n` 都是需要人工输入的变量。
   - *代码*：
```c
int n, i, mul = 1;
double x, b = 1.0, s = 0;
scanf("%lf%d", &x, &n);
for(i = 1; i <= n; i++){
    mul = mul * i;
    b = b * x;
    s = s + b / mul;
}
printf("%f", s);
```

### 🖍️ 重点速览

#### 🚩 考点重点
- [00:13:16](https://getnotes.seek:796) **整数除法陷阱**：整数与整数相除结果仍为整数，`1/2` 得 0。求分数序列时必须写 `1.0/i` 或 `(float)1/i`。这是本题型最核心的易错点，考试常以“结果为什么恒为1”的形式考查。
- [00:14:48](https://getnotes.seek:888) **类型联动修改（牵一发而动全身）**：一旦通项变为小数，存放通项的变量和累加器 `sum` 都必须改为 `float`/`double`，否则小数被截断。
- [00:04:52](https://getnotes.seek:292) **累乘初值必须为 1**：累加初值为 0，累乘初值为 1，写反则结果错误。
- [00:04:12](https://getnotes.seek:252) **输出语句位置**：`printf` 必须放在循环体外，否则输出每次中间结果。
- [00:37:34](https://getnotes.seek:2254) **幂运算即累乘**：x 的 k 次方 = 循环 k 次、每次乘 x；与阶乘的区别仅在于“每次乘的数是否变化”。
- [00:44:22](https://getnotes.seek:2662) **考试高频提示**：老师明确“这里的题目考试经常考”，累加/累乘及其全部变式为必考题型。
- [00:28:53](https://getnotes.seek:1733) **通用方法与简便方法的取舍**：简便写法（单循环内先乘后加）适用于阶乘求和，但遇到课后练第1题等变式可能失效，需用上周讲的通用方法。

#### 💡 核心概念
- **累加模板**：`sum=0; for(i=1;i<=n;i++) sum=sum+i;`
- **累乘模板**：`mul=1; for(i=1;i<=n;i++) mul=mul*i;`
- **阶乘求和简便式**：`for(i=1;i<=5;i++){ mul=mul*i; sum=sum+mul; }`
- **分数累加通项**：`t = 1.0 / i;`（`t`、`sum` 均为浮点型）
- **幂次方累乘**：`b=1.0; for(...) b=b*x;`（`b` 为浮点型）
- **整数除法规则**：整数 / 整数 = 整数（向零截断）
