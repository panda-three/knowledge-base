#### 知识精讲

本节课围绕“递推法”展开，以斐波那契数列、三项递推数列和分数数列求和三个典型例题为载体，讲解如何从数列规律中提炼“前若干项如何滚动更新”的递推关系，并将其转化为循环结构的C语言代码，核心是变量更新顺序与临时变量的使用。

**递推法的基本思想**
* **概念**：递推是指从已知的初始项出发，利用相邻项之间的固定关系，逐步推出后续每一项的方法，即“不停地推”。后一个数的大小取决于前面的数。
* **解题关键**：先找出数列的规律（尤其是前几项如何向后“滚动”），再把这种滚动规律翻译成变量赋值语句，最后套入循环。

**例1：斐波那契数列（求前20项）**
* **数列规律**：前两个数均为1，从第3个数开始，每个数等于前两个数之和。即 $F_n = F_{n-1} + F_{n-2}$（$n \geq 3$），数列为 1, 1, 2, 3, 5, 8, 13, 21…
* **前两项无规律，需单独处理**：因为前两个数没有递推规律，必须先单独定义并输出，再从第3个数开始循环。
* **变量滚动规律**：设前两个数分别为 F1、F2，则下一次的 F1 等于上一次的 F2，下一次的 F2 等于上一次的 F1+F2（即刚算出的 F3）。
   - 🚩重点：**重点就是这两句代码**——F1 = F2; F2 = F3;（即前两个数的滚动更新），老师明确要求必须发现并掌握这个变化规律。
* *代码*：
```c
int F1 = 1, F2 = 1, F3;
printf("%d\t%d\t", F1, F2);   // 先单独输出前两个数
for (int i = 1; i <= 18; i++) {  // 还剩18个数
    F3 = F1 + F2;              // 当前数 = 前两数之和
    printf("%d\t", F3);
    F1 = F2;                   // 滚动：F1 取上一次的 F2
    F2 = F3;                   // 滚动：F2 取刚算出的 F3
}
```
* *补充说明*：老师带值演示——i=1 时 F3=1+1=2 并输出；随后 F1=1、F2=2；i=2 时 F3=1+2=3 输出；再滚动为 F1=2、F2=3，依此类推，体现“F1、F2 一直在变”的递推思想。

**例2：三项递推数列（54页第1题，求前20项）**
* **数列规律**：前三个数为 0, 1, 1，从第4个数开始，每个数等于前三个数之和。数列为 0, 1, 1, 2, 4, 7, 11…
* **与例1的区别**：例1前2个数无规律，本题前3个数无规律，因此需要多定义一个变量 F4，并单独输出前三个数。
* **循环次数**：共20个数，已输出3个，循环次数改为 17。
* **变量滚动规律**：下一次的 F1 = 上一次的 F2，下一次的 F2 = 上一次的 F3，下一次的 F3 = 上一次的 F4（即刚算出的三数之和）。
   - 🚩重点：本题的易错点在于**规律找错**——老师点评学生板书时指出，滚动必须是 F1=F2、F2=F3、F3=F4，不能写成 F3=F4 之外的多余赋值或错位赋值。
* *代码*：
```c
int F1 = 0, F2 = 1, F3 = 1, F4;
printf("%d\t%d\t%d\t", F1, F2, F3);  // 先单独输出前三个数
for (int i = 1; i <= 17; i++) {      // 还剩17个数
    F4 = F1 + F2 + F3;               // 当前数 = 前三数之和
    printf("%d\t", F4);
    F1 = F2;
    F2 = F3;
    F3 = F4;
}
```

**例3：分数数列求和（53页第2题，求前10项及总和）**
* **数列规律**：数列为 $\frac{1}{2}, \frac{2}{3}, \frac{3}{5}, \frac{5}{8}, \frac{8}{13}\cdots$，下一个数的分子等于上一个数的分母，下一个数的分母等于上一个数的分子与分母之和。
* **分子分母必须拆开看**：老师强调不能把分数合在一起找规律，必须把分子、分母分别用两个变量表示才能发现规律。
* **变量类型必须用浮点型**：若分子分母都定义为整型，整数除以整数结果会变成0，因此 A、B、C 均定义为 float（老师课上纠正为 float 类型）。
* **临时变量 t 的必要性**：若先执行 A = B，则 A 的原值被覆盖，再算 A+B 就错了。因此必须先用临时变量 t 保存 A+B 的值，再更新 A 和 B。
   - 🚩重点：**错就错在这个地方**——老师带值演示时指出，第一步若先改 A 的值，后续分母计算就会出错，必须引入临时变量 t 提前保存 A+B。
* *代码*：
```c
float A = 1, B = 2, C, t, sum = 0;
for (int i = 1; i <= 10; i++) {
    C = A / B;          // 当前项 = 分子 / 分母
    printf("%.2f\t", C); // 保留两位小数输出
    sum = sum + C;       // 累加求和
    t = A + B;           // 先用临时变量保存分子分母之和
    A = B;               // 下一个分子 = 上一个分母
    B = t;               // 下一个分母 = 上一个分子分母之和
}
printf("sum = %.2f\n", sum);  // 循环外输出总和
```
* *补充说明*：求和只需在循环前定义 sum=0，循环内累加 C，循环结束后在循环外统一打印 sum；本题既要求输出每个数，也要求输出最后的和。

**递推法小结**
* **本质**：后一个数的大小取决于前面的数，通过不停推理找到后面的数；代码中体现为 F1、F2（或 A、B）等变量在每次循环中不断滚动更新。

#### 💡 核心概念
- **递推法**：从已知初始项出发，利用相邻项之间的固定关系逐步推出后续各项的方法，即后一个数取决于前面的数。
- **斐波那契数列**：$F_1=F_2=1$，$F_n=F_{n-1}+F_{n-2}$（$n\geq3$）。
- **三项递推数列**：前3项为 0、1、1，$F_n=F_{n-1}+F_{n-2}+F_{n-3}$（$n\geq4$）。
- **分数数列**：$\frac{1}{2},\frac{2}{3},\frac{3}{5},\frac{5}{8},\frac{8}{13}\cdots$，下一项分子=上一项分母，下一项分母=上一项分子+分母。
- **变量滚动更新**：`F1 = F2; F2 = F3;`（两项递推）与 `F1 = F2; F2 = F3; F3 = F4;`（三项递推）。
