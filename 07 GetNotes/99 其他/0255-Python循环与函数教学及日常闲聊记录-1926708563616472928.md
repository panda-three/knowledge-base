#### 知识精讲

本节课围绕“循环”与“函数”两大核心概念展开，旨在讲清二者分别解决“重复做的事”与“重复写的代码”这一本质区别，并通过动画演示、代码填空与课后习题精讲，训练学生读懂循环执行流程、掌握`for`/`while`/`range`/`def`的识别与嵌套循环的分析方法。

**循环与函数的本质区别**
* **循环**：解决“重复去做某件事”的问题，如每天起床刷牙、跑操转圈。程序中的循环就是让某段代码反复执行。
* **函数**：解决“重复的代码”问题，把反复出现的代码打包成一个工具，通过调用函数名来复用，避免重复书写。老师以“榨汁机”和“求X的平方”作类比说明函数的打包复用特性。
   - 🚩重点：看到`for`和`while`就想到循环；看到`def`就想到函数。

**`for`循环与`range`函数**
* **`for`循环基本形式**：`for name in ["小明","小红","小刚"]:`，依次从列表中取出元素并执行循环体，取完即结束。老师用点名动画演示了“取第一个→打印→回到循环头→取下一个→……”的完整执行流程。
* **`range`函数**：表示范围，功能是“让电脑帮你数数”。
   - *代码*：`for i in range(1, 6):` 配合 `print("第%d遍" % i)`
   - 🚩重点：`range(1, 6)` 取值为 1、2、3、4、5，**包左不包右**，数到5就停，取不到6。用数学区间表示即 $[1, 6)$。
   - *补充说明*：老师强调考试不会让大家写代码，但**必须能看懂**，看到`range`只需关注后面的两个数字，它表示一个范围。
   - 变式：`range(2, 7)` 取 2、3、4、5、6，取不到7。

**`while`循环**
* **`while`循环基本形式**：`n = 1` 配合 `while n <= 5:`，同样表示循环。老师用红绿灯倒计时动画演示：每等一秒执行一次，n 从1递增到5后变绿灯结束。
* **`while`与`range`的等价关系**：`n = 1; while n <= 5:` 与 `range(1, 6)` 表示同样的意思，只是写法不同。n 能取 1、2、3、4、5，效果一致。
   - 🚩重点：只要看到`for`或`while`，都表示循环，即“一直在重复做，直到它停”。

**函数的定义与调用**
* **函数定义**：用`def`关键字定义函数，函数名由自己命名（如`say_hello`）。把重复的“你好”等代码写死在函数体内，只需写一遍。
   - *代码*：`def say_hello():` 函数体内写打印语句，下方通过 `say_hello()` 反复调用。
* **函数调用**：定义后可在下方多次调用，每次调用只需传名字即可，无需重复写`printf("你好，小明")`之类的完整语句。
   - 🚩重点：`def`定义函数时，第一行末尾的**冒号不能省**；函数体第二行前面的**缩进空格也不能省**。

**循环底层执行流程（理解性内容）**
* **底层通信机制**：程序并非简单地“重复两句代码”，底层实际经历：执行开始指令→询问“还有元素吗”→有则取出当前元素I→打印I→再次询问→……→元素取空则结束。老师强调此过程不细讲，仅作理解。

**课后习题精讲：图形打印与嵌套循环分析**
* **50页第1题（4行6列数字阵）**：外层循环 `for(i=1;i<=4;i++)`，内层循环 `for(j=1;j<=6;j++)`。每行输出1～6，恰好等于内层变量 j 的值，故把原来输出星号改为输出 j。
   - 🚩重点：输出变量**必须使用占位符**（如`%d`），不能直接写变量名；换行语句在内层循环结束后执行，若内层循环省略大括号则换行紧随其后。
* **50页第2题（对称字母图形 A/AB/ABC…）**：对称类问题外层循环变量取对称值，7行对应 i 从 -3 到 3。每行星号个数为 `4 - abs(i)`（abs为绝对值）。输出字母时从 `'A'` 开始递增，用 `65 + j` 或 `'A' + j` 表示。
   - 🚩重点：内层循环条件若写成 `j <= 4-abs(i)` 会多执行一次，应改为 `j < 4-abs(i)`（去掉等于号）；外层循环的**大括号不能省**，否则换行会在整个循环结束后才执行一次。
   - 变式提醒：若 j 从1开始，则条件加等号、输出改为 `65+j-1`，逻辑一致。
* **50页第3题（数字金字塔 1/121/12321…）**：外层4行；先输出空格，空格数满足 `i + j = 4`，即 `j <= 4-i`；再输出数字，每行个数为 `2*i-1`。
   - 🚩重点：直接输出 `2*i-1` 会导致每行全是同一个数（如第二行输出333），必须用 `if` 判断：当 `k <= i` 时输出 k，否则输出 `2*i-k`，从而得到 1/121/12321 的对称效果。
* **50页第4题（倒三角星号 4/3/2/1颗）**：外层 `i=1..4`，内层星号个数与行号之和为5，故 `j <= 5-i`（若 j 从0开始则 `j < 4-i`）。再将星号改为递增数字1～10，需在循环外定义 `m=1`，输出时用 `m++` 实现每执行一次自增1。
   - 🚩重点：`m` 的初始值1不能漏，否则最终结果会少1。
* **48页第2题（三重嵌套循环变量统计）**：外层 i 取1、2、3；j 随 i 取1～i；k 随 j 取 j～3。分别统计 A、B、M 的累加结果。
   - A 的计算：`i += i` 在内层执行，i 先被重置为0，第三次时 i=3，该句执行3次，故 A = 0 + 3×3 = 9。
   - B 的计算：`b += 2` 随外层 i 执行3次，B = 0 + 3×2 = 6。
   - M 的计算：`m += 1` 的执行次数等于 k 取值总个数，即 (3+2+1)+(2+1)+1 = 10，加上初始值1，M = 1 + 10 = 11（老师口算给出15，按板书逻辑应为初始值1加各轮次数）。
   - 🚩重点：此类题必须注意变量的**初始值**（如 m=1），很多同学因漏看初始值导致答案错误；判断某句代码执行几次，要看其所在循环的变量能取几个值。

#### 💡 核心概念
- **循环**：重复去做某件事，程序中表现为某段代码反复执行。
- **函数**：把重复的代码打包成一个工具，通过函数名调用复用。
- **`for`循环**：`for name in 列表:` 依次取元素执行循环体。
- **`range`函数**：`range(a, b)` 表示范围 $[a, b)$，包左不包右。
- **`while`循环**：`while 条件:` 条件成立时反复执行，直到条件不成立。
- **函数定义**：`def 函数名():` 后接缩进的函数体。
- **绝对值函数**：`abs(i)`，正数取本身，负数取相反数。
- **ASCII码**：字符`'A'`等价于65，`'A'+j`可依次得到B、C等。
