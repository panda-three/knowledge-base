* **键盘符号操作技巧**：井号、分号等编程专用符号，必须在英文模式下敲击对应按键，若按键输出异常，优先使用Shift组合键切换输出。

**while循环基础代码逐行解析**
* **变量初始化**：`S = 0` 等同于数学中的未知数赋值，定义变量S并将初始值设为0。
* **while关键字含义**：while在英文中翻译为“当……的时候”，是循环结构的核心标识。
   - 🚩重点：小高考不会要求手写代码，只需要能看懂代码的执行逻辑即可。
* **循环条件与执行逻辑**：`while S <= 30:` 表示当S满足小于等于30的条件时，持续执行冒号后的代码块。
* **循环体语句**：`S = S + 10` 表示将S当前的值加10后重新赋值给S，`print(S)` 表示在控制台打印输出S的当前值。
* **完整执行流程**：初始S=0，满足条件后S变为10并打印；S=10仍满足条件，S变为20并打印；S=20满足条件，S变为30并打印；S=30满足条件，S变为40并打印，最终输出10、20、30、40。

**输出1到100连续整数的代码改造**
* **参数调整思路**：将循环条件中的30改为99，同时将每次累加的步长从10改为1。
   - 🚩重点：如果直接将条件改为`S <= 100`，最终会多输出一个101，去掉条件中的等于号改为`S < 100`也可以实现正确效果。
* **改造后效果**：程序会依次输出1、2、3……直到100，刚好覆盖1到100的所有整数。

**输出1到99奇数的代码改造**
* **初始错误排查**：直接将步长改为2时，初始S=0会先执行S=0+2得到3，导致第一个输出值是3，漏掉数字1。
* **正确改造方案**：将变量S的初始值从0改为-1，步长保持为2，第一次循环时S=-1+2得到1，后续依次输出3、5……直到99。
   - 🚩重点：循环体中先执行累加再打印的顺序，决定了初始值的设置逻辑，要根据输出首项反推初始值。

**输出5的倍数序列的代码改造**
* **步长设置规律**：相邻两个输出数的差值就是循环的步长，5和10的差值为5，所以将步长设置为5。
* **初始值调整**：将S的初始值设置为-5，第一次循环时S=-5+5得到5，后续依次输出10、15……所有5的倍数。
   - 🚩重点：等差数列输出的通用规律：步长等于数列相邻两项的差值，初始值等于首项减去步长。

**1到100累加求和的代码实现**
* **累加变量定义**：新增变量Y并初始化为0，用来存储累加的总和。
* **累加逻辑编写**：在循环体中添加语句`Y = Y + S`，每次循环都将当前S的值加到Y上。
* **输出结果调整**：将最后的打印语句从打印S改为打印Y，最终运行结果为5050。
* **数学公式验证**：使用等差数列求和公式验证：
   $$ \text{总和} = \frac{(首项+尾项) \times 项数}{2} = \frac{(1+100) \times 100}{2} = 5050 $$

**奇数求和的快速改造**
* **复用已有逻辑**：在1到100求和代码的基础上，将步长改为2，调整初始值保证输出1、3、5……99，即可直接实现奇数序列的累加求和。

### 🖍️ 重点速览

#### 🚩 考点重点
- [00:07:49](https://getnotes.seek:469) **小高考考核要求**：高二信息技术小高考不会要求手写代码，只需要能看懂循环代码的执行逻辑即可，这是备考的核心方向。
- [00:15:07](https://getnotes.seek:907) **循环边界易错点**：当循环条件设置为`S <= 100`时，最终会多输出一个101，正确的写法是改为`S < 100`，这是选择题高频易错考点。
- [00:22:39](https://getnotes.seek:1359) **等差数列输出规律**：循环步长等于数列相邻两项的差值，初始值等于首项减去步长，这个规律是所有等差数列输出题目的通用解题思路。
- [00:27:02](https://getnotes.seek:1622) **累加求和公式**：等差数列求和公式为`(首项+尾项)×项数/2`，1到100的和为5050，是编程题和数学题的常考结果。

#### 💡 核心概念
- **循环**：重复执行指定代码块的程序结构，while循环通过条件判断控制重复执行的次数。
- **变量赋值**：`S = S + 1` 是编程中特有的赋值语句，将S当前的值加1后重新赋值给S，和数学中的等式含义不同。
- **while循环基础结构**：
```python
S = 0
while S <= 30:
    S = S + 10
    print(S)
```
- **1到100累加求和核心代码**：
```python
S = 0
Y = 0
while S < 100:
    S = S + 1
    Y = Y + S
print(Y)
```
- **等差数列求和公式**：
$$ \text{总和} = \frac{(首项+尾项) \times 项数}{2} $$
