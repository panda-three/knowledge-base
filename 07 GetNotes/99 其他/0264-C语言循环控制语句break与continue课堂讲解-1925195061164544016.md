#### 知识精讲
本节课讲解了C语言中`continue`语句的基本概念，对比了它和`break`语句的功能差异，并结合习题分析了混合使用`break`、`continue`、`switch`和循环时的执行流程，强调了两者的区别是考点。

**continue语句的基本概念**
* **continue的功能与使用限制**：表示跳过本次循环，继续下一次循环，仅能出现在循环结构中。对比`break`语句：`break`既可以用在循环中，也可以用在`switch`语句中，功能是跳出并结束当前整个循环，执行循环外的代码。
   - 🚩重点：`continue`和`break`的功能差异是**必考内容**，核心区别是：`break`结束整个循环，`continue`只结束本次循环，不影响后续循环执行。
* **执行流程示例**：对`for(i=1;i<=5;i++)`，当`i==3`时执行`continue`，执行流程为：
  1. `i=1`和`i=2`时，条件不满足，正常输出`i`，然后执行`i++`
  2. `i=3`时，条件满足，执行`continue`，跳过本次循环后续的输出语句，直接执行`i++`，因此3不会被输出
  3. `i=4`和`i=5`正常输出，最终结果为输出1、2、4、5，跳过了3
* **常见易错点**：输出语句的位置错误会导致逻辑错误：如果将输出语句放在判断`continue`的`if`块内，最终会只输出满足条件（需要跳过）的数，和需求相反。

**基础编程习题分析**
* **习题1：输出1～20中所有非3的倍数**
  * 解题思路：遍历1到20，判断如果是3的倍数，执行`continue`跳过，否则输出。
  * 代码框架：
```c
for(int i = 1; i <= 20; i++){
    if(i % 3 == 0){
        continue;
    }
    printf("%d ", i);
}
```
  * 🚩重点：`if`后大括号不要省略，输出语句必须放在`if`外面，不能放在`if`里面，否则只会输出3的倍数，逻辑错误。
* **习题2：输出1～50中所有个位不是4的数**
  * 解题思路：遍历1到50，通过`i%10 == 4`判断个位是否为4，如果是则执行`continue`跳过，否则输出。
  * 代码框架：
```c
for(int i = 1; i <= 50; i++){
    if(i % 10 == 4){
        continue;
    }
    printf("%d ", i);
}
```
  * 🚩重点：输出语句不能放在`continue`判断之前，否则无论是否满足条件都会先输出，`continue`不会起到跳过作用，逻辑错误。

**程序分析题：求1～10奇数和**
* **代码功能分析**：
```c
int i, s = 0;
for(i = 1; i <= 10; i++){
    if(i % 2 == 0){
        continue;
    }
    s += i;
}
```
  * 执行逻辑：遍历1～10，如果是偶数，执行`continue`跳过累加，只有奇数会执行累加，因此最终结果为1～10内所有奇数的和，即`1+3+5+7+9 = 25`。
  * 拓展修改：如果要求1～10内偶数和，只需要将判断条件修改为`if(i%2 == 1)`，跳过奇数即可。

**混合程序分析题：break与continue混合逻辑**
* **代码逻辑简化**：
```c
int A, B;
for(A = 1, B = 1; A <= 50; A++){
    if(B >= 20){
        break;
    }
    if(B % 3 == 1){
        continue;
    }
    B -= 3;
}
printf("%d", A);
```
* **结果分析**：初始B=1，第一次循环`B%3==1`成立，执行`continue`，不执行`B-=3`，A自增到2；第二次循环B仍为1，同样满足条件，以此类推，所有循环中B始终等于1，永远不会满足`B>=20`，也不会执行`B-=3`，循环会一直执行到`A=51`时条件`A<=50`不满足才结束，因此最终输出A的值为**51**。
  * 🚩重点：做程序分析题要灵活，不需要一步步执行完所有循环，从逻辑上推导最终结果即可。

**综合题：break、continue、switch、do-while混合分析**
* **题目代码（根据课堂描述整理）**：
```c
int i = 10;
do{
    switch(i % 2){
        case 0: continue;
        case 1: break;
    }
    i = i - 2;
    printf("i=%d\n", i);
}while(i > 0);
```
* **执行流程分步分析**：
  1. 初始`i=10`，进入循环，`i%2=0`匹配case0，执行`continue`：跳过本次循环后续的`i=i-2`和输出，直接进入下一次循环，`i`自减（根据do-while逻辑回到循环开头，此时`i`先减1变为9）
  2. `i=9`，`i%2=1`匹配case1，执行`break`：仅结束`switch`，继续执行后续代码，`i = 9 - 2 = 6`，输出`i=6`，判断`i>0`成立，进入下一次循环
  3. `i=6`，进入循环后`i`先减1变为5，`i%2=1`匹配case1，执行`break`结束switch，`i=5-2=2`，输出`i=2`，判断`i>0`成立，进入下一次循环
  4. `i=2`，进入循环后`i`先减1变为1，`i%2=1`匹配case1，执行`break`结束switch，`i=1-2=-2`，输出`i=-2`，判断`i>0`不成立，循环结束
* 🚩重点：`break`的作用范围由它所在位置决定：放在`switch`中只结束`switch`，不结束外层循环；只有放在循环中才会结束当前整个循环。
* 最终输出结果：
  ```
  i=6
  i=2
  i=-2
  ```

#### 💡 核心概念
- **break语句**：可以用在循环和switch语句中，功能是结束当前所在的整个结构，跳出到结构外执行后续代码。
- **continue语句**：只能用在循环语句中，功能是跳过本次循环中continue之后的所有代码，直接进入下一次循环，不结束整个循环。
