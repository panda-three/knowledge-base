#### 知识精讲
本次课程为AI产品开发实操课，讲解Work Buddy AI工具的核心功能与使用方法，演示了从零开发微信小程序的完整流程，同时介绍了内容生产流程搭建与个人知识库搭建的后续计划。

**Work Buddy AI工具基础使用**
* **核心收费规则**：新用户注册登录赠送500免费积分，不同模型标注的数字为每轮积分消耗量，数字越大消耗越多；**新用户每日可领取100积分**，可设置定时任务自动领取。
   - 免费模型：标注0.00X的模型可免费使用，无需消耗积分。
* **核心功能讲解**：
   1. **添加文件**：支持上传Word、PPT等任意格式文件，可让AI直接处理用户本地工作文件。
   2. **运行模式**：分为问答模式和计划模式：问答模式会直接完成用户需求；计划模式仅输出任务执行计划，不直接完成任务，可先修改计划后再执行，效果更好。
   3. **专家功能**：每个专家针对特定领域训练了专属数据，点击召唤后即可在对应领域获得更精准的输出效果，例如微信小程序开发者、创业导师等。
   4. **专家团模式**：模拟企业开发流程，由多个不同职能专家组合完成任务：交付总监先分析需求，再分发给对应开发专家执行，功能强大适合完整项目开发。
   5. **技能功能**：将固定操作固化为技能，安装后无需重复写提示词，直接输入需求主题即可完成任务，例如PPT制作技能。
   6. **连接器功能**：可打通飞书、企业微信、腾讯会议等第三方工具，让AI直接操作第三方工具完成任务，例如自动创建飞书文档、给联系人发消息。
* **微信助理配置**：
   操作步骤：进入个人账号设置 → 找到助理设置入口 → 选择微信助理 → 点击连接/配置 → 扫码绑定微信 → 绑定后可直接在微信发消息给AI，AI会在电脑端自动完成任务，支持远程操作。
* **资料库功能**：提供线上云端存储空间，AI生成的所有内容都会自动保存在资料库中，支持检索；也可以导入公众号链接，AI会自动解析内容生成结构化文档保存；支持团队空间，可供团队成员共享文档，方便协作。
* **定时任务功能**：支持设置固定时间自动执行任务，例如设置每日9点自动搜集微信公众号AI相关信息，整理后发送给用户；也可设置每日自动领取积分，避免遗忘。
🚩重点：工具使用核心结论：专家和技能功能是和日常使用最相关的核心功能，建议优先体验。

**微信小程序全流程开发（功德木鱼案例）**
* **前期准备**：开发小程序需要准备3样工具：微信小程序账号+微信开发者工具+Work Buddy/豆包AI。
* **小程序账号注册步骤**：
   1. 准备材料：未绑定过微信公众平台（公众号、小程序、企业微信）的邮箱、身份证号码、手机号、绑定银行卡的个人微信用于实名认证。
   2. 打开微信开发者平台，点击「小程序」入口，填写邮箱地址，接收并填写验证码，点击激活邮件内的链接完成激活。
   3. 选择主体类型：
      - 个人：无需营业执照，免费注册，**不需要每年缴纳300元认证费**；但个人主体无法获取用户手机号，部分行业类目无法开通，个人目前可开通微信支付功能。
      - 个体工商户：需要营业执照。
      - 企业：需要营业执照+对公账户，每年需要缴纳300元认证费，可开通所有能力，可获取用户信息。
   4. 主体信息确认提交后，填写小程序基础信息：包括名称、头像、功能介绍，🚩重点：**小程序名称一年只能修改3次，头像和介绍可多次修改，因此确定名称后再填写**，没想好可先不填。
   5. 补充小程序类目：需要选择对应类目才能通过微信官方审核，🚩重点：新手做工具类小程序选择「工具-信息查询」类目，审核通过率极高；医疗、金融、电商等敏感类目审核严格，个人主体无法开通。
   6. 获取APP ID：注册完成后，进入「管理-开发管理」，获取小程序唯一标识APP ID，开发时需要填入，同时生成密钥，**密钥不可泄露给他人**。
* **开发流程实操**：
   1. 下载安装微信开发者工具：根据自己的操作系统（Windows/Mac）下载对应版本，一路下一步安装即可。
   2. AI生成代码：将提前写好的需求提示词发送给Work Buddy或豆包，指定本地项目文件夹，AI会在约10分钟内生成完整的小程序代码，本次案例为**功德木鱼小程序**。
   3. 导入项目：打开微信开发者工具，点击「导入项目」，填入获取到的APP ID，选择AI生成的代码解压后的文件夹，点击创建即可看到小程序效果。
   4. 预览体验：导入后可生成预览二维码，用微信扫码即可在手机端体验自己开发的小程序。

[00:20:39](https://getnotes.seek:1239) **Work Buddy四大核心概念讲解**
梳理四大核心概念的区别：
1. 技能：只干单一特定任务，例如HR筛简历技能，只负责过滤不符合要求的简历。
2. 专家：负责一整个完整流程，例如HR专家可以负责从筛简历、面试审核到通知全流程。
3. 专家团：多个不同职能专家组成团队，模拟真实公司工作流程，例如开发游戏时，交付总监先分析需求，再分发给对应开发专家完成开发。
4. 连接器：对接外部第三方工具，实现AI操作外部工具。

[00:33:14](https://getnotes.seek:1994) **小程序注册详细步骤讲解**
1. 准备材料：需要一个未绑定过微信公众平台的邮箱，准备身份证号、手机号、绑定银行卡的微信用于验证。
2. 打开微信开发者平台，点击小程序入口，填写邮箱，接收验证码，点击激活邮件内的链接完成激活。
3. 选择主体类型，个人开发选择个人即可，输入身份信息，微信扫码验证即可完成登录。
4. 主体类型分为三种：个人无需营业执照，免费；个体工商户需要营业执照；企业需要营业执照和对公账户，每年300元认证费。
5. 填写小程序基础信息，包括名称、头像、功能介绍，🚩重点强调：小程序名称一年只能修改3次，头像和介绍可以多次修改，因此确定名称后再填写，没想好可以先不填。
6. 补充小程序类目，选择类目后微信官方会审核，新手做工具类选择「工具-信息查询」审核很容易通过，敏感行业审核很难通过。设置完成后小程序就注册完成了。
7. 权限说明：个人开发免费，不需要交300元认证费；现在个人主体也可以开通微信支付功能，企业主体可以开通更多能力，可以获取用户手机号。
8. 获取APP ID：注册完成后进入开发管理，获取APP ID，这是小程序的唯一标识，开发代码时必须使用；如果没有密钥需要点击重置生成，密钥不可以泄露给他人。
