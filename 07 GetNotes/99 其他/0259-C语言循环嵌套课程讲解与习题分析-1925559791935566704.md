#### 知识精讲

本节课围绕循环嵌套的执行流程展开，通过第4、5题的逐步推演，重点训练“标变量、不跳步、找规律”的解题方法，并讲解阶乘累加问题的嵌套循环实现与变量作用域。

**循环嵌套题目的通用解题方法**
* **变量标注法**：做循环嵌套类题目，**刚开始就要把变量标好**，在书上像老师示范那样标注每个变量的当前值。
   - 🚩重点：**每执行一步就更新一次变量值，绝对不要跳步**，尤其在不熟练阶段，跳步极易出错。
   - *补充说明*：老师反复强调“不要跳步”“一步一步来”，这是循环嵌套题不失分的核心操作规范。
* **do-while 与前置/后置自减的执行顺序**：`do-while` 先执行循环体再判断条件；`j--` 是先用后减，即判断时使用 j 的当前值，判断完成后再将 j 减 1。
   - 🚩重点：判断时 j 的值与判断后 j 的值不同，这是本题最容易出错的地方（“重点来了”）。

**第4题：for 嵌套 do-while 的完整推演**
* **程序结构**：外层 `for(i=0; i<5; i++)`，循环体内先 `j = i % 2`，再执行 `do { n++; } while(j--)`。
* **i=0 的执行过程**：j=0%2=0；进入 do-while，n 加 1；判断 `while(0)`，j 先用 0 判断为假，判断后 j 变为 -1；do-while 结束，回到 for 执行 i++，i 变为 1。
* **i=1 的执行过程**：j=1%2=1；n 加 1；判断 `while(1)` 为真，j 判断后变为 0，循环体再执行一次 n 加 1；再判断 `while(0)` 为假，j 变为 -1，do-while 结束；i++ 后 i=2。
* **i=2 的执行过程**：j=2%2=0；n 加 1；判断 `while(0)` 为假，j 变为 -1，do-while 结束；i 变为 3。
   - 🚩重点：**规律——i 为偶数时 n 只加 1 次，i 为奇数时 n 加 2 次**。发现规律后无需逐轮硬推，若把 5 改成 10 也能快速求解。
* **最终结果推导**：i 取 0、1、2、3、4，对应 n 的累加为 +1、+2、+1、+2、+1，n 从 0 开始，最终 **n=7**。
   - 🚩重点：**循环外输出 i 时，i 一定是使循环不成立的最小值**。本题条件为 i<5，故最终 **i=5**；每轮 do-while 结束后 j 均为 -1，故 **j=-1**。最终输出为 `5,-1,7`。
   - *补充说明*：老师强调考试时间紧张（300分、2个半小时），C语言题目若花半小时硬推就不值得，必须通过1～2轮执行发现规律以提高速度。

**第5题：for 嵌套 while 的完整推演（质因数分解式输出）**
* **程序结构**：`x = -125`；`if(x<0){ printf("-%d=", -x); x = -x; }`；随后 `for(i=2; i<=x; i++)`，循环体内 `r = x % i`，`while(r==0){ printf("%d", i); x = x / i; if(x>1) printf("*"); r = x % i; }`。
* **初始分支处理**：x=-125<0 成立，输出 `-125=`（即 `-%d=` 中 %d 被 -x=125 替换），然后 x=-x 使 x 变为 125；if 成立则 else 不执行。
   - 🚩重点：`printf` 中占位符要用后面的值替换，这是最基础的知识点；分支结构只能执行其中一支。
* **for 循环推演要点**：i 从 2 开始，依次计算 r=125%i。i=2、3、4 时 r 均不为 0，while 不执行，i 递增；i=5 时 r=125%5=0，while 开始执行。
* **while 循环内部推演**：r=0 成立，输出 i=5，x=125/5=25，x>1 成立输出 `*`；r=25%5=0 仍成立，再输出 5，x=25/5=5，输出 `*`；r=5%5=0 仍成立，再输出 5，x=5/5=1，x>1 不成立不输出 `*`；r=1%5=1≠0，while 结束。
   - 🚩重点：**每一步都必须更新变量值再进入下一步**，否则极易出错；注意 `%` 是取余不是除法（5%5=0 而非 1）。
* **循环收尾**：while 结束后 i++ 使 i=6，6<=x（x=1）不成立，for 结束；最后 `if(x>1)` 中 x=1 不成立，不执行。
* **最终结果**：`-125=-5*5*5`。
   - 🚩重点：此类题目无法靠选项猜测，必须严格按执行流程逐步跟踪，考验对每一步的把控。

**阶乘的累乘实现**
* **阶乘定义**：`n!` 表示从 1 乘到 n，如 `5! = 5×4×3×2×1`，与数学中阶乘概念一致。
* **累乘与累加的类比**：求 5 的阶乘与从 1 加到 5 的累加思路完全相同，只是把初值从 0 改为 1、把加改为乘。
   - *代码示例*：
```c
int i, mul = 1;
for(i = 1; i <= 5; i++)
    mul = mul * i;
printf("%d", mul);
```
   - 🚩重点：**累乘变量初值必须为 1（不能为 0）**，命名建议用 `mul`（乘法），累加用 `sum`。
* **执行验证**：i=1 时 mul=1×1；i=2 时 mul=1×2；i=3 时 mul=1×2×3……与累加逻辑一一对应。

**1!+2!+…+5! 的嵌套循环实现**
* **外层再套一层循环**：要求 1 到 5 每个数的阶乘再求和，需在外层加 `for(j=1; j<=5; j++)`，把内层循环的上限 5 改为 j，从而分别求出 1!、2!、3!、4!、5!。
   - *代码示例*：
```c
int i, j, mul, sum = 0;
for(j = 1; j <= 5; j++) {
    mul = 1;
    for(i = 1; i <= j; i++)
        mul = mul * i;
    sum = sum + mul;
}
printf("%d", sum);
```
   - 🚩重点：**mul 必须在每次外层循环开始时重置为 1**，否则会累乘上一轮的阶乘结果导致错误。
* **求和累加**：在外层循环内执行 `sum = sum + mul`，把每个阶乘累加；**最终总和 sum 的输出必须放在外层循环之外**。
   - 🚩重点：**总和输出不能放在循环里面**，很多人喜欢把输出放进循环内，这是典型错误；同理，`sum` 的累加语句位置、`mul` 的重置位置都需要通过上机调试亲自梳理清楚。
   - *补充说明*：老师以昨天“判断回文数/合分数后在外层套大循环找 0～1000”为例，说明“先写单个判断，再外套循环”的通用套路。

#### 💡 核心概念
- **循环嵌套**：外层循环每执行一次，内层循环完整执行一轮；分析时逐层跟踪变量。
- **do-while**：先执行循环体，再判断条件，至少执行一次。
- **前置/后置自减**：`j--` 先用后减，判断用旧值，判断后变量减 1。
- **阶乘**：`n! = 1×2×…×n`，如 `5! = 120`。
- **累乘模板**：`mul = 1; for(i=1;i<=n;i++) mul = mul * i;`
- **阶乘和模板**：
```c
int i, j, mul, sum = 0;
for(j = 1; j <= 5; j++) {
    mul = 1;
    for(i = 1; i <= j; i++)
        mul = mul * i;
    sum = sum + mul;
}
printf("%d", sum);
```
