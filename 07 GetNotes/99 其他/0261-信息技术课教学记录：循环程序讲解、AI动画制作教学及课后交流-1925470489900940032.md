**键盘输入规范与编程基础注意事项**
* **编程输入规则**：编程过程中除了汉字注释，所有代码、符号都必须在英文输入法状态下输入，避免中文符号导致程序报错。
   - 🚩重点：输入特殊符号（如分号、括号）时，如果直接按键盘无法输出，按住Shift键再按对应按键即可打出正确的英文符号。
* **小高考考点提示**：高二信息技术小高考不会要求学生手写完整代码，核心考察点是**代码阅读能力**，能读懂给定代码的运行结果即可。

**基础while循环逐行解析**
* **变量初始化**：`S = 0` 定义变量S并赋值为0，作用等价于数学中的未知数，用于存储循环过程中的累加值。
* **while循环条件**：`while S <= 30:` 表示当S满足“小于等于30”的条件时，持续执行冒号后的缩进代码块。
* **循环体执行逻辑**：循环内先执行`S = S + 10`，在S原有数值基础上加10，再执行`print(S)`打印当前S的值，最终程序会依次输出10、20、30、40。

**循环变形：输出指定范围数字**
* **输出1到100的整数**：在基础代码上做两处修改，将`S = S + 10`改为`S = S + 1`，将循环条件`S <= 30`改为`S < 100`，即可实现逐行输出1到100的所有整数。
* **输出1到99的奇数**：将变量初始值改为`S = -1`，循环内改为`S = S + 2`，循环条件保持`S < 99`，即可实现逐行输出1、3、5…99的所有奇数。

**等差数列求和实现**
* **1到100求和**：新增变量`Y = 0`用于存储累加和，在循环体中添加`Y = Y + S`，每次循环将当前S的值累加到Y中，循环结束后输出Y，最终结果为5050，与等差数列求和公式`(首项+末项)*项数/2`的计算结果完全一致。
* **奇数求和扩展**：基于奇数输出的代码，复用求和逻辑，即可快速实现1+3+5+…+99的求和计算。

**循环嵌套核心概念与执行规则**
* **循环嵌套定义**：一个循环的代码块内部包含另一个完整的循环，外层的循环称为外层循环，内部的循环称为内层循环。
* **执行逻辑**：外层循环每执行1次，内层循环必须完整跑完所有轮次，内层全部执行完毕后，外层循环才会进入下一次迭代。
   - 🚩重点：循环嵌套的核心口诀：外循环控行，内循环管列；外层走一次，内层跑整圈；先定外边界，再填内条件；内层跑完后换行。

**星型图案打印实操**
* **5行5列全星阵**：外层循环控制行数`for(i=1; i<=5; i++)`，内层循环控制每行打印5个星号，内层循环结束后执行换行，最终输出5行、每行5个星号的矩形图案。
* **递增三角星阵**：仅修改内层循环的条件，将`j <=5`改为`j <=i`，即可实现第1行打印1颗星、第2行打印2颗星…第5行打印5颗星的直角三角形图案。
   - *代码*：
```c
for(i=1; i<=5; i++){
    for(j=1; j<=i; j++){
        printf("*");
    }
    printf("\n");
}
```

**数字特征筛选进阶案例**
* **0～1000数字各位和为15的筛选**：外层循环遍历0到999的所有整数，内层循环取出当前数字的每一位并累加求和，判断累加和等于15时输出该数字。
   - 🚩重点：必须为遍历的数字设置“替身变量”，避免原数字在取位过程中被除以10变为0，导致最终无法输出原始数值。
* **0～1000回文数筛选**：复用外层遍历逻辑，内层循环计算当前数字的逆序数，判断原数字与逆序数相等时，该数字即为回文数并输出。
   - 🚩重点：逆序数生成核心代码`S = S * 10 + v`是后续大量编程题的基础，后续刷题过程中会反复出现至少30次，必须熟练掌握。

#### 💡 核心概念
- **while循环**：当指定条件成立时，重复执行缩进代码块的循环结构。
- **循环嵌套**：一个循环内部包含另一个完整循环的结构，外层循环控行，内层循环管列。
- **替身变量**：用于保存原始数值，避免原变量在循环运算中被修改，导致最终无法输出正确结果。
- **回文数**：正读和反读数值完全相等的数字，例如121、1331。
- **核心代码**：
```c
// 1到100求和
S = 0
Y = 0
while S < 100:
    S = S + 1
    Y = Y + S
print(Y)

// 递增三角星阵
for(i=1; i<=5; i++){
    for(j=1; j<=i; j++){
        printf("*");
    }
    printf("\n");
}
```
