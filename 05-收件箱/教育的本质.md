## 🔑 你现在"一眼统一看"的效果

整棵树**只有两个大分支：A 教材、B 教学**。原来独立成块的 ②③，现在都变成了格子里的标签：

| 原独立块 | 现在挂在哪（见图标） |
|---|---|
| ⚙️ 找魂 | A-①魂 |
| ⚙️ 宽而不泛 | A-④审美 |
| ⚙️ 逐字稿 / ABACC / 说人话 | B-②解读教材 |
| 🔄 研究 BA | **横跨 3 格**：A-②问题、A-③解法、B-④反馈 |

## 📐 为什么这样嵌是成立的（内在逻辑）

**① 生产能力和"内容格"是一一对应的**——哪个能力就是为造哪个内容而生：

```
⚙️找魂 ──────────► A-①魂         （有魂，教材才有方向）
⚙️宽而不泛 ──────► A-④审美       （有尺子，才知道内容好不好）
⚙️逐字稿/ABACC ──► B-②解读教材   （有表达力，教材才讲得出来）
🔄研究BA ─────────► A-②  A-③  B-④ （找问题、抄解法、做复盘，全程都用）
```

**② 横跨方法（BA）本质就是"同一把尺子量三处"**：
- 量 **A-②问题** → 预期与现实的 Gap
- 量 **A-③解法** → 对标最佳实践
- 量 **B-④反馈** → 复盘
