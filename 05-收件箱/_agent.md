# 05-收件箱 · 就近规则（_agent.md）

> 在本文件夹操作时**先读本文件**。区域规则 > 全局规则（AGENTS.md），冲突取更严格者。

---

## 区域定位

所有输入的**唯一入口**与缓冲区。外部链接/文件/文字/截图先落这里，AI 当天转化归档，**保持空、不滞留**。

## 铁律

1. **输入唯一通道**：一切输入只走 05-收件箱；旧库 memory-base-codex 及 01 Inbox 作废。
2. **当天转化**：补 YAML 按 `00-天一生水/05-架构设计/12.检索：文档模板规范.md` 8 字段齐备（**keywords 必写**：3-5 个「用户会怎么问」白话词；parent 指所属索引）+ 规范命名按 `00-天一生水/05-架构设计/13.命名：三级目录规范.md`（AI 新建文档=`序号.主题：文档名`；目录=`NN-名称` 半角连字符，禁空格/emoji；专有名词只写标准写法）。字段不齐 = 转化未完成，不移动。
3. **意图识别优先**：先识别意图（任务/资料/混合），连续消息同任务合并，不逐条拆。

## 两层决策分拣（标准不临场改）

1. **先认知阶段定层**：外部成熟可信→01（默认拒入，过准入闸）；想的/新的/未验证→02；做过的→03；敢发学员→04；系统规则→00。
2. **再主题领域定子目录**：10 个人成长 / 20 产品与设计 / 30 创业与商业 / 40 管理与组织 / 50 AI 技术与应用 / 60 教育与教学 / 70 案例库 / 90 其他。
3. **新建目录前过「同问」**（`00-天一生水/05-架构设计/14.分类：同问判据.md`）：拟建目录的同层兄弟，用同一个问句要能全部答上；答不上 = 混轴，不新开，先提请裁决。

## 操作规范

| 操作 | 权限 |
|---|---|
| 接收输入、转档、分拣 | 自由（按两层决策） |
| 过程文档落位 | **先列全部候选清单经用户确认，或用户主动触发**，不静默自动落位 |
| 敏感内容（隐私/未定稿/对外） | 始终先问 |
| 删除收件箱内容 | 转化后清空；未转化删除需确认 |
