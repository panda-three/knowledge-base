# 素材：拼贴海报提示词模板

**一句话结论：** 新媒体设计第一要义是"抄"——直接问各平台大模型要最佳实践，再用拼贴风模板快速出图；公众号封面要情绪张力，小红书配图要种草感。

---

## 一、核心交付

- 三个新媒体场景：公众号封面/小红书配图/社群海报
- 一个抄秘诀：问元宝=公众号、问豆包=抖音
- 一套拼贴风海报提示词模板（Role/Task/Style/Elements/Composition/Variables）

## 二、关键框架

### 2.1 三个新媒体场景

| 场景 | 核心 | 要点 |
|---|---|---|
| 公众号封面 | 情绪张力+平台调性 | 900x383，大字报高反差，文章内核转情绪标题 |
| 小红书配图 | 种草感 | 高颜值/强细节/生活化，Before-After或玩梗 |
| 社群海报 | 信息密度+视觉冲击 | 字体大小/色块/图标区分信息层级 |

### 2.2 抄最佳实践秘诀

> 各家大模型用自己平台数据训练，直接问它该平台怎么做好。

| 平台 | 问谁 |
|---|---|
| 微信公众号/视频号 | 问元宝 |
| 抖音 | 问豆包 |

### 2.3 拼贴风海报模板结构

| 模块 | 内容 |
|---|---|
| Role | 精通拼贴艺术的新锐平面设计师 |
| Task | 生成活力拼贴风海报，剪贴感+街头潮流 |
| Style | 剪影拼贴/高饱和/粗糙白边/社交活力感 |
| Elements | 块状字体/撞色/Emoji贴纸/箭头/气泡框 |
| Composition | 竖版主标题在上人物上下错落，横版左右呼应 |
| Variables | 尺寸/主色调/主标题/副标题/气泡口号/卖点标签/背景/人物/漂浮元素 |

**模型推荐**：GPT Image 2（偏灰质感好）/ Nano Banana Pro

## 三、金句与判断

> 「普通人用AIGC做设计的第一要义：抄。」
> 「AI像许愿池里的王八——得清楚自己拜什么。」
> 「求人不如求AI。」

## 四、行动建议

| 层级 | 行动 |
|---|---|
| 基础 | 直接问元宝/豆包你所在平台的封面最佳实践 |
| 进阶 | 用拼贴风模板替换变量，3:4做小红书、9:16做竖版 |
| 高阶 | 对比4个模型出图效果，选最适合自己调性的 |
