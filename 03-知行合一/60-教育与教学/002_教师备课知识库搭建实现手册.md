## 2. 文件命名规范（公式 + 正反例）

| 对象 | 公式 | 正例 | 反例 |
|---|---|---|---|
| 教案 | `L{课次}_{主题}_教案` | `L03_循环嵌套_教案.md` | `循环嵌套教案最终版.md` |
| 课后反馈 | `L{课次}_{主题}_反馈` | `L03_循环嵌套_反馈.md` | `课后感想.md` |
| 学生档案 | `{序号}_{姓名}_档案` | `001_张三_档案.md` | `张三.md` |
| 题库 | `{课程}_{章节}_题库` | `C语言_循环_题库.md` | `练习题.md` |
| 课程入口 | `{课程}_MOC` | `C语言_MOC.md` | `C语言.md` |
| 进度页 | `{班级}_进度` | `25计算机1班_进度.md` | `1班.md` |

规则：文件名 ≤15 字；对话产出文件仍加 `NNN_` 前缀（本手册即 002）；版本迭代保留 `_vN` 后缀；版本号优先放 YAML `version`。

## 4. Obsidian 插件配置清单（7 个）

| 插件 | 必装 | 用途 | 关键设置 |
|---|---|---|---|
| **Dataview** | ✅必装 | 进度仪表板、课时索引、学生台账全部靠它 | 开启后直接用 `dataview` 代码块；无需 JS 查询 |
| **Templater** | ✅必装 | 一键生成教案/档案模板 | Settings → Template folder 指向 `_模板/`；`Trigger Templater on new file creation` 开启 |
| **Calendar** | ✅必装 | 课表视图，点日期看当天教案 | 关联日记文件夹；配合 Daily notes |
| **Obsidian Git** | ✅必装 | 自动备份（你已有 .git） | 设置 Auto backup interval: 30 分钟；Auto pull: off |
| Tasks | 可选 | 备课待办（改作业、打印等） | 全局查询语法 |
| QuickAdd | 可选 | 一键 capture 灵感进收件箱 | 配置 Capture to `05-收件箱` |
| Excalidraw | 可选 | 画知识点图解 | 无特殊设置 |

> 你库已有 `.obsidian` 与 Git 基础，Obsidian Git 装好即可用，无需额外建仓。

## 7. 备课工作流 SOP（课前→课中→课后）

### 课前 T-2 天（15 分钟）
1. 对 AI 说："备 L03 循环嵌套，25计算机1班" → AI 自动拉料（01 方法论 + 03 历史教案 + 素材）
2. AI 产出备课包初稿（目标/主线/案例/互动/练习）→ 落 `90-教案库/C语言/L03_循环嵌套_教案.md`，`status: 待应用`
3. 人工审校 10 分钟：案例换成本班真实例子、调整难度

### 课中
- 当日日记记 3 件事：卡点 / 学生亮点 / 下次必改
- （不打断授课，只留记号）

### 课后 48h 内（10 分钟）
1. 生成 `L03_循环嵌套_反馈.md`：效果 + 下次改进（从日记搬）
2. 逐班补学生档案观察记录（每生 1-2 句，只写有信息量的）
3. 有凭证 → 教案 `status: 已应用`（按你库四同步规则迁移）
4. 学生真实错题 → 追加进 `96-题库` 易错区

> 关键闭环：反馈文件 + 学生错题必须**回灌**题库与教案模板，否则库会只进不出。AI 可自动执行 1/3/4，你只做 2 与审校。
