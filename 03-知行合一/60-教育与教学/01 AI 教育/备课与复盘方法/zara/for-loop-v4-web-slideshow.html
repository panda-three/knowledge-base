Common Bug

方向反了，循环一开始就不会执行

因为一开始 5 <= 1 就不成立。

起点、终点、变化方向必须是一套。

33
Count Code

条件统计完整代码

#include <stdio.h>

int main() {
    int start, end;
    int i;
    int count = 0;

    printf("请输入范围的开始和结束：");
    scanf("%d %d", &start, &end);

    for (i = start; i <= end; i++) {
        if (i % 6 == 0 && i % 8 == 0) {
            count++;
        }
    }

    printf("满足条件的数字个数是：%d\n", count);
    return 0;
}

#include <stdio.h>

int main() {
    int i;

    for (i = 100; i <= 999; i++) {
        int ge = i % 10;
        int shi = i / 10 % 10;
        int bai = i / 100;

        if (bai*bai*bai + shi*shi*shi + ge*ge*ge == i) {

    }

}

9 · 常见错误

错误 1：分不清 < 和 <=

for (i = 1; i < 5; i++)

判断方法：最后一个数要不要处理？

要处理最后一个数：常用 <= 或 >=
42
Common Error

错误 2：忘记 i++ 或 i--

for (i = 1; i <= 5; ) {
    printf("%d\n", i);
}

循环变量不变化，就像人在原地踏步，永远到不了终点。

43
Common Error

错误 3：把代码放错大括号

每一轮都要做 → 放进 {}
只做一次 → 放在循环外

判断一句代码要不要进循环体，先问：这件事是不是每一轮都要做？

44
Common Error

错误 4：把 sum = sum + i 写成 sum = i

sum = i;
≠
sum = sum + i;

sum = i 会覆盖原来的结果，只留下这一次的 i。
