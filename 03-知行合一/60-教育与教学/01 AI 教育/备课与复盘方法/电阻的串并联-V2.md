# 电阻的串并联 V2

> 版本定位：把原来的“PPT 知识点堆叠稿”升级为一堂**认知推演驱动**的理论课。  
> 主目标不是让学生背下串联、并联公式，而是让学生真正看懂：**串联为什么分压，并联为什么分流，等效电阻为什么这样算。**

---

## 0. 这版课的审美标准

这节课不再按“欧姆定律 → 串联公式 → 并联公式 → 做题”的平铺方式走，而是按理论课的审美做三件事：

1. **把公式藏起来，先让学生猜现象**：为什么两个灯泡串起来会变暗？为什么并联后每个灯泡都能正常亮？
2. **用同一个电路推三遍**：先看表象，再看电流/电压路径，最后推出计算公式。
3. **用闭合句钉住重点**：每讲完一个概念，都压成一句学生能带走的话。

一句话目标：

> 学生下课后不是只会背 `R = R1 + R2` 和 `1/R = 1/R1 + 1/R2`，而是能解释：**串联看电流，并联看电压；分压看电阻占比，分流看电阻反比。**

## 2. 开场 2 分钟：L5 逐句锁死

> 🗣 **L5 开场钩子**  
> “同学们，今天我们先不背公式。  
> 我先问一个生活里的问题：两只一模一样的小灯泡，接在同一个电源上。  
> 如果把它们一个接一个串起来，灯会怎么样？  
> 如果把它们并排接在电源两端，灯又会怎么样？”

停顿 3 秒。

> “你可能会说：串联变暗，并联差不多正常亮。  
> 这句话背后，其实就是今天整节课的核心。  
> 串联为什么会变暗？因为它在分电压。  
> 并联为什么能各自亮？因为它们共享电压、分走电流。  
> 今天我们只抓一句话：**串联看电流，并联看电压。**”

## 4. 核心认知模型

### 4.1 一句话模型

> **串联一条路：电流相同，电压分配。并联多条路：电压相同，电流分配。**

### 4.2 三个判断问题

| 判断问题           | 如果答案是……   | 对应结构 |
| -------------- | --------- | ---- |
| 电流有没有分岔？       | 不分岔，只有一条路 | 串联   |
| 两端是不是接在同两个节点上？ | 是，同头同尾    | 并联   |
| 能不能先合并一部分？     | 能，先局部等效   | 混联   |

### 4.3 公式不是起点，是结论

| 结构   | 先看什么 | 为什么            | 公式                         |
| ---- | ---- | -------------- | -------------------------- |
| 串联   | 电流   | 一条路上电流处处相等     | `R总 = R1 + R2 + ...`       |
| 并联   | 电压   | 每个支路都接在同一对节点上  | `1/R总 = 1/R1 + 1/R2 + ...` |
| 串联分压 | 电阻占比 | 电流相同，`U = IR`  | `U1 = R1 / (R1 + R2) × U`  |
| 并联分流 | 电阻反比 | 电压相同，`I = U/R` | `I1 = R2 / (R1 + R2) × I`  |

## 5. 认知推演路径图

### ⑤ 话题 1：串联电路（10min）

- 认知台阶 1：什么叫串联？
  - 🔑 认知缺口：「如果电流从电源出来后，只有一条路可走，会发生什么？」
  - 📖 揭示：「它只能依次经过每一个电阻，所以各处电流相等。」
  - 🎯 闭合句：「所以你只需要记住一件事：串联不是看摆放位置，是看电流有没有分岔。」

- 认知台阶 2：为什么总电阻相加？
  - 🔑 认知缺口：「同一个电流要连续穿过两个电阻，这相当于什么变大了？」
  - 📖 揭示：「相当于阻碍一段一段叠加，所以总电阻等于各电阻之和。」
  - 🗣 L3 逻辑链：一条路 → 电流相同 → 每个电阻都阻碍同一股电流 → 阻碍叠加 → `R总 = R1 + R2 + R3`

- 认知台阶 3：为什么串联会分压？
  - 🔑 认知缺口：「如果电流相同，哪个电阻两端电压更大？」
  - 📖 揭示：「根据 `U = IR`，I 相同，R 越大，U 越大。」
  - ⚡ 反直觉时刻：「你以为电源电压是平均分的，其实不是。电压按电阻大小分配。」
  - 🎯 闭合句：「所以你只需要记住一件事：串联分压，谁电阻大，谁分到的电压多。」

- 🗣 L4 过渡：
  > “好，串联我们看清楚了：一条路，所以电流相同；阻碍叠加，所以电阻相加；电压按电阻比例分。接下来我们看它的反面——如果电流不是一条路，而是分成几条路，会发生什么？”

### ⑦ 话题 2：并联电路（10min）

- 认知台阶 1：什么叫并联？
  - 🔑 认知缺口：「如果两个电阻的两端都接在同一个电源两端，它们得到的电压一样吗？」
  - 📖 揭示：「一样。因为它们的首端接同一个点，末端也接同一个点。」
  - 🎯 闭合句：「所以你只需要记住一件事：并联不是看画得并排，而是看是不是同头同尾。」

- 认知台阶 2：为什么总电流相加？
  - 🔑 认知缺口：「电流走到分岔路口，会只走一条路吗？」
  - 📖 揭示：「不会。它会按各支路电阻大小分流，总电流等于各支路电流之和。」
  - 🗣 L3 逻辑链：多条路 → 电压相同 → 每条路各自有电流 → 总电流是支路电流之和 → `I = I1 + I2 + I3`

- 认知台阶 3：为什么并联后总电阻变小？
  - 🔑 认知缺口：「多接一个并联电阻，总电阻会变大还是变小？」
  - 📖 揭示：「会变小。因为你不是增加一道阻碍，而是增加一条路。」
  - ⚡ 反直觉时刻：「你以为多接一个电阻，阻力应该更大；真相正好相反——并联多一条路，总阻力变小。」
  - 🎯 闭合句：「所以你只需要记住一件事：并联不是阻碍叠加，而是道路增加。」

- 认知台阶 4：为什么并联会分流？
  - 🔑 认知缺口：「同样的电压压在两条路上，哪条路电流更大？」
  - 📖 揭示：「根据 `I = U/R`，U 相同，R 越小，I 越大。」
  - ⚡ 反直觉时刻：「分流不是平均分，电流更愿意走电阻小的路。」
  - 🎯 闭合句：「所以你只需要记住一件事：并联分流，谁电阻小，谁分到的电流多。」

## 6. 五层密度逐字稿

### 节点③ 预热思考题：电阻变大，电流一定变小吗？（3min）

🗣 **L5 提问**：

> “我问一个看起来很简单的问题：电阻变大，电流一定变小吗？  
> 先不要急着回答。你先想 5 秒。”

停顿 5 秒。

🗣 **L3 逻辑链锁死**：

> “如果电压不变，电阻变大，电流会变小。  
> 这是欧姆定律：`I = U / R`。  
> 但注意，前提是电压不变。  
> 如果电压也变了，就不能只盯着电阻一个量。”

🎯 **L5 闭合句**：

> “所以你只需要记住一件事：欧姆定律不是背公式，是看三个量谁不变、谁变化。”

---

### 节点④ 欧姆定律回顾（5min）

#### 4.1 部分电路欧姆定律

🗣 **L3 逻辑链锁死**：

> “在一段不包括电源的电路中，通过导体的电流，跟导体两端电压成正比，跟导体电阻成反比。  
> 电压越大，推动越强，电流越大。  
> 电阻越大，阻碍越强，电流越小。  
> 这三者的关系，就是 `I = U / R`。”

| 物理量 | 符号 | 单位 | 常用换算 |
|---|---|---|---|
| 电流 | I | 安培 A | `1A = 10^3 mA = 10^6 μA` |
| 电压 | U | 伏特 V | `1V = 10^3 mV = 10^6 μV` |
| 电阻 | R | 欧姆 Ω | `1000Ω = 1kΩ` |

> 注：欧姆定律主要适用于线性电阻电路。非线性元件不能简单套用固定电阻值。

🔑 **认知缺口**：

> “为什么白炽灯刚通电和正常发光时，电阻可能不一样？”

📖 **揭示方向**：灯丝温度变化 → 电阻变化 → 伏安特性不再是简单直线。

#### 4.2 全电路欧姆定律（简化处理）

🗣 **L2 要点提纲**：

- 电源内部也有电阻，叫内阻 `r`。
- 外电路电阻是 `R`。
- 全电路电流：`I = E / (R + r)`。
- 端电压：`U = E - Ir`。
- 开路时 `I = 0`，端电压约等于电动势 `E`。
- 短路时外电阻近似为 0，电流很大，危险。

🎯 **闭合句**：

> “所以你只需要记住一件事：真实电源不是完美电源，它内部也会分掉一部分电压。”

## 7. 话题 1 完整讲法：电阻串联

### 7.1 定义

> **串联**：把电阻一个接一个依次连接起来，电流只有一条通路。

🗣 **L5 判断句**：

> “判断串联，不是看它们是不是排成一排，而是看电流有没有别的路可走。没有分岔，就是串联。”

### 7.2 串联特点

| 特点 | 公式 | 解释 |
|---|---|---|
| 电流处处相等 | `I = I1 = I2 = I3` | 只有一条路，电流不能分身 |
| 总电压等于各电压之和 | `U = U1 + U2 + U3` | 电源电压被各电阻分掉 |
| 总电阻等于各电阻之和 | `R = R1 + R2 + R3` | 阻碍一段一段叠加 |
| 电压按电阻比例分配 | `U1 = R1 / (R1 + R2) × U` | 同一电流下，电阻越大电压越大 |

### 7.3 串联分压推导

🗣 **L3 逻辑链锁死**：

> “串联电路里，电流相同。  
> 对 R1，有 `U1 = I × R1`。  
> 对 R2，有 `U2 = I × R2`。  
> 所以 `U1 : U2 = R1 : R2`。  
> 这就是分压公式的本质。”

⚡ **反直觉时刻**：

> “电压不是平均分的。电压是按电阻比例分的。”

🎯 **闭合句**：

> “所以你只需要记住一件事：串联分压，电阻越大，分到的电压越多。”

### 7.4 串联例题 A：求各电压与总功率

> 题型：已知 `R1`、`R2`、电流或总电压，求 `U1`、`U2`、`U`、`P`。

🗣 **L2 解题流程**：

1. 先判断：有没有分岔？没有 → 串联。
2. 求总电阻：`R总 = R1 + R2`。
3. 如果已知总电压：先求 `I = U / R总`。
4. 分别求电压：`U1 = I R1`，`U2 = I R2`。
5. 求总功率：`P = UI = I^2 R总 = U^2 / R总`。

### 7.5 串联例题 B：10V 分成 7V 和 3V

> 题目：想要用两个电阻串联将 `10V` 电压分成 `7V` 和 `3V`，要求总等效电阻为 `200Ω`，两个电阻各为多少？

🗣 **L3 逻辑链锁死**：

> “这是分压题。  
> 串联分压，电压比等于电阻比。  
> 所以 `R1 : R2 = U1 : U2 = 7 : 3`。  
> 总电阻是 `200Ω`。  
> 10 份对应 200Ω，1 份对应 20Ω。  
> 7 份就是 140Ω，3 份就是 60Ω。”

✅ 答案：

- `R1 = 140Ω`
- `R2 = 60Ω`

🎯 **闭合句**：

> “看到串联分压题，先别急着代公式，先看比例。”

## 8. 话题 2 完整讲法：电阻并联

### 8.1 定义

> **并联**：几个电阻的两端分别接在同两个节点上，形成多条电流通路。

🗣 **L5 判断句**：

> “判断并联，不是看它们是不是画得并排，而是看它们是不是同头同尾。”

### 8.2 并联特点

| 特点 | 公式 | 解释 |
|---|---|---|
| 总电流等于各支路电流之和 | `I = I1 + I2 + I3` | 电流在节点处分流 |
| 各支路电压相等 | `U = U1 = U2 = U3` | 各支路接在同两个节点上 |
| 总电阻倒数等于各电阻倒数之和 | `1/R总 = 1/R1 + 1/R2 + 1/R3` | 多一条路，总阻碍变小 |
| 两个电阻并联 | `R总 = R1 × R2 / (R1 + R2)` | 常用速算公式 |
| 电流按电阻反比分配 | `I1 = R2 / (R1 + R2) × I` | 电阻越小，分流越多 |

### 8.3 并联等效电阻推导

🗣 **L3 逻辑链锁死**：

> “并联电路里，各支路电压相同。  
> 总电流等于各支路电流之和。  
> `I = I1 + I2`。  
> 又因为 `I = U / R总`，`I1 = U / R1`，`I2 = U / R2`。  
> 所以 `U / R总 = U / R1 + U / R2`。  
> 两边同时除以 U，就得到：`1/R总 = 1/R1 + 1/R2`。”

⚡ **反直觉时刻**：

> “并联多接一个电阻，总电阻不是变大，而是变小。因为你增加的不是阻碍，而是道路。”

🎯 **闭合句**：

> “所以你只需要记住一件事：并联总电阻一定小于任意一个支路电阻。”

### 8.4 并联分流推导

🗣 **L3 逻辑链锁死**：

> “并联电路里，电压相同。  
> 对 R1，有 `I1 = U / R1`。  
> 对 R2，有 `I2 = U / R2`。  
> 所以 `I1 : I2 = 1/R1 : 1/R2`。  
> 也就是说，电流和电阻成反比。”

🎯 **闭合句**：

> “所以你只需要记住一件事：并联分流，电阻越小，分到的电流越大。”

### 8.5 并联例题 A：求等效电阻

🗣 **L2 解题流程**：

1. 先判断：两端是否接在同两个节点上？是 → 并联。
2. 如果只有两个电阻：优先用 `R总 = R1R2 / (R1 + R2)`。
3. 如果有多个电阻：用倒数公式 `1/R总 = 1/R1 + 1/R2 + ...`。
4. 检查结果：并联总电阻应小于最小支路电阻。

### 8.6 混联例题：先局部后整体

> 题型：已知 `R1 = 2Ω`，`R2 = 6Ω`，`R3 = 3Ω`，`U = 12V`，求总等效电阻及各部分电流。

🗣 **L2 解题流程**：

1. 先不算，先圈结构：哪几个电阻同头同尾？哪几个在一条路上？
2. 先合并最明显的串联或并联部分。
3. 每合并一步，重新画一个简化电路。
4. 求总电阻后，求总电流。
5. 再倒推各支路电压、电流。

🎯 **闭合句**：

> “混联题不要一上来套公式，先把电路一层一层化简。”

## 10. 总结：一页大字口诀

🗣 **L5 收口**：

> “今天的公式很多，但你不要用背的方式记。  
> 你只记这四句话：  
> 串联一条路，电流处处同。  
> 串联会分压，电阻大者多。  
> 并联同头尾，电压处处同。  
> 并联会分流，电阻小者多。”

最终闭合句：

> **串联看电流，并联看电压；先判断结构，再使用公式。**

## 11. 限时检测

### 题 1：概念判断

两个电阻接入电路后，如果通过它们的电流一定相等，它们一定是串联吗？为什么？

> 参考方向：在简单无分支电路中可判断为串联；严谨表达应看是否在同一条无分岔路径上。

### 题 2：串联分压

两个电阻 `R1 = 3Ω`、`R2 = 6Ω` 串联接在 `12V` 电源上，求 `U1`、`U2`。

参考答案：

- `R总 = 9Ω`
- `I = 12 / 9 = 4/3 A`
- `U1 = 4V`
- `U2 = 8V`

### 题 3：并联等效

两个电阻 `R1 = 3Ω`、`R2 = 6Ω` 并联，求等效电阻。

参考答案：

- `R总 = 3 × 6 / (3 + 6) = 2Ω`
- 检查：`2Ω < 3Ω`，符合并联总电阻小于最小支路电阻。

### 题 4：功率理解

灯泡功率 `P = U² / R`，这个公式成立的前提是什么？

参考答案：

- 把灯泡近似看成电阻负载。
- 在稳定工作状态下，用欧姆定律和 `P = UI` 推出。
- 若灯丝温度变化明显，电阻并非恒定，需要注意适用条件。
