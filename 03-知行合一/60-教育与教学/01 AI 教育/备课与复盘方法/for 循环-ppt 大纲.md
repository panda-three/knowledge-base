# PPT 大纲：for 循环——把重复劳动交给电脑

> 面向学生。  
> 目标：让学生听懂、记住、能写出最基础的 for 循环。  
> 核心卖点：**for 循环不是背格式，而是用“四问”控制重复。**

---

## 01 封面

**for 循环**  
把重复劳动交给电脑

副标题：不用背死格式，先学会问四个问题。

---

## 02 开场问题：如果要打印 100 遍怎么办？

屏幕展示：

```c
printf("我爱 C 语言!\n");
printf("我爱 C 语言!\n");
printf("我爱 C 语言!\n");
printf("我爱 C 语言!\n");
printf("我爱 C 语言!\n");
```

问题：

- 打印 5 遍可以复制 5 行
- 打印 50 遍呢？
- 打印 100 遍呢？
- 如果内容要改，是不是每一行都要改？

**本页结论**：重复不是错误，重复是信号。

---

## 03 为什么需要循环

不用循环：

- 代码很长
- 修改麻烦
- 容易复制错
- 人在做重复劳动

用循环：

- 让电脑重复做
- 代码更短
- 逻辑更清楚
- 次数可以控制

**一句话**：循环就是把重复劳动交给电脑。

---

## 04 本节课核心目标

学完这节课，你要能说清楚：

```c
for (i = 1; i <= 5; i++) {
    printf("%d\n", i);
}
```

里面每个位置是什么意思：

- `i = 1`：从哪开始
- `i <= 5`：到哪结束
- `i++`：每次怎么变
- `printf`：重复做什么

---

## 05 for 循环不是先背格式

很多人一开始会死背：

```c
for (初始化; 条件; 变化) {
    循环体;
}
```

但更重要的是先问：

```txt
1. 从哪开始？
2. 到哪结束？
3. 每次怎么变？
4. 重复做什么？
```

**本页结论**：会写 for，本质是会回答四个问题。

---

## 06 for 循环四问模型

```c
for (从哪开始; 到哪结束; 每次怎么变) {
    重复做什么;
}
```

| 四问 | for 中的位置 | 例子 |
|---|---|---|
| 从哪开始？ | 初始化 | `i = 1` |
| 到哪结束？ | 条件判断 | `i <= 5` |
| 每次怎么变？ | 条件控制 | `i++` |
| 重复做什么？ | 循环体 | `printf(...)` |

---

## 07 口诀页

```txt
先定起点
再定终点
每轮变一次
身体做重复
```

视觉建议：  
把 for 循环画成一条路：

```txt
起点 → 判断 → 执行 → 变化 → 再判断
```

## 08 示例 1：打印 1 到 5

需求：

```txt
打印 1 到 5
```

先填四问：

| 四问 | 答案 |
|---|---|
| 从哪开始？ | `i = 1` |
| 到哪结束？ | `i <= 5` |
| 每次怎么变？ | `i++` |
| 重复做什么？ | 打印 i |

---

## 09 示例 1：完整代码

```c
#include <stdio.h>

int main() {
    int i;

    for (i = 1; i <= 5; i++) {
        printf("%d\n", i);
    }

    return 0;
}
```

输出：

```txt
1
2
3
4
5
```

**本页重点**：代码不是凭空写出来的，是四问填出来的。

---

## 10 张力点：一个等号，结果就变了

把：

```c
i <= 5
```

改成：

```c
i < 5
```

结果会变成：

```txt
1
2
3
4
```

少了 `5`。

**本页结论**：循环里最贵的错误，经常不是语法错，而是边界错。

---

## 11 for 的执行顺序

for 循环不是从左到右走一遍。

它的真实顺序是：

```txt
① 起点：i = 1，只执行一次
② 判断：i <= 3
③ 执行循环体
④ 变化：i++
⑤ 回到②继续判断
```

**记忆句**：

```txt
起点一次
判断多次
身体多次
变化多次
```

---

## 12 示例 2：为什么结束时 i = 4

代码：

```c
for (i = 1; i <= 3; i++) {
    printf("i = %d\n", i);
}

printf("结束时 i = %d\n", i);
```

输出：

```txt
i = 1
i = 2
i = 3
结束时 i = 4
```

重点解释：

- 打印完 3 后，i 还会执行一次 `i++`
- i 变成 4
- 再判断 `4 <= 3`
- 不成立，循环结束

---

## 13 示例 3：反向输出 5 到 1

需求：

```txt
打印 5 4 3 2 1
```

四问变化：

| 四问 | 答案 |
|---|---|
| 从哪开始？ | `i = 5` |
| 到哪结束？ | `i >= 1` |
| 每次怎么变？ | `i--` |
| 重复做什么？ | 打印 i |

---

## 14 反向输出完整代码

```c
#include <stdio.h>

int main() {
    int i;

    for (i = 5; i >= 1; i--) {
        printf("%d ", i);
    }

    return 0;
}
```

输出：

```txt
5 4 3 2 1
```

**本页结论**：起点、终点、变化方向必须是一套。

---

## 15 示例 4：求 1 到 5 的和

这一次不只是打印，还要“装起来”。

两个变量：

```txt
i   ：负责一个一个走
sum ：负责把每个数装起来
```

核心代码：

```c
sum = sum + i;
```

**比喻**：  
`i` 是一个个来的数字，`sum` 是篮子。

---

## 16 求和完整代码

```c
#include <stdio.h>

int main() {
    int i;
    int sum = 0;

    for (i = 1; i <= 5; i++) {
        sum = sum + i;
    }

    printf("sum = %d\n", sum);
    return 0;
}
```

输出：

```txt
sum = 15
```

**本页结论**：求和题里，i 负责走，sum 负责装。

## 17 从打印到统计：for + if

统计题：

```txt
统计 start 到 end 中，
既能被 6 整除，又能被 8 整除的数字个数。
```

核心思路：

```txt
循环负责一个个试
if 负责判断
count 负责记录
```

四问：

| 四问 | 答案 |
|---|---|
| 从哪开始？ | `i = start` |
| 到哪结束？ | `i <= end` |
| 每次怎么变？ | `i++` |
| 重复做什么？ | 判断条件，满足就 count++ |

---

## 18 条件统计代码

```c
for (i = start; i <= end; i++) {
    if (i % 6 == 0 && i % 8 == 0) {
        count++;
    }
}
```

关键问题：

```txt
count++ 应该放在 if 里面，还是外面？
```

答案：

```txt
放在 if 里面。
因为只有满足条件的数字才应该被计数。
```

---

## 19 常见错误 1：边界错

错误：

```c
for (i = 1; i < 5; i++)
```

如果目标是打印 1 到 5，这样会少打印 5。

判断方法：

```txt
最后一个数要不要处理？
要处理，多数情况下用 <= 或 >=。
```

---

## 20 常见错误 2：忘记变化

错误：

```c
for (i = 1; i <= 5; ) {
    printf("%d\n", i);
}
```

问题：

- i 一直是 1
- 条件一直成立
- 循环走不出去

**本页结论**：不变化，就会死循环。

---

## 21 常见错误 3：变量分工混乱

错误理解：

```txt
i 和 sum 都是数字，所以随便用。
```

正确理解：

```txt
i         负责走
sum/count 负责装
if        负责判断
```

**本页结论**：变量不是随便起的，每个变量都有角色。

## 22 进阶挑战：水仙花数

题目：

```txt
打印 100 到 999 之间所有水仙花数。
```

水仙花数：

```txt
153 = 1*1*1 + 5*5*5 + 3*3*3
```

四问：

| 四问 | 答案 |
|---|---|
| 从哪开始？ | `i = 100` |
| 到哪结束？ | `i <= 999` |
| 每次怎么变？ | `i++` |
| 重复做什么？ | 拆数字 + 判断 |

---

## 23 水仙花数的关键：拆数字

```c
int ge = i % 10;
int shi = i / 10 % 10;
int bai = i / 100;
```

对应关系：

```txt
ge  ：个位
shi ：十位
bai ：百位
```

判断条件：

```c
bai*bai*bai + shi*shi*shi + ge*ge*ge == i
```

## 24 本节总结

写 for 循环，不要先背格式，先问四句话：

```txt
1. 从哪开始？
2. 到哪结束？
3. 每次怎么变？
4. 重复做什么？
```

再记住三个角色：

```txt
i         负责走
sum/count 负责装
if        负责判断
```

最后一句：

> for 循环真正难的不是括号，而是你能不能从题目里找出这四件事。
