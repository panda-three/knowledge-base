# 复盘：if-else 教学想当然致结巴

> 原话（语音转写）：「今天在讲 if else 关于成绩的时候就是一开始是大于90，后来是大于80到90，那个小于90能不能是别的问题，那这个问题我当时过于想当然了，所以导致我讲的时候比较结巴，然后因为考虑到同门的基础问题，所以我应该是考虑到他们的问题，应该就是说不要那么急着去让他们回答把小于90去掉有没有问题，尽量是提前好说」

## 复盘要点

1. **场景**：讲 if-else 成绩判定（>90、80~90、<90 的边界处理）时，让学生思考"把 <90 去掉有没有问题"。
2. **问题**：过于想当然（没先考虑学生基础），导致讲解时结巴。
3. **教训**：提问/互动前先评估学生基础；不要急着让学生立刻回答边界问题，**尽量提前铺垫好**。
