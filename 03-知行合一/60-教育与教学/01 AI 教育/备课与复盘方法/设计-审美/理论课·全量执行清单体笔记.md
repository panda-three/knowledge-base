# 理论课·全量执行清单体笔记

---

## 一、理论课定义与适用判断

### 什么是理论课
- **定义**：以概念、原理、框架、方法论为核心教学内容的课程，不依赖实时操作演示
- **一句话**：学生不是看你做，是跟你「想」——你的嘴就是唯一的教学工具
- **与实操课的本质区别**：没有操作轨兜底。逻辑一旦断裂，学生直接掉线。对语言精度和逻辑链的要求比实操课高一个量级

### 什么时候选理论课
- 教的是**概念原理**（AI 幻觉机制、Prompt 底层逻辑、注意力机制直觉版……）
- 教的是**思考框架**（ROI 决策、五步法、动力阻力触点……）
- 教学路径**无法/不需要**在屏幕上操作演示
- 目标不是「学生会操作」，而是「学生会思考、会判断、会推导」

### 什么时候不选理论课
- 教的是工具使用 → 选实操课
- 有天然的屏幕操作路径可以展示 → 选实操课
- 理论 + 操作混合 → 理论段用理论课方法，实操段用实操课方法。先理论（建认知），再实操（验证认知）

## 二、理论课核心认知：它比实操课难在哪

### 一条只有嘴的轨道
- 实操课：两条轨（操作轨 + 讲解轨）并行，操作分散了学生的注意力负担，也给了你喘息空间
- 理论课：只有一条轨——你的嘴。屏幕上是静态的 PPT，学生的全部注意力都在你说了什么
- **结果**：理论课对语言精度的要求是实操课的 3–5 倍。一句废话、一个逻辑跳跃、一段 3 分钟没有认知刺激的平铺直叙——学生直接走神

### 最大的敌人不是翻车，是枯燥
- 实操课翻车（AI 输出不对、工具挂了）→ 学生反而兴奋，因为「真实」
- 理论课翻车（讲散了、逻辑断了、学生听不懂）→ 学生沉默走神，你还不知道
- **枯燥预案是理论课的翻车预案**——必须提前设计，不可临场补救

### 学生走神的三个关键时刻
- **开场 2 分钟后**：「好像也没什么新鲜的」→ 没打中认知盲区
- **方法论讲到第 5 分钟**：「信息有点多，我先放一放」→ 认知过载，没有闭合句
- **案例讲完没总结**：「所以刚才那个案例说明了什么？」→ 学生自己串不起来

## 三、完整交付流水线（不可跳步）

```
Step 1: 用户访谈 → 挖掘认知盲区
        ↓
Step 2: 画出认知推演路径图（认知台阶 + 案例推演路径）
        ↓
Step 3: 标注全部动力锚点（认知缺口 / 反直觉时刻 / 认知闭合）
        ↓
Step 4: 填写五层密度逐字稿
        ↓
Step 5: 逻辑链测试 + 锚点间隔检查
        ↓
Step 6: PPT 制作（60–90 页，每 30–60 秒切页，每页一个信息）
        ↓
Step 7: 试讲 → 回修逐字稿 → 上台
```

**铁律**：理论课逐字稿的审查方式不是静默演练（那是实操课的），是**逻辑链测试 + 锚点间隔检查**。跳过审查 = 带着逻辑断裂和枯燥段上台。

## 四、Step 1：用户访谈——挖认知盲区

### 为什么理论课的访谈比实操课更重要
- 实操课：「我试了 AI 写歌，出来不能听」→ 痛点直接、可操作验证
- 理论课：「Prompt 不就是说清楚吗？」→ 这个认知本身就是错的，但用户自己不知道。这是**认知盲区**，不是**操作痛点**

### 访谈目标：找到三个东西

| 挖掘目标      | 定义              | 访谈问题模板                       | 产出物      |
| --------- | --------------- | ---------------------------- | -------- |
| **认知盲区**  | 用户以为自己懂但其实是错的   | 「你觉得 Prompt 的本质是什么？一句话说清楚」   | 开场钩子的弹药  |
| **最大困惑**  | 用户知道自己不懂但不知道为什么 | 「你用 AI 最挫败的一次是什么？你当时怎么想的？」   | 为什么学段的素材 |
| **反直觉事实** | 真相和直觉相反的点       | 「如果我说 AI 根本不在乎你说了什么——你觉得对吗？」 | 反直觉时刻的素材 |

**硬约束**：访谈 3–5 人，输出至少 3 个用户的**原话**。开场时念原话——比你自己总结有力量十倍。

## 五、Step 2：画认知推演路径图

### 核心认知
实操课靠「操作演示」推动课程前进，理论课靠「认知推演」推动课程前进。

**认知推演 = 把结论拆成若干认知台阶，每一步都先让学生猜/想、再给答案。学生不是被灌输结论，是跟着你一起推导出结论。**

### 认知推演路径图结构

```
① 开场钩子：打认知盲区（2min）
② 为什么学：用户原话 + 「今天解决的就是这个」（3min）
③ 预热思考题：一个反直觉问题（2min）
④ 划重点：3–4 个话题，30 秒读完（1min）
⑤ 话题1：认知台阶×3–4 + 闭合句（10–12min）
⑥ 案例推演：同一个案例推三遍（8–10min）
⑦ 话题2：认知台阶×3–4 + 闭合句（10–12min）
⑧ 套路沉淀+口诀（2min）
⑨ 作业：最小可验证动作（1min）
⑩ Candy：下节课钩子（1min）
```

### 单个认知台阶的标准格式

```markdown
- 话题X：XXX（Xmin）
    - 认知台阶1：
        - 🔑 认知缺口：「为什么___？」（先问）
        - 📖 揭示：「因为___」（再答）
    - 认知台阶2：
        - 🔑 认知缺口：（下一个为什么）
        - 📖 揭示：
    - 认知台阶3：
        - 🔑 认知缺口：
        - 📖 揭示：
    - 🎯 闭合句：「所以你只需要记住一件事：___」
    - 🗣 L4 框架锁死（过渡到下个话题）：过渡句写死
```

### 认知台阶设计铁律

| 铁律 | 说明 | 反例 |
|---|---|---|
| **先问再答** | 每个台阶必须先制造认知缺口，再给答案 | 直接给答案 → 学生被动接收 |
| **一层只推一个东西** | 一个台阶只推进一层认知深度 | 一个台阶塞三个结论 → 认知过载 |
| **台阶间必须是因果/递进/转折** | 台阶 2 必须是台阶 1 的「所以呢」/「不只」/「但是」 | 台阶间无逻辑关系 → 散架 |
| **最后必闭合** | 每个话题结束必须有一句闭合句 | 讲完就切 → 学生不知道重点 |

## 六、Step 2 附：案例推演三遍法

### 与实操课案例的区别

| | 实操课案例 | 理论课案例 |
|---|---|---|
| **手法** | 三段平行时空：并列对比 | 三遍推演：纵深剥开 |
| **逻辑** | 横向——「同一个任务，三种水平」 | 纵向——「同一个案例，三层深度」 |
| **学生体感** | 「差这么多！」（感官冲击） | 「原来是这样一层层剥开的！」（认知冲击） |

### 三遍推演标准格式

| 推演轮次    | 屏幕展示               | 你的嘴                            | 认知层级                        |
| ------- | ------------------ | ------------------------------ | --------------------------- |
| **第一遍** | 展示案例表象（一个 AI 翻车现场） | 「你看——AI 犯了一个什么错误？」             | 学生**识别表象**——「它编了一个不存在的引用」   |
| **第二遍** | 展示底层机制图解           | 「它不是在查资料——它是在猜下一个字。这个本质决定了什么？」 | 学生**理解底层原理**——「所以它不是撒谎，是续写」 |
| **第三遍** | 展示应对策略             | 「知道原理之后——你的动作是什么？」             | 学生**从原理推导出行动**——「我得验证关键事实」  |

### 案例选择铁律
- **只选一个案例**：一个案例推三遍，不是三个案例各推一遍
- **案例必须「反直觉」**：推完之后学生有「原来如此」的体感，不能是「本来就该这样」
- **案例必须能支撑三层深度**：如果推到第二遍就推不下去了，案例选错了

## 七、Step 3：标注动力锚点

### 理论课三种动力锚点

| 锚点          | 定义                  | 频率要求                     | 话术模板              |
| ----------- | ------------------- | ------------------------ | ----------------- |
| **🔑 认知缺口** | 「为什么」的悬念——让学生在脑子里先猜 | 每 3–5 分钟一次               | 「为什么___？你先想 5 秒」  |
| **⚡ 反直觉时刻** | 「你以为 A，其实是 B」的颠覆    | 每 8–10 分钟一次；45 分钟课 ≥ 3 个 | 「如果我告诉你——真相正好相反」  |
| **🎯 认知闭合** | 一句话钉死结论，学生有「懂了」的爽感  | 每个话题结束                   | 「所以你只需要记住一件事：___」 |

### 标注方式

在认知推演路径图上用符号标注：

```markdown
- 🔑 认知缺口：「为什么同样的指令，不同模型输出差这么多？」
- ⚡ 反直觉时刻：「真相是——AI 根本不在乎你说了什么，它在乎的是概率」
- 🎯 闭合句：「所以你只需要记住一件事：Prompt 不是在和 AI 说话，是在和概率分布谈判」
```

### 枯燥预案硬约束
- [ ] 任何两个锚点之间不超过 5 分钟
- [ ] 反直觉时刻 ≥ 3 个（45 分钟课）
- [ ] 每个话题结束有闭合句
- [ ] 超过 5 分钟无锚点 = 那段内容**必须重写或删除**

## 八、Step 4：五层密度逐字稿

### 核心认知
理论课没有操作轨兜底。你嘴里的每一句话都是认知台阶上的一块砖——句子和句子之间必须咬合，密度必须精准投放。

### 为什么理论课需要五层（实操课只需要三层）
- 实操课：操作期间可以半即兴，操作本身在帮学生消化信息
- 理论课：全程只有你的嘴，过渡句一散 = 逻辑断裂 = 学生掉线；关键推导措辞不准 = 学生理解偏差 = 后面全白讲
- 所以理论课多了 **L4 框架锁死**（过渡句提前锁死）和 **L3 逻辑链锁死**（核心推导的因果/递进/转折链提前锁死）

### 五层密度表

| 密度层级         | 适用场景                      | 写法                   | 标识      |
| ------------ | ------------------------- | -------------------- | ------- |
| **L5 逐句锁死**  | 开场钩子、收口总结、闭合句、反直觉时刻的揭示、口诀 | 每个字都写死，上场不改一个字       | `🗣 L5` |
| **L4 框架锁死**  | 认知台阶间过渡、案例各轮次间过渡、大话题间过渡   | 过渡句逐句写死，中间的展开部分写关键词  | `🗣 L4` |
| **L3 逻辑链锁死** | 方法论核心推导、认知台阶内的关键因果/递进/转折  | 逻辑链写死（A→B→C），具体措辞可微调 | `🗣 L3` |
| **L2 要点提纲**  | 案例展开细节、补充说明、例子的具体展开       | 3–5 个要点 + 一个闭合句      | `🗣 L2` |
| **L1 即兴区**   | 互动回应、临场举例、学生提问响应          | 只标注「这个节点传达什么方向」      | `🗣 L1` |

### 各层密度填法详解

**L5 逐句锁死**：
- 写完读出声，确认语言流畅
- 删到不能再删一个字——理论课的 L5 比实操课的 L3 更「干」
- 写到「这句话换任何一个人念，效果都一样好」的程度

**L4 框架锁死**：
- 过渡句 = 学生脑子的「转向灯」。不亮灯就转弯 = 学生跟丢
- 模板：「好，刚才我们看到了___。接下来——___。」
- 展开部分只写关键词，不写完整句

**L3 逻辑链锁死**：
- 把核心推导写成 A→B→C 的链条
- 每一环之间必须是因果/递进/转折之一
- 措辞允许微调，但链条顺序不可变

**L2 要点提纲**：
- 3–5 个要点，每个一句话
- 结尾必须回到闭合句——不能让展开部分「散出去收不回来」

**L1 即兴区**：
- 只写一句话方向：「用学生自己的例子回应」「这个点通常有 3 种常见疑问」
- 不给具体措辞，给应对策略

## 九、逐字稿三铁律

### 铁律一：一句只做一件事

**检验方式**：指着逐字稿里的每一句话问——这句话到底在干什么？
- 解释概念？举例？总结？过渡？提问？
- 如果一句话同时干了两件以上的事 → **拆成两句**

```
❌ 「Prompt 的三角结构就是角色加任务加约束，这三者叠加时 AI 的输出质量会大幅提升，比如你写'你是一个专家'和'你是一个专家请用三段式写出方案'出来的结果完全不同」

✅ 拆：
「Prompt 有一个三角结构。三个角：角色、任务、约束。」
「缺一个角，AI 就猜一个——猜的结果你控制不了。」
「举个例子。」（切屏幕对比）
```

### 铁律二：推演逻辑比语言漂亮重要十倍

**检验方式——逻辑链测试**：把逐字稿里每一句话的**开头第一个词或短语**连起来读。

- 如果连起来是一条清晰的因果/递进/转折链 → 通过
- 如果连起来发现某两句话之间没有逻辑关系 → **逻辑断裂点，必须修**

```
示例（通过）：
「为什么？→ 因为 A。→ 不只 A，还有 B。→ 但 B 有一个漏洞。→ 所以你需要 C。」
```

```
示例（不通过）：
「为什么？→ 因为 A。→ 另外说一下 D。→ 回到 B。」→ D 是岔路，打断链条
```

**修复方式**：删掉岔路的句子，或把它移到该在的位置。

### 铁律三：每个认知台阶结束必有一句闭合句

**标准格式**：「所以你只需要记住一件事：_____。」

- 闭合句必须能**脱离上下文独立存在**——学生只记住这一句，也能回忆起整个话题
- 闭合句不能是「以上我们讲了三点」——那是总结，不是闭合
- 闭合句是把三层推演**压成一颗子弹**

## 十、Step 5：审查——逻辑链测试 + 锚点间隔检查

### 审查 A：逻辑链测试

- [ ] 把逐字稿每句话的开头连起来读，是否形成因果/递进/转折链？
- [ ] 链上有断裂吗？有岔路吗？
- [ ] 每个话题内的逻辑链是否独立清晰？
- [ ] 话题间的过渡（L4 框架锁死部分）是否也通过了逻辑链测试？

### 审查 B：锚点间隔检查

- [ ] 任何两个动力锚点（🔑/⚡/🎯）之间不超过 5 分钟？
- [ ] 反直觉时刻（⚡）是否 ≥ 3 个（45 分钟课）？
- [ ] 每个话题结束是否有闭合句（🎯）？
- [ ] 开场 2 分钟内是否有第一个认知缺口（🔑）？

### 审查 C：信息密度检查

- [ ] 有没有连续 3 分钟以上纯「讲」没有「问」的段落？
- [ ] 有没有一句超过 40 个字的长句？（有 = 拆）
- [ ] 有没有一段超过 3 个新概念的密集轰炸？（有 = 拆成两个话题）

## 十一、Step 6：PPT 制作

### 核心认知
理论课 PPT 是**主角**——因为屏幕上没有操作工具界面。PPT 是学生唯一的视觉来源。视觉节奏直接等于注意力节奏。

### PPT 数量与切页频率

| 参数 | 数值 | 原因 |
|---|---|---|
| **总页数** | 60–90 页（45 分钟课） | 不是信息密度高，是节奏快——每页只一个信息 |
| **切页频率** | 每 30–60 秒切一页 | 翻页本身就是注意力锚点 |
| **一页一个信息** | 绝对铁律 | 一页两个信息 = 学生不知道看哪个 |

### 反推规则

| 逐字稿里的内容 | PPT 处理 |
|---|---|
| 认知缺口（🔑） | 一整页只有那个问题，大字 |
| 反直觉时刻（⚡） | 一整页「你以为 A」→ 切下一页「其实是 B」 |
| 闭合句（🎯） | 一整页只有那句闭合句 |
| 案例对比 | 左右分屏，不并列在一页 |
| 方法论模型图 | 一页只放一个模型，不要在一页上标注 5 个要点 |
| 过渡 | 一页只写下一话题标题 |

### 理论课 PPT 禁止项

- ❌ 一页上超过 3 行字（大字标题除外）
- ❌ 一页讲超过 2 分钟
- ❌ 在学生需要思考的时候，PPT 上提前给了答案
- ❌ 模型图上加满注解——注解应该由你的嘴说出来，PPT 上是干净的图

## 十二、Step 7：试讲 → 回修 → 上台

### 试讲
- 不要对着镜子念——对着一个人讲
- 重点观察：对方的眼睛什么时候开始飘？那就是你的枯燥段
- 记录每一个「逻辑链测试没发现但真实讲出来别扭」的地方

### 回修逐字稿
- 试讲中卡顿/别扭的地方 → 改措辞
- 对方眼睛飘的地方 → 加认知缺口或反直觉时刻
- 如果一段怎么也修不好 → 删掉。理论课宁少勿多

### 上台前
- [ ] 逐字稿打印/放第二屏（不要和 PPT 同屏翻）

## 十三、完整示例：Prompt 工程原理课（话题 1 片段）

### 认知推演路径图（话题 1：Prompt 三角结构）

```markdown
- ⑤ 话题1：Prompt三角结构（10min）
    
    - 认知台阶1：烂Prompt → 揭示「缺角色」
        - 🔑 认知缺口：展示一个烂Prompt：「帮我写个方案」+ AI 烂输出
          你：「这个 Prompt 为什么烂？你先想 5 秒」
        - 📖 揭示：「因为它缺了最重要的东西——角色。你没告诉 AI 你是谁，
          它就猜一个最平均的用户。最平均的用户得到最平均的输出。」
    
    - 认知台阶2：加角色 → 揭示角色约束输出空间
        - 🔑 认知缺口：「我只加一句话——『你是一位资深产品经理』。
          你猜输出会有什么变化？先想，再看。」
        - 📖 揭示：「AI 不再写泛泛的方案了。它用产品经理的语言、框架、
          关注点来写。为什么？因为角色约束了它的输出空间。」
    
    - 认知台阶3：加任务+格式约束 → 揭示三要素叠加效应
        - 🔑 认知缺口：「现在角色有了，但还缺什么？
          你只告诉了它『你是谁』，没告诉它『你要什么、怎么给』。」
        - 📖 揭示：同时展示三要素完整版 vs 缺角版的对比
        - ⚡ 反直觉时刻：「你以为多写几个字只是锦上添花，但实际上——
          三要素齐全 vs 裸写，输出质量差一个量级。」
    
    - 🎯 闭合句：「所以你只需要记住一件事——
      Prompt 不是在和 AI 说话，是在和概率分布谈判。
      你给的约束越多，它猜的空间越小，输出越准。」
    
    - 🗣 L4 框架锁死（过渡）：
      「好，你看到了三角结构的力量。但它有一个隐藏前提——
      你的约束必须『有效』。什么是无效约束？我们来看——」
```

### 对应五层密度逐字稿（话题 1 完整版）

```markdown
🗣 L5（开场，逐句锁死）：
「我们从一个真实的失败开始。这个 Prompt 只有一句话——
『帮我写个方案』。你看 AI 的输出。你看得下去吗？

你可能觉得——『是我没说清楚』。但真相更残酷——
不是你『没说清楚』，是你根本不知道要说什么。」

（切页→烂Prompt + 烂输出对比）

🗣 L3（逻辑链锁死，核心推导）：
「为什么烂？
→ 因为你没告诉 AI 你是谁。
→ 它不知道你是谁，就猜一个最平均的用户。
→ 最平均的用户得到最平均的输出。
→ 这就是缺角色的代价。」

🔑 停顿 3 秒

🗣 L3（继续逻辑链）：
「现在我们加一个角色——只加这一个变量。
你是一位资深产品经理。同样的任务——写方案。
你猜输出会有什么变化？先想 5 秒。」

（切页→加角色后的输出）

「它开始用产品经理的语言写。它开始关注竞品分析、用户画像、MVP——
这些是『产品经理』这个角色自带的上下文。

为什么？因为——角色不是礼貌用语。
角色是你和 AI 之间唯一的上下文契约。
你给它一个角色，它就把自己『装进』这个角色里。」

🔑 停顿 3 秒

🗣 L3（逻辑链锁死）：
「角色有了。够了吗？不够。
你只告诉了它你是谁，没告诉它——
你要什么、怎么给、给多少。

这就是另外两个角：任务和约束。」

（切页→三角结构图，逐个出现三个角）

「缺一个角，AI 就猜一个角。
三个角齐了，AI 的『猜』被压缩到最小范围。
输出质量——差一个量级。」

🗣 ⚡ L5（反直觉时刻，逐句锁死）：
「如果我告诉你——你多写的这几个字，
不是锦上添花，而是决定输出质量的关键杠杆。
你信吗？」

（切页→三要素齐全版 vs 裸写版 并列对比）

「差距不在 AI。差距在你的 Prompt 结构。」

🗣 🎯 L5（闭合句，逐句锁死）：
「所以你只需要记住一件事——
Prompt 不是在和 AI 说话，是在和概率分布谈判。
你给的约束越多，它猜的空间越小，输出越准。」

🗣 L4（框架锁死，过渡）：
「好。你看到了三角结构的力量。
但它有一个隐藏前提——你的约束必须『有效』。
什么是无效约束？我们看下一个话题。」
```

## 十四、全局铁律

| # | 铁律 | 违反后果 |
|---|---|---|
| 1 | 逐字稿先于 PPT。PPT 被逐字稿反推 | 反过来做 = PPT 和嘴打架 |
| 2 | 每个认知台阶先问再答。不问就答 = 灌输 | 学生被动接收 |
| 3 | 一句只做一件事 | 认知过载 |
| 4 | 两句话间必须是因果/递进/转折之一。没有 = 废话 | 逻辑断裂，学生掉线 |
| 5 | 每个话题结束必有一句闭合句 | 学生不知道重点是什么 |
| 6 | 任何两个锚点间不超过 5 分钟 | 枯燥段 = 学生走神 |
| 7 | 反直觉时刻 ≥ 3 个（45 分钟课） | 全程平铺直叙 |
| 8 | PPT 每 30–60 秒切一页，每页只一个信息 | 视觉和听觉打架 |
| 9 | 开场 2 分钟 L5 写死。收口 1 分钟 L5 写死 | 开场散 = 全场散；收口烂 = 白上 |
| 10 | 案例只选一个，推三遍，不选三个各推一遍 | 认知不深 |
| 11 | 逻辑链测试 + 锚点检查不可跳过 | 带着逻辑断裂上台 |
| 12 | 访谈在动笔前。先有用户原话，后有逐字稿 | 打的痛点可能是你假设的 |

## 十八、实操课 vs 理论课 快速对照卡

| 维度 | 实操课 | 理论课 |
|---|---|---|
| **核心武器** | 你的手 | 你的嘴 |
| **课程推进力** | 操作演示 | 认知推演 |
| **案例手法** | 三段平行时空（并列对比） | 三遍推演（纵深剥开） |
| **稿子形态** | 双轨脚本（操作+讲解+停顿） | 五层密度逐字稿 |
| **密度层级** | 3 层 | 5 层 |
| **PPT 角色** | 配角，15–20 页 | 主角，60–90 页，30–60 秒切页 |
| **致命风险** | 翻车（AI 不可控） | 枯燥（认知过载） |
| **审查方式** | 静默演练 | 逻辑链测试 + 锚点间隔检查 |
| **最大禁忌** | 等待期沉默 | 超过 5 分钟无锚点 |
