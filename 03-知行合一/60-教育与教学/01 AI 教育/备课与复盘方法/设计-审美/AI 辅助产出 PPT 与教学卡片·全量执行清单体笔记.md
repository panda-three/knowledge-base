# AI 辅助产出 PPT 与教学卡片·全量执行清单体笔记

---

## 一、核心原则：PPT 和卡片都是「被反推出来的」，不是「先做出来的」

### 一条铁律管两个产出物

| 产出物 | 反推来源 | 角色 |
|---|---|---|
| **PPT** | 被双轨脚本（实操课）或五层逐字稿（理论课）反推 | 屏幕上的视觉锚点 |
| **教学卡片** | 被方法论模型 + 学生常见错误 + 练习需求反推 | 学生带走的「可复用工具」 |

**核心认知**：PPT 和卡片都不是「设计出来的」，是「从教学逻辑里长出来的」。教学逻辑没定 → PPT 和卡片做再多也是废的。先定脚本/逐字稿，再反推视觉。

## 二、PPT：AI 辅助反推全流程

### Step 0：先建 PPT 审美池子（你亲自做，AI 帮你搜集）

**为什么这一步不能跳过**：你不知道什么样的 PPT 是「好的」，AI 给你生成一堆你也判断不了。

**操作**：

| 你负责 | AI 帮你 |
|---|---|
| 找 5–10 份你觉得最好的教学 PPT（一堂的、你认可的讲师的） | 帮你全网搜索「最佳教学 PPT 设计案例」 |
| 逐页标注：这一页好在哪？信息量？切换节奏？视觉重心？ | — |
| 提炼你自己的「PPT 审美标准」——3–5 条 | — |

**一堂级 PPT 审美标准速查**：

| 标准 | 含义 | 反例 |
|---|---|---|
| **一页只一个信息** | 大字标题 + 一个视觉元素，绝不超过 3 行字 | 一页上塞了标题+5 个要点+一张图 |
| **翻页 = 注意力锚点** | 每 30–60 秒切一页，切页本身就是节奏 | 一页 PPT 讲 5 分钟 |
| **形式重心 = 内容重心** | 最想让学生看的，视觉上最突出 | 最想让学生看结论，但结论在角落里 12px |
| **留白 > 填满** | 宁愿一页 10 个字，不等于一页 100 个字 | 留白恐惧症，哪空补哪 |
| **对比靠位置，不靠文字** | 左右分屏对比 > 上下排列对比 > 同一页两个框 | 对比内容放在同一段文字里 |

### Step 1：从脚本/逐字稿反推 PPT 内容结构

**这是最关键的一步——先定内容，再定视觉。**

**实操课反推规则**（从双轨脚本反推）：

| 双轨脚本里的内容 | PPT 对应处理 |
|---|---|
| 「屏幕」列写了什么 | PPT 就做什么页 |
| 「播放音频/视频/演示」 | PPT 一页大字「先听/看，别判断」 |
| 「停顿点」标记 | PPT 单独一页，大字留白 |
| 「三段对比」 | PPT 三行大字并列 + 核心差异关键词 |
| 「闭合句/口诀」 | PPT 一整页只有那句口诀，最大字号 |
| 开场钩子 | PPT 一页，一个问题或一句反常识，不写课程标题 |
| 收口总结 | PPT 一页，只有最后一句话 |

**理论课反推规则**（从五层逐字稿反推）：

| 逐字稿里的内容 | PPT 对应处理 |
|---|---|
| 认知缺口（🔑） | 一整页只有那个问题，大字 |
| 反直觉时刻（⚡） | 「你以为 A」→ 切下一页「其实是 B」 |
| 闭合句（🎯） | 一整页只有那句闭合句 |
| 认知台阶间的过渡（L4） | 一整页只写下一话题的标题 |
| 案例对比 | 左右分屏，不并列在一页 |
| 方法论模型图 | 一页只放一个干净的模型图，不加满注解 |

**你现在用 AI 做这一步**：

**提示词模板**：

```
以下是我的[双轨脚本/五层逐字稿]。请帮我反推出 PPT 的每一页内容：

严格遵循以下反推规则：
[粘贴实操课反推规则 或 理论课反推规则——从上面选对应的]

输出格式——每一页一行：
| 页码 | PPT页面内容（一句话描述） | 对应脚本的哪个位置 |

[粘贴你的双轨脚本或逐字稿]
```

**你的操作**：拿到 AI 出的内容结构后，逐行审核——有没有哪一页塞了两个信息？有没有哪一段脚本没对应 PPT 页？删多余的，补缺失的。**这一步不做视觉，只定内容。**

### Step 2：逐页生成视觉方案

**内容结构定稿后，让 AI 一页一页出视觉方案。不要一次生成全部——一页一页调。**

**提示词模板（逐页用）**：

```
请为以下 PPT 页面设计视觉方案：

页面内容：[粘贴 Step 1 输出的一行——比如"一整页只有『Prompt 不是在和 AI 说话，是在和概率分布谈判』"]

设计要求：
- 只承载这一个信息
- 大字标题，字体足够大（想象投影到屏幕上最后一排也能看清）
- 背景干净，不用复杂装饰
- 如果有对比，用左右分屏
- 配色方案：[你的配色偏好，比如深蓝底白字 / 白底黑字+一个强调色]

请输出：
1. 页面布局描述（文字放哪、多大、对齐方式）
2. 配色建议（背景色/文字色/强调色）
3. 如果需要配图，配什么类型的图
```

**你的操作**：AI 出方案 → 你在 PPT 工具里做出来 → 预览 → 不满意就追问 AI 调。

**追问模板**：

```
这一页我还是觉得太空/太满/重点不突出。
问题描述：[具体说你觉得哪不对]
请给我 3 个修改方案。
```

### Step 3：实操课 vs 理论课的 PPT 差异——AI 必须知道的

**在每次给 AI 的提示词前，加上这段上下文**：

如果是实操课，加：
```
这是一节实操课（实时演示驱动），PPT 是配角。大部分时间屏幕上是
VS Code / 浏览器 / AI 工具界面，PPT 只在开场、过渡、方法论讲解、
停顿点和收口时切回来。PPT 总页数不超过 20 页。
```

如果是理论课，加：
```
这是一节理论课，PPT 是学生唯一的视觉来源。PPT 总页数 60-90 页，
每 30-60 秒切一页。每页只承载一个信息。翻页本身就是注意力锚点。
```

---

### Step 4：你最终审核——三问定稿

| 审核问题 | 通过标准 |
|---|---|
| **删** | 每一页上，有没有一个字是可以删掉的？有 → 删 |
| **拆** | 有没有哪一页同时承载了两个信息？有 → 拆成两页 |
| **看** | 连续翻一遍，节奏有没有「这里应该切一页但没有」的空白？有 → 补 |

**铁律**：PPT 定稿前，你自己连续翻一遍，模拟上课节奏。任何一个让你觉得「这段有点长」的地方，加一页切过去。

## 三、教学卡片：AI 辅助设计全流程

### 什么是教学卡片

**定义**：学生可以带走、贴在桌上、反复翻看的「最小可复用单元」。不是讲义，不是笔记，是「做完这件事只需要看这一张卡」。

**一堂五段范式中「实操工具」段的标准产物**：小抄、画布、检查单——卡片就是这些工具的实体形态。

---

### 卡片类型定义（先定类型，再设计）

| 类型 | 功能 | 典型大小 | C 语言循环课示例 |
|---|---|---|---|
| **小抄卡** | 关键语法/公式/模板，忘了看一眼 | 手机屏幕大小 | for 循环三表达式模板 + 常见错误 |
| **对比卡** | A vs B 并列对比，一眼看出差距 | 横版，左右分屏 | `i<=n` vs `i<n` 的边界对比 |
| **检查单卡** | 做完这件事必须检查的 N 个点 | 纵向列表 | 「写循环后必查 5 项」 |
| **模型卡** | 方法论模型图 + 口诀 | 一张图 + 一句话 | 「循环三步法：定界→定步→定体」 |
| **练习卡** | 一道题 + 判断标准，学生自己做 | 题面 + 反面答案 | 「预测输出」题 + AI 逐轮执行答案 |

---

### 卡片设计四原则

| 原则 | 含义 | 反例 |
|---|---|---|
| **一卡一用** | 一张卡片只解决一个问题 | 小抄卡上同时放语法+对比+练习 |
| **即看即懂** | 不需要解释，不需要上下文，拿起来就能用 | 卡上写「详见第三章」 |
| **可独立携带** | 截屏就能存，打印就能贴 | 依赖别的文档才能理解 |
| **学生视角** | 不是「老师觉得有用」，是「学生什么时候会拿出来看」 | 卡片内容是老师的教案不是学生的痛点 |

---

### 各类型卡片的 AI 生成流程

#### 类型①：小抄卡

**适用场景**：学生写代码时放旁边，忘了看一眼。

**提示词模板**：

```
请为 C 语言 for 循环生成一张「小抄卡」：

卡片类型：小抄卡（学生写代码时放旁边快速查阅）
卡片尺寸：手机屏幕大小（约 750×1334 像素比例）

内容要求：
1. for 循环的标准语法模板（三个表达式标注清楚各自的作用）
2. 最常见的 3 个错误写法 + 正确写法对比
3. 不超过 8 行信息
4. 用「学生一看就懂」的语言，不要教科书腔

同时给出：
- 卡片视觉布局描述（文字排版、强调色位置、分区）
- 如果要配图，配什么
```

#### 类型②：对比卡

**适用场景**：学生搞混某个边界条件时，这张卡比任何讲解都快。

**提示词模板**：

```
请为 C 语言循环的边界条件设计一张「对比卡」：

对比主题：< vs <= 在循环条件中的差异
卡片类型：对比卡（左右分屏并列对比）
对比内容：用同一段代码，只改这一个字符，展示输出差异

要求：
- 左右两栏，标注「代码 A：i < n」和「代码 B：i <= n」
- 每栏展示：代码片段 + 实际输出 + 循环次数
- 最下方一句话结论：「差一个等号，多跑一圈」
- 学生看完 10 秒内能理解差距
```

#### 类型③：检查单卡

**适用场景**：学生写完循环后，对照自查。

**提示词模板**：

```
请为 C 语言循环设计一张「写循环后必查 5 项」检查单卡：

检查单类型：写完代码后逐项打勾
目标学生：刚学完循环、经常出低级错误的 L2 学生

要求：
- 5 个检查项，按「最容易错 → 最容易忽略」排序
- 每项一句话，动词开头（「检查___」「确认___」）
- 每项附一个「如果错了会怎样」的迷你示例
- 卡片底部留一行「以上全对 → 进入下一个挑战」
```

#### 类型④：模型卡

**适用场景**：学生学完方法论后，这张卡帮他们记住核心框架。

**提示词模板**：

```
请为「循环三步法」设计一张方法论模型卡：

模型名称：循环三步法
三步：定界 → 定步 → 定体
口诀：「先定边界再动笔，内层走完外层一」

要求：
- 视觉中心是一个三段的流程图或三个方块
- 每步下面一句话解释
- 口诀在卡片底部，最大字号
- 干净、简单，学生一眼能记住这个框架
```

#### 类型⑤：练习卡

**适用场景**：学生课后自测，正面是题，背面是答案和解析。

**提示词模板**：

```
请为 C 语言嵌套循环设计一张「练习卡」：

类型：练习卡（正面题目 + 反面答案）
目标段位：L3 学生（基础循环已会，嵌套还容易晕）

正面——题目：
- 一段嵌套循环代码
- 问题：「请预测这段代码的完整输出」
- 代码中故意放一个容易预测错的边界条件

反面——答案：
- AI 逐轮执行表格（标明每一轮各变量的值和输出）
- 标注最容易预测错的那一步（用❗标记）
- 一句话总结：「大多数人在这里预测错，因为___」
```

**一堂级卡片审美速查**：

| 标准 | 含义 |
|---|---|
| **即看即懂** | 不需要任何上下文，拿起来就能用 |
| **一卡一块** | 一张卡只解决一个问题。两个问题 = 两张卡 |
| **最简视觉** | 能不用图就不用图，能用字就不用装饰 |
| **学生什么时候用** | 设计时脑子里有一个具体场景——学生写代码时？复习时？考试前？ |

### 卡片设计完成后——你审核的三问

| 审核问题 | 通过标准 |
|---|---|
| **能用吗** | 你想象自己是一个刚学完循环的学生，拿到这张卡，能不能独立使用？ |
| **会看吗** | 学生什么时候会拿出这张卡？如果没有「拿出来看一眼」的场景 → 卡没价值 |
| **够简吗** | 这张卡上还有没有一个字是可以删掉的？有 → 删 |

## 四、实操课卡片 vs 理论课卡片

| | 实操课卡片 | 理论课卡片 |
|---|---|---|
| **主力类型** | 小抄卡、检查单卡、练习卡 | 对比卡、模型卡 |
| **使用场景** | 学生动手操作时放旁边对照 | 学生理解概念后用来记忆和回顾 |
| **设计重点** | 快查快用，信息密度高但一瞥即得 | 框架清晰，一张图 + 一句话钉死核心 |
| **典型尺寸** | 手机屏幕大小，方便截屏存 | 可大可小，重点是模型图 + 口诀 |

## 五、PPT + 卡片联合作战：同一节课的两个产物

### 以 C 语言循环课为例

| 课程段 | PPT 页 | 对应卡片 | 卡片什么时候给 |
|---|---|---|---|
| ⑤ 方法论 | 模型图：「循环三步法」 | 模型卡：循环三步法 | 讲完方法论当场发 |
| ⑥⑦⑧ 三段演示 | 三段代码对比页 | 对比卡：`<` vs `<=` | 三段对比收口后发 |
| ⑨ 横评总结 | 三个版本并列 + 差距关键词 | — | — |
| ⑩ 套路沉淀 | 口诀一整页 | 检查单卡：写循环后必查 5 项 | 讲完口诀后发 |
| ⑫ 作业 | 作业要求 | 练习卡 ×3（L2/L3/L4 各一张） | 下课时发 |

**核心逻辑**：PPT 是上课时屏幕上的视觉锚点，卡片是学生带回家的「可复用工具」。PPT 决定学生「此刻看什么」，卡片决定学生「课后记住什么」。

## 九、全局铁律速查

| # | 铁律 |
|---|---|
| 1 | 先定脚本，再反推 PPT。反过来做 = PPT 和嘴打架 |
| 2 | 先定内容，再定视觉。内容没定就做视觉 = 白做 |
| 3 | 一页只一个信息。一页两个信息 = 学生不知道看哪个 |
| 4 | 一卡只解决一个问题。一张卡两个问题 = 哪个都没解决 |
| 5 | 卡片设计时脑子里必须有一个具体使用场景——「学生什么时候掏出这张卡」 |
| 6 | 最终审核 = 删字。PPT 和卡片上任何可删的字，删 |
| 7 | AI 出方案，你拍板。AI 给你 5 个布局，你选 1 个 |
| 8 | 建审美池子不是一次性动作——每次看到好的 PPT 和卡片，扔进池子 |
