# for 循环实操课 V2

> 版本定位：把原来的“知识点讲解稿”升级为一堂**实时写代码演示驱动**的实操课。  
> 主屏幕不是 PPT，而是 VS Code / Dev-C++：学生跟着老师一起看变量怎么动、边界怎么错、循环怎么把重复劳动交给电脑。

---

## 0. 这版课的审美标准

这节课不再按“先讲概念 → 再讲语法 → 再做题”的平铺方式走，而是按实操课的审美做三件事：

1. **用屏幕制造冲击**：先让学生看到“手写 5 行重复代码”很笨，再用 for 循环一行解决。
2. **用平行时空建立段位感**：同一类任务，连续展示 L1 裸跑版、L3 规范版、L5 高手版，让学生看见差距。
3. **用停顿让学生自己跑脑子**：关键操作前先猜，运行结果后再复盘，不把学生变成抄代码机器。

一句话目标：

> 学生下课后不是只会背 `for(初始化;条件;变化)`，而是能在脑子里追踪：**i 从几开始、到哪停、每次怎么变、循环体重复做什么。**

## 4. 核心模型：循环四问

> 🗣 **L5 闭合句**  
> “写 for 循环，不是先背格式，而是先问四句话：从哪开始？到哪结束？每次怎么变？重复做什么？”

```c
for (从哪开始; 到哪结束; 每次怎么变) {
    重复做什么;
}
```

### 4.1 四问对应 for 的四个位置

| 四问 | for 中的位置 | 学生常见错误 | 纠正话术 |
|---|---|---|---|
| 从哪开始？ | 初始化语句 | 不知道 `i` 初始值该写几 | “第一个要处理的数据是谁，i 就先等于谁。” |
| 到哪结束？ | 条件判断语句 | `<=` 和 `<` 混乱 | “最后一个要不要被处理？要，就通常写 `<=`。” |
| 每次怎么变？ | 条件控制语句 | 忘记 `i++`，死循环 | “不变化，循环就永远走不出去。” |
| 重复做什么？ | 循环体 | 把不该重复的代码放进去 | “只有每一轮都要做的事，才放进大括号。” |

### 4.2 口诀

> **先定起点，再定终点；每轮变一次，身体做重复。**

### 节点⑤ 方法论：for 循环执行流程（4min）

屏幕代码：

```c
#include <stdio.h>

int main() {
    int i;
    for (i = 1; i <= 3; i++) {
        printf("第 %d 次：我爱 C 语言!\n", i);
    }
    return 0;
}
```

| 时间 | 屏幕 | 操作（手） | 讲解（嘴） | 停顿 |
|---|---|---|---|---|
| 0:00 | 代码框架 | 先写 `for ( ; ; ) { }` | 🗣 L3：先看骨架，for 里面有两个分号，分成三格 | — |
| 0:40 | 填 `i = 1` | 写初始化 | 🗣 L3：第一格，只执行一次，给 i 一个起点 | — |
| 1:15 | 填 `i <= 3` | 写条件 | 🗣 L3：第二格，每轮都检查，成立才进大括号 | — |
| 1:50 | 填 `i++` | 写变化 | 🗣 L3：第三格，每轮结束后走一步 | — |
| 2:20 | 写循环体 | 写 `printf` | 🗣 L3：大括号里才是重复做的事 | — |
| 3:00 | 运行输出 | 编译运行 | 🗣 L5：“for 的顺序不是从左到右一次走完，而是：起点一次，判断多次，身体多次，变化多次。” | **复盘停顿**：让学生说顺序 |

执行流程板书：

```txt
① i = 1
② 判断 i <= 3
③ 执行 printf
④ i++
⑤ 回到②继续判断
```

### 节点⑨ 平行时空③：L5 高手版——条件统计 + 水仙花数（8min）

#### 任务 A：统计一个范围内能同时被 6 和 8 整除的数字个数

需求：键盘录入两个数字，表示范围 `[start, end]`，统计这个范围中既能被 6 整除，又能被 8 整除的数字个数。

```c
#include <stdio.h>

int main() {
    int start, end;
    int i;
    int count = 0;

    printf("请输入范围的开始和结束：");
    scanf("%d %d", &start, &end);

    for (i = start; i <= end; i++) {
        if (i % 6 == 0 && i % 8 == 0) {
            count++;
        }
    }

    printf("满足条件的数字个数是：%d\n", count);
    return 0;
}
```

四问拆解：

| 四问 | 本题答案 |
|---|---|
| 从哪开始？ | `i = start` |
| 到哪结束？ | `i <= end` |
| 每次怎么变？ | `i++` |
| 重复做什么？ | 判断 `i` 是否同时被 6 和 8 整除，是就 `count++` |

#### 任务 B：打印 100-999 所有水仙花数

```c
#include <stdio.h>

int main() {
    int i;

    for (i = 100; i <= 999; i++) {
        int ge = i % 10;
        int shi = i / 10 % 10;
        int bai = i / 100;

        if (bai * bai * bai + shi * shi * shi + ge * ge * ge == i) {
            printf("%d\n", i);
        }
    }

    return 0;
}
```

| 时间 | 屏幕 | 操作（手） | 讲解（嘴） | 停顿 |
|---|---|---|---|---|
| 0:00 | 任务 A 需求 | 先不写代码，写四问表 | 🗣 L5：“高手版不是代码更长，而是写代码前先把题目翻译成循环四问。” | — |
| 1:10 | 写输入和 `count` | 写 `scanf`、`count = 0` | 🗣 L3：`count` 是计数器，跟 `sum` 一样，是篮子 | — |
| 2:20 | 写 for | 按四问填 for | 🗣 L3：范围从用户输入来，所以起点终点不是固定数字 | — |
| 3:20 | 写 if 条件 | 写 `% 6 == 0 && % 8 == 0` | 🗣 L3：每个数字都问同一个问题，符合就计数 | **复盘停顿**：问“count++ 放在 if 里还是外？” |
| 4:30 | 任务 B 需求 | 切到水仙花数 | 🗣 L5：“水仙花数看起来难，其实还是循环四问，只是循环体里多了一步拆数字。” | — |
| 5:30 | 写拆位代码 | 写 `ge/shi/bai` | 🗣 L3：个位 `%10`，十位 `/10%10`，百位 `/100` | — |
| 6:40 | 写 if 并运行 | 编译运行 | 🗣 L3：判断立方和是否等于自己 | — |
| 7:30 | 输出结果 | 圈出 153、370、371、407 | 🗣 L5：“你看，复杂题不是突然出现的。它只是：循环负责一个个试，if 负责判断，变量负责记录。” | **复盘停顿** |

### 节点⑪ 现场出题：跑完整流程（8min）

推荐现场题三选一，根据课堂状态选择。

| 题目 | 难度 | 适用状态 |
|---|---|---|
| 打印 1-100 中所有偶数 | 低 | 学生刚入门，增强信心 |
| 求 1-n 的和 | 中 | 学生已经懂变量累加 |
| 统计 1-100 中能被 3 整除的数的个数 | 中 | 衔接条件统计 |

#### 示例：打印 1-100 中所有偶数

```c
#include <stdio.h>

int main() {
    int i;

    for (i = 1; i <= 100; i++) {
        if (i % 2 == 0) {
            printf("%d ", i);
        }
    }

    return 0;
}
```

| 2:30 | for 框架 | 根据四问写 for | 🗣 L3：学生说一个，老师写一个 | — |
| 4:00 | if 条件 | 引导学生说条件 | 🗣 L3：偶数条件是 `% 2 == 0` | — |
| 5:00 | 运行 | 编译运行 | 🗣 L3：先看输出，再评价 | — |
| 6:00 | 改写挑战 | 把 `i=1;i<=100;i++` 改成 `i=2;i<=100;i+=2` | 🗣 L5：“同一道题，还有更直接的走法：既然只要偶数，那 i 可以每次走 2 步。” | **复盘停顿** |

进阶写法：

```c
#include <stdio.h>

int main() {
    int i;

    for (i = 2; i <= 100; i += 2) {
        printf("%d ", i);
    }

    return 0;
}
```

### 节点⑫ 作业 + Candy（1min）

#### 作业：只追一个动作

> 请独立完成一道题：  
> **键盘录入一个正整数 n，求 1 到 n 之间所有奇数的和。**

提交内容只要三样：

1. 代码截图
2. 运行结果截图
3. 用一句话写出你的循环四问：从哪开始、到哪结束、每次怎么变、重复做什么

参考答案：

```c
#include <stdio.h>

int main() {
    int n;
    int i;
    int sum = 0;

    printf("请输入 n：");
    scanf("%d", &n);

    for (i = 1; i <= n; i += 2) {
        sum = sum + i;
    }

    printf("1 到 %d 之间所有奇数的和是：%d\n", n, sum);
    return 0;
}
```

#### Candy：下节课钩子

> 🗣 L5  
> “今天我们让 i 一次走一步，也让 i 一次走两步。下节课你会看到更刺激的：一个循环里面再放一个循环。到那时，电脑不是走一条线，而是在走一个方阵。九九乘法表就是这么来的。”

## 7. 翻车预案

| 翻车场景              | 现场表现        | 处理动作              | 话术                                |
| ----------------- | ----------- | ----------------- | --------------------------------- |
| 少分号               | 编译报错        | 指给学生看报错行，补分号后重跑   | “这不是事故，这是 C 语言在提醒你：语句要有句号。”       |
| 中文标点              | 分号/括号用了中文   | 切英文输入法，重打一遍       | “写代码时，标点必须是英文。中文标点看起来像，编译器不认。”    |
| 死循环               | 程序一直输出      | 终止运行，回到 `i++`     | “循环走不出去，通常是变量没变化，或者变化方向错了。”       |
| 输出少一个             | 1-5 只输出 1-4 | 对比 `<` 和 `<=`     | “最后一个要不要处理？要，就别把等号丢了。”            |
| 输出多一个             | 输出到 6       | 检查结束条件            | “多一个也是边界错。循环题最常见的错不是中间，是头和尾。”     |
| `count++` 放错      | 每轮都计数       | 把 `count++` 移进 if | “计数器不是每轮都加，而是符合条件才加。”             |
| 学生看不懂 `sum=sum+i` | 觉得左右相等很怪    | 用篮子比喻 + 追踪表       | “等号右边先算，再把结果放回左边。sum 是篮子，不是数学方程。” |
| 水仙花数拆位卡住          | 个十百位写错      | 先用 153 手算，再写表达式   | “不会拆位，就先拿一个具体数试，不要空想。”            |

## 11. 一句话收住

> for 循环不是一段格式，而是一种思路：  
> **找到一组要处理的数据，让变量一个个走过去，每走到一个位置，就执行同一套动作。**
