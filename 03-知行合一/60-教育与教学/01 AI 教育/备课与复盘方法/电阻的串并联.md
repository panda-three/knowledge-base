## **一、部分电路欧姆定律**

**1、概念**

德国物理学家**欧姆**首先在19世纪初期用实验的方法研究得出：在一段**不包括电源**的电路中，通过导体的电流，与导体两端的电压成正比，与导体的电阻成反比。

**2、公式**

- 电流（I）的单位是安培（A）     1A = 1×103mA(毫安) = 1×106uA(微安)
- 电压（U）的单位是伏特（V）    1V = 1×103mV(毫伏) **=** 1×103uV(微安)
- 电阻（R）的单位是欧姆（Ω）    1000Ω = 1KΩ

## **二、全电路欧姆定律**

### **1、内容**

电流与电源的电动势成正比，与整个电路的内外阻之和成反比，

即I = $\frac{E}{R+r}$ 。

### **3、负载最大功率**

## **三、电阻的串联**

**1、定义：**

把电阻一个接一个地依次连接起来。

**2、特点：**

①电路中各处电流相等(I = I1 = I2=I3)。

**②**总电压等于各电压之和(U = U1+U2+U3)。

③总电阻等于各电阻之和(R = R1+R2+R3)。

④分压公式U1 = $\frac{R1}{R1+R2}$ U，U2 = $\frac{R2}{R1+R2}$ U

## **四、电阻的并联**

**1、定义：**

把几个电阻并列地连接起来，就组成了并联电路。

**2、特点：**

①电路中总电流等于各电流之和(I = I1 + I2 + I3)。

**②**电压处处相等(U = U1=U2=U3)。

③总电阻地倒数等于各电阻地倒数之和( $\frac{1}{R总}$  = $\frac{1}{R1}$ + $\frac{1}{R2}$ + $\frac{1}{R3}$ )，对于两个电阻

R总 = $\frac{R1\times R2}{R1+R2}$ 。

④分流公式I1 = $\frac{R2}{R1+R2}$ I，I2 = $\frac{R1}{R1+R2}I$
