# 开始上课

Hello，大家好啊，

我是 panda，欢迎大家回来继续上课，进入本周的专业课成长时间。

如果直播间有新同学的话，先简单说一下：这门课我们不是为了背一堆公式，而是为了把专业课里最容易丢分的地方，一点点讲明白。

今天这节课，我们进入直流电路里非常核心的一块：

> **电阻的串联和并联。**

【热场】来来来，我们先热个身。

大家先别急着想“串联”“并联”这两个词。

一上来就说概念，肯定很抽象。

我们先想一个更简单的生活场景：

假设你从教室门口走到讲台，有两种路。

第一种，只有一条窄路，所有人都必须一个接一个往前走。

第二种，中间分出来好几条路，有的人走左边，有的人走右边，最后都能到同一个地方。

来，大家凭直觉想一下：

哪一种更容易堵？

肯定是第一种，对不对？

因为所有人都挤在一条路上。

第二种为什么不容易堵？

因为路变多了，人可以分开走。

电路其实也可以先这么理解。

电流不是一个很神秘的东西，你可以先把它想成“在电路里走路的人”。

有时候，它只有一条路，只能一个元件一个元件地经过。

有时候，它走到某个地方，会分成好几条路，各走各的。

今天这节课，我们真正要学的不是先背公式，而是先看懂一件事：

> **电流到底是只走一条路，还是会分成好几条路？**

只走一条路，后面我们把它叫串联。

分成好几条路，后面我们把它叫并联。

你先把“走路”这个感觉建立起来，串联和并联就不难了。

---

## 快速回顾

上节或者前面我们已经接触过三个基本物理量：

| 名称 | 符号 | 单位 |
|---|---|---|
| 电流 | I | 安培 A |
| 电压 | U | 伏特 V |
| 电阻 | R | 欧姆 Ω |

再回顾一个最重要的公式：

```Plain
I = U / R
```

也就是欧姆定律。

这个公式你们不要只把它当成数学式子。

它背后其实是一句很朴素的话：

> 电压是推动，电阻是阻碍，电流是最后真正流起来的结果。

电压越大，推动越强，电流越大。

电阻越大，阻碍越强，电流越小。

但是注意，后面做串并联题的时候，最容易错的地方就是：只盯一个量，不看条件。

比如，电阻变大，电流一定变小吗？

不一定。

如果电压不变，电阻变大，电流变小。

如果电压也变了，那就不能只凭一句话判断。

所以今天整节课，我们都要带着一个习惯：

> **先判断结构，再使用公式。**

---

## 为什么要学？

为什么要学电阻的串并联？

第一，考试会考。

直流电路里，串联、并联、混联、电压电流计算，是非常基础也非常高频的内容。

第二，后面很多内容都离不开它。

你后面学电路分析、功率、测量、电工实操，只要看到电路图，就绕不开串并联判断。

第三，它其实是电路思维的分水岭。

有些同学学电路，一直停留在背公式：

```Plain
串联 R 相加
并联倒数相加
```

但一到图复杂一点，就不知道谁和谁串联，谁和谁并联。

这说明问题不在公式，问题在结构没看懂。

所以今天我们不先死背公式。

我们先把电路看成“路”。

串联，就是一条路。

并联，就是多条路。

只要这个感觉建立起来，公式就不是硬背出来的，而是推出来的。

## 预热思考题

来来，照例，给大家一个预热思考题。

这里可以放一张图：两只一样的小灯泡，接在同一个电源上。

第一种接法：电流只有一条路，必须先经过第一只灯泡，再经过第二只灯泡。

第二种接法：电流走到中间以后，分成两条路，一条路经过第一只灯泡，另一条路经过第二只灯泡。

我问大家两个问题：

> 哪一种接法里，每只灯泡更容易变暗？
>
> 哪一种接法里，即使其中一条路出了问题，另一条路还有可能继续工作？

大家先不要急着看公式，先凭“走路”的感觉猜一下。

如果所有电流都挤在一条路上，它经过的阻碍是不是更多？

如果电流可以分成几条路，它是不是更容易通过？

好，我们把这个现象先放在这里。

今天一整节课，就是解释这件事：

> 一条路的电路，有什么规律？
>
> 多条路的电路，又有什么规律？

等你能解释这两句话，后面的串联、并联、分压、分流就会好做很多。

# 体感：为什么要区分串联和并联

我们先不讲定义，先看现象。

假设有一个电源，两只一样的小灯泡。

如果电流从电源正极出来，先经过第一个灯泡，再经过第二个灯泡，最后回到电源负极。

这就像什么？

像一条单行道。

所有人都必须依次通过这两个路口。

电流也是一样，它没有别的路可以走。

这种结构，后面我们叫串联。

再看另一种。

电流从电源出来以后，到了一个分岔口，可以走第一只灯泡，也可以走第二只灯泡。

这就像什么？

像两条并排的路。

电流可以分开走。

这种结构，后面我们叫并联。

所以大家先记住最朴素的判断：

```Plain
串联：一条路
并联：多条路
```

不要先看它画得横还是竖。

不要先看它是不是摆在一起。

电路图里有些元件画得很近，但不一定并联。

有些元件画得不在一条直线上，但可能就是串联。

真正要看的是：

> 电流有没有分岔？

如果没有分岔，一路走到底，通常就是串联。

如果有分岔，几条支路接在同一对节点之间，通常就是并联。

这里大家一定要建立画面感。

电路不是一堆符号，电路是一条条可以走的路。

---

## 小结

串并联判断的第一句话：

```Plain
看电流有没有分岔。
```

没有分岔，一条路，串联。

有分岔，多条路，并联。

OK，有了这个体感，我们再回到计算地基：欧姆定律。

---

# 理解：欧姆定律是地基

在正式讲串联和并联之前，我们先把欧姆定律压实。

公式是：

```Plain
I = U / R
```

也可以变形为：

```Plain
U = I × R
R = U / I
```

很多同学的问题不是不会背公式，而是不知道什么时候用哪个式子。

我们用一句话来理解：

> 电压推动电流，电阻阻碍电流。

如果电阻不变，电压越大，电流越大。

如果电压不变，电阻越大，电流越小。

这里有一个很重要的条件意识。

比如我问：电阻变大，电流一定变小吗？

大家第一反应可能是：一定。

但严谨一点说：

> 在电压不变的情况下，电阻变大，电流才会变小。

这就是专业课里很重要的思维：

不要只看一个量，要看三个量之间的关系。

---

## 单位换算

这里顺手把单位也过一下。

电流 I 的单位是安培 A。

```Plain
1A = 10^3 mA = 10^6 μA
```

电压 U 的单位是伏特 V。

```Plain
1V = 10^3 mV = 10^6 μV
```

电阻 R 的单位是欧姆 Ω。

```Plain
1000Ω = 1kΩ
```

大家注意，单位换算不要写错。

尤其是毫、微、千这几个量级，考试里一换算错，后面全错。

---

## 欧姆定律的适用范围

再补一个点。

欧姆定律主要适用于线性电阻电路。

什么叫线性？

简单说，就是电压和电流大致成正比，图像像一条直线。

有些元件，比如白炽灯灯丝，刚通电时温度低，工作一会儿温度升高，电阻会变。

这个时候你就不能机械地认为它永远是一个固定电阻。

这不是今天的主线，但大家要有这个意识：

> 公式有适用条件。

---

## 小结

欧姆定律这一段，只抓一句话：

```Plain
不是背 I = U / R，而是看 U、I、R 谁不变，谁变化。
```

接下来，我们进入今天第一个重点：串联。

---

# 理解：电阻的串联

## 什么是串联？

我们先给定义。

把电阻一个接一个依次连接起来，电流只有一条通路，这种连接方式叫串联。

但是定义很书面，大家上课不用死背。

你就记这个判断：

> 电流有没有别的路可走？

如果没有，只能一个一个经过，那就是串联。

比如 R1、R2、R3 一个接一个接起来。

电流从电源出来以后，先经过 R1，再经过 R2，再经过 R3。

它中间没有分岔。

那它就是串联。

---

## 串联特点 1：电流处处相等

串联第一个特点：

```Plain
I = I1 = I2 = I3
```

为什么？

因为只有一条路。

电流没有地方分出去。

就像一条水管，中间没有分支，前面流过多少水，后面也要流过多少水。

所以串联电路里，各处电流相等。

这里大家不要把它背成一句空话。

它背后的原因是：

> 没有分岔。

只要你记住没有分岔，电流相等就非常自然。

---

## 串联特点 2：总电压等于各部分电压之和

串联第二个特点：

```Plain
U = U1 + U2 + U3
```

什么意思？

电源一共提供一个总电压。

这个总电压会被每个电阻分掉一部分。

R1 两端有 U1。

R2 两端有 U2。

R3 两端有 U3。

总的电压就是它们相加。

所以串联电路还有一个名字，大家可以这样理解：

> 串联电路会分电压。

这就是前面灯泡串起来变暗的原因之一。

两个灯泡串起来以后，每个灯泡分到的电压不再是完整电源电压，而是总电压的一部分。

电压变小，灯泡自然就暗。

---

## 串联特点 3：总电阻等于各电阻之和

串联第三个特点：

```Plain
R总 = R1 + R2 + R3
```

这个也不要死背。

你想一下，同一股电流要先经过 R1，再经过 R2，再经过 R3。

每经过一个电阻，都会受到一次阻碍。

几个阻碍连续叠加，总阻碍当然变大。

所以串联总电阻就是各电阻相加。

这句话非常重要：

> 串联是阻碍叠加。

所以串联电阻越多，总电阻越大。

总电阻越大，在电源电压不变时，总电流就越小。

这也解释了：为什么串联灯泡会变暗。

因为总电阻变大了，总电流变小了，每个灯泡分到的电压也变了。

---

## 串联特点 4：串联分压

接下来是串联最容易考的点：分压。

我们先不背公式，先推一遍。

串联里，电流相同。

对 R1 来说：

```Plain
U1 = I × R1
```

对 R2 来说：

```Plain
U2 = I × R2
```

注意，这两个式子里的 I 是同一个 I。

所以 U1 和 U2 的大小，就取决于 R1 和 R2 的大小。

因此：

```Plain
U1 : U2 = R1 : R2
```

这就是分压的本质。

电压不是平均分的。

电压是按电阻大小分的。

如果 R1 比 R2 大，R1 分到的电压就更多。

如果 R2 比 R1 大，R2 分到的电压就更多。

两个电阻串联时，常用公式是：

```Plain
U1 = R1 / (R1 + R2) × U
U2 = R2 / (R1 + R2) × U
```

但是大家记公式之前，先记人话：

> 串联分压，谁电阻大，谁分到的电压多。

---

## 案例 1：10V 分成 7V 和 3V

我们来做一个典型题。

题目是：

> 想要用两个电阻串联，将 10V 电压分成 7V 和 3V，要求总等效电阻为 200Ω，两个电阻应各为多少？

来来，先不要急着列公式。

第一步先判断结构。

两个电阻串联。

串联有什么规律？

电压比等于电阻比。

所以：

```Plain
R1 : R2 = U1 : U2 = 7 : 3
```

总电阻是 200Ω。

7 份加 3 份，一共 10 份。

10 份对应 200Ω。

那 1 份就是：

```Plain
200Ω ÷ 10 = 20Ω
```

所以 7 份是：

```Plain
7 × 20Ω = 140Ω
```

3 份是：

```Plain
3 × 20Ω = 60Ω
```

答案：

```Plain
R1 = 140Ω
R2 = 60Ω
```

大家看，这道题如果你背公式当然也能做。

但更快的方法是看比例。

因为串联分压，本质就是按电阻比例分电压。

---

## 案例 2：3Ω 和 6Ω 串联接 12V

再来一个简单题。

题目：

> R1 = 3Ω，R2 = 6Ω，两个电阻串联接在 12V 电源上，求 U1 和 U2。

第一步，判断结构。

串联。

第二步，求总电阻。

```Plain
R总 = R1 + R2 = 3Ω + 6Ω = 9Ω
```

第三步，求总电流。

```Plain
I = U / R总 = 12V / 9Ω = 4/3 A
```

第四步，分别求电压。

```Plain
U1 = I × R1 = 4/3 × 3 = 4V
U2 = I × R2 = 4/3 × 6 = 8V
```

检查一下：

```Plain
U1 + U2 = 4V + 8V = 12V
```

对上总电压。

这道题也可以直接用分压比例。

R1 : R2 = 3 : 6 = 1 : 2。

总电压 12V 按 1 : 2 分。

所以 U1 = 4V，U2 = 8V。

---

## 串联小结

串联这一段，我们只收四句话：

```Plain
1. 串联一条路，电流处处同。
2. 串联电压加，总压等于各部分电压之和。
3. 串联电阻加，阻碍一段段叠加。
4. 串联会分压，电阻大者多。
```

这四句话记住，串联题基本就稳了一半。

接下来，我们看串联的反面：并联。

---

# 理解：电阻的并联

## 什么是并联？

几个电阻并列地连接起来，形成多条电流通路，这种连接叫并联。

但这句话依然很书面。

我们换成更好判断的说法：

> 两个元件如果接在同一对节点之间，就是并联。

也可以说：

> 同头同尾，就是并联。

什么叫同头同尾？

比如 R1 的左端和 R2 的左端接在同一个点。

R1 的右端和 R2 的右端也接在同一个点。

那它们两端电压就一样。

这就是并联判断里最重要的一点。

不要只看画得是不是并排。

有些图画得歪歪扭扭，但只要同头同尾，就是并联。

---

## 并联特点 1：各支路电压相等

并联第一个特点：

```Plain
U = U1 = U2 = U3
```

为什么？

因为每一条支路都接在同一对节点上。

就像两条路的起点一样、终点也一样。

两端的电势差相同，所以电压相同。

这就是为什么家里的电器要并联。

如果每个电器都并联在电源两端，它们就都能获得相同的电压。

不会因为多插一个电器，前面的电器就被迫分掉一部分电压。

---

## 并联特点 2：总电流等于各支路电流之和

并联第二个特点：

```Plain
I = I1 + I2 + I3
```

为什么？

因为电流到了分岔口，会分成几路走。

每一条支路都有自己的电流。

最后回到电源时，这些电流又汇合起来。

所以总电流等于各支路电流之和。

这里大家可以想象水管。

一根主管分成三根支管，每根支管都有水流。

主管里的总水流量，就是几根支管水流量相加。

---

## 并联特点 3：总电阻倒数等于各电阻倒数之和

并联第三个特点，也是很多同学觉得最绕的地方：

```Plain
1/R总 = 1/R1 + 1/R2 + 1/R3
```

两个电阻并联时，常用公式是：

```Plain
R总 = R1 × R2 / (R1 + R2)
```

为什么并联这么麻烦？

我们推一下。

并联里，电压相同。

总电流等于支路电流之和。

所以：

```Plain
I = I1 + I2
```

根据欧姆定律：

```Plain
I = U / R总
I1 = U / R1
I2 = U / R2
```

代进去：

```Plain
U / R总 = U / R1 + U / R2
```

两边同时除以 U：

```Plain
1/R总 = 1/R1 + 1/R2
```

这就是并联电阻公式的来源。

大家不要觉得它是凭空来的。

它其实就来自两句话：

> 并联电压相同。
>
> 总电流等于支路电流之和。

---

## 反直觉：并联越多，总电阻越小

这里有一个特别容易错的点。

我问大家：多接一个电阻，总电阻是变大还是变小？

如果是串联，多接一个电阻，总电阻变大。

因为阻碍叠加了。

但如果是并联，多接一个电阻，总电阻反而变小。

为什么？

因为你不是在原来的路上增加一个阻碍。

你是在旁边又开了一条路。

路变多了，总体更容易通过。

所以并联总电阻一定小于任意一个支路电阻。

比如 3Ω 和 6Ω 并联，结果不是 9Ω。

我们算一下：

```Plain
R总 = 3 × 6 / (3 + 6) = 18 / 9 = 2Ω
```

2Ω 比 3Ω 还小。

这就是并联的特点。

大家一定要记住这句检查语：

> 并联总电阻，要小于最小的那个支路电阻。

如果你算出来 3Ω 和 6Ω 并联等于 9Ω，那一定错了。

因为 9Ω 是串联。

---

## 并联特点 4：并联分流

并联还有一个重要规律：分流。

串联是分压。

并联是分流。

为什么？

因为并联电路里，各支路电压相同。

对 R1 来说：

```Plain
I1 = U / R1
```

对 R2 来说：

```Plain
I2 = U / R2
```

这里 U 是同一个 U。

所以电阻越小，电流越大。

电阻越大，电流越小。

也就是说：

> 电流更愿意走电阻小的路。

两个电阻并联时，常用分流公式是：

```Plain
I1 = R2 / (R1 + R2) × I
I2 = R1 / (R1 + R2) × I
```

注意，这里很容易写反。

I1 前面乘的是 R2。

I2 前面乘的是 R1。

为什么交叉？

因为并联分流跟电阻成反比。

谁的电阻小，谁分到的电流大。

---

## 案例 3：3Ω 和 6Ω 并联

题目：

> R1 = 3Ω，R2 = 6Ω，两个电阻并联，求等效电阻。

第一步，判断结构。

并联。

第二步，用两个电阻并联公式：

```Plain
R总 = R1 × R2 / (R1 + R2)
```

代入：

```Plain
R总 = 3 × 6 / (3 + 6)
R总 = 18 / 9
R总 = 2Ω
```

第三步，检查。

最小的支路电阻是 3Ω。

并联总电阻必须小于 3Ω。

2Ω 符合。

所以答案合理。

---

## 并联小结

并联这一段，我们也收四句话：

```Plain
1. 并联多条路，电流会分流。
2. 并联同头尾，电压处处同。
3. 并联总电阻，倒数相加。
4. 并联会分流，电阻小者多。
```

大家把串联和并联放在一起对比，就会非常清楚。

串联：

```Plain
一条路 → 电流相同 → 电压分配 → 电阻相加
```

并联：

```Plain
多条路 → 电压相同 → 电流分配 → 倒数相加
```

# 课堂练习：先判断结构，再计算

接下来我们做几道课堂练习。

注意，我不希望大家一看到数字就开始算。

所有题目都先问一句：

> 它是串联，还是并联，还是混联？

---

## 练习 1：判断串联还是并联

题目：

> 两个电阻中间没有任何分岔，电流必须先经过 R1，再经过 R2。它们是什么连接？

答案：串联。

理由：电流只有一条路，没有分岔。

---

## 练习 2：串联分压

题目：

> R1 = 2Ω，R2 = 4Ω，串联接在 12V 电源上，求 R1 和 R2 两端电压。

先写判断：

```Plain
结构：串联
规律：串联分压，电压比等于电阻比
```

电阻比：

```Plain
R1 : R2 = 2 : 4 = 1 : 2
```

总电压 12V，按 1 : 2 分。

一共 3 份。

每份：

```Plain
12V ÷ 3 = 4V
```

所以：

```Plain
U1 = 4V
U2 = 8V
```

检查：

```Plain
4V + 8V = 12V
```

没问题。

---

## 练习 3：并联等效

题目：

> R1 = 4Ω，R2 = 4Ω，两个电阻并联，求等效电阻。

两个相同电阻并联，其实可以直接判断：

两个一样的路并在一起，总电阻变成一半。

所以答案是：

```Plain
R总 = 2Ω
```

用公式验证：

```Plain
R总 = 4 × 4 / (4 + 4)
R总 = 16 / 8
R总 = 2Ω
```

检查：2Ω 小于 4Ω，合理。

---

## 练习 4：混联题怎么下手

有些题不是纯串联，也不是纯并联，而是混联。

混联题不要慌。

它的核心方法是：

```Plain
先局部，后整体。
```

什么意思？

先看有没有明显串联的一组。

再看有没有明显并联的一组。

能合并一部分，就先合并一部分。

每合并一步，就把图画简单一点。

最后变成一个总电阻。

混联题最怕什么？

最怕你一上来就乱套公式。

所以我再强调一次：

> 先判断结构，再使用公式。

---

# 本节总结

好，我们收一下今天这节课。

今天公式看起来不少，但主线其实非常简单。

第一，欧姆定律是地基：

```Plain
I = U / R
```

不是死背公式，而是看电压、电流、电阻三个量的关系。

第二，串联是一条路。

```Plain
电流相同
电压相加
电阻相加
串联分压
```

串联最重要的一句话：

> 串联分压，电阻大者多。

第三，并联是多条路。

```Plain
电压相同
电流相加
电阻倒数相加
并联分流
```

并联最重要的一句话：

> 并联分流，电阻小者多。

最后，全课最重要的一句：

```Plain
串联看电流，并联看电压；先判断结构，再使用公式。
```

大家把这句话扣在脑子里。

以后看到电路图，第一反应不要是找公式。

第一反应是看路：

电流有没有分岔？

元件是不是同头同尾？

能不能先局部化简？

这才是电路题的正确打开方式。
