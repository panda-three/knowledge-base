# 谈单提示词

```Plain
你是XXX的金牌销售，现在我是客户，你代入第一人称，竭尽全力转化我，要体现出专业，不要那么快报价（即使我问你你也要先打太极），尽量增加我的沉没成本。先把需求问清楚
每次回复要像自然人打字，不要罗列式输出，不要机械味AI味太重，不要太长
```

# 客户需求模糊

```Plain
我需要给客户做PPT，这是我和客户的聊天记录【上传截图】，我应该问客户什么问题才能更好的帮助我完成这个PPT，把客户的想要的都挖出。
```

# 需求拆解

```Plain
我需要给客户做PPT，深刻理解客户需求，然后等我指令
```

# 资料上传

```Plain
【上传文档/截图】
这是客户的资料，深刻理解学习，提取有效信息，然后等我指令
```

# 搜集资料

```Plain
根据客户需求，我需要找什么资料给你才能帮助你更好的完成PPT大纲，给我具体的3-5个关键词，我搜回来给你。
```

# 生成大纲

```Plain
你是一位专业的PPT设计师。【角色】
请根据以上我提供的【资料】内容。【背景】
帮我生成一个逻辑清晰、结构完整，我可以直接复制粘贴到PPT里进行排版的XX页PPT大纲及正文。【任务/目标】
加上封面、目录、尾页内容一共XX页。【输出格式】
并给我具体的美化排版建议，配图建议，图表等。【附加需求】
```

# 配图

```Plain
根据以上大纲，生成每一页的需要用到的图片素材，输出中文提示词我让AI画出来
```

# 结构化

```Plain
根据以上大纲排版美化建议，使用[XX风格色调]，HTML格式输出。生成可视化面板/生成[第X页]，我直接截图放PPT里
```

# 返修

```Plain
这是我给客户做的PPT最终版【上传文档】，客户给出了以下修改意见【聊天记录】
严格根据客户的修改意见修改PPT内容
怎么改，改哪了，改什么，并标注具体位置
```

```Plain
这是最终完成的PPT，客户PPT听众是[XXX]，请以自然人演讲的形式输出每一页的演讲逐字稿，不要罗列式输出
```
