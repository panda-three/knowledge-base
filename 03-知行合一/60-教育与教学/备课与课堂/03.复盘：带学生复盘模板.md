# 带学生复盘 · 四步模板

> 本质一句话：复盘不是把做过的事再过一遍，是让学生从这次经历里挖出「下次能用的认知」。全场只验一条金线：**这次复盘，改变了下一次的哪个动作？**

## 一、开场定调（2 分钟，防伪复盘）

1. 对齐一句话：复盘不是批斗、不是夸夸、不是总结，是学习。
2. 定角度：决策类（方向/范围选对没）还是执行类（动作做稳没）。
3. 四问过滤，全否则不用正式复盘：这事会重复吗？重要吗？偏差大吗？

## 二、问什么：四步问答清单

### 第 1 步 成败认定（找差距）

1. 这次的目标是什么？
2. 实际结果是什么？（要数字，不要形容词）
3. 达成了吗？差距在哪？

老师追问：满分 10 分你打几分？扣的分扣在哪一条？
规则：「还行 / 不错 / 马虎」一律打回重说，直到带出数字。

### 第 2 步 场景还原（找事实）

1. 按时间线说一遍：当时实际怎么做的？
2. 关键节点上，你具体做了什么动作？
3. 和原计划比，哪里不一样？

老师追问：假如有个反对者坐在这里，他会怎么描述这件事？

### 第 3 步 得失分析（找原因）

1. 哪里做得好？为什么好？（成功要素是什么）
2. 哪里没做好？为什么？（追到能改的那一层）
3. 重来一次，你会保留什么、换掉什么？

老师追问梯子：为什么？→ 再问一层为什么？→ 这是方法问题、习惯问题还是判断问题？
禁止词：粗心、没状态、不够努力——全是情绪词，出现就再问一层。

### 第 4 步 总结提炼（找行动）

1. 这个规律还能用在别的科目 / 场景吗？（迁移）
2. 下次再遇到，你会有什么不同？
3. 一句话收口：什么情况下 → 怎么做 → 避免什么。

## 三、怎么收录

1. 学生侧：一页复盘卡（四步各三行以内），归进自己的错题本 / 学习档案。
2. 老师侧：带共性的认知收进知识库，按回流流程落位（一句话教训 → 写进下次一定会读到的地方）。
3. 口径：还原事实就事论事，提炼认知尽量普适；复盘不过夜。

## 四、怎么落实成行动

1. 行动只收三条：坚持做 / 放弃做 / 新增做。每条写清「做什么 + 什么时候 + 怎么算做到」。
2. 写进下次的行动清单；下次复盘第一件事：回看上次三条，逐条核销。
3. 没做到的不批评，问「是行动定错了，还是执行卡住了」——回到第 3 步再挖。

## 五、验收标准：这次复盘合格吗？

一票否决（出现任何一条 = 不合格）：

1. 全程只有形容词，没有数字（停在感受层）。
2. 变成批斗会或夸夸会（对人不对事）。
3. 散场时没有任何一条具体行动（流程满分，价值零分）。

合格线（五条全过才算合格）：

1. 有数据：成败认定带数字锚点。
2. 有根因：原因追到能改的那一层，没有情绪词收尾。
3. 有迁移：至少说出 1 条能用到其他场景的规律。
4. 有行动：三条行动，条条可核销。
5. 有回看：下次复盘从核销上次行动开始。

优秀线（不强制，挖到就加分）：

1. 触到能力层：说出「我缺什么基本功、打算怎么练」。
2. 产出武器：沉淀出一个清单 / 步骤 / 口诀，可直接复用。

## 六、轻量版：3 分钟复盘（小事用）

做完一件小事，顺手问三句：实际改了什么？为什么？下次怎么做？不为深度，为把复盘养成动作的一部分。
