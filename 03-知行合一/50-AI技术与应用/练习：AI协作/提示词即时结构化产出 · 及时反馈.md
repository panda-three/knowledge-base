# 提示词即时结构化产出 · 及时反馈完全笔记

> 从「事后抽空复盘」到「当场三钩子 + AI自评双重验证」——口喷提示词的及时反馈全案。

---

## 一、起点：你现在的状态 vs 目标状态

| | 现在 | 目标 |
|---|---|---|
| 反馈方式 | 事后翻口喷文字，对着套路清单一个一个对 | 当场就能知道哪里偏了 |
| 反馈速度 | "抽空的时候"——可能隔半天、一天甚至更久 | 至少一半口喷当天复盘，每天至少一次当场反馈 |
| 反馈视角 | 只有自己一个视角——自己的清单、自己的标准 | 自己 + AI自评双重验证，偶尔加第三只眼 |
| 最大盲区 | 反馈太慢，缝隙里错误动作被重复巩固 | 当场知道差距，当场刻印，下次不犯 |

**核心卡点：** 不是你不复盘。你是有结构化复盘意识的——对着11个武器清单一个一个对，知道下一轮改什么。问题出在时间缝隙：口喷到复盘之间隔了太久，复盘到下次口喷又隔了太久。缝隙越大，错误动作越容易被重复巩固。目标不是推翻你的复盘系统，是**把反馈往前推——从隔天推到当天，从当天推到当场。**

---

## 二、核心概念：反馈的本质

反馈不是为了评价你，而是帮你找到差距。

| 反馈要回答四个问题 |
|---|
| 哪个动作做对了，下次继续 |
| 哪个动作做错了，下次换方式 |
| 哪个动作做忘了，下次记得 |
| 哪个动作不够好，下次再跳一跳 |

**定性标准：** 只有评价不够，反馈必须能转成下一轮动作。光是"这次还行"或"这次不太行"没用——你得知道下一轮改什么。

## 三、反馈速度三层级

| 层级 | 反馈速度 | 价值 | 你的现状 |
|---|---|---|---|
| 🟢 **当场反馈** | 口喷完10秒内就知道哪里偏了 | 即时刻印，一次顶隔天五次 | ❌ 没有——要等复盘 |
| 🟡 **当天反馈** | 当天内通过复盘知道差距 | 还能回忆起当时为什么那样喷 | ❌ 不稳定——"抽空的时候" |
| 🔴 **隔天反馈** | 第二天甚至更久才复盘 | 已经忘了喷的时候在想什么 | ✅ 你的常态 |

**目标：** 至少一半口喷从🔴拉到🟡，每天至少一次拉到🟢。当场反馈不需要每次都做到——每天一次当场反馈，比你一周集中复盘五次都有效。

## 四、场景对比：有反馈 vs 没反馈

**平行世界，同一个人两个月口喷练习：**

- **❌ 只有隔天反馈：** 每次口喷完就完了。过两天翻出来复盘，已经忘了当时为什么选那个切法、为什么忘了限定条件。对着清单打完勾，写一句"下次注意加限定"。下次口喷——还是忘了。两个月后，⚠️标记散落在聊天记录里，从没连起来看过。他感觉自己练了很多，但说不清自己进步在哪。

- **✅ 当场反馈 + 双重验证：** 每次口喷完立刻看AI产出，三个钩子花10秒扫一遍，打一行⚠️标记。每周末搜⚠️，五条摆在一起看。他发现自己连着三周⚠️最多的词是"限定"——我的盲区原来在这。他开始每次口喷前花5秒翻上次⚠️，带一个改进点进场。两个月后，⚠️标记里"限定"那行越来越少，"没卡 🟢"越来越多。翻聊天记录能看到一条清晰的进步轨迹。

**差距不在复盘能力，在反馈速度。同样复盘，当场做的效果是隔天做的三到五倍。**

## 五、当场反馈系统（核心操作层）

### 5.1 当场三钩子——喷完10秒看AI产出

AI产出本身就是一面镜子。你本来就要看AI产出，只是以前只看"能不能用"。现在多扫三个钩子：

| 钩子 | 看什么 | ⚠️怎么记 |
|---|---|---|
| **结构钩** | AI产出有没有按你拆的步骤走？还是它自己发挥了？ | 按步骤走了 → ✅ 没按 → ⚠️拆不生效 |
| **限定钩** | 你说的限定条件有没有被遵守？风格、字数、术语？ | 遵守了 → ✅ 没遵守 → ⚠️限定未生效 |
| **可用钩** | 这个东西能直接用吗？还是要再改一轮？ | 能用 → ✅ 不能用 → ⚠️返工 |

三个钩子各花3秒，总共10秒。打完⚠️标记就结束，不多想。这是从"隔天反馈"变成"当场反馈"的最短路径——不需要新工具、不需要新习惯、不需要别人。

### 5.2 质量维度标记——不只是"用了/忘了"

同一个武器，"用了"和"用了且AI精准遵守"是两回事：

| 钩子 | 用了但差（⚠️虚） | 用了且好（✅） |
|---|---|---|
| 结构钩 | AI按步骤走了但步骤本身太泛，产出还是散 | AI严格按步骤走，每步产出清晰独立 |
| 限定钩 | 说了限定但太笼统（"写得好一点"），AI没感知到 | 限定具体（"每步不超过一句话"），AI精准遵守 |
| 可用钩 | 能用但要改一轮 | 直接可用，零修改 |

⚠️标记升级版：

```
⚠️限定虚  → 说了，但AI没感知到
⚠️限定 ✅  → 说了，AI精准遵守
⚠️拆不生效  → 拆了步骤，AI没按步骤走
⚠️拆到位 ✅  → 拆了步骤，AI严格按步骤产出
```

**只在"你以为用了但AI没反应"的时候记⚠️虚——那才是真正的盲区。** 你以为自己做到了，但其实没做到位。

## 六、双重验证系统

### 6.1 AI自评——第二双眼睛

口喷完之后，在提示词末尾加一句：

> "你出完之后，先自己评估一下：0到10分打几分？哪里扣了分？然后按10分标准重写一版。"

让AI自己找差距、自己改。你不用立刻复盘，但下次翻聊天记录时不光能看到你喷了什么，还能看到AI自己说自己哪里不足。

### 6.2 交叉对照——两套判断摆在一起

| 你的⚠️标记 | AI的自评 | 发现了什么 |
|---|---|---|
| ⚠️没卡 ✅ | "打7分，扣3分因为缺少具体例子" | 你以为够了，AI觉得还缺——你对"够"的标准可能偏低 |
| ⚠️限定 ✅ | "打8分，扣2分因为后半段风格不太一致" | 你检查了限定，AI也基本遵守——这个武器稳了 |
| ⚠️没卡 🟢 | "打9分，几乎不需要改" | 双重确认——这次是真正的舒适区 |

不需要每次都做。一周选2-3次。最有价值的是看"你以为自己做好了但AI说你没做好"的情况——那就是你真正的盲区。

### 6.3 第三只眼——学员/用户的反应

教育场景天然带第三只眼。这些都是**已经发生的反馈信号**，只是你以前没把它们当反馈看：

| 反馈源 | 怎么看 | 信号解读 |
|---|---|---|
| 学员收到AI产出后 | 他看懂了吗？照做了吗？还是又问了一遍？ | 追问 = 上次口喷缺了关键信息 |
| 同事/合作方拿到后 | 他直接用了吗？还是自己又改了一遍？ | 他又改 = 产出不够直接可用 |
| 直播观众的反应 | 弹幕有没有"学到了""原来这么简单"？还是沉默了？ | 沉默 = 没感知到价值或没看懂 |

⚠️标记里多一行：

```
⚠️限定 ✅
→ 学员反馈：没追问，直接照做了
```

或者：

```
⚠️拆太粗
→ 学员反馈：问了一句"第二步什么意思"
→ 下次：步骤之间加一句过渡说明
```

## 七、极简反馈对照表（复盘用）

你已经在对着套路清单一个一个对了。统一成一个格式，只打勾不描述，复盘速度翻倍：

```
📋 口喷复盘 · 日期___

角色：用了 / 忘了 / 用了但太虚
切法：时间切 / 维度切 / 条件切 / 没拆
限定：说了 / 忘了
格式：说了 / 忘了
上下文：给了 / 没给
示例：给了 / 没给

本次AI自评分：___ / 10

下次只改：___
```

**三个特点：**
- **只打勾，不描述。** 细节放⚠️标记里
- **加上AI自评分。** 自评和AI自评在同一页，差距一目了然
- **一页一条，一屏看5-6条。** 周末一两分钟看完本周全部复盘

## 八、反馈最小闭环

在你现有系统上只加三步，闭环就收紧一圈：

| 时机 | 动作 | 花多久 |
|---|---|---|
| **口喷前** | 翻聊天记录，搜⚠️，看上一两条 | 5秒 |
| **口喷中** | 脑子里只带一个"上次要改的"进去 | 0 |
| **口喷后** | 当场看AI产出，三个钩子扫一遍，打⚠️标记 | 10秒 |
| **有空时** | 翻聊天记录搜⚠️，填复盘对照表 | 2分钟/次 |

**口喷前扫一眼是性价比最高的环节。** 5秒，但能让每次口喷都带着一个明确的改进点进场——大概率不会再犯同样的错。

## 九、反馈深度三阶段

| 阶段 | 反馈回答的问题 | 你的现状 |
|---|---|---|
| **阶段一：对错反馈** | "我做对了吗？" | ✅ 能做到——对标清单，知道哪个武器用了哪个忘了 |
| **阶段二：差距反馈** | "差在哪？差多少？" | ⚠️ 部分做到——知道忘了限定，但不太清楚"限定好 vs 差"的差距 |
| **阶段三：动作反馈** | "下一轮具体怎么改？" | ⚠️ 部分做到——知道下次加限定，但不知道"加限定这个动作怎么练才能不忘记" |

**当前任务：用双重验证（自己+AI自评）把阶段二填满。** 因为只有知道"差在哪、差多少"，才能把"下次加限定"从一个笼统想法变成可执行动作。

## 十、不同武器的反馈标准

前4个⭐必用武器，从AI产出就能直接判断对错：

| 武器 | 做对了的证据 | 没做对的信号 |
|---|---|---|
| ⭐三问题框架 | AI产出有明确的角色感、有步骤感、有可用的约束 | AI产出角色模糊、自由发挥、不受控 |
| ⭐角色库 | AI的口气、术语、节奏符合你设定的角色 | AI角色漂移——开头是老师，中间变客服 |
| ⭐任务拆解 | AI严格按你拆的步骤走，不跳步不发挥 | AI合并了你的步骤、跳过了某步、自己加了料 |
| ⭐限定条件 | 每一条限定都被遵守（字数、风格、术语、不要的） | 有某条限定被AI忽略了 |

🔧和🎯武器的标准等前4个稳定了再定。这页直接放进练习文档，复盘时对照用。

## 十一、盲区探测器

自己看自己有三个天然盲区：看不出"以为说清楚了但AI没听懂"的地方、判断不了"武器用得好不好"、只能跟昨天的自己比没有外部参照。两个低成本探测器：

| 探测器 | 怎么做 | 发现什么 | 花多久 |
|---|---|---|---|
| **AI反问法** | 口喷完加一句："在我给你的提示词里，有没有什么信息是你需要的但我没给的？" | AI会告诉你漏了上下文、漏了限定、漏了格式——你完全没意识到自己没给的 | 喷完多说一句，10秒 |
| **高手一句** | 把口喷文字发给口喷比你强的人，只问："如果只改一处，你会改哪？" | 对方不需要完整点评，一句话暴露你的盲区 | 一周一次 |

AI反问法可以嵌入口喷流程（和AI自评放在一起），高手一句一周用一次。

## 十二、快速对标反馈

聊天记录里到处都是对标素材。口喷完，搜你之前处理过类似需求的提示词——不复盘，只对比。10秒扫一眼：

| 比什么 | 差异自现 |
|---|---|
| 上次这个需求用了几个武器？ | 这次用了几个？ |
| 上次有没有限定条件？ | 这次呢？ |
| 上次AI产出要调几轮？ | 这次调了几轮？ |

不需要打开文档、不需要打表。搜一下，扫一眼。差异自己跳出来。

## 十三、反馈的节奏与界限

### 13.1 什么时候不需要反馈

不是每次口喷都要当场反馈。分类处理：

| 口喷类型 | 反馈深度 |
|---|---|
| 🟢 低风险练习（对手机录音、随便喷） | 当场三钩子 + ⚠️标记，不复盘 |
| 🟡 真实场景（答疑、内部演示） | 当场三钩子 + ⚠️标记 + AI自评 |
| 🔴 高风险场景（直播、重要交付） | 事后完整复盘 + 填对照表 |
| ⚪ 纯实用口喷（干活的，不练武器） | ⚠️标记都不用打，能用就行 |

**铁律：纯实用口喷不需要反馈。** 帮同事快速喷一条让他拿去用，喷完就完了。不要用训练标准要求干活场景。反过来，训练场景不要用"能用就行"糊弄自己。

### 13.2 及格线定义

| 场景 | 及格标准 |
|---|---|
| 纯实用口喷 | 能用，不需要再调 |
| 训练口喷（带挑战） | 挑战完成了 + AI产出符合基本预期 |
| 高风险口喷 | 产出零失误，能直接交付 |

## 十四、正向反馈——不让⚠️变成自我打击

⚠️标记天然偏负面。只盯错误，时间长了觉得自己怎么这么差，然后放弃。

加一行正向标记：

```
🎉 第一次没忘限定
🎉 维度切不卡了
✅这次比以前好：限定条件开口前就想了，没等到喷一半才补
```

不是每次都写。有突破的时候写一行。它的作用是**翻聊天记录时不全是批评，也有证据证明自己在往上走。**

## 十五、趋势阅读——单次反馈没用，连续五次才是数据

一条⚠️只能告诉你一次的状态。但连续五条摆在一起：

```
⚠️限定
⚠️限定
⚠️限定虚  → 这次说了但太虚
⚠️限定 ✅  → 这次精准了
⚠️没卡 🟢
```

看到的不是五次口喷，而是一条**「限定条件」从遗忘→虚用→精准→自动化的完整进步轨迹。** 这是唯一能证明自己真的在进步的证据。

**做法：** 周末翻聊天记录搜⚠️时，不只看最近一条。把本周五条摆在一起看。找规律——哪个武器出现最多？哪个从⚠️变成了✅？哪个从没出现过（回避型武器）？

一屏看五条，趋势自己跳出来。
