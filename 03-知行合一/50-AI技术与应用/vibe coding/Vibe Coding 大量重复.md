## 大量重复 · Vibe Coding 场景版

---

### 一、核心定义

> **大量重复不是「做很多项目」，而是围绕同一个底层动作，反复做、拿到反馈、调整、再做下一轮。**

你做 50 个项目，如果 Grade 有时走有时跳、To PRD 有时写有时不写、闪念即固定有时触发有时忘——**项目数量涨了，但同一个底层动作的循环次数没有稳定堆起来。**

---

### 二、本质：不是堆项目，是堆循环

```text
一个篮球运动员打 50 场比赛，每次投篮姿势都不一样
→ 比赛经验涨了，投篮能力没涨

你做 50 个 vibe coding 项目，每次核心动作看状态选配
→ 项目经验涨了，底层能力没涨
```

**每个项目都在练同一套姿势，次数才是有效次数。**

---

### 三、怎么才能大量重复？

你的卡点是「有时做有时跳，取决于当前状态」。所以策略不是增加新项目，而是**把核心动作焊死在固定节点上，让状态没机会决定做不做。**

| 手段         | 具体动作                                                 | 解决什么问题                    |
| ---------- | ---------------------------------------------------- | ------------------------- |
| **焊死核心动作** | 每个项目做完，无脑走三步：Grade → To PRD → 主动索取三问                 | 解决「看状态选配」——不选，就是必走        |
| **最轻兜底**   | 状态差到极点，至少问 AI 一句：「这次有什么值得留的？」                        | 解决「状态差就全跳」——循环不断，哪怕只跑最低保底 |
| **拆小练习**   | 不需要完整项目也能练——日常小任务单独练 Grade 对齐、单独练 To PRD 沉淀、单独练闪念即固定 | 解决「没大项目就没机会练」——小任务也是练习场   |
| **迁移练习**   | 不同项目、不同技术栈，但都在跑同一组底层动作：Grade → To PRD → 主动索取 → 闪念即固定 | 解决「项目不一样没法重复」——底层动作一样     |

---

### 四、极简执行卡

> **每个项目做完，无脑走三步：Grade → To PRD → 主动索取三问。状态再差，至少问 AI 一句。**
