# 主题：输出质量门（Skill 协议草稿 V0.1）

> **一句话定位**：敢发给学员之前，过四道闸门——内容完整 → 论证闭环 → 讲香到位 → 扛住最聪明学生的第一问。
> **边界公式**：稳定意图 = 作品达到可面对北大清华学生的交付标准；稳定工作流 = G1 完整 → G2 论证 → G3 讲香 → G4 抗压，逐关放行；稳定产物 = 质检报告 + 修改清单。
> **及格线**：能扛住最聪明学生的第一问，是及格线，不是优秀线。

---

## 0. 什么时候调用（触发条件）

| 触发场景 | 动作 |
|---|---|
| 任何作品要发 04-作品出口 | 强制四闸门全过 |
| 任何课程 / 公开课要开讲 | 课前强制 |
| 备课包产出后（AI 拉料组装完成） | 先过反幻觉 Skill 的事实关，再过本质量门 |
| 用户说「这版可以发了」 | 仍须过闸门（用户认可不等于质量达标） |

**前置凭证**：反幻觉 Skill 的事实核查报告。

## 1. 四道闸门

### G1 内容完整性（PACK_COMPLETE）

**目标**：作品没丢原料的核心血肉。

- 对照设计意图 / 原始原料，逐项比对：核心模型是否完整保留？关键案例在不在？二级细节（如 40 个策略）是否全收？
- 用「覆盖清单法」：先把原料拆成清单（模型 / 案例 / 数字 / 策略 / 故事），再逐项核对作品里有没有。
- **判定**：缺失关键项 ≥3 个 → 不过，先补再走。

### G2 论证完整性（PACK_ARGUMENT）

**目标**：每一条主张都有证据和推理，禁得住「为什么」。

- 主张 → 证据 → 推理，三点一线，逐条检查。
- 扫描逻辑缺陷：循环论证、以偏概全、幸存者偏差、因果倒置、偷换概念。
- **判定**：任一条主张链条断裂 → 不过，标注断裂点。

### G3 讲香校验（十指讲香模型）

**目标**：内容有价值 ≠ 学生感受到价值。课程本身必须过讲香。

- 用十指讲香模型自查：开头有没有场景化（学生为什么关心）？关键论点有没有数字化 / 故事化？有没有金句可记忆？有没有升华（和学生的长远利益挂钩）？
- 参照「讲香实操：一堂十指模型」的 40 个二级策略做增强点诊断。
- **判定**：全文无场景化开场、无一个可记忆金句 → 不过，先打磨表达。

### G4 压力测试（PACK_ADVERSARY）

**目标**：模拟最挑剔的学生，把作品「问穿」。

- 用挑剔学生题库逐题攻击，**必须真问真答**，不许走过场。
- 每答不上 / 答不稳的问题 = 一个必须补的漏洞。
- **判定**：存在任何「当场答不出或答了会被反驳」的问题且未修复 → 不过。

## 2. 数据资产包（正式化时拆为独立 PACK 文件）

### PACK_GATE 四闸门放行卡
（G1-G4 的判定标准 + 放行 / 拦截记录表）

### PACK_COMPLETE 完整度比对清单
- 核心模型：______（原料的模型名 / 坐标轴 / 结构是否逐字保留？）
- 关键案例：______（每个案例是否对过原始出处？）
- 二级细节：______（策略表 / 角色比喻 / 推导过程是否全收？）
- 数字证据：______（是否与原料一致？）
- 一句话：这个作品相对原料丢了什么？丢的部分为什么可以不讲？

### PACK_ARGUMENT 论证链扫描
| 检查项 | 问句 |
|---|---|
| 主张有证据 | 「这个结论靠什么支撑？」 |
| 证据可溯源 | 「证据哪来的？L 级？」 |
| 推理不跳步 | 「从证据到结论，中间有没有省略关键一步？」 |
| 无循环论证 | 「结论有没有被当作前提？」 |
| 无以偏概全 | 「样本 / 案例能代表整体吗？」 |
| 无幸存者偏差 | 「只讲了成功案例吗？失败的呢？」 |
| 无因果倒置 | 「相关性能当因果讲吗？」 |
| 边界条件 | 「这个结论在什么条件下不成立？」 |

### PACK_ADVERSARY 挑剔学生题库（北大清华场景，V0.1 收录 12 题）

**连续追问类**
1. 「你这个结论的数据从哪来的？给我看原始出处。」
2. 「你这个例子是真实发生的吗？当事人叫什么？在哪一期？」
3. 「你说 X 是主流共识——谁公认的？引用一篇论文或一份报告？」
4. 「上一页你说了 A，这一页你说 B——A 和 B 矛盾，你解释一下？」

**反例搜索类**
5. 「我身边就有人这样做了失败了——你的模型怎么解释他？」
6. 「有没有反例？如果一个案例推翻你，你前面讲的还算数吗？」

**边界条件类**
7. 「这个方法在什么情况下不适用？给个具体场景。」
8. 「你说的『普遍规律』，边界在哪？大公司 / 小团队 / 非教育行业还成立吗？」

**前置假设类**
9. 「你默认我们都会 X——但我的同学里有人不会，怎么办？」
10. 「这个结论建立在什么假设上？假设不成立会怎样？」

**替代解释类**
11. 「有没有更简单的解释？会不会只是幸存者偏差？」
12. 「如果换一个理论框架，同样的案例得出相反结论，你怎么证明你的框架更对？」

**使用规则**：每版作品至少真实执行 6 题（前 4 题必做）；答不上的问题记入修改清单，修复后重问。

## 3. 产物规范

- **质检报告**：四闸门逐关记录（通过 / 拦截 + 证据），整体评级 A（四关全过可发）/ B（表达层小改）/ C（有内容缺失或论证断裂，必须返工）/ D（未达可讲标准）。
- 报告落 `00-天一生水/01-系统文档/AI教育课沉淀/meta/`，命名 `质检报告_<作品名>_<日期>.md`。
- 评级 ≥ B 且无 P0 级漏洞，作品才可进 04-作品出口；D 级作品直接打回。

---

## 4. 使用原则

1. **四闸门有顺序**：G1 不过不查 G2（内容都没齐，论证无从谈起）。
2. **压力测试必须真实执行**：真问、真答、真改。把「最聪明学生」当真人，不把题库当走过场。
3. **用户认可 ≠ 质量达标**：闸门是客观标准，不是主观感觉。
4. **讲香是质量不是装饰**：面向顶级学生，表达力决定他们是否听进去。
5. **与反幻觉 Skill 串联**：先事实关（每句话真不真），后质量门（整篇完不完整、扛不扛问）。两道都过，才敢发。
