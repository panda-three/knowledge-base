# C 语言相似题巩固 Partner · 状态机设计

## 一、主流程

```text
S0 接收起点题
  ↓
S1 提取练习焦点
  ↓
S2 生成相似题候选池
  ↓
S3 精选三题路径
  ↓
S4 输出学生版推荐
  ↓
S5 回收做题结果
  ↓
S6 下一轮调度
```

## 二、每个状态的完成条件

| 状态 | 目标 | 完成条件 |
|---|---|---|
| S0 接收起点题 | 拿到学生刚做完的题 | 至少有题目卡、题号、题干摘要或考点之一 |
| S1 提取练习焦点 | 明确本轮要练什么 | 得到考点、解题动作、易错点、难度；缺失项已标注 |
| S2 生成候选池 | 找到可推荐的相似题 | 候选题按相似度评分，综合得分 ≥ 6 入池 |
| S3 精选三题路径 | 排出同构、变式、迁移 | 三题各有角色、难度、推荐理由；不足三题时说明缺口 |
| S4 输出学生版推荐 | 让学生知道先练什么 | 输出三题路径 + 每题一句提醒 + 先做第一题的指令 |
| S5 回收结果 | 判断练习是否有效 | 学生反馈每题对/错/卡点 |
| S6 下一轮调度 | 决定继续巩固还是爬坡 | 给出下一步：再同构、加变式、提高难度或转讲解 |

## 三、分支规则

| 场景 | 处理 |
|---|---|
| 学生只说“我错了这类题” | 追问：题号/题目卡/考点/错在哪一步，四选一即可 |
| 标签完整 | 直接按相似度评分出三题路径 |
| 缺少解题动作 | 不能稳推迁移题；先基于考点和难度做保守推荐 |
| 候选不足三道 | 不硬凑；输出已有推荐 + 缺口说明 |
| 第一题又错 | 暂停爬坡，回到同构巩固或建议先讲解 |
| 第一题做对、第二题错 | 增加同考点变式，不上迁移挑战 |
| 三题全对 | 下一轮可提高难度或进入新考点 |
| 学生要求答案 | 简短提醒：先做题，做完可以复盘卡点，不直接给答案 |
