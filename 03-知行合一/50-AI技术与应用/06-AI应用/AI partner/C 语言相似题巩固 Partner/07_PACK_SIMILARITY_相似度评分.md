# PACK_SIMILARITY · 相似度评分包 V1.0

## 0. 定位

本包负责把“老师觉得这两题像”翻译成可执行的评分规则。

主要参考：32 相似题练习组模板-V4。

## 1. 相似度评分表

| 条件 | 分值 | 说明 |
|---|---:|---|
| 题型相同 | +1 | 外壳相似，只是微调 |
| 答案相关考点相同 | +3 | 核心知识相同，是推荐的灵魂 |
| 解题动作相同 | +3 | 能力动作可迁移，是最重要依据 |
| 易错点相同 | +1 | 错后复练更贴合 |
| 难度接近 | +1 | 避免坡度过陡 |

综合得分：0–9 分。

## 2. 入池规则

| 综合得分 | 级别 | 处理 |
|---:|---|---|
| 8–9 | 高相似 | 进入候选池，优先同构巩固 |
| 6–7 | 中相似 | 进入候选池，适合变式或迁移 |
| <6 | 低相似 | 默认不进入候选池 |

关键底线：

```text
答案相关考点相同 + 解题动作相同 = 6 分。
只要这两项都对，就具备推荐价值。
```

## 3. 三题路径选择

### 3.1 第一题 · 同构巩固

优先条件：

- 综合得分 8–9
- 考点相同
- 动作相同
- 难度接近
- 题型最好相同
- 易错点最好相同

学生版理由模板：

```text
这题和刚才那题练的是同一个动作：[动作]。外壳也很像，适合先把刚才没稳的步骤重新走一遍。
```

### 3.2 第二题 · 变式训练

优先条件：

- 综合得分 6–8
- 考点或动作相同
- 题面、输入形式或代码结构有变化
- 难度不陡增

学生版理由模板：

```text
这题换了一个外壳，但底层还是在练：[考点/动作]。如果这题能做出来，说明你不是只记住了刚才那道题。
```

### 3.3 第三题 · 迁移挑战

优先条件：

- 综合得分 ≥ 6
- 外壳变化最大
- 解题动作仍相同
- 难度可略高，但不超过起点题 +1，除非学生前两题都轻松做对

学生版理由模板：

```text
这题表面不像，但底层动作还是：[动作]。它用来检查你能不能把这个动作迁移到新场景里。
```

## 4. 排除规则

以下情况不得推荐：

- 综合得分 < 6，且没有人工指定理由。
- 学生刚做过同一题。
- 第一题难度明显高于起点题。
- 只有题型相同，但考点和动作都不同。
- 推荐理由说不清楚具体练什么。

## 5. 评分示例

起点题：switch 分支执行与格式化输出。

候选题 A：同为 switch 输出追踪。

```text
题型相同 +1
考点相同：switch 分支入口 +3
动作相同：匹配 case → 判断 break → 按格式输出 +3
易错点相同：漏看 break +1
难度接近 +1
综合得分：9，高相似，同构巩固
```

候选题 B：if-else 多分支输出追踪。

```text
题型相同 +1
考点不同 +0
动作相同：追踪条件 → 匹配分支 → 输出 +3
易错点相同：分支入口判断错 +1
难度接近 +1
综合得分：6，中相似，变式训练
```
