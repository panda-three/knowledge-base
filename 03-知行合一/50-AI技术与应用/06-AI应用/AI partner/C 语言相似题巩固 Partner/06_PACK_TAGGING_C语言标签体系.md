# PACK_TAGGING · C 语言标签体系包 V1.0

## 0. 定位

本包负责解释 C 语言题目卡中的关键字段，帮助 Partner 判断“这道题到底该推荐哪些相似题”。

主要参考：

- 32 相似题练习组模板-V4

## 1. 推荐所需的五类标签

| 字段 | 作用 | 推荐中的权重 |
|---|---|---|
| 题型 | 判断外壳是否相近 | 低 |
| 答案相关考点 | 判断核心知识是否相同 | 高 |
| 解题动作 | 判断能力动作是否可迁移 | 最高 |
| 易错点 | 判断错后复练是否贴合 | 中 |
| 难度 | 控制练习坡度 | 中 |

## 2. 字段解释

### 2.1 题型

常见题型：

- 选择题
- 判断题
- 填空题
- 程序阅读题
- 程序填空题
- 程序改错题
- 编程题

题型相同只能说明外壳相似，不能单独作为推荐依据。

### 2.2 答案相关考点

只标和答案直接相关的 1–3 个考点。

示例：

- switch-case 分支入口判断
- break 终止 switch
- printf 格式化输出
- 字符数字转换
- 数组下标从 0 开始
- 循环边界判断
- 字符串遍历与字符分类

### 2.3 解题动作

解题动作必须用动词表达。

示例：

- 判断 switch 表达式值并匹配 case
- 追踪变量每轮变化
- 按格式控制符写出输出
- 判断循环最后一次进入条件
- 将字符数字转换为整数
- 用数组下标记录计数
- 对字符串逐字符分类

推荐时，解题动作比题型更重要。

### 2.4 易错点

易错点描述学生可能在哪里翻车。

示例：

- 忘记 break 导致贯穿执行
- 把字符 `'1'` 当成数字 `1`
- 把 `=` 当成 `==`
- 数组最后一个元素写成 `a[n]`
- 忽略 `%c` 会读入回车
- 漏写 `scanf` 里的 `&`

### 2.5 难度

使用 1–5 星或 1–5 级均可。

推荐时默认策略：

- 错后第一题：难度 ≤ 起点题 + 1
- 变式训练：难度接近起点题
- 迁移挑战：最多比起点题高 1 级

## 3. 标签缺失处理

| 缺失字段 | 处理 |
|---|---|
| 缺题型 | 仍可推荐，但不能判断外壳相似 |
| 缺考点 | 不稳定，先追问题目考什么 |
| 缺解题动作 | 不推荐迁移挑战，只做保守同考点推荐 |
| 缺易错点 | 可以推荐，但错后贴合度下降 |
| 缺难度 | 默认按中等难度处理，并提醒不确定 |

## 4. 练习焦点生成模板

```text
这题要练的核心不是 [题型]，而是：
[答案相关考点] + [解题动作]。
最容易翻车的地方是：[易错点]。
```

示例：

```text
这题要练的核心不是程序阅读，而是：
switch 分支入口判断 + break 终止位置确认。
最容易翻车的地方是：忘记没有 break 会继续往下执行。
```
