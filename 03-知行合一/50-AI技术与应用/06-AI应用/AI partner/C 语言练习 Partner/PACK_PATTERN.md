## 2. 逐骨架详解

### P1：遍历-计数

**模式定义**：

```text
输入：一个序列（字符串/数组）
处理：遍历每个元素，用元素的某个属性作为数组下标，在那个位置 +1
输出：统计结果数组
```

**代码骨架**：

```c
int count[10] = {0};  // 计数数组，初始全为 0
for (i = 0; i < len; i++) {
    int index = 从元素中提取要计数的值;
    count[index]++;
}
// 现在 count[k] 就是 k 出现了几次
```

**真题映射**：

| 真题 | 被计数的对象 | 计数数组 | 提取 index 的方式 |
|---|---|---|---|
| 第一题"19731204" | 数字 0-9 | `digit[10]` | `c = number_d[i] - 48` |

**典型考题变形**：
- 统计字符串中每个字母的出现次数（`count[c-'a']++`）
- 统计学生成绩各分数段人数
- 统计投票中每个候选人的得票数

**容易混淆**：
- 和 P11（累加器+计数器）的区别：P1 是被计数值作为数组下标，P11 是独立变量累加
- 学生常犯错误：忘了初始化计数数组为 0

**识别口诀**：**「数组下标 = 被计数值，下标位置存次数」**

**变式检验题**：

```text
统计字符串 "abracadabra" 中每个小写字母出现的次数。
只输出出现次数大于 0 的字母和次数。

骨架：P1（遍历-计数），计数数组大小 26，index = c - 'a'
```

### P2：遍历-过滤

**模式定义**：

```text
输入：一个序列
处理：遍历每个元素，符合条件就放进新数组
输出：过滤后的新数组
```

**代码骨架**：

```c
char result[N];
int j = 0;
for (i = 0; i < len; i++) {
    if (满足保留条件) {
        result[j] = 原数组[i];
        j++;
    }
}
result[j] = '\0';  // 如果处理的是字符串
```

**真题映射**：

| 真题 | 过滤条件 | 结果 |
|---|---|---|
| 第二题"1H3ap1py!" | 是字母 | str = "Happy" |

**典型考题变形**：
- 从数字序列里挑出偶数/奇数
- 从成绩数组里挑出及格的学生
- 删除字符串中的空格

**容易混淆**：
- 和 P8（数组删除-前移覆盖）的区别：P2 是**新建数组存放结果**，原数组不动；P8 是**在原数组上删除元素**，后面元素前移

**识别口诀**：**「符合条件的留下来，放到新数组里」**

**变式检验题**：

```text
从字符串 "a1b2c3d4" 中提取所有数字字符，形成一个新字符串。
输出新字符串和它的长度。

骨架：P2（遍历-过滤），过滤条件：c>='0' && c<='9'
```

### P3：遍历-累加数字

**模式定义**：

```text
输入：包含连续数字字符的字符串
处理：遍历每个字符，遇到数字就 sum = 10*sum + 当前数字
输出：累计的整数
```

**代码骨架**：

```c
long sum = 0;
for (i = 0; i < len; i++) {
    if (c[i] >= '0' && c[i] <= '9') {
        sum = 10 * sum + (c[i] - '0');  // or c[i] - 48
    }
}
```

**真题映射**：

| 真题 | 输入 | 输出 |
|---|---|---|
| 第二题"1H3ap1py!" | 字符串里散落的数字字符 | sum = 131 |

**知识点**：十进制位值原理。`10 * sum` 是把已有的数字左移一位（个位→十位→百位），再加上新数字。

**典型考题变形**：
- 把字符串 "123" 转成整数 123
- 从文件读取数字并累计
- 多项式的系数累加

**容易混淆**：
- 和 P1（遍历-计数）的区别：P1 是被计数值作为下标分散存储，P3 是用一个变量连续累加
- 学生常犯错误：忘记 `10 * sum` 这一步，直接写成 `sum = sum + c - '0'`——这样 "12" 会变成 1+2=3，而不是 12

**识别口诀**：**「已有结果左移一位（×10），新数字加到最后」**

**变式检验题**：

```text
字符串 s = "x12y34z"，提取其中的数字并计算所有数字之和。
注意：不是 "12+34"，而是 12 是一个两位数。

骨架：P3（遍历-累加数字），识别连续数字段，逐段累加
```

### P4：遍历-同时多路处理

**模式定义**：

```text
输入：一个序列
处理：在一个循环里同时做两件以上不同的事（每件事各自有独立的结果变量/数组）
输出：多个结果
```

**代码骨架**：

```c
// 多路处理的典型结构
char filtered[N];
int j = 0;
long sum = 0;

for (i = 0; i < len; i++) {
    // 路 1：过滤字母
    if (是字母) {
        filtered[j] = 原数组[i];
        j++;
    }
    // 路 2：累加数字
    if (是数字) {
        sum = 10 * sum + (原数组[i] - '0');
    }
    // 路 3（可能有）：其他处理
}
```

**真题映射**：

| 真题 | 路 1 | 路 2 |
|---|---|---|
| 第二题"1H3ap1py!" | 过滤字母 → str = "Happy" | 累加数字 → sum = 131 |

**识别口诀**：**「一个循环里维护多个结果变量，各走各的 if」**

**典型考题变形**：
- 遍历成绩数组，同时统计及格人数 + 计算及格学生的平均分
- 遍历字符串，同时统计字母数 + 数字数 + 其他字符数

**学生最易卡住的地方**：
- 分不清每条「路」的变量是独立的——字母过滤用 `str` 和 `j`，数字累加用 `sum`，各管各的
- 看到 `str[i]` 和 `sum` 出现在同一个循环里就晕了

**变式检验题**：

```text
字符串 s = "A3b7C9d2"，遍历这个字符串：
- 把所有大写字母拼接成新字符串
- 把所有小写字母拼接成新字符串
- 计算所有数字之和

骨架：P4（遍历-同时三路处理）
```

### P5：遍历-分类判断

**模式定义**：

```text
输入：一个值
处理：用多层 if-else 判断它属于哪一类
输出：分类结果
```

**代码骨架**：

```c
if (条件 A) {
    if (条件 AA) {
        if (条件 AAA) { 类别1; }
        else { 类别2; }
    }
    else { 类别3; }
}
else { 类别4; }
```

**真题映射**：

| 真题 | 判断对象 | 分类结果 |
|---|---|---|
| 题 78（闰年） | 年份 m | n=1（是闰年）/ n=0（不是闰年） |

**识别口诀**：**「一层一层缩小范围，每一层砍掉一部分」**

**容易混淆**：
- 学生常把 `else` 配对搞错——哪个 `else` 属于哪个 `if`
- 闰年的逻辑条件：`year%4==0 && year%100!=0 || year%400==0`——学生经常把 AND 和 OR 搞反

**变式检验题**：

```text
输入一个学生的成绩，按以下规则输出等级：
90-100：A
80-89：B
70-79：C
60-69：D
0-59：E

分别用多层 if-else 和 if-else if-else 两种写法实现。

骨架：P5（遍历-分类判断）
```

### P6：遍历-查缺

**模式定义**：

```text
输入：已知全集范围（如 0-9），已有数据的统计结果
处理：遍历全集，找出统计结果为 0 的项
输出：缺失项列表
```

**代码骨架**：

```c
for (i = 0; i < 全集大小; i++) {
    if (count[i] == 0) {   // 或 !count[i]
        输出 i;            // 这个值缺失了
        计数器++;
    }
}
```

**真题映射**：

| 真题 | 全集 | 统计来源 | 缺失结果 |
|---|---|---|---|
| 第一题"19731204" | 0-9 | P1 的 digit 数组 | 5, 6, 8 |

**和 P1 的关系**：P1 往往和 P6 成对出现——先用 P1 统计，再用 P6 查缺。

**识别口诀**：**「遍历全集，找出计数为零的」**

**变式检验题**：

```text
字符串 s = "hello world"，统计其中出现了哪些小写字母，
输出没有出现的小写字母。

骨架：P1（遍历-计数）+ P6（遍历-查缺），全集 = a-z
```

### P7：嵌套循环-图形打印

**模式定义**：

```text
输入：图形参数（行数、字符等）
处理：外层循环控制行数，内层循环控制每行内容
输出：打印图形
```

**代码骨架**：

```c
// 上半部分
for (i = 1; i <= rows; i++) {
    打印前置空格（数量与 i 相关）;
    打印核心字符（数量与 i 相关或固定）;
    换行;
}
// 下半部分（如果有）
for (i = rows-1; i >= 1; i--) {
    打印前置空格（数量与 i 相关）;
    打印核心字符;
    换行;
}
```

**真题映射**：

| 真题 | 图形结构 | 外层逻辑 | 内层逻辑 |
|---|---|---|---|
| 题 80 | 上三行+下两行 | `for(i=1;i<=3;i++)` 和 `for(i=3;i>1;i--)` | 空格 + 调用 prn(ss) 打印 5 个 $ |

**典型考题变形**：
- 打印金字塔（每行星号递增）
- 打印菱形
- 打印九九乘法表
- 打印数字三角形

**引导推演的专有方法**：让学生先画图，再推代码。

```text
"先不推代码。你画一下第一行：
  几个空格？几个 $？
  第二行呢？
  画完之后再来看代码——外层循环 i=1 对应你画的第一行。"
```

**识别口诀**：**「先画图，再看代码；外层管行，内层管这行长什么样」**

**变式检验题**：

```text
打印以下图形（用*）：
*
**
***
****
*****

骨架：P7（嵌套循环-图形打印），外层 i=1→5，内层打印 i 个 *
```

### P8：数组删除-前移覆盖

**模式定义**：

```text
输入：数组 + 要删除的元素位置
处理：从删除位置开始，把后面的每个元素往前移一位
输出：数组有效长度减一
```

**代码骨架**：

```c
// 删除下标为 del_index 的元素
for (j = del_index; j < 当前有效长度 - 1; j++) {
    arr[j] = arr[j + 1];
}
有效长度--;
```

**真题映射**：

| 真题 | 删除条件 | 前移操作 |
|---|---|---|
| 题 81 | 平均分 < 60 | `scores[j][k] = scores[j+1][k]` + `avestu[j] = avestu[j+1]` |

**和 P2（遍历-过滤）的区别**：

| | P2：遍历-过滤 | P8：数组删除-前移覆盖 |
|---|---|---|
| 操作位置 | 新建数组 | 原数组上操作 |
| 空间 | 需要额外数组 | 不需要额外空间 |
| 稳定性 | 原数据不变 | 原数据被修改 |
| 适用场景 | 简单过滤 | 需要保留原数组其他数据 |

**识别口诀**：**「删了一个位置，后面全体前移，就像排队有人走了后面补上来」**

**常见错误**：只把那个位置清零，没有把后面元素前移——导致数组中间出现一个空位。

**变式检验题**：

```text
数组 a = {3, 7, 2, 9, 5}，删除所有偶数，不创建新数组。
输出删除后的数组。

骨架：P8（数组删除-前移覆盖），遍历+前移，注意遍历方向（从后往前避免跳过元素）
```

### P9：滑动窗口-子串枚举

**模式定义**：

```text
输入：一个字符串
处理：从每个位置出发，枚举所有可能的子串（长度从 2 到末尾）
输出：所有子串
```

**代码骨架**：

```c
for (start = 0; start < len - 1; start++) {       // 枚举起点
    for (end = start + 2; end < len; end++) {     // 枚举终点（长度 > 2）
        // 子串 s[start..end]
        检查这个子串是否满足条件;
    }
}
```

**真题映射**：

| 真题 | 起点枚举范围 | 终点枚举范围 | 检查条件 |
|---|---|---|---|
| 题 8（回文） | `start = 0` 到 `len-3` | `end = start+2` 到 `len-1` | 是否回文 + 是否已存在 |

**识别口诀**：**「固定起点，滑动终点，枚举所有子串」**

**容易混淆**：
- 学生常把起点和终点的边界搞错——长度要大于 2，所以终点至少是起点+2
- 终点枚举的结束位置是字符串长度-1

**变式检验题**：

```text
找出字符串 "abcabc" 中所有出现过至少两次的长度为 2 的子串。

骨架：P9（滑动窗口-子串枚举）+ P1（遍历-计数）
```

### P10：回文判断

**模式定义**：

```text
输入：一个字符串
处理：从两端往中间比较对应位置是否相等
输出：是回文 / 不是回文
```

**代码骨架**：

```c
int head = 0, tail = len - 1;
while (head < tail) {
    if (s[head] != s[tail]) {
        return 0;  // 不是回文
    }
    head++;
    tail--;
}
return 1;  // 是回文
```

**真题映射**：

| 真题 | 需要判断的位置 | 和主程序的关系 |
|---|---|---|
| 题 8（回文） | GenStr 函数内部，判断每个子串 | P9 枚举出子串 → P10 判断是否回文 |

**典型考题变形**：
- 判断一个整数是不是回文数字
- 判断一句英文忽略大小写和标点后是不是回文

**识别口诀**：**「从两端往中间走，每一步都比较，不一样就不是回文」**

**变式检验题**：

```text
判断字符串 "madam" 是不是回文，推演 head 和 tail 的每一步变化。

骨架：P10（回文判断）
```

### P11：累加器+计数器

**模式定义**：

```text
输入：一个序列
处理：循环中同时维护一个计数变量和一个累加变量
输出：计数结果 + 累加结果
```

**代码骨架**：

```c
int count = 0;
int sum = 0;  // 或 long sum = 0
for (i = 0; i < len; i++) {
    if (满足条件) {
        sum += 某个值;
        count++;
    }
}
// 结果：count 是符合条件的个数，sum 是它们的累加值
```

**真题映射**：

| 真题 | 计数器 | 累加器 | 条件 |
|---|---|---|---|
| 第一题"19731204" | `count++` | —（只有计数器） | `!digit[i]` |
| 第二题"1H3ap1py!" | — | `sum`（累加数字） | `c[s] >= '0' && c[s] <= '9'` |

**容易混淆**：
- 和 P1（计数数组）的区别：P1 用数组分散计数，P11 用一个变量集中计数
- P11 的「累加器」是 sum += 值；P1 的「累加」是对数组某个位置 +1

**识别口诀**：**「count 管有几个，sum 管一共多少」**

**变式检验题**：

```text
数组 scores = {78, 92, 65, 88, 54, 73}
统计及格人数 + 及格学生的总分。

骨架：P11（累加器+计数器）
```

### P12：标志位

**模式定义**：

```text
输入：根据某些条件
处理：设置一个标志位（通常 int 类型，取值 0/1 或具体值）
输出：标志位用于控制后续分支行为
```

**代码骨架**：

```c
int flag = 0;  // 默认状态
if (条件 A) {
    if (条件 B) {
        flag = 1;  // 满足特殊条件时改变标志
    } else {
        flag = 0;
    }
} else {
    flag = 0;
}

// 后续根据 flag 决定行为
if (flag) {
    // 满足条件时的操作
} else {
    // 不满足时的操作
}
```

**真题映射**：

| 真题 | 标志位 | 含义 | 后续用途 |
|---|---|---|---|
| 题 78（闰年） | `n` | `n=1` 闰年 / `n=0` 非闰年 | `if(n)` 控制输出 |

**典型考题变形**：
- 判断素数：用 `isPrime` 标志位
- 搜索数组中是否存在某个值：用 `found` 标志位

**容易混淆**：
- 标志位未初始化的 bug（学生的常见错误）
- `if(flag)` 等价于 `if(flag != 0)`——学生可能不熟悉这种写法

**识别口诀**：**「先设一个标记，满足条件就改它，后面看标记决定走哪条路」**

**变式检验题**：

```text
判断数字 n 是否为素数。用标志位实现。

骨架：P12（标志位），设 isPrime=1，如果能被 2 到 sqrt(n) 整除就改为 0
```

## 3. 骨架复合关系

很多真题不是单一骨架，而是多个骨架的复合：

| 真题 | 骨架组合 | 复合方式 |
|---|---|---|
| 第一题"19731204" | P1（遍历-计数）→ P6（遍历-查缺）+ P11（计数器） | 先计数再查缺，两段顺序执行 |
| 第二题"1H3ap1py!" | P2（过滤）+ P3（累加数字）= P4（同时多路处理） | 一个循环同时做两件事 |
| 题 78（闰年） | P5（分类判断）→ P12（标志位） | 分类结果存为标志位，后续使用 |
| 题 80（图形） | P7（嵌套循环-图形打印）×2 | 上半部分 + 下半部分两个 P7 顺序执行 |
| 题 81（成绩） | P8（数组删除）+ P11（累加器）+ P1（计数） | P8 内部需要 P11 |
| 题 8（回文） | P9（滑动窗口-子串枚举）+ P10（回文判断） | P9 产生子串 → P10 检查 → 排序去重 |

**复合时学生最容易卡住的地方**：

```text
1. 分不清两个骨架的「边界」——哪里是第一个骨架结束、第二个开始
2. 当一个循环同时实现两个骨架时（P4），分不清两套变量各管各的
3. 嵌套复合时（一个骨架内部调用另一个骨架），推演容易断
```

**教学的默认顺序**：

```text
1. 先教单骨架（P1-P12 每个单独讲）
2. 再教顺序复合（P1→P6 这种，前一个结果给后一个用）
3. 再教同步复合（P4 这种，一个循环同时做多件事）
4. 最后教嵌套复合（P9→P10 这种，一个骨架内部调用另一个）
```

## 4. 骨架识别教学法

### 4.1 学生说「每行都能看懂，但不知道程序在干什么」时的标准流程

```text
第一步：帮学生识别程序骨架
  "你先不看代码细节。就说：这个程序拿什么做输入，想输出什么结果？"
  → 学生能用自然语言说清功能

第二步：命名骨架
  "这个过程，其实就是一个很常见的模式：[骨架名称]。
   你看，[一句话解释这个骨架在做什么]。"
  → 从 P1-P12 中找到匹配的骨架

第三步：回看代码用骨架套
  "好，现在带着这个骨架回看代码：
   外层循环在做什么？是哪一步？
   这个数组在做什么？是哪一步？"
  → 代码从「一堆散行」变成「骨架的具体实现」

第四步：变式检验
  "换一道题。不需要你写代码——先说骨架是什么。"
  → 用骨架的变式检验题验收
```

### 4.2 骨架比较教学法（针对 M23 假懂）

当学生第一题「懂了」第二题又不会时：

```text
第一步：让学生做骨架命名
  "第一题是什么骨架？第二题是什么骨架？"
  → 如果学生说不清，说明他只是记住了题

第二步：并列对照
  |  | 第一题 | 第二题 |
  |---|---|---|
  | 骨架 | P1+P6 | P4（P2+P3） |
  | 输入 | 纯数字字符串 | 混合字符 |
  | 一个循环做几件事 | 一件事（计数） | 两件事（过滤+累加） |

第三步：让学生自己找出差异
  "你自己看出来没有——第一题的循环只管一件事，
   第二题的循环同时管两件事。
   这就是为什么你第一题会了第二题又不会：
   不是因为 C 语言没学好，
   是因为没有意识到两道题的程序骨架完全不同。"
```

## 5. 骨架识别速查表（给 AI 用）

当学生发来一道题，AI 内部快速判断：

```text
1. 程序里有 digit[c]++ → 考虑 P1（遍历-计数）
2. 程序里有 sum = 10 * sum + c - 48 → 考虑 P3（遍历-累加数字）
3. 程序里一个循环同时有 P1/P2/P3 中的两种以上 → 这是 P4（同时多路处理）
4. 程序里有 if(!count[i]) → 考虑 P6（遍历-查缺）
5. 程序里有嵌套循环 + printf 空格和字符 → P7（图形打印）
6. 程序里有 arr[j] = arr[j+1] → P8（数组删除-前移覆盖）
7. 程序里有双层 for 枚举起点和终点 → P9（滑动窗口-子串枚举）
8. 程序里有 while(head < tail) 两端比较 → P10（回文判断）
9. 程序里有 count++ 和 sum+= → P11（累加器+计数器）
10. 程序里有 flag = 0/1，后面 if(flag) → P12（标志位）
```

## 6. 本包使用原则

1. **骨架是理解工具，不是背诵材料。** 和学生对话时不要说「这是 P1 骨架」——说「这个程序其实就在做一件事：遍历 + 计数」。
2. **先骨架，再逐行。** M22 卡点的学生，先帮他识别骨架，再逐行推演。不要一上来就逐行。
3. **一次只比较两个骨架。** 骨架比较时不要一口气列 5 个——拿学生刚做的题和刚卡住的题比。
4. **变式检验是骨架教学的终点。** 学生能正确识别骨架之后，必须做一次变式检验，否则无法判断是真懂还是背题。
5. **如果骨架不在本库中，判断学生卡的是具体知识点（转 PACK_MISCONCEPTION）还是新骨架模式（可能需要扩展本库）。**
