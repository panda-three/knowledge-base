## 一、红九模型：9 种人生红点类型

### 总论

人生红点不是「你适合干什么工作」，而是「你未来很长一段时间里，最值得持续投入的核心命题」。9 种类型不互斥，但第一红点只能有一个。

**三个内核条件（缺一不可）：**

| 条件 | 判断标准 |
|---|---|
| **你擅长** | 你真的擅长，且有机会做到 Top |
| **你享受** | 你享受且有成就动机，能够持续努力 |
| **有意义** | 对别人有价值，对你人生有意义 |

---

### 9 种类型完整定义

#### 1. 作品型
- **核心追求**：做出一个完整的、有形的、属于自己的作品
- **能量来源**：从无到有的创造过程；看到成品时的完成感
- **典型表现**：做产品、写书、拍电影、作曲、画画、写代码发布开源项目、做一门课
- **擅长**：动手建造，把想法变成现实
- **常见误区**：把「喜欢消费作品」当成「喜欢创造作品」
- **Truman 判断金句**：「作品型的人，最怕的不是做不出来，是做出来了没人看、没人用。」

#### 2. 体验型
- **核心追求**：充分体验人生的丰富性，追求峰值体验
- **能量来源**：新鲜感、多样性、探索未知
- **典型表现**：旅行、尝试不同行业、接触不同文化、追求极致的感官或情感体验
- **擅长**：适应力强，对多样性有天然包容
- **常见误区**：把「逃避无聊」当成「追求体验」；容易浅尝辄止
- **Truman 判断金句**：「体验型的人，最难的不是出发，是持续。」

#### 3. 赚钱型
- **核心追求**：通过商业手段持续创造财富
- **能量来源**：数字增长、交易完成、资源配置的效率感
- **典型表现**：创业以盈利为核心、投资、交易、销售
- **擅长**：算账、资源配置、识别机会
- **常见误区**：把钱和人生意义划等号；不赚钱就不做
- **Truman 判断金句**：「赚钱型的人需要问自己：钱够了之后呢？」

#### 4. 高手型
- **核心追求**：在某个领域成为顶尖专家，追求极致专业
- **能量来源**：对「深度」和「精通」的痴迷；持续突破技术上限
- **典型表现**：技术专家、医生、律师、学者、匠人
- **擅长**：专注、持续深耕、耐受长期枯燥
- **常见误区**：只追求深度，忽略宽度和迁移性
- **Truman 判断金句**：「高手型的陷阱：越深越窄，最后只剩下自己。」

#### 5. 成就型
- **核心追求**：持续达成更高目标，追求可量化的里程碑
- **能量来源**：破纪录、达成目标、获得认可、阶段性的胜利感
- **典型表现**：职业经理人、运动员、竞赛型选手
- **擅长**：目标管理、执行力强、善于打硬仗
- **常见误区**：目标达成了然后呢？容易进入「下一个目标」的空转
- **Truman 判断金句**：「成就型的终极问题是：最后一个成就之后，你是谁？」

#### 6. 关系型
- **核心追求**：帮助他人成长，建立深度关系
- **能量来源**：看到别人因为自己而变好；深度连接中的情感流动
- **典型表现**：老师、教练、咨询师、管理者（以人为核心）
- **擅长**：共情、倾听、引导、建立信任
- **常见误区**：过度投入他人而忽略自己；边界模糊
- **Truman 判断金句**：「关系型的人最需要学会的是：帮人不等于替人活。」

#### 7. 自由型
- **核心追求**：对时间和生活的掌控权
- **能量来源**：不受约束地做自己想做的事；拒绝被绑定
- **典型表现**：自由职业、数字游民、独立创作者
- **擅长**：自我驱动、高效决策、极简生活
- **常见误区**：把「不想被管」当成「追求自由」；缺乏结构导致低效
- **Truman 判断金句**：「自由型的核心不是'没人管我'，是'我能管好自己'。」

#### 8. 意义型
- **核心追求**：推动某个更大的事业或信念，改变世界的一部分
- **能量来源**：使命感、影响他人、推动变革
- **典型表现**：公益、社会企业、环保、教育公平、基础科研
- **擅长**：长期坚持、忍受短期没有回报、凝聚同路人
- **常见误区**：过于宏大而忽略个人生存基础
- **Truman 判断金句**：「意义型最危险的是：用全人类的痛苦替代自己具体该做的事。」

#### 9. 生活型
- **核心追求**：过好每一天的日子，在平淡中感受幸福
- **能量来源**：家庭、日常、小确幸、稳态的幸福感
- **典型表现**：重视家庭时间、追求工作生活平衡、享受日常仪式感
- **擅长**：稳定输出、可持续、不折腾
- **常见误区**：把「生活型」当成「没追求」——这本身是一种偏见
- **Truman 判断金句**：「生活型不是没追求，是追求的东西不在大众评价体系里。」

---

### Truman 原话：不叫什么人生红点

1. 不是你的工作（工作是红点的载体，不是红点本身）
2. 不是你的爱好（爱好不需要承担压力）
3. 不是你擅长的事（擅长但不享受的事，做久了会消耗）
4. 不是你享受的事（享受但不给别人创造价值，长期会空虚）
5. 不是别人觉得你应该做的事（别人的人生红点不是你的）

## 二、餐巾纸诊断法：五步法

### 步骤一：收集线索

问用户的 12 组问题（详见系统提示词「起·承·转·合四段法」），收集足够多的决策事实和感受线索。

### 步骤二：识别模式

从线索中找三个东西：
- **共性**：反复出现的方向或特质
- **矛盾**：言行不一致的地方
- **缺失**：用户在回避什么

### 步骤三：提出假设

用红九模型做映射：「基于你刚才说的，你更像是 X 型和 Y 型的混合，但第一红点更像是 X。你觉得呢？」

### 步骤四：验证假设

用两个问题验证：
1. 「如果未来 3 年你只做这一件事，你会不会觉得亏了？」
2. 「如果这一件事你做成了，你还会继续做吗？」

### 步骤五：形成判断

不追求 100% 确定。达到「80% 笃定」就可以开始行动。Truman 原话：「人生红点不是算命，不用等 100%，80% 笃定就够了。剩下的 20%，边做边校准。」

## 三、真实案例速查（脱敏版）

### 案例一：以为是高手型，其实是作品型

**用户自述**：「我在技术领域做了 8 年，我觉得自己是高手型。」

**诊断发现**：
- 用户享受的不是技术深度本身，而是「把一个东西做出来，给别人用」
- 最深层的满足感来自「用户说好用」而不是「技术难度最高」
- 真正驱动力是建造和交付，不是精进技术

**Truman 的判断**：「你真正追求的，是做出一款你和用户都满意的产品，这个追求的本质是作品型。你这些年的技术积累，是你作品的红利和壁垒。」

---

### 案例二：嘴上说追求意义，实际上一直在选赚钱

**用户自述**：「我想做有意义的事，像教育、环保之类的。」

**诊断发现**：
- 用户过去 5 年的关键决策，每一次都选了收入更高的选项
- 「有意义的事」从来没有被真正推进过，只是一个挂在嘴边的愿望
- 提到收入数字时眼睛发亮，提到公益项目时语气平淡

**Truman 的判断**：「你嘴上说的想要——意义；和你实际一直在追求的——赚钱。这是两个东西。你的第一红点可能更接近赚钱型，意义可以是你赚钱以后去支持的东西。不是说赚钱型就比意义型低一等——你的选择已经替你回答了。」

---

### 案例三：不知道自己是什么型，但所有线索指向同一个方向

**用户自述**：「我真的不知道自己喜欢什么，好像什么都行，又好像什么都不够。」

**诊断发现**：
- 用户每份工作都干不长，不是能力问题，是「做着做着就觉得没意思了」
- 唯一持续做的事是：旅行。每年至少 2-3 次，每次都有详细的攻略记录
- 提到旅行时，从语气到细节量完全不同——能说出每个城市的街道、食物、当地人的习惯

**Truman 的判断**：「你在这个话题上的信息量和能量完全不一样。你过去几年的选择，其实一直在为体验让路——换工作是因为'没意思了'，攒钱是为了下一次旅行。你很可能是一个体验型。你之前不敢承认，是因为社会告诉你'体验型不是正经追求'。但你就是。」

---

### 案例四：陷入多重矛盾，最后发现被「应该」绑架了

**用户自述**：一直在纠结几个方向，每个都说了一堆理由。

**诊断发现**：
- 用户说的 A、B、C 三个方向里，A 是父母期望的，B 是同行都在做的，C 是自己忍不住偷偷做的
- 提到 C 时语速变快、细节变多、开始笑
- 但用户一直在给 A 和 B 加理由，给 C 找借口说是「不成熟的想法」

**Truman 的判断**：「A 是你觉得应该做的。B 是别人觉得你应该做的。C 是你忍不住会做的。你过去花 90% 的时间在论证 A 和 B 的合理性，只花 10% 的时间在做 C。但你的能量完全在 C 那里。你在用你的逻辑对抗你的本能。这就是为什么你一直在纠结。」

## 四、Truman 判断金句全库（对话中可直接使用）

| 金句 | 使用场景 |
|---|---|
| 「你嘴上说的想要，和你实际一直在追求的，可能不是同一个东西。」 | 用户言行不一致时 |
| 「案例背后是状态，状态背后是理念，理念背后是取舍。」 | 用户说了很多案例但缺规律时 |
| 「你真正花在核心追求上的高质量训练时间，不到工作总时间的 20%。」 | 帮用户量化真实投入时 |
| 「A 是你觉得应该做的，B 是你忍不住会做的——哪个才是你？」 | 用户纠结于「应该」和「本能」时 |
| 「你在用你的逻辑对抗你的本能。」 | 用户过度理性化自己的选择时 |
| 「你过去几年的选择，已经替你回答了。」 | 用户说不清但决策记录很诚实 |
| 「体验型的核心不是'没人管我'，是'我能管好自己'。」 | 给自由型做校准 |
| 「钱够了之后呢？」 | 给赚钱型做深度追问 |
| 「关系型最需要学会的是：帮人不等于替人活。」 | 给关系型做边界提醒 |
| 「最后一个成就之后，你是谁？」 | 给成就型做深度追问 |
| 「人生红点不是算命，不用等 100%，80% 笃定就够了。剩下 20%，边做边校准。」 | 收口时给用户降低决策压力 |
| 「最终答案在你自己心里。」 | 诊断结束前 |
| 「AI 有幻觉且不稳定，拿不准多测 2-3 轮交叉验证。」 | 每次对话结束时 |

## 五、常见用户状态识别与应对

| 用户状态 | 典型信号 | 应对方式 |
|---|---|---|
| **过度理性化** | 「我分析过，A 的市场更大，B 的竞争更小...」但语气平淡 | 绕开分析，问「你忍不住会做哪个」 |
| **防御性模糊** | 「都差不多」「说不上来」 | 换角度问具体案例：「上一次发生是什么时候？」 |
| **被应该绑架** | 一直在论证某个方向的合理性 | 「如果没有人会评价你，你会怎么选？」 |
| **焦虑型纠结** | 「我怕选错」「万一不是呢」 | 降压力：「80% 笃定就够了，不用等 100%。剩下 20%，边做边校准。」 |
| **能量太低** | 全程语气平淡，没有任何话题能量明显走高 | 可能有更深层问题，温和建议：「你现在的状态可能需要先把基本状态恢复，红点探索可以等一等。」 |

## 六、十二问速查卡（精简版，对话中快速调用）

| 角度 | 第一问 | 关键追问 |
|---|---|---|
| 关键选择 | 过去做过哪些关键决策？ | 背后原因是什么？有没有规律？ |
| 峰值瞬间 | 过去有哪些特别开心兴奋的时刻？ | 当时具体发生了什么？为什么开心？ |
| 低谷瞬间 | 过去有哪些特别沮丧厌恶的时刻？ | 当时发生了什么？为什么难受？ |
| 对标标杆 | 你特别想去对标谁？ | 他们的什么打动了你？ |
| 无限想象 | 钱不是问题的话，最想做什么？ | 你希望成为什么样的人？ |
| 具体画面 | 你能想象到的最美好状态是什么？ | 哪些具体画面是你向往的？ |
| 挖掘共性 | 过去的经历和未来的向往中，有哪些共性？ | 这些共性背后有什么底层特质？ |
| 找寻冲突 | 过去的决策有没有价值判断很不一样的？ | 为什么有这些冲突？ |
| 内核边界 | 你最最想做的事情类型是什么？ | 哪些事情是你不能忍受的？ |
| 红点排除 | 九个红点类型中，哪个肯定可以排除？ | 先排除掉 3 个不是的，是哪三个？ |
| 设置底线 | 哪些是底线，60 分就可以？ | 这些做到 OK 水平，人生是不是真的足够 OK？ |
| 强制排序 | 最想追求的 Top1 红点是什么？ | 如果 A 和 B 矛盾，只能选一个，选哪个？ |
