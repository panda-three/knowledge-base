# 五、新建主题文件夹的判断标准
source: 自创/实践产物
---
## 一、核心公式

```
新主题文件夹 = 同时满足两个条件：

条件A：≥ 3 张卡片
条件B：核心问题不被已有主题覆盖
```

两个条件缺一不可。

---

## 二、条件 A：≥ 3 张卡片

**为什么是 3 张：** 1 张卡不构成主题——它可能只是一篇独立文章。2 张卡是巧合——可能刚好有两篇相关但不成体系。3 张卡说明这是一个可以被持续积累的知识类别。

**怎么数：**

| 情况 | 判断 |
|---|---|
| 一篇笔记拆出 ≥ 3 张卡 | ✅ 满足条件 A |
| 一篇笔记只拆出 1-2 张卡 | ❌ 不满足。归入已有主题或暂放 |
| 多篇笔记累加 ≥ 3 张卡 | ✅ 满足。前提是这些笔记都属于同一个核心问题 |

**实例：**

```
✅ 机会预判认知篇 → 拆出 9 张卡 → ≥ 3 → 满足条件A
✅ 科学销售案例课 → 拆出 8 张卡 → ≥ 3 → 满足条件A
✅ 项目管理必修课 → 拆出 7 张卡 → ≥ 3 → 满足条件A
✅ 灵感闪现（认知篇+工具篇）→ 累计 12 张 → ≥ 3 → 满足条件A
✅ 刻意练习认知篇 → 拆出 9 张卡 → ≥ 3 → 满足条件A
```

---

## 三、条件 B：核心问题不被已有主题覆盖

**判断方法：** 如果这篇笔记的核心问题，已经有一个主题文件夹在回答了，就归入已有主题。否则，新建。

**每个主题回答的核心问题：**

| 已有主题 | 回答的核心问题 |
|---|---|
| 灵感闪现 | 面对开放性难题，如何独立产生大量创造性解法？ |
| 刻意练习方法论 | 如何用科学方法把认知变成稳定能力？ |
| 科学销售 | 如何从直觉式销售管理进化到科学式销售管理？ |
| 机会预判 | 如何判断一个创业方向值不值得做？ |
| 项目管理 | 如何把一件事从方案推到复盘，稳稳办成？ |
| 团队知识管理 | 如何让团队的知识持续沉淀、复用、迭代？ |
| AI知识库搭建 | 如何用 AI 时代的方法搭建和管理个人/团队知识库？ |
| Partner搭建 | 如何设计、搭建、迭代一个能稳定工作的 AI Partner？ |

**判断流程：**

```
这篇笔记最想回答的核心问题是什么？
  ↓
打开上面那个表，一个一个对
  ↓
有匹配的吗？
  ├── 有 → 归入那个主题。不新建。
  └── 没有 → 满足条件B。配合条件A判断是否新建。
```

**实例：**

```
✅ 新建「机会预判」
   核心问题：如何判断创业方向值不值得做？
   已有主题无一匹配 → 条件B满足 → 新建

✅ 归入「灵感闪现」
   核心问题：SOUL工具篇——如何具体操作灵感闪现？
   已有「灵感闪现」主题 → 不新建 → 归入已有主题

✅ 新建「项目管理」
   核心问题：如何稳稳地把一件事做成？
   已有主题无一匹配 → 条件B满足 → 新建

⚠️ 边界案例：
   如果一篇笔记讲「如何用刻意练习的方法练项目管理」
   → 核心问题是项目管理 → 归入「项目管理」
   → 同时做跨主题关联到「刻意练习方法论」
```

## 四、决策流图

```
一篇笔记拆完
    ↓
数卡片数量
    ↓
  < 3 张？
    ├── 是 → 归入最接近的已有主题，或暂放
    └── 否 → 往下走
              ↓
         核心问题已被已有主题覆盖？
           ├── 是 → 归入已有主题
           └── 否 → 新建主题文件夹
```

## 五、新建主题的标准结构

```
04 man/20最佳实践池子/[新主题名]/
├── [枢纽卡名].md                 ← 🏠 核心模型
├── [子卡1].md
├── [子卡2].md
├── ...
├── [策略武器库卡].md
├── [评估工具卡].md
├── [案例卡].md
└── [其他子卡].md
```

**命名规则：**

- 主题文件夹名 = `category` 值 = 中文，2-6 个字
- 必须是名词或名词短语，不能是句子
- 能让人一眼看出这个文件夹里装的是什么

**当前所有主题文件夹：**

```
04 man/20最佳实践池子/
├── 灵感闪现/
├── 刻意练习方法论/
├── 科学销售/
├── 机会预判/
├── 项目管理/
├── 团队知识管理/
├── AI知识库搭建/
├── Partner搭建/
├── AI教学/（已有，在 man 里）
└── C语言教学/（已有，在 man 里）
```

## 六、何时不新建——归入已有主题

**场景一：工具篇/实操篇**

灵感闪现工具篇 → 归入「灵感闪现」。项目管理实操篇 → 归入「项目管理」。

**判断：** 这篇笔记的核心问题，认知篇已经在回答了。工具篇是认知篇的子集。

**场景二：同一主题的进阶课**

预判商业篇、预判行业篇 → 归入「机会预判」。不同的课，同一个核心问题。

**场景三：卡片数不足 3 张**

拆出来只有 1-2 张 → 不新建。找到最接近的已有主题，归入。同时写清楚 experience_boundary 说明这张卡的独立性，便于以后拆多了再独立。

**场景四：核心问题模糊**

如果连「这篇笔记回答什么问题」都说不清楚 → 不新建。先归入已有主题，等认知清楚了再调整。

## 七、⚠️ 可以破例的情况

以下情况不满足条件 A（< 3 张），但可以考虑新建：

| 破例条件 | 示例 | 理由 |
|---|---|---|
| 这个主题你确定会持续积累 | 你刚开始拆清单体笔记，目前只拆了 2 张，但你知道一个月内会拆出 10 张 | 预判性建文件夹，减少后续迁移成本 |
| 这 1-2 张卡极其独立，找不到已有的主题可以归属 | 一张关于「面试技巧」的卡，不属于灵感闪现/刻意练习/知识管理任何一个 | 放错文件夹比空文件夹更糟糕 |

**破例时的注意事项：**

- 在文件夹里放一个空文件 `(主题说明).md`，写清楚这个主题回答什么问题、预期会有什么类型的卡片
- 不要因为破例而降低标准——破例是预判，不是偷懒

## 九、实操自检清单

每次拆完一篇新笔记，做这个检查：

```
[ ] 这篇笔记最想回答的一个核心问题是什么？能一句话说清楚吗？
[ ] 这个问题已经被哪个已有主题覆盖了吗？（对照主题地图）
    [ ] 已有覆盖 → 归入已有主题
    [ ] 没有覆盖 → 往下走
[ ] 拆出了几张卡片？
    [ ] ≥ 3 张 → 新建主题文件夹
    [ ] < 3 张 → 归入最接近的已有主题，或满足破例条件时新建
[ ] 新建的主题名符合命名规则吗？（2-6个字，名词短语，一眼看出装什么）
[ ] 新建的文件夹有枢纽卡吗？（必须有，不能全是子卡）
```
