# 通用版 · 大量重复设计（完整展开）

---

## 先记住核心判断

```
大量重复 ≠ 每次都走完全程。
大量重复 = 围绕一个具体实操能力，让至少一个动作在今天再循环一轮。
```

三个动作在同一天内、围绕同一个练习对象跑完——哪怕拆到不同时段——就是一次完整有效重复。

---

## 通用启动流程

给任何能力设计大量重复时，只问三句话：

```
1. 这个能力，能不能绑定一个每天必然发生的场景？
   → 能 → 路一（日常绑定）。这是最快拉次数的方式。

2. 这个能力太重，能不能拆出一个 3-5 分钟就能做的小动作？
   → 能 → 路二（专项小练）。这是保底的不中断方式。

3. 这个能力的底层是什么？能不能在其他场景也练到？
   → 能 → 路五（迁移练习）。这是最省力的翻倍方式。
```

三句话答完，你的大量重复设计就成型了。

## 五条路 · 通用模板

### 路一：日常练习 — 绑定固定场景

**一句话**：找到一个每天必然发生的事，把练习嵌进去。不额外安排时间。

**设计模板**：

```
1. 列出你每天或每周必然发生的事（开会、写文档、发消息、做决策、和别人沟通……）
2. 从里面挑 2-3 个最高频的
3. 把练习动作绑上去：这件事发生 = 练习自动触发
```

**不只清单体笔记的例子**：

| 能力 | 绑定场景 | 绑什么动作 |
|---|---|---|
| 写提示词 | 每次打开 AI 工具 | 写之前先在脑子里默念一遍你的提示词 checklist 前三项 |
| AI 培训讲课 | 每次内部分享/汇报 | 不管主题是什么，刻意练「开场用一句话讲清楚今天要解决什么问题」 |
| 学员辅导 | 每次学员找你问问题 | 不管多忙，先追问一句「你刚才说的这个问题，背后真正卡住你的是什么」 |
| 做决策 | 每次有人找你拍板 | 先写假设、再找证据、再判断——哪怕只花 30 秒 |
| 写作/表达 | 每次发工作消息 | 结论先行，一行一义——连微信消息都是练习场 |

---

### 路二：专项练习 — 拆成小动作单练

**一句话**：完整练习太重时，把最薄弱的 1 个动作拆出来单独练。3-5 分钟就能跑一轮。

**设计模板**：

```
1. 把这个能力的完整动作拆成 3-5 个小步骤
2. 找出你最薄弱的 1 个步骤
3. 设计一个只用 3-5 分钟就能单练这个步骤的小练习
4. 能随时做，不需要等完整场景
```

**不只清单体笔记的例子**：

| 能力 | 拆出的小动作 | 单练方式 | 耗时 |
|---|---|---|---|
| 写提示词 | 任务描述清晰度 | 拿一个旧 Prompt，只改第一段任务描述，改到不能再清楚 | 5 分钟 |
| 写提示词 | 边界处理 | 拿一个能跑的 Prompt，故意想 3 种它会翻车的输入，补约束 | 5 分钟 |
| AI 培训讲课 | 举例能力 | 每天找一个概念，只用一句话 + 一个例子把它讲清楚 | 3 分钟 |
| AI 培训讲课 | 节奏控制 | 录自己讲 5 分钟，回听，只关注「哪里语速突然变快了」 | 5 分钟 |
| 学员辅导 | 追问 | 翻出以前的辅导记录，对学员的每一句回答，补一个你应该追问但当时没问的问题 | 3 分钟 |
| 学员辅导 | 卡点判断 | 看一段学员描述，只写一句话：他最核心的卡点是什么？ | 2 分钟 |
| 做决策 | 假设先行 | 翻出一个已经做完的决策，倒推：如果重新来，我会先写哪 3 个假设？ | 3 分钟 |

**关键**：小动作够小，才能在碎片时间里跑起来。3 分钟能做的，就别设计成 30 分钟的。

---

### 路三：主动练习 — 不等任务安排

**一句话**：不等到「正好有项目」「正好有人找我」才练。自己把日常信息、任务、碎片全部变成练习对象。

**设计模板**：

```
1. 扫描你一天中会自然遇到的「输入」：消息、文章、对话、任务、决策……
2. 每遇到一个，问自己：这件事能不能顺便练一下 [能力名]？
3. 能就立刻做，哪怕只做 30 秒
```

**不只清单体笔记的例子**：

| 能力 | 主动找的机会 | 动作 |
|---|---|---|
| 写提示词 | 看到别人分享了一个好用的 Prompt | 不直接复制。自己重写一遍，只改结构不改功能 |
| AI 培训讲课 | 听到别人讲了一个好概念 | 停下来，心里默默用你自己的话重讲一遍 |
| 学员辅导 | 群里有人提问 | 不直接给答案。先反问一句帮他澄清问题 |
| 做决策 | 看到一个新闻/案例 | 问自己：如果是我来做这个决策，我最先查什么信息？ |
| 结构化表达 | 写任何东西之前 | 先花 10 秒在脑子里列 3 个要点，再动笔 |

---

### 路四：叠加练习 — 同一段时间练不止一层

**一句话**：你已经在一个场景里了，顺手多练一层能力。不额外花时间。

**设计模板**：

```
1. 找一个你每天都在做的任务（主任务）
2. 问自己：做这个任务时，我能不能同时在心里练 [能力名] 的某一个动作？
3. 叠加进去。主任务不丢，练习白捡
```

**不只清单体笔记的例子**：

| 主任务 | 叠加练什么 | 怎么练 |
|---|---|---|
| 写工作文档 | 提示词思维 | 每写一段，问自己：如果我把这段变成给 AI 的 Prompt，我会怎么写？ |
| 听别人汇报 | 卡点判断 | 在心里判断：他卡在哪里？是信息不够、判断不准、还是表达不清？ |
| 开会 | 追问能力 | 每次有人说完，在心里补一个追问：他说的这句话，真正的原因是什么？ |
| 看一篇好文章 | 结构化表达 | 看完不关。用 3 个要点把这篇文章的结构拆出来 |
| 和 AI 协作 | 脱水能力 | AI 输出一大段，你在心里压成 3 行 |

**这是最省时间的翻倍方式。** 时间没多花，练习密度翻倍。

---

### 路五：迁移练习 — 越底层，机会越多

**一句话**：不要只盯着表层任务练。抽到它背后的底层能力，你会发现同一个能力在很多场景都能练。

**设计模板**：

```
1. 问自己：这个能力，底层在练什么？（通常能归到表达、判断、萃取、建模、追问这几类）
2. 列出其他也会用到这个底层能力的场景
3. 每次进入那些场景时，提醒自己：这也是在练 [底层能力]
```

**不只清单体笔记的例子**：

| 表层能力 | 底层能力 | 可以在哪些场景练 |
|---|---|---|
| 写提示词 | **结构化表达** | 写文档、写复盘、写方案、发长消息、做 PPT |
| AI 培训讲课 | **概念讲香** | 给同事解释一件事、写周报、做分享、回答学员问题 |
| 学员辅导 | **追问 + 卡点判断** | 开会时追问同事、看文章时判断作者真正在说什么、自己做决策时追问自己 |
| 做方案 | **假设-验证** | 做任何决策、分析任何问题、评估任何选项 |
| 记笔记 | **信息萃取** | 听汇报、读文章、看数据、和同事沟通——任何信息输入场景 |

## 跨能力大量重复设计模板

把这个模板存下来，以后给任何能力设计大量重复时直接套：

```
【能力名】· 大量重复设计

1. 硬底线（每次必须守住的最小动作）：
   - [___] ← 这个动作不做，就根本不算在练这个能力

2. 绑定场景（路一）：
   - 场景：[___] → 自动触发动作：[___]
   - 场景：[___] → 自动触发动作：[___]

3. 专项小练习（路二）：
   - 小动作1：[___]（耗时：___分钟）
   - 小动作2：[___]（耗时：___分钟）
   - 小动作3：[___]（耗时：___分钟）

4. 主动找的机会（路三）：
   - 机会：[___] → 立刻做：[___]

5. 叠加练习（路四）：
   - 主任务：[___] → 顺便练：[___]

6. 底层能力迁移（路五）：
   - 底层能力：[___]
   - 其他可练场景：[___]、[___]、[___]

7. 一天内的拆分模式：
   - 上午/触发：[___]
   - 下午/精力好时：[___]
   - 晚上/收尾：[___]

8. 次数怎么算：
   - 只做了硬底线 = 0.5 次
   - 硬底线 + 挑战/反馈至少做 1 个 = 0.7 次
   - 上午 + 下午 + 晚上，同一天围绕同一对象跑完 = 1 次 ✅
```

## 回到你身上：下一步可以做什么

你现在手上有三个能力可以练：清单体笔记（已经有完整设计）、AI 培训讲课、学员辅导。

**建议先挑一个，用上面的模板花 5 分钟填一遍。** 填完你会发现：原来这个能力的练习机会比你想象的多得多，只是过去没有被命名。
