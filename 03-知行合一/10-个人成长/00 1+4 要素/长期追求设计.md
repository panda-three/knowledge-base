# 通用版 · 长期追求设计（完整展开）

---

## 先记住核心判断

```
长期追求 ≠ 先想清楚一生方向。
长期追求 = 让这件能力和你的真实角色、阶段目标、或高手画面连上，
         连上之后，你才愿意为它凑齐套路、挑战、反馈和重复。
```

长期追求不是四个训练动作之一。它是发动机——发动机弱，后面四个要素很难持续发生。

---

## 常见卡点（对号入座）

| 卡点 | 表现 | 优先策略 |
|---|---|---|
| 理性认可，但不贴身 | 「知道重要，但和我关系不大」 | 人生红点 / 渴望高手 |
| 目标太多，排不动 | 「每个能力都重要」 | 能力分层 / 年度晋级 |
| 知道重要，但总被短期挤掉 | 「经常被任务推着走」 | 阶段目标 / 外部督促 |
| 觉得应该练，但没有心跳 | 「没有热爱」 | 对标榜样 / 过程激励 |
| 10000 小时太吓人 | 「没法投入那么多」 | 能力分层（不是每个能力都要 10 年） |
| 坚持不住 | 「练几周就停了」 | 过程激励 / 外部督促 |

## 七条路 · 通用模板

### 路一：人生红点 — 最强驱动

**一句话**：如果这件能力是你人生红点的必经之路，它就不是普通技能。你练强一点，红点实现水平就更高一点。

**适合**：已经有比较清楚的人生红点或长期方向。

**操作模板**：

```
1. 写出你的人生红点（你最想长期做成的那件事）
2. 写下：要实现它，必须经过哪 3-5 个能力关卡？
3. 当前这件能力，在其中哪个位置？
   → 如果是必经关卡 → 这份追求不需要额外设计，它已经够贴身
   → 如果不是 → 走其他路
```

**不只清单体笔记的例子**：

| 人生红点 | 必经能力 |
|---|---|
| 成为 AI 教育领域最好的产品人 | 信息萃取、结构化表达、概念讲香、用户洞察、系统设计 |
| 做出一个影响 100 万人的课程 | 讲香能力、课程设计、学员辅导、内容生产 |
| 带出一支顶级教研团队 | 识人、辅导、建模、决策、领导力 |

> 人生红点不一定每个人都清楚。没有就用下面的路，不要硬编。

---

### 路二：对标榜样 — 用高手画面拉自己

**一句话**：如果你说不清想成为什么样，但能说出佩服谁——把那个人拆开，找出你真正想学的那条能力。

**适合**：目标比较虚，需要一个具体的高手画面。

**操作模板**：

```
1. 写下这个领域你最佩服的 1-3 个人
2. 问自己：我佩服的不是他整个人，而是他哪 1-2 种能力？
3. 把那 1-2 种能力写下来 → 这就是你的追求对象
4. 每次练之前，花 10 秒想一下：如果他在旁边看，他会怎么说？
```

**不只清单体笔记的例子**：

| 佩服的人 | 真正想学的能力 |
|---|---|
| Truman | 把复杂概念讲香、深度追问、结构化表达 |
| 某个你佩服的讲师 | 开场一句话讲清问题、举例打到痛处、节奏控制 |
| 某个你佩服的提示词高手 | 系统设计思维、边界处理、清晰度 |

> 榜样不是用来崇拜的，是用来拆解的。

---

### 路三：渴望高手 — 从任务身份转向能力身份

**一句话**：把目标从「完成任务」升级成「成为这个领域更专业的人」。同样是写提示词，有人只是交差，有人在成为「能稳定封装高质量提示词的人」。

**适合**：习惯把练习当成临时任务，想要更强的身份认同。

**操作模板**：

```
1. 写下：这件能力如果练成，你希望别人怎么评价你？
   不是「能用」「会做」，而是「很专业」「很稳定」「可以被信任」
2. 这个评价就是你当前阶段的追求
3. 每次练完问自己：这一轮，我离那个评价近了一点吗？
```

**不只清单体笔记的例子**：

| 能力 | 任务身份 | 高手身份 |
|---|---|---|
| 写提示词 | 「我会用 AI」 | 「我能稳定封装高质量系统提示词」 |
| AI 培训讲课 | 「我能讲完一节课」 | 「学员听完能立刻动手，而且不容易跑偏」 |
| 学员辅导 | 「我能回答学员问题」 | 「我能在 3 个问题内定位学员真正的卡点」 |

---

### 路四：年度晋级 — 把长期压成一年

**一句话**：不用想十年。只看今年：这件能力从哪个段位升到哪个段位？从「能做」到「稳定做」，还是从「靠感觉到」到「有套路做」？

**适合**：目标太远缺台阶，或正在面临职业/业务晋级压力。

**操作模板**：

```
1. 写下：这件能力，我现在在什么段位？（能做 / 稳定做 / 有套路做 / 能教别人做）
2. 写下：今年结束，我最想升到哪个段位？
3. 这个段位差 = 今年的长期追求
```

**不只清单体笔记的例子**：

| 能力 | 当前段位 | 今年目标 |
|---|---|---|
| 清单体笔记 | 能做现场速记，课后不稳定 | 课后 5 动作稳定做满，一周 3 次完整循环 |
| 写提示词 | 能写能用的 Prompt | 能写出结构稳定、边界清楚、可复用的系统提示词 |
| AI 培训讲课 | 能讲完 | 每节课至少 3 次互动 + 结尾一句话总结 |

---

### 路五：阶段目标 — 一次次把鞋子扔过去

**一句话**：不用想一年。先设一个看得见的下一关：20 小时快速上手、1 个月练稳一个动作、3 个月能独立完成。

**适合**：需要低门槛起步，或被 10000 小时吓住了。

**操作模板**：

```
1. 给自己一个短周期：20 小时 / 1 个月 / 3 个月
2. 写下：这个周期结束时，这件能力最明显的变化是什么？
3. 这个变化必须别人能看出来——不是「我更有感觉了」
```

**不只清单体笔记的例子**：

| 能力 | 周期 | 出口 |
|---|---|---|
| 清单体笔记 | 1 个月 | 能稳定走完现场 3 条 + 课后 5 动作，一周至少 3 次 |
| 写提示词 | 20 小时 | 能独立写出 5 个稳定运行的系统提示词 |
| AI 培训讲课 | 3 个月 | 能独立讲完一节课，学员评分稳定在 4 分以上 |

---

### 路六：过程激励 — 让练习本身有爽感

**一句话**：不是所有动力都要靠宏大意义。很多时候练得下去，是因为每次做完都有一点正反馈——作品变好了、别人认可了、效率提升了。

**适合**：理性知道重要但坚持不住，练习过程太苦。

**操作模板**：

```
1. 列出这件能力练得更好之后，你能获得的正反馈：
   - 效率快了多少？
   - 别人说过什么？
   - 作品质量有变化吗？
   - 自己做完有没有爽感？
2. 每次练完，刻意花 5 秒感受一下今天的正反馈
3. 如果长期没有正反馈 → 你的反馈机制可能没跟上（回到及时反馈要素）
```

---

### 路七：外部督促 — 让环境托住你

**一句话**：不靠意志力硬扛。用高要求的同伴、教练、公开承诺、定期检查来让自己不容易降标准。

**适合**：靠自己很难持续，但周围有高要求的人或环境。

**操作模板**：

```
1. 这件能力，身边有没有人能持续提醒你别降标准？
   → 有 → 让他定期看你的练习产出，只问一句"这轮比上轮好在哪"
   → 没有 → 能不能建一个？哪怕只找一个同伴互相看
2. 如果连同伴都找不到 → 用公开承诺替代：
   在群里立一个阶段目标，到期汇报结果
```

> 外部督促不是低级。真正成熟的练习系统，通常不是靠一个人每天热血沸腾。

## 能力分层（不是所有能力都要 10 年）

这是长期追求最重要的一个配套工具。很多时候用户不是缺追求，而是把「练能力」默认理解成「练到世界级」，然后被吓住了。

| 类型 | 周期 | 适合什么能力 | 追求写法 |
|---|---|---|---|
| 20 小时快速上手 | 1-4 周 | 小技能、工具操作、基础技巧 | 「4 周后能独立完成 X」 |
| 3-12 个月阶段进阶 | 一个阶段 | 当前阶段能拉开差距的能力 | 「半年后这个能力明显比现在稳一档」 |
| 3-10 年长期核心 | 长期 | 和人生红点、专业身份强相关 | 「这是我成为 X 的必经能力」 |
| 顺手练 / 叠加练 | 长期复利 | 不专门练，但每次做其他事时顺便磨 | 「不做专项，但每次写文档时都在练」 |

**启动问题**：这件能力对你来说，属于上面哪一类？分完类，追求的压力就会降下来。

---

## 通用启动流程

给任何能力设计长期追求时，只问四句话：

```
1. 这件能力对我为什么重要？
   → 答不上来 → 路二（找榜样）或路三（渴望高手）
   → 答得上来 → 继续

2. 它属于 20 小时上手、年度晋级、还是 10 年核心？
   → 分完类，压力先降下来

3. 我和高手的差距在哪？
   → 有具体画面 → 路二（对标榜样）
   → 没有 → 先找对标

4. 我需要什么来维持动力？
   → 缺短期出口 → 路五（阶段目标）
   → 缺爽感 → 路六（过程激励）
   → 缺外部压力 → 路七（外部督促）
```

## 跨能力长期追求设计模板

```
【能力名】· 长期追求设计

1. 这件能力为什么重要？
   - 和我的 [角色 / 红点 / 阶段目标] 的关系是：[___]

2. 它属于哪一类？
   - [ ] 20 小时快速上手 → 出口：[___]
   - [ ] 3-12 个月阶段进阶 → 今年目标：[___]
   - [ ] 3-10 年长期核心 → 它是我成为 [___] 的必经能力

3. 对标谁？
   - 榜样：[___] → 我想学他的 [具体能力]
   - 高手身份：我希望别人评价我 [___]

4. 动力来源（至少选 1 个）：
   - [ ] 人生红点
   - [ ] 对标榜样
   - [ ] 渴望高手
   - [ ] 年度晋级
   - [ ] 阶段目标
   - [ ] 过程激励
   - [ ] 外部督促

5. 当前阶段出口：
   - 周期：[___]
   - 结束时，别人能看出来的变化：[___]
```
