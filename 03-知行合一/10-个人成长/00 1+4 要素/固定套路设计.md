## 固定套路设计六条路

### 路一：创建文档 — 给练习一个稳定容器

这是最基础的。你清单体笔记那份规划就是这条路走出来的。

**设计模板（四个坑位）**：

```
# [能力名] · 刻意练习

## 启动（做之前10秒）
- 第一步：
- 第二步：

## 执行（做之中）
- 底线1：
- 底线2：
- 底线3：

## 收尾（做完后3分钟）
- 检查项1：
- 检查项2：

## 迭代记录
- 上次反馈：
- 这次改了什么：
```

**什么时候用**：能力还没有任何文档，需要从零沉淀。先建一个极粗糙的 1.0，哪怕只有 3 条底线。

---

### 路二：使用现成模型 — 先站在巨人肩膀上

不是所有套路都要自己从零发明。很多能力已经有成熟方法论。

**设计模板**：

```
1. 找到这个领域最成熟的一套方法（课程、书籍、行业标准、公司 SOP）
2. 把它拆成：启动动作 + 执行底线 + 收尾检查
3. 先严格照做 5-10 次，不跳过
4. 10 次后，根据你自己的使用体验改掉不适配的部分
```

**清单体笔记你就是走了这条路**——六条底线来自一堂笔记法课程，启动/收尾是你自己补的。

---

### 路三：匹配阶段 — 套路颗粒度和当前水平对齐

这是你刚才最有体感的一条。同一个能力，不同阶段需要不同颗粒度的套路。

**设计模板**：

| 阶段 | 套路颗粒度 | 套路长什么样 |
|---|---|---|
| 新手期 | 极粗，3-5 条 | 只记最核心的动作底线，不追求完整 |
| 进阶期 | 中等，加收尾和检查 | 可以加上自查清单、常见坑、好案例 |
| 高手期 | 细密，可自动化 | 套路内化到不需要文档，但仍在迭代 |

**你清单体笔记的应用**：现场速记用新手版（3 条），课后整理用进阶版（6 条底线 + 收尾 5 个动作）。这是同一个能力配了两套不同颗粒度的套路。

---

### 路四：抽底层模型 — 把多个技能归到同一条能力线

这是防止「每个能力都要从零设计」的关键。很多看似不同的能力，底层是同一条。

**设计模板**：

```
1. 列出你最近最常做的 5 类任务
2. 问自己：它们背后在练同一种底层能力吗？
3. 如果是，给这条底层能力建一个固定套路
4. 每次做不同任务时，都用同一套套路
```

**举例**：

| 表层任务         | 底层能力      | 可以共享的套路                  |
| ------------ | --------- | ------------------------ |
| 写提示词、写文档、写复盘 | **结构化表达** | 结论先行 → 分点 → 每条独立 → 关键词开头 |
| 记笔记、做访谈、听分享  | **信息萃取**  | 脱水 → 分层 → 抓判断不抓事实        |
| 做方案、做决策、做分析  | **假设-验证** | 先写假设 → 找证据 → 判断 → 迭代     |

当你发现写提示词和记笔记背后都在练「结构化表达」，你就不会觉得要分别设计两套完全不同的东西。

---

### 路五：自建模型 — 没有现成的就自己造 1.0

当你进入一个没有成熟方法论的新领域，就只能自己建。

**设计模板（四步沉淀法）**：

```
第一步：记下来
- 每次做完，把做得好的动作、踩过的坑、收到的反馈扔进文档

第二步：分分堆
- 攒了 10-20 条后，把这些碎片按「启动/执行/收尾」或按场景分类

第三步：排排序
- 从每一堆里抽出最高频、最能决定质量的那 3-5 条

第四步：长期迭代
- 每次练习后，根据反馈改一条
```

**关键心态**：自建 1.0 不需要完美。只要它能指导下一次动作，就已经是套路。

---

### 路六：严格执行 — 套路有了，不打折扣

这是你目前最需要补的一条。你已经把路一走通了，卡在路六。

**设计模板（执行保护机制）**：

```
1. 缩小执行单元：不要「整个套路全执行」，只锁定一个最小动作
   - 比如：不要求「六条底线全守」，只要求「这次一定分点」

2. 设置触发信号：在动作开始前，放一个绕不开的提醒
   - 比如：打开笔记第一行必须写「> 挑战：XXX」

3. 降低启动摩擦：让你的套路物理上更容易被看见
   - 比如：把「现场 3 条」贴在 Obsidian 快捷入口，一打开就能看到
```

## 回到你身上

你现在已经出了清单体笔记，未来如果要给「AI 培训讲课」「提示词设计」「学员辅导」这些能力设计固定套路，不需要每次都从零摸索。

**标准起步动作**：

```
问自己三句话 → 
这个领域有现成模型吗？有，就用（路二）。
没有，我现在的水平适合多粗的套路？（路三）
这个能力和我已经有的哪个套路是同一底层线？（路四）
```

然后挑一条路动手，先建一个极粗的 1.0，跑 5 次，再迭代。

---

好，这一轮我们把固定套路的设计方法论完整讲完了。回到收束——

1. **笃定感**：现在几分？
2. **现实实操**：仍然几分？
3. **实操提升信心**：有信心从几分推到几分？
