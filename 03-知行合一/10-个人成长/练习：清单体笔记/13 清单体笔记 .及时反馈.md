# 及时反馈 · 完整设计

---

## 一、先记住核心定义

```
反馈 ≠ 别人评价你。
反馈 = 尽快看见自己和真实套路/最佳实践之间的差距，
       并把它翻译成下一篇具体练什么。
```

没有反馈，你可能重复 10 次都在固化同一个错误。有反馈，第 2 次就能修正，第 5 次明显进步。**反馈不是附加项，是练习闭环的最后一环。**

---

## 二、清单体笔记 · 反馈机制（直接塞进收尾）

### 动作一：最佳实践对标（练前 + 练后）

| 时机 | 动作 | 耗时 |
|---|---|---|
| 记前 | 打开池子扫 1 分钟，只找 1 个差距 | 1 分钟 |
| 记后 | 再比一次，那个差距补上了吗？ | 30 秒 |

### 动作二：打颜色（暴露舒适区）

记完后立刻标：

| 颜色 | 含义 | 触发条件 |
|---|---|---|
| 🔴 舒适 | 纯惯性，没任何挑战 | 没对标、没追问、没挑战行 |
| 🟡 边缘 | 碰了一点边界，但不深 | 写了挑战行但执行打折扣 |
| 🟢 非舒适 | 待在能力边界，有突破感 | 追到了第三层、画了高质量表 |

### 动作三：复盘三问 + 推导链（绑定收尾）

每次记完后，直接在笔记底部打这三行：

```
> 这篇比上篇哪里好：___
> 哪里还不行：___
> 下一篇练什么：___
🔴/🟡/🟢
```

如果卡在「下一篇练什么」，走这条推导链：

```
1. 对标差距 → 扫一眼最佳实践，我这篇和它差在哪？
               ↓ 追问不够深 → 下一篇练「全程追问层」
               ↓ 没画表 → 下一篇练「该画表画表」

2. 颜色标记 → 🔴 → 必须加挑战
               🟡 → 把打折扣的地方做满

3. 收尾自查 → 课后 5 个动作哪个没做？
               ↓ 没写结论 → 下一篇练写一句真结论
               ↓ 没脱水 → 下一篇练脱水

4. 复盘三问里「哪里还不行」→ 直接变成下一篇挑战
```

推导链走完，`> 挑战：XXX` 自然就出来了。不需要灵感。

## 三、通用版 · 任何能力都能用的反馈设计

清单体笔记只是一个例子。当你给其他能力设计反馈时，不需要每次都从零想，八条路里每次挑最贴身的 1-2 条。

### 八条反馈来源

| 序号 | 来源 | 一句话 | 适用于 |
|---|---|---|---|
| 1 | **自我反馈** | 做完后对照套路自查 | 有固定套路/检查清单时 |
| 2 | **事实反馈** | 用数据、录像、记录修正感觉 | 自我判断容易主观时 |
| 3 | **专家反馈** | 找高手在关键节点看一眼 | 技能专业门槛高时 |
| 4 | **主动索取** | 不问「我做得怎样」，问「这一步和最佳差在哪」 | 有专家但很忙时 |
| 5 | **版本对比** | 把前后版本放在一起看差异 | 产出型工作（文档/代码/方案/提示词） |
| 6 | **同伴反馈** | 多人做同类练习，交叉看 | 有同学/同事/社群时 |
| 7 | **最佳实践池子** | 建标杆库，每次扔进去比 | 有高水平案例时（最通用的入口） |
| 8 | **最佳实践建模** | 把标杆拆成 3-5 个评分维度 | 已有很多标杆，需要系统对比时 |

### 通用启动流程

给任何能力设计反馈时，只问三句话：

```
1. 我有没有现成的对标案例？
   → 有 → 路 7（建池子，每次比）
   → 没有 → 路 1（先对照套路自查）

2. 做完后，有没有客观证据能修正我的感觉？
   → 有数据/录像/版本记录 → 路 2（事实反馈）
   → 没有 → 路 5（建版本对比，每次留 Before）

3. 身边有没有能问的人？
   → 有专家但很忙 → 路 4（主动索取具体差距）
   → 有同伴一起练 → 路 6（交叉评估）
   → 都没有 → 路 7 路 8（自己建对标池子）
```

## 四、回到你身上：即刻可做的行动

把这三样东西直接绑进你的清单体笔记收尾区，下次记完就做：

```
> 对标差距：[扫池子，我差在___]
> 颜色：🔴/🟡/🟢
> 比上篇哪里好：[___]
> 哪里还不行：[___]
> → 下一篇练什么：[推导链走完，填空]
```

不填完不关文件。哪怕每行只写半句话，习惯先建起来。

---

回到收束——

1. **笃定感**：几分？
2. **现实实操**：仍然几分？
3. **实操提升信心**：有信心从几分推到几分？
