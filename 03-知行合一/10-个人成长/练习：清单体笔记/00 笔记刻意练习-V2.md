# 清单体笔记 · 刻意练习文档

> 核心判断：清单体笔记不是"把东西记下来"，而是**把复杂信息变清楚、把思考外化、把判断质量拉高**的基本功。
> 它轻量、高频、独立可完成，而且和你的思考、建模、决策、AI 协作全部连着。
> 练好了，不只是笔记好看——是思考段位、建模能力、协作质量整体被抬上去。

## 一、长期目标

📍 **当前段位**：L2–L3 之间（清单体格式已成习惯，高阶动作在做，但底盘还没钉稳）
📍 **目标段位**：L6 萃取（保四争六）
📍 **人生红点**：用 AI 改变中职教育——笔记是你所有野心的基础设施
📍 **一年目标**：10 篇满意的建模笔记 + 年练习次数 300+

> 段位对照：L1 不记 → L2 备忘 → L3 协作 → L4 内化 → L5 思考 → L6 萃取

## 二、固定套路（通用记法）

> 但凡重复，必有套路。这套记法适用于会议、学习、思考、建模、灵感闪现、复杂决策——所有场景。

### 2.1 启动三步（记前 30 秒 · 按场景分流）

| 场景 | 启动动作 |
|---|---|
| **记录型**（听课/开会/学习） | 定主题 → 画骨架（3–5 个关键词或大类） → 定使用者 |
| **思考型**（灵感闪现/假设推演/复杂决策） | **先抛一个问题 → 给一个临时判断 → 定使用者** |
| **萃取型**（访谈/现场建模/专家对话） | **先套已知模型 → 锁定要萃取的核心判断 → 定使用者** |

> 判断口诀：信息进来用记录型，脑子里有东西要榨用思考型，对方有东西要当场提炼用萃取型。

### 2.2 填充原则（记中持续做）

- **一行一义**：每行只讲一件事，独立、可移动
- **脱水不逐字**：记关键判断和结论，不记完整表达和语气词
- **2–3 层**：层级不超过 3 层，同层同颗粒度
- **有序 vs 无序**：有先后用 `1.`，并列用 `-`——问自己"换顺序还成立吗？"
- **关键词标题**：每行用"关键词："开头，短、准、齐、可扫读
- **该画表画表**：对比信息、评分规则、分级标准——表格比列表更高效
- **追问层（L5 动作）**：在关键事实/观点下面，至少跟一条自己的判断或一个问题
  - 示例：`- 学生不会指针的本质：不是语法没记住，是内存模型没建立 → 追问：讲指针之前要不要先讲内存？顺序反了会怎样？`
- **模型标记（L6 动作）**：匹配到已知模型的地方，行尾标记模型名并补一句"为什么匹配"
  - 示例：`- 学生刷题不动脑 → 动力阻力模型：阻力大（挫败感），动力弱（没即时反馈）`

### 2.3 收尾三步（记后 3 分钟）

1. 写一句结论：把整篇笔记压成一句话（可置顶，可置底）
2. 扫 checklist：层级对不对？该画表画了没？关键词标题全不全？缺不缺结论？追问层和模型标记做了没？
3. 打颜色自评 + 定下一个动作：
   - 🔴 舒适区 / 🟡 边缘区 / 🟢 非舒适区
   - **下一篇优先练哪个动作？**（如"下次补追问层""下次试萃取型启动"）

### 2.4 好坏 checklist（每次收尾逐条过）

- [ ] 主题清楚？不开篇就懵
- [ ] 先骨架再填充？还是想到哪写到哪
- [ ] 层级 2–3 层？同一层级有没有两组编号打架
- [ ] 该画表画表？对比信息没用列表硬堆
- [ ] 有关键词标题？每块能扫读定位
- [ ] 有序/无序用对了？换顺序还成立吗
- [ ] 有结论收口？未来回看不需重推
- [ ] 隔一周能看懂？最小备忘需求是否满足
- [ ] **追问层**：关键事实下面有没有自己的判断或问题？（L5）
- [ ] **模型标记**：匹配到已知模型的地方，标记了没有？（L6）
- [ ] **可复用资产**：这篇笔记里有没有能拆出来单独用的东西？（一句讲法、一个 prompt、一个练习、一个判断）

### 2.5 常见错误对照

| 错误 | 表现 | 正确做法 |
|---|---|---|
| 层级断裂 | 同一层出现两组 1. 2. 3. 并列 | 拆成 4a / 4b 或独立成大块 |
| 编号打架 | `-` 前面手动加 ①②③ | 纯并列用 `-`，有顺序用 `1.`，不混 |
| 没结论 | 全篇记完，不知道定了什么 | 顶部或底部写一句结论 |
| 格式具体化不够 | 只写"用表格"，没写清楚什么结构 | 写到能直接执行："Markdown 三列表格，人机共读" |
| 问句当结论 | "能不能沉淀数据？" | 改成陈述句：每次使用后沉淀数据，闭环增强 |
| 记完没追问 | 全篇只有事实，没有自己的判断 | 至少找一处关键事实，补一个追问或判断 |

### 2.6 套路迭代规则

- 每记完 5 篇笔记，回头翻这篇文档
- 发现一个好动作 → 加一条
- 踩了一个坑 → 补进"常见错误对照"
- 发现一条规则可以更精确 → 直接改

> 工作方式：记笔记 → 对照套路文档 → 发现新规则 → 反向更新文档

## 三、非舒适区（每次比上次好一点）

> 成长都在"暂时不会"的那部分。不是痛苦区，是那种有点不舒服、得用脑才能完成的状态。

### 3.1 每次加一个挑战（记前从下表挑 1 个）

| 挑战 | 什么场景下用 |
|---|---|
| 全部加关键词标题 | 笔记层级多、扫读困难时 |
| 记完花 10 分钟整理故事线 | 信息量大、原始顺序混乱时 |
| 画一张表 | 有对比信息或评分规则时 |
| 写一句精准结论 | 每次——这个是默认动作 |
| 顶层分块用 `##` 标题 | 笔记超过 3 个主题时 |
| 把一段口语压成 3 行 | 有逐字稿倾向时 |
| 写完和最佳实践池子对比 | 不确定自己记得好不好时 |
| 记完当场写 3 个问题 | 想倒逼深度思考时 |
| 全程追问层 | 想逼自己不只记事实、也要记判断时 |
| 全程模型标记 | 想练建模肌肉记忆时 |

### 3.2 脑力管理

- 25 分钟一个冲刺，头晕是正常信号——站起来走两分钟再开下一轮
- 笔记是脑力外挂：思路写下来，脑子被释放做更高级的判断
- 永远保持拉满——不因为时间到了就"差不多记完算了"

### 3.3 自评颜色（每篇标注）

- 🔴 舒适区：和上次差不多，没挑战
- 🟡 边缘区：犹豫了一两次，有一两处新尝试
- 🟢 非舒适区：多次需要停下来想，记完觉得比上篇强

> ⚠️ 一周下来全是 🔴 → 立刻调整，下篇必须加一个挑战

### 3.4 对标最佳实践

- 记完和最佳实践池子里最好的笔记比
- 找 3 条差距（层级？关键词？结论？表格？追问？模型标记？）
- 差距就是下一篇的挑战

## 四、及时反馈（知道差在哪）

> 反馈不是打分，是找差距——做对了下次接着做，做错了下次换方式，做忘了下次记得做，不够好下次再跳一跳。

### 4.1 反馈来源（按优先级）

| 优先级 | 方式 | 操作 |
|---|---|---|
| 🥇 | **最佳实践池子** | 建一个文件夹放 5–10 篇好笔记，每次记完扔进去对比，找 3 条差距 |
| 🥈 | **版本对比** | 同一篇内容记两版，放一起对照 Before/After |
| 🥉 | **教练诊断** | 把笔记发给清单体笔记教练，用八维审美标准诊断 |
| 兜底 | **当场复盘** | 记完花 3 分钟问三个问题——哪里比上篇好？哪里还不行？下一篇练什么？ |

### 4.2 当场复盘三问（每次记完必做）

1. 这篇哪里比上篇好？
2. 哪里还不行？
3. 下一篇重点练哪个动作？

### 4.3 八维自评表（进阶，选做）

| 维度 | 分值 | 自评 |
|---|---|---|
| 使用者最小需求（能回忆/追溯/串起来） | 10 | |
| 信息取舍与脱水（留关键、删噪音） | 15 | |
| 精华压缩与化简（口语→可复用信息点） | 10 | |
| 逻辑分点与不换行（一行一义） | 15 | |
| 层级控制与信息密度（2–3 层、宽而充实） | 15 | |
| 分点标题与格式对齐（关键词：开头） | 10 | |
| 视觉标注与扫读（加粗/颜色服务扫读） | 10 | |
| 故事线与逻辑重构（不照搬原始顺序） | 15 | |
| **总分** | **100** | |

## 五、大量重复（把笔记变高频动作）

> 重复次数 ≈ 进步速度。目标不是等一个"完整场景"才记，而是把所有碎片都变成练习机会。

### 5.1 场景开发

| 场景 | 示例 | 时长 |
|---|---|---|
| 听课/看书 | 一堂课、一篇长文、一本教材 | 5–30 分钟 |
| 灵感闪现 | 一个教学判断、一个产品想法、一个育儿观察 | 3–5 行，5 分钟 |
| 会议/讨论 | 教研组讨论、内部脑暴 | 全程记 |
| 思考/建模 | 系统设计、方案推演、复杂决策 | 15–30 分钟 |
| 复盘/总结 | 一天结束后的关键收获、一次项目后的经验 | 10 分钟 |

### 5.2 上量策略

| 策略 | 操作 | 目标 |
|---|---|---|
| 多记小笔记 | 灵感、判断、观察全拆成 5 分钟小笔记 | 年次数从 70 翻到 300+ |
| 主动找机会 | 不是自己负责的会也记，旁听课也记 | 不等机会，制造机会 |
| 叠加练习 | 听课时边听边记边整理逻辑（同一段时间做两层） | 练内容 + 练结构 |
| 数量目标 | 第一个月冲到每周 5–7 篇 | 半年后笔记变成默认思考方式 |

## 六、行动计划

### 🚀 24 小时内

- 把这篇文档放进 Obsidian/飞书顶层
- 建「最佳实践池子」文件夹，扔 5–10 篇好笔记进去
- 下一篇笔记按"启动三步（按场景选） → 填充原则 → 收尾三步"完整走一遍

### 📆 一个月内

- 每次记笔记照这篇文档执行，不跳步
- 每次收尾打颜色自评 + 当场复盘三问
- 每次记完对标最佳实践池子，找 3 条差距
- 每 5 篇回头翻这篇文档，加一条或改一条
- 多记小笔记：灵感、观察全拆成 5 分钟笔记

### 🎯 一年内

- 10 篇满意建模笔记
- 年练习次数 300+
- 这篇文档至少迭代 20 次
- 最佳实践池子从 5 篇扩展到 20 篇

> 节奏逻辑：24 小时搭框架 → 一个月跑顺新节奏 → 一年正反馈飞轮转起来

## 七、一句话收住

> 清单体笔记不是文档格式，是思考方式。
> 固定套路让你每次有章法，非舒适区让你每次在长进，
> 及时反馈让你知道差在哪，大量重复让动作变肌肉记忆。
> 四个要素一起跑，同样的时间投入，拿 3 到 10 倍的进步速度。
