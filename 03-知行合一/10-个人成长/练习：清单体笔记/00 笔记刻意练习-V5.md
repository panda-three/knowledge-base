## 长期目标

清单体笔记不是目的，是手段。真正的追求是：

```
我要成为一个能把任何信息、课程、对话——
在听完之后 3 分钟内压成结构化判断的人。
这不是"记笔记"，这是 AI 教育者的底层能力：
萃取 → 分层 → 追问 → 表达。
```

这个能力和你的 AI 教育长期底盘直接相连。以后你讲课、写提示词、做分析、带学员——这些场景全都在练同一条底层线。清单体笔记是这条线的第一个正式训练场。

## 固定套路
|场景|套路颗粒度|只记什么|
|---|---|---|
|**现场速记（开会/听课）**|极简3条|分点、关键词开头、一行一义。其他不管，先记下来。|
|**课后整理（收尾+迭代）**|完整6条+收尾三步|脱水、分层、画表、结论、打颜色、写下一篇练什|

| 动作   | 一句话              | 什么时候做 |
| ---- | ---------------- | ----- |
| 脱水   | 挤掉水分，只记判断和结论     | 课后整理  |
| 分层   | 同层同颗粒，2-3 层      | 课后整理  |
| 画表   | 有对比就画，别用文字堆      | 课后整理  |
| 结论   | 写一句记之前没想到的判断     | 收尾    |
| 打颜色  | 红/黄/绿暴露舒适区       | 收尾    |
| 分点   | 有序用 `1.`，并列用 `-` | 当场    |
| 关键词  | 关键词开头，短准齐        | 当场    |
| 一行一义 | 一行一义，独立可移动       | 当场    |

## 非舒适区（每次只挑 1 个）

1. 严格按照套路
2. 每次打开笔记，先花1分钟看最佳实践池子里最好的一篇，把找到的差距写进挑战行，然后才开始记。

> **记前 10 秒写在笔记第一行**（如 `> 挑战：全程追问层`）。没做到全程也没关系——在一处做到了就算进了非舒适区。


## 及时反馈

- 对标差距：[扫池子，我差在___]
- 颜色：🔴/🟡/🟢
- 比上篇哪里好：[___]
- 哪里还不行：[___]
- → 下一篇练什么：[推导链走完，填空]

## 大量重复

1. 一次有效练习** = 启动 + 填充 + 收尾打颜色 + 写下一篇练什么。缺任一条，只算半次。
