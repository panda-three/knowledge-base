# 清单体笔记 · 刻意练习文档

## 本文档用法

> ⚠️ 不是每次打开全读一遍，更不是每次全做到。
> **每次只盯三个地方**：2.1 启动 → 2.2 填充（前六条）→ 2.3 收尾。然后从 3.1 挑战表里**只挑一个**。
> 其他全当不存在。套路文档是工具箱，不是刑具。

## 一、长期目标

- **当前段位**：L2–L3 之间（清单体格式已成习惯，高阶动作在做，底盘还没钉稳）
- **目标段位**：L6 萃取（保四争六）
- **人生红点**：用 AI 改变中职教育——笔记是所有野心的基础设施
- **一年目标**：10 篇满意的建模笔记 + 年练习次数 300+

| 段位 | 关键词 | 一句话 |
|---|---|---|
| L1 | 不记 | 主要记脑子里 |
| L2 | 备忘 | 能回忆、不丢信息 |
| L3 | 协作 | 逻辑清晰、方便扫读 |
| L4 | 内化 | 重新整理、有故事线 |
| L5 | 思考 | 笔记本身就是思考结构 |
| L6 | 萃取 | 现场建模、一次到位 |

## 二、固定套路（通用记法）

> 定位：这套记法适用于会议、学习、思考、建模、灵感闪现、复杂决策——所有场景。但凡重复，必有套路。

### 2.1 启动三步（记前 30 秒，按场景分流）

| 场景 | 启动动作 | 判断口诀 |
|---|---|---|
| **记录型**（听课/开会/学习） | 定主题 → 画骨架（3–5 个关键词） → 定使用者 | 信息进来，要接住 |
| **思考型**（灵感闪现/假设推演/复杂决策） | 先抛一个问题 → 给一个临时判断 → 定使用者 | 脑子里有东西要榨出来 |
| **萃取型**（访谈/现场建模/专家对话） | 先套已知模型 → 锁定要萃取的核心判断 → 定使用者 | 对方有东西要当场提炼 |

### 2.2 填充原则（记中持续做）

**底盘动作（每次必做，六条）**：

- **一行一义**：每行只讲一件事，独立、可移动
- **脱水不逐字**：记关键判断和结论，不记完整表达和语气词
- **2–3 层**：层级不超过 3 层，同层同颗粒度
- **有序 vs 无序**：有先后用 `1.`，并列用 `-`——问自己"换顺序还成立吗？"
- **关键词标题**：每行用"关键词："开头，短、准、齐、可扫读
- **该画表画表**：对比信息、评分规则、分级标准——表格优于列表

**进阶动作（每次挑 1 个）**：

- **追问层（L5）**：关键事实/观点下面，至少跟一条自己的判断或一个问题
- **模型标记（L6）**：匹配到已知模型的地方，行尾标记模型名 + 一句为什么匹配

### 2.3 收尾三步（记后 3 分钟）

1. **写一句结论**：把整篇笔记压成一句话（置顶或置底）
2. **扫 checklist**：层级、画表、关键词标题、结论、追问层、模型标记——缺什么？
3. **打颜色 + 定动作**：🔴舒适区 / 🟡边缘区 / 🟢非舒适区，**下一篇优先练哪个动作？**

### 2.4 好坏 checklist（收尾逐条过）

- [ ] 主题清楚？不开篇就懵
- [ ] 先骨架再填充？
- [ ] 层级 2–3 层？同一层有没有两组编号打架
- [ ] 该画表画表？对比信息没用列表硬堆
- [ ] 有关键词标题？每块能扫读定位
- [ ] 有序/无序用对了？换顺序还成立吗
- [ ] 有结论收口？未来回看不需重推
- [ ] 隔一周能看懂？最小备忘需求满足了吗
- [ ] **追问层（L5）**：关键事实下面有自己的判断或问题吗
- [ ] **模型标记（L6）**：匹配到已知模型的地方标记了吗
- [ ] **可复用资产**：能拆出来单独用的东西？（讲法/prompt/练习/判断）

### 2.5 常见错误

| 错误    | 表现                  | 正确做法                 |
| ----- | ------------------- | -------------------- |
| 层级断裂  | 同一层出现两组 1. 2. 3. 并列 | 拆成 4a / 4b 或独立大块     |
| 编号打架  | `-` 前手动加 ①②③        | 并列用 `-`，有顺序用 `1.`，不混 |
| 没结论   | 全篇记完，不知道定了什么        | 顶部或底部写一句结论           |
| 问句当结论 | "能不能沉淀数据？"          | 改成陈述句：每次使用后沉淀数据，闭环增强 |
| 记完没追问 | 全篇只有事实，没自己的判断       | 至少找一处关键事实，补一个追问或判断   |

### 2.6 套路迭代规则

- **触发**：每记完 5 篇笔记，回头翻这篇文档
- **加**：发现一个好动作 → 加一条
- **补**：踩了一个坑 → 补进"常见错误"
- **改**：发现一条规则可以更精确 → 直接改

> 工作方式：记笔记 → 对照套路文档 → 发现新规则 → 反向更新文档

## 三、非舒适区（每次比上次好一点）

> 定位：成长都在"暂时不会"的那部分。不是痛苦区，是有点不舒服、得用脑才能完成的状态。

### 3.1 每次加一个挑战（记前挑 1 个，写在笔记第一行）

| 挑战 | 适用场景 |
|---|---|
| 全部加关键词标题 | 层级多、扫读困难 |
| 记完花 10 分钟整理故事线 | 信息量大、原始顺序混乱 |
| 画一张表 | 有对比信息或评分规则 |
| 写一句精准结论 | 每次——默认动作 |
| 顶层分块用 `##` 标题 | 笔记超过 3 个主题 |
| 把一段口语压成 3 行 | 有逐字稿倾向 |
| 写完和最佳实践池子对比 | 不确定自己记得好不好 |
| 记完当场写 3 个问题 | 想倒逼深度思考 |
| 全程追问层 | 想逼自己不只记事实、也要记判断 |
| 全程模型标记 | 想练建模肌肉记忆 |

> **执行技巧**：
> 1. 记前 10 秒，把挑战写在笔记第一行（如 `> 挑战：全程追问层`），写下那一刻默认模式就被改写了
> 2. 现阶段只暴露 3 个挑战，其余折叠——选择越少，决策越快
> 3. 允许 60 分——选了"全程追问层"只在一处做到也算进了非舒适区。非舒适区不是完美区

**追问层示例**：
```
- C 语言期中考试平均分 52
  → 追问：是知识点没记住，还是题没见过？两个补法完全不一样
```

**模型标记示例**：
```
- 学生刷题不动脑 → 动力阻力模型：阻力大（挫败感），动力弱（没即时反馈）
```

### 3.2 脑力管理

- **冲刺节奏**：25 分钟一个冲刺，头晕是正常信号——站两分钟再开下一轮
- **笔记 = 外挂**：思路写下来，脑子被释放做更高级的判断
- **永远拉满**：不因为时间到了就"差不多记完算了"

### 3.3 自评颜色（每篇标注）

- 🔴 **舒适区**：和上次差不多，没挑战
- 🟡 **边缘区**：犹豫了一两次，有一两处新尝试
- 🟢 **非舒适区**：多次需要停下来想，记完觉得比上篇强

> ⚠️ 一周全是 🔴 → 立刻调整，下篇必须加挑战

### 3.4 对标最佳实践

- 记完和最佳实践池子里最好的笔记比
- 找 3 条差距（层级？关键词？结论？表格？追问？模型标记？）
- 差距 → 3.1 挑战表 → 下一篇执行

## 四、及时反馈（知道差在哪）

> 定位：反馈不是打分，是找差距。做对了接着做，做错了换方式，做忘了记得做，不够好再跳一跳。

### 4.1 反馈来源（按优先级）

| 优先级 | 方式         | 操作                                   |
| --- | ---------- | ------------------------------------ |
| 🥇  | **最佳实践池子** | 建文件夹放 5–10 篇好笔记，每次记完对比找 3 条差距        |
| 🥈  | **版本对比**   | 同一内容记两版，对照 Before/After              |
| 🥈  | **事实反馈**   | 两周后重读看能不能扫懂；给 AI 用后看有没有理解偏差；判断事后验证对吗 |
| 🥉  | **教练诊断**   | 发给清单体笔记教练，用八维审美标准诊断                  |
| 兜底  | **当场复盘**   | 记完花 3 分钟走 4.2 复盘三问                   |
|     |            |                                      |

> ⚠️ **收口规则**：任何反馈产出的差距，必须落到 3.1 挑战表里——差距 → 挑战 → 下一篇执行。否则反馈白做了。

### 4.2 当场复盘三问（每次记完必做）

1. 这篇哪里比上篇好？
2. 哪里还不行？
3. 下一篇重点练哪个动作？

### 4.3 八维自评表（进阶，选做）

| 维度 | 分值 | 自评 |
|---|---|---|
| 使用者最小需求（能回忆/追溯/串起来） | 10 | |
| 信息取舍与脱水（留关键、删噪音） | 15 | |
| 精华压缩与化简（口语→可复用信息点） | 10 | |
| 逻辑分点与不换行（一行一义） | 15 | |
| 层级控制与信息密度（2–3 层、宽而充实） | 15 | |
| 分点标题与格式对齐（关键词：开头） | 10 | |
| 视觉标注与扫读（加粗/颜色服务扫读） | 10 | |
| 故事线与逻辑重构（不照搬原始顺序） | 15 | |
| **总分** | **100** | |

## 五、大量重复（把笔记变高频动作）

> 定位：重复次数 ≈ 进步速度。不等"完整场景"才记，把所有碎片都变成练习机会。

- **一次有效练习** = 启动三步 + 填充原则 + 收尾打了颜色自评 + 写了下一篇练什么。缺任一条，只算半次

### 5.1 场景开发

| 场景 | 示例 | 时长 |
|---|---|---|
| 听课/看书 | 一堂课、一篇长文、一本教材 | 5–30 分钟 |
| 灵感闪现 | 一个教学判断、一个产品想法、一个育儿观察 | 3–5 行，5 分钟 |
| 会议/讨论 | 教研组讨论、内部脑暴 | 全程记 |
| 思考/建模 | 系统设计、方案推演、复杂决策 | 15–30 分钟 |
| 复盘/总结 | 一天结束后的关键收获、一次项目后的经验 | 10 分钟 |
| **AI 对话沉淀** | 和 AI 协作完，花 3 分钟把关键判断、有效 prompt、下一步压成小笔记 | 3–5 分钟 |
| **课堂即时观察** | 上课时捕捉的学生反应、讲法效果、卡点线索——课后 5 分钟倒出来 | 5 分钟 |

### 5.2 上量策略

| 策略    | 操作                          | 目标              |
| ----- | --------------------------- | --------------- |
| 多记小笔记 | 灵感、判断、观察全拆成 5 分钟小笔记         | 年次数从 70 翻到 300+ |
| 主动找机会 | 不是自己负责的会也记，旁听课也记            | 不等机会，制造机会       |
| 叠加练习  | 边听边记边整理逻辑；上课观察学生，课后 5 分钟倒笔记 | 同一段时间做两层        |
| 数量目标  | 第一个月冲到每周 5–7 篇              | 半年后笔记变默认思考方式    |

> ⚠️ **重复不是孤立堆次数**：每次重复 = 按场景选启动（套路） + 从 3.1 挑一个挑战（非舒适区） + 收尾走 4.2 复盘三问（反馈）。三个动作全走完，才算一次有效练习。

## 六、行动计划

### 🚀 24 小时内

- 把这篇文档放进 Obsidian 顶层
- 建「最佳实践池子」文件夹，扔 5–10 篇好笔记进去
- 下一篇笔记按"启动三步 → 填充原则 → 收尾三步"完整走一遍

### 📆 一个月内

- 每次记笔记照本文档执行，不跳步
- 每次收尾打颜色自评 + 复盘三问
- 每次记完对标最佳实践池子，找 3 条差距
- 每 5 篇回头翻本文档，加一条或改一条
- 多记小笔记：灵感、观察、AI 对话沉淀、课堂即时观察全拆成 5 分钟笔记

### 🎯 一年内

- 10 篇满意建模笔记
- 年练习次数 300+
- 本文档至少迭代 20 次
- 最佳实践池子从 5 篇扩展到 20 篇

> 节奏：24 小时搭框架 → 一个月跑顺新节奏 → 一年正反馈飞轮转起来

## 七、一句话收住

> 清单体笔记不是文档格式，是思考方式。
> 固定套路让你每次有章法，非舒适区让你每次在长进，
> 及时反馈让你知道差在哪，大量重复让动作变肌肉记忆。
> 四个要素一起跑，同样的时间投入，拿 3 到 10 倍的进步速度。
```
