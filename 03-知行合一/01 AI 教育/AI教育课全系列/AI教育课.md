# 课程：AI教育课项目定位

**一句话结论：《AI教育课》是把AI基础与思维融入基础教学的原创项目——面向青少年，教孩子从"会用AI"到"会驾驭AI"，结课可出参赛作品。**

## 一、项目基本盘
| 项目 | 内容 |
|---|---|
| 类型 | 原创AI教育培训项目 |
| 核心创意 | 将AI基础/思维融入基础教学 |
| 目标对象 | 15-18岁青少年（招生面向6-10岁孩子家长） |
| 课程特色 | 图片/视频/思维/产品训练四结合 |
| 整体气质 | 朴素、真实、有趣、励志 |
| 视频 | 30秒品牌创意宣传片 |
| 口号 | 这一问，问出AI新世界 |
| 最终交付 | 品牌招生策划、海报、宣传片、课程介绍PPT |

## 二、核心表达与视觉方向
- 沟通对象：先打动家长（焦虑→放心），再吸引学生（好奇→向往）
- 叙事逻辑：你以为AI是工具→其实是思维方式→学会提问就是掌握未来
- 宣传语：**AI不会淘汰人，但会用AI的人会**
- 主色调：暖橙/暖黄为底，科技蓝点缀，避免冷硬
- 主视觉：青少年真实使用AI创作的场景（专注/好奇/有成就感）
- 排版：干净留白、信息层级清晰、拒绝堆砌
- 禁忌：赛博朋克炫技风、低幼卡通风、纯代码电路板元素
