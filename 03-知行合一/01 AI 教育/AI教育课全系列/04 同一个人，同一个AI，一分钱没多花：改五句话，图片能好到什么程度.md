# 课程：改五句话图片·04

**一句话结论：同一个人同一个AI，不换工具不加钱，一版只改一个变量，形象照从"不能用"五步做到能印名片。**

## 一、案例设定
- 主角：李姐，36岁县城家装设计师，自由接单
- 需求：能印名片/当朋友圈头图/发公众号的形象照
- 痛点：影楼拍一套约800元、等三天、改还要加钱
- 方法：不换软件不换钱，**一次只改一个变量**，保留有效改动再进下一版

## 二、五版迭代（每版只改一件事）
| 版本 | 只加什么 | 关键提示词 | 提升 |
|---|---|---|---|
| V1 随口说 | 无 | "36岁女性，在家里，要好看一点" | 顶光生硬、人物僵硬 |
| V2 身份场景穿着 | 身份+场景+身份道具 | 家装设计师/工作室/色卡图纸绿植 | 从路人变专业人士 |
| V3 加光 | 只改光线 | 左45度柔光+反光板补暗部+背景比脸暗 | 最省力、提升最明显 |
| V4 加镜头构图 | 镜头景深裁切 | 85mm f/1.8+浅景深+眼睛在1/3线 | 跨过手机随手拍分界线 |
| V5 加用途留白调色 | 用途+留白+调色 | 名片用、人物靠左右侧留白、暖中性胶片颗粒 | 可直接用于名片/主页 |

## 三、拧成一条公式（五要素）
1. **主体是谁**：36岁家装设计师/我的椴树蜜/我家卤鸭脖
2. **在哪、有什么道具**：工作室工作台有色卡图纸
3. **光怎么打**：左45度柔光+反光板补暗部+背景比主体暗
4. **什么镜头怎么裁**：85mm f/1.8、背景虚化、胸口以上、眼睛在上1/3
5. **拿去做什么**：名片用，人物靠左，右侧留白放文字

## 四、最容易踩的五个坑
| 坑 | 改法 |
|---|---|
| 只说"好看/高级/有质感" | 换成柔和侧光/背景虚化/暖中性色等具体做法 |
| 一次塞全部、不满意就整段重写 | 一次只改一处，否则不知哪句有效 |
| 生成后直接用不查细节 | 放大查手指数量/画面文字/耳朵眼镜腿 |
| 把虚构AI人脸当自己 | 个人形象照用本人真照片修图换背景 |
| 不存提示词，每次从零 | 满意提示词存下来，下次只换主体/场景/用途 |

## 五、15分钟现场练习
1. 备忘录写下"主体"（你是谁/卖什么）
2. 写三样"一看就懂"的身份道具
3. 加光线三句（左45度柔光/反光板/背景暗）
4. 加镜头（85mm f/1.8、浅景深、竖幅3:4）
5. 写用途+留白侧
6. 五句拼起来发给AI，不满意一次只改一句

## 六、金句
> 「一张图好不好看，七成看光。」
> 「AI不会让不会表达的人自动变厉害，它只会让会表达的人变快。」
> 「先定用途，再定构图；要放文字的地方，一定提前告诉AI"这里留空"。」

## 七、我的批注（双轨）
- 我的：五要素公式+"一次只改一个变量"可直接做成中职生图课的实操脚本。
- 注意：课件配图均AI生成，仅教学演示；真人形象照须用本人照片修图换背景。
