# 教学领域·全量最佳实践清单体笔记

---

## 一、核心哲学层

### 教育本质定义
- **教育 = 问题 + 解法 + 教学**：三者缺一不可。只给解法不打痛点 = 学生无动机；只打痛点不给解法 = 制造焦虑；有痛点有解法无教学 = 无法吸收
- **课程唯一目的**：改变。不是传递信息，不是展示能力，是让学生从「不会」到「会」

### 成年人改变四前提（不可跳步）
1. **先理解问题差距，再学习解法**：没意识到自己烂，不会认真学
2. **先打碎认知，再重构认知**：旧框架不拆，新知识装不进去
3. **先改变脑子，再改变手**：认知不到位的动手 = 机械模仿
4. **先培养渴望，再长期精进**：没渴望的练习 = 应付任务

### 三层笃定（不笃定不讲课）
- **问题笃定**：脑子里有 100 个用户痛到心里的样子，能复述至少 3 个具体故事
- **解法笃定**：横向对比过所有解法，纵向挖到最底层，能说清为什么「别人的解法不够、我的解法是必修」
- **教学笃定**：满脑子都是用户喊「真香」的画面，每一个教学手段都从用户视角出发

> **硬约束**：宁可不交付，也不交付仅及格的产品。一堂曾为解法不笃定 delay 课程，赔付 1000+ 张选课券（价值 20 万+）

## 二、课程骨架层

### 抽象教练五段范式（单节课底层改变逻辑）

| 段落       | 功能             | 一句话        | 检验标准               |
| -------- | -------------- | ---------- | ------------------ |
| **唤醒问题** | Before——制造认知缺口 | 「你也有这个困扰吗」 | 学生听完想打自己——「这不就是我吗」 |
| **建立审美** | After——见识天花板   | 「原来还可以这样」  | 学生有「之前白活了」的体感      |
| **思考模型** | 方法论——构建底层逻辑    | 「科学有逻辑」    | 学生能用自己的话复述模型       |
| **实操工具** | 工具——可带走即用      | 「拿走就能用」    | 小抄/画布/检查单，当堂用一次    |
| **作业任务** | 闭环——完成从 0 到 1  | 「第一次动手」    | 学生自己验证结论，不等别人告诉    |

### 七段结构（五段范式的课堂展开版）
```
① 为什么要学（打痛点）→ ② 预热思考题（造悬念）→ 
③ 提前划重点（给地图）→ ④ 正文·方法论（建模型）→ 
⑤ 正文·案例（推演对比）→ ⑥ 作业（最小可验证动作）→ 
⑦ Candy（长期钩子）
```

### 七段各段设计铁律
- **① 为什么学**：先访谈 3–5 人，挖认知盲区，再写开场。不讲价值，打痛点
- **② 预热思考题**：1–2 个问题，听完就想知道答案，但靠自己答不上来
- **③ 划重点**：3–4 句话，30 秒读完，读完知道能带走什么
- **④ 正文方法论**：提炼成 模型 + 段位 + 口诀，不是堆信息
- **⑤ 正文案例**：实操课用平行时空，理论课用案例推演（详见 §三）
- **⑥ 作业**：只追一个动作，必须承诺反馈。贪多 = 不做
- **⑦ Candy**：下节课悬念 + 课后持续价值，不可无

## 三、两种课型的差异化设计

### 课型对比总表

|            | 实操课（实时演示驱动）           | 理论课                     |
| ---------- | --------------------- | ----------------------- |
| **正文逻辑**   | 操作演示 → 平行时空并列对比       | 认知推演 → 案例纵深推演           |
| **案例手法**   | 三段平行时空：同一任务、三种段位、并列对比 | 三遍推演：同一案例、三层深度、逐层剥开     |
| **动力锚点**   | 实时操作震撼 + 听觉/视觉冲击      | 认知缺口 + 反直觉时刻 + 认知闭合     |
| **稿子形态**   | 双轨脚本：操作轨 + 讲解轨 + 停顿点  | 五层密度逐字稿                 |
| **PPT 角色** | 配角（15–20 页），屏幕主角是工具界面 | 主角（60–90 页），每 30–60 秒切页 |
| **致命风险**   | 翻车（AI 输出不可控）          | 枯燥 + 认知过载（走神 / 逻辑断裂）    |
| **审查方式**   | 静默演练（不张嘴走操作）          | 逻辑链测试 + 锚点间隔检查          |

### 实操课专有：双轨脚本设计

**核心认知**：实时演示时大脑同时处理操作 + 讲解。不提前分工 = 现场必乱。

**双轨对照表格式**：

| 时间  | 屏幕  | 操作（手） | 讲解（嘴） | 停顿  |
| --- | --- | ----- | ----- | --- |

**讲解轨三层密度**：

| 密度        | 场景             | 写法           |
| --------- | -------------- | ------------ |
| 半逐字（写死）   | 开场钩子、收口总结、关键结论 | 每字写死，上场不发挥   |
| 要点提纲（半写死） | 方法论讲解、套路沉淀     | 关键词 + 一句核心逻辑 |
| 即兴区（只标方向） | 互动回应、翻车处理      | 「这个节点要传达什么」  |

**三种停顿点（骨架级，不可省）**：
- **预告停顿**（操作前）：「我接下来改一个词，你猜输出怎么变？先想 3 秒」
- **复盘停顿**（操作后）：「刚才你注意到哪一步是关键转折？」
- **张弛停顿**（每 8–10 分钟）：完全停下操作，回到 PPT，认知喘息

**等待期利用**：AI 生成等待的 20–30 秒是黄金窗口——必须预埋知识点，不可空等或说无关话

**翻车三岔路预案**：每个关键演示节点提前标注——

| 结果  | 处理                    |
| --- | --------------------- |
| 理想  | 当场展示、拆解               |
| 偏离  | 现场纠错——纠错过程就是教学        |
| 翻车  | 切「翻车教学」模式——「这是一个经典问题」 |
|     |                       |

**翻车硬底线**：每个演示节点至少一份本地备用音频/截图。AI 挂了直接切

### 理论课专有：五层密度逐字稿

**为什么比实操课多两层**：没有操作轨兜底，过渡和逻辑链一旦断掉，学生直接掉线。

| 密度           | 场景                | 写法                |
| ------------ | ----------------- | ----------------- |
| **L5 逐句锁死**  | 开场钩子、收口、闭合句、反直觉时刻 | 每字写死，不改           |
| **L4 框架锁死**  | 认知台阶间过渡、案例引入      | 过渡句写死，展开写关键词      |
| **L3 逻辑链锁死** | 方法论核心推导           | 因果/递进/转折链写死，措辞可微调 |
| **L2 要点提纲**  | 案例展开、补充说明         | 3–5 个要点 + 一个闭合句   |
| **L1 即兴区**   | 互动回应、临场举例         | 只标注方向             |

**逐字稿三铁律**：
1. **一句只做一件事**：一句话同时解释概念、举例、总结 → 拆成三句
2. **推演逻辑比语言漂亮重要十倍**：两句话之间必须是因果/递进/转折之一。没有 = 废话，删。写完做逻辑链测试——连起来读每句开头，连不起来处 = 断裂点
3. **每认知台阶结束必有一句闭合句**：格式——「所以你只需要记住一件事：____」

**理论课三种动力锚点**：

| 锚点 | 频率 | 做法 |
|---|---|---|
| 认知缺口 | 每 3–5 分钟 | 「为什么」悬念，先问再答 |
| 反直觉时刻 | 每 8–10 分钟，45 分钟课 ≥ 3 个 | 「你以为 A，其实是 B」 |
| 认知闭合 | 每个话题结束 | 闭合句钉死结论 |

**枯燥预案硬约束**：任何两个锚点之间不超过 5 分钟。超过 = 那段内容大概率无效

### 对应四次审美飞跃

| 飞跃  | 之前           | 之后               | 判断句           |
| --- | ------------ | ---------------- | ------------- |
| 第一次 | 闭门造车，50–70 分 | 刻意花 30–70% 时间建审美 | 「很有信心，又持续不满意」 |

## 六、Y 模型：一堂全部课程的底层操作系统

```
1 个核心：因果认知（不断积累规律）
2 个基本点：理论 + 事实
3 大必备原则：知行合一 + 实事求是 + 解放思想
```

**两大核心价值**：

- **无限进步**：四种策略 ×N，认知无限逼近真理

**关键金句**：「一个人真正入门的标志，是形成了一个对于复杂事情的基本的、朴素的、框架性的认知。」

## 七、创造力体系

### SOUL 灵感闪现模型

| 步骤 | 含义 |
|---|---|
| **S**ituation | 识别场景——这是灵感闪现场景吗？ |
| **O**bject | 闪现目标——保 5 争 10 / 保 10 争 20 / 保 20 争 30 |
| **U**se Tools | 使用工具——对标、联想、具象场景、分类、逻辑链、AI 辅助（最后用） |
| **L**evel | 挖掘层级——水面 L1–L3（不依赖创意），水下 L4–L7（需心流沉浸） |

**7 层级 23 个关键动作**。音译记忆：SOUL =「搜」= 搜索前半生人生阅历。

### 灵感闪现四次自我修养跃迁
1. **场景识别**：能识别灵感闪现的工作场景
2. **拉满练习**：立 Flag + 环境建模 + 逼自己拉满 + 版本对比
3. **稳定闪现**：知道自己的基准值，很少失手
4. **无限激发**：解放思想 + 灵感轰炸（不满就一直轰） + 组合创新

**Truman 当前基准**：15 分钟 10–15 条风险策略；通勤 30 分钟 40 句营销点；1 小时 70–100 个创意

**铁律**：人先拉满，AI 最后用。AI 优先 = 自废武功

### 十层解读
- **定义**：用多个角度解读同一个东西，做深度穿透
- **与灵感闪现的关系**：灵感闪现做广度（大量涌现），十层解读做深度（多角度穿透）
- **应用**：磨课时立多角度解读目标，驱动极致打磨

### 攻坚会
- **定义**：集中优势兵力攻克开放难题——拉 5–10 人，一个周末下午，不完成不结束
- **效果**：3–5 小时完成过去可能 2–3 周的工作
- **一堂战绩**：20+ 次，成功率 50–90%

### 真实课程生产三层协作
1. **学员**提供大量事实认知（共建课作业）
2. **教研**解读并与 Truman 研讨

**核心机制**：认知换认知——用你对课题的理解交换学员的理解，收集真问题，萃取真解法。

**数据**：一堂 ROI 课一次共建收 182858 字作业，128 份，40 份千字以上，12 份 S 级。18 万字 → 3 万字报告：7 种心路历程 + 6 类最深痛点。

| **B 级** | 记笔记、会议记录、写逐字稿、做调研 | 独立完成案例访谈撰写循环 | 2 周脱产 Landing + 半年循环 |

## 九、课程交付流水线

### 实操课流水线
```
演示路径节点图 → 双轨脚本 0.5 → PPT（被脚本反推）→ 双轨脚本 1.0 → 静默演练 → 上台
```
**核心约束**：每一步帮上一步显形隐藏问题。跳过任何一步 = 问题留到台上给学生看见。

### 理论课流水线
```
用户访谈 → 认知推演路径图 → 标注动力锚点 → 五层密度逐字稿 → 逻辑链测试+锚点检查 → PPT（60–90页）→ 试讲
```

### 静默演练检查单（实操课上场前必过）
- [ ] 每个节点切换是否顺畅？有无「不知道怎么过渡」的空白？
- [ ] 每个等待期是否预埋了知识点？
- [ ] 每个播放后停顿是否到位（≥5 秒）？
- [ ] 三段对比播放文件名是否提前准备好？
- [ ] 备用音频是否全部就绪（每节点至少一份本地备份）？
- [ ] 翻车话术是否每个关键节点至少标了一条？
- [ ] 开场钩子是否逐句写死？
- [ ] 收口总结是否逐句写死？

### 理论课审查：逻辑链测试 + 锚点检查
- [ ] 每句话开头连起来读 → 形成因果/递进/转折链？
- [ ] 任何两个锚点之间不超过 5 分钟？
