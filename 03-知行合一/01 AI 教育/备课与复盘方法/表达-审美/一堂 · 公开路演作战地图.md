# 一堂 · 公开路演作战地图

**核心心法**：公开路演，就是你高考前的模拟考试——不是要你成为演讲高手，而是要你做一次**合格**的交付。
**一句话定义**：在 1v 多的公开场景下，用有限的时间（通常 5–15 分钟），把项目讲清楚、有逻辑、打动人，让对方听完愿意进一步了解。
**场景边界**：包括线下路演、线上视频路演、公开项目宣讲（找合伙人/从 0 到 1 招募）。**不包括** 1v1 讨论互动式路演、业务判断和融资问题准备（那是高中学习，这是考前模拟）。
**课程起源**：一堂组织十几场路演日，Truman 听了几百个同学的路演，发现很多项目不错但讲不出来、很吃亏——于是做了这节指导课。

## 一、路演五类常见问题（先对号入座）

| # | 问题类型 | 典型表现 | 本质 |
|---|---|---|---|
| 1 | **没讲清楚** | 我搞的是 B2B2C/S2B2C/O2O 平台…我是中国的 Udacity… | 用户听完还不知道你项目是干什么的 |
| 2 | **内容跑偏** | 消费品项目花 5 分钟用四种方式讲市场天花板；AI 项目大篇幅讲技术框架 | 没分清「这几分钟该讲什么重点」 |
| 3 | **没控制时间** | 严重超时，路演比赛被关麦 | 没提前彩排、没练时间分配 |
| 4 | **无聊冗长** | 全程没互动、语速慢、没节奏、没新意 | 投资人很容易错过你 |
| 5 | **不自信** | 眼睛只盯 BP 和地板、身体绷紧内缩、结巴、忘词 | 缺上台机会、缺准备 |

**一堂自己的数据**：Truman 见过一个医美项目，创始人本身是非常资深的专家，行业也很有机会——但因为紧张，全程表述非常不自然，没能吸引到投资人。

## 二、优秀路演的三要素

**一句话**：讲清楚，有故事逻辑，能打动人。

**理解场景前提——先回答两个问题**：

| 问题 | 正确态度 |
|---|---|
| 在公开路演场合，你默认大家都是专业的 / 懂你赛道的（A），还是普遍缺少认知的小白（B）？ | **默认 B**——默认大家是小白，用简单的话把复杂的事说清楚 |
| 具体完整、项目清晰、精彩打动人，这三项你怎么排序？ | **清晰 > 完整 > 精彩**——先让人听懂，再追求完整，最后追求锦上添花的精彩 |

**最关键的一条心态底线**：路演的本质是**说服**（Pitch），不是汇报。

## 三、公开路演三部曲 · 总览

| 环节 | 对结果影响 | 核心工作 |
|---|---|---|
| **第一步 · 内容准备** | **50%** | 梳理卖点 / 逻辑 / 故事技巧 |
| **第二步 · 提前彩排** | **30%** | 刻意练习 / 控制时间 / 练到自信 |
| **第三步 · 现场表达** | **20%** | 自信 / 表达 / Checklist 兜底 |

**关键原则**：内容准备占一半权重。内容不行，彩排和表现再好也没用——火箭没装卫星就先发射了。

## 四、第一步 · 内容准备（路演筹备画布 3×3 模型）

**一句话**：准备一场路演，就是把 3×3 = 9 个格子填满。这是本节课的作业框架。

### 3×3 画布

| 关键任务 | 你要填的内容 | 一句话法则 |
|---|---|---|
| **① 提炼卖点** | 用三句话提炼路演卖点——**对方想要什么** | 数据 / 商业模式 / 团队 / 资方 / 目标用户 / 解决痛点 / 其他 |
| **② 讲清项目** | 三句话讲清楚项目——**你是干什么的** | 用户是谁 / 解决什么问题 / 怎么赚钱 |
| **③ 印象深刻** | 选三个让人印象深刻的技巧 | 从讲好故事技巧集里选 3 个埋进去 |

---

### 任务① · 提炼卖点

**融资常见卖点 Checklist**：

| 卖点类型 | 举例 |
|---|---|
| 数据（收入、利润、用户数、增速、留存） | 马蜂窝：用户数超 8000 万 |
| 商业模式（唯一性、颠覆性、创新性） | 拼多多：微信裂变 |
| 团队（越早期优先级越高） | 瑞幸咖啡：神州专车高层团队打造 |
| 历史资方（知名品牌） | 真格投资的 K12 大语文教育 |
| 目标用户（有特色） | 拼多多：四五线城市下沉市场 |
| 解决痛点 | 摩拜：解决最后一公里出行问题 |
| 其他 | 使命初心、模式、技术、垂直领域 |

**实操**：从 Checklist 里挑 3–4 个最适合你项目和听众的卖点，写成三句话。

### 任务② · 讲清项目

**特别糟糕的表达（立即删除）**：
- 「我做的是校企合作的 2B 教育平台」
- 「我做的是某某行业的 S2B2b2C 平台」
- 「我做的是中国的 Udacity / Headspace / Techstars」

**为什么不行**：如果听众还不知道你产品是什么，过早分析竞争、数据、进展、天花板——用户根本听不懂，更别说打动了。

**讲清楚的三件事（越早讲越好）**：

| 三问 | 回答示例 |
|---|---|
| 你的用户（客户）是谁？ | 未来渴望做大的早期创业者，B 轮以前 |
| 你的场景和解决了什么问题？ | 遇到具体的业务难题，缺高质量的教练和陪跑者 |
| 你的商业模式和怎么赚钱？ | 会员选课服务 + VIP 专项训练服务 |

**一堂自己的 3×3 画布填入示例**：

| 任务 | 一堂的填入 |
|---|---|
| 提炼卖点 | ① 以太创服孵化，超强的决心和使命感 ② 强大团队，创新教研模式，高质量标准课程 ③ 模式已验证，增速快，可以跑到头部 |
| 讲清项目 | ① 早期创业者 B 轮以前 ② 遇业务难题缺教练陪跑 ③ 会员选课 + VIP 训练 |
| 印象深刻 | ① 选时间线展开 ② 初心故事开始 ③ MagicWords |

### 任务③ · 印象深刻（讲好故事技巧集）

**四类技巧，任选 3 个埋进路演**：

#### 第一类 · 讲清楚价值

| 技巧 | 做法 |
|---|---|
| 直接展示产品 | 图片、视频、实物——比任何描述都有力 |
| Before/After | 代入具体场景，「原来是这样 → 用了我们之后是这样」 |
| 拯救者模型 | 用户没有你时多痛 → 你的产品拯救了他们 |

#### 第二类 · 分析竞争位置

| 技巧 | 做法 |
|---|---|
| 竞争分析模型 | 解释竞争分析空间——你在哪个格子、对手在哪个格子 |
| 竞争区间模型 | 解释市场定位——你为什么在这一块比对手更有机会 |

#### 第三类 · 有故事和逻辑线

| 技巧 | 做法 | 适用场景 |
|---|---|---|
| **Topdown 故事线** | 从宏大的行业问题一路缩到自己的项目 | 行业存在普遍问题 → 你的项目恰好解决 |
| **按时间组织故事线** | 从过去讲到未来，完整叙事 | 有完整发展历程的项目 |
| **以小见大故事线** | 从一个很小的点开始，讲出一个很大的故事 | 有一个特别动人的小切口——推荐！ |

#### 第四类 · 提升表达张力

| 技巧 | 做法 |
|---|---|
| **15 秒热场** | 站上台立刻热场，打破沉默进入节奏 |
| **提问互动** | 提问反问，唤起思考，更好进入状态 |
| **MagicWords** | 设计一些能打动人的漂亮词汇和文案 |
| **CallBack** | 重复扣之前抛出的内容——呼应形成记忆闭环 |

## 五、路演完整案例 · 一堂自己的路演逐字稿（全流程示范）

**开场**：以太创服孵化，超强决心和使命感。

**故事线（以小见大）**：

- **从过去开始**：我从美团加入以太，遇到了一个做线下共享睡眠舱的创业者——融资很受挫，一遍遍犯错
- **深挖问题**：研究后发现，背后是业务问题、商业模式数据问题、验证问题，甚至是方向选择问题
- **发现普适性**：这样的创业者太多了，国内有 50–100 万，这个问题可以解决吗？
- **坦白限制**：但这些我们 FA 帮不了——能力不够，咨询价格太高了
- **构建产品**：找到机会——研发顶级成体系的标准化课程，大规模服务大家。组建团队：美团、腾讯、人人、核桃编程的同学 + 今日头条天使投资人 + 迅雷创始人荣誉校长 + 诸多投资人 + 年营收 5000w 以上的创业老兵参与课程研发。把以太上千个项目的融资辅导案例做了深度拆解
- **讲数据**：两年时间，14000+ 创业者学习过，平均 82% NPS 高分，6000 人近 3000 万字业务复盘作业
- **讲模式**：体验课 + 会员 + VIP 集训营，最近半年盈亏平衡，最近三个季度收入增速 75%，单月服务人数 3000 人
- **讲未来**：线上相对于竞品，一堂最有价值的点在于大规模复制的潜力。10% 市场渗透率即 5 万人，年付费 1 万，有机会成为国内创投领域第一名

**这本身就是一个完整的三部曲示范**——卖点提炼（以太孵化、验证模式、增速数据）+ 讲清项目（谁、什么问题、怎么赚钱）+ 印象深刻（以小见大故事线、初心故事、MagicWords）。

## 六、第二步 · 提前彩排

**第一原则**：准备系数 N = 提前练习时间 ÷ 正式演讲时间。N 越大越好。

**Truman 自问**：一场 10 分钟的演讲，你提前花 20 分钟准备 → N=2。你觉得合理吗？

**彩排四个重点工作**：

| 重点           | 动作                              | 针对的问题        |
| ------------ | ------------------------------- | ------------ |
| **① 捋顺口语表达** | 把逐字稿大声念出来，哪里卡壳改哪里——念不顺就是写得不对    | 没讲清楚 / 无聊冗长  |
| **② 练习时间分配** | 计时、分段、分头优化（特别优化卖点部分）→ 反复练       | 没控制时间 / 内容跑偏 |
| **③ 重复直到自信** | 不断重复，练到脱口而出的程度——熟练产生自信          | 不自信          |
| **④ 做好心理建设** | 设想最差情况，用底线思维兜底——「最差也不过是……，我能接受」 | 不自信          |

**Truman 自己的彩排习惯**：初五做活动、讲复盘营开课时，都会写出完整发言大纲（目标 → 自我介绍 → 学习建议 → 重点预告），提前反复演练。

## 七、第三步 · 现场表达

**核心认知**：路演不是对着投资人讲一堆 PPT，而是在 PPT 的辅助下讲一个故事。

### 两条关键建议

| 建议 | 做法 |
|---|---|
| **默认是小白** | 用简单的语言把复杂的事情介绍清楚——不假设对方懂你的赛道、懂你的商业模式、懂你的名词 |
| **不要过度展开** | 时间有限，聚焦 3×3 核心信息，不要在每个点上无限展开 |

### 现场表达 Checklist（上台前逐条过）

| 关键项 | 核心点 |
|---|---|
| **对象感** | 你是面对观众讲故事/介绍项目，而不是读一遍 PPT |
| **自信** | 保持自信，相信自己和项目，感染场上氛围 |
| **大声** | 声音适当放大，很自信笃定地介绍自己的项目 |
| **眼神** | 不要游离或盯紧 PPT，和观众有眼神交流，最好循环环视大家 |
| **语速** | 建议语速适当快，同时适当留白，控制一下表达节奏 |
| **插入语** | 加入一些承上启下的过渡——提升表达的逻辑性和前后衔接 |

## 九、路演时间标杆（知己知彼）

| 机构/场景 | 路演时长 |
|---|---|
| 奇绩创坛 | 3 分钟 |
| 真格 & 以太 | 4 分钟 |
| 经纬超级路演室 | 5 分钟 |
| 真格 & 鲸准 | 10 分钟 + 投资人提问环节 |
| 活动行各类资本活动 | 10–15 分钟 |
| 微软加速器 | 10–20 分钟（平均 14.4 分钟） |
| 合伙中国人 | 8–20 分钟 |

**结论**：市场上普遍路演时间 5–15 分钟。管理严格的路演比赛甚至会现场倒计时，到时间关麦——**千万养成好习惯，不要超时。**

## 十、迁移到你的 C 语言教学

**路演能力对你的三个直接应用场景**：

- **公开课 / 教学分享**：你在学校或行业的教学分享会上介绍自己的 C 语言教学方法——这就是一场公开路演。听众是同行或校领导，默认他们是小白（不了解你的具体教法），用 3×3 画布组织内容。
- **课程介绍（给学生）**：新学期第一堂课，你在讲台上介绍「这门课学什么、为什么学、怎么学」——本质是向学生 pitch 你的课程。卖点：你能让他们学到什么？讲清：用户（学生）、痛点（怕编程/学不会）、价值（学完能干什么）。
- **项目汇报 / 答辩**：教学改革汇报、课题答辩——同样是公开路演场景。

**你的第一个训练动作**：用 3×3 画布，给你下学期 C 语言课的第一堂课写一份 5 分钟的「课程路演稿」。填三格——卖点（3 句话）、讲清（你的学生是谁/他们什么痛点/你能给什么结果）、印象深刻（选 3 个技巧）。填完后，按彩排四重点完整走一遍。

---

**最后一句**：刻意练习，这东西是练出来的，不是天赋。公开路演，就是你高考前的模拟考试——没人指望你一次满分，但你不能连模拟考都不参加。**路演不是你讲得有多好，而是你讲完之后，对方有没有说出那一句：「这个项目，我想再聊一次。」**
