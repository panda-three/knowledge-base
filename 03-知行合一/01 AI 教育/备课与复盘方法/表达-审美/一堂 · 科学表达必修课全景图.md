# 一堂 · 科学表达必修课全景图

**核心心法**：商业讲究简单、朴素、有效。不要过多使用「演讲技巧」。
**一句话定义**：科学表达 = 把你的卖点，通过**有逻辑、有张力**的语言，交付给一个真实的对象，让对方被打动、信任、并采取行动。
**本质公式**：表达能力 = 卖点（方向）× 张力（感受）。两者缺一不可——有卖点无张力是「麻木的，听不进去」；有张力无卖点是「听个响，听完就忘」；两者都没有是「自说自话，赶紧结束」。

**一堂为什么做这门课**：大量创业者埋头于业务和管理，忽略了或很不擅长把自己做的事说出来。一次关键的面试沟通、一次投资人沟通会——在这些场景中如果会表达，可以抓住机会，少走弯路。

## 一、表达本质象限 · 你在哪个位置

| | 张力强 | 张力弱 |
|---|---|---|
| **卖点丰富** | ✅ 优秀的表达 | ⚠️ 麻木的，听不进去 |
| **卖点匮乏** | ⚠️ 听个响，听完就忘 | ❌ 自说自话，赶紧结束 |

**判断自己的位置**：你的表达能让听众说出哪句话？
- 「说得好有道理，我记住了一个核心观点」→ 卖点到位
- 「听得很过瘾，但具体讲了什么想不起来」→ 只有张力
- 「他到底想说什么……」→ 两个都没有

## 二、一堂表达力火箭模型 · 总览

**一句话**：好的商业表达 = 一枚三系统火箭——方向系统保证「讲什么」，动力系统保证「怎么让人听懂并记住」，推力系统保证「怎么稳定交付」。

**三大系统 × 四个要素**：

| 系统   | 要素    | 一句话职责               |
| ---- | ----- | ------------------- |
| 方向系统 | ① 卖点  | 我到底要讲什么？听众听完必须带走什么？ |
| 动力系统 | ② 逻辑  | 听众怎么跟上我的思路？         |
| 动力系统 | ③ 张力  | 听众怎么会觉得「卧槽」而不是走神？   |
| 推力系统 | ④ 逐字稿 | 怎么让每次交付都稳定在 70 分以上？ |

**建造顺序铁律**：先建方向系统（卖点），再建动力系统（逻辑 + 张力），最后建推力系统（逐字稿）。卖点没找对就写逐字稿 = 火箭发射了才发现没装卫星。

## 三、方向系统 · 找卖点

**第一原则**：商业表达最最最重要的事，是有卖点（说服点 / pitch 点）。不同场景下，目标完全不同。

**三大商业表达场景 × 卖点 Checklist**：

### 场景 1 · 自我介绍（线下活动 / 社交场）

**只能讲 3 个点，每次相对固定**：

- **名字亮点**：把名字变成一个记忆点。例：「我叫雅洁，雅致洁净的雅洁」「我叫吴迪，我爸妈希望我无论做什么都无人能敌」
- **兴趣爱好（强调特质）**：不是泛泛「喜欢踢足球」，而是「我喜欢和队友默契配合的那种状态，很有成就感」
- **与你有关**：我能给你什么价值？「我擅长做时间管理，如果你总觉得时间不够用，欢迎来找我交个朋友」
- **树立标签**：给自己一个能被记住的外号或标签。「我坚持日更写作三年，身边朋友送我一个外号，叫拼命三郎」

### 场景 2 · 项目介绍（路演 / 分享）

- **目标人群（很聚焦）**：到底服务谁？例：「一堂的用户是一批爱学习的、未来希望规模化做创新业务的人」
- **数据（收入、利润、用户数、增速、留存等）**：用数字说话
- **商业模式（唯一性、颠覆性、创新性）**：和同行最大的不同是什么？
- **解决方案（很独特）**：怎么解决用户的问题？
- **团队（越早期优先级越高）**：核心团队是谁，为什么是他们？
- **兴趣爱好（强调特质）**：创始人个人的特质加持
- **历史资方（知名品牌）**：信任状
- **核心壁垒（很稳固）**：别人为什么不能轻易复制？
- **价值观**：你做这件事的初心和信念

### 场景 3 · 融资路演

- **目标用户（有特色）**：清晰、聚焦
- **对你有用**：产品解决什么具体问题？
- **增长渠道（很创新）**：怎么获客？例：「一堂现在主要的获客渠道是 KOL」
- **核心壁垒（很稳固）**：护城河在哪？例：「一堂未来做大的核心竞争力主要是品牌，以及一定的课程规模」
- **商业模式（很定量）**：单元模型跑通了吗？数据是多少？
- **其他**：头部案例（ToB）、使命初心、模式、技术、垂直领域等

**卖点判断三原则**：
- **同维最好**：同一维度下最强的卖点才值得作为主打
- **场景前提**：不同场景下，卖点强弱完全不同
- **普适优先**：先讲 1-3 个普适卖点争取 80% 用户认可

## 四、动力系统① · 有逻辑

**为什么缺逻辑就是灾难**：一个人讲话超过 3 分钟，听众就开始听不懂了——不明所以，跟不上节奏，不知道到底想表达什么。

**逻辑线策略小抄（9 条，从基础到高阶）**：

### A. 基础逻辑线（极高使用频率）

| 逻辑线 | 解释 | 使用频率 |
|---|---|---|
| A1. 按时间 | 按照时间线发展，把事情说清楚 | 极高 |
| A2. 按空间 | 以地理单位为最基本的表达结构 | 低 |

### B. 进阶逻辑线（高使用频率）

| 逻辑线     | 解释              | 使用频率 |
| ------- | --------------- | ---- |
| B1. 按分点 | 第一、第二、第三        | 极高   |
| B2. 按递进 | 第一步、第二步、第三步     | 高    |
| B3. 按因果 | 说事实、找原因、提方案     | 高    |
| B4. 按对比 | 硬币 A 面，另一面 B 是… | 低    |

### C. 高阶逻辑线

| 逻辑线         | 解释                          | 使用频率 |
| ----------- | --------------------------- | ---- |
| C1. 英雄之旅    | 难题 → 破解 → 新难题 → 又破解         | 中    |
| C2. Topdown | 从行业到模式，从过去到未来               | 中    |
| C3. 多轮本质    | 深看一层，再看一层，再看一层              | 中    |
| C4. 一堂五步法   | 专业的商业全局预判（需求→方案→商业模式→增长→壁垒） | 中高   |

**一堂实操案例 · 堕落虾案例课的逻辑线升级**：
- 原版：按时间线平淡叙述
- 升级版：Topdown（行业格局 → 堕落虾的切入机会）→ 按因果（做了什么 + 背后的专业逻辑）→ 一堂五步法（五个环节逐一拆解）→ 多轮本质（每步追问一层「所以呢？」）
- 效果：超过 150 分钟的案例大课，听众能爱听、能听得进去

## 五、动力系统② · 提张力

**一句话**：张力，就是让听众产生「卧槽」「说的就是我」「这个有意思」的瞬间。张力是语文能力的刻意练习。

**张力挖掘追问清单（照着问，往死里挖）**：
- 当初遇到的困难是什么？→ #要情节
- 很多新手常在这里犯什么错误？→ #要对比
- 这背后的逻辑是什么？→ #要深度
- 有没有印象特别深刻的瞬间？→ #要细节
- 当时做到了什么数字？→ #要真实数字
- 能找到当时的照片吗？→ #要画面

**一堂实操案例**：磨堕落虾案例课时，Truman 用这 6 问陪着 Peter 回忆和复盘，挖出了 30-50 个强有力的张力点，加上逐字稿阶段的提问、互动、图片、金句——**一堂 100 多分钟的课埋了约 100 个张力点**。

### 提升表达张力的超级小抄（武器库核心）

**低难度（立刻能用）**：

| 技巧              | 解释                        | 示例                     |
| --------------- | ------------------------- | ---------------------- |
| 用话术引导           | 「接下来非常重要…」引导听众按你的角度理解     | 「接下来这一条，可能会颠覆你之前的认知」   |
| MagicWords · 强调 | 特别、一定、务必、非常、强调、核心、千万不要、关键 | —                      |
| MagicWords · 规律 | 背后逻辑、底层思考、本质、深层次原因、思考模型   | —                      |
| MagicWords · 疑问 | 究竟、到底、难道                  | 「这件事的背后逻辑，究竟是什么？」      |
| MagicWords · 稀缺 | 首次、唯一、最、根本、真的、极少、只        | 「这是我第一次公开讲这段经历」        |
| 运用「想象」          | 将用户迅速带入场景                 | 「想象一下，你坐在投资人面前，他问你…」   |
| 真诚坦白            | 主动暴露不足或不光彩，拉近距离           | 「这个项目做成之前其实犯过很多不该犯的错误」 |
| 寻找韵律            | 押韵、排比、对仗、叠词               | —                      |
| 拯救者模型           | 用户没有产品时多痛 → 产品拯救了他们       | —                      |

**中难度（需设计和准备）**：

| 技巧           | 解释                                           |
| ------------ | -------------------------------------------- |
| 用数据强调 · 类比   | 把抽象数字具象化。例：「一年卖出 3 亿个，可以绕地球一圈」               |
| 用数据强调 · 变换单位 | 把数据调到可感范围。例：「开售 200 天已卖出 200 万台 = 平均每天 1 万台」 |
| 用数据强调 · 进行对比 | 让数据形成差异点。例：「复购率 80% vs 同行平均 30%」             |
| 用数据强调 · 单位换算 | 增加数据的感染力。例：「整整 240 个小时 = 10 天」               |
| 刻意夸张         | 刻意用夸张的说法，说绝对一些                               |
| 重复扣题         | 先抛一个观点/公式，过几分钟再重复，不断强化                       |
| 提出问题         | 适当提问，唤起思考（注意不要提问投资人！）                        |
| 添加悬念         | 抛一个问题，吊胃口，一会儿来回答                             |
| 颠覆常识         | 「你是错的，你听我说」「你想复杂了，你听我说」                      |
| 解决痛点         | 「你不知道，你听我说」                                  |
| 强烈对比         | Before + After 对比                            |
| 文字渲染 · 时空法   | 描述事件发生的具体时间、空间、情境                            |
| 互动提问         | 唤起大家思考，更好进入状态                                |

**高难度（需深度设计和反复打磨）**：

| 技巧      | 解释                             |
| ------- | ------------------------------ |
| 本质升华    | 挖掘本质，主题升华                      |
| 互动游戏    | 做互动活动，激发参与感                    |
| 刻意转折    | **每 3 分钟出现一次转折**，不断强化困境，激发好奇心  |
| 画面法     | 你看到了什么？听到了什么？心里想的是什么？现在还忘不了什么？ |
| 带实物分享   | 让听众现场直接品尝/体验                   |
| 使用图片/视频 | 富媒体辅助                          |

**设置情节四步法**（一条张力弧线）：
- 「你是错的，你听我说」→ 颠覆常识
- 「你不知道，你听我说」→ 解决痛点
- 「你想复杂了，你听我说」→ 简化认知
- 「你想简单了，你听我说」→ 揭示深度

## 六、推力系统 · 逐字稿

**一句话**：火箭造得再好，没有逐字稿这个推进器，你每次都从零起步。逐字稿让你每次交付稳定在 70 分以上。

### 逐字稿三段位

| 段位 | 评价 Feature | 听众感受 |
|---|---|---|
| **60 分 #能听** | 有对象感、口语化、路线清晰 | 「嗯，是在跟我说话」「说人话，能听懂」「逻辑性不错，我能跟上」 |
| **70 分 #好听** | 语言有节奏、用词有讲究、不时有金句 | 「语言听着很舒服」「用词很准确」「这句很精彩啊」 |
| **85 分 #入戏** | 表达有张力、课程有情节、主题有升华 | 「听起来很有张力」「很吸引人，引人入胜」「主题很颠覆/印象深刻」 |

### 逐字稿撰写核心原则

**60 分段位底线（必须全部做到）**：

- **培养对象感**：想象对面坐着一个真实的用户，讲给他听——而不是对着空气讲
- **用嘴写作，不该省的字不要省**：口语和书面语是两种语言。写逐字稿时大声念出来，念不顺就是写得不对
- **避免书面语**：综上所述→总结一下、例如→举个例子、迅速→很快、立即→马上、从而→这样就、连日来→这些天、地处→位置在、同期→同一时期
- **少用修饰语**：尽量不用定语、状语和补语
- **尽量不用并列名词**：三个名词叠在一起听众就跟丢了

**70 分段位进阶**：

- **用句要短**：避免长难句
- **避免从句、复句、倒装句**：口头表达不是阅读理解
- **多用「专有名词」**：人名、地名、事物名——能唤起画面感的词
- **用插入语引导听众感受**：「尤其是」「特别是」「请注意」「你看/你想」「感觉怎么样」
- **用逻辑关系词增加框架感**：「首先」「然后」「接下来」「最后」「总之」
- **用语气词让语言生动**：「好啊」「很赞啊」「哈哈」「这是什么意思呢」

### 逐字稿训练的铁律

- **先写下来**：绝大多数人讲得差，根本原因是没写——以为自己能即兴讲好。写逐字稿的过程，就是「设计一台戏剧」的过程。
- **合格逐字稿三个硬标准**：使用自然语言、有对象感、没有长难句、易理解。
- **好逐字稿不是写出来的，是改出来的**：第一稿一定是 60 分，改到第三稿才能到 70 分。

## 七、执行武器库全景图（一张大表）

**武器库 = 张力小抄 + 逻辑线小抄 + 口语化写作清单 + 三大场景卖点 Checklist + 逐字稿段位表**

**使用方式**：准备任何一个商业表达前，打开武器库——
1. 先定卖点：从三大场景 Checklist 中挑 3 个最匹配的
2. 再选逻辑线：从 9 条逻辑线中选 1-2 条做骨架
3. 埋张力点：从张力小抄中挑 10-20 个技巧，埋进关键节点（目标：每 3 分钟至少一个张力点）
4. 写逐字稿：按口语化清单写，按三段位标准自检，改到 70 分
5. 反复迭代：讲一遍 → 录下来 → 自己听 → 改 → 再讲

**一堂训练强度参考**：Truman 把表达课**试讲了 77 遍**才上线；一堂内部每个课程逐字稿都经历了「热身拆解 → 交叉评审 → 多人分工撰写 → 桌下练习 → 自我 Before/After 对比 → Truman 点评 → 下周再对比迭代」的循环，人均每月练 20-30 次。

## 八、Before/After 案例 · 堕落虾路演改造

**改造前（简版大纲稿，典型 L2 备忘级表达）**：
> 「大家好，我是 Peter。这是我在 2015 年开始跟兄弟做的项目，从 0 开始，三年开了 1000+ 店。堕落虾，定位于城市年轻人饮食升级的一站式餐饮服务平台，我们致力于通过科技改造餐饮，推动餐饮产业化发展……」

**问题诊断**：按时间线讲流水账、没有核心卖点、没有张力点、书面语浓重、听众 30 秒就失去兴趣。

**改造过程**：
1. **找卖点**：锁定「液氮冷冻技术解决小龙虾季节性痛点」为核心 pitch 点
2. **选逻辑线**：Topdown（行业痛点 → 技术方案 → 商业模式 → 壁垒）替代纯时间线
3. **挖张力**：用 6 问追问 Peter → 挖出三年 1500+ 店、液氮试错几十种、单店模型数据、天天地铁写 PR 稿、为创业献身长胖等 30-50 个张力点
4. **写逐字稿**：从头重写，口语化，埋 100 个张力点到 100 分钟课程中

**改造后效果**：从 MBA 答辩风的平淡报告 → 投资人听完主动要聊的强 pitch。核心逻辑没有变（还是堕落虾这个项目），但表达质量从不及格拉到 85 分。

## 九、普通人的训练路径

**三种训练场景**：

| 场景      | 练法                                          | 频率      |
| ------- | ------------------------------------------- | ------- |
| 自我介绍    | 写 3 个固定卖点 + 逐字稿，每次用同一版，迭代到别人听完主动加微信         | 每次社交场   |
| 项目/课程介绍 | 用武器库完整走一遍：卖点 → 逻辑线 → 埋张力点 → 逐字稿 → 讲 3 遍 → 改 | 每次正式场合前 |
| 日常小表达   | 开会发言、课堂讲解前，花 3 分钟在大脑里过一遍「卖点 + 逻辑线 + 2 个张力点」 | 每天      |

**ROI 自问**：未来 10 年你有多少重要的表达场景？每次表达如果从 60 分拉到 80 分，累计能带来多少回报？算完这个账，要不要认真练，自己就有答案了。

**Truman 的一句话收尾**：商业讲究简单、朴素、有效。不要过多使用演讲技巧——**真正的表达力，是你把一件事想清楚、讲清楚、让对方感受到价值的能力。练的不是口才，是思考的精度。**

## 十、迁移到你的 C 语言教学

**火箭模型完全适用**：

- **方向系统 · 卖点**：你的一节课的核心 pitch 是什么？不是「今天讲 for 循环」，而是「上完这节课，你能自己写出一个猜数字游戏」
- **动力系统 · 逻辑**：用递进逻辑线——第一步看现象（冲突代码）→ 第二步拆规则（循环执行顺序）→ 第三步练变体（梯度练习）
- **动力系统 · 张力**：每 3 分钟一个张力点——认知冲突代码、让学生预测输出、揭晓意外结果、一个金句总结、一个类比（「循环就像流水线工人，每次检查一个条件，做到不满足就下班」）
- **推力系统 · 逐字稿**：把一堂课的讲解逐字写下来，按三段位自检——能不能「说人话」？有没有「语言节奏」？能不能让学生「入戏」？

**你的第一个训练动作**：挑一节课，写一份 5 分钟的「课眼逐字稿」——只写这节课最关键的那 5 分钟讲解。用张力小抄埋 5 个点，用口语化清单自检，改到 70 分，然后下一堂课实际用出来。录下来，自己听一遍。
