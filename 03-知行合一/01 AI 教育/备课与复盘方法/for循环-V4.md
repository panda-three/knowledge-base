# for 循环学生讲义 V4

> 本节课主线：**重复劳动 → for 循环四问 → 执行流程追踪 → 边界控制 → 累加 / 计数应用**。  
> 学完后，你不只是会背 `for(初始化; 条件; 变化)`，还要能说清楚：**i 从几开始、到哪停、每次怎么变、循环体重复做什么。**

---

## 0. 课前基础

学习本节内容前，默认你已经学过：

- 变量
- `printf` / `scanf`
- `if` / `switch`
- 基本运算符：`+ - * / %`

本节课最小目标：能独立写出下面这种循环，并能解释每个位置为什么这样写。

```c
for (i = 1; i <= 5; i++) {
    printf("%d\n", i);
}
```

---

## 1. 为什么需要循环

如果要打印 5 遍“我爱 C 语言”，可以这样写：

```c
#include <stdio.h>

int main() {
    printf("我爱 C 语言!\n");
    printf("我爱 C 语言!\n");
    printf("我爱 C 语言!\n");
    printf("我爱 C 语言!\n");
    printf("我爱 C 语言!\n");
    return 0;
}
```

这段代码结果是对的，但问题很明显：

- 太重复
- 太麻烦
- 如果次数变成 50 次、100 次，代码会很长
- 修改内容时，每一行都要跟着改

**重复不是错误，但重复是信号。**  
它在提醒你：这里有结构，可以交给循环。

for 循环的作用，就是让电脑替你重复做一件事。

---

## 2. 核心模型：for 循环四问

for 循环的基本结构：

```c
int i;
for (初始化语句; 条件判断语句; 条件控制语句) {
    循环体语句;
}
```

刚开始看，括号里有三个位置，还有两个分号，可能有点乱。不要先死背格式，先记住四个问题：

```txt
写 for 循环，先问四句话：

1. 从哪开始？
2. 到哪结束？
3. 每次怎么变？
4. 重复做什么？
```

对应到代码：

```c
for (从哪开始; 到哪结束; 每次怎么变) {
    重复做什么;
}
```

### 四问解释表

| 四问     | for 中的位置 | 例子            | 常见错误          |
| ------ | -------- | ------------- | ------------- |
| 从哪开始？  | 初始化语句    | `i = 1`       | 不知道 i 初始值写几   |
| 到哪结束？  | 条件判断语句   | `i <= 5`      | `<` 和 `<=` 混乱 |
| 每次怎么变？ | 条件控制语句   | `i++`         | 忘记变化，死循环      |
| 重复做什么？ | 循环体      | `printf(...)` | 把不该重复的代码放进大括号 |

### 口诀

> **先定起点，再定终点；每轮变一次，身体做重复。**

## 3. 示例 1：打印 1 到 5

### 需求

打印 1 到 5。

### 先写四问

| 四问     | 本题答案                        |
| ------ | --------------------------- |
| 从哪开始？  | 从 1 开始，所以 `i = 1`           |
| 到哪结束？  | 到 5 结束，而且 5 要打印，所以 `i <= 5` |
| 每次怎么变？ | 每次加 1，所以 `i++`              |
| 重复做什么？ | 打印当前的 `i`                   |

### 完整代码

```c
#include <stdio.h>

int main() {
    int i;

    for (i = 1; i <= 5; i++) {
        printf("%d\n", i);
    }

    return 0;
}
```

### 预期输出

```txt
1
2
3
4
5
```

### 代码理解

- `int i;`：定义循环变量，负责一轮一轮地走。
- `i = 1`：从 1 开始。
- `i <= 5`：只要 i 没有超过 5，就继续执行。
- `i++`：每一轮结束后，i 往前走一步。
- `{ printf("%d\n", i); }`：每一轮都打印当前的 i。

### 想一想

如果把：

```c
i <= 5
```

改成：

```c
i < 5
```

输出会少哪个数？

答案：会少 `5`。

### 小结

循环里最容易出错的地方，经常不是语法，而是边界。  
一个等号，就可能少处理一个数据。

## 4. 示例 2：执行流程追踪

for 循环不是“从左到右走一遍”，而是反复经历：判断、执行、变化。

### 代码

```c
#include <stdio.h>

int main() {
    int i;

    for (i = 1; i <= 3; i++) {
        printf("i = %d\n", i);
    }

    printf("结束时 i = %d\n", i);
    return 0;
}
```

### 运行前先猜

这段代码会打印几行？最后 `i` 是几？

### 预期输出

```txt
i = 1
i = 2
i = 3
结束时 i = 4
```

### 执行流程

```txt
① 执行 i = 1        只执行一次
② 判断 i <= 3       成立，进入循环体
③ 执行 printf
④ 执行 i++          i 变成 2
⑤ 回到②继续判断

当 i 变成 4 时：
判断 i <= 3 不成立，循环结束。
```

最容易忽略的是最后的 `4`。  
因为 i 打印完 3 以后，还会先执行一次 `i++`，变成 4，再去判断。判断不成立，循环才结束。

### 小结

for 的执行顺序是：

```txt
起点一次
判断多次
身体多次
变化多次
```

## 5. 示例 3：反向输出 5 到 1

### 需求

打印 5 到 1。

### 先写四问

| 四问 | 本题答案 |
|---|---|
| 从哪开始？ | 从 5 开始，所以 `i = 5` |
| 到哪结束？ | 到 1 结束，而且 1 要打印，所以 `i >= 1` |
| 每次怎么变？ | 每次减 1，所以 `i--` |
| 重复做什么？ | 打印当前的 `i` |

### 完整代码

```c
#include <stdio.h>

int main() {
    int i;

    for (i = 5; i >= 1; i--) {
        printf("%d ", i);
    }

    return 0;
}
```

### 预期输出

```txt
5 4 3 2 1
```

### 代码理解

这题没有新语法，只有方向变了。

- 正向走：从小到大，通常用 `i++`
- 反向走：从大到小，通常用 `i--`
- 条件也要跟着方向变，不能再写 `i <= 5`

### 常见错误

错误写法：

```c
for (i = 5; i <= 1; i--)
```

这个循环不会执行。因为一开始 `5 <= 1` 就不成立。

### 小结

写循环时，起点、终点、变化方向必须是一套。  
如果方向反了，循环要么不走，要么走不出去。

## 6. 示例 4：求 1 到 5 的和

### 需求

求 1 到 5 的和。

### 先区分两个变量

```txt
i   ：负责一个一个走
sum ：负责把每个数装起来
```

### 完整代码

```c
#include <stdio.h>

int main() {
    int i;
    int sum = 0;

    for (i = 1; i <= 5; i++) {
        sum = sum + i;
    }

    printf("sum = %d\n", sum);
    return 0;
}
```

### 预期输出

```txt
sum = 15
```

### 代码理解

打印题里，i 走到哪里，就把 i 打出来。  
求和题里，i 还是负责走，但还需要一个变量 `sum` 当篮子。

每来一个 i，就把它放进篮子里：

```c
sum = sum + i;
```

### 追踪表

| 轮次 | i | 本轮之前 sum | 执行 `sum = sum + i` 后 |
|---:|---:|---:|---:|
| 1 | 1 | 0 | 1 |
| 2 | 2 | 1 | 3 |
| 3 | 3 | 3 | 6 |
| 4 | 4 | 6 | 10 |
| 5 | 5 | 10 | 15 |

### 想一想

第三轮结束后，sum 是多少？

答案：`6`。

### 小结

循环变量 `i` 负责走，`sum` 负责装。  
以后遇到求和，先想：**我要让谁走？我要用谁装？**

## 7. 练习：条件统计

### 题目

键盘录入两个数字，表示一个范围 `[start, end]`。统计这个范围中，既能被 6 整除，又能被 8 整除的数字个数。

如果刚开始觉得输入麻烦，可以先把范围固定成 `1` 到 `100`。

### 先写四问

| 四问 | 本题答案 |
|---|---|
| 从哪开始？ | `i = start` |
| 到哪结束？ | `i <= end` |
| 每次怎么变？ | `i++` |
| 重复做什么？ | 判断 i 是否同时被 6 和 8 整除，满足就 `count++` |

### 完整代码

```c
#include <stdio.h>

int main() {
    int start, end;
    int i;
    int count = 0;

    printf("请输入范围的开始和结束：");
    scanf("%d %d", &start, &end);

    for (i = start; i <= end; i++) {
        if (i % 6 == 0 && i % 8 == 0) {
            count++;
        }
    }

    printf("满足条件的数字个数是：%d\n", count);
    return 0;
}
```

### 代码理解

这道题看起来比打印数字难，但本质还是四问。  
只是循环体里不再是直接打印，而是每一轮都判断：这个 i 能不能同时被 6 和 8 整除？

能，就让 `count` 加 1。

### 想一想

`count++` 应该放在 `if` 里面，还是外面？为什么？

答案：放在 `if` 里面。因为只有满足条件的数字才应该被计数。

### 小结

复杂题不是突然出现的。它通常只是：

```txt
循环负责一个个试
if 负责判断
变量负责记录
```

## 8. 进阶挑战：水仙花数

### 题目

打印 100 到 999 之间所有水仙花数。

水仙花数：一个三位数，各位数字的立方和等于它本身。  
例如：

```txt
153 = 1*1*1 + 5*5*5 + 3*3*3
```

### 完整代码

```c
#include <stdio.h>

int main() {
    int i;

    for (i = 100; i <= 999; i++) {
        int ge = i % 10;
        int shi = i / 10 % 10;
        int bai = i / 100;

        if (bai * bai * bai + shi * shi * shi + ge * ge * ge == i) {
            printf("%d\n", i);
        }
    }

    return 0;
}
```

### 预期输出

```txt
153
370
371
407
```

### 代码理解

水仙花数没有脱离今天的主线。它还是四问：

| 四问 | 本题答案 |
|---|---|
| 从哪开始？ | `i = 100` |
| 到哪结束？ | `i <= 999` |
| 每次怎么变？ | `i++` |
| 重复做什么？ | 拆出个位、十位、百位，然后判断立方和是否等于 i |

拆数字的方法：

```c
int ge = i % 10;        // 个位
int shi = i / 10 % 10;  // 十位
int bai = i / 100;      // 百位
```

## 9. 常见错误

### 1. 分不清 `<` 和 `<=`

不要先想符号，先想：最后一个数据要不要被处理？

- 要处理最后一个数：常用 `<=` 或 `>=`
- 不处理最后一个数：常用 `<` 或 `>`

例如打印 1 到 5：

```c
for (i = 1; i <= 5; i++)
```

如果写成：

```c
for (i = 1; i < 5; i++)
```

就只会打印到 4。

### 2. 忘记 `i++` 或 `i--`

循环变量如果不变化，就像人在原地踏步，永远到不了终点。

错误示例：

```c
for (i = 1; i <= 5; ) {
    printf("%d\n", i);
}
```

这段代码里 i 一直是 1，会变成死循环。

### 3. 把代码放错大括号

判断一行代码要不要放进循环体，先问：这件事是不是每一轮都要做？

- 每一轮都要做：放进 `{}`
- 只做一次：放在循环外

### 4. 把 `sum = sum + i` 写成 `sum = i`

`sum = i` 会覆盖原来的结果，只留下这一次的 i。  
`sum = sum + i` 才是把新的 i 加到原来的 sum 里。

### 5. 统计题把 `count++` 放在 if 外面

如果 `count++` 放在 `if` 外面，就表示每个数字都计数了。  
但题目要的是“满足条件的数字个数”，所以 `count++` 应该放在 `if` 里面。

## 10. 本节总结

写 for 循环时，不要只背格式，先问四句话：

```txt
1. 从哪开始？
2. 到哪结束？
3. 每次怎么变？
4. 重复做什么？
```

再记住三个角色：

```txt
i         负责走
sum/count 负责装
if        负责判断
```

for 循环真正难的不是括号，而是能不能从题目里找出这四件事。  
当你能找出来，打印、求和、统计、水仙花数，其实都在一条线上。
