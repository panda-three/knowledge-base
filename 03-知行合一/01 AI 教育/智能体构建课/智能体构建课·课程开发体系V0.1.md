# 智能体构建课 · 课程开发体系 V0.1

> **一句话定位**：以双三角为操作系统、四 Skill 为流水线，开发一门 2 天 12 小时的「智能体构建：AI产品开发与商业化验证」课——让北大清华学生在两天内做出一个**可演示、算得过账**的 AI 智能体产品。

---

## 1. 体系总览（四层结构）

```
┌────────────────────────────────────────────────┐
│ 哲学层  双三角操作系统（这门课的魂：为什么这样教）         │
├────────────────────────────────────────────────┤
│ 任务层  四线并行流水线（收料 / 加工 / 设计 / 质检）       │
├────────────────────────────────────────────────┤
│ 内容层  12 小时课程骨架（两天 × 双三角锚点）            │
├────────────────────────────────────────────────┤
│ 质量层  四 Skill 闸门（拆解 / 检索 / 反幻觉 / 质量门）   │
└────────────────────────────────────────────────┘
```

**核心思想**：这门课本身就是双三角的**实证**——不是教"怎么用 AI 造产品"，而是教"人机如何共同把一件事做成"，并让学生当场做出产品证明这个飞轮转起来了。

---

## 2. 哲学层：双三角如何成为这门课的魂

### 2.1 课程主张

> 不要只学怎么用 AI 造产品，要学怎么和 AI 一起把产品做成。
> —— 双三角实证课：人搭系统（产品/审美/体系），AI 跑系统（场景/基本功/数据）。

两个灵魂拷问直接做开场：

1. 同样都在用 AI 造产品，为什么有人两天做出能演示的产品，有人两天还在调提示词？（答：人三角——创造力/审美/体系）
2. 同样都是产品高手，为什么有人 AI 用得出神入化，有人只会问答？（答：AI 三角——场景/基本功/数据）

### 2.2 课表 × 双三角映射（课程设计的指挥棒）

| 课表内容 | 双三角主角 | 这角教什么 |
|---|---|---|
| 软件产品生态 | 体系 | 产品技术栈怎么拆（前端/后端/数据/AI）——人先搭系统 |
| AI 创业产品设计 | 创造力 + 体系 | 提出假设、定义 MVP、需求原点——人做判断 |
| AI 生成原型与 UI | 审美 | 知道什么叫好产品——审美的具象化 |
| AI 辅助代码生成 | 基本功 | 把任务交代清楚、迭代清楚——AI 基本功 |
| 数据库与接口设计 | 数据 + 基本功 | 数据存哪、怎么流——数据资产起步 |
| 产品测试与联调 | 场景 | AI 介入的工作位置 + 迭代闭环 |
| 商业模式初探 | 场景 + 数据 | 谁付钱、成本、毛利——商业验证 + 数据复利 |

### 2.3 双三角贯穿线（三处点睛）

- **开场（Day1 第一段）**：两个灵魂拷问 + 一张双三角总图，告诉学生"这两天不是学工具，是学操作系统"。
- **中段（每个模块切换时）**：每进入一个新模块，点明"现在转到哪一角"——让学生时刻知道自己在双三角的哪个位置。
- **收尾（Day2 路演）**：用双三角验收学员作品——你的产品里，审美在哪？体系在哪？数据从哪来？这就是"六角验收"。

### 2.4 学员产出定义（课程的"飞轮实证"）

每个学员两天后交付三样东西：

1. **一个能演示的 AI 智能体产品**（现场做出）
2. **一笔算得过的商业账**（谁付钱/成本/毛利/壁垒）
3. **一张双三角六角自评卡**（作品里六角各做了几分、缺哪角）

这三样就是飞轮的证据：人（创造力/审美/体系）调教 AI（场景/基本功/数据）→ 做出产品 → 产生数据 → 数据养强 AI → 辅助人更强。

## 3. 任务层：四线并行流水线

### 3.1 依赖关系总图

```
A 收料线（可并行拆 3 条）         B 加工线            C 设计线            D 质检线
A1 库内素材盘点 ──────────────┐
A2 库外调研补缺 ────────────┼──→ B 内容加工 ──→ C 课程设计 ──→ D 制作质检
A3 案例故事化素材 ────────────┘   （概念讲义）    （大纲/教案/练习）  （PPT/核查/压力测试）
```

**并行原则**：A1 / A2 / A3 三条收料子任务互不依赖，可同时启动；B 依赖 A 出料；C 的"大纲总设计"可先行（依赖 B 的概念讲义一半即可启动），C 的"教案/练习"依赖大纲；D 的 PPT 制作与反幻觉核查可并行，压力测试依赖成品。

### 3.2 任务分解表（供你建任务时直接套用）

| 任务 | 输入 | 输出 | 依赖 |
|---|---|---|---|
| A1 库内素材盘点 | 知识库 1113 篇 | 素材清单（S/A/B/C 分级 + 缺料清单） | 无（可立即启动） |
| A2 库外调研补缺 | 缺料清单（数据库接口/测试联调/低代码工具链） | 补齐素材（OSCAR 调研） | 依赖 A1 缺料清单（可并行等待） |
| A3 案例故事化 | 案例素材 | before/after 故事包（每个模块 1-2 个） | 无（可立即启动） |
| B1 概念讲义 | 素材清单 | 每个知识点一页纸（含双三角锚点） | A1/A2/A3 |
| B2 问题树定型 | 概念讲义 | 课程问题树 Q1-Q8 终版 | B1 一半 |
| C1 大纲总设计 | 问题树 + 概念讲义 | 12 小时课程大纲（两天结构） | B1/B2 |
| C2 逐课时教案 | 大纲 | 8 个课段教案（每段 90 分钟） | C1 |
| C3 练习与项目设计 | 大纲 + 案例包 | 现场项目任务书 + 作业卡 | C1 |
| D1 PPT/课件制作 | 教案 | 课件成品 | C2 |
| D2 反幻觉核查 | 全部内容 | 事实核查报告（A/B/C/D 评级） | B/C 全部 |
| D3 压力测试 | 课件成品 | 质检报告 + 修改清单（≥B 才发） | D1/D2 |
| D4 演示预演 | 教案 + 课件 | 讲台逐字稿 + 工具链预演记录 | D1 |

### 3.3 任务编排建议

- **第一波并行**（现在就能启动）：A1 + A3 + B2 初版（问题树我已示范过 V0.1）。
- **第二波**：A2（等 A1 缺料清单）+ B1。
- **第三波**：C1 大纲 → C2/C3。
- **第四波**：D1/D2 并行 → D3 → D4。
- 全程质量门把关：每个里程碑产物过对应闸门，不返工到最后一刻。

## 4. 内容层：12 小时课程骨架（V0.1 供审，定稿后深化）

### 4.1 两天结构（8 段 × 90 分钟）

| 段 | 时间 | 内容 | 双三角锚点 |
|---|---|---|---|
| Day1-1 | 09:00-10:30 | 开场：两个灵魂拷问 + 双三角总纲 + 软件产品生态全景 | 体系（人先搭系统） |
| Day1-2 | 10:45-12:15 | AI 创业产品设计：需求原点 → MVP 定义 | 创造力 + 体系 |
| Day1-3 | 14:00-15:30 | AI 生成产品原型与 UI：工具链 + 现场 demo | 审美 |
| Day1-4 | 15:45-17:15 | AI 辅助代码生成 + 数据库与接口设计：现场动手 | 基本功 + 数据 |
| Day2-1 | 09:00-10:30 | 产品测试与联调：报错→定位→修复闭环 | 场景 |
| Day2-2 | 10:45-12:15 | 现场项目冲刺（把产品做完整） | 六角齐转 |
| Day2-3 | 14:00-15:30 | 商业模式初探：算一笔商业账 | 场景 + 数据 |
| Day2-4 | 15:45-17:15 | 项目路演 + 双三角六角验收 + 复盘 | 飞轮实证 |

### 4.2 现场项目主线（贯穿两天）

每个学员（或 2 人组）从 Day1-2 选定一个 AI 智能体产品课题，之后每段课都在自己的课题上推进：设计 → 原型 → 代码 → 数据库 → 测试 → 商业账 → 路演。**课表是骨架，项目是血肉**——所有知识点都落在学员自己的产品上。

### 4.3 成功标准（对应双三角的"可证伪"）

课程结束后，学员能：

1. 说清双三角六角，并指出自己作品里每角做功的位置。
2. 现场演示一个能跑的 AI 智能体产品（不是 PPT 里的截图）。
3. 算出产品的商业账，回答"谁付钱、成本多少、毛利多少、壁垒在哪"。

## 5. 质量层：四 Skill 闸门挂接

| 里程碑产物 | 闸门 | 通过标准 |
|---|---|---|
| 课程问题树 | 拆解引擎 | 每个子问题有可证伪判定 |
| 素材检索包 | 检索雷达 | 无缺料硬凑，缺料清单明确 |
| 概念讲义 + 教案 | 反幻觉 | 每个案例/数字有 L1-L3 来源 |
| 课件成品 | 输出质量门 | G1-G4 全过，评级 ≥B |
