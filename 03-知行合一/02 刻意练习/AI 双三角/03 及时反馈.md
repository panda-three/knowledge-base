### 策略1：版本对比 —— 每次练习单独留一份画布副本，不覆盖

**第一层：覆盖检查（及格线）——每次练完看一眼**

| 要素  | 检查问题                    | 答案必须是"有"才算过 |
| --- | ----------------------- | ----------- |
| 场景  | 我写清楚"这次要解决什么具体问题"了吗？    | 有 / 没有      |
| 审美  | 我写了一个"好结果长什么样"的判断标准吗？   | 有 / 没有      |
| 体系  | 我写了"解决这类问题的成熟框架或步骤"吗？   | 有 / 没有      |
| 基本功 | 我写了"用什么AI工具/提示词策略/能力"吗？ | 有 / 没有      |
| 数据  | 我写了"需要什么数据输入给AI"吗？      | 有 / 没有      |
| 创造力 | 我写了"AI可以在基础上做什么新尝试"吗？   | 有 / 没有      |

### 策略2：事实反馈 —— 每张画布底部加三行「自我检查」

1. **哪个要素填得最顺？** （通常是你已经熟练的那个）
2. **哪个要素填得最卡？** （通常是你想跳过或只写了一句话的那个）
3. **下一轮我先改什么？** （必须指向一个具体要素的一个具体动作）
