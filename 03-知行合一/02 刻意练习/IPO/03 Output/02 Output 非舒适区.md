## Output 环节 · 非舒适区 策略卡

### 一句话定义

> 非舒适区不是痛苦，而是**每次 Output 都比惯性状态多挑战一点**——让套路不变成惯性执行，每一轮都在能力边界附近练。

### 核心认知：套路是方向盘，非舒适区是油门

| 没有非舒适区 | 有非舒适区 |
|---|---|
| 每次按 1.1 跑一遍，深度、速度、标准不变 | 每次跑 1.1 时，有一个明确的「这次要比上次多突破一点」的挑战 |
| 做 10 次复盘，只是在熟练模板 | 做 10 次复盘，每次都在突破新边界 |
| 越来越熟练，但不一定越来越强 | 每轮都在把能力边界往外推 |

---

### Output 非舒适区 · 三种策略

| 策略 | 做法 | Output 场景示例 |
|---|---|---|
| **对标最佳** | 拿高水平标杆对比自己的产出，找具体差距 | 做完复盘后，用 Truman 的 Trumind 报告逐模块对照，记下 3 个差距 |
| **提升 20%** | 每次在某一个维度上比上次多做一小截 | 上次只做了 2 张三行卡片，这次做 4 张；上次分堆只有 2 类，这次三类全覆盖 |
| **能力拉满** | 偶尔一次不收力，把某个维度做到当前极限 | 不限时、不跳步，五模块全部填满，做到不能再改为止 |

### 你的第一个非舒适区挑战：对标最佳

**场景：** 本次对话结束后，做一次完整复盘报告，对标 Truman 的 Trumind 报告。

**操作步骤：**

1. **先做自己的**——用 Output 1.1 的 ③-B 五模块模板，把这段对话写成复盘报告。不偷看标杆。
2. **再打开标杆**——拿出 Truman 的 Trumind 报告，逐模块对照。
3. **记下至少 3 个具体差距**——不说「他做得更好」，说「他的全景概览有数据表，我的只有一句话」。

---

**对比框架：**

| 模块 | 你的报告 | Truman 的 Trumind 报告 | 差距在哪？（≥3 个） |
|---|---|---|---|
| ① 全景概览 | | 项目目标 + 数据表 + 探索路径全景图 | |
| ② 过程还原 | | 13 轮命名路径图 + 关键转折标注 | |
| ③ 深度解读 | | 五层含义解读 + 三个完整故事 | |
| ④ 方法论萃取 | | 命名七维度 + 人机协作四步法 | |
| ⑤ 可分享产出 | | 团队分享要点 + 一句话/十秒故事 | |

---

### 非舒适区使用原则

| 原则 | 说明 |
|---|---|
| **贴边不崩** | 挑战要略高于当前水平，不是完全做不到 |
| **每次只加一个挑战点** | 不要同时对标最佳 + 能力拉满 + 限时，一次只盯一个维度 |
| **做完要回头比对** | 挑战的价值在被看见——做完对标练习后，把自己找出的差距记录下来，这就是下一次的起点 |
| **不鼓励硬冲高风险** | 非舒适区是在可反馈、可恢复的范围内贴边练习，不是盲目加压 |
