## AI 对话复盘 · Output 固定套路 1.1

---

### 总览

```
① 实时标记
    ↓
② 对话后分堆
    ↓
②.5 对话回溯（多轮后触发）
    ↓
    ├─→ ③-A 三行卡片（单点收获）
    │
    └─→ ③-B 完整复盘报告（链状收获）
    ↓
④ Obsidian 归档
```

---

### ① 实时标记

**时机：** 对话进行中，每轮随时做。

**动作：** 听到有启发的判断、框架、概念或纠偏时，立刻记一个关键词或一句话。**不等聊完再回忆。**

**工具：** Obsidian 新建 `AI对话-实时标记.md`，每行一条，不用整理。

**示例：**
```
- 遇到有价值的判断立刻记，别等聊完
- 收获必须落脚到"下一步改什么动作"
- 固定套路不是死模板，是当前最好水平的记录
- Output 是我 IPO 的最佳起点，阻力最小
```

---

### ② 对话后分堆

**时机：** 单轮对话结束后。

**动作：** 把实时标记的条目扔进三个固定篮子，每类最多放 5 条。

| 篮子 | 判断标准 |
|---|---|
| 🆕 新概念 | 以前不知道、今天第一次被点醒的 |
| 🔧 纠偏 | 以前理解有偏差，今天被纠正的 |
| 🎯 可执行动作 | 下一步就能改、能试的 |

> 一个标记同时跨两个篮子可以双脚站，优先归到 🎯 可执行动作（复用率最高）。

---

### ②.5 对话回溯

**时机：** 几轮对话叠加后，或数天后回看。**适用于多轮对话中逐渐"长出来"的理解。**

**固定三个问题：**

```text
1. 这几轮对话，最核心的一个判断是什么？
   （用自己的话总结，不是复述原话）

2. 这个判断是怎么推导出来的？中间经历了哪几个关键转折？

3. 我最后的理解和最初的理解，差在哪里？
```

**产出：** 一张回溯卡片（轻量版），或进入 ③-B 输出完整报告。标签加 `#回溯`。

---

### ③-A 三行卡片

**适用场景：** 单个洞察、一个纠偏、一个可执行动作——点状收获。

**固定模板（每张不超过 3 句话）：**

```text
① 这是什么
② 为什么重要
③ 我下一步改什么
```

**示例：**

> **卡片：实时标记，不等聊完再回忆**
>
> ① 对话中遇到有价值的判断或框架，立刻用一句话记下来。
> ② 聊完再回忆会大量丢失关键细节，及时标记是高质量 Input 的第一道闸门。
> ③ 下次跟 AI 对话时，开 Obsidian 收件箱，每听到有启发的内容立刻敲一行关键词，不等聊完。

---

> **卡片：收获必须落脚到「下一步改一个什么动作」**
>
> ① 每次得到有价值的信息后，追问一句：我下一步要改一个什么具体动作。
> ② 没有落脚到动作的收获，聊完容易散掉。只有变成动作，信息才从"短暂触动"升级为"能力改变"。
> ③ 每次 AI 对话后，在所有标记节点里至少选 1 条，写成"我下周改什么"——不写计划，只写一个具体动作。

---

### ③-B 完整复盘报告

**适用场景：** 多轮对话产生了深度理解、方法论框架、或值得分享的成果。触发条件：回看时发现「这几轮能提炼出一个可复用框架」或「这个成果值得给别人讲」。

**五模块模板：**

| 模块          | 要回答的问题                  | 具体做法                                                 |
| ----------- | ----------------------- | ---------------------------------------------------- |
| **① 全景概览**  | 这是什么项目？规模多大？经历了什么路径？    | 一句话定义 + 关键数据表（轮次/时长/产出）+ 探索路径图（标注关键转折）               |
| **② 过程还原**  | 中间经历了哪几个关键转折？每个转折改变了什么？ | 选 5-8 个关键节点，每节点标注：当时卡在哪 → 做了什么突破 → 结果改变了什么。**不写流水账** |
| **③ 深度解读**  | 最终成果好在哪？能从哪些层次理解它？      | 至少两重解读（字面 + 深层），最好能扩展到 3-5 层。如果涉及方法论，拆成步骤或维度         |
| **④ 方法论萃取** | 这次经验能提炼出什么可复用的框架？       | 至少产出 1 个可复用框架（步骤链 / 多维模型 / 判断标准），用表格呈现               |
| **⑤ 可分享产出** | 如果给别人讲，怎么讲？             | 一句话版 / 三句话版 / 完整版，至少有一个「别人可以直接用」的东西                  |

**两份参考案例（你提供的）：**

| | Trumind 报告 | 科学决策报告 |
|---|---|---|
| 全景概览 | 项目目标 + 数据表 + 探索路径全景图 | 对话全景流程图 + 项目统计表 |
| 过程还原 | 13 轮命名探索路径图 + 关键转折标注 | 8 轮交互流程图 + 角色动作拆解表 |
| 深度解读 | 五层含义解读 + 三个完整故事 | 方法论覆盖统计 + Agent 动作拆解 |
| 方法论萃取 | 命名七维度 + 人机协作四步法 | Agent 反问→拆要素→戳假设→要数据→出结论 动作链 |
| 可分享产出 | 团队分享要点 + 一句话/十秒故事 | 决策画布 8 模块 |
