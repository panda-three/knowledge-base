# 非舒适区

1. **非舒适区不是被逼，而是你主动选择离开惯性动作** 哪怕一件事完全没人看、没后果，你依然可以给自己加要求
2. **非舒适区不是一种感觉，而是一次选择。** 你不能等自己“有挑战的状态”之后才进入挑战，而是要在还没感觉到挑战的时候，就先说一句：“这篇，我要挑战全程追问层”，然后逼自己再多问一句、再追一层。你不需要一口气把挑战变成本能。你只要保证一件事：**每次打开笔记，在写“> 挑战：”那一行的时候，不停手、不跳过、不空着。** 哪怕你最后只追问了一层、只画了半张表、只写了三行故事线，只要那一行被填上了，你就已经离开了惯性动作。进了，哪怕只进了一点点，就是进了。
3. **不是换新框架、不是越痛苦越好，而是每次比惯性动作再拉满一点——让自己必须动脑、调整、突破旧动作。**
4. **非舒适区的本质，就是持续拉伸审美。**

# 固定套路

1. **套路不是一把抓，而是匹配场景**。比如开会时，你同时在干三件很耗脑的事：听懂对方说什么、判断哪些值得记、还要按六条底线去组织笔记。这时候大脑带宽基本用满了，根本没有余力再去翻一份完整的套路清单。这不是你弱，是几乎所有人在现场速记时都会遇到的瓶颈。**你的套路是「一把抓」的，没有给不同场景配不同颗粒度。** 现场开会、课后整理、专题研究——这三种场景对套路的需求完全不同。你用同一份清单去应付所有场景，自然有些场合会被跳过。
2. 固定套路的精髓不在于「每次都把所有步骤走一遍」，而在于：**你知道哪些步骤存在，然后根据任务大小，有意识地选择这次走哪几步、跳过哪几步。**
3. 固定套路获得有六条路：创建文档、严格执行、使用模型、阶段模型、底层模型、自建模型
4. 固定套路的本质是：**把你当前最好的理解、动作和判断标准沉淀成可重复、可检查、可迭代的东西**

# 及时反馈

1. **反馈的本质不是「多做一个动作」，而是它决定了你前面的努力到底有没有用。**


# 大量重复
1. > **大量重复不是「做很多项目」，而是围绕同一个底层动作，反复做、拿到反馈、调整、再做下一轮。**
