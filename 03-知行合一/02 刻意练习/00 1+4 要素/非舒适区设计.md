## 非舒适区设计六条路（通用版）

### 路一：严格执行 — 把已知标准做满

**适合什么情况**：你已经有套路/清单/SOP，但执行时经常因熟悉而打折扣。

**设计模板**：

```
1. 找出你现有套路里最容易跳过的 1 个动作
2. 下一次练习，把「不跳过这个动作」设为本轮唯一挑战
3. 挑战行写法：> 挑战：这次[动作名]不跳过
```

| 能力 | 例子 |
|---|---|
| 写提示词 | 写完后必须对照你的提示词检查清单，不自以为没问题就跳过 |
| AI 培训讲课 | 每次讲完必须做满复盘三步：学员反应记录 → 哪里卡了 → 下次改哪 |
| 学员辅导 | 每次辅导后必须写下学员卡点判断，不凭感觉模糊过去 |

**判断标准**：不是「做得更好」，而是「不跳步」。

---

### 路二：能力拉满 — 单维度探上限

**适合什么情况**：你觉得自己老在一个水平上晃，想知道当前边界在哪。

**设计模板**：

```
1. 从质量/数量/速度/深度里只选 1 个维度
2. 这次练习在那个维度上不做保留
3. 挑战行写法：> 挑战：[维度名]拉满
```

| 能力 | 拉满维度 | 例子 |
|---|---|---|
| 写提示词 | 质量 | 改到不能再改，每句话都推敲过 |
| AI 培训讲课 | 深度 | 不只讲操作，每个操作都追问「为什么这么设计」 |
| 学员辅导 | 数量 | 一次追问追到学员说「这个我没想过」为止 |
| 做方案 | 完整度 | 不只给结论，把假设、证据、替代方案全写出来 |

**注意**：不要所有维度一起拉满，那会崩溃。只选一个。

---

### 路三：对标最佳 — 用更高标准拉自己

**适合什么情况**：你不知道更高水平长什么样，或觉得自己做得还行。

**设计模板**：

```
1. 找到这个能力至少 3 个高水平案例（作品/人/方法论）
2. 每次练习前花 1-3 分钟扫一眼
3. 问自己：我和它差在哪三个地方？
4. 挑 1 个差距变成本轮挑战
5. 挑战行写法：> 挑战：对标[具体案例]，这次补[具体差距]
```

| 能力 | 最佳实践去哪找 |
|---|---|
| 写提示词 | 找 3 个高质量系统提示词（Anthropic 官方、社区精品）|
| AI 培训讲课 | 找 3 个你佩服的讲师/课程，拆他们的结构和讲法 |
| 学员辅导 | 找 3 个优秀辅导案例（一堂 Candy 里有）|
| 写文档/方案 | 找 3 个你觉得「写得真清楚」的文档 |

**这是最通用的入口**。几乎任何能力都有比你强的人或作品。

---

### 路四：提升 20% — 小步持续拔高

**适合什么情况**：你不想太累，不想冒险，但想每次都进步一点点。

**设计模板**：

```
1. 看上一次练习的结果
2. 在质量/数量/深度/速度里选 1 个维度
3. 这次只比上次多进 20%
4. 挑战行写法：> 挑战：比上篇多[具体动作]，比如多追一层/多改一轮/多压 20%
```

| 能力 | 例子 |
|---|---|
| 写提示词 | 比上个版本多压缩 20% 字数，同样功能 |
| AI 培训讲课 | 比上次多准备 1 个学员可能问的问题 |
| 学员辅导 | 比上次多追问一层「这背后真正的原因是什么」 |

**关键**：20% 是心理门槛。你不会觉得太难，但做完后能力往前挪了。

---

### 路五：永远 60 分 — 打破满意区

**适合什么情况**：你已经做得不错了，身边人也认可，容易停下来。

**设计模板**：

```
1. 做完后问自己一句：如果这个领域最顶尖的人来做，他会做到什么程度？
2. 找到至少 1 个「他能做到但我没做到」的点
3. 把它写成下一篇的挑战
4. 挑战行写法：> 挑战：补上[具体差距]，向[标杆]靠近
```

| 能力 | 例子 |
|---|---|
| 写提示词 | 问：如果 Anthropic 的提示词工程师来做，他会多考虑哪些边界情况？ |
| AI 培训讲课 | 问：如果 Truman 来讲这节课，他会在哪几个点追得更深？ |
| 学员辅导 | 问：最好的领教来辅导这个学员，他会多问哪类问题？ |

**这个策略不需要你真的找到完美标杆**，只需要你承认「我还有差距」。

---

### 路六：最佳实践想象 — 找不到标杆时自己造

**适合什么情况**：你已经在一个小领域领先，找不到够高的真实参照。

**设计模板**：

```
1. 想象一个「这件事做得最牛的人/团队」
2. 写下他会多做的 3 件事
3. 从 3 件里挑 1 件，这次就做
4. 挑战行写法：> 挑战：想象最佳版本会[做什么]，这次我做[具体动作]
```

**只有当你确实找不到真实标杆时才用这一条**。大多数情况下路三（对标最佳）就够了。

## 通用启动流程（任何能力都能用）

当你面对一个新能力，想给它设计非舒适区时，只问三句话：

```
1. 我现在对这个能力最常见的惯性动作是什么？（先识别舒适区）
2. 我有没有现成的对标案例？（有 → 路三；没有 → 路五或路六）
3. 我今天想拉满、想小进步、还是只求不跳步？（选路一/路二/路四）
```

三句话答完，挑战行就出来了。

## 举个例子：假设你要给「AI 培训讲课」设计非舒适区

你现在不一定就要练这个，但我用它展示一下套用方法：

**第一步：识别惯性**
- 惯性：每次按准备的内容讲完，不观察学员反应，不讲完就行

**第二步：找对标**
- 对标：Truman 的课、一堂其他优秀讲师的课
- 差距：他们会在讲到关键概念时停下来问学员「你刚才听到了什么」，而不是一直往下灌

**第三步：选一条路**
- 这次选路四（提升 20%）：> 挑战：这节课至少停 2 次，问学员「你现在理解的是什么」，根据反馈当场调讲法

六条路你不需要全用，每次只挑一条，写进挑战行，就开始。

好，非舒适区的通用设计方法完整讲完了。加上之前清单体笔记的六条具体设计，你现在应该能感觉到：**非舒适区不是「逼自己努力」这一种姿势，而是在六条路里每次挑一条最贴身的。**

回到收束——

1. **笃定感**：现在几分？
2. **现实实操**：仍然几分？
3. **实操提升信心**：有信心从几分推到几分？
