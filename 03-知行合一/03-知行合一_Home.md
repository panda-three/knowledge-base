# 03-知行合一 · Home（产出层）

## 本层定义（准入标准）

> 产出层：**亲身实践过的项目产出与可复用素材**。回答「你做过了什么、能不能复用」。
> 判定口诀：**做过的 → 03**。
> 领域按主题归类；状态（`待应用` → `已应用`）用 YAML `status` 表达，不建状态物理目录。

**准入**：亲身实践（教案/练习/项目/复盘/产物）与可复用素材（提示词/金句/模板）→ 03；素材随领域归位，用 `type: 实践记录` 或 `素材` 标记。

**排除（分流）**：成熟可信的体系/事实 → 01；新想法/假设 → 02。**02 vs 03 一句话分界：02 装「想的」，03 装「干的」。** 同名 ≠ 同性质——02 是设计/构想，03 是实践/产物。

**判定速查（存东西时按顺序问）**：

1. 这是我**做过**的吗？（教案/练习/项目/复盘）→ **03**
2. 这是**一堂官方课 / 经典教科书**吗？→ **01**
3. 都不是（看到的 / 想的 / 不确定）→ **02**，拿不准一律先放 02
4. 实在判不了 → **05 收件箱**

## 从这里开始

- 领域入口见下表；可复用素材随领域归位（`type: 素材`）
- 三库共用同一套领域编号（10/20/30/40/50/60/70/90），沿编号可与 01、02 横向对齐做交叉验证
