# 03-知行合一 · 就近规则（_agent.md）

> 在本文件夹操作时先读本文件。区域规则 > 全局规则，冲突取更严格者。

## 区域定位

03 保存**亲身实践留下的资产**：做过的项目、教案、练习、复盘，以及实践中产出的可复用素材。
本层只回答「做过什么」；层内物理路径只表达两件事：**属于哪个领域 → 服务哪个实践对象**。

## 分类铁律

1. **顺序固定**：先认知阶段定 03，再按实践目的定领域，最后按实践对象定文件夹。
2. **一个层级一个分类轴**：领域之下只按实践对象分；练习、复盘、案例、素材、最佳实践等文档类型，用 YAML `type`、文件名或标签表达，不新建平行分类夹。
3. **按目的，不按工具或题目归类**：看文档直接服务哪件事，不看标题里出现了 AI、教育、案例等名词。
4. **主档唯一**：跨领域文档只保留一个主位置，另一处用双链关联，不复制第二份。
5. **先有文档，再有文件夹**：一篇零散记录先放对应领域根目录；同一对象会持续产生多篇文档，或自带图片、代码、版本包时，才建独立文件夹。
6. **不拿状态建目录**：待应用、已应用、进行中、已完成、归档等状态不进物理路径。

普通笔记最多按「03 → 领域 → 实践对象 → 文档」组织；项目自身的版本包、图片和代码目录可以更深，但不再叠加分类学层级。

## 新文档落位算法

1. **这是外部输入吗？** 是，先走 05；自己直接写的实践记录可直达 03。
2. **这是做过的吗？** 未实践的想法 → 02；敢发学员的成品 → 04；判不了 → 05。
3. **它直接服务哪类实践？** 自我管理/学习 → 10；产品/设计 → 20；AI 技术、工具或自己用 AI → 50；备课/授课/教学复盘 → 60。
4. **它在为哪件持续做的事积累资产？** 放入该实践对象文件夹；没有持续对象，先放领域根目录，不硬造文件夹。
5. **它是什么文档类型？** 写入 YAML 或文件名，不因“复盘/素材/练习”再换文件夹。

## 冲突裁决

- **AI + 教学**：教别人 AI 的教案、授课和复盘 → 60；研究 AI 工具、Agent、提示词本身 → 50。
- **项目专属 + 领域通用**：只服务某项目 → 项目夹；能脱离项目反复调用 → 对应领域的通用实践对象或领域根目录。
- **练习 + 某领域**：练 AI 协作 → 50；练清单体写作 → 10；练儿童教学 → 60。“刻意练习”只是方法，不决定物理位置。
- **同题不同性质**：自己练 AI双三角 → 50；把 AI双三角做成课 → 60。
- **仍有两个候选**：问「下次我会在做哪件事时找它」，选那个位置；另一处加双链。仍判不了 → 05。

## 操作规范

| 操作        | 规则                            |
| --------- | ----------------------------- |
| 新建实践文档    | 按本文件直接落位，不另造“复盘/素材/待应用”等平行夹   |
| 新建实践对象文件夹 | 先检查同义目录；有持续产出、附件或版本包才创建       |
| 移动、合并旧文件  | 每批先列全部「源路径 → 目标路径」清单，经用户确认后执行 |
| 版本文件      | `_vN`、`V0.x`、人工修改版全部保留，不删不并   |
| 迁移后       | 检查附件与双链，更新 Home、总索引及相关 MOC    |
| 删除        | 不擅自删除；重复内容也只列候选，由用户拍板         |
