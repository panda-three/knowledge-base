# 简历交互网站制作流程与提示词

## 01 目标定位

这份简历不适合直接做成传统在线简历，而更适合转化为一个 **简约、交互、作品集化的个人主页**。

网站的核心目标不是堆信息，而是让访问者快速形成三个判断：

1. 我不是普通老师，而是有一线教学场景的 **AI 教育实践者**。
2. 我不是纯产品经理或纯开发，而是能把 **教学经验、知识库、AI 工具和系统开发** 串起来的人。
3. 我有真实项目积累：C 语言学习反馈系统、Obsidian 知识库、Storm AI、教学与开发经历。

推荐的人设表达：

> AI 教育系统搭建型实践者  
> 一线教学场景 × AI 协作方法 × 软件工程能力

推荐网站气质：

- 简约、克制、有系统感
- 像「个人研究室 / AI 教育实验室 / 高级作品集」
- 少用花哨科技蓝、赛博霓虹、模板化卡片
- 关键词：留白、网格、卡片、细线、微交互、低饱和色、清晰信息层级

---

## 02 整体工作流

### Step 1：沉淀需求文档

先把简历大纲转成网站需求文档，不急着写代码。

需求文档建议包含：

- 网站目标：面向招聘方、合作方、教育产品相关机会
- 核心人设：AI 教育系统搭建型实践者
- 访问者路径：
  - 30 秒理解我是谁
  - 2 分钟理解我做过什么
  - 5 分钟愿意进一步联系
- 页面结构：
  - 首屏 Hero
  - 能力模型：双三角模型
  - Anchor Case：C 语言学习反馈系统
  - 项目经历：Obsidian 知识库 / Storm AI
  - 任职经历时间线
  - 作品与方法论
  - 联系方式
- 交互重点：
  - 能力模型可点击展开
  - 项目卡片 hover / 展开详情
  - 时间线滚动出现
  - 移动端保持极简
- 不做内容：
  - 不做复杂后台
  - 不做博客系统
  - 不做过度动画
  - 不做传统 Word 简历网页化

---

### Step 2：设计 UI 原型

不要一上来定稿，先做 2-3 个风格方向。

推荐三个原型方向：

#### 方向一：高级简历型

- 首页像精致个人档案
- 适合投递、面试、正式场景
- 优点：稳、专业、易理解

#### 方向二：系统地图型

- 用「双三角模型」作为视觉中心
- 项目围绕能力模型展开
- 优点：差异化强，能体现系统思维

#### 方向三：案例作品集型

- 用 Anchor Case 开场
- 先证明解决过真实问题，再展示能力
- 优点：更像作品集，适合 AI 教育产品机会

最终推荐：

> 系统地图型 + 案例作品集型混合

首屏不建议写一堆履历，建议这样表达：

> 周磊 / Panda  
> AI 教育系统搭建型实践者  
> 我把一线教学经验、AI 协作方法和软件工程能力，转化为可复用的学习反馈系统、知识库和教育产品原型。

---

### Step 3：根据 UI 原型开发

推荐技术栈：

- Next.js
- Tailwind CSS
- Framer Motion
- shadcn/ui 可选
- Vercel 部署

开发方式：

- 先把所有内容抽成一个 `resumeData` 数据结构
- 页面组件只负责展示，不把文案写死在 JSX 里
- 先完成静态页面，再加微交互
- 动画只服务信息层级，不做炫技
- 移动端优先保证阅读体验

核心模块：

- `HeroSection`
- `CapabilityModel`
- `ProjectShowcase`
- `ExperienceTimeline`
- `WorksSection`
- `ContactSection`

---

### Step 4：审美提升原则

#### 避免

- 过度渐变
- 霓虹科技风
- 满屏图标
- 信息密度过高
- 动画太多
- 像模板站

#### 追求

- 首屏一句话有力量
- 字体层级清楚
- 卡片之间有呼吸感
- 交互轻，不打扰阅读
- 项目经历有「问题 → 方法 → 结果」结构
- 页面整体像一个「可信、安静、有深度的人」

#### 推荐视觉语言

- 背景：米白 / 暖灰 / 深墨色
- 主色：黑、灰、象牙白
- 强调色：克制的琥珀色、苔绿色或电光蓝，只用一点
- 字体：中文用系统黑体或思源黑体，英文用 Inter / Geist
- 布局：12 栏网格、大留白、细线分割

## 03 可直接使用的提示词

### 提示词 1：生成需求文档

```text
你是一名高级产品经理和个人品牌顾问。

我会给你一份简历大纲，请你把它转化为一个「交互式个人简历网站」的需求文档。

目标不是做传统在线简历，而是做一个简约、精美、有高级感的个人作品站。

请输出以下内容：

1. 网站定位
2. 目标访问者
3. 访问者看完后应该形成的核心印象
4. 首页信息架构
5. 每个模块的内容目标
6. 推荐交互方式
7. 不建议做的内容
8. MVP 版本范围
9. 后续可扩展方向

审美要求：
- 克制、简约、有系统感
- 不要赛博朋克、不要廉价科技风
- 强调个人实践、系统搭建能力和 AI 教育场景

这是我的简历大纲：
【粘贴简历内容】
```

请避免：
- 普通模板站
- 花哨科技风

- 信息堆砌

【粘贴需求文档】

### 提示词 3：生成 UI 原型

```text
你是一名前端原型设计师。

请根据下面选定的 UI 方向，生成一个可交互的网页原型方案。

要求：

1. 给出页面整体布局
2. 给出每个区块的视觉描述
3. 给出关键交互
4. 给出移动端适配方案
5. 给出组件拆分
6. 给出首屏文案
7. 给出项目卡片文案结构
8. 给出动画建议

交互要求：
- 能力模型可以点击展开
- 项目经历以卡片展示
- 任职经历用时间线
- 滚动时有轻微动效
- 动画要克制，不要喧宾夺主

审美要求：
- 高级、安静、清晰
- 大留白
- 细线、网格、卡片
- 低饱和色
- 像个人研究室，而不是普通招聘简历

选定方向：
【粘贴 UI 方向】
```

### 提示词 5：审美质检与优化

```text
你是一名非常挑剔的高级设计评审。

请审查下面这个个人简历网站方案，重点从审美、信息层级、个人品牌表达和交互体验上提出修改意见。

请重点检查：

1. 是否像模板站
2. 是否过度科技风
3. 首屏是否能 10 秒内建立人物认知
4. 项目经历是否有说服力
5. 页面节奏是否有呼吸感
6. 交互是否服务内容
7. 移动端是否适合阅读
8. 是否体现「AI 教育系统搭建型实践者」这个定位

请输出：
- 最大的 5 个问题
- 每个问题的修改建议
- 更高级的替代表达
- 可以立刻执行的优化清单

网站方案如下：
【粘贴当前方案或代码截图描述】
```

## 04 默认决策

- 网站主要用于个人品牌、求职、合作机会展示
- 第一版做单页网站即可，不做多页面系统
- 内容以现有简历大纲为基础，但需要重写成作品集语言
- 最终风格应更接近「AI 教育实验室个人主页」，而不是传统简历
- 正式开发前，先完成需求文档和 UI 原型，再进入代码实现

---

## 05 下一步建议

下一步可以从 `简历-终版.md` 出发，先生成第一版《交互式个人简历网站 PRD》，然后再进入 UI 原型阶段。

建议顺序：

1. 用提示词 1 生成 PRD
2. 用提示词 2 生成 3 个 UI 方向
3. 选择一个方向后，用提示词 3 生成原型
4. 用提示词 4 开发网站
5. 用提示词 5 做审美质检
