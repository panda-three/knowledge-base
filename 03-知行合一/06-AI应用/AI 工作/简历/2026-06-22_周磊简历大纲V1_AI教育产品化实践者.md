## 03｜Anchor Case：C 语言刻意练习与学习反馈系统

### 模块目标

这是全简历的峰值记忆点，用来证明“真实教学现场 + AI 教育产品化 + 工程落地”的复合能力。

### 项目定位

面向中职计算机学生的 C 语言学习反馈系统探索，当前处于课堂验证和机制打磨阶段。

### 推荐写法

基于中职 C 语言教学场景，围绕学生“听得懂但做不出、换题不会迁移、错后不知道如何复练”等典型卡点，探索题目数据化、考点标签、错因分析、相似题推荐和 AI 辅助反馈机制，将教师经验转化为可复用的学习反馈系统雏形。

### 项目拆解

| 维度  | 内容                                              |
| --- | ----------------------------------------------- |
| 问题  | 学生听讲时能跟上，但独立做题时不会起手；换题后不会迁移；做错后不知道该补哪类题。        |
| 动作  | 设计 C 语言题目标注体系，拆解重要性、题型、关联考点、解题动作、易错点、相似题、难度等维度。 |
| 产出  | 题目卡模板、标签指南、相似题练习组、推荐引擎需求、AI 辅助反馈方案、系统设计文档。      |
| 价值  | 把一次性的教师经验转化为可复用、可验证、可迭代的学习反馈系统雏形。               |
| 证据  | 后续补样例题目卡、练习组截图、课堂验证记录、系统文档入口。                   |

### 可用 bullet

- 梳理中职 C 语言学习中的典型卡点，包括起手困难、迁移不足、错因不清和复练低效。
- 设计题目标注体系，覆盖题型、考点、解题动作、易错点、相似题、难度和练习意图。
- 沉淀题目卡模板、相似题练习组模板、推荐引擎需求和 AI 辅助反馈方案。
- 探索基于学生画像、练习意图和历史数据推荐“刚好够不着”的练习题。

### 后续证据优先级

1. 样例题目卡
2. 相似题练习组截图
3. 课堂使用场景记录
4. 学生人数、题目数量、阶段性反馈
5. 系统需求文档或 Demo 入口

## 09｜一页版排序建议

正式一页简历建议采用以下顺序：

1. 顶部信息 + 一句话定位
2. 价值主张
3. Anchor Case：C 语言刻意练习与学习反馈系统
4. 支撑项目
5. 核心能力
6. 工作经历
7. 教育背景 / 证书 / 荣誉
8. 证据入口 / 联系方式

不建议采用传统顺序：

> 基本信息 → 教育背景 → 工作经历 → 自我评价

原因：传统顺序会把你重新拉回普通教师简历，弱化“AI 教育场景 + 产品化 + 工程落地”这条差异化主线。
