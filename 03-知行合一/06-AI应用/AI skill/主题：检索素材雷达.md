# 主题：检索素材雷达（Skill 协议草稿 V0.1）

> **一句话定位**：备课时把「要讲什么」转成「去哪里拿什么」——库内库外双通道，素材分级后再组装，缺料明确报警，**不许硬凑**。
> **边界公式**：稳定意图 = 每次备课 / 调研前先想清楚要什么，再动手搜；稳定工作流 = 意图五问 → 库内检索 → 库外 OSCAR → 素材分级 → 组装 + 缺料报警；稳定产物 = 素材检索包。

---

## 0. 什么时候调用（触发条件）

| 触发场景 | 动作 |
|---|---|
| 备课：「备 XX 课」「帮我拉料」 | 强制全流程 |
| 调研 / 做方案需要外部资料 | 走库外 OSCAR 通道 |
| 日常「帮我找找 XX」 | 至少走意图五问 + 分级 |

**前置凭证**：子问题拆解引擎的问题树（有 Q1-Q8 才拉料，避免搜一堆用不上）。

---

## 1. 核心工作流（五步）

### 第一步：检索意图五问（PACK_INTENT）

动手搜之前先答五问：

1. **要什么类型**：模型 / 案例 / 数据 / 金句 / 练习 / 故事 / 反例？
2. **给谁用**：北大清华学生？初中生？家长？——决定深度和语言
3. **什么场景用**：开场（建立兴趣）/ 论证（建立信服）/ 练习（建立能力）/ 收尾（建立记忆）？
4. **什么标准**：真实性要求（L1-L3？）、相关性要求（直接讲这个模型？）
5. **缺了什么**：问题树里哪个子问题现有素材库回答不了？

**输出**：一句话检索需求。例：「为双三角 Q4（因果机制）找 1 个真实企业 AI 落地案例，需 L1-L2 来源，用于论证飞轮机制。」

### 第二步：库内检索（PACK_INSIDE，先内后外）

按序执行：

1. **Home 入口**：01/02/03 的 _Home 看目录地图
2. **目录定位**：按领域子目录找（案例课 / AI技能 / AI教育 / 素材）
3. **YAML 过滤**：type（案例/方法/素材）+ status（**只取已验证 / 已应用**，02 待验证的要标注意）+ tags
4. **related 链顺藤摸瓜**：从命中笔记的 related 字段往上下游摸 1-2 层
5. **状态把关**：取到的素材若 status 非「已验证」，标记「待验证」交给反幻觉 Skill 复核

### 第三步：库外检索（PACK_OUTSIDE，OSCAR 化）

库内不够时，用**你库里已有的 OSCAR 调研法**约束外部检索（不另起炉灶）：

- **O 明确目标**：这次补的问题树哪个子问题？→ 一句话
- **S 缩小范围**：只看哪类信息？先不看什么？（防被信息洪流带走）
- **C 罗列清单**：检索关键词 / 站点 / 信源清单，按「必须看 / 可以看 / 暂时不看」分类
- **A 获取情报**：搜索 / 抓取 / 访谈 / 观察，手段与要拿的信息匹配
- **R 正确判断**：哪些发现最重要、哪些是噪音、哪些结论能支持决策

完整提示词模板见《06_OSCAR 调研提示词》（直接复用，不重写）。

### 第四步：素材分级（PACK_GRADE）

每条命中素材打级：

| 级 | 含义 | 使用规则 |
|---|---|---|
| S | 真实 + 强相关 + 可直接用 | 直接进备课包 |
| A | 真实 + 相关，需加工 | 加工后可用 |
| B | 相关但真实性存疑 / 关联弱 | 只作启发，标 L4/L5，不进关键位置 |
| C | 不相关 / 无法验证 | 弃用 |

### 第五步：组装 + 缺料报警（PACK_ASSEMBLE）

- 按备课包结构组装：教学目标 / 教学主线 / 关键案例 / 互动设计 / 课后练习。
- **缺料报警**：问题树某子问题没有 S/A 级素材支撑 → 明确写进「缺料清单」：缺什么、影响哪个教学环节、建议补法（调研 / 访谈 / 实验）。
- **铁律**：缺料项不许用 B/C 级素材硬填关键位置；缺料清单本身就是下一步行动清单。

## 3. 产物规范

- **素材检索包**：检索需求一句话 + 素材清单（分级 + 来源 + 用途）+ 备课包初稿 + 缺料清单。
- 检索结果默认落备课包文件（03-知行合一/01 AI 教育 对应子目录）；重大调研另出调研报告。
- 每个素材必须带来源和 L 级——这是反幻觉 Skill 的输入，**没有来源的素材不进备课包**。

---

## 4. 使用原则

1. **先内后外**：库里有 1113 篇笔记，先榨干自己的库，再出去搜。
2. **意图不清不搜**：五问答不上来 = 还没想清楚要什么，先回拆解引擎。
3. **缺料要报警，不许硬凑**：S/A 级不够就明说，用 B 级素材填关键位置是对学生撒谎。
4. **OSCAR 是既定通道**：库外检索用你库里已有的 OSCAR 提示词，本 Skill 不重造轮子。
5. **与拆解、反幻觉串联**：问题树是输入，素材分级是过程，事实核查是出口——三关齐了素材才敢上讲台。
