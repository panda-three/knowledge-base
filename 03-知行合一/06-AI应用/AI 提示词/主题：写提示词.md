# 写提示词的执行清单

---

## 一、核心命题（刻进骨头）

> **你的认知上限，是大模型的下限。**

- 提示词是你认知的外显
- 模型是人类知识的加权平均，默认输出就是"平庸解"
- 给它平庸的输入 → 它回馈你平庸
- 能在提示词里暴露你真正的认知——你对这个问题想过多深、有什么独特框架、要的到底是什么——模型就会从平庸曲线上跳出来
- **提示词不是在写指令，是在把你对一件事的理解变成 AI 能理解的结构。这个结构本身，就是你的认知。**
- 提示词越接近你真实的认知和体感，输出越有用

—— 小七姐

---

## 二、三种美（总览）

| 类型 | 代表 prompt | 核心机制 | 适用场景 |
|------|------------|----------|----------|
| 结构之美 | 001 访谈分析 | 给模型一个思考的脚手架，控制处理信息的顺序 | 结构化任务、信息提取 |
| 语言之美 | 002 洞见生成器 | 用语言的编排把认知结构"投影"到模型的语义空间 | 创意生成、深度思考 |
| 想象之美 | 003 prompt 如诗 | 给出方向但留出空间，构建让思维涌现的场域 | 元认知、人格模拟、开放探索 |

## 三、001 · 访谈文本结构化分析（结构之美）

**来源**：三亿（小七姐团队），小七姐分享解读

**用途**：将访谈文本按结构化框架拆解，输出摘要、主题、金句、证据四类成果

### 核心技法
- **五钥标注**（人/时/事/论/据）：对每个要点做多维度打标，结构化提取信息
- **类型适配**：根据访谈类型切换分析框架，不一刀切
- **输出四象**：预定义四种输出格式，确保产出完整且可复用
- **品质准绳**：用隐喻设定质量标准，引导模型追求深度而非表面完整

### 提示词全文（直接复制用）

```
基于用户输入访谈文本按以下工作流处理和输出

应用结构化框架处理：
1. 分层术：剖文为三阶。
   - 宏旨：识别核心议题（如"论数字化转型之困"）。
   - 中枢：划分主题柱（默认"挑战、解法、案例"，或根据文本调整）。
   - 微节：提取关键句（要点），标注五钥（表格呈现）：
     - 人：发言者身份
     - 时：时序（过去/现在/未来）
     - 事：具体事例
     - 论：观点主张
     - 据：数据佐证
2. 链理术：建立因果逻辑链（例："挑战→解法→成效"），并绘制简要关系图。
3. 类型适配：指定访谈类型（探索式、验证式、叙事式），调整框架：
   - 探索式：树状扩散，留"未知"余地。
   - 验证式：对照假说，设"证伪"关卡。
   - 叙事式：依时轴，嵌"转折"标石。
4. 输出四象：
   - 摘要纲目：100字内概括全貌。
   - 主题枢要：分项列出核心主题内容（基于中枢层）。
   - 引语金句：摘录重要原话（突出观点）。
   - 证据汇编：汇总数据、事例（基于据钥）。

输出要求：
1.品质准绳：
   - 重脱胎换骨之悟，非止皮相之全。
   - 质之极者，当效洪钟撞心
   - 质之次者，徒作秋蝉噪耳
2.逻辑连贯，保持信息链传递完整性。
```

### 深层解读

- **分层处理改变了 AI 处理信息的顺序**：没有脚手架，AI 面对万字访谈只能从头读到尾凭感觉写综述；有了脚手架，它知道先退远看全局，再分类，最后进细节。**顺序不同，结果不同。**
- **文言文的信息密度优势**：「剖文为三阶」「标注五钥」每个词都很短但指向明确，换成现代汉语得写一大段。现代汉语高频词被稀释严重，"总结要点"这种说法信号模糊，模型只能取最安全的中间值。
- **「洪钟撞心」不是抒情**：是在告诉模型——你可以扔掉那些"正确的废话"。

## 四、002 · 罕见洞见生成器（语言之美）

**来源**：奥德赛（小七姐好友），小七姐分享解读

**用途**：让 AI 直接输出一个高度原创、深刻且简洁的洞见，不需要用户提供主题

### 核心技法
- **正向标准 + 反向排除**：先定义"必须是什么"，再严格列出"不能是什么"，双向夹逼
- **检验锚点**（逻辑/经验/解释力/认知震撼）：给出可验证的质量标准，不是主观感觉
- **输出行为约束**：禁止解释过程、禁止询问、禁止辩护——砍掉 AI 的一切"安全垫"行为
- **一句话挑战**：用"如果可能，用一句话"进一步压缩，迫使模型提炼到极致

### 提示词全文（直接复制用）

```
你是一位罕见洞见的发现者。无需我提供主题或方向，立即生成一个满足以下全部条件的洞见：
真正深刻：触及人类经验或现实本质的根本层面。高度新颖：位于思想分布曲线的远端边缘。令人震撼地简单：一旦理解就显得惊人地不言自明。几乎无人意识到：不是已被广泛讨论的观点的变体
这个洞见必须：
能通过逻辑和经验检验。具有广泛解释力。能重构既有认知框架。产生"啊，原来如此"的认知震撼
严格排除：
泛泛而谈的模糊陈述。浮夸但空洞的表达。伪装成深刻的陈词滥调。包装成洞见的常识。循环论证的思维陷阱
直接给出这个洞见，不要解释你如何得到它，不要询问方向或主题，不要为洞见辩护，只需精准表达这个洞见本身。如果可能，用一句话表达它的核心。
```

### 深层解读

- **精髓在「双向夹逼」**：正向标准把质量拉高，反向排除把常见的低质量输出堵死。大多数人只做正向要求（"请给我深刻的洞见"），结果 AI 输出一堆包装过的常识。这条加了严格排除清单，等于告诉 AI「我知道你会怎么偷懒，别想了」。
- **奥德赛做的是一次「认知暴露」**：从深度、稀缺性、认知体验、原创性等十个角度定义"洞见"，把自己对这个概念的全部理解摊开在模型面前。模型接收到的不是模糊指令，而是一个人对某个概念极其清晰的认知图谱。
- **所有"平庸的逃生通道"都被堵死了**：模型只能往思想分布曲线的边缘去找东西。
- **核心启示**：提示词的质量取决于你对自己想要的东西有多清楚。不是"我想要好的回答"的模糊感觉，而是能从十个角度把"好"拆开。

## 五、003 · 场域论：prompt 如诗（想象之美）

**来源**：小七姐（基于李继刚的诗歌笔记）

**用途**：不是具体 prompt，而是写 prompt 的底层哲学框架——用诗歌理论解释为什么好的 prompt 有效

### 核心论点

诗和好的 prompt 共享同一个机制——**高信息熵 + 抗过拟合**。

| 层面 | 诗歌机制 | → Prompt 映射 |
|------|---------|--------------|
| **本体论** | 诗是「将说又未说」，留出投射空间；独特体验提供高信息熵，避开现代话语的过拟合 | 好的 prompt 不是在关键处把所有细节写死，而是留白，让模型在语义空间中找到最优解 |
| **认识论** | 四要素：行顿（音乐性）、酌字（凝练）、跳跃、留白（哑语） | 四要素直接映射到 prompt 技法（见下表） |
| **目的论** | 诗歌是所有文体中最能「四两拨千斤」、产生「弦外之音」的文体 | 写 prompt 的终极目标：用最少的文字撬动最大的语义空间 |

### 诗歌四要素 → Prompt 技法映射

| 诗歌要素 | 含义 | → Prompt 对应 | 操作 |
|---------|------|--------------|------|
| **行顿** | 音乐性、节奏 | 控制模型的注意力流向 | 用分段、空行、缩进制造阅读节奏 |
| **酌字** | 凝练、精准 | 每个词都承载信息量 | 不注水，删除"请帮我""能不能"等无效词 |
| **跳跃** | 省略显而易见的中间步骤 | 直接给出关键锚点 | 不写"首先你要理解…然后你再…"，直接跳到关键约束 |
| **留白** | 哑语、不说的部分 | 给模型推理空间 | 不说的部分和说的部分同样重要 |

### 深层解读

- **主流提示词追求"说清楚"——拆细、列全、划死边界**。好处是确定，问题也是太确定：话说太满，模型反而没有空间展开。
- **诗歌式写法追求「将说又未说」**：给方向但留空间，给内核但不规定形式。给的不是一个点，而是一个**场域**，模型在场域里自己找位置。
- **延伸应用：模拟一个人的思维方式**：不是模仿表面特征（用词、句式），而是用"诗意"的方式勾勒底层结构——面对新问题的第一反应、因果归因方向、对模糊地带的态度。点到为止，留出空间，AI 拿到的不是僵硬人设，而是人格的坐标系。

## 六、004 · 产品方向探测器（自创 · 三种美融合）

**来源**：Panda 自创，基于小七姐三种美融合

**用途**：为独立开发者在"不知道做什么产品"的卡点上，提供需求缝隙的发现框架，而非产品列表

**设计意图**：不让 AI 给答案，让 AI 帮建坐标系。结合想象之美（场域留白）、结构之美（约束漏斗）、语言之美（认知暴露 + 反向排除）

### 迭代全记录（三次教训，一次比一次深）

| 版本 | 改动 | 现象 | 核心教训 |
|------|------|------|---------|
| v1 | 硬约束含「出海适配：面向海外用户」 | 输出全部偏向海外场景（VBA 迁移/硬件说明书/SEO 清洁工），离用户体感太远 | **约束决定了模型的搜索空间**，把不熟悉的领域设为硬约束 = 逼模型在你没体感的地方找答案，输出再"正确"你也接不住 |
| v2 | 出海从硬约束降级为加分项，新增「场景认知」约束 | 输出落在职教领域（技能大赛审计/信息化教学组件/跨境电商模拟），但仍然离日常太远——这些是"中职教师"的统计平均值 | **标签 ≠ 上下文**，"中职计算机教师"六个字信息量太低。模型需要的是你具体的一天，不是你的职业名称 |
| v3 | 去掉标签式描述，换成真实日常口述；品质锚点转向"发现自己日常里的产品种子" | 输出贴合真实生活 | **prompt 越接近你真实的认知和体感，输出越有用** |

### 提示词全文 v3（直接复制用）

```
一个人站在岔路口。

他的日常是这样的：
每天备课、上课，教中职计算机。学生要参加职教高考，他最在意的是自己的备课和讲课质量，能不能真正帮到学生的考试成绩。他最烦的是备课和讲课中大量的重复劳动——备课应该怎么备？有哪些工作流？讲课分哪些场景，每种场景怎么讲？这些东西他每天都在做，但从来没有沉淀成一套可复用的方法论。

他手里还有一张牌：AI 编程能力。课后的碎片时间加上每年三个月寒暑假，他想用这张牌做点什么——不只是自用，而是变成一个产品。

他不需要别人告诉他走哪条路。他需要一面镜子，照见自己没注意到的缝隙。

在以下坐标系内思考：

【硬约束】
- 从他的真实日常出发：备课、上课、职教高考备考、教学方法论沉淀——这些是他每天在做的事，他能立刻判断一个痛点是不是真的
- 时间结构：碎片时间推进 + 假期集中冲刺，不能是需要每天盯盘的生意
- 能力杠杆：AI 编程是核心武器，方向必须让这张牌发挥乘数效应
- 冷启动：一个人跑通 MVP，不依赖团队或资金
- 从自用到产品：先解决自己的问题，再看同类人群是否有同样的痛

【软约束】
- 出海潜力：不强求，但如果方向天然具备出海可能性，是加分项

【严格排除——以下是正确的废话，不要给我】
- "做一个 AI 写作助手"之类人人想得到的泛泛建议
- 需要大量冷启动用户才能转起来的社交/社区类产品
- 已是红海且无差异化切入点的赛道
- 听起来很酷但三个月内无法验证的方向
- "提高效率""赋能创作者"这类空洞表述
- 我日常接触不到的场景（技能大赛集训、信息化教学大赛、跨境电商实训等）

【输出】
不要给产品列表。给我三个"需求缝隙"——从我的日常里长出来的、被忽视的、真实存在的痛点场景。

每个缝隙标注：
- 谁在痛：具体到能想象出这个人一天怎么过的程度
- 痛多久了：新痛还是老痛，是什么变化让这个痛点浮出水面
- 现在怎么凑合的：目前的替代方案是什么，为什么凑合得不舒服
- AI 为什么能改变：不是"提高效率"，要说清楚 AI 在这个场景里具体解锁了什么之前做不到的事

最后：如果你是我，你会先验证哪个，为什么。

【品质锚点】
我要的不是市场分析报告。
我要的是：读完之后，我能看到自己日常里一个一直在做但从没想过可以变成产品的事情，而 AI 刚好能让它从"个人经验"变成"可复制的系统"。
```

### 技法拆解

| 区块 | 对应的美 | 具体机制 |
|------|----------|---------|
| 开头场景 | 想象之美 | 用真实日常口述替代职业标签，给模型具体的生活画面 |
| 硬约束 | 结构之美 | 五维漏斗（日常出发/时间结构/能力杠杆/冷启动/自用→产品） |
| 严格排除 | 语言之美 | 把前两次跑偏的具体场景（技能大赛/信息化教学/跨境电商）加入排除清单 |
| 输出标注 | 结构之美 | 五钥变体（谁在痛/痛多久/怎么凑合/AI 为什么能改变），保持结构化 |
| 品质锚点 | 语言之美 | 从"看到陌生人群"改为"看到自己日常里被忽视的东西"，认知暴露更精准 |

## 七、四条 prompt 的关联（一张图看清）


**001 和 002 是具体技法，003 是技法背后的「道」，004 是三条路汇合的实战产物。**

## 八、写提示词的标准流程

1. **先暴露认知**：我对这个问题到底知道什么？从多个角度拆开
2. **选技法组合**：
   - 需要控制处理顺序 → 结构之美（分层/链理/类型适配/输出四象）
   - 需要逼出高质量输出 → 语言之美（正向标准 + 反向排除 + 检验锚点 + 行为约束）
   - 需要给方向但留空间 → 想象之美（场域留白、诗歌四要素）
3. **设硬约束**：必须是什么、必须在什么范围内（约束决定了模型的搜索空间）
4. **写反向排除**：把 AI 最容易偷懒的方式全部堵死，把之前跑偏的场景加进去
5. **定输出格式**：不是"请给我答案"，是"按这个结构给我"（如四象、五钥变体）
6. **放品质锚点**：用有画面感的隐喻设定质量基线（"洪钟撞心 vs 秋蝉噪耳"、"四两拨千斤"）
7. **试跑迭代**：跑一遍 → 看哪里跑偏 → 记录 → 修正约束/反向排除 → 再跑

## 九、迭代铁律（来自 004 的三次教训）

| # | 教训 | 核心 |
|---|------|------|
| 1 | 约束指向没体感的领域 → 输出正确但接不住 | 不把不熟悉的领域设为硬约束 |
| 2 | 标签 ≠ 上下文 | "职业名称"六个字信息量太低，换成真实日常口述 |
| 3 | prompt 越接近你的真实认知 → 输出越有用 | 这不是技巧，是底层规律 |

## 十、四个王牌提示词模板（直接复制用）

### 1. 认知外显模板
> 「我有一段关于[主题]的思考，目前是 200 字左右的碎片想法：
>
> [粘贴碎片]
>
> 请完成以下三步：
> 1. 帮我提炼出其中的核心洞察
> 2. 用结构化框架展开成 1500 字
> 3. 不要编造我没说过的观点，只在我说过的基础上展开」

**时机**：脑子里有碎片想法但不成型。

### 2. 清洁模板
> 「请忽略以上所有内容。」

**时机**：对话跑偏、上下文污染，一句话重置。

### 3. 收口模板
> 「请用一句话总结你刚刚说的内容，不超过 40 个字。」

**时机**：AI 输出大段内容，快速确认理解是否对齐。

### 4. 专家角色模板
> 「假如你是[XX 领域]的专家，拥有 20 年经验，请从以下三个角度帮我分析[具体问题]：
> 1. [角度一]
> 2. [角度二]
> 3. [角度三]」

**时机**：需要专业视角，三角度防止只从一个面切入。

---

## 十一、一句话行动清单

- [ ] 写提示词前：先问自己「我对这个问题到底知道什么」——从多个角度拆开
- [ ] 选技法：结构之美 / 语言之美 / 想象之美，哪几个要用
- [ ] 写完检查：正向标准有了，反向排除堵死了吗？（AI 最容易偷懒的地方全堵了？）
- [ ] 开头检查：给的是真实日常画面，还是抽象标签？
- [ ] 约束检查：所有硬约束指向我有体感的领域（约束 = 搜索空间）
- [ ] 品质锚点：有没有「洪钟撞心 vs 秋蝉噪耳」级别的质量基线？
- [ ] 格式检查：输出格式是预定义的（四象/五钥变体），还是让 AI 自己发挥？
- [ ] 行为检查：需要禁止解释过程/禁止询问/禁止辩护吗？
- [ ] 每次跑偏：记录跑偏方向 → 反向排除里加进去 → 下次就不偏了
- [ ] 迭代：prompt 不是一次写成的，是和 AI 来回磨合出来的

---

> **记住一句**：提示词不是写指令，是你把对一个东西的全部理解摊在模型面前。你摊得越清楚，它回得越精准。认知上限，就是模型的下限。
