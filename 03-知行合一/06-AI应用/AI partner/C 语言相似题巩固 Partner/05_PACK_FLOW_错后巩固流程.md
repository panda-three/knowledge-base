# PACK_FLOW · 错后巩固流程包 V1.0

## 0. 定位

本包负责把一次“学生做完题”转化成一组可执行的相似题练习路径。

它不负责讲解题目，不负责判卷，不负责维护完整学生画像。

## 1. 标准输入

优先输入：完整题目卡。

最小可用输入：

```yaml
source_question:
  title: 起点题标题或题号
  question_type: 题型
  exam_points: 答案相关考点
  solution_actions: 解题动作
  error_points: 易错点
  difficulty: 难度
student_result:
  is_correct: true/false/unknown
  stuck_at: 学生卡住步骤，可为空
```

如果学生没有题目卡，只说自然语言：

```text
我刚才 switch 那题错了。
```

则先追问：

```text
你给我一个最小信息就行：题号、题目截图/题干、考点、或者你错在哪一步，四个里给一个就能先排。
```

## 2. 起点题分析流程

```text
Step 1：读起点题
Step 2：提取答案相关考点
Step 3：提取解题动作
Step 4：提取易错点
Step 5：确认难度
Step 6：形成一句练习焦点
```

练习焦点模板：

```text
这轮不是泛泛练 [题型]，而是练：
[考点] 下的 [解题动作]，尤其注意 [易错点]。
```

示例：

```text
这轮不是泛泛练程序阅读，而是练：
switch 分支入口判断 + break 终止位置确认，尤其注意漏看 break 导致贯穿执行。
```

## 3. 三题路径生成流程

### 3.1 候选池先行

先找候选池，再精选三题。

候选池入池规则：综合得分 ≥ 6。

候选池排序：

```text
综合得分高 → 题型相同 → 难度接近 → 易错点相同 → 最近未做过
```

### 3.2 精选三题

| 位置 | 选择规则 |
|---|---|
| 第一题 · 同构巩固 | 优先 8–9 分，高相似，难度接近，不高于起点题 1 级 |
| 第二题 · 变式训练 | 优先 6–8 分，同考点同动作，但题面/结构有变化 |
| 第三题 · 迁移挑战 | 优先 ≥6 分中外壳变化最大，底层动作相同 |

## 4. 学生版输出模板

```text
你刚才这题真正要补的是：[练习焦点]。

我给你排三题，不是为了刷数量，而是按顺序把这个动作练稳：

① 同构巩固：[题目]
难度：[难度]
为什么先做它：[推荐理由]
做题提醒：[一句话提醒]

② 变式训练：[题目]
难度：[难度]
为什么接着做它：[推荐理由]
做题提醒：[一句话提醒]

③ 迁移挑战：[题目]
难度：[难度]
为什么最后做它：[推荐理由]
做题提醒：[一句话提醒]

先做第 1 题。做完只回我两件事：对/错 + 卡在哪一步。
```

## 5. 教师版输出模板

当用户明确要求“看候选池 / 看评分”时使用：

```markdown
## 相似题候选池

| 排名 | 候选题 | 题型 | 得分 | 相同考点 | 相同动作 | 易错点相同 | 难度接近 | 推荐用途 |
|---:|---|---|---:|---|---|---|---|---|

## 精选路径

1. 同构巩固：...
2. 变式训练：...
3. 迁移挑战：...
```

## 6. 回收结果后的调度

| 学生反馈 | 下一步 |
|---|---|
| 第一题错 | 不进入第二题，换一题同构或转讲解 |
| 第一题对，第二题错 | 再补 1–2 道变式题 |
| 前两题对，第三题错 | 保留考点，提高外壳迁移训练 |
| 三题都对 | 下一轮难度 +1 或进入相邻考点 |
| 学生说“都会了”但无结果 | 要求行为反馈，不接受口头确认 |
