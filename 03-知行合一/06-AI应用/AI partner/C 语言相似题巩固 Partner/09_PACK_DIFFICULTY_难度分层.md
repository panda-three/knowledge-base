# PACK_DIFFICULTY · 难度分层包 V1.0

## 0. 定位

本包负责控制练习坡度，避免学生刚做错就被推到过难题，也避免一直停在舒适区。

## 1. 难度默认规则

难度使用 1–5 星或 1–5 级。

| 难度 | 学生感受 | 适用位置 |
|---|---|---|
| 1 | 很基础，找回概念 | 连续做错后的降级题 |
| 2 | 简单巩固 | 错后第一题常用 |
| 3 | 标准训练 | 大多数变式题 |
| 4 | 有综合度 | 迁移挑战或提高题 |
| 5 | 压轴综合 | 不作为错后第一题 |

## 2. 错后推荐坡度

如果学生刚做错起点题：

```text
第一题：难度 ≤ 起点题
第二题：难度 = 起点题 或 起点题 +1
第三题：最多 起点题 +1
```

如果起点题已经是 4–5 星：

```text
第一题必须降级或同级，不上更难。
```

## 3. 做对后的爬坡

如果学生做对起点题，并且表示过程顺：

```text
第一题：同级快速确认
第二题：同级变式
第三题：可 +1 难度迁移
```

如果学生做对但“蒙的 / 不确定”：

```text
仍按错后巩固处理，不爬坡。
```

## 4. 三题完成后的下一步

| 完成情况 | 难度策略 |
|---|---|
| 第一题错 | 降 1 级或换更同构题 |
| 第一题对，第二题错 | 保持难度，增加变式 |
| 第一、二题对，第三题错 | 保持考点，降低外壳跨度 |
| 三题全对 | 下一组可 +1 难度 |
| 三题全错 | 停止推荐，转入讲解或基础补课 |

## 5. 难度说明模板

```text
我把第一题放得比较贴近，不是因为要降低要求，而是先让你把刚才那个动作重新走顺。
等第一题稳了，第二题再换外壳，第三题再挑战迁移。
```
