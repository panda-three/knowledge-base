# C语言考点指南

> 核心判断：考点不是目录，考点是推荐相似题的依据。
> 这份指南回答三个问题——这道题在考什么、学生要做什么动作、怎么找到同类题。
> 打标签时对照这份指南，不凭感觉。

## 一、使用定位

1. 这份指南用于给 C 语言题目打**考点标签**
2. 这份指南也用于寻找**关联性最高的相似题**
3. 题目整理时，优先标注"学生要练什么动作"
4. 每道题至少标 4 类标签：
    - **题型标签**：选择、判断、填空、程序阅读、程序填空、综合题
    - **知识考点标签**：数组、循环、函数、文件、结构体等
    - **解题动作标签**：追踪变量、判断边界、匹配格式、补参数等
    - **易错点标签**：少 `&`、漏 `break`、下标越界、类型转换等
5. 相似题优先看**解题动作**是否相同
    - 同知识点但动作不同 → 中相似
    - 同动作但知识点不同 → 迁移练习

## 二、考点详解

### 2.1 程序基础（§3–§4）

**3. 计算机语言与算法基础**
- 计算机语言分类
    - **机器语言**：由 0 和 1 组成，计算机可直接识别
    - **汇编语言**：用助记符表示机器指令
    - **高级语言**：接近自然语言，需要编译或解释
- C 语言定位
    - C 语言属于**高级语言**
    - C 语言兼具高级语言和底层操作能力
    - 常考"C 语言不是机器语言"
- 程序与程序设计
    - **程序**是一组有序指令
    - **程序设计**是分析问题、设计算法、编写代码、测试维护
    - 考题常问程序设计的一般步骤
- 算法概念
    - 算法是解决问题的**步骤**
    - 算法必须有输入、输出、确定性、有限性、有效性
    - 常见表示方法：自然语言、流程图、伪代码、程序语言
- 三种基本结构
    - **顺序结构**：按语句顺序执行
    - **选择结构**：根据条件选择路径
    - **循环结构**：重复执行某些语句
- 拿分动作
    - 看到流程图 → 先判断起止框、处理框、判断框
    - 看到算法题 → 先找输入、处理、输出
    - 看到结构题 → 先判断属于顺序、选择还是循环

**4. C 程序设计概述**
- C 程序基本结构
    - 常见结构：预处理命令、主函数、函数体
    - `#include <stdio.h>` 用于引入标准输入输出库
    - `main` 是程序执行入口
- 注释
    - `/* ... */` 多行注释
    - `//` 单行注释
    - 注释不参与程序运行
- 编译运行过程：编辑 → 编译 → 连接 → 运行
- 格式特点
    - C 语言区分大小写
    - 语句通常以分号结束
    - 花括号表示复合语句或函数体
- 易错标签：`main` 大小写错、漏分号、头文件写成普通语句

### 2.2 数据类型与表达式（§5、§9–§10）

**5. 数据类型、常量与变量**
- 基本数据类型
    - **整型**：`int`，用于整数
    - **实型**：`float`、`double`，用于小数
    - **字符型**：`char`，用于单个字符
- 常量
    - 整型常量如 `10`、`-3`
    - 实型常量如 `3.14`、`2.0`
    - 字符常量用单引号，如 `'A'`
    - 字符串常量用双引号，如 `"A"`
- 符号常量：`#define PI 3.14` 定义，不能被赋值改变
- 变量
    - 使用前一般要先定义，格式是"类型名 变量名"
    - 初始化是在定义时给初值
- 标识符
    - 由字母、数字、下划线组成
    - 不能以数字开头，不能使用关键字，区分大小写
- 转义字符：`\n` 换行、`\t` 制表、`\\` 反斜杠、`\'` 单引号、`\"` 双引号
- 易错标签：单双引号混用、变量未初始化就计算、标识符以数字开头、`=` 当数学等号

**9. 运算符与表达式**
- 算术运算：`+ - * / %`，整数除整数结果仍为整数，`%` 只能用于整数
- 自增自减：`++i` 先加再用，`i++` 先用再加
- 赋值运算：`=` 是赋值不是判等，复合赋值如 `a += b`
- 逗号表达式：从左到右，整个表达式的值是最后一个的值
- 条件运算符：`条件 ? 表达式1 : 表达式2`
- 类型转换：自动向更高精度转换，强制转换格式 `(int)x`
- `sizeof`：求类型或变量占用字节数
- 易错标签：前置后置自增混淆、整除误当小数除法、`%` 用在实数、逗号表达式取错最终值

**10. 关系运算与逻辑运算**
- 关系运算符：`>` `<` `>=` `<=` `==` `!=`，结果为 1 或 0
- ⚠️ `a < b < c` 在 C 中不等于数学写法，判断区间应写成 `a < b && b < c`
- 逻辑运算符：`!` 非、`&&` 与、`||` 或
- 真假规则：0 为假，非 0 为真
- 短路规则：`&&` 左边为假右边不算，`||` 左边为真右边不算
- 易错标签：`=` 和 `==` 混用、区间判断写成连续关系式、忽略短路

### 2.3 输入输出（§6–§8）

**6. 基本语句与顺序结构**
- C 语句类型：空语句（只有一个分号）、表达式语句、函数调用语句、复合语句（`{}` 包住多条）
- 顺序结构：程序按语句从上到下执行，变量值以后执行语句为准
- 字符输入输出：`getchar()` 输入、`putchar(ch)` 输出，字符可按 ASCII 码参与运算
- 大小写转换：小写转大写常用 `ch - 32`，大写转小写 `ch + 32`
- 拿分动作：读顺序结构题逐行写变量新值、遇到字符运算联想到 ASCII 码、遇到复合语句看花括号范围

**7. printf 格式化输出**
- 基本格式：`printf("格式控制", 输出项);`，格式控制符与输出项对应
- 常用格式字符：`%d` 整数、`%f` 小数、`%c` 字符、`%s` 字符串
- 输出宽度：`%5d` 宽度 5 右对齐，`%-5d` 左对齐，宽度不足按实际输出
- 小数位数：`%.2f` 保留 2 位，`%7.2f` 总宽 7、小数 2 位
- 易错标签：格式符和变量类型不匹配、忽略输出宽度、忽略小数保留位数

**8. scanf 格式化输入**
- 基本格式：`scanf("格式控制", 地址表);`，普通变量通常要加 `&`
- 常用格式字符：`%d` 整数、`%f` 输入 float、`%lf` 输入 double、`%c` 字符、`%s` 字符串
- 输入分隔：多个非字符数据可用空格/回车/Tab 分隔，格式串中的普通字符必须原样输入，`%c` 会读取空格或回车
- 修饰符：宽度修饰符限制读取字符数，`*` 跳过对应输入项
- 易错标签：漏写 `&`、`%f` 和 `%lf` 混淆、`%c` 误读前一个回车、格式串写了逗号但输入没输入逗号

### 2.4 选择结构（§11–§12）

**11. if 选择结构**
- 单分支 if：`if (条件) 语句;`，不加花括号只控制一条语句
- 双分支 if-else：两个分支只能执行一个
- 多分支 if-else-if：从上到下依次判断，一旦成立后面不再判断
- if 嵌套：`else` 总与最近的未配对 `if` 配对，花括号可改变配对范围
- 常见题型：判断正负数、奇偶数、成绩等级、字符分类、闰年、分段函数
- 拿分动作：先看条件表达式真假 → 再看 if 控制几条语句 → 嵌套题画出 if-else 配对
- 易错标签：if 后误加分号、多条语句未加花括号、else 配对错误、多分支顺序安排错误

**12. switch 选择结构**
- 基本形式：`switch(表达式)` 根据表达式值选择 case，`default` 表示没有匹配时执行
- 使用规则：switch 表达式常为整型/字符型/枚举型，case 后必须是常量表达式，case 值不能重复
- ⚡ break 规则：`break` 用于跳出 switch，没有 `break` 会贯穿执行后续 case
- 常见题型：成绩等级、菜单选择、四则运算、月份或星期判断、折扣或收费等级
- 拿分动作：先确定 switch 表达式值 → 找到匹配 case 入口 → 从入口往下执行直到遇到 break 或结束 → 记录变量最终值
- 易错标签：忘记 break 的贯穿效果、default 位置不等于最后才执行、case 后写变量范围、switch 表达式使用实型

### 2.5 循环结构（§13–§20）

**13. 递推法与穷举法**
- 递推法：用前一个结果推出后一个，核心是找初值和递推公式，常见于斐波那契、分数数列、小球反弹
- 穷举法：把可能情况逐个试一遍，核心是控制循环范围和筛选条件，常见于百钱买百鸡
- 拿分动作：递推题先写初值再找每轮如何更新，穷举题先找变量范围再写筛选条件
- 易错标签：递推初值错、更新顺序错、穷举范围过大或漏情况

**14. while 循环**
- 基本形式：`while(条件) 循环体;`，先判断条件再执行，条件一开始为假则一次也不执行
- 常见用途：累加、阶乘、输出指定次数字符、人口增长、素数判断
- 拿分动作：找循环变量初值 → 判断循环继续条件 → 追踪循环体中变量变化 → 看循环变量是否更新
- 易错标签：死循环、循环次数多算或少算、循环结束时变量值判断错

**15. do-while 循环**
- 基本形式：`do { 循环体; } while(条件);`，先执行再判断，至少执行一次
- 与 while 区别：while 可能一次不执行，do-while 至少一次，结尾 `while` 后面要分号
- 常见用途：累加和、反复输入直到满足条件、求整数各位数字之和
- 易错标签：忘记最后分号、忽略至少执行一次、条件判断位置看错

**16. for 循环**
- 基本形式：`for(初始化; 条件; 更新) 循环体;`，初始化只执行一次，每轮先判断条件 → 执行循环体 → 更新
- 常见用途：输出连续整数、求 1 到 n 的和、阶乘、按规律输出奇数或偶数
- 灵活形式：三个表达式都可省略但分号不能省，多个初始化或更新用逗号表达式，循环体为空时注意分号
- 拿分动作：先写循环变量初值 → 每轮判断条件 → 记录执行次数 → 最后看循环结束时变量值
- 易错标签：`i < n` 和 `i <= n` 混淆、for 后误加分号、更新表达式方向写反

**17. 循环次数与文本输出**
- 循环次数分析：固定范围题看起点/终点/步长，嵌套循环次数通常是内外次数相乘或累加
- 文本作图：外层控制行数，内层控制每行列数，空格和星号分开循环输出
- 常见图形：矩形、直角三角形、倒三角形、右对齐三角形、对称图形
- 拿分动作：先数行 → 再数每行空格 → 再数每行字符 → 最后检查换行位置
- 易错标签：外层和内层作用混淆、`printf("\n")` 位置错误、空格数和星号数对应关系错

**18. 累加、累乘与素数**
- 累加：累加器初始化为 0，每轮 `sum += 项`
- 累乘：累乘器初始化为 1，每轮 `product *= 项`，阶乘题常用
- 正负交替级数：用变量 `sign` 每轮乘 `-1` 或根据奇偶决定正负
- 素数判断：只能被 1 和自身整除，从 2 试除到 `n-1` 或 `sqrt(n)`，找到一个因子即可判定不是素数
- 输出多个素数：外层枚举候选数，内层判断是否为素数，计数器控制每行输出个数
- 易错标签：累加器未初始化、累乘器初始化为 0、素数判断把 1 当素数、内层 break 位置错误

**19. 循环嵌套**
- 基本概念：外层循环执行一次，内层循环完整执行一轮
- 常见题型：矩阵输出、乘法口诀表、嵌套累加、二重枚举
- 拿分动作：先确定外层变量控制什么 → 内层变量控制什么 → 用表格写每轮变量组合 → 输出题检查换行位置
- 易错标签：内层变量未重新初始化、break 只跳出一层循环、continue 只影响当前层本轮

**20. 转移语句**
- break：可跳出 switch，可提前结束当前层循环，嵌套循环中只跳出最近一层
- continue：跳过本轮剩余语句，直接进入下一轮循环判断或更新，不会结束整个循环
- goto：无条件跳转到标号位置，一般不推荐使用
- 拿分动作：遇到 break 找它跳出哪一层，遇到 continue 跳过后面哪些语句，遇到 switch 看 break 是否防止贯穿
- 易错标签：把 continue 当 break、以为 break 能跳出所有嵌套循环、忽略 switch 中 break 的作用

### 2.6 数组（§21–§25）

**21. 一维数组基础**
- 定义：格式如 `int a[10];`，元素个数必须明确
- 下标：从 0 开始，长度为 n 的数组有效下标是 `0 ~ n-1`
- 初始化：可整体初始化或部分初始化（未赋值元素通常为 0），初始化时可省略长度
- 常见题型：输出满足条件的元素、计算数组元素和、判断数组是否对称、统计满足条件的个数
- 拿分动作：先找数组长度 → 再找循环下标范围 → 每轮追踪 `a[i]` 的值 → 判断是否越界
- 易错标签：下标从 1 开始误判、`i <= n` 导致越界、数组整体赋值错误

**22. 一维数组最值与查找**
- 最值查找：先假设第一个元素为最值，循环从第二个开始比较，发现更大或更小就更新
- 顺序查找：从头到尾逐个比较，找到目标可记录位置或提前结束
- 折半查找 ⚡：前提数组已有序，使用 `low`/`high`/`mid` 表示查找区间，`mid=(low+high)/2`，目标小于中间值更新 `high=mid-1`，大于更新 `low=mid+1`
- 拿分动作：最值题追踪比较和更新，顺序查找追踪当前位置和标志变量，折半查找追踪 `low/high/mid` 三个变量
- 易错标签：最值初值随便设、顺序查找找到后没停止、折半查找忘记有序前提、`low <= high` 写成 `low < high`、左右边界更新写反

**23. 一维数组排序**
- 直接选择排序：每轮从未排序区找最值，找到后与当前位置交换，轮数通常是 `n-1`
- 冒泡排序：相邻两两比较，顺序不对就交换，每轮把一个最值送到边界
- 直接插入排序：把当前元素插入前面已有序序列，前面元素后移腾位置
- 顺序比较排序：双重循环比较任意两项，条件满足时交换
- 特殊排序：按个位排序用 `%10`，按十位排序用 `/10%10`，只排序偶数下标要限制下标范围
- 拿分动作：先判断升降序 → 判断比较的是元素本身还是某一位 → 找交换语句 → 用小数组追踪一轮
- 易错标签：外层循环次数错、内层边界错、升降序条件写反、交换时临时变量使用错误

**24. 一维数组插入、删除与移动**
- 插入有序数组：先找插入位置 → 从后往前移动元素 → 空出位置放入新元素 → 元素个数加 1
- 删除指定元素：找到要删除的位置 → 从该位置开始后一个覆盖前一个 → 元素个数减 1
- 分区存放：可把正数和负数分别放入不同区域，也可使用双指针或辅助数组
- 拿分动作：插入题看移动方向（通常从后往前），删除题看覆盖方向（通常从前往后），追踪元素个数 `n` 是否变化
- 易错标签：插入移动方向反导致覆盖、删除后没更新长度、循环边界少移或多移

**25. 二维数组**
- 定义：格式如 `int a[3][4];`，第一个下标行，第二个下标列
- 初始化：可按行初始化、部分初始化、按存储顺序初始化，初始化时可省略第一维不能省略第二维
- 常见题型：输入输出矩阵、杨辉三角、求每行平均值/最大值、求主对角线元素
- 拿分动作：外层循环控制行，内层循环控制列，访问元素写成 `a[i][j]`，表格题直接画行列表
- 易错标签：行列下标写反、省略第二维、二维数组下标越界、初始化顺序误判

### 2.7 函数（§26–§27）

**26. 函数基础**
- 函数定义：包含返回值类型、函数名、形参表、函数体
- 函数四种类型：无参无返回值、无参有返回值、有参无返回值、有参有返回值
- 函数调用：实参与形参按顺序对应，有返回值函数可参与表达式，无返回值函数不能当作值使用
- 函数声明：函数先调用后定义时通常要声明，声明说明函数名、返回值类型、参数类型，末尾有分号
- 常见题型：求两数最大值、求整数各位数字之和、求数组元素和、判断素数函数
- 拿分动作：先看返回值类型 → 看形参数量和顺序 → 调用时匹配实参 → 看返回值接给谁
- 易错标签：忘记函数声明、形参实参顺序错、有返回值函数没有 return、void 函数被当成表达式使用

**27. 函数进阶**
- 形参与实参：形参是定义中的参数，实参是调用时传入的值，普通变量传值时形参改变不影响实参
- 函数嵌套调用：一个函数内部可以调用另一个函数，先算内层再参与外层
- 递归调用：函数自己调用自己，必须有递归结束条件，常见于阶乘、递推、数字处理
- 数组作函数参数：数组元素作参相当于普通变量传值，数组名作参可在函数中修改数组元素，通常还要传长度
- 变量作用域：局部变量只在本函数或代码块中有效，全局变量在多个函数中可访问，同名变量优先使用局部
- 静态变量 static ⚡：静态局部变量只初始化一次，函数调用结束后值仍保留，常考多次调用后的累积效果
- 易错标签：以为形参改变影响实参、递归没有出口、数组名参数和数组元素参数混淆、static 多次初始化误判

### 2.8 字符串（§28–§29）

**28. 字符数组与字符串**
- 字符数组：一组字符元素，可逐个字符初始化，不一定是字符串
- 字符串：以 `\0` 作为结束标志，字符串常量用双引号，存储字符串的字符数组要留出 `\0` 位置
- 初始化：`char s[]="abc";` 实际包含 `a b c \0`，`char s[3]={'a','b','c'};` 不一定是字符串
- 常见题型：字符数组复制、字符串逆序输出、大小写转换、数字字符转数值、删除字符串中的数字字符
- 字符数字转换：数字字符转数值用 `ch - '0'`，数值转数字字符用 `x + '0'`
- 拿分动作：判断循环是否到 `\0` 结束、区分字符和字符串、字符处理题逐个下标追踪、删除字符题看覆盖和结束符处理
- 易错标签：忘记 `\0`、字符用双引号、字符串用单引号、删除后未补结束符

**29. 字符串函数**
- 头文件：常用字符串函数需要 `#include <string.h>`
- 输入输出：`gets` 输入一行（安全性差），`puts` 输出并自动换行
- `strlen`：求字符串长度，不包括 `\0`，与数组容量不同
- `strcat`：字符串连接，第二个接到第一个后面，第一个数组空间必须足够
- `strcpy`：字符串复制，把源复制到目标，目标空间必须足够
- `strcmp` ⚡：字符串比较，相等时返回 0，比较的是字典顺序不是长度
- 常见题型：比较两个字符串、统计字母/数字/空格个数、十进制转十六进制、统计单词个数
- 易错标签：用 `==` 比较字符串内容、以为 `strlen` 包括 `\0`、`strcmp` 返回 0 时才相等、目标数组空间不足

### 2.9 文件与结构体（§30–§31）

**30. 文件**
- 文件指针：`FILE *fp;`，操作结束后应关闭文件
- 打开文件：`fopen("文件名", "方式")`，成功返回文件指针，失败返回 `NULL`
- 打开方式：`r` 只读、`w` 写入（原内容可能被清空）、`a` 追加，`rb`/`wb` 二进制
- 字符读写：`fputc(ch, fp)` 写、`fgetc(fp)` 读
- 字符串读写：`fputs(str, fp)` 写、`fgets(str, n, fp)` 读
- 格式化读写：`fprintf(fp, 格式, 输出项)` 写、`fscanf(fp, 格式, 地址表)` 读
- 二进制读写：`fwrite` 写数据块、`fread` 读数据块
- 文件定位：`rewind(fp)` 回到开头、`fseek(fp, offset, origin)` 移动位置
- 文件检测：`feof(fp)` 检测文件结束、`ferror(fp)` 检测文件错误
- 拿分动作：先看文件打开方式 → 看使用哪个文件指针 → 读写函数看参数顺序 → 最后看是否关闭文件
- 易错标签：文件指针参数漏写、`fscanf` 忘记地址符、`w` 模式清空原文件、忘记 `fclose(fp)`

**31. 结构体**
- 基本概念：结构体把多个不同类型数据组合成一条记录，常用于学生、商品、成绩等
- 定义格式：`struct 结构体名 { 成员列表 };`，末尾要有分号
- 定义变量：可先定义结构体类型再定义变量，也可定义结构体时顺便定义变量，可定义结构体数组
- 成员访问：结构体变量访问成员用 `.`，如 `stu.score`；结构体数组用 `stu[i].score`
- 输入输出：输入整型/实型成员通常要加 `&`，输入字符数组成员通常不加 `&`
- 结构体数组：一个元素一条记录，循环下标表示第几条，排序和交换时常常整条记录一起交换
- 考试常见考法：找结构体定义行、判断成员、判断成员访问写法、补输入输出语句、按成员筛选或排序
- 结构体解题步骤：找 `struct` → 看结构体名 → 看成员名和类型 → 看变量或数组名 → 看成员访问表达式
- 易错标签：把结构体名当变量名、忘记点号、结构体数组下标从 1 开始误判、输入整型成员忘记 `&`、输入字符数组成员乱加 `&`
