## 验收标准（执行前定，做完按此判）

> 一句话：验的是「准全快真的发生了」，不是「我做了那些动作」。没有基线就没有验收；因果有延迟，所以分三层。

**第 0 层 · 基线（前置，不做不算开始）**
- 取 20 个真实查找问题（从过往真实场景抽，不现编）
- 记录当前：命中数 / 用时 / 幻觉数 → 后续所有提升都跟它比

**第 1 层 · 果的验收（把「准全快」变成可测数字）**
- 准：20 问命中正确文档 ≥ 18；幻觉 = 0（一票否决，出现即不合格）
- 全：该在库里的信息，漏检 ≤ 1
- 快：单问从提问到可用答案 ≤ 10 秒
- 溯源：答案能指回原文位置，覆盖 100%

**第 2 层 · 解锁验收（决定教育工作流能否启动）**
- 连续 3 次真实备课，全程无「找不到 / 不准 / 重找」
- 换一个主题仍能复用同一套流程（证明不是靠临场发挥）
- 达标 → 底座合格 → 教育工作流解锁

**每条任务的验收口径**
- 任何一条做完，验收 = 它宣称改善的那个指标，在基线上有可测提升
- 例：P0-4 关键词提命中 → 加字段前后，同一组 20 问的命中数对比
- 无量化指标的（如 C-6 基本功），只验「是否进入每周复盘并检查」，不验感觉
