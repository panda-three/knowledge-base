# 00-专注区 · 就近规则（_agent.md）

> 在本文件夹操作时**先读本文件**。区域规则 > 全局规则（AGENTS.md），冲突取更严格者。

---

## 区域定位

当前在做什么（时间维度工作台）。与六层「内容归宿」正交：**这里管「进行中」，六层管「最终放哪」**。一周一个 `_本周.md`，边界清晰。

## 区域结构

```
00-专注区/
├── _本周.md        ← 当前周工作台（Layer 1 工作记忆）
├── MEMORY_LOG.md   ← 记忆系统日志（认知类）
├── _agent.md       ← 本文件
└── _归档/          ← 历史周文件 YYYY-Wnn.md（只读）
```

## 周节奏（三阶段）

| 阶段 | 动作 |
|---|---|
| 周启动（周日/周一） | 用户口述 → AI 拆任务 → 确认计划，填入 _本周.md |
| 周中推进 | 增量更新任务/进展，AI 基于实际产出补整理，不强制重组 |
| 周末归档（周五~周日） | 确认产出 → 记忆复盘（按 `00-天一生水/03-基本法/07.复盘：回流流程.md`）→ _本周.md 改名 YYYY-Wnn.md 移入 _归档/ → 新建下周 |

## 五区块约定（_本周.md）

原始口述（AI 不编辑）/ 任务清单 / 参考材料 / 进展记录 / 本周文档。

## 操作规范

| 操作 | 权限 |
|---|---|
| 更新 _本周.md 任务/进展 | 自由（基于实际产出补整理） |
| 用户口头裁决 | 当场写入 _本周.md 进展记录，不留在对话里 |
| 写 MEMORY_LOG.md | 记忆变更时记一笔，认知类内容需用户确认 |
| 归档本周文件 | 周末进行，移入 _归档/ 后只读 |
| 删除历史周文件 | 需用户确认（过程数据保留原则） |

## 与其他区关系

- 任务用 `[项目名]` 标签关联到 01-05 内容层；周归档时**只动专注区**，内容层文件不动。
- 记忆复盘发现的稳定模式 → 提议写入根目录 `MEMORY.md`（需用户确认）。
