# 交付验收门禁（交付前必查，一项不过即返工）

## 1. 备注门禁

```bash
python scripts/verify_pptx.py <课件.pptx> --notes
```

- 总页数、每页备注字数、非空标记逐页列出；
- 每页备注必须非空且带标记（`AI初稿` 或教师原话版）；
- 缺一页备注 = FAIL，补齐后重验。

## 2. 动画 spid 校验

```bash
python scripts/verify_pptx.py <课件.pptx> --spid
```

- timing XML 引用的每个形状 ID 必须真实存在于该页 spTree（引用不存在的形状 = 放映时报错或动画丢失）；
- 同时列出每页点击步数与每组元素数，**逐元素出现页每组必须恰好 1 个元素**。

## 3. 渲染目检

```bash
python scripts/verify_pptx.py <课件.pptx> --render <输出目录>
```

- LibreOffice 转 PDF 再转 PNG，逐页读图检查：无文字溢出、无形状重叠、无空白页、无 CJK 方块；
- 封面、最高密度页、流程图页、动画页（看动画播完的终态）必查；
- 渲染图同时用于给教师预览（`aily-cli image upload` 取链接内联）。

## 4. 数据风险表

课件含经营数据、对外承诺、外部结论或影响决策的数字时，最终回复必须附数据风险与置信度说明（`场景/主张 | 事实状态 | 数据风险与限制 | 置信度 | 核验方式`）。事实状态仅限：已核验事实 / 待核验事实 / 虚拟示例 / 假设 / 理论推演 / 概念构想。教材原文照录 = 已核验；AI 常识级技术事实 = 待核验（注明"建议按教材口径核对"）。

## 5. 云盘交付

- PPTX 上传 `lark-cli drive +upload --as user --file <本地文件> --name "<中文名>.pptx"` 取链接；
- **迭代必须原地覆盖**：`--file-token <已有文件token>` 传同一文件，链接不变、版本历史可回退；覆盖后如文件名被还原为本地名，用 `drive +update-title --token <token> --type file --title "<中文名>"` 恢复；
- 预览图走 `aily-cli image upload`，以 Markdown 内联图嵌入评论，同一资源不重复挂载。

## 6. 逐页验收提示给教师

交付评论必须包含：改动页清单（页码+改了什么）、验证结果如实报备（哪项过了哪项没跑）、下一步动作（试讲采集或按页迭代）。不写"已完成"unless上述 1-3 全过。
