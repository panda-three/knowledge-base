# 视觉令牌 · 暗色科技风（用户 2026-09-11 定版，默认沿用）

> 来源：教师经 10 版风格选型馆对比后选定，代表作《AI时代的数据计算》32 页课件、《2.1 计算机解决问题的过程》11 页课件。其他教师/场景可换默认，但同一教师定版后不重新选型。

## 色板

| 令牌 | 色值 | 用途 |
| --- | --- | --- |
| BG 深空黑 | `#0E0E12` | 页面底色 |
| ACCENT 电光青 | `#22D3EE` | **唯一强调色**：关键词、连线、页眉横线、卡片顶光 |
| TEXT 银白 | `#E5E7EB` | 正文主文字 |
| SUB 灰 | `#8B90A0` | 次级文字、页码、提示语 |
| CARD 玻璃卡 | `#1A1C24` + 描边 `#2E3140`（1pt） | 内容卡片 |
| TERM 终端块 | `#0A0C10` | 代码/AI 提示词专用底色 |

## 版式元素

- **背景**：深空黑 + 点阵网格（`#262A36`，间距 48px，点半径 2px）+ 顶部青色微光。用 `darktech_lib.make_bg()` 生成。
- **页眉**：青色短横线（0.42"×3.2pt）+ mono 模块标签（如 `LESSON / FLOWCHART`）+ 右上页码（`04 / 11`）。
- **卡片**：圆角矩形（adjustment 0.055），玻璃卡填充+描边，顶部 2pt 青色光线（通栏减 0.56"）。
- **终端块**：卡片内用 `$` / `>` / `▊` 前缀的等宽行写规则、代码、状态。
- **流程图**：框体 TERM 填充 + ACCENT 描边 1.6pt，流程线 1.8~2.0pt 带箭头。
- **标题**：主标题 30~36pt，结论式——关键词用 ACCENT、其余 TEXT，一次点击只强调一个词。

## 字体

- 中文：微软雅黑（`set_ea` 同时设拉丁+东亚字体，否则中文回退宋体）
- 等宽/代码/页眉标签：Consolas

## 动画规范

- 教学节奏用**逐元素单击出现**（appear，非渐变飞入）：`add_click_appear(slide, [[id1], [id2], ...])`，一组 = 一个元素。
- **禁止多元素绑同一次点击**（教师明确要求"一个个出现，不要同时出现"——2.1 课实测修正）。
- 互动页初始只留起点元素（如流程图只留"开始"框），其余全部注册为点击序列。
- 钩子问句一律点击出现，不提前剧透。
