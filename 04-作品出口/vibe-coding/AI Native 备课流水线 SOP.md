# 《AI Native 备课流水线 SOP》

### 总原则
> **人给"人类三角 ＋ 数据食材"，AI 干"AI三角 ＋ 全部苦力"。**

| 角色       | 提供什么                                    |
| -------- | --------------------------------------- |
| **你（人）** | 审美（什么叫好）＋体系（结构）＋创造力（魂/独创）＋**数据食材（案例卡）** |
| **AI**   | 场景落地＋全部产出（框架→干货点→大纲→逐字稿→讲香→PPT）         |

### 运行五步（一轮课一次）
1. **投料**：把「知识底座」喂给AI（案例卡＋参数＋方法论＋好课样板）
2. **跑链**：依次跑 Prompt 1→7
3. **卡关**：每一步用「对表检查表」过一遍（审美/体系/创造力）
4. **成型**：产出 PPT＋逐字稿
5. **回流**：把本轮的定稿好段落，加进「好课样板」，下次更香

### 关键铁律（防翻车）
- **不投料 = 幻觉**：没喂案例卡，AI必编案例
- **不卡关 = 空课**：每步必过检查表，否则只是"漂亮的空课"
- **讲香必须人补**：AI做到60分，那20分靠你

## 件2 ｜7个 Prompt 模板（可直接复制）

### Prompt 1 · 魂
```
你是"一堂"的课程总设计师。基于我给的【课程参数】和【案例卡】，产出3个"魂"候选。
每个候选给：①一句话魂 ②三层拆解（认知层/能力层/结果层）③为什么能挂住双三角。
只输出"魂"，不要框架、不要大纲。
【课程参数】3天×6h／线下坐一屋／职场人零基础／学员只有手机／讲练50:50／产出2个智能体
【案例卡】（粘贴你的7张卡）
```

### Prompt 2 · 框架
```
基于已确定的魂，产出2-3个"框架"候选。
硬要求：框架必须是"认知爬升路径"（学员先学啥→再学啥），不是知识点清单。
每个框架给：三幕命名／每幕认知台阶（学员心里那句话）／每幕作品／每幕点亮哪个双三角维度。
```

### Prompt 3 · 干货点清单
```
针对选中框架的每一幕，三步走：
①狂码：把所有相关干货点全倒出来（做加法、不排序）
②分类：归入〔心智/方法/案例/动作/金句/工具〕六类
③排序：按"认知爬升"排教学顺序（不按重要性）
输出：每幕一张表。
```

### Prompt 4 · 大纲
```
把干货点排成时间轴。每天6h=360min。
规则：①训战≈50:50 ②每45-50min插一次休息 ③每天留30min机动兜底 ④标出〔训/战/休/机动〕
输出：时间段｜时长｜训战｜干货点｜动作
```

### Prompt 5 · 逐字稿
```
按大纲逐段铺逐字稿。
要求：口语、短句、教师第一人称；关键处标（停）；每段≤300字；凡是金句/故事/情绪处，标【此处要香】。
```

### Prompt 6 · 讲香
```
对指定段落，用"讲香十指模型"加工：
具象侧：场景/口语/数字/故事/素材
抽象侧：比喻/金句/情绪/冲突/升华
输出：①加工表（指→加工→结果）②加工后的逐字稿。
```

### Prompt 7 · PPT
```
把逐字稿转成PPT大纲。
要求：每页=一个观点；标题≤12字；要点≤3条、每条≤15字；标配图建议或演示动作；附"讲师口播注解"。
输出：页码｜标题｜要点｜配图/演示｜口播注解
```

## 件3 ｜案例卡模板（固化，以后照填）

```
【案例卡·名称】
1.一句话：它是什么／给谁／解决什么
2.起点：做之前的状态（对应"认知台阶"）
3.步骤：做了哪几步（能拆成Feature最好）
4.工具：用什么做的
5.数据：喂了什么资料
6.结果：硬数字（用户/省多少钱/省多少时间）
7.展示：能现场演示吗／有无截图
8.亮点：双三角哪个维度最突出
9.哇点：观众会"哇"的那一下
```

**你已定稿的7张**：生图网站／作业系统／知识库+Skill／网页版简历／用数据讲故事／贪吃蛇／你的故事。

## 件4 ｜人对表检查表（每步跑完必过）

| 关卡 | 审美 | 体系 | 创造力 | 判定 |
|---|---|---|---|---|
| 1.魂 | 打不打动人 | 是否自洽 | 是否够独特 | □过 □改 |
| 2.框架 | 台阶顺不顺 | 结构闭不闭 | 有没有新意 | □过 □改 |
| 3.干货点 | 案例香不香 | 分类清不清 | 有没有独创点 | □过 □改 |
| 4.大纲 | 节奏累不累 | 时间够不够 | 有没有惊喜点 | □过 □改 |
| 5.逐字稿 | 听得进去吗 | 逻辑顺吗 | 有没有记忆点 | □过 □改 |
| 6.讲香 | 够不够香 | — | — | □过 □改 |
| 7.PPT | 好不好看 | 结构清吗 | — | □过 □改 |
