# 工作稿版本约定（2026-09-28 起生效）

**规则：所有文件更新一律"新增版本"，保留过程数据，不覆盖原文件。**

## 命名规范

| 场景 | 做法 | 示例 |
|---|---|---|
| 首次创建 | `文件名-v1.md` 或 `文件名.md`（首个版本，头部标注 v1） | 01-生图网站-案例打磨稿-v1.md |
| 内容更新 | **新开** `文件名-v2.md`（或 v3/v4…），原版本文件原样保留 | 01-生图网站-案例打磨稿-v2.md |
| 方向性变更 | 版本号＋变更说明，如 `-v2-集中版`、`-v1-分散版` | 01-生图网站-案例大纲-v2-集中版.md |
| 无版本号主文件 | = 当前最新版，头部注明"最新版 vX，历史版本见 -vX" | 01-生图网站-案例大纲.md（v2集中版） |

## 每条版本文件的头部必备

1. `状态：vN（历史版本，保留过程数据）` 或 `状态：vN（当前最新版）`
2. 一句话说明本版与上一版的关键差异
3. 指引：历史版本见哪些文件／最新版见哪个文件

## 为什么这样做

- 过程数据（打磨取舍、被推翻的设计、数字的演变）是可复用资产——v1 分散版被推翻的"为什么"本身就是经验。
- 可追溯：任何一轮改动都能回看当时的口径和依据。
